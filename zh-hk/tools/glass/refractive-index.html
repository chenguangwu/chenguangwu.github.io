📋 常見介質折射率

斯涅爾定律：n₁·sinθ₁ = n₂·sinθ₂，故 θ₂ = arcsin(n₁·sinθ₁ / n₂)。
全反射：當 n₁ > n₂ 且入射角大於臨界角 θc = arcsin(n₂/n₁) 時發生全反射，光線不進入 n₂。
色散：折射率隨波長變化（如冕牌玻璃 n 藍光 > 紅光），導致色散（阿貝數 Vd 衡量）。
視深：從空氣看水中物體，視深 = 實深 × (n₂/n₁) = 實深 / 1.33，故水中物體看起來更淺。
