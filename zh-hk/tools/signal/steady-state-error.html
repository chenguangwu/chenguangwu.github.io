Steady State Error

Steady State Error is available directly in your browser, with no data uploaded.

📐 計算公式
e_ss = 1 / (1 + K_p)

0 型單位反饋系統在單位階躍輸入下的穩態誤差。

📌 計算説明
  • e_ss = 1/(1+K_p)（0 型系統、單位階躍）。
  • K_p=9 時 e_ss=0.1（10%）。

📚 深度解析：階躍穩態誤差（e_ss = 1 / (1 + K_p)）

💡 常見使用場景

  • 在複核 階躍穩態誤差（e_ss = 1 / (1 + K_p)） 時，先檢查輸入量綱（Hz、V、Ω、%）是否統一，再做一次樣例演算，可快速發現口徑偏差導致的量級錯誤。
  • 教學複核：把單變量固定、逐步變更一個參數，觀察輸出趨勢，建立參數-結果敏感度認知。
  • Steady State Error
快速複核「階躍穩態誤差（e_ss = 1 / (1 + K_p)）」
先用一組簡單樣例計算得到直觀結果，隨後逐步調整一項輸入參數確認變化趨勢是否符合物理直覺，再對比多次輸入以排除邊界誤差。

❓ 常見問題（FAQ）

階躍穩態誤差（e_ss = 1 / (1 + K_p)） 結果可直接用於決策嗎？
階躍穩態誤差（e_ss = 1 / (1 + K_p)） 僅做本地公式計算和展示，適合教學、驗算與參數複核，正式決策建議結合原始標準、工藝約束與量綱定義再次確認。
為什麼和預期差距很大？
優先核對輸入單位、取值範圍和是否存在百分號/小數混寫；再比較分子分母口徑是否一致（如總功率/有效值/週期）。
