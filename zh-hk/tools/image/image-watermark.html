📝 工具簡介

圖片水印工具是一款基於 Canvas API 的純前端在線圖片加水印工具。無需安裝軟件，上傳圖片後即可添加文字水印或圖片水印，支持 9 宮格快速定位、自定義座標、全圖平鋪與旋轉角度，實時預覽效果並一鍵導出 PNG/JPEG/WebP，所有處理在瀏覽器本地完成，圖片不會上傳到伺服器。

✨ 功能特點

  • 拖拽或點擊上傳圖片
  • 文字水印：字體/字號/顏色/透明度/描邊
  • 圖片水印：上傳水印圖/縮放/透明度
  • 9 宮格快速定位
  • 自定義 X/Y 座標精確定位

  • 支持深色模式與響應式

💬 常見問題

圖片會被上傳到伺服器嗎？
不會。所有圖片讀取、水印繪製、導出均在你的瀏覽器本地通過 Canvas API 完成，圖片數據不會離開你的設備。
平鋪水印的旋轉角度有什麼用？
旋轉角度讓平鋪的水印呈對角線分佈（如 -30°），比正交排列更美觀且更難被裁剪去除，是常見的防盜水印樣式。配合"偏移錯位"可讓相鄰行交錯排列。
導出 PNG 還是 JPEG？
PNG 為無損格式且支持透明背景，適合需要高保真的場景；JPEG 為有損壓縮，文件更小但不支持透明；WebP 兼顧質量與體積。建議版權水印優先用 PNG。
支持的最大圖片尺寸？
取決於瀏覽器 Canvas 的內存限制，一般支持千萬像素級圖片。超大圖片可能導致處理變慢，建議適當壓縮後再加水印。
⚠️ 使用説明與注意事項
  • 本工具純前端運行，圖片文件不會上傳到伺服器
  • 建議在主流瀏覽器（Chrome / Safari / Firefox / Edge）中使用
  • JPEG 格式不支持透明，導出時背景為白色
  • 超大圖片處理可能需要數秒，請耐心等待預覽刷新
  • 調整任意參數會實時刷新預覽，所見即所得
