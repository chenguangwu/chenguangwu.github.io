📝工具簡介

圖片拼圖合成工具是一款免費的在線拼圖生成器，可將多張圖片按豎排、橫排或網格佈局合成為一張長圖或拼圖。基於瀏覽器 Canvas API 實時渲染，支持自定義間距、外邊距、背景色、適應方式與拖拽排序，合成後可導出 PNG 或 JPG 圖片。所有處理在本地完成，圖片不會上傳伺服器。

✨功能特點

  • 多圖上傳，支持拖拽排序與上下移動
  • 豎排拼接、橫排拼接、2×2 / 3×3 / 自定義網格
  • 可調圖片間距（0~50px）與外邊距
  • 自定義背景色，支持透明背景（PNG）
  • 自適應尺寸或固定寬度/高度
  • 網格適應方式：完整顯示、填滿裁剪、拉伸
  • 實時預覽，一鍵下載 PNG / JPG
  • 純前端處理，圖片不上傳，保護隱私

🎯使用場景

  • 將多張截圖豎排拼接為長圖分享
  • 製作朋友圈、小紅書九宮格拼圖
  • 產品多圖合成一張展示圖
  • 組合證件照、簽證照排版
  • 旅行照片拼接成長卷預覽
  • 課程筆記、聊天記錄合併為長圖

💬常見問題

我的圖片會被上傳到伺服器嗎？
不會。所有圖片都在你的瀏覽器本地通過 Canvas 處理，不會發送到任何伺服器，隱私安全有保障。
支持哪些圖片格式？
支持 PNG、JPG/JPEG、WEBP、GIF、BMP 等瀏覽器可解碼的常見格式，可一次選擇多張。
網格佈局圖片數量不夠怎麼辦？
圖片數量少於網格格子數時，多餘格子會顯示為背景色；圖片數量多於格子數時，僅合成前若干張（可在預覽信息中看到提示）。
為什麼導出的圖片很大？
合成畫布尺寸由圖片數量與佈局決定，圖片越多越大。可在「尺寸模式」中選擇固定寬度/高度來控制輸出尺寸，工具也會在畫布過大時自動等比縮放以保證合成成功。
透明背景有什麼用？
勾選透明背景後，導出的 PNG 會保留透明區域（適合完整顯示留白模式）；若下載 JPG，會自動填充白色背景。
