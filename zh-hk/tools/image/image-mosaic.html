📝工具簡介

圖片馬賽克效果工具是一款在線圖像處理工具，可將圖片像素化以實現打碼遮擋效果。支持全圖馬賽克與局部區域框選馬賽克兩種模式，可通過滑塊自由調節像素塊大小並實時預覽，處理完成後可下載 PNG 或 JPEG 圖片。所有運算均在瀏覽器本地完成，圖片不上傳伺服器，隱私安全有保障。

✨功能特點

  • 純前端 Canvas 處理，圖片不上傳
  • 全圖馬賽克與區域框選馬賽克兩種模式
  • 像素塊大小 2~50px 自由調節，實時預覽
  • 支持拖拽上傳與觸摸框選，移動端友好
  • 按原圖分辨率導出 PNG/JPEG，畫質無損
  • 支持深色模式與響應式佈局

🎯使用場景

  • 遮擋身份證、車牌、人臉等隱私信息
  • 給分享截圖中的敏感內容打碼
  • 製作像素化風格的創意圖片
  • 隱藏圖片中的文字、水印或賬號信息
  • 對局部區域進行模糊遮擋處理
  • 隱私敏感場景下的本地圖片處理

💬常見問題

這個工具是免費的嗎？
完全免費，無需註冊登錄，直接在瀏覽器中打開即可使用。
我的圖片會被上傳到伺服器嗎？
不會。所有馬賽克處理都在你的瀏覽器本地通過 Canvas API 完成，圖片數據不會發送到任何伺服器，充分保護隱私。
如何只對圖片的某一部分打馬賽克？
點擊「區域馬賽克」切換到區域模式，然後在圖片上按住滑鼠或手指拖拽框選需要打碼的區域，鬆手後即可實時看到效果，可反覆拖拽調整。
像素塊大小設為多少比較合適？
一般 8~30px 效果較好：數值越大遮擋越徹底但越粗糙，數值越小越精細但可能仍能辨認細節。請根據遮擋需求調節。
下載的圖片是原始分辨率嗎？
是的，下載時會按圖片原始分辨率重新渲染馬賽克效果，不會因為預覽縮放而降低畫質。PNG 為無損格式，JPEG 文件更小。
支持哪些圖片格式？
支持 JPG、PNG、WebP、GIF、BMP 等主流圖片格式，導出時可選擇 PNG 或 JPEG。
