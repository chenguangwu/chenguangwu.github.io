📝工具簡介

GIF分解工具是一款圖像處理類的在線工具，用於將 GIF 動畫逐幀分解提取。工具直接在瀏覽器中解析 GIF 二進制格式（GIF89a），還原每一幀畫面，支持單幀下載 PNG 與批量打包 ZIP，所有處理本地完成，文件不上傳。

✨功能特點

  • 純前端解析，GIF 不離開設備
  • 逐幀提取，顯示幀序號與延遲時間
  • 正確處理透明色與幀疊加合成
  • 單幀下載 PNG，批量打包 ZIP
  • 點擊縮略圖放大預覽，支持前後切換
  • 顯示總幀數、尺寸、循環次數等信息
  • 支持深色模式與響應式佈局

🎯使用場景

  • 提取 GIF 動畫的某一幀做素材
  • 將 GIF 轉為 PNG 序列幀
  • 分析 GIF 的幀率與延遲設置
  • 逐幀查看動畫細節與過渡
  • 獲取 GIF 透明通道的單獨幀
  • 隱私敏感的動圖處理需求

💬常見問題

這個工具是免費的嗎？
完全免費，無需註冊，直接在瀏覽器中使用。
我的 GIF 會被上傳嗎？
不會。所有解析與處理都在瀏覽器本地完成，GIF 文件不會發送到任何伺服器。
提取的幀是什麼格式？
每一幀可導出為 PNG 格式（支持透明通道），也可批量打包為 ZIP 下載。
為什麼有的幀看起來是空白的？
部分 GIF 使用了幀疊加（disposal）與透明色，某些幀只包含變化部分。本工具會按規範合成完整畫面，每幀均為完整可見圖。
循環次數顯示為「無限循環」是什麼意思？
GIF 的 NETSCAPE 循環標記為 0 表示無限循環；若為 N 則表示循環 N 次。
