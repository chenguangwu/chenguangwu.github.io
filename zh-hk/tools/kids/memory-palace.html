🏰 Memory Palace

Memory Palace is available directly in your browser, with no data uploaded.

📐 工作原理與説明

記憶宮殿（Method of Loci）把待記項編碼為生動意象，依次“放置”在熟悉的空間路徑（房間、路線）上，回憶時沿路徑提取。數字常用 00–99 雙位編碼（每數對應一個形象）轉成可掛鈎的意象。

  • 編碼越誇張、多感官，提取越牢；路徑越熟悉越穩定。
  • 本工具生成編碼表與練習序列，純本地、不上傳。

📋 編碼對照表

使用方法：把要記的內容拆成"片段"，依次放入虛擬格子的固定位置。回憶時只需按順序"走進"每個格子取出片段。點擊"開始回憶"可隱藏內容進行自測，點擊格子揭示答案。
