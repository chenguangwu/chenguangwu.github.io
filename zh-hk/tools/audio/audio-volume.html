📝工具簡介

音頻音量調節工具基於瀏覽器原生 Web Audio API 的 GainNode 節點，實時調節音頻文件的音量增益，範圍從 0%（靜音）到 200%（放大兩倍）。支持播放控制、進度拖動、漸入漸出、VU 音量表可視化，並可將調整後的音頻導出為標準 WAV 文件。所有處理均在瀏覽器本地完成，音頻文件不會上傳到任何伺服器。

✨功能特點

  • Web Audio API GainNode 實時增益
  • 音量範圍 0% ~ 200%
  • 靜音/50%/100%/150%/200% 快捷預設
  • 播放/暫停與進度條拖動
  • 漸入漸出效果（0-10 秒）
  • VU 表實時電平可視化
  • OfflineAudioContext 導出 WAV
  • 純前端處理，文件不上傳
  • 支持深色模式與響應式佈局

🎯使用場景

  • 音頻音量過小需要放大
  • 錄音文件音量過大需要降低
  • 製作帶淡入淡出效果的音頻
  • 統一多個音頻文件的響度
  • 音頻後期處理與剪輯
  • 播客/視頻配音音量調整

💬常見問題

音量調到 200% 會有雜音怎麼辦？
增益超過 100% 時可能出現削波失真（clipping）。建議適度提升，若原始音頻電平已接近滿幅，放大後會產生爆音，可配合淡入淡出或適當降低增益。
為什麼導出的是 WAV 而不是 MP3？
WAV 是無壓縮格式，可通過 Web Audio API 的 OfflineAudioContext 直接編碼生成，無需第三方庫。MP3 編碼需要專門的編碼器庫，為保證純前端輕量運行，本工具導出 WAV。
淡入淡出在實時播放時生效嗎？
實時播放時僅應用基礎音量增益以保證流暢體驗；淡入淡出效果在導出 WAV 時完整應用，確保導出文件包含完整的漸變效果。
支持哪些音頻格式？
支持瀏覽器可解碼的所有格式，包括 MP3、WAV、OGG、M4A、FLAC 等（具體取決於瀏覽器支持）。導出統一為 WAV 格式。

用一組真實口徑樣本執行一次計算，保存輸入截圖與輸出記錄，再對一個邊界場景複測，確認是否穩定。

❓ 常見問題（FAQ）

audio 業務裏如何快速落地？
先抽取3-5個典型樣本定義口徑，再把所有輸入按該口徑映射後運行，輸出用於討論決策。
發現輸出不一致怎麼辦？
先確認字段單位和時點定義，再回傳人工樣本複核，避免直接基於異常結果做業務動作。
⚠️ 使用説明與注意事項
  • 本工具純前端運行，音頻文件不會上傳到伺服器，隱私安全
  • 增益超過 100% 可能產生削波失真，建議適度調整
  • 建議在主流瀏覽器（Chrome/Safari/Firefox/Edge 最新版）中使用
  • 大文件導出 WAV 需要一定處理時間，請耐心等待
