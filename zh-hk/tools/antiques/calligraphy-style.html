📋 書體演變簡史

書體演變：甲骨文(商) → 金文(周) → 大篆(春秋戰國) → 小篆(秦) → 隸書(漢) → 楷/行/草(魏晉定型) → 沿用至今。

筆法演變：篆書圓轉中鋒 → 隸書方折波磔 → 楷書提按頓挫 → 行書流暢連帶 → 草書簡練奔放。

時代風格："晉人尚韻、唐人尚法、宋人尚意、明人尚態、清人尚碑"。每個時代的書法審美取向不同，是斷代的重要依據。

鑑定要點：紙張/絹帛材質、墨色、印章、題跋、著錄等輔助斷代。筆法、結體、氣韻需與傳世標準件比對。本表供學習參考，真偽鑑定需專業機構。
