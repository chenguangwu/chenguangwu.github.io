👂 關於耳訓練器 ▼

耳訓練器是一款基於 Web Audio API 的在線聽音訓練工具，幫助你提升音樂聽力技能。通過反覆練習音程和和絃的識別，你可以更快地聽辨音高關係，為視唱練耳、即興演奏和音樂創作打下堅實基礎。

✨ 功能特點

  • 音程識別（12種音程）
  • 和絃識別（大三/小三/增三/減三）
  • 三種難度級別
  • 同時發聲 / 琶音兩種播放方式
  • 實時統計與連擊計數
  • 純前端處理，無需聯網

🎯 使用場景

  • 音樂學生日常練耳
  • 樂理課程輔助訓練
  • 合唱團 / 樂隊聽力訓練
  • 音樂愛好者自學提升

❓ 常見問題

需要聯網使用嗎？
不需要。本工具完全在瀏覽器中運行，使用 Web Audio API 合成音色，無需下載任何音頻文件或連接伺服器。
為什麼聽不到聲音？
請確保設備未靜音，音量已打開。部分瀏覽器首次訪問時需要用户交互後才能播放音頻，請先點擊頁面任意位置再使用。

❓ 常見問題（FAQ）

耳訓練器 可直接用於正式報告嗎？
適合用於快速核對和教學演示；正式報告建議補充數據來源、口徑定義、邊界條件與審核責任鏈。
值跳變或異常偏差怎麼辦？
先核查輸入是否超出定義域、單位是否混用、以及參數是否按同一計算版本口徑輸入。

  • 建議在主流瀏覽器（Chrome/Safari/Firefox/Edge）中使用
  • 計算結果僅供參考，請以實際應用場景為準
