📐 計算公式
Ra = up·Σ(qsi·li) + qp·Ap

單樁豎向承載力特徵值 Ra = 樁周總側阻 + 樁端阻力
up = π·d（樁周長），Ap = π·d²/4（樁端面積）
需要樁數 n = N / Ra（取整，並適當富餘）

💡 本公式適用於摩擦樁及端承摩擦樁；端承樁以樁端阻力為主。承載力特徵值已含安全係數，實際設計須按《建築樁基技術規範》JGJ 94 驗算。
