Pell-Gregory 分類説明

水平分類（與升支關係）

• Class Ⅰ：升支前緣與第二磨牙遠中面間有足夠間隙容納智牙冠近遠中徑

• Class Ⅱ：間隙小於智牙冠近遠中徑

• Class Ⅲ：智牙全部位於升支前緣內側

深度分類（與咬合平面關係）

• Class A：智牙咬合面與第二磨牙咬合平面平齊（最高位）

• Class B：介於咬合平面與第二磨牙釉牙骨質界之間

• Class C：低於第二磨牙釉牙骨質界（最深位）

難度評分參考（Pederson難度指數）

水平：Class Ⅰ=1分，Ⅱ=2分，Ⅲ=3分

深度：A=1分，B=2分，C=3分

方向：垂直=1分，近中=2分，水平=3分，遠中=4分
