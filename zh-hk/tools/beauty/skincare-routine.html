📋 你的專屬護膚流程

📌 護膚基本原則

  • 潔面：温和清潔，避免過度清潔破壞屏障
  • 化妝水：二次清潔、補水、打開吸收通道
  • 精華：功效性產品，分子小先塗
  • 眼霜：眼周肌膚薄，需要專門護理
  • 乳液/面霜：保濕鎖水，封住前面的營養
  • 防曬：白天最後一步，抗老的關鍵

🔄 正確順序口訣

水 → 精華 → 眼 → 乳 → 霜 → 防曬

質地從稀到稠，分子從小到大。先塗水質，再塗油質。

❌ 不能一起用的成分

酸類 + 酸類
水楊酸+果酸、水楊酸+維A醇 = 過度去角質，屏障受損
維A醇 + 高濃度酸
A醇+果酸/水楊酸 = 刺激性翻倍，容易泛紅脱皮
維C + 煙酰胺
高濃度原型VC（pH<3.5）+煙酰胺 = 可能轉化為煙酸刺激皮膚
銅肽 + 維C
藍銅胜肽遇到維C會被氧化失活
蛋白酶 + 強酸
酶類去角質成分在強酸環境下失活
✅ 安全搭配：
• 早C晚A（但需建立耐受）
• 煙酰胺 + A醇（黃金搭配）
• 神經酰胺 + 任何成分（修護+功效）
• 玻尿酸 + 任何成分（百搭補水）

📏 各產品標準用量

產品用量直觀參考
潔面1-2g黃豆到花生米大小
化妝水1-2ml浸透化妝棉/一元硬幣
精華0.3-0.5g2-3滴，黃豆大小
眼霜0.1g米粒大小，每隻眼
乳液0.5-1g1-2個黃豆大小
面霜0.8-1g花生米大小
防曬1-2mg/cm²一元硬幣大小（全臉）
⚠️ 用量不足等於白用！尤其是防曬，塗不夠量完全沒有防護效果。
