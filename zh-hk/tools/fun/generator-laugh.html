📐 工作原理與説明

笑聲由 Web Audio API 在瀏覽器內實時合成,不涉及任何第三方音頻素材:

  • 基頻振盪器(sawtooth / square)模擬聲帶"哈"的頓挫。
  • ADSR 包絡控制每個"哈"的起音/衰減/釋放,形成節奏。
  • LFO 顫音 + 共振峯(formant)濾波逼近人聲元音音色。

參數隨機微調產生多樣的"哈哈哈"。合成音頻可自由下載使用,無版權風險。

本生成器依據指定格式規範在前端按規則隨機或確定性生成內容，結果可直接複製使用，數據不離開瀏覽器。 工具名稱：笑聲音效生成器（合成）。
