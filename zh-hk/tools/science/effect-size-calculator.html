📊 Effect Size Calculator

📋 Cohen's d 解釋

d = (M − μ₀) / SD  |  雙樣本 d = (M₁ − M₂) / SD_pooled
Cohen's d 經驗判讀：
• |d| ≈ 0.2：小效應
• |d| ≈ 0.5：中等效應
• |d| ≈ 0.8：大效應
• |d| > 1.3：極大效應
注意：效應量與顯著性互補；前者衡量"差異大小"，後者衡量"差異可信度"。
