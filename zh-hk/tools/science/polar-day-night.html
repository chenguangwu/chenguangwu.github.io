📖 極晝極夜原理

基本概念

  • 極晝：太陽連續24小時以上不落下的現象
  • 極夜：太陽連續24小時以上不升起的黑暗時期
  • 北極圈：66°33'56" N（約66.56°）
  • 南極圈：66°33'56" S（約66.56°）

太陽赤緯公式

太陽赤緯 δ = 23.44° x sin(2π x (N+284) / 365)

其中 N 為年內第幾天（1月1日 N=1），23.44° 為黃赤交角

當 δ > 0 時（夏至附近），北極晝南極夜

當 δ < 0 時（冬至附近），北極夜南極晝

極晝極夜天數與緯度的關係

  • 66.56°（極圈）：極晝/極夜各約1天
  • 70°：極晝約65天，極夜約60天
  • 75°：極晝約105天，極夜約95天
  • 80°：極晝約135天，極夜約125天
  • 90°（極點）：極晝/極夜各約半年
此計算為理論值，未考慮大氣折射（太陽在地平線下約34'仍可見）、地形遮擋等因素。實際極晝極夜天數可能略有不同。
