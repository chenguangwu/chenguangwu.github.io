📱 Screen Size

📐 計算公式
對角線像素 = √(寬² + 高²)

Screen Size is available directly in your browser, with no data uploaded.

📐 計算公式

對角線像素 = √(寬² + 高²)

PPI = 對角線像素 ÷ 對角線英寸

每英寸物理寬 = 分辨率寬 ÷ PPI

長寬比 = 寬 : 高（化簡）

點距 = 25.4 ÷ PPI（mm）

提示：PPI 越高顯示越細膩，手機一般 300+ PPI 為視網膜級別。長寬比化簡使用最大公約數。
