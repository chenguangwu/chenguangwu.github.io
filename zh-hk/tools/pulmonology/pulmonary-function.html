📋 通氣功能障礙判讀邏輯

類型條件説明
正常FEV1/FVC ≥ 閾值 且 FVC ≥ 80%預計通氣功能正常
阻塞性FEV1/FVC < 閾值氣流受限，常見於COPD/哮喘
限制性FEV1/FVC ≥ 閾值 且 FVC < 80%預計需TLC確認，見於肺纖維化/胸壁疾病
混合性FEV1/FVC < 閾值 且 FVC < 80%預計同時存在阻塞與限制

📊 GOLD 阻塞性氣流受限嚴重度（基於 FEV1%預計值）

分級嚴重度FEV1 %預計值
GOLD 1輕度≥80%
GOLD 2中度50–79%
GOLD 3重度30–49%
GOLD 4極重度<30%
提示：FEV1/FVC 固定閾值 0.70 對年輕人可能高估、對老年人可能低估阻塞性疾病，建議結合 LLN(正常下限) 綜合判讀。限制性障礙需肺總量(TLC)確認。支氣管舒張試驗後 FEV1/FVC<0.70 提示不完全可逆氣流受限(COPD)。僅供臨牀參考。
