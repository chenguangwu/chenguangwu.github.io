📋 BASDAI 計算方法

公式：BASDAI = (Q1 + Q2 + Q3 + Q4 + (Q5 + Q6)/2) / 5

第5、6項（晨僵嚴重程度和持續時間）取平均值後與其他4項加總，再除以5。

📊 BASDAI 臨牀意義

BASDAI疾病活動度臨牀決策
<4低活動度維持NSAIDs+功能鍛鍊
≥4高活動度考慮啓動抗TNF生物製劑
≥4 + ASDAS≥2.1高活動度(確認)推薦生物製劑/JAK抑制劑
提示：BASDAI≥4是ASAS/EULAR推薦啓動抗TNF生物製劑治療的主要標準之一。BASDAI主觀性較強，建議結合ASDAS(含CRP/ESR的客觀指標)綜合評估。ASDAS-CRP = 0.12×腰背痛 + 0.06×晨僵持續時間 + 0.07×患者總體 + 0.11×CRP(√)。僅供臨牀參考。
