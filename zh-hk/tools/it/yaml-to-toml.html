🔧 YAML 轉 TOML 轉換器

在 Rust/Go 項目配置、pyproject、Cargo.toml 等場景常需要在 YAML 與 TOML 之間遷移。粘貼 YAML，立即得到結構等價的 TOML。

📐 工作原理與説明

遞歸將 YAML 結構轉為 TOML：映射 → [section] 表（嵌套映射用 [a.b] 點分層級）；列表 → 數組；標量按類型輸出（字符串加引號、數字/布爾直出）。YAML 錨點/合併鍵先展開再轉換。

  • TOML 不支持 YAML 的任意鍵順序語義，表需先於引用出現。
  • 純前端轉換，數據不離開瀏覽器；粘貼即轉，支持嵌套與註釋保留策略。
⚠️ 使用説明與注意事項
  • 轉換按結構等價進行：YAML 映射→TOML 表，YAML 列表→TOML 數組；嵌套映射會展開為 [section] 小節。
  • TOML 不支持 YAML 的錨點/合併（&anchor、*alias）與多行摺疊，這類高級語法會被忽略或報錯。
  • 字符串中含特殊字符（冒號、#、方括號等）會自動加引號以保證 TOML 合法。

📋 YAML ↔ TOML 對照

YAMLTOML
key: valuekey = "value"
list:\n - a\n - blist = ["a", "b"]
[a, b, c]arr = ["a", "b", "c"]
parent:\n child: 1[parent]\nchild = 1

本工具支持常見子集（映射、列表、標量、註釋、嵌套小節）；極複雜 YAML 建議先用 JSON 中轉。
