💾 File Size Unit Converter

Convert file sizes between decimal (SI) and binary (IEC) units.

📐 工作原理與説明

本工具用於單位與格式換算，換算因子依據國際單位制(SI)及相關標準定義，結果保留輸入精度；純前端本地處理。 工具名稱：文件大小單位換算 - 在十進制（SI）與二進制（IEC）單位之間快速換算文件大。

📌 單位説明
  • SI 十進制：1 KB = 1,000 B，1 MB = 1,000 KB（硬碟廠商常用）。
  • IEC 二進制：1 KiB = 1,024 B，1 MiB = 1,024 KiB（作業系統常用）。
  • Windows 顯示的“GB”實際為 GiB，Mac 顯示的“GB”通常為十進制 GB。
