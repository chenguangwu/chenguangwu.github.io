🌐 HTTP 方法速查

HTTP 方法（動詞）描述對資源執行的操作。理解 safe（安全）與 idempotent（冪等）有助於設計可緩存、可重試的 RESTful 接口。選擇方法即可查看詳情。

📐 工作原理與説明

本開發工具在前端本地完成解析、轉換與處理，代碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：HTTP 方法速查。

⚠️ 使用説明與注意事項
  • Safe（安全）：方法不應改變伺服器狀態，GET/HEAD/OPTIONS/TRACE/CONNECT 中除 CONNECT 外被視為安全方法，可緩存。
  • Idempotent（冪等）：多次相同請求產生相同最終狀態，GET/PUT/DELETE/HEAD/OPTIONS/TRACE 冪等，POST/PATCH 不保證。
  • REST 約定：查詢用 GET、整體新建用 POST、整體更新用 PUT、局部更新用 PATCH、刪除用 DELETE。
