▶️ 工具介紹 ▼

在線代碼運行器是一款純前端代碼編輯與預覽工具，支持 HTML、CSS、JavaScript 三種語言的實時編輯和運行。

🔥 功能特點

  • 三欄代碼編輯（HTML / CSS / JS）
  • iframe 沙箱安全運行
  • console.log / warn / error 輸出捕獲
  • 實時預覽模式（300ms 防抖）
  • 5 套內置示例代碼
  • 一鍵複製 / 清空代碼
  • 深色模式支持
  • 移動端自適應佈局

🏠 使用場景

  • 快速測試 HTML/CSS/JS 代碼片段
  • 前端學習與教學演示
  • 調試 UI 組件和動畫效果
  • 代碼面試在線手寫驗證

❓ 常見問題

代碼運行安全嗎？
代碼在 iframe 的 sandbox 模式中運行，僅允許腳本執行，限制了對外部資源的訪問，確保安全性。
為什麼控制台沒有輸出？
請確認代碼中使用了 console.log() 等方法，並且 iframe 已成功加載運行。如果控制台面板被摺疊，點擊面板標題即可展開。
