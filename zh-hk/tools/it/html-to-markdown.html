🔁 HTML to Markdown

HTML to Markdown

📐 工作原理與説明

本工具用於單位與格式換算，換算因子依據國際單位制(SI)及相關標準定義，結果保留輸入精度；純前端本地處理。 工具名稱：HTML 轉 Markdown。

📌 説明
  • 基於解析後的 DOM 節點逐層轉換，保留多層列表結構。
  • 支持 h1~h3、p、ul/ol、table、a、img 與代碼塊。
  • 輸出為純 Markdown 文本，未聯網處理。
