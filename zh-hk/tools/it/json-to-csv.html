📊 JSON to CSV

JSON to CSV is available directly in your browser, with no data uploaded.

📐 工作原理與説明

將 JSON 對象數組展平為二維表格的邏輯:

  • 遞歸下鑽嵌套對象/數組,鍵名以"·"或"."合併為列名(如 user.name)。
  • 每個數組元素輸出一行;值轉為字符串(布爾、數字、日期原樣)。
  • null / 缺失字段留空;數組經索引展開。

導出建議帶 UTF-8 BOM,以便 Excel 正確識別中文不亂碼。全程純前端解析,數據不上傳。

本開發工具在前端本地完成解析、轉換與處理，代碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：JSON 轉 CSV - 把 JSON 數組一鍵轉為 CSV。
