📚 算法原理

什麼是維吉尼亞密碼？

維吉尼亞密碼（Vigenère cipher）是一種多表替換密碼，由法國密碼學家布萊斯·德·維吉尼亞於16世紀完善。它使用一個關鍵詞作為密鑰，對明文的每個字母使用不同的凱撒密碼進行加密。

加密公式

Ci = (Pi + Ki) mod 26

其中 C 是密文，P 是明文，K 是密鑰（循環重複）。

解密公式

Pi = (Ci - Ki + 26) mod 26

工作原理

1. 選擇密鑰：例如密鑰為 "LEMON"
2. 重複密鑰：將密鑰重複直到與明文長度相同
3. 逐字符加密：每個明文字母與對應密鑰字母在維吉尼亞方陣中查找交叉點
4. 得到密文：所有交叉點字母連接起來就是密文

歷史意義

維吉尼亞密碼曾被認為是"不可破譯的"（法語：le chiffre indéchiffrable），直到19世紀被弗里德里希·卡西斯基和查爾斯·巴貝奇分別破解。它是古典密碼學的巔峯之作。

安全弱點

• 密鑰重複使用導致週期性
• 卡西斯基試驗和重合指數法可確定密鑰長度
• 確定密鑰長度後，每一列都是一個凱撒密碼，可通過頻率分析破解
