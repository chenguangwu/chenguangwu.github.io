YAML Grammar Verifier is available directly in your browser, with no data uploaded.

📐 工作原理與説明

  • 常見錯誤：冒號後缺空格、混用 Tab/空格、字符串含特殊字符未加引號。

💬常見問題

    
YAML 驗證失敗提示縮進錯誤怎麼辦？
YAML 嚴格要求使用空格縮進且同一層級縮進必須一致，不能混用 Tab 和空格。請根據錯誤提示的行號檢查對應行的縮進，確保使用統一的空格數（通常 2 個），並避免用 Tab 鍵。本工具的輸入框已將 Tab 鍵映射為插入 2 個空格，幫助避免此類問題。

    
支持多個 YAML 文檔放在一個輸入裏嗎？
支持。使用三個連字符 --- 作為文檔分隔符即可在一個輸入中包含多個 YAML 文檔。驗證與轉換時會分別解析每個文檔，JSON 結果以數組形式輸出，每個元素對應一個文檔。

    
我的 YAML 數據會被上傳到伺服器嗎？
不會。本工具完全在瀏覽器本地運行，所有解析、校驗與轉換都在你的設備上完成，YAML 內容不會發送到任何伺服器，可放心處理敏感配置。

    
為什麼轉換出的 JSON 裏字符串變成了數字或布爾值？
這是 YAML 的自動類型推斷機制。YAML 會將 true/false 解析為布爾值、純數字解析為數值。若希望保留為字符串，可用引號包裹該值，例如 "true" 或 "123"。
