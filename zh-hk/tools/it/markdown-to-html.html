📝 Markdown to HTML

Markdown to HTML is available directly in your browser, with no data uploaded.

📐 工作原理與説明

按 CommonMark 規則將 Markdown 解析為 HTML：# 標題、** 粗體、* 斜體、[]() 鏈接、- 列表、` 行內代碼、| 表格等。前端解析器（如 marked）生成帶語義標籤的 HTML，可實時預覽。

  • 直接插入 DOM 需防 XSS（對不可信輸入做消毒/沙箱）。
  • 純前端轉換，粘貼內容不離開瀏覽器。

  • 在教學、方案評審、調試聯調時，可用固定樣本快速復現實驗流程，驗證參數選擇是否正確。

⚠️ 使用説明與注意事項
  • 支持：#1-6 標題、**粗體**、*斜體*、`行內代碼`
  • 支持：- 無序列表、數字列表、> 引用、--- 分割線
  • 支持：``` 代碼塊、| 表格、[鏈接](url)
  • 轉換純本地進行，文本不會上傳
