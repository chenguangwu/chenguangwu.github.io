🐳 Dockerfile 生成器

容器化第一步是寫 Dockerfile。填入基礎鏡像、工作目錄、暴露端口與啓動命令，本工具拼出標準 Dockerfile 供複製到項目根目錄。

📐 工作原理與説明

本開發工具在前端本地完成解析、轉換與處理，代碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：Dockerfile 生成器。

⚠️ 使用説明與注意事項
  • 示例為單階段構建；生產建議用多階段構建（builder 階段編譯、runtime 階段只拷產物）以減小鏡像。
  • EXPOSE 僅聲明文檔化端口，真正映射由 docker run -p 決定；二者應一致。
  • COPY . /app 前應放 .dockerignore 排除 node_modules 等，避免上下文臃腫與緩存失效。

📋 多階段示例片段

FROM node:20 AS build
WORKDIR /app
COPY . .
RUN npm ci && npm run build
FROM node:20-alpine
COPY --from=build /app/dist /app
CMD ["npm","start"]
