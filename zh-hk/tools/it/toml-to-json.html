🔧 TOML 轉 JSON 轉換器

把 Cargo.toml、pyproject.toml 等配置轉成 JSON，方便在腳本、API、前端裏消費。粘貼即轉，可設縮進。

⚠️ 使用説明與注意事項
  • TOML [section] 轉為嵌套 JSON 對象；[[數組表]] 轉為 JSON 數組。
  • 字符串、整數、浮點、布爾、數組、內聯表都會被正確解析。
  • 結果縮進可選 2/4 空格或 Tab。

📋 TOML 基礎

寫法含義
key = "v"字符串
[section]表
[[arr]]數組表
list = [1, 2]數組
