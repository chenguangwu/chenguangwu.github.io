🌲 JSON Path Extractor

Extract values from JSON by dot-path (e.g. user.name).

📐 工作原理與説明

本開發工具在前端本地完成解析、轉換與處理，代碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：JSON路徑提取器 - 使用點號路徑（如 user.name）從 JSON。

📌 路徑語法
  • 點號路徑：user.name 等價於 user['name']。
  • 數組下標：tags[0]、items[1].id。
  • 根路徑：直接留空可查看完整 JSON。
  • 僅支持簡單點號與方括號路徑，不支持通配符或過濾表達式。
