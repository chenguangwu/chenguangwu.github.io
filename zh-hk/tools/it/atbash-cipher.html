📚 算法原理

什麼是埃特巴什碼？

埃特巴什碼（Atbash cipher）是一種已知最早的替換密碼之一，起源於希伯來語。它的名字來自希伯來字母表的第一個字母 Aleph、第二個 Beth、倒數第二個 Taw 和最後一個 Shin —— Aleph-Taw, Beth-Shin，即 Atbash。

加密原理

埃特巴什碼將字母表反轉，使第一個字母與最後一個字母對應，第二個與倒數第二個對應，以此類推：

• A (第1位) ↔ Z (第26位)
• B (第2位) ↔ Y (第25位)
• C (第3位) ↔ X (第24位)
• ...
• M (第13位) ↔ N (第14位)

數學公式

f(x) = 25 - x (其中 x 為字母位置，A=0, B=1, ... Z=25)

自反特性

埃特巴什碼是一種自反密碼（involution），也就是説加密和解密使用完全相同的操作。對明文應用一次埃特巴什碼得到密文，對密文再應用一次就還原回明文。

這是因為反轉字母表兩次就恢復了原順序：A→Z→A, B→Y→B, ...

歷史背景

埃特巴什密碼最早出現在《耶利米書》中，用希伯來語書寫。它被用來掩蓋一些地名和人名，例如"巴比倫"被寫成"示巴"。在中世紀的猶太神秘主義文獻中也有使用。

安全性

埃特巴什碼的安全性極低，因為它只有一種固定的替換方式，不需要密鑰。任何人只要知道這是埃特巴什碼，就能立即解密。它本質上是凱撒密碼在位移為13時的特例（對於26個字母來説）。

擴展版本

• 全字符埃特巴什：對 ASCII 可打印字符進行反向映射
• 自定義字母表：可以針對不同的字母表（如希伯來語、希臘語）應用
• 數字埃特巴什：0↔9, 1↔8, 2↔7, ...
