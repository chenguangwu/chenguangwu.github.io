📖 使用説明

功能説明

  • 美化格式化：統一縮進、換行，使CSS結構清晰易讀
  • 壓縮：移除所有註釋、空白、換行，生成最小體積CSS
  • 壓縮率統計：實時顯示壓縮前後體積對比
  • 歷史記錄：自動保存處理記錄，可快速恢復

壓縮優化項

  • 移除 /* comments */ 註釋
  • 移除多餘空白字符和換行
  • 移除最後一個分號
  • 保留必要空格（選擇器之間）
  • 顏色值優化（如 #ffffff → #fff）
