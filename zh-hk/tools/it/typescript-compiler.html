📝工具簡介

TypeScript 轉 JavaScript 編譯器是一款基於官方 TypeScript 5.3 編譯器的在線工具。它在瀏覽器本地調用 ts.transpileModule API，將 TypeScript 代碼實時轉譯為 JavaScript，支持選擇 ES3 到 ESNext 的目標版本與 None、CommonJS、AMD、ESNext 模塊系統，並提供編譯診斷信息。所有代碼處理都在瀏覽器中完成，不會上傳到任何伺服器，保障隱私安全。

✨功能特點

  • 基於官方 TypeScript 5.3 編譯器
  • 左右分欄實時編輯與輸出
  • 支持 ES3/ES5/ES6/ES2017/ES2020/ESNext 目標
  • 支持 None/CommonJS/AMD/ESNext 模塊系統
  • 移除註釋、嚴格模式、isolatedModules 選項
  • 300ms 防抖實時編譯
  • 編譯診斷信息（錯誤/警告/位置）
  • 顯示編譯耗時與輸出行數
  • Tab 鍵縮進支持
  • 一鍵複製 / 下載 JS 文件
  • 深色模式與移動端響應式

💬常見問題

這個工具能檢測類型錯誤嗎？
本工具使用 ts.transpileModule 進行單文件轉譯，主要移除類型註解並做語法降級，不做完整的類型檢查。類型不匹配等錯誤通常不會出現在診斷面板，僅語法錯誤和部分語義錯誤會被報告。如需完整類型檢查，請使用本地 tsc 命令或 IDE。
isolatedModules 選項有什麼作用？
isolatedModules 啓用單文件編譯語義，強制每個文件可獨立轉譯。由於 transpileModule 本身就是單文件模式，該選項主要用於約束部分語法（如 export =、const enum 等）的可用性。
目標版本和模塊系統如何選擇？
目標版本決定輸出的 JS 語法級別：需要兼容舊瀏覽器選 ES5 或 ES3；現代環境選 ES2020 或 ESNext。模塊系統決定 import/export 的編譯方式：Node.js 環境選 CommonJS，瀏覽器原生模塊選 ESNext，不使用模塊選 None。
我的代碼會被上傳嗎？
不會。所有編譯都在你的瀏覽器本地完成，TypeScript 編譯器從 CDN 加載後在本地運行，代碼不會發送到任何伺服器。
為什麼首次加載稍慢？
工具需要從 CDN 下載約 8MB 的 TypeScript 編譯器腳本，首次加載可能稍慢，加載完成後即可流暢使用。建議在網絡良好的環境下使用。
