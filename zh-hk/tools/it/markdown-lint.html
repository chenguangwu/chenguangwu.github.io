📝 Markdown 檢查器

規範的 Markdown 更易渲染與維護。本工具掃描常見風格問題（如跳級標題、列表缺空格、空鏈接），逐條列出便於修正。

📐 工作原理與説明

本開發工具在前端本地完成解析、轉換與處理，代碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：Markdown 檢查器。

⚠️ 使用説明與注意事項
  • 標題建議從 H1 起逐層遞增，跳級會影響文檔大綱與 SEO 錨點。
  • 無序列表 `-`/`*` 後需一個空格；有序列表 `1. ` 後也需空格，否則不渲染為列表。
  • 本檢查為風格輔助，不覆蓋 CommonMark 全部語法；導出前仍建議用官方解析器預覽。
