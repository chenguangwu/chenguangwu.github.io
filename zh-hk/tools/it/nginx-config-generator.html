🪙 Nginx 配置生成器

Nginx 常用於託管靜態站點或反向代理後端。選擇場景並填參數，本工具生成標準 server 塊，複製到站點配置即可啓用。

📐 工作原理與説明

本開發工具在前端本地完成解析、轉換與處理，代碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：Nginx 配置生成器。

⚠️ 使用説明與注意事項
  • 反向代理的 proxy_pass 末尾是否帶 / 影響路徑拼接：帶 / 會剝離 location 前綴，按需選擇。
  • 配置改完用 nginx -t 校驗語法，再 nginx -s reload 生效，避免寫錯導致服務中斷。
  • 生產應補 TLS（listen 443 ssl）、gzip、緩存頭等；本工具只生成最小可用骨架。
