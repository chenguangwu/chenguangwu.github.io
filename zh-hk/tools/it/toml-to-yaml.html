🔧 TOML 轉 YAML 轉換器

從 Cargo.toml / pyproject 等遷移到 Kubernetes、GitHub Actions 等 YAML 配置時，用本工具把 TOML 結構轉成 YAML。

⚠️ 使用説明與注意事項
  • TOML 的 [section] 錶轉為 YAML 嵌套映射；[[數組表]] 轉為 YAML 列表，每個元素是一個映射。
  • TOML 的數組（[1,2,3]）轉為 YAML 行內或塊列表。
  • 時間戳等 TOML 專有類型會按字符串保留，避免信息丟失。

📋 TOML → YAML 要點

TOMLYAML
key = "v"key: v
[sec]sec:
[[arr]]arr:\n - ...
list = [1,2]list:\n - 1\n - 2
