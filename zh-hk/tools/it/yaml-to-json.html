🔧 YAML 轉 JSON 轉換器

在 CI、API、前端配置裏常需要把 YAML（如 GitHub Actions、docker-compose）轉成 JSON。粘貼即轉，可設縮進。

⚠️ 使用説明與注意事項
  • 轉換結果可直接粘貼進 JSON 配置、REST 請求體或代碼。
  • 支持常見 YAML 子集：映射、列表、標量（字符串/數字/布爾/null）；不支持錨點、多文檔等高級特性。
  • 縮進可選 2/4 空格或 Tab，便於對接不同代碼風格。
