⚡ JS 壓縮器

部署前壓縮 JS 可減小下載體積。本工具去除 // 與 /* */ 註釋並壓縮空白，保留代碼結構，便於回看與調試定位。

📐 工作原理與説明

本開發工具在前端本地完成解析、轉換與處理，代碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：JS 壓縮器。

⚠️ 使用説明與注意事項
  • 本壓縮為「安全型」：只去註釋與空白，不重命名變量、不改作用域，幾乎不改變行為。
  • 真正的生產壓縮應交給 Terser/esbuild：會做變量重命名、死代碼消除、常量摺疊，體積更小但不可讀。
  • 壓縮會刪除版權/許可證註釋，若需保留請用 /*! 開頭的重要註釋（本工具一併移除，發佈前請確認）。

📋 建議

僅做快速瘦身可用本工具；CI 流水線裏推薦集成 Terser 以獲得更優壓縮率與 tree-shaking。
