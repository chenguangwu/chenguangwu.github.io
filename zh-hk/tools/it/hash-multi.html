🧬 Hash Multi

📐 工作原理與説明

Hash Multi is available directly in your browser, with no data uploaded.

  • 支持 MD5(128b)/ SHA-1(160b)/ SHA-256 / SHA-512 / SHA-3,經 Web Crypto SubtleCrypto.digest 計算。
  • 用途:文件完整性校驗、去重、內容指紋。

⚠️ 安全提示:MD5、SHA-1 已被證明可碰撞,勿用於數字簽名或口令存儲;口令應使用 bcrypt / Argon2 等慢哈希。本工具純前端,數據不上傳。

一鍵計算多種哈希：MD5 / SHA-1 / SHA-256 / SHA-512 / CRC32，支持多算法同時輸出與大小寫切換。SHA 走瀏覽器原生 crypto.subtle，全程本地。
