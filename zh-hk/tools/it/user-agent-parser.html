💡 UA 字符串結構

典型 UA 格式：
Mozilla/5.0 (平台; 系统信息) 引擎/版本 浏览器/版本

歷史原因：現代 UA 都以 "Mozilla/5.0" 開頭，是瀏覽器大戰時代為兼容舊網站留下的"兼容性標記"，並非真實身份。

提示：自 2020 年起，Chrome、Firefox、Safari 開始降低 UA 字符串的精度以保護用户隱私（UA Client Hints），建議新應用使用 navigator.userAgentData 替代字符串解析。
