📚 技術説明

Base64

Base64 是一種基於 64 個可打印字符來表示二進制數據的編碼方式，使用 A-Z、a-z、0-9、+、/ 共 64 個字符（URL安全模式使用 - 和 _）。每 3 個字節編碼為 4 個字符，數據膨脹約 33%。常用於電子郵件、URL、數據存儲等場景。

Base32

Base32 使用 A-Z 和 2-7 共 32 個字符，每 5 個字節編碼為 8 個字符，數據膨脹約 60%。相比 Base64，它不區分大小寫，更適合不區分大小寫的系統（如 DNS、文件名）。

Base85 (Ascii85)

Base85 使用 85 個 ASCII 字符，每 4 個字節編碼為 5 個字符，數據膨脹約 25%，是編碼效率最高的常見編碼方式。常用於 PostScript、PDF 等格式中。

URL安全模式

URL安全的 Base64 將 + 替換為 -，/ 替換為 _，並移除末尾的 = 填充，使編碼結果可安全用於 URL 和文件名。

❓ 常見問題（FAQ）

Base64 是加密嗎？
不是。Base64 只是編碼（二進制↔文本映射），任何人都能解碼，不含任何密鑰或保密性，絕不能用來保護敏感數據。
為什麼編碼後變長了約 1/3？
Base64 每 3 字節原始數據變成 4 個可打印字符，體積約膨脹 33%，這是編碼的固有代價。
URL 裏為什麼有時看到 - 和 _ 而不是 + 和 /？
標準 Base64 的 + / = 在 URL 中有特殊含義，URL-safe 變體把它們替換為 - _ 並去掉填充 =，適合直接拼進查詢參數。
