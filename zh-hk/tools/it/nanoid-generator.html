📖 NanoID 説明

• 默認長度 21 字符，比 UUID 短但碰撞率極低

• 使用 Web Crypto API 的 getRandomValues 保證密碼學安全

• 默認字母表：A-Za-z0-9_- (URL 安全，64 字符)

• 21 字符長度提供約 122 位熵，約 4 年後才有 1% 碰撞概率（350M ID/s）
