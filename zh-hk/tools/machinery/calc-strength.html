📐 計算公式
軸強度 σ = M/W

按第四強度理論計算實心圓軸的應力與安全係數

💡 第四強度理論：σe=√(σ²+3τ²)。抗彎截面係數 W=πd³/32，抗扭截面係數 Wp=πd³/16。安全係數 n=σs/σe。

安全係數評定標準

  • n ≥ 1.5：安全（靜強度足夠）
  • 1.2 ≤ n < 1.5：基本安全（一般用途）
  • 1.0 ≤ n < 1.2：臨界（需進一步校核疲勞）
  • n < 1.0：不安全（需增大軸徑或換材料）
