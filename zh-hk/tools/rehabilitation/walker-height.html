📖 輔助器具高度標準

標準助行器（Walker）

  • 手柄高度 = 股骨大轉子高度（約身高的55-60%）
  • 或 = 地面至腕橫紋距離 + 2-3cm
  • 站立時肘關節屈曲20-30度
  • 使用時身體應在助行器後方，不要太前傾

前臂枴杖（Forearm Crutch）

  • 手柄高度同助行器（腕橫紋+2-3cm）
  • 前臂套環高度 = 鷹嘴上方2.5-3cm
  • 前臂套環鬆緊適中，能通過前臂但不滑脱

腋拐（Axillary Crutch）

  • 腋托高度 = 腋窩下方5cm（約身高的77%）
  • 手柄高度 = 腕橫紋+2-3cm（肘屈20-30°）
  • 腋窩不應直接承重，力量在手上
  • 腋托與腋窩保留2-3指寬度間隙

單拐/手杖（Cane）

  • 手柄高度 = 股骨大轉子高度
  • 或 = 地面至腕橫紋距離
  • 站立時肘關節屈曲20-30度
  • 應使用在健側（非患側）
