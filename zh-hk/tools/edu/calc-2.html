📈 Z-Score (Standard Score) Calculator

📐 計算公式
Z = (X - μ) / σ

Compute the z-score of a value in a dataset.

公式：Z = (X - μ) / σ。Z 分數表示原始分數與平均值之間相差幾個標準差。

📝工具簡介

Z 分數（標準分數）用於衡量某個數值相對於數據集平均水平的偏離程度。Z = 0 表示等於平均值，Z 為正表示高於平均，Z 為負表示低於平均。

✨功能特點

  • 自動計算 Z 分數
  • 估算標準正態百分位
  • 給出等級評價
  • 支持反向指標（越低越好）

🎯使用場景

  • 考試成績標準化分析
  • 心理測評分數解讀
  • 競賽成績橫向對比
  • 統計學課程學習

💬常見問題

Z 分數為 1 代表什麼？
表示該分數比平均值高 1 個標準差，約高於 84% 的數據。
百分位是怎麼估算的？
基於標準正態分佈累積分佈函數近似計算，假設數據近似正態分佈。
