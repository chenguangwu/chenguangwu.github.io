📐 計算公式
績效考核 = 指標加權評分

六大維度加權評分（客户滿意度20%+設施維護20%+響應時效15%+收費率15%+安全合規15%+環境品質15%），自動生成考核等級

💡 加權得分 = Σ(各維度得分 × 權重) / Σ權重。考核等級：A級(≥90)優秀 / B級(80-89)良好 / C級(70-79)合格 / D級(60-69)待改進 / E級(<60)不合格。維度得分參考：滿意度調查均分、設施完好率、工單響應時間達標率、實際收費率、安全檢查通過率、環境巡查合格率。
⚠️ 使用説明與注意事項
  • 各維度得分0-100分，參考實際考核數據填入
  • 權重可自定義調整，默認按行業經驗分配，總權重建議100%
  • 客户滿意度建議採用季度調查均值（樣本量≥30%）
  • 響應時效：15分鐘內響應為100分，每超10分鐘扣5分
  • 安全合規含消防/電梯/配電/燃氣等特種設備檢查通過率
  • 結果僅供參考，實際考核應結合合同約定和當地物業管理辦法

📝工具簡介

物業績效考核評分體系，支持客户滿意度、設施維護質量、響應時效、收費率、安全合規、環境品質六大維度的加權評分計算。可自定義各維度權重，自動生成A-E五級考核結果，並識別薄弱環節提供改進建議。

✨功能特點

  • 六大考核維度全面覆蓋物業服務品質
  • 支持自定義權重，適應不同項目考核需求
  • 可視化條形圖直觀展示各維度得分
  • 自動識別最低分維度並生成改進建議

🎯使用場景

  • 物業公司季度/年度績效考核
  • 業委會對物業公司服務品質評估
  • 多項目橫向對比評比
  • 物業服務合同履約評價

💬常見問題

各維度得分如何獲取？
客户滿意度通過業主調查問卷獲取；設施維護根據設備完好率統計；響應時效從工單系統導出達標率；收費率取實際收繳率；安全合規取檢查通過率；環境品質取巡查合格率。
權重可以調整嗎？
可以。默認按行業經驗分配權重，您可根據項目特點和合同約定調整各維度權重，總權重建議為100%。
我的數據會被上傳嗎？
不會。所有計算均在瀏覽器本地完成，數據不會發送到任何伺服器。
