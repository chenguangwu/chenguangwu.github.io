買入總成本 = 買入價 x 數量 + 買入佣金 + 買入過户費

賣出總收入 = 賣出價 x 數量 - 賣出印花税 - 賣出佣金 - 賣出過户費

盈虧金額 = 賣出總收入 - 買入總成本

盈虧百分比 = 盈虧金額 / 買入總成本 x 100%

印花税：賣出時收取，費率 0.05%（2023年8月28日起減半）

佣金：買賣雙向收取，默認 0.025%，最低 5 元/筆

過户費：買賣雙向收取，費率 0.001%（滬市為主，深市2023年起統一）

保本賣出價 = (買入總成本 + 賣出綜合費率 x 數量 x 保本價) / 數量

即：保本價 ≈ 買入總成本 / (數量 x (1 - 賣出綜合費率))
