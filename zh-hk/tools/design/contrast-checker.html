⚖️ 對比度檢查器説明 ▼

WCAG（Web 內容無障礙指南）對比度檢查器，幫助設計師和開發者驗證文字顏色與背景顏色之間的對比度是否符合無障礙標準。

📌 WCAG 對比度標準

  • AA 級正常文字：對比度 ≥ 4.5:1
  • AA 級大文字（18px+ 或 14px 粗體+）：對比度 ≥ 3:1
  • AAA 級正常文字：對比度 ≥ 7:1
  • AAA 級大文字：對比度 ≥ 4.5:1

🎯 使用場景

  • UI 設計稿配色驗證
  • 網頁開發顏色可讀性檢查
  • 品牌色與文字色搭配優化
  • 無障礙合規性審查

❓ 常見問題

什麼算"大文字"？
WCAG 定義大文字為 18pt（24px）或 14pt（18.66px）粗體及以上的文字。大文字因為筆畫更粗，在較低對比度下仍可辨識。
對比度是如何計算的？
先將 sRGB 顏色值線性化，然後按公式 L = 0.2126 × R + 0.7152 × G + 0.0722 × B 計算相對亮度。對比度 = (L1 + 0.05) / (L2 + 0.05)，其中 L1 為較亮的顏色。

❓ 常見問題（FAQ）

對比度檢查器 結果可直接用於決策嗎？
對比度檢查器 適合用於預估與複核，正式決策請結合完整數據口徑説明（口徑定義、時間區間、邊界條件）。
結果偏離預期很大怎麼辦？
先核對輸入單位與是否存在“% 與小數”混用，再確認分母與分子定義是否同口徑，最後替換一組可復現實例複測。
