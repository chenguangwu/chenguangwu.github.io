❓ 常見問題（FAQ）

對比度檢查（WCAG標準） 結果可直接用於決策嗎？
對比度檢查（WCAG標準） 適合用於預估與複核，正式決策請結合完整數據口徑説明（口徑定義、時間區間、邊界條件）。
結果偏離預期很大怎麼辦？
先核對輸入單位與是否存在“% 與小數”混用，再確認分母與分子定義是否同口徑，最後替換一組可復現實例複測。
⚠️ 使用説明與注意事項
  • 對比度計算遵循 WCAG 2.1 標準（W3C Web Content Accessibility Guidelines）
  • AA 級要求：正常文字 ≥ 4.5:1，大號文字（≥18px 或 ≥14px 粗體）≥ 3:1
  • AAA 級要求：正常文字 ≥ 7:1，大號文字 ≥ 4.5:1
  • 輸入色值支持 #RRGGBB、#RGB、rgb(r,g,b) 格式
  • 對比度比率範圍為 1:1（完全相同）到 21:1（黑白對比）

💬常見問題

這個工具是免費的嗎？
完全免費，無需註冊，直接在瀏覽器中使用。
WCAG 標準是什麼？
WCAG（Web Content Accessibility Guidelines）是 W3C 制定的 Web 內容無障礙指南，對比度要求是其中視覺可讀性的重要指標。
大號文字的標準是什麼？
大號文字指 18px 以上的常規文字或 14px 以上的粗體文字，其對比度要求比正常文字更低。
