💡 使用説明

  • CSV → JSON: 第一行作為字段名，每行一條記錄
  • JSON → CSV: 自動提取所有字段，生成表頭
  • 支持帶引號的字段（包含分隔符、換行符）
  • 支持嵌套 JSON 對象（輸出為 JSON 字符串字段）
  • 支持數字自動識別（可關閉保持字符串）
  • Excel 複製的內容可直接粘貼為 CSV
