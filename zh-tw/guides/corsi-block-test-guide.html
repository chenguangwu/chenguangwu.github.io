Corsi 木塊敲擊測試

在螢幕上依次點亮一組方塊，你按相同順序點選複述；序列長度逐輪增加，直到無法正確複述，所得最大長度即為你的視覺空間工作記憶廣度（Corsi 廣度）。適合評估注意力、腦損傷康復與日常記憶訓練。

核心功能

  • 順向廣度：按原順序複述點亮的方塊序列
  • 逆向廣度（可選）：按相反順序複述，難度更高
  • 序列長度自適應遞增，精準定位記憶上限
  • 即時反饋對錯與當前最長序列
  • 可設定起始長度與最大長度
  • 純瀏覽器本地執行，資料不上傳

適用場景

  • 認知評估：快速瞭解視覺空間工作記憶水平
  • 康復隨訪：腦損傷或卒中後的記憶訓練
  • 日常訓練：用遞增難度鍛鍊短期記憶

使用步驟

  1. 點選開始，記住第一組點亮的方塊順序
  2. 按順序點選方塊複述該序列
  3. 答對則下一輪序列加長，答錯則結束
  4. 檢視你的最大正確序列長度（Corsi 廣度）
  5. 需要挑戰時開啟逆向模式重新測

實用技巧

  • 順向廣度正常成人約 5~6 個，逆向約 4~5 個
  • 分心環境會明顯下降，建議在安靜處測
  • 單次結果有波動，可取多次平均
  • 逆向廣度更能反映中央執行功能

常見問題

Corsi 廣度和數字廣度有什麼區別？
Corsi 測視覺空間記憶（位置序列），數字廣度測語音/言語記憶（數字序列），兩者評估不同通路。
結果偏低要緊嗎？
單次偏低未必異常，受疲勞與注意力影響；若持續明顯偏低建議就醫評估。
