📋 計算說明

鍛造比 K：表示金屬變形程度，是鍛造工藝的重要指標。
拔長：K = F₀ / F₁ = 原始截面積 / 鍛後截面積
鐓粗：K = H₀ / H₁ = 原始高度 / 鍛後高度
變形程度 ε = (F₀ − F₁) / F₀ × 100%（拔長）或 (H₀ − H₁) / H₀ × 100%（鐓粗）

參考要求：碳素結構鋼拔長比 ≥ 2~3；合金結構鋼 ≥ 3~4；高合金鋼/工具鋼 ≥ 4~6（需破碎碳化物）；鐓粗比一般取 2~3。鍛造比過小組織不均，過大則形成纖維方向性。
