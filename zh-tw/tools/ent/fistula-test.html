檢查方法與引數
加壓反應觀察
✓
加正壓時出現眼震 向測試側（同側）眼震 — 提示瘻管可能存在
✓
加負壓時出現眼震 向對側眼震 — 提示瘻管可能存在
✓
加壓時出現眩暈/傾倒 患者感覺明顯眩暈、身體偏倒或搖晃
✓
Tullio現象陽性 強聲刺激誘發眩暈/眼震
✓
Hennebert徵陽性 外耳道負壓誘發眼震和眩暈（即使無瘻管）
✓
加壓無任何反應 正負壓均未誘發眼震或眩暈

瘻管試驗結果判讀標準

結果臨床表現臨床意義
陽性加壓誘發眼震+眩暈高度提示迷路瘻管存在
可疑陽性僅眩暈無眼震，或僅Hennebert徵不能排除瘻管，需結合其他檢查
陰性無眼震、無眩暈不支援瘻管診斷（假陰性約10-15%）

常見瘻管位置

位置發生率常見病因
外半規管~80%慢性中耳炎、膽脂瘤
前庭窗（卵圓窗）~15%外傷、手術、梅毒
蝸窗（圓窗）~5%外傷、爆震、特發性
注意事項：瘻管試驗陰性不能完全排除瘻管（假陰性率10-15%）。確診需結合臨床表現、顳骨CT和手術探查。檢查時壓力不宜過大，避免損傷。Tullio現象和Hennebert徵也可見於梅尼埃病、梅毒等非瘻管疾病，需注意鑑別。
