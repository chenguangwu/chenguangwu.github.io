計算公式與判讀標準

單側減弱 (Unilateral Weakness, UW)

UW = [(RW + RC) - (LW + LC)] / (RW + RC + LW + LC) × 100%

UW > 20-25% 提示一側半規管功能減弱（管麻痺），正值表示右側減弱，負值表示左側減弱

方向優勢 (Directional Preponderance, DP)

DP = [(RW + LC) - (LW + RC)] / (RW + LC + LW + RC) × 100%

DP > 25-30% 提示優勢偏向，正值表示向左優勢，負值表示向右優勢，常見於前庭中樞代償不完全

臨床要點：冷熱試驗主要評估外半規管及前庭上神經功能。UW異常提示周圍性前庭病變（如梅尼埃病、前庭神經炎等）；DP異常多為前庭張力失衡的反映，可見於周圍性或中樞性病變。檢查前需確認無鼓膜穿孔。
