⚖️ Ratio Calculator

Solve for an unknown term in a proportion.

📐 計算公式
比例 a:b = a/b

根據比例式 A : B = C : D，輸入任意三項求解第四項。

比例式：A : B = C : D ⟺ A × D = B × C。留空需要求解的一項，工具會自動計算。
⚠️ 使用說明與注意事項
  • 本工具純前端執行，資料不會上傳到伺服器。
  • 請至少輸入三項有效數值，留空一項作為求解目標。
  • 作為除數的項不能為 0。

❓ 常見問題（FAQ）

比例計算 結果可直接用於決策嗎？
比例計算 適合用於預估與複核，正式決策請結合完整資料口徑說明（口徑定義、時間區間、邊界條件）。
結果偏離預期很大怎麼辦？
先核對輸入單位與是否存在“% 與小數”混用，再確認分母與分子定義是否同口徑，最後替換一組可復現例項複測。

📝工具簡介

比例計算器根據比例的基本性質（內項積等於外項積）求解未知項，適用於各類按比例分配與換算場景。

✨功能特點

  • 四項任意留空求解
  • 自動識別未知項位置
  • 即時計算結果
  • 介面清晰，便於理解

🎯使用場景

  • 地圖比例尺換算
  • 配方配比計算
  • 影像縮放尺寸換算
  • 金融槓桿與配比估算

💬常見問題

四項都填會怎樣？
工具會校驗比例是否成立，並顯示內項積與外項積是否相等。
結果可以是負數嗎？
可以。比例中的量可正可負，視具體應用場景而定。
