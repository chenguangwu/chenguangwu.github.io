兩點斜率
過 (1,2) 與 (4,8)：斜率 m=(8-2)/(4-1)=6/3=2，即 x 每增 1，y 增 2。垂直直線斜率不存在（分母為 0）。
斜率與角度
m=tanθ，m=1 對應 45°，m=√3 對應 60°。負斜率表示下降。

❓ 常見問題（FAQ）

斜率為 0 和不存在分別是什麼線？
斜率為 0 是水平線（y 恆定）；斜率不存在（分母 0）是豎直線（x 恆定）。
斜率和傾角關係？
m=tanθ，θ 為與 x 軸正向夾角。由此可從斜率反推角度，或從角度得斜率。
