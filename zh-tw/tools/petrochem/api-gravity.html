🛢️ API Gravity

API Gravity is available directly in your browser, with no data uploaded.

📋 原油分類與公式

API 度 = 141.5 / SG − 131.5

SG = 141.5 / (API + 131.5)

密度 = SG × 水密度（g/cm³）

API 度類別典型代表
> 31.1輕質原油布倫特、WTI
22.3 - 31.1中質原油迪拜原油
10 - 22.3重質原油瑪雅原油
< 10超重質/瀝青委內瑞拉重油
