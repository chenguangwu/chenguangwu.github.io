📋 理論公式與參考

BPSK/QPSK：BER = Q(√(2·Eb/N0))

M-QAM 矩形 (k=log₂M 位元/符號)

BPSK/QPSK (M=4)：BER = Q(√(2·γb))

16-QAM：BER ≈ (3/4)·Q(√(4/5·γb))，γb = Eb/N0(線性)

64-QAM：BER ≈ (7/12)·Q(√(4/7·γb))

Q(x) = 0.5·erfc(x/√2)，γb 由 dB 轉線性：γb = 10^(Eb/N0_dB/10)

典型 BER=1e-5 所需 Eb/N0

BPSK/QPSK ≈ 9.6 dB　|　16-QAM ≈ 13.4 dB　|　64-QAM ≈ 17.2 dB

注：本工具為 AWGN 通道理論值，未含編碼增益與實現損耗。
