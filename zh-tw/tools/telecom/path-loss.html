自由空間路徑損耗 (FSPL) 計算，估算無線訊號傳輸損耗與接收功率。

📋 公式與說明

自由空間路徑損耗 (FSPL)：
FSPL(dB) = 20·log₁₀(d) + 20·log₁₀(f) + 32.44
（d 單位 km，f 單位 MHz）

接收功率：
Pr(dBm) = Pt + Gt + Gr − FSPL

典型場景：2.4GHz WiFi、5GHz WiFi、4G/5G 行動通訊、衛星鏈路等。
注：自由空間為理想模型，實際還需考慮大氣吸收、障礙物、多徑等附加損耗。

💡 常見使用場景

  • 在telecom場景裡，先統一 Path Loss 的輸入口徑，再輸出可複用結構，便於快速對賬與複核。
  • 當同類任務需要批次處理時，可用該工具做第一輪標準化；結果異常時再回到人工複核環節，降低漏檢率。
  • 在業務流程中，先做小樣本試算再擴充套件規模，能快速驗證引數假設是否與實際口徑一致。
一體化標準化使用示例
先準備一組典型樣本並固定單位與格式，執行一次並記錄輸出；再切換到邊界樣本（含缺失項、異常值）觀察是否給出可解釋結果，以便形成可復盤的分析清單。

這個 telecom 工具適合什麼階段使用？
適合需求澄清和第一輪評估階段；輸出可直接用於方案討論、初篩與結果複核，但關鍵決策建議結合歷史策略再確認。
