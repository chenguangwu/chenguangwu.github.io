圖片馬賽克工具是一款純前端線上打碼工具，可對圖片進行畫素化處理，常用於隱私保護、資訊遮擋等場景。

🎯 功能特點

  • 純本地處理，圖片不上傳
  • 支援全圖和框選區域兩種模式
  • 塊大小 5-50px 自由調節
  • 即時預覽處理效果
  • 一鍵下載 PNG 結果
  • 支援深色模式

📖 使用場景

  • 截圖隱私資訊打碼
  • 人臉模糊化處理
  • 證件號碼遮擋
  • 敏感資訊畫素化

❓ 常見問題

圖片會被上傳到伺服器嗎？
不會。所有處理均在瀏覽器本地通過 Canvas API 完成，圖片資料不會離開您的裝置。
支援哪些圖片格式？
支援 JPG、PNG、WebP、BMP 等主流圖片格式。處理結果匯出為 PNG 格式，保證畫質無損。
馬賽克塊大小怎麼選？
塊越大，馬賽克效果越模糊、遮擋越徹底；塊越小，越接近原圖但仍有畫素化效果。一般 10-20px 適合日常打碼。

❓ 常見問題（FAQ）

圖片馬賽克工具 結果可直接用於決策嗎？
圖片馬賽克工具 適合用於預估與複核，正式決策請結合完整資料口徑說明（口徑定義、時間區間、邊界條件）。
