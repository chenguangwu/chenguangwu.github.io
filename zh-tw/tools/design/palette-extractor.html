🎨 工具介紹與常見問題 ▼

調色盤提取器是一款純前端圖片顏色分析工具，採用中位切分法（Median Cut）演算法，從上傳的圖片中智慧提取主色調，幫助設計師和開發者快速獲取配色方案。

✨ 功能特點

  • 中位切分法顏色量化演算法
  • 支援拖拽和點選上傳圖片
  • 5/8/10/12 色自由選擇
  • 按頻率、亮度、色相排序
  • 匯出 CSS / JSON / SCSS / Tailwind
  • 純前端處理，圖片不上傳伺服器

🎯 使用場景

  • 提取設計稿/照片的主色調
  • 為專案生成配色方案
  • 分析品牌視覺色彩構成
  • 建立 CSS 變數和設計 Token

❓ 常見問題

圖片資料會上傳到伺服器嗎？
不會。所有圖片分析均在瀏覽器本地完成，通過 Canvas API 讀取畫素資料，不會上傳到任何伺服器。
支援哪些圖片格式？
支援 JPG、PNG、WebP、BMP、GIF 等主流瀏覽器支援的圖片格式。
提取的顏色不準確怎麼辦？
建議上傳色彩豐富且解析度適中的圖片。純白/純黑背景佔比過大會影響結果，可嘗試裁剪掉大面積單色區域後再提取。

💡 常見使用場景

  • 快速核對調色盤提取器：優先統一輸入單位、口徑和引數範圍，再對典型樣例做一遍手工驗算。
  • 教學與複核：建議固定其餘引數，只變動一個輸入變數，確認輸出變化趨勢，避免“算式正確但口徑錯位”。
  • 常見場景：Palette Extractor
快速複核「調色盤提取器」
先輸入一組典型引數跑基準值，再做 ±10%、±20% 調參演算，檢查輸出是否沿業務常識方向變化。

❓ 常見問題（FAQ）

調色盤提取器 結果可直接用於決策嗎？
調色盤提取器 適合用於預估與複核，正式決策請結合完整資料口徑說明（口徑定義、時間區間、邊界條件）。
結果偏離預期很大怎麼辦？
先核對輸入單位與是否存在“% 與小數”混用，再確認分母與分子定義是否同口徑，最後替換一組可復現例項複測。

  • 本工具純前端執行，資料不會上傳到伺服器
  • 建議在主流瀏覽器（Chrome/Safari/Firefox/Edge）中使用
  • 計算結果僅供參考，請以實際應用場景為準
