❓ 常見問題

雙色球中一等獎的機率是多少？
雙色球一等獎需要6個紅球全中（1/33選6）且藍球也中（1/16選1），總組合數為 C(33,6) x 16 = 17,721,088，一等獎機率約為 1/1772萬，即約 0.0000000564。
大樂透和雙色球哪個更容易中獎？
大樂透一等獎總組合數為 C(35,5) x C(12,2) = 21,425,712，雙色球為 17,721,088。因此雙色球一等獎機率略高於大樂透，但兩者差距不大，都極其困難。
什麼是組合數 C(N,K)？
C(N,K) 表示從 N 個不同元素中選取 K 個元素的組合數，計算公式為 N! / (K! x (N-K)!)。例如 C(33,6) 表示從33個號碼中選6個，共有 1,107,568 種組合。
為什麼使用 BigInt 計算？
彩票的組合數可能非常大（如 C(35,5) = 324,632），而總組合數（如大樂透的 21,425,712）更大。JavaScript 的 Number 型別在超過 2^53 時會丟失精度，使用 BigInt 可以精確計算任意大的整數。
