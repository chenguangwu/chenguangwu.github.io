⚠️ 使用說明與注意事項
  • NPV = 初始投資 + Σ(第 t 期現金流 / (1+r)^t)
  • NPV > 0 通常表示專案收益超過預期回報，值得投資
  • NPV < 0 表示專案收益低於預期回報，應謹慎決策
  • NPV = 0 時的折現率即為 IRR
  • 本工具純前端執行，資料不會上傳到伺服器

❓ 常見問題（FAQ）

NPV淨現值計算 適合用於預估與複核，正式決策請結合完整資料口徑說明（口徑定義、時間區間、邊界條件）。
