公式說明：
直接成本 = 魚苗 + 飼料 + 電費 + 藥品
間接成本 = 人工 + 塘租 + 其他
總成本 = 直接成本 + 間接成本
總收入 = 產量 × 單價 + 副產品收入
毛利潤 = 總收入 - 直接成本
淨利潤 = 總收入 - 總成本
利潤率 = 淨利潤 / 總收入 × 100%
投資回報率 ROI = 淨利潤 / 總成本 × 100%
