📖 撞擊坑物理模型

動能計算公式

E = 0.5 x m x v²

其中：

  • m = 隕石質量 = ρ x (4/3)π(d/2)³ （ρ密度，d直徑）
  • v = 撞擊速度（m/s）
  • TNT當量 = E / 4.184 x 10⁹ （1噸TNT = 4.184 x 10⁹ J）

撞擊坑直徑公式（簡化）

D = 0.07 x (E / ρ_target)⅓

其中：

  • D = 最終撞擊坑直徑
  • E = 撞擊動能
  • ρ_target = 目標地表密度
  • 角度修正：D_final = D x sin(θ) （θ為入射角）

此為簡化模型，實際撞擊坑形成涉及複雜的流體力學和相變過程

著名撞擊事件參考

  • 希克蘇魯伯（6600萬年前）：直徑約10km隕石，速度20km/s，坑徑180km，導致恐龍滅絕
  • 通古斯（1908年）：約60m天體，空中爆炸，釋放約15百萬噸TNT當量
  • 巴林傑隕石坑（5萬年前）：50m鐵隕石，坑徑1.2km，位於美國亞利桑那州
  • 車里雅賓斯克（2013年）：20m天體，空中爆炸，釋放約500千噸TNT當量

TNT當量參考

  • 1千噸 = 4.184 x 10¹² J

  • 沙皇炸彈 ≈ 50百萬噸
