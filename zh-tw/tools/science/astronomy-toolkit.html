月相週期說明

朔望月週期約為 29.53 天。從新月到滿月為"上弦"階段（漸盈），從滿月到新月為"下弦"階段（漸虧）。月齡是從最近一次新月開始經過的天數，0 天為新月，約 14.76 天為滿月。

公式：亮度比 = 2.512^(m2 - m1)，星等越小越亮。

星等知識

視星等（Apparent Magnitude）是衡量天體亮度的一個指標，數值越小表示越亮。星等每差 1 等，亮度相差約 2.512 倍；每差 5 等，亮度相差恰好 100 倍。星等可以為負數，太陽 (-26.74) 比滿月 (-12.74) 亮約 39.8 萬倍。

估算原理

基於 Pi-Group scaling law 簡化公式：先計算撞擊動能 E = 0.5 × m × v²，再根據經驗關係式估算最終撞擊坑直徑。實際撞擊坑大小還受地層結構、岩石型別、大氣層減速等因素影響，本工具結果僅供科普參考。

UTM 座標系說明

UTM（Universal Transverse Mercator）投影將地球分為 60 個帶，每頻寬 6°。每個帶內的座標使用東移（Easting，500000m 為中央經線）和北移（Northing，赤道為 0）表示。UTM 座標廣泛應用於地圖測繪、GPS 導航和軍事地圖等領域。

極晝極夜原理

極晝和極夜發生在緯度高於 66.5°（北極圈/南極圈）的區域。當太陽直射點到達北迴歸線（23.5°N，夏至）時，北極圈內出現極晝，南極圈內出現極夜。太陽赤緯 = 23.5° × sin(2π × (N-81)/365)，其中 N 為年內天數。

Bortle 光汙染等級說明

  • Class 1：完美暗天，銀河肉眼可見，黃道光明顯

  • Class 4：鄉村/郊區過渡，銀河可見但細節減少
  • Class 5：郊區，銀河勉強可見
  • Class 6：郊區/城市過渡，銀河不可見
  • Class 7：城市/郊區過渡，雲層被照亮
  • Class 8：城市天空，只能看到亮星
  • Class 9：市中心，只能看到行星和最亮恆星

❓ 常見問題

月相計算準確嗎？
使用簡化天文演算法，精度在 1-2 天內，滿足日常參考需求。精確天文歷需要考慮月球軌道偏心率等更多因素。
UTM 座標精度如何？
使用 WGS84 橢球體引數，簡化投影公式在小範圍內精度良好，適用於一般地理參考。

❓ 常見問題（FAQ）

天文觀測工具箱 結果可直接用於決策嗎？
天文觀測工具箱 適合用於預估與複核，正式決策請結合完整資料口徑說明（口徑定義、時間區間、邊界條件）。

先核對輸入單位與是否存在“% 與小數”混用，再確認分母與分子定義是否同口徑，最後替換一組可復現例項複測。
