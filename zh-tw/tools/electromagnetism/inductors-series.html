📐 計算公式
L = L₁ + L₂

串聯電感總和即為等效電感（忽略互感）。

📌 計算說明
  • L_eq = L₁ + L₂（無互感）。
  • 1+2 = 3 mH。

📚 深度解析：串聯電感

💡 常見使用場景

  • 多電感串聯求總感
  • 升壓/濾波
  • 總感計算
公式
無互感時 Lt = L1 + L2 + ...；有互感 M：Ls = L1 + L2 ± 2M。例：10+22+33 mH = 65 mH。

❓ 常見問題（FAQ）

互感影響？
同向串聯加 2M，反向減 2M，由佈線繞向決定符號。
