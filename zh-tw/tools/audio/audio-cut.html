📝 工具簡介

音訊剪下工具是一款基於 Web Audio API 的純前端線上音訊裁剪器。無需安裝軟體，上傳音訊後即可在視覺化波形上拖拽選擇片段，精確到毫秒級裁剪，並一鍵匯出標準 WAV 檔案。

✨ 功能特點

  • 拖拽上傳音訊
  • Canvas 波形視覺化
  • 滑鼠拖選剪下區域
  • 精確時間輸入（秒）
  • 片段試聽預覽
  • OfflineAudioContext 渲染匯出
  • 匯出標準 WAV（16bit PCM）
  • 純本地處理，資料不上傳
  • 支援深色模式與響應式

🎯 使用場景

  • 擷取音訊片段做鈴聲
  • 裁剪播客/錄音多餘開頭結尾
  • 提取音樂高潮部分
  • 為影片製作精準音訊素材
  • 去除音訊中的靜音或噪聲段

💬 常見問題

匯出的為什麼是 WAV 格式？
WAV 是無損未壓縮格式，可由瀏覽器原生 Web Audio API 直接編碼生成，無需第三方庫，相容性最佳。如需 MP3，可用音訊格式轉換工具二次處理。
為什麼有些音訊檔案無法載入？
瀏覽器僅支援其內建解碼器可處理的格式（如 MP3、WAV、OGG、M4A、FLAC 等）。若格式不被支援，將提示解碼失敗，建議轉換格式後再試。
裁剪會損失音質嗎？
不會。本工具通過 Web Audio API 直接對原始 PCM 取樣進行切片並重新渲染，匯出的 WAV 與源音訊在該片段內的取樣資料一致，無額外有失真壓縮。
⚠️ 使用說明與注意事項
  • 本工具純前端執行，音訊檔案不會上傳到伺服器
  • 建議在主流瀏覽器（Chrome / Safari / Firefox / Edge）中使用
  • 首次播放/試聽需使用者互動後瀏覽器才會允許音訊輸出
  • 大檔案解碼可能需要數秒，請耐心等待
  • 匯出的 WAV 檔案體積較大（約每分鐘 10MB/單聲道），請注意儲存空間
