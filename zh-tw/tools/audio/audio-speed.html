📝工具簡介

音訊播放速度調節工具，基於 Web Audio API 與 HTML5 Audio 實現。上傳任意音訊檔案後，可通過滑塊在 0.25x 到 4x 範圍內自由調節播放速度，支援保持原音調播放、進度拖拽定位、一鍵匯出變速後的 WAV 檔案。所有處理在瀏覽器本地完成，資料不上傳，保護隱私安全。

✨功能特點

  • 0.25x ~ 4x 無級變速調節
  • 6 檔預設速度快捷切換
  • 可選保持原音調不變調播放
  • 進度條拖拽快速定位
  • 匯出變速 WAV 檔案（OfflineAudioContext 渲染）
  • 純前端處理，檔案不上傳
  • 支援深色模式與移動端響應式

🎯使用場景

  • 語言學習：慢速聽清外語發音細節
  • 播客速聽：1.5x~2x 加速收聽節省時間
  • 音樂練習：放慢節奏逐句學習樂器
  • 聽寫轉寫：變速反覆聽寫會議錄音
  • 音訊製作：生成變速變調特效音訊
  • 字幕製作：精準定位對齊時間軸

💬常見問題

變速後音調會變嗎？
預設情況下音調會隨速度變化（加速變尖、減速變沉）。勾選"保持原音調"後，即時播放將保持原始音調。匯出的 WAV 檔案為純變速渲染，音調會隨速度變化。
匯出的 WAV 檔案和原檔案有什麼區別？
匯出的是經過變速渲染的 WAV 格式音訊（16bit PCM）。如果原檔案是 MP3/OGG 等壓縮格式，匯出後會轉為無損 WAV，音質取決於原始解碼質量。
我的資料會被上傳嗎？
不會。所有音訊解碼、播放、渲染和匯出都在你的瀏覽器本地完成，檔案不會發送到任何伺服器。
支援哪些音訊格式？
支援瀏覽器可解碼的所有格式，包括 MP3、WAV、OGG、M4A、FLAC、AAC 等。具體支援情況取決於瀏覽器。
