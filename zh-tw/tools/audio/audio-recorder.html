📝工具簡介

線上錄音工具基於 Web Audio API 與 MediaRecorder API 實現，可直接在瀏覽器中呼叫麥克風進行錄音，無需安裝任何外掛或軟體。錄音過程中提供即時波形視覺化與音量電平條，幫助直觀掌握錄音狀態，並支援暫停、繼續、停止等完整控制。

✨功能特點

  • 即時波形視覺化（Canvas + AnalyserNode）
  • 即時音量電平條顯示
  • 錄音時長精確計時（分:秒.毫秒）
  • 開始 / 暫停 / 繼續 / 停止 完整控制
  • 支援 WebM/Opus 與 WAV 兩種格式
  • 錄音列表可線上播放、下載、刪除
  • 純前端處理，錄音不上傳伺服器
  • 支援深色模式與移動端響應式佈局

🎯使用場景

  • 會議、課堂、訪談快速錄音
  • 語音備忘與靈感記錄
  • 配音、朗讀練習與回放
  • 播客、自媒體音訊素材採集
  • 語言學習跟讀對比
  • 無需安裝軟體的臨時錄音需求

💬常見問題

錄音時瀏覽器提示需要麥克風許可權怎麼辦？
點選「允許」即可。若誤點了拒絕，可點選瀏覽器位址列左側的鎖形/調整圖示，將麥克風許可權改為允許後重新整理頁面重試。
WebM 和 WAV 該選哪個？
WebM/Opus 採用壓縮編碼，體積小、音質好，適合絕大多數日常場景；WAV 為無損 PCM 格式，音質最佳但檔案較大，適合需要後期專業處理的場景。
錄音會儲存到伺服器嗎？
不會。所有錄音都在瀏覽器本地完成，資料僅存在當前頁面記憶體中，不會上傳任何伺服器。關閉頁面後錄音會清空，請及時下載。
為什麼有些瀏覽器無法錄音？
請確保使用支援 MediaRecorder API 的現代瀏覽器（Chrome、Edge、Firefox、Safari 較新版本），並確認裝置已連線麥克風且未被其他程式佔用。
