📝工具簡介

音訊音量調節工具基於瀏覽器原生 Web Audio API 的 GainNode 節點，即時調節音訊檔案的音量增益，範圍從 0%（靜音）到 200%（放大兩倍）。支援播放控制、進度拖動、漸入漸出、VU 音量表視覺化，並可將調整後的音訊匯出為標準 WAV 檔案。所有處理均在瀏覽器本地完成，音訊檔案不會上傳到任何伺服器。

✨功能特點

  • Web Audio API GainNode 即時增益
  • 音量範圍 0% ~ 200%
  • 靜音/50%/100%/150%/200% 快捷預設
  • 播放/暫停與進度條拖動
  • 漸入漸出效果（0-10 秒）
  • VU 表即時電平視覺化
  • OfflineAudioContext 匯出 WAV
  • 純前端處理，檔案不上傳
  • 支援深色模式與響應式佈局

🎯使用場景

  • 音訊音量過小需要放大
  • 錄音檔案音量過大需要降低
  • 製作帶淡入淡出效果的音訊
  • 統一多個音訊檔案的響度
  • 音訊後期處理與剪輯
  • 播客/影片配音音量調整

💬常見問題

音量調到 200% 會有雜音怎麼辦？
增益超過 100% 時可能出現削波失真（clipping）。建議適度提升，若原始音訊電平已接近滿幅，放大後會產生爆音，可配合淡入淡出或適當降低增益。
為什麼匯出的是 WAV 而不是 MP3？
WAV 是無壓縮格式，可通過 Web Audio API 的 OfflineAudioContext 直接編碼生成，無需第三方庫。MP3 編碼需要專門的編碼器庫，為保證純前端輕量執行，本工具匯出 WAV。
淡入淡出在即時播放時生效嗎？
即時播放時僅應用基礎音量增益以保證流暢體驗；淡入淡出效果在匯出 WAV 時完整應用，確保匯出檔案包含完整的漸變效果。
支援哪些音訊格式？
支援瀏覽器可解碼的所有格式，包括 MP3、WAV、OGG、M4A、FLAC 等（具體取決於瀏覽器支援）。匯出統一為 WAV 格式。

❓ 常見問題（FAQ）

audio 業務裡如何快速落地？
先抽取3-5個典型樣本定義口徑，再把所有輸入按該口徑對映後執行，輸出用於討論決策。
發現輸出不一致怎麼辦？
先確認欄位單位和時點定義，再回傳人工樣本複核，避免直接基於異常結果做業務動作。
⚠️ 使用說明與注意事項
  • 本工具純前端執行，音訊檔案不會上傳到伺服器，隱私安全
  • 增益超過 100% 可能產生削波失真，建議適度調整
  • 建議在主流瀏覽器（Chrome/Safari/Firefox/Edge 最新版）中使用
  • 大檔案匯出 WAV 需要一定處理時間，請耐心等待
