🎺 關於鋼琴鍵盤模擬器
▼

這是一個完全在瀏覽器中執行的虛擬鋼琴，使用 Web Audio API 合成逼真的鋼琴音色。無需安裝任何軟體或外掛，開啟即用。

⚡ 功能特點

  • Web Audio API 合成音色
  • 三種音色：鋼琴 / 電子琴 / 風琴
  • 鍵盤快捷鍵彈奏
  • 錄製彈奏序列
  • 可回放錄製內容
  • 可切換八度範圍
  • ADSR 包絡模擬
  • 響應式設計

🎬 使用場景

  • 音樂學習與練習
  • 旋律創作與靈感記錄
  • 音高與和絃辨識訓練
  • 教學演示與講解

❓ 常見問題

聲音沒有播放怎麼辦？
Web Audio API 需要使用者互動後才能啟用。請點選頁面上任意位置後再試。另外請確認裝置沒有靜音。
如何在移動端使用？
直接用手指點選琴鍵即可彈奏。左右滑動可以檢視完整鍵盤。
支援哪些音色？
目前提供鋼琴（正弦波+衰減）、電子琴（方波）和風琴（正弦波+諧波）三種音色，每種都有獨立的 ADSR 包絡引數。
