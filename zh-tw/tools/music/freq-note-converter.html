✦ 常見問題

什麼是十二平均律？
將一個八度等分為12個半音的律制，每個半音的頻率比為 2^(1/12) ≈ 1.0595。這是現代音樂最常用的律制。
偏差（cents）是什麼意思？
1 cent 等於一個半音的 1/100。如果偏差為 +50 cents，說明頻率比最近的音符高半個半音，剛好在兩個音之間。
A4 = 432 Hz 和 440 Hz 有什麼區別？
440 Hz 是國際標準音高（ISO 16）。432 Hz 被部分人認為更"自然"，但兩者差僅約 32 cents（約 0.32 個半音），在音樂實踐中有明顯音高差異。
試聽功能為什麼沒有聲音？
請確認瀏覽器未靜音且音量已開啟。試聽使用瀏覽器原生的 Web Audio API 生成正弦波，需要使用者先與頁面互動（點選）後才能播放。
