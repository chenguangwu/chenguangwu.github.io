🫁 COPD ( CAT Score ) Questionnaire

COPD ( CAT Score ) Questionnaire is available directly in your browser, with no data uploaded.

📐 工作原理與說明

本健康工具基於通用生理常數與經驗公式估算，結果僅供參考，不替代專業醫療診斷與建議。 工具名稱：COPD(CAT評分)問卷器 - 慢性阻塞性肺疾病評估測試8題量表。

請就 近2周 狀況選擇（0=無影響，5=極重影響）：

📋 CAT 評分臨床意義

總分影響程度臨床建議
0–10輕度影響輕微，維持治療，關注急性加重
11–20中度影響中等，最佳化治療，加強肺康復
21–30重度影響嚴重，強化藥物與支援治療
31–40極重度影響極重，全面評估，多學科管理
提示：CAT 是評估COPD健康狀態的簡明工具，建議每次隨訪複測。CAT變化≥2分視為有臨床意義的改變。GOLD 推薦結合 CAT、mMRC 及急性加重史進行 ABE 分組以指導治療。僅供臨床參考。
