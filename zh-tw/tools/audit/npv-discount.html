📋 折現明細表

期數現金流折現因子現值(PV)累計現值
公式：PV(t) = CF(t) / (1+r)^t ， NPV = Σ PV(t)
NPV > 0 專案可行；NPV < 0 專案不可行。折現率越高，遠期現金流現值越低。
