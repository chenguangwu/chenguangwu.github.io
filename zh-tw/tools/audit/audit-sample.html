變數抽樣
屬性抽樣公式（泊松分佈法）
n = R / (TM - EP)
R：可信賴程度對應的可靠性因子
TM：可容忍誤差率，EP：預期誤差率
可靠性因子表：90%→2.31，95%→3.0，99%→4.61
變數抽樣公式（均值估計法）
n = (Z × σ × N / TM)² （放回抽樣）
n = n₀ / (1 + n₀/N) （不放回抽樣，有限總體修正）
Z：可靠性係數（95%→1.96，90%→1.645，99%→2.576）
提示：樣本量越大，審計結論越可靠但成本越高。實際工作中還需考慮總體變異性、分層抽樣等因素，本工具結果供參考。
