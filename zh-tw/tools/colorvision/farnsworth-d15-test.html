🎨 Farnsworth D-15 Color Arrangement Test - ToolBox

A browser implementation of the classic Farnsworth Panel D-15: arrange 15 equal-lightness caps into a smooth hue sequence, then get a CIE u′v′ polar hue-trace plot, Total Error Score, confusion index and protan/deutan/tritan classification. Runs entirely locally.

📐 判定原理

① 色帽生成：取 D-15 的 15 個色度點 (x, y)，在固定亮度 Y 下換算 XYZ = (Y/y·x, Y, Y/y·(1−x−y))，再經 sRGB 逆矩陣得線性 RGB；越界的點沿「向同亮度中性灰收斂」的方向做二分法壓縮到色域內，因此 15 個色帽明度一致、只有色相與飽和度差異——這正是排列測試能遮蔽明暗線索的關鍵（可勾選「灰度預覽」自行驗證）。
② 色差度量：把每個色帽轉到 CIE 1976 u′v′ 均勻色度圖，u′ = 4x/(−2x+12y+3)、v′ = 9y/(−2x+12y+3)。相鄰兩帽的色度距離 √(Δu′²+Δv′²)×100 即一步色差；把 14 步累加得總誤差分 TES。理想順序的 TES 記為基準，混淆指數 C = TES(你的排列) / TES(理想排列)，完美排列 C = 1.00。
③ 軸向分析：只取「相鄰兩帽編號不連續」的錯位跳躍作為誤差向量，計算二階矩 Sxx、Syy、Sxy，主軸方向 θ = ½·arctan2(2Sxy, Sxx−Syy)，主/次特徵值之比開方得選擇性指數 S。S 越大說明錯誤越集中在一條直線上（二色視特徵），S≈1 說明錯誤是隨機的。
④ 分型：三條混淆線由二色視共軛點（copunctal point）確定——紅色盲 (0.747, 0.253)、綠色盲 (1.400, −0.400)、藍色盲 (0.171, 0.000)。把它們和 D65 白點連線投到 u′v′ 得到三個參考軸向角，θ 與哪一條最接近就歸為哪一型，嚴重度由 C 的大小分級。

把中間 13 個色帽按顏色漸變最平滑的順序排列：讓每一個色帽都和左右鄰居顏色最接近。兩端帶紫色圈的是固定基準帽，不能移動。桌面端可直接拖拽色帽；移動端點一下選中、再點另一個即可換位，也可以用色帽下方的 ◀ ▶ 按鈕微調，鍵盤使用者可用 Tab 聚焦後按 ← → 移動。

⚠️ 使用邊界與已知侷限
  • 本頁不是醫學檢查，結論不能作為診斷依據。真正的 D-15 是實體色帽在標準 C 光源／D65 照明箱下進行的，螢幕測試無法復現。
  • 顯示結果受顯示器色域、亮度、色溫、環境光、系統色彩管理與夜覽／護眼模式影響極大；測試前請關閉夜覽/色溫調節，把亮度調到舒適的中高檔，並在不反光的環境下進行。
  • 色度座標為公開文獻中的近似值，且經過 sRGB 色域壓縮，飽和度低於實物色帽，因此對輕度色弱的檢出靈敏度不如實體測試。
  • 矩量軸向分析在錯位數很少（1～2 處）時統計意義弱，容易被一次手滑放大成「有軸向」；此時請重測幾輪看結論是否穩定。
  • D-15 屬於篩查型測試，只對中重度色覺異常較敏感；正常結果不代表色覺完全無異常。若結果異常或日常已有紅綠混淆困擾，請到醫療機構做專業色覺檢查。
