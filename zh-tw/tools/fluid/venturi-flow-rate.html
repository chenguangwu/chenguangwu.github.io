📐 計算公式
Q = A₂√(2ΔP / [ρ(1−(A₂/A₁)²)])

輸入入口/喉部面積 A1、A2 與壓差 ΔP、密度 ρ，求流量。

📌 計算說明
  • 由伯努利+連續性推導。
  • 示例 → 約 0.00204 m³/s。

公式
Q = Cd*A2*sqrt(2*Δp/(rho*(1-(A2/A1)^2)))。喉部縮徑產生壓差換算流量。

❓ 常見問題（FAQ）

為何節能？
無活動件、壓損小，靠壓差測量流量。
Cd？
文丘裡 Cd 高達 0.98-0.99。
