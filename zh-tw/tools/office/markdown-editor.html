📝工具簡介

Markdown 編輯器是一款免費的線上分屏 Markdown 編輯工具。左側輸入 Markdown 文本，右側即時渲染 HTML 預覽效果。內建程式碼語法高亮（highlight.js）、Markdown 語法工具欄、自動儲存、檔案匯出等功能，適合編寫文件、部落格文章、技術筆記、README 檔案等場景。所有資料在瀏覽器本地處理，不上傳伺服器，保護隱私安全。

✨功能特點

  • 左右分屏即時預覽
  • 程式碼語法高亮（180+ 語言）
  • 工具欄快捷插入 Markdown 語法
  • 支援 GFM 表格、任務列表、刪除線
  • 自動儲存到 localStorage
  • 一鍵匯出 HTML / Markdown 檔案
  • 複製 HTML 原始碼或 Markdown 原文
  • Tab 鍵縮排與快捷鍵支援
  • 字數統計與閱讀時長估算
  • 深色模式與移動端適配

🎯使用場景

  • 編寫 GitHub README 文件
  • 撰寫技術部落格與教程
  • 編寫專案文件與 API 說明
  • 記錄學習筆記與知識整理
  • 編寫 Wiki 與協作文件
  • 排版微信公眾號文章草稿
  • 編寫產品需求文件（PRD）
  • 編寫技術方案與設計文件

💬常見問題

Markdown 編輯器是免費的嗎？
完全免費，無需註冊，直接在瀏覽器中開啟即可使用。所有功能均無限制。
我的內容會被上傳到伺服器嗎？
不會。所有編輯和渲染都在瀏覽器本地完成，內容自動儲存在 localStorage 中，不會發送到任何伺服器。
支援哪些 Markdown 語法？
支援標準 Markdown 語法和 GitHub Flavored Markdown（GFM），包括標題、加粗、斜體、刪除線、連結、圖片、程式碼塊（帶語法高亮）、列表、引用、表格、分割線、任務列表等。
如何匯出編輯好的文件？
點選「下載 HTML」可匯出包含樣式的 HTML 檔案，點選「下載 .md」可匯出 Markdown 原始檔。也可點選「複製 HTML」或「複製 Markdown」直接複製到剪貼簿。
關閉頁面後內容會丟失嗎？
不會。編輯內容會自動儲存到瀏覽器本地儲存中，下次開啟同一頁面時會自動恢復。如需清空內容，點選「清空」按鈕即可。
支援手機使用嗎？
支援。頁面已做響應式適配，在手機上編輯區和預覽區自動切換為上下排列布局，工具欄按鈕也會自適應排列。
