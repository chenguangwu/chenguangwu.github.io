MAGE 臨床意義：評估血糖波動的重要"金標準"指標。僅計算振幅大於1個SD的有效波動，取所有有效波峰到波谷或波谷到波峰的平均絕對值，不受基礎血糖水平影響。

MAGE 評估標準

MAGE (mmol/L)波動等級臨床意義
< 3.9穩定血糖波動小，控制良好
3.9 - 6.1輕度升高血糖波動中度，需關注
> 6.1顯著升高血糖波動大，需調整方案
計算公式：
1. 計算所有血糖值的平均值(MBG)和標準差(SD)
2. 識別連續血糖曲線上的波峰和波谷
3. 計算相鄰波峰-波谷的振幅差值
4. 篩選振幅 ＞ SD 的有效波動（以SD為閾值，通常1個SD）
5. MAGE = 所有有效波動振幅絕對值的算術平均數
注：本工具採用簡化演算法，將連續遞增段最高點作為波峰、連續遞減段最低點作為波谷進行識別。
