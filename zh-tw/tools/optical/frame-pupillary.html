📐 計算公式
單眼移心量 = (A + DBL) / 2 − PD / 2

Frame Pupillary is available directly in your browser, with no data uploaded.

幾何中心距 = A + DBL（兩鏡圈幾何中心間距）
單眼移心量 = (A + DBL) / 2 − PD / 2，正值表示向鼻側(內)移心，負值向顳側(外)移心
最小未切邊片徑 = ED + 2×|移心量| + 2mm 磨邊餘量
移心量過大需更大直徑鏡片或定製片，實際還需考慮散光軸位與稜鏡移心。結果供配鏡加工參考。
