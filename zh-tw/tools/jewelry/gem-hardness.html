📋 莫氏硬度等級說明

莫氏硬度(Mohs)：由德國礦物學家莫斯(Friedrich Mohs)於1812年提出，以10種標準礦物為參照，表示礦物抵抗刻劃的能力。

標準礦物：1滑石 → 2石膏 → 3方解石 → 4螢石 → 5磷灰石 → 6正長石 → 7石英 → 8黃玉 → 9剛玉 → 10金剛石。

佩戴建議：硬度≥7適合日常佩戴(耐刮擦)；硬度6-7需小心使用；硬度<6僅適合耳環、吊墜等不易碰撞的飾品，避免與硬物接觸。
