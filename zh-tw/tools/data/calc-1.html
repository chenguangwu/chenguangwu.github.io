📊 CSV to JSON Converter

Convert CSV data to a JSON array locally in your browser.

📐 工作原理與說明

本工具用於單位與格式換算，換算因子依據國際單位制(SI)及相關標準定義，結果保留輸入精度；純前端本地處理。 工具名稱：CSV轉JSON - 在瀏覽器本地將 CSV 資料轉換為 JSON 陣列。

📌 轉換規則
  • 首行為表頭時，欄位名取自第一行；否則使用 field_0、field_1 等預設鍵。
  • 支援引號包裹的欄位，引號內可包含分隔符和換行。
  • 空單元格將轉換為空字串，未填寫的行會被忽略。

❓ 常見問題（FAQ）

CSV轉JSON 可直接用於正式報告嗎？
適合用於快速核對和教學演示；正式報告建議補充資料來源、口徑定義、邊界條件與稽核責任鏈。
值跳變或異常偏差怎麼辦？
先核查輸入是否超出定義域、單位是否混用、以及引數是否按同一計算版本口徑輸入。
