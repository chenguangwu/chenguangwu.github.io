🧮 Hamming Code Checksum Bits

Hamming Code Checksum Bits is available directly in your browser, with no data uploaded.

📐 計算公式與說明

滿足 2ʳ ≥ m + r + 1 的最小 r
碼長 = m + r，效率 = m/(m+r)

漢明碼可檢測並糾正單位元錯誤。
