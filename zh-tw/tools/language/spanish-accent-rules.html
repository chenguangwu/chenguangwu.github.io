📖 重音規則說明

規則一：以母音 / n / s 結尾

以母音 (a, e, i, o, u) 或子音 n、s 結尾的單詞，重音落在倒數第二音節。

casa → CA-saperro → PE-rrocantan → CAN-tanmeses → ME-ses

規則二：以其他子音結尾

以除 n、s 以外的子音結尾的單詞，重音落在倒數第一音節(末音節)。

papel → pa-PELfeliz → fe-LIZseñor → se-ÑORreloj → re-LOJ

規則三：重音符號 (´)

如果重音不落在上述預設位置，必須用重音符號標出。有重音符號的單詞，重音就是符號所在音節。

lápiz → LÁ-pizespárrago → es-PÁ-rra-gojamás → ja-MÁSestán → es-TÁN

規則四：二重母音和三重母音

二重母音 (ai, au, ei, eu, ia, ie, io, iu, ou, ua, ue, uo, ui) 中，強母音 (a, e, o) 與弱母音 (i, u) 組合算一個音節；兩個弱母音也算一個音節。兩個強母音相鄰則分屬不同音節。

ciudad → ciu-DADpais → pa-ÍSreal → re-AL
