📝工具簡介

圖片縮放工具是一款基於瀏覽器 Canvas API 的線上影像尺寸調整工具。支援按百分比比例縮放和精確指定目標寬高兩種模式，可一鍵鎖定寬高比保持畫面比例，提供平滑（雙線性高質量）與快速（最近鄰）兩種重取樣演算法，並支援 PNG、JPEG、WebP 三種輸出格式及質量調節。所有處理在本地完成，圖片不上傳，安全可靠。

✨功能特點

  • 按比例縮放（10%~200%滑塊 + 預設按鈕）
  • 精確指定目標寬高，可鎖定寬高比
  • 平滑 / 快速兩種重取樣演算法可選
  • PNG / JPEG / WebP 多格式輸出
  • JPEG/WebP 質量可調（10%~100%）
  • 即時預覽縮放效果與尺寸對比
  • 純前端 Canvas 處理，圖片不上傳
  • 支援深色模式與移動端響應式佈局

🎯使用場景

  • 網頁配圖按比例縮小，最佳化載入速度
  • 縮圖 / 封面圖批次尺寸調整
  • 社交媒體頭像、封面尺寸適配
  • 證件照、報名照指定畫素尺寸
  • 桌布、 banner 放大或縮小
  • 郵件附件圖片壓縮減小體積

💬常見問題

圖片會被上傳到伺服器嗎？
不會。本工具使用瀏覽器原生 Canvas API 在本地完成所有縮放處理，圖片資料始終留在您的裝置上，不會發送到任何伺服器。
放大圖片會變得更清晰嗎？
不會。放大隻是將原有畫素資訊拉伸或插值到更大尺寸，無法憑空增加真實細節。建議選擇"平滑"演算法以獲得更自然的放大效果。
平滑演算法和快速演算法有什麼區別？
平滑演算法使用雙線性插值，畫質更好但稍慢；快速演算法使用最近鄰取樣，速度最快但放大會出現明顯鋸齒。日常使用建議選平滑演算法。
為什麼 JPEG 輸出後透明背景變白了？
JPEG 格式本身不支援透明通道，匯出時會自動以白色填充背景。如需保留透明效果，請選擇 PNG 或 WebP 格式輸出。
這個工具是免費的嗎？
完全免費，無需註冊登入，直接在瀏覽器中開啟即可使用，無使用次數限制。
