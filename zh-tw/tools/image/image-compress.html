⚠️ 使用說明與注意事項
  • 本工具純前端執行，圖片不會上傳到任何伺服器，保護隱私安全
  • JPEG 為有損格式，不支援透明背景（透明區域會填充白色）
  • WebP 相容現代瀏覽器（Chrome/Edge/Firefox/Safari 14+），壓縮率最優
  • PNG 為無損格式，質量滑塊不生效；對照片壓縮效果有限
  • 「最大尺寸」會等比縮放圖片，使長邊不超過設定值
  • 部分舊瀏覽器可能不支援 WebP 輸出，如遇失敗請改選 JPEG

📝工具簡介

圖片壓縮工具是一款線上影像處理工具，利用瀏覽器 Canvas API 對圖片進行壓縮與最佳化。支援 JPEG、WebP、PNG 三種輸出格式，可自由調節壓縮質量（1%～100%），並可設定最大尺寸進行等比縮放。支援單張即時對比預覽與多張批次壓縮，所有處理在本地瀏覽器完成，圖片不離開裝置。

💬常見問題

圖片會被上傳到伺服器嗎？
不會。所有壓縮處理都在你自己的瀏覽器中通過 Canvas API 完成，圖片資料不會發送到任何伺服器，完全保護隱私。
為什麼壓縮後圖片反而變大了？
當原圖本身已是高度壓縮的格式（如小體積 JPEG），轉成 PNG 無損格式時體積可能增大。建議照片使用 JPEG 或 WebP 格式，圖示/截圖使用 PNG。
WebP 和 JPEG 哪個更好？
WebP 在同等畫質下通常比 JPEG 體積更小（約小 25%-35%），且支援透明通道。現代瀏覽器均支援 WebP，推薦優先使用。如需相容老舊環境，可選 JPEG。
質量滑塊設為多少合適？
一般 70%-85% 即可在體積與畫質間取得良好平衡。網頁用圖建議 70%-80%，需要高畫質保留細節可設 85%-95%。可拖動對比滑塊即時檢視效果。
支援哪些圖片格式上傳？
支援所有瀏覽器能解析的圖片格式，包括 JPEG、PNG、WebP、GIF（靜態）、BMP 等。輸出僅支援 JPEG、WebP、PNG 三種常見格式。
