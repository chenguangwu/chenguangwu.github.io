Molality

Molality is available directly in your browser, with no data uploaded.

📐 計算公式
b = n / m_溶劑

質量摩爾濃度 = 溶質物質的量 / 溶劑質量(kg)，不受溫度影響。

📌 計算說明
  • b = n_溶質 / m_溶劑(kg)。
  • 1 mol 溶於 0.5 kg 溶劑得 2 mol/kg。

❓ 常見問題（FAQ）

質量摩爾濃度（b = n / m_溶劑） 更適合用於快速校驗與教學說明，正式輸出前請確認口徑、來源與邊界條件。
