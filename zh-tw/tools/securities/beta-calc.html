📋 計算說明

🔢 Beta計算公式

Beta = Cov(Ri, Rm) / Var(Rm)

其中 Cov 為協方差，Var 為方差，Ri 為個股收益，Rm 為市場收益

相關係數 = Cov(Ri, Rm) / (σi × σm)

📊 CAPM模型

預期收益 E(Ri) = Rf + β × (E(Rm) - Rf)

Rf 為無風險利率，E(Rm) 為市場預期收益

📈 Beta值解讀

Beta範圍風險特徵說明
β = 1同步與市場同幅波動
β > 1進攻型波動大於市場，漲幅跌幅更大
0 < β < 1防守型波動小於市場，相對穩健
β = 0無關與市場波動無關
β < 0反向與市場反向波動（罕見）
兩個序列長度需相同，建議至少12期資料以提高統計可靠性。Beta反映系統性風險，非總風險。
