🔐 Password Generator

Create strong random passwords with customizable length and character sets.

📐 工作原理與說明

使用密碼學安全隨機源（crypto.getRandomValues）生成，可配長度與字元集（大小寫字母、數字、符號）。密碼強度用資訊熵衡量：熵(bit) = 長度 × log₂(字元池大小)。

  • 建議長度 ≥12、熵 ≥80 bit；含符號可顯著提升抗暴力破解。
  • 避免詞典詞與個人資訊；生成後妥善儲存，前端不留存。
  • 純瀏覽器生成，不離開本地。

高強度口令
勾選大小寫 + 數字 + 符號、長度 16，得到如 Tq7#mK9pL2@xW3vR 的口令；可同時生成多組供不同服務使用。

❓ 常見問題（FAQ）

長度和複雜度哪個更重要？
長度通常比複雜度更關鍵：12 位以上的隨機口令已極難暴力破解，混合字元集主要為了防止字典攻擊，關鍵是「隨機」而非「有規律」。
密碼管理器比自己記更好嗎？
是。用口令管理器儲存每個網站的唯一強密碼，你只需記住一個主口令，既強又不易複用，遠勝多個網站共用同一密碼。
