JSON 標準
  • CSV: Comma-Separated Values，逗號分隔值，是一種簡單的檔案格式，用於儲存表格資料
  • JSON: JavaScript Object Notation，是一種輕量級的資料交換格式，易於人閱讀和編寫
  • RFC 4180: CSV 的正式標準，規定了換行符、引號、轉義等規則
  • TSV: Tab-Separated Values，製表符分隔值，另一種常見的表格資料格式
  • 轉義規則: 欄位中包含分隔符、引號或換行符時，需要用引號包裹並轉義內部引號
