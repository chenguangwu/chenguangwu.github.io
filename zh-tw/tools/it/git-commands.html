🔄 Git Flow 工作流

Git Flow 是一種適合釋出型專案的分支模型，包含 5 種分支：master、develop、feature、release、hotfix。

1
初始化 Git Flow：
git flow init
2
開始新功能： 從 develop 建立 feature 分支
git flow feature start my-feature
3
完成功能： 合併回 develop，刪除 feature 分支
git flow feature finish my-feature
4
開始釋出： 從 develop 建立 release 分支
git flow release start 1.0.0
5
完成釋出： 合併到 master 和 develop，打 tag
git flow release finish 1.0.0
6
緊急修復： 從 master 建立 hotfix 分支
git flow hotfix start hotfix-1.0.1

🐙 GitHub Flow 工作流

GitHub Flow 是更簡潔的工作流，適合持續部署的專案。只有 master 和 feature 分支。

1
從 master 建立分支：
git checkout -b feature/my-feature
2
提交修改：
git add . && git commit -m "feat: 添加新功能"
3
推送到遠端：
git push -u origin feature/my-feature
4
建立 Pull Request：
在 GitHub 網頁上發起 PR，請求團隊成員 Code Review。
5
評審併合並：
評審通過後合併到 master，可使用 Squash merge 保持歷史整潔。
6
刪除分支並部署：
git branch -d feature/my-feature
合併後自動部署到生產環境。
