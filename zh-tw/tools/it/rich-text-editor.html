📝 富文本編輯器

所見即所得（WYSIWYG）線上編輯器：支援加粗、斜體、下劃線、標題層級、有序/無序列表、超連結、表格、文字與背景顏色、對齊方式、引用與程式碼塊；即時統計字元數、詞數、段落數；可一鍵匯出 HTML 原始碼、純文本或 Markdown，也支援匯入本地 HTML 檔案繼續編輯。全部在瀏覽器本地完成，內容不上傳伺服器。

📐 工作原理與說明

編輯區基於瀏覽器原生 contentEditable 與 document.execCommand 實現，不依賴任何富文本框架；Markdown 匯出由內建規則對 HTML 節點做結構化轉換；檔案匯入使用 FileReader 在本地讀取，全流程無網路請求。工具名稱：富文本編輯器 - 所見即所得線上編輯器。

❓ 常見問題（FAQ）

該工具適用於哪些 it 場景？
只要資料可對映到本工具支援的引數結構，就可用於日常分析、篩選、校驗等流程；多數情況下適合前置評估和結果複核。
結果可信度如何保證？
工具預設按前端可見規則即時計算，不依賴外部服務；如有偏差，建議結合歷史基準值做交叉確認。
⚠️ 使用說明與注意事項
  • 本工具純前端執行，編輯內容不會上傳到伺服器，重新整理頁面會丟失，請先匯出儲存
  • 建議在主流瀏覽器（Chrome/Safari/Firefox/Edge）中使用，快捷鍵 Ctrl+B / Ctrl+I / Ctrl+U 可用
  • Markdown 匯出為常用語法的近似轉換（標題、列表、加粗、斜體、連結、引用、程式碼），複雜表格可能需手工微調
  • 貼上外部內容時若帶入冗餘樣式，可用「🧹 清格式」按鈕清除
