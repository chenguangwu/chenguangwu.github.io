📊 JSON to CSV

JSON to CSV is available directly in your browser, with no data uploaded.

📐 工作原理與說明

將 JSON 物件陣列展平為二維表格的邏輯:

  • 遞迴下鑽巢狀物件/陣列,鍵名以"·"或"."合併為列名(如 user.name)。
  • 每個陣列元素輸出一行;值轉為字串(布林、數字、日期原樣)。
  • null / 缺失欄位留空;陣列經索引展開。

匯出建議帶 UTF-8 BOM,以便 Excel 正確識別中文不亂碼。全程純前端解析,資料不上傳。

本開發工具在前端本地完成解析、轉換與處理，程式碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：JSON 轉 CSV - 把 JSON 陣列一鍵轉為 CSV。
