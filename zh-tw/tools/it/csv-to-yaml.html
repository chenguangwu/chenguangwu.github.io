📄 CSV 轉 YAML 轉換器

在配置、CI、Kubernetes 等場景常需要在 CSV 與 YAML 之間互轉。首行會被當作欄位名生成鍵值對；若首行也想要陣列，可勾選“無表頭”。

📐 工作原理與說明

本開發工具在前端本地完成解析、轉換與處理，程式碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：CSV 轉 YAML 轉換器。

⚠️ 使用說明與注意事項
  • 逗號、換行、雙引號會被自動按 RFC 4180 處理；包含逗號/換行的欄位請用雙引號包裹。
  • 無表頭模式輸出為巢狀陣列，有表頭模式輸出為鍵值對列表。
  • 值為空時輸出空字串；如需 null 可後續手動替換。

📄 YAML 基礎語法

結構寫法
列表- item1
- item2
對映key: value
巢狀parent:
  child: 1
多行文本text: |
  line1
  line2

本工具輸出採用 2 空格縮排的標準 YAML；引號由 JSON.stringify 處理特殊字元，可被常見 YAML 解析器直接讀取。
