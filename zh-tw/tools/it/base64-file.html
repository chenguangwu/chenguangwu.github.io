📚 深度解析：檔案轉 Base64（Data URI）

💡 常見使用場景

  • 把小圖示 / 圖片內聯為 data URI，嵌入郵件或單檔案 HTML，避免額外請求。
  • 上傳前在瀏覽器本地預覽檔案內容，不把檔案發到伺服器。
  • 把證書、字型等二進位制資源轉成可貼上的文本形式。
圖片轉 Data URI
選擇一個 PNG 檔案，工具在本地讀取並輸出 data:image/png;base64,iVBORw0KGgo... 形式字串，可直接放入 <img src="..."> 或 CSS background。

❓ 常見問題（FAQ）

Data URI 有大小限制嗎？
瀏覽器和郵件系統對 URL / data URI 長度有限制（常見幾 MB 到幾十 MB 不等），大檔案應改用普通檔案連結而非內聯，否則可能截斷或拖慢頁面。
內聯圖片會影響效能嗎？
Data URI 省了一次請求，但無法被瀏覽器單獨快取、且體積比原檔案大約 33%，適合小圖示；大圖仍建議用獨立檔案 + 快取。
