❓ 常見問題

正規表示式支援哪些語法？
支援 JavaScript 標準正則語法，包括捕獲組 ($1, $2)、非捕獲組 (?:)、前瞻 (?=) 等。替換內容中可用 $& 引用整個匹配、$1 引用第一個捕獲組。
多行模式有什麼作用？
啟用多行模式後，^ 和 $ 將匹配每行的開頭和結尾，而不是整個文本的開頭和結尾。適合逐行處理文本。
我的資料安全嗎？
完全安全。所有文本處理均在瀏覽器本地完成，不會上傳到任何伺服器，關閉頁面後資料即消失。
