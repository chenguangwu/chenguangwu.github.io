🗜️ JSON Compress / Format

JSON Compress / Format is available directly in your browser, with no data uploaded.

📐 工作原理與說明

本開發工具在前端本地完成解析、轉換與處理，程式碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：JSON 壓縮/格式化。

模式：

📚 JSON 規範速查

要點說明
合法值型別string / number / object / array / true / false / null
鍵與字串必須使用雙引號，單引號不合法
跳脫字元\" \\ \/ \b \f \n \r \t \uXXXX
壓縮本質移除所有無意義空白與換行，不改變語義

常見錯誤：使用單引號、末尾多餘逗號、含註釋、數值帶前導零——均會導致解析失敗。

📚 深度解析：JSON 壓縮（Minify）

💡 常見使用場景

  • 在介面請求 / 響應中去掉空白與換行，減小傳輸體積、節省頻寬。
  • 把 JSON 嵌入 <script> 或屬性前壓縮，縮短文本長度。
  • 對比壓縮前後確認語義未被改變。
去空白
把帶縮排格式化的 JSON 貼上進去，輸出去除所有空格換行的單行版本，欄位順序與值完全不變。

❓ 常見問題（FAQ）

壓縮會改變資料含義嗎？
不會。Minify 只刪除空白與換行，鍵、值、結構保持不變，是純文本層面的瘦身。
壓縮和 gzip 有什麼區別？
壓縮（minify）是去掉原始碼層空白，傳輸層 gzip / brotli 再對位元組流整體壓縮，兩者互補：先 minify 減小明文體積，再 gzip 進一步壓縮網路包。
