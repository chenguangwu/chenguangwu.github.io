🐳 docker run 轉 docker-compose

docker run 一長串命令列引數，遷移到 docker-compose 時需逐條對應成 YAML 欄位。本工具解析常用引數並生成可貼上的 compose 片段，便於多容器編排管理。

📐 工作原理與說明

本開發工具在前端本地完成解析、轉換與處理，程式碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：docker run 轉 docker-compose。

⚠️ 使用說明與注意事項
  • 支援引數：-d/--detach、-p/--publish、-v/--volume、-e/--env、--name、--restart；其餘未知 - 引數在解析時跳過，可按需手動補到 compose。
  • compose 預設以後臺執行，原 -d 無需對應欄位；restart 策略沿用 unless-stopped / always / no 等原值。
  • 本解析為輕量級：不支援 --network、--link、多值 -e 合併等複雜寫法，生成後請在本地 docker compose config 校驗。
