📖 使用說明

功能說明

  • 格式化：自動調整縮排、對齊，使YAML結構清晰易讀
  • 壓縮：移除多餘空白和註釋，生成緊湊YAML
  • 驗證：檢查YAML語法錯誤，定位錯誤位置
  • YAML↔JSON互轉：一鍵在兩種格式間轉換

YAML 語法要點

  • 使用縮排表示層級關係（空格，不能用Tab）
  • 鍵值對用冒號分隔: key: value
  • 列表用短橫線: - item
  • 註釋以 # 開頭
  • 字串通常不需要引號，特殊字元需要
