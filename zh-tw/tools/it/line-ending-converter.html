↩️ 換行符轉換器

貼上文本，自動統計 CRLF（Windows）、LF（Unix/macOS）、CR（老 Mac）三種換行符數量，一鍵轉換為目標格式，解決跨平臺檔案亂碼與 Git 換行告警。
