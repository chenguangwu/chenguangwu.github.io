🛠️ JSON 修復器

從介面日誌、配置檔案複製來的 JSON 常帶尾隨逗號、單引號鍵、JS 註釋等問題，直接 JSON.parse 會報錯。本工具嘗試自動修復並輸出可解析的結果。

📐 工作原理與說明

本開發工具在前端本地完成解析、轉換與處理，程式碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：JSON 修復器。

⚠️ 使用說明與注意事項
  • 修復器會移除 /* */ 與 // 註釋、把單引號鍵/值轉成雙引號、刪除物件/陣列尾隨的逗號，覆蓋大多數複製貼上造成的錯誤。
  • 修復是啟發式的：若結構本身嚴重損壞（缺括號、鍵名無引號且非數字），仍可能失敗，請對照錯誤提示手動修正。
  • 處理敏感資料時請在本地完成，不要上傳到第三方修復網站。

📋 常見 JSON 錯誤與修復

問題示例修復
尾隨逗號[1,2,3,][1,2,3]
單引號{'a':1}{"a":1}
行註釋{"a":1} // x{"a":1}
鍵無引號{a:1}{"a":1}
