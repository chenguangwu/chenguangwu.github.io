📚 原理說明

什麼是 HTML 實體轉義？

HTML 實體轉義是將特殊字元轉換為 HTML 實體的過程，以確保這些字元在網頁中正確顯示而不被瀏覽器解析為 HTML 程式碼。

為什麼需要轉義？

• 防止 XSS 攻擊：轉義使用者輸入，避免惡意指令碼注入
• 正確顯示特殊字元：如 < > & 等在 HTML 中有特殊含義的字元
• 程式碼展示：在網頁中顯示 HTML/XML 原始碼

三種實體格式

1. 命名實體：&lt;（可讀性好，數量有限）
2. 數字字元引用（十進位制）：&#60;（支援所有 Unicode 字元）
3. 十六進位制字元引用：&#x3C;（與 Unicode 碼點對應）

JavaScript 轉義

在 JavaScript 字串中，特殊字元需要用反斜槓轉義：
• \" 雙引號
• \\ 反斜槓
• \n 換行符
• \t 製表符
• \uXXXX Unicode 字元

URL 編碼

URL 中只能使用 ASCII 字元集。非 ASCII 字元和特殊字元需要使用百分號編碼（Percent-encoding），格式為 %XX，其中 XX 是字元的十六進位制值。
