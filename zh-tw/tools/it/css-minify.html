🎯 CSS 壓縮器

上線前壓縮 CSS 可減少傳輸體積、提升首屏速度。本工具去除 /* */ 註釋與冗餘空白，輸出精簡 CSS，體積對比一目瞭然。

📐 工作原理與說明

本開發工具在前端本地完成解析、轉換與處理，程式碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：CSS 壓縮器。

⚠️ 使用說明與注意事項
  • 壓縮僅去註釋與空白，不改變選擇器與宣告語義；但會移除 source map 關聯與可讀性，釋出版勿保留源註釋。
  • 本工具不重寫屬性（如合併 0px→0），屬於「安全壓縮」；激進壓縮（變數內聯、自動字首）需交給構建工具（cssnano/esbuild）。
  • 生產環境應同時開啟 Gzip/Brotli，文本壓縮對 CSS 收益最大。

📋 說明

壓縮後請本地預覽效果是否一致；涉及 content 偽元素裡特殊空格時，過度去空白可能需謹慎。本工具保留宣告間必要空格。
