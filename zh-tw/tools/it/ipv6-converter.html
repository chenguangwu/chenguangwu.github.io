🌐 IPv6 地址轉換器

IPv6 用冒號分隔的 8 組 16 進製表示，連續全 0 段可壓縮為 ::。本工具標準化輸入並給出完整展開式與各段，便於核對與填寫。

📐 工作原理與說明

本開發工具在前端本地完成解析、轉換與處理，程式碼不離開瀏覽器，遵循對應語法與格式規範。 工具名稱：IPv6 地址轉換器。

⚠️ 使用說明與注意事項
  • IPv6 共 128 位，寫成 8 組、每組 4 個十六進位制數字，組間用冒號分隔。
  • 壓縮規則：連續的全 0 段可替換為 ::（一個地址只能壓縮一次），如 2001:db8:0:0:0:0:0:1 → 2001:db8::1。
  • 每組前導 0 可省略（1:0:0:0 寫作 1::），但 :: 只能出現一次，否則無法唯一還原。

📋 示例

壓縮完整
::10000:0000:0000:0000:0000:0000:0000:0001
2001:db8::12001:0db8:0000:0000:0000:0000:0000:0001
fe80::1fe80:0000:0000:0000:0000:0000:0000:0001
