📖 使用說明

功能說明

  • 即時編譯：輸入 Less 程式碼時自動延遲編譯，無需手動點選
  • 變數 Variables：@width: 10px; 定義變數，可在全域性複用
  • 混合 Mixins：.bordered(); 引用一組屬性集合
  • 巢狀 Nesting：支援選擇器層級巢狀，結構更清晰
  • 運算 Operations：支援加減乘除等數學運算
  • 函式 Functions：darken()、lighten()、fade() 等顏色與數學函式

編譯選項

  • 壓縮模式：移除註釋和多餘空白，輸出最小體積 CSS
  • 嚴格數學：僅在括號內執行數學運算，避免 font: 12px/1.5 被計算
  • 嚴格單位：單位不一致時報錯，而非自動轉換
  • Tab 縮排：輸入框中按 Tab 鍵可插入兩個空格縮排

📝工具簡介

Less 轉 CSS 編譯器是一款線上工具，可將 Less 前處理器程式碼即時編譯為瀏覽器可識別的標準 CSS。基於 less.js 引擎，支援變數、混合、巢狀、運算、函式等 Less 全部核心特性。所有編譯均在瀏覽器本地完成，程式碼不離開你的裝置。

✨功能特點

  • 純前端處理，程式碼不上傳伺服器
  • 即時編譯，輸入即編譯
  • 支援變數、混合、巢狀語法
  • 支援運算與內建函式
  • 壓縮模式輸出最小體積
  • 嚴格數學/嚴格單位模式
  • 編譯耗時與輸出統計
  • 詳細錯誤資訊提示
  • 一鍵複製與下載 CSS
  • 支援深色模式

🎯使用場景

  • 前端專案 Less 樣式開發除錯
  • 快速預覽 Less 編譯效果
  • 學習 Less 語法與特性
  • 將 Less 程式碼轉換為純 CSS
  • CSS 前處理器技術選型評估
  • 線上編寫可複用的樣式元件

💬常見問題

這個工具是免費的嗎？
完全免費，無需註冊，直接在瀏覽器中開啟即可使用。
我的程式碼會被上傳嗎？
不會。所有編譯都在你的瀏覽器本地完成，Less 程式碼不會發送到任何伺服器。
支援哪些 Less 特性？
支援 Less 的全部核心特性，包括變數（@var）、混合（Mixin）、巢狀（Nesting）、運算（Operations）、函式（Functions）、匯入（@import）、條件表示式等。
嚴格數學模式有什麼用？
開啟後，Less 只在括號內執行數學運算。這對於 font 簡寫中的行高（如 font: 12px/1.5）很有用，避免被誤計算。
編譯報錯怎麼辦？
錯誤面板會顯示詳細的錯誤資訊和行號，請根據提示檢查 Less 語法，如變數名拼寫、括號匹配、分號缺失等常見問題。
