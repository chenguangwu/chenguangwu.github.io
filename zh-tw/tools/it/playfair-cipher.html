📖 加密規則

  • 規則 1：同行字母 — 兩個字母在同一行，各取右邊的字母（最後一個取第一個）
  • 規則 2：同列字母 — 兩個字母在同一列，各取下邊的字母（最後一個取第一個）
  • 規則 3：矩形對角 — 兩個字母不在同行同列，取對方所在列的同行字母
  • 特殊：相同字母 — 兩個相同字母，在中間插入 X（或 Q），再分組
  • 特殊：奇數長度 — 明文長度為奇數時，末尾補 X（或 Q）
  • 特殊：I/J 合併 — I 和 J 視為同一字母，通常將 J 替換為 I

📚 演算法原理

什麼是普萊費爾密碼？

普萊費爾密碼（Playfair cipher）是第一種實用的雙字母替換密碼，由查爾斯·惠斯通於1854年發明，以其朋友萊昂·普萊費爾的名字命名。它在第二次布林戰爭和第一次世界大戰中被廣泛使用。

密碼矩陣構造

1. 選擇一個關鍵詞（如 "PLAYFAIR"）
2. 去除重複字母（"PLAYFIR"）
3. 將字母填入 5×5 矩陣
4. 剩餘位置按字母表順序填入剩餘字母
5. I 和 J 合併到同一格（通常將 J 替換為 I）

加密步驟

1. 將明文中的 J 替換為 I
2. 將明文按兩個字母一組劃分
3. 如果一組中兩個字母相同，在中間插入 X
4. 如果總長度為奇數，末尾補 X
5. 對每一組應用三條規則之一進行加密

歷史意義

普萊費爾密碼是第一個廣泛使用的雙字母替換密碼。與單字母替換密碼相比，它的安全性大大提高，因為頻率分析針對的是單個字母，而普萊費爾有 26×26=676 種可能的字母對，使得頻率分析變得困難得多。

安全性

雖然比單字母替換安全，但普萊費爾密碼仍可被破解：

• 只需幾百個字母的密文即可通過頻率分析破解
• 已知明文攻擊非常有效
• 現代計算機可以在幾秒鐘內暴力破解所有可能的金鑰

變體

• 雙字母替換：6×6 矩陣，包含數字
• 四方密碼：使用四個 5×5 矩陣
• 希爾密碼：基於線性代數的多字母替換
