📖 使用說明

支援的SQL方言

  • 標準SQL：ANSI SQL通用格式
  • MySQL：MySQL特有語法（反引號、LIMIT等）
  • PostgreSQL：PostgreSQL特有語法
  • SQL Server：T-SQL語法（TOP、方括號等）
  • SQLite：輕量資料庫SQL語法

格式化特性

  • 關鍵字自動大寫/小寫
  • SELECT欄位換行對齊
  • FROM/JOIN/WHERE/GROUP BY/ORDER BY等子句換行
  • 縮排對齊，可讀性強
  • 壓縮模式：移除所有空白，生成緊湊SQL
