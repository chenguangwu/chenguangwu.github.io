📌 計算說明
  • 計算長度 l₀ = k·h + 2a（扣件式鋼管腳手架簡化公式）
  • 長細比 λ = l₀ / i，i 為截面回轉半徑
  • 穩定係數 φ 按 a 類截面近似查表（線性插值）
  • 立杆穩定承載力 N ≤ φ·A·f，其中 f = fy / 抗力分項係數（取 1.1）
