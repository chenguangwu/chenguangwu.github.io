📋 負荷特性指標

負荷率 = 平均負荷 / 最大負荷，反映負荷平穩程度，越接近1越平穩。
峰谷差 = 最大負荷 − 最小負荷，反映負荷波動幅度。
峰谷差率 = 峰谷差 / 最大負荷，越大說明調峰需求越強。
需用係數 = 最大負荷 / 裝機容量（需輸入裝機容量估算）。
用電量 = Σ(各時段負荷 × 1h)，單位 kWh。
