🧩 工具嵌入 API

ToolBox 的所有工具均為純前端實現，可直接通過 <iframe> 嵌入到你的網站、部落格或文件中，資料全部在訪客瀏覽器本地處理。

免費 · 無後端 · 資料不出瀏覽器

1. 推薦寫法：帶署名回鏈

iframe 本身不傳遞 SEO 權重——搜尋引擎看到的是 iframe 的 src，不會給嵌入方或本站加分。 真正有價值的是 iframe 下方那條可點選、可抓取的署名連結。因此推薦用下面這段完整程式碼：

<div class="toolbox-embed">
  <iframe
    src="https://chenguangwu.github.io/tools/it/json-formatter.html?embed=1"
    width="100%" height="520"
    style="border:0;border-radius:12px" loading="lazy"
    title="JSON Formatter"></iframe>
  <p style="margin:6px 0 0;font:12px/1.5 system-ui,-apple-system,sans-serif;text-align:right">
    <a href="https://chenguangwu.github.io/tools/it/json-formatter.html" target="_blank" rel="noopener">JSON Formatter · ToolBox</a>
  </p>
</div>

不必手抄：開啟任意工具頁，頁面底部都有「分享與嵌入」區塊，展開即可一鍵複製適配當前工具的程式碼（可選高度與深淺主題）。

2. 基礎嵌入（最簡寫法）

將任意工具頁 URL 放入 iframe 即可（注意：這種裸 iframe 不含回鏈，不會傳遞權重）：

<iframe
  src="https://chenguangwu.github.io/tools/it/json-formatter.html?embed=1"
  width="100%" height="520" style="border:0;border-radius:12px"
  loading="lazy"></iframe>

3. 嵌入引數

引數說明示例
embed開啟嵌入模式，自動隱藏導航欄、麵包屑、隱私標識與主題按鈕?embed=1
theme強制主題：dark 或 light?theme=dark
accent自定義主題色（十六進位制，含 #）?accent=%23FF6B35

4. 組合示例

<iframe
  src="https://chenguangwu.github.io/tools/finance/compound-interest.html?embed=1&theme=dark&accent=%237C3AED"
  width="100%" height="560" style="border:0;border-radius:12px"
  loading="lazy"></iframe>

6. 注意事項與 SEO 說明

  • 嵌入頁與官網完全一致，所有計算在訪客本地完成，無需你的伺服器承擔算力。
  • 建議為 iframe 設定合適的固定高度（工具頁內容高度隨輸入變化）。
  • 如被瀏覽器攔截（X-Frame-Options），本站點已允許同源/跨域 iframe 嵌入。
  • 關於權重：iframe 不傳遞連結權重，只有頁面裡真實存在的 <a href> 才會傳遞。若希望這次嵌入也算作對 ToolBox 的一次推薦，請保留第 1 節中的署名回鏈（不要給它加 rel="nofollow"）；若不方便展示，去掉也完全沒問題，工具照樣可用。
