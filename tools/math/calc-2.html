📐 计算公式
比例 a:b = a/b

根据比例式 A : B = C : D，输入任意三项求解第四项。

比例式：A : B = C : D ⟺ A × D = B × C。留空需要求解的一项，工具会自动计算。
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器。
  • 请至少输入三项有效数值，留空一项作为求解目标。
  • 作为除数的项不能为 0。

📝工具简介

比例计算器根据比例的基本性质（内项积等于外项积）求解未知项，适用于各类按比例分配与换算场景。

✨功能特点

  • 四项任意留空求解
  • 自动识别未知项位置
  • 实时计算结果
  • 界面清晰，便于理解

🎯使用场景

  • 地图比例尺换算
  • 配方配比计算
  • 图像缩放尺寸换算
  • 金融杠杆与配比估算

💬常见问题

四项都填会怎样？
工具会校验比例是否成立，并显示内项积与外项积是否相等。
结果可以是负数吗？
可以。比例中的量可正可负，视具体应用场景而定。
