📐 计算公式
圆面积 A = πr², 周长 C = 2πr

输入半径、直径、面积或周长中的任意一项，自动计算其余三项。

公式：d = 2r，S = πr²，C = 2πr = πd。π 取 3.14159265359。

  • 若输入多个量，工具会以半径为优先依据重新计算。

圆是最基本的几何图形之一。本工具支持根据半径、直径、面积或周长中的任意一个量，快速推导其余三个量。

✨功能特点

  • 四项互算，灵活输入
  • 自动识别优先输入
  • 高精度 π 计算
  • 实时显示结果

🎯使用场景

  • 圆形场地面积估算

💬常见问题

输入多个量结果以哪个为准？
工具按 半径 → 直径 → 面积 → 周长 的优先级读取，优先使用最靠前的有效输入。
π 的精度是多少？
使用 Math.PI，约为 3.14159265359，足以满足日常学习与工程估算需求。
