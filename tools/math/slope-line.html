  • (1,2)→(4,8) 斜率 2。
  • 分母为零为竖直线。

📚 深度解析：直线斜率

💡 常见使用场景

  • 求两点连线的倾斜程度
  • 判断函数增减性、趋势
  • 工程坡度、道路仰角换算
两点斜率
过 (1,2) 与 (4,8)：斜率 m=(8-2)/(4-1)=6/3=2，即 x 每增 1，y 增 2。垂直直线斜率不存在（分母为 0）。
斜率与角度
m=tanθ，m=1 对应 45°，m=√3 对应 60°。负斜率表示下降。

❓ 常见问题（FAQ）

斜率为 0 和不存在分别是什么线？
斜率为 0 是水平线（y 恒定）；斜率不存在（分母 0）是竖直线（x 恒定）。
斜率和倾角关系？
m=tanθ，θ 为与 x 轴正向夹角。由此可从斜率反推角度，或从角度得斜率。
