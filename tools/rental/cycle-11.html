📐 工作原理与说明
用量 = 本次读数 − 上次读数。正常行读数倒退视为录入异常并阻止结算；勾选「换表」的行按新表读数从 0 起算。单一费率：费用 = 用量 × 单价。阶梯电价：第 i 档区间 = 本档上限 − 上一档上限，该档用量 = min(剩余用量, 区间)，费用 = 该档用量 × 档单价；末档不设上限，超出部分按末档单价计，不再漏计。计费周期可选「每次抄表区间独立累计」或「整个结算周期累计后统一套档」；后者按各段用量比例分摊总费用。结算对电/水/气分别汇总，记录最多保留最近 12 条。

💡 常见使用场景

  • 退租或换租时录入上次与本次读数，按阶梯或单一费率结算，并展示每段用量与费用明细。
  • 总用量超过原末档上限时，末档按不设上限处理，超出部分仍按末档单价计，不再出现「剩余用量免费」。
  • 电表更换或读数倒退时，勾选该行「换表」，按新表读数从 0 起算；未勾选则阻止结算并提示具体行。
330 kWh 与超过末档上限
上次读数 12 450、本次 12 780 → 用电 330 kWh。单一电价 0.60 元/kWh：330×0.60 = 198.00 元。阶梯第一档 0–200 kWh 按 0.55 元、第二档 200–600 按 0.63 元：200×0.55 + 130×0.63 = 110.00 + 81.90 = 191.90 元。若某段用量 700 kWh、末档从 600 起不设上限，则 200×0.55 + 400×0.63 + 100×0.83 = 445.00 元，100 kWh 不会漏计。

❓ 常见问题（FAQ）

读数倒退为什么不能直接记 0？
倒退可能是抄错、换表或表盘翻转。直接记 0 会少收费用且掩盖问题。工具会列出具体行与前后读数，要求更正，或由用户勾选「换表」按新表从 0 起算。
阶梯按每次抄表区间还是整个周期累计？
可在「阶梯累计周期」选择。每次区间独立套档适合按月抄表；整个结算周期累计适合跨月一次结算，此时先对总用量套档，再按各段用量比例分摊费用并在报告中注明。
空读数会怎样？
空读数不再被保存为 0，也不会参与结算；工具提示该行读数为空或无效，需补填或删除该行。

✨功能特点

  • 电/水/燃气三种表计
  • 阶梯末档不设上限
  • 换表与读数倒退校验
  • 按区间或整周期累计并展示明细

🎯使用场景

  • 退租或换租按读数结算
  • 超出末档用量核对
  • 换表后从 0 起算
