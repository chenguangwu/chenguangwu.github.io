Assessor 36

📐 工作原理与说明
社工介入需求总分 = 经济保障 + 健康照护 + 心理支持 + 社会支持（每项 0 至 3 分，满分 12）；不超过 3 分为低需求、4 至 7 分为中需求、8 分及以上为高需求；按得分最低的维度优先链接低保申请、家庭医生签约或心理咨询等社区资源。

老年人社工介入需求评估与资源链接（4维度，每项0-3分）

📚 深度解析：社工（介入/评估/资源）链接

💡 常见使用场景

  • 居家养老服务中，按经济保障、健康照护、心理支持、社会支持四维度评估介入需求。
  • 评估结果为低/中/高需求，对应不同随访频次与资源链接策略。
  • 重点维度（评分≥2）自动生成资源链接清单（如长护险、日间照料）。
算例：四项均评 0（状况良好）
介入需求总分 = 0 / 12 → 『低需求』，建议定期随访、保持社区联系即可。
算例：四项均评 2（重点介入）
总分 = 8 > 7 → 『高需求』，立即个案管理、多专业协作、每周随访，并链接四项对应资源（低保/家庭医生/心理热线/日间照料等）。

❓ 常见问题（FAQ）

介入需求分几级？
本工具按四维度求和（满分 12）：≤3 低需求、≤7 中需求、>7 高需求。高需求须立即个案管理并链接多方资源。
什么是『重点介入』维度？
单维度评分≥2 视为重点介入，工具会据维度推送对应资源（如健康照护→长护险申请、社会支持→志愿者结对），便于精准帮扶。
