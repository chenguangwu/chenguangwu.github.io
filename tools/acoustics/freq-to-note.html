📐 计算公式
n = 69 + 12·log₂(f/440)

输入频率，求最接近的标准音名（A4=440 Hz）及音分偏差。

📌 计算说明
  • A4=440 Hz 为基准，十二平均律。
  • 442 Hz → A4 +约 +8 音分。

  • 调音软件把检测到的频率映射到最近的钢琴音名。
  • 合成器或编曲中确认某频率对应哪个音高。
  • 音乐教学中理解十二平均律与 440 Hz 基准。
440 Hz 对应音名
以 A4=440 Hz 为基准，MIDI 音高 n=69+12·log2(f/440)。f=440 得 n=69 即 A4；f=523.25 得 n≈72 即 C5。

❓ 常见问题（FAQ）

十二平均律怎么定义音？
相邻半音频率比恒为 2^(1/12)≈1.0595，每八度翻倍，A4 约定为 440 Hz。
为什么同一音名有不同频率？
取决于基准音高（如 A4=432 Hz 与 440 Hz 体系），本工具默认 440 Hz 国际标准。
