Sound Intensity Level Calculator

Compute the intensity level from sound intensity relative to the reference I₀: L_I = 10·log₁₀(I / I₀).

📐 计算公式
声强级（主式）：L_I = 10·log₁₀(I ÷ I₀)（dB），参考声强 I₀ = 10⁻¹² W/m²；联动量：反推声强比 = 10^(L_I/10)、线性声强比 = I ÷ I₀、L_I/10（贝尔数）。校验：声强 I 非空守卫。判据：无固定分级，声强每 ×10 声强级 +10 dB，如 I=10⁻⁶ W/m² → 60 dB。

❓ 常见问题（FAQ）

声强级和声压级有什么区别？
声强级由声强定义，声压级由声压定义；自由场且平面波时二者数值相等。
I0=10⁻¹² 是怎么来的？
这是人耳在 1 kHz 附近可听阈的近似声强，被定为声强级基准。

📊 结果解读

结果含义

声强级 LI 表示声音相对于基准声强 I₀=10⁻¹² W/m² 的强度，以分贝（dB）对数刻度表达；数值越大，声音越强。

单位与量级参考

单位 dB（分贝，无量纲对数比）。日常参考：0 dB 听觉阈值、40 dB 正常谈话、70 dB 吸尘器、85 dB 以上长期暴露有听力损伤风险、120 dB 痛阈。

适用边界与注意事项

公式 LI=10·log₁₀(I/I₀) 适用于点声源自由场近似；实际声压级还受距离平方反比、环境反射与频率加权（A 计权）影响。本工具按理想模型计算，结果供快速估算参考。
