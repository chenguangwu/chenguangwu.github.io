From thread specification and material type, computes cutting speed, spindle speed and feed rate.

📐 计算公式
H = 0.866×P（理论）；H₁ ≈ 0.5413×P（实际牙高）

基于 ISO 公制 60° 螺纹基本牙型：理论三角形高度 H=0.866P，实际牙高 H₁≈0.5413P（约为 H 的 5/8）；用于螺纹加工切削深度确定。

💡 主轴转速 n = Vc×1000 / (π×D)；进给量 f = 螺距 P (mm/r)；切削次数根据螺距递减分配
⚠️ 注意事项
  • 按 Enter 快速计算，Ctrl/Cmd + Enter 复制结果
  • 仅支持公制(M)螺纹，粗牙可省略螺距（如 M10）
  • 切削速度为推荐范围中值，实际需根据刀具和工况调整
  • 高速钢刀取低值，硬质合金刀取高值

📚 深度解析：螺纹加工参数计算（转速、进给与分层进刀）

💡 常见使用场景

  • 车削编程：由螺纹规格与材料算主轴转速与进给速度
  • 攻丝/车螺纹工艺：确定切削次数与每次进刀深度
  • 材料适配：比较碳钢、不锈钢、铝合金等的切削速度区间
方法
算法：按材料取切削速度区间（碳钢 60~80、不锈钢 30~50、铝合金 120~200、黄铜 80~120、铸铁 70~100 m/min）；中值 Vc = (Vc_min+Vc_max)/2；主轴转速 n = Vc×1000/(π×公称直径)；每转进给 = 螺距 P；螺纹牙深 = 0.5413×P；总进刀量 = 牙深×1.3；切削次数 = ⌈P/0.3⌉+2；各次进刀按递减分配，前几次为平均量×1.2，最后一刀取剩余量；进给速度 = 中值转速×P（mm/min）。转速 >2000rpm 提示注意安全，<100rpm 提示效率低。
算例
例：M10×1.5 碳钢 → Vc 70m/min、转速 2228rpm（范围 1910~2546）、进给 1.5mm/r、进给速度 3342mm/min、牙深 0.812mm、切削 7 次，各次进刀 0.181→0.181→0.181→0.181→0.181→0.151→0.000mm，提示「转速较高，注意安全」。若改 M20×2.5 不锈钢 → Vc 40m/min、转速 637rpm、进给 2.5mm/r、进给速度 1593mm/min、牙深 1.353mm、切削 11 次，各次进刀 0.192mm×9 →0.032→0.000mm，提示「转速适中」。若改 M20×2.5 铝合金 → Vc 160m/min、转速 2546rpm、进给速度 6366mm/min。

❓ 常见问题（FAQ）

牙深 0.5413P 是什么？
0.5413×P 是 ISO 公制 60° 螺纹的基本牙型高度 H₁（理论三角形高为 0.866P，实际牙高约为其 5/8 = 0.5413P）。车削时径向进刀量按此牙高控制，再乘 1.3 的系数是为了计入刀尖圆弧与让刀，保证牙底清根。
最后一刀为什么显示 0.000？
本工具采用「前几刀取平均量×1.2、最后一刀取剩余量」的递减分配，当前几刀已把总余量吃完后，最后一刀剩余量为 0，实际加工中即为空走刀（光整刀）。这符合实际工艺——末刀常作为无切深的光整行程，用于消除让刀、提高牙面质量。
