🛢️ API Gravity

API Gravity is available directly in your browser, with no data uploaded.

📋 原油分类与公式

API 度 = 141.5 / SG − 131.5

SG = 141.5 / (API + 131.5)

密度 = SG × 水密度（g/cm³）

API 度类别典型代表
> 31.1轻质原油布伦特、WTI
22.3 - 31.1中质原油迪拜原油
10 - 22.3重质原油玛雅原油
< 10超重质/沥青委内瑞拉重油
