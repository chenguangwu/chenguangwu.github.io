🚀 Oil Viscosity Selection (ISO VG)

Select lubricant viscosity by temperature, load and speed.

📐 计算公式
润滑油粘度选型（VG 等级）
基准粘度（40°C）：<10°C → VG32｜<40 → VG46｜<60 → VG68｜<80 → VG100｜<100 → VG150｜<120 → VG220｜≥120 → VG320
载荷系数：轻载 0.8｜中载 1.0｜重载 1.3
转速系数：>3000rpm 0.7｜>1500 0.85｜>500 1.0｜≤500 1.2
计算粘度 = 基准粘度 × 载荷系数 × 转速系数
推荐等级：取与计算粘度最接近的标准 VG 等级（10~680）
工况粘度估算 = 推荐VG × e^(−0.04×(工况温度 − 40))
润滑油粘度选型：基于工况温度、载荷等级与转速，按润滑油牌号与粘度标准（如 ISO VG）选择适用粘度等级，并校核工作温度下的实际粘度是否足够，用于润滑设计。
💡 基准粘度随温度升高而增大；重载×1.3，轻载×0.8；高速降低粘度，低速增大粘度；匹配最近ISO VG等级
⚠️ 注意事项
  • 按 Enter 快速计算，Ctrl/Cmd + Enter 复制结果
  • 粘度等级为40℃运动粘度中心值（cSt）
  • 高温工况(>100℃)建议使用合成油
  • 实际选型还需考虑润滑方式和添加剂要求

📚 深度解析：润滑油粘度选型（ISO VG 等级推荐）

💡 常见使用场景

  • 齿轮箱/轴承选型：按温度、载荷与转速推荐 ISO VG 等级
  • 换油规范：为设备制定润滑油牌号与粘度标准
  • 工况校核：估算工作温度下的实际粘度是否足够
方法
算法：先按工况温度取基准粘度（<10℃ VG32、<40℃ VG46、<60℃ VG68、<80℃ VG100、<100℃ VG150、<120℃ VG220、否则 VG320）；载荷系数 轻载 0.8/中载 1.0/重载 1.3；转速系数 >3000rpm 取 0.7、>1500 取 0.85、>500 取 1.0、否则 1.2；计算粘度 = 基准×载荷系数×转速系数；在 ISO VG 系列 [10,22,32,46,68,100,150,220,320,460,680] 中取最接近的一档；工况粘度 = 推荐 VG×e^(−0.04×(温度−40))。油品类型：>100℃ 用全合成（PAO/酯类）、>70℃ 用半合成或高品质矿物油、重载用极压 EP 齿轮油、其余用矿物油或半合成油。
算例
例：60℃、中载、1500rpm → 基准 VG100、载荷系数 1.0、转速系数 1.00，计算粘度 100cSt，推荐 VG100，工况粘度约 44.9cSt，推荐「矿物油或半合成油」。若 90℃、重载、400rpm → 基准 VG150、载荷 1.3、转速 1.20，计算 234cSt，取最接近的 VG220，工况粘度约 29.8cSt，推荐「半合成油或高品质矿物油」。若 30℃、轻载、3500rpm → 基准 VG46、载荷 0.8、转速 0.70，计算 26cSt，推荐 VG22，工况粘度约 32.8cSt。

❓ 常见问题（FAQ）

为什么高速要选低粘度、低速重载选高粘度？
高速时低粘度可减小搅油损失与发热、利于散热；低速重载时油膜容易被挤破，需要更高粘度保证油膜强度，重载还应选用含极压抗磨添加剂的 EP 齿轮油。
工况粘度估算为什么随温度下降？
矿物油粘温关系近似指数，工具用 e^(−0.04×(T−40)) 折算：相对 40℃ 基准，温度每升高约 25℃ 粘度降至约 37%。选型的关键是保证工作温度下仍有足够油膜厚度，因此高温工况应选更高 VG 等级。

📝工具简介

润滑油粘度选型工具根据工况温度、载荷等级和转速，综合计算所需的运动粘度，匹配最接近的 ISO VG 粘度等级，并推荐合适的润滑油类型（矿物油/半合成/全合成）。

✨功能特点

  • 温度-载荷-转速三因素综合选型
  • 匹配 ISO VG 10~680 标准等级
  • 估算工况下的实际运动粘度
  • 根据温度和载荷推荐油品类型

🎯使用场景

  • 轴承、齿轮箱润滑油选型
  • 液压系统油品粘度确定
  • 设备维护换油参考
  • 高温/重载工况油品升级
