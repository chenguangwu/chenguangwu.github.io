📐 计算公式
轴强度 σ = M/W

按第四强度理论计算实心圆轴的应力与安全系数

💡 第四强度理论：σe=√(σ²+3τ²)。抗弯截面系数 W=πd³/32，抗扭截面系数 Wp=πd³/16。安全系数 n=σs/σe。

安全系数评定标准

  • n ≥ 1.5：安全（静强度足够）
  • 1.2 ≤ n < 1.5：基本安全（一般用途）
  • 1.0 ≤ n < 1.2：临界（需进一步校核疲劳）
  • n < 1.0：不安全（需增大轴径或换材料）
