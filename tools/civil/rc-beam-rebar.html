📐 计算公式
单筋矩形梁正截面：h₀ = h − a_s（mm，弯矩 M ×10⁶ 化 N·mm、α₁=1.0）；α_s = M ÷ (α₁·f_c·b·h₀²)；ξ = 1 − √(1−2α_s)；受拉钢筋面积 A_s = ξ·α₁·f_c·b·h₀ ÷ f_y（mm²）；配筋率 ρ = A_s ÷ (b·h₀) × 100（%）。校验：M、b、h₀、f_c、f_y 须 >0，否则报「请输入有效的截面与内力参数」。判据：α_s > ξ_b(1−0.5ξ_b) 判超限（ξ_b = 0.8/[1+f_y/(2×10⁵×0.0033)]，GB 50010-2010 式 6.2.7/6.2.10；HRB400 时约 0.384），报「需增大截面或改为双筋截面」。正常使用极限状态裂缝宽度（GB 50010-2010 式 7.1.2）：σ_s = M_k ÷ (0.87·h₀·A_s)；ψ = 1.1 − 0.65·f_tk ÷ (ρ_te·σ_s)（夹取 0.2 ≤ ψ ≤ 1.0）；ρ_te = A_s ÷ A_te（矩形受弯 A_te=0.5·b·h，ρ_te<0.01 时取 0.01）；d_eq = Σ(n_i·d_i²) ÷ Σ(n_i·ν_i·d_i)（带肋 ν=1.0、光面 ν=0.7）；w_max = α_cr·ψ·σ_s/E_s·(1.9c + 0.08·d_eq/ρ_te)，受弯 α_cr=1.9、E_s=2×10⁵ MPa；对照 GB 50010-2010 表 3.3.1 三级裂缝 0.3mm（二级 0.2mm、一级 0.1mm/预应力）判满足与否。开裂判定：先按 7.1.1 算 M_cr = f_tk·W_0（W_0 = b·h²/6，未计塑性影响系数 γ，偏安全），M_k ≤ M_cr 时构件未开裂，ψ 不适用、w_max = 0；M_k > M_cr 才按式 7.1.2 计算。

按单筋矩形截面受弯构件，由弯矩设计值计算所需受拉钢筋面积。

📌 计算说明
  • α_s = M / (α₁·f_c·b·h₀²)，h₀ = h − a_s
  • ξ = 1 − √(1 − 2α_s)，单筋适筋上限 α_s,max = ξ_b(1−0.5ξ_b)，HRB400 时 ξ_b=0.518、α_s,max≈0.384（GB 50010-2010 式 6.2.7）
  • A_s = ξ·α₁·f_c·b·h₀ / f_y
  • c 为保护层厚度（钢筋外边缘至混凝土表面），a_s 为受拉钢筋合力点至受拉边缘距离，两者是不同量；h₀ = h − a_s，不能用 c 直接代替 a_s（单排 a_s 常取 35~40mm、双排 60~70mm）
  • 裂缝宽度：先按 M_cr = f_tk·W_0（W_0 = b·h²/6，GB 50010-2010 7.1.1）判 M_k ≤ M_cr，未开裂时 ψ 不适用、w_max = 0；开裂后 σ_s = M_k/(0.87·h₀·A_s)，ψ 夹取 0.2~1.0，ρ_te = A_s/(0.5·b·h) 且不小于 0.01，w_max 对照三级裂缝 0.3mm（GB 50010-2010 式 7.1.2、表 3.3.1）

💡 常见使用场景

  • 矩形梁正截面受弯：已知弯矩 M 求底筋 As，并校核 ξ≤ξb 防超筋脆性。
  • 双筋截面：ξ>ξb 时加受压钢筋，或加大截面/提高混凝土等级。
  • 裂缝宽度：按 GB 50010-2010 式 7.1.2 由 M_k、A_s、f_tk、d_eq、c 算 w_max，对照表 3.3.1 三级 0.3mm；计算前先按 7.1.1 的 M_cr = f_tk·W_0 判是否开裂，M_k ≤ M_cr 时 ψ 不适用、w_max 记 0。c（保护层厚度）与 a_s（合力点距离）是两个不同量，不可混用。

❓ 常见问题（FAQ）

ξ>ξb 怎么办？
属超筋，破坏呈脆性不安全；应加大截面、提高混凝土等级或改双筋（加受压筋）受压区高度，不能只加底筋。
最小配筋率为什么有？
防止少筋梁一裂即断（脆性），ρ≥ρmin（约 0.2%）；配筋率过低按素混凝土梁设计反而更经济。
强度够了还验算什么？
使用阶段裂缝宽度与挠度，过大会影响耐久与观感；大跨梁挠度常控制配筋而非强度。
c 和 a_s 是一回事吗？
不是。c 是保护层厚度（钢筋外边缘至混凝土表面），a_s 是受拉钢筋合力点至受拉边缘的距离；h₀=h-a_s，若把 c 当 a_s 会高估 h₀、低估配筋。单排梁 a_s 常取 35~40mm，双排 60~70mm。
