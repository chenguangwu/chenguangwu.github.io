📐 计算公式
简支梁均布荷载：最大弯矩 M = qL² ÷ 8（kN·m）、最大剪力 V = qL ÷ 2（kN）、跨中挠度 δ = 5qL⁴ ÷ 384EI（弹性；q 先由 kN/m 化 N/m，E 按 GPa×1e9 化 Pa；I 由 b×h 自动取 I = bh³ ÷ 12，cm⁴ 经 ×1e−8 化 m⁴，结果 ×1000 折 mm）；截面模量 W = bh² ÷ 6（mm³），弯曲应力 σ = M×1e6 ÷ W（MPa，M 由 kN·m 化 N·mm）。校验：L、E、b、h 须 >0 且 q ≥0，否则提示「请输入有效的梁参数」。说明：I 只读，与应力所用同一截面，避免两套截面口径矛盾。荷载组合：q_k 为标准组合均布荷载（标准值），q_q 为准永久组合均布荷载（准永久值，不是荷载分项系数后的设计值）；M_k = q_k·L² ÷ 8、M_q = q_q·L² ÷ 8。正常使用极限状态（GB 50010-2010 3.4.3 / 7.2.1 / 7.2.2 / 7.2.3）：钢筋混凝土受弯构件的最大挠度按准永久组合计算并考虑长期作用，σ_s、ψ、B_s 同按准永久组合（7.1.1-3 / 7.1.4 / 7.2.3）。h₀ = h − a_s（a_s 为受拉钢筋合力点至受拉边缘距离，不是保护层 c）；ρ = A_s ÷ (b·h₀)、ρ_te = A_s ÷ (0.5·b·h)（<0.01 取 0.01）、α_E = E_s ÷ E_c（E_s=2×10⁵MPa）；σ_s = M_q ÷ (0.87·h₀·A_s)；ψ = 1.1 − 0.65·f_tk ÷ (ρ_te·σ_s)（夹取 0.2~1.0）；B_s = E_s·A_s·h₀² ÷ [1.15ψ + 0.2 + 6α_Eρ ÷ (1+3.5γ_f')]；准永久组合的长期刚度 B = B_s ÷ θ（式 7.2.2-2，θ 按 7.2.5-1 取用）；δ_lt = 5·M_q·L² ÷ (48·B)（7.2.1 结构力学方法）；限值按计算跨度 l₀ 分档（l₀<7m 取 l₀/200、7m≤l₀≤9m 取 l₀/250、l₀>9m 取 l₀/300，表 3.4.3），δ_lt ≤ 限值判满足（等号算满足）。标准组合的长期刚度 B = M_k ÷ [M_q(θ−1)+M_k]·B_s（式 7.2.2-1）仅适用于预应力混凝土构件（3.4.3 规定其挠度按标准组合）；本页为钢筋混凝土，不采用该路径，M_k 仅作参考显示。

计算受均布荷载简支梁的最大弯矩、剪力、跨中挠度与跨中弯曲应力。

📌 计算说明
  • 最大弯矩 Mmax = qL²/8（跨中）
  • 最大剪力 Vmax = qL/2（支座处）
  • 跨中挠度 δ = 5qL⁴/(384EI)（单位统一为 N、m）
  • 弯曲应力 σ = M/W，W = bh²/6 为截面模量
  • h₀ = h − a_s；a_s 为受拉钢筋合力点至受拉边缘距离（单排常取 35、双排 60），不是保护层厚度 c
  • 强度等级 C25–C40 联动 f_tk 与 E_c，可手动覆盖；手动值与等级不匹配时页面给出提示，避免「C25 强度、C40 刚度」混配
  • q_k 为标准组合均布荷载（标准值），q_q 为准永久组合均布荷载（可变荷载准永久值系数 ψ_q 与标准值组合后再计入永久荷载标准值）；q_q 不是荷载分项系数后的设计值，也不是标准值简单打折；页内 M_k = q_kL²/8、M_q = q_qL²/8
  • 挠度按准永久组合：GB 50010-2010 3.4.3 规定钢筋混凝土受弯构件的最大挠度按荷载准永久组合并考虑长期作用，故 σ_s、ψ、B_s 均用 M_q（7.1.1-3 / 7.1.4 / 7.2.3），长期刚度 B = B_s/θ（7.2.2-2），δ_lt = 5M_qL²/(48B)；标准组合的 B 公式（7.2.2-1）仅用于预应力构件，本页不采用
  • θ 按 7.2.5-1 取用：ρ' = 0 取 2.0、ρ' = ρ 取 1.6、中间线性内插；翼缘位于受拉区的倒 T 形截面 θ 应增加 20%；本页按输入值计算，不是恒等常数，非常规情况须按实际配筋调整
  • 挠度限值按计算跨度 l₀ 分档（表 3.4.3）：l₀<7m → l₀/200、7m≤l₀≤9m → l₀/250、l₀>9m → l₀/300；δ_lt ≤ 限值判满足，等号算满足

💡 常见使用场景

  • 楼板、次梁按简支估算跨中弯矩 Mmax=wL²/8 与剪力 Vmax=wL/2，作为配筋与连接设计的控制内力。
  • 校核变形：跨中挠度 f=5wL⁴/(384EI)，用于楼盖舒适度与净高控制。
  • 对比不同跨度 L、线荷载 w 对弯矩的敏感度，优化梁高与材料用量。
4m 简支次梁均布荷载
跨度 L=4m、线荷载 w=10kN/m：Mmax=wL²/8=10×16/8=20kN·m；Vmax=wL/2=20kN；若 EI=2.4×10¹¹N·mm²，则跨中挠度 f≈5wL⁴/(384EI)（按单位换算后评估）。

❓ 常见问题（FAQ）

均布荷载与点荷载结果差多少？
同总荷载下，跨中弯矩点荷（PL/4）约为均布（wL²/8=PL/8）的 2 倍，故荷载形式直接影响配筋，不可混用。
挠度超限怎么调？
增大截面高度 h（挠度∝1/h³ 量级）、提高刚度 EI 或减小跨度；也可加反拱或改用连续梁降低跨中弯矩。
连续梁能按简支估算吗？
不能。连续梁支座负弯矩显著大于简支跨中弯矩，简支结果会低估支座区配筋，需按连续梁系数或有限元复核。
