📐 计算公式
物业绩效考核：综合得分 = Σ(六维得分 × 归一化权重)，归一化权重 = 该维权重 ÷ 非零权重合计。得分必须在 0–100、权重必须在 0–100 且不得为负；超范围/空值直接点名报错，不做静默截断。权重为 0 的维度不参与综合得分、等级与改进排序。评级阈值可配置（默认 A≥90、B≥80、C≥70、D≥60、E<60），并须严格递减。改进优先级按「(100−得分)×归一化权重」排序，同时体现分差与权重。

六大维度加权评分（客户满意度20%+设施维护20%+响应时效15%+收费率15%+安全合规15%+环境品质15%），自动生成考核等级

阈值须严格递减（A > B > C > D ≥ 0），低于 D 级下限为 E 级；可按公司制度调整，评级与合同复核建议仅供参考。

💡 加权得分 = Σ(各维度得分 × 归一化权重)，归一化权重 = 该维权重 ÷ 非零权重合计。等级阈值可在上方配置（默认 A≥90 / B≥80 / C≥70 / D≥60 / E<60）；权重为 0 的维度不参与评分与优先改进。评级、改进建议与合同复核提示仅供管理参考，不替代合同条款和公司考核制度。

⚠️ 使用说明与注意事项
  • 各维度得分0-100分，参考实际考核数据填入
  • 权重可自定义调整，默认按行业经验分配，总权重建议100%
  • 客户满意度建议采用季度调查均值（样本量≥30%）
  • 响应时效：15分钟内响应为100分，每超10分钟扣5分
  • 安全合规含消防/电梯/配电/燃气等特种设备检查通过率
  • 结果仅供参考，实际考核应结合合同约定和当地物业管理办法

📚 深度解析：物业绩效考核评分体系

💡 常见使用场景

  • 物业项目经理按月对各岗位评分，各维度权重按岗位职责差异化配置
  • 公司自定义 A/B/C/D 等级阈值，按合同或制度复核绩效等级
  • 设置零权重维度以保留观察数据，但不让其影响综合得分与优先改进排序
加权评分与归一化
客户满意度 90（权重20）、设施维护 85（20）、响应时效 90（15）、收费率 88（15）、安全合规 92（15）、环境品质 85（15）→ 权重合计 100，归一化后分别为 20%/20%/15%/15%/15%/15%；综合 = 0.20×90 + 0.20×85 + 0.15×90 + 0.15×88 + 0.15×92 + 0.15×85 = 88.25 分。
零权重维度
环境品质得分 10、权重改为 0，其余权重合计 85。该维度不参与得分与优先排序，归一化权重变为 23.5%/23.5%/17.6%/17.6%/17.6%；综合 = (85×20 + 80×20 + 90×15 + 88×15 + 92×15) ÷ 85 = 86.5 分。低分不会再被误列为优先改进。
可配置评级阈值
默认 A≥90、B≥80、C≥70、D≥60、E<60；若公司改为 A≥85、B≥75、C≥65、D≥55，则 86.3 分由 B 变为 A。阈值须严格递减；合同复核提示随当前等级给出，是否复核仍以合同条款为准。

❓ 常见问题（FAQ）

超出 0–100 的分数会被截断吗？
不会。得分超过 100、低于 0、为空或非数字，以及权重为负或超过 100，都会点名报错并停止计算，输入框保留原值，便于核对后改正。
权重为 0 的维度参与考核吗？
不参与。权重为 0 的维度不进入综合得分、等级判断和优先改进排序，页面会单独标注「不计入」，并展示其余维度的实际归一化权重。
改进优先级为什么不是直接看最低分？
低分但权重很小的维度，即使拉满对总分影响也有限。工具按「(100−得分)×归一化权重」计算加权提升空间，同时体现分差和权重，取前 3 项列为优先改进。
评级阈值可以按公司制度调整吗？
可以。A/B/C/D 四个下限均可配置，要求严格递减；低于 D 下限为 E 级。评级和合同复核提示仅供参考，不替代合同条款和公司考核制度。

📝工具简介

物业绩效考核评分体系，支持客户满意度、设施维护质量、响应时效、收费率、安全合规、环境品质六大维度的加权评分。可自定义各维度权重并展示实际归一化权重，评级阈值可按公司制度配置；权重为 0 的维度不参与得分与排序，改进优先级按分差×归一化权重列出。

✨功能特点

  • 六大考核维度全面覆盖物业服务品质
  • 自定义权重并展示归一化权重
  • 可视化条形图直观展示各维度得分
  • 评级阈值可配置，零权重维度不计入
  • 按分差×权重列出优先改进

🎯使用场景

  • 物业公司季度/年度绩效考核
  • 业委会对物业公司服务品质评估
  • 多项目横向对比评比
  • 物业服务合同履约评价
