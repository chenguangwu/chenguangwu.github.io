📖 Benchmarking (Compare / Learn / Surpass) Analysis

Compare property and operations metrics against a benchmark, quantify gaps and output improvement priorities.

📐 工作原理与说明
相对差距 rel = (标杆值 − 自身值) ÷ 标杆值（方向 low 时取反）；rel > 0 为落后、rel < 0 为领先；改进空间评分 = 落后项的加权平均 rel × 100%，领先项不计入；优先改进按 rel × 权重降序取 Top3

标杆分析用于量化自身与行业/内部标杆的差距，明确改进优先级：

方向 high 表示越高越好（如毛利率、满意度）；low 表示越低越好（如费用率、空置率），计算时取反。只有 rel > 0 的落后项进入改进空间评分与 Top3；rel < 0 的领先项单独列示，不推高改进空间。

标杆值为 0 时相对差距无意义，页面改为显示绝对差并标注“相对差距不适用”，该行不参与加权评分。每行可选填权重（默认 1）与口径说明；方向、数值、权重不合法会逐行列出跳过原因。

💡 常见使用场景

  • 物业公司将本小区关键指标（报修响应、绿化达标率）与同级别标杆项目对比
  • 月度经营会用工单量与满意度数据找差距
  • 制定赶超计划，把标杆值设为下季度目标
报修响应对比
本小区平均响应 4.2 小时、标杆 2.0 小时，方向 low（越低越好）：相对差距 (2.0−4.2)/2.0 = −1.10，取反后 +110%，属于落后项，列为一号改进项并设下季度目标 3.0 小时。
满意度领先
本小区满意度 95 分、标杆 90 分，方向 high：相对差距 (90−95)/90 = −5.6%，属于领先项；只计入“领先项”展示，不进入改进空间评分和 Top3。
零基准与权重
投诉率 5、标杆 0，方向 low：相对差距无意义，页面显示绝对差 5、标注“相对差距不适用”，不参与评分；另一项人效 60 对 80、权重 2，落后 25%，加权后改进空间评分仍为 25%。

❓ 常见问题（FAQ）

标杆项目怎么选？
选同城市、同档次、规模相近且公开数据可信的项目，避免跨类型硬比导致结论失真。
对标后只抄指标行吗？
不行，要分析标杆背后的流程（排班、培训、回访），把做法本地化，而非只追数字。
自身已经优于标杆会怎样？
按方向判断为领先项，单独列出并计算平均优势，不再进入改进空间评分和优先改进 Top3；优势越大不会被误判为越需改进。
标杆值为 0 怎么算？
相对差距分母为 0，页面改为显示绝对差并标注“相对差距不适用”，该行不参与评分和 Top3。
