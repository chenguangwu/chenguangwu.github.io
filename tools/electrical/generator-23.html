📐 计算规则
解析布尔表达式并枚举全部 2ⁿ 种变量取值：变量 A–H，非 ! / ~，与 & / &&，或 | / ||，异或 ^，蕴含 ->，等价 <-> / ==，亦支持 AND / OR / NOT / XOR 关键字；逐行输出各变量值与表达式结果，并统计真值行数、判定重言式/矛盾式/可满足式。

💡 常见使用场景

  • 数字逻辑教学：输入布尔表达式，自动生成真值表
  • 电路验证：核对组合逻辑输出与预期

方法
用法：输入布尔表达式（变量 A–H，支持 ! / & / | / ^ / -> / <-> 与 AND/OR/NOT/XOR 关键字及括号），工具按优先级解析后枚举全部 2ⁿ 种取值，逐行求值并统计真值行数。n 个变量固定 2ⁿ 行。
算例
例：A && (B || !C)，变量 A/B/C 共 8 行，结果为真的仅 3 行（A=1 且 B=1，或 A=1 且 C=0），判定为可满足式。 再例：A || !A → 2 行均为 1，判定重言式；A && !A → 2 行均为 0，判定矛盾式。

❓ 常见问题（FAQ）

支持哪些运算符？
非(! / ~)、与(& / && / AND)、或(| / || / OR)、异或(^ / XOR)、蕴含(->)、等价(<-> / ==) 与括号，优先级由高到低：! → & → ^ → | → -> → <->。
变量数上限？
最多 8 个变量（2⁸ = 256 行）；超出会提示，避免页面过长。
