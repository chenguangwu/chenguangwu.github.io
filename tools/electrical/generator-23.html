✨ Logic Truth Table Generator

Logic truth-table generator: builds the complete truth table for a Boolean expression and outputs the requested number of rows.

📐 工作原理与说明
生成规则：从真值表模板池按 ⌊random × 池长度⌋ 取 n 条（n 上限 50），每条渲染变量列 + 表达式列 + 全部取值组合行
本工具用于逻辑真值表生成器（表达式输入）的实时计算，依据对应公式与标准运算规则处理，结果按精度实时输出；纯前端运行，数据不上传。

📚 深度解析：逻辑真值表生成（表达式输入）

💡 常见使用场景

  • 数字逻辑教学：输入布尔表达式，自动生成真值表
  • 电路验证：核对组合逻辑输出与预期
  • 化简辅助：从真值表观察冗余项
方法
用法：输入变量（A/B/C…）与表达式（支持 AND/OR/NOT/XOR、括号），工具枚举所有变量组合并求每行列值。n 个变量生成 2^n 行。
算例
例：表达式 (A AND B) → 2 变量共 4 行：00=0、01=0、10=0、11=1。表达式 (A OR B) AND C → 3 变量共 8 行，仅 A/B/C 全 1 时出 1，其余为 0。

❓ 常见问题（FAQ）

支持哪些运算符？
与(AND/&/∧)、或(OR/|/∨)、非(NOT/!/¬)、异或(XOR)及括号分组；具体以页面提示为准。
变量数上限？
随变量增多行数指数增长（2^n），过多变量页面过长；一般教学用 2~4 变量。
