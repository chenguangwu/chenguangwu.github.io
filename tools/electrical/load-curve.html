📋 负荷特性指标

负荷率 = 平均负荷 / 最大负荷，反映负荷平稳程度，越接近1越平稳。
峰谷差 = 最大负荷 − 最小负荷，反映负荷波动幅度。
峰谷差率 = 峰谷差 / 最大负荷，越大说明调峰需求越强。
需用系数 = 最大负荷 / 装机容量（需输入装机容量估算）。
用电量 = Σ(各时段负荷 × 1h)，单位 kWh。
