📋 常见介质折射率

斯涅尔定律：n₁·sinθ₁ = n₂·sinθ₂，故 θ₂ = arcsin(n₁·sinθ₁ / n₂)。
全反射：当 n₁ > n₂ 且入射角大于临界角 θc = arcsin(n₂/n₁) 时发生全反射，光线不进入 n₂。
色散：折射率随波长变化（如冕牌玻璃 n 蓝光 > 红光），导致色散（阿贝数 Vd 衡量）。
视深：从空气看水中物体，视深 = 实深 × (n₂/n₁) = 实深 / 1.33，故水中物体看起来更浅。
