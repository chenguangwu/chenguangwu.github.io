🔗 URL Extractor

📐 工作原理与说明
URL 正则为 (https?://|ftp://|file://)? 开头可选协议，接 [a-zA-Z0-9][-a-zA-Z0-9]* 再加一个或多个「.域名段」，后接可选的路径（不含空白与 < > " ' ( ) [ ] { }）。缺协议时自动补 http://；只要 HTTP/HTTPS 时丢弃 ftp/file 开头的项；去参数时先按 ? 截断再按 # 截断。之后按选项去重（保留首次出现）、字典序排序，输出条数即结果条数，用所选分隔符连接（分隔符为 \n 时按换行连）

Extract every URL from long text or page source and deduplicate the list, handy for batch reference collection, backlink audits and link validation.

❓ 常见问题（FAQ）

带参数的长链接完整吗？
完整保留 query（?id=1&t=2）；但末尾标点若紧贴会被误含，建议抽取后 trim 或启用「止于标点」模式。
相对路径能抽吗？
相对路径（/doc/a）不以 http 开头，默认不抽；需结合基址拼接时才算完整 URL。
