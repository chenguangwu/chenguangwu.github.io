🎉 Text to Banner

📐 工作原理与说明
文本列宽 = Σ（半角字符 1 列 / 中文、全角标点、emoji 2 列）；内容宽 = 文本列宽 + 左右填充 × 2；边框行 = 左上角字符 + 横线条重复内容宽次 + 右上角字符；上下各插 纵向填充 行（竖线 + 填充符 × 内容宽 + 竖线）；文本行 = 竖线 + 填充符 × 左填充 + 文本 + 填充符 × 右填充 + 竖线；底边同顶边，用左下 / 右下角字符

Wrap text in a configurable ASCII/Unicode character frame, preview the column-aligned banner, then copy it or download it as a .txt file (no image or colour output).

生成「HI」横幅
输入「HI」、井号填充、左右内边距 2 → 文本列宽 2、内容宽 6，输出「╔════════╗ / ║##HI##║ / ╚════════╝」（实际为 3 行，上下填充为 0）；复制或下载后可直接粘进终端与 README。

❓ 常见问题（FAQ）

中文会错位吗？
不会。工具按显示列宽计算：中文、全角标点与 emoji 各计 2 列，半角字符计 1 列，因此中英混排的边框能对齐；但终端字体若非等宽，实际显示仍可能轻微偏移。
有哪些样式？
8 种字符边框：井号填充、星号包围、等号横线、虚线框、双线框、圆角框、爱心边框、菱形边框；再配合左右与上下内边距控制留白。
能导出图片吗？
不能。本工具只产出纯文本字符横幅，可复制或下载 .txt；需要图片请用截图或专门的图片横幅工具，页面不再宣称图片导出。
