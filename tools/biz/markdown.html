❓ 常见问题（FAQ）

和标准 Markdown 有差异吗？
本工具按 GitHub 风格 GFM 解析（支持表格、删除线、任务列表）；若你用严格 CommonMark，部分扩展语法（如表格）在标准里不定义，迁移时注意。
HTML 混写安全吗？
Markdown 允许内联 HTML，但发布到公网前需确认不过滤危险标签；本工具仅本地渲染，不上传内容。
