🛰️ NDVI Vegetation Analyzer

NDVI = (NIR − RED) / (NIR + RED). Enter band reflectances to estimate vegetation cover.

📐 工作原理与公式
NDVI（归一化植被指数）利用绿色植被在近红外波段强反射、红光波段强吸收的光谱特性来量化植被覆盖：NDVI =（NIR − RED）/（NIR + RED）。取值范围 −1 ～ 1：水体、云、雪为负值，裸土与岩石接近 0，植被越茂密越接近 1。输入可为反射率（0–1）或原始 DN 值，只要两波段量纲一致，相除后量纲约去，结果相同。纯前端本地计算，数据不上传。
NDVI 区间覆盖类型
< 0水体 / 云 / 雪
0 ～ 0.1裸土 / 岩石 / 建筑
0.1 ～ 0.2稀疏植被 / 荒地
0.2 ～ 0.4中等植被 / 灌木草地
0.4 ～ 0.6较茂密植被 / 农作物
> 0.6茂密植被 / 森林

💡 常见使用场景

  • 遥感影像的植被覆盖度快速评估
  • 农田作物长势监测与地块间差异对比
  • 生态修复工程的前后期覆盖变化分析
单点算例
NIR=0.35、RED=0.10：NDVI=(0.35−0.10)/(0.35+0.10)=0.25/0.45≈0.5556，落在 0.4–0.6 区间，属“较茂密植被 / 农作物”。
多期对比
同一地块三期 NDVI 为 0.20 → 0.35 → 0.55，可直观看出植被由稀疏恢复到较茂密。

❓ 常见问题（FAQ）

NDVI 的取值范围和含义？
范围 −1 ～ 1。负值多为水体、云、雪；裸土与建筑接近 0；值越大表示绿色植被越茂密。
输入反射率还是 DN 值？
两者皆可，只要近红外与红光量纲一致，相除后量纲约去，结果相同。反射率通常取 0–1。
为什么两波段之和不能为 0？
分母为 0 时 NDVI 无定义；当 NIR+RED=0（如全黑像元）时应剔除该像元或改用其他植被指数。
