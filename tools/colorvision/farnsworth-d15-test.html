🎨 Farnsworth D-15 Color Arrangement Test - ToolBox

A browser implementation of the classic Farnsworth Panel D-15: arrange 15 equal-lightness caps into a smooth hue sequence, then get a CIE u′v′ polar hue-trace plot, Total Error Score, confusion index and protan/deutan/tritan classification. Runs entirely locally.

📐 判定原理

① 色帽生成：取 D-15 的 15 个色度点 (x, y)，在固定亮度 Y 下换算 XYZ = (Y/y·x, Y, Y/y·(1−x−y))，再经 sRGB 逆矩阵得线性 RGB；越界的点沿「向同亮度中性灰收敛」的方向做二分法压缩到色域内，因此 15 个色帽明度一致、只有色相与饱和度差异——这正是排列测试能屏蔽明暗线索的关键（可勾选「灰度预览」自行验证）。
② 色差度量：把每个色帽转到 CIE 1976 u′v′ 均匀色度图，u′ = 4x/(−2x+12y+3)、v′ = 9y/(−2x+12y+3)。相邻两帽的色度距离 √(Δu′²+Δv′²)×100 即一步色差；把 14 步累加得总误差分 TES。理想顺序的 TES 记为基准，混淆指数 C = TES(你的排列) / TES(理想排列)，完美排列 C = 1.00。
③ 轴向分析：只取「相邻两帽编号不连续」的错位跳跃作为误差向量，计算二阶矩 Sxx、Syy、Sxy，主轴方向 θ = ½·arctan2(2Sxy, Sxx−Syy)，主/次特征值之比开方得选择性指数 S。S 越大说明错误越集中在一条直线上（二色视特征），S≈1 说明错误是随机的。
④ 分型：三条混淆线由二色视共轭点（copunctal point）确定——红色盲 (0.747, 0.253)、绿色盲 (1.400, −0.400)、蓝色盲 (0.171, 0.000)。把它们和 D65 白点连线投到 u′v′ 得到三个参考轴向角，θ 与哪一条最接近就归为哪一型，严重度由 C 的大小分级。

把中间 13 个色帽按颜色渐变最平滑的顺序排列：让每一个色帽都和左右邻居颜色最接近。两端带紫色圈的是固定基准帽，不能移动。桌面端可直接拖拽色帽；移动端点一下选中、再点另一个即可换位，也可以用色帽下方的 ◀ ▶ 按钮微调，键盘用户可用 Tab 聚焦后按 ← → 移动。

⚠️ 使用边界与已知局限
  • 本页不是医学检查，结论不能作为诊断依据。真正的 D-15 是实体色帽在标准 C 光源／D65 照明箱下进行的，屏幕测试无法复现。
  • 显示结果受显示器色域、亮度、色温、环境光、系统色彩管理与夜览／护眼模式影响极大；测试前请关闭夜览/色温调节，把亮度调到舒适的中高档，并在不反光的环境下进行。
  • 色度坐标为公开文献中的近似值，且经过 sRGB 色域压缩，饱和度低于实物色帽，因此对轻度色弱的检出灵敏度不如实体测试。
  • 矩量轴向分析在错位数很少（1～2 处）时统计意义弱，容易被一次手滑放大成「有轴向」；此时请重测几轮看结论是否稳定。
  • D-15 属于筛查型测试，只对中重度色觉异常较敏感；正常结果不代表色觉完全无异常。若结果异常或日常已有红绿混淆困扰，请到医疗机构做专业色觉检查。

💡 常见使用场景

  • 色觉筛查：将 15 色帽按色相环排列，记录跨轴错误（红绿轴、蓝黄轴）判型。
  • 培训/科普：演示正常色觉与各类缺陷者在排列路径上的典型错误模式。
  • 辅助评估：作为详细检测前的快速分类，指向需进一步正式测试的方向。
错误模式判型
正常排列呈连续色相环；若出现沿红-绿轴的跨位连线（如把红与绿相邻误排），提示红绿（protan/deutan）缺陷；沿蓝-黄轴跨位提示蓝黄（tritan）缺陷；错误数越多严重度越高。

❓ 常见问题（FAQ）

D-15 能确诊色盲吗？
不能。它是快速筛查与分型工具，正式诊断需结合更全的色觉检测由专业机构作出。
蓝黄轴错误少见吗？
tritan（蓝黄）类型本身较少见，若出现蓝黄轴跨位连线应特别注意，必要时进一步评估。
排列受照明影响吗？
会。应在标准光源或自然日光下、避免偏色屏幕与环境光干扰，否则错误可能由照明而非色觉引起。
