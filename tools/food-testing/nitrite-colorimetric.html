Nitrite Colorimetric

📐 工作原理与说明
亚硝酸盐比色法测定（盐酸萘乙二胺法）
曲线浓度 C(μg/mL) = (吸光度A − 截距) ÷ 斜率
含量(mg/kg) = C × 定容体积(mL) × 样品处理液总体积(mL) ÷ (测定液体积(mL) × 样品质量(g))
浓度 C < 0 记为未检出（吸光度低于截距）
判定：含量 > 限量 → 超标；≤ 限量 → 合格

Key formulas: Math.round(content×1000)÷1000

标准曲线参数

标准曲线方程：A = k·C + b（C为亚硝酸钠浓度 μg/mL，A为吸光度）

样品参数

📋 计算公式

曲线浓度 C = (A - b) / k （μg/mL）

亚硝酸盐含量 = (C × 显色体积 × 定容体积) / (取样体积 × 样品质量) （mg/kg）

结果以亚硝酸钠（NaNO₂）计。

💡 常见使用场景

  • 肉制品亚硝酸盐检测

  • 限量合规判定
公式
按 GB 5009.33，标准曲线 c=(A−截距)/斜率（A 为吸光度）；结合取样/测试体积换算样品中亚硝酸盐含量。
算例
样品吸光度 0.210、曲线斜率 0.0185、截距 0.002：c=(0.210−0.002)/0.0185≈11.24 mg/L；按取样体积换算样品中亚硝酸盐约 11.2 mg/kg（< 限量 30 → 合格）。

❓ 常见问题（FAQ）

为什么测亚硝酸盐？
肉制品护色抑菌，但过量生成亚硝胺致癌，须严控并标加入量。
限量多少？
熟肉制品亚硝酸盐残留≤30 mg/kg（以 NaNO₂计），西式火腿等更严，按 GB 2760。

Quantification method A standard curve is built from a nitrite series and the sample absorbance is used to obtain the content. GB 5009.33-2016, spectrophotometric method
Contaminant limit Nitrite must comply with the limits set in the national contaminant standard for foods. GB 2762-2022, limits of contaminants in foods
