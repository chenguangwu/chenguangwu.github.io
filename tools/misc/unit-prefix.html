📏 单位前缀换算

在 SI 单位前缀（nano / micro / milli / kilo / Mega / Giga / Tera 等）之间换算数值。

全部前缀对照

📐 换算原理

方法：先将源前缀数值换算为基本单位（乘以 10^源指数），再除以 10^目标指数得到目标前缀值。
示例：5 km → m = 5 × 10³ = 5000 m；3 MHz → kHz = 3 × 10⁶ / 10³ = 3000 kHz。
