📐 计算公式
Ra = up·Σ(qsi·li) + qp·Ap

单桩竖向承载力特征值 Ra = 桩周总侧阻 + 桩端阻力
up = π·d（桩周长），Ap = π·d²/4（桩端面积）
需要桩数 n = N / Ra（取整，并适当富余）

💡 本公式适用于摩擦桩及端承摩擦桩；端承桩以桩端阻力为主。承载力特征值已含安全系数，实际设计须按《建筑桩基技术规范》JGJ 94 验算。
