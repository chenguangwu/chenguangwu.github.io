属性抽样公式（泊松分布法）
n = R / (TM - EP)
R：可信赖程度对应的可靠性因子
TM：可容忍误差率，EP：预期误差率
可靠性因子表：90%→2.31，95%→3.0，99%→4.61
变量抽样公式（均值估计法）
n = (Z × σ × N / TM)² （放回抽样）
n = n₀ / (1 + n₀/N) （不放回抽样，有限总体修正）
Z：可靠性系数（95%→1.96，90%→1.645，99%→2.576）
