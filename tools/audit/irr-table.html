📋 NPV 扫描表

折现率NPV 净现值状态
原理：IRR 是使 NPV = 0 的折现率。扫描表中 NPV 由正变负（或由负变正）的相邻两行之间即为 IRR 所在区间，工具已用线性插值法精确计算。
