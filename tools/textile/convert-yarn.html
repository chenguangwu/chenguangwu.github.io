💡 常见使用场景

  • 按 tex 与长度互算纱线重量，核算单件用纱量
  • 不同回潮率下把净重折算为公定重量，公平结算
  • tex 与旦尼尔互转（denier = tex × 9）
tex 转旦尼尔
20 tex → denier = 20 × 9 = 180 D；即 20tex 合 180 旦，常用于长丝标注。
公定重量折算
净重 1000 g、实际回潮率 6%、棉公定回潮率 8.5% → 公定重量 = 1000 × (1 + 8.5%) / (1 + 6%) ≈ 1023.6 g。

❓ 常见问题（FAQ）

为什么要用公定重量？
纱线含水率随环境变化，公定重量按标准回潮率折算，买卖计量才公平可比。
tex 和旦尼尔差在哪？
tex = g/km，denier = g/9km，旦尼尔多用于长丝、tex 多用于短纤与通用。
