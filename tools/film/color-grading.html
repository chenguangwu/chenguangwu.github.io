Color Palette LUT Reference

Color Palette LUT Reference focuses on common LUT types, working color spaces, and grading parameters used in film post-production, with client-side filtering and search for fast decision support.

📐 工作原理与说明

本表汇总 1D/3D LUT 的典型分工：1D LUT 处理灰阶映射（如监视器校正、基础色彩变换），3D LUT 处理三维色彩映射（如 Log 转 Rec.709 或创意风格化）。通过筛选与搜索，可快速查找适配镜头来源与交付规格的参考项，辅助色彩决策。

LUT 说明：LUT（Look-Up Table）查找表用于色彩空间转换和创意调色。1D LUT 处理灰度曲线（1024级），3D LUT 处理色彩映射（33³或65³立方体）。技术LUT 用于色彩空间转换，创意LUT 用于风格调色。

先按类型下拉筛选（如"胶片模拟"），再在搜索框输入关键词（如"柯达""富士""青橙"）缩小范围，表格会列出 LUT 名称、适用色彩空间与典型调色参数（对比度、饱和度、色温偏移等）。例如 Log 素材通常要先套还原 LUT 回到 Rec.709，再叠加风格 LUT，顺序反了会出现色偏。

❓ 常见问题（FAQ）

表里的参数能直接照搬吗？
只能作为起点。不同摄影机的 Log 曲线、色温与曝光基准都不同，实际调色要以示波器与监看为准，把参数当作参考区间而非固定值。
为什么套完 LUT 画面发灰？
多半是把风格 LUT 直接套在了 Log 素材上。Log 素材需要先做色彩空间转换（还原 LUT 或 CST）回到显示空间，再叠加风格 LUT。
