PR = (Below + 0.5·Equal) / N × 100

Enter a data set and a target value to compute the percentile rank, i.e. the percentage of the data below that value, for score and ranking evaluation.

📐 计算公式
百分等级（本页代码口径）：PR=(小于目标值的个数+0.5×等于目标值的个数)÷N×100（%，N=数据总个数，数据按逗号分隔逐项 parseFloat）；联动量：无其它派生项。校验：数据逐项 parseFloat 后过滤非有限值（无法解析的项不计入 N）；目标值非数字按 0 兜底。判据：无固定分级，PR 表征目标值在样本中的相对位置，恰为 50 即样本中位水平。

某值低于总体中多少比例的数据。

📚 深度解析：百分等级

💡 常见使用场景

  • PR=(低于数+0.5×等于数)/N×100。
  • 某分数在群体中的相对位置。
  • 成绩、身高的"超过百分之多少"。
考试 80 分
30 人中 12 人低于 80、3 人等于 80：PR=(12+0.5×3)/30×100=(13.5)/30×100=45，即超过约 45% 的人（第 45 百分位）。
最高分
若无人高于：PR=(29+0.5×1)/30×100≈98.3。

❓ 常见问题（FAQ）

百分位 vs 百分等级？
百分位 P_k 是"第 k% 的人低于此值"的分数；百分等级是某分数对应的 k，互为反函数。
为什么要 +0.5？
把等于自身的半个人计入排名，避免把自身算作"低于"，是常用经验修正。
