🧮 Sample Size Estimate

Sample Size Estimate is available directly in your browser, with no data uploaded.

📐 计算公式与说明

n = (Z · σ / ME)²（均值）
n = Z² · p(1−p) / ME²（比例）

结果向上取整。

❓ 常见问题（FAQ）

样本量估算 结果可直接用于决策吗？
样本量估算 适合用于预估与复核，正式决策请结合完整数据口径说明（口径定义、时间区间、边界条件）。
结果偏离预期很大怎么办？
先核对输入单位与是否存在“% 与小数”混用，再确认分母与分子定义是否同口径，最后替换一组可复现实例复测。
