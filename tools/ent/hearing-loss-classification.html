Hearing Loss Classification

PTA气导(dB) = (500+1000+2000 Hz 气导阈值)/3；PTA骨导 = (500+1000+2000 Hz 骨导)/3；气骨导差 ABG = 气导 − 骨导；高频平均 HFA = (500+1000+2000+4000)/4。分级(按PTA气导)：≤25 正常、≤40 轻度、≤60 中度、≤80 重度、>80 极重度。分型(按ABG与骨导)：ABG≤10 且骨导>25→感音神经性聋；ABG>10 且骨导>25→混合性聋；ABG>10 且骨导正常→传导性聋。

中度感音神经性
四频平均听阈 55 dB HL，气骨导均升（差<10 dB），属中度感音神经性听力损失，建议助听器。

❓ 常见问题（FAQ）

为什么取这四个频率平均？
500–4000 Hz 覆盖言语主要频率，平均听阈最能反映言语理解能力，国际通用分级法。
传导性与感音神经性怎么分？
气导差、骨导正常为传导性（外中耳）；气骨导均差且差<10 dB 为感音神经性（内耳/蜗后）；差>10 dB 为混合性。
