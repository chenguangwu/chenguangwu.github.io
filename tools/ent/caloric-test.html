👂 前庭功能(冷热试验)半规管评估器

📐 计算公式
UW = [(RW + RC) - (LW + LC)] / (RW + RC + LW + LC) × 100%

根据双耳双温（44°C热刺激与30°C冷刺激）眼震慢相速度，计算单侧减弱(UW)与方向优势(DP)，评估外半规管功能

各条件眼震慢相速度 (°/s)

热刺激 → 向左眼震
热刺激 → 向右眼震
冷刺激 → 向右眼震
冷刺激 → 向左眼震

计算公式与判读标准

单侧减弱 (Unilateral Weakness, UW)

UW = [(RW + RC) - (LW + LC)] / (RW + RC + LW + LC) × 100%

UW > 20-25% 提示一侧半规管功能减弱（管麻痹），正值表示右侧减弱，负值表示左侧减弱

方向优势 (Directional Preponderance, DP)

DP = [(RW + LC) - (LW + RC)] / (RW + LC + LW + RC) × 100%

DP > 25-30% 提示优势偏向，正值表示向左优势，负值表示向右优势，常见于前庭中枢代偿不完全

临床要点：冷热试验主要评估外半规管及前庭上神经功能。UW异常提示周围性前庭病变（如梅尼埃病、前庭神经炎等）；DP异常多为前庭张力失衡的反映，可见于周围性或中枢性病变。检查前需确认无鼓膜穿孔。
