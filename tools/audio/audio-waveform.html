📝工具简介

音频波形显示工具基于 Web Audio API 的 AnalyserNode 实现，可对本地音频文件进行实时可视化分析。支持时域波形（示波器）、频域频谱（FFT 分析）和静态波形概览三种显示模式，并提供 FFT 大小、波形颜色、平滑度等参数调节。所有处理在浏览器本地完成，文件不上传，隐私安全有保障。

✨功能特点

  • 三种可视化模式自由切换
  • 实时时域波形示波器显示
  • 实时频域 FFT 频谱分析
  • 整段音频静态波形概览
  • FFT 大小可选（256~4096）
  • 自定义波形颜色与平滑度
  • 高 DPI 屏幕清晰渲染
  • 支持深色模式与响应式布局
  • 纯前端处理，文件不上传

🎯使用场景

💬常见问题

支持哪些音频格式？
支持浏览器可解码的格式，通常包括 MP3、WAV、OGG、FLAC、M4A 等。具体支持的格式取决于你所使用的浏览器，部分小众编码可能无法解析。
我的音频文件会被上传吗？
不会。所有音频解码、分析和可视化均在你的浏览器本地完成，文件不会发送到任何服务器。
时域波形和频域频谱有什么区别？
时域波形（示波器）显示音频信号随时间变化的振幅曲线；频域频谱（FFT）将信号分解为不同频率成分，显示各频率的能量分布。两者从不同角度呈现音频特征。
FFT 大小应该怎么选？
FFT 大小决定频率分辨率：值越大频率越精细但时间响应略慢。一般 2048 适合大多数场景，需要更细腻的频率分析可选 4096，需要更快响应可选 1024 或更小。
支持手机使用吗？
支持。页面已做响应式适配，手机和电脑均可正常使用。
