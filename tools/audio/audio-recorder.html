📝工具简介

在线录音工具基于 Web Audio API 与 MediaRecorder API 实现，可直接在浏览器中调用麦克风进行录音，无需安装任何插件或软件。录音过程中提供实时波形可视化与音量电平条，帮助直观掌握录音状态，并支持暂停、继续、停止等完整控制。

✨功能特点

  • 实时波形可视化（Canvas + AnalyserNode）
  • 实时音量电平条显示
  • 录音时长精确计时（分:秒.毫秒）
  • 开始 / 暂停 / 继续 / 停止 完整控制
  • 支持 WebM/Opus 与 WAV 两种格式
  • 录音列表可在线播放、下载、删除
  • 纯前端处理，录音不上传服务器
  • 支持深色模式与移动端响应式布局

🎯使用场景

  • 会议、课堂、访谈快速录音
  • 语音备忘与灵感记录
  • 配音、朗读练习与回放
  • 播客、自媒体音频素材采集
  • 语言学习跟读对比
  • 无需安装软件的临时录音需求

💬常见问题

录音时浏览器提示需要麦克风权限怎么办？
点击「允许」即可。若误点了拒绝，可点击浏览器地址栏左侧的锁形/调整图标，将麦克风权限改为允许后刷新页面重试。
WebM 和 WAV 该选哪个？
WebM/Opus 采用压缩编码，体积小、音质好，适合绝大多数日常场景；WAV 为无损 PCM 格式，音质最佳但文件较大，适合需要后期专业处理的场景。
录音会保存到服务器吗？
不会。所有录音都在浏览器本地完成，数据仅存在当前页面内存中，不会上传任何服务器。关闭页面后录音会清空，请及时下载。
为什么有些浏览器无法录音？
请确保使用支持 MediaRecorder API 的现代浏览器（Chrome、Edge、Firefox、Safari 较新版本），并确认设备已连接麦克风且未被其他程序占用。
