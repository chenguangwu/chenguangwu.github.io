📚 使用说明

📝工具简介

音频音量调节工具基于浏览器原生 Web Audio API 的 GainNode 节点，实时调节音频文件的音量增益，范围从 0%（静音）到 200%（放大两倍）。支持播放控制、进度拖动、渐入渐出、VU 音量表可视化，并可将调整后的音频导出为标准 WAV 文件。所有处理均在浏览器本地完成，音频文件不会上传到任何服务器。

✨功能特点

  • Web Audio API GainNode 实时增益
  • 音量范围 0% ~ 200%
  • 静音/50%/100%/150%/200% 快捷预设
  • 播放/暂停与进度条拖动
  • 渐入渐出效果（0-10 秒）
  • VU 表实时电平可视化
  • OfflineAudioContext 导出 WAV
  • 纯前端处理，文件不上传
  • 支持深色模式与响应式布局

🎯使用场景

  • 音频音量过小需要放大
  • 录音文件音量过大需要降低
  • 制作带淡入淡出效果的音频
  • 统一多个音频文件的响度
  • 音频后期处理与剪辑
  • 播客/视频配音音量调整

💬常见问题

音量调到 200% 会有杂音怎么办？
增益超过 100% 时可能出现削波失真（clipping）。建议适度提升，若原始音频电平已接近满幅，放大后会产生爆音，可配合淡入淡出或适当降低增益。
为什么导出的是 WAV 而不是 MP3？
WAV 是无压缩格式，可通过 Web Audio API 的 OfflineAudioContext 直接编码生成，无需第三方库。MP3 编码需要专门的编码器库，为保证纯前端轻量运行，本工具导出 WAV。
淡入淡出在实时播放时生效吗？
实时播放时仅应用基础音量增益以保证流畅体验；淡入淡出效果在导出 WAV 时完整应用，确保导出文件包含完整的渐变效果。
支持哪些音频格式？
支持浏览器可解码的所有格式，包括 MP3、WAV、OGG、M4A、FLAC 等（具体取决于浏览器支持）。导出统一为 WAV 格式。
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，音频文件不会上传到服务器，隐私安全
  • 增益超过 100% 可能产生削波失真，建议适度调整
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge 最新版）中使用
  • 大文件导出 WAV 需要一定处理时间，请耐心等待
