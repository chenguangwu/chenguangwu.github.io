📝 工具简介

音频剪切工具是一款基于 Web Audio API 的纯前端在线音频裁剪器。无需安装软件，上传音频后即可在可视化波形上拖拽选择片段，精确到毫秒级裁剪，并一键导出标准 WAV 文件。

✨ 功能特点

  • 拖拽上传音频
  • Canvas 波形可视化
  • 鼠标拖选剪切区域
  • 精确时间输入（秒）
  • 片段试听预览
  • OfflineAudioContext 渲染导出
  • 导出标准 WAV（16bit PCM）
  • 纯本地处理，数据不上传
  • 支持深色模式与响应式

🎯 使用场景

  • 截取音频片段做铃声
  • 裁剪播客/录音多余开头结尾
  • 提取音乐高潮部分
  • 为视频制作精准音频素材
  • 去除音频中的静音或噪声段

💬 常见问题

导出的为什么是 WAV 格式？
WAV 是无损未压缩格式，可由浏览器原生 Web Audio API 直接编码生成，无需第三方库，兼容性最佳。如需 MP3，可用音频格式转换工具二次处理。
为什么有些音频文件无法加载？
浏览器仅支持其内置解码器可处理的格式（如 MP3、WAV、OGG、M4A、FLAC 等）。若格式不被支持，将提示解码失败，建议转换格式后再试。
裁剪会损失音质吗？
不会。本工具通过 Web Audio API 直接对原始 PCM 采样进行切片并重新渲染，导出的 WAV 与源音频在该片段内的采样数据一致，无额外有损压缩。
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，音频文件不会上传到服务器
  • 建议在主流浏览器（Chrome / Safari / Firefox / Edge）中使用
  • 首次播放/试听需用户交互后浏览器才会允许音频输出
  • 大文件解码可能需要数秒，请耐心等待
  • 导出的 WAV 文件体积较大（约每分钟 10MB/单声道），请注意存储空间
