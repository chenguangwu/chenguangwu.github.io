💡 常见使用场景

  • 从长录音中截取一段精彩片段或去头尾静音，生成可直接使用的短音频。

  • 把一首曲子裁成铃声或铃声素材，避免手动再转码。
精确裁剪与淡变示例
一段 44100Hz 立体声音频，若要截取 30.000 秒到 35.250 秒，对应采样点区间为 44100×30=1,323,000 到 44100×35.25=1,554,225（每声道）。裁剪边界处建议加 5~10ms 线性淡入淡出，避免起点/终点因波形不连续产生爆音。导出 WAV 为非破坏性截取，原采样精度保留。

❓ 常见问题（FAQ）

剪切后为什么开头有咔哒一声？
当裁剪点落在波形非零位置，信号被硬切断会形成不连续的跳变产生爆音。在裁剪边界加极短的淡入淡出（几毫秒）即可消除，本工具在波形上拖选后导出即应用该处理。
剪切会损失音质吗？
纯按采样点截取是无损的（非重编码），只要导出格式与原精度一致（如都导出 WAV）就不会二次有损；若导出为有损格式才会引入压缩损失。

📝 工具简介

音频剪切工具是一款基于 Web Audio API 的纯前端在线音频裁剪器。无需安装软件，上传音频后即可在可视化波形上拖拽选择片段，精确到毫秒级裁剪，并一键导出标准 WAV 文件。

✨ 功能特点

  • 拖拽上传音频
  • Canvas 波形可视化
  • 鼠标拖选剪切区域
  • 精确时间输入（秒）
  • 片段试听预览
  • OfflineAudioContext 渲染导出
  • 导出标准 WAV（16bit PCM）
  • 纯本地处理，数据不上传
  • 支持深色模式与响应式

🎯 使用场景

  • 截取音频片段做铃声
  • 裁剪播客/录音多余开头结尾
  • 提取音乐高潮部分
  • 为视频制作精准音频素材
  • 去除音频中的静音或噪声段
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，音频文件不会上传到服务器
  • 建议在主流浏览器（Chrome / Safari / Firefox / Edge）中使用
  • 首次播放/试听需用户交互后浏览器才会允许音频输出
  • 大文件解码可能需要数秒，请耐心等待
  • 导出的 WAV 文件体积较大（约每分钟 10MB/单声道），请注意存储空间
