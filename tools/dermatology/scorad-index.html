🩹 特应性皮炎(SCORAD)指数评估器

📐 计算公式
SCORAD = A/5 + 7×B/2 + C = A/5 + 3.5×B + C

基于 SCORAD（Severity Scoring of Atopic Dermatitis）标准，从皮损面积(A)、皮损强度(B)及主观症状(C)三维度评估特应性皮炎/湿疹严重程度

A. 皮损面积（占体表百分比，0-100）
20%
使用「九分法」估算：头颈9%、双上肢各9%、躯干前18%、躯干后18%、双下肢各18%、会阴1%
B. 皮损强度（6项，各0-3分，最高18分）
C. 主观症状（各0-10分，最高20分；由患者近3天平均评分）

SCORAD 严重度分级

SCORAD 分值严重度临床意义
< 25轻度以外用糖皮质激素、保湿剂为主
25 - 50中度需规范外用治疗，必要时系统干预
> 50重度建议系统治疗，考虑生物制剂
计算公式：SCORAD = A/5 + 7×B/2 + C = A/5 + 3.5×B + C（A为面积%，B为强度分，C为主观分）。儿童可使用客观 SCORAD（仅 A/5 + 7B/2）。
