u = (u′ + v) / (1 + u′v/c²)

Combine velocities in the relativistic regime using (u+v)/(1+uv/c²), which never exceeds the speed of light.

📐 计算公式
u = (u′+v)/(1+u′v/c²)。 0.6c+0.6c → 0.882c（亚光速）。

高速参考系下的速度合成，永不超光速。

📌 计算说明
  • u = (u′+v)/(1+u′v/c²)。
  • 0.6c+0.6c → 0.882c（亚光速）。

💡 常见使用场景

  • 接近光速时速度不能简单相加。
  • 亚光速运动合成。
  • 高速情形下合成两个速度，保证结果不超过光速。
0.6c + 0.6c
u = (0.6c+0.6c)/(1+0.6×0.6) = 1.2c/1.36 ≈ 0.882c。即两 0.6c 叠加仍小于 c，不超光速。
两个速度各为 0.5c，光速取 3×10⁸ m/s
u=(u′+v)/(1+u′v/c²)=(0.5+0.5)/(1+0.25)=0.800000 c，即约 2.400×10⁸ m/s。经典力学直接相加得 1.0c，明显违背相对论。

❓ 常见问题（FAQ）

为什么不超过 c？
经典相加得 1.2c 错；相对论分母 1+u′v/c² 修正后结果恒 < c，光速不可超越。
日常速度为什么感觉不到这个差别？
因为修正项 u′v/c² 极小。以两列 350 km/h 的高铁相向为例，uv/c² 只有约 10⁻¹² 量级，相对论结果与直接相加的差别远小于任何仪器的测量误差。只有当速度接近光速时修正才显著。
