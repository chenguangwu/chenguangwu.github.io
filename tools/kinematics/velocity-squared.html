v² = v₀² + 2·a·Δx

Compute final velocity without time using v² = v₀² + 2ax from initial velocity, acceleration and displacement.

📐 计算公式
v² = v₀² + 2aΔx。 0 + 2×9.8×100 → v≈44.27 m/s。

不含时间的速度与位移关系。

📌 计算说明
  • v² = v₀² + 2aΔx。
  • 0 + 2×9.8×100 → v≈44.27 m/s。

📚 深度解析：速度位移关系（v²=v₀²+2aΔx）

💡 常见使用场景

  • 不知时间，由位移求末速。
  • 自由落体末速（已知高度）。
  • 不含时间地直接建立速度与位移的关系。
v₀=0、a=9.8、Δx=100
v = √(0+2×9.8×100) = √1960 ≈ 44.27 m/s。即自由下落 100 米末速约 44.3 m/s。
初速度 4 m/s，加速度 3 m/s²，位移 20 m
v=√(v₀²+2ax)=√(16+120)=√136=11.662 m/s。适用于只知道经过多远、不知道花了多久的场景，如制动痕长度推算。

❓ 常见问题（FAQ）

和 free-fall-time 一致？
一致：由 h=½gt² 与 v=gt 消去 t 即 v²=2gh，是同一运动不同表达。
这个公式能反过来用吗？
可以。交通事故鉴定中常测得制动痕长度 x，假定减速度 a 后反推初速 v₀=√(v²−2ax)；若车辆最终停住（v=0），则 v₀=√(−2ax)，a 取负值即可。
