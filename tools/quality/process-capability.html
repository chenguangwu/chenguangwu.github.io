📖 公式与判读

计算公式

Cp = (USL − LSL) / (6σ)　潜在过程能力

Cpu = (USL − μ) / (3σ)　上偏能力

Cpl = (μ − LSL) / (3σ)　下偏能力

Cpk = min(Cpu, Cpl)　实际过程能力

Zbench = 3 × Cpk　合格率 = Φ(Zbench)

DPMO = (1 − 合格率) × 1,000,000

Cpk 判读参考

Cpk ≥ 1.67：能力充足（优秀）

1.33 ≤ Cpk < 1.67：能力尚可

1.00 ≤ Cpk < 1.33：能力勉强，需改进

Cpk < 1.00：能力不足，需立即改善
