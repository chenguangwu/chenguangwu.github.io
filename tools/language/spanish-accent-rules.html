📖 重音规则说明

规则一：以元音 / n / s 结尾

以元音 (a, e, i, o, u) 或辅音 n、s 结尾的单词，重音落在倒数第二音节。

casa → CA-saperro → PE-rrocantan → CAN-tanmeses → ME-ses

规则二：以其他辅音结尾

以除 n、s 以外的辅音结尾的单词，重音落在倒数第一音节(末音节)。

papel → pa-PELfeliz → fe-LIZseñor → se-ÑORreloj → re-LOJ

规则三：重音符号 (´)

如果重音不落在上述默认位置，必须用重音符号标出。有重音符号的单词，重音就是符号所在音节。

lápiz → LÁ-pizespárrago → es-PÁ-rra-gojamás → ja-MÁSestán → es-TÁN

规则四：二重元音和三重元音

二重元音 (ai, au, ei, eu, ia, ie, io, iu, ou, ua, ue, uo, ui) 中，强元音 (a, e, o) 与弱元音 (i, u) 组合算一个音节；两个弱元音也算一个音节。两个强元音相邻则分属不同音节。

ciudad → ciu-DADpais → pa-ÍSreal → re-AL
