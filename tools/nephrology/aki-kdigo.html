📋 KDIGO 急性肾损伤诊断与分期标准

分期血清肌酐标准尿量标准
1期↑≥26.5 μmol/L(48h内) 或 ↑1.5-1.9倍基线<0.5 mL/kg/h 持续6-12h
2期↑2.0-2.9倍基线<0.5 mL/kg/h 持续≥12h
3期↑≥3倍基线 或 ≥353.6 μmol/L 或 需透析<0.3 mL/kg/h 持续≥24h 或 无尿≥12h

AKI诊断：48h内Scr升高≥26.5 μmol/L，或7天内Scr升高≥1.5倍基线，或尿量减少达上述标准。

提示：AKI分期取肌酐标准和尿量标准中较高者。AKI 3期需紧急肾内科会诊，评估透析指征。常见病因：肾前性（低容量、心衰）、肾性（ATN、AGN、AIN）、肾后性（梗阻）。本工具仅供临床参考。
