📐 计算公式
表面粗糙度 = Ra 对照

输入 Ra 值快速换算 Rz、Ry 及表面等级（N），并查看粗糙度与加工方法对照表。

📋 Ra / Rz / N 级 对照表

Ra：轮廓算术平均偏差，最常用粗糙度指标。
Rz：微观不平度十点高度（5 个取样长度内最大峰谷高度平均），约为 Ra 的 4~7 倍。
Ry/Rmax：轮廓最大高度，约为 Rz 的 1.2~1.6 倍。
N 级：ISO 粗糙度等级代号（N1~N12），数值越大越粗糙。
换算为经验近似，实际因加工方法与表面形貌而异。
