📋 计算说明

锻造比 K：表示金属变形程度，是锻造工艺的重要指标。
拔长：K = F₀ / F₁ = 原始截面积 / 锻后截面积
镦粗：K = H₀ / H₁ = 原始高度 / 锻后高度
变形程度 ε = (F₀ − F₁) / F₀ × 100%（拔长）或 (H₀ − H₁) / H₀ × 100%（镦粗）

参考要求：碳素结构钢拔长比 ≥ 2~3；合金结构钢 ≥ 3~4；高合金钢/工具钢 ≥ 4~6（需破碎碳化物）；镦粗比一般取 2~3。锻造比过小组织不均，过大则形成纤维方向性。
