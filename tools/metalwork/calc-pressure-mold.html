📐 计算公式
冲裁力 F = 冲裁周长 L × 板厚 t × 抗剪强度 τ（N），÷1000 化 kN；设计冲裁力 = 冲裁力(kN)×1.3；单边间隙 c = 材料系数×t（低碳钢/铜 0.07、中碳钢 0.08、不锈钢 0.09、铝 0.06），双边间隙 = 2c；卸料力 ≈ 冲裁力(kN)×5%、推件力 ≈ 冲裁力(kN)×4%。校验：板厚、抗剪强度、周长任一非数或 ≤0 分别提示输入有效值。判据：切换材料下拉自动联动抗剪强度参考值与间隙系数。

输入板厚、材料抗剪强度、冲裁周长，计算冲裁力与模具间隙

💡 冲裁力 F = L × t × τ；单边间隙 c = m × t（m 为材料系数，约 5%-12%）。

📚 深度解析：冲裁力与模具间隙计算

💡 常见使用场景

  • 冲压工艺设计冲裁力，选压力机吨位。
  • 确定单边/双边间隙保证断面质量。
  • 估算卸料力、推件力配置气缸。
冲裁力
周长 L=100mm、料厚 t=2mm、抗剪强度 τ=350MPa：理论冲裁力 F = L×t×τ = 100×2×350 = 70000 N = 70 kN；设计力 Fd = 70×1.3 = 91 kN（含安全系数）。
间隙与卸料力
单边间隙 c = 料厚×间隙率（如 5%×2 = 0.10mm），双边 z = 2×0.10 = 0.20mm；卸料力约 5%、推件力约 4% 即 70×0.05≈3.5kN、70×0.04≈2.8kN。

❓ 常见问题（FAQ）

压力机吨位怎么留余量？
取理论冲裁力×1.3 安全系数并叠加卸料/推件力，再选相近标准吨位，避免满负荷降低寿命。
间隙大了小了会怎样？
间隙过大断面毛刺大、塌角多；过小模具磨损快、易卡料。一般软料取料厚 5–8%、硬料 3–5%。
