计算公式与方法

方法一（放大率法）： 实际牙长 = X线测得牙长 ÷ (1 + 放大率) 方法二（插锉法）： 实际牙长 = 初始锉深度 + X线根尖余留 ÷ (1 + 放大率) 工作长度 WL = 实际牙长 - 根尖止点距根尖距离 - 安全余量

💡 常见使用场景

  • 术前根尖片测牙长，输入放大率后工具换算真实牙长，预估工作长度。
  • 根尖孔未闭合年轻恒牙，提示工作长度止于根管口附近并谨慎预备。
  • 再治疗核对旧充填到达位置与现止点差异。（结果仅供口腔健康科普与自我初筛参考，不替代口腔检查、根尖片/CBCT 等影像学评估及口腔医师、正畸科、牙周科等专业诊断与治疗；如有牙痛、牙龈出血、溃疡久不愈、口腔黏膜异常或咬合不适，请及时到正规医院口腔科就诊。）
工作长度换算
输入：片上牙长 22mm，放大率 1.1，根尖止点距根尖 0.5mm 计算：实际牙长 = 22 / 1.1 = 20mm；工作长度 WL = 20 − 0.5 = 19.5mm 说明：实际以电子根尖定位仪与片结合确定。

❓ 常见问题（FAQ）

为什么要校正放大率？
X 线有放大，片测长度偏大；除以放大率得真实牙长，避免工作长度偏长导致超充或偏短欠充。
根尖止点设在哪里？
通常止于距解剖根尖 0.5~1mm 的根尖狭窄区，兼顾清理与窄小封闭；以电子根尖定位仪辅助。
能代替根尖定位仪吗？
不能。本工具为片测估算，临床以电子根尖定位仪结合片确定工作长度，由牙体牙髓科医师操作。
