Pell-Gregory 分类说明

水平分类（与升支关系）

• Class Ⅰ：升支前缘与第二磨牙远中面间有足够间隙容纳智牙冠近远中径

• Class Ⅱ：间隙小于智牙冠近远中径

• Class Ⅲ：智牙全部位于升支前缘内侧

深度分类（与咬合平面关系）

• Class A：智牙咬合面与第二磨牙咬合平面平齐（最高位）

• Class B：介于咬合平面与第二磨牙釉牙骨质界之间

• Class C：低于第二磨牙釉牙骨质界（最深位）

难度评分参考（Pederson难度指数）

水平：Class Ⅰ=1分，Ⅱ=2分，Ⅲ=3分

深度：A=1分，B=2分，C=3分

方向：垂直=1分，近中=2分，水平=3分，远中=4分
