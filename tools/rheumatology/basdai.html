📋 BASDAI 计算方法

公式：BASDAI = (Q1 + Q2 + Q3 + Q4 + (Q5 + Q6)/2) / 5

第5、6项（晨僵严重程度和持续时间）取平均值后与其他4项加总，再除以5。

📊 BASDAI 临床意义

BASDAI疾病活动度临床决策
<4低活动度维持NSAIDs+功能锻炼
≥4高活动度考虑启动抗TNF生物制剂
≥4 + ASDAS≥2.1高活动度(确认)推荐生物制剂/JAK抑制剂
提示：BASDAI≥4是ASAS/EULAR推荐启动抗TNF生物制剂治疗的主要标准之一。BASDAI主观性较强，建议结合ASDAS(含CRP/ESR的客观指标)综合评估。ASDAS-CRP = 0.12×腰背痛 + 0.06×晨僵持续时间 + 0.07×患者总体 + 0.11×CRP(√)。仅供临床参考。
