Nominal to Real Value

Deflate a nominal value to real terms using an inflation (or deflator) rate, removing the effect of price change.

📐 计算公式
名义值折算实际值（费雪方程口径）：实际值 = 名义值 ÷ (1+π)（π 通胀率，按小数输入，如 5% 填 0.05）；联动量：折减额 = 名义值 − 实际值、名义÷实际 与 实际÷名义 两个比值。校验：名义值、通胀率两项必填守卫，(1+π) 为隐含分母（π=−100% 时无意义）。判据：无固定分级，π 为正时实际值低于名义值，π 为负（通缩）时实际值高于名义值。

输入名义值 Nominal 与通胀率 π，求实际值。

📌 计算说明
  • Real = Nominal/(1+π)。
  • 110,π=10% → 100。

  • 实际化：录入名义值与通胀率，算实际值（购买力）。

  • 教学演示：演示高通胀下名义增但实际降。
使用示例
示例：名义工资 11000、通胀 10%，实际=11000/1.1=10000，购买力持平。
