GDP by Expenditure

Compute GDP using the expenditure approach: GDP = C + I + G + NX (consumption, investment, government spending, net exports).

📐 计算公式
Y = C+I+G+(X−M)。 1000+300+200+50 → 1550。

输入消费 C、投资 I、政府支出 G、净出口 NX，求 GDP。

📌 计算说明
