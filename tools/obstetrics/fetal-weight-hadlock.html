⚖️ Fundal Height/Abdominal Circumference and Fetal Weight (Hadlock)

Estimate fetal weight with the Hadlock formulas from BPD, HC, AC, FL and symphysis-fundal height.

输入B超测量值(任选参数，参数越多越准)

📐 计算公式

Hadlock 四参数（Hadlock 1985, Am J Obstet Gynecol 151:333）：EFW(g) = 10^(1.3596 − 0.00386·AC·FL + 0.0064·HC + 0.00061·BPD·AC + 0.0424·AC + 0.174·FL)；缺 HC 时用 Hadlock 三参数（BPD+AC+FL，Hadlock C 1985，同上文献）：10^(1.335 − 0.0034·AC·FL + 0.0316·BPD + 0.0457·AC + 0.1623·FL)；仅 AC+FL 时用 Hadlock 两参数（Hadlock 1985）：10^(1.304 + 0.05281·AC + 0.1938·FL − 0.004·AC·FL)；仅有 BPD+AC 时用 Shepard 1982：10^(−1.7492 + 0.166·BPD + 0.046·AC − 2.646·AC·BPD/1000)（原式以 kg 计，×1000 → g）。以上 log₁₀ 均以 10 为底、长度单位 cm，EFW 单位 g。宫高腹围页签为经验式：EFW(g) = 2900 + 0.3·宫高·腹围；Johnson 法（未入盆 n=12）：EFW(g) = (宫高 − 12)·155。

B 超参数越全越准：四参数（BPD+HC+AC+FL）优先；缺 HC 用 Hadlock 三参数（BPD+AC+FL）；仅 AC+FL 用 Hadlock 两参数；仅有 BPD+AC 用 Shepard 两参数。注意 Shepard 原式单位是 kg，直接当 g 会放大 1000 倍，代码已显式 ×1000。仅有单个参数（如只有 AC 或只有 FL）时不做伪公式估算，直接提示参数不足。宫高腹围页签为床旁经验式：2900 + 0.3·宫高·腹围 与 Johnson 法（宫高 − 12）·155（n=12 指未入盆，入盆时常用 n=11）。估计体重 ≥ 4000 g 为巨大儿。

临床触诊宫高与腹围，简易估算（误差常达数百克）

📐 Hadlock公式 (1985)

BPD + HC + AC + FL（四参数，最准确）— Hadlock 1985, Am J Obstet Gynecol 151:333

log₁₀(EFW/g) = 1.3596 - 0.00386×AC×FL + 0.0064×HC + 0.00061×BPD×AC + 0.0424×AC + 0.174×FL

BPD + AC + FL（三参数，缺 HC）— Hadlock C 1985（同上文献）

log₁₀(EFW/g) = 1.335 - 0.0034×AC×FL + 0.0316×BPD + 0.0457×AC + 0.1623×FL

AC + FL（Hadlock 两参数）— Hadlock 1985（同上文献）

log₁₀(EFW/g) = 1.304 + 0.05281×AC + 0.1938×FL - 0.004×AC×FL

BPD + AC（Shepard 两参数，仅有 BPD+AC 时）— Shepard 1982, Am J Obstet Gynecol 142:47

log₁₀(EFW/kg) = -1.7492 + 0.166×BPD + 0.046×AC - 2.646×(AC×BPD)/1000；长度 cm，原式输出 kg，本工具 ×1000 换算为 g

宫高 × 腹围（床旁经验式，非回归发表式）

EFW(g) = 2900 + 0.3 × 宫高(cm) × 腹围(cm)（足月附近粗估；仅作床旁参考，误差常达数百克）

Johnson 法（床旁经验式）

EFW(g) = (宫高 − n) × 155；未入盆 n=12，入盆 n=11（本工具固定按未入盆 n=12）

💡 常见使用场景

  • 晚孕超声用 BPD/HC/AC/FL 估算胎儿体重（EFW）。
  • 识别巨大儿（≥4000g）与 FGR（<2500g）。
  • 分娩方式评估（体重过大需防肩难产）。
正常体重估算
BPD 9.2cm、HC 33.1cm、AC 31.5cm、FL 7.2cm 代入 Hadlock 四参数：log₁₀(EFW/g)≈3.4612，EFW≈10^3.4612≈2892g，属正常体重（2500–4000g）。
巨大儿预警
若 AC 升至 36cm、BPD 9.8cm，EFW 可超 4000g 触发巨大儿提示，需评估糖尿病与肩难产风险、计划分娩方式。

❓ 常见问题（FAQ）

估算误差有多大？
Hadlock 等公式平均误差约 ±10–15%；胎儿越偏离均值误差越大，临床仅作参考而非精确值。
巨大儿如何定义？
出生体重 ≥4000g 为巨大儿（部分国家 ≥4500g），与母体糖尿病、过期妊娠相关，增加难产与产伤风险。
