📚 深度解析：人员安全疏散时间估算（流量法）

💡 常见使用场景

  • 疏散设计中，由人数、出口宽度、人流速度与行走距离估算总疏散时间。
  • 预案编制时，把行走时间、出口排队时间与预动作时间叠加得到总耗时。
  • 出口能力不足会形成排队瓶颈，是疏散时间的主要来源。
算例：100 人、出口宽 2m、流量 1.5 人/(s·m)、距离 30m、速度 1.2m/s、预动作 30s
行走 = 30/1.2 = 25.0 s；排队 = 100/(2×1.5) = 33.3 s；总疏散 = 25.0 + 33.3 + 30 = 88.3 s（≈1.47 min）；出口能力 = 2×1.5 = 3.00 人/s。
算例：瓶颈识别
总时间 = 行走 + 排队 + 预动作，其中『排队 = 人数/(出口宽×单位宽度流量)』对结果最敏感。加宽出口或分流可显著压降排队时间。

❓ 常见问题（FAQ）

单位宽度人流流量取多少？
常见设计取值约 1.3–1.5 人/(s·m)（水平出口），楼梯略低。实际受人员构成、熟悉度影响，本工具以输入为准，取值应参考现行疏散设计规范。
预动作时间是什么？
指人员发现火情到开始撤离的反应时间（察觉、判断、广播、起身），通常 30–60 s 量级。它不依赖出口能力，但占疏散总时长的相当比例，演练可显著缩短。
