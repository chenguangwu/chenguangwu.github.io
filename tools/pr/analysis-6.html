💡 常见使用场景

  • 把一批帖子、评论或短新闻粘贴进来，用内置词表统计正、负向词命中次数，先得到整体极性指数。
  • 危机处置中按时间窗口分别粘贴文本，对比两次的极性指数与负向词构成，判断舆情是在缓和还是恶化。
  • 批量稿件初筛时只看负向词列表：高密度负面且集中在「退款、延误、敷衍」等词的样本优先人工复核。
正面稿件的读数
一段 36 字的体验短评「体验很好，性能稳定，价格也很实惠，客服态度专业，物流速度快，值得推荐」，命中正向词 6 次、负向词 0 次，极性指数 =（6 − 0）÷（6 + 0） = 100.00%，情感词密度 16.67%，判为正面倾向。
投诉帖里的负向词构成
一段 45 字投诉「卡顿和失灵，客服态度敷衍，物流延误两天，退款也拖沓，体验很差，完全不值」，命中负向词 8 次且分布在不同环节（质量、服务、物流、售后、性价比），极性指数 −100.00%。这种多维度同时负面的样本比单点吐槽更应优先处置。
为什么不能只看极性指数
两段文本极性指数都接近 0，但一段是正负各命中 5 次（争议性内容，两方对立），另一段是一次也没命中（中性陈述，无情绪）。因此要同时看情感词密度，密度很接近 0 时说明结论不可靠，应人工判读或改用更完整的模型。

❓ 常见问题（FAQ）

这种方法能替代专业情感分析模型吗？
不能。词典法不做分词与句法分析，无法处理否定（如「不好」）、反讽与上下文语义，也识别不出词典外的网络新词。它的价值在于零依赖、可离线、秒级出结果，适合大批量样本的粗筛与人工复核前的排序，最终定论仍应结合上下文。
极性指数为 0 代表中性吗？
不一定。它只能说明正、负向词命中次数相等。若两者都很大属于争议性内容，若都为 0 则表示没有匹配到任何情感词、结论不可信。这时要连同「情感词密度」一起判读，密度过低时建议人工复核。
词典里没有的领域词怎么办？
本工具使用固定词表，不支持自定义。行业特有表达（如保险条款里的「拒赔」）若不在表内会被漏掉。遇到这种情况可先把结果作为参考，再按你的业务词表人工复检，或选用支持自定义词典的专业工具。
英文内容能用吗？
总词量会把中文字符数与英文单词数相加，但内置词表只覆盖中文，英文里的情感词不会被计入。纯英文或中英混排且情绪主要由英文表达的文本，结果会明显偏低，建议先翻译为中文再统计。
