📝 Markdown Table Generator

Generate Markdown table syntax from rows, columns, and content.

📐 工作原理与说明
行数取输入值并保证在 1 到 50 之间（非法时取 1），列数取输入值并保证在 1 到 20 之间（非法时取 1）。表头与正文种子均按 CSV 规则切分：英文逗号分隔，单元格可用双引号包裹以容纳逗号（"" 表示一个字面引号）；未加引号的字段去首尾空白，引号内的首尾空格会保留并以   在 Markdown 中明示。未闭合双引号会报错并停止生成。填充单元格时按顺序取种子值，取不到时用「C 加列序号」占位，并对内容做 Markdown 转义：先把反斜杠转义为双反斜杠，再把竖线转义为反斜杠加竖线，最后把换行换成空格。分隔行按对齐方式生成标记。正文每行在种子值后追加行序号。CSV 导出默认对 = + - @ 开头的非数值单元格加单引号防公式注入，并可选 UTF-8 BOM。
生成 Markdown 格式的表格。
  • 结构：表头行 + 分隔行（| --- | --- |）+ 数据行。
  • 对齐：分隔行写 :--- 左对齐、---: 右对齐、:---: 居中。
  • 转义：单元格内的竖线需写作 \|，否则会被当作列分隔。
  • 用途：在 README 与文档中清晰呈现参数、对照表与结果数据。
  • CSV 导出：默认中和 = + - @ 开头的非数值内容（防公式注入），可选 Excel 兼容 BOM；负数与普通文本保持原样。

  • 全部在浏览器本地执行，不上传内容。

❓ 常见问题（FAQ）

对齐怎么设？
`:---` 左、`:--:` 中、`---:` 右。
单元格里有竖线怎么办？
需要转义成 \|，否则会被当作列分隔符破坏整行结构，这是 Markdown 表格最常见的坑。另外单元格内换行在标准 Markdown 里无法直接表达，通常改用 <br> 标签（但部分平台会转义 HTML），或拆成多行记录。
