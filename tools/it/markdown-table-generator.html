📋 Markdown Table Generator

Generate Markdown table syntax from rows, columns, and content.

📐 工作原理与说明

生成 Markdown 格式的表格。

  • 结构：表头行 + 分隔行（| --- | --- |）+ 数据行。
  • 对齐：分隔行写 :--- 左对齐、---: 右对齐、:---: 居中。
  • 转义：单元格内的竖线需写作 \|，否则会被当作列分隔。
  • 用途：在 README 与文档中清晰呈现参数、对照表与结果数据。
📌 说明
  • 表头与数据均可直接编辑后重新生成。
  • 不支持合并单元格，适合用于表格文档、Issue、README 场景。
  • 全部在浏览器本地执行，不上传内容。
