🧩 TOML 转 XML 转换器

把 TOML 配置转回 XML，用于老系统或需要 XML 的接口。粘贴 TOML，立即得到 XML。

⚠️ 使用说明与注意事项
  • TOML 中以 @ 开头的键会转为 XML 属性；数组展开为多个同名元素。
  • 转换按约定进行，复杂结构建议人工核对。

📚 深度解析：TOML 转 XML

💡 常见使用场景

  • 配置互转：把 TOML 配置转成 XML 供老系统 / 部分构建工具消费。
  • 数据桥接：在 TOML 与 XML 两种格式之间搬运结构化配置。
示例：TOML → XML
输入： ```toml [config] name = "demo" port = "8080" ``` 输出： ```xml <config><name>demo</name><port>8080</port></config> ``` （表名成为父节点，键值成为子元素）

❓ 常见问题（FAQ）

嵌套结构怎么表达？
TOML 的 `[a.b]` 表会变成 `<a><b>…</b></a>` 的嵌套 XML 节点；数组会展开为重复的同名子元素。
和 TOML 转 JSON 结果一致吗？
语义一致、表示不同：JSON 用花括号与方括号，XML 用标签嵌套；字段名与值保持相同。
