📄 TOML to XML Converter

📐 工作原理与说明
把 TOML 转换为 XML。
  • 映射：TOML 的表映射为 XML 元素，键成为子元素或属性（依具体约定）。
  • 转义：XML 中的 & < > 等保留字符必须转义。
  • 限制：XML 元素名不能以数字开头或含空格，非法名称需做转换。
  • 用途：与仅支持 XML 输入的系统对接。

Convert TOML configuration into XML, mapping tables to nested elements for systems that require XML.

⚠️ 使用说明与注意事项
  • TOML 中以 @ 开头的键会转为 XML 属性；数组展开为多个同名元素。
  • 转换按约定进行，复杂结构建议人工核对。

❓ 常见问题（FAQ）

表怎么转 XML？
转成嵌套元素。
为什么生成的结构和预期不一样？
因为两种模型的表达能力不对等：TOML 有表、表数组与内联表，XML 有元素与属性，没有统一映射规则。多数转换器把表映射为元素、标量映射为文本或属性。跨系统对接时应先用小样例验证结构，必要时调整源配置的层级。
