🔎 MSISDN Query

📐 工作原理与说明
MSISDN 是手机号码在移动通信网络中的完整国际编号。
  • 结构：国家码（CC）+ 国内目的地码（NDC）+ 用户号码（SN），总长不超过 15 位。
  • 与 E.164：MSISDN 遵循 E.164 编号计划，通常以 + 开头表示国际格式。
  • 与 IMSI：MSISDN 是「拨号用的号码」，IMSI 是 SIM 卡内标识用户的身份，二者不同。
  • 用途：号码归属地识别、国际短信与通话路由。

MSISDN 与 IMSI 区别？
MSISDN 是用户可见号码，IMSI 是 SIM 内国际标识。
