🔎 MSISDN Query

📐 工作原理与说明
归一化：去除空格、连字符、括号、点，剥离前导 +；国家/地区码按 3→2→1 位降序匹配 E.164 码表；先校验 E.164 总长 8–15 位与各国国内号长，再按 +86 前 3 位号段查运营商（162/165/167/170/171 等移动通信转售号段只给底层网络、不判定实际签约服务商，其中 170 按前 4 位区分底层网络）、+1 按 NANP（NPA/NXX）规则校验并查区号；输出 E.164（+国家码+国内号码）
MSISDN 是手机号码在移动通信网络中的完整国际编号。
  • 结构：国家码（CC）+ 国内目的地码（NDC）+ 用户号码（SN），总长不超过 15 位。
  • 与 E.164：MSISDN 遵循 E.164 编号计划，通常以 + 开头表示国际格式。
  • 与 IMSI：MSISDN 是「拨号用的号码」，IMSI 是 SIM 卡内标识用户的身份，二者不同。
  • 用途：号码归属地识别、国际短信与通话路由。

💡 常见使用场景

  • 解析手机号的国家码/运营商片段。
  • 清洗国际用户号码：解析出国家码与国内有效号，统一成 E.164 格式后再入库，避免重复与误判归属地。
解析
`8613800138000` → CC=86(中国), NDC=138, SN=00138000（示例结构）。

❓ 常见问题（FAQ）

MSISDN 与 IMSI 区别？
MSISDN 是用户可见号码，IMSI 是 SIM 内国际标识。
为什么同一个号码解析结果不同？
因为号码规划会调整：携号转网后号码段不再代表原运营商，新启用的号段也可能尚未收录；162、165、167、170、171 等移动通信转售号段由虚拟运营商放号，静态号段只能说明底层承载网络，无法确定用户实际签约服务商。此外部分国家的号码长度不固定（如德国、奥地利），需结合国家码判断。因此解析结果适合作为辅助信息，不应作为计费或路由的唯一依据。
