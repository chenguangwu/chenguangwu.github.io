🗜️ CSS Minifier

CSS Minifier - Strip comments and redundant whitespace to shrink CSS for faster loads, preserving semantics. Free, browser-only.

📐 工作原理与说明
依次执行：删除块注释；把连续空白压缩为单个空格；去掉花括号、冒号、分号、逗号、大于号这些符号两侧的空白；再去掉右花括号之前多余的分号。最终得到压缩后的 CSS
压缩 CSS 以减小文件体积。
  • 手段：去注释与空白、删除冗余分号、把 0px 简写为 0、缩进颜色值。
  • 合并：可合并等价声明与简写属性（如 margin 四值合并）进一步减小体积。
  • 风险：过度合并可能改变层叠与优先级，压缩后必须做视觉回归。
  • 建议：集成进构建流程并产出 source map，便于线上问题定位。
⚠️ 使用说明与注意事项
  • 压缩仅去注释与空白，不改变选择器与声明语义；但会移除 source map 关联与可读性，发布版勿保留源注释。
  • 本工具不重写属性（如合并 0px→0），属于「安全压缩」；激进压缩（变量内联、自动前缀）需交给构建工具（cssnano/esbuild）。
  • 生产环境应同时开启 Gzip/Brotli，文本压缩对 CSS 收益最大。

📋 说明

压缩后请本地预览效果是否一致；涉及 content 伪元素里特殊空格时，过度去空白可能需谨慎。本工具保留声明间必要空格。

❓ 常见问题（FAQ）

压缩会删注释吗？
会，含版权注释如需保留用特殊标记。
压缩会破坏 @media 或 @supports 吗？
正常的压缩器会完整保留 at-rule 及其嵌套块，不会破坏。风险来自两处：一是压缩器对现代语法（如 @layer、原生嵌套）支持滞后；二是 CSS hack（如 *height）可能被当作无效声明删除。压缩后应在目标浏览器实测关键样式。
