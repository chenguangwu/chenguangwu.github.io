📝工具简介

      
SQLite 在线执行工具基于 sql.js（将 SQLite 编译为 WebAssembly）实现，在浏览器内存中运行完整的 SQLite 数据库引擎。无需安装任何软件、无需注册账号，打开网页即可编写并执行 SQL 语句，实时查看查询结果。所有数据均在浏览器本地处理，不会上传到任何服务器。

💬常见问题

      
我的数据会被上传到服务器吗？
不会。本工具基于 sql.js 在浏览器本地内存中运行 SQLite，所有建表、插入、查询操作均在你的浏览器内完成，数据不会发送到任何服务器。

      
支持哪些 SQL 语法？
支持完整的 SQLite SQL 语法，包括 CREATE TABLE、INSERT、UPDATE、DELETE、SELECT、JOIN、聚合函数、子查询、视图、触发器、PRAGMA 等。

      
刷新页面后数据还在吗？
不在。数据库运行在浏览器内存中，刷新或关闭页面后数据会清空。如需保存，可点击「导出 .sqlite」下载数据库文件。

      
执行多条 SQL 语句时报错怎么办？
请确保每条语句以分号（;）结尾。工具会逐条执行并分别显示每条语句的结果或错误，方便定位问题。

      
这个工具是免费的吗？
完全免费，无需注册，直接在浏览器中打开即可使用。
