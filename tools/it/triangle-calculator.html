📐 工作原理与说明
三角形求解（SSS 已知三边）
构成条件：任意两边之和 > 第三边（a+b>c、a+c>b、b+c>a）
海伦公式：半周长 s = (a+b+c)/2，面积 = √[s(s−a)(s−b)(s−c)]
余弦定理求内角：cos A = (b²+c²−a²) ÷ (2bc)，A = arccos(…)×180/π
类型判定：任一内角 = 90° 为直角三角形｜全 <90° 锐角｜否则钝角
三内角之和恒为 180°
按三角形已知条件求解边长、角度、面积与周长。
  • 内角和：三角形三个内角之和恒为 180°。
  • 勾股定理：直角三角形满足 a² + b² = c²，c 为斜边。
  • 海伦公式：令 s=(a+b+c)/2，面积 = √(s(s−a)(s−b)(s−c))，已知三边即可求面积。
  • 正余弦定理：a/sinA = b/sinB = c/sinC；c² = a² + b² − 2ab·cosC。

⚠️ 使用说明与注意事项
  • 海伦公式：面积 = √[s(s−a)(s−b)(s−c)]，其中 s 为半周长（周长的一半），对任意三角形都成立。
  • 余弦定理：cos A = (b²+c²−a²)/(2bc)，据此反推角度；三个角之和恒为 180°。
  • 判断类型：任一内角≈90° 为直角，三者都<90° 为锐角，否则为钝角（浮点误差用 1e-6 容差）。

❓ 常见问题（FAQ）

余弦定理公式？
c²=a²+b²−2ab·cosC。
为什么提示无法构成三角形？
因为不满足三角形不等式：任意两边之和必须大于第三边（两边之差小于第三边）。此外角度输入需注意单位（度与弧度），两角之和不能超过 180°。若输入的三边中两边之和等于或小于第三边，几何上就无法闭合。
