⌨️ 按键码 Keycode 查询

按下任意键，实时显示 event.key / code / keyCode / 修饰键等全部按键信息，附常见按键码速查表，前端开发调试利器。

📐 工作原理与说明

本开发工具在前端本地完成解析、转换与处理，代码不离开浏览器，遵循对应语法与格式规范。 工具名称：按键码 Keycode 查询 - 按下任意键，实时显示 event.key / code。

焦点在页面上时按下任意键即可捕获（无需输入框）
event.key

属性值说明
event.code—物理按键位置（推荐）
event.key—按键字符值
keyCode (废弃)—旧式数字键码，仅兼容用
修饰键—Ctrl/Shift/Alt/Meta
