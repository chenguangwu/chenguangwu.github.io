📖 什么是 TSV？

TSV（Tab-Separated Values，制表符分隔值）是一种简单的文本文件格式，用制表符（Tab）分隔各列数据。与 CSV 相比，TSV 更少出现分隔符冲突问题，因为数据中很少包含 Tab 字符。

💡 使用场景

• 数据导出导入：Excel、Google Sheets 等电子表格软件支持 TSV 格式

• API 数据处理：将 JSON 接口数据转为 TSV 方便分析

• 日志分析：将结构化日志转成表格形式查看

• 数据迁移：不同系统之间的数据交换

• 数据库导出：将查询结果导出为 TSV 方便分享

📝 JSON → TSV 示例

输入 JSON 数组：

[
  {
    "name": "张三",
    "age": 25,
    "city": "北京"
  },
  {
    "name": "李四",
    "age": 30,
    "city": "上海"
  }
]

输出 TSV（Tab 分隔）：

name	age	city
张三	25	北京
李四	30	上海

⚠️ 注意事项

• JSON 必须是合法的数组格式，每个元素为对象

• TSV 中如果值包含 Tab 字符，会被自动替换为空格

• 嵌套对象或数组会被转为 JSON 字符串形式

• 所有处理都在浏览器本地完成，数据不会上传到服务器

⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge）中使用
