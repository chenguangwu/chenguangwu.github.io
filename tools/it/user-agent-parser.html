💡 UA 字符串结构

典型 UA 格式：
Mozilla/5.0 (平台; 系统信息) 引擎/版本 浏览器/版本

历史原因：现代 UA 都以 "Mozilla/5.0" 开头，是浏览器大战时代为兼容旧网站留下的"兼容性标记"，并非真实身份。

提示：自 2020 年起，Chrome、Firefox、Safari 开始降低 UA 字符串的精度以保护用户隐私（UA Client Hints），建议新应用使用 navigator.userAgentData 替代字符串解析。
