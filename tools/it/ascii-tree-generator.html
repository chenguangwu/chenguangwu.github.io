✨ ASCII Directory Tree Generator

Generate ASCII directory trees from a path list in your browser — great for docs and READMEs.

📐 工作原理与说明
把层级数据渲染成终端风格的目录树，用缩进与连接符表达父子关系。
  • 连接符：非末级子项用 ├──，同层最后一项用 └──，用 │ 延续父级竖线。
  • 规则：某节点是其父的最后一项时，其子树前缀补空格而非 │，保证视觉闭合。
  • 输入：支持缩进文本或路径列表（按 / 切分）自动推断层级。
  • 输出：纯文本，可直接粘贴进 README、接口文档或终端说明。

💡 常见使用场景

  • 把文件结构渲染成 tree 文本。
  • 写文档时贴目录结构：在 README 或接口文档里用树形文本说明工程目录，比截图更轻量、可复制、可搜索。
生成
输入路径列表 → `├─ a │ └─ b └─ c` 树形。

❓ 常见问题（FAQ）

与 tree 命令区别？
本工具在线生成，无需 shell。
├── 和 └── 的区别是什么？
├── 表示该节点后面还有同级兄弟，└── 表示它是父节点的最后一个子项。父级是否继续画竖线 │ 也由此决定：最后一个子项之后不再延续，整棵树才不会多出断线。
