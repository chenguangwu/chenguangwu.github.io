📊 CSV 转 HTML 表格

粘贴 CSV 数据，自动解析（支持引号转义与换行），生成可直接使用的 HTML <table> 代码，右侧实时预览渲染效果。

⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge）中使用
  • 处理结果请自行核对后再用于生产环境
