💻 Text Truncate

📐 工作原理与说明
截断模式分四种：按字符数取前 limit 个字符，开启单词边界时从第 limit 个字符往前找到最近的空白字符作为终点，一直找不到则回退到 limit；按词数先按空白切分为词数组，取前 limit 个再以空格连接；按行数先按换行切分，取前 limit 行再以换行连接；按字节数逐字符累加字节数（中日韩统一表意文字与全角区字符记 2 字节，其余记 1 字节），累加会超过 limit 时停止。开启从末尾截断时改为取末尾对应数量的字符、词或行。发生截断且设置了省略符时，从末尾截断把省略符加在前面，否则加在后面。开启逐行处理且模式不是按行时，先按换行切分再对每一行单独执行上述截断
按长度截断文本并添加省略标记。
  • 处理：达到指定长度后截断，并在末尾追加省略号或自定义后缀。
  • 字素簇：应按字素簇截断，避免切在代理对中间产生半个 emoji 或乱码。
  • 词边界：可选择在词边界处截断，避免把单词切成两半。
  • 用途：列表摘要、卡片描述、控制 SEO description 长度。

❓ 常见问题（FAQ）

按字节还是字符？
可选，中文按字符更友好。
为什么截断后出现了半个字？
因为按字节截断时切在了多字节字符中间：UTF-8 下一个汉字占 3 字节，从中间切断会得到无法解码的字节序列，显示为问号或方块。正确做法是按字符（或字素簇）计数后再截断；若必须按字节限制（如短信、数据库字段），应在字符边界处回退。
