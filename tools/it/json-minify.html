📄 JSON Compress / Format

Compress and format JSON in your browser — minify to save space or pretty-print for readability, with no upload.

📐 工作原理与说明
解析输入 JSON 后重新序列化：压缩模式输出紧凑形式，美化模式输出两个空格缩进的形式。原始字节数与输出字节数均按 UTF-8 字节长度计算；压缩率 = (1 − 输出字节数 ÷ 原始字节数) × 100%，保留 1 位小数（原始字节数为 0 时取 0）。压缩模式下压缩率为负（即输出反而变大）时提示小体积 JSON 建议保留美化格式。解析失败时输出解析失败原因并清空输出
压缩或美化 JSON 文本。
  • 压缩：移除所有非必要空白与换行，得到最小体积的 JSON。
  • 美化：按层级缩进输出（常用 2 空格），便于阅读与 diff。
  • 语法：JSON 要求键与字符串用双引号，不允许尾随逗号与注释。
  • 语义：压缩与美化均不改变数据内容，仅改变排版。

📚 JSON 规范速查

要点说明
合法值类型string / number / object / array / true / false / null
键与字符串必须使用双引号，单引号不合法
转义字符\" \\ \/ \b \f \n \r \t \uXXXX
压缩本质移除所有无意义空白与换行，不改变语义

常见错误：使用单引号、末尾多余逗号、含注释、数值带前导零——均会导致解析失败。

❓ 常见问题（FAQ）

压缩 JSON 还能解析吗？
能，合法 JSON 不依赖换行。
压缩会丢数据吗？
不会。JSON 规范明确忽略记号之间的空白，键名与字符串值内部的内容不受影响，去掉缩进、换行与空格后的解析结果完全一致。唯一要小心的是手写拼接 JSON 时误删了字符串值内部的空格——那属于内容而非格式。
