💡 常见使用场景

  • 在接口请求 / 响应中去掉空白与换行，减小传输体积、节省带宽。
  • 把 JSON 嵌入 <script> 或属性前压缩，缩短文本长度。
  • 对比压缩前后确认语义未被改变。
去空白
把带缩进格式化的 JSON 粘贴进去，输出去除所有空格换行的单行版本，字段顺序与值完全不变。

❓ 常见问题（FAQ）

压缩会改变数据含义吗？
不会。Minify 只删除空白与换行，键、值、结构保持不变，是纯文本层面的瘦身。
压缩和 gzip 有什么区别？
压缩（minify）是去掉源码层空白，传输层 gzip / brotli 再对字节流整体压缩，两者互补：先 minify 减小明文体积，再 gzip 进一步压缩网络包。
