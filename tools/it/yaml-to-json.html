🔧 YAML 转 JSON 转换器

在 CI、API、前端配置里常需要把 YAML（如 GitHub Actions、docker-compose）转成 JSON。粘贴即转，可设缩进。

⚠️ 使用说明与注意事项
  • 转换结果可直接粘贴进 JSON 配置、REST 请求体或代码。
  • 支持常见 YAML 子集：映射、列表、标量（字符串/数字/布尔/null）；不支持锚点、多文档等高级特性。
  • 缩进可选 2/4 空格或 Tab，便于对接不同代码风格。
