▶️ 工具介绍 ▼

在线代码运行器是一款纯前端代码编辑与预览工具，支持 HTML、CSS、JavaScript 三种语言的实时编辑和运行。

🔥 功能特点

  • 三栏代码编辑（HTML / CSS / JS）
  • iframe 沙箱安全运行
  • console.log / warn / error 输出捕获
  • 实时预览模式（300ms 防抖）
  • 5 套内置示例代码
  • 一键复制 / 清空代码
  • 深色模式支持
  • 移动端自适应布局

🏠 使用场景

  • 快速测试 HTML/CSS/JS 代码片段
  • 前端学习与教学演示
  • 调试 UI 组件和动画效果
  • 代码面试在线手写验证

❓ 常见问题

代码运行安全吗？
代码在 iframe 的 sandbox 模式中运行，仅允许脚本执行，限制了对外部资源的访问，确保安全性。
为什么控制台没有输出？
请确认代码中使用了 console.log() 等方法，并且 iframe 已成功加载运行。如果控制台面板被折叠，点击面板标题即可展开。
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge）中使用
  • 计算结果仅供参考，请以实际应用场景为准
