🔄 IPv6 Address Converter

IPv6 Address Converter - Switch between compressed (::) and full 8-group IPv6 forms. Free, browser-only.

📐 工作原理与说明
IPv6 地址的展开、压缩与格式转换。
  • 结构：128 位，写作 8 组 4 位十六进制，以冒号分隔。
  • 压缩：连续的全 0 组可用 :: 代替（全地址中只能出现一次），每组前导 0 可省略。
  • 特殊地址：::1 环回、:: 未指定、fe80::/10 链路本地、fc00::/7 唯一本地。
  • 内嵌 IPv4：末 32 位可写作点分十进制，如 ::ffff:192.0.2.1。
⚠️ 使用说明与注意事项
  • IPv6 共 128 位，写成 8 组、每组 4 个十六进制数字，组间用冒号分隔。
  • 压缩规则：连续的全 0 段可替换为 ::（一个地址只能压缩一次），如 2001:db8:0:0:0:0:0:1 → 2001:db8::1。
  • 每组前导 0 可省略（1:0:0:0 写作 1::），但 :: 只能出现一次，否则无法唯一还原。

❓ 常见问题（FAQ）

:: 代表什么？
一段或多段全零的压缩写法，一个地址中只能用一次。
IPv4 映射地址长什么样？
有两种常见形式：::ffff:192.0.2.1（IPv4 映射的 IPv6 地址，用于双栈 socket）与 64:ff9b::192.0.2.1（NAT64 的知名前缀）。压缩表示时最后 32 位常写成点分十进制，展开成纯十六进制时容易看漏，核对规则时要特别留意。
