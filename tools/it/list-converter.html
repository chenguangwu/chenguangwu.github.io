🔄 List Converter

Convert between list formats (lines, CSV, JSON) in your browser — reshape data quickly.

📐 工作原理与说明
先按换行切分、逐行去首尾空白并剔除空行得到有效项；八种输出：comma 用「, 」连接、quote 每项加双引号且内部双引号转义、json 走 JSON.stringify(数组, null, 2)、sql 输出括号包裹的单引号列表且内部单引号写成两个单引号、csv 每项加双引号且内部双引号写成两个双引号并按换行连接、html 逐项输出转义后的 li 标签、pipe 用「 | 」连接、bullet 每行前加「- 」；统计项为有效行数
在不同格式的列表之间转换并做清洗。
  • 格式：逗号分隔、换行分隔、空格分隔、分号分隔、JSON 数组。
  • 清洗：支持去重、去空项、去首尾空白、排序与引号剥离。
  • 转义：值内若含分隔符，需引号包裹或转义，否则切分会出错。
  • 用途：批量数据处理、生成 SQL IN 子句、整理配置项。

💡 常见使用场景

  • 分隔符/CSV/数组互转。
  • 把数据库导出的一列 ID 转成 SQL 的 IN 子句：先转成逗号分隔并加引号，直接粘进查询里。
转换
`a,b,c` → 每行一项或 `["a","b","c"]`。

❓ 常见问题（FAQ）

引号怎么处理？
CSV 模式按需加引号。
字段本身含分隔符怎么办？
需要转义或用引号包裹，规则与 CSV 一致：含分隔符、引号或换行的字段用双引号包围，字段内的双引号写成两个双引号。若源数据分隔符不统一（混用中英文逗号、分号），应先统一再转换，否则列会被切错。
