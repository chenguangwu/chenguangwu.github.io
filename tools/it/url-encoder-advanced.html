🔐 URL 高级编解码

支持 URI / Component / Form / Query 多种模式。

📐 工作原理与说明

本编解码工具基于对应编码标准(RFC/规范)，纯前端本地处理，数据不上传。 工具名称：URL 高级编解码 - 免费编码解码工具，在线URL 高级编解码，免费使用。

📖 模式说明

encodeURIComponent: 编码所有特殊字符（除 A-Za-z0-9-_.!~*'()）

encodeURI: 保留 URL 结构字符 (:/?#[]@!$&'()*+,;=)

Form: 表单提交，空格 → +

Query: 与 Form 类似，用于查询字符串
