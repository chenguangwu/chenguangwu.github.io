📊 Code128 Barcode

📐 工作原理与说明
总模块数 = 11 × (1 起始符 + n 数据符号 + 1 校验符) + 13 终止符
校验位 C = (VStart + Σi=1…n Vi × i) mod 103
Code 128 的每个符号固定占 11 个模块（3 条 3 空，条宽之和为偶数、空宽之和为奇数），终止符特殊、占 13 个模块。校验位按加权模 103 计算：起始符权重为 1，其后第 i 个数据符号权重为 i，把加权和除以 103 取余即得校验符号值。输入为纯数字且长度为偶数时，本页自动改用 Code C，每两位数字压缩为一个符号，条码更短。

💡 常见使用场景

  • 物流与仓储标签：Code 128 支持全部 128 个 ASCII 字符、密度高，是快递面单与仓库周转箱的主流选择；纯数字且长度为偶数时自动切到 Code C，条码更短。
  • GS1-128 对接：在零售与医疗供应链中，Code 128 常以 FNC1 开头承载 GS1 应用标识符（如 (01) 全球贸易项目代码、(17) 有效期），需按 AI 规则解析而不是当作普通字符串。

❓ 常见问题（FAQ）

Code 128 的校验位怎么算？
加权模 103：起始符权重为 1，其后第 i 个数据符号权重为 i，把各符号值乘以权重求和后除以 103 取余，余数即校验符号的值。校验符与终止符都必须编码进条码，扫描器会自动核对其一致性。
Code 128 有 A/B/C 三套子集，怎么选？
A 含大写字母、数字与控制字符，B 含大小写字母与数字，C 专为纯数字设计（每两位压成一个符号，长度减半）。多数编码器会自动混合：数字段用 C、字母段用 A/B，通过切换码过渡，兼顾密度与表达力。
