🔑 Basic Auth 生成器

一键生成 HTTP Basic 认证所需的 Authorization 头与 URL 形式：用户名+密码 → Base64 令牌，支持中文用户名，供接口调试与开发使用。

📐 工作原理与说明

本开发工具在前端本地完成解析、转换与处理，代码不离开浏览器，遵循对应语法与格式规范。 工具名称：Basic Auth 生成器 - 一键生成 HTTP Basic 认证所需的。

URL 形式（curl / 浏览器访问）
