📚 深度解析：文件转 Base64（Data URI）

💡 常见使用场景

  • 把小图标 / 图片内联为 data URI，嵌入邮件或单文件 HTML，避免额外请求。
  • 上传前在浏览器本地预览文件内容，不把文件发到服务器。
  • 把证书、字体等二进制资源转成可粘贴的文本形式。
图片转 Data URI
选择一个 PNG 文件，工具在本地读取并输出 data:image/png;base64,iVBORw0KGgo... 形式字符串，可直接放入 <img src="..."> 或 CSS background。

❓ 常见问题（FAQ）

Data URI 有大小限制吗？
浏览器和邮件系统对 URL / data URI 长度有限制（常见几 MB 到几十 MB 不等），大文件应改用普通文件链接而非内联，否则可能截断或拖慢页面。
内联图片会影响性能吗？
Data URI 省了一次请求，但无法被浏览器单独缓存、且体积比原文件大约 33%，适合小图标；大图仍建议用独立文件 + 缓存。
