📚 算法说明

MD5

128位哈希值，由 Ronald Rivest 于 1991 年设计。已被证明不安全，存在碰撞攻击，仅可用于非安全场景的文件校验和数据完整性验证。

SHA-1

160位哈希值，由 NSA 设计。已不推荐用于安全场景，2017年已被证明存在碰撞攻击。仍在一些旧系统和 Git 中使用。

SHA-256 / SHA-384 / SHA-512

SHA-2 家族算法，分别产生 256/384/512 位哈希值。目前安全，广泛用于密码学、数字签名、区块链等场景。SHA-256 是最常用的选择。

CRC32

32位循环冗余校验，非加密哈希。计算速度极快，用于检测数据传输或存储中的意外错误。碰撞概率高，不能用于安全目的。常见于 ZIP、PNG 等格式。

Adler-32

32位校验和，由 Mark Adler 发明。非加密哈希。比 CRC32 更快但可靠性稍低。常用于 zlib 压缩和 rsync 等场景。

HMAC

基于哈希的消息认证码（Hash-based Message Authentication Code），使用密钥和哈希算法生成消息认证码。可同时验证数据完整性和真实性。常用于 API 签名、JWT 等场景。
