📊 Code39 Barcode

📐 工作原理与说明
每字符 = 9 元素（5 条 4 空），其中 3 宽 6 窄
格式：* + 数据 + *（* 为起止符）
Code 39 是最早的字母数字条码之一：每个字符用 9 个元素（5 条 4 空）表示，其中恰有 3 个宽元素、6 个窄元素，故得名「三九码」。宽窄比通常为 2:1 至 3:1，比例越大越易读。字符集含 A–Z、0–9、空格与 - . $ / + %，用 * 同时作起始与终止符。标准 Code 39 不强制校验位，需要时可用 Mod 43 校验。因密度较低（每字符约 9–16 模块），适合标签空间充裕的工业与物流场景。

💡 常见使用场景

  • 工业与资产标签：Code 39 支持大写字母与数字、无需校验位即可打印，广泛用于设备资产牌、仓库货架与军工（LOGMARS）标签。
  • 需要 Mod 43 校验的场景：标签内容较长或打印质量不稳定时，可开启 Mod 43 校验位——把每个字符的值求和后除以 43 取余，把余数对应字符追加到末尾，能拦住大部分误读。

❓ 常见问题（FAQ）

Code 39 一定要加 * 号吗？
标准 Code 39 不强制校验位；需要时可用 Mod 43。与 EAN/UPC 不同，它的校验位是可选的，由应用方决定是否启用——这也是同一串数据在两个系统里长度可能差一位的原因。
能编码小写字母吗？
标准 Code 39 只有大写 A–Z、0–9、空格与 - . $ / + % 共 43 个字符；小写需借助扩展 Code 39（用两个字符组合表示一个 ASCII 字符），条码长度会明显增加。若必须支持小写，建议改用 Code 128。
