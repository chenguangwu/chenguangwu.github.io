📖 使用说明

TOML 语法简介

  • 键值对：key = "value"
  • 字符串：用引号包裹，支持多行字符串 """
  • 数字：整数、浮点数、科学计数法
  • 布尔值：true / false
  • 数组：[1, 2, 3]
  • 表(section)：[table] 表示一个对象
  • 数组表：[[array_of_tables]]
  • 注释：# 开头
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge）中使用
