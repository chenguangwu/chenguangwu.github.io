📄 TOML Format

📐 工作原理与说明
先把 TOML 文本解析为对象，再递归序列化：把当前层级的键分为「普通值」与「表（值为非数组的对象）」两组，先逐行输出普通值（键 = 格式化后的值），再逐个处理表——拼出完整键名（有前缀时以前缀加点号连接），若已有输出则先补一个空行，输出方括号包裹的表头，然后递归序列化该表的内容
TOML 配置文件的格式化与校验。
  • 语法：[table] 表示表，key = value 表示键值，数组用 []，内联表用 {}。
  • 字符串：基础字符串用双引号、字面字符串用单引号、多行用三引号。
  • 格式化：统一缩进与空行，保持语义不变，便于阅读与 diff。
  • 用途：整理 Cargo.toml、pyproject.toml 等配置文件。

Format and beautify TOML in your browser — consistent, readable configuration files.

📖 使用说明

TOML 语法简介

  • 键值对：key = "value"
  • 字符串：用引号包裹，支持多行字符串 """
  • 数字：整数、浮点数、科学计数法
  • 布尔值：true / false
  • 数组：[1, 2, 3]
  • 表(section)：[table] 表示一个对象
  • 数组表：[[array_of_tables]]
  • 注释：# 开头

❓ 常见问题（FAQ）

TOML 与 YAML 比？
TOML 对配置更直观，类型明确。
为什么格式化后键的顺序变了？
TOML 要求「表必须位于所有普通键之后」，格式化器会把根级标量提到前面、再按层级排列表头，所以看起来顺序被重排。这是格式约束而非数据丢失。若需要人眼可读的固定顺序，可在源文件中就按层级组织，或用注释分段标记。
