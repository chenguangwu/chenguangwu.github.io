🌿 Git 命令速查表

忘记某个 Git 操作怎么写？输入关键词（如 rebase / 回退 / 分支）即时过滤命令表，点“复制”拿走。

📐 工作原理与说明

Git 是分布式版本控制系统,代码在四个区域间流动:

  • 工作区(Working Tree)→ 暂存区(index, git add)→ 本地仓库(git commit)→ 远程仓库(git push)。
  • 常用:init / clone / status / diff / branch / switch / merge / rebase / cherry-pick / stash / log。

merge 保留分支分叉历史;rebase 将提交"重放"成线性历史(已推送到公共分支的提交勿随意 rebase)。.gitignore 控制哪些文件不被跟踪。

本开发工具在前端本地完成解析、转换与处理，代码不离开浏览器，遵循对应语法与格式规范。 工具名称：Git 命令速查表。

⚠️ 使用说明与注意事项
  • rebase 会改写提交历史，协作分支上请谨慎使用；个人分支或 feature 分支更合适。
  • reset --hard 会丢失未提交改动，必要时先用 stash 暂存。
  • 推送前建议先 pull / fetch 解决冲突，避免强制 push 覆盖他人提交。

🌿 工作流建议

Feature 分支：switch -c feat → 开发 → commit → push -u → PR/MR → merge。

同步主干：switch main → pull → switch feat → rebase main → push --force-with-lease。

回退错误：未推送用 reset/revert；已推送用 revert 生成新提交，安全可追溯。
