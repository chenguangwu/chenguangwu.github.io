🧬 Hash Multi

📐 工作原理与说明

Hash Multi is available directly in your browser, with no data uploaded.

  • 支持 MD5(128b)/ SHA-1(160b)/ SHA-256 / SHA-512 / SHA-3,经 Web Crypto SubtleCrypto.digest 计算。
  • 用途:文件完整性校验、去重、内容指纹。

⚠️ 安全提示:MD5、SHA-1 已被证明可碰撞,勿用于数字签名或口令存储;口令应使用 bcrypt / Argon2 等慢哈希。本工具纯前端,数据不上传。

一键计算多种哈希：MD5 / SHA-1 / SHA-256 / SHA-512 / CRC32，支持多算法同时输出与大小写切换。SHA 走浏览器原生 crypto.subtle，全程本地。

哈希是单向不可逆函数，用于完整性校验与指纹；存储密码须加盐并使用慢哈希(bcrypt/argon2)。
