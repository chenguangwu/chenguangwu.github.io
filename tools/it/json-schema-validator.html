📄 JSON Schema Verifier

Validate JSON against a JSON Schema in your browser — catch structural errors fast.

📐 工作原理与说明
分别解析模式与数据两处 JSON，模式解析失败或数据为 null 时提示 JSON 格式错误。随后从根节点递归校验：先判断值是否符合模式声明的类型，不符合即记为「类型不匹配 + 路径 + 期望类型」并停止下探；类型为对象时要求值确实是非数组的对象（否则记为不是对象），逐项检查必填字段列表中每个键是否存在于数据中（缺失记为缺少必填字段），再对属性表中同时存在于数据中的键继续递归校验。收集到任何问题时逐条列出并标注未通过，全部通过则提示校验通过
JSON Schema 是一种用 JSON 描述数据结构的规范：用 type 约束字段类型、required 标记必填、properties 定义子字段、additionalProperties 控制是否允许额外字段。本工具在浏览器内解析 Schema 与待校验 JSON，逐条比对约束并定位首个错误位置，数据不出本地。

❓ 常见问题（FAQ）

Schema 用哪个规范？
常用 draft-07 或 2020-12，注意版本差异。
校验通过了就安全吗？
只说明结构合规，不代表业务合法。Schema 能约束类型、必填与范围，但无法表达「结束时间必须晚于开始时间」这类跨字段规则，也不做权限判断。校验通过后仍需按输出上下文做转义与参数化查询，防止注入。
