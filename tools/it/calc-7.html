🔎 JSON Path Extractor

Extract values from JSON by dot-path (e.g. user.name).

📐 工作原理与说明
JSONPath 求值：把路径按 . 与 [n] 切分为键或下标序列，从根对象 $ 起逐级下钻。当前值不是对象或数组时提示该路径无法继续访问；数组时下标必须是非负整数且不越界（越界提示数组下标越界）；对象时键必须存在（不存在提示键不存在）。每步把已走过的路径拼成可读轨迹（数字下标写作 [n]、字符串键写作 .key）。结果按所选格式输出为美化缩进的 JSON 或紧凑形式；输入 JSON 解析失败时显示解析错误
用路径表达式从 JSON 中快速定位并提取字段。
  • 语法：$ 表示根，点号取属性（$.a.b），方括号取下标（$.list[0]）。
  • 通配符：* 遍历数组全部元素或对象全部成员，配合下标可批量取值。
  • 求值：从根对象逐段下钻，任一段缺失即返回 undefined（可配置严格或宽松模式）。
  • 用途：在大型 API 响应中定位字段、做数据抽样与接口调试。

📌 路径语法
  • 点号路径：user.name 等价于 user['name']。
  • 数组下标：tags[0]、items[1].id。
  • 根路径：直接留空可查看完整 JSON。
  • 仅支持简单点号与方括号路径，不支持通配符或过滤表达式。

❓ 常见问题（FAQ）

$ 表示什么？
$ 代表根对象，后续用 . 或 [] 下钻。
键名里有特殊字符怎么办？
用方括号加引号：$['user-name']、$['a.b']。点号语法只支持合法标识符（字母、数字、下划线且不以数字开头），遇到连字符、空格、点号或以数字开头的键名必须改用方括号形式，否则会被当作层级解析而取不到值。
