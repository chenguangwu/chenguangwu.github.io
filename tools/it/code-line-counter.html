💻 Code Line Counter

📐 工作原理与说明
按所选语言（选择自动时按 JavaScript 处理）取该语言的行注释规则与块注释规则，逐行扫描：去除空白后为空的行计入空行；处于块注释中时本行计入注释行，并在本行找到块注释结束符时退出块注释状态（结束符之后还有内容则按剩余内容重新判定）；否则先判断是否以某个行注释符开头，再判断是否进入块注释——命中块注释开始符且其后同一行内没有结束符时进入块注释状态。既不是注释也未进入块注释的行计入代码行。总行数为全部行数，代码占比 = 代码行 ÷ 总行数 × 100%（总行数为 0 时取 0），保留 1 位小数
统计代码的总行数、代码行、注释行与空行。
  • 维度：总行数、代码行、注释行、空行，可按语言或目录汇总。
  • 注释识别：行注释（//、#）与块注释（/* */、三引号），依语言规则判定。
  • 陷阱：字符串或正则字面量中出现的 //、/* 不应被误判为注释。
  • 解读：行数可用于规模估算，但不等于工作量或复杂度。

💡 常见使用场景

  • 统计项目代码行/注释/空行。
  • 项目规模度量：统计有效代码行、注释行与空行，估算工作量或跟踪重构后的删减量。

❓ 常见问题（FAQ）

算注释行吗？
可单独统计注释与空行。
行数能代表开发效率吗？
不能，它只反映代码规模。删除冗余代码会减少行数却提升质量，用不同语言或风格实现同一功能行数也可能相差数倍。合理的用法是看趋势与构成（注释率、单文件长度），而不是拿它考核产出。
