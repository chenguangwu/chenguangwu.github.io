📄 代码行数统计

粘贴代码或选择代码文件，自动按扩展名匹配语言注释规则（//、/* */、#、<!-- -->、-- 等），统计总行数、代码行、注释行与空行。

⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge）中使用
  • 处理结果请自行核对后再用于生产环境
