📖 身份证号码结构说明

18位居民身份证号码由以下四部分组成

号码结构

  • 第1-6位：地址码（省、市、县）
  • 第7-14位：出生日期码（YYYYMMDD）
  • 第15-17位：顺序码（奇数分配给男性，偶数分配给女性）
  • 第18位：校验码（按 ISO 7064:1983 MOD 11-2 算法计算）

校验码算法

1. 将前17位数字分别乘以权重因子 [7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2]

2. 将乘积之和除以 11，得到余数

3. 根据余数查表得到校验码：['1','0','X','9','8','7','6','5','4','3','2']
