🧪 Hypothesis Test

📋 Z 检验公式

Z = (x̄ − μ₀) / (σ / √n)
步骤：
1. H₀: μ = μ₀；H₁: μ ≠ / < / > μ₀
2. 计算检验统计量 Z
3. 求 p 值 = P(|Z| ≥ |z| | H₀)
4. 若 p < α，拒绝 H₀
适用条件：总体标准差已知，或大样本（n ≥ 30）。
