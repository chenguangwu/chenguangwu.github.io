🧪 Hypothesis Test

📐 工作原理与说明
单样本 Z 检验（总体标准差 σ 已知）
标准误 SE = σ ÷ √n
检验统计量 Z = (x̄ − μ₀) ÷ SE
p 值：双侧 p = 2·min(Φ(Z), 1−Φ(Z))｜左尾 p = Φ(Z)｜右尾 p = 1−Φ(Z)
临界值：双侧 z* = Φ⁻¹(1−α/2)｜左尾 Φ⁻¹(α)｜右尾 Φ⁻¹(1−α)
判定规则：p < α → 拒绝 H₀；p ≥ α → 不拒绝 H₀
用样本数据检验关于总体的假设是否成立。
  • 流程：提出原假设 H0 与备择假设 H1 → 选检验统计量 → 计算 p 值 → 与显著性水平 α 比较。
  • z 检验：σ 已知或大样本时用 z = (x̄ − μ₀)/(σ/√n)。
  • t 检验：σ 未知且小样本时用 t = (x̄ − μ₀)/(s/√n)，自由度为 n−1。
  • 判定：p < α 则拒绝 H0；需留意第一类错误 α（弃真）与第二类错误 β（取伪）。

📋 Z 检验公式

Z = (x̄ − μ₀) / (σ / √n)
步骤：
1. H₀: μ = μ₀；H₁: μ ≠ / < / > μ₀
2. 计算检验统计量 Z
3. 求 p 值 = P(|Z| ≥ |z| | H₀)
4. 若 p < α，拒绝 H₀
适用条件：总体标准差已知，或大样本（n ≥ 30）。

📚 深度解析：单样本 Z 检验

💡 常见使用场景

  • 已知总体方差时检验样本均值是否等于假设值。
  • 判断改版是否真的有效：把改版前后的数据代入检验，看 p 值是否小于显著性水平，而不是只看数值上有差异。
Z 检验
μ0=100,σ=15,n=36,x̄=105：Z=(105−100)/(15/√36)=2.0，p≈0.045 <0.05 → 拒绝原假设。

❓ 常见问题（FAQ）

Z 检验与 t 检验？
已知 σ 用 Z；σ 未知用样本 s 且小样本用 t。
p 值小于 0.05 就说明有效吗？
只能说「在总体无差异的假设下，观察到这么极端结果的概率不足 5%」。它不等于「有 95% 概率有效」，也不代表效果量足够大。样本量很大时，微小到没有业务价值的差异也会显著；因此应同时看效应量与置信区间，并在实验前就定好判定标准。
