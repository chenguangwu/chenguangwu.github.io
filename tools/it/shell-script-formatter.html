⌥ Shell Script Format

📐 工作原理与说明
按行遍历脚本并维护缩进深度。先处理 here 文档：命中「重定向符加定界符」的行原样输出并进入文档态，直到出现与定界符相同（或去掉引号后相同）的行才退出，期间所有行原样保留。普通行去掉首尾空白后处理；连续空行只保留一个。本行缩进判据：以 fi、done、esac 开头，或以 else、elif 开头，或整行是分号类终止符时，本行深度减 1（不小于 0）。输出后调整深度：以 if、for、while、until、case 开头，或行尾为左花括号，或行尾是 then、do，或整行就是左花括号时深度加 1；case 分支模式行以右括号结尾时深度再加 1；整行是 fi、done、esac 或以右花括号开头或整行就是右花括号时深度减 1；分号类终止符时深度再减 1。最终按「缩进单位 × 深度 + 去空白后的行」拼接输出

❓ 常见问题（FAQ）

格式化会改行为吗？
不，仅调整空白。
为什么格式化后脚本报错了？
Shell 对空白极其敏感：if [ ... ] 里方括号两侧必须有空格、变量赋值等号两边不能有空格、续行符 \ 后不能有任何字符（包括空格）。格式化工具若不熟悉这些规则就可能改坏。因此格式化后必须 shellcheck 检查、并在测试环境实跑一遍再上线。
