🔄 JSON to Code

📐 工作原理与说明
先 JSON.parse 解析输入，解析失败则输出错误信息；按目标语言分派生成器：TypeScript / Go / C# / Java / Kotlin / Rust / Python / Protobuf，根类型名取设定值（默认 Root）；类型按 JSON 值形态映射（对象→结构体或类、数组→列表、字符串→string、数字按是否含小数取整型或浮点、布尔→bool、null→可空类型）；根节点是数组或标量时生成切片/类型别名（含元素类型定义），是 null 时给出明确提示；键名按目标语言惯例转换（camelCase / PascalCase / snake_case），被改名的字段附原键名注释或 serde/json 映射；生成结果再做语法高亮写入输出区
由 JSON 样本生成目标语言的类型定义。
  • 输出：TypeScript 的 interface、Go 的 struct（带 json tag）、Python 的 dataclass/TypedDict 等。
  • 嵌套：嵌套对象生成子类型，数组生成元素类型。
  • 命名：按目标语言惯例转换命名风格（如 snake_case → camelCase）。
  • 后续：生成结果为基础骨架，校验规则与注释需补充。

❓ 常见问题（FAQ）




嵌套对象怎么转？
递归生成嵌套接口/结构体。


生成的字段名不符合规范怎么办？
多数生成器支持注入命名规则：TS 通常保留原样或转 camelCase，Go 需要转 PascalCase 并加 json tag，Python 的 dataclass 则要注意保留字冲突。生成后应统一跑一次格式化与 lint，并对 nullable 字段确认用的是指针还是值类型。
