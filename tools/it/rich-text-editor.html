📝 富文本编辑器

所见即所得（WYSIWYG）在线编辑器：支持加粗、斜体、下划线、标题层级、有序/无序列表、超链接、表格、文字与背景颜色、对齐方式、引用与代码块；实时统计字符数、词数、段落数；可一键导出 HTML 源码、纯文本或 Markdown，也支持导入本地 HTML 文件继续编辑。全部在浏览器本地完成，内容不上传服务器。

📐 工作原理与说明

编辑区基于浏览器原生 contentEditable 与 document.execCommand 实现，不依赖任何富文本框架；Markdown 导出由内置规则对 HTML 节点做结构化转换；文件导入使用 FileReader 在本地读取，全流程无网络请求。工具名称：富文本编辑器 - 所见即所得在线编辑器。

⚠️ 使用说明与注意事项
  • 本工具纯前端运行，编辑内容不会上传到服务器，刷新页面会丢失，请先导出保存
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge）中使用，快捷键 Ctrl+B / Ctrl+I / Ctrl+U 可用
  • Markdown 导出为常用语法的近似转换（标题、列表、加粗、斜体、链接、引用、代码），复杂表格可能需手工微调
