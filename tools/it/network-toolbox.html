📐 工作原理与说明
全部工具在浏览器本地运行：网络请求用 fetch/WebRTC/Image 发起，超时统一由 AbortController 或定时器控制；结果只写入当前页面与 localStorage，不上传、不埋点。可达性类工具只能判断网络层是否接受请求，无法读取 HTTP 状态码（no-cors 返回 opaque 响应），结论均为启发式推断；需要密钥或自有服务端的 DNS 出口查询在未配置时明确降级，不伪造数据。

13 client-side network diagnostics: IP lookup, reachability, WebRTC leak, NAT, CDN, speed test, browser fingerprint and service status.

T1 多源 IP 查询

空态

展示公网 IP、版本、地区、ISP、ASN、时区与数据来源。按 ipwho.is → ipapi.co → api.ip.sb → ipify 顺序回退，IPv6 单独探测。

尚未查询，点击「刷新查询」开始。

T2 任意 IP 查询

空态

输入 IPv4/IPv6 查询归属，先校验格式，合法才发请求；主源失败回退备源。支持回车触发。

尚未查询。

T3 本机内网 IP

空态

用无 STUN 的 WebRTC host candidate 收集本机内网地址；浏览器可能返回 mDNS 混淆地址，会单独标注。

需按钮点击触发（浏览器手势要求）。3 秒后自动关闭连接。

尚未收集。

T4 目标站点可达性

空态

并发探测 Google / GitHub / Cloudflare / OpenAI 的 favicon，记录可达性与近似耗时，并发上限 5。

favicon 改版或 CDN 拦截可能导致误判，结果仅供参考。

尚未探测。

T5 自定义 URL 可达性

空态

输入 URL（无协议自动补 https://），先用 fetch no-cors 判断网络层可达性，失败回退 favicon 图片探测。

no-cors 无法读取状态码，只能判断请求是否被网络层接受。

尚未探测。

T6 WebRTC 泄露检测

空态

用公共 STUN 收集全部 ICE 候选，解析 IP / 类型 / 协议，与 T1 公网 IP 比对，并列出内网或 mDNS 地址。

需按钮点击触发；5 秒后关闭连接。URL 参数 stun= 可自定义 STUN。

尚未检测。建议先运行 T1 以获得公网 IP 用于比对。

T7 NAT 类型推断

空态

向 3 个公共 STUN 分别取 srflx 映射的 IP:端口，按端口是否一致推断锥形 / 对称 NAT。

基于 STUN 的启发式推断，非精确检测，受多出口与运营商 NAT 层级影响。

尚未推断。

T8 DNS 出口查询

需配置

需自有域名与权威 DNS 日志才能反映递归解析器出口 IP；未配置时明确降级，不伪造结果。

降级行为：本页默认不配置任何自有域名接口，点击只会显示配置说明，不会生成假数据。

需配置自有域名后才能使用。

T9 CDN 边缘节点探测

空态

请求同一 CDN 的静态小文件，读取 cf-ray / x-served-by / x-cache 等响应头；读不到时退化为最小 RTT 延迟指纹。

CORS 可能隐藏 CDN 专有头，结果可能不完整。

尚未探测。

T10 代理分流规则测试

空态

分别探测国内组与国外组站点，按通过数推断可能的代理模式，并给出逐项明细。

启发式推断，非读取系统代理配置；favicon 可达性受 CDN 与站点改版影响。

尚未测试。

T11 下行 + 延迟测速

空态

用 Cloudflare 测速端点：预热 256KB → 10 次小请求取延迟中位数与抖动 → 1MB/5MB/10MB 多轮下载取中位数。

非专业测速，受节点与网络影响；测速时请保持页面在前台。

尚未测速。

T12 浏览器指纹

空态

本地采集 UA、语言、时区、屏幕、CPU、Canvas 与 WebGL 特征，计算 SHA-256 哈希。

全部本地计算、不上报。指纹可能被站点用于追踪，请勿将其视为匿名标识。

尚未计算。

空态

聚合 GitHub / Cloudflare / Vercel / npm 的公开状态 JSON，5 秒超时，失败显示 unknown。

各服务状态接口 CORS 策略可能变化；读不到时显示 unknown，不猜测状态。
