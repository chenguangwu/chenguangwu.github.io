🔧 YAML 转 TOML 转换器

在 Rust/Go 项目配置、pyproject、Cargo.toml 等场景常需要在 YAML 与 TOML 之间迁移。粘贴 YAML，立即得到结构等价的 TOML。

📐 工作原理与说明

递归将 YAML 结构转为 TOML：映射 → [section] 表（嵌套映射用 [a.b] 点分层级）；列表 → 数组；标量按类型输出（字符串加引号、数字/布尔直出）。YAML 锚点/合并键先展开再转换。

  • TOML 不支持 YAML 的任意键顺序语义，表需先于引用出现。
  • 纯前端转换，数据不离开浏览器；粘贴即转，支持嵌套与注释保留策略。
⚠️ 使用说明与注意事项
  • 转换按结构等价进行：YAML 映射→TOML 表，YAML 列表→TOML 数组；嵌套映射会展开为 [section] 小节。
  • TOML 不支持 YAML 的锚点/合并（&anchor、*alias）与多行折叠，这类高级语法会被忽略或报错。
  • 字符串中含特殊字符（冒号、#、方括号等）会自动加引号以保证 TOML 合法。

📋 YAML ↔ TOML 对照

YAMLTOML
key: valuekey = "value"
list:\n - a\n - blist = ["a", "b"]
[a, b, c]arr = ["a", "b", "c"]
parent:\n child: 1[parent]\nchild = 1

本工具支持常见子集（映射、列表、标量、注释、嵌套小节）；极复杂 YAML 建议先用 JSON 中转。
