😊 Emoji 选择器

写文案、注释、社交内容时想快速插入 emoji？输入中文或英文关键词（如“笑”“fire”“爱心”），点一下就复制到剪贴板。

📐 工作原理与说明

内置 Unicode Emoji 数据集（含 CLDR 分组与多语言关键词），前端按关键词或分类实时过滤，点击即复制 Emoji 字符或其码点（如 U+1F600）。复杂 Emoji 可由 ZWJ（零宽连接符 U+200D） 序列组合（如家庭、职业组合）。

  • 数据随 Unicode 版本更新（15.x 已超 3000 个 Emoji）。
  • 纯前端本地检索，不上传；复制结果依赖系统字体回退渲染。
⚠️ 使用说明与注意事项
  • 支持中英文关键词，按 emoji 名称与中文释义模糊匹配；留空显示全部。
  • 点击任意 emoji 即复制到剪贴板（兼容无 HTTPS/剪贴板 API 的环境，使用 execCommand 兜底）。
  • 内置约 180 个常用 emoji；更多字符建议用系统输入法的 emoji 面板。
