🔄 Git Flow 工作流

Git Flow 是一种适合发布型项目的分支模型，包含 5 种分支：master、develop、feature、release、hotfix。

1
初始化 Git Flow：
git flow init
2
开始新功能： 从 develop 创建 feature 分支
git flow feature start my-feature
3
完成功能： 合并回 develop，删除 feature 分支
git flow feature finish my-feature
4
开始发布： 从 develop 创建 release 分支
git flow release start 1.0.0
5
完成发布： 合并到 master 和 develop，打 tag
git flow release finish 1.0.0
6
紧急修复： 从 master 创建 hotfix 分支
git flow hotfix start hotfix-1.0.1

🐙 GitHub Flow 工作流

GitHub Flow 是更简洁的工作流，适合持续部署的项目。只有 master 和 feature 分支。

1
从 master 创建分支：
git checkout -b feature/my-feature
2
提交修改：
git add . && git commit -m "feat: 添加新功能"
3
推送到远程：
git push -u origin feature/my-feature
4
创建 Pull Request：
在 GitHub 网页上发起 PR，请求团队成员 Code Review。
5
评审并合并：
评审通过后合并到 master，可使用 Squash merge 保持历史整洁。
6
删除分支并部署：
git branch -d feature/my-feature
合并后自动部署到生产环境。
