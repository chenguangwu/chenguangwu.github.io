📄 YAML to XML Converter

📐 工作原理与说明
把 YAML 转换为 XML。
  • 映射：YAML 的映射键成为 XML 元素名，序列生成重复的同名元素。
  • 转义：XML 保留字符（& < > 等）必须转义。
  • 命名：含空格或以数字开头的键需转换为合法的 XML 元素名。
  • 用途：与仅接受 XML 输入的系统对接。

YAML to XML Converter - Paste YAML and convert it to XML (@key as attribute, #text as element text). Free, browser-only.

⚠️ 使用说明与注意事项
  • YAML 中以 @ 开头的键会转为 XML 属性（如 @id → id="..."），#text 键转为元素文本。
  • 列表会展开为多个同名元素；标量直接作为元素文本。
  • 转换按约定进行，复杂结构建议人工核对属性/元素的选择。

❓ 常见问题（FAQ）

多文档 YAML 怎么转？
需指定文档或逐文档转换。
为什么转换失败或结果异常？
常见原因：YAML 里有锚点与别名（需先展开）、多文档分隔（需指定取哪一个），或非字符串键（XML 元素名必须是合法名称，数字或含特殊字符的键无法直接映射）。转换前应先把 YAML 规整为「字符串键 + 无锚点 + 单文档」的形式。
