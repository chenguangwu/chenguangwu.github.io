📖 加密规则

  • 规则 1：同行字母 — 两个字母在同一行，各取右边的字母（最后一个取第一个）
  • 规则 2：同列字母 — 两个字母在同一列，各取下边的字母（最后一个取第一个）
  • 规则 3：矩形对角 — 两个字母不在同行同列，取对方所在列的同行字母
  • 特殊：相同字母 — 两个相同字母，在中间插入 X（或 Q），再分组
  • 特殊：奇数长度 — 明文长度为奇数时，末尾补 X（或 Q）
  • 特殊：I/J 合并 — I 和 J 视为同一字母，通常将 J 替换为 I

📚 算法原理

什么是普莱费尔密码？

普莱费尔密码（Playfair cipher）是第一种实用的双字母替换密码，由查尔斯·惠斯通于1854年发明，以其朋友莱昂·普莱费尔的名字命名。它在第二次布尔战争和第一次世界大战中被广泛使用。

密码矩阵构造

1. 选择一个关键词（如 "PLAYFAIR"）
2. 去除重复字母（"PLAYFIR"）
3. 将字母填入 5×5 矩阵
4. 剩余位置按字母表顺序填入剩余字母
5. I 和 J 合并到同一格（通常将 J 替换为 I）

加密步骤

1. 将明文中的 J 替换为 I
2. 将明文按两个字母一组划分
3. 如果一组中两个字母相同，在中间插入 X
4. 如果总长度为奇数，末尾补 X
5. 对每一组应用三条规则之一进行加密

历史意义

普莱费尔密码是第一个广泛使用的双字母替换密码。与单字母替换密码相比，它的安全性大大提高，因为频率分析针对的是单个字母，而普莱费尔有 26×26=676 种可能的字母对，使得频率分析变得困难得多。

安全性

虽然比单字母替换安全，但普莱费尔密码仍可被破解：

• 只需几百个字母的密文即可通过频率分析破解
• 已知明文攻击非常有效
• 现代计算机可以在几秒钟内暴力破解所有可能的密钥

变体

• 双字母替换：6×6 矩阵，包含数字
• 四方密码：使用四个 5×5 矩阵
• 希尔密码：基于线性代数的多字母替换
