🎲 Random String Generator

📐 工作原理与说明
生成指定字符集的随机字符串。
  • 字符集：大小写字母、数字、符号可自由组合，并支持排除易混字符（如 0/O、l/1）。
  • 安全：用于口令或令牌时必须用 crypto.getRandomValues，而非 Math.random。
  • 强度：熵 ≈ 长度 × log₂(字符集大小)，熵越高越难被猜到。
  • 用途：临时口令、API 令牌、验证码与前端临时标识。

⚠️ 使用说明与注意事项
  • 使用浏览器 crypto.getRandomValues 生成密码学安全的随机值；不支持时回退到 Math.random。
  • 长度上限 128、数量上限 50，避免一次性生成过多造成卡顿。
  • 符号集含常见安全符号；如需自定义可手动编辑结果。

❓ 常见问题（FAQ）

用 crypto 随机吗？
安全场景应使用密码学安全随机数。
为什么不能用 Math.random 生成？
因为 Math.random 用的是可预测的伪随机算法，攻击者观测到若干输出后可反推内部状态，进而预测后续所有值。凭证、口令、令牌这类场景必须使用 crypto.getRandomValues（浏览器）或 secrets 模块（Python）等密码学安全随机源。
