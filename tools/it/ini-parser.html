📝 INI Parser

📐 工作原理与说明
解析：跳过空行与以 ; 或 # 开头的注释行；以 [ 开头且以 ] 结尾的行视为节名并新建该节的空对象；其余行取第一个 = 作为键值分隔符，左侧为键、右侧为值，均去首尾空白；有当前节时写入该节，否则写入根级。反向输出：值为普通对象时先写 [节名]，再逐行写「子键 = 值」，节末补一个空行；非对象直接写「键 = 值」，最后整体去首尾空白
本开发工具在前端本地完成解析、转换与处理，代码不离开浏览器，遵循对应语法与格式规范。 工具名称：INI 解析器 - 免费开发工具，在线INI 解析器，免费使用。

Parse INI configuration into sections and key-value pairs, and serialize it back.

❓ 常见问题（FAQ）

重复键怎么办？
后值覆盖前值（视实现）。
INI 有标准格式吗？
没有正式标准，只有广泛约定：方括号表示节、= 或 : 分隔键值、# 或 ; 表示注释。不同实现在引号处理、大小写敏感性、是否支持嵌套与多行值上差异很大；跨语言交换配置时建议改用 JSON / YAML / TOML。
