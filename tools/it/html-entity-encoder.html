🔤 HTML Entity Encoder

Encode and decode HTML entities (named and numeric) in your browser for safe markup and text.

📐 工作原理与说明
按顺序依次替换：与号替换为对应实体，小于号替换为对应实体，大于号替换为对应实体，双引号替换为对应实体，单引号替换为数字实体形式。替换后的结果写入输出框
HTML 实体的编码与解码。
  • 安全输出：把用户内容插入 HTML 时必须转义 & < > " '。
  • 属性上下文：属性值需额外注意引号处理，单引号包裹的属性也要转义单引号。
  • 局限：实体转义不能替代富文本净化，应配合白名单过滤（如 DOMPurify）。
  • 上下文：HTML 文本、属性、JS、CSS、URL 各有不同的转义规则，不可混用。

❓ 常见问题（FAQ）

命名实体和十进制实体能混用吗？
可以，浏览器都能解析。
空格和换行需要转成实体吗？
通常不需要。普通空格在 HTML 中会被折叠为一个，只有需保留连续空格时才用 &nbsp;；换行需用 <br> 或 CSS 的 white-space 控制，转成 &#10; 并不会产生换行效果。批量转义时应只处理危险字符与确实需要保形的空白。
