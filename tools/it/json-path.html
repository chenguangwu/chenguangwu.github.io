表达式说明示例
$根节点$ - 整个 JSON
@当前节点@.price - 当前节点的 price
.property子属性$.user.name
..property递归查找$..id - 所有层级的 id
*通配符$.store.* - store 下所有子元素
[index]数组索引$.items[0]
[start:end]数组切片$.items[1:3]
[?(expr)]过滤表达式$.items[?(@.price>10)]
length()数组长度$.items.length()
