📄 TOML to YAML Converter

📐 工作原理与说明
TOML 解析：逐行去空白，跳过空行与 # 注释（# 的判定需避开成对双引号内的内容）；[节名] 按 . 逐级建立嵌套对象并设为当前表，[[数组名]] 同名数组追加一个新元素并设为当前表（路径中若碰到数组表则下钻到它的最后一个元素，子表才不会丢）；其余行取第一个 = 分隔键与值，键按 . 形成点号路径，值先剥掉行尾 # 注释再解析；值以 [ 或 { 开头且括号未闭合时继续吞并后续行，支持多行数组。值解析：双引号串单遍反转义（\\ \n \t \r \" 一次映射，避免 \\temp 被拆成反斜杠+制表符），true/false 转布尔，纯整数转 parseInt，纯小数转 parseFloat，[ ] 内按顶层逗号（跳过引号与嵌套括号内的逗号）递归解析为数组，{ } 内联表按 a=1 递归解析为映射。输出：键名匹配 ^[A-Za-z0-9_-]+$ 时原样写，否则加双引号并转义反斜杠与引号；字符串含反斜杠、换行、制表符或 YAML 特殊字符时加双引号并转义，数组元素是映射时按 - 键: 值 逐行展开（子表/子数组继续缩进递归），同一表内先写标量键再写子表，可选按键名字典序排序
把 TOML 转换为 YAML。
  • 映射：TOML 的表与键值分别转为 YAML 的映射与标量，数组转为序列。
  • 缩进：YAML 以缩进表达层级，只能使用空格，不能使用 Tab。
  • 类型：形如 true、0123 的值需加引号，避免被 YAML 误推断类型。
  • 用途：配置文件在两种格式之间迁移。

⚠️ 使用说明与注意事项
  • TOML 的 [section] 表转为 YAML 嵌套映射；[[数组表]] 转为 YAML 列表，每个元素是一个映射。
  • TOML 的数组（[1,2,3]）转为 YAML 行内或块列表。
  • 时间戳等 TOML 专有类型会按字符串保留，避免信息丢失。

❓ 常见问题（FAQ）

两者都支持注释吗？
都支持，但转换需约定注释去留。
转换后注释没了怎么办？
这是常见现象：多数转换器基于解析后的数据结构再序列化，注释在解析阶段就被丢弃了。若注释承载重要说明，应在转换后手工补回，或保留 TOML 作为唯一数据源、把 YAML 当作生成产物（并在 CI 中自动重新生成，禁止手改）。
