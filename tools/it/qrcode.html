📐 工作原理与说明

QR 码由定位与编码两类图案组成:

  • 定位图案:三个角上的 Finder(回字)、Alignment、Timing,用于扫码定位与校正。
  • 编码模式:数字 / 字母数字 / 字节(UTF-8)/ 汉字,自动选最短以省空间。
  • 纠错等级 L / M / Q / H 可恢复约 7% / 15% / 25% / 30% 的损毁。
  • 版本 1–40 对应模块 21×21 → 177×177;含 Reed-Solomon 纠错与掩码优化。

纯前端生成,扫码即可读取,无需联网。

❓ 常见问题（FAQ）

纠错级别有什么用？
纠错级别越高，二维码容污损、可遮挡比例越大（L≈7% / M≈15% / Q≈25% / H≈30%），但同等信息量下图案更密；印刷物料建议用较高纠错。
二维码能存多少内容？
容量随版本增大，纯数字最多约 7000+ 字符，字节模式约 2900+ 字节；内容越长密度越高、越小越难扫，长文本建议改用短链接。
