📝 String Length Counter

Count characters, bytes, lines, words and spaces.

📐 工作原理与说明

本文本工具基于标准字符编码与文本处理规则，纯前端运行，代码不离开浏览器。 工具名称：字符串长度统计 - 统计字符数、字节数、行数、词数、空格数及中文字符数。

📌 统计规则
  • 字符数：Unicode 码点数量（含空格、换行、标点）。
  • 字节数：按 UTF-8 编码计算，中文通常占 3 字节。
  • 词数：按空白分隔的连续非空白片段计数。
  • 行数：按换行符分割，空文本计为 0 行。
