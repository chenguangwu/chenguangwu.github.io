📝 String Length Counter

Count characters, bytes, lines, words and spaces.

📐 工作原理与说明

统计文本的字符数、字节数、词数与行数，是内容与接口限长校验的常用工具。

  • 字符 vs 码元：JS 的 .length 计的是 UTF-16 码元，emoji 与部分生僻汉字占 2 个码元。
  • 准确计数：用 [...str].length 或 Intl.Segmenter 按字素簇切分更符合直觉。
  • 字节数：取决于编码，UTF-8 下英文 1 字节、常用中文 3 字节、emoji 常 4 字节。
  • 词数：英文按空白与标点切分；中文需分词，常用字数与字符数近似。
📌 统计规则
  • 字符数：Unicode 码点数量（含空格、换行、标点）。
  • 字节数：按 UTF-8 编码计算，中文通常占 3 字节。
  • 词数：按空白分隔的连续非空白片段计数。
  • 行数：按换行符分割，空文本计为 0 行。

❓ 常见问题（FAQ）

字符数与字节数为何不同？
中文等多字节字符在 UTF-8 占多字节，数据库常按字节限制。
