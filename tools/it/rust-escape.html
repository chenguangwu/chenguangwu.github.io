🔤 Rust String Escape

📐 工作原理与说明
先去掉首尾空白；匹配原始字符串形式（r 后跟若干个井号再加引号，且整体以引号结尾）时，按井号数量定位并直接输出内层内容。否则去掉开头的字节串前缀 b，再去掉成对的外层双引号或单引号。逐字符扫描：遇到反斜杠且后面还有字符时，按后随字符转义——n 转换行、r 转回车、t 转制表符、0 转空字符、反斜杠与单双引号转其自身；x 取后随 2 位十六进制解析为码点；u 后随左花括号时取到右花括号之间的十六进制解析为码点并跳到右花括号之后，否则取后随 4 位十六进制；其余情况取后随字符本身。不是转义序列的字符原样保留
Rust 字符串字面量的转义与反转义。
  • 转义序列：\n \t \r \" \' \\ \0 \xHH \u{XXXX}。
  • 原始字符串：r"…" 不转义；内容含引号时用 r#"…"#，井号数量可按需增加。
  • 字节串：b"…" 为字节串，br"…" 为原始字节串。
  • 差异：Rust 的 Unicode 转义用花括号包裹 1–6 位十六进制，与 C/Java 的固定四位不同。

❓ 常见问题（FAQ）

Rust 支持 \u{...} 吗？
支持，如 \u{1F600} 表示 😀。
Windows 路径怎么办？
两个办法：一是用原始字符串 r"C:\Users\..."（仍需保留反斜杠，只是不用双写；若以反斜杠结尾需用 r#"..."# 形式）；二是直接用正斜杠 C:/Users/...，Windows API 与 Rust 标准库都接受正斜杠。后者最省事，也避免了转义错误。
