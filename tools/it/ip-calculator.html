无类域间路由

  • B 类私有: 172.16.0.0/12 (172.16.0.0 - 172.31.255.255)
  • C 类私有: 192.168.0.0/16 (192.168.0.0 - 192.168.255.255)
  • 环回地址: 127.0.0.0/8 (IPv4)，::1/128 (IPv6)
  • 链路本地: 169.254.0.0/16 (IPv4)，fe80::/10 (IPv6)
  • CIDR /32: 单主机路由，/31: 点对点链路（无广播）
