🔧 JSON Formatter

Syntax highlighting, tree view, sorting, escape/unescape, JSONP extraction. Pure frontend, no upload.

📐 工作原理与说明

将 JSON 文本解析为对象树后重新序列化：美化按 2/4 空格缩进、保留层级；压缩去除空白；校验在解析失败时定位错误行列。支持语法高亮与层级折叠便于阅读。

  • 合法 JSON 要求双引号键、无尾逗号、无注释（JSON5 才支持）。
  • 纯前端解析，粘贴内容不离开浏览器，适合脱敏前本地处理。

输入单行 `{"name":"Alice","age":30,"skills":["js","go"]}` 选择 2 空格缩进后输出： ```json { "name": "Alice", "age": 30, "skills": ["js", "go"] } ``` 若输入不是合法 JSON，工具会提示出错位置（行/列）。

❓ 常见问题（FAQ）

报错了怎么定位问题？
报错信息会尽量指出出错的大致位置（如第几行、哪个字符附近）。常见原因：末尾多了逗号、引号未闭合、用了单引号或注释——JSON 标准不支持这些写法。
支持 JSON5 / 注释吗？
标准 JSON 不支持注释与单引号；若你的源文件是 JSON5，请先去掉注释与单引号再格式化，否则会被判为非法。
