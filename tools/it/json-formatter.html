❓ 常见问题（FAQ）

JSON 和 JavaScript 对象字面量一样吗？
不一样。JSON 的键必须用双引号、不能出现末尾逗号、不能写函数或 undefined，是 JavaScript 对象的一个严格子集，便于跨语言解析。
大整数会被截断吗？
JSON 本身支持任意精度整数，但部分语言 / 解析器（如早期 JS 的 Number）对超过 2^53 的整数会丢失精度，处理订单号、ID 等大整数时要注意用字符串表示。
