功能说明

  • 美化格式化：统一缩进、换行，使CSS结构清晰易读
  • 压缩：移除所有注释、空白、换行，生成最小体积CSS
  • 压缩率统计：实时显示压缩前后体积对比
  • 历史记录：自动保存处理记录，可快速恢复

压缩优化项

  • 移除 /* comments */ 注释
  • 移除多余空白字符和换行
  • 移除最后一个分号
  • 保留必要空格（选择器之间）
  • 颜色值优化（如 #ffffff → #fff）
