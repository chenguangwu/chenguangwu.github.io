🚫 .gitignore 生成器

不同技术栈需忽略的文件各异（依赖目录、构建产物、虚拟环境）。选择你的栈，本工具拼出对应 .gitignore，开箱即用。

📐 工作原理与说明
按技术栈生成 .gitignore 忽略规则。
  • 语法：# 注释、* 通配、** 跨目录、/ 开头仅匹配根目录、! 取反。
  • 模板：按语言（Node/Python/Java）、框架与编辑器选择模板合并生成。
  • 范围：只作用于未跟踪文件；已入库文件需先 git rm --cached 才会被忽略。
  • 全局：可用 core.excludesFile 配置跨仓库的全局忽略规则。
⚠️ 使用说明与注意事项
  • 勾选项对应各生态官方社区模板的精简版；多栈项目直接合并即可，重复项无害。
  • .gitignore 对已被跟踪的文件不生效——若误提交了 node_modules，需先 git rm --cached 再忽略。
  • 机密文件（.env）务必忽略；但 .gitignore 不是安全边界，敏感信息请勿入库。

📋 提示

生成后保存为项目根目录的 .gitignore 即可。可继续手动追加项目特有忽略项。

💡 常见使用场景

  • 按语言/框架生成忽略规则。
  • 新建项目时按技术栈生成忽略规则，避免把依赖目录、构建产物与本地配置误提交。
生成
选 Node → 输出 `node_modules/`、`dist/`、`.env` 等规则。

❓ 常见问题（FAQ）

.gitignore 对已跟踪文件生效吗？
不生效，需先 `git rm --cached`。
规则不生效怎么排查？
先看该文件是否已被 Git 跟踪（.gitignore 只对未跟踪文件有效，需先 git rm --cached）；再检查规则写法——目录要带斜杠、取反用 !、** 匹配多级；同名规则后者覆盖前者，注意顺序。可用 git check-ignore -v 逐条定位命中情况。
