📝 Markdown to HTML

Markdown to HTML is available directly in your browser, with no data uploaded.

📐 工作原理与说明

按 CommonMark 规则将 Markdown 解析为 HTML：# 标题、** 粗体、* 斜体、[]() 链接、- 列表、` 行内代码、| 表格等。前端解析器（如 marked）生成带语义标签的 HTML，可实时预览。

  • 直接插入 DOM 需防 XSS（对不可信输入做消毒/沙箱）。
  • 纯前端转换，粘贴内容不离开浏览器。

📚 深度解析：Markdown 转 HTML

💡 常见使用场景

  • 写文档 / 博客 / README：用轻量 Markdown 写完，一键生成可直接粘贴的 HTML。
  • 富文本与邮件模板：把产品说明、公告的 Markdown 源转成 HTML 片段嵌入页面或邮件。
示例：基础语法转换
输入： ``` # 标题 这是**加粗**和*斜体*。 - 列表项一 - 列表项二 ``` 输出： ```html <h1>标题</h1> <p>这是<strong>加粗</strong>和<em>斜体</em>。</p> <ul><li>列表项一</li><li>列表项二</li></ul> ```

❓ 常见问题（FAQ）

支持哪些语法？
覆盖标题、加粗/斜体、列表、链接、图片、代码块、引用、表格等常用语法；少数扩展语法（如脚注、任务列表）视实现而定。
转出的 HTML 安全吗？
纯转换工具本身不主动注入脚本，但 Markdown 允许内联 HTML，若源文本里含有 `<script>` 等，转换后也会原样保留。把结果用于公开页面前，请自行做 XSS 过滤。
⚠️ 使用说明与注意事项
  • 支持：#1-6 标题、**粗体**、*斜体*、`行内代码`
  • 支持：- 无序列表、数字列表、> 引用、--- 分割线
  • 支持：``` 代码块、| 表格、[链接](url)
  • 转换纯本地进行，文本不会上传
