📝 Markdown to HTML

Markdown to HTML is available directly in your browser, with no data uploaded.

📐 工作原理与说明

按 CommonMark 规则将 Markdown 解析为 HTML：# 标题、** 粗体、* 斜体、[]() 链接、- 列表、` 行内代码、| 表格等。前端解析器（如 marked）生成带语义标签的 HTML，可实时预览。

  • 直接插入 DOM 需防 XSS（对不可信输入做消毒/沙箱）。
  • 纯前端转换，粘贴内容不离开浏览器。
⚠️ 使用说明与注意事项
  • 支持：#1-6 标题、**粗体**、*斜体*、`行内代码`
  • 支持：- 无序列表、数字列表、> 引用、--- 分割线
  • 支持：``` 代码块、| 表格、[链接](url)
  • 转换纯本地进行，文本不会上传
