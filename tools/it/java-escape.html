🔤 Java String Escape

📐 工作原理与说明
逐字符处理并把结果放在一对双引号内：反斜杠转为两个反斜杠；双引号与单引号转为反斜杠加该字符；换行转反斜杠 n，回车转反斜杠 r，制表符转反斜杠 t，退格转反斜杠 b，换页转反斜杠 f；其余字符在码点小于 0x20 时，开启 Unicode 选项则输出反斜杠 u 加四位十六进制（不足补前导 0），否则输出对应简写形式。开启包裹选项时在首尾补上引号
Java 字符串字面量的转义与反转义。
  • 转义序列：\n \t \r \" \\ \b \f \' \uXXXX \OOO。
  • 特性：\uXXXX 在编译期即被解析，即便出现在注释中也会生效。
  • 文本块：Java 15+ 支持 """ 文本块，可多行书写并减少转义。
  • 要求：\u 必须恰好四位十六进制，不足需补前导 0。

❓ 常见问题（FAQ）

Java 文本块 """ 能省转义吗？
JDK 15+ 文本块可免多数转义，但仍需处理 `"""` 本身。
Java 属性文件里的转义规则一样吗？
不一样。.properties 有自己的规则：键名中的空格、冒号与等号需要反斜杠转义；非 Latin-1 字符通常按 \uXXXX 表示（Java 9 起默认按 UTF-8 读取，情况有所变化）。不要直接把 Java 字面量的转义结果复制进属性文件。
