📐 工作原理与说明
短链接生成原理的本地模拟。
  • 原理：服务端把长 URL 存入数据库并分配短码，访问短链时返回 301/302 跳转到原地址。
  • 短码：常由自增 ID 经 Base62 编码生成，也可随机生成后查重。
  • 重定向：301 为永久重定向会被浏览器缓存，302 为临时重定向便于统计。
  • 说明：本工具在本地演示编码与映射，生成的短链不具备真实跳转服务。
