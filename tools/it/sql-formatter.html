📖 使用说明

支持的SQL方言

  • 标准SQL：ANSI SQL通用格式
  • MySQL：MySQL特有语法（反引号、LIMIT等）
  • PostgreSQL：PostgreSQL特有语法
  • SQL Server：T-SQL语法（TOP、方括号等）
  • SQLite：轻量数据库SQL语法

格式化特性

  • 关键字自动大写/小写
  • SELECT字段换行对齐
  • FROM/JOIN/WHERE/GROUP BY/ORDER BY等子句换行
  • 缩进对齐，可读性强
  • 压缩模式：移除所有空白，生成紧凑SQL
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge）中使用
  • 计算结果仅供参考，请以实际应用场景为准
