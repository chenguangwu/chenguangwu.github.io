📐 工作原理与说明

本开发工具在前端本地完成解析、转换与处理，代码不离开浏览器，遵循对应语法与格式规范。 工具名称：HTML 嵌套检查器 - 检查 HTML 标签嵌套是否合法：未闭合标签、错误嵌套。

📚 深度解析：HTML 嵌套检查器

💡 常见使用场景

  • 模板调试：手写 / 生成的 HTML 出现样式错乱时，检查是不是标签嵌套或闭合错误导致。
  • 质量审计：在提交页面前扫一遍嵌套合法性，减少可访问性与渲染隐患。
示例：检测错误嵌套
输入 `<div><p>文字</div></p>`，工具会指出：`p` 在 `div` 闭合前未先闭合，属于交叉嵌套（非法的 `<div><p></div>` 结构）。
示例：未闭合标签
输入 `<ul><li>项一<li>项二</ul>`，提示第二个 `li` 未正确闭合。

❓ 常见问题（FAQ）

依据什么规则判断？
依据 HTML 标签的合法嵌套关系（如块级 / 行内元素、表格 / 列表的父子约束）以及标签开闭是否配对来判断。
自闭合标签怎么处理？
img、br、input、hr 等标准自闭合标签按规范识别，不会误报为"未闭合"；是否允许自定义自闭合标签取决于工具设置。

结果含义

HTML 嵌套检查指出标签是否被正确闭合与合法嵌套（如 <p> 不能包含块级 <div>）。结果列出错误位置与类型。
