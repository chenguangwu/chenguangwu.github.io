📊 JSON to CSV

JSON to CSV is available directly in your browser, with no data uploaded.

📐 工作原理与说明

将 JSON 对象数组展平为二维表格的逻辑:

  • 递归下钻嵌套对象/数组,键名以"·"或"."合并为列名(如 user.name)。
  • 每个数组元素输出一行;值转为字符串(布尔、数字、日期原样)。
  • null / 缺失字段留空;数组经索引展开。

导出建议带 UTF-8 BOM,以便 Excel 正确识别中文不乱码。全程纯前端解析,数据不上传。

本开发工具在前端本地完成解析、转换与处理，代码不离开浏览器，遵循对应语法与格式规范。 工具名称：JSON 转 CSV - 把 JSON 数组一键转为 CSV。
