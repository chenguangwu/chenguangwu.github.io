❓ 常见问题（FAQ）

会合并重复规则吗？
格式化一般不改规则，去重需另外处理。
格式化会改变样式效果吗？
纯格式化不会——它只调整空白与缩进，不改变选择器或声明本身。但要留意：某些压缩器会把 0px 写成 0、去掉最后一条声明的分号、合并同值属性，这些是压缩期的语义等价改写，格式化不会还原它们。
