📐 工作原理与说明

AES 是对称分组密码：密钥 128/192/256 位，分组固定 16 字节。常见模式：ECB（同明文同密文，不推荐）、CBC（需随机 IV、PKCS7 填充）、GCM（带认证与完整性校验，无需填充）。本工具经浏览器 Web Crypto API 在本地完成，密钥不经网络。

  • 口令到密钥通常用 PBKDF2/scrypt 派生并加盐，避免弱口令直用。
  • GCM 的 IV 须唯一，密文含认证标签防篡改。
  • 本地加解密仅供您自己数据，密钥请妥善保存（遗失不可恢复）。

📖 使用说明与安全建议

AES 算法简介：高级加密标准（AES）是一种对称加密算法，支持 128/192/256 位密钥。

模式说明：

• ECB：电子密码本，最简单但不安全，相同明文块产生相同密文

• CBC：密码分组链接，推荐使用，每个明文块与前一个密文块异或

• CFB：密码反馈，将分组密码转换为流密码

• OFB：输出反馈，将分组密码转换为流密码，误差不传播

• CTR：计数器模式，使用计数器生成密钥流，可并行处理

安全建议：

• 推荐使用 AES-256 + CBC 或 CTR 模式

• 始终使用随机生成的 IV，IV 不需要保密但必须唯一

• 使用 Salt 加盐防止彩虹表攻击

• 密码应足够复杂（至少12位，包含大小写、数字、符号）

• ECB 模式不推荐用于加密大于一个块的数据

• 本工具在浏览器本地执行，数据不会上传到服务器

PBKDF2 密钥派生：使用 SHA-256 哈希，100000 次迭代从密码派生密钥。
