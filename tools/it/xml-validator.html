📄 XML Validator

XML Validator - Check XML for well-formedness: tag pairing, quoted attributes and illegal characters, with error location. Free, browser-only.

📐 工作原理与说明
输入为空时提示请粘贴 XML 内容。用 XML 解析器按 XML 类型解析文本：若文档中存在解析错误节点则判定格式错误并展示错误详情；否则判定 XML 格式良好，并给出根元素名与文档中的元素总数。解析过程抛出异常时展示异常信息
校验 XML 文档是否规范。
  • 检查项：标签是否闭合、嵌套是否正确、属性值是否加引号、特殊字符是否转义、是否有唯一根元素。
  • 两个层次：well-formed 指符合 XML 语法；valid 指还满足 DTD 或 XSD 约束。
  • 常见错误：未转义的 &、标签大小写不一致、缺少根元素、属性未加引号。
  • 用途：接口数据与配置文件的合法性检查。
⚠️ 使用说明与注意事项
  • XML 与 HTML 不同：所有标签必须闭合，属性必须用引号包裹，大小写敏感，且只能有一个根元素。
  • DOMParser 在浏览器环境可解析，但不同引擎报错信息措辞不同；生产校验建议用专用 XML 校验器（如 xmllint）。
  • 注意 XML 声明 `` 应位于文件第一行，前面不能有空行或 BOM。
