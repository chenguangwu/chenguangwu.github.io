💾 File Size Unit Converter

Convert file sizes between decimal (SI) and binary (IEC) units.

📐 工作原理与说明

本工具用于单位与格式换算，换算因子依据国际单位制(SI)及相关标准定义，结果保留输入精度；纯前端本地处理。 工具名称：文件大小单位换算 - 在十进制（SI）与二进制（IEC）单位之间快速换算文件大。

📌 单位说明
  • SI 十进制：1 KB = 1,000 B，1 MB = 1,000 KB（硬盘厂商常用）。
  • IEC 二进制：1 KiB = 1,024 B，1 MiB = 1,024 KiB（操作系统常用）。
  • Windows 显示的“GB”实际为 GiB，Mac 显示的“GB”通常为十进制 GB。
