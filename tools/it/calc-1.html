🔄 File Size Unit Converter

Convert file sizes between decimal (SI) and binary (IEC) units.

📐 工作原理与说明
输入须为有效的非负数值，否则提示请输入有效的非负数值。字节数 = 输入值 × 所选单位的换算因子；随后用同一套因子表把字节数换算为其它各单位的数值并逐一展示，数值按中文地区千分位格式输出，同时给出原始大小与等价字节数
在存储与传输的单位之间换算，需区分十进制与二进制两套前缀。
  • 两套标准：SI 十进制按 10³ 递进（KB/MB/GB），IEC 二进制按 2¹⁰ 递进（KiB/MiB/GiB）。
  • 差异：1 KB = 1000 B，而 1 KiB = 1024 B；硬盘厂商标称用十进制，操作系统显示常用二进制。
  • 位与字节：1 B = 8 bit；带宽常用 bit/s（Mbps），下载速度常用 B/s，相差 8 倍。
  • 影响：同一容量用两种标准表示约差 7%（如 1 GB 与 1 GiB），换算时须明确口径。

📌 单位说明
  • SI 十进制：1 KB = 1,000 B，1 MB = 1,000 KB（硬盘厂商常用）。
  • IEC 二进制：1 KiB = 1,024 B，1 MiB = 1,024 KiB（操作系统常用）。
  • Windows 显示的“GB”实际为 GiB，Mac 显示的“GB”通常为十进制 GB。

💡 常见使用场景

  • KB/MB/GB 与 KiB/MiB 混用时换算。
  • 核对硬盘容量：厂商标称 1 TB 按十进制（10¹² 字节），操作系统按二进制显示（÷ 1024⁴ ≈ 0.909 TiB），两者差约 9% 属正常，不是缩水。
换算
1 GB=1000 MB（十进制）；1 GiB=1024 MiB（二进制）。100 MiB×1024²≈104.9 MB。

❓ 常见问题（FAQ）

KB 与 KiB 区别？
KB=10³ 字节，KiB=2¹⁰ 字节，存储厂商标十进制、系统常显二进制。
MB 和 MiB 到底差多少？
1 MB = 1,000,000 字节，1 MiB = 1,048,576 字节，相差 4.86%。单级差别不大，但逐级累积：1 GB 与 1 GiB 差 7.4%，1 TB 与 1 TiB 差约 10%。传输速率同理——100 Mbps 宽带的理论下载速度是 12.5 MB/s 而非 12.5 MiB/s。

📊 结果解读

换算口径

文件大小按 1 KB=1024 B（二进制，KiB）或 1 KB=1000 B（十进制，SI）换算；系统/厂商口径不一常致"标称 vs 显示"差异。

用途

存储、带宽与传输量估算；注意 GiB/GB、MiB/MB 区分以对账准确。

注意

磁盘/流量常标十进制，操作系统常显二进制，差额约 7% 量级。
