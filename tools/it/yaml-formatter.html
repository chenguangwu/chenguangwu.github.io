📖 使用说明

功能说明

  • 格式化：自动调整缩进、对齐，使YAML结构清晰易读
  • 压缩：移除多余空白和注释，生成紧凑YAML
  • 验证：检查YAML语法错误，定位错误位置
  • YAML↔JSON互转：一键在两种格式间转换

YAML 语法要点

  • 使用缩进表示层级关系（空格，不能用Tab）
  • 键值对用冒号分隔: key: value
  • 列表用短横线: - item
  • 注释以 # 开头
  • 字符串通常不需要引号，特殊字符需要
