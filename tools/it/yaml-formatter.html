📄 YAML Format

📐 工作原理与说明
用 js-yaml（YAML 1.2 Core Schema）完整解析与序列化：格式化按所选缩进宽度 dump，多文档用 --- 保留分隔；压缩输出每个文档的紧凑 JSON（JSON 也是合法 YAML）；YAML→JSON 保留布尔、数字、空容器与嵌套结构；注释、锚点与别名不保留，检测到即提示核对。
YAML 配置文件的格式化与校验。
  • 语法：key: value 为映射，- 开头为序列，# 为注释，| 与 > 处理多行文本。
  • 缩进：YAML 用缩进表示层级，只能使用空格，禁止使用 Tab。
  • 格式化：统一缩进宽度与空行，不改变数据内容。
  • 校验：缩进错误会改变结构，格式化后应重新解析确认语义未变。

Format and beautify YAML in your browser — consistent indentation and clean config.

📖 使用说明

功能说明

  • 格式化：自动调整缩进、对齐，使YAML结构清晰易读
  • 压缩：移除多余空白和注释，生成紧凑YAML
  • 验证：检查YAML语法错误，定位错误位置
  • YAML↔JSON互转：一键在两种格式间转换

YAML 语法要点

  • 使用缩进表示层级关系（空格，不能用Tab）
  • 键值对用冒号分隔: key: value
  • 列表用短横线: - item
  • 注释以 # 开头
  • 字符串通常不需要引号，特殊字符需要
  • 格式化会重排结构并丢弃注释、锚点与别名；重要配置请先备份，格式化后核对语义。

❓ 常见问题（FAQ）

Tab 能缩进 YAML 吗？
不能，YAML 仅允许空格缩进。
为什么格式化后引号没了？
因为该值不加引号也不会产生歧义（如普通单词），格式化器按 YAML 规范去掉了冗余引号，语义上等价。但要注意：形如 123、yes/no、null 的值去掉引号会改变类型——规范的格式化器会保留它们的引号；若发现类型被改，应手工加回。
