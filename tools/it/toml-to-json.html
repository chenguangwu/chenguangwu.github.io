🔧 TOML 转 JSON 转换器

把 Cargo.toml、pyproject.toml 等配置转成 JSON，方便在脚本、API、前端里消费。粘贴即转，可设缩进。

⚠️ 使用说明与注意事项
  • TOML [section] 转为嵌套 JSON 对象；[[数组表]] 转为 JSON 数组。
  • 字符串、整数、浮点、布尔、数组、内联表都会被正确解析。
  • 结果缩进可选 2/4 空格或 Tab。

📋 TOML 基础

写法含义
key = "v"字符串
[section]表
[[arr]]数组表
list = [1, 2]数组

📚 深度解析：TOML 转 JSON

💡 常见使用场景

  • 配置迁移：把 Cargo.toml、pyproject.toml 等 TOML 配置转成程序更易消费的 JSON。
  • 跨语言对接：前端 / 脚本需要读取 TOML 配置时，先转成 JSON 再解析。
示例：TOML → JSON
输入： ```toml [server] port = 8080 debug = true [db] url = "postgres://localhost" ``` 输出： ```json {"server":{"port":8080,"debug":true},"db":{"url":"postgres://localhost"}} ``` （TOML 的表变成嵌套对象，类型按内容推断）

❓ 常见问题（FAQ）

注释和类型会保留吗？
注释在转换成 JSON 后会丢失（JSON 不支持注释）；类型会自动推断：未加引号的 8080 变数字、true 变布尔、带引号的是字符串。
数组、多行字符串支持吗？
支持 TOML 的数组与基本字符串；特殊写法（如多行字符串、日期时间）会尽量按规范转换，个别边缘语法以解析器实现为准。
