📄 TOML to JSON Converter

📐 工作原理与说明
TOML 解析：去回车后逐行处理，跳过空行与 # 注释（# 判定避开引号内部）；[节名] 按 . 逐级建立嵌套对象，[[数组名]] 向同名数组追加新元素；其余行取第一个 = 分隔键与值，行尾 # 注释在引号外剥离。值解析支持双引号串（\n \t \" \\ 反转义）、单引号字面量串、三引号多行串、布尔、整数/浮点（可含下划线与 0x/0o/0b 前缀、科学计数）、[ ] 数组（按「顶层逗号」切分，引号内逗号与嵌套层级不受影响）与 { } 内联表（递归键值）；多行数组/内联表/多行串会跨行累积到括号闭合；日期时间等 JSON 无对应类型的值保留原字符串。输出 JSON 时缩进取 tab 或指定个数的空格（缺省 2），勾选排序时按键名字典序递归重排所有层级的键
把 TOML 转换为 JSON。
  • 映射：TOML 的表与数组分别转换为 JSON 对象与数组。
  • 类型：字符串、整数、浮点、布尔按对应类型转换。
  • 日期：TOML 原生支持日期时间类型，而 JSON 没有，通常序列化为字符串。
  • 用途：配置迁移、跨语言数据交换与工具链对接。

⚠️ 使用说明与注意事项
  • TOML [section] 转为嵌套 JSON 对象；[[数组表]] 转为 JSON 数组。
  • 字符串、整数、浮点、布尔、数组、内联表都会被正确解析。
  • 结果缩进可选 2/4 空格或 Tab。

❓ 常见问题（FAQ）

日期类型保留吗？
TOML 的日期时间会转为字符串或对应类型。
为什么数字变成了字符串？
多半是类型信息在转换中被保守处理：TOML 有原生日期时间类型，JSON 没有对应类型，通常会被转成 ISO 8601 字符串；此外超大整数为避免精度丢失也可能以字符串输出。消费端需按字段自行解析，尤其是日期与 64 位整数。
