🖥️ Nginx Config Generator

Nginx Config Generator - Pick static site or reverse proxy and fill params to emit a server block config. Free, browser-only.

📐 工作原理与说明
按场景生成 Nginx server 配置。
  • 场景：静态站点、反向代理、HTTPS、负载均衡、单页应用（SPA）回退。
  • 核心项：listen 端口、server_name、root/index、location 匹配规则与优先级。
  • HTTPS：ssl_certificate、ssl_certificate_key，并限制协议版本与加密套件。
  • 反代：需设置 proxy_set_header 传递真实客户端 IP，否则后端日志全是代理 IP。
⚠️ 使用说明与注意事项
  • 反向代理的 proxy_pass 末尾是否带 / 影响路径拼接：带 / 会剥离 location 前缀，按需选择。
  • 配置改完用 nginx -t 校验语法，再 nginx -s reload 生效，避免写错导致服务中断。
  • 生产应补 TLS（listen 443 ssl）、gzip、缓存头等；本工具只生成最小可用骨架。

❓ 常见问题（FAQ）

生成后怎么用？
放入 conf.d 并 `nginx -t` 校验后 reload。
生成后还要补什么？
至少三件事：一是 HTTPS（证书路径、HTTP/2，以及 80 端口跳转）；二是安全头（HSTS、X-Content-Type-Options，CSP 视情况）；三是上传大小与超时（client_max_body_size、proxy_read_timeout），默认值常不适合实际业务。上线前务必 nginx -t 校验。
