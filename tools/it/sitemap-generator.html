✨ Sitemap Generator

Sitemap Generator - Paste one URL per line to build a standard sitemap.xml with lastmod for search engines. Free, browser-only.

📐 工作原理与说明
生成供搜索引擎抓取的 XML Sitemap。
  • 字段：每个 URL 含 loc（地址）、lastmod（最后修改）、changefreq（更新频率）、priority（优先级）。
  • 限制：单个 sitemap 最多 5 万条 URL、未压缩不超过 50MB；超出需用 sitemap index 分片。
  • 提交：在 robots.txt 中声明 Sitemap 地址，或通过搜索引擎站长平台提交。
  • 说明：sitemap 只是抓取线索，不保证收录；priority 仅供搜索引擎参考。
⚠️ 使用说明与注意事项
  • 单 sitemap 最多 50000 条 URL 且文件不超过 50MB；超限需用 sitemap 索引文件拆分。
  • URL 必须是绝对地址且可被爬虫访问；含非 ASCII 需做百分号编码。
  • 生成后放到站点根目录并在 robots.txt 声明 Sitemap 路径，再到搜索引擎后台提交。

📋 结构

<urlset xmlns=".../0.9">
  <url><loc>https://x/</loc></url>
</urlset>

❓ 常见问题（FAQ）

上限多少？
单文件 5 万 URL / 50MB，超出需索引。
生成的 sitemap 一定能被收录吗？
不能保证。sitemap 只是「告知」而非「命令」——搜索引擎会自行判断是否抓取与收录；被 robots 屏蔽、返回非 200 或质量过低的页面即便写进 sitemap 也不会被收录。因此应先确保页面可访问、内容有独特价值，并保持 sitemap 与实际状态一致。
