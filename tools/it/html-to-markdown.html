🔁 HTML to Markdown

HTML to Markdown

📐 工作原理与说明

本工具用于单位与格式换算，换算因子依据国际单位制(SI)及相关标准定义，结果保留输入精度；纯前端本地处理。 工具名称：HTML 转 Markdown。

📌 说明
  • 基于解析后的 DOM 节点逐层转换，保留多层列表结构。
  • 支持 h1~h3、p、ul/ol、table、a、img 与代码块。
  • 输出为纯 Markdown 文本，未联网处理。
