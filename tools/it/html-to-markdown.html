🔁 HTML to Markdown

HTML to Markdown

📐 工作原理与说明
📌 说明
  • 基于解析后的 DOM 节点逐层转换，保留多层列表结构。
  • 支持 h1~h3、p、ul/ol、table、a、img 与代码块。
  • 输出为纯 Markdown 文本，未联网处理。

📚 深度解析：HTML 转 Markdown

💡 常见使用场景

  • 把网页内容转成轻量 Markdown。
转换
`<h1>标题</h1><p>文本 <b>粗</b></p>` → `# 标题 文本 **粗**`。
