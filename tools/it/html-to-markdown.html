📝 HTML to Markdown

HTML to Markdown

📐 工作原理与说明
把 HTML 转换为 Markdown 文本。
  • 映射：h1–h6 → #~######，strong/b → **，em/i → _，a → [文本](链接)，img → ![alt](src)。
  • 结构：列表、引用、代码块、表格需按 Markdown 语法保留层级与对齐。
  • 丢失：class、style、脚本等表现层信息会被丢弃，Markdown 不表达样式。
  • 转义：内容中的 * _ [ ] 等需转义，避免渲染错乱。
📌 说明
  • 基于解析后的 DOM 节点逐层转换，保留多层列表结构。
  • 支持 h1~h3、p、ul/ol、table、a、img 与代码块。
  • 输出为纯 Markdown 文本，未联网处理。

💡 常见使用场景

  • 把网页内容转成轻量 Markdown。
  • 把旧站点文章批量迁到 Markdown 博客：先转格式再人工校对，比逐篇重写省时得多。
转换
`<h1>标题</h1><p>文本 <b>粗</b></p>` → `# 标题 文本 **粗**`。

❓ 常见问题（FAQ）

复杂表格能转吗？
多数能，但合并单元格等需人工修。
转换后格式丢了怎么办？
Markdown 的表达能力弱于 HTML：合并单元格、内联样式、自定义容器与脚本交互都没有对应语法，通常降级为纯文本或被丢弃。策略是先转换、再对复杂区块单独手工处理；若原文档大量依赖这些特性，保留 HTML 反而是更务实的选择。
