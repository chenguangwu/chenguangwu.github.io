📚 原理说明

什么是 HTML 实体转义？

HTML 实体转义是将特殊字符转换为 HTML 实体的过程，以确保这些字符在网页中正确显示而不被浏览器解析为 HTML 代码。

为什么需要转义？

• 防止 XSS 攻击：转义用户输入，避免恶意脚本注入
• 正确显示特殊字符：如 < > & 等在 HTML 中有特殊含义的字符
• 代码展示：在网页中显示 HTML/XML 源代码

三种实体格式

1. 命名实体：&lt;（可读性好，数量有限）
2. 数字字符引用（十进制）：&#60;（支持所有 Unicode 字符）
3. 十六进制字符引用：&#x3C;（与 Unicode 码点对应）

JavaScript 转义

在 JavaScript 字符串中，特殊字符需要用反斜杠转义：
• \" 双引号
• \\ 反斜杠
• \n 换行符
• \t 制表符
• \uXXXX Unicode 字符

URL 编码

URL 中只能使用 ASCII 字符集。非 ASCII 字符和特殊字符需要使用百分号编码（Percent-encoding），格式为 %XX，其中 XX 是字符的十六进制值。
