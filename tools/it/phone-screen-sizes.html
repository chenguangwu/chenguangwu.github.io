☎️ 手机屏幕尺寸速查

主流机型屏幕参数速查：分辨率、英寸、PPI 一表看完，还可按英寸与分辨率反算 PPI。

📐 工作原理与说明
主流手机屏幕参数速查。
  • 指标：物理尺寸（英寸）、分辨率（物理像素）、像素密度 PPI、逻辑视口（CSS 像素）。
  • DPR：设备像素比 = 物理像素 ÷ CSS 像素，决定切图需要提供几倍图。
  • 常见视口：iPhone 约 390–430 CSS px，Android 常见 360–412 CSS px。
  • 用途：设定响应式断点、选择图片倍率、评估移动端布局表现。

📚 深度解析：Phone Screen Sizes

💡 常见使用场景

  • 查主流机型分辨率与 DPR 做适配。
  • 做移动端适配时查目标机型：确认视口宽度、DPR 与常用断点，再决定用 rem 还是 vw 方案。

❓ 常见问题（FAQ）

DPR 是什么？
设备像素比，CSS px × DPR = 物理像素。
为什么按 CSS 像素而不是物理像素设计？
因为 CSS 像素是逻辑单位，浏览器已按 DPR 完成换算：DPR=3 的手机上一个 CSS 像素对应 3×3 个物理像素。设计稿通常按 CSS 像素给，实现时也按 CSS 像素写，只有图片资源才需要提供 2x/3x 以匹配高 DPR 屏幕。
⚠️ 使用说明与注意事项
  • PPI = √(分辨率宽²+分辨率高²) ÷ 屏幕英寸
  • 内置 10 款主流机型参数速查
  • 数据为常见公开参数，以厂商规格为准
  • 反算功能可输入任意分辨率与英寸
