📝工具简介

TypeScript 转 JavaScript 编译器是一款基于官方 TypeScript 5.3 编译器的在线工具。它在浏览器本地调用 ts.transpileModule API，将 TypeScript 代码实时转译为 JavaScript，支持选择 ES3 到 ESNext 的目标版本与 None、CommonJS、AMD、ESNext 模块系统，并提供编译诊断信息。所有代码处理都在浏览器中完成，不会上传到任何服务器，保障隐私安全。

✨功能特点

  • 基于官方 TypeScript 5.3 编译器
  • 左右分栏实时编辑与输出
  • 支持 ES3/ES5/ES6/ES2017/ES2020/ESNext 目标
  • 支持 None/CommonJS/AMD/ESNext 模块系统
  • 移除注释、严格模式、isolatedModules 选项
  • 300ms 防抖实时编译
  • 编译诊断信息（错误/警告/位置）
  • 显示编译耗时与输出行数
  • Tab 键缩进支持
  • 一键复制 / 下载 JS 文件
  • 深色模式与移动端响应式

💬常见问题

这个工具能检测类型错误吗？
本工具使用 ts.transpileModule 进行单文件转译，主要移除类型注解并做语法降级，不做完整的类型检查。类型不匹配等错误通常不会出现在诊断面板，仅语法错误和部分语义错误会被报告。如需完整类型检查，请使用本地 tsc 命令或 IDE。
isolatedModules 选项有什么作用？
isolatedModules 启用单文件编译语义，强制每个文件可独立转译。由于 transpileModule 本身就是单文件模式，该选项主要用于约束部分语法（如 export =、const enum 等）的可用性。
目标版本和模块系统如何选择？
目标版本决定输出的 JS 语法级别：需要兼容旧浏览器选 ES5 或 ES3；现代环境选 ES2020 或 ESNext。模块系统决定 import/export 的编译方式：Node.js 环境选 CommonJS，浏览器原生模块选 ESNext，不使用模块选 None。
我的代码会被上传吗？
不会。所有编译都在你的浏览器本地完成，TypeScript 编译器从 CDN 加载后在本地运行，代码不会发送到任何服务器。
为什么首次加载稍慢？
工具需要从 CDN 下载约 8MB 的 TypeScript 编译器脚本，首次加载可能稍慢，加载完成后即可流畅使用。建议在网络良好的环境下使用。
