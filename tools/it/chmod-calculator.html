📐 工作原理与说明
Unix 权限位计算（三位八进制）
每位 = 读(4) + 写(2) + 执行(1)：rwx=7｜rw-=6｜r-x=5｜r--=4｜---=0
三位依次为属主(user) / 组(group) / 其他(other)，如 755 = rwxr-xr-x（属主全权限，组与其他可读可执行）
常用：644 普通文件｜700 私密脚本｜600 私钥配置｜444 全局只读｜555 全局防写｜000 无权限
在符号模式与八进制之间换算 Unix 文件权限。
  • 权限位：读 r=4、写 w=2、执行 x=1，三组分别对应 u（属主）、g（属组）、o（其他）。
  • 八进制：每组取和，如 755 表示 u=rwx(7)、g=r-x(5)、o=r-x(5)。
  • 符号模式：u/g/o/a 配合 + - = 与 r/w/x，如 chmod u+x。
  • 特殊位：setuid=4、setgid=2、sticky=1，置于四位数最高位（如 4755）。

💡 常见使用场景

  • 把 rwx 转成数字权限，或反查权限含义。
  • 排查权限拒绝：把线上文件的 644 转成 rwx 形式确认组用户是否有写权限，或反查出 755 与 775 的差别在哪一位。
转换
rwxr-xr-x → 755（owner 7=rwx、group 5=rx、other 5=rx）。

❓ 常见问题（FAQ）

s 位（setuid）怎么表示？
特殊位加在最前，如 4755 表示 setuid+755。
umask 和 chmod 有什么关系？
umask 决定新建文件的默认权限：实际权限 = 默认权限 & ~umask。文件默认 666、目录默认 777，umask 022 时新建文件为 644、目录为 755。修改 umask 只影响之后创建的文件，不会改变已有文件的权限。
