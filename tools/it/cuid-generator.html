🆔 CUID Generator

📐 工作原理与说明
CUID 生成规则：id = c + base36(Date.now 时间戳) + 计数器（(counter+1) mod 36⁴ 后 base36 补齐 4 字符）+ 指纹（navigator 键数 base36 拼 3 位随机数、补齐 4 字符）+ 两组各 2 字符 base36 随机块。校验：生成数量 parseInt 直取，结果含 NaN/Infinity 时显示错误提示。判据：同毫秒内靠计数器递增保证不重复，随机段保证不可预测性。
CUID（Collision-resistant Unique Identifier）为单机与分布式场景下的抗碰撞 ID 设计，结构为：小写 c 开头 + 时间戳（base36，保证大致按生成顺序递增）+ 单机计数器（同毫秒内自增，避免同一进程碰撞）+ 客户端指纹（浏览器/进程特征哈希，区分不同机器）+ 随机数。相比 UUID v4，它在数据库索引上更友好（前缀有序、减少页分裂），但因含指纹信息，不应用于需要不可预测性的安全场景。

❓ 常见问题（FAQ）

CUID 会泄露信息吗？
含时间片段但非明文，冲突概率极低。
CUID 和 UUID 该选哪个？
需要按时间有序、对数据库索引友好时选 CUID（或 ULID）；需要跨系统标准化、且不希望透露生成时间时选 UUID。注意 CUID 含时间戳与客户端指纹，虽不直接暴露业务数据，但会透露生成时间与来源设备，对外暴露 ID 的场景需权衡。
