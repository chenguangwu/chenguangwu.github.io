💬常见问题

    
YAML 验证失败提示缩进错误怎么办？
YAML 严格要求使用空格缩进且同一层级缩进必须一致，不能混用 Tab 和空格。请根据错误提示的行号检查对应行的缩进，确保使用统一的空格数（通常 2 个），并避免用 Tab 键。本工具的输入框已将 Tab 键映射为插入 2 个空格，帮助避免此类问题。

    
支持多个 YAML 文档放在一个输入里吗？
支持。使用三个连字符 --- 作为文档分隔符即可在一个输入中包含多个 YAML 文档。验证与转换时会分别解析每个文档，JSON 结果以数组形式输出，每个元素对应一个文档。

    
我的 YAML 数据会被上传到服务器吗？
不会。本工具完全在浏览器本地运行，所有解析、校验与转换都在你的设备上完成，YAML 内容不会发送到任何服务器，可放心处理敏感配置。

    
为什么转换出的 JSON 里字符串变成了数字或布尔值？
这是 YAML 的自动类型推断机制。YAML 会将 true/false 解析为布尔值、纯数字解析为数值。若希望保留为字符串，可用引号包裹该值，例如 "true" 或 "123"。
