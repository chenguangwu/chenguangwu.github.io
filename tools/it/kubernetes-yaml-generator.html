☸️ Kubernetes YAML 生成器

部署到 K8s 通常需 Deployment 与 Service 两份清单。填入关键参数，本工具拼出标准 YAML，复制到集群即可 apply。

📐 工作原理与说明

生成 Kubernetes 资源清单 YAML。

  • 必填字段：apiVersion、kind、metadata、spec。
  • 关联：Deployment 的 selector 必须与 Pod template 的标签匹配；Service 通过 selector 选中 Pod。
  • 资源：requests 决定调度，limits 决定使用上限，二者应合理设置。
  • 建议：同时配置 readiness/liveness 探针，避免流量打入未就绪的 Pod。
⚠️ 使用说明与注意事项
  • image: latest 不利于回滚与可重现部署，生产应锁定具体版本/tag 或 digest。
  • Service 的 targetPort 须与容器 containerPort 一致；对外暴露需改 type: NodePort/LoadBalancer 或接 Ingress。
  • 生成后 kubectl apply -f 部署；变更镜像建议走滚动更新与探针（liveness/readiness）保障可用性。

📋 清单结构

Deployment（副本/镜像）+ Service（暴露）；用 --- 分隔多文档。资源限制（resources）、探针建议另行补充。
