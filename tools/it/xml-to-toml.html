📄 XML to TOML Converter

📐 工作原理与说明
XML 侧：剔除注释、处理指令并把 CDATA 还原为文本，逐元素取头部标签名与属性（([\w:-]+)\s*=\s*"([^"]*)"），按标签名分组，同名单个取单值、多个取数组，属性以 @ 前缀、文本以 #text 存放。TOML 侧输出：键名匹配 ^[A-Za-z0-9_-]+$ 时原样写，否则加双引号并转义反斜杠与引号；值为空写 ""，布尔写 true/false，数字直接写字符串，数组写 [a, b]，其余加双引号转义；同一表先写标量键再写子表，可选按键名字典序排序
把 XML 转换为 TOML。
  • 映射：XML 元素名成为 TOML 的键，嵌套元素成为子表。
  • 数组：重复的兄弟元素通常转换为 TOML 数组。
  • 属性：元素属性可作为键值，或用前缀区分以避免与子元素重名。
  • 用途：配置格式迁移与系统间数据对接。

Convert XML documents into TOML, mapping nested elements to tables for configuration workflows.

⚠️ 使用说明与注意事项
  • XML 属性转为 TOML 中以 @ 开头的键；重复同名子元素转为 TOML 数组。
  • TOML 不支持 XML 的属性和混合内容的全部语义，转换按约定归一化。
  • 极复杂 XML 建议人工核对。

❓ 常见问题（FAQ）

深层嵌套怎么转？
用 [section] 表层级表示。
为什么转换结果不完整？
因为两种模型不对等：XML 有属性与混合内容、允许同名元素重复出现，TOML 只有表、数组与标量。属性与重复元素需靠约定映射（如属性转字段、重复元素转数组），不同工具约定不同。跨系统使用时应先用小样例验证，并在迁移后做一次回读校验。
