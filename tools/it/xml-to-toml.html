🧩 XML 转 TOML 转换器

在 Rust/Go 配置、pyproject 等 TOML 场景，常需要把 XML 数据转成 TOML。粘贴 XML，立即得到 TOML。

⚠️ 使用说明与注意事项
  • XML 属性转为 TOML 中以 @ 开头的键；重复同名子元素转为 TOML 数组。
  • TOML 不支持 XML 的属性和混合内容的全部语义，转换按约定归一化。
  • 极复杂 XML 建议人工核对。
