📄 CSV 转 YAML 转换器

在配置、CI、Kubernetes 等场景常需要在 CSV 与 YAML 之间互转。首行会被当作字段名生成键值对；若首行也想要数组，可勾选“无表头”。

📐 工作原理与说明

本开发工具在前端本地完成解析、转换与处理，代码不离开浏览器，遵循对应语法与格式规范。 工具名称：CSV 转 YAML 转换器。

⚠️ 使用说明与注意事项
  • 逗号、换行、双引号会被自动按 RFC 4180 处理；包含逗号/换行的字段请用双引号包裹。
  • 无表头模式输出为嵌套数组，有表头模式输出为键值对列表。
  • 值为空时输出空字符串；如需 null 可后续手动替换。

📄 YAML 基础语法

结构写法
列表- item1
- item2
映射key: value
嵌套parent:
  child: 1
多行文本text: |
  line1
  line2

本工具输出采用 2 空格缩进的标准 YAML；引号由 JSON.stringify 处理特殊字符，可被常见 YAML 解析器直接读取。
