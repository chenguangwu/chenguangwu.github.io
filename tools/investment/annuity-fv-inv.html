Annuity Future Value Calculator

Compute the future value of a level periodic investment from PMT, per-period rate r and period count n using FV = PMT·[(1+r)^n − 1]/r.

📐 计算公式
FV = PMT·((1+i)^n−1)/i

输入每期定投 PMT、每期利率 r 与期数 n，求年金终值。

📌 计算说明
  • 适用于定期定额投资。
  • 1000,5%,10 期 → 12578 元。

📚 深度解析：年金终值（每期定投积累）

💡 常见使用场景

  • 每月/每年定投，算 n 年后能攒多少，做养老或教育金规划。
  • 对比不同利率下年金终值的差距。
  • 估算基金定投、零存整取在若干期后的本息合计（含再投资收益）。
年投 1000、5%、10 年
FV = 1000×((1.05¹⁰−1)/0.05) = 1000×12.5779 ≈ 12578 元。即每年投 1000、5% 复利 10 年终值约 1.26 万。
月投 1000 元，月利率 0.5%，共 60 期
FV=1000×[(1.005⁶⁰−1)/0.005]≈69770.03 元；同期累计投入只有 60000 元，多出的 9770.03 元来自复利累积。

❓ 常见问题（FAQ）

和复利终值区别？
复利终值是一次性本金生息；年金终值是每期追加现金流的累计，多了期数维度。
期末付和期初付结果差多少？
本工具按普通年金（每期期末投入）计算。若改为每期期初投入，终值需再乘 (1+r)：上例为 69770.03×1.005≈70118.88 元。
