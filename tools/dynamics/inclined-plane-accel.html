a = g·(sinθ − μ·cosθ)

Enter the incline angle, static/kinetic friction coefficients, and initial state to decide whether the object starts from rest and compute the acceleration once sliding.

📐 计算公式
斜面临界与下滑加速度：先比较 tanθ 与静摩擦系数 μ_s 判断能否由静止起动；已滑动后用动摩擦系数 μ_k 计算 a = g × (sin θ − μ_k × cos θ)（m/s²）。校验：θ 须在 0–90°、μ_s/μ_k 非负、g 为正，空值或非数值会提示并中止，不按 0 兜底。判据：由静止释放且 tanθ ≤ μ_s → 静止（静摩擦平衡）；tanθ > μ_s → 起动。已向下滑动时 a > 0 加速、a = 0 匀速、a < 0 减速，负加速度不代表静止。

输入斜面倾角、静/动摩擦系数与初始状态，判断能否起动并计算已下滑时的加速度。

💡 常见使用场景

  • 斜面下滑：录入倾角与摩擦系数，求加速度，判断物体是否加速下滑（sinθ>μcosθ）。
  • 货物输送：对传送带/斜坡录入参数，估算下滑或需施加的约束力。
  • 教学演示：演示倾角增大加速度增大、摩擦增大则减小。
使用示例
示例：θ=30°、μ=0.2、g=9.8，a=9.8×(0.5−0.2×0.866)=9.8×0.327≈3.2 m/s²。

❓ 常见问题（FAQ）

物体一定下滑吗？
当 sinθ>μcosθ（即 tanθ>μ）才加速下滑；否则静止或需外力。结果按标准力学公式实时计算，供物理学习、作业演算与工程估算参考；涉及安全或实际工程请以专业规范与实测数据为准。
无摩擦时呢？
μ=0 时 a=g sinθ，即沿斜面分量决定加速度，与质量无关。结果按标准力学公式实时计算，供物理学习、作业演算与工程估算参考；涉及安全或实际工程请以专业规范与实测数据为准。
质量影响加速度吗？
理想斜面（无滚动）加速度与质量无关；若考虑转动惯量（滚动）则略降。结果按标准力学公式实时计算，供物理学习、作业演算与工程估算参考；涉及安全或实际工程请以专业规范与实测数据为准。
