📖 罗经校正原理

三种航向关系

  • 真航向 TH：以真北（地理北）为基准
  • 磁航向 MH：以磁北为基准，TH = MH + Var（东差为正）
  • 罗航向 CH：罗经读数，MH = CH + Dev（东差为正）
  • 综合：TH = CH + Dev + Var = CH + 总修正量（罗经差）

记忆口诀

  • "Can Dead Men Vote Twice At Elections"
  • Compass → Deviation → Magnetic → Variation → True（罗→自→磁→差→真）
  • 从罗到真：依次加上自差、磁差（东正西负）
  • 从真到罗：依次减去磁差、自差

自差五系数模型

  • Dev = A + B×sin(CH) + C×cos(CH) + D×sin(2×CH) + E×cos(2×CH)
  • A：固定系数（安装误差）
  • B、C：半圆自差（硬铁磁化）
  • D、E：象限自差（软铁感应）
磁差（Var）随地理位置变化，可查询海图标注；自差（Dev）随船舶航向变化，需定期校准测定。
