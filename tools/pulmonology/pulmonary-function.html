📋 通气功能障碍判读逻辑

类型条件说明
正常FEV1/FVC ≥ 阈值 且 FVC ≥ 80%预计通气功能正常
阻塞性FEV1/FVC < 阈值气流受限，常见于COPD/哮喘
限制性FEV1/FVC ≥ 阈值 且 FVC < 80%预计需TLC确认，见于肺纤维化/胸壁疾病
混合性FEV1/FVC < 阈值 且 FVC < 80%预计同时存在阻塞与限制

📊 GOLD 阻塞性气流受限严重度（基于 FEV1%预计值）

分级严重度FEV1 %预计值
GOLD 1轻度≥80%
GOLD 2中度50–79%
GOLD 3重度30–49%
GOLD 4极重度<30%
提示：FEV1/FVC 固定阈值 0.70 对年轻人可能高估、对老年人可能低估阻塞性疾病，建议结合 LLN(正常下限) 综合判读。限制性障碍需肺总量(TLC)确认。支气管舒张试验后 FEV1/FVC<0.70 提示不完全可逆气流受限(COPD)。仅供临床参考。
