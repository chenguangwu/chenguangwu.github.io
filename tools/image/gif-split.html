📝工具简介

GIF分解工具是一款图像处理类的在线工具，用于将 GIF 动画逐帧分解提取。工具直接在浏览器中解析 GIF 二进制格式（GIF89a），还原每一帧画面，支持单帧下载 PNG 与批量打包 ZIP，所有处理本地完成，文件不上传。

✨功能特点

  • 纯前端解析，GIF 不离开设备
  • 逐帧提取，显示帧序号与延迟时间
  • 正确处理透明色与帧叠加合成
  • 单帧下载 PNG，批量打包 ZIP
  • 点击缩略图放大预览，支持前后切换
  • 显示总帧数、尺寸、循环次数等信息
  • 支持深色模式与响应式布局

🎯使用场景

  • 提取 GIF 动画的某一帧做素材
  • 将 GIF 转为 PNG 序列帧
  • 分析 GIF 的帧率与延迟设置
  • 逐帧查看动画细节与过渡
  • 获取 GIF 透明通道的单独帧
  • 隐私敏感的动图处理需求

💬常见问题

这个工具是免费的吗？
完全免费，无需注册，直接在浏览器中使用。
我的 GIF 会被上传吗？
不会。所有解析与处理都在浏览器本地完成，GIF 文件不会发送到任何服务器。
提取的帧是什么格式？
每一帧可导出为 PNG 格式（支持透明通道），也可批量打包为 ZIP 下载。
为什么有的帧看起来是空白的？
部分 GIF 使用了帧叠加（disposal）与透明色，某些帧只包含变化部分。本工具会按规范合成完整画面，每帧均为完整可见图。
循环次数显示为「无限循环」是什么意思？
GIF 的 NETSCAPE 循环标记为 0 表示无限循环；若为 N 则表示循环 N 次。
