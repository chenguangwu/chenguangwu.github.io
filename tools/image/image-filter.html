❓ 常见问题（FAQ）

参数基准为什么是 100？
100 代表原值不调整；>100 增强（亮度/对比/饱和），<100 减弱；色相 0 为原色相。
模糊和灰阶会互相影响吗？
各自独立叠加。先定模糊程度再决定灰阶，顺序不同观感略有差异，可实时对比。

📝工具简介

上传本地图片后，通过 CSS Filter 与 Canvas 实时叠加灰度、模糊、对比度、饱和度等滤镜效果，支持参数滑动调节与结果预览，所有处理在浏览器本地完成，适合快速美化或统一图片风格

✨功能特点

  • 纯前端单图处理，无需上传
  • 支持 PNG、JPEG、WebP、GIF 静态图
  • 20 个预设与自定义滑块，即时预览
  • 按住查看原图，保留当前参数
  • 保护隐私，图片不离开设备

🎯使用场景

  • 单张照片快速调色
  • 为同一组图片分别套用相近参数

  • 隐私敏感、不希望上传的图片处理
