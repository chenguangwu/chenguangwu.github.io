📝工具简介

图片拼图合成工具是一款免费的在线拼图生成器，可将多张图片按竖排、横排或网格布局合成为一张长图或拼图。基于浏览器 Canvas API 实时渲染，支持自定义间距、外边距、背景色、适应方式与拖拽排序，合成后可导出 PNG 或 JPG 图片。所有处理在本地完成，图片不会上传服务器。

✨功能特点

  • 多图上传，支持拖拽排序与上下移动
  • 竖排拼接、横排拼接、2×2 / 3×3 / 自定义网格
  • 可调图片间距（0~50px）与外边距
  • 自定义背景色，支持透明背景（PNG）
  • 自适应尺寸或固定宽度/高度
  • 网格适应方式：完整显示、填满裁剪、拉伸
  • 实时预览，一键下载 PNG / JPG
  • 纯前端处理，图片不上传，保护隐私

🎯使用场景

  • 将多张截图竖排拼接为长图分享
  • 制作朋友圈、小红书九宫格拼图
  • 产品多图合成一张展示图
  • 组合证件照、签证照排版
  • 旅行照片拼接成长卷预览
  • 课程笔记、聊天记录合并为长图

💬常见问题

我的图片会被上传到服务器吗？
不会。所有图片都在你的浏览器本地通过 Canvas 处理，不会发送到任何服务器，隐私安全有保障。
支持哪些图片格式？
支持 PNG、JPG/JPEG、WEBP、GIF、BMP 等浏览器可解码的常见格式，可一次选择多张。
网格布局图片数量不够怎么办？
图片数量少于网格格子数时，多余格子会显示为背景色；图片数量多于格子数时，仅合成前若干张（可在预览信息中看到提示）。
为什么导出的图片很大？
合成画布尺寸由图片数量与布局决定，图片越多越大。可在「尺寸模式」中选择固定宽度/高度来控制输出尺寸，工具也会在画布过大时自动等比缩放以保证合成成功。
透明背景有什么用？
勾选透明背景后，导出的 PNG 会保留透明区域（适合完整显示留白模式）；若下载 JPG，会自动填充白色背景。
