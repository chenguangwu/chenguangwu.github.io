⚠️ 使用说明与注意事项
  • 本工具纯前端运行，图片不会上传到任何服务器，保护隐私安全
  • JPEG 为有损格式，不支持透明背景（透明区域会填充白色）
  • WebP 兼容现代浏览器（Chrome/Edge/Firefox/Safari 14+），压缩率最优
  • PNG 为无损格式，质量滑块不生效；对照片压缩效果有限
  • 「最大尺寸」会等比缩放图片，使长边不超过设定值
  • 部分旧浏览器可能不支持 WebP 输出，如遇失败请改选 JPEG

图片压缩工具是一款在线图像处理工具，利用浏览器 Canvas API 对图片进行压缩与优化。支持 JPEG、WebP、PNG 三种输出格式，可自由调节压缩质量（1%～100%），并可设置最大尺寸进行等比缩放。支持单张实时对比预览与多张批量压缩，所有处理在本地浏览器完成，图片不离开设备。

💬常见问题

图片会被上传到服务器吗？
不会。所有压缩处理都在你自己的浏览器中通过 Canvas API 完成，图片数据不会发送到任何服务器，完全保护隐私。
为什么压缩后图片反而变大了？
当原图本身已是高度压缩的格式（如小体积 JPEG），转成 PNG 无损格式时体积可能增大。建议照片使用 JPEG 或 WebP 格式，图标/截图使用 PNG。
WebP 和 JPEG 哪个更好？
WebP 在同等画质下通常比 JPEG 体积更小（约小 25%-35%），且支持透明通道。现代浏览器均支持 WebP，推荐优先使用。如需兼容老旧环境，可选 JPEG。
质量滑块设为多少合适？
一般 70%-85% 即可在体积与画质间取得良好平衡。网页用图建议 70%-80%，需要高清保留细节可设 85%-95%。可拖动对比滑块实时查看效果。
支持哪些图片格式上传？
支持所有浏览器能解析的图片格式，包括 JPEG、PNG、WebP、GIF（静态）、BMP 等。输出仅支持 JPEG、WebP、PNG 三种常见格式。
