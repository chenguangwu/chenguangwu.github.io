图片水印工具是一款基于 Canvas API 的纯前端在线图片加水印工具。无需安装软件，上传图片后即可添加文字水印或图片水印，支持 9 宫格快速定位、自定义坐标、全图平铺与旋转角度，实时预览效果并一键导出 PNG/JPEG/WebP，所有处理在浏览器本地完成，图片不会上传到服务器。

💬 常见问题

图片会被上传到服务器吗？
不会。所有图片读取、水印绘制、导出均在你的浏览器本地通过 Canvas API 完成，图片数据不会离开你的设备。
平铺水印的旋转角度有什么用？
旋转角度让平铺的水印呈对角线分布（如 -30°），比正交排列更美观且更难被裁剪去除，是常见的防盗水印样式。配合"偏移错位"可让相邻行交错排列。
导出 PNG 还是 JPEG？
PNG 为无损格式且支持透明背景，适合需要高保真的场景；JPEG 为有损压缩，文件更小但不支持透明；WebP 兼顾质量与体积。建议版权水印优先用 PNG。
支持的最大图片尺寸？
取决于浏览器 Canvas 的内存限制，一般支持千万像素级图片。超大图片可能导致处理变慢，建议适当压缩后再加水印。
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，图片文件不会上传到服务器
  • 建议在主流浏览器（Chrome / Safari / Firefox / Edge）中使用
  • JPEG 格式不支持透明，导出时背景为白色
  • 超大图片处理可能需要数秒，请耐心等待预览刷新
  • 调整任意参数会实时刷新预览，所见即所得
