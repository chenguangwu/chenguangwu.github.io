📝工具简介

图片缩放工具是一款基于浏览器 Canvas API 的在线图像尺寸调整工具。支持按百分比比例缩放和精确指定目标宽高两种模式，可一键锁定宽高比保持画面比例，提供平滑（双线性高质量）与快速（最近邻）两种重采样算法，并支持 PNG、JPEG、WebP 三种输出格式及质量调节。所有处理在本地完成，图片不上传，安全可靠。

✨功能特点

  • 按比例缩放（10%~200%滑块 + 预设按钮）
  • 精确指定目标宽高，可锁定宽高比
  • 平滑 / 快速两种重采样算法可选
  • PNG / JPEG / WebP 多格式输出
  • JPEG/WebP 质量可调（10%~100%）
  • 实时预览缩放效果与尺寸对比
  • 纯前端 Canvas 处理，图片不上传
  • 支持深色模式与移动端响应式布局

🎯使用场景

  • 网页配图按比例缩小，优化加载速度
  • 缩略图 / 封面图批量尺寸调整
  • 社交媒体头像、封面尺寸适配
  • 证件照、报名照指定像素尺寸
  • 壁纸、 banner 放大或缩小
  • 邮件附件图片压缩减小体积

💬常见问题

图片会被上传到服务器吗？
不会。本工具使用浏览器原生 Canvas API 在本地完成所有缩放处理，图片数据始终留在您的设备上，不会发送到任何服务器。
放大图片会变得更清晰吗？
不会。放大只是将原有像素信息拉伸或插值到更大尺寸，无法凭空增加真实细节。建议选择"平滑"算法以获得更自然的放大效果。
平滑算法和快速算法有什么区别？
平滑算法使用双线性插值，画质更好但稍慢；快速算法使用最近邻采样，速度最快但放大会出现明显锯齿。日常使用建议选平滑算法。
为什么 JPEG 输出后透明背景变白了？
JPEG 格式本身不支持透明通道，导出时会自动以白色填充背景。如需保留透明效果，请选择 PNG 或 WebP 格式输出。

完全免费，无需注册登录，直接在浏览器中打开即可使用，无使用次数限制。
