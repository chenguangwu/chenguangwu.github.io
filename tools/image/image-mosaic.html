📝工具简介

图片马赛克效果工具是一款在线图像处理工具，可将图片像素化以实现打码遮挡效果。支持全图马赛克与局部区域框选马赛克两种模式，可通过滑块自由调节像素块大小并实时预览，处理完成后可下载 PNG 或 JPEG 图片。所有运算均在浏览器本地完成，图片不上传服务器，隐私安全有保障。

✨功能特点

  • 纯前端 Canvas 处理，图片不上传
  • 全图马赛克与区域框选马赛克两种模式
  • 像素块大小 2~50px 自由调节，实时预览
  • 支持拖拽上传与触摸框选，移动端友好
  • 按原图分辨率导出 PNG/JPEG，画质无损
  • 支持深色模式与响应式布局

🎯使用场景

  • 遮挡身份证、车牌、人脸等隐私信息
  • 给分享截图中的敏感内容打码
  • 制作像素化风格的创意图片
  • 隐藏图片中的文字、水印或账号信息
  • 对局部区域进行模糊遮挡处理
  • 隐私敏感场景下的本地图片处理

💬常见问题

这个工具是免费的吗？
完全免费，无需注册登录，直接在浏览器中打开即可使用。
我的图片会被上传到服务器吗？
不会。所有马赛克处理都在你的浏览器本地通过 Canvas API 完成，图片数据不会发送到任何服务器，充分保护隐私。
如何只对图片的某一部分打马赛克？
点击「区域马赛克」切换到区域模式，然后在图片上按住鼠标或手指拖拽框选需要打码的区域，松手后即可实时看到效果，可反复拖拽调整。
像素块大小设为多少比较合适？
一般 8~30px 效果较好：数值越大遮挡越彻底但越粗糙，数值越小越精细但可能仍能辨认细节。请根据遮挡需求调节。
下载的图片是原始分辨率吗？
是的，下载时会按图片原始分辨率重新渲染马赛克效果，不会因为预览缩放而降低画质。PNG 为无损格式，JPEG 文件更小。
支持哪些图片格式？
支持 JPG、PNG、WebP、GIF、BMP 等主流图片格式，导出时可选择 PNG 或 JPEG。
