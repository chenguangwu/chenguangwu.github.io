📝工具简介

图片裁剪工具是一款基于 HTML5 Canvas 的在线图片处理工具。无需安装软件、无需注册登录，打开网页即可使用。支持自由拖拽创建裁剪框、四角四边调整大小、多种宽高比预设、90° 旋转以及实时预览，全部在浏览器本地完成，图片不离开设备。

✨功能特点

  • 拖拽创建裁剪框，所见即所得
  • 四角 + 四边八向调整大小
  • 7 种宽高比预设（1:1、4:3、16:9 等）
  • 90° 左右旋转，裁剪前自由调整方向
  • 实时显示裁剪坐标与尺寸
  • 实时预览裁剪结果
  • 支持 PNG / JPEG 输出与质量控制
  • 纯前端处理，图片不上传，保护隐私
  • 支持深色模式与移动端响应式布局

🎯使用场景

  • 裁剪头像、证件照尺寸调整
  • 社交媒体封面图（16:9 / 1:1）
  • 手机壁纸裁剪（9:16 竖屏）
  • 电商主图、详情图比例裁剪
  • 去除图片多余边距与水印区域
  • 批量前处理素材，快速构图

💬常见问题

这个工具是免费的吗？
完全免费，无需注册，直接在浏览器中打开即可使用，没有任何使用次数限制。
我的图片会被上传吗？
不会。所有裁剪、旋转、预览操作都在浏览器本地通过 Canvas 完成，图片不会发送到任何服务器，隐私安全有保障。
支持哪些图片格式？
支持读取 PNG、JPG/JPEG、GIF（首帧）、WebP、BMP 等主流格式。导出时可选择 PNG（保留透明）或 JPEG（体积更小）。
如何精确控制裁剪比例？
点击上方「宽高比预设」中的任意比例（如 1:1、16:9），裁剪框将自动锁定该比例，拖拽四角时会保持比例不变。选择「自由」则可任意调整。
裁剪后的图片清晰度会下降吗？
不会。裁剪基于原始分辨率进行，导出 PNG 时为无损画质；选择 JPEG 时可通过质量滑块平衡画质与体积。
