📈 Z-Score (Standard Score) Calculator

📐 计算公式
Z = (X - μ) / σ

Compute the z-score of a value in a dataset.

公式：Z = (X - μ) / σ。Z 分数表示原始分数与平均值之间相差几个标准差。

📋 Z 分数等级参考

Z 分数范围百分位近似等级描述
Z ≥ 2.0≥ 97.7%优秀（远超平均）
1.0 ≤ Z < 2.084.1%–97.7%良好（高于平均）
-1.0 ≤ Z < 1.015.9%–84.1%中等（接近平均）
-2.0 ≤ Z < -1.02.3%–15.9%偏低（低于平均）
Z < -2.0< 2.3%较低（远低于平均）
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器。
  • 百分位基于标准正态分布近似估算。
  • 若数据不服从正态分布，Z 分数解释需谨慎。

📝工具简介

Z 分数（标准分数）用于衡量某个数值相对于数据集平均水平的偏离程度。Z = 0 表示等于平均值，Z 为正表示高于平均，Z 为负表示低于平均。

✨功能特点

  • 自动计算 Z 分数
  • 估算标准正态百分位
  • 给出等级评价
  • 支持反向指标（越低越好）

🎯使用场景

  • 考试成绩标准化分析
  • 心理测评分数解读
  • 竞赛成绩横向对比
  • 统计学课程学习

💬常见问题

Z 分数为 1 代表什么？
表示该分数比平均值高 1 个标准差，约高于 84% 的数据。
百分位是怎么估算的？
基于标准正态分布累积分布函数近似计算，假设数据近似正态分布。
