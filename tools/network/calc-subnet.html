🌐 子网掩码计算（CIDR / 子网划分）

输入 IP 地址与 CIDR 前缀（如 24 或 /24）或点分掩码，自动计算网络信息

💡 公式：网络地址 = IP AND 掩码；广播地址 = IP OR 通配符掩码；可用主机数 = 2^(32-前缀) - 2

✂️ 子网划分

⚠️ 使用说明与注意事项
  • 支持 IPv4，CIDR 前缀范围 0–32，掩码如 255.255.255.0 也可自动识别
  • /31 为点对点链路（2 个地址），/32 为单主机地址，主机数按规范处理
  • 按 Enter 快速计算，Ctrl/Cmd + Enter 复制结果
  • 本工具纯前端运行，数据不会上传到服务器

📝工具简介

输入 IPv4 地址与 CIDR 前缀或子网掩码，自动计算网络地址、广播地址、可用主机范围、通配符掩码、IP 类别与公私网类型，并支持按数量划分子网。

✨功能特点

  • 支持 CIDR 前缀与点分掩码两种输入
  • 自动识别 IP 类别（A/B/C/D/E）与公网/私有地址
  • 支持子网划分，借用主机位生成多个子网
  • 纯前端处理，数据不上传服务器

🎯使用场景

  • 网络工程师日常排障

💬常见问题

CIDR 前缀和子网掩码是什么关系？
前缀 /24 等价于掩码 255.255.255.0，前缀表示网络位的数量，剩余为主机位。
为什么 /31 有 2 个可用主机？
/31 为点对点链路专用（RFC 3021），两个地址均可用作主机，无需网络号和广播地址。
我的数据会被上传吗？
不会。所有计算都在浏览器本地完成，数据不会发送到任何服务器。
