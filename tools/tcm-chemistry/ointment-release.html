常用中药软膏处方

紫草膏（油脂性基质）

紫草提取物 + 当归提取物 + 凡士林基质

释药较慢，适合慢性皮损修复

黄连软膏（O/W乳剂）

小檗碱 + 十六/十八醇 + 吐温/司盘乳化

释药快，适合急性感染性皮肤

冰片凝胶（水凝胶基质）

冰片 + 薄荷脑 + 卡波姆凝胶

释药快，清凉感强，适合蚊虫叮咬

释放度测定方法

方法：浆碟法（药典通则1093）

介质：磷酸盐缓冲液（pH 5.0-7.4）或人工汗液

温度：32±0.5°C（模拟皮肤温度）

取样时间：1h、2h、4h、6h、8h、12h、24h

评价：计算各时间点累积释放量，绘制释放曲线

释放动力学模型

Higuchi模型：Q = K√t （基质型控释）

零级动力学：Q = K₀t （恒速释放）

一级动力学：ln(1-Q) = -K₁t

Korsmeyer-Peppas：Q = K·tⁿ（n≤0.45 Fick扩散，0.45<n<0.89 混合机制）
