⛅ Drought Assessment Model

Assess drought severity from precipitation deficit and soil moisture using standardized indices.

📐 计算方式
标准化降水指数 SPI = (当期降水量 − 同期均值) ÷ 标准差，标准差 ≤ 0 或数据无效时提示输入有效数据。干旱等级：SPI ≥ −0.5 无旱、≥ −1.0 轻旱、≥ −1.5 中旱、≥ −2.0 重旱、< −2.0 特旱；进度条按 (SPI + 3) ÷ 3 × 100% 且下限取 0

干旱评估用两类指标：降水距平百分率 Pa=(当前降水量−同期均值)÷同期均值×100%，按 Pa 阈值分级（≥−15% 无旱、−30% 轻旱、−50% 中旱、−70% 重旱、<−70% 特旱）；标准化降水指数 SPI=(当前−均值)÷标准差，按 SPI 阈值（≥−0.5 无旱、−1.0 轻旱、−1.5 中旱、−2.0 重旱、<−2.0 特旱）分级，用于多时间尺度干旱监测。

降水距平百分率 Pa = (P - P̄) / P̄ × 100%

SPI ≈ (P - P̄) / σ（简化Z-score近似法）

Formula & Standard References

ItemFormulaSource / Standard
Standardised precipitation index SPI = (P - mean) / standard deviation WMO SPI user guide
Precipitation anomaly percent PA = (P - normal) / normal * 100 WMO drought monitoring guidance
Drought class thresholds SPI at or below -1.0 moderate drought WMO SPI classification
⚠️ 使用说明与注意事项
  • 降水距平百分率Pa适用于快速评估，需多年（≥30年）气象数据
  • SPI采用Z-score近似法，精确值需用Gamma分布拟合
  • SPI-1/3监测短期气象干旱，SPI-6/12监测长期水文干旱
  • 干旱评估需结合土壤墒情、径流量等综合判断
  • 纯前端运行，数据不会上传到服务器

📚 深度解析：气象灾害风险评估

💡 常见使用场景

  • 对某区域按历史极值与暴露度评气象灾害等级。
  • 基建选址看台风/暴雨/雷电综合风险。
  • 出具风险分级支撑保险与预案。
综合评级
某园区台风最大风速 33m/s（12级）、年暴雨日 12、雷暴日 80 → 三项加权得风险指数 78/100（高），建议一级防雷+排涝。
分级阈值
风险指数<40 低、40–70 中、>70 高；该园区 78 落高风险，须按高等级配防御设施。

❓ 常见问题（FAQ）

风险评估靠什么数据？
历史极值（最大风速、最大雨量）、频率、暴露人口/资产，缺长时间序列会偏保守。
指数高就一定受灾？
不一定，指数是「可能性×后果」的量级，配合防御能力才决定实际损失。

📝工具简介

干旱评估计算工具，支持降水距平百分率（Pa）和标准化降水指数（SPI）两种干旱指标计算，自动判定无旱/轻旱/中旱/重旱/特旱五级干旱等级。

✨功能特点

  • 降水距平百分率法（GB/T 20481）
  • SPI标准化降水指数计算（多时间尺度）
  • 五级干旱等级自动判定
  • 分级抗旱应对建议
  • 纯前端处理，数据不上传服务器

🎯使用场景

  • 气象干旱监测与预警
  • 农业干旱风险评估
  • 抗旱应急响应决策
  • 干旱科学研究与教学
