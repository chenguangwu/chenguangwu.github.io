📋 莫氏硬度等级说明

莫氏硬度(Mohs)：由德国矿物学家莫斯(Friedrich Mohs)于1812年提出，以10种标准矿物为参照，表示矿物抵抗刻划的能力。

标准矿物：1滑石 → 2石膏 → 3方解石 → 4萤石 → 5磷灰石 → 6正长石 → 7石英 → 8黄玉 → 9刚玉 → 10金刚石。

佩戴建议：硬度≥7适合日常佩戴(耐刮擦)；硬度6-7需小心使用；硬度<6仅适合耳环、吊坠等不易碰撞的饰品，避免与硬物接触。
