Optical Path Length Calculator

Compute optical path length and optical path difference for interference analysis.

📐 计算公式
光程：光程 OPL = 折射率 n × 几何路程 L（mm）；联动量：米口径 = nL ÷ 1000（m）、折射率增量 = n−1、光程与 (n+1) 之比 = nL ÷ max(n+1,10⁻⁹)。校验：无强校验，空值按 0 兜底。判据：无固定分级，光程即同等传播时间内光在真空中走过的距离，n 越大光程越长。

由折射率与几何路程，按 光程 = n·L 计算光在介质中的等效真空路径。

📌 计算说明
  • 光程是把介质路径折算为真空等效长度，费马原理与干涉分析的基础。

📚 深度解析：光程计算

💡 常见使用场景

  • 由介质折射率与几何路程算光程 OPL=n·L。
  • 干涉/等光程条件用。
  • 费马原理等效空气路径。
单介质
n=1.5 的玻璃厚 10cm → 光程 OPL=1.5×10=15cm，等效空气走 15cm 的相位延迟。
多段
空气 5cm(n=1)+水 3cm(n=1.33) → OPL=5+3.99=8.99cm；干涉看各路 OPL 差是否为 λ 整数倍。

❓ 常见问题（FAQ）

光程是什么？
几何路程按折射率加权，反映相位累积；等光程即等相位，是干涉亮暗的判据。
光程和路程区别？
真空中相等；介质中光程=折射率×路程，比几何路程长（光变慢）。
