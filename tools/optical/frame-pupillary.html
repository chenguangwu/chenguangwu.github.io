👓 镜框尺寸与瞳距计算器

📐 计算公式
单眼移心量 = (A + DBL) / 2 − PD / 2

根据镜圈宽度A、鼻梁宽度DBL与瞳距PD，计算每眼移心量与所需最小镜片直径

几何中心距 = A + DBL（两镜圈几何中心间距）
单眼移心量 = (A + DBL) / 2 − PD / 2，正值表示向鼻侧(内)移心，负值向颞侧(外)移心
最小未切边片径 = ED + 2×|移心量| + 2mm 磨边余量
移心量过大需更大直径镜片或定制片，实际还需考虑散光轴位与棱镜移心。结果供配镜加工参考。
