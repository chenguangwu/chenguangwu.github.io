📐 工作原理与说明
合计 = Σ各分项金额；各分项占比 = 金额 / 合计 × 100%；前 N 大项累计占比 = 金额前 N 大之和 / 合计 × 100%；偏差 = (合计 − 参考预算) / 参考预算 × 100%。
预算编制与成本控制中，先汇总各分项得到总投资或年运营成本，再用占比结构识别主要成本驱动项（前 N 大项），并对照参考预算判断超支或节余。结果随口径与价格假设变化，正式预算以内部核算制度为准。

💡 常见使用场景

  • 项目预算编制：汇总设备、安装、原料、能耗等分项，得总投资与年运营成本，支撑立项与比选。
  • 成本结构分析：用各分项占比与前 N 大项累计占比识别主要成本驱动，聚焦降本重点。
  • 偏差监控：对照参考预算量化超支或节余及偏差率，辅助预算执行跟踪。
算例（6 个分项，参考预算 2500）
分项金额（元）：800、200、1200、300、500、150。合计 3150.00；最大分项 1200.00、最小 150.00；各分项占比最高 38.10%（1200）；前 3 大项（1200、800、500）累计占比 79.37%；对比参考预算 2500 超支 650.00（偏差 26.00%）。

❓ 常见问题（FAQ）

前 N 大项累计占比有什么用？
它快速指出贡献最大的少数分项。例如前 3 大项累计占比接近 80% 时，意味着降本重点应放在这几个核心分项上，而非平均用力。
偏差率正负怎么看？
合计大于参考预算时显示「超支」与正偏差率，小于时显示「节余」与负偏差率；偏差率绝对值越大，预算执行偏离越多，需核查口径与价格假设。
