📖 YAML 语法说明

  • 缩进：必须用空格，不能用 Tab，相同层级缩进相同
  • 键值对：key: value（冒号后有空格）
  • 数组：用 - 开头，或 [a, b, c]
  • 对象：用 {key: value} 内联格式
  • 字符串：通常无需引号，含特殊字符时用单/双引号
  • 多行字符串：| 保留换行，> 折叠换行
  • 注释：# 开头
  • 布尔：true/false/yes/no
  • 空值：null 或 ~
