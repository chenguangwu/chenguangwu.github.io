💡 使用说明

  • CSV → JSON: 第一行作为字段名，每行一条记录
  • JSON → CSV: 自动提取所有字段，生成表头
  • 支持带引号的字段（包含分隔符、换行符）
  • 支持嵌套 JSON 对象（输出为 JSON 字符串字段）
  • 支持数字自动识别（可关闭保持字符串）
  • Excel 复制的内容可直接粘贴为 CSV
⚠️ 使用说明与注意事项
  • 本工具纯前端运行，数据不会上传到服务器
  • 建议在主流浏览器（Chrome/Safari/Firefox/Edge）中使用
