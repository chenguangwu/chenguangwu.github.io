📐 计算公式 / 原理
X 是 Y 的百分之几 = X ÷ Y × 100%；Y 的 p% = p ÷ 100 × Y；增加后 = X × (1 + p÷100)；减少后 = X × (1 − p÷100)

❓ 常见问题（FAQ）

百分比点？
与百分点不同，后者是差值单位。
「百分比」和「百分点」一样吗？
不一样。从 10% 升到 12% 是涨了 2 个百分点、涨幅 20%；两者含义不同，汇报时需区分。

📖关于「百分比计算器」 ▼

📝工具简介

支持五种常用百分比算法：X 是 Y 的百分之几、Y 的 X% 是多少、按百分比增加、按百分比减少，以及从旧值到新值的变化率。输入后即显示结果，并说明百分点与变化率的区别、分母或旧值为 0 时的处理，以及负基数下变化率符号的局限。

✨功能特点

  • 五种模式分别对应占比、求值、增减和变化率，不把百分点当成百分比
  • 分母为 0 明确提示；旧值为 0 时改给绝对增量，不伪造无穷增长率
  • 负基数单独提示：变化率符号不代表数值方向，以绝对变化为准
  • 纯前端处理，数据不上传，支持手机使用

🎯使用场景

  • 折扣、税费、涨幅与降幅：计算折后价、加价后的金额或变化比例
  • 成绩、投票、销售占比：用“X 是 Y 的百分之几”核对部分与整体
  • 预算与配额：按总额的某个百分比分配金额
  • 数据对比：用变化率比较旧值到新值，并另行说明百分点差异
