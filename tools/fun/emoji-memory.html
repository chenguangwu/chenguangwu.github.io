😊 Emoji Memory Game

📐 工作原理与说明
每轮从表情库中取下标 floor(随机数 × 表情总数) 的表情追加进序列，序列长度受「当前长度 + 2 与表情总数取较小值」限制；答对则关卡 +1；重置时置为未开始态、清空序列与关卡显示并移除隐藏样式

Match pairs of Emoji across increasing levels to train visual memory and concentration. Runs entirely in the browser and offline.

📚 深度解析：Emoji 记忆配对游戏

💡 常见使用场景

  • 记忆训练：翻牌找出成对的 Emoji，练视觉记忆与专注。
  • 关卡递增：对数随关卡增多，难度逐步上升。
  • 休闲放松：纯前端离线可玩，记录最短步数/时间。
方法（配对规则）
棋盘初始全部盖住，每次翻两张；相同则消除、不同则盖回，全部配对成功过关。关卡越高对数越多。
算例（演示）
第 1 关 6 对（12 格），全配对过关；第 3 关 10 对（20 格）。记录最短翻牌步数与用时，错翻越多步数越长，用「位置编码」能减少回翻。

❓ 常见问题（FAQ）

怎么记牌更快？
翻第一张时就在脑里给位置编号，错配后记住那两张在哪，下次直接配对。
有提示吗？
翻错会自动盖回，本身即「负向提示」；部分版本提供限时预览。
