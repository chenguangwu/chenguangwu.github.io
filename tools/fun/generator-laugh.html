✨ Laugh Sound Generator (Web Audio)

Synthesizes a variety of laughs in real time with the Web Audio API, with randomized parameter tweaks and downloadable output.

📐 工作原理与说明

笑声由 Web Audio API 在浏览器内实时合成,不涉及任何第三方音频素材:

  • 基频振荡器(sawtooth / square)模拟声带"哈"的顿挫。
  • ADSR 包络控制每个"哈"的起音/衰减/释放,形成节奏。
  • LFO 颤音 + 共振峰(formant)滤波逼近人声元音音色。

参数随机微调产生多样的"哈哈哈"。合成音频可自由下载使用,无版权风险。

用浏览器原生 Web Audio API 实时合成：基频振荡 + 颤音(LFO) + 包络(起承转合) 拼出笑声波形，可调参数后导出本地 wav，无第三方音频素材。
