🔥 铸件凝固时间（模数法）计算

基于 Chvorinov 法则 t = C × (V/A)²，输入截面形状与尺寸自动计算模数 M 与凝固时间 t，支持多截面凝固顺序排序。

📐 铸件截面

💡 Chvorinov 法则：t = C × M²，M = V/A（模数 = 体积/冷却表面积）；凝固时间长者后凝固，冒口模数应大于补缩部位模数。

📊 常用凝固常数 C 参考值

⚠️ 使用说明与注意事项
  • 按 Enter 快速计算，Ctrl/Cmd + Enter 复制结果
  • C 值为经验常数，受铸型材料、浇注温度、合金特性影响
  • 模数法适用于砂型铸造，金属型需修正
  • 冒口设计原则：M_冒口 ≥ 1.2 × M_铸件
  • 本工具纯前端运行，数据不会上传到服务器

📝工具简介

基于 Chvorinov 法则 t = C × (V/A)² 计算铸件凝固时间。支持平板、圆柱、立方体、球体、矩形杆、矩形块等多种截面形状，自动计算模数与凝固时间，排序凝固顺序，辅助冒口设计。

✨功能特点

  • 纯前端处理，数据不上传服务器
  • 支持 7 种截面形状自动计算模数
  • 多截面凝固顺序排序与对比
  • 冒口模数建议（M ≥ 1.2 × M_铸件）

🎯使用场景

  • 铸造工艺设计与冒口布置
  • 铸件凝固顺序分析
  • 铸造工艺教学与学习
  • 浇注系统设计参考
