📐 工作原理与说明
HBW = 0.0469·HRC² + 4.87·HRC + 108（HRC→布氏硬度拟合式，适用 HRC 20~67）；输入制式为 HBW 时改由求根公式 (−b+√(b²−4ac)) ÷ (2a) 反解 HRC，无实根或越界不输出数值；输入制式为 HV 时 HBW = 0.9544·HV（近似换算）。判据：反解 HRC 超出 [20,67] 显示「超出拟合区间」，HRC 输入须落在 20~67。
HV = 0.1865·HRC² − 1.455·HRC + 156.7（HRC→维氏硬度拟合式，适用 HRC 20~67）；输入制式为 HV 时由求根公式 (−b+√(b²−4ac)) ÷ (2a) 反解 HRC，HV 输出即输入值；输入制式为 HBW 时 HV = HBW ÷ 0.9544。判据：反解 HRC 超出 [20,67] 显示「超出拟合区间」，不再输出 NaN。

经验多项式（基于 ASTM E140 数据回归，20–67 HRC）；HB↔HV 取 HB = 0.9544·HV。仅供快速估算，精确值请查对照表。

💡 常见使用场景

  • 由 HRC 读数同时得到 HBW 与 HV（二次拟合）。
  • 由 HBW 或 HV 反算 HRC，并判断是否落在 20–67 有效区间。
  • 核对检测报告中 HRC/HBW/HV 三组数值是否自洽。
HRC 30 → HBW / HV
HRC 30：HBW = 0.0469×30² + 4.87×30 + 108 = 42.21 + 146.1 + 108 = 296.31；HV = 0.1865×30² − 1.455×30 + 156.7 = 167.85 − 43.65 + 156.7 = 280.90。页面输出 HRC 30.00 / HBW 296.31 / HV 280.90。
HBW / HV 反解 HRC
HBW 296.31 代入 0.0469x² + 4.87x + 108 = 296.31，解得 x ≈ 30.0；HV 280.90 代入 0.1865x² − 1.455x + 156.7 = 280.90，解得 x ≈ 30.0。反解仅在 HRC 20–67 内有效，超出时页面显示「—（超出 HRC 20–67 拟合区间）」。

❓ 常见问题（FAQ）

为什么 HRC 只适用于 20–67？
拟合式基于该区间数据，二次曲线外推误差迅速增大；HRC 低于 20 或高于 67 时应改用 HBW/HV，或按 ASTM E140 对照表换算。
HBW 与 HV 的 0.9544 是什么？
页面在 HBW 与 HV 之间采用近似比例 HV ≈ HBW ÷ 0.9544（即 HBW ≈ 0.9544×HV），仅在常用区间作工程换算；高精度场合仍以对照表为准。
跨标尺换算是精确值吗？
不是。三种标尺的压头、载荷与几何定义不同，二次拟合与查表均为近似；关键判据应以实测标尺和标准对照表为准。
