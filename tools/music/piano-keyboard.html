🎺 关于钢琴键盘模拟器
▼

这是一个完全在浏览器中运行的虚拟钢琴，使用 Web Audio API 合成逼真的钢琴音色。无需安装任何软件或插件，打开即用。

⚡ 功能特点

  • Web Audio API 合成音色
  • 三种音色：钢琴 / 电子琴 / 风琴
  • 键盘快捷键弹奏
  • 录制弹奏序列
  • 可回放录制内容
  • 可切换八度范围
  • ADSR 包络模拟
  • 响应式设计

🎬 使用场景

  • 音乐学习与练习
  • 旋律创作与灵感记录
  • 音高与和弦辨识训练
  • 教学演示与讲解

❓ 常见问题

声音没有播放怎么办？
Web Audio API 需要用户交互后才能激活。请点击页面上任意位置后再试。另外请确认设备没有静音。
如何在移动端使用？
直接用手指点击琴键即可弹奏。左右滑动可以查看完整键盘。
支持哪些音色？
目前提供钢琴（正弦波+衰减）、电子琴（方波）和风琴（正弦波+谐波）三种音色，每种都有独立的 ADSR 包络参数。
