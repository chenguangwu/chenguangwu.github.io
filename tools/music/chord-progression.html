🎶 关于和弦进行生成器 ▼

和弦进行（Chord Progression）是指一组和弦按照特定顺序排列，构成音乐的基本和声框架。不同风格的和弦进行能营造出截然不同的情感和氛围，是歌曲创作和编曲的核心元素。

❓ 常见问题

什么是 I-V-vi-IV 进行？
这是流行音乐中最常见的和弦进行，例如 C 大调中的 C-G-Am-F，几乎在数万首热门歌曲中出现。被称为"流行万能进行"。
罗马数字代表什么？
罗马数字代表和弦在音阶中的级数（如 I=一级和弦，V=五级和弦）。大写表示大三和弦，小写表示小三和弦。
播放功能如何工作？
使用浏览器原生的 Web Audio API 合成和弦音色，无需安装任何插件或加载外部音频文件。
