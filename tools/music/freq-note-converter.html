✦ 常见问题

什么是十二平均律？
将一个八度等分为12个半音的律制，每个半音的频率比为 2^(1/12) ≈ 1.0595。这是现代音乐最常用的律制。
偏差（cents）是什么意思？
1 cent 等于一个半音的 1/100。如果偏差为 +50 cents，说明频率比最近的音符高半个半音，刚好在两个音之间。
A4 = 432 Hz 和 440 Hz 有什么区别？
440 Hz 是国际标准音高（ISO 16）。432 Hz 被部分人认为更"自然"，但两者差仅约 32 cents（约 0.32 个半音），在音乐实践中有明显音高差异。
试听功能为什么没有声音？
请确认浏览器未静音且音量已开启。试听使用浏览器原生的 Web Audio API 生成正弦波，需要用户先与页面交互（点击）后才能播放。
