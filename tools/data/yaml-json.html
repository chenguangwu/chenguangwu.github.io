📄 YAML / JSON Converter

📐 工作原理与说明
JSON 转 YAML：先 JSON.parse 解析为对象，再按缩进层级递归序列化为 YAML 文本；YAML 转 JSON：先解析为对象，再以 JSON.stringify(对象, null, 2) 输出带两空格缩进的 JSON；任一环节异常时输出错误信息，输入为空白时清空输出

Convert between YAML and JSON in both directions with syntax validation and error hints.

📖 YAML 语法说明

  • 缩进：必须用空格，不能用 Tab，相同层级缩进相同
  • 键值对：key: value（冒号后有空格）
  • 数组：用 - 开头，或 [a, b, c]
  • 对象：用 {key: value} 内联格式
  • 字符串：通常无需引号，含特殊字符时用单/双引号
  • 多行字符串：| 保留换行，> 折叠换行
  • 注释：# 开头
  • 布尔：true/false/yes/no
  • 空值：null 或 ~

❓ 常见问题（FAQ）

注释保留？
JSON 无注释，转换即丢。
注释会保留吗？
不会。YAML 注释在解析为数据结构时即被丢弃，转向 JSON 或转回 YAML 都不保留注释，需另行备份。
