📊 CSV转JSON

在浏览器本地将 CSV 数据转换为 JSON 数组，支持自定义分隔符与表头。

📐 工作原理与说明

本工具用于单位与格式换算，换算因子依据国际单位制(SI)及相关标准定义，结果保留输入精度；纯前端本地处理。 工具名称：CSV转JSON - 在浏览器本地将 CSV 数据转换为 JSON 数组。

📌 转换规则
  • 首行为表头时，字段名取自第一行；否则使用 field_0、field_1 等默认键。
  • 支持引号包裹的字段，引号内可包含分隔符和换行。
  • 空单元格将转换为空字符串，未填写的行会被忽略。
