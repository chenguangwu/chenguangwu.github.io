📊 CSV to JSON Converter

Convert CSV data to a JSON array locally in your browser.

📐 工作原理与说明

本工具在浏览器本地将 CSV 文本解析并转换为 JSON 数组，支持自定义分隔符、引号与表头映射，数据不上传、代码不离开浏览器。 工具名称：CSV转JSON - 在浏览器本地将 CSV 数据转换为 JSON 数组。

📌 转换规则
  • 首行为表头时，字段名取自第一行；否则使用 field_0、field_1 等默认键。
  • 支持引号包裹的字段，引号内可包含分隔符和换行。
  • 空单元格将转换为空字符串，未填写的行会被忽略。

💡 常见使用场景

  • 接口联调：把后端导出的 CSV 结果快速转成 JSON 数组，直接粘贴进请求体或前端 mock，省去手写字段。
  • 表格迁移：Excel 或数据库导出的 CSV 需换成 JSON 以适配 NoSQL 存储或多维结构，转换后保留原始行列。
  • 字段对齐：转换时指定表头映射与分隔符，避免中文逗号、半角引号导致的解析错位与字段错位。
订单 CSV 转 JSON
粘贴含「订单号,金额,状态」三列的 CSV，选择逗号分隔、首行作为表头；工具输出 [{"订单号":"A1001","金额":"99.00","状态":"已付款"}]，可直接用于接口校验或前端表格渲染。

❓ 常见问题（FAQ）

支持哪些分隔符？
支持逗号、制表符、分号及自定义单字符；引号包裹字段内的分隔符不会被误拆，字段内容原样保留。
中文或特殊字符会乱码吗？
转换仅在本地进行，原样保留 UTF-8 字符；导出后建议以 UTF-8 保存，避免二次打开时编码错乱。
结果能直接当接口数据用吗？
仅做格式转换、不校验业务合法性；金额、日期等类型仍按字符串保留，接入前请按需做类型与范围校验。
