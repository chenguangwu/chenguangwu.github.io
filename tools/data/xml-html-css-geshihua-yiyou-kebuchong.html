📄 XML / HTML / CSS Formatter

Format and beautify XML, HTML and CSS code with proper indentation.

代码格式化按层级缩进重建排版：行首缩进宽度 = 当前层级 × 每级空格数。HTML/XML 依开闭标签配对计算层级，自闭合标签与 HTML 空元素（br、img、input 等）不加深；CSS 依花括号配对计算层级，每条声明单独成行。格式化后字符数 = 原字符数 + 各行缩进空格之和 + 换行符数，代码内容本身不做任何改写。

📚 深度解析：对 XML/HTML/CSS 代码做层级缩进美化与结构重排，辅助阅读、教学与排错。

💡 常见使用场景

  • 压缩后的 HTML/CSS 一行代码难以阅读，按层级缩进重排后快速定位嵌套关系与遗漏的闭合标签。
  • 写教学示例或文档片段时，把随手粘贴的紧凑代码整理成规范缩进，便于展示与讲解。
  • 排查布局/样式异常时，先格式化再逐层核对选择器与声明归属，减少肉眼比对成本。
可复现算例：HTML 片段按 4 空格缩进
输入：`<div class="a"><p>hi</p></div>`（30 字符，1 行），代码类型 HTML，缩进 4 空格。 处理：按开闭标签配对计算层级，div 为第 0 层、p 为第 1 层，行首缩进 = 层级 × 4 空格。 输出：3 行、36 字符（比原文本多 2 个换行符与 4 个缩进空格），最大嵌套深度 2 层，标签数 4 个。 结论：格式化只重排缩进与换行，不改变任何代码内容；把缩进改成 2 空格可再省 4 个字符。

❓ 常见问题（FAQ）

格式化会修改我的代码内容吗？
不会。只按开闭标签（HTML/XML）或花括号（CSS）的配对关系重排缩进与换行，标签名、属性、文本、声明内容均原样保留，可放心用于生产代码。
HTML 与 XML 的处理有什么区别？
区别在于空元素判定：HTML 模式下 br、img、input、meta 等空元素不加深层级；XML 模式只认自闭合写法（以 /> 结尾），其余一律视为需要闭合标签的普通元素。
能顺便校验语法错误吗？
本工具只做格式化，不替代完整语法校验。它会如实统计最大嵌套深度与标签数，若深度明显异常（例如少写闭合标签导致层级一直加深），可据此发现标签不配对的问题。
