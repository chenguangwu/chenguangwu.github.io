RL Time Constant

Compute the RL time constant from inductance L and resistance R using τ = L/R for transient-circuit analysis.

📐 计算公式
RL 时间常数（本页代码口径）：τ=L÷R（s，L 电感 H、R 电阻 Ω）；联动量：τ(ms)=τ×1000、时间常数倒数=1÷max(τ,10⁻¹²)、R÷L 比=R÷max(L,10⁻¹²)。校验：L、R 空值即提示并中止。判据：无固定分级，τ 越大电流建立越慢，工程上约 3τ~5τ 视为进入稳态。

输入电感 L 与电阻 R，求 RL 电路时间常数。
