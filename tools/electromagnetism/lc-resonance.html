LC Resonance Frequency

Compute the natural resonant frequency of an undamped LC circuit from L and C using f = 1/(2π√(L·C)).

📐 计算公式
LC 谐振频率（本页代码口径）：f = 1÷(2π×√(L×C))（Hz，L 按 mH÷1000 转 H、C 按 µF÷10⁶ 转 F 后代入 SI 式）；联动量：kHz 口径 = f÷1000、角频率 ω = 2π×f（rad/s）、谐振周期 T = 1÷(2π×f)（s）。校验：两项输入空值守卫，空值即提示；L 或 C 为 0 时除零结果按「—」兜底。判据：无固定分级，L 或 C 越大谐振频率越低（平方根反比），谐振时感抗与容抗相等。

无阻尼 LC 回路的固有谐振频率。

❓ 常见问题（FAQ）

Q 值如何影响选频？
Q 越高选择性越好（带通窄）；低 Q 适合宽带滤波/电源 LC 滤波。本工具为电磁学/电路基础辅助计算，结果仅供教学与方案预研参考，不替代正式工程设计、电磁兼容标准与持证工程师的判定。
为何实际谐振频率与计算偏差？
杂散电容（线圈匝间/对地）、引线电感、磁芯损耗均影响；高频需矢量网络分析仪实测。本工具为电磁学/电路基础辅助计算，结果仅供教学与方案预研参考，不替代正式工程设计、电磁兼容标准与持证工程师的判定。
