📐 分压公式

Vout = Vin × R2 / (R1 + R2)

Vin：输入电压
Vout：输出电压
R1：上拉电阻
R2：下拉电阻

🔄 逆推公式

R1 = R2 × (Vin/Vout - 1)
R2 = R1 / (Vin/Vout - 1)

已知目标输出电压时，可计算所需电阻值

⚡ 电路参数

• 回路电流：I = Vin / (R1 + R2)
• 总功耗：P = Vin × I = Vin² / (R1 + R2)
• R1功耗：P1 = I² × R1
• R2功耗：P2 = I² × R2

💡 设计要点

• 电阻值不宜过小，以免功耗过大
• 电阻值不宜过大，以免受负载影响
• 建议选择E24或E96系列标准电阻
• 考虑电阻精度对输出的影响
• 输出端接负载时需考虑负载效应
