📐 计算公式
n 次方根（本页代码口径）：结果=x^(1÷n)；x<0 且 n 为奇整数时取 −(−x)^(1÷n)，x<0 且 n 为偶整数时实数范围内无解、n 非整数时无定义，x=0 时结果为 0；验证式 (结果)ⁿ≈x 逐步展示。校验：x、n 非数值，或 n=0（根指数不能为 0）时提示并中止。判据：n 为 2–8 的整数且 x>0 时另列出全部 n 个复数根 x^(1÷n)×(cos(2πk÷n)+i·sin(2πk÷n))，k=0…n−1。
n 次方根 ⁿ√x = x^(1/n)：n 为奇数时负数亦有实根，n 为偶数时仅非负数有实根；n=0 无定义。

负根？
偶次根非负实根，奇次根可负（如 ∛-8=-2）。
