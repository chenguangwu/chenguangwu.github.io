📍 经纬度与UTM坐标转换

基于WGS84椭球体，在经纬度(WGS84)与UTM坐标之间互转

📖 UTM投影说明

WGS84椭球体参数

长半轴 a = 6378137.0 m

短半轴 b = 6356752.314245 m

扁率 f = 1/298.257223563

UTM分带规则

  • 全球分为60个带，每带宽6度经度
  • 带号从180度起向东编号 1-60
  • 中央经线 = (带号 - 1) x 6 - 180 + 3
  • 中央经线比例因子 k0 = 0.9996
  • 东移假值 = 500000 m（中央经线以东为正）
  • 北移假值 = 0 m（赤道），南半球加 10000000 m

坐标精度说明

  • 1度 ≈ 111 km（纬度方向）
  • 小数点后5位 ≈ 1.1 m 精度
  • 小数点后6位 ≈ 0.11 m 精度
  • 小数点后7位 ≈ 1.1 cm 精度
  • UTM坐标精度取决于投影变形，边缘区域误差增大
本工具使用简化的横轴墨卡托投影公式，适用于一般精度需求（米级）。高精度测绘请使用专业GIS软件。
