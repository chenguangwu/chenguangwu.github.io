📖 UTM投影说明

WGS84椭球体参数

长半轴 a = 6378137.0 m

短半轴 b = 6356752.314245 m

扁率 f = 1/298.257223563

UTM分带规则

  • 全球分为60个带，每带宽6度经度
  • 带号从180度起向东编号 1-60
  • 中央经线 = (带号 - 1) x 6 - 180 + 3
  • 中央经线比例因子 k0 = 0.9996
  • 东移假值 = 500000 m（中央经线以东为正）
  • 北移假值 = 0 m（赤道），南半球加 10000000 m

坐标精度说明

  • 1度 ≈ 111 km（纬度方向）
  • 小数点后5位 ≈ 1.1 m 精度
  • 小数点后6位 ≈ 0.11 m 精度
  • 小数点后7位 ≈ 1.1 cm 精度
  • UTM坐标精度取决于投影变形，边缘区域误差增大

💡 常见使用场景

  • 把 WGS84 经纬度投影到 UTM 平面坐标
  • GIS/测绘数据对接
  • 公里网坐标获取
投影
UTM 把地球分 60 个 6° 带，每带用横轴墨卡托投影为东向(E)/北向(N)米。如北京约在 50N 带，得 E/N 平面坐标便于工程计算。
带号
带号 = floor((经度+180)/6)+1；跨带需统一带号，否则坐标不连续。南北半球 N 从赤道起算（南半球加假北 1e7）。

❓ 常见问题（FAQ）

UTM 和经纬度区别？
经纬度是球面角坐标；UTM 是投影后的平面直角坐标（米），方便测距面积但仅局部准确、离带边变形大。
为什么要分带？
墨卡托投影在高纬/带边变形大，分带把变形控制在本带内，每带独立坐标系。
