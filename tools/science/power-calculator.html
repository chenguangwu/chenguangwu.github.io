📖 定义与公式
幂 aⁿ 表示 n 个底数 a 连乘（n 为正整数）。指数推广到实数后有：a⁰=1（a≠0）、a⁻ⁿ=1/aⁿ、a^(1/n)=ⁿ√a，以及指数律 aᵐ·aⁿ=a^(m+n)、(aᵐ)ⁿ=a^(m·n)、(a·b)ⁿ=aⁿ·bⁿ。对实数域，负底数只有在指数为整数时才有定义：(-2)³=-8 成立，(-2)^0.5 则无定义。本页以 Math.pow(a,b) 求值，并对「0 的负指数（除以零）」与「负数非整数次幂」给出明确提示。
⚠️ 适用条件与常见误用
底数为 0 且指数为负 → 除以零，页面判为未定义，不要当成 0。 负数只能取整数次幂；非整数次幂在实数域无结果。 显示精度有限：|结果| > 1e18 或 < 1e-6 时转科学计数法（10 位小数），其余最多 3 位小数，因此 0.0009765625 显示为 0.001。 误用一：把 a^b 写成 a^(1/b)——b 次幂与开 b 次方根不是同一运算。 误用二：把 (aᵐ)ⁿ 当成 a^(m+n)，正确结果是 a^(m·n)。 误用三：在 number 输入框写 1e-6，部分浏览器会截断科学计数法，建议直接写 0.000001。
📊 多组输入对照（实跑）
2^10：结果 1,024，步骤行展开为 2×2×…×2（共 10 个 2）。 2^-10：结果 0.001（精确值 0.0009765625），步骤行给出 1 / 2^10 = 1 / 1,024。 9^0.5：结果为 3，是唯一走「e^(b·ln a)」分支的常见整数例（ln9 = 2.197、0.5×2.197 = 1.099、e^1.099 = 3）。 (-2)^3：结果为 -8，步骤行展开 -2 × -2 × -2；同一个底数换成 0.5 次幂即提示未定义。 0^0：页面输出 1，并附注「0^0 通常约定为 1」；0^-1 则提示「除以零」。
🧭 使用场景与取值建议
幂运算在工程里最常见的三种用法：① 量级换算，如 2^10 = 1,024 是 KiB 与 B 的换算基数、2^20 ≈ 1.05×10⁶；② 复利与折现，(1+r)^n 里的 n 是期数、r 是每期利率，输入小数指数可用于「不满一期」的连续复利近似；③ 缩放与衰减，如每级放大 2 倍重复 10 级即 2^10 倍。取负指数时结果必然小于 1，若业务上不接受「除以零」，底数请填非零值。
2¹⁰
2^10 = 2×2×…×2（共 10 个 2）= 1,024，页面同时展开连乘过程。
2⁻¹⁰
2^-10 = 1 / 2^10 = 1 / 1,024 = 0.0009765625；页面显示为 0.001（先四舍五入到 12 位小数，再按 locale 保留最多 3 位小数）。
9^0.5 与 (-2)³
9^0.5 = 3（即 √9）；(-2)^3 = -8。若输入 (-2)^0.5，页面提示「负数的非整数次幂在实数范围内未定义」。
0⁰ 的约定
0^0 在本页按 Math.pow 输出 1。这是程序与组合数学常用的约定，并非所有数学教材都采用，理论推导时先确认题设口径。

❓ 常见问题（FAQ）

负指数？
a⁻ⁿ=1/aⁿ。
0 的 0 次方等于几？
数学上通常约定为 1，不同计算器实现可能不一致。
幂与开方、对数是什么关系？
a^(1/2)=√a（a≥0）；a^b=e^(b·ln a)（a>0），后者是计算器内部处理大指数与非整数指数的常用算法。
负指数为什么等于倒数？
由 aᵐ·aⁿ=a^(m+n) 取 m=n 与 n=−n，得 aⁿ·a⁻ⁿ=a⁰=1，故 a⁻ⁿ=1/aⁿ（a≠0）。
为什么 2^-10 显示 0.001 而不是 0.0009765625？
页面先把结果四舍五入到 12 位小数，再按 locale 最多保留 3 位；精确值仍体现在步骤行的 1 / 1,024 里，需要高精度时请以分数形式复算。
指数很大时会怎样？
|结果| 超过 1e18 或小于 1e-6 时页面改用科学计数法（10 位小数），再大则超出 JS number 的表示范围、显示 Infinity，此时应改用对数先估量级。
