📐 工作原理与说明
组合数 C(n,r) = n! / (r! · (n−r)!)；对称性 C(n,r) = C(n, n−r)；递推 C(n,r) = C(n−1,r−1) + C(n−1,r)

Compute the number of ways to choose r items from n without repetition using C(n,r) = n! / (r!(n−r)!).

从 n 个不同元素中取 r 个的组合数：C(n,r) = n! / (r!·(n−r)!)

📚 深度解析：组合数 C(n, r)

💡 常见使用场景

  • 从 n 个取 r 个不计顺序。
  • 抽奖选号或分组时计算不重复的组合总数。
计算
C(10,3)=10!/(3!·7!)=120。

❓ 常见问题（FAQ）

组合与排列？
组合不计顺序 C(n,r)，排列计顺序 P(n,r)=C·r!。
允许重复怎么算？
可重组合数为 C(n+r−1, r)。
