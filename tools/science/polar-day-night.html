📖 极昼极夜原理

基本概念

  • 极昼：太阳连续24小时以上不落下的现象
  • 极夜：太阳连续24小时以上不升起的黑暗时期
  • 北极圈：66°33'56" N（约66.56°）
  • 南极圈：66°33'56" S（约66.56°）

太阳赤纬公式

太阳赤纬 δ = 23.44° x sin(2π x (N+284) / 365)

其中 N 为年内第几天（1月1日 N=1），23.44° 为黄赤交角

当 δ > 0 时（夏至附近），北极昼南极夜

当 δ < 0 时（冬至附近），北极夜南极昼

极昼极夜天数与纬度的关系

  • 66.56°（极圈）：极昼/极夜各约1天
  • 70°：极昼约65天，极夜约60天
  • 75°：极昼约105天，极夜约95天
  • 80°：极昼约135天，极夜约125天
  • 90°（极点）：极昼/极夜各约半年
此计算为理论值，未考虑大气折射（太阳在地平线下约34'仍可见）、地形遮挡等因素。实际极昼极夜天数可能略有不同。

💡 常见使用场景

  • 按纬度与日期判断是否极昼／极夜。

  • 旅行或摄影规划极昼、极夜出现的时段。
判断
北极圈（66.5°N）夏至前后约 1 天极昼、冬至前后约 1 天极夜，纬度越高持续越久；北纬 70° 极昼 5/21–7/23（64 天）、极夜 11/19–次年 1/21（64 天）。

❓ 常见问题（FAQ）

南极相反？
是，南北半球季节相反。
极昼能持续多久？
极点附近约半年，纬度越高持续越长，极圈附近仅一天。
白夜怎么定义？
午夜太阳高度 > −6°（民用曙暮光），整夜不黑、无需照明；极昼期间同样计入白夜，因此白夜天数多于极昼天数。
