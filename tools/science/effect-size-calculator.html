📋 Cohen's d 解释

d = (M − μ₀) / SD  |  双样本 d = (M₁ − M₂) / SD_pooled
Cohen's d 经验判读：
• |d| ≈ 0.2：小效应
• |d| ≈ 0.5：中等效应
• |d| ≈ 0.8：大效应
• |d| > 1.3：极大效应
注意：效应量与显著性互补；前者衡量"差异大小"，后者衡量"差异可信度"。
