调频指数 β = 最大频偏 Δf ÷ 调制频率 f_m，二者单位必须一致；β 无量纲，β≪1 为窄带 FM，β≳1 为宽带 FM。

📚 深度解析：FM 调制指数 β

💡 常见使用场景

  • 调频指数 β = 最大频偏/调制频率。
  • 判断窄带/宽带 FM 与边带数目。
  • 卡森带宽公式的输入。
Δf=75kHz、fm=15kHz
调制指数 β = 75 / 15 = 5，属宽带 FM，边带较多。
窄带情形
若 Δf=5kHz、fm=15kHz，则 β≈0.33，接近窄带 FM（β≪1）。
📖 定义与公式
调频指数 β = 最大频偏 Δf ÷ 调制频率 f_m，是一个无量纲比值。β≪1 称窄带 FM（边带少、带宽接近 2f_m），β≳1 称宽带 FM（边带多、占用带宽显著增加）。工程上常用卡森规则估算带宽：B ≈ 2(Δf + f_m) = 2f_m(β+1)。注意本页只计算 β 及其辅助系数，不直接输出带宽。
🧮 算例（按本页代码口径实跑）
Δf=75 kHz、f_m=15 kHz：β = 75/15 = 5.000，百分数 500.00%，倒数 1/β = 0.2000，辅助系数 β/(1+β) = 0.8333；按卡森规则带宽约 2×(75+15) = 180 kHz。 Δf=200 kHz、f_m=10 kHz：β = 20.000，百分数 2000.00%，倒数 0.0500，β/(1+β) = 0.9524；带宽约 420 kHz。 Δf=5 kHz、f_m=15 kHz：β = 0.333，属于窄带 FM（β≪1），带宽约 40 kHz。 f_m=0：页面提示「调制频率 f_m 是本计算的分母，不能为 0」，不做除法。
🧭 取值依据
β 只由 Δf 与 f_m 的比值决定，与载波频率无关。广播 FM 的 Δf 通常固定（如 ±75 kHz），f_m 随节目内容在 15 kHz 以内变化，因此 β 在语音/音乐不同段落并不恒定；做系统设计时按最大 f_m 与最大 Δf 取最坏值。百分比一列只是 β×100，便于与「调制深度」类指标对照，不是独立物理量。
⚠ 常见误用
单位混用：Δf 用 kHz、f_m 用 Hz 直接相除会得到 1000 倍的错误 β，两者必须先统一。 把 β 当带宽：β 是无量纲比值，带宽要按卡森规则另算。 输入负值：页面按公式直算会得到负 β（如 Δf=−75 时 β=−5.000），物理上无意义，频偏与调制频率都应取非负值。
📐 补充对照（同一公式直算）
Δf=1 kHz、f_m=1 kHz：β = 1.000，百分数 100.00%，倒数 1.0000，β/(1+β) = 0.5000 —— 恰好落在窄带与宽带的交界。 Δf=15 kHz、f_m=75 kHz：β = 0.200，百分数 20.00%，倒数 5.0000，β/(1+β) = 0.1667；此时频偏小于调制频率，属于窄带 FM。 单位换算：1 kHz = 1000 Hz，若一边用 kHz、一边用 Hz，先统一到 Hz 再除，否则 β 会相差 1000 倍。
🧭 设计取值参考
调制灵敏度 k_f（Hz/V）把输入幅度换成频偏：Δf = k_f·A_m，于是 β = k_f·A_m/f_m。以广播 FM 为例，Δf=75 kHz、f_m≤15 kHz、A_m=1 V 时 k_f=75 kHz/V，β 最大 5.000，卡森带宽 2×(75+15)=180 kHz；窄带对讲 Δf=5 kHz、f_m=3 kHz 时 β=1.667（166.67%），倒数 0.6000，β/(1+β)=0.6250，卡森带宽 2×(5+3)=16 kHz。卡森规则是工程估算，β 较大时实际占用带宽通常略大于估计值，滤波器设计应预留 10%–20% 余量。
📶 边带与带宽估算
宽带 FM 的频谱以载波为中心、边带间隔为 f_m。按卡森规则，需要保留的边带对数约为 β+1：β=5 时约 6 对（±6 阶），总带宽 2(β+1)f_m = 2×6×15 = 180 kHz；β=20 时约 21 对，2×21×10 = 420 kHz。β 越大，能量越向高阶边带扩散，所以「提高 β 换抗噪」的代价是带宽按线性增长。若中频滤波器只按 2f_m 设计，高阶边带会被削掉，解调波形出现明显失真。

❓ 常见问题（FAQ）

β 与带宽关系？
卡森带宽 ≈ 2(Δf + fm) = 2fm(β+1)，β 越大占用频带越宽。
宽带与窄带如何界定？
通常 β≪1 为窄带 FM，β 较大为宽带 FM，无绝对硬界。
β 越大越好吗？
不是。β 增大提升抗噪性能，但占用带宽同步增加（卡森规则下近似线性），频谱效率下降；需要在抗扰度与带宽之间折中。
β/(1+β) 是什么指标？
本页给出的辅助系数，等于 β 占 (1+β) 的比例，取值随 β 单调递增、上限趋近 1：β=1 时为 0.5000、β=5 时为 0.8333、β=20 时为 0.9524；它不是标准定义的效率或带宽，只用于快速比较不同 β 的相对大小。
β 与「调制深度」是同一个量吗？
不是。AM 的调制深度是幅度比 m=A_m/A_c，工程上通常限制在 0–1；FM 的 β 是频偏与调制频率之比，没有 0–1 的实用上限，只受带宽约束，两者量纲与物理含义都不同，不能直接比较或换算。
