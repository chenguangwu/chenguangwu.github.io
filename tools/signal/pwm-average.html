📐 计算公式
PWM 平均电压（本页代码口径，占空比按百分数输入）：平均电压 V_avg=(D÷100)×V_cc（V）；联动量：等效占空比=V_avg÷V_cc×100（%）、有效值 V_rms=V_cc×√(D÷100)、关断期电压差=V_cc−V_avg。校验：两字段经输入守卫必填且须为合法数值，否则提示并中止。判据：无固定分级，V_avg 随占空比线性变化，D=0 与 D=100 分别对应 0 与 V_cc；V_rms 随 D 的平方根增长。

脉宽调制输出经低通滤波后的平均电压等于占空比乘电源电压。

📌 计算说明
  • V_avg = D·V_cc，D 为 0–100% 占空比。
  • 50% 占空比、5 V 电源 → 2.5 V。

📚 深度解析：PWM 平均电压

💡 常见使用场景

  • 占空比 D 与供电 Vcc 得理想平均电压。
  • 电机/LED 平均驱动测算。
  • 对比不同占空比的平均效果。
D=50%、Vcc=5V
平均电压 Vavg = (50/100) × 5 = 2.5 V；D 升到 80% 则为 4.0V。
全占空比
D=100% 时 Vavg=5V 等于直流供电，D=0% 则 0V。

❓ 常见问题（FAQ）

实际平均电压等于理论吗？
理想开关成立；实际有开关损耗、滤波与负载，会有纹波与偏差。
占空比与亮度/转速线性吗？
平均量线性，但人眼亮度、电机转速还受非线性与惯性影响。

📊 结果解读

结果含义

PWM 平均电压 V_avg=D·V_sup：占空比 D(0–1) 与电源电压的乘积，即一个周期内输出电压的时间平均值。

用法

D=高电平时间/周期。用于 LED 调光、电机调速：平均电压决定亮度/转速。低通滤波后可得到近似直流 V_avg。
