Fft Resolution

📐 计算公式
Δf = f_s / N

N 点 FFT 的频率分辨率为采样率除以点数。

📌 计算说明
  • Δf = f_s / N；N 越大分辨率越高。
  • 1 kHz 采样、1024 点 → 约 0.977 Hz。

📚 深度解析：FFT 频率分辨率

💡 常见使用场景

  • 采样率 fs 与点数 N 决定频率分辨率 df = fs/N。
  • 区分相近频率分量所需的点数测算。
  • 加窗前评估频谱泄漏与分辨率。
fs=1000Hz、N=1024
分辨率 df = 1000 / 1024 ≈ 0.977 Hz，即相邻谱线间隔约 1Hz。
提高分辨率
若 N 增到 8192，则 df ≈ 0.122 Hz，能分辨更接近的频率。

❓ 常见问题（FAQ）

如何提高频率分辨率？
增大 N（更长的采集时间）或降低 fs，df = fs/N。
分辨率与泄漏是一回事吗？
不是，分辨率是谱线间隔，泄漏由截断窗引起，二者需分别处理。
