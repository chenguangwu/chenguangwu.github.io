Group Delay

Group Delay

📐 计算公式
群时延（本页代码口径，含负号与角度换算）：τ_g = −(Δφ×π÷180)÷Δω（s，Δφ 按度输入先转弧度、Δω 单位 rad/s）；联动量：相位差 rad = Δφ×π÷180、相位差°与角频率间隔回显。校验：两项输入空值守卫，空值即提示；Δω 为 0 时除零结果按「—」兜底。判据：无固定分级，τ_g 为负表示相位随频率增加而滞后，线性相位系统群时延恒定（无色散）。

输入相位差 Δφ（度）与角频率差 Δω（rad/s），求群时延。

📌 计算说明
  • τ_g = −dφ/dω，相位以弧度计。
  • Δφ=90°,Δω=1000 → τ_g≈−1.57 ms。

📚 深度解析：群延迟

💡 常见使用场景

  • 相频斜率 −dφ/dω 得群延迟，衡量各频率分量延时一致性。
  • 滤波器线性相位评估。
  • 宽带信号失真（波形展宽）测算。
Δφ=90°、Δω=1000
群延迟 tg = −(90×π/180) / 1000 = −(π/2)/1000 ≈ −1.571×10⁻³ s ≈ −1.57 ms。
恒延时
若相位随频率线性（斜率恒定），则群延迟为常数，信号无失真。

❓ 常见问题（FAQ）

群延迟为负有问题吗？
物理可实现系统群延迟非负；示例中符号取决于相位定义方向，绝对值才有意义。
群延迟与相位延迟区别？
相位延迟是单频相移/频率，群延迟是相频斜率，决定包络延时。
