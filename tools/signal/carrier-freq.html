Carrier Freq

📐 计算公式
载波频率 fc = (上边频 f_H + 下边频 f_L) ÷ 2；带宽 B = f_H − f_L；上边频与载波比 = f_H ÷ max(fc, 10⁻⁹)；几何中心频率 = √(f_H×f_L)。校验：无强校验，非数输入按 0 兜底。判据：fc 取上下边频算术中点，频差越大几何中心相对 fc 越低。

输入上边带与下边带频率，求载波频率。

📌 计算说明
  • f_c = (f_upper+f_lower)/2。
  • (1010+990)/2 → 1000 kHz。

💡 常见使用场景

  • 已知上边频 fu 与下边频 fl，求载波 fc。
  • AM 调幅波频谱参数测算。
  • 验证调制后边带是否对称。
fu=1010Hz、fl=990Hz
载波 fc = (1010 + 990) / 2 = 1000 Hz；频偏 = 1010 − 1000 = 10 Hz。
宽频偏情形
若 fu=1200、fl=800，则 fc=1000、频偏 200Hz，调制越深边带越宽。

❓ 常见问题（FAQ）

载波频率与中心频率一样吗？
对对称调制两者一致，fc = (fu+fl)/2；非对称调制时以定义者为准。
边频差反映什么？
上下边频之差的一半即调制信号最高频率或最大频偏。
