DB Power Ratio

📐 计算公式
功率比分贝：L = 10×log₁₀(P₁ ÷ P₂)（dB）；联动卡：幅值比 = √(P₁ ÷ max(P₂, 10⁻¹²))、奈培 Np = 0.5×ln(P₁ ÷ max(P₂, 10⁻¹²))（分母 0 按 10⁻¹² 兜底）。校验：P₁、P₂ 两项非空合法数值守卫。判据：无固定分级，dB 保留 3 位小数、功率比按指数形式展示，功率每翻倍约增 3.01 dB。

输入功率 P1、P2，求分贝比值。

📌 计算说明
  • 功率比 dB = 10·log10(P1/P2)。
  • 100/1 → 20 dB。

💡 常见使用场景

  • 两功率 p1/p2 取 10 倍 log10 得 dB。
  • 链路功率增益/损耗表达。
  • 信噪比以 dB 表示时的功率基准。
p1=100、p2=1
L = 10×log10(100/1) = 10×2 = 20 dB，即功率比为 100 倍。
衰减情形
若 p1=1、p2=10，则 L = 10×log10(0.1) = −10 dB，表示衰减 10 倍。

❓ 常见问题（FAQ）

功率 dB 为什么乘 10？
分贝基于功率比的对数，功率与幅度平方对应，故系数 10（幅度则 20）。
负值怎么理解？
负 dB 表示 p1 小于 p2，即衰减或损耗。
