Q Factor

Q Factor - online utility on ToolBox.

📐 计算公式
Q = f₀ / Δf

输入中心频率 f0 与 -3dB 带宽 Δf，求品质因数 Q。

📌 计算说明
  • Q = f₀/Δf，越大选择性越好。
  • 1000/100 → Q=10。

📚 深度解析：品质因数 Q

💡 常见使用场景

  • 谐振器 Q = f0 / 带宽，衡量储能与损耗比。
  • 滤波器选择性、腔体 Q 评估。
  • 对比窄带高 Q 与宽带低 Q。
f0=1000Hz、BW=100Hz
Q = 1000 / 100 = 10；若 BW 收窄到 10Hz，则 Q=100（更高选择性）。
低 Q
若 BW=500Hz，则 Q=2，宽带低选择性、损耗相对大。

❓ 常见问题（FAQ）

Q 越高代表什么？
Q 高表示损耗小、谐振尖锐、选频能力强，但带宽窄。
Q 与带宽关系？
Q = f0/BW，二者成反比，高 Q 必窄带。
