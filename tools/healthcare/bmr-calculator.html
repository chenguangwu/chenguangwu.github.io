🏋️ Basal Metabolic Rate Calculator

Estimate resting daily calorie burn with the Mifflin-St Jeor equation from height, weight, age and sex, as the baseline for any nutrition or weight plan.

📐 计算公式与说明

基础代谢率（Mifflin-St Jeor 式）：BMR = 10×体重(kg) + 6.25×身高(cm) − 5×年龄 + (男 +5 / 女 −161)，结果取整以 kcal/天 展示。校验：无强校验，非数输入按 0 兜底，性别由下拉取值（值 1 为男、其余按女式）。判据：体重与身高越大、年龄越小 BMR 越高，同参数下男性基准项比女性高 166 kcal/天。

为基础静息消耗，非每日总消耗。

📚 深度解析：基础代谢率 BMR（Mifflin-St Jeor）

💡 常见使用场景

  • 营养评估：估静息最低热量消耗，制定减脂/增肌饮食
  • 热量预算：由 BMR 乘活动系数得 TDEE，定摄入目标
  • 科普：理解年龄、性别对代谢的影响
方法
算法（Mifflin-St Jeor）：BMR = 10×体重(kg) + 6.25×身高(cm) − 5×年龄 + (男 +5 / 女 −161)，单位 kcal/天。要求各值>0。
算例
例1（65kg / 170cm / 30 岁 / 男）：BMR = 10×65 + 6.25×170 − 5×30 + 5 = 650 + 1062.5 − 150 + 5 = 1568 kcal/天。例2（55kg / 160cm / 25 岁 / 女）：BMR = 550 + 1000 − 125 − 161 = 1264 kcal/天。

❓ 常见问题（FAQ）

BMR 和 TDEE 区别？
BMR 是躺着不动的最低消耗；TDEE = BMR × 活动系数（久坐约 1.2、中等约 1.55、高强度约 1.9），才是 daily 总消耗。减脂摄入应略低于 TDEE。
公式适合所有人吗？
Mifflin-St Jeor 对普通成人较准；运动员、孕妇、甲亢/减等特殊情况偏差大，仅作估算。
