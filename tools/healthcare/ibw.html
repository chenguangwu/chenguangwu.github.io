📚 深度解析：理想体重 IBW（Devine 公式）

💡 常见使用场景

  • 剂量基准：临床由 IBW 算许多药物剂量
  • 营养支持：机械通气潮气量等按 IBW 设
  • 参考意义：IBW 是临床基准而非健康胖瘦标准
方法
算法（Devine）：男 IBW = 50 + 0.91×(身高cm−152.4)；女 IBW = 45.5 + 0.91×(身高cm−152.4)；上限 = IBW×1.1、下限 = IBW×0.9。要求身高>0。
算例
例1（170cm、男）：IBW = 50 + 0.91×17.6 = 66.0kg，区间 59.4–72.6kg。例2（160cm、女）：IBW = 45.5 + 0.91×7.6 = 52.4kg，区间 47.2–57.7kg。

❓ 常见问题（FAQ）

IBW 是"标准体重"吗？
不是健康评判，而是临床计算的参考基准（尤其给药、呼吸机参数）；实际理想体重因人而异，肌肉量高者 IBW 偏低也正常。
肥胖患者剂量按 IBW 还是实际体重？
视药物与指南：脂溶性/分布广的药物可能用校正体重，水溶/按 IBW 设计的则用 IBW；须依具体药品说明书与临床决策。
