📣 Comprehensive Advertising Effectiveness Assessment

Compute the Advertising Effectiveness Index (AEI) from reach, frequency, CTR, memory, attitude and spend. Zero reach, zero recall and zero cost are valid and only make the affected ratios undefined.

📐 工作原理与说明
广告效果指数 AEI（三维度加权）
曝光效果 = 触达率分 + 频次分 + CTR 分：触达率 = 触达人数 ÷ 目标人群 × 100%
触达率分 = min(触达率,100)×0.3；频次分：3–7 次 40｜2–10 次 25｜其余 10
CTR 分 = min(CTR%÷5×30, 30)（CTR 5% 满分）
记忆效果 = 辅助回忆×0.35 + 无辅助回忆×0.40 + 识别×0.25
态度效果 = min(好感度,50)×0.7 + min(购买意向,50)×0.7 + (NPS+100)÷200×36
AEI = 曝光×0.30 + 记忆×0.35 + 态度×0.35
CPM(元/千次曝光) = 投入万元×10000 ÷ (触达人数×平均曝光频次÷1000)，总曝光=触达×频次
每触达人次成本 = 投入×10000 ÷ 触达人数；每回忆用户成本 = 投入×10000 ÷ (触达×无辅助回忆%)
评级：≥80 卓越｜≥65 良好｜≥50 一般｜<50 较差；零触达、零回忆、零投入只让对应比率显示未定义，不阻断其余指标

Key formulas: Math.round(min(aidedRecall,100)×0.35+min(unaidedRecall,100)×0.40+min(recognition,100)×0.25); Math.round(min(favorability,50)×0.7+min(purchaseIntent,50)×0.7+((nps+100)÷200)×36); Math.round(exposureScore×0.30+memoryScore×0.35+attitudeScore×0.35)

⚠️ 使用说明与注意事项
  • 触达率 = 触达人数 / 目标人群 × 100%
  • 有效频次：3-7次为佳，过低记忆不足，过高浪费预算
  • 辅助回忆率>40%为良好，无辅助回忆率>20%为优秀
  • NPS（净推荐值）：推荐者%-贬损者%，>30为良好，>50为优秀
  • 纯前端运行，数据不会上传到服务器

📚 深度解析：广告效果指数（AEI）评估

💡 常见使用场景

  • 一轮投放结束后汇总触达、频次、CTR、回忆率、态度与投入，算 AEI 并分维度定位短板。
  • 零触达、零回忆、零投入都是合法输入：只让对应比率显示「未定义」，不阻断其他指标。
  • 用 CPM 与每回忆用户成本做跨渠道性价比比较；成本为 0 时按 ¥0 展示，而不是替换成 1 万元。
50 万元投放的 AEI 计算
触达 400000 / 目标 800000（触达率 50% → 15 分）、平均频次 4（3–7 档 → 40 分）、CTR 2.0%（12 分）→ 曝光 67 分。辅助回忆 60%、无辅助 35%、识别 70% → 记忆 = 60×0.35 + 35×0.40 + 70×0.25 = 53 分。好感 +20%、意向 +15%、NPS 30 → 态度 = 20×0.7 + 15×0.7 +（130/200）×36 = 48 分。AEI = 67×0.30 + 53×0.35 + 48×0.35 ≈ 55 →「效果一般」，短板在记忆。投入 50 万元时每回忆用户成本 = 500000 ÷（400000×35%）= 3.57 元；总曝光 1.6 百万次，CPM = 500000 ÷ 1600 = 312.5 元。
触达 0、回忆 0、成本 0 的处理
触达填 0：其他分项仍计算，但触达率 0%、CPM 显示「未定义（触达人数或平均频次为 0）」，并提示不能代表真实投放。无辅助回忆填 0：每回忆用户成本显示未定义，记忆效果按 0 计入，但仍提示这不代表广告没触达。成本填 0：CPM 与每回忆用户成本都显示 ¥0，并提醒确认是免费资源而非漏填预算。

❓ 常见问题（FAQ）

AEI 三个维度为什么权重不同？
曝光 30%、记忆 35%、态度 35%。曝光只是前置条件，真正驱动转化的是消费者是否记住并产生偏好，因此后两者各占 35%。
评级区间怎么划分？
AEI ≥80 效果卓越、65–79 效果良好、50–64 效果一般、<50 效果较差。低于 65 时应按三项分项得分定位短板，而不是简单加预算。
为什么 CPM 会显示「未定义」？
CPM 需要触达人数和平均频次都大于 0；任一为 0 时没有可计算的曝光量。页面不会显示 0 或 — 混淆，而是明确写「未定义」，其余指标继续输出。
