Sample Size / Quota / Margin of Error Calculator

Compute sample size and actual sampling error, then allocate strata quotas by the largest-remainder method: every quota is non-negative and sums exactly to n.

📐 工作原理与说明
抽样样本量计算（Cochran + 有限总体修正）
无限总体样本量 n₀ = Z² × p × (1−p) ÷ e²
Z 由置信度查表；p 为预期比例；e 为允许误差
有限总体修正：n = ⌈n₀ ÷ (1 + (n₀−1)/N)⌉
未填 N 或勾选无限总体时 n = ⌈n₀⌉
实际抽样误差 = Z × √(p(1−p)/n) × FPC
FPC = √((N−n)/(N−1))（无限总体取 1）
判定：实际误差 ≤ 目标误差为满足，否则需扩大样本
样本充足性：n ≥ n 需求时显示超出量，否则显示缺口
误差与样本量平方根成反比，样本翻倍误差仅降约 29%
分层比例配额：按最大余数法分配 nᵢ，先取 floor(n×层规模÷分层合计)，再把剩余名额按余数从大到小分配（余数相同按层规模大→小、输入顺序前→后），保证 nᵢ 非负整数且合计 = n
约束：误差须在 0~100% 之间，实际样本须 ≥1

Key formulas: Math.round(n×s.size÷totalStrata); Math.ceil(n0÷(1+(n0-1)÷N)); Math.ceil(n0)

⚠️ 使用说明与注意事项
  • 分层规模之和应接近 N，否则按实际合计分配
  • 比例分配适用于各层方差相近；方差差异大时可考虑 Neyman 分配
  • 无限总体时不应用有限总体修正（FPC）
  • 实际误差随样本量增大而递减，但收益边际递减

📚 深度解析：样本量、抽样误差与分层配额

💡 常见使用场景

  • 调研设计阶段按置信水平、预期比例与允许误差反推最小样本量，并用有限总体校正检查是否高估。
  • 已知实际样本量时反算抽样误差；有限总体下先检查 n 是否超过 N，避免把负数 N 当成无限总体。
  • 分层抽样按最大余数法分配配额，保证每层非负且合计严格等于 n，不再把负余数塞给最大层。
95% 置信、±5% 误差需要多少样本
置信水平 95%（z=1.96）、预期比例 p=50%、允许误差 e=5%、无限总体：n₀ = 1.96² × 0.5 × 0.5 ÷ 0.05² = 384.16 → 至少 385 份。若总体 N=5000 并计入有限总体校正：n = 384.16 ÷（1 + 383.16/5000）= 356.8 → 357 份。反向校验 n=385 时实际误差约 4.99%，与 5% 一致。
四层等规模、n=2 的配额
分层「A,100」「B,100」「C,100」「D,100」，n=2、N=400：按 2×100÷400=0.5 取整后四层都是 0，剩余 2 个名额按余数相同、层规模相同、输入顺序前→后分配，得到 1、1、0、0，合计严格为 2，不会出现某个层 -1。
负数 N 不再被当作无限总体
未勾选「视为无限总体」且 N 填 -5 时，页面提示「有限总体规模 N 必须是 >0 的整数」，不会走无限总体分支；N 留空才按页面说明视为无限总体。n 填 2.5 也会被拦截，不会被 Math.round 悄悄改成 2 或 3。

❓ 常见问题（FAQ）

为什么预期比例默认取 50%？
p(1−p) 在 p=50% 时最大，算出的样本量最保守。若确信比例接近 0 或 1（如罕见行为 5%），按实际比例算可显著减少样本量。
什么时候要用有限总体校正？
抽样比 n/N 超过约 5% 时校正影响明显。有限总体下 n 不能超过 N；n=N 是普查，抽样误差为零，但其他非抽样误差仍存在。
分层合计和 N 不一致怎么办？
配额按分层合计计算，不强制等于 N；若有限总体下分层合计大于 N，页面会以口径矛盾阻止计算。合计小于 N 时会提示未覆盖部分未分配配额，请确认分层是否覆盖全部总体。
