📐 工作原理与说明
边框样式按 solid / dashed / dotted / double / groove / ridge / inset / outset 八种轮换（下拉可固定其中一种）；宽度与圆角留空时随机（宽度 1–8 px、圆角 0–32 px），填写后按填写值固定输出；配色默认在 10 色板内随机，把「配色方式」切到「使用左侧颜色」则统一使用所选色值；双线 double 宽度小于 3 px 时自动提升到 3 px（否则浏览器按实线渲染）。单边独立开启后只输出 border-top / border-right / border-bottom / border-left 中的一条，四边联动则输出 border 简写。
按边框宽度、样式、圆角与配色拼装 border 系列声明，支持单边独立设置；用于分隔线、卡片边框等样式产出。
