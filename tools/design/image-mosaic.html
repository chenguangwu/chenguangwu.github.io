图片马赛克工具是一款纯前端在线打码工具，可对图片进行像素化处理，常用于隐私保护、信息遮挡等场景。

🎯 功能特点

  • 纯本地处理，图片不上传
  • 支持全图和框选区域两种模式
  • 块大小 5-50px 自由调节
  • 实时预览处理效果
  • 一键下载 PNG 结果
  • 支持深色模式

📖 使用场景

  • 截图隐私信息打码
  • 人脸模糊化处理
  • 证件号码遮挡
  • 敏感信息像素化

❓ 常见问题

图片会被上传到服务器吗？
不会。所有处理均在浏览器本地通过 Canvas API 完成，图片数据不会离开您的设备。
支持哪些图片格式？
支持 JPG、PNG、WebP、BMP 等主流图片格式。处理结果导出为 PNG 格式，保证画质无损。
马赛克块大小怎么选？
块越大，马赛克效果越模糊、遮挡越彻底；块越小，越接近原图但仍有像素化效果。一般 10-20px 适合日常打码。
