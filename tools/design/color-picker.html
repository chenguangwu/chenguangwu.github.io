📚 深度解析：取色器

💡 常见使用场景

  • 从屏幕/图片中吸取颜色得到 HEX/RGB
  • 还原设计稿里的具体色值
  • 比对两个颜色的差异
格式互转
吸取某点得到 RGB(52,152,219)，等价 HEX #3498db、HSL(204°,68%,53%)。同一颜色在不同色彩空间数值不同，但指向同一像素。
拾色注意
屏幕为 sRGB，不同设备有色差；印刷需转 CMYK，屏幕取的 HEX 直接印可能偏色。

❓ 常见问题（FAQ）

HEX 和 RGB 哪个更准？
表示同一颜色，无精度差异。HEX 是 RGB 的十六进制写法，前端 CSS 两者都接受；设计协作常用 HEX，代码里 RGB/RGBA 便于控制透明度。
取色后和原图看起来不一样？
可能是色彩配置（sRGB/Display P3）或显示器校色差异；以目标输出设备的色彩空间为准。
