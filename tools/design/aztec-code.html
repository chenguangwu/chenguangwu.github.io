📐 计算公式 / 原理
容量 = ((紧凑 88 / 全尺寸 112) + 16L) × L bit；纠错字 ≈ ⌊数据位 × 纠错率 / 100⌋ + 11；边长 = 11 + 4L（紧凑型）或 14 + 4L + 参考网格（全尺寸），L 为层数
高电平编码先按 UPPER / LOWER / DIGIT / MIXED / PUNCT 五张码表做动态规划取最短位串，再按码字长度插入隔位，用 Reed-Solomon（紧凑型 GF(64)、全尺寸 GF(256)、模式消息 GF(16)）补纠错字，最后把数据位按层螺旋写入四边、中心画同心方靶心。层数与纠错字数由数据量算出，不做伪随机填充；编码器移植自 ZXing（Apache-2.0），已用其官方单元测试向量逐位对齐。

💡 常见使用场景

  • 票据与登机牌：Aztec 靠中心靶心定位、不需要静区，同样内容占用的印刷面积更小。
  • 物流与工单标签：内容含校验字段时，可按 23%–50% 选择纠错比例，容忍油污与折损。
  • 与二维矩阵码对比：同等数据量下 Aztec 通常更紧凑，但 QR 的识读设备与生态更普及。

❓ 常见问题（FAQ）

Aztec 和 QR 有什么区别？
Aztec 以中心同心方靶心定位、不需要静区，紧凑型 4 层以内即可容纳多数票据内容；QR 靠三个角上的定位图形，识读生态更广。两者都是二维矩阵码。
能存多少字符？
容量由层数决定：紧凑型 1 层约 11 个数据码字，紧凑型最多 4 层、上限 64 个数据码字；超出后自动升级为全尺寸符号，最多 32 层。文本越长符号越大，超过最大容量时页面会明确提示，不做静默截断。
会保存或上传我的内容吗？
不会。高电平编码、Reed-Solomon 纠错与绘制全部在浏览器内完成，文本不离开本机。

📝工具简介

输入文本即可生成符合 ISO/IEC 24778 的 Aztec 码：自动选层与 Reed-Solomon 纠错，可导出 PNG/SVG，纯前端本地编码不上传。

✨功能特点

  • 真实编码：高电平编码 + Reed-Solomon 纠错，非随机矩阵
  • 自动选层：优先紧凑型 1–4 层，数据超限自动升级全尺寸符号
  • 三档纠错：23% / 33% / 50%，兼顾面积与抗污损
  • PNG 与 SVG 双导出，SVG 为矢量、放大不失真
  • 支持中文：非 ASCII 文本按 UTF-8 编码并写入 ECI 26

🎯使用场景

  • 票据、登机牌、车票等小面积印刷
  • 物流与工单标签的内容编码、打样核对
  • 对比 Aztec 与 QR 的符号结构与容量差异
  • 为设计稿生成可扫描的条码素材
