⚠️ 使用说明与注意事项
  • 对比度计算遵循 WCAG 2.1 标准（W3C Web Content Accessibility Guidelines）
  • AA 级要求：正常文字 ≥ 4.5:1，大号文字（≥18px 或 ≥14px 粗体）≥ 3:1
  • AAA 级要求：正常文字 ≥ 7:1，大号文字 ≥ 4.5:1
  • 输入色值支持 #RRGGBB、#RGB、rgb(r,g,b) 格式
  • 对比度比率范围为 1:1（完全相同）到 21:1（黑白对比）

💬常见问题

这个工具是免费的吗？
完全免费，无需注册，直接在浏览器中使用。
WCAG 标准是什么？
WCAG（Web Content Accessibility Guidelines）是 W3C 制定的 Web 内容无障碍指南，对比度要求是其中视觉可读性的重要指标。
大号文字的标准是什么？
大号文字指 18px 以上的常规文字或 14px 以上的粗体文字，其对比度要求比正常文字更低。
