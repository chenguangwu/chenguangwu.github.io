🎵 Web Audio Metronome

A precise metronome built on the Web Audio API with selectable time signatures for instrument practice and rhythm training.

📐 工作原理与说明
拍间隔(ms) = 60000 / BPM；每小节拍数由拍号（如 4/4、3/4）决定
基于 Web Audio 的精确时钟调度：按 BPM 计算拍间隔并预排音频事件以降低定时抖动；支持多种拍号与重音，用于乐器练习与节奏训练。
