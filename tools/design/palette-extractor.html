调色板提取器是一款纯前端图片颜色分析工具，采用中位切分法（Median Cut）算法，从上传的图片中智能提取主色调，帮助设计师和开发者快速获取配色方案。

✨ 功能特点

  • 中位切分法颜色量化算法
  • 支持拖拽和点击上传图片
  • 5/8/10/12 色自由选择
  • 按频率、亮度、色相排序
  • 导出 CSS / JSON / SCSS / Tailwind
  • 纯前端处理，图片不上传服务器

🎯 使用场景

  • 提取设计稿/照片的主色调
  • 为项目生成配色方案
  • 分析品牌视觉色彩构成
  • 创建 CSS 变量和设计 Token
