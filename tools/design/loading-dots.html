📐 计算公式 / 原理
延迟序列：第 i 个圆点 delay = i × speed ÷ count（保留 2 位小数）；数量 count 钳制 2–8，直径 ≥4px；bounce / pulse / slide / fade 四种关键帧，周期均为 speed 秒
三点加载动画：为每个点设置错开的 animation-delay 触发缩放或位移，参数化拼装 CSS 并可复制；用于网页加载占位。
