📐 工作原理与说明
从背景色十六进制串取 R = slice(1,3)、G = slice(3,5)、B = slice(5,7) 按 16 进制解析；按钮样式：padding = 纵向 px 横向 px、background 取背景色、color 取文字色、border = 边框宽 px solid 边框色、border-radius = 圆角 px、font-size = 字号 px、box-shadow = 阴影X px 阴影Y px 模糊 px rgba(R,G,B,0.4)；悬停态上移 2px 且阴影改为 阴影Y+2 / 模糊+4、透明度 0.5
把背景、圆角、内边距、阴影与悬停态参数拼装为完整 CSS 规则（含 :hover 伪类），实时预览并可复制；用于快速产出风格统一的按钮样式。
