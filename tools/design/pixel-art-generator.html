🖼️ Pixel Art Generator

Draw pixel art on a grid (4–24 cells per side) using one of six fixed colors, then export it as character art or CSS.

📐 计算公式 / 原理
网格尺寸限 4-24，越界报错；8×8 时载入预置笑脸位图（置 1 处填 #F59E0B），其余尺寸全空；画布单元格 32px、间距 2px、列数 = 网格尺寸；字符画预览：有色的格记 ■、空白记 ·；点击按当前颜色上色，擦除模式恢复 #e2e8f0
Grid size ranges from 4 to 24 and colors come from a fixed set of six. Clicking a cell writes the current color into a 2-D array, which feeds the character-art preview and the CSS box-shadow export. The page does not read images or perform automatic pixelation or color quantization.

📚 深度解析：像素画生成器

💡 常见使用场景

  • 手绘 8×8 / 16×16 像素头像、图标或游戏素材。
  • 把网格作品导出为字符画，贴进文档、README 或聊天窗口。
  • 导出 CSS 像素块（box-shadow 方案），直接放进网页做装饰元素。
8×8 笑脸导出
网格尺寸 8、颜色选橙色（#F59E0B），页面载入预置笑脸：共 48 个有色格、16 个空格。字符画为 8 行、每行 8 个符号（■ 有色、· 空白）；CSS 导出生成含 48 条 box-shadow 的 .pixel-art 规则，可直接嵌入页面。
自绘 16×16 图标
网格尺寸改为 16 后画布清空，点击格子逐格上色；切换「擦除」模式可清除误点格。绘制完成后用「导出字符画 .txt」或「导出 CSS 像素块」保存，字符画预览与导出内容一致。

❓ 常见问题（FAQ）

支持导入图片自动像素化吗？
不支持。本工具是手工网格绘制，不读取本地图片，也不做色彩量化；需要照片像素化请先用图像软件处理。
调色板有几种颜色？
固定 6 色（红、橙、绿、蓝、紫、黑），另可切到擦除模式清除格子；不支持任意色值输入。
会保存或上传我的内容吗？
不会。绘图状态只存在当前页面内存中，刷新即重置；导出通过浏览器本地下载，数据不上传。

如何使用像素画生成器

  1. 选择网格尺寸（4–24）与当前颜色（固定 6 色之一），再选择「绘制」或「擦除」模式。
  2. 在网格上点击格子逐格上色；同一格再点一次会按当前模式覆盖。改变网格尺寸会清空画布，8×8 会载入预置笑脸。
  3. 点击「导出字符画 .txt」或「导出 CSS 像素块」保存结果；字符画预览会随每次点击同步更新。

参数说明

  • 网格尺寸（N×N）：4–24，越界会提示错误
  • 当前颜色：红、橙、绿、蓝、紫、黑共 6 色
  • 绘制模式：绘制写入当前颜色，擦除恢复空白

适用场景

手绘像素头像、图标与游戏素材；把网格作品导出为字符画贴进文档或 README；导出 CSS box-shadow 像素块做网页装饰。
