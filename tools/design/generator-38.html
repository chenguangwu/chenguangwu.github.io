📐 提示词五要素与完整度评分

结构化提示词 = 角色 + 任务 + 上下文 + 输出格式 + 约束。五要素齐备时，模型输出的一致性与可直接使用的比例最高；缺项对应的典型症状：缺角色→用词泛化，缺输出格式→返回散文而非可复制列表，缺约束→字数与语气失控。

完整度评分 = 已填写要素数 ÷ 5 × 100（0~100）。本工具按五项逐项检查并给出补写建议。

要素作用：角色 → 决定专业深度与用词；任务 → 决定动作（生成 / 优化 / 分析 / 改写）；上下文 → 界定信息边界与受众；输出格式 → 决定可解析性；约束 → 字数、语气、禁用词等硬性条件。

📚 深度解析：AI 提示词构建（五要素拼装与完整度自检）

💡 常见使用场景

  • 文案与内容生成前先固定角色、约束与输出格式，避免反复返工
  • 把模糊需求（「写得专业点」）翻译成可校验的提示词要素
  • 团队内统一提示词写法，减少同一任务在不同人手里的结果波动
方法
五要素 = 角色 + 任务 + 上下文 + 输出格式 + 约束。完整度只按「该要素是否填写」计数：角色恒为已填，其余四项每填一项加 20 分，故全空时为 20 分而非 0 分。约束用「；」分隔会自动拆成独立约束项并写入自检清单；输出条数被钳制在 1~20 之间。生成结果是一段带【角色】【任务】【输出格式】【约束】【自检】【禁用】六段的可复制文本，不调用任何模型。
算例
任务 = 优化、目标对象 = 落地页文案、输出格式 = 分点列表、约束 = 「每条≤20字；不要感叹号」、期望条数 = 5 → 完整度 100（5/5）、期望输出条数 5；提示词含「【任务】对「落地页文案」执行优化」「按分点列表输出 5 条」「每条≤20字；不要感叹号。」与「条数是否等于 5」的自检项。目标对象留空时完整度降为 60，缺失项提示「建议补齐：上下文、约束」。

❓ 常见问题（FAQ）

完整度评分是怎么算的？
只按「要素是否填写」计数，不判断内容质量：角色恒为已填，任务、上下文、输出格式、约束四项各占 20 分。所以全部留空时是 20 分而不是 0 分，满分 100 分表示五项齐备。
这个工具会调用 AI 生成内容吗？
不会。它只把五要素拼装成一段结构化提示词文本并做完整度自检，不联网、不调用任何模型；拿到提示词后需要自己复制到所用的 AI 工具里执行。
输出条数怎么限制？
输入框的值会被钳制在 1~20 之间：填 0 或非法值回退为 1，填 99 也按 20 处理，避免提示词里出现不切实际的条数要求。
⚠️ 使用说明与注意事项
  • 提示词由五要素文本拼装生成，输出完全确定、可重复；本工具不调用任何在线模型
  • 完整度评分只衡量要素是否填写，不代表生成质量；结果质量还取决于模型能力与上下文的真实程度
  • 约束条件建议写成可校验的硬指标（字数上限、禁用词、条数），避免「专业一点」这类主观描述
  • 本工具纯前端运行，数据不会上传到服务器
