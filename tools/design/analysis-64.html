📐 加权评分模型与判定口径

加权总分 = Σ(各维度得分 × 该维度权重)，权重之和恒为 1。维度：价格竞争力 / 功能完整度 / 使用体验 / 品牌信任 / 服务支持。

维度差距 = 我方得分 − 竞品得分（正值为优势）；对总分的贡献 = 维度差距 × 权重，五项贡献之和 = 总分差。

结论口径：总分差 ÷ 竞品总分 ≥ +8% → 领先；−8% ~ +8% → 胶着；≤ −8% → 落后。差距阈值按满分 10 分制折算，属于管理层汇报常用的经验分档，可按行业实际情况调整。

优先补强：取「贡献为负且权重最高」的维度排序 —— 高权重上的劣势对总分的拖累最大，应优先投入资源。

📚 深度解析：竞品对标加权评分（五维 / 权重敏感性）

💡 常见使用场景

  • 立项前对标：判断与头部竞品的总分差落在哪个区间
  • 差异化定位：找出高权重上的劣势维度，作为下一版功能的优先级依据
  • 评审会辩论：切换权重方案，验证结论是否只是权重假设的产物
方法
五个维度为价格竞争力、功能完整度、使用体验、品牌信任、服务支持。各维度得分先按所选量程归一到 0–100（得分 ÷ 量程 × 100），再按权重加权求和得到双方总分；总分差 = 我方 − 竞品，百分比 = 总分差 ÷ 竞品总分 × 100。|百分比| < 8% 判为「双方胶着」，≥ 8% 为我方领先或落后。逐维度贡献 =（我方 − 竞品）× 该维度权重，正贡献进入「优势维度」、负贡献进入「优先补强」。
算例
量程 10、均衡权重（20/25/25/15/15%），五维我方 8/6/7/5/9、竞品 7/7/5/6/8 → 我方 69.5、竞品 65.0、总分差 +4.5（6.9%），判定「双方胶着」；优势维度为使用体验（贡献 +5.0）与价格竞争力（+2.0），优先补强为功能完整度（−2.5）与品牌信任（−1.5）。

❓ 常见问题（FAQ）

为什么切换权重后结论会翻转？
总分差是「各维度差距 × 权重」之和，权重本身就是价值主张的声明。同一组打分在「重价格」与「重体验」下可能得出相反结论 —— 结论翻转恰恰说明该维度是决策敏感项，应先对齐权重口径再谈胜负。
打分越界或量程填错会怎样？
低于 0 按 0 计、高于所选量程按量程上限计；量程本身若填 0 或非法值会回退为默认 10 分制，避免出现除零或全员满分。
五个维度的分数怎么定？
页面附有评分口径参考表：价格竞争力看同规格性价比与折扣折算、功能完整度看核心功能覆盖与深度、使用体验看上手成本与错误恢复、品牌信任看口碑案例与资质、服务支持看响应速度与 SLA。建议先对齐口径再打分，减少主观漂移。
⚠️ 使用说明与注意事项
  • 加权总分、差距与贡献均按输入得分与权重线性换算，结果确定可复现（不含任何随机成分）
  • ±8% 的分档阈值是管理汇报经验值，不同行业可自行调整；结论对权重极敏感，务必先对齐权重口径
  • 各维度得分为主观评分，建议先定义评分口径（见「维度评分口径参考」）再打分，减少个人偏差
  • 本工具只做加权数学计算，不提供任何市场或投资结论；正式决策请结合真实调研数据
  • 本工具纯前端运行，数据不会上传到服务器

📝工具简介

竞品对标加权评分：为「价格竞争力 / 功能完整度 / 使用体验 / 品牌信任 / 服务支持」五个维度分别给我方与竞品打分，按选定权重（均衡/重价格/重体验/重功能）加权汇总，输出总分差、逐维度差距与对总分的贡献、优势与优先补强维度排序。

  • 五维度 × 双方打分（10 分制 / 5 分制 / 百分制可切换），自动换算到统一 0–100 口径
  • 四套权重方案（均衡 / 重价格 / 重体验 / 重功能），一键切换看结论是否翻转
  • 总分差与百分比、±8% 阈值判定（领先 / 胶着 / 落后）
  • 逐维度差距表：标注优势（红/绿按差距符号）与「差距 × 权重」对总分的贡献
  • 输出优势维度 TOP2 与优先补强维度；附五维度评分口径参考；纯前端本地计算
  • 立项前对标：判断与头部竞品的总分差落在哪个区间
  • 差异化定位：找出高权重上的劣势维度，作为下一版功能优先级依据
  • 评审会辩论：切换权重方案，验证结论是否只是权重假设的产物
  • 评分口径对齐：用维度定义表统一团队打分标准，减少主观漂移
