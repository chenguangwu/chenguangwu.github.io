📐 工作原理与说明

CSS border-radius 可为四角分别设圆角：按顺序 左上/右上/右下/左下（斜杠后可分别设水平/垂直半径实现椭圆角）。值用 px 或 %（% 相对盒宽高）。生成代码实时驱动预览。

  • 单值=四角同；两值=对角；三值=左上+右上左下+右下。
  • 椭圆角（/ 后值）可做“胶囊”“叶子”等形状。
  • 纯前端生成，复制即用。
