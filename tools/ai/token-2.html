🔑 LLM Token Cost Estimator

Estimate API cost from input and output token counts and unit price, to budget a LLM feature before launch.

📐 计算公式 / 原理
输入费用 = 输入 tokens / 10⁶ × 输入单价；输出费用 = 输出 tokens / 10⁶ × 输出单价；人民币 ≈ 美元 × 汇率
大模型 API 普遍按输入与输出分别计价，且输出单价通常高于输入，因此压缩提示词与控制生成长度都能直接省钱。换算人民币时汇率按当期取值，另需考虑批量/缓存折扣与最低计费粒度。

📐 计算公式与说明

费用 = Token 数 × 单价 / 1,000,000

汇率按 1 USD ≈ 7.2 CNY 估算。

📚 深度解析：提示词 Token 成本

💡 常见使用场景

  • 费用=输入 token×输入单价+输出 token×输出单价，按模型计费口径估算。
  • 支持按 1 USD≈7.2 CNY 折算人民币，辅助调用预算与成本对比。
  • 不同模型分词器差异大，token 数需以对应模型为准，本估算为量级参考。
成本估算
输入 10k token($0.01/1k)、输出 2k token($0.03/1k) → 费用=10×0.01+2×0.03=0.16 USD≈1.15 元。批量调用前用此预判账单。

❓ 常见问题（FAQ）

为什么不同模型费用差很多？
单价随模型能力与上下文长度差异大，且输入输出单价常不同；大上下文/强模型更贵，选型需权衡效果与成本。
估算的 token 数准吗？
不准到精确位。中文在 GPT/Claude/国产模型下 token 数差异明显，本工具给量级参考，精确计费以厂商账单为准。
