🤖 Speech to Text

Transcribe recorded speech into Chinese text in real time using the Web Speech API, entirely in the browser.

本工具在浏览器本地解码音频并加载 Whisper 模型转写文字，支持 mp3 / wav / m4a 等格式，全程不上传。
时长估算按中文正常语速约 240 字/分钟折算，仅供核对参考。

💡 常见使用场景

  • 在浏览器本地用 Web Speech API 将麦克风录音实时识别为中文文本。
  • 纯前端、不上传音频，保护隐私；适合会议纪要、字幕与速记。
  • 识别受口音、噪声与网络语音引擎可用性影响，长段需分段校对。
本地转写
点击录音后口述'明天上午十点开会'，工具实时返回'明天上午十点开会'。环境嘈杂或含专有名词时可能误识，需人工核对关键点。

❓ 常见问题（FAQ）

为什么有时识别不了？
Web Speech API 在部分浏览器/环境需联网调用系统语音引擎，离线或无权限时会失败；口音重、噪声大也会降准。
录音会泄露吗？
本工具在浏览器内处理、不上传；但是否真正本地取决于浏览器实现，部分引擎仍会调用云端识别服务，敏感内容需确认。
