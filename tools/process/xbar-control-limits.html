💡 常见使用场景

  • 为均值控制图（X̄图）计算中心线 CL 与控制限 UCL/LCL，监控过程均值是否受控、有无特殊原因波动。
  • 过程能力研究前先确认过程稳定（受控），否则能力指数无意义。
  • 子组容量变化时（n 不同），按 √n 更新标准误与界限。
公式
标准误 SE = σ/√n（σ 为过程标准差，n 为子组容量）；中心线 CL = μ（过程目标/均值）；控制限 UCL = μ + 3·SE、LCL = μ − 3·SE（3σ 原则，对应约 0.27% 误发警报率）。σ 未知时多用子组极差均值 R̄/d₂ 估计。
算例
过程目标 μ=50、σ=2、子组容量 n=5：SE = 2/√5 ≈ 0.8944；UCL = 50 + 3×0.8944 ≈ 52.683，LCL = 50 − 3×0.8944 ≈ 47.317，CL = 50.000。若某子组均值超出 [47.317, 52.683] 即触发判异，应查特殊原因而非立即调机。

❓ 常见问题（FAQ）

公式里的 σ 用哪个？
控制图限用『过程固有标准差』估计（如 R̄/d₂ 或 S̄/c₄），反映受控下的普通原因波动；不要用全样本整体标准差（含特殊原因会夸大 σ、放宽控制限、漏检异常）。
子组容量 n 越大控制限越窄吗？
是的。SE = σ/√n，n 越大 SE 越小、控制限越窄，对均值漂移越敏感；但 n 过大会增加检测滞后与成本，常规取 4~5，关键过程可取更大子组。
