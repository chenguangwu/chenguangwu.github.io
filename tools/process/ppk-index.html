Ppk Index

📐 计算公式
Ppk = min((USL−μ),(μ−LSL)) / (3σ_lt)

Ppk Index is available directly in your browser, with no data uploaded.

📌 计算说明
  • Ppk 含长期变异与偏移。
  • Ppk≥1.33 视为性能充足。

📚 深度解析：过程性能计算器

💡 常见使用场景

  • 用整体标准差（长期）评估过程实际性能 Ppk，同时纳入均值偏移，给出长期可达的合格品能力。
  • 与 Cpk 对照：Ppk 用整体σ、Cpk 用组内σ，两者差大表示长期存在偏移或特殊原因。
  • 客户年度审核、PPAP 等用 Ppk 作为长期质量承诺指标。
公式与判定
Ppk = min[(USL − μ)/(3σ_long), (μ − LSL)/(3σ_long)]，σ_long 为整体标准差。判定：≥1.33 长期充足、<1.00 不足。Ppk 通常 ≤ Cpk。
算例
规格 USL=10.05、LSL=9.95，长期均值 μ=10.0、整体σ_long=0.015：Ppk = min[(10.05−10.0)/(3×0.015), (10.0−9.95)/(3×0.015)] = min[0.05/0.045, 0.05/0.045] = min[1.111, 1.111] = 1.111。若短期 Cpk=1.667，则 Ppk<Cpk，提示长期需进一步稳定化。

❓ 常见问题（FAQ）

Ppk 与 Cpk 的核心区别？
唯一差别在σ 的来源：Cpk 用组内（短期）标准差，Ppk 用整体（长期）标准差；两者都计均值偏移。因而 Ppk 更贴近客户长期收到货的实际表现。
客户要 Ppk 还是 Cpk？
PPAP/年度审核多要求 Ppk（长期承诺），过程开发阶段内部用 Cpk（短期能力）驱动改进；稳妥做法是两者都达标且差距小，说明过程既能力强又稳定。
