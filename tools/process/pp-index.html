📚 深度解析：过程性能计算器

💡 常见使用场景

  • 用整体标准差（长期）评估过程实际性能 Pp，反映包含特殊原因在内的总波动能否满足规格。
  • 与 Cp 对照（Pp 用整体σ、Cp 用组内σ），两者差距大说明过程存在特殊原因、尚未稳定。
  • 长期供货质量审核时作为客户验收的性能指标。
公式与判定
Pp = (USL − LSL) / (6σ_long)，σ_long 为基于全部历史数据的整体标准差（含特殊原因波动）。判定阈值同 Cp：≥1.33 充足、<1.00 不足。Pp 通常 ≤ Cp，因为整体波动不小于组内波动。
算例
规格 USL=10.05、LSL=9.95，长期整体σ_long=0.015：Pp = (10.05−9.95)/(6×0.015) = 0.10/0.09 ≈ 1.111。若短期组内σ=0.01（对应 Cp=1.667），则 Pp(1.111) < Cp(1.667)，差距提示过程受特殊原因扰动、稳定性有待提升。

❓ 常见问题（FAQ）

Pp 和 Cp 怎么选？
Cp/Ppk 用组内标准差，代表『短期/固有』能力，前提是过程已受控；Pp/Ppk 用整体标准差，代表『长期/实际』性能。供货审核常两者都要：受控且长期也达标才算真正好过程。
Pp 小于 Cp 说明什么？
说明整体波动大于组内波动，存在可识别的特殊原因（如换班差异、设备漂移、来料波动）；应先做过程稳定化（SPC 管控），再谈能力提升，否则能力指数会被虚高。
