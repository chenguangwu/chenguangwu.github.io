📚 深度解析：Cpk 过程能力计算器

💡 常见使用场景

  • 在 Cp 之外进一步纳入均值偏移，给出过程实际能稳定产出合格品的能力，是供方准入与客户验收最常用的单一判据。
  • 当过程均值因设备磨损、温漂等偏离规格中心时，用 Cpk 量化偏移造成的合格品率损失。
  • 监控改进措施（如重新对刀、调平夹具）前后的能力变化，验证纠偏有效。
公式与判定
Cpk = min[(USL − μ)/(3σ), (μ − LSL)/(3σ)]，取上、下单侧能力指数的较小值，代表受偏移压制的一侧。σ 为组内标准差，μ 为过程均值。判定：Cpk ≥ 1.33 能力充足（多数汽车行业要求 ≥1.33 或更高）；1.00 ≤ Cpk < 1.33 勉强；Cpk < 1.00 不足需改进；Cpk ≥ 2.0 为六西格玛级（考虑 1.5σ 偏移对应约 3.4 DPMO）。
算例
轴径规格 10±0.05（USL=10.05、LSL=9.95），μ=10.0、σ=0.01：Cpk = min[(10.05−10.0)/(3×0.01), (10.0−9.95)/(3×0.01)] = min[0.05/0.03, 0.05/0.03] = min[1.667, 1.667] = 1.667，均值居中故与 Cp 相等。若因刀具磨损使 μ 漂到 10.02：Cpk = min[(10.05−10.02)/0.03, (10.02−9.95)/0.03] = min[1.000, 2.333] = 1.000，即便离散度未变，偏移已使能力跌破 1.33。

❓ 常见问题（FAQ）

Cpk 为什么取两者最小值？
过程只能以『更受限的一侧』为准：若均值偏上，超出上限的风险更大；偏下则低于下限风险更大。取 min 即保守地把最坏一侧作为整体能力，避免被另一侧的好看数字掩盖。
Cpk 到多少才算合格？
没有统一铁律，取决于行业与客户：一般制造业 ≥1.33，汽车/医疗/航空常要求 ≥1.67，关键安全件更高。低于 1.0 通常视为过程不合格、必须整改后才能批量交付。
