📐 计算公式
吉布斯自由能判据：ΔG = ΔH − T×ΔS（kJ/mol）；判据：ΔG <0 正向反应自发、ΔG >0 非自发、ΔG = 0 达到平衡。校验：无输入守卫，空值按 0 参与计算。输出：ΔG 保留 3 位小数并标注反应方向。

输入焓变、熵变与温度，求吉布斯自由能变并判断反应方向。

📌 计算说明
  • ΔG = ΔH − TΔS，单位需一致（kJ）。
  • ΔH=-100, ΔS=0.05, T=298 → ΔG≈-114.9，自发。

📚 深度解析：判断反应自发性

💡 常见使用场景

  • 自发性判定：给定 ΔH、ΔS、T 算 ΔG，ΔG<0 为自发。
  • 转变温度：算 ΔG=0 的 T=ΔH/ΔS，判断高温或低温自发区间。
  • 熵驱动反应识别：ΔH>0 但 ΔS>0 时高温自发（如冰融化）。
ΔH=−100 kJ/mol、ΔS=+50 J/mol·K 演练
输入 T=298K，工具输出 ΔG≈−114.9 kJ/mol，判定自发；并提示 T=2000K 为 ΔG=0 转变温度。

❓ 常见问题（FAQ）

ΔG<0 就一定能发生吗？
只代表热力学自发，速率由动力学决定，可能极慢（如金刚石→石墨）。
熵单位用 J 还是 kJ？
ΔH 用 kJ、ΔS 用 J 时 TΔS 差 1000 倍，需统一为同一能量单位。
标准态和实际情况有差吗？
实际浓度/分压用 ΔG=ΔG°+RTlnQ 修正，本工具按给定值直接算。
