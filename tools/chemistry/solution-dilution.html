Dilute a stock solution to a target concentration using C₁V₁ = C₂V₂, solving for any unknown.

📐 工作原理与说明
稀释定律：C₁V₁ = C₂V₂，稀释前后溶质物质的量不变；稀释后体积 V₂ = C₁V₁ ÷ C₂；需加溶剂量 = V₂ − V₁；稀释倍数 = C₁ ÷ C₂，用于实验配液与母液稀释。

📚 深度解析：溶液稀释（C₁V₁ = C₂V₂）

💡 常见使用场景

  • 稀释定容：1 M 取 10 mL 稀释到 100 mL 得 0.1 M。
  • 加水量：由 V1、V2 算加水量（≈V2−V1）。
  • 多级稀释：逐级算终浓度，避免单次超量程。
C1=1.0、V1=50 mL、C2=0.2 演练
输入 C1=1.0、V1=50 mL、C2=0.2，工具输出 V2=250 mL（加水约 200 mL），并提示以定容 V2 为准。

❓ 常见问题（FAQ）

加水量=V2−V1 吗？
稀溶液近似成立；浓溶液体积不严格加和，以定容 V2 为准。
和 dilution-c1v1 区别？
本工具固定稀释场景（求 V2 或加水），后者更通用求第四项。
浓酸稀释注意？
酸入水慢加并冷却，防喷溅。
