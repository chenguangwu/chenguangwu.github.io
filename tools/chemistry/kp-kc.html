Kp–Kc Converter

Convert between equilibrium constants using Kp = Kc·(R·T)^Δn, where Δn is the change in moles of gas.

📐 计算公式
平衡常数换算主式：Kp = Kc·(R·T)^Δn（R = 0.08206 L·atm/(mol·K)，T 为热力学温度 K，Δn = 气体摩尔数变化 = 生成物 − 反应物；Kp 以 atm 基准，与教科书约定一致）；联动输出 RT = 0.08206 × T；特例 Δn = 0 时 Kp = Kc。校验：无强校验，空值按 0 兜底。判据：无固定分级，Δn>0 时 (RT)^Δn >1、Δn<0 时 <1。

输入 Kc、温度与气体摩尔数变化 Δn，求 Kp（R=0.08206，T 为开尔文，Kp 以 atm 基准）。

💡 常见使用场景

  • Kp↔Kc 互算：给定 Kc、T 与 Δn（气体计量差）求 Kp。
  • Δn 判定：由反应式气体计量系数差定 Δn 符号，影响换算方向。
  • 温度影响：RT 项随 T 变化，提示 Kp 与 Kc 一般不等。
Kc=0.5、T=298K、Δn=1 演练
输入 Kc=0.5、T=298K、Δn=1，工具输出 Kp≈12.3（RT≈24.6 L·atm/mol），并提示Δn=0 时 Kp=Kc。

❓ 常见问题（FAQ）

Δn 怎么算？
生成气体计量和减反应气体计量和；无气体或相等则 Δn=0，Kp=Kc。
R 用哪个值？
与 P 单位匹配：P 用 atm 取 0.0821 L·atm/(mol·K)；用 Pa 取 8.314。
Kp 和 Kc 量纲一样吗？
数值与量纲不同（因 (RT)^Δn 带单位），不可直接比大小。
