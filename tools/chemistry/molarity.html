📐 计算公式
c = n / V

由物质的量与溶液体积计算物质的量浓度。

📌 计算说明
  • c = n / V；V 为溶液体积(L)。
  • 2 mol 溶于 1 L 得 2 mol/L。

📚 深度解析：摩尔浓度（c = n / V）

💡 常见使用场景

  • 标准液配制：称固体定容到 V 得 c，作滴定基准。
  • 滴定计算：由 c 与 V 算参加反应摩尔，联算待测浓度。
  • 稀释复核：稀释后 c 按 C1V1=C2V2 变。
0.5 mol 溶质定容 250 mL 演练
输入 n=0.5 mol、V=250 mL，工具输出 c=2.0 mol/L，并提示须定容至刻度而非加溶剂到体积。

❓ 常见问题（FAQ）

定容到 V 不是加到 V？
是定容至刻度：先溶后加水至线，而非加溶剂到 V。
温度影响吗？
体积随温度变，c 略变；精确实验需恒温。
和 molality 怎么选？
配制滴定多用 c，依数性用 b。
