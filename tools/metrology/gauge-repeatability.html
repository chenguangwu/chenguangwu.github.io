Gauge Repeatability Calculator

Compute repeatability standard deviation σ_r = R̄/d₂ from the average range of repeated readings using the range method for measurement system analysis (MSA).

📐 计算公式
量具重复性（极差法）：σ_r = R̄ ÷ d₂；d₂ 按测量次数查表——2 次 1.128、3 次 1.693、4 次 2.059、5 次 2.326，表外回落 1.693；99% 过程带宽 = 5.15σ_r、95% 重复性区间 = ±2.576σ_r、6σ 过程变差 = 6σ_r。校验：无强校验，空值按 0 兜底。判据：无固定分级，σ_r 越小量具重复性越好。

重复性标准偏差 = 平均极差 / d₂。

📌 计算说明
  • 极差法快速估算。
  • d₂ 随测量次数变化。
