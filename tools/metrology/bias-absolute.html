Absolute Bias Calculator

Compute absolute bias as x − x_ref from a measured value and the reference standard value to evaluate measurement system deviation.

📐 计算公式
绝对偏倚 = 测量值 x − 参考值 x_ref；相对偏倚% = 偏倚 ÷ max(x_ref, 1e−12) × 100；测量参考比 = x ÷ x_ref；绝对值 = |偏倚|。校验：两项数值输入无强校验，分母以 1e−12 兜底防除零。判据：正偏倚示值偏高、负偏低；|偏倚| 越小准确度越好，需对照允差限判定。

输入测得值与参考标准值，求绝对偏倚。

📌 计算说明
  • 偏倚反映系统误差方向。
  • 10.2−10.0 → 0.2。

💡 常见使用场景

  • 算量具系统偏倚
  • 偏倚判定
  • 校准修正
公式
bias = mean(测量值) - 参考值（真值）。例：参考 10.000 mm，10 次均值 10.015，bias = +0.015 mm。
测得值 20.35，参考值 20
Bias=x−x_ref=20.35−20=0.350。正值说明测量值系统性偏高，做修正时应从后续读数中减去这一量。

❓ 常见问题（FAQ）

偏倚与误差？
偏倚是重复测量的系统误差平均，反映量具整体偏移。
如何修正？
校准时减去偏倚或建立修正曲线使用。
