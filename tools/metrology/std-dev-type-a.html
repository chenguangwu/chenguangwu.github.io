📐 计算公式
u_A = s/√n

输入样本标准差 s 与测量次数 n，求 A 类标准不确定度。

📌 计算说明
  • u_A = s/√n（多次重复测量）。
  • s=2,n=9 → 0.6667。

公式
s = sqrt(sum((xi-xbar)^2)/(n-1))。例：5 次测 10.001,10.003,9.999,10.002,10.000，s≈0.0016。
