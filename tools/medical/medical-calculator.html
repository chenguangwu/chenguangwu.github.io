💊 用药剂量计算器（按体重）

公式：每日总剂量 = 体重 x 推荐剂量；每次剂量 = 每日总剂量 / 服药频率。计算结果仅供参考，请遵医嘱。

🎯 输液滴速计算器

公式：每分钟滴数 = (输液总量 x 滴系数) / 输液时间(分钟)；每小时毫升数 = 输液总量 / (输液时间/60)。
