🔮 RAW File Size Estimator

Estimate RAW file size from sensor resolution and bit depth, with typical compression ratios for common camera formats.

📐 计算公式与说明

RAW 数据量估算（本页代码口径）：单帧大小=百万像素×10⁶×位深÷8÷10⁶（MB，即像素数×bit÷8 再折 MB）；每分钟数据量=单帧 MB×帧率 fps×60÷1000（GB，按输入帧率计算而非固定 10fps，页面「分钟@10帧」文案仅为默认值示例口径）。校验：无强校验，空值按 0 兜底。判据：无固定分级，数据量与位深、帧率均成正比，8bit 折半、16bit 翻倍。

未计压缩与元数据开销。

📚 深度解析：RAW 文件大小与录制

💡 常见使用场景

  • 由像素与位深算单张 RAW MB。
  • 估视频/连拍缓冲占用。
  • 存储卡选型。
单张大小
24MP、14bit：RAW = 24e6×14/8/1e6 ≈ 42MB/张；连拍 10fps 缓冲每秒约 420MB，需高速卡。
录制占用
同参数 @10fps 录 60s：42×10×60/1000 ≈ 25.2GB，RAW 视频极吃存储，一般用压缩代理。

❓ 常见问题（FAQ）

RAW 比 JPEG 大多少？
约 3–8 倍，因含全部拜耳数据与元数据；位深 14bit 比 12bit 多 17%。
为什么连拍看卡速？
每秒数百 MB 写入，低速卡迅速填满缓冲停拍，需 V90/UHS-II 级。
