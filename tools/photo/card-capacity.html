📷 Memory Card Shot Capacity Estimator

Estimate how many photos a memory card can hold from card capacity, image resolution and file format.

📐 计算公式与说明

可拍张数 = 卡容量(GB) × 1000 ÷ 单张大小(MB)（1GB 按 1000MB 计），RAW 与 JPEG 按各自单张大小分别计算；可录分钟数 = RAW张数 ÷ 10（按 10fps 连拍估算）。校验：卡容量、RAW 单张、JPEG 单张均为必填有效数值（必填校验壳拦截）。判据：单张文件越小可拍张数与可录时长越多，两者均与卡容量成线性正比。

RAW 通常 20–50 MB，JPEG 较小。

⚠️ Unit-basis notice: this page uses the card-vendor basis of 1 GB = 1000 MB (decimal), while photo file sizes estimated on a binary basis (1 MB = 1024×1024 bytes, MiB) differ by about 7.4%. When cross-checking "file size × shots" against card capacity across pages, convert to the same basis first.

📚 深度解析：存储卡容量与张数估算

💡 常见使用场景

  • 按卡容量与单张大小算可拍 RAW/JPEG 张数。
  • 估算延时/视频录制时长。
  • 出行备卡规划。
64GB 卡
64GB 卡、RAW 约 25MB/张：张数 = 64×1000÷25 ≈ 2560 张；JPEG 约 8MB → 8000 张；按 10fps 录制约可存 64×1000÷(25×10×60) ≈ 4.3 分钟。
容量换算
单张 30MB、拍 1000 张需 30GB；14bit RAW 比压缩 JPEG 大数倍，连拍前先估峰值占用避免写满。

❓ 常见问题（FAQ）

RAW 和 JPEG 差多少？
未压缩 RAW 约 12–30MB、JPEG 高画质 3–10MB，RAW 含全部数据利于后期但占空间大。
视频为什么更吃容量？
视频是连续码流，4K 100Mbps 一分钟约 750MB，远快于单张；延时按帧率折算。
