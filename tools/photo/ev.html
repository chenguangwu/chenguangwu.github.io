📣 Exposure Value (EV) Reference

Reference common exposure values (EV) for typical lighting scenes and map them to aperture, shutter speed and ISO combinations.

📐 计算公式与说明

EV = log₂(N² / t) − log₂(ISO/100)
N 为光圈值，t 为快门时间

EV 越低画面越亮。

💡 常见使用场景

  • 由光圈、快门、ISO 求 EV 判断曝光量。
  • 对比不同参数组合的等效曝光。
  • 测光表读数核对。
EV 计算
f/8、1/125s、ISO100：EV100 = log2(N²/t) = log2(64×125) = log2(8000) ≈ 12.97；按 EV₁₀₀ 场景分档落在「阴天/明亮阴影」，晴天正午约为 EV 14–15。
等效互换
EV 相同则曝光量等：f/8·1/125 等效 f/11·1/60（各变一档），可换参数保亮度调虚化。

❓ 常见问题（FAQ）

EV 是什么？
曝光值，每 +1 EV 曝光量翻倍；EV100 以 ISO100 为基准，公式 EV = log2(N²/t×100/ISO)。
EV 高低代表什么？
EV 高=亮环境（如晴日 EV14+），低=暗环境（室内 EV4–7）；相机自动曝光即追目标 EV。
EV 分档怎么对应场景？
EV₁₀₀（ISO 100）常用分档：≥16 雪地/沙滩正午、≥14 明亮日光（阳光 16 法则）、≥12 阴天/明亮阴影、≥10 室内明亮、≥8 室内一般/黄昏、≥6 日落、≤2 夜景。本页与「曝光三角计算」页共用同一套分档。
