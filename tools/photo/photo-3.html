📋 Flash Guide Number Calculator

Compute flash guide number from distance and aperture, or derive the correct aperture for a given flash-to-subject distance.

📐 计算公式与说明

距离 = GN / f
ISO 加倍，距离 ×√2

GN 通常以 ISO100 标定。

📚 深度解析：ISO 与闪光有效距离

💡 常见使用场景

  • 由 GN 与 ISO 求有效照明距离。
  • 反推所需光圈。
  • 弱光补光规划。
有效距离
GN=40、ISO100、f/4：ISO100 距离 = GN/f = 40/4 = 10m；ISO400 系数 2 → 实际 = 20m，更远仍照得亮。
所需光圈
距 8m、GN40、ISO100：所需 f = 40/8 = f/5，开于 f/4 会过曝、收 f/8 欠曝。

❓ 常见问题（FAQ）

距离和 ISO 什么关系？
有效距离随 √(ISO/100) 增；高 ISO 让闪光打得更远或可用更小光圈。
为什么还要调光圈？
GN 固定时距离与光圈互锁，改其一必调另一，ISO 是第三变量三者联立。
