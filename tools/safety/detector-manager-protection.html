  • 职场职业健康风险管理：输入危害因素、日暴露时长、防护措施数与检测频率，评风险等级

  • 改进决策：低分项提示应先补哪类措施
方法
算法：暴露分 = 时长≤限值×0.5?100 : ≤限值?70 : 40；防护分 = 措施≥5?100 : ≥3?75 : ≥1?50 : 20；频率分 = 月检?100 : 季检?70 : 半年?50 : 20；总分 = 暴露×0.4 + 防护×0.35 + 频率×0.25（四舍五入）；≥80 低、≥60 中、≥40 高、其余极高。（限值：粉尘8/化学毒物4/噪声8/高温6/辐射4 h）
算例
例：粉尘岗位 6h/天、措施 3 项、每季检 → 暴露 70、防护 75、频率 70，总分 72 → 中风险。化学毒物 2h/天、措施 5 项、月检 → 100/100/100，总分 100 → 低风险。噪声 9h/天、措施 0、半年检 → 40/20/50，总分 36 → 极高风险。

❓ 常见问题（FAQ）

限值是什么？
为各危害因素的国家接触限值示例（如粉尘 8h、化学毒物 4h 等 PC-TWA），实际以 GBZ 2.1 等现行标准为准。
分数能代替检测报告吗？
不能。本工具是管理自查的粗略评分，正式风险评价须以职业卫生检测数据与评价报告为依据。
⚠️ 使用说明与注意事项
  • 职业健康风险评估依据GBZ 2.1《工作场所有害因素职业接触限值》
  • 暴露时间、防护措施和健康检查是三大关键维度
  • 用低毒/无毒材料替代是职业危害控制首选方案
  • 本工具纯前端运行，数据不会上传到服务器

📝工具简介

健康（防护/检测/替代）管理工具，输入职业危害因素、日暴露时间、防护措施数和健康检查频率，综合评估职业健康风险等级。暴露控制权重40%、防护措施35%、健康检查25%，输出低/中/高/极高四档风险等级及防护建议。适用于企业职业健康管理、防护措施优化和替代方案评估。

✨功能特点

  • 支持五种职业危害因素评估
  • 三维加权综合评分
  • 针对不同危害输出防护建议
  • 提供替代方案建议

🎯使用场景

  • 企业职业健康管理
  • 职业防护措施评估
  • 职业卫生检查准备
  • 职业危害替代方案
