表面积 = 2×(L×W + L×H + W×H)

展开面积 = 表面积 + 插边/粘口 + 出血

纸板尺寸 ≈ 展开后最大长宽 + 余量

💡 常见使用场景

  • 印刷报价前核算包装盒展开用纸面积，结合纸张规格估算单只成本与每千只用纸量。
  • 刀模设计时确认纸板净尺寸（长×宽），给拼版与裁切留足粘口与出血余量。
  • 对比不同盒型（长方体盒/插边盒/托盘盒）的用纸差异，在满足结构强度下选省料方案。
以「长方体盒 长300×宽200×高100 mm、粘口30 mm、出血3 mm」为例
长方体表面积=2×(300×200+300×100+200×100)=220000 mm²=2200 cm²。展开面积=侧壁带 2×(300+200)×100=100000 + 两端 2×300×200=120000 + 粘口 flap×(2×100+2×200)=30×600=18000，合计 238000 mm²=2380 cm²。纸板净尺寸=((300+200)×2+30)×(100+200+30)=1030×330 mm，加出血后为 1036×336 mm。含出血总面积=(238000+(1030+330)×2×3)/100=2461.6 cm²，每 1000 个用纸=2461.6×1000/10000≈246.16 m²。

❓ 常见问题（FAQ）

三种盒型的展开面积差在哪？
长方体盒(rect)侧壁环绕+两端+粘口；插边盒(tuck)多一块翻盖、展开长边更长；托盘盒(tray)只有底+矮边+折耳、用纸最少。本工具按所选盒型套用对应公式，盒型越复杂、摇盖越多，展开面积越大。
出血和粘口为什么计入用纸？
出血是裁切安全边（通常 3 mm），避免裁偏露白；粘口是成型时涂胶搭接区，虽被遮住但也消耗纸板。报价应按含出血的净纸板尺寸算，而非仅按几何表面积，否则会低估用纸 5%~10%。
