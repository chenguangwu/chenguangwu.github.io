📐 计算说明

表面积 = 2×(L×W + L×H + W×H)

展开面积 = 表面积 + 插边/粘口 + 出血

纸板尺寸 ≈ 展开后最大长宽 + 余量

注：不同盒型展开方式不同，本工具为近似估算，实际以结构图为准。
