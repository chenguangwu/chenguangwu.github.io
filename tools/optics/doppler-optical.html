Optical Doppler Shift Calculator (f′ = f·(1 + v/c))

Compute the observed frequency from source frequency, relative velocity and the speed of light, using the non-relativistic approximation.

📐 工作原理与说明
光学多普勒效应：观测频率 f prime = f*(1 + v/c)，v 为光源与观察者的相对速度（远离为正、接近为负），c 为光速；频移量 Δf = f prime − f = f*v/c；相对频移 Δf/f = v/c，用于激光测速与天体红移测量。

Formula Reference

Item Formula / Note Source / Standard
Optical Doppler shift (non-relativistic)f' = f (1 ± v/c), first-order approximation for v << cClassical Doppler effect (Doppler, 1842)
Relativistic exact formf' = f·sqrt((1−β)/(1+β)) for recession, β=v/cSpecial relativity (Einstein, 1905)
📌 计算说明
  • v 取正为靠近（蓝移）。
  • 5×10¹⁴,3×10⁵,3×10⁸ → 5.005×10¹⁴。

Constants used on this page and their authoritative sources, for verification and citation

Note: this page uses the classical longitudinal approximation f′ = f·(1 ± v/c), valid only for v ≪ c. At high speeds use the relativistic form f′ = f·√((1+β)/(1−β)) with β = v/c; transverse motion gives rise to the transverse Doppler effect.

❓ 常见问题（FAQ）

接近光速为何用此近似？
v≪c 时用经典近似 f′=f(1+v/c)；高速须用相对论纵向多普勒公式。
红移蓝移怎么区分？
远离（v>0 背离）频率降低为红移，趋近频率升高为蓝移。
