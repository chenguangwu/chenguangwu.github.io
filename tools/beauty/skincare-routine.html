📋 你的专属护肤流程

📌 护肤基本原则

  • 洁面：温和清洁，避免过度清洁破坏屏障
  • 化妆水：二次清洁、补水、打开吸收通道
  • 精华：功效性产品，分子小先涂
  • 眼霜：眼周肌肤薄，需要专门护理
  • 乳液/面霜：保湿锁水，封住前面的营养
  • 防晒：白天最后一步，抗老的关键

🔄 正确顺序口诀

水 → 精华 → 眼 → 乳 → 霜 → 防晒

质地从稀到稠，分子从小到大。先涂水质，再涂油质。

❌ 不能一起用的成分

酸类 + 酸类
水杨酸+果酸、水杨酸+维A醇 = 过度去角质，屏障受损
维A醇 + 高浓度酸
A醇+果酸/水杨酸 = 刺激性翻倍，容易泛红脱皮
维C + 烟酰胺
高浓度原型VC（pH<3.5）+烟酰胺 = 可能转化为烟酸刺激皮肤
铜肽 + 维C
蓝铜胜肽遇到维C会被氧化失活
蛋白酶 + 强酸
酶类去角质成分在强酸环境下失活
✅ 安全搭配：
• 早C晚A（但需建立耐受）
• 烟酰胺 + A醇（黄金搭配）
• 神经酰胺 + 任何成分（修护+功效）
• 玻尿酸 + 任何成分（百搭补水）

📏 各产品标准用量

产品用量直观参考
洁面1-2g黄豆到花生米大小
化妆水1-2ml浸透化妆棉/一元硬币
精华0.3-0.5g2-3滴，黄豆大小
眼霜0.1g米粒大小，每只眼
乳液0.5-1g1-2个黄豆大小
面霜0.8-1g花生米大小
防晒1-2mg/cm²一元硬币大小（全脸）
⚠️ 用量不足等于白用！尤其是防晒，涂不够量完全没有防护效果。
