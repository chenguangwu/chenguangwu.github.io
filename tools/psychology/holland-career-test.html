🧭 Holland Code Career Test (RIASEC) - Online Tool

60 items produce your three-letter Holland Code, hexagonal profile and Top-10 occupation matches via cosine similarity.

📐 计分与匹配算法

单题计分：喜欢 = 2 分、不确定 = 1 分、不喜欢 = 0 分；每型 10 题，原始分 0—20。Holland Code = 原始分最高的三个类型按降序排列（首位为「主导型」）。六边形剖面图按各型得分占总分比例径向绘制。职业匹配：将你的六维得分归一化（÷20）得到用户向量 U，每个职业的三字母代码按位置权重 [1.0, 0.7, 0.5] 映射到六维向量 V，相似度 = cos(U, V) = Σ(Uᵢ·Vᵢ) ÷ (‖U‖·‖V‖)，取前 10 名。一致性依据六边形上首两字母的相邻关系判断，区分度依据最高与最低得分的落差。
