📝工具简介

Markdown 编辑器是一款免费的在线分屏 Markdown 编辑工具。左侧输入 Markdown 文本，右侧实时渲染 HTML 预览效果。内置代码语法高亮（highlight.js）、Markdown 语法工具栏、自动保存、文件导出等功能，适合编写文档、博客文章、技术笔记、README 文件等场景。所有数据在浏览器本地处理，不上传服务器，保护隐私安全。

✨功能特点

  • 左右分屏实时预览
  • 代码语法高亮（180+ 语言）
  • 工具栏快捷插入 Markdown 语法
  • 支持 GFM 表格、任务列表、删除线
  • 自动保存到 localStorage
  • 一键导出 HTML / Markdown 文件
  • 复制 HTML 源码或 Markdown 原文
  • Tab 键缩进与快捷键支持
  • 字数统计与阅读时长估算
  • 深色模式与移动端适配

💬常见问题

Markdown 编辑器是免费的吗？
完全免费，无需注册，直接在浏览器中打开即可使用。所有功能均无限制。
我的内容会被上传到服务器吗？
不会。所有编辑和渲染都在浏览器本地完成，内容自动保存在 localStorage 中，不会发送到任何服务器。
支持哪些 Markdown 语法？
支持标准 Markdown 语法和 GitHub Flavored Markdown（GFM），包括标题、加粗、斜体、删除线、链接、图片、代码块（带语法高亮）、列表、引用、表格、分割线、任务列表等。
如何导出编辑好的文档？
点击「下载 HTML」可导出包含样式的 HTML 文件，点击「下载 .md」可导出 Markdown 源文件。也可点击「复制 HTML」或「复制 Markdown」直接复制到剪贴板。
关闭页面后内容会丢失吗？
不会。编辑内容会自动保存到浏览器本地存储中，下次打开同一页面时会自动恢复。如需清空内容，点击「清空」按钮即可。
支持手机使用吗？
支持。页面已做响应式适配，在手机上编辑区和预览区自动切换为上下排列布局，工具栏按钮也会自适应排列。
