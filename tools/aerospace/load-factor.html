n = 1 / cos φ

Compute the load factor from lift and weight.

📐 计算公式
坡度转弯载荷因子：n = 1 ÷ cos φ（φ 坡度/转弯角按度输入、转弧度计算，水平飞行 φ=0 时 n=1）；联动量：等效加速度 = n×9.80665（m/s²）、过载载荷增量系数 = n−1、倒数 = 1 ÷ n。校验：无强校验，空值按 0 兜底。判据：无固定分级，φ=60° 时 n=2，φ 趋近 90° 时 n 急剧发散（超过失速极限无法维持）。

协调转弯载荷因子 n = 1/cos φ。

📚 深度解析：载荷因子 n

💡 常见使用场景

  • 协调转弯或机动中，由坡度角 φ 求载荷因数 n=1/cosφ（对称机动）。
  • 给定结构限制载荷因数，反推允许的最大坡度或机动强度。
  • 评估突风/阵风引入的附加载荷因数。
60° 坡度载荷因数
坡度角 φ=60°，载荷因数 n=1/cos60°=1/0.5=2。飞机与乘员承受 2g，属常见机动范围；若结构限制 +2.5g，则还有 0.5g 余量。

❓ 常见问题（FAQ）

n=1 是什么状态？
平飞或小坡度缓转，升力仅平衡重力，乘员感觉'正常体重'。n>1 是拉起/转弯使升力大于重力的结果。
载荷因数超限有什么后果？
超过限制载荷因数可能造成结构永久变形甚至破坏。适航对各类飞机规定正/负限制（如运输机 +2.5/−1.0），飞行包线内机动不得超过。
