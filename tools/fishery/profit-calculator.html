公式说明：
直接成本 = 鱼苗 + 饲料 + 电费 + 药品
间接成本 = 人工 + 塘租 + 其他
总成本 = 直接成本 + 间接成本
总收入 = 产量 × 单价 + 副产品收入
毛利润 = 总收入 - 直接成本
净利润 = 总收入 - 总成本
利润率 = 净利润 / 总收入 × 100%
投资回报率 ROI = 净利润 / 总成本 × 100%
