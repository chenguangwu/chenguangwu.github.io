📐 计算公式
百分比三模式计算（按模式切换的实际口径）：求部分 = a×b÷100；求百分比 = b≠0 时 a÷b×100、b=0 记 0（%）；求变化输出 变化量 = b−a 与 增长率 = a≠0 时 (b−a)÷a×100、否则 0。校验：无强校验，非数输入按 0 兜底。判据：无固定分级，分母为 0 时结果记 0 不报错。

💡 常见使用场景

  • 跑步/骑行坡度换算。
  • 野雪路线用落差与水平距算坡度，识别 >30° 雪坡的雪崩风险等级。
换算
坡度角 5° → 百分比坡度=tan5°×100≈8.75%；10% 坡对应约 5.7°。

❓ 常见问题（FAQ）

百分比坡含义？
每水平 100 上升高度，如 8% 即百米升 8 米。
坡度角比百分比更直观？
工程常用百分比，滑手常用角度；>35° 属陡坡，救援与滑行难度陡增。
⚠️ 使用说明与注意事项
  • 结果保留两位小数
  • 分母为零时会显示 0
  • 增长率可为负数表示下降
