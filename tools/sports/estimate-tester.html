🏃 VO2max Estimator (Running Test)

Estimate VO2max from a Cooper 12-minute run test using VO2max = (distance − 504.9) / 44.73, with several running-test methods supported.

📐 计算公式
Cooper 12 分钟跑：VO2max = (距离(m) − 504.9) ÷ 44.73；1.5 英里跑：VO2max = 483 ÷ 时间(分) + 3.5

通过Cooper 12分钟跑测试估算最大摄氧量(VO2max)。公式：VO2max=(距离-504.9)/44.73，支持多种跑步测试方法。

测试方法选择

Cooper 12分钟跑：记录12分钟内跑的最大距离。1.5英里跑：记录跑完1.5英里(2400米)的时间。

⚠️ 使用说明与注意事项
  • VO2max是最大摄氧量，反映心肺耐力的金标准
  • Cooper 12分钟跑公式：VO2max=(距离-504.9)/44.73
  • 1.5英里跑公式：VO2max=483/时间(分)+3.5（如 12 分钟完成 → 483÷12+3.5≈43.8）
  • VO2max受年龄、性别、训练水平影响
  • 本工具纯前端运行，数据不会上传到服务器
