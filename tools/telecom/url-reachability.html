URL Reachability

Enter any URL (https:// added automatically) and check network-layer reachability via fetch no-cors or favicon image.

📐 工作原理与说明
先用 fetch 的 no-cors 模式请求目标 URL 判断网络层是否接受连接；若失败则回退为请求该站点 favicon 图片。no-cors 返回 opaque 响应，无法读取状态码。

❓ 常见问题

为什么不显示 HTTP 状态码？
no-cors 模式下浏览器隐藏响应内容，只能判断请求是否被网络层接受，无法读取 200/404 等状态码。
可以探测内网地址吗？
可以输入内网 URL，但受浏览器混合内容与 CORS 策略限制，结果可能不准确。
支持哪些协议？
仅 http / https，省略协议时默认补 https://。
