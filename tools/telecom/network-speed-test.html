Network Speed Test

Use Cloudflare speed endpoint: warm-up, repeated small requests for latency/jitter, multi-round downloads for median download speed.

📐 工作原理与说明
先预热连接，再发 10 次小请求取延迟中位数与抖动；随后对 1/5/10MB 各下载 2 轮，取下行速率中位数。测速端点为 Cloudflare 公共 __down 接口。

🕘 本机运行记录与对比

最近一次成功结果只保存在你本机浏览器（localStorage），不上传。可展开对比本次与上次输出的变化；换浏览器或清除站点数据后记录会消失。

❓ 常见问题

这是专业测速吗？
不是，仅用公共端点做粗略估算，受节点、时段、网络拥塞影响较大。
会消耗流量吗？
会下载约 30MB 测试数据（多轮累加），请留意移动网络流量。
测速时要做什么？
保持页面在前台、避免同时占用带宽，结果更稳定。
