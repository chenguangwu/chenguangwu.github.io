IP Geolocation

Look up any IPv4/IPv6 address for country, region, city, ISP, ASN and domain, with format validation before request.

📐 工作原理与说明
先本地校验 IP 格式（IPv4 四段十进制 / IPv6 冒号分组），合法才发请求；主源 ipwho.is 失败回退 ipapi.co。支持回车触发查询。

❓ 常见问题

支持哪些格式？
标准 IPv4（如 8.8.8.8）与 IPv6（如 2001:4860:4860::8888）。格式不合法时不会发送请求。
能查内网 IP 吗？
内网保留地址（如 192.168.1.1）没有公网归属信息，查询结果可能为空。
数据来源是谁？
使用 ipwho.is 与 ipapi.co 公开接口，归属数据库由对方维护。
