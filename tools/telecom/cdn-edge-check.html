CDN Edge Check

Request the same CDN static file, read cf-ray / x-served-by / x-cache headers, falling back to RTT fingerprint.

📐 工作原理与说明
多次请求指定 CDN 文件，尝试读取 cf-ray、x-served-by、x-cache 等边缘节点响应头；若 CORS 隐藏了这些头，则退化为以往返时延（RTT）作为节点指纹。

❓ 常见问题

为什么读不到节点头？
跨域请求的自定义响应头默认被浏览器隐藏（CORS），除非 CDN 显式允许，此时只能看 RTT。
默认探测哪个 CDN？
默认用 jsDelivr 的静态文件，可在输入框改成其它 CDN 地址。
RTT 能定位节点吗？
只能粗略反映网络远近，不能精确定位物理位置。
