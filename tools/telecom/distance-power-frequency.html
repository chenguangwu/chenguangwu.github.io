📏 Wireless Video Link Distance (Friis)

Estimates maximum line-of-sight transmission distance via the Friis free-space path loss equation from transmit power, frequency, transmit and receive antenna gains and receiver sensitivity.

📐 计算公式
路径损耗 Lp ≈ 20·log10(f) + 20·log10(d) + C（自由空间近似）
基于无线链路预算：图传距离由发射功率、收发天线增益、接收灵敏度与频率决定（路径损耗随频率与距离增大），用于无线图传设备选型与覆盖评估。
💡 Friis 公式：Pr = Pt + Gt + Gr − FSPL；FSPL(dB) = 20·lg(d_km) + 20·lg(f_MHz) + 32.44。令 Pr = 接收灵敏度，解得最大视距距离 d = 10^((Pt+Gt+Gr−Pr−20·lg(f)−32.44)/20) km。

⚠️ 使用说明与注意事项
  • 结果为理想自由空间视距距离，未考虑障碍物遮挡
  • 实际受多径、干扰、人体遮挡、地面反射影响显著
  • 5.8GHz 图传典型灵敏度约 −85 ~ −95 dBm
  • 本工具纯前端运行，数据不会上传到服务器

📚 深度解析：无线图传视距距离估算（Friis 路径损耗）

💡 常见使用场景

  • 无线图传链路预算：输入发射功率、频率、收发增益与接收灵敏度，估视距最大距离
  • 方案选型：对比不同频段/增益下的覆盖
  • 现场排查：距离不达标时定位是功率、增益还是灵敏度瓶颈
方法
算法（Friis）：EIRP = 发射功率 + 发射增益；链路预算 = 发射功率 + 发射增益 + 接收增益 − 接收灵敏度；FSPL(dB)=20log10(d_km)+20log10(f_MHz)+32.44；由预算反解 d_km = 10^((预算−20log10(f)−32.44)/20)；波长 λ=300/f（m）。
算例
例：20dBm、5.8GHz、收发各 3dBi、灵敏度 −90dBm → EIRP=23dBm、预算=116dB、距离≈2.6km、λ≈5.2cm。若 30dBm、2.4GHz、各 5dBi、−100dBm → 预算 140dB、距离≈99.5km、λ≈12.5cm。

❓ 常见问题（FAQ）

这是自由空间距离，现实更远还是更近？
通常更近。Friis 仅算自由空间路径损耗，实际还有遮挡、多径、大气与馈线损耗；山区/室内须用更保守模型（如 ITU-R 经验模型）。
频率越高距离越短？
同预算下 FSPL 随频率升高而增大，故高频（如 5.8GHz）比低频（如 915MHz）距离更短；高频换来更大带宽，须权衡。

📝工具简介

无线图传距离估算器基于 Friis 自由空间路径损耗公式，根据发射功率、频率、收发天线增益与接收灵敏度，估算视距条件下的最大传输距离，适用于无人机图传、无线监控与对讲链路规划。

✨功能特点

  • Friis 公式链路预算计算
  • 输出最大视距距离
  • 给出 EIRP 与可容许路径损耗
  • 自动换算波长

🎯使用场景

  • 无人机图传链路评估
  • 无线监控覆盖规划
  • 对讲机通信距离估算
  • 天线选型与增益评估
