Local IP Address

Collect your local private IP addresses via WebRTC host candidates (no STUN) and flag mDNS-obfuscated ones.

📐 工作原理与说明
创建不带 STUN 服务器的 RTCPeerConnection，通过本地 SDP 的 host candidate 读取网卡内网地址，3 秒后自动关闭连接。不连接任何外部服务器。

❓ 常见问题

为什么需要点击按钮？
浏览器要求 WebRTC 由用户手势触发，页面加载后需手动点一次「收集本机地址」。
为什么显示 .local 结尾？
部分浏览器启用 mDNS 混淆，真实内网 IP 被替换成随机 .local 域名，属于隐私保护机制。
多网卡会显示多个吗？
会逐个列出所有 host candidate，包括蓝牙、虚拟网卡等产生的地址。
