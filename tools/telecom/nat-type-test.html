NAT Type Test

Query srflx mappings from 3 public STUN servers and infer cone vs symmetric NAT from port consistency.

📐 工作原理与说明
向多个 STUN 服务器分别发起映射请求，比较返回的公网映射端口：若各服务器看到的端口一致，多为锥形 NAT；端口各不相同则多为对称 NAT。基于 STUN 的启发式推断，非精确检测。

❓ 常见问题

结果准确吗？
这是启发式推断，受多出口、运营商多级 NAT、STUN 可用性影响，仅供网络排查参考。
锥形和对称有什么区别？
锥形 NAT 对外端口固定，便于 P2P 直连；对称 NAT 对每目标分配不同端口，P2P 更难穿透。
为什么显示无法判断？
少于 2 个 STUN 返回有效映射时无法比较，通常是网络限制或 STUN 不可达。
