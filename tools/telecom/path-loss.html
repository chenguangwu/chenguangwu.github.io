自由空间路径损耗 (FSPL) 计算，估算无线信号传输损耗与接收功率。

📋 公式与说明

自由空间路径损耗 (FSPL)：
FSPL(dB) = 20·log₁₀(d) + 20·log₁₀(f) + 32.44
（d 单位 km，f 单位 MHz）

接收功率：
Pr(dBm) = Pt + Gt + Gr − FSPL

典型场景：2.4GHz WiFi、5GHz WiFi、4G/5G 移动通信、卫星链路等。
注：自由空间为理想模型，实际还需考虑大气吸收、障碍物、多径等附加损耗。

📚 深度解析：路径损耗与接收功率估算

💡 常见使用场景

  • 基站或室分系统初设时，按频率、距离与天线参数估算损耗与接收功率。
  • 对比 700 MHz / 2.6 GHz / 3.5 GHz 等不同频段的覆盖能力，为选频提供依据。
  • 把估算结果与接收灵敏度比对，判断是否需要加中继或提高天线增益。
700 MHz 与 3.5 GHz 的覆盖对比
同为 2 km：700 MHz → FSPL = 20log₁₀2 + 20log₁₀700 + 32.44 = 6.02 + 56.90 + 32.44 = 95.36 dB；3.5 GHz（3500 MHz）→ 6.02 + 70.88 + 32.44 = 109.34 dB，相差约 14 dB。在 Pt = 40 dBm、Gt = 15 dBi、Gr = 3 dBi 时，700 MHz 接收功率 = 58 − 95.36 = −37.36 dBm，3.5 GHz 为 58 − 109.34 = −51.36 dBm —— 频率高 5 倍，接收功率低 14 dB，这正是低频段覆盖更好的原因。

❓ 常见问题（FAQ）

低频段一定更好吗？
覆盖上低频段损耗小、绕射强，但可用带宽窄、容量低。5G 常用 3.5 GHz 做容量层、700 MHz 做覆盖层，两者互补而非替代。
室内场景能用这个模型吗？
自由空间模型在室内会严重低估损耗。室内应叠加墙体穿透损耗（混凝土墙常 10–20 dB），或使用专门的室内传播模型。
