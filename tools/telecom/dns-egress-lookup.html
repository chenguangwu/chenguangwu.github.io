📐 工作原理与说明
真实查询 DNS 出口需要：① 在权威 DNS 为专属子域开启查询日志；② 页面用随机 token 加载图片触发一次解析；③ 从静态接口按 token 取回解析器 IP。本页不配置任何自有域名接口，因此只展示配置说明，不生成假结果。

❓ 常见问题

为什么直接显示配置说明？
DNS 出口 IP 必须从你自己的权威 DNS 日志读取，没有自有域名和接口时无法真实测得，故不伪造数据。
DNS 出口 IP 有什么用？
可判断你的 DNS 查询经由哪个递归解析器，用于排查 DNS 劫持或隐私泄露。
需要后端吗？
需要自有域名和能读取日志的接口，本工具不提供也不上传任何数据。
