Service Status

Aggregate public status JSON from GitHub, Cloudflare, Vercel and npm with 5s timeout, showing unknown on failure.

📐 工作原理与说明
并发读取各服务的公开状态 JSON，把 indicator 映射为 operational / degraded / outage，并展示更新时间；读不到时明确显示 unknown，不猜测状态。
空态
常用预设 / 快捷操作：
尚未执行，点击上方按钮开始。

💡 结果速读

下面的解读由本页面在你浏览器里对刚才的结果做本地分析得出，不上传、不调用额外接口；仅供排查参考，不替代专业判断。

执行后自动生成解读。

📋 输出字段说明

服务GitHub / Cloudflare / Vercel / npm
状态正常 / 降级 / 故障 / 未知
更新于状态最后更新时间

🕘 本机运行记录与对比

最近一次成功结果只保存在你本机浏览器（localStorage），不上传。可展开对比本次与上次输出的变化；换浏览器或清除站点数据后记录会消失。

状态最近成功时间上次结果摘要操作
尚未有运行记录，点击上方「刷新状态」开始。

❓ 常见问题

数据来源可靠吗？
直接读取各服务商官方状态页的公开 API，权威可靠。
为什么显示 unknown？
接口超时、CORS 限制或服务临时不可用时显示未知，不会臆测正常。
会定时刷新吗？
点击「刷新状态」重新读取，本页不自动轮询以免产生持续流量。
