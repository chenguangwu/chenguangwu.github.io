Proxy Routing Test

Probe domestic and global site groups separately to infer possible proxy routing mode with per-target details.

📐 工作原理与说明
并发探测国内组（百度/淘宝/QQ）与国外组（Google/GitHub/Cloudflare）的 favicon，按两组的可达性组合推断：全通、规则分流、全局代理或网络故障。属启发式推断，非读取系统代理配置。

❓ 常见问题

这是读取系统代理设置吗？
不是，只通过外部站点的可达性差异推断，无法读取浏览器或系统的代理配置。
结果为什么可能误判？
站点改版、CDN 拦截、本地网络策略都会影响 favicon 可达性，结果仅供参考。
能测规则分流吗？
当国内通、国外部分不通时，通常提示规则分流，但无法给出具体规则。
