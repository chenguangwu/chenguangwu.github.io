❓ 常见问题

为什么不直接显示我的公网 IP？
任何自动查询都要把请求发往第三方接口，可能暴露出口 IP。本页选择不请求，改为指导你在路由器或运营商官方渠道自查。
路由器 WAN 地址一定是公网 IP 吗？
不一定。运营商 CGNAT 时路由器 WAN 侧可能是 100.64.0.0/10 等共享地址，需要向运营商确认。
会采集或上传吗？
不会。本页没有公网 IP 接口请求，也不保存或上传你的网络信息。
