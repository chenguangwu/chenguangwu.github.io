Public IP Lookup

Show your public IP, version, region, ISP, ASN and timezone with multi-source fallback and separate IPv6 detection.

📐 工作原理与说明
按 ipwho.is → ipapi.co → api.ip.sb → ipify 顺序请求公网 IP 归属服务，首个成功即采用；随后单独探测 IPv6 地址。全部请求走浏览器 fetch 并设 6 秒超时，失败自动切换下一数据源。

尚未查询，点击「刷新查询」开始（页面加载后会自动查询一次）。

💡 结果速读

检测会向你输入的目标地址或公开接口发起请求，结果只在本地展示，页面不保存查询记录；结论仅供排查参考，不替代专业判断。

执行后自动生成解读。

🕘 本机运行记录与对比

最近一次成功结果只保存在你本机浏览器（localStorage），不上传。可展开对比本次与上次输出的变化；换浏览器或清除站点数据后记录会消失。

❓ 常见问题

为什么结果和本地 IP 不同？
这里显示的是你的公网出口 IP（路由器对外地址），与局域网内 192.168.x.x / 10.x.x.x 的内网 IP 不同。
多源回退是什么意思？
首个接口失败或超时会自动切换备用接口，提高成功率；结果里的「来源」字段会标明最终采用哪个源。
IP 查询准确吗？
归属地为第三方数据库推断，精确到城市级别，可能有误差，仅供参考。
