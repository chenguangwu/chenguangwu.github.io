📋 书体演变简史

书体演变：甲骨文(商) → 金文(周) → 大篆(春秋战国) → 小篆(秦) → 隶书(汉) → 楷/行/草(魏晋定型) → 沿用至今。

笔法演变：篆书圆转中锋 → 隶书方折波磔 → 楷书提按顿挫 → 行书流畅连带 → 草书简练奔放。

时代风格："晋人尚韵、唐人尚法、宋人尚意、明人尚态、清人尚碑"。每个时代的书法审美取向不同，是断代的重要依据。

鉴定要点：纸张/绢帛材质、墨色、印章、题跋、著录等辅助断代。笔法、结体、气韵需与传世标准件比对。本表的风格概括只用于学习和初步比对，不能单独作为作品真伪、年代或作者的鉴定依据；正式鉴定须由具备资质的专业机构结合原件目检、材料检测与递藏著录综合判断。主要参考：《中国书法史》（江苏教育出版社）及各时期碑帖著录。

以"用笔+结字"区分颜体与柳体
颜真卿（颜体）用笔丰腴雄浑、外拓开张，结字宽博端庄（如《多宝塔》《颜勤礼碑》）；柳公权（柳体）用笔瘦硬挺劲、内擫收敛，结字中心收紧（如《玄秘塔碑》）。所谓"颜筋柳骨"，正指二者一丰一瘦的用笔差异，可据此区分唐楷两大宗。

❓ 常见问题（FAQ）

如何从笔法判断一件作品更接近晋人还是唐人？
晋人（如王羲之）重韵致、用笔灵动使转多、结字欹侧自然；唐人重法度、用笔规范、结字严谨匀称。一件强调提按顿挫与规范间架的楷书更近唐法，而流畅连带、萧散自然的行书更近晋韵。
"碑学"与"帖学"在风格鉴定上如何区分？
帖学以墨迹法帖为宗，用笔细腻、风格妍美（二王一脉）；碑学尊碑版石刻，取方峻、生拙、金石气（如北魏墓志、摩崖）。清中叶后碑学兴起，作品多显厚重苍茫，与帖学的流美秀润形成对照。
