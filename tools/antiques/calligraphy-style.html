📋 书体演变简史

书体演变：甲骨文(商) → 金文(周) → 大篆(春秋战国) → 小篆(秦) → 隶书(汉) → 楷/行/草(魏晋定型) → 沿用至今。

笔法演变：篆书圆转中锋 → 隶书方折波磔 → 楷书提按顿挫 → 行书流畅连带 → 草书简练奔放。

时代风格："晋人尚韵、唐人尚法、宋人尚意、明人尚态、清人尚碑"。每个时代的书法审美取向不同，是断代的重要依据。

鉴定要点：纸张/绢帛材质、墨色、印章、题跋、著录等辅助断代。笔法、结体、气韵需与传世标准件比对。本表供学习参考，真伪鉴定需专业机构。
