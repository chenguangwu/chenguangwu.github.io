CAPM Expected Return Calculator

Capital Asset Pricing Model: required return from the risk-free rate, beta and market return, with a security market line reference table and an alpha verdict.

📐 计算公式
E(R) = Rf + β × (Rm − Rf)　　α = R实际 − E(R)

Rf 为无风险利率（通常取国债到期收益率），Rm 为市场组合预期收益率，β 衡量该资产对市场波动的敏感度（β = 1 与市场同步、β > 1 放大波动、β < 0 反向）。括号内的 (Rm − Rf) 是市场风险溢价，也是证券市场线的斜率；乘以 β 得到该资产应得的风险补偿。若同时填入实际（观测）收益率，则 α = 实际 − 要求：α > 0 表示实际收益高于同等风险下的必要回报，α < 0 表示承担了风险却没拿够补偿。下方按 β 从 0 到 2 给出对应必要收益率，用于快速定位标的在 SML 上的位置。

📌 计算说明
  • β 衡量系统性风险：β = 1.2 表示市场每变动 1%，该资产预期同向变动 1.2%。
  • 市场风险溢价 (Rm − Rf) 是 SML 的斜率，斜率为负时风险越大要求回报反而越低，属异常输入。
  • Rm < Rf 现实中仅短期出现，页面给出提示但仍照公式计算，便于对照检查。
  • α 是事后指标，只有在填入真实观测收益率后才有意义；不填时只输出必要收益率与 SML 对照。
  • β 为负的资产（避险资产、反向头寸）用 CAPM 估计可靠性偏低，结论需谨慎。
  • 本工具纯前端运行，输入数据不会上传到服务器。

📚 深度解析：CAPM 预期收益率计算器 · 证券市场线与阿尔法

💡 常见使用场景

  • 估值取折现率：用无风险利率、β 与市场收益率求出权益资本成本
  • 横向比较：把不同 β 的标的统一到「同等风险下的必要回报」量纲上
  • 事后复盘：填入实际收益率算 α，判断是跑赢还是跑输
  • 口径核对：支持小数（0.03）与百分数（3）两种输入，避免量级填错
方法
E(R) = Rf + β×(Rm − Rf)。先算市场风险溢价 Rm − Rf，再乘 β 得风险补偿，加上无风险利率即必要收益率；α = 实际收益率 − E(R)。输入口径由「单位」下拉决定：选小数时 0.03 表示 3%，选百分数时直接填 3，四个输入项要用同一种单位，否则量级会差出 100 倍。SML 对照表按 β 从 0 到 2、步长 0.25 列出 9 档必要收益率，当前 β 所在行会加底色高亮。
算例
Rf = 3%、β = 1.2、Rm = 8% → 市场风险溢价 5.000%，风险补偿 1.2 × 5.000% = 6.000%，E(R) = 3.000% + 6.000% = 9.0000%。SML 上 β = 0 对应 3.000%（无风险资产）、β = 1 对应 8.000%（与市场同步）、β = 2 对应 13.000%。若同时填入实际收益率 10.000%，α = 10.000% − 9.000% = 1.000% > 0，说明实际收益高于同等风险下的必要回报。

❓ 常见问题（FAQ）

β 该填多少才合理？
β 是对系统性风险的度量，通常取可比公司或指数回归得到的区间中值：公用事业常在 0.5~0.8，科技与周期成长股常在 1.2~1.8。β 会随回归窗口与频率变化，稳妥做法是同时给出 0.8 / 1.2 等情景区间，而不是只填一个点值。
市场风险溢价 Rm − Rf 为负说明什么？
说明填入的市场收益率低于无风险利率，现实中只在短期或口径异常时出现。页面会给出提示但仍照公式计算：此时 SML 斜率为负，β 越大的资产必要收益率反而越低，属异常结果，优先核对 Rm 是否为长期平均市场收益、Rf 是否用了同期国债收益率。
α 为负就一定该卖出吗？
不一定。α 是事后指标，受样本区间、基准选择与运气影响很大，单期 α 为负可能只是正常波动。更稳妥的做法是看 2~3 年滚动 α 是否持续为负，并结合换手成本、税费与 β 的估计误差一起判断。

📝工具简介

按资本资产定价模型（CAPM）由无风险利率、贝塔系数与市场收益率求必要收益率：先算市场风险溢价（Rm−Rf）与风险补偿 β×(Rm−Rf)，再给出证券市场线（SML）上 9 档 β 的对照值；填入实际收益率后还会算出阿尔法 α，判断该资产被高估还是低估。

✨功能特点

  • 必要收益率 E(R) = Rf + β×(Rm−Rf) 一次算全
  • 市场风险溢价与风险补偿分步展示，便于核对口径
  • SML 对照表覆盖 β = 0 ~ 2（每 0.25 一档），自动高亮当前 β 所在行
  • 支持百分数（填 3 表示 3%）与小数（填 0.03）两种输入口径一键切换
  • 填入实际收益率即得 α，并给出高估 / 低估的文字判定
  • 纯前端计算，输入数据不会上传到服务器

🎯使用场景

  • 估值模型里确定权益资本成本（折现率）
  • 把不同 β 的股票换算到同一「要求回报」基准上做横向比较
  • 复盘持仓的实际收益是否跑赢同等风险下的必要回报
  • 金融课程与考试中校验 SML 与 α 的计算过程
