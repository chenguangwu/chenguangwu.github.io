📈 买入看涨期权 (Long Call)

核心公式：

  • 到期盈亏 = max(S - K, 0) - p
  • 盈亏平衡点 = K + p
  • 最大亏损 = p（权利金）
  • 最大盈利 = 无限（标的上涨越多，盈利越大）

说明：预期标的价格上涨时买入看涨期权。付出权利金，获得以行权价买入标的的权利。上涨盈利无限，下跌亏损有限（最多亏权利金）。

适用场景：看涨行情、突破行情、杠杆做多

📉 买入看跌期权 (Long Put)

核心公式：

  • 到期盈亏 = max(K - S, 0) - p
  • 盈亏平衡点 = K - p
  • 最大亏损 = p（权利金）
  • 最大盈利 = K - p（标的跌到0时）

说明：预期标的价格下跌时买入看跌期权。付出权利金，获得以行权价卖出标的的权利。下跌盈利可观，上涨亏损有限。

适用场景：看跌行情、套期保值、避险保护

📊 卖出看涨期权 (Short Call)

核心公式：

  • 到期盈亏 = p - max(S - K, 0)
  • 盈亏平衡点 = K + p
  • 最大盈利 = p（权利金）
  • 最大亏损 = 无限（标的上涨越多，亏损越大）

说明：预期标的价格不涨或小幅下跌时卖出看涨期权。收取权利金，承担以行权价卖出标的的义务。盈利有限（权利金），亏损无限。

适用场景：震荡行情、增强收益、备兑开仓

📈 卖出看跌期权 (Short Put)

核心公式：

  • 到期盈亏 = p - max(K - S, 0)
  • 盈亏平衡点 = K - p
  • 最大盈利 = p（权利金）
  • 最大亏损 = K - p（标的跌到0时）

说明：预期标的价格不跌或小幅上涨时卖出看跌期权。收取权利金，承担以行权价买入标的的义务。盈利有限，亏损可观。

适用场景：震荡偏多、低价接货、收取权利金
