⚠️ 使用说明与注意事项
  • NPV = 初始投资 + Σ(第 t 期现金流 / (1+r)^t)
  • NPV > 0 通常表示项目收益超过预期回报，值得投资
  • NPV < 0 表示项目收益低于预期回报，应谨慎决策
  • NPV = 0 时的折现率即为 IRR
  • 本工具纯前端运行，数据不会上传到服务器
