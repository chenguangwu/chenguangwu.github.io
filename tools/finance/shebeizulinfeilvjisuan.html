Compute equipment lease rate by straight-line depreciation, maintenance and target margin.

📐 计算公式
D = P×(1−s)/(Y×12)；月租金 R = D + P×r/(12×100) + P×m/(12×100)
基于设备租赁定价模型：月折旧 D 按原值 P、残值率 s、折旧年限 Y 直线计提；月租金 R 含折旧+维护(费率 r)+期望利润(利润率 m)；用于租赁报价与投资回报评估。
💡 公式：月折旧额 D = P×(1−s) / (Y×12)；月维护费 = P×r/(12×100)；月租金 R = D + 维护费 + P×m/(12×100)；投资回报率 ROI = (R×T − P×s) / (P×s) × 100%（残值作为期末回收）。

📚 深度解析：设备租赁费率计算（租金/折旧/ROI）

💡 常见使用场景

  • 租赁定价：由设备原值、折旧年限与费率算月租金
  • 收益评估：算租期内总租金、净收益与投资回报率
  • 方案比选：调整租期、利润率后对比回报水平
方法
算法：残值 = 原值×残值率%；应计折旧总额 = 原值 − 残值；月折旧 = 应计折旧/(折旧年限×12)；月维护费 = 原值×维护费率/(12×100)；月利润 = 原值×利润率/(12×100)；月租金 = 月折旧 + 月维护费 + 月利润；总租金收入 = 月租金×租期月数；净收益 = 总租金 + 残值 − 原值；ROI = 净收益/原值×100%。另给出日租金、年租金与月租费率。评级：ROI<0 亏损、<10% 低回报、<30% 合理回报、否则高回报。
算例
例：原值 50 万元、租期 24 个月、折旧 8 年、维护费率 3%、利润率 8%、残值率 5% → 残值 25000 元、月折旧 4947.92 元、月维护 1250.00 元、月利润 3333.33 元，月租金 9531.25 元（月租费率 1.906%、日租金 317.71 元），总租金 228750 元，净收益 −246250 元、ROI −49.25%，评级「亏损」——因为只租 2 年却按 8 年折旧计租，尚未收回折旧。若租期拉长到 96 个月（8 年）→ 总租金 915000 元、净收益 440000 元、ROI 88.00%，评级「高回报」。另例：20 万元、36 个月、折旧 5 年、维护 2.5%、利润 10%、残值 8% → 月租金 5150.00 元、总租金 185400 元、净收益 1400 元、ROI 0.70%，评级「低回报」。

❓ 常见问题（FAQ）

为什么短期租约算出来是亏损？
本工具的 ROI 只统计租期内的租金收入，而月折旧按整个折旧年限分摊。租期短于折旧年限时，累计租金不足以覆盖未折旧完的账面价值，属正常现象；评价长期收益应把后续租约或转售残值一并计入。
利润率和维护费率怎么定？
维护费率可按同类设备的年均保养支出占原值比例估算（工程机械常 2%~5%）；利润率参考行业资金成本与竞争水平，通常 5%~15%。两者均以年为单位输入，工具按月摊分。
