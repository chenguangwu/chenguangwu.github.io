🎯 凯利公式 (Kelly Criterion)

公式：f = (bp - q) / b

  • f = 最优仓位比例
  • b = 盈亏比（平均盈利/平均亏损）
  • p = 胜率
  • q = 败率 = 1 - p

简化版：f = p - q/b = 胜率 - 败率/盈亏比

示例：胜率55%，盈亏比2:1 → f = 0.55 - 0.45/2 = 0.325 = 32.5%

注意：实际应用中常用"半凯利"（乘以0.5），降低波动

📐 固定比例法

原理：每次买入固定比例的资金，不考虑胜率和盈亏比

  • 仓位金额 = 总资产 × 固定比例
  • 持股数量 = 仓位金额 ÷ 买入价格
  • 风险金额 = 持股数量 × (买入价 - 止损价)

优点：简单易用，适合新手

常用比例：单票5%-15%，同时持有3-10只

🛡️ 风险预算法

原理：根据单笔最大亏损比例反推仓位大小

  • 单笔最大亏损 = 总资产 × 单笔风险比例
  • 每股风险 = 买入价 - 止损价
  • 持股数量 = 单笔最大亏损 ÷ 每股风险
  • 仓位金额 = 持股数量 × 买入价

优点：风险可控，专业交易者常用

常用比例：单笔风险1%-3%

📈 马丁格尔策略

原理：亏损后加倍下注，期望一次盈利弥补之前亏损

  • 第n次仓位 = 初始仓位 × 倍数^(n-1)
  • 累计仓位 = 初始仓位 × (倍数^n - 1) / (倍数 - 1)

优点：只要不一直加仓，最终盈利可回本盈利

风险：资金可能耗尽，需谨慎使用

📊 仓位管理原则

  • 分散投资：不要把鸡蛋放在一个篮子里
  • 止损纪律：每笔交易必须设止损，严格执行
  • 分批建仓：不要一次性满仓
  • 顺势加仓：盈利时加仓，亏损时减仓
  • 现金储备：保持一定现金，应对突发情况
  • 风险匹配：仓位大小与风险承受能力匹配

⚠️ 常见误区

  • 越跌越买：亏损加仓可能导致深度套牢
  • 满仓操作：没有容错空间
  • 频繁交易：手续费侵蚀利润
  • 不止损：小亏变大亏
  • 听消息炒股：没有自己的交易系统
  • 追涨杀跌：情绪化交易
