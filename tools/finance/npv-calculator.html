📐 公式说明

NPV 净现值 = Σ CFt / (1+r)^t - 初始投资

NPV > 0：项目可行；NPV < 0：项目不可行

IRR 内部收益率：使 NPV = 0 的折现率

PI 获利指数 = 未来现金流现值 / 初始投资

PI > 1：可行；PI < 1：不可行

投资回收期：累计现金流转正所需时间

静态回收期 = 累计净现金流量出现正值年份 - 1 + 上年累计绝对值 / 当年净现金流量
