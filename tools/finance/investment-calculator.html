📈 Investment Return Calculator

📐 计算公式
累计回报率 = (期末价值 − 总投入) / 总投入
年化收益率 CAGR = (期末价值 / 总投入)^(1 / 年数) − 1
总投入 = 初始投入 + 追加投入。CAGR 已考虑复利；简单年化 = 累计回报率 / 年数（不计复利）。

📐 公式说明

累计回报率：(期末 - 投入) / 投入 × 100%

年化收益率（CAGR）：(期末/投入)^(1/年) - 1

CAGR 假设资金按复利均匀增长，不考虑现金流时点

期间追加投入：按总投入计算，未做时点修正（近似）

例：1 万 → 1.8 万，5 年 → CAGR ≈ 12.47%

❓ 常见问题（FAQ）

年化收益和累计收益区别？
累计是总倍数；年化是把不同期限拉平到「每年」的可比指标。短期高累计可能因时间短，年化更公平比较。
复利频率影响大吗？
在合理利率下影响有限，但长期+高息时日复利明显优于年复利；关键是持续与低费率。
