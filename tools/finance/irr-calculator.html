📋 分析说明

IRR（内部收益率）：使净现值为零的折现率，反映投资真实回报率

• IRR > 折现率：项目可行，值得投资

• IRR < 折现率：项目不可行，不建议投资

NPV（净现值）：未来现金流折现到现在的价值总和

• NPV > 0：投资收益超过预期，可行

• NPV = 0：刚好达到预期收益率

• NPV < 0：投资收益低于预期，不可行

计算公式：NPV = Σ CFt / (1+r)^t

CFt：第t期现金流，r：折现率，t：期数

注：本工具使用牛顿迭代法计算 IRR，结果仅供参考，不构成投资建议。
