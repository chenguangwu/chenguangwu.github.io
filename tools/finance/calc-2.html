📈 IRR内部收益率计算

📐 计算公式（IRR / NPV）
NPV = Σ [ CFₜ / (1 + r)^t ]
IRR = 使 NPV = 0 的折现率 r
CFₜ 为第 t 期现金流（期初投入为负），r 为折现率。IRR 反映项目实际收益率。

输入初始投资（负值）与各期现金流，计算使 NPV=0 的内部收益率

📋 现金流与折现明细

期数现金流折现因子折现值（按 IRR）累计 NPV
⚠️ 使用说明与注意事项
  • IRR 是使项目净现值 NPV 等于 0 的折现率，反映投资项目的年化收益率
  • 现金流符号必须至少变化一次（通常初始投资为负，后续收益为正）
  • 若现金流存在多个符号变化，可能出现多重 IRR，本工具返回首次收敛值
  • 当无法收敛时，会给出提示并展示最接近 0 的折现率
  • 本工具纯前端运行，数据不会上传到服务器
