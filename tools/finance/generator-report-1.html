📐 计算口径（单位：万元）
营业成本 = 营业收入 × 成本率；毛利 = 营业收入 − 营业成本；营业利润 = 毛利 − 期间费用；所得税 = 营业利润 × 所得税率（亏损为 0）；净利润 = 营业利润 − 所得税；负债 = 资产总额 × 资产负债率；所有者权益 = 资产总额 − 负债；经营现金流 = 净利润 + 折旧摊销；现金净增加额 = 经营 + 投资(−资本开支) + 筹资(−分红)。
三张报表由同一组输入派生，保证「资产 = 负债 + 所有者权益」与「经营现金流 = 净利润 + 折旧摊销」两项勾稽恒成立；结果为演示与教学用途，非审计报表。

算例（默认参数，单位万元）
营业收入 1000、成本率 65% → 营业成本 650、毛利 350；期间费用 150 → 营业利润 200；税率 25% → 所得税 50、净利润 150。资产 1200、负债率 45% → 负债 540、权益 660（1200 − 540 − 660 = 0）。经营现金流 150 + 折旧 60 = 210；投资 −80、筹资 −30 → 现金净增加 100，期末现金 300（期初 200）。

❓ 常见问题（FAQ）

结果会随机变化吗？
不会。三表完全由输入参数决定，同一组参数重复生成结果一致，便于复核与课堂对照。
能直接用于正式报表吗？
不能。模型省略了应收应付、存货、其他损益等科目，仅用于演示与教学；正式报表需按会计准则编制并经审计。
