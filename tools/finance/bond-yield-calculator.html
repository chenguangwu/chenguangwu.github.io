🎯 到期收益率 (YTM)

定义：买入债券并持有至到期的年化收益率

公式（附息债券）：

P = C/(1+r) + C/(1+r)² + ... + (C+F)/(1+r)ⁿ

  • P = 债券价格
  • C = 每期利息
  • F = 面值
  • r = 到期收益率
  • n = 期数

零息债券：r = (F/P)^(1/n) - 1

特点：考虑了利息再投资收益，是最常用的债券收益率指标

📊 当期收益率

定义：债券年利息与当前市场价格的比率

公式：当期收益率 = 年利息 / 当前价格 × 100%

示例：面值1000元，票面利率5%，价格950元 → 50/950 = 5.26%

特点：简单直观，只反映利息收益，不考虑资本利得

📈 持有期收益率

定义：持有债券期间的总收益率

公式：

  • 总收益 = 卖出价 - 买入价 + 持有期间利息
  • 持有期收益率 = 总收益 / 买入价 × 100%
  • 年化收益率 = (1 + 持有期收益率)^(1/年数) - 1

特点：反映实际投资收益，适用于中途卖出的情况

💰 债券定价

原理：债券价格等于未来现金流的现值之和

公式：

  • 附息债券：P = Σ(C/(1+r)^t) + F/(1+r)^n
  • 零息债券：P = F/(1+r)^n

价格与利率关系：

  • 市场利率上升，债券价格下降
  • 市场利率下降，债券价格上升
  • 长期债券对利率更敏感

🏛️ 债券类型

  • 国债：国家发行，信用最高，风险最低
  • 地方政府债：地方政府发行，用于地方建设
  • 企业债：企业发行，风险高于国债
  • 公司债：上市公司发行，需核准
  • 可转换债券：可转换成股票的债券
  • 零息债券：不付息，折价发行，到期还本
  • 永续债券：无到期日，永久付息

📉 债券风险

  • 利率风险：利率上升导致债券价格下跌
  • 信用风险：发行人违约，无法还本付息
  • 流动性风险：无法及时变现
  • 再投资风险：利息再投资收益下降
  • 通胀风险：通胀侵蚀实际收益
  • 赎回风险：债券被提前赎回

📊 债券常用指标

  • 久期(Duration)：衡量债券利率风险，价格对利率的敏感度
  • 凸性(Convexity)：久期的二阶导数，更精确衡量利率风险
  • 到期收益率(YTM)：持有到期的年化收益
  • 信用评级：评估违约风险，如AAA、AA、A等

💡 投资建议

  • 根据风险承受能力选择债券信用等级
  • 利率上行期选短债，利率下行期选长债
  • 分散投资，降低单一债券违约风险
  • 关注债券基金，专业管理更省心
  • 国债逆回购也是现金管理好工具
