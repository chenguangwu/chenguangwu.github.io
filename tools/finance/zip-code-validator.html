❓ 常见问题（FAQ）

ZIP 和 ZIP+4 的区别？
ZIP 为 5 位基础码，ZIP+4 在其后追加 4 位细化到街区或楼群，写作 XXXXX-XXXX。
从 ZIP 能确定地址吗？
ZIP 只定位到邮政区域，同一 ZIP 内仍有多个街区与城市，不能唯一定位地址。
校验通过代表地址可达吗？
不代表。格式正确不等于具体地址存在，须以 USPS 数据为准。
