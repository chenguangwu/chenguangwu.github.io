E(Rp) = Σ wᵢ·Rᵢ

Weighted-average expected return of a multi-asset portfolio.

📐 计算公式
两资产组合预期收益 rp = 权重 w₁×收益 r₁ + 权重 w₂×收益 r₂（w 以百分比输入，计算时 ÷100）。校验：权重、收益为有效数；权重合计应≈100%。

按权重加总的组合期望收益。

📚 深度解析：组合预期收益（加权平均）

💡 常见使用场景

  • 由资产权重与预期收益求组合期望回报。
  • 做配置目标设定。
60%/40%：预期 12% 与 8%
E(Rp) = 0.6×12% + 0.4×8% = 10.4%。即组合预期年化约 10.4%。

❓ 常见问题（FAQ）

权重按市值还是成本？
用当前市值权重更反映实际敞口；再平衡时回到目标权重，收益随之更新。
组合预期收益是加权平均，风险也是吗？
预期收益是各资产预期收益按权重的线性加权；但风险不是——组合方差要计入两两资产的协方差。这正是分散化的来源：相关性越低，组合波动越小于各资产波动的加权平均。
