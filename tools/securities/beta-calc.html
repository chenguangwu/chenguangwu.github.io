📋 计算说明

🔢 Beta计算公式

Beta = Cov(Ri, Rm) / Var(Rm)

其中 Cov 为协方差，Var 为方差，Ri 为个股收益，Rm 为市场收益

相关系数 = Cov(Ri, Rm) / (σi × σm)

📊 CAPM模型

预期收益 E(Ri) = Rf + β × (E(Rm) - Rf)

Rf 为无风险利率，E(Rm) 为市场预期收益

📈 Beta值解读

Beta范围风险特征说明
β = 1同步与市场同幅波动
β > 1进攻型波动大于市场，涨幅跌幅更大
0 < β < 1防守型波动小于市场，相对稳健
β = 0无关与市场波动无关
β < 0反向与市场反向波动（罕见）
两个序列长度需相同，建议至少12期数据以提高统计可靠性。Beta反映系统性风险，非总风险。
