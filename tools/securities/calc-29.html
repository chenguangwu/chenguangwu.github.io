📈 Bollinger Bands Calculator

Compute Bollinger Bands: midline, bands, %B and bandwidth.

📐 计算公式

中轨 = MA(N)；上/下轨 = 中轨 ± K × σN；σN = √( Σ(price_i − MA)² / N )

布林带以 N 周期移动平均为中轨、以 K 倍标准差为带宽；价格触及上/下轨分别视为超买/超卖信号，带宽收窄常意味波动率下降。

📖 公式：中轨 SMA = 近N日收盘价均值；上轨 = SMA + K×σ；下轨 = SMA − K×σ（σ为N日总体标准差）；%B = (价格−下轨)/(上轨−下轨)×100；带宽 = (上轨−下轨)/SMA×100。

📚 深度解析：布林带（Bollinger Bands）

💡 常见使用场景

  • 用 20 日收盘价计算中轨（SMA）、上轨/下轨（±2σ），判断价格相对位置。
  • 识别超买（贴近上轨）/超卖（贴近下轨）。
  • 带宽（Bandwidth）衡量波动扩张/收缩。
20 日均价 50、σ=2
中轨=50；上轨=50+2×2=54；下轨=50−2×2=46。带宽=(54−46)/50=16%；%B=(现价−46)/(54−46)：现价 50 → %B=(50−46)/8=50%（位于中轨），现价 54 → %B=100%（触及上轨）。
带宽收窄
若 σ 降到 1：上轨 52、下轨 48、带宽=(52−48)/50=8%。带宽收缩常预示波动放大（"布林带挤压"）。

❓ 常见问题（FAQ）

参数为什么是 20、2？
20 日是中短期常用窗口，2σ 约覆盖 95% 正态分布区间。可随策略调整（如 10、1.5 或 50、2.5）。
%B 是什么？
%B = (价格−下轨)/(上轨−下轨)，0 在下轨、1 在上轨、>1 突破上轨。用于量化超买超卖位置。
