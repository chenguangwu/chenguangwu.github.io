Holding Period Return Calculator

Compute holding period return from buy and sell prices and dividends received.

📐 计算公式
股票持有期收益率（本页代码口径）：r=(卖出价−买入价+股息)÷买入价×100（%）；联动量：资本利得率=(卖出价−买入价)÷买入价×100（%）、股息收益率=股息÷买入价×100（%，买入价为 0 时分母按 1 兜底）。校验：三项空值即提示并中止。判据：无固定分级，总收益由资本利得与股息两部分同向叠加构成。

输入买入价、卖出价与期间股息，求持有期收益率。

📌 计算说明
  • 含股息的总回报。
  • (110−100+2)/100 → 12%。

📚 深度解析：股票持有期回报

💡 常见使用场景

  • 计算买入到卖出的总回报（含资本利得与股息）。
  • 多笔买卖合并算期回报。
  • 与年化回报换算（已知持有天数）。
买入 50、卖出 55、股息 2
持有期回报 = (卖出−买入+股息)/买入 = (55−50+2)/50 = 7/50 = 14%。
亏损
买入 50、卖出 45、股息 1：回报=(45−50+1)/50=−4/50=−8%。

❓ 常见问题（FAQ）

含分红再投资吗？
本工具红利按现金计入；若分红再投资，需用复权价计算总回报，结果通常略高。
怎么年化？
年化 = (1+期回报)^(365/持有天数) − 1。持有 半年、回报 14% → 年化≈(1.14)^2−1≈29.96%。
