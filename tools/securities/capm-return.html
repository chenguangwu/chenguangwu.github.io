Capm Return

📐 计算公式（CAPM 资本资产定价模型）
E(r) = r_f + β·(r_m − r_f)
r_f 无风险利率，β 个股相对市场波动，r_m 市场预期收益率，(r_m − r_f) 市场风险溢价。

E(r) = r_f + β·(r_m − r_f)。

📌 计算说明
  • CAPM: E(r) = r_f + β(r_m − r_f)。
  • β>1 波动大于市场，β<1 小于市场。
