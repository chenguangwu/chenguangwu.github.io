Capm Return

📐 计算公式（CAPM 资本资产定价模型）
E(r) = r_f + β·(r_m − r_f)
r_f 无风险利率，β 个股相对市场波动，r_m 市场预期收益率，(r_m − r_f) 市场风险溢价。

E(r) = r_f + β·(r_m − r_f)。

📌 计算说明
  • CAPM: E(r) = r_f + β(r_m − r_f)。
  • β>1 波动大于市场，β<1 小于市场。

📚 深度解析：CAPM 预期收益

💡 常见使用场景

  • 用资本资产定价模型估算资产的必要/预期收益率。
  • 项目资本成本（WACC 中权益成本）估算。
  • 判断当前价格隐含的预期收益是否被满足。
rf=3%, β=1.2, rm=8%
E(R)=rf+β×(rm−rf)=3%+1.2×(8%−3%)=3%+6%=9%。该资产要求年化回报 9%。
无风险上行
若 rf 升至 4%：E(R)=4%+1.2×4%=8.8%。无风险利率上升，权益必要收益略降（风险溢价收窄）。

❓ 常见问题（FAQ）

市场风险溢价多少合理？
历史长期 A股/美股股权风险溢价约 4%–6%，具体用哪个取决于估计窗口与方法，无统一值。
算出的 9% 是保底收益吗？
不是。CAPM 给的是"要求回报"（贴现率），实际收益由市场决定，可能高于或低于该值。
