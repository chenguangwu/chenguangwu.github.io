📊 组合收益率计算器

输入各持仓资产金额与收益率，计算加权组合收益率

📋 计算说明

🔢 加权收益率公式

组合收益率 = Σ (资产金额 × 资产收益率) ÷ 总金额

即：Rp = Σ (wi × Ri)，其中 wi 为各资产权重

组合盈亏 = Σ (资产金额 × 资产收益率)

📚 应用场景

  • 资产配置评估：衡量整体投资组合表现
  • 再平衡决策：识别拖累组合的资产
  • 业绩归因：分析各资产贡献度
收益率为百分比，正数表示盈利，负数表示亏损。空行将自动忽略。
