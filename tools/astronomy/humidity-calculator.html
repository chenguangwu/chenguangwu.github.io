计算公式：
饱和水汽压（Magnus 公式）：e_s(T) = 6.1094 × exp(17.625T / (T+243.04)) hPa
实际水汽压（Sprung 公式）：e = e_s(t') − A·p·(t − t')，其中 A = 0.000662
相对湿度：RH = (e / e_s(t)) × 100%
露点温度：Td = 243.04·ln(e/6.1094) / (17.625 − ln(e/6.1094)) °C
绝对湿度：AH = 216.7·e / (t + 273.15) g/m³

📐计算原理

干湿球法利用干球温度计与湿球温度计的读数差推算空气湿度。水分蒸发使湿球温度降低，空气越干燥蒸发越快、温差越大。先由 Sprung 公式计算实际水汽压 e = e_s(t') − A·p·(t − t')，再与干球温度下的饱和水汽压 e_s(t)（Magnus 公式）相比得到相对湿度。

💬常见问题

这个工具是免费的吗？
完全免费，无需注册，直接在浏览器中使用。
我的数据会被上传吗？
不会。所有计算都在你的浏览器本地完成，数据不会发送到任何服务器。
为什么湿球温度不能高于干球温度？
湿球因水分蒸发吸热，温度始终低于或等于干球。当两者相等时，空气达到饱和，相对湿度为 100%。
公式中的 A=0.000662 是什么？
这是通风干湿表的 psychrometric constant（干湿表系数），适用于通风良好的百叶箱或阿斯曼通风干湿表。自然通风条件下该值略大。
支持结冰情况吗？
当前公式适用于湿球未结冰（湿球温度高于 0°C）的情况。湿球结冰时需使用冰面饱和水汽压，本工具暂不支持。
支持手机使用吗？
支持。页面已做响应式适配，手机和电脑均可正常使用。
