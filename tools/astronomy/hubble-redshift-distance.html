Hubble Redshift Distance

Hubble Redshift Distance is available directly in your browser, with no data uploaded.

📐 计算公式
d = c·z / H₀

低红移下，退行速度与距离成线性关系。

📌 计算说明
  • d ≈ c·z/H₀（低红移近似）；H₀=70 km/s/Mpc。
  • z=0.01 约 42.8 Mpc。

📚 深度解析：近似距离（d = c·z / H₀）

💡 常见使用场景

  • 对低红移星系，用哈勃定律 d=c·z/H₀ 做粗略测距，适合宇宙学入门。
  • 根据测得的红移 z 与哈勃常数 H₀，估算星系退行速度与距离。
  • 在科普中直观展示「红移越大、离我们越远」的宇宙膨胀关系。
示例：红移 z=0.01 的星系距离
取 c=3×10⁵ km/s、H₀≈70 km/s/Mpc，d=c·z/H₀=3×10⁵·0.01/70≈42.9 Mpc，约 1.4 亿光年。其退行速度 v≈cz≈3000 km/s。

❓ 常见问题（FAQ）

这个公式适合多大红移？
仅适合低红移（z≪1）。高红移需考虑宇宙膨胀历史与暗能量，用完整宇宙学距离积分。
哈勃常数 H₀ 的取值影响大吗？
很大。H₀ 当前测量存在约 70 与 73 km/s/Mpc 之争，会成比例地改变距离估计。
