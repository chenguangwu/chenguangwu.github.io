✅ Hamming Code Parity Bits

Compute the Hamming parity bits r from data bits m using 2^r >= m + r + 1 for single-bit error correction.

📐 计算公式与说明

满足 2ʳ ≥ m + r + 1 的最小 r
码长 = m + r，效率 = m/(m+r)

汉明码可检测并纠正单比特错误。

📚 深度解析：汉明码校验位

💡 常见使用场景

  • 内存 ECC 设计：为 m 位数据规划最少校验位以纠单比特错。
  • 教学演示：展示数据位增长时校验位呈对数增加。
  • 协议校验规划：为关键字段加汉明保护的成本估算。
示例：8 位数据
需 r=4（2^4=16≥8+4+1=13），共 12 位码字，可纠 1 位错、检 2 位错。

❓ 常见问题（FAQ）

公式含义？
2^r ≥ m+r+1 保证 r 个校验位能定位 m+r 个位置（含整体无错）。
汉明码能纠几位？
标准汉明码纠单比特错、检双比特错；SEC-DED 需加一位总奇偶。
校验位放在哪？
放在 2 的幂位置（1,2,4,8…），数据位填其余，由奇偶覆盖定位错误位。
