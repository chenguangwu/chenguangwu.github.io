#️⃣ Hash Output Length

Look up the output length (bytes and bits) of common hash algorithms (MD5, SHA family) for hash value storage planning.

📐 计算公式与说明

MD5=128bit, SHA1=160bit, SHA256=256bit, SHA512=512bit
Hex 长度 = 字节数 × 2

用于预估哈希值存储空间。

📚 深度解析：哈希输出长度

💡 常见使用场景

  • 字段设计：为数据库/索引选择哈希长度以平衡冲突与存储。
  • 签名对接：确认对端摘要位数（如 SHA-256 为 32 字节）。
  • 教学速查：对比 MD5/SHA-1/SHA-256 输出规模。
示例：SHA-256
输出 256 bit = 32 字节 = 64 个十六进制字符。

❓ 常见问题（FAQ）

MD5 还能用吗？
仅用于非安全校验（如去重），因其已被攻破不可用于完整性/防篡改。
位数与安全性关系？
抗碰撞强度约与位数半相关（生日攻击），SHA-256 远强于 MD5/SHA-1。
为何同时给字节与位数？
存储按字节、展示常用十六进制（2 字符/字节），两者都常用。
