Horizontal Distance from Slope Distance and Vertical Angle

Compute the horizontal distance from a slope distance and a vertical angle.

📐 计算公式
斜距化平距（本页代码口径，垂直角按度输入先化弧度）：水平距离 H=斜距 S×cos(垂直角)；联动量：高差 Δh=S×sin(垂直角)、斜距与平距之差=S−H、斜距水平比=S÷max(H,10⁻⁹)。校验：无强校验，空值按 0 兜底。判据：无固定分级，垂直角为 0 时平距等于斜距、高差为 0，角度增大平距缩短而高差增大。

输入斜距 S 与垂直角 v（度），求水平距离。

Formula & Standard References

Item Formula / Note Source / Standard
Horizontal distance S = L · cos(alpha), where L is the slope distance and alpha the vertical angle GB 50026-2020, Code for engineering surveying
Height difference h = L · sin(alpha) GB 50026-2020, Code for engineering surveying
Long-distance corrections Over long distances, apply curvature and refraction corrections GB 50026-2020, Code for engineering surveying
Check relation S^2 + h^2 = L^2 serves as a computational check GB 50026-2020, Code for engineering surveying
📌 计算说明
  • 垂直角越大平距越短。
  • 100·cos10° → 98.48 米。

💡 常见使用场景

  • 由斜距与倾角算水平距。
  • 全站仪斜距改化。
  • 坡地边长归算。
改化
斜距 100.5m、俯角 5.71%（≈天顶距 84.29°）→ 水平距=100.5×sin(84.29°)=100.0m。
影响
10% 坡下斜距比水平距长约 0.5%，大坡（30%）差达 15%，必须改化。

❓ 常见问题（FAQ）

公式？
水平距=斜距×cos(俯角)=斜距×sin(天顶距)。
不化会怎样？
面积/坐标全偏大，坡地工程差异显著，须先改化再算。
