📐 计算公式
平面坐标旋转（绕原点）：x′ = x·cosθ − y·sinθ、y′ = x·sinθ + y·cosθ（θ 旋转角按度输入、×π÷180 转弧度参与计算）。校验：无强校验，空值按 0 兜底。判据：无固定分级，旋转为正交变换、不改变点到原点的距离，结果保留三位小数。

x' = x·cosθ − y·sinθ，y' = x·sinθ + y·cosθ。

📌 计算说明
  • 逆时针为正。
  • 常用于坐标转换。

📚 深度解析：坐标旋转

💡 常见使用场景

  • 把点绕原点旋转 θ 得新坐标。
  • 轴线对齐/局部系建立。
  • 图形定向。
旋转 90°
(1,0) 绕原点转 90° → x'=1·cos90−0·sin90=0，y'=1·sin90+0=1 → (0,1)。
通用
θ=30°、点(2,0) → x'=2×0.866=1.732，y'=2×0.5=1.0 → (1.732,1.0)，用于把建筑轴转到正北。

❓ 常见问题（FAQ）

旋转公式？
x'=x cosθ−y sinθ，y'=x sinθ+y cosθ；逆时针为正，注意符号与弧度。
和坐标转换关系？
旋转是转换的一部分，配合平移/尺度才完整（四参数）。
