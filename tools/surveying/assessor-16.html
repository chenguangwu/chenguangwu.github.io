📋 GPS Accuracy (PDOP) Assessor

📐 计算公式
PDOP = √(HDOP² + VDOP²)；三维误差 = PDOP×UERE，水平/垂直误差分别 = HDOP/VDOP×UERE（m，UERE 默认 3）。校验：各项必填；PDOP 与由 HDOP/VDOP 复算值之差 <0.1 记 ✓。判据：PDOP ≤1 理想、≤2 优秀、≤5 良好、≤10 一般、>10 差；>5 建议等卫星或用 RTK；可见卫星 <5 无法可靠 3D 定位（≥6 记 ✓）。

📚 深度解析：GPS（精度/PDOP）评估

💡 常见使用场景

  • 外业前评估当前卫星几何构型的定位精度是否达标。
  • 判断 PDOP 是否满足 RTK、静态或快速静态测量的精度要求。
  • 结合 DOP 与误差等级选择最佳观测时段。
PDOP 与三维误差
UERE 取 3m 时：PDOP=2 → 三维误差≈±6m；PDOP=5 → ≈±15m；PDOP=10 → ≈±30m。DOP 越小精度越高，一般 <5 视为良好。
等级判定
PDOP≤1 理想、≤2 优秀、≤5 良好、≤10 一般、>10 差；可见卫星 <5 颗无法可靠三维定位，建议等待卫星或改用 RTK。

❓ 常见问题（FAQ）

PDOP 是什么？
位置精度因子，反映卫星空间几何构型对定位误差的放大倍数，值越小几何构型越好、精度越高。
HDOP / VDOP 与 PDOP 关系？
HDOP 为平面精度因子、VDOP 为高程精度因子，满足 PDOP²=HDOP²+VDOP²；误差=DOP×UERE。

Formula & Standard References

Item Formula / Note Source / Standard
DOP and positioning error Position error ≈ DOP × user equivalent range error (UERE) U.S. DoD, GPS Standard Positioning Service Performance Standard (5th ed., 2020)
PDOP and its components PDOP^2 = HDOP^2 + VDOP^2, combining horizontal and vertical parts U.S. DoD, GPS Standard Positioning Service Performance Standard (5th ed., 2020)
Interpretation A smaller DOP means a better satellite geometry and higher accuracy U.S. DoD, GPS Standard Positioning Service Performance Standard (5th ed., 2020)
How to improve it DOP drops as more satellites are visible and more widely spread U.S. DoD, GPS Standard Positioning Service Performance Standard (5th ed., 2020)
⚠️ 使用说明与注意事项
  • PDOP反映卫星几何分布对定位精度的影响，越小越好
  • PDOP=√(HDOP²+VDOP²)，理想值≤1，合格值≤5
  • 定位误差≈PDOP×UERE，UERE通常3-6m
  • 差分GPS(RTK)可将精度从米级提升到厘米级
  • 可见卫星数应≥4颗方可3D定位，≥6颗较可靠
