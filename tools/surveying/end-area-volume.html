Earthwork Volume from Two End Areas

Compute earthwork volume between two cross-sections from their end areas and spacing.

📐 计算公式
平均断面法土方量（本页代码口径）：V=(A₁+A₂)÷2×L（m³，A₁/A₂ 两端断面面积 m²、L 断面间距 m）；联动量：平均断面面积=(A₁+A₂)÷2（m²）、两端面积差=|A₁−A₂|（m²）。校验：无强校验，空值按 0 兜底。判据：无固定分级，两端面积差越大该法误差越明显，宜加密断面。

输入两端断面面积 A₁、A₂ 与间距 L，求体积。

Formula & Standard References

Item Formula / Note Source / Standard
Average end-area method V = (A1 + A2)/2 · L GB 50026-2020, Code for engineering surveying
Prismoidal formula V = L/3 · ( A1 + A2 + sqrt(A1 · A2) ) GB 50026-2020, Code for engineering surveying (earthwork volume)
Difference between the two The average end-area method errs more as end areas differ; prefer the prismoidal formula then GB 50026-2020, Code for engineering surveying
Units Volume in cubic metres, area in square metres and spacing in metres GB 50026-2020, Code for engineering surveying
📌 计算说明
  • 相邻断面取平均乘间距。
  • (10+20)/2×50 → 750 米³。

  • 两断面面积平均乘间距。
  • 渠道/路基土方。

断面
A₁=120、A₂=80、L=15m → V=(120+80)/2×15=1500 m³。
分段

❓ 常见问题（FAQ）

和棱镜体区别？
平均断面=(A₁+A₂)/2×L；棱镜体=L/6(A₁+4Am+A₂) 更准（含中截面），线性变化两者等。
间距均一吗？
间距应相等或逐段用对应 L，混距直接套会错。
