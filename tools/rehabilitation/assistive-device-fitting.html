📖 适配原则参考

轮椅适配原则

  • 座宽 = 臀宽 + 2cm
  • 座深 = 坐深 - 2-5cm（腘窝距座面前缘2-5cm）
  • 座高 = 小腿长 + 5cm（脚踏板离地5cm）
  • 靠背高 = 坐高 - 座高（高位截瘫需加高）
  • 扶手高 = 坐位时前臂平放高度
  • 承重选择：体重×1.5倍安全系数

矫形器适配原则

  • AFO：小腿围+2cm余量
  • KAFO：大腿围+2-3cm余量
  • 关节铰链对准解剖关节轴
  • 压力面均匀分布，避免压疮
  • 重量不超过患肢承重能力

假肢适配原则

  • 接受腔全面接触，均匀承重
  • K级别决定组件选择
  • 假肢重量≤对侧肢体重量的80%
  • 残肢长度影响悬吊和控制
  • 定期调整适配残肢变化
