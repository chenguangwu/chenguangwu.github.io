🩼 助行器高度(股骨大转子)调节器

计算助行器、拐杖、手杖的正确高度，确保安全使用和正确姿势

请输入身高等参数

📖 辅助器具高度标准

标准助行器（Walker）

  • 手柄高度 = 股骨大转子高度（约身高的55-60%）
  • 或 = 地面至腕横纹距离 + 2-3cm
  • 站立时肘关节屈曲20-30度
  • 使用时身体应在助行器后方，不要太前倾

前臂拐杖（Forearm Crutch）

  • 手柄高度同助行器（腕横纹+2-3cm）
  • 前臂套环高度 = 鹰嘴上方2.5-3cm
  • 前臂套环松紧适中，能通过前臂但不滑脱

腋拐（Axillary Crutch）

  • 腋托高度 = 腋窝下方5cm（约身高的77%）
  • 手柄高度 = 腕横纹+2-3cm（肘屈20-30°）
  • 腋窝不应直接承重，力量在手上
  • 腋托与腋窝保留2-3指宽度间隙

单拐/手杖（Cane）

  • 手柄高度 = 股骨大转子高度
  • 或 = 地面至腕横纹距离
  • 站立时肘关节屈曲20-30度
  • 应使用在健侧（非患侧）
