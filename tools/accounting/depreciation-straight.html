Compute annual depreciation and the depreciation rate with the straight-line method from cost, salvage value and useful life.

📐 计算公式
直线折旧（年限平均法）：年折旧额 = (原值−残值)÷使用年限（元）；联动量：年折旧率 = 年折旧额÷原值×100（%）、首年末账面值 = 原值−年折旧额（元）。校验：三项输入空值守卫，空值即提示；年限为 0 时除零结果按「—」兜底。判据：无固定分级，各年折旧额均等、账面值线性递减直至残值。

年折旧 = (C − S) / n。

  • 残值不计提折旧。

💡 常见使用场景

  • 房屋、家具等效用在各期均衡的资产，用直线法平稳分摊成本。
  • 需要简单、可预期的年度折旧费用便于预算与报价。
  • 税务折旧与会计折旧一致时，减少纳税调整工作量。
计算直线法年折旧
某设备原值 50 万元、预计残值 5 万元、使用年限 5 年，年折旧=(50−5)/5=9 万元，月折旧 0.75 万元，五年后账面净值等于残值 5 万元。

❓ 常见问题（FAQ）

直线法为什么最常用？
计算简单、各期费用均衡、利润平滑，适合效用稳定、技术更新慢的资产，也便于与外部报表和税务衔接。
预计净残值为 0 或负数怎么办？
净残值一般取预计处置收入减处置费用后的净额，通常≥0；若预计处置费用高于收入，实务中仍按 0 处理，不得提为负。
