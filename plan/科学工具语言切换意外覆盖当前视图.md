# 科学工具语言切换意外覆盖当前视图

- 受影响工具路径：`tools/science/statistics-calculator.html`、`tools/science/vector-calculator.html`
- 问题：综合统计工具画过直方图后，将语言切换事件长期绑定到 `showHistogram()`；即使用户随后切到计算结果、频数表、公式或历史，切换语言仍会重新生成直方图并覆盖当前视图。向量工具在绘制含结果向量的图后同样长期绑定 `showPlot()`，可能覆盖随后显示的结果、公式或历史。依据事件处理源码静态分析，实际语言切换行为待浏览器核验。
- 解决方案：保存当前视图类型，仅在图表仍是当前视图时重绘该图；其他视图按原状态翻译或重渲染，避免重复计算或新增历史。覆盖画图后切到结果、公式和历史再切换语言，以及尚未画图和输入变更的场景。
