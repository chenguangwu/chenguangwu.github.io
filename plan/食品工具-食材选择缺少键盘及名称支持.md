# 食品工具：食材选择缺少键盘与无障碍支持

## 问题

食材搭配的选择卡片使用仅带点击事件的 `div`，不能通过键盘聚焦或操作，也未暴露选中状态；维生素 C 对比的复选框没有关联标签或可访问名称，食材名称只是相邻文本，读屏用户难以辨认控件。静态源码核查，待浏览器及辅助技术复现。

## 解决方案

食材搭配使用原生按钮或复选框并提供选中状态和可见焦点；维生素 C 对比将名称与复选框关联。验证 Tab、空格、回车、重绘后焦点、选择上限提示以及中英文可访问名称。

## 受影响的工具路径

- `tools/food/food-pairing.html`
- `tools/food/vitamin-c-compare.html`
