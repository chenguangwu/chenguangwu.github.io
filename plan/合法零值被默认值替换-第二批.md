# 合法零值被默认值替换：第二批

## 问题描述

以下页面的字段允许输入 0，但部分计算或重置路径使用 `值 || 非零默认值`：

- `tools/electronics/smt-stencil.html`：焊膏转移率允许 0–100%，输入 0 时 `calc()` 使用 70%，因此理论转移体积显示为非零。
- `tools/cosmetic-derm/corneometer.html`：环境湿度允许 0–100%，输入 0 时使用 50%，导致按湿度调整的数值与输入不符。
- `tools/wedding/wedding-budget-planner.html`：总预算为 0 后使用重置预算分配，`renderItems()` 使用 100000 生成分类金额，和输入的零预算不一致。
- `tools/geology/calc-1.html`：阈值字段允许 0，但计算使用 100；需核对该参数的标准适用范围，决定明确禁止 0 还是正确处理 0，不能静默替换。

上述均由字段及计算源码确认，需分别用浏览器复现完整结果及复制/导出链路；其中与工程或健康相关的解释须由相应专业人员核对。

## 解决方案及验收

按实际业务范围显式验证空值、有限数和允许区间；允许 0 的字段应让 0 参与计算，不允许的字段应显示原因。逐页验证 0、默认值、普通值、空值及越界值，检查预设、重置、结果、复制与导出一致，中英文提示同步。
