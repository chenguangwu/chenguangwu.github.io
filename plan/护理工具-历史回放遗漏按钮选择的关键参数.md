# 护理工具：历史回放遗漏按钮选择的关键参数

- 受影响工具路径：
  - `tools/clinical-nursing/cvc-maintenance.html`
  - `tools/clinical-nursing/gastric-tube-depth.html`
  - `tools/clinical-nursing/chest-compression-depth.html`
  - `tools/clinical-nursing/tracheostomy-dressing.html`
  - `tools/clinical-nursing/oxygen-concentration.html`
  - `tools/clinical-nursing/restraint-duration.html`
- 问题描述：这些页面的关键类别或计算方法由按钮维护在 JavaScript 变量中，通用历史快照只收集带 ID 的表单控件。回放时恢复控件后直接按当前变量计算，切换类别后回放可能得到与保存时不同的结果。例如透析导管记录在当前为普通 CVC 时回放，会按普通 CVC 计算；胃管测量法记录在当前为身高法时回放，也会使用当前方法。约束松解计划回放也会沿用当前约束类型，导致与保存时的类型和松解时长不一致。
- 解决方案：将按钮选择的状态显式纳入每次历史快照，恢复时先恢复类别和相关控件状态，再按保存的参数计算；避免恢复类别时默认值覆盖已保存输入。逐页验证跨类别回放的选中状态、输入、结果与摘要一致，并排查其他使用同类历史组件的工具。
