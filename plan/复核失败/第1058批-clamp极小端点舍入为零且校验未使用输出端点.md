# 第1058批复核失败：clamp 极小端点舍入为零且校验未使用输出端点

- 页面：`tools/it/clamp-calculator.html`，`fmtSize()`、`clampConfig()` 和 `slide()`。
- 复现：输入最小字号 `0.000000001`、首选 `0.000000002`、最大 `0.000000003`，视口 `320` 至 `1200`。这些均满足当前 `clampConfig()` 的正数和顺序校验。直接执行页面函数得到 `clamp(0px, 0.0000000002vw + 0.0000000004px, 0px)`，实际 CSS 固定为 0；但内部 `evaluate(320/760/1200)` 分别约为 `1.04e-9 / 1.92e-9 / 2.8e-9`，计算的最大偏差约 `2e-10`，没有反映输出端点已经变成 0。`slide()` 另以两位小数格式化预览，小于 0.005px 的值也显示为 0。
- 原因：表达式端点固定保留 8 位小数，而校验闭包仍使用未舍入的 `m` / `x`；预览又单独使用两位小数。第1058批关于极小边界及“预览和表达式按实际输出求值”的问题仍未彻底解决。
- 建议：按输入量级选择足够精度或明确限制可接受的最小值；用最终序列化后的端点及系数计算校验和预览，无法在支持精度内表达时明确提示，不应输出与校验不一致的表达式。补充上述样例及舍入临界、非线性折线回归。
