# 复核失败：JSON 生成代码的 Go 特殊键映射

- 来源：已修复批次「2026-11-09-重做-第一批-JSON生成代码定义顺序与关键字转义」，IT-N380 / N382 / N384 为同一条，部分修复不得判通过。
- 已复核：Python 子类型顺序、Python/Java/Kotlin/Rust 保留字处理与特殊键字面量语法转义；另修复控制字符导致 Python 源码含 NUL 的问题。定向回归 24/24，Python 生成代码六个样例实际执行通过。
- 失败点：Go 的 `json` struct tag 虽可通过转义使生成代码语法合法，`encoding/json` 仅接受 Unicode 字母、数字及除引号、反斜杠和逗号之外的 ASCII 标点组成的非空 tag 名，含双引号、反斜杠、控制字符等 JSON 键会被忽略或错解析，退回字段名，不能保留原键映射。官方依据：https://go.dev/src/encoding/json/encode.go （Marshal 的 struct tag 说明）。
- 复现：输入 `{"a\"b":1}` 选择 Go；生成 `AB int` 及 `json:"a\"b"` tag；实际 tag 名解码后为 `a"b`，不符合标准库允许字符，序列化键为字段名 `AB` 而不是 `a"b`。反斜杠、逗号及控制字符也须覆盖。
- 待处理：为不能由标准 `encoding/json` tag 直接表达的键设计正确的序列化与反序列化方案，或对该限制明确提示而不得暗示映射正确；使用 Go 真实编译器和 `encoding/json` 进行双向行为验证，覆盖特殊键和普通键。当前环境未安装 Go，未声称真实编译验证。
