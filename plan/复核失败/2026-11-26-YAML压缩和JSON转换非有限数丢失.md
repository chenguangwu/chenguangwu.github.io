# YAML 压缩与转 JSON 静默丢失非有限数

复核第 797 批：`tools/it/yaml-formatter.html` 以 `jsyaml.CORE_SCHEMA` 解析 YAML 后，压缩和 YAML→JSON 直接使用 `JSON.stringify()`。合法输入 `a: .inf\nb: .nan` 解析为 Infinity 与 NaN，序列化得到 `{"a":null,"b":null}`，两处均静默改变数据，压缩后的 YAML 不再保留类型和值。使用仓库 js-yaml 与 Node 已复现。

修复方案：压缩时采用能保留 YAML 非有限数的序列化方式；转 JSON 时递归检测 JSON 不支持的值并明确拒绝或提示用户选择转换策略，不得静默改成 null。覆盖正负无穷、NaN 及嵌套结构，并解析输出比对。
