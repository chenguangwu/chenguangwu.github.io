# 第438、451、452批复核失败：三个工具页实际缺少 main 地标

`tools/it/code-highlighter.html`、`tools/it/html-tags.html` 和 `tools/it/html-minifier.html` 都有真实 `.container`，但 DOM 内均无 `<main>` 或 `[role="main"]`；三页各在示例代码或脚本字符串中含字面 `<main>`，文本匹配会将其误判为实际地标。用 jsdom 解析三页并执行 `document.querySelectorAll('main,[role="main"]').length` 均为 0，屏幕阅读器无法定位主内容。

建议构建过程和审计跳过 script、style、textarea、pre 等代码/文本示例，按实际 DOM 判断，再给对应真实主容器增加 `role="main"`；用 DOM 验证此三页均恰有一个主地标，并确认重复构建不回退。
