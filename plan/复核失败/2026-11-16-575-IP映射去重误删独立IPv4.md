# 575 批复核失败：IPv4 映射去重误删独立地址

原记录：`2026-11-15-575-大小写字符频率IP三页.md`，BS-N89 要求 IPv4 映射地址不重复输出。

`tools/biz/text-extract-ips.html` 的 `extract()` 先分别提取全文 v4/v6，再以 `v4.filter(ip => !v6.some(x => x.includes(ip)))` 全局按文本过滤；输入 `::ffff:192.168.1.1 192.168.1.1` 且关闭去重时，独立出现的 IPv4 也被删掉，无法正确统计出现次数。应按匹配位置排除映射地址内部的 IPv4，而非删除所有同值地址。代码静态核验，未运行浏览器。
