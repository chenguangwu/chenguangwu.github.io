# 第 943 批复核失败：视频时长零值处理与记录不符

本批 14 个字段的 min/step 改动和默认值对齐已核对；记录宣称改成 `min=0` 后仍由 JS 拦截零值，但视频页不满足：

- `tools/video/video-compressor.html` 的 `calc()` 使用 `+duration.value || 10`，输入 0 会静默按 10 分钟计算，不会拦截；清空也会回退为 10。
- `tools/video/video-converter.html` 的 `generate()` 直接读取数值并用于大小估算，0 不会按记录所述拦截。

请依据视频时长业务规则明确处理 0 和空值，避免静默使用默认值，补输入 0、清空和有效值切换后的结果/导出测试。其他字段如宠物年龄的 0 是否有效应按实际业务判断，不能仅凭本批统一声明判定。
