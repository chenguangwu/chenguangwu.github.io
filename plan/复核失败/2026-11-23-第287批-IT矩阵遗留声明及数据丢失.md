# 第 287 批复核失败：IT 矩阵仍有具名缺陷

原矩阵的“声明超出实现”并未全部处理：

- `tools/it/csv-to-json.html:484` 仅遍历表头构造对象；输入 `a,b\n1,2,3` 时第三列静默丢失，正文只笼统说列数不一致应有策略，未提示会丢数据。应拒绝超出表头的行并提示行号，或提供明确保留多余列的方案，增加不等列数回归。
- `tools/it/yaml-to-json.html:330` 仍以 `^([^:]+):` 拆键，对合法引号键 `"a:b": 1` 错误拆分并静默输出错误结果。应使用可靠的 YAML 解析器，或拒绝未支持语法并提示，不可静默转换；同族 YAML 页逐一检查。
- `tools/it/http-methods.html:317` 将 TRACE 标为“已废弃”；原矩阵已指出 RFC 9110 仍定义它。应改为诊断方法、常因安全策略禁用，并核对相关翻译。

历史矩阵中其他已确认回归另见第 145、161、320、351 批的复核失败记录；修复时一并复查矩阵原记录的其他边界及跨语言输出。
