# JSON 格式化极小指数下溢后静默变零

来源：已修复第 722 批。`tools/it/json-formatter.html` 的 `__isRiskyNumber()` 只检查非有限数、不安全整数和有效位数，对 `1e-400` 返回 false；`__parseJsonPreserve()` 随后调用 `Number()` 得到 0，格式化、复制及下载都丢失原始数字。`9e-324` 也会舍入为 `1e-323`。

修复方案：对指数形式的下溢及无法精确保持的数字字面量使用保精度类型，避免先转为 Number；增加正负下溢、次正规数和普通指数回归，并核对树视图、格式化、排序、复制与下载。
