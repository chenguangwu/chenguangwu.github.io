# 第 462 批复核失败：部分输入仍静默按 0 计算

- 原问题：非法输入被 `|| 0` 静默变成合法零值，产生看似正常的结论。修复要求包括三相功率各模式输入均校验，以及车贷利率原始串非空。
- `tools/electrical/calc-2.html` 的 `calcThreePhase()` 三个模式仍分别用 `parseFloat(... ) || 0` 读取 current、pInput、qInput，之后 `isFinite` 已无法识别空值或 NaN；这三项清空均输出 0.000 而非提示。用 Node VM 执行当前函数、固定电压 380 和功率因数 0.8，依次清空三个模式的输入，三次均得到 0.000。需要在兜底前判空和判有限数，保留真实 0 的合法性。
- `tools/finance/car-loan-calculator.html` 的 `calculate()` 将 `rateRaw === ''` 直接设为 0，且非空校验只覆盖 price/downPct/years；与记录所称利率原始串非空不符，清空利率仍按零利率计算。需明确提示空利率，同时允许用户明确输入 0。
- 其余列出的修复通过源码核查：DLI、鼓室图、干物质、贝叶斯概率输入的有限数及范围守卫仍在，化学页 select 已有兼容回退，水质页不再 `|| 0`。
