# JSON 差异的指数形式数字仍丢精度

来源：已修复第 723 批。`tools/it/json-diff.html` 的 `jdParse()` 只对不带指数的整数、带小数点且高有效位数的数字创建 `JDNumber`。实测 `9007199254740993e0` 和 `9007199254740992e0` 均被解析为 9007199254740992，从而漏报差异；`1e400` 成为 Infinity，`1e-400` 成为 0，也不能保留原文。

修复方案：按完整数字字面量（包括指数）识别溢出、下溢和精度损失，并以保精度数字参与比较与序列化；增加上述不同数值及等值指数写法的双向比较、视图和导出回归。
