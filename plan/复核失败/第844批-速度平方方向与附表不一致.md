# 速度平方工具仍错误判定运动方向，附表沿用正根

复核来源：第 844 批，`tools/kinematics/velocity-squared.html` 的 `calcTool()` 和 `__velocity_squaredExtras()`。

主计算对所有 `v0 >= 0` 直接取正根，但正向运动减速后可能反向。例如初速度 10 m/s、加速度 −1 m/s²、位移 0 m，t=0 与 t=20 s 都到达该位移，速度分别为 +10 和 −10 m/s，页面却只给 +10，声称“取正向分支”。初速度 0 且加速度为负时同样应取负向，页面仍取正根。附表无条件用正根算“末速度/速度增量”：初速度 −10、加速度 0、位移 1 时，主结果为 −10 和 0，附表却显示 +10 和 +20；不可达时附表还会出现 NaN。

建议根据速度方程及非负时间求可行分支，对可能多次到达的位置展示全部有效速度与对应条件；附表和历史复用主计算结果，不可达时清空，新增上述反向、零初速度及附表一致性测试。
