# 第 528 批复核失败：指南面包屑 HTML 损坏

## 问题与依据

`guides/uuid-generator-guide.html:70` 的导航写成 `data-i18n-fb="> 使用指南</a> / <span data-i18n="...`，属性引号未闭合，后续标签被解析成属性或文本。真机英文态扫描可见 `> 使用指南</a> / <span data-i18n=` 等源码碎片；同一损坏模式在指南目录命中 63 页，包含 csv-to-json、parking-fee 等原批抽查页。英文头部审计通过无法覆盖这一问题。

## 建议修复

修复所有受影响页面的面包屑属性和标签闭合，核实中英文切换与导航链接；增加基于浏览器 DOM 的面包屑结构和可见文本回归检查，避免只检查 head。
