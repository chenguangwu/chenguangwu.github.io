# 第233批复核失败：Proto 校验接受 oneof 内的 map

- 原项：IT-N277 要求校验不再仅数括号，应识别非法 .proto 并报告失败；本批同时扩展 IT-N276 的 map 解析。
- 未落实：`tools/it/protobuf-parser.html` 的 `parseOneof()` 明确接受 map 字段，专项脚本将该行为视为通过，因而 `doValidate()` 会把不合法的 oneof 声明判为通过。

- 应在 oneof 中拒绝 map 字段，补充与真实 protoc 对照的非法输入测试，并保持普通 message 内 map 支持。

其余 IT-N273、N274、N275 及普通 message 内 map 解析已按当前源码与专项脚本核验。
