# 金融 F-N75：ROI 页亏损超过本金时年化静默显示 0.00%（已修 · 申请复核）

## 来源
- `plan/categories/02-金融财务/finance.md` 的 F-N75（低，确认缺陷）。

## 根因
- `tools/finance/calc-5.html` `calc()` 中 `annualized` 初值 0，仅在 `years>0 && roi>-1` 时计算；但摘要卡 `{num:years>0?fmt(annualized*100,2)+'%':'—'}` 只要 `years>0` 就无条件渲染，因此 ROI ≤ −100%（本金全损/倒亏）时总 ROI 显示 −100%/−150%，年化却显示 0.00%，正文 `annualText` 为空，两处互相掩盖，易被误读为保本。

## 修复位点
- 正文分支补无解提示：
  ```javascript
  } else if(years>0){
    // F-N75：1+roi ≤ 0 时无法按复利开方，不能把年化初值 0 渲染成「零回报」
    const __en = (typeof TBKit!=='undefined'&&TBKit.util.isEn());
    annualText = __en ? '<p style="color:var(--danger)">Loss exceeds principal; compound annualization is undefined.</p>' : '<p style="color:var(--danger)">亏损超过本金，无法按复利年化。</p>';
  }
  ```
- 摘要卡改为与计算同条件：`{num:(years>0 && roi>-1)?fmt(annualized*100,2)+'%':'—',label:'年化回报率'}`。
- 有效 ROI 路径输出完全不变；英文态经页面既有 helper 输出纯英文。
