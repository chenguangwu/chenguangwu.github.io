# 第 980 批复核失败：合法 XML 自闭合标签被误判

## 问题与证据

`tools/it/xml-to-json.html`、`xml-to-toml.html`、`xml-to-yaml.html` 的 `xmlWellFormed()` 使用 `[^>]*?` 截取标签尾部，不能识别引号内的 `>`。合法 XML `<根 属性="1>2"/>` 会在属性值中的 `>` 提前结束正则匹配，未识别后面的自闭合 `/`，留下未闭合栈，三页均拒绝。直接提取三页现有 `xmlWellFormed()` 用该输入执行，返回均为 `false`；普通 `<根 属性="1>2">x</根>` 则返回 `true`，原记录的测试仅覆盖后者。

## 建议修复

让结构预检正确跳过属性引号内的 `>` 并识别自闭合，或依靠浏览器 `DOMParser` 的解析错误检查，避免维护不完整的正则 XML 解析器。三页均增加中文标签、单/双引号属性含 `>` 的自闭合与普通标签回归，同时保留非法结构拒绝测试。
