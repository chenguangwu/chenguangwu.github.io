# 第1343批复核失败：零值被拒与空值被当作海平面

1. `tools/food-testing/convert-36.html` 对滴定体积使用 `V<=0` 守卫，体积为 0 的测量被当作无效，尽管其计算结果可以为 0；应区分空输入与合法零值，样品质量和浓度仍按实际物理约束验证，增加 V=0 与空输入用例。
2. `tools/astronomy/convert-18.html` 的 `const v=+...value||0` 在海拔转气压模式把空输入当作 0 米，显示 1013.25 hPa；应先检查原始字符串是否为空，再解析并保留合法 0 米，同时测试空值和零值。

纱线除零、退休表及复利图清理的定向检查通过；上述问题不被本批源码形态测试覆盖。
