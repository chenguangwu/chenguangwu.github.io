# 553 复核失败：价格不变时导出仍计算无定义弹性

原记录：`plan/已修复/2026-11-15-553-MS-N61N62-弧弹性深解与价格未变守卫.md`。

- `tools/marketing/price-elasticity.html` 的 `calc()` 已阻止 P₁=P₂，但 `__peExport()` 只检查四项大于零，仍以 `dP=0` 除法生成 `Infinity` 或 `NaN` 并导出弹性等级和建议。应对导出同样执行价格未变守卫，避免输出无定义结果；例如 P₁=P₂=100、Q₁=100、Q₂=120 会导出 Infinity 和富有弹性。
- 原验收记录称 100→90、1000→1200 得 −2.478、收入 +17%；按中点法实际是 −1.727、收入 +8%。页面默认新销量是 1300，才得到 −2.478 和 +17%；应纠正验收数据并重验。
- 正弹性时的收入建议仍可能与实际变化相反：100→110、100→120 时收入从 10000 增至 13200，却写「涨价会减少收入」，导出也相同。应按实际收入或适用前提给出一致建议。

证据：静态检查同页 `calc()`、`__peExport()`；上述数值按页面公式计算。其他已落实内容不保留于此。
