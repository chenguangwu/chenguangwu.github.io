# Cron：末日列表和步长表达式校验通过但不执行

复核第 773 批：`tools/it/cron.html` 的 `validateCronField()` 在日期字段允许列表项 `L`，且解析完步长后仍直接接受 `L`，例如 `0 0 L,15 * *` 和 `0 0 L/2 * *` 都通过校验。`matchField()` 仅对整个字段恰好为 `L` 做月末匹配，列表中的 `L` 会被 `parseInt` 忽略，`L/2` 的起点为 NaN，导致前者漏掉月末、后者永不匹配。Node 执行校验函数已确认两条被接受。

修复方案：将 L 的语法限制与匹配实现统一；如不支持列表或步长，校验时明确拒绝，否则逐项实现并说明方言。覆盖月末与 15 日、带 L 步长、单独 L 和非法表达式，核对预览实际执行时间。
