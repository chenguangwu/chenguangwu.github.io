# 正则可视化的状态链误导匹配语义

- 原记录：第559批-默认值计算NaN扫描与正则图修复。
- 位置：`tools/it/regex-visualizer.html` 的 `tokenize()` 与 `buildStates()`。
- 复核：末边的 `undefined` 已替换成 `ε`，但状态链仍逐字符将运算符当作顺序转移标签。例如 `a|b` 被绘制为 `a → | → b → ε`，`a*` 被绘制为 `a → * → ε`，既没有分支也没有重复路径。页面称其为状态转移图，并说明可据状态链理解转移顺序，容易被理解成可执行的正则匹配状态图；正文 FAQ 还声称量词会表现为跳过/重复回路，与实际输出矛盾。
- 建议：由语法树构造能表达分支和量词的真实状态转移图；如暂不实现，则明确改称词元顺序示意并移除状态转移及回路相关误导说明，避免用于推断匹配行为。验证 `a|b`、`a*` 和字符类等案例。
