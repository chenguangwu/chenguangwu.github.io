# 复核失败：F-N211 镜像文字仍拆分组合 emoji

- 来源：`plan/已修复/2026-11-10-金融F-N211-镜像文字emoji码元反转乱码.md`。
- 已复核：`tools/finance/mirror-text.html` 改为按 Unicode 码点反转，`a😀b → d😀ɒ`、`a𠀀b → d𠀀ɒ`、`abc → ɔdɒ` 均正确，单个增补平面字符代理项不再拆散。
- 失败点：按码点反转仍会打乱由多个码点组成的用户可见字符。`a👩‍💻b` 实际输出 `d💻‍👩ɒ`，把 ZWJ 序列倒过来；`a🇨🇳b` 实际输出 `d🇳🇨ɒ`，中国国旗变成另一旗帜。测试均使用 `scripts/verify_it_calc.js` 的 `runCase` 执行页面 `convert()` 确认。
- 待处理：按用户感知字符（字素簇）反转并保留簇内部顺序，考虑主流浏览器兼容；覆盖 ZWJ emoji、国旗、肤色修饰符、组合重音、单 emoji、生僻字及普通文本，确认复制结果保留原簇。
