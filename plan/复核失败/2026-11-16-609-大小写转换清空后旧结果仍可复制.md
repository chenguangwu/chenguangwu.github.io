# 第 609 批复核失败：大小写转换清空输入后保留旧结果

- 原要求：输入变化后预览、复制、历史不再指向旧文本，并明确复核「合法 → 清空 → 恢复」。
- 证据：`tools/biz/text-case-advanced.html` 的 `updatePreview()` 仅在 `lastMode && input && input.value` 为真时调用 `convert(lastMode)`。先把 `abc` 转为 `ABC`，再手动清空输入，会跳过重算，预览仍为 `ABC`；`copyResult()` 随后仍可复制旧值。虽然 `convert()` 自身有空输入提示，但此路径未调用。应清空或提示并阻止复制旧结果，补充清空及恢复的行为回归。
- 已复核：其余列出文本页专项用例 26/26；`text-stats` 和 `random-script` 英文态探针均无残留。
