# 第 463 批复核失败：零人数漏斗仍未完整兑现

- 原要求：两个漏斗全阶段人数为 0 时，基准与柱宽按 0 处理；历史回填保留合法零值。
- `tools/hr/recruitment-funnel.html` 的页面柱宽已按 0 处理，但 `__rfExport()` 仍直接执行 `stages[i].count/maxCount*100`；全零时得到 `NaN`，导出表的宽度为 `NaN%`，不符合零计数宽度为 0% 的要求。证据：该函数约第 354–364 行，`(0/0*100).toFixed(1)` 为 `NaN`。
- `tools/sales/conversion-funnel.html` 的 `calc()` 约第 263 行把首阶段 0 直接当作未填写，显示“请填写首阶段人数”，并不展示记录要求的 0% 柱宽；0 是合法数值，不能等同未填写。
- 五页对应历史回填当前均使用 `??`，合法 0 不再被非零默认值覆盖。
