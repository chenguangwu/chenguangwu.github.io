# 第240批复核失败：Python 三引号内容被改写、非法缩进通过

- IT-N300：`formatPython()` 按新缩进重写三引号体内的文本，改变字符串值。JSDOM 输入 `if True:\n    s = """start\n    keep\n    """\n    print(repr(s))`，默认 2 空格缩进的输出将字符串内容行的 4 个空格改成 2 个；两者都能编译但字符串不同。应保留三引号文本的字节内容并用值比较测试。
- IT-N302：`doValidate()` 只检查冒号后的下一行缩进，没有检查后续退格是否匹配已有层级。输入 `if True:\n    x=1\n  y=2` 时页面显示「✅ 结构检查通过（缩进/括号/三引号）」，Python 实际会报 `IndentationError: unindent does not match any outer indentation level`。应检查缩进栈，覆盖不匹配退格。
