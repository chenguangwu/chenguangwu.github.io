# 声压级叠加迁移后空值守卫丢失

历史第 57 条修复了 `tools/acoustics/spl-add.html` 中缺一声压级被当作 0 dB 的问题。该地址现为重定向壳，目标 `tools/acoustics/combine-two-spl.html` 的 `num()` 对空值返回 0，`calcTool()` 未再校验原始输入。例如第一项 80 dB、第二项留空时，仍输出约 80.00 dB 和后续结论，重新出现原缺陷。

修复方案：在目标页读取原始值并分别校验非空且有限，保留合法的 0 dB；缺项时清除结果及附属图表、表格和复制导出内容，补迁移目标页单项清空、0 dB 和恢复有效输入的测试，并核对旧地址相关用例已迁移。
