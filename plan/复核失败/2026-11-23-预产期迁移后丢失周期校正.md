# 预产期迁移后丢失月经周期校正

原 `tools/medical/calculator-calc-due-date.html` 支持输入 21–45 天月经周期，并仅在末次月经模式按 `280 + 周期 - 28` 天计算。当前旧地址重定向到 `tools/health/pregnancy-due-date.html`，目标页末次月经模式只按固定 28 天周期计算，无法输入规律但非 28 天的周期。例如 32 天周期原工具会比 28 天周期推迟 4 天，现工具无法体现。

建议在目标页恢复周期输入及末次月经模式下的校正，并保持排卵日、超声和 IVF 模式不重复校正；同步检查提示及各模式回归。
