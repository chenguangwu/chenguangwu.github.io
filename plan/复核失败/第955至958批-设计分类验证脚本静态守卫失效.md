# 第955至958批复核失败：设计分类验证脚本静态守卫误报

## 现象与定位

当前合并 master 后运行 `node scripts/verify_design_calc.js`，计算用例 411/411 通过，但静态项 32/33，进程报告 `B202 converter token missing:if (__token !== __convertToken) return;`。`scripts/verify_design_calc.js:113` 要求固定源码字符串；`tools/image/image-converter.html:406` 当前过期分支先释放对象 URL，再 return，后续转换也有 token 守卫。静态断言没有接受现行的资源清理逻辑，导致本批声称通过的分类验证在当前代码上失败。

## 修复方案

将脆弱的固定字符串断言改成验证过期任务不能更新结果且资源被释放的行为用例；若仍保留静态守卫，应覆盖现行分支与异步回调，再运行设计分类验证，确认完整通过。
