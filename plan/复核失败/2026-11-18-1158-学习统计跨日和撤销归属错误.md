# 第 1158 批复核失败：学习统计跨日和撤销归属错误

`tools/edu/study-planner.html` 只在 `loadData()` 检查日期和周变化；页面跨午夜保持打开时，`toggleTask()` 直接累加旧统计并更新日期键，导致昨日数据被算作今日且后续刷新也无法重置。另任务未保存完成日期，次日撤销昨日完成的任务会从今日/本周统计扣除该任务时长；每日任务完成数、科目和总时长因此可能错位。取消进度输入的 prompt 返回 null 也被 `Number(null)` 当 0 并保存。

建议在每次统计变动前检查并滚动日期/周，保存任务完成时间或以事件重算对应期间，撤销只影响原归属日期；prompt 取消须直接返回。补跨午夜不刷新、跨日撤销及取消输入测试。其余首启归零、计划联动、历史入口和科目选择已核对。
