# 证件照默认快捷预设仍引用旧尺寸

`tools/image/id-photo-crop.html:724` 的「默认参数」快捷预设仍把 `preset` 设为 `258,335,一寸（258×335）`，而 select 选项已经改为 `295,413,一寸（25×35mm / 295×413px）`。旧值不再匹配选项；点击该快捷预设会令选择器失去有效选项，后续解析和导出可能失败。第 585 批声称四组合预设及旧值已清除，当前不成立。

修复方案：将默认快捷预设改成与 select 完全一致的新值，检查所有预设是否都能命中现有 option，并真机验证点击默认后能正常预览导出 295×413。
