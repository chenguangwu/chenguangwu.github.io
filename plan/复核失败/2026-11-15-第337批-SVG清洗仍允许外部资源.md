# 第337批复核失败：SVG 预览仍可加载外部资源

原记录要求清洗外部引用并在终检发现外链时丢弃内容，但当前清洗和终检只检查 `href`/`xlink:href`，`generate()` 只要求输入包含一对 SVG 标签，随后将整个输入写入 `preview.innerHTML`。例如 `<svg></svg><img src="https://example.com/tracker.png">` 经实际调用 `sanitizeSvg()` 后原样保留、`removed=false`，`__svgStillDangerous()` 返回 false；浏览器解析后会创建外部图片请求。SVG 内的 CSS `url(...)` 也未被上述检查覆盖。应限制解析范围及资源引用，并以真实浏览器验证不会发起外部请求。

验证：`node scripts/verify_design_calc.js svg-viewer` 为 5/5；对当前函数执行上述输入得到原字符串和 `danger=false`，说明现有用例未覆盖该路径。原记录其他清洗及提示项目已复核，从原记录移除。
