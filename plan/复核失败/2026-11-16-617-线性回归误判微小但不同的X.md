# 第 617 批复核失败：线性回归误判微小但不同的 X

原记录要求仅在五个 X 全相同、回归分母为零时停算。`tools/statistics/statistics-16.html` 的 `calc()` 和 `__lrExtras()` 使用固定绝对阈值 `Math.abs(5*Σx²-(Σx)²)<1e-12`，把合法的小尺度数据也当作全相同。

验证：X 为 `0, 0.00000001, 0.00000002, 0.00000003, 0.00000004` 时，分母约 `5e-15`，页面会提示“x 值全部相同”；取 Y 为 `0,1,2,3,4` 时，各 X 明显不同，直线斜率应为 `100000000`。需用数值稳定且适配数据尺度的方式判断退化，避免错误停算，并覆盖小尺度合法数据。

其他原修复项的专项测试 `node scripts/verify_statistics_calc.js statistics-16` 为 4/4；英文探针默认态无可见中文残留。
