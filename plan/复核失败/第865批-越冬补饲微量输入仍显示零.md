# 越冬补饲极小正数仍被显示为零

复核来源：第 865 批，`tools/beekeeping/winter-feed-syrup.html` 的 `fmtKg()`、`fmtL()`、`fmtMoney()` 和 `calcData()`。

计算只要求每群补饲量大于 0，没有下限；但格式函数将质量以整数毫克、体积以两位毫升、费用以三位元四舍五入。输入 1 群、每群 0.00000001 L、糖水比 2、其余参数有效时，实际质量和体积均为正，页面与 CSV 会显示 `0 mg`、`0.00 mL` 和 `0.000 元`，与该批消除“小量配料被四舍五入为零”的目标不一致。

建议给输入设置合理且明确的最小量，或对微量继续增加精度/使用科学计数或“小于显示精度”提示；主结果、图表、历史及导出应使用一致口径，并补小于 0.5 mg 和 0.005 mL 的边界测试。
