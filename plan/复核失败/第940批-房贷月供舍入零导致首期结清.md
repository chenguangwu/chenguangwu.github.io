# 第940批复核失败：房贷月供舍入为零后首期错误结清

## 问题与复现

`tools/finance/mortgage-calculator.html` 的 `buildSchedule()` 先将等额本息月供按分舍入；当舍入后的月供减利息不大于零时，代码直接将全部余额作为当期本金并结束计划。页面只要求本金大于零：例如直接输入本金 0.000001 万元（0.01 元）、0% 利率、30 年，计算得到的月供应为每月约 0.0000278 元，舍入为 0 后却显示首期支付 0.01 元并结清，而不是提示当前本金和期限无法按分生成正常计划。较高利率下月供不足以覆盖利息时也会错误结清。

## 修复方案

生成前验证按分舍入后的月供足以偿还利息和本金；无法按所选期限生成有效计划时明确提示并清空明细与导出，或者制定并说明可核对的尾差分配规则。增加极小本金、月供不足利息及正常贷款的回归验证。
