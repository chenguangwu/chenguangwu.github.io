# 第 603 批复核失败：Schema 验证输入与合法性判定不完整

- 原要求：验证输出区当前可编辑或粘贴的 Schema；非空非法 JSON 报错；对合法 Schema 作合理结构校验。
- 当前 `tools/it/json-schema-generator.html` 的 `#output` 是普通 `div`，没有 `contenteditable` 或输入控件，用户无法按交接所述编辑或粘贴 Schema。`validateSchema()` 在非空文本不含 `{` 时也会回退 `lastSchema`（第 742 行附近），例如 `oops` 不会作为非法 JSON 报错；解析错误只 toast，未按交接同步更新状态。
- `__schemaIssues()` 要求 required 每项必须列于同一层 properties，但 JSON Schema 允许 `{"type":"object","required":["a"]}`，因此会错误拒绝合法 Schema；布尔 Schema 也合法却被拒绝。应按支持的 Draft 明确验证范围及区别结构错误与提示。参见 https://json-schema.org/draft-07/schema# 。现有专项 21/21 的测试以注入 DOM 的方式覆盖 `required: ghost` 与 `{oops`，未覆盖真实可编辑入口和上述反例。
- 已复核部分：CSS 字符串保护、选择器 NaN 保留及其他列出的旧问题均有对应实现和专项用例。
