# 拼音 slug 混合英文被错误转换

- 原记录：商业创业收口中的 slug 多音字修复。
- 位置：`tools/biz/text-to-slug.html` 的 `chineseToPinyin()` 和 `convert()`，约 342–395 行。
- 问题：文本只要包含一个中文字符，拼音模式就把整个字符串交给 `chineseToPinyin()`；未命中词表的字符一律输出 `u` 加码位，英文、数字和空格也被转成码位。例如“银行 ABC”得到 `yin-hang-u20-u41-u42-u43`，而非保留英文的 `yin-hang-abc`。此行为由多音字修复后的兜底引入。
- 修复方案：仅对未收录汉字使用码位兜底，普通 ASCII 和分隔符原样保留供后续规范化；按 Unicode 码点遍历，避免补充字符拆成代理对。增加中英数字混排、多音词及未知汉字回归用例。
