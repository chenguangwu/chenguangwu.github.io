# 向量极小非零值因平方下溢误判为零

- 来源：`tools/science/vector-calculator.html`，SMS-166 修复记录宣称非零极小向量不再误判。
- 复现：输入 A=(1e-200,0,0)、B=(1,0,0) 并计算夹角。`mag(A)` 以 `sqrt(sum(x*x))` 实现，`1e-200 * 1e-200` 在 JavaScript 双精度下下溢为 0；`__isZeroVec(A)` 因此判断为零向量，输出无法计算夹角，数学上实际为 0°。单位向量等依赖同一模长的分支也受影响。
- 建议：使用缩放后的稳定范数（如 `Math.hypot`）计算模长，对夹角、投影和单位向量的中间乘除也进行缩放，避免下溢/上溢；增加极小及极大非零向量与真实零向量的判别测试。
