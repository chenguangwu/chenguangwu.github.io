# 第 1376 批复核：切换法律援助预设会保留先前事项

`tools/legal/legal-aid-eligibility.html:416` 的各预设只将各自事项复选框设为 1，没有取消其他已选事项。`js/tool-kit.js:1025` 的预设赋值仅遍历给定字段，故先点击「重度残疾」（社会保险），再点击「农民工讨薪」（劳动争议），社会保险仍被勾选，评估内容与选中的场景不一致。用户手工选过的其他事项也同样会残留。

建议每组预设显式设置所有事项复选框的开关状态（包括目前没有 id 的事项），或在应用预设时先清除该组，再设置目标事项；不要改变普通用户的手工多选功能。回归覆盖互相切换预设及已有手工勾选后应用预设。
