# 第320批复核失败：网格渐变三色预设不能补齐色块

原记录：`2026-11-12-320-设计-网格渐变完整修复与预设占位与数量校验.md`。其余已核对的修复点从原记录移除。

- 原要求：三组预设应重建 `colors` 并同步色块 UI 和主图。
- 证据：`tools/design/mesh-gradient.html` 允许通过 `removeColor` 减到两个色块。`TBKit.preset.bar` 只能给现存控件赋值；预设回调逐个读取现存 `color0..color2`，第三个不存在就跳过，再以两个颜色重建数组。因此从两色状态点击任一三色预设，第三个预设颜色丢失，结果仍为两色；从四、五色状态则会缩为三色。
- 验证：源码核对 `removeColor`、`renderColors` 和 `__mesh_gradientPresets`；`node scripts/verify_design_calc.js mesh-gradient css-border-radius generator-6` 为 12/12，未覆盖两色切三色预设。
- 待修：按预设定义直接重建完整颜色数组，验证从两色和五色切换到每组三色预设时色块、主图及 CSS 一致。
