# 第 1022 批复核失败：修正空时间后导出仍被禁用

## 问题与证据

`tools/audio/audio-cut.html` 的 `onTimeInput()` 在时间为空时将 `timeInputValid=false` 并禁用 `btnExport`；用户重新输入合法时间后只恢复 `timeInputValid=true` 并调用 `updateSelInfo(true)`，两处均没有重新启用导出按钮。`selectAll()`、`resetSelection()` 也没有恢复按钮（前者还未复位 `timeInputValid`）。因此加载音频 → 清空起点 → 重新填入合法起点后，选区恢复但“导出 WAV”仍不可点击，必须重新加载音频才能恢复。

## 建议修复

统一根据音频是否已加载、起止时间有效、选区长度和导出任务是否在进行中刷新试听/导出控件；输入恢复、波形拖选、全选、重置和异步导出完成均调用该状态更新。增加从有效→空值→有效，以及空值→全选/重置的实际按钮状态与导出回归。
