# 劳动补偿工作年限余数计算复核失败

- 位置：`tools/legal/labor-compensation.html` 的主计算约 398–403 行与趋势计算约 555 行。
- 问题：已修复 0.5 年为 1 个月工资，但工作年限超过 1 年时，余数大于 0 且小于 0.5 年的部分被忽略。例如 1.25 年、月工资 12,345 元，页面按 N=1 而不是 1.5 计算，低估补偿；趋势计算同样遗漏。
- 修复方案：整年部分之外，余数大于 0 且不足 0.5 年加 0.5，余数达到 0.5 年加 1；主计算与趋势图复用同一函数，并覆盖整年、1.25 年、1.5 年及封顶边界。日期换算的自然月边界另需与法定口径核对。
