# 成绩权重计算器动态得分框无正确无障碍名称

- 页面：`tools/edu/grade-weight-calculator.html:231`。
- 问题：动态行的“得分”输入框设为 `aria-label="未出"`，它覆盖邻近未关联的“得分”标签；读屏用户听到的是状态提示“未出”，无法知道该输入框填写什么。该行的项目名称和权重标签也未通过 `for` 或包裹方式关联输入框。
- 复现：打开页面，通过无障碍树或读屏检查动态成绩行；得分输入框的 accessible name 为“未出”。
- 修复方案：为每行输入框生成唯一 id 并关联可见 label，或分别设置表达字段含义的多语言无障碍名称（项目名称、权重、得分）；将“未出”保留为占位提示，并检查新增行及中英文状态。
