# 第224批复核失败：ISO 日期校验不足会生成非法 TOML

- 原项：IT-N201，支持 ISO 日期字符串；该批修复要求合法日期输出原生值，不合法字符串仍加引号，避免生成非法 TOML。
- 未落实：`tools/it/json-to-toml.html` 的 `tomlDateLiteral()` 只检查日为 1–31，未核对各月天数或闰年，也未检查时区偏移范围。
- 验证：JSDOM 调用当前函数，`2023-02-31` 与 `2020-01-01T00:00:00+99:99` 均原样返回为裸值；将其分别作为 `d = ...` 交 Python 标准库 `tomllib.loads` 解析，均抛 `TOMLDecodeError`。现有 `scripts/_verify_it_batch224.mjs` 36/36 通过，但没有覆盖这两类边界。
- 应校验真实日历日期和合法偏移，非法值按普通字符串引用，并补充解析验证。

其余 IT-N199、N200 和 N201 的 null/混合数组已按当前实现及专项脚本核验。
