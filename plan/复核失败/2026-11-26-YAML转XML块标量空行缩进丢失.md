# YAML 转 XML：块标量丢失空行与缩进

复核第 808 批：`tools/it/yaml-to-xml.html` 的 `parseYaml()` 对所有行执行 `trim()` 并跳过空行，`yCollectBlock()` 再拼接非空行。因此合法输入 `text: |\n  first\n\n    indented\n  last` 中的空行和 `indented` 前额外缩进均丢失；`|+` 也无法保留多个尾随空行。该行为与记录中支持字面换行及 chomping 的描述不符。

修复方案：使用标准 YAML 解析器，或在解析块标量时保留原始行、相对缩进与尾部空行并正确处理折叠与 chomping；以标准 YAML 解析器为基准，验证 `|`、`|-`、`|+`、`>` 对空行、额外缩进和末尾换行的值，再核对 XML 文本。
