# 第 1259 批：量化体积增加饼图重复计算增加部分

`tools/ai/quantization-ratio.html` 的反向情况饼图用「量化后 after」和「体积增加 delta」两个扇区；after 已包含 delta，因此图中总和是 `after + delta`，重复计入增加部分。例如原体积 7000、新体积 28000、增加 21000 时饼图绘制 28000 与 21000，不能正确表示新体积的构成，应以原体积和增加量为两部分或改用适合的对比图。

另外压缩比判读把 `≥1` 一律描述为体积变小，而相等时（fromB=toB，ratio=1）体积不变。表格增量正数和增幅计算已核对；`node scripts/verify_ai_calc.js` 128/128、DOM host 10/10，现有用例未覆盖扇区组成及相等边界。
