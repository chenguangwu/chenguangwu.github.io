# 第 210 批复核失败：JSON Schema 同类型数组元素合并丢失约束

- 来源：`plan/已修复/2026-11-11-210-IT清单3条-json-schema生成器契约口径.md`，IT-N269 混合类型数组及数组对象合并。
- 当前实现：`tools/it/json-schema-generator.html::mergeSchemas()` 对同类型且非 object 的多个 schema 直接返回第一个，未合并它们的内容或约束。
- 验证：沿用 `scripts/_verify_it_batch210.mjs` 的 JSDOM 生成器，输入 `{"items":[[1],["x"]]}`，得到 `items.items={"type":"array","items":{"type":"integer",...},...}`；第二个子数组的字符串类型丢失，生成的 schema 连输入样本也不能通过。输入 `{"items":["a@b.com","hello"]}`，生成的元素 schema 沿用第一个字符串的 `format:"email"`，在启用 format 校验的验证器中会错误拒绝 `hello`。原脚本 21/21 只测一层 integer/string 混合与简单同类型项。
- 已核实部分：单层混合类型生成 anyOf、描述开关、非 null 字段与简单对象数组 required、IPv4 边界通过原批脚本。
- 待落实：递归合并数组子项，针对同类型但格式或长度等约束不同的样本保留可覆盖全部样本的 schema；使用 JSON Schema 验证器验证生成结果至少接受原始样本，并覆盖嵌套数组和字符串 format 混合。
