# 840 批复核失败：Identicon 算法引据章节仍不匹配

原问题要求将乘 31 的 String.hashCode 变体指向正确来源，而不是无关的 SHA-2 / FIPS 标准。当前 `tools/design/identicon-generator.html:228` 虽移除了 FIPS，但改为「Java Language Specification §15.8.2 String.hashCode」。Oracle 的 [Java Language Specification §15.8.2](https://docs.oracle.com/javase/specs/jls/se21/html/jls-15.html#jls-15.8.2) 实际是 Class Literals，不能作为该算法引据；对应哈希公式应核对 [String.hashCode API 文档](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/String.html#hashCode())，并说明页面为变体。

验证：`node scripts/verify_design_calc.js svg-viewer identicon-generator badge-generator favicon-generator generator-38` 为 21/21，但该测试未核对引据章节真实性。
