# 第1146批：拉丁字母缩写范围与实现不符

原 EL-F16 要求明确支持范围并正确取词首字母。`tools/language/language-toolkit.html` 声称支持拉丁字母，但 `generateAcronym()` 只匹配 `[a-zA-Z]`，例如法语 `École` 被取成 `C` 而非 `É`，`é` 则被错误提示为非拉丁词并跳过。中日文单独词的跳过处理已核对。

验证：检查匹配表达式，`node scripts/verify_language_calc.js` 42/42 未覆盖带变音符号的拉丁文字。应支持拉丁文字母及 Unicode 组合形式的正确词首处理，或将中英文 UI 和提示限定为 ASCII 英文字母并明确带重音字母如何处理；补充带重音和混合文本行为用例。
