# 第 610 批复核失败：HTML 文档风格注释仍未闭合

- 原要求：注释生成器输出可用于目标语言，复核 12 种语言及各样式。
- `tools/biz/comment-generator.html` 的 `doc` 分支对 HTML 落入通用路径 `cfg.line + ' ' + l`，而 HTML 的 `cfg.line` 是 `<!--`，不会加 `-->`。例如内容 `hello` 生成 `<!-- hello`，粘贴后仍会吞掉后续页面，原问题在该样式下依旧存在。现有 23/23 专项仅覆盖 HTML 的 line/frame 等，未覆盖 HTML doc。
- 已复核：记录列出的行注释、横幅及 YAML 块注释有修复和专项用例；首屏导出及运动清单相关改动保留原实现。
