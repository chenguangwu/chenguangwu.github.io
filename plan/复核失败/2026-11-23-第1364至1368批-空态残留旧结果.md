# 第 1364—1368 批复核：空态仍可复制或保存上次结果

## 复现与定位

这些页面先使用默认值正常计算，再清空守卫涉及的全部数值输入、点击计算；结果区出现填写提示，但点击复制仍得到上一轮结果：

- `tools/fishery/fish-growth-curve.html:258`：空态提前返回时不清空 `lastResult`，`copyResult()` 在 315 行继续复制。
- `tools/fishery/water-oxygen.html:324`：`lookup()` 的空态分支未清 `lastResult`，367 行继续复制旧溶氧结果。
- `tools/restaurant/delivery-time.html:277`、`tools/restaurant/seasoning-scaler.html:298`、`tools/restaurant/table-turnover.html:227`：空态分支分别保留 `_resultText` 或 `_copyText`，复制按钮继续输出旧结果；翻台率页的 `resultRefBar` 也在空态下未清除，旧评价仍显示。
- `tools/textile/pattern-calculator.html:314`：空态分支未清 `window._lastCalc`，复制和保存历史仍使用上次排料数据。

## 建议修复

空态和其他无效输入分支同步清空相应结果缓存、独立图表及参考标尺，禁止复制和保存无效结果；恢复有效输入后重新生成缓存。增加“有效计算 → 全部清空 → 再计算 → 复制/保存及图表检查 → 恢复有效输入”的交互回归测试。
