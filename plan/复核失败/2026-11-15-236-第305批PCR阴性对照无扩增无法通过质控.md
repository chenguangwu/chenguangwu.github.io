# 第 305 批复核失败：PCR 阴性对照无扩增的合法输入无法通过质控

`tools/clinical-lab/pcr-ct-interpretation.html` 阴性对照输入提示「无扩增填0」，但 `interpretQual()` 定义 `negFilled = isFinite(neg) && neg > 0`；阴性对照填 0、阳性对照填 22 时，进入「质控未完成」，提示两项都必须大于 0，无法将页面定义的正常阴性对照结果识别为已填写。需要区分空值与明确填写 0，并依据临床质控规则验证其他边界与双语提示。

已复核成功部分：Ct ≤ 0 不输出该定性卡的定量结果、对照留空不显示质控正常；历史结果优先从定量区读取，回放会重算定性。`node scripts/verify_it_calc.js pcr-ct-interpretation` 2/2；该测试未覆盖上述对照 0 场景。
