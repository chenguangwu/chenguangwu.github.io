# EDSS 评分先按功能系统分支导致忽略行走能力

`tools/neurology/edss.html` 的 `calc()` 先根据功能系统最高分进入 0、1、2、2.5、3、3.5 分分支，只有未命中这些分支才检查行走能力。因此所有功能系统选 0、行走能力选「卧床」时，仍输出 0 分和「神经系统检查完全正常」；单项 3 分配轮椅也仍输出 3 分并称可独立行走。结果与输入及页面对 EDSS 高分的说明矛盾，可能严重低估残疾程度。

应由具备相应资质的专业人员核对 EDSS 判分条件与输入完整性，调整行走能力与功能系统的综合判定；对互相矛盾的输入明确提示，不能输出正常结论。增加卧床、轮椅、助行等跨分支边界测试，并核对页面对实现范围的描述。
