# GraphQL 校验空输入与不同类型括号误报成功

`tools/it/graphql-formatter.html:304` 的 `doValidate()` 对空串直接 tokenize，得到零个 token 仍输出「GraphQL 语法正确」「校验通过」，原空输入问题仍存在。它只增减统一深度，不匹配括号类型，`{]` 等也可通过；非 GraphQL 任意名称同样可能通过，因此现有实现只能粗略统计括号，不能证明 GraphQL 语法正确。

修复方案：空白输入清除旧结果并提示输入；采用符合 GraphQL 语法的解析器验证，或明确降级为括号平衡检查并按类型匹配，不宣称完整语法正确；测试空串、`{]`、合法查询及非法语句。
