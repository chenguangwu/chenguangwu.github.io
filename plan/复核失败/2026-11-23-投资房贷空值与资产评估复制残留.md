# 投资、房贷空值及无形资产评估复制残留

1. `tools/investment/npv-calc.html:255–269`：`num()` 将空贴现率转换为 0；只要任一现金流非零就通过全空守卫，清空贴现率仍按 0% 输出 NPV。应将必填贴现率的空串与显式 0 分开处理，并验证清空及零利率两态。
2. `tools/realestate/down-payment.html:281–289`：年利率和首付比例均经 `parseFloat(...) || 0`，清空任何一项仍以 0 计算月供/首付；0 本身应允许，但空值不应产生结论。应分别检查空串并清理结果，覆盖空与显式 0。
3. `tools/realestate/assessor-44.html:195–205,231–232`：成功计算设置 `res.dataset.copyValue`，随后清空折现率或输入非法参数只替换可见内容、未清理该属性；点击复制仍得到上一次资产估值。应在所有无效分支清除缓存并阻止复制旧结果，测试有效→清空/非法→复制。
