# 复核失败：F-N54 马丁格尔零成交价产生虚假平均成本

- 来源：`plan/已修复/2026-11-10-金融F-N54-马丁格尔平均价恒等于当期价.md`。
- 已核实：一般场景累计股数与累计投入计算正确，初始 2000、倍率 2、3 层、跌幅 10% 得平均成本 85.78、跌幅 14.22%；页面现有定向测试 4/4。
- 失败点：`tools/finance/position-size-calculator.html` 接受 100% 跌幅（输入 max=100），从第二层开始价格为 0，`shares = pos / price` 为 Infinity，`cumCost / cumShares` 得 0，却正常显示平均成本为 0 和跌幅 100%，无法代表有效成交。使用 `scripts/verify_it_calc.js` 的 `runCase`，初始 1000、倍率 2、3 层、跌幅 100%，检查 `currentResult.positions` 确认后续 `avgPrice:0`。
- 待处理：成交价必须为正时停止不可能的买入并清理旧结果，合理处理 100% 跌幅与越界输入；覆盖 0%、正常跌幅、100%、超过 100%、多层及历史/导出，断言真实平均成本与错误态。

## 原移交记录

- 金融财务 F-N54，第 75 批；原平均价因为累计投入被当作股数且按当期价折算，恒等于当期价。
- 修改为每层 `shares = pos / price` 并累加股数，平均成本 = 累计投入 / 累计股数；示例 2000、2 倍、3 层、跌 10% 应为 85.78 元。
- 原验证：金融 452/452、判别力无逃生、输入 id 无僵尸；回退旧源码单页 3/4，新源码 4/4。未覆盖零成交价。
