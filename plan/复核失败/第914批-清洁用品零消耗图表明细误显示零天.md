# 第914批复核失败：零消耗与长周期在图表明细中失真

## 问题与复现

`tools/life/cycle-4.html` 的 `getDaysUntilEmpty()` 对零消耗返回 `null`，但 `renderSupplyChart()` 和 `__supplyTable()` 均将 `null` 转成 `0`。添加库存大于零、消耗为零的用品后，图表和明细显示预计耗尽 0 天，与“未设消耗 / 库存充足”相矛盾。明细还把超过 365 天的实际天数截成 365，列名未说明截断，无法核对真实周期。

## 修复方案

图表对无消耗使用无数据或独立说明，不要绘成 0 天；明细显示“未设消耗”，正消耗展示真实天数。图表若保留 365 天上限，明确封顶并保留实际值提示；补零消耗和超过 365 天用例，核对卡片、图表、明细与导出。
