# 第 977 批复测新发现：零实际产量被拒

`tools/agriculture/harvest-loss-rate.html` 的实际产量输入允许 `min="0"`，但 `calc()` 与 `copyResult()` 分别以 `actual<=0` 拒绝零；理论产量为正、实际产量为 0 时应可表达颗粒无收和 100% 损失，当前无法计算或复制。空值还经 `||0` 与零混同。原第 977 批 `actual>theory` 边界测试和现有 agriculture verify 188/188 均通过，但没有覆盖此合法零值。

建议区分空串与数值 0，在理论产量为正时允许实际产量为 0，仍拒绝负数和大于理论值，并同步计算、复制路径及真机测试。
