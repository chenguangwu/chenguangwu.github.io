# 第946批复核失败：固定资产旧记录被静默过滤并可能覆盖

## 问题与复现

`tools/finance/register-depreciation.html` 加载本地台账后直接执行 `assets.filter(isValidAsset)`，年限超过 100 年及其他不符合当前校验的旧记录不会显示，也不会包含在 JSON 备份中。用户随后新增、编辑或删除资产时，`save()` 用过滤后的数组覆盖原 localStorage，旧记录永久丢失，页面没有提示。防止长循环的目标不应导致用户已有台账被静默丢弃。

## 修复方案

保留原始记录并将无效记录隔离展示，停止对其进行折旧循环，提示用户修正或导出；任何保存操作不得隐式删除这些记录。增加旧记录超限、导出备份和新增资产后重新加载的数据保留用例。
