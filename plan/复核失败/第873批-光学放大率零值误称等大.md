# 光学放大率为零时被误称等大

复核来源：第 873 批，`tools/optics/magnification-optics.html` 的 `calcTool()`。

输入物距 1 m、像距 0 m 时，放大率 M=0，页面却在取向卡显示“等大/无放大”（英文 Same size / no magnification）。等大应为 |M|=1，M=0 表示像高为零、不能以此判断正立或倒立；同时薄透镜关系得出焦距 0，这一退化情形也需要说明物理模型边界。

建议对 M=0 显示“取向不适用，像高为零”，等大单独以 |M|=1 判断；对零像距提示退化/模型不适用，并同步中英文及附表，增加 0、+1、−1 的测试。
