# 第320批复核失败：英文标题审计仍误报标准版本号

运行 `python3 scripts/audit_industry.py --ind it`，`body title 真·代号/全英文=1`，命中 `json-schema-validator` 的真实标题 `JSON Schema Validator (Draft-07)`。Draft-07 是规范版本，而不是工具占位代号，说明该批宣称的全站结果为零当前不成立，误报会干扰后续审计。

修复方案：为 JSON Schema Draft 版本等真实标准版本建立精确白名单或优化代号匹配，并加入同时覆盖真实标准名和 `Generator 16` 这类占位标题的回归用例；避免宽泛排除数字导致漏报。
