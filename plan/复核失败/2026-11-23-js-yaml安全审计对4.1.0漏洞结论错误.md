# js-yaml 安全审计对 4.1.0 的漏洞结论错误

`tools/it/yaml-validator.html` 加载本地 `vendor/js-yaml/4.1.0/js-yaml.min.js` 并解析用户 YAML。原记录称 4.1.0 已修 merge-key 问题，但 [上游安全公告 GHSA-mh29-5h37-fv8m](https://github.com/nodeca/js-yaml/security/advisories/GHSA-mh29-5h37-fv8m) 明确 4.0.0–4.1.0 受 CVE-2025-64718 影响，4.1.1 修复。页面使用 `JSON_SCHEMA`，该具体调用能否触发 merge-key 问题尚需验证，不能断言当前页面可利用。

修复方案：升级并锁定到已覆盖相关上游漏洞的安全版本，更新本地资源和 SRI，复核 YAML 解析与离线可用性；同时评估实际 schema 的可达性及其他公开公告。
