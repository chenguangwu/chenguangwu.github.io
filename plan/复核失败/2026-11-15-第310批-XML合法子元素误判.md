# 第310批复核失败：XML 合法子元素被判为解析错误

- 原记录：`plan/已修复/2026-11-12-310-IT清单批量10条-QR族解析与元数据与计数修复.md`，第 8 项 IT-D20；原清单 `plan/categories/01-IT开发/it.md` 的 XML 验证器误判。
- 已验证：合法根元素 `<parsererror>` 不再仅因同名而判错。IT 小门禁相关 30/30 通过，但未覆盖合法同名子元素。
- 未落实：`tools/it/xml-validator.html` 的 `getElementsByTagName('parsererror')` 会找到合法子元素，`:263` 只要它不是文档根便视作错误。合法 XML `<root><parsererror>valid</parsererror></root>` 因而被误报格式错误，修复判据仍把用户自定义元素当成解析失败。
- 复核证据：用 jsdom 的 `DOMParser` 解析该输入后，根为 `root`、子元素命名空间为 null；按页面现有判据计算 `reportedError: true`。这是 DOM 模拟验证，尚未在各浏览器实测。应区分解析器实际生成的错误文档与合法文档内容，并补根、子元素和真实无效 XML 的回归测试。
