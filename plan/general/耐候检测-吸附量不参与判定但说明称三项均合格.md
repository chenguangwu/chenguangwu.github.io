# 耐候检测：吸附量不参与判定但说明称三项均合格

- 受影响工具：`tools/general/detector-205.html`。
- 问题：代码明确将吸附量作为单独参考，不计入综合判定；但结果为合格时仍声称“所有检测项目均符合本页阈值”，深度解析和算例也称三项全合格才能验收。例如盐雾 500 h、湿热 1200 h、吸附量 0 时，吸附显示参考偏低，综合仍合格且文字声称所有项目符合。页面还仅按试验时长输出合格，没有输入试验后的腐蚀或外观结果。
- 解决方案：统一综合范围和文案，明确吸附项适用材料及是否计分；非综合项不应被概括为全部达标。将试验时间区分为已试验时长与达到规定外观要求的耐受时长，补充检验结果、产品规格和阈值来源，避免将示意结果描述为验收依据。
