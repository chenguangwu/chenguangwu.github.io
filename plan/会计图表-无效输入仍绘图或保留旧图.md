# 会计图表：无效输入仍绘图或保留旧图

## 问题

贡献边际和杜邦分析的图表独立于主结果校验，读取数值时将空白回退为 0。例如贡献边际清空销量、杜邦分析清空任一因子，主结果提示缺项，但图表仍可按 0 绘制；贡献边际填负销量也可绘图。此外贡献边际的合法售价不高于单位变动成本时直接跳过绘图，之前的图可能仍留在页面，不能反映零或负边际。以上为静态代码分析，需结合浏览器验证图表和切换状态。

## 解决方案

主结果、表格和图表共用校验状态；缺项或无效时清除图表并提示，合法零值和负边际应有明确展示。验证正常输入切换为空白、负销量、零边际、负边际及恢复正常。
