# 化学检测工具：未填检测项被当作零并给出结论

## 问题

三个检测页将空值通过 `parseFloat(...) || 0` 转成零，随后直接参与单项及综合判定。例如消毒液检测中浓度 3%、pH 8、细菌总数留空时，未检测的细菌总数被显示为 0 并判合格，综合结果也错误显示合格。切削液检测中未填写防锈等级同样可能被判合格；悬浮液检测也会把未填写项显示为零并给出不合格结论。

## 解决方案

区分未填写、无效值和真实零值；缺失项目显示未检测，必填项目未齐时不输出综合结论。根据各指标的实际取值范围限制负数等无效输入，并明确标准来源、适用对象与判定条件。分别验证空值、合法零值和完整数据。
