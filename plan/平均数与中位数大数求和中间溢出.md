# 平均数与中位数大数求和中间溢出

## 问题
平均数先把样本相加再除以数量，偶数样本的中位数也先加两个中间值。输入两个有限值 `1e308, 1e308` 时，中间和超出 Number 范围，但真实平均数和中位数仍是有限的 `1e308`；页面因此无法给出正确结果。静态分析，浏览器表现待核验。

## 解决方案
使用有缩放的平均计算方式避免可避免的中间溢出；分别处理实际总和超出表示范围的提示，不让它掩盖可计算的平均数或中位数。覆盖同号大数、异号大数和普通数据。
