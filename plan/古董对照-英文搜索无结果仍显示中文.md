# 古董对照：英文搜索无结果仍显示中文

- 受影响工具：`tools/antiques/porcelain-date.html`、`tools/antiques/calligraphy-style.html`、`tools/antiques/seal-identification.html`、`tools/antiques/bronze-identification.html`、`tools/antiques/furniture-style.html`
- 问题：五个页面计算 `en` 后，动态空结果仍固定写入「未找到匹配内容」，而复制空结果提示已区分语言；英文用户输入无匹配关键词时会看到中文提示。
- 解决方案：空结果和错误分支按当前语言生成并在语言切换后刷新，同时检查页面历史与导出的动态提示，使用浏览器英文态实测。
