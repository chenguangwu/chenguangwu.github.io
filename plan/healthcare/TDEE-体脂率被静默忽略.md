# TDEE：可填体脂率被静默忽略

- 受影响工具：`tools/healthcare/tdee-calculator.html`。
- 问题：输入提示称体脂率用于 Katch 公式，表单校验允许 0–70%，但实际仅 `5 < 体脂率 < 50` 时使用该公式；5%、50% 及其区间外的合法表单值静默退回 Mifflin 公式。原函数验证 5.1 和 49.9 用 Katch，5 和 50 用 Mifflin，用户无法从输入提示理解这一切换。
- 解决方案：按已核实的公式适用条件定义体脂率的有效范围和边界；输入不适用时明确说明，不得静默忽略。让用户可见实际使用的公式和限制，并允许显式选择或清空体脂率。
- 验收：覆盖 0、5、5.1、49.9、50、70 和空白；核对所选公式、错误提示、结果和保存记录。
