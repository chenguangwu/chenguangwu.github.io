# TDEE：固定份量食谱标注随目标变化的热量

- 受影响工具：`tools/healthcare/tdee-calculator.html`。
- 问题：早餐、午餐、加餐、晚餐的食物及份量是固定字符串，但餐次热量按目标热量的 25%、35%、10%、30% 动态标注。切换减脂与增肌时，同一份“燕麦 50g + 鸡蛋 2 个 + 牛奶 250ml + 香蕉 1 根”会显示不同热量，容易让用户误以为食物能量发生变化。
- 证据：页面原 `updateGoalContent()` 输出在不同目标下使用相同食材份量和不同目标热量比例，已执行函数复现；未对各食物实际热量作营养成分断言。
- 解决方案：若提供量化食谱，使用标注数据来源、重量口径和可编辑食材的本地营养数据按份量计算；或把餐次值明确写成“目标预算”，并去除将固定示例暗示为该热量的文案。标识估算范围及个体差异。
- 验收：不同目标下，同份量食物的估算热量一致，餐次预算与实际估算分开显示；中文、英文及导出结果一致。
