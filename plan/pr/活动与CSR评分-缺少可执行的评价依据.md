# 活动与 CSR 评分：缺少打分依据和复盘能力

## 问题描述
两个工具只收集各维度 0–5 分并按固定阈值给结论，没有各分值的判断标准、证据或自定义权重。活动工具正文提出事前事后对比和多活动排名，CSR 工具提出中期重评和多个选题排序，但当前只显示一次评分，无法直接完成这些场景。

## 解决方案
为各维度提供评分锚点和备注，明确等级只是自评参考；支持本地保存多个方案及权重、对比前后变化并导出分项和依据。同步修正文案与英文翻译，避免声称已有未实现的功能。
