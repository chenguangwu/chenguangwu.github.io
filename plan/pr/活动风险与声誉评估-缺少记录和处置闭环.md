# 活动风险与声誉评估：缺少记录和处置闭环

## 问题描述
活动风险仅固定五类的概率与影响，结果给出统一建议，无法登记具体风险、责任人、措施及复评；复制结果只包含最高等级和数量，丢失各项明细。声誉评估建议前后比较，但页面只保留当前打分，复制也只有总分；低分即要求立即启动修复，缺少证据与语境。

## 解决方案
增加本地保存的风险明细、责任人、措施和复评，并复制或导出完整矩阵；声誉评估支持注明证据与时间、保存并对比多次评分，建议明确为自评提示，由用户结合事实判断。
