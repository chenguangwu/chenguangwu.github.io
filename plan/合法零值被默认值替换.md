# 合法零值被非零默认值替换

## 问题描述

以下工具用 `数值 || 默认值` 处理允许 0 的字段，输入 0 会被静默替换，产生与输入不一致的计算结果：

- `tools/legal/divorce-property.html`：自定义我方比例为 0% 时按 50% 计算。页面“全归对方”预设也设置为 0%。已在隔离 JavaScript 环境用 10 万净资产复现：我方和对方各显示 5 万，而非 0 和 10 万。
- `tools/energy/fridge-power-estimator.html`：电价字段允许 0，但 0 被替换为 0.58 元/kWh，年/月电费不为 0。
- `tools/energy/standby-power-calculator.html`：电价字段允许 0，但 0 被替换为 0.58 元/kWh，电费与节约金额因此不正确。
- `tools/textile/pattern-calculator.html`：缝份/损耗允许 0%，但 0 被替换为 8%，裁片面积和用料结果偏大。
- `tools/acupuncture/warm-needle-moxibustion.html`：环境温度允许 0℃，计算读取时将其替换为 25℃；需结合输出和适用范围实机复核影响。

后四项从字段和计算源码确认，仍需在浏览器验证完整结果、历史及导出。静态扫描找到 37 条类似候选，仅上述项目已核对字段含义，其他候选可能零值本就非法或位于非核心路径，不应直接认定为缺陷。

## 解决方案及验收

用空字符串和有限数校验区分未填、非法值与合法的数值 0，不通过 `||` 设非零默认值；缺失时给出提示，合法 0 正常参与计算。逐页验证 0、默认值、普通非零值和清空，核对结果、预设、复制、导出与历史恢复，并检查中英文提示。
