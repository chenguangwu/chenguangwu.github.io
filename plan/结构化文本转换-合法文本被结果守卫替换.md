# 结构化文本转换：合法文本被结果守卫替换

- 受影响工具：`tools/it/yaml-to-json.html`、`tools/it/toml-to-json.html`、`tools/it/toml-to-yaml.html`、`tools/it/toml-to-xml.html`、`tools/it/xml-to-yaml.html`、`tools/it/csv-to-yaml.html`、`tools/it/csv-to-html-table.html`、`tools/it/js-minify.html`
- 问题：结果展示对整个转换结果替换 `Infinity` 和 `NaN`。输入含这些内容的合法文本或代码时，页面显示的值被改成 `—`，与内部转换结果不一致，用户直接复制可见内容会得到错误数据。源码已核实，待浏览器复核。
- 解决方案：展示层只做 HTML 转义；对数值类型单独校验非有限值，保证显示和复制的结果一致，并覆盖值、键名和代码中的相关文字。
