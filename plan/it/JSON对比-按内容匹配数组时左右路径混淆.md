# JSON 对比：按内容匹配数组时左右路径混淆

## 问题

启用“数组按内容匹配”后，剩余元素可在左右不同下标之间配对，但修改项仅保存左侧下标作为路径和 JSON Pointer，未标明右侧位置。例如左侧 `[1,2]`、右侧 `[0,1,3]`：`1` 被对齐后，`2` 与 `0` 配对，结果标为 `/1`，而右侧 `/1` 实际是 `1`。使用该路径定位右侧变化会得到错误值。此为源码分析，需浏览器复核。

## 解决方案

对跨下标配对分别记录和展示左右 JSON Pointer，并在复制与 JSON 导出中保留两侧位置；无法可靠配对时以新增和删除表示，避免暗示相同路径。验证插入、删除、换序、重复值及嵌套数组场景。
