# Python 字符串转义：三单引号反转义保留多余引号

## 问题描述

输入合法 Python 三单引号字面量 `'''hello'''` 并点击反转义，工具只按普通单引号去除首尾各一个字符，输出 `''hello''` 而非 `hello`。`r'''hello'''` 也有同样问题，且原始字符串模式直接返回错误结果。

## 解决方案

在普通单引号判定之前识别成对的三单引号定界符，与现有三双引号同样处理，并验证结束定界符。覆盖普通和原始三单引号、多行文本、内部引号及未闭合输入。

- `tools/it/python-escape.html`：`unesc()` 的引号和原始字符串处理。
