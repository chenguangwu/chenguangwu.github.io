# 蓝牙版本比较：不能仅凭版本断言音频能力

**受影响工具路径：** `tools/it/bluetooth-version.html`

## 问题

音频场景只按版本号判断：5.2 及以上显示“支持 LE Audio（LC3）”，更早版本显示“仅经典音频（SBC/AAC）”；页面还建议“选购设备看 BLE 版本即可”。版本号本身不能证明具体设备实现了 LE Audio、LC3、AAC 等音频能力，也不能证明两端互通，可能误导用户选购。以上为源码分析，具体兼容性表述需按蓝牙标准及设备资料核对。

## 解决方案

将版本变化与设备可选能力分开说明，不将版本号当作具体音频能力的证明；增加两端 LE Audio、LC3、经典音频和实际支持的配置文件检查清单，注明以设备规格和双方共同支持为准。核对各版本速率、距离和兼容性文案及中英文表达。
