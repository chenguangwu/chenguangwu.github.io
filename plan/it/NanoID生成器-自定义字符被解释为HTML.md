# NanoID 生成器：自定义字符需安全显示

- 受影响工具：`tools/it/nanoid-generator.html`
- 问题：生成的 ID 从自定义字母表取得后直接拼接进 `innerHTML`，包含 `<`、`&` 等字符时可能被解释为 HTML 实体或标签，显示和复制的结果与实际生成值不同；特定组合还可能插入页面元素。源码分析，待浏览器复核。
- 解决方案：通过 `textContent` 或完整 HTML 转义渲染每个 ID，复制时直接使用生成值；文本内容不要应用针对数值的 `NaN`/`Infinity` 正则。用尖括号、引号、`&`、emoji 和常见字母表验证输出、复制和导出一致。
