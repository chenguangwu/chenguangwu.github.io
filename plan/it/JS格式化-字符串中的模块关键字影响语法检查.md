# JavaScript 格式化：字符串中的模块关键字影响语法检查

受影响工具：`tools/it/js-formatter.html`

## 问题描述
语法检查用正则在源代码全文查找 `import` 或 `export`，匹配后直接提示模块语法并跳过 Acorn 检查。普通字符串、注释里的这些词也会命中，例如 `const s = "import";`，即使不存在模块语法，也无法得到正常语法检查结果。

## 解决方案
通过解析器区分脚本与模块语法，或提供明确的脚本／模块模式选择，并对两种模式实际执行语法检查；覆盖字符串、注释、动态 import、静态 import/export 和语法错误。
