# ASCII 码表 C1 控制字符的 HTML 实体易误导

- 受影响工具：`tools/it/ascii-table.html`
- 问题：128–159 被标记为 ISO-8859-1 C1 控制区，但详情统一给出 `&#数字;` 作为 HTML 实体。HTML 对部分 C1 数字字符引用按兼容规则映射到其他字符，例如 `&#128;` 会显示欧元符号，而非 U+0080 控制字符。源码与 HTML 字符引用规则表明存在口径差异，待浏览器复核。
- 解决方案：区分 Unicode 码位、Latin-1 字节和 HTML 数字字符引用的解析结果；对 C1 映射及无效控制字符给出实际浏览器表现和提示，不将实体描述为无损对应。验证 0、128、130、159 和普通可打印字符。
