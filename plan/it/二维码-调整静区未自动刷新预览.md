# 二维码：调整静区未自动刷新预览

受影响工具：`tools/it/qrcode.html`

问题：静区输入框没有绑定生成事件；修改数值后，页面显示的新数值与预览及下载的二维码仍采用的旧静区不一致，直到点击生成或改变其他触发生成的控件。

解决方案：为静区输入提供一致的更新机制；输入为空、小数及超出范围时明确提示或规范化，并在更新完成前避免下载旧结果。验证静区从 4 改到 0、其他有效值和无效值时，预览、PNG、SVG 和显示值一致。

证据范围：本机无头 Chrome 中，静区由 4 改为 0 并触发 input 和 change 后，已生成项目的静区仍为 4；本次以本地文件加载，实际下载和扫码待复核。
