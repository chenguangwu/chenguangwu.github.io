# JSON 格式化：顶层假值无法展示和导出

受影响工具：`tools/it/json-formatter.html`（首页编辑精选）

合法 JSON 顶层值 `0`、`false`、`""` 和 `null` 解析成功后，`renderOutput()` 用 `if (!lastValidJSON) return` 跳过渲染；复制和下载也用真值判断而拒绝结果。隔离执行页面原渲染函数时，这四种输入均保留了原有输出。`null` 同时被用作“没有有效结果”的哨兵，需单独区分。

解决方案：使用独立的解析成功状态保存任意 JSON 值，渲染、统计、复制、下载和缩进切换都以状态判断；保留所有合法顶层标量。验证上述四值、非空字符串、数字、数组和对象，以及从有效值切到无效输入或清空的过程。
