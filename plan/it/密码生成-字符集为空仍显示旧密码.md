# 密码生成：未选字符集时仍显示旧密码

受影响工具：`tools/it/password-generator.html`（首页编辑精选）

取消全部字符集后，`generateRandomPassword()` 返回空串；`generatePassword()` 清空当前批量数组，但只有成功生成时才更新 `passwordDisplay`，没有提示或清除上一条显示的密码。用户点击生成后可能继续看到并复制旧密码，误以为已换新。源码确认，需在浏览器核对复制按钮及结果区的完整状态。

解决方案：生成前检查至少一个可用字符集，失败时明确提示并清空或标记旧密码不可复制；检查选项互斥和可用字符池为空的其他情况。验证成功→取消全部→生成→复制、重新选取→生成及多条密码，并确保失败提示不会暴露或保存密码。
