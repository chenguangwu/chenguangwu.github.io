# CSS clamp 计算器：标准引据中的参数顺序和边界错误

## 问题

页面“公式与标准引据”将 CSS 函数写为 `clamp(x, lo, hi) = min(max(x, lo), hi)`，但 CSS 参数顺序是最小值、首选值、最大值；例如 `clamp(10px, 20px, 30px)` 的结果为 20px，而表中公式按同顺序套入会得到 10px。同表还称最小值大于最大值时结果由实现决定，CSS 的定义实际是最小值优先，例如 `clamp(100px, 50px, 10px)` 结果为 100px。页面生成器自身限制正常顺序，但这段速查内容会误导学习和手写 CSS 的用户。

## 解决方案

统一改成 `clamp(lo, x, hi) = max(lo, min(x, hi))`，并解释最小值大于最大值时最小值优先；同步中英文文案与标准引据，并用普通区间及反序边界的浏览器计算值验证。
