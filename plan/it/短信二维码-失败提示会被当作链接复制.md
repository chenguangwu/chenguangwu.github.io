# 短信二维码：失败提示会被当作链接复制

## 问题描述

生成时输入非法电话号码，结果区显示错误提示；点击“复制”会直接复制该提示并显示“已复制”，用户可能将错误文案误当作短信链接。二维码库加载失败时，结果区同时包含错误提示和链接，复制还会把两者拼在一起。

## 解决方案

独立保存有效的短信 URI，复制按钮只复制该值；输入无效或生成失败时清除或禁用复制，并反馈原因。区分二维码库加载失败但 URI 有效的情况，明确允许单独复制 URI；验证成功、无效号码与库加载失败三种状态。

## 受影响工具路径

- `tools/it/sms-qr.html`：`generate()` 与 `copyResult()`。
