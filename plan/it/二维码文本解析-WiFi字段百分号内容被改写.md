# 二维码文本解析：Wi-Fi 字段百分号内容被改写

## 问题描述

输入 `WIFI:T:WPA;S:Cafe%20WiFi;P:abc%21;;`，解析结果将网络名显示为 `Cafe WiFi`、密码显示为 `abc!`。Wi-Fi 二维码字段本身并非 URL 查询参数，百分号可以是 SSID 或密码的实际字符；自动百分号解码会改变配网凭据。

## 解决方案

Wi-Fi 字段默认只处理格式规定的反斜杠转义，保留原始百分号；若需兼容非标准百分号编码，提供显式选择并同时展示原文与解码结果。验证 `%20`、`%21`、中文、反斜杠及分号等字符与生成器往返一致。
