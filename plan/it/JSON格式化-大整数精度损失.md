# JSON 格式化：大整数被静默改变

受影响工具：`tools/it/json-formatter.html`（首页编辑精选）

格式化、压缩、排序和提取使用 JavaScript `JSON.parse()` / `JSON.stringify()` 往返。隔离验证 `{"id":9007199254740993}` 后输出 `{"id":9007199254740992}`；超过安全整数范围的 ID 等数据会被悄悄改变，尽管 JSON 文本本身合法。

解决方案：在处理前检测超出安全范围或无法精确保留的数字，明确提示并提供保留原始数字字面量的格式化方式；排序、树视图、复制下载应保持同一语义。验证安全整数边界、正负大整数、小数、指数、嵌套值以及往返文本，不能通过转换成字符串而无提示改变数据类型。
