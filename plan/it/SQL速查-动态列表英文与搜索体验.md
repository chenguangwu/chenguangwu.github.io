# SQL 速查：动态列表的英文与搜索体验

- 受影响工具：`tools/it/sql-cheatsheet.html`
- 问题：分类和命令列表由 `renderCategories`、`renderCommands` 使用中文数据与“共、参数、语法、分类、复制”等字面量动态拼接；搜索或切换分类会重建内容，英文状态有中文残留的风险，需在英文状态实际操作复核。搜索无结果时列表为空，没有解释或重置入口。
- 解决方案：为命令描述、分类及动态控件提供中英文数据，渲染和语言切换时按当前语言重新输出；搜索同时匹配中英文名称与命令；提供本地化无结果提示和清除筛选操作，并验证切换语言、筛选及复制后文字。
