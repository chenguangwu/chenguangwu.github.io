# CSV 转 JSON：字段和空记录被静默丢弃

受影响工具：`tools/it/csv-to-json.html`

## 问题描述

用页面原 `parseCSV()` 与 `toJSON()` 在隔离 JavaScript 环境验证：

- 表头 `a,b`、数据行 `1,2,3` 输出 `{"a":"1","b":"2"}`，第三列被丢弃。
- 表头 `a,a`、数据行 `1,2` 输出 `{"a":"2"}`，后一个同名键覆盖前一个值。
- 表头 `a,b` 后存在 `,` 这样的全空字段记录时，该记录被 `dataRows.filter` 丢弃，无法区分空记录与根本没有这一行。

这些行为均未要求用户确认，可能导致数据迁移不完整。实际浏览器输出、预览与下载链路仍需复验。

## 解决方案及验收

转换前显示列数不一致、重复或空表头及对应行列，允许用户选择停止、改名或使用数组保留原始字段；对全空记录明确提供保留或忽略选项并说明默认策略。验证有/无表头、重复键、空键、超出和缺失字段、全空行、引号与换行、JSON 往返，以及预览和下载结果与实际转换一致。全部处理保持本地执行。
