# 默认场景数字表达式错误

## 受影响工具路径
- `tools/it/regex.html`

## 问题描述
快捷场景“默认参数”把正则设置为 `d+`，其匹配字母 d 而非数字；同时未设置测试文本，依赖用户之前输入。初始输入的 HTML `value` 写成两个反斜杠加 `d+`，HTML 属性不会像 JavaScript 字符串那样转义，与数字匹配 `\d+` 的单反斜杠表达式不同。静态检查确认，需在真实浏览器复核显示与行为。

## 解决方案
将初始值和默认场景统一为可直接输入正则框的单反斜杠数字表达式，并设置可复现示例文本；校验匹配 `123` 而非 `ddd` 或反斜杠字面量，并核对中英文场景。
