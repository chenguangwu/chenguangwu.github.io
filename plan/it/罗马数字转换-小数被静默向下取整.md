# 罗马数字转换：小数被静默向下取整

## 问题描述

在数字转罗马模式输入 `1.9`，页面直接显示 `1 = I`。输入框虽然标记 `step="1"`，但 `oninput` 会立即调用转换，代码先用 `Math.floor()`，再检查范围，未检查原值是否为整数，导致小数被当作另一个数字转换，结果误导用户。

## 解决方案

先读取原始输入并校验为有限整数及 1–3999 范围；小数、空值和非法输入展示明确提示，不产生转换结果。验证 `1.9`、`3999.9`、空值与合法边界 1、3999。

## 受影响工具路径

- `tools/it/roman-numeral-converter.html`：`calcTool()` 的数字转罗马分支。
