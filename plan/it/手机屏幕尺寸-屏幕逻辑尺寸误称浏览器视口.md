# 手机屏幕尺寸：屏幕逻辑尺寸误称 CSS 视口

## 问题

机型表用物理屏幕分辨率除以标称 DPR，直接作为“CSS 视口（宽×高）”。这一计算最多表示假设条件下的逻辑屏幕尺寸，并非浏览器实际页面视口；例如移动浏览器地址栏、工具栏和横竖屏会改变页面可用高度，安卓表内 DPR 本身也只是统一假设。用户照表格高度设置固定布局，可能导致内容被遮挡或产生滚动。

## 解决方案

将该列更名为按假设 DPR 推算的逻辑屏幕尺寸，说明不能代表 `window.innerWidth/innerHeight`，并在页面提供本机视口与 DPR 的实时检测；机型资料标出来源、更新时间和估算条件。验证浏览器工具栏展开收起及横竖屏变化时视口提示。
