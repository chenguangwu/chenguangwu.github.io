# Cron 预览：L 组合语法通过校验却不匹配

## 问题

日期字段校验允许列表项 `L`，也会接受 `L/2`；但匹配函数只有整个字段恰为 `L` 时才识别月末。因而 `0 0 L,15 * *` 通过校验，预览只匹配每月 15 日，遗漏月末；`0 0 L/2 * *` 通过校验却不会按预期匹配。该扩展是否应支持取决于选定方言，现状是接受的语法与预览实现不一致。此为源码分析，需浏览器复核。

## 解决方案

明确所支持方言的 `L` 组合语法：支持的写法在逐列表项匹配时实现，不支持的写法直接给出校验错误；不要显示可复制的误导性结果。验证单独 `L`、`L,15`、`L/2` 和普通列表，并与目标实现核对。
