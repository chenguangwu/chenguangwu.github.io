# UUID 解析：非 RFC 变体误套版本语义

- 受影响工具路径：`tools/it/uuid-generator.html`

## 问题描述

页面识别出 NCS、Microsoft 等变体后，仍仅依据版本位展示 v1 时间或 v7 时间戳。例如 `00000000-0000-1000-0000-000000000000` 属 NCS 变体，却显示 v1 时间字段。NIL／MAX 的说明称无版本语义，版本卡片却仍显示数字。依据源码判断，待浏览器复核。

## 解决方案

结合变体和特殊值决定是否解释版本及字段；对 NIL／MAX 统一展示无版本语义。验证 RFC、NCS、Microsoft、保留变体及两个特殊值。
