# HTML 转 Markdown：代码内容含反引号破坏定界

## 问题描述

行内 `<code>a`b</code>` 被转换为单反引号包围的代码，其内部反引号会提前结束代码片段；`<pre>` 内容若包含独立一行三个反引号，也会提前关闭固定的三反引号代码块。输出 Markdown 重新渲染后，代码内容和结构不再与原 HTML 对应。

## 解决方案

根据代码内容中连续反引号的最长长度选择更长的行内或块级定界符，正确处理行内代码前后空格；也可在适当场景使用波浪号围栏。验证内含单个和连续反引号、独立围栏行及多行代码的转换和回渲。

## 受影响工具路径

- `tools/it/html-to-markdown.html`：`nodeToMarkdown()` 的 `CODE` 和 `PRE` 分支。
