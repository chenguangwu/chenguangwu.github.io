# JWT 验签：修改令牌或密钥后旧结果仍显示

受影响工具：`tools/it/jwt-parser.html`（首页编辑精选）

`verifySignature()` 将验签结果写入 `verifyResult`；JWT 文本变化只调用 `parseJwt()`，密钥和算法控件也未见清除验签结果的输入处理。验证成功后修改令牌、密钥或算法，旧的“签名有效”可能继续显示，误导用户认为新输入已验证。异步 HMAC 计算期间若输入变化，旧请求完成后也可能覆盖新状态。源码确认，需用不同令牌和密钥在隔离浏览器实测。

解决方案：任一验签输入变化立即失效并清空旧结论；为异步请求绑定输入快照或序号，只允许最新请求写结果。清晰区分签名验证与过期、生效时间、签发者/受众等声明检查，避免把签名成功表述为完整可信。验证成功→修改每个输入→重新验证、快速连续验证、清空和语言切换。
