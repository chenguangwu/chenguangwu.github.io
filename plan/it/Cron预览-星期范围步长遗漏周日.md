# Cron 预览：星期范围步长遗漏周日

## 问题

星期字段允许 0–7，并将 7 作为周日；但归一化遇到带步长的项时原样返回，匹配时浏览器星期值只可能是 0–6。例如 `0 0 * * 6-7/1` 通过校验，预览只匹配周六，遗漏应由 7 表示的周日。单独的 `7/1` 同样无法匹配周日。此为源码分析，需浏览器和目标 Cron 方言复核。

## 解决方案

先按所选方言展开或匹配星期范围及步长，再将值 7 与 0 统一为周日；明确不支持的写法并拒绝。验证 `6-7/1`、`1-7/2`、`7/1` 和包含周日的列表，避免简单字符串替换破坏步长。
