# CSS 阴影生成器：非法输入和预览不一致

**受影响工具路径：** `tools/it/box-shadow-generator.html`

## 问题

模糊半径输入虽然声明 `min="0"`，但生成函数没有检查输入有效性，手动输入负数时仍输出负模糊半径的 `box-shadow`，该 CSS 无效；浏览器可能保留此前有效预览，导致预览和复制的代码不一致。清空数值输入又会被 `|| 0` 静默当成零。以上根据源码分析，需浏览器复核。

## 解决方案

在生成和复制前验证各输入，模糊半径不得为负，空值给出明确提示；输入无效时清除或标明过期预览并禁用复制。测试负数、空值、零和恢复合法值后预览与复制代码一致。
