# JSON Schema 生成：对象数组特殊键在合并时丢失

## 问题描述

输入 `[{"__proto__":1},{"__proto__":2}]` 生成 Schema，数组对象合并时使用普通对象存放 `properties`，给 `__proto__` 赋值会触发原型 setter 而不是创建字段。生成结果丢失该属性定义；勾选必填时还可能留下没有对应类型约束的必填项，无法正确约束样本字段。

## 解决方案

所有以用户键名为键的映射都使用无原型对象或安全的自有属性定义，包括合并和样例构建环节；确保 `__proto__`、`constructor` 等键完整输出并正确推断类型。验证单对象和多对象数组的特殊键，生成后用 Schema 校验原始样本及类型不匹配数据。

## 受影响工具路径

- `tools/it/json-schema-generator.html`：`mergeSchemas()` 对象属性合并和 `inferSchema()` 示例构建。
