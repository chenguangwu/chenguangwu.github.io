# IP 计算器 IPv6 网络地址拼接丢失低位

## 问题

IPv6 网络地址转换将高、低 64 位分别补至 32 个十六进制字符，拼接后只读取前 32 个字符，导致地址位错位或丢失低位。修复计算中的异常后仍会得到错误网络地址，例如 `2001:db8::1/64` 的网络地址不能正确还原为 `2001:db8::`。

## 解决方案

按 128 位地址结构正确拼接两段 64 位数据，每段补齐 16 个十六进制字符后再转换和压缩；验证 `/0`、`/64`、`/128`、高低位非零及边界地址。
