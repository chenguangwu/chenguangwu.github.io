# XML 格式化：输入自动保存且明细导出包含原文

受影响工具：`tools/it/xml-formatter.html`、`js/tool-kit.js`

问题：美化后页面将输入 XML 和缩进作为快照写入浏览器历史；“导出明细 CSV”导出历史表而非完整格式化输出，其中可能包含 XML 原文。配置、令牌或业务报文因此可能在用户不知情时留在本地或被导出。

解决方案：默认不持久化原文，提供自愿保存及清除机制；把输出下载和历史导出分开命名，并说明导出内容。验证首次加载、手动美化、刷新和清除历史，以及敏感样本不会在默认 CSV 中出现。

证据范围：静态代码分析，实际存储和下载文件待验证。
