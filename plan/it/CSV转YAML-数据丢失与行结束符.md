# CSV 转 YAML：多余字段和重复表头

受影响工具：`tools/it/csv-to-yaml.html`

## 问题描述

带表头模式仅遍历表头生成键值，数据行比表头多出的字段被静默丢弃。例如 `a,b` 下一行 `1,2,3` 的第三项不会写入输出。重复表头如 `a,a` 会生成重复 YAML 键，不同解析器可能覆盖其中一个值。输入只有 CR 作为行结束符时，解析器会跳过 CR，`a,b\r1,2` 被解析为一行 `["a","b1","2"]`。已用页面原解析函数在隔离 JavaScript 环境核实这三种解析结果；最终 YAML 及浏览器交互仍需复验。

## 解决方案及验收

转换前校验每行字段数与表头唯一性，报告具体行及重复列，提供明确的用户选择，不能悄悄丢值；正确识别 CRLF、LF、CR 并保留引号内换行。用多余/缺失字段、重复及空表头、引号内逗号和换行、Unicode、三种行结束符和无表头模式测试；核验生成的 YAML 可被独立解析并保留全部数据，中英文提示准确。
