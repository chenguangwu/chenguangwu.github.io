# 邮箱归一：格式检查接受明显无效地址

- 受影响工具：`tools/it/email-normalizer.html`
- 问题：正则只限制字符集合，未约束点和连字符的位置。例如 `a..b@example.com`、`.a@example.com` 或 `a@-example.com` 会被显示为规范化完成；启用 Gmail 规则时，`+tag@gmail.com` 去掉标签后甚至生成空本地部分 `@gmail.com`。
- 解决方案：对支持的地址子集执行完整的本地部分、域名标签和归一后结果校验；对不支持的合法格式明确提示适用范围，不能仅凭格式判断地址存在或可以投递。
- 验证建议：覆盖首尾点、连续点、域名标签首尾连字符、空本地部分和常见有效地址，分别检查 Gmail 开关与复制结果。
