# 文本转十进制的 HTML 实体模式语义错误

- 受影响工具：`tools/it/text-to-decimal.html`
- 问题：选择 `&#` 分隔形式时，页面将编码后的每个字节直接包装成十进制 HTML 字符引用；例如 UTF-8 输入“中”输出 `&#228;&#184;&#173;`，浏览器解析后不是原字符，而正确的字符引用应基于 Unicode 码点。反向转换也按字节范围解析，无法处理 `&#20013;`。源码推断，待浏览器复核。
- 解决方案：将 HTML 数字字符引用作为独立的码点转换模式，与字节十进制模式分开；校验 Unicode 标量值，并测试中文、表情、ASCII 及无效引用。
