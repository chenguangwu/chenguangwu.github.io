# C 字符串反转义：十六进制边界与空白丢失

**受影响工具路径：** `tools/it/c-string-escape.html`

## 问题

反转义中的 `\x` 最多读取两位，但 C 的十六进制转义会继续读取后续十六进制数字；例如 `\x041` 被本工具解为 U+0004 加 `1`，与 C 编译器对该转义的解析不同。此外函数对输入无条件 `trim()`，没有包裹引号的文本首尾空格会被静默删除，影响往返。以上为源码分析，需在浏览器和 C 编译器中复核。

## 解决方案

按 C 词法读取完整十六进制序列，对超出目标字符类型或执行字符集可表达范围的值明确提示，避免把字节值直接误认作 Unicode 字符；区分带引号字面量与原始内容，仅处理字面量外的空白。覆盖 `\x041`、紧邻十六进制字符、首尾空格、八进制边界及非法转义。
