# Code 39 条码：Unicode 大写转换静默改变输入

- 受影响工具：`tools/it/barcode-code39.html`
- 问题：生成前先对完整输入调用 `toUpperCase()`，再检查是否属于 Code 39 字符集。部分 Unicode 字符会变成一个或多个 ASCII 字符，例如 `ß` 变为 `SS`，从而通过校验并生成与原输入不同的数据，用户未获提示。
- 解决方案：先针对原输入验证允许字符，仅对 ASCII 小写字母进行明确可见的大小写转换；对不支持的字符提示位置，生成前展示实际编码内容和校验字符。
- 验证建议：分别输入 `ß`、ASCII 小写和标准大写字母，核对错误提示、显示值与扫码实际数据。
