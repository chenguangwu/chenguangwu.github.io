# Go 字符串转义：原始字符串含反引号生成非法代码

## 问题描述

选择 Go 原始字符串模式，输入 `a` 后接一个反引号再接 `b`，工具直接在两端添加反引号，输出包含三个反引号的字面量。Go 原始字符串不能在内容中直接包含反引号，该结果无法作为单个合法字符串编译，页面却没有提示。

## 解决方案

生成前检测内容是否包含反引号；提示原始字符串的限制，并提供切换为普通双引号字符串或生成等价拼接表达式的选项。若选择拼接，还需明确输出是表达式而非单个字面量。验证反引号、换行和普通文本的生成结果及 Go 编译行为。

## 受影响工具路径

- `tools/it/go-escape.html`：`esc()` 的 `raw` 分支。
