# JSON 差异：科学计数法丢精度导致漏报

- 受影响工具路径：`tools/it/json-diff.html`

## 问题描述

数字解析对纯大整数有无损处理，但不含小数点的科学计数法直接转换为 JavaScript `Number`。例如 `9007199254740992e0` 与 `9007199254740993e0` 被舍入成相同数，比较可能漏报差异；`1e400` 与 `2e400` 也会同时变成 Infinity。此问题根据源码判断，需浏览器复核。

## 解决方案

对含指数的完整数字字面量进行无损解析，或规范化尾数和指数后精确比较；覆盖超安全整数、上下溢以及 `1e3` 与 `1000` 这样的等值写法。
