# Markdown 表格：CSV 引号字段内换行无法导入

- 受影响工具路径：`tools/it/markdown-table-generator.html`

## 问题描述

正文先按物理换行拆分，再分别解析 CSV 行。合法的跨行引号字段（例如 `"hello\nworld",x`，其中 `\n` 为实际换行）因此被当成未闭合引号，无法生成表格。此结论根据源码判断，待浏览器复核。

## 解决方案

按引号状态解析完整 CSV 输入，在 Markdown 中以可读换行形式呈现单元格，并在 CSV 导出时保留原始换行；若暂不支持，应在输入处明确说明。验证跨行、转义引号和普通多行数据。
