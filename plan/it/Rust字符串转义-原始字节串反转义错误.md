# Rust 字符串转义：原始字节串反转义错误

## 问题描述

页面说明列出 Rust 原始字节串 `br"…"`，但反转义只在去掉 `b` 前识别 `r` 开头的原始字符串。输入合法字面量 `br"abc"` 后点击反转义，结果为 `r"abc"` 而不是 `abc`；含反斜杠的原始字节串还会错误执行普通转义解析。

## 解决方案

先识别并校验完整字面量类型，包括 `br"…"` 和带井号的 `br#"…"#`，按原始字节串规则保留内部反斜杠；非法定界符明确报错。验证普通及原始字节串、引号和反斜杠内容，以及非法输入。
