# UUID v5：批量模式悄然改变名称

受影响工具：`tools/it/uuid-generator.html`（首页编辑精选）

单个 v5 生成使用用户输入的名称；当数量大于 1 时，代码改为对名称追加 `:0`、`:1` 等后缀再散列，却未在结果中标出实际名称。相同命名空间与输入名称仅改变数量，第一条结果便不再对应输入的名称。以 DNS 命名空间及 `example.com` 为例，原名的 v5 为 `cfbff0d1-9375-5685-968c-48ce8b15ae17`，追加 `:0` 后为 `6493d4bd-a95a-5ec6-90ba-f737c3a9907e`；已用独立 SHA-1 实现核对。

解决方案：v5 默认按实际名称生成确定性结果；批量生成应接受明确的名称列表或让用户显式选择后缀规则，并逐条展示名称与 UUID 的对应关系，不能静默修改名称。验证单条与批量、空名称、Unicode、标准命名空间向量、复制导出和重复名称。
