# 域名生成：关键词静默改写且候选长度未校验

- 受影响工具：`tools/it/domain-name-generator.html`
- 问题：输入会静默删除所有非 ASCII 字母数字，如 `我的app` 只保留 `app`，含义发生变化；长关键词与前后缀组合后未检查域名标签长度，可能输出不符合长度限制的候选。页面搜索描述提及“可用域名”，但生成逻辑不查询注册状态。
- 解决方案：说明支持的关键词字符，对转换或删除的字符提供预览与明确提示；校验标签长度和域名格式。把“可用”改为“候选”，明确注册状态需另行查询；可选提供纯前端的拼音输入辅助，但不能声称已验证可注册。
- 验证建议：测试中英混合、只有中文及超长关键词，核对实际保留内容和超限提示。
