# XML 转 YAML：正确解析实体和拒绝非法 XML

- 受影响工具：`tools/it/xml-to-yaml.html`
- 问题：手写解析器读取文本和属性后未解码 XML 字符实体，`<x>A &amp; B</x>` 的值会保留为 `A &amp; B`；遇到结束标签也未比较名称，`<a></b>` 可能被当作有效输入。源码分析，待浏览器复核；CDATA 替换后再按标签解析也可能改变其文本。
- 解决方案：使用浏览器 XML 解析器检查解析错误并正确读取文本、属性与 CDATA；明确重复元素、混合内容及命名空间的映射规则，对无法无损表示的结构提示。用实体、CDATA、错误结束标签和混合内容验证转换结果。
