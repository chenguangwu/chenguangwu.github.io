# 密码短语：词数超过词表会无限循环

受影响工具：`tools/it/password-generator.html`（首页编辑精选）

字段 HTML 标注词数 2–10，但 `generatePassphrase()` 只用 `parseInt(...) || 4`，不在函数中验证范围；它要求单词不重复，当前词表只有 64 个不同单词。输入 65 后，`while (words.length < wordCount)` 无法完成。隔离运行原函数并使用可控随机源，200ms 内未结束，被超时终止；不要在普通浏览器直接复现。

解决方案：在生成前校验有限整数、页面允许范围和不重复词表容量，并使用有界抽样；超出时显示明确提示而不是生成部分结果。随机密码长度和批量数量也需在函数层验证其声明上限，防止无界运算。测试空值、0、小数、边界、超词表和正常生成，并确保使用安全随机源。
