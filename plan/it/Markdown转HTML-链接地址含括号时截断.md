# Markdown 转 HTML：链接地址含括号时截断

## 问题描述

输入 `[维基](https://en.wikipedia.org/wiki/Function_(mathematics))`，转换器用匹配到第一个右括号为止的正则解析链接，生成的地址缺少末尾右括号，并将剩余括号显示在正文。链接虽可点击，但指向了不同地址；带括号的图片地址同样受影响。

## 解决方案

使用支持成对括号和转义的 Markdown 链接解析器，避免以单个正则截断目标地址；保留现有危险 URL 协议过滤。验证嵌套括号、反斜杠转义括号、图片地址及不安全协议。

## 受影响工具路径

- `tools/it/markdown-to-html.html`：`inline()` 的链接和图片处理。
