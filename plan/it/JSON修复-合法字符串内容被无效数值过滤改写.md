# JSON 修复：合法字符串内容被无效数值过滤改写

## 问题描述

输入合法 JSON `{"value":"Infinity and NaN"}`，工具的修复逻辑会保留原文并提示合法，但展示结果经过通用 `escH()` 与最终 HTML 过滤，把字符串内的 `Infinity`、`NaN` 替换为破折号。用户复制显示结果后数据已改变；包含这些字符的键名同样受影响。

## 解决方案

展示和复制 JSON 时仅进行 HTML 转义，不对文本中的 `Infinity` 或 `NaN` 做全局替换；无效数值应通过 JSON 解析结果判断。将原始修复结果与展示节点分离，并验证合法字符串、键名及确实非法的裸 `NaN` 输入。

## 受影响工具路径

- `tools/it/json-repair.html`：`escH()` 与 `calcTool()` 的结果渲染。
