# Base64 文件转换：历史记录保存完整文件内容

- 受影响工具：`tools/it/base64-file.html`
- 问题：点击“还原为文件”后，页面快照会收集所有非空输入和文本框，包括完整的 `b64Out` 与 `b64In`，再由 `TBKit.history.record` 写入本地存储，且历史表格也可能展示这些内容。Base64 不是加密，文件可能含敏感信息；大文件编码后也可能触发存储配额，记录失败被静默吞掉。
- 解决方案：默认不将文件内容、Base64 或解码文本写入持久历史及表格；若保留历史，限定为文件大小、类型和状态等非敏感摘要，提供明确可见的清理入口，并处理已有历史残留。仅在用户明确选择时保存内容。
- 验证建议：转换含独特标记的文件并触发下载，检查页面历史和本地存储中无明文或其 Base64；用超过存储配额的文件确认功能不受历史记录影响。
