# JSON 差异：清空和交换未同步本地草稿

- 受影响工具：`tools/it/json-diff.html`
- 问题：页面通过输入事件把左右文本保存到 localStorage，但清空、交换和加载示例通过赋值修改输入框，没有触发保存事件。用户输入内容后点击清空再刷新，先前保存的内容可能重新出现；交换或加载示例后刷新，也可能恢复操作前的草稿。
- 解决方案：统一管理草稿读写，所有程序化输入变更同步更新或删除对应存储；清空应清除持久化内容，并覆盖交换、示例与刷新场景。对旧版已保存草稿提供可控清除方式。
- 验证：依据输入赋值及存储事件监听的源码静态分析；需在浏览器验证加载顺序及各操作后的实际恢复结果。
