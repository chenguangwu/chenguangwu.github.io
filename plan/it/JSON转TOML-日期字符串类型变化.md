# JSON 转 TOML：日期样式字符串被改变类型

受影响工具：`tools/it/json-to-toml.html`

页面将符合 ISO 格式的 JSON 字符串自动输出为未加引号的 TOML 日期或时间。使用原 `toToml()` 将 `{"v":"2024-01-02"}` 转换，再用 Python `tomllib` 解析，`v` 成为日期类型而非原始字符串。对需要保持配置字段类型和往返结果的用户，这会产生意外的语义变化；目前页面描述只说支持日期字符串，未清楚说明会改变类型。

建议默认保留 JSON 字符串类型，并提供明确的“将 ISO 字符串推断为 TOML 日期”选项，列出会转换的字段；如产品决定保留当前行为，必须在操作前说明并允许关闭。用日期、时间、时区、类似日期但非法的字符串、嵌套数组及普通字符串做 TOML 解析往返测试；核验中英文说明与复制下载输出。
