# JavaScript 压缩：行注释吞掉行分隔符后的代码

- 受影响工具路径：`tools/it/js-formatter.html`

## 问题描述

单行注释扫描只在换行符 LF 结束，没有识别 CR、U+2028 和 U+2029 等 JavaScript 行终止符。输入 `let a=1;//comment`、U+2028、`let b=2;` 时，后续有效代码可能被当成注释删除，而输出仍能通过语法检查。此问题根据源码判断，需浏览器复核。

## 解决方案

按 JavaScript 行终止符规则处理注释，包括 CRLF，并保留自动分号插入所需的换行语义；用包含这些分隔符的代码比较压缩前后的执行结果。
