# YAML 格式化：序列化丢失类型和结构

- 受影响工具：`tools/it/yaml-formatter.html`
- 问题：JSON 转 YAML 的 `{"a":"true","b":"","x":[],"y":{}}` 输出 `a: true`、`b:`、`x:`、`y:`，字符串及空容器的类型无法保留；`[{"a":{"b":1}}]` 输出 `- a: [object Object]`。格式化 `key: "true"` 也会输出 `key: true`，再次读取时变成布尔值。
- 解决方案：使用支持递归、转义和类型保真的 YAML 序列化器；明确注释、锚点等往返保留能力，对不能保留的内容提示。用字符串、空集合、嵌套对象、换行和特殊键做往返测试。
