# JSON 差异：自动保存原始数据缺少隐私选择

- 受影响工具：`tools/it/json-diff.html`
- 问题：页面自动将两侧文本完整写入本地 localStorage 并在之后恢复，JSON 可能含令牌、个人数据或配置；页面说明数据不会上传，但未明确告知本机持久化或提供关闭草稿保存的选项。
- 解决方案：在输入区域说明数据仅在本机处理且可能保存在当前浏览器，提供可关闭的草稿保存及清除本地草稿入口，并清晰说明清除范围；不将敏感数据纳入其他持久化记录。验证刷新、关闭保存、清空和多标签页行为。
- 验证：基于页面 localStorage 代码及可见说明静态分析；需检查运行时是否另有统一隐私入口。
