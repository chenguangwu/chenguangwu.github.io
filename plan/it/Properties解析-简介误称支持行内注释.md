# Properties 简介误称支持行内注释

- 受影响工具：`tools/it/properties-parser.html`
- 问题：中文简介宣称支持行内注释，解析器只跳过行首空白后的 `#` 或 `!`，例如 `a=value # note` 将 `# note` 作为值的一部分。Java Properties 通常也将其作为值，现有文案可能让用户误以为注释被剔除。源码已核实，待与目标 Java 行为及浏览器复核。
- 解决方案：按 Java Properties 的实际语义修正中英文简介及示例，区分整行注释和属性值内的 `#`、`!`；若增加非标准行内注释模式，应显式选择并提示兼容性。
