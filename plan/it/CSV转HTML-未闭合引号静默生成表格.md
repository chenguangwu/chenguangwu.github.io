# CSV 转 HTML：未闭合引号静默生成表格

## 问题描述

输入 `name,city` 换行后输入 `Alice,"Shanghai`，点击转换，解析器读到结尾时没有检查引号状态，仍生成包含 `Shanghai` 的表格并展示成功统计。用户无法发现 CSV 格式不完整，复制或下载后可能把错误数据当成正常结果。

## 解决方案

解析结束时检查未闭合引用字段，并检查闭合引号后只能接分隔符、换行或文件结束；对非法输入显示行列及修正提示，清除过期结果，禁止复制下载。覆盖正常跨行引用、双引号转义和不完整输入。

## 受影响工具路径

- `tools/it/csv-to-html-table.html`：`parseCSV()` 与 `calcTool()`。
