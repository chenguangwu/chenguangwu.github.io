# Cron 生成器：可视化步长和范围未校验可复制无效表达式

## 问题

可视化步长输入只用 HTML 的 min/max，`setStep()` 和 `updateCron()` 没有调用表达式校验，仍直接将状态标为有效并启用复制。用户输入 0 或清空步长并触发 change 后，可能生成 `*/0` 或 `*/NaN` 并可复制；范围起点大于终点也可生成无效表达式。只有进入下一次执行时间页时才校验。此为源码分析，需浏览器复核。

## 解决方案

可视化变更也走统一校验，步长必须为有效正整数且范围起点不大于终点；无效时显示具体字段错误、禁用复制并清除旧预览，修正后恢复。验证键盘输入 0、空值、负值、反向范围和正常值。
