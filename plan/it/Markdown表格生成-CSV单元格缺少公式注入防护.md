# Markdown 表格生成：CSV 单元格缺少公式注入防护

受影响工具：`tools/it/markdown-table-generator.html`

问题：CSV 导出对单元格仅做双引号转义，没有处理电子表格可能识别为公式的内容。用户输入或编辑输出中以 `=`、`+`、`-`、`@` 等开头的文本，打开 CSV 时可能被电子表格解释为公式；CSV 加引号本身不等于阻止公式求值。

解决方案：提供默认安全的电子表格导出，对潜在公式值进行适当中和，并说明对原始文本和数值类型的影响；如提供原样导出应明确风险。使用无害公式探针、前导空白、负数、普通文本和表头在目标表格软件中验证。

证据范围：静态代码分析，实际软件对公式的处理需验证。
