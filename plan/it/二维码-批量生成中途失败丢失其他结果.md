# 二维码：批量生成中途失败时缺少逐项结果

受影响工具：`tools/it/qrcode.html`

问题：批量生成共用一个 try/catch，某行生成失败时会清空整个预览和已生成列表，其他有效行也无法下载；提示未明确标出失败行，用户难以定位需要缩短或修改的内容。编码器在超容量场景抛出的值不一定具有 `message`，当前提示还可能显示“生成出错：undefined”。

解决方案：逐行校验并展示成功与失败状态，标明原始行号及可理解的原因；允许下载成功项，同时明确是否存在未生成项。验证首行、中间行和末行容量超限，以及重试、清空和切换参数后的状态。

证据范围：本机无头 Chrome 以本地文件加载，输入有效行、3000 个小写字符、有效行后，结果列表及画布均为空，提示为“生成出错：undefined”。其他失败位置和 HTTP 场景待复核。
