# 摄像头录制启动失败后可能继续占用设备

- 受影响工具：`tools/it/camera-recorder.html`
- 问题：成功获取媒体流后，若 `MediaRecorder` 构造或启动抛错，异常落入统一 catch 显示“无法访问摄像头”，但 catch 未停止已获取的音视频轨道；浏览器不支持 MediaRecorder 时也进入仅预览分支而未明确关闭流。源码推断，待浏览器复核异常及预览退出路径。
- 解决方案：区分设备授权失败与录制器启动失败，在启动失败时停止所有已获取轨道并恢复按钮状态；仅预览模式提供明确关闭操作。模拟构造异常、启动异常和权限拒绝，验证摄像头与麦克风指示灯关闭。
