# Playfair 密码：清空后仍显示旧步骤信息

- 受影响工具：`tools/it/playfair-cipher.html`
- 问题：输入文字并启用分步演示后点击清空，`clearAll()` 将内部步骤数归零，但未更新页面的 `stepTotal`，也未清除 `playfairNote`，因此页面仍显示上一次的步骤总数与预处理说明。直接清空输入时，`process()` 虽更新总数，却未重置当前步骤和演示信息，也可能保留旧结果的步骤描述。
- 解决方案：统一空输入、清空按钮及无效输入的状态重置，清除说明和配对列表，同步总步数、当前步数、按钮状态及矩阵高亮；覆盖有结果后清空、删除输入及错误输入等场景。
- 验证说明：依据页面处理逻辑静态分析，实施时需用浏览器复现并验证。
