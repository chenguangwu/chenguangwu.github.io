# Shell 脚本格式化：保留多行文本语义

- 受影响工具：`tools/it/shell-script-formatter.html`
- 问题：here-document 的定界符检测只识别未加引号的单词；合法的 `cat <<'EOF'` 不会被识别，格式化和压缩会将正文当作代码处理并改变缩进或空行。跨行引号字符串同样没有跨行词法状态，压缩逐行 `trim()` 会改变字符串内容。以上为源码分析，待浏览器实测。
- 解决方案：使用能跟踪跨行引号、转义和 here-document 的 Shell 词法分析，支持引号定界符、`<<-` 及多个待处理正文，逐字保留文本内容；无法安全分析时提示并保留原文。用包含缩进、空行和引号定界符的脚本验证处理前后输出一致。
