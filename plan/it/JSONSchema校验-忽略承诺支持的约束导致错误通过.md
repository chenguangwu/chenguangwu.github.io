# JSON Schema 校验：忽略承诺支持的约束导致错误通过

## 问题描述

搜索描述和结构化数据声称支持 `enum`、数值范围、字符串长度、正则及数组唯一性，但实际递归只处理类型、必填、属性、额外属性和数组元素。例如 Schema `{"type":"integer","minimum":10}` 配数据 `1`，页面显示“校验通过”；`{"enum":[1]}` 配数据 `2` 同样通过。用户可能把不合规数据误认成合法。

## 解决方案

使用符合所标明 Draft-07 的本地校验实现，覆盖页面承诺的关键字和布尔 Schema，并对无效 Schema 或不支持的关键字明确报错或提示，不得给出完整通过结论。完成前同步修改搜索描述和页面支持范围；验证数值边界、enum、长度、正则、唯一性和嵌套路径。

## 受影响工具路径

- `tools/it/json-schema-validator.html`：元数据、`walk()` 和 `validateJSON()`。
