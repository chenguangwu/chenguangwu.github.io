# JSON 转 YAML：数组中的空容器生成无效 YAML

受影响工具：`tools/it/json-to-yaml.html`

## 问题描述

`toYaml()` 处理数组元素时先输出 `-` 和换行，再递归输出对象；而空数组或空对象的递归分支直接返回 `[]` / `{}`，没有按层级缩进。页面原函数将 `[[],{}]` 生成为 `- \n[]\n- \n{}`；对嵌套对象中的数组亦然。使用 Ruby 自带 YAML 解析器验证，这些结果无法解析，但页面转换流程仍会提示成功。

## 解决方案及验收

数组元素为空容器时在 `-` 后直接输出 `[]` 或 `{}`，或正确处理嵌套缩进；对任意递归组合生成可解析、语义相同的 YAML。用独立 YAML 解析器往返核对根级和多级数组、空对象、空数组、混合标量、缩进选项及压缩输出，并验证中英文错误提示。
