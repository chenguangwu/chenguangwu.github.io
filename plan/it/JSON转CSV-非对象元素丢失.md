# JSON 转 CSV：非对象数组元素被当空行

受影响工具：`tools/it/json-to-csv.html`

页面接受任意非空 JSON 数组，但只从对象元素提取列名。使用页面原 `toCSV()` 在隔离 JavaScript 环境输入 `[1,2]`，输出仅含换行，却提示“已转换 2 行 × 0 列”；混合数组里的数字、字符串或 null 也无法正确表示。用户会收到看似成功但丢失原始值的结果。

解决方案：明确支持的顶层数组结构；若仅支持对象数组，逐项校验并指出不支持的元素位置，阻止输出成功状态；若支持基本类型或混合数组，提供可理解、无损的列映射选项。核验纯基本类型、混合对象、空对象、嵌套对象、null 及空数组，比较页面输出、复制和下载结果；中英文说明需一致。
