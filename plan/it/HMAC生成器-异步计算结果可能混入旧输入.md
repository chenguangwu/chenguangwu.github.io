# HMAC 生成器：异步计算结果可能混入旧输入

## 问题

密钥、消息和编码变化时立即调用异步 `calc()`；每次调用清空结果后依次等待四次 Web Crypto 运算，再逐项追加卡片，没有请求序号或取消机制。快速输入、切换编码或计算中点击清空时，旧运算仍可能在后续追加结果，与新输入的摘要混在一起，或在清空后重新出现。用户复制到的签名可能对应不同输入。

## 解决方案

为计算增加版本标识，输入变化、失败和清空时令旧任务失效；先在内存汇总当前输入对应的四种摘要，确认版本仍有效后一次性展示。覆盖延迟的 Web Crypto、快速连续输入和计算中清空。

## 受影响工具路径

- `tools/it/hmac-generator.html`（`calc`、`renderResult`、`clearAll`）
