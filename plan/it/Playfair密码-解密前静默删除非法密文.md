# Playfair 密码：解密前静默删除非法密文

- 受影响工具：`tools/it/playfair-cipher.html`
- 问题：解密先将内容转大写并删除所有非英文字母，再仅验证清洗后长度。比如 `AB!CD` 会被按 `ABCD` 解密；数字、标点或其他输入错误不会提示，可能产生错误明文却被用户当作有效结果。Unicode 大写也可能将字符展开或改写。
- 解决方案：解密时仅允许明确说明的空白分组符，其他非法字符及未配对字母提示具体位置，避免静默修改密文；编码明确告知 I/J 合并、过滤及填充不可逆的限制。
- 验证建议：比较合法 `AB CD`、含 `!` 或数字的密文、奇数字母和非 ASCII 字符，确保错误不输出旧结果。
