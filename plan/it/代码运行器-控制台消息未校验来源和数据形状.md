# 代码运行器：控制台消息缺少来源与格式校验

受影响工具：`tools/it/code-runner.html`

## 问题描述
父页面的 message 监听只检查 `data.type === "console"`，未确认来源为当前预览 iframe，也未验证 method 和 data 是预期类型。其他能向页面发送消息的窗口可能插入伪造输出；非数组 data 会在 `data.map` 处抛错，快速重运行时旧预览消息也可能混入。

## 解决方案
校验消息源是否为当前 iframe、消息结构与允许的方法，限制单次内容长度和输出数量；重建预览时隔离旧运行的消息。验证异常对象、旧窗口消息和大量日志。
