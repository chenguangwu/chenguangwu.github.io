# JSON 转 XML 的键名转换可能产生同名节点

## 问题

不符合 XML 标签格式的 JSON 键会被替换成下划线，却没有提示或保留原键。例如 `{"a b":1,"a_b":2}` 的两个键都会输出为 `<a_b>`，后续系统无法还原原始键名，可能把数据误认为数组或覆盖其中一项。字符串中的 XML 不允许的控制字符也未被检测，可能生成无法解析的 XML。

## 解决方案

采用可逆的键名编码或显式记录原始键名，并检测归一化冲突；拒绝或按明确规则处理 XML 不允许的字符。用包含空格、下划线、数字开头、中文键和控制字符的输入验证输出可解析及信息保留。
