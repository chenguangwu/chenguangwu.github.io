# Code 39 条码：空输入和扫描留白

**受影响工具路径：** `tools/it/barcode-code39.html`

## 问题

1. 清空输入后生成会把空值替换成一个空格，产出包含空格数据的条码；用户可能误以为生成的是空数据。
2. 画布两侧固定留白各 10 像素，而窄模块宽 2 像素，仅相当于 5 个窄模块，可能不足以满足扫码设备所需的静区，影响打印扫描。

以上为源码分析，实际扫描表现需使用扫码器和打印样张验证。

## 解决方案

空输入给出明确提示，保留用户主动输入的空格并在结果中清晰展示实际编码内容。按 Code 39 规范及目标设备要求设置并展示静区，提供可调整的模块宽度及适合打印的导出尺寸；用多种输入、屏幕及实际打印样张验证扫描结果。
