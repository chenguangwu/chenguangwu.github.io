# 代码运行器：示例覆盖草稿且使用了错误语言算例

受影响工具：`tools/it/code-runner.html`

## 问题描述
选择示例直接覆盖 HTML、CSS 和 JS 三个编辑框并立即运行，没有草稿恢复或确认；刷新时也总是载入默认示例。正文“运行”算例写 `print(2**10)`，但工具实际运行 JavaScript，未提供 Python 解释器，按例输入不会得到所承诺的控制台结果。

## 解决方案
示例切换前保留可撤销草稿，提供本地持久化与清除控制；将示例改为可在 JavaScript 控制台运行的 `console.log(2**10)` 并校验预期。覆盖三栏草稿、刷新及示例切换。
