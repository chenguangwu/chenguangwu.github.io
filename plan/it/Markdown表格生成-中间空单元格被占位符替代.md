# Markdown 表格生成：中间空单元格被替换为占位符

受影响工具：`tools/it/markdown-table-generator.html`

问题：`fillCells()` 对空字符串使用 `C1`、`C2` 等占位符；例如表头输入 `姓名,,城市` 时，第二列被替换成 `C2`，空数据也会被改写。用户可能希望有意保留空单元格，生成结果却静默改变了内容。

解决方案：区分用户明确输入的空值和未提供的列；保留空值，对不足列数的处理提供清晰选择或提示。验证中间、末尾空列、带引号的空值以及 Markdown 与 CSV 往返一致。

证据范围：静态代码分析，浏览器与 CSV 往返待验证。
