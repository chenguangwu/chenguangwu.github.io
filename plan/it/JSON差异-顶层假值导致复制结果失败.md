# JSON 差异：顶层假值导致复制结果失败

- 受影响工具：`tools/it/json-diff.html`
- 问题：普通结果视图的 `copyDiff()` 使用 `lastLeft && lastRight` 判断是否存在比较结果。JSON 顶层值可以是 `0`、`false`、`null` 或空字符串，因此比较 `0` 和 `1` 后虽然有差异，普通视图复制却提示没有内容；JSON 结果视图走另一分支。
- 解决方案：以独立的比较完成状态或有效差异报告判断是否可复制，不能用输入值的真值判断；明确零差异时的复制行为。测试两侧分别为各种假值的差异、零差异、清空及失败后的状态，并与 JSON 视图和下载报告保持一致。
- 验证：依据复制分支静态分析，已验证 JavaScript 真值条件；完整交互待浏览器复核。
