# Plist 转换：字典特殊键与非法结构

- 受影响工具：`tools/it/plist-parser.html`
- 问题：Plist 字典通过普通对象 `obj[k] = ...` 转换，键名 `__proto__` 会触发对象原型访问器，导致该键不能可靠进入 JSON 结果；缺值的 key、重复 key 和未知类型标签则可能被静默忽略、覆盖或转为文本。以上为源码分析，待浏览器验证。
- 解决方案：用无原型对象或安全的自有属性定义保留任意合法键；严格校验 dict 的 key/value 配对、重复键和支持的类型，对无法无损转换的内容报错并定位位置。补充 `__proto__`、重复键及缺失 value 的往返和错误用例。
