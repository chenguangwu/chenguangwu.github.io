# 随机数：清空输入后仍按隐藏默认值生成

受影响工具：`tools/it/random.html`（首页编辑精选）

`numberField()` 在最小值、最大值或数量为空时分别回退为 0、100、1，但输入框仍为空，生成结果没有说明采用了替代值。用户清空上限后仍会得到 0–100 内的结果，可能误认为使用了所需范围。页面数量字段标注最多 50，但函数也未校验上限，可能造成过量工作。源码确认，需浏览器核对提示、旧结果和导出。

解决方案：将空值作为未填写提示，显式输入 0 仍有效；函数内验证数量为有限整数且处于声明范围，错误时清除或标记旧结果。测试各字段单独清空、0、负值、科学计数法、50 和超过 50，以及重新生成、复制与导出。
