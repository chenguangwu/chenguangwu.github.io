# JSON 差异：重复键被覆盖导致漏报

- 受影响工具：`tools/it/json-diff.html`
- 问题：比较前使用 `JSON.parse`，同一对象的重复键会被后一个值覆盖。例如 `{"id":1,"id":2}` 和 `{"id":2}` 解析后相同，工具可能显示完全相同，没有提醒原始输入存在重复键。JSON 对象成员名应唯一，静默覆盖会掩盖配置问题。
- 解决方案：解析时识别同一对象层级内的重复键并指出侧别、路径与位置，提供修正提示；若仍允许比较，明确比较的是覆盖后的结果，不将原始文本描述为完全相同。测试嵌套对象、转义后相同的键、不同对象内同名键和数组内对象。
- 验证：已用 Node 验证上述输入解析结果相同；页面提示及边界情形待浏览器复核。
