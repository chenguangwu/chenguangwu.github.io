# Java 字符串转义：八进制反转义吞掉第三位

## 问题描述

Java 八进制转义的首位为 4–7 时最多使用两位；例如字面量 `"\777"` 的值是 `?7`（`\77` 加字符 `7`）。工具反转义时无条件读取最多三位，错误地将 `777` 作为八进制数 511 转成单个字符，改变原文。

## 解决方案

按 Java 八进制转义规则解析：首位为 0–3 时最多三位，首位为 4–7 时最多两位，并在输入不符合字面量语法时明确提示。验证 `\777`、`\377`、`\400` 和转义后紧随数字的情况，使用 Java 实际求值作为对照。

- `tools/it/java-escape.html`：`unesc()` 的八进制转义分支。
