# HMAC 生成器：不支持空消息且输入时重复弹窗

## 问题

`calc()` 将空消息视为错误，但 HMAC 可以对空字节消息计算认证码，测试协议或标准测试向量时无法完成。消息和密钥输入框每次 input 都调用 `calc()`，删除至空会立即弹出模态提示，并在校验返回前保留之前的结果，用户可能把旧摘要当作当前输入的结果复制。

## 解决方案

支持对空消息计算；密钥的空值按明确规则处理并在界面说明。交互式编辑时使用非阻塞状态提示，输入不满足条件立即清空或标记旧结果失效；验证空消息测试向量、删除输入、重新输入及复制行为。
