# 密码生成：长度与数量未按控件范围校验

受影响工具：`tools/it/password-generator.html`

问题：长度和数量控件声明了 4–128、1–100 的范围，但点击生成时只用 `parseInt(...) || 默认值` 读取，没有检查范围及整数形式。空值或 0 会静默替换为默认值；超大数量或长度会进入同步生成循环，可能长时间占用页面；负数等输入也不能给出明确反馈。

解决方案：生成前对两个字段验证非空、整数及页面声明的上下限，明确提示错误并保证结果状态与输入一致；有需要时通过分批执行保持大量生成过程可响应。验证空值、0、负数、小数、边界和超大输入，同时检查复制及下载状态。

证据范围：本机无头 Chrome 中，数量设为 101 实际生成 101 条；长度设为 0 实际生成 16 位。大数性能、其他边界及 HTTP 场景待验证。
