# JSON 格式化：数字键排序口径未说明

- 受影响工具：`tools/it/json-formatter.html`。
- 问题：排序先对键执行字符串排序，再写入普通 JavaScript 对象并序列化；整数索引形式的键会按数字顺序枚举，无法保留纯字符串字典序。例如 `{"10":1,"2":2,"a":3}` 的结果是 `{"2":2,"10":1,"a":3}`，而纯字符串排序会把 `10` 放在 `2` 前。页面仅显示“排序”，未说明规则；已用 Node 隔离验证对象枚举结果。
- 解决方案：明确排序规则并提供字典序或自然序选择；若承诺字典序，使用能够保留目标键顺序的序列化方式，不通过普通对象枚举丢失顺序。验收整数键、前导零、嵌套对象和复制下载一致性，同时避免 `__proto__` 特殊键丢失。
