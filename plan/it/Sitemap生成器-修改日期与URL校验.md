# Sitemap 生成器：修改日期和 URL 校验

**受影响工具路径：** `tools/it/sitemap-generator.html`

## 问题

生成器将所有 URL 的 `lastmod` 设为生成当天，即使页面并未在该日修改；输入只检查是否以 `http://` 或 `https://` 开头，非法地址可能进入结果，不符合前缀的行又被静默丢弃。生成的站点地图可能包含不可靠日期或漏掉用户输入的 URL。以上根据源码分析，需浏览器复核。

## 解决方案

不自动虚构修改时间：默认省略 `lastmod`，允许用户提供真实日期并验证；逐行使用 URL 解析和协议检查，列出无效行并允许修正，明确重复 URL 和跨站地址的处理。测试特殊字符转义、无效 URL、日期及大量输入。
