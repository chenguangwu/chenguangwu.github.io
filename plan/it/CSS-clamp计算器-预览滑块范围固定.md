# CSS clamp 计算器：预览滑块范围未跟随视口配置

**受影响工具路径：** `tools/it/clamp-calculator.html`

## 问题

最小与最大视口允许分别填写 200–2000 和 400–4000 px，但预览滑块固定为 320–1920 px。用户设置 200 px 或 2560 px 等合法端点后，无法通过滑块查看这些断点处的排版效果，影响对生成规则的验证。以上为源码分析，需浏览器复核。

## 解决方案

随有效的最小和最大视口更新滑块范围，保留或合理夹取当前选择值，同时提供直接输入视口宽度或端点快捷选择。验证配置变大、变小以及输入无效后恢复时，滑块、预览和生成代码保持一致。
