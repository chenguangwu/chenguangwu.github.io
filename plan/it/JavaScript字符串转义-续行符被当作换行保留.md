# JavaScript 字符串转义：续行符被当作换行保留

## 问题描述

输入一个双引号 JavaScript 字符串，在 `a` 与 `b` 之间插入反斜杠和实际换行，再点击反转义。JavaScript 将反斜杠加换行视为续行，字符串的值为 `ab`；工具默认分支丢弃反斜杠但保留换行，得到两行文本，改变了实际值。

## 解决方案

按 JavaScript 字符串字面量语法处理反斜杠后 LF、CRLF、CR 和 Unicode 行分隔符组成的续行，不向结果插入换行；不合法的字面量应提示而非猜测。验证实际续行与 `\n` 转义、普通换行分别得到正确结果。

- `tools/it/js-escape.html`：`unesc()` 的转义扫描。
