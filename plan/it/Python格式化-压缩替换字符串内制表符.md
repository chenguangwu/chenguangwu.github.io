# Python 格式化：压缩会替换字符串内制表符

## 问题

压缩对普通代码行执行全行 `replace(/\t/g,'    ')`，不仅改变缩进，也会替换单引号或双引号字符串中的实际制表符。比如代码中 `x = "a<TAB>b"`（`<TAB>` 表示实际制表符）压缩后变成四个空格；程序仍可运行，但字符串值已变化。页面却提示压缩保留语义。

## 解决方案

仅处理词法上属于缩进的前导空白，并避免修改字符串、注释、续行及字面量；不能可靠识别时保持原文或提示。用实际制表符、转义 `\\t`、三引号及混合缩进的代码比较压缩前后的执行结果。

## 受影响工具路径

- `tools/it/python-formatter.html`（`minifyPython`）
