# 随机数：小数边界下整数可能越界

受影响工具：`tools/it/random.html`（首页编辑精选）

整数模式调用 `Math.floor(Math.random() * (max + 1 - min) + min)`，未要求上下界为整数，也未先取整边界。例如最小值 0.2、最大值 1.2 时，按公式可产生 0 或 2，均超出用户指定范围；不重复容量检查也基于未取整的边界，可能误判可选数量。HTML number 输入允许小数，需浏览器复现显示与复制。

解决方案：整数模式先明确并校验边界：可要求整数输入，或以 `ceil(min)` / `floor(max)` 计算实际整数集合并提示；空集合应报错，容量检查基于实际整数数量。测试正负小数边界、单个可选整数、无整数、相等边界、大数安全范围和唯一抽样。
