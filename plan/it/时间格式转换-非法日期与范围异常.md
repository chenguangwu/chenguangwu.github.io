# 时间格式转换：校验日期和时间范围

- 受影响工具：`tools/it/time-format-converter.html`
- 问题：纯日期直接交给 `new Date(year, month, day)`，例如 `2024-02-31` 会自动进位为 3 月日期而非提示错误，年份 0000–0099 也会触发 JavaScript 年份特殊规则。纯数字超出 Date 支持范围时仍返回 Invalid Date 对象，后续 `toISOString()` 抛错且旧结果可能保留。源码分析，待浏览器复核。
- 解决方案：构造日期后核对年、月、日与输入一致，并显式处理 0–99 年；所有解析分支统一验证 `getTime()` 有限，转换失败时显示本地化错误并清理旧结果。覆盖闰日、非法日、早期年份、超范围时间戳及恢复正常输入。
