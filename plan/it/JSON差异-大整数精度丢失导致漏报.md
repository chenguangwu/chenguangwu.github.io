# JSON 差异：大整数精度丢失导致漏报

- 受影响工具：`tools/it/json-diff.html`
- 问题：比较前直接使用 `JSON.parse`，超出 JavaScript 安全整数范围的值可能被舍入。左右分别输入 `{"id":9007199254740992}` 和 `{"id":9007199254740993}` 时，两者解析为同一个数，深度和简单比较都会漏报该差异；格式化后的行视图和导出结果也无法反映原始数值。
- 解决方案：使用保留数字原始字面量的解析与比较方式，或在可能发生精度损失时明确警告并避免宣称完全相同；各视图、复制和导出应保持一致。覆盖安全整数边界、负数、小数、指数及嵌套数组；确认语义等价的数字形式如何比较并向用户说明。
- 验证：已用 Node 验证示例解析后相等；页面交互及其他数字形式仍需浏览器复核。
