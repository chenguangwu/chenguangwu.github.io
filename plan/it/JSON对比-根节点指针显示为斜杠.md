# JSON 对比：根节点指针显示为斜杠

## 问题

根节点变化时，差异记录中的 JSON Pointer 是空字符串，但路径视图及文本复制使用 `pointer || '/'`，将其显示为 `/`。按 JSON Pointer 规则，空字符串指向整个文档，`/` 指向名称为空字符串的成员；例如比较 `1` 与 `2` 时复制得到的指针会误导后续定位。JSON 格式导出仍保留空字符串，造成展示与导出不一致。此为源码分析，需浏览器复核。

## 解决方案

保留根节点的空字符串指针，并以清晰的“根节点（空指针）”说明展示；复制文本也应明确表示空指针，不与 `/` 混淆。验证根节点替换、空字符串键、含 `/` 和 `~` 的键以及 JSON 导出。
