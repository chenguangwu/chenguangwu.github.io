# PIN 生成器：重试耗尽仍输出不符合条件的 PIN

**受影响工具路径：** `tools/it/pin-generator.html`

## 问题

勾选避免连续数字后，每个 PIN 最多尝试 50 次；若 50 次都不符合条件，循环结束仍输出最后一次候选，没有说明失败，因此结果可能违反用户选择。批量复制通过容器 `textContent` 获取多个块元素，可能把 PIN 直接拼接而不换行。以上根据源码分析，需浏览器复核并用可控随机输入覆盖耗尽重试场景。

## 解决方案

仅输出通过全部条件的候选；无法在限制内生成时明确报告失败和已生成数量，必要时改用有界的候选构造算法。批量复制以换行连接，测试限制组合、重试耗尽、单条与多条复制。
