# JSON 格式化：排序时丢失 `__proto__` 键

受影响工具：`tools/it/json-formatter.html`（首页编辑精选）

`sortKeys()` 创建普通对象后通过 `sorted[k] = ...` 写入键；键名为 `__proto__` 时会触发对象原型的特殊赋值，而不是保留普通数据字段。隔离执行页面原函数，输入 `{"__proto__":{"x":1},"normal":2}` 排序后只剩 `{"normal":2}`，造成静默数据丢失。

解决方案：使用无原型对象或安全的数据属性定义进行排序，递归保留所有合法 JSON 键；不要把特殊键赋给对象原型。验证顶层和嵌套 `__proto__`、`constructor`、数组中的对象、键排序以及格式化、复制和下载的往返一致性。
