# Python 格式化：反斜杠续行字符串空格被删除

## 问题

格式化仅识别三引号跨行字符串，对普通引号中反斜杠续行没有保留状态，后续物理行的首尾空白会被 `trim()` 改写。例如 Python 源码 `s = "a\` 换行后接两个空格和 `b"`，原字符串是 `a  b`；格式化后续行的前导空格被去除，变为 `ab`，但页面仍提示格式化成功。

## 解决方案

基于 Python 词法状态识别单/双引号字符串、反斜杠续行和转义，保留字面量内容；对不支持的复杂语法停止并提示，不输出可能改变语义的代码。验证续行字符串在格式化前后的值，以及跨行括号、注释和三引号的行为。

## 受影响工具路径

- `tools/it/python-formatter.html`（`formatPython`）
