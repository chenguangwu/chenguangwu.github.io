# ASCII 目录树：单行前导空格导致路径列表误判

- 受影响工具：`tools/it/ascii-tree-generator.html`
- 问题：工具用“任意一行以空格开头”判断输入为缩进树。粘贴路径列表时只要某行偶然带前导空格，例如 `src/a.js` 与 `  src/b.js`，整份输入就按缩进树解释，斜杠路径被作为单个名称，父子关系和输出结果错误，却仍显示生成成功。
- 解决方案：提供明确的路径列表和缩进树输入模式，或在检测模糊时提示用户选择；路径模式按行处理合理的前后空白，避免一行异常改变全部解析方式。
- 验证建议：对比同一组路径有无行首空格的结果，并覆盖真正的缩进树、混合格式与斜杠路径。
