# 正则可视化：多字符转义被拆散并错误绑定量词

## 问题描述

输入合法表达式 `\x41+`，实际含义是匹配一个或多个 `A`；语法树解析转义时固定只消费两个字符，展示为转义 `\x`、字面量 `4` 和被 `+` 修饰的字面量 `1`。同类问题影响 `\u0041`、命名反向引用等多字符转义，用户据此理解匹配范围会得到错误结论。

## 解决方案

使用符合当前支持的 JavaScript 正则语法的解析器，完整识别转义序列、反向引用及其修饰范围；无法准确解析的语法应明确提示，而非展示错误语法树。增加 `\x41+`、`\u0041+` 和命名反向引用的树结构验证，并注明支持的正则标志。
