# API 签名逐行输入无法保留值中的与号

- 受影响工具：`tools/it/api-sign-generator.html`
- 问题：页面提示值中的 `&` 可编码为 `%26` 或改为每行一个参数，但解析器只要发现 `&` 就按查询串分割，无论是否逐行输入。`message=a&b` 会报错，`message=a&b=c` 更会被当作两个参数；而 `%26` 又按页面规则原样参与签名，不能替代原始 `&`。源码已核实，待浏览器复核。
- 解决方案：提供明确的逐行与查询串输入模式：逐行模式仅以首个 `=` 分割，保留值中 `&`；查询串模式说明编码与解码规则。展示最终签名串并验证这两种输入及混合特殊字符。
