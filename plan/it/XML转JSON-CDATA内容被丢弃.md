# XML 转 JSON：CDATA 内容丢失

**受影响工具路径：** `tools/it/xml-to-json.html`

## 问题

转换只收集 `nodeType === 3` 的文本节点，忽略 CDATA 节点。浏览器 XML DOM 中 `<root><![CDATA[hello]]></root>` 的 CDATA 是节点类型 4，因此结果可能为空字符串，导致正文内容丢失；混合文本还会将不同位置的文本拼接，无法还原原有顺序。以上根据源码分析，需浏览器复核。

## 解决方案

识别 CDATA 并保留其文本，明确提供简单对象模式与保序混合内容模式及其取舍；说明空白处理规则。覆盖纯 CDATA、文本与子元素交替、空白、重复元素和属性混合样例。
