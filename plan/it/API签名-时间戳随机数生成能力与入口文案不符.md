# API 签名时间戳与随机数能力和入口文案不符

- 受影响工具：`tools/it/api-sign-generator.html`、`tools/it/ascii-tree-generator.html`
- 问题：目录树页的相关工具卡片称 API 签名工具能生成带时间戳与随机数的签名；签名页只处理用户手工填写的参数，没有生成或自动加入 timestamp、nonce 的功能。用户可能以为已具备防重放参数，而实际默认示例中没有。源码已核实，待浏览器复核。
- 解决方案：提供明确可选的本地时间戳和安全随机 nonce 生成及参数注入，展示单位与实际参与签名的内容；在未启用时提示需自行填写，并说明服务端仍须校验时间窗口和 nonce。同步修正相关卡片与中英文介绍。
