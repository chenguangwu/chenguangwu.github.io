# 仿射密码：大整数密钥精度丢失

**受影响工具路径：** `tools/it/affine-cipher.html`

## 问题

参数校验允许任意长度的整数字符串，再转换为 JavaScript `Number` 取模；超过安全整数范围的值可能先被舍入，导致实际使用的密钥与输入不一致。例如 `9007199254740993` 无法精确表示，计算出的模 26 值可能改变。页面未提示精度损失。以上根据源码分析，需浏览器复核。

## 解决方案

使用安全整数范围检查并明确提示，或直接对整数字符串使用 BigInt 求模；显示实际归一化后的 a、b，避免用户误解。测试正负大整数、最大安全整数边界、互素判断和加解密往返。
