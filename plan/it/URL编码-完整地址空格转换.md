# URL 编码：完整地址的空格被替换成路径加号

受影响工具：`tools/it/url-encode.html`（首页编辑精选）

同时选中“完整 URL 模式”和“空格编码为 +”时，代码先通过 `URL` 得到地址，再全局将 `%20` 换成 `+`。例如 `https://example.com/a b?q=c d` 变成 `https://example.com/a+b?q=c+d`；路径中的 `+` 通常是字面加号，已不再表示原先的空格。解码时全局把加号当空格也有相同的上下文问题。上述例子已用浏览器同源的 `URL` 实现复算。

解决方案：明确“+ 表示空格”仅适用于表单编码的查询参数，而不是整个 URL；对完整地址分别处理路径、查询与片段，保留字面加号和结构。验证路径与查询各自含空格/加号、已有百分号编码、片段、重复参数和往返结果，并同步界面说明。
