# JavaScript 格式化：文件开头的正则压缩可能改变匹配内容

受影响工具：`tools/it/js-formatter.html`

## 问题描述
词法器只在已有 token 时尝试识别正则字面量。文件以正则表达式开头时，正则内部会被按普通符号和空白分词；例如 `/a  b/.test(s)` 的两个空格在压缩时可能被合并为一个。压缩后的代码仍可通过语法检查，但匹配语义已变。该示例根据代码静态推断，需执行复核。

## 解决方案
采用可正确识别正则和除法的成熟 JavaScript 解析与生成方案，保证字面量内容及语义不变；验证文件开头正则、字符类、转义斜杠、除法及模板字符串，不能仅用语法通过作为语义等价证明。
