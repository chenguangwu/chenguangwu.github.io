# 密码生成：列表和历史复制按钮将密码嵌入 HTML 属性

受影响工具：`tools/it/password-generator.html`

问题：批量列表与会话记录把生成的密码直接拼入 `onclick` 属性，只对单引号做 JavaScript 层替换，没有进行 HTML 属性层编码。字符集包含 `&` 和 `;`，若密码碰巧包含类似 `&amp;` 的字符实体，浏览器解析属性时可能改变复制参数，造成复制值与显示值不一致。

解决方案：不要将凭证拼入 HTML 和内联代码；通过 DOM 事件绑定持有原始字符串或按索引从内存读取，并仅把显示内容作为文本节点写入。用包含 `&amp;` 字面字符及各符号的受控样例，核对列表、历史、复制全部和下载的字节内容一致。

证据范围：已用本机无头 Chrome 和受控假数据验证：列表中的字面值 `A&amp;B` 点击复制得到 `A&B`。会话历史和 HTTP 场景仍待复核；不应在日志或测试报告中记录真实凭证。
