# TOML 格式化：引用表名被拆成多级路径

## 问题描述

输入合法 TOML：

```toml
["a.b"]
value = 1
```

点击格式化后，输出表头变成 `[a.b]`。原表名是一个包含点号的键，输出却表示 `a` 下的子表 `b`，再次解析后数据结构发生变化；带空格等需引用的表名还可能生成非法 TOML。数组表及嵌套表也使用相同拼接方式。

## 解决方案

生成表头时对每一级键分别按 TOML 规则引用和转义，再用点号连接，不能直接拼接原始键。增加含点号、空格、引号的普通表、嵌套表及数组表格式化后重新解析的等价性验证。

## 受影响工具路径

- `tools/it/toml-formatter.html`：`tomlStringify()` 拼接表头时未使用 `formatTomlKey()`。
