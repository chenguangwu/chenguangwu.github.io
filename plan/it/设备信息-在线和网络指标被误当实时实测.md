# 设备信息：在线状态与网络指标容易误导

## 问题

页面把 `navigator.onLine` 直接标为“在线/离线”，但浏览器的在线状态不能保证互联网或目标服务可达；局域网已连接而外网不通时仍可能显示在线。页面将 `navigator.connection.downlink` 和 `rtt` 标为“下行带宽”“往返延迟”，未说明它们是浏览器估算值，并非当前链路测速实测。上述信息只在初次加载及每分钟重新读取，状态变化后可在最多约一分钟内显示旧值。

## 解决方案

将状态标为浏览器报告的网络连接状态，说明不代表外网可达；将 Network Information API 数值标为估算值，并说明浏览器可能不支持。监听 online/offline 和 connection change 更新展示，保持无外部请求的本地运行方式；用断网事件、无外网的局域网和不支持 API 的环境验证提示。
