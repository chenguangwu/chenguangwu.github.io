# CSV 校验器：非法引号被判无问题

受影响工具：`tools/it/csv-validator.html`

## 问题描述

当前解析器把未引用字段中间的双引号当普通字符，并允许闭合引号后紧接其他字符。用页面原 `calcTool()` 在隔离 JavaScript 环境中实测以下输入，均显示“未发现列数/引号问题”：

```csv
a,b
x"y,z
```

```csv
a,b
"x"bad,z
```

这些格式不满足页面正文所述的双引号字段规则，可能让格式问题漏过导入前检查；合法的 `"x,y",z` 也应继续通过。另外正文建议确认“编码正确”，但页面只接收已解码的文本，并未验证源文件编码，容易造成能力误解。

## 解决方案及验收

用明确的字段状态区分未引用字段、引号内、引号闭合后；对字段内未转义引号和闭合后非法字符报告准确的物理行列及原因。明确规定空行、行尾换行、不同分隔符和严格模式，避免把已支持的兼容格式误判；纠正文案中的编码校验承诺，或单独提供明确解码方式的本地文件检查。覆盖合法转义双引号、嵌入换行、CRLF、异常引号、不同分隔符与首尾空字段，并校验中英文反馈。
