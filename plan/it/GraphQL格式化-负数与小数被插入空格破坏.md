# GraphQL 格式化：负数与小数被插入空格破坏

## 问题描述

输入合法查询 `{ products(limit: -1, rating: 1.5) { id } }` 并点击格式化，词法器将负号和小数点拆成独立词元，格式化器在词元间插入空格，得到 `- 1` 和 `1 . 5`。输出不再是原来的 GraphQL 数字字面量，可能无法解析，而页面仍显示格式化成功。

## 解决方案

使用完整识别 GraphQL 整数、浮点数和指数形式的词法解析及格式化方案；输出前验证语法并保证解析后的值不变，失败时显示错误而非成功。覆盖负整数、小数、负指数及相邻参数的格式化与重新解析。

## 受影响工具路径

- `tools/it/graphql-formatter.html`：`tokenize()` 和 `formatGraphQL()`。
