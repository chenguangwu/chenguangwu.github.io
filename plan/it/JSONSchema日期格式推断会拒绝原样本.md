# JSON Schema 日期格式推断可能拒绝原样本

## 问题

生成器仅凭正则形状给字符串添加 `date` 或 `date-time` 格式。例如 `2026-02-30` 和缺少时区的 `2026-01-01T12:30:00` 会被分别标记为日期和日期时间；启用格式验证时，生成的 schema 可能拒绝用于生成它的样本。

## 解决方案

严格校验日历日期和 RFC 3339 日期时间，再决定是否推断格式；无法确认时保留普通字符串。使用独立的格式验证器检查闰日、非法日期、缺失时区及合法时区偏移，确保生成结果接受原样本。

## 受影响工具路径

- `tools/it/json-schema-generator.html`
