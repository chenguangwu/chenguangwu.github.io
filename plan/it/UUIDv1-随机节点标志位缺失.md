# UUID v1：随机节点未设置组播标志位

受影响工具：`tools/it/uuid-generator.html`（首页编辑精选）

`generateUuidV1()` 使用随机字节作为节点字段，但未设置节点首字节的最低位；隔离执行原函数并用全零随机源测试，生成的节点首字节该位为 0。[RFC 9562 §6.10](https://www.rfc-editor.org/rfc/rfc9562.html#section-6.10) 要求随机生成的 48 位节点设置该位，以区分网络卡地址。当前随机输出有一部分不满足该要求。

解决方案：随机节点生成后设置规定的组播位，同时保持版本、变体及其余随机位；不要使用真实硬件地址。使用可控随机源测试该位恒为 1，并校验节点布局、时间戳、版本、变体、批量输出及无安全随机源时的提示。
