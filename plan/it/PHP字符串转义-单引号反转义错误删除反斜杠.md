# PHP 字符串转义：单引号反转义错误删除反斜杠

## 问题描述

输入 PHP 单引号字面量 `'a\nb'` 并点击反转义，工具输出 `anb`。PHP 单引号字符串中，除 `\\` 和 `\'` 外的反斜杠序列应保留反斜杠，因此实际值为 `a\nb`（其中 `\n` 是两个字符）。当前实现对任意反斜杠后字符都删除反斜杠，会破坏路径和其他文本。

## 解决方案

单引号模式仅解析 `\\` 和 `\'`，其他反斜杠及其后字符原样保留；对不完整字面量提示错误。验证 `\n`、Windows 路径、转义单引号和连续反斜杠，与 PHP 的实际求值结果比对。

## 受影响工具路径

- `tools/it/php-escape.html`：`unesc()` 的单引号分支。
