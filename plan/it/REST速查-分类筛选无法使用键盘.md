# REST API 速查：分类筛选无法使用键盘

## 问题

分类筛选由普通 `div` 渲染，仅绑定点击事件，没有可聚焦属性或键盘操作。用户无法通过 Tab 选中 GET、POST 或状态码等分类，也无法使用 Enter 或空格触发筛选；当前选中状态同样未向辅助技术暴露。

## 解决方案

使用原生按钮实现分类筛选，暴露当前选中状态并保留清晰焦点样式；筛选重渲染后保持合理焦点。验证 Tab、Enter、空格、屏幕阅读器和移动端触控，保证现有搜索与分类组合仍有效。

- `tools/it/rest-api-cheatsheet.html`（`renderCategories`）
