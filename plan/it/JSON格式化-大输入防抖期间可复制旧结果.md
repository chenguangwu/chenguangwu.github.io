# JSON 格式化：大输入防抖期间可复制旧结果

## 问题

输入超过 5 万字符时，页面延迟 350ms 才重新校验；等待期间没有清除或标记已有的 `lastValidJSON`，复制和下载仍直接使用它。编辑或粘贴新内容后立即操作，可能得到上一次有效 JSON，即使当前输入已无效。此为源码分析，需用大输入和受控计时复核；此前的无效输入清理在延迟校验执行后才生效。

## 解决方案

输入变化时立即将结果标记为待校验并禁用复制、下载等依赖旧状态的操作，解析完成后根据当前输入版本恢复；防止过期计时器覆盖新状态。验证大文本编辑、粘贴无效内容、快速连续输入及立即复制/下载。
