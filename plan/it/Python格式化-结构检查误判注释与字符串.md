# Python 格式化：结构检查误判注释与字符串

- 受影响工具：`tools/it/python-formatter.html`
- 问题：结构检查在跳过空行后立即检查待缩进块，但没有跳过注释行。例如 `if True:\n# comment\n    pass` 是合法 Python，却报告冒号后的行未缩进。括号计数也使用保留字符串内容的 `stripCommentAndString`，例如 `print("(")` 会误报括号不平衡。以上依据源码分析，待浏览器复核。
- 解决方案：词法分析时区分注释、单行字符串、转义和三引号字符串；只有实际代码行参与块缩进判断，括号栈只统计字符串和注释之外的字符并校验类型。补充上述示例及未闭合字符串、混合括号的回归用例；若仅做启发式检查，明确提示不能代替 Python 语法解析。
