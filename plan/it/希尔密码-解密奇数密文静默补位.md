# 希尔密码：解密时静默修改密文

- 受影响工具：`tools/it/hill-cipher.html`
- 问题：加密和解密共用 `process`：它先将内容转大写并删除所有非 A–Z 字符，长度为奇数时追加 X。两字符分组的密文若缺少一位或含输入错误，解密仍会静默补位或删字符并输出结果；Unicode 大写还可能改变原字符，且不能可靠区分原文末尾 X 与补位 X。
- 解决方案：解密前严格检查密文字符和偶数长度，明确提示错误，不在解密时补位；加密时说明支持的字符及补位规则，提示原始末尾 X 的歧义，必要时保留长度元数据。
- 验证建议：测试奇数密文、非法字符、小写、非 ASCII 输入，以及原文明文末尾 X 的往返。
