# KSUID 生成器：时间戳与排序说明错误

## 问题

页面介绍声称前 4 字节是 Unix 秒级时间戳，实际实现存储的是 Unix 秒数减去 KSUID 偏移量 1400000000；直接按页面说明解码会得到错误日期。源码注释还将该偏移量标为 2014-05-13 00:00:00 UTC，实际对应 2014-05-13 16:53:20 UTC。页面同时声称字符串字典序就是生成时间顺序，但时间戳只有秒级精度，同一秒生成的 ID 在时间字段相同后按随机负载排序，并不保证先后顺序。

## 解决方案

更正中英文说明和源码注释：解码时间需将 32 位无符号秒数加回 1400000000，标明 UTC 偏移基准；说明字典序按秒排序、同秒内不保证生成先后。以已知字节和生成实例验证解码日期，以及同秒随机 ID 的排序边界。
