# URL 编解码：基础地址未纳入历史脱敏

- 受影响工具：`tools/it/url-encode.html`
- 问题：通用历史快照遍历所有带 ID 的输入框，仅对 `input`、`parseInput`、`builtUrl` 和 `output` 记录长度；参数构建器的 `baseUrl` 不在脱敏名单中。用户在基础地址输入含凭据或令牌的 URL 后再执行编码，通用历史可能将完整地址写入本地存储。源码静态分析，需实机检查实际存储与清理路径。
- 解决方案：按敏感数据默认不落盘处理基础地址及其他 URL 输入，避免以字段名遗漏绕过；迁移清理已有历史中的明文，并用包含模拟凭据的构建器、编码与历史恢复场景验证。
