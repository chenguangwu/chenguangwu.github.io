# Base 编码文本解码：非 UTF-8 字节被静默替换

受影响工具：`tools/it/base64-converter.html`（首页编辑精选）

文本解码将字节交给默认的 `TextDecoder()`，非法 UTF-8 字节会被替换为 U+FFFD，而不是报错。例如 Base64 `/w==` 表示单个字节 `FF`，文本解码会得到替换字符；再次编码不能还原原字节。编码本身有效，但页面没有区分“有效编码”与“可作为 UTF-8 文本解码”，用户可能误以为数据无损。

解决方案：文本模式使用严格 UTF-8 校验，遇不可解码字节时提示并保留字节结果，提供本地下载或十六进制查看；如提供宽松替换，明确标注不可逆并由用户选择。测试合法中文、空字节、非法及截断 UTF-8、二进制文件、Base32/Base85 和复制下载往返。
