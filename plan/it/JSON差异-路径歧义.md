# JSON 差异：键名中的点和下标导致路径歧义

受影响工具：`tools/it/json-diff.html`

`deepDiff()` 将对象键直接用 `.` 拼接，将数组下标拼成 `[n]`。实测左侧 `{"a.b":1,"a":{"b":1}}`、右侧对应两个值均为 2 时，两个不同字段都输出相同路径 `a.b`，用户无法根据差异列表定位目标；键名含中括号时也有类似歧义。页面引用 JSON Pointer 和 JSON Patch 规范，但实际差异输出使用自定义点路径及 `mod` 等字段，不能直接当成标准补丁。

解决方案：内部保留路径片段，展示时对特殊键使用明确转义，或输出 RFC 6901 JSON Pointer；如提供 JSON Patch，使用标准操作与路径并单独验证，明确区分现有差异列表。测试点号、方括号、斜杠、波浪号、空键、数字字符串和数组嵌套，确保不同节点路径不冲突，复制结果与界面一致；同步修正文档对标准的适用范围。
