# JSON 格式化：无效输入时旧树仍可见

受影响工具：`tools/it/json-formatter.html`（首页编辑精选）

`autoValidate()` 在 JSON 解析失败时设置错误状态和 `lastValidJSON=null`，但没有清空 `viewJson` 或 `treeCopyValues`；之前的树视图仍留在页面，树节点的复制按钮仍能读取旧数据。用户将有效文本修改为无效文本后，可能把旧结果当作当前输入的结果。源码确认，需浏览器验证交互和复制。

解决方案：解析失败时清除或明确禁用旧树、统计及节点复制，显示当前错误；恢复有效输入后重新生成。验证有效→无效→修复→清空，核对树节点、复制、下载、统计和中英文提示，避免泄漏此前输入。
