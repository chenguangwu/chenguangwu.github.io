# CSS 压缩：伪类前空格被删除改变选择器

受影响工具：`tools/it/css-minifier.html`

问题：压缩对所有代码片段统一删除冒号周围空格，未区分声明冒号与选择器中的伪类。输入 `.a :hover { color: red; }` 会输出 `.a:hover{color:red}`，前者选中 `.a` 内被悬停的后代，后者选中被悬停的 `.a` 本身，样式匹配发生变化。

解决方案：使用能识别选择器和声明上下文的 CSS 解析器或可靠分词处理，保留必要的后代组合符；语法无法安全处理时提示而非静默修改。验证 `:hover`、`:is()`、`:not()`、伪元素和嵌套规则，比较压缩前后浏览器实际匹配。

证据范围：已用页面同一压缩正则对上述字符串执行复现；浏览器样式匹配待验证。
