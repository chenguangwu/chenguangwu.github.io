# Polybius 密码：密钥中的 J 被删除

- 受影响工具：`tools/it/polybius-cipher.html`
- 问题：编码明文时将 J 映射为 I，但生成密钥方阵时直接跳过密钥中的 J，而不是按相同规则合并到 I。以 `JABC` 与 `IABC` 为密钥会得到不同方阵，使用者按页面常见 I/J 合并约定与其他工具互通时可能得到不同结果；非 ASCII 字符经过 Unicode 大写也可能改变原密钥。
- 解决方案：明确方阵密钥的 I/J 处理规则并与编码一致，转换或忽略字符时给予提示；展示实际规范化密钥和最终方阵以便跨工具校对。
- 验证建议：比较 `JABC`、`IABC` 与包含非 ASCII 字符的密钥，核对方阵和编码解码结果。
