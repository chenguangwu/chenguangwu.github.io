# 字符编码工具：普通文本触发无效数字拦截

## 问题

结果渲染前对整段生成 HTML 检测 `Infinity` 和独立的 `NaN`，而字符编码属于文本处理。输入 `NaN` 或 `Infinity` 时，这些合法字符串出现在常用 HTML 实体、JS 转义等结果中，导致页面显示“计算结果含无效值”，而不是编码结果。浏览器文本与代码示例中出现这些字符串很常见。

## 解决方案

移除对任意编码文本的数值关键字拦截，仅在涉及实际数值计算时验证数值本身；保留现有结果转义。覆盖独立及嵌入文本中的 `NaN`、`Infinity`，并验证各编码行和复制功能。

## 受影响工具路径

- `tools/it/char-encoder.html`（`convert` 结果输出守卫）
