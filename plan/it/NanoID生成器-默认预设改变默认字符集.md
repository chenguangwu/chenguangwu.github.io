# NanoID 生成器：默认预设改变默认字符集

## 问题

页面初始选择“URL 默认”，字符表包含 64 个字符，含 `_`、`-`。点击“默认参数”预设时，预设写入自定义字符表并触发 input 事件，自动勾选“自定义”；该表只有数字和大小写字母 62 个字符，不包含 `_`、`-`。因此恢复默认后实际生成规则、每位熵和碰撞概率都与初始默认状态不同，且与页面对默认 64 字符表的说明不一致。

## 解决方案

让“默认参数”同时恢复 URL 默认单选项、长度和数量；其他明确使用自定义字符表的预设继续选中自定义。验证从每种字符集切回默认后的选项、字符范围及生成结果，并同步展示当前字符集的熵和碰撞估计。

## 受影响工具路径

- `tools/it/nanoid-generator.html`（字母表选项、`__nanoid_generatorPresets`）
