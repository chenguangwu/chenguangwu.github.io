# Nginx 配置生成器：字段未安全引用或完整校验

**受影响工具路径：** `tools/it/nginx-config-generator.html`

## 问题

域名、静态目录、证书路径及上游地址直接插入 Nginx 指令，未按配置语法检查或引用。带空格的合法文件路径会被拆成多个参数；分号、换行或大括号也可能改变生成的配置结构。页面只做 HTML 转义，不能保证生成配置语法正确。以上根据源码分析，需用本地 Nginx 配置测试复核。

## 解决方案

按各字段语义严格校验，并对允许的路径使用符合 Nginx 语法的引用和转义；拒绝未支持的控制字符及指令分隔符。标明输出需在部署前用 `nginx -t` 检查，覆盖空格路径、特殊字符、域名和代理地址。
