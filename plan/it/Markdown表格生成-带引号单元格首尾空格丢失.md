# Markdown 表格生成：带引号单元格首尾空格丢失

受影响工具：`tools/it/markdown-table-generator.html`

问题：`parseRow()` 对所有解析后的字段执行 `trim()`，`escapeMarkdown()` 和 CSV 导出拆分时也会裁剪空格。即使用户用双引号明确输入带首尾空格的内容，生成和导出仍会静默改变数据。Markdown 表格语法和渲染器对单元格边缘空格有特殊处理，直接保留原始空格也不一定能够保证往返。

解决方案：明确区分 CSV 字段的真实内容与表格分隔符周围的格式空格，针对需要保留的空格设计可逆表示或在界面明确提示不支持无损往返；提供验证数据预览。覆盖带引号的首尾空格、普通字段、连续空格及 Markdown、CSV 导出往返，并核实目标 Markdown 渲染器的表现。

证据范围：本机无头 Chrome、本地文件加载；带引号的表头字段 `" x "` 输出为 `x`。Markdown 渲染器与完整导出往返、HTTP 场景待复核。
