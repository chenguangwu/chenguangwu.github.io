# HTML 嵌套检查器的原始文本与注释解析错误

- 受影响工具：`tools/it/html-nesting-checker.html`
- 问题：最终检查循环跳过 `script`、`style`、`textarea`、`title` 的开始标签，却仍处理其结束标签；例如 `<script>const x = 1;</script>` 会报告多余闭合标签。正则还会把 HTML 注释和脚本字符串内的标签样文本作为真实标签，导致额外误报。以上为源码分析，待浏览器复核。
- 解决方案：使用遵循 HTML 词法规则的解析器或状态机，区分注释、属性值及原始文本区域，成对处理原始文本元素；保留源位置并分别验证脚本、样式、文本域、注释中含尖括号及真实错误嵌套的场景。
