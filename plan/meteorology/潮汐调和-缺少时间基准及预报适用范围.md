# 潮汐调和：缺少时间基准及预报条件

- 受影响工具：`tools/meteorology/analysis-tide.html`
- 问题：只输入四个振幅和迟角，没有日期、时区、站点或相位基准；代码以 `cos(角速度×相对小时−迟角)` 生成从 00:00 开始的曲线，却在标题和 SEO 中称适合航海、港口与海岸工程预报。15 分钟采样极值也只是近似。空值默认 0 或 24，可能掩盖缺失参数。
- 解决方案：先将现有模式明确标为相对时间下的教学模拟，取消适用于航行和工程预报的无依据表述；明确参数基准、有限分潮及采样精度。若后续提供预报，应支持参考时刻、时区、站点调和常数和必要天文改正，并由潮汐专业人员核验；校验必填项与振幅范围。
