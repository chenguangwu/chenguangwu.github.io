# 空气质量 AQI：缺测被当作零并产生确定结论

- 受影响工具：`tools/meteorology/air-aqi.html`
- 问题：`getNum()` 将空值转换为 0；负值则被排除，但页面仍以其余数据计算完整 AQI。清空全部输入会显示 AQI 0、空气质量优。首要污染物只保留第一个最大值，未表达并列或低指数时的判定条件；超表上限直接显示 500，未说明超限。
- 解决方案：区分零、缺测和非法值，说明监测数据完整性对结果的影响；分别展示各污染物 IAQI、并列首要污染物及超限提示。按适用的 AQI 标准核验取整、时均值和首要污染物规则，并补充对应边界例子。当前为源码分析，标准细节待专业核验。
