# N-back 自适应难度变化后仍按旧规则评分

- 受影响工具：`tools/cognition/nback-training.html`
- 问题：训练开始时按初始 N 一次生成所有试次及匹配标记；自适应模式中 N 升降后，界面提示使用新 N，但后续仍以初始 N 的匹配标记计分，命中率、正确率及难度调整可能错误。触发调整的试次还在调整后才记录 N，明细中的 N 也可能与该试次实际规则不符。以上为静态代码分析，运行复现待补。
- 解决方案：按每个试次开始时的 N 增量生成刺激和判定标记，固定记录该试次使用的 N，再在结束时调整下一试次难度；验证升、降级后位置和声音通道的匹配、计分与历史明细一致。
