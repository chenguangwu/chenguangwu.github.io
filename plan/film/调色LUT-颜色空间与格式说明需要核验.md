# 调色 LUT 参考表需要明确适用条件

- 受影响工具：`tools/film/color-grading.html`
- 问题：页面把 1D LUT 描述为固定 1024 级、3D LUT 描述为固定 33³ 或 65³，并将 sRGB→DCI-P3 列为 1D 转换；色彩空间表也把 Rec.2020 与 PQ/HLG 固定关联。这些写法容易把常见配置理解为唯一规格，且不同色域之间的转换是否能由每通道独立 1D 映射完成需要专业核验。
- 解决方案：依据公开色彩标准与 LUT 格式文档逐条核查维度、采样、色域和传递函数的关系；将常见配置标为示例，明确实现和工作流限制，避免把参考表作为可直接套用的转换配置。
