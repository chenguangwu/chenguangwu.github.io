# 租售比计算：添加对比时零费用变成默认费用

受影响工具：`tools/finance/rental-yield-calculator.html`

单套计算读取费用时使用 `|| 0`，但“添加房产”调用的 `addCompare()` 对物业费、取暖费、装修费、维修费和税费使用 `||` 加非零默认值。例如将物业费设为 0 后加入对比，会记录为 300；其他上述费用也分别变成默认费用。0 租金或房价亦被非零值替换。这样同一套输入的对比结果可能与单套计算不一致。源码已确认，需在浏览器核对实际表格数值和保存行为。

解决方案：共用单套计算的统一输入解析与校验，保留合法 0，未填和非法输入按明确规则提示；比较卡片显示参与计算的参数，避免静默替换。逐个验证各项费用为 0、正常非零值、空值，以及单套结果与对比卡片一致；核查历史、复制和导出。
