# 词频统计：最小词长和占比口径错误

## 问题

英文分词分支只检查 `key.length < 1`，没有应用用户选择的最小词长；设置最小长度为 3 时，`a cat` 中的 `a` 仍被统计。词条百分比以展示的 Top N 总次数为分母，Top N 改变会改变同一词的占比，而汇总指标以全部词次为分母，容易误解。

## 解决方案

英文按所选最小词长过滤；中文明确目前采用固定长度的重叠字串而非真正的分词，并考虑提供词语分词模式。词条占比统一使用过滤后全部词次，或明确提供两种分母及说明；覆盖改变 Top N、最小长度和中英文混合输入的测试。
