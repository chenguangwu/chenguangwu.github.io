# 折扣计算器：反向边界和功能介绍不准确

受影响工具：`tools/finance/discount-calculator.html`

## 问题描述
反向计算只接受大于 0 的折扣，但错误提示写“0–10 折”，未解释 0 折无法唯一反推原价。页面及 SEO 介绍还称可以“一键回填到含税反向计算”，实际三个模式通过 `setMode()` 重建输入并使用默认值，没有回填当前结果的操作。

## 解决方案
反向模式说明折扣范围为大于 0 至 10 折，并解释 0 折时原价无法唯一确定；提供明确的折后价转入税务计算操作，或在实现前修正中英文介绍、SEO 和结构化数据。验证两种税务方向以及切换时的数据保留。
