# 单词顺序反转：标点固定和字符完整性

## 问题

按空格分词时标点与单词粘在同一 token，“保留标点位置”仅对独立的标点 token 生效。例如 `hello, world!` 反转后标点跟随单词移动，与选项含义不符。逐字符模式使用 `split('')`，会反转 emoji 的 UTF-16 代理项并破坏字符。

## 解决方案

将单词、空白和标点分开识别并固定标点位置；明确标点与空白的处理规则。逐字符模式按字素簇反转并提供兼容回退，验证中英文标点、emoji 和组合字符。
