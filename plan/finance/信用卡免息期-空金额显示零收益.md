# 信用卡免息期：空金额或收益率显示零收益

受影响工具：`tools/finance/credit-card-grace-period.html`

`num()` 将无法解析的值统一返回 0，`calcTool()` 不检查消费金额或收益率是否为空，因此清空任一输入后仍输出“资金收益 ¥0”等数值；附加数据表对空值却会提前返回，可能留下与主结果不同步的旧数据。0 金额与 0 收益率是有效的数值，不能当成未填写。

解决方案：区分空值、非法值和合法的 0；可独立计算的账单日期结果与依赖金额/收益率的结果分别明确状态，依赖字段未填写时不输出收益结论，并清理旧表格和导出内容。验证有效输入→清空→输入 0→恢复，以及中英文、数据表、图表和历史同步。
