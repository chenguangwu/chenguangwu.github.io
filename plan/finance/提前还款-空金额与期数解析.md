# 提前还款：空金额被当作零，期数被截断

受影响工具：`tools/finance/mortgage-prepayment.html`

`calc()` 以 `parseFloat(prepay.value) || 0` 读取提前还款额，因此清空该字段后会当作“提前还款 0 元”计算并展示节省结论；显式输入 0 是合法的另一种状态。剩余月数使用 `parseInt` 后只检查大于 0，例如 `12.5` 会被当作 12，科学计数法 `1e2` 会被当作 1，未提示用户输入已改变。需浏览器复核输入控件和结果区。

解决方案：区分空值与数值 0，对未填金额提示或提供明确“本次不提前还款”的选择；以完整数值解析月数并验证有限正整数和合理计算范围，不静默截断。测试空值、显式 0、小数、科学计数法、普通整数、无效值及恢复输入，核对结果、图表和导出一致。
