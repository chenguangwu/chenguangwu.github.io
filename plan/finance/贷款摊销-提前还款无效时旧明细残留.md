# 提前还款无效时旧明细残留

## 受影响工具路径
- `tools/finance/loan-amortization.html`

## 问题描述
先计算一笔有效提前还款，再将提前还款金额改为 0 或期数改为越界值，结果区提示错误后立即返回，但 `scheduleData`、表格和图表仍保留上一次提前还款方案；导出使用的也可能是旧方案。已用页面原函数及 DOM 桩确认 `scheduleData` 未重置，表格和导出应在真实浏览器进一步验证。

## 解决方案
无效状态下清空提前还款方案，或恢复原始还款计划并明确标注；统一结果、图表、表格与导出的数据来源。覆盖有效到无效再恢复有效的切换。
