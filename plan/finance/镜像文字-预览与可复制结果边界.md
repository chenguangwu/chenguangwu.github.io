# 镜像文字：预览与复制结果差异

## 问题

页面的真实视觉镜像使用 CSS `scaleX(-1)`，复制按钮复制的却是另一套有限字符映射结果。未收录的中文等字符只改变顺序而不镜像字形，与预览图不同；页面没有提供预览图下载，SEO 文案却将结果称为可复制字符或预览图，用户用于水印时难以得到预期效果。

## 解决方案

明确区分字符近似替换与视觉镜像预览，标识不支持的字符和复制后的差异；增加纯前端图片导出并处理多行、透明背景和分辨率。同步修正中英文搜索描述及示例，验证中文、英文与 emoji。
