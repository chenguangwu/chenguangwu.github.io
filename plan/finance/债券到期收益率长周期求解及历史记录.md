# 债券到期收益率长周期求解及历史记录

受影响工具：`tools/finance/bond-yield-calculator.html`。

## 问题

附息债到期收益率求解固定用接近 -100% 的每期利率作为下界，并在下界现值溢出时直接判无解。面值和价格均为 1000、票息 5%、剩余 30 年、半年付息的普通平价债券，本应得到名义年收益率 5%，但 60 期下界现值溢出导致结果为 NaN。保存该结果时 JSON 将 NaN 转为 null，历史记录随后对 null 调用 `toFixed()`，可能导致整段历史无法显示。

## 解决方案

调整求解边界与现值计算，允许表示现值趋于正无穷的有效下界，保持负收益率场景可求解；对无法求解的结果阻止保存或保存明确的失败状态，历史展示兼容已有异常记录。覆盖平价长债、负收益率及异常历史数据。
