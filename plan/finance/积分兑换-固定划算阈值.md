# 积分兑换：固定阈值与用户实际兑换选项脱节

受影响工具：`tools/finance/points-redemption-value.html`

页面按每万分净价值固定分段给出“很划算 / 较划算 / 一般 / 偏亏”，并展示通用兑换渠道价值，但没有选择积分项目、实际可兑换选项或这些参考值的来源及有效期。不同积分体系的单位价值和可用范围不同，仅凭固定绝对阈值可能让用户把示例判断当成实际兑换建议。净价值公式仍可作为计算结果展示。

建议让用户输入两个或更多可选兑换方案（积分、补差价、实际现金价格），展示每万分净价值与差额；默认把固定阈值标为示例或允许自定义，并解释比较仅适用于相同积分体系、未计机会成本和限制。所有数据本地计算，不接实时价格。验证零补差、价格低于补差、不同积分量、同值和空值，以及中英文文案。
