# 折扣计算器：历史记录缺少折扣链与税务方向

受影响工具：`tools/finance/discount-calculator.html`

## 问题描述
通用快照只采集有 id 的输入，折扣链输入和税前／税后单选框没有 id，当前模式也未记录。因此历史不包含完整计算条件。恢复时还会取消未记录的单选按钮，再调用 `calc()`；税务模式的 `querySelector(...:checked).value` 可能因无选中项报错，而恢复逻辑吞掉异常。此为静态代码分析，需复核实际交互。

## 解决方案
为历史明确保存模式、完整折扣数组、金额、税率及税务方向，恢复时先切换模式再填值并计算；兼容旧记录并提示缺失字段。以多级折扣和两种税务方向跨模式往返验证。
