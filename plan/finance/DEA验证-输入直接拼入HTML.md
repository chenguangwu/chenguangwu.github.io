# DEA 验证：用户输入直接插入 HTML

## 问题

`validate()` 在验证长度和格式前，把未经转义的 `raw` 放入 HTML 模板并赋给 `innerHTML`。输入含标签时，错误结果仍会解析这些标签；例如输入 `<b>TEST</b>`，输出的输入回显会出现加粗元素，恶意事件属性也可能执行，存在脚本注入风险。

## 解决方案

用户输入用 `textContent` 输出，或在拼接前统一 HTML 转义；所有错误分支也必须遵守。验证普通 DEA 号码、无效长度及含标签、事件属性的输入，确保结果仅作为文本显示。
