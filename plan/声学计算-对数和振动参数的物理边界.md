# 声学计算：明确对数和振动参数的边界

- 受影响工具：`tools/acoustics/sound-intensity-level.html`、`tools/acoustics/sound-intensity-spherical.html`、`tools/acoustics/sound-pressure-level.html`、`tools/acoustics/mass-law-tl.html`、`tools/acoustics/spring-natural-freq.html`、`tools/acoustics/string-fundamental.html`、`tools/acoustics/reverberation-time.html`
- 问题：计算路径直接对输入取对数、开方或作除数，未看到完整的物理边界校验。零或负的声功率、声压、频率、面密度、弦长、线密度、质量及吸声量等可能生成非有限值或无物理意义的结果；混响页 `60/(T||1)` 还会把零混响时间的未定义衰减速率替换成 60。
- 解决方案：按各公式分别限定物理参数和模型条件，区分允许的零值与对数为负无穷、分母为零等未定义结果；显示可理解的提示而非虚构值，并用典型值、零和负值验证。
- 依据：静态阅读各页 `calcTool()`；公共输入守卫和实际显示需在实施时复核。
