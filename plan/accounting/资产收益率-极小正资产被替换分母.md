# 资产收益率：极小正资产的小数结果使用不同分母

## 问题

资产大于 0 时，主结果中的 ROA 百分比和万分比使用实际资产作分母，而小数形式使用 `Math.max(资产, 1e-9)`。资产在 0 与 1e-9 之间时，三个结果不再等价。例如净利润和资产均为 1e-10 时，百分比为 100%，小数却为 0.1。辅助表则使用实际分母。以上为静态算例。

## 解决方案

对有效非零资产统一使用真实分母，明确数值精度与极小值的显示策略；覆盖极小正数、零资产和普通输入，校验小数、百分比、万分比及明细一致。
