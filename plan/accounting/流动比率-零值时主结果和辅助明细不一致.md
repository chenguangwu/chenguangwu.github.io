# 流动比率：合法零值时主结果和辅助明细不一致

## 问题

主结果对流动资产或流动负债为 0 的比值显示「—」，但辅助明细对相同分母直接除法，并将流动比率写入历史。例如流动资产 100、流动负债 0 时，主结果为未定义，而明细计算 `100/0`、历史记录 `Infinity`；流动资产为 0 时负债占比也直接除以零。明细中的「流动比率倒数」行还把值和标签的顺序写反。以上为静态检查，需复核实际显示和导出。

## 解决方案

对每个分母分别判零，主结果、明细、历史与导出统一显示未定义并说明原因；无定义的数值不作为有限指标参与历史比较。调整明细行顺序，并验证两项分别为零及同时为零。
