# 速动比率：零资产或零负债时结果不一致

## 问题

当流动资产与存货均为 0、流动负债大于 0 时，主结果仍直接计算「流动负债÷流动资产」和「存货占流动资产比」，分别得到 `Infinity` 和 `NaN`，而辅助表对同样分母显示「—」。流动负债为 0 时主结果指出比率无定义，但辅助缺口分析仍把该情形当作达到 1.0 目标并显示安全垫，还继续用零负债计算仪表值。以上为静态检查，实际呈现需复核。

## 解决方案

对各指标的分母分别判零，主结果与明细统一显示无定义及原因；流动负债为 0 时不作比率达标或安全垫结论，不绘制无定义仪表值。覆盖零资产、零负债、两者均为零和正常输入。
