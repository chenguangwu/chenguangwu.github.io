# 世界时钟：城市搜索缺少同区常见城市别名

- 受影响工具：`tools/life/world-clock.html`
- 问题：搜索只匹配城市中文名、国家中文名和时区 ID。中国大陆时区条目标记为“北京”、ID 为 `Asia/Shanghai`，输入中文“上海”无法匹配；印度时区标记为“孟买”，输入“新德里”也无法匹配。用户可能误以为工具不支持这些城市。
- 解决方案：为同一时区增加常见城市中英文别名及拼音检索，展示城市与时区映射，不重复创建错误时区；提供无搜索结果提示和替代建议。测试中文城市、英文名、时区 ID 和无匹配输入。
- 验证：源码中的城市表和搜索条件已核对，需浏览器验证搜索与语言切换。
