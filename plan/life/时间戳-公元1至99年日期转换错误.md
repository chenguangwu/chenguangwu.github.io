# 时间戳：公元 1 至 99 年日期转换错误

- 受影响工具路径：`tools/life/timestamp.html`
- 问题描述：日期转时间戳使用 `new Date(year, ...)` 或 `Date.UTC(year, ...)`；JavaScript 会将 0 至 99 的年份解释为 1900 至 1999。因此输入公元 0001 年等日期时，计算结果会落在 1901 年，而非输入年份。
- 解决方案：采用显式设置完整年份的方式构造日期，同时保留所选时区和日期校验；验证本地、UTC、固定偏移下的 0001、0099、0100 年和闰日边界，并确认浏览器日期控件的可输入范围。
