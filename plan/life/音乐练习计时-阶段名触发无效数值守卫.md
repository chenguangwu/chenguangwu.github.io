# 音乐练习计时：阶段名称触发错误提示

- 受影响工具：`tools/life/music-practice-timer.html`
- 问题：自定义阶段名称可以包含普通英文，但渲染阶段列表后，代码对整个 HTML 字符串检查 `Infinity` 和独立单词 `NaN`。例如输入 `Infinity Etude`，列表被替换为“计算结果含无效值”，无法正常查看阶段。
- 解决方案：对阶段时长等数值直接校验有限性，不在包含用户名称的 HTML 中匹配数值文本；同时按已有任务处理阶段名称的 HTML 转义。
- 验证建议：分别添加 `Infinity Etude`、`NaN Study` 和普通阶段，检查列表及计时流程；测试非有限时长仍有明确错误提示。
