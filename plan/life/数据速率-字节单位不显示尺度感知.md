# 数据速率：字节单位无法显示尺度参照

- 受影响工具路径：`tools/life/data-rate-converter.html`
- 问题：主换算支持 Bps、KBps、MBps 和 GBps，但尺度感知脚本的换算表仅包含 bps、kbps、Mbps 和 Gbps。选择任何字节单位时，脚本直接清空参照区域，导致同一速率以不同单位输入时体验不一致。
- 解决方案：尺度参照复用主换算的完整单位系数，明确区分 bit 与 byte，避免两套单位表再次漂移；错误或空值仍应清除旧参照。
- 验证建议：分别输入 1 MBps 与 8 Mbps，确认主结果和尺度参照相同，检查其余字节单位和切换单位后的状态。
