# 饮水计划：无效体重仍生成明细与历史

- 受影响工具路径：`tools/life/drinking-water-plan.html`

## 问题描述

主计算遇到体重为 0 或负数会显示错误并返回，但外层包装仍调用 `__drinking_water_planExtras()`，该函数只检查体重是否为有限数，没有复用正数校验。因此输入 0 kg 并计算时，主结果提示错误，明细和历史仍可能记录按零体重得到的饮水目标；导出也可包含这些无效结果。

## 解决方案

统一主结果、历史、明细与导出的输入校验和计算数据来源；无效时清除旧明细并禁止记录及导出，保留明确提示。验证零、负数、空体重以及从有效值改成无效值后查看历史和导出。
