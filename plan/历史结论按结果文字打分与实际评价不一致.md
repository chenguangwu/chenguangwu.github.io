# 历史结论按结果文字打分与实际评价不一致

- 受影响工具：`tools/agriculture/seed-germination-rate.html`、`tools/machinery/calc-strength.html`
- 问题：这两个页面的历史表通过截取结果前 80 字并搜索「失败」「错误」等词生成「通过／未通过」，没有读取实际业务判定。例如发芽率的质量等级可为「不合格」，轴强度可显示「不安全」，均未匹配评分词，历史表可能仍标为「通过」。这是静态代码分析，需浏览器复验；类似附加历史模板还需逐页排查。
- 解决方案：由各工具直接提供结构化的计算有效性和业务评价，分别命名和展示；对无业务合格标准的工具取消「通过」及二值趋势。覆盖不合格、不安全、无效输入以及历史恢复与 CSV 导出。
