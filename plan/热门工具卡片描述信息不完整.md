# 热门工具卡片描述信息不完整

## 问题

首页等入口使用的热门工具数据中，多条英文描述在源文本内就以省略号截断，例如 JSON 格式化、Base64 和正则工具；放宽显示空间也无法读到完整句子。部分中文描述只重复工具名称，难以帮助用户判断功能和特色。静态检查显示 `json/hot-tools.json` 的 81 条精选项目中有 70 条英文描述以省略号结尾；精选不代表访问量。

## 解决方案

追溯描述的数据源和生成逻辑，保存完整且准确的中英文描述，突出实际功能和本地处理等特点；视觉空间不足时通过样式限行并提供完整描述的访问方式。对照工具实际能力验证文案。

## 受影响工具路径

- `tools/it/json-formatter.html`
- `tools/it/base64-converter.html`
- `tools/it/regex.html`
- 其他使用热门工具数据的工具页面，需逐条核实。
