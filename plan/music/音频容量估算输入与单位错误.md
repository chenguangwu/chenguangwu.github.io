# 音频容量估算输入与单位错误

- 受影响工具：`tools/music/audio-converter.html`
- 问题：仅全部清空才提示，单项清空或填 0 会静默使用默认值，负值还可得到负容量。PCM 按二进制字节除数计算却标为 MB，MP3/AAC 将十进制 kbps 的结果除以 1024 后也标为 MB，单位口径混杂；320 kbps、180 秒应约为 7.2 MB 或 6.87 MiB，页面约为 7.03 MB。
- 解决方案：逐项校验必填值和物理范围，明确合法零值的语义，非法时清除结论；统一采用十进制 MB 或明确的 MiB，并正确换算码率及容器开销。用上述算例和空值、负值验证。
