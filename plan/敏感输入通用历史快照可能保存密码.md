# 敏感工具：通用历史快照可能收集密码明文

受影响工具：`tools/it/bcrypt.html`、`tools/life/detector-checker-strength.html`；后者另有单工具任务。

## 问题描述
上述页面的通用快照收集所有带 id 的输入，并只排除 button、submit 和 hidden，未排除密码字段；结果非空时记录对象会交给 `TBKit.history.record`，该方法将完整对象写入本地存储并供历史表使用。bcrypt 的哈希计算是异步流程，实际触发条件和界面、导出表现需用虚构密码在浏览器复核。密码检测页可能在键入时记录。单靠密码输入框的掩码不能保护已写入的明文。

## 解决方案
为敏感工具禁止收集密码、密钥、令牌和其他保密输入及结果，覆盖输入类型被切换为 text 的情况；公共历史机制采用明确的安全白名单而非仅按 input 类型判断。审计表格、导出、恢复与统计采集，设计既有记录的安全清理，并用虚构数据验证存储和所有展示路径。

## 验证

用虚构密码对页面原始快照函数及 `js/tool-kit.js` 原始历史记录函数进行隔离模拟，两页快照均包含明文，写入模拟存储后均可检索到明文；这验证了数据流，完整浏览器事件、页面显示及导出仍待复核。
