# 银行工具英文简介退化为工具名

## 问题描述

多个银行工具的英文预渲染简介只有工具名或文件名式短语，例如季度复利存款为 “Fd Quarterly”，储蓄目标为 “Savings Goal Monthly”。这些简介没有说明输入、计算结果或适用前提，英文用户和搜索引擎难以了解工具用途；对应行业正文词典也采用相同短语。以上为源码及词典静态核查，其他翻译层对运行态的覆盖仍需复核。

## 解决方案

按各工具实际功能撰写自然英文标题和完整简介，说明主要输入、输出及关键模型假设；同步核对各翻译层、静态内容与搜索描述，验证英文运行态不被旧词条覆盖。
