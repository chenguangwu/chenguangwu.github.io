# 圆曲线工具在极小转角下发生数值消减

## 问题

圆曲线、中点垂距、弦长和外距工具使用 `1 - cos(Δ/2)` 或 `1 / cos(Δ/2) - 1` 计算垂距和外距。极小转角时余弦会因浮点精度舍入为 1，使原本非零的结果被算成零；例如 Δ=0.000001° 时，JavaScript 的 `1 - Math.cos(Δπ/360)` 为 0，而等价的 `2 * Math.sin(Δπ/720) ** 2` 约为 3.8077e-17。半径较大时误差可在显示精度内放大；中点垂距表的 M/E 比值也可能变为 NaN。上述算例在本地 Node 中验证，实际浏览器表格仍需复核。

## 解决方案

采用半角正弦平方等数值稳定形式计算垂距，再结合余弦求外距；对接近奇点的角度明确限制或提示，并避免有效比值因中间消减而失效。用小转角、大半径及普通角度算例对照高精度结果，统一主结果和辅助表。
