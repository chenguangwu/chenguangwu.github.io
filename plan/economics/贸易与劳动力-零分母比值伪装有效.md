# 贸易和劳动力：零分母比值伪装为有效数值

## 问题描述
贸易差额页面的出口进口比在进口为 0 时使用 `1e-9` 代替分母；出口为 0 时差额占出口比也这样处理。劳动力页面就业和失业均为 0 时显示失业率与就业率均为 0%，失业为 0 时就业失业比又显示极大数。这些比率原本不可计算。

## 解决方案
各指标分别使用真实分母，零分母显示不可计算及原因；总额与差额等仍可计算的指标正常展示。补充零进出口、零劳动力和零失业场景，并检查导出。
