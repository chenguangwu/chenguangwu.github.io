# 奥肯定律：系数表述冲突及零基准比值

## 问题描述
主计算使用 `Δu=-0.5(g−g*)`，公式引据却在同一方向的公式里写 β 常取 2；正文又称系数 2 并用 0.5 计算，FAQ 写“经典约 −2”。这些系数对应方向未交代清楚，容易产生四倍的误读。潜在增长率为 0 时，“相对增长缺口”把分母替换成 1，仍给出百分比。

## 解决方案
统一写明回归方向、单位和示例系数，若引用反向系数应明确其定义；支持用户调整经验系数并提示地区、时期差异。零基准下相对比值显示不可计算，增长差额和失业率变化正常展示。
