# 成本售价互算：空加价率当零及负值边界

## 问题描述

求售价或成本模式下，清空加价率会被 `num()` 转成 0 并直接给出结果，无法区分未填和明确零加价。HTML 的最小值不等于业务校验：代码未检查加价率下界，输入 −100% 时求成本分母为零、求售价为零且利润率分母为零；小于 −100% 还可得负价格或成本。静态分析，浏览器提示与结果待复核。

## 解决方案

对当前模式所需字段区分空值和合法的 0，明确加价率是否允许负数及其取值边界；遇到分母为零或不符合业务定义时停止计算并提示。覆盖空值、零、−100%、更小负值及正常正值。
