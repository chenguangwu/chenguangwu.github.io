# 转化漏斗：空人数当零及校验后旧图表

## 问题描述

各阶段人数编辑时以 `+this.value` 转换，清空某阶段会变成 0 并继续参与漏斗；若后续人数也为 0，无法区分未填和真实零人。人数允许小数，却在表格中四舍五入为整数而按原小数计算比例，展示和计算可能不一致。发生负数或阶段人数递增等校验错误时，主漏斗和表格清空，但 `funnelChart` 没有清空，可能保留上一组图表。静态分析，交互待复核。

## 解决方案

保留输入空状态，按人数或数量的实际口径校验整数与非负值；清空或无效时同步清除漏斗、摘要、表格及图表，恢复有效值后重算。覆盖中间阶段清空、真实 0、小数、递增错误和修正恢复。
