# 目标分解：尾差集中扣减产生负目标

## 问题描述

每人成果先四舍五入到两位小数，再把全部尾差加到最大项。总目标 0.03、6 人均分时，每人初始四舍五入为 0.01，尾差 −0.03 集中扣在一人后形成 −0.02，其余为 0.01；总数虽然吻合，却分配出负目标。独立 Node 算例已复现算法，界面及导出待浏览器复核。单位为“个/单”时仍按两位小数分配，是否允许拆分也未说明。

## 解决方案

采用按最小单位分配的非负余数算法，逐项分摊尾差并保证合计一致；按金额与“个/单”区分精度及整数约束。覆盖小总额、多成员、零权重及整数单位，校验页面、图表和导出一致。
