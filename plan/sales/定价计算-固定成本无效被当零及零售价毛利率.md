# 定价计算：固定成本无效被当零及零售价毛利率

## 问题描述

固定成本为空或负数时被静默替换成 0，目标利润定价和平衡销量因此可能低估。售价为 0 时，毛利率分母为 0，页面却显示 0%；例如单位成本为 10、竞品价为 0，单位毛利为 −10，但毛利率显示 0%。成本占比图也将亏损情形裁剪成成本 100%、毛利 0%，无法体现负毛利。静态分析，界面待复核。

## 解决方案

区分未填写、合法零和负固定成本，提示需修正的输入；零售价时显示毛利率无定义。亏损时明确标示负毛利及成本超过售价，避免截断图形掩盖亏损。验证空成本、负成本、零售价及售价低于成本。
