# 叠加折扣：减额负值和空字段仍参与计算

## 问题描述

折扣比例有范围检查，但满减金额和门槛没有对应业务校验；负减额会使计算后的价格增加，负门槛也可能触发优惠。编辑框清空时通过 `+this.value` 变成 0，折扣率清空后可被当成 0 折，产生免费结果。导出复用相同口径。静态分析，浏览器交互待复核。

## 解决方案

保留原始输入状态，对启用的每层优惠严格校验空值、有限数和非负范围；错误时清除旧结果并禁止导出，明确 0 折与未填不同。覆盖空折扣率、负减额、负门槛、合法零和修正恢复。
