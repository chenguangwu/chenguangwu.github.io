# 银行计算工具：极小利率导致年金与月供精度丢失

- 受影响工具：`tools/banking/present-value-annuity-due.html`、`tools/banking/future-value-annuity-due.html`、`tools/banking/emi-loan.html`。
- 问题：公式直接计算 `1+r` 的幂再与 1 相减。极小正利率时浮点舍入使差值归零；按源码公式在 Node 中复现，每期 1000、利率 `1e-17`、12 期的两种年金结果均为 0，合理极限约 12000；本金 500000、年利率 `1e-14%`、30 年的月供成为 Infinity。实际页面输入及图表表现仍需浏览器复核。
- 解决方案：用 `log1p`、`expm1` 或经过误差分析的近零展开计算，统一主结果、对照项及图表；覆盖零利率和极小正利率连续性，并检测非有限结果。
