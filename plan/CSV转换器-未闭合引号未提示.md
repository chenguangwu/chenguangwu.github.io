# CSV 转换器：未闭合引号被静默转换

受影响工具：`tools/it/csv-to-json.html`、`tools/it/csv-to-yaml.html`、`tools/it/csv-to-html-table.html`。

三个解析器读到文件末尾时不检查引号状态。将 `a,b\n"x,y\nz,w` 分别交给页面原解析函数，均把后续两行吞为一个字段而不报告未闭合引号；用户可能误以为转换成功且结果完整。已通过隔离 JavaScript 环境验证解析结果，三个页面的可见提示和导出链路仍需实机核验。

解决方案：在转换前检查引号状态和字段边界，指出未闭合字段起始行及原因；默认停止输出成功结果，若提供宽松修复应明确提示并由用户选择。用合法字段内换行、转义引号、不同分隔符、首尾空字段与多种行结束符测试，不得把合法多行 CSV 当成损坏数据；同步验证预览、复制、下载和中英文提示。
