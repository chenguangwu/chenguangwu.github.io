# 瓦楞抗压参数校验与输入名称

**受影响工具路径：** `tools/packaging/strength-11.html`

## 问题描述

1. 页面只校验必填、有限数及厚度非零，没有拒绝负边压强度和负厚度。输入 ECT = -6、厚度 = 2.5 可得到负抗压强度；厚度为负时平方根无实数意义，结果被替换成破折号而非提示修正参数。
2. ECT 与纸板厚度输入框的 `aria-label` 分别是「楞型」和「强度」，与可见标签不一致；读屏用户可能误解参数。两项不同单位之间还有「互换 A/B」按钮，易误操作。

## 解决方案

对 ECT 和厚度分别检查正数及有限值，错误时阻止计算并清除旧结论；校正无障碍名称，移除或重新设计不同物理量之间的互换操作。覆盖负数、零、正常值及读屏标签。
