# PDF 合并和拆分：内部页面跳转目标可能失效

- 受影响工具路径：`tools/office/pdf-merge.html`、`tools/office/pdf-split.html`

## 问题描述

两个工具新建文档并复制页面。使用项目内 PDF 库构造两页 PDF 并按相同方式复制后，第一页内部链接目标引用与输出页树中的第二页引用不一致，可能导致页内跳转失效。该验证确认了引用不匹配，实际阅读器行为还需复核；书签丢失任务不涵盖页面内链接。

## 解决方案

在输出时按页映射修正内部链接目标，并明确拆分后目标页不在结果中时的处理；使用不同 PDF 阅读器验证重排、重复页面、未选目标页及外部 URL。
