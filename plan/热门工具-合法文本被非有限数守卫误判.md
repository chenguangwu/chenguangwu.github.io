# 热门工具：合法文本被非有限数守卫误判

## 问题描述

部分页面对整段生成的 HTML 字符串搜索 `Infinity` 或独立的 `NaN`，将命中当作无效计算结果。这些词也可以是合法的用户文本，而不是数值异常。

- `tools/it/json-formatter.html`：隔离执行页面原渲染函数，合法 JSON `{"title":"Infinity War"}` 和 `{"title":"NaN"}` 均显示“计算结果含无效值”。
- `tools/it/json-diff.html`：左右及合并行视图对包含用户 JSON 的渲染字符串执行相同守卫；包含 `Infinity` 的字符串会触发错误提示，需浏览器复核各视图。
- `tools/it/regex.html`：匹配结果和高亮文本执行相同守卫，用户输入或匹配文本含 `Infinity` 时可能被错误替换成提示，需浏览器复核。

静态扫描约 1,071 个工具页包含同形守卫，其中首页编辑精选 51 个；不少守卫只处理固定文本或数值，不能直接把候选数当作缺陷数。

## 解决方案及验收

在数值计算边界检查原始数值是否有限，不扫描包含用户文本的整段 HTML；保持安全转义。验证普通文本、`Infinity`、`NaN`、实际非有限计算、各视图及中英文提示，并逐页复核其余候选。
