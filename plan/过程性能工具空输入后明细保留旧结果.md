# 过程性能工具空输入后明细保留旧结果

**受影响工具路径：** `tools/process/pp-index.html`、`tools/process/ppk-index.html`

## 问题描述

先输入有效数据生成明细，再清空一个必填输入。主计算显示填写提示，但两个页面的 `__pp_indexExtras()` / `__ppk_indexExtras()` 遇到非有限输入直接返回，不清除之前的明细表；Pp 页的曲线也不会清除。导出函数仍指向该明细，用户可能将旧数据当成当前输入结果。上述行为来自代码路径，需在浏览器中复核导出的实际内容。

## 解决方案

集中管理输入有效性，失效时同步清除明细和图表并禁用导出；恢复有效输入后重算所有结果。验证有效→清空→导出→重新输入的连续操作。
