# 世界时区转换跨本机夏令时偏差

## 受影响工具路径
- `tools/travel/world-timezone-converter.html`

## 问题描述
代码先依据目标和本机当前偏移改变时间戳，再以本机时区格式化这个新时间戳；如果新时间戳跨越本机夏令时切换，会再次叠加偏移变化。将本机时区设为 `America/New_York`，输入 2026-03-08 01:30，页面算法输出东京 16:30，而同一时刻用浏览器 Intl 直接格式化东京为 15:30。按页面相同算法的 Node 时区测试复现，实际浏览器界面待核验。

## 解决方案
保持同一个真实时间戳，以目标 IANA 时区的 `Intl.DateTimeFormat.formatToParts` 直接生成日期、时间和跨日差；对本机不存在或重复的夏令时本地时间明确提示。覆盖两次切换前后、跨日、半小时及非夏令时地区；表格和导出复用同一结果。
