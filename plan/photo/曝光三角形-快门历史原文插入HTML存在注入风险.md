# 曝光三角形快门历史原文插入 HTML 存在注入风险

- 受影响工具：`tools/photo/calc-exposure-aperture.html`
- 问题：快门输入为文本，解析采用 `parseFloat`，以数字开头的额外内容仍可能通过校验；保存历史时保留快门原文，渲染历史时 `h.shutter` 直接拼接到 `innerHTML`，没有像时间和 EV 一样转义。输入包含 HTML 时存在本地页面注入风险；需用无害样例在浏览器复核。
- 解决方案：严格解析完整快门字符串，历史显示使用文本节点或统一转义，兼容已经保存的旧记录；用普通分数、非法后缀与无害 HTML 文本检查计算、刷新、恢复和历史渲染。
