# 保密自查：英文名称与简介存在占位词

## 问题

英文卡片名称和描述数据使用“Checker Manager Training Hr”等由文件标识拼成的占位词，工具页初始英文简介也是同一短语，不能说明保密协议、培训和检查功能。单页英文词典虽包含较完整的正文译文，卡片及初始 HTML 文案仍不准确。静态检查发现，实际语言切换还需浏览器复核。

## 解决方案

在英文卡片、标题、简介及相关字典中使用准确且一致的保密管理名称和具体功能描述；核对中英文默认态、动态切换及 SEO 元数据。

## 受影响工具路径

- `tools/admin/checker-manager-training-hr.html`
