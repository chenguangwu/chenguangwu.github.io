# 文件版本管理：版本格式与建议版本未校验

## 问题

页面宣传支持语义化版本号，但新增版本只检查非空，解析使用 `parseInt` 和零值回退，非法格式或带前缀的内容仍可保存，下一建议版本可能由错误数字生成。建议版本仅取最近新增记录，手工录入较低版本或删除最新记录后不一定符合用户对最高版本的预期。静态代码分析发现。

## 解决方案

明确支持的 SemVer 范围并严格验证，提示重复与非法版本；规定建议版本的基准并处理删除或手工输入后的刷新。测试正常版本、预发布标识、非法输入及版本回退。
