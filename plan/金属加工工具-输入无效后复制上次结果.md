# 金属加工工具：输入无效后复制上次结果

- 受影响工具路径：`tools/metalwork/calc-pressure-mold.html`、`tools/metalwork/thread.html`；另见 `plan/metalwork/铣削参数-无效输入仍复制旧结果.md`、`plan/metalwork/铸造方法-无效输入后复制上次推荐.md`、`plan/metalwork/齿轮加工-空螺旋角被当作直齿且复制旧值.md`。
- 问题：有效计算后清空或填入无效核心参数，页面显示错误，但部分页面保留上一次的 `lastResult`；此时点击复制仍可能得到与当前输入不符的旧结果。以上两个新增路径由代码静态确认，浏览器交互待复核。
- 解决方案：输入变更和校验失败时清除或标记结果过期，禁用复制；仅在当前输入有效且结果已更新时允许复制，并覆盖有效→无效→重新有效的交互场景。
