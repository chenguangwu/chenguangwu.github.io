# 园艺工具速查：导出明细实际导出历史表

- 受影响工具：`tools/gardening/garden-tools.html`
- 问题：“导出明细 CSV”调用 `TBKit.util.exportTable('#garden_toolsTable', ...)`，目标是历史记录表而非当前工具卡片；搜索和类别筛选后的名称、用途、选购、技巧与保养未按当前结果导出。没有历史时表格也可能为空。源码确认，导出文件待浏览器核验。
- 方案：增加按当前筛选结果生成的 CSV，包含类型、名称及四类说明；历史导出如需保留应单独命名。空结果时提示。
- 验证：分别筛选单类、有匹配和无匹配的关键词，检查文件行数与字段和界面一致。
