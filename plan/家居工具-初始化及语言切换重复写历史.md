# 家居工具：初始化及语言切换重复写历史

## 问题描述
这些工具的成功计算会写历史，页面初始化和切换语言也调用计算，因此打开页面或切换语言可能保存未主动计算的默认或重复参数。历史保留条数有限，原有记录可能被挤掉。

## 解决方案
分离渲染和保存历史，仅在用户明确计算时记录，并处理重复记录；验证首次打开、语言切换和已有历史保留。
