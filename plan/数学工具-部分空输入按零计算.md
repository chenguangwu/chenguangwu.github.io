# 数学工具：部分空输入按零计算

## 问题描述
这些工具只在所有输入均为空时停止，单个字段为空则通过数值读取函数转为 0，仍生成结果和结论。例如二维距离默认点 (0,0) 与 (3,4)，清空第二点的 x 坐标后仍按 0 计算距离 4。辅助表的校验口径不同，还可能留下旧结果。

## 解决方案
逐字段区分未填写与合法的 0，缺项时停止计算并清除相关旧表及导出；验证单项清空、真实零值与恢复输入。
