# 充电时间零分母仍输出结论

受影响工具：`tools/energy/estimate-time-current.html`

## 问题

计算允许充电电流、效率和电池容量为 0，却分别用 `current×efficiency` 与 `capacity` 作分母。电流或效率为 0 时计算得到无穷时间，容量为 0 时倍率可能无定义，页面仍构造时间和快充等级，可能出现无效数值或误导结论。

## 解决方案

按物理意义处理零容量、零电流和零效率：对不能完成充电或倍率无定义的情况明确说明，不输出有限时间与充电等级；当前电量 100% 等边界单独判断。清除失效的复制、图表和历史状态，并验证零分母及正常样例。
