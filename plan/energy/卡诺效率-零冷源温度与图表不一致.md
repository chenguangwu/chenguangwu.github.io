# 卡诺效率：零冷源温度与图表不一致

## 问题

主计算允许冷源温度为 0 K 并显示 100% 的公式极限，但图表函数要求冷源温度大于 0，输入 0 后直接返回，可能保留上一次曲线；这一极限也不应被理解为可以实际实现的热机状态。此结论来自静态代码，需在浏览器验证曲线状态。

## 解决方案

统一主结果与图表的输入口径：若展示 0 K 的数学极限，绘制对应曲线并明确实际不可达；若不支持该极限，则各处一致提示并清除旧图。验证从正温度切换到 0 及恢复的过程，热力学说明请专业人员核验。
