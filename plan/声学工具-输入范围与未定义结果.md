# 声学工具：校验物理范围与未定义结果

- 受影响工具：`tools/acoustics/critical-distance.html`、`tools/acoustics/pipe-open.html`、`tools/acoustics/pipe-closed.html`、`tools/acoustics/freq-to-note.html`、`tools/acoustics/beat-frequency.html`、`tools/acoustics/acoustic-impedance.html`
- 问题：多页公式未针对正数或分母作业务校验：零管长、零混响时间和非正频率可产生非有限或无意义结果；拍频为 0 时拍周期无有限值；声阻抗页的 `1/(c||1)` 在声速为 0 时显示 1 而不是提示未定义，且输入空值会被数值辅助函数当作 0。
- 解决方案：逐工具区分空值、合法零值及必须为正的参数；对无穷周期或无定义结果显示明确状态，不以默认值代替；增加边界输入、等频及正常示例的回归验收。
- 依据：静态阅读各页面计算函数，运行态和公共守卫需复核。
