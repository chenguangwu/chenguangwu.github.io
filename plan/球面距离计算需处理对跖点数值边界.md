# 球面距离计算需处理对跖点数值边界

## 问题

多个地理距离工具使用 Haversine 公式时直接对 `1-a` 开平方，没有约束中间量 `a` 的浮点误差。对跖点的数学值应为 1，但例如纬度 ±10.959935216969441°、经度 0° 与 180° 的 JavaScript 运算可得到 `a=1.0000000000000002`，导致距离为 NaN；两个页面又分别将非有限值替换为占位符或展示无效结果。相同点和对跖点的方位也没有唯一解。已用 Node 验证中间量，页面交互待核验。

## 解决方案

将经有限性检查的中间量限制在数学区间 [0,1]，保留可计算的距离，并对重合、对跖或近对跖时不稳定的方位及中点单独说明。覆盖完全对跖、近对跖、重合与普通点，并与参考实现比较。相关单工具记录可一并处理。
