# DNS 出口页搜索描述与实际功能不符

- **受影响工具路径**：`tools/telecom/dns-egress-lookup.html`；引用该工具的相关工具卡片也需检查。
- **问题描述**：页面标题和 meta、OG、WebApplication 描述称可通过公共 DoH 查询本机出口及排查污染；实际正文说明未配置接口，只提供自有域名和日志查询的说明，并不执行该功能。搜索用户可能因错误承诺进入页面后立即离开。
- **解决方案**：保持 URL 稳定，统一中英文标题、搜索摘要、结构化数据及卡片，准确表述当前为 DNS 排查指南；在纯前端约束内补充交互式诊断清单和结果解释，不声称能直接读取解析器出口。涉及外部服务的能力须先解决项目禁止 API 和数据上传的约束，不能以新增后端或第三方查询接口作为默认方案。
