# 网络诊断外部请求与数据安全约束冲突

- **受影响工具路径**：`tools/telecom/ip-geolocation.html`、`tools/telecom/public-ip-lookup.html`、`tools/telecom/service-status.html`、`tools/telecom/network-speed-test.html`；共用逻辑 `js/network-toolbox.js`。
- **问题描述**：共享脚本调用公开 IP 查询及服务状态接口，IP 归属查询把用户输入的 IP 传至第三方；测速访问第三方端点。页面虽有部分提示，但这与项目禁止第三方 API 和上传用户数据的约束存在冲突；不应把浏览器直接请求等同于数据不会发送给第三方。
- **解决方案**：逐项梳理真实出站请求、参数和触发时机，依据项目约束重新设计：涉及用户输入的远程查询不发送，优先提供本地校验、离线解释及手动导入分析；对于无法离线实现的状态和测速能力准确标明不可用或改为说明页。同步清理相关功能承诺及中英文隐私说明，后续用网络面板核验。
