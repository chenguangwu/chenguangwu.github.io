# 无线距离工具接收功率公式和输入校验

- **受影响工具路径**：`tools/telecom/distance-power-frequency.html`
- **问题描述**：结果中的“到达接收点功率”直接显示发射功率与两端天线增益之和，未减传播损耗；按页面反算的最大距离，接收功率应等于设定灵敏度。说明文字还称 dBm 与 dBi 不能直接相加，与链路预算常用的对数单位计算相矛盾。非频率字段被标记无效时不会中止计算，解析失败还被转换为 0。
- **解决方案**：注明距离和传播条件，按 `Pr = Pt + Gt + Gr − 路径损耗` 计算并标明最大距离处的接收功率；解释功率与增益的单位关系。所有输入均须完整、有限且有效后才计算，保留合法的 0 dBm 和 0 dBi，用已知链路预算样例验证。
