# 会计收益率：零分母历史记录仍保存非有限结果

## 问题

净资产收益率和净利率主结果及辅助表在净资产或收入为 0 时显示不适用，但历史记录仍直接计算除法并保存 `Infinity` 或 `NaN`。这与页面结果不一致；持久化和历史展示的具体呈现还需运行验证。

## 解决方案

以统一的结果状态记录历史，分母为 0 时保存明确的不适用状态而不是非有限数；恢复和展示历史时保留该状态，并验证分子为 0 和非 0 两种情况。
