# 西格玛水平的零缺陷和偏移解释

**受影响工具路径：** `tools/process/sigma-level.html`

## 问题描述

DPMO = 0 时页面称「已达到六西格玛上限」。公式中的逆正态在概率端点没有有限值，6σ 也不是该公式的上限；如果零缺陷来自有限样本，更不能单凭这一结果证明总体无缺陷。页面同时把加 1.5 后的数值与「长期西格玛水平」混用，未交代偏移假设及报告口径，容易与未加偏移的 Z 值混淆。

## 解决方案

将零缺陷作为端点单独说明，避免有限样本得出总体零风险或上限结论；可允许输入样本机会数，另行展示有方法依据的置信区间。明确 Z 与加偏移后指标的命名、1.5σ 是约定假设而非观测事实，并允许选择是否使用偏移；核对两种口径及边界显示。
