# 公差 RSS 零值比例与统计前提

**受影响工具路径：** `tools/process/tolerance-rss.html`

## 问题描述

三个公差均为 0 时，总公差和线性叠加均为 0，但代码以 `((t1+t2+t3)||1)` 将分母替换为 1，显示 RSS 占线性叠加比为 0%；实际 0/0 没有定义。页面还只写 RSS 方法，未说明分量独立性、相同统计覆盖水平及公差作为对称幅值等适用条件，容易把统计估计当作保证的最坏界限。

## 解决方案

线性叠加为 0 时将比例标为不适用，并保留两个总公差为 0 的结果；解释 RSS 的统计前提和与最坏情况的区别。验证全零、单项非零及常规数据，明细和导出保持一致。
