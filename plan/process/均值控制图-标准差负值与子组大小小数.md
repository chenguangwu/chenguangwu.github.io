# 均值控制图输入边界不完整

**受影响工具路径：** `tools/process/xbar-control-limits.html`

## 问题描述

输入守卫只禁止子组大小 n 为 0 或负数，未限制其为整数；标准差 σ 未禁止负值。例如均值 50、σ = -2、n = 5 时公式给出的 UCL 约 47.317、LCL 约 52.683，上下控制限颠倒，页面仍展示结果。n = 2.5 也会用于计算，尽管子组样本数量不能为小数。

## 解决方案

要求标准差为有限非负值，子组大小为有限正整数，并解释 σ 为单件过程标准差及其估计前提；无效时清除主结果与明细、禁止导出旧数据。覆盖负 σ、零 σ、n 小数和正常样例，确认 UCL ≥ LCL。
