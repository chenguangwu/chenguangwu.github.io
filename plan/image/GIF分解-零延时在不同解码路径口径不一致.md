# GIF 分解：零延时在不同解码路径口径不一致

受影响工具：`tools/image/gif-split.html`

## 问题

页面 FAQ 称按 GIF 字段原值显示 0 ms。手动解码路径保存原始 `fm.delay`，而 ImageDecoder 路径在原值为 0 时使用 `VideoFrame.duration` 回退；如果浏览器返回非零播放时长，显示和 ZIP 清单可能不再是原始值，且随浏览器解码路径变化。源码分析，需构造零延时 GIF 并在支持 ImageDecoder 的浏览器复核。

## 解决方案

分别保留原始字段延时和播放器实际或估算延时，界面和清单注明来源与单位；不要把 0 当作缺失值。对照有、无图形控制扩展及不同解码路径的样例。
