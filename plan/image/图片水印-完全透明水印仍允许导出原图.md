# 图片水印：完全透明水印仍允许导出原图

## 问题

文字和图片水印的不透明度滑块均允许设为 0%。`__wmReady` 只检查文字非空或图片已加载，导出时仍认为水印有效；绘制则设置 `globalAlpha = 0`，生成的结果没有可见水印。这与页面针对无有效水印阻止导出原图的提示不一致，可能让用户误以为已添加保护标记。单点和平铺模式均使用该不透明度。

## 解决方案

不透明度为 0% 时明确标记水印不可见，导出前阻止或要求用户明确确认导出无可见水印；单点模式也应检查水印完全位于画外的情况。验证两种水印类型、单点与平铺、透明度为 0 和正常值时的提示与导出。
