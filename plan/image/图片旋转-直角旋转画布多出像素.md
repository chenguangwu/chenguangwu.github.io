# 图片旋转：直角旋转画布可能多出像素

受影响工具：`tools/image/image-rotate.html`

## 问题

预览与批量导出的外接尺寸直接对浮点三角函数结果取 `Math.ceil`。JavaScript 中直角的余弦并非精确零，导致多出 1 px：按源码公式在 Node 计算，100×50 旋转 90° 得到 51×100，400×300 旋转 180° 得到 401×301。精确尺寸场景可能出现额外边缘或不符合平台尺寸要求；实际导出像素和边缘待浏览器复核。

## 解决方案

对 0°、±90° 和 180° 使用精确的宽高关系，或安全处理接近整数的浮点误差；单图和批量共用同一尺寸计算。验证奇偶宽高、透明与不透明背景、快捷旋转以及实际导出尺寸。
