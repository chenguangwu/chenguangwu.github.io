# 图片裁剪换图加载与下载可能串图

## 受影响工具路径
- `tools/image/image-crop.html`

## 问题描述
图片加载回调没有版本检查，快速选择 A、B 时较晚加载的 A 可能覆盖 B；文件名在开始加载时即更新，与实际回调完成的图可能不一致。下载回调异步读取全局 `fileName`，下载过程中换图也可能让旧裁剪内容使用新图文件名。成功加载的 object URL 未见释放。以上为源码分析候选，需以受控延迟在浏览器复现。

## 解决方案
为加载和下载分别绑定请求代次及当前图片快照，取消或丢弃过期回调，并在成功、失败、重置时释放 object URL；测试交错加载、下载期间换图和重置。
