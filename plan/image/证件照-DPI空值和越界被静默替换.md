# 证件照：DPI 空值和越界被静默替换

## 问题
DPI 输入提示范围为 72–600，但读取时通过 `Number` 和钳制处理：清空输入会被当作 0 并输出 72 DPI，输入 1000 会输出 600 DPI，输入框仍显示原值。小数也可进入读取路径，显示值和写入 PNG 时四舍五入后的值可能不同；用户无法从输入框判断实际导出参数。

## 解决方案
导出前验证非空、整数及范围，在输入框附近显示中英文错误，禁止以替代值静默导出；结果区及 ZIP 清单均显示实际写入的 DPI。验证空值、边界、越界、小数及单图／多规格输出元数据。
