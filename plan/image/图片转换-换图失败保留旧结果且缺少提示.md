# 图片转换：换图失败后仍显示旧结果

受影响工具：`tools/image/image-converter.html`

问题：选择新文件时只更新文件对象和转换令牌，没有立即隐藏旧图信息和下载卡片；图片解码只设置 `onload`，没有 `onerror`。新文件损坏或解码失败时，页面继续显示并允许下载上一张图的结果，却没有失败提示；新建对象 URL 也未在失败时释放。

解决方案：选择新图即进入加载状态并使旧结果不可下载，解码失败时明确提示并释放对应 URL；各次异步加载应绑定独立对象及令牌，过期回调只清理自己的资源。验证正常换图、损坏图片、连续快速选择以及失败后重试。

证据范围：静态代码分析，浏览器中解码失败和资源释放行为待验证。
