# 圆角图片：批量大图可能耗尽内存

## 问题

每张图只限制单张画布不超过 8192 边长及约 3355 万像素，但允许同时处理 12 张。每张成功结果都保留原尺寸 canvas 和 PNG Data URL，并在结果中创建预览；没有按批次限制累计像素或估算内存。多张接近上限的图片可能占用很大内存、卡住或崩溃，单张限制不足以保障批处理。此为源码资源分析，需在受控设备上评估实际阈值。

## 解决方案

在解码和生成前评估累计像素、输出大小和设备能力，超出预算时提示分批处理；编码后释放不再需要的画布，使用可释放的 Blob URL 和缩略图，避免同时保留多份大数据。验证接近上限的多图、参数反复修改、清空和下载时的内存释放与失败提示。
