# 图片拼图：固定尺寸非法输入被静默替换

受影响工具：`tools/image/image-collage.html`

## 问题

固定尺寸输入标注范围为 100–8000 px，但渲染时使用 `clamp(+value || 1200, 100, 8000)`：空值及 0 会按 1200 处理，超出范围则按边界处理，输入框仍保留原值。用户可能以为预览或下载使用了填写的尺寸。源码静态分析，浏览器输入和导出结果待复核。

## 解决方案

对空值、非整数及越界值给出明确提示并暂停对应渲染或下载；如选择自动修正，应同步更新输入框并告知用户。验证清空、0、小数、上下限及超限值，并检查实际画布尺寸。
