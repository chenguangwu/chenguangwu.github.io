# 图片压缩：全部下载静默跳过未完成或失败项目

受影响工具：`tools/image/image-compress.html`

问题：批量列表在仍有图片处理中或失败时保留“全部下载”入口；`downloadAll()` 仅筛选 `status === 'done'` 的图片并下载，提示只显示开始下载数量，没有明确指出哪些文件未完成或失败。用户可能误以为整个批次均已导出。

解决方案：下载前显示成功、处理中、失败的数量和文件，提供“下载已完成项”与等待或重试的明确选择；批量状态变化时保持下载范围可解释。测试混合成功、失败与处理中，核对浏览器多文件下载限制、取消、重试和中英文提示。

证据范围：本机无头 Chrome 通过本地 HTTP 测试一张有效图片和一张无法解码的文件；点击全部下载只触发有效文件的下载链接，提示“开始下载 1 张图片”，没有在下载提示中说明失败项。下载链接被拦截，处理中场景及真实保存待复核。
