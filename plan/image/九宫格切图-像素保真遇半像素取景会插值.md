# 九宫格切图：像素保真遇半像素取景会插值

## 问题

像素保真模式仅将切片边界取整；居中裁方时，源图长短边差为奇数会产生 0.5 像素的裁切起点，适应留白模式也可能以 0.5 像素偏移绘制原图。例如 7×6 图居中裁方的 X 起点是 0.5。后续画布绘制可能发生插值，切片拼回后虽然尺寸正确，颜色细节仍可能不同于源图，与“像素保真”的预期不一致。该问题依据静态路径分析，需用像素棋盘格在目标浏览器验证。

## 解决方案

在像素保真模式下采用整数源坐标和整数留白偏移，明确奇数差值时多出的一像素放在哪一侧，并保持预览、提示与导出一致。使用奇偶尺寸组合的多色像素图检查逐像素拼回结果；如无法保持原像素，应明确提示而非称为像素保真。
