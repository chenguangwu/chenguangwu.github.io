# GIF 分解：截断或未知块可能被当作完整动画

受影响工具：`tools/image/gif-split.html`

## 问题

结构解析遇到未知块直接结束，读取颜色表和图像数据子块时未逐项验证剩余长度，末尾也未要求读到 GIF 结束标记；只要已经收集到帧，调用方就继续解码。损坏或截断文件可能被当成完整动画处理，结果缺帧而未提示。源码静态分析，需用截断及畸形文件复核两种解码路径。

## 解决方案

对签名、逻辑屏幕、块长度、子块终止符及结束标记进行边界检查，区分完整文件、可恢复部分文件与无效文件；若支持部分提取，应明确提示缺失风险。验证不同截断位置和合法扩展块，避免误拒正常 GIF。
