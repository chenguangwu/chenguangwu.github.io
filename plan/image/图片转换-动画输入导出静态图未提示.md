# 图片转换：动画输入只导出静态画面缺少提示

受影响工具：`tools/image/image-converter.html`

问题：文件选择器接受 GIF，也可接受带动画的 WebP；转换通过单次 `canvas.drawImage` 和 `toBlob` 生成静态图，没有逐帧处理或提示动画丢失。页面格式表标注 WebP 支持动画，用户容易误以为转换后仍保留动画。

解决方案：识别或明确告知可能包含动画的输入当前仅导出静态画面，并在导出前清晰提示；若后续增加动画转换，应在纯前端条件下验证解码编码能力、时长和内存限制。测试动画 GIF、动画 WebP 与普通静态图片的提示和结果。

证据范围：静态代码分析，需用各浏览器实测最终帧内容和提示。
