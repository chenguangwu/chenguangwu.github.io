# 图片压缩：GIF 动画输出为静态图片未说明

受影响工具：`tools/image/image-compress.html`

问题：上传入口列出 GIF，但压缩流程将 `Image` 绘制到单张 Canvas，并只提供 JPEG、PNG、WebP 静态导出；页面没有明确告知动画帧不会保留。用户可能误以为下载结果仍是动图。

解决方案：检测 GIF 和其他可能含动画的输入，处理前明确提示当前仅输出静态画面，并提供取消或确认；如将来实现动画压缩，应在浏览器本地完整处理帧、时长、循环及透明度。验证动态图、静态 GIF 和混合批次的说明与实际输出。

证据范围：源码静态分析，具体取帧及各浏览器行为待验证。
