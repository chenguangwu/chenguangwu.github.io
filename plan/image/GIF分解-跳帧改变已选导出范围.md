# GIF 分解：跳帧会改变已选导出范围

## 问题

“跳到帧号”看似只用于定位预览，但 `jumpToFrame` 会把当前帧范围改成目标所在的 60 帧页。用户先设置所需范围，再跳到某一帧查看，之后下载 ZIP 时会按被替换后的范围打包，可能多导出或漏掉帧；范围文字会更新，但操作本身没有说明会改变导出范围。

## 解决方案

将跳转预览与导出范围分别保存；跳转到范围外时仍保持原范围，或明确告知并由用户选择是否调整。验证先设置 10–20 帧、跳到第 15 帧或范围外的帧再导出，确保 ZIP 清单符合用户选择。

- `tools/image/gif-split.html`
