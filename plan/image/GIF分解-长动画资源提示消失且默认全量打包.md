# GIF 分解：长动画资源提示消失且默认全量打包

## 问题

长动画解析时计算总帧像素并显示资源提示，但 `finishLoad` 随后把提示区域改为仅显示解析警告；没有解析警告时会隐藏资源提示。同时长动画仅预留前 60 帧画布，却将默认帧范围设为全部帧；点击 ZIP 下载会先对整个范围执行 `__gsEnsureRange`，同步重新渲染并保留全部画布。大动画可能在缺少资源提醒的情况下大量占用内存或卡住页面。此为静态分析，实际设备容量和卡顿程度需受控验证。

## 解决方案

分别保留资源提示和解析警告，清楚展示当前范围及预估占用；长动画默认选择可控范围，或采用分批编码、释放帧的方式导出，并允许取消及设置资源上限。测试大尺寸多帧、切换范围、清除范围和 ZIP 导出，确认不会静默全量分配。
