# 图片拼接：文件初始化异常阻塞后续批次

## 问题

文件批次入队后，逐个创建对象 URL 和图片对象。如果初始化过程中抛错，未启动的文件和出错文件都不会减少该批次的 `pending`，批次也不会标记为完成。队列只处理已完成的首批，因此本批及后续批次可能一直停留在加载状态。此为静态分析，需模拟对象 URL 创建失败复验。

## 解决方案

对每个文件的初始化独立捕获异常，记录失败原因并完成计数，继续处理其余文件；确保异常路径释放已创建的资源，队首失败后仍可推进后续批次。模拟首个和中途文件失败，并验证连续添加与清空后的恢复。

## 受影响的工具路径

- `tools/image/image-collage.html`
