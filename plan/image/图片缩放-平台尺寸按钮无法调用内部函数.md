# 图片缩放：平台尺寸按钮无法调用内部函数

受影响工具：`tools/image/image-resize.html`

问题：四个平台尺寸按钮通过内联 `onclick` 调用 `setPlatformSize()`，但该函数位于立即执行函数的私有作用域，并未像其他处理函数一样暴露到 `window`。因此按钮无法找到处理函数，不能应用预设。

解决方案：在初始化时为按钮绑定作用域内的事件处理器，或按项目既有方式正确暴露函数；使用实际上传的图片验证四个按钮能设置对应宽高并更新预览，同时处理等比适配问题。

证据范围：本机无头 Chrome 在本地文件点击按钮捕获 `setPlatformSize is not defined`；通过本地 HTTP 加载时也确认 `window.setPlatformSize` 为 `undefined`。HTTP 实际点击与上传流程仍需完整复核。
