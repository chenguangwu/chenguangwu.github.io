# GIF 分解：预览翻到未缓存帧会报错

## 问题

长动画只缓存部分帧画布；打开预览时会按需重建当前帧，但预览里的上一帧、下一帧直接改变索引并调用 `renderPreview`，未检查目标帧画布。翻过缓存边界时，`drawImage(fr.canvas, ...)` 会收到空值并报错，预览无法正常切换；键盘左右键也走同一逻辑。手动选择较窄的帧范围后也可能触发。以上为静态代码分析，需用多于 60 帧的样本交互复验。

## 解决方案

在预览跳转前按需重建目标帧或邻近页面，失败时保留原帧并给出可操作的提示；明确预览导航是否限制在所选范围内。验证首尾循环、跨页、缩窄范围、按钮及键盘操作，并兼顾缓存上限。
