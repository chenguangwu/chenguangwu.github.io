# 图片转换：新文件读取失败后混用旧图和新文件信息

## 问题

已有一张成功转换的图片时，选择新图片会先将 `originalFile` 改成新文件，再尝试创建对象 URL。若 `URL.createObjectURL` 抛错，处理只显示读取失败并返回，旧的 `originalImg` 和转换卡片仍在，而文件信息已指向新文件。此后调整质量等参数会重新转换旧图，却使用新文件的名称和大小计算结果，容易误认输出来源。该异常分支为静态分析，需模拟 URL 创建失败复验。

## 解决方案

将待加载文件及图片作为独立候选状态，成功解码后再原子替换当前图片、文件信息及结果；读取失败时明确保留完整的旧状态或统一清空，禁止混用。验证已有结果后模拟对象 URL 创建失败、再修改参数和下载的行为。
