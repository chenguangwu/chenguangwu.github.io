# 图片裁剪：动画图片导出静态画面未说明

- 受影响工具：`tools/image/image-crop.html`
- 问题：上传区域明确接受 GIF，文件处理也接受图片类型；裁剪流程将图片绘制到 Canvas，下载仅提供 PNG 或 JPEG，不能保留动画，但上传和下载位置没有说明。动画 GIF 或动画 WebP 用户可能误以为导出后仍可播放。以上为源码分析，待浏览器用动画样本验证具体画面。
- 解决方案：选择可能包含动画的图片时清晰提示当前只输出静态画面，并在导出格式附近重复说明；若未来支持动画裁剪，应在浏览器本地逐帧处理，明确格式、时长和内存限制。验收覆盖动画 GIF、动画 WebP 和普通静态图，检查提示及下载文件。
