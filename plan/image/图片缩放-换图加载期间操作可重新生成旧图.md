# 图片缩放：换图加载期间修改参数可重新生成旧图

受影响工具：`tools/image/image-resize.html`

问题：换图开始时清空结果但保留旧的 `originalImg` 和 `originalFile`，主区域仍可操作；新图解码期间修改尺寸、算法或格式会调用 `render()`，重新用旧图生成可下载结果。如果新图较慢或失败前用户下载，拿到的仍是旧图片。

解决方案：进入加载态时禁用参数及下载操作，或清空旧图引用并使本次加载独占状态；新图成功后才允许渲染。验证慢速解码期间调整所有参数、下载、失败重试和快速连续换图。

证据范围：静态代码分析，需使用受控加载在浏览器复现。
