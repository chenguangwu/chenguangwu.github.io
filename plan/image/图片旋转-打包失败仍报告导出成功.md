# 图片旋转：ZIP 打包失败仍报告导出成功

## 问题

批量旋转完成编码后，`runBatchExport` 在 ZIP 创建或下载触发抛错时显示“打包 ZIP 失败”，但随后仍根据已编码的条目数生成“已导出”和成功提示；若没有图片编码失败，还会提示 ZIP 已导出。用户实际可能没有得到文件，却被成功信息误导，且失败重试列表不包含这些图片。此问题由异常分支静态确认，需在浏览器模拟打包或下载异常验证。

## 解决方案

将图片编码成功与 ZIP 创建、下载触发成功分开记录；打包失败时保留明确的失败状态，不显示导出成功，并提供使用原快照重新打包的操作。针对全部成功、部分编码失败及 ZIP 打包失败分别验证提示和重试行为。

- `tools/image/image-rotate.html`
