# 图片拼图：批量导入跳过文件缺少明细

受影响工具：`tools/image/image-collage.html`

## 问题

批量导入时，没有 `image/` MIME 类型的文件被直接跳过；部分图片解码失败时只显示失败数量，不列出文件名。用户混合拖入多个文件后，可能不知道哪些文件没有参与拼图，尤其是浏览器未提供 MIME 类型的图片。源码静态分析，需在目标浏览器和系统文件选择器复核。

## 解决方案

按文件列出成功、跳过及失败状态和原因，允许移除或重新选择失败项；对缺少 MIME 类型的文件结合扩展名和实际解码结果处理，并保留不支持格式的明确提示。验证混合文件、空 MIME 和损坏图片。
