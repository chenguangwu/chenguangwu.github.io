# 图片压缩：单图失败缺少清除和重试入口

受影响工具：`tools/image/image-compress.html`

问题：单图失败时结果区只渲染错误文案并返回，没有删除、清空或重试按钮；批量失败行则有删除按钮。再次上传会追加文件，用户难以直接移除失败项或理解如何重新开始。

解决方案：在单图失败态提供移除、重新选择文件；对可通过调整参数恢复的失败提供重试，明确区分解码失败与压缩失败。验证无效文件、目标体积失败、重试成功、再次上传及批量切换。

证据范围：本机无头 Chrome 经本地 HTTP 加载，提交无效 PNG 后单图结果仅显示“图片加载失败”，结果区按钮数为 0，失败项仍在列表中。参数失败和实际重试流程待复核。
