# 随机数据工具：生成数量未严格校验

## 问题描述
多个随机数据工具的数量输入声明为 1–50，但生成时只限制上限并用 5 作为假值回退。清空或输入 0 会生成 5 条；输入 2.5 的循环会生成 3 条；负数得到空结果，超过 50 则被静默截断，均与输入不一致。

## 解决方案
生成前严格校验 1–50 的整数，非法时提示并清除或标记旧结果，不静默替换。分别验证空值、零、小数、负数和超限。
