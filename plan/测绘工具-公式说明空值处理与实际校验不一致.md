# 测绘工具空值处理说明与实际校验不一致

## 问题

下列工具的公式说明称输入为空时按 0 处理或缺省为 0，但 `calcTool` 对所需字段使用 `__svReq`，空值会提示填写并停止主计算。用户依照文案留空无法得到预期结果，且“留空”和合法的数值 0 容易混淆。平面距离方位角的同类说明问题已有单独任务，此处一并列出便于核对。

## 解决方案

逐项核对实际必填字段，将公式说明改为明确的必填和零值规则；增加留空、输入 0 和正常输入的交互核验，检查中英文说明一致。
