# 震源机制：输入名称插入 HTML 且无角度校验

- 受影响工具：`tools/seismology/analysis-stress.html`
- 问题：节面名称直接拼接到 `innerHTML`，包含 HTML 标记的输入会被浏览器解释；非法行静默跳过，角度未限制有效范围，部分数字由 `parseFloat` 容忍尾部字符。页面相关工具描述称基于地震波形估算应力场，而页面实际只处理输入的节面参数并计算轴和分类。
- 解决方案：将用户名称按文本渲染；严格解析每行并标出错误行、检查角度约定和范围。说明使用的坐标、输入前提与结果局限，修正 SEO 和相关卡片的波形及应力场承诺。
- 验证建议：输入含标记的名称、非法和超范围角度以及有效示例，检查文本安全、逐行提示和结果；对照独立机制解验证轴约定。
