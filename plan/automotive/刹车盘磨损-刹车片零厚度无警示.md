# 刹车盘磨损：刹车片零厚度无警示

## 问题描述

刹车片剩余厚度字段允许留空，也允许输入 0；提醒条件却限定 `pad > 0 && pad <= 3`。输入 0 时不会出现刹车片警告，刹车盘条件正常时页面还可能显示“状态正常 · 继续使用”，容易使用户误认为刹车片也安全。负值同样未提示无效。

## 解决方案

区分未填写、零和负值：对零及其他达到设定更换阈值的有效读数显示明确检查或更换提醒，负值提示无效；把盘的状态标为盘的评估，避免覆盖片的独立警告。验证空、负、0、阈值及阈值以上输入。
