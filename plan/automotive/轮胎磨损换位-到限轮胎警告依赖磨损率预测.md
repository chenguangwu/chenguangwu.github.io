# 轮胎磨损换位：到限轮胎警告依赖磨损率预测

## 问题

到限警告只检查预测剩余里程最短的轮胎。若某轮花纹已达极限但里程为 0 或该轮磨损率无法计算，其剩余里程被设为无限，可能不会被选为最先到限轮胎；例如新胎深 8 mm、极限 1.6 mm、左前 1.6 mm、里程为 0 时，预测不可用但仍可能只给出均匀磨损或换位提示。表格中的到限状态不应依赖预测是否可用。

## 解决方案

独立检查每条轮胎当前花纹是否达到极限，逐条给出更换提示并优先于换位建议；剩余里程预测不可用时标明未知，不将其当作无限安全寿命。覆盖零里程、多个轮胎到限和缺失深度。
