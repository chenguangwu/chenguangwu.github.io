# 保养排程：超过里程周期后自动滚动到下一周期

## 问题

排程使用上次保养里程加周期的整数倍寻找不早于当前里程的到期点，但没有证据表明中间周期已经保养。例如上次 0 km、机油周期 10000 km、当前 15000 km 时，工具将下次到期设为 20000 km，显示还有 5000 km，遗漏已超期 5000 km。

## 解决方案

对有明确上次保养记录的项目，按上次实际保养里程加该项目周期判断到期和超期；各项目维护独立的上次保养信息，缺少记录时明确说明为推测，不能把整周期滚动当作已完成保养。
