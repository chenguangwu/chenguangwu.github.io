# 期货计算工具：空输入被静默转为零

- 受影响工具：`tools/futures/futures-pricing.html`、`tools/futures/hedge-ratio.html`、`tools/futures/margin-calc.html`、`tools/futures/option-greeks.html`、`tools/futures/option-payoff.html`。
- 问题：多个页面 `getVal()` 使用 `+value || 0`，将空值当作有效的零。比如清空期权权利金仍按零成本出损益；清空期权利率或股息仍按零参与定价；清空套保相关系数则生成零对冲结果。用户正在输入时可能看到看似有效但并非其输入的结论。
- 解决方案：逐项区分空值、合法零和无效数字；必填项缺失时提示并清除图表与附表，不把合法零当作缺失。覆盖清空、填零、重新输入及复制导出。
