## 2026-11-03 续查（并行批 I）

### AR-N1 编码器页把 CPR 当 PPR 再除以 4，主结果最多偏小 4 倍（高，确认）
- 描述：输入标签把「每转脉冲 CPR」与「PPR（单相脉冲/转）」当成同一个量，结果又固定按四倍频除以 4。按 CPR（已含四倍频的计数/转）填数的用户会得到偏小 4 倍的分辨率，且页面无任何口径提示。
- 证据：`tools/robotics/encoder-angle-resolution.html:126` 标签为「每转脉冲 CPR (PPR)」，`:279` 代码 `const th=360/(4*cpr)`。复现 cpr=4000 → 实际输出 `0.0225°`；若 4000 是 CPR，正确分辨率应为 360/4000 = `0.0900°`。
- 影响：`tools/robotics/encoder-angle-resolution.html` 主结果卡、明细表、角分卡与导出的 4 个派生值全部同步偏小 4 倍。
- 方案：二选一并写进口径说明——① 输入改名为「PPR（单相脉冲/转）」保留 4 倍频；② 输入改名为「CPR（计数/转）」并去掉 ×4。同步 i18n 标签与 FAQ，并补 4000 CPR 的对照示例。

### AR-N2 火箭 Δv 页在 m_f > m_0 时输出负速度增量且无提示（中，确认）
- 描述：输入守卫只校验非空与非零，不校验「初始质量应大于最终质量」，质量比小于 1 时对数取负，主结果直接显示负的「速度增量」。
- 证据：`tools/aerospace/delta-v-rocket.html:216`（必填项）、`:238`（仅把 m0/mf 当分母拦 0）、`:271` `dv=isp*9.81*Math.log(m0/mf)`。复现 isp=300、m0=100000、mf=500000 → 输出 `-4737 m/s` / `-4.74 km/s`，标签仍为「速度增量 Δv」。
- 影响：`tools/aerospace/delta-v-rocket.html` 主结果、明细表、CSV 导出与历史记录共用同一负值。
- 方案：要求 m0 > mf（或 m0 ≥ mf），不满足即提示「最终质量不能大于初始质量」并中止；同时同步校验 mf>0，避免 0 质量推进剂场景被当作正常输入。

### AR-N3 由比冲求 Δv 页同样接受 m_f > m_0，推进剂质量分数变 −100%（中，确认）
- 描述：与 AR-N2 同源缺陷，且本页额外输出「推进剂质量分数」，逆序输入时该值也为负，读者会误读为负推进剂。
- 证据：`tools/aerospace/rocket-delta-v.html:272` `dv=ve*Math.log(m0/mf)`、`:276` `((m0-mf)/m0*100)`。复现 ve=2500、m0=100、mf=200 → `-1732.9 m/s` 与 `-100.000%`。
- 影响：`tools/aerospace/rocket-delta-v.html` 主结果、明细表与导出。
- 方案：与 AR-N2 统一加 m0>mf 校验；质量分数改为「仅在有效质量比下展示」，并在注释里说明 mf 是末质量（含载荷与结构）。

### AR-N4 两页 Δv 工具的 g₀ 与算例尾数同标准引据不一致（低，确认）
- 描述：代码与公式箱用 9.81，同页引据/FAQ 却写 9.80665；深度解析算例又用截断的 ln(5)=1.609，导致正文数值与页面实算差 3–4 m/s。
- 证据：`tools/aerospace/delta-v-rocket.html:120`（「g₀ 固定取 9.81」）与 `:319`（FAQ「标准重力加速度 9.80665」）；`:315` 写「2943×1.609≈4733」，node 复算 300×9.81×ln5=`4736.6`，页面实际显示 `4737 m/s / 4.74 km/s`。`tools/aerospace/specific-impulse.html:121` 用 9.81、`:162` 引据写 9.80665。`tools/aerospace/rocket-delta-v.html:317` 写「≈4023」，实算 2500×ln5=`4024.4`。
- 影响：两页的可核对性下降；用户按 FAQ 的 9.80665 复算会与结果对不上（差值约 0.04%）。
- 方案：三处统一常量（建议 9.80665 并注明「显示按 9.81 四舍五入」），深度解析算例数字用 node 实跑取值后回填。

### AR-N5 二连杆正运动学「计算说明」示例坐标与真实输出不符（中，确认）
- 描述：计算说明给出一组坐标，既不是页面实算值，也与同页深度解析示例冲突；三处口径不一致。
- 证据：`tools/robotics/forward-kinematics-2r.html:162` 写「θ₁=30°、θ₂=45°、L=1 → 约 (1.297, 1.207)」；`:240-241` 实算 `x=cos30+cos75=1.1248`、`y=sin30+sin75=1.4659`；`:195` 深度解析写 (1.125, 1.466)。node 复现输入 30/45/1/1 → `(1.1248, 1.4659)`。
- 影响：`tools/robotics/forward-kinematics-2r.html` 计算说明区误导核对；主结果本身正确。
- 方案：计算说明改用真实输出 (1.1248, 1.4659)，并由 node 生成后回填，避免手写尾数漂移。

### AR-N6 轮式里程计深度解析把右轮多走判成「右转」，转向符号与实际相反（中，确认）
- 描述：按差速运动学，右轮行距大于左轮时期望航向角为正（逆时针/左转）；页面正文却写「右转」，且公式箱又含糊说「右轮多为正转向」，同一页方向说明自相矛盾。
- 证据：`tools/robotics/wheel-odometry.html:287` `dth=(dr-dl)/L`（正即逆时针）；`:189` 示例 dl=1.0、dr=1.2、L=0.4 → node 复算 dθ=`+0.5 rad`（`+28.65°`），正文却写「前进 1.1m 并右转 0.5rad」；`:120` 写「右轮多为正转向」。
- 影响：`tools/robotics/wheel-odometry.html` 主结果的「航向变化 (°)」正负号会被读者按文字反向理解，下游航位推算方向可能整体翻转。
- 方案：统一为「右轮多走 → θ 增加（逆时针/左转）」，公式箱、深度解析、FAQ 改同一句；可加 ±180° 环绕与 |dr−dl|>L 的边界说明。

### AR-N7 重力补偿扭矩页的 θ 物理定义在同一页内两说，公式箱与 FAQ 冲突（中，确认）
- 描述：公式箱称 θ 是「杆件与竖直方向夹角」并说 θ=0°（竖直下垂）扭矩最大；FAQ 与代码实际按「与水平方向夹角」用 cosθ。两种定义差 90°，按公式箱口径理解会得到完全相反的大小关系。
- 证据：`tools/robotics/gravity-comp-torque.html:120`（「θ 为杆件与竖直方向夹角」「θ=0°扭矩最大」）、`:205`（FAQ「臂与水平夹角；水平 θ=0 时重力矩最大」）、`:245` `tau=m*g*L*Math.cos(th*Math.PI/180)`；`:201` 深度解析按水平口径给 14.7 N·m，node 复算 m=5、L=0.3、θ=0 → `14.715`。若真按「与竖直夹角」，公式应为 sinθ。
- 影响：`tools/robotics/gravity-comp-torque.html` 主结果与图表横轴含义不明；按公式箱理解会取反。
- 方案：统一为「θ 为连杆与水平方向夹角」，公式箱补一句「竖直时 τ=0」；图表 x 轴标注角度定义，并在示例中给出 θ=90° 的 0 N·m 对照。

### AR-N8 比冲页接受负推力/负质量流率并输出负比冲（低，确认）
- 描述：守卫只拦空值与分母 0，未限制 F、ṁ 为正，负值会照常算出负比冲与负排气速度。
- 证据：`tools/aerospace/specific-impulse.html:236`（仅把 mdot 登记为分母）、`:269` `isp=f/(md*9.81)`。复现 f=-100000、mdot=40 → `比冲 Isp -254.8 s`、`有效排气速度 -2500.0 m/s`。
- 影响：`tools/aerospace/specific-impulse.html` 主结果、明细与导出出现物理无意义负值。
- 方案：加 F>0、ṁ>0 校验并提示「推力与质量流率应为正值」；负值直接中止，不进历史。

### AR-N9 转弯半径页未限制坡度角上限，φ≥90° 给出负半径与负周期（低，确认）
- 描述：只把 φ 当分母拦 0，未限制 0<φ<90°；φ 进入第二象限后 tan 为负，半径、侧向加速度、盘旋周期同时变负。
- 证据：`tools/aerospace/turn-radius.html:235`（φ 仅按分母拦 0）、`:268` `R=v*v/(9.81*Math.tan(phi))`、`:272-273`。复现 v=100、φ=120° → node 复算 `R=-588.5 m`、侧向加速度 `-16.990 m/s²`、盘旋周期 `-36.97 s`。
- 影响：`tools/aerospace/turn-radius.html` 主结果 4 张卡与图表扫描区间全部出现负值。
- 方案：限定 0<φ<90°（建议 0–75° 并提示大坡度载荷因数），φ≥90° 提示「坡度角超出物理范围」并中止；同时补 |φ| 的下限说明。
