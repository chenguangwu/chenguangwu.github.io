## 2026-11-03 审计补充

### 化验质控静默丢弃无效样本（高，确认缺陷）
- 问题：批量样本缺列或数字解析失败时被静默跳过，剩余行仍计算合格率与批次结论，用户难以发现漏检。
- 证据：`tools/geology/analysis-33.html:118-130,209-230`：`forEach` 遇列数不足或 NaN 直接 return，只有全部行无效才提示；合格率分母使用已入 `arr` 的行数。浏览器未实测。
- 影响：`tools/geology/analysis-33.html`；混合有效与无效输入可产生不完整的质控结论。
- 方案：逐行报告行号、原因及已接受/拒绝数量；对存在错误的批次默认不输出最终合格结论，允许纠正后重新计算；增加混合无效行用例。

### 留存优化：保留质控复核证据（中，建议）

### 潮汐跨午夜搜索区间倒置（高，确认源码缺陷）

### 12-G1 养蜂采蜜量估算：负/空花源面积产出负产量或 0 产量（高，确认）
- 描述：`hives` 有 `<=0` 拦截，但 `area` 用 `parseFloat(...) || 0` 且无正数校验；负面积把面积因子算成负值，总产量、斤数、收入随之为负；清空面积则因子为 0，页面仍显示 0.0 kg 并给出"花源偏少"提示，不报缺项。
- 证据：`tools/beekeeping/honey-estimator.html:143-151,313-341`（`:315` 面积解析、`:320-324` 仅校验 hives、`:329-333` 面积因子、`:335` 产量）。node 复算：10 群、花源 -50 亩、气候 1.0、经验 1.0、混合花源 35 kg/群 → 面积因子 -1.25，总产蜜 -437.5 kg、约 -875 斤、收入 ¥-17500、"建议花源 40 亩"；花源清空 → 0.0 kg、约 0 斤、收入 ¥0。
- 影响：负收益与零产量被当作正常估算展示；用户无法察觉面积未填或为负。
- 方案：面积要求有限正数（0<area≤10000），无效时清空全部结果并提示；不足承载只允许折减到 0–1，不得为负；补 -50/0/空/上限用例；仅对有效输入写历史。

### 12-G2 运动鞋尺码对照：CN 与 EU 文案和输出自相矛盾（中，确认）
- 描述：公式区声明"中国码数值=脚长(cm)（脚长 250 mm 即 CN 250）""25.5cm → 40.25 ≈ 40"，实现却输出 CN=25.5，并把 40.25 按半码向上取成 40.5。
- 证据：`tools/daily-goods/shoe-size.html:130,159-163,249-266`（`:251` `Math.round((cm*1.5+2)*2)/2`、`:258-259` 二次取半码、`:263-266` 输出）。node 复算：255 mm → CN 25.5、EU 40.5（`Math.round(80.5)/2`）、US 男 8.5、UK 7.5；250 mm → EU 39.5、US 男 7.5、UK 6.5。文案示例（40.25≈40、CN 250）与输出不一致。
- 影响：核心结果与页面解释冲突，按 CN/EU 海淘选码易错；美/英码系数是否贴合品牌官方表需另比对，该子项标待验证（本批未比对品牌表）。
- 方案：统一 CN 口径（mm 250/255 或 cm 25.0/25.5 二选一并全页一致）；写明 .25 归属规则或保留两位；补 250/255/260 与 EU 40/42 往返用例；US/UK 按品牌对照表校准。

### 12-G3 机车牵引力/功率匹配：负输入照算负功率，0 速度提示泄露键名（中，确认）
- 描述：`__tbInputGuard` 只拦空值与全 0，不拦负数；负牵引力或负速度均输出负牵引功率/负标定功率。速度为 0 时提示串使用 `__D` 映射的键名 `v1` 而非中文标签。
- 证据：`tools/railway/power-5.html:130,132,188-292,312,665-683`（`:214/267` `__D={"v1":"v1"}`、`:673-677` 五项结果）。node 复算：牵引力 -200 kN、速度 60 km/h → 牵引功率 -3333.33 kW、柴油机标定 -3921.57 kW、单位速度牵引力 -3.333；牵引力 200、速度 -60 同为 -3333.33 kW；速度 0 → 显示"「v1」是本计算的分母，不能为 0。"。
- 影响：物理上不可能的负功率被当作有效结果；错误提示含内部变量名，用户无法对应到"运行速度"输入框。
- 方案：v0/v1 均要求有限正数并设合理上限；负数、零分别给字段级错误；`__D` 改为中文标签映射；补 0/负/空用例。

### 12-G4 样本量计算：清空比例得 0 样本，非法输入残留旧结论（高，确认）
- 描述：`+''` 把空值变成 0；`p` 为空或 p=1 时 n₀=0，主结果直接显示 0 且无提示。E=0 时只把主数字改为"参数无效"，`sample-label` 与 `calc-detail` 仍保留上一次置信度/误差/计算过程。N 为负数按无限总体处理。E 标签写"绝对"，代码却按百分比除以 100。
- 证据：`tools/stats/sample-size.html:168-170,289-327`（`:291-293` 解析、`:295-298` 校验、`:301-312` 结果、`:314-327` 明细）。node 复算：p 清空 → p=0、n₀=0、`Math.ceil(0)=0`，label "95% 置信 · 误差 ±5.00% · p=0"；p=1 → 同为 0；E=0 → 仅主数字变化；N=-500 → 仍给 385。默认 p=0.5、E=5、N=0 → 385（正常）。
- 影响：问卷/实验规划可能拿到 0 样本，或看不到参数已失效的旧结论；负总体被静默忽略。
- 方案：p、E、N 分别校验有限性与范围（p∈(0,1) 或明确提示 0/1 退化，E>0，N 为 0 或正整数）；无效时同时清空 label 与明细；标签改为"误差范围 E (%)"；补空值/0/1/负数用例。

### 12-G5 桥梁挠度计算：负刚度/负荷载仍判"满足"，无效输入残留旧结果（高，确认）
- 描述：仅拦 0/NaN，负 E、负 q、负 P 可通过；负挠度与限值比较必然"满足"。清空荷载时函数直接 return，四张结果卡与结果正文保留上一次数值。
- 证据：`tools/bridge/deflection-calc.html:138-146,159,169,298-335`（`:303` 校验、`:309/317` 挠度、`:325` `ok=f<=fLim`、`:326-333` 输出）。node 复算：L=20 m、E=-32.5 GPa、I=0.15 m⁴、q=30 kN/m → EI=-4.875e9、f=-12.82 mm，`resCheck`="满足"；q=-30 同样 f=-12.82 mm、"满足"；清空 q → 旧 f/限值/挠跨比/校核不变。
- 影响：结构初筛会把不可能的负刚度或负荷载判为合格，属安全性误导。
- 方案：L/E/I/q/P 均要求有限正数（荷载允许 0 时需明确"无荷载"分支）；无效时清空全部结果与 `_lastResult`；补负值/0/空用例。

### 12-G6 桥梁挠度计算深度解析：EI=2.0e8 kN·m² 与 10.1 mm 算例自相矛盾（中，确认）
- 描述：深度解析以 q=20 kN/m、L=6 m、EI=2.0e8 kN·m² 推导"≈10.1 mm、约 L/594"，按页内公式复算仅约 0.0017 mm。
- 证据：`tools/bridge/deflection-calc.html:199,241`。node 复算：5×20×6⁴/(384×2.0e8)=1.6875e-6 m=0.0016875 mm；若要得到 10.1 mm，EI 应约 3.34e4 kN·m²（相差约 6000 倍）。
- 影响：示例数字与页面公式不一致，用户按示例参数复算会得到完全不同结果，削弱可信度。
- 方案：按页内公式重算示例（EI≈3.34e4 kN·m²，或改荷载/跨度），同步修正 L/594 结论；示例数字用 node 实跑取值。

### 12-G7 隧道通风计算：CO 稀释法单位口径错误写入主结果（高，确认）
- 描述：CO 模式按 `Q=q·N·L(米)/δ(ppm 数值)` 直接计算，主卡标题仍为"需风量 Q/稀释需风量"；默认参数给 160 m³/h，而按 km 与体积比的标准口径应为 160000 m³/h。同时负交通量、负容许浓度、负断面积均可通过校验，输出负风量与负风速。
- 证据：`tools/tunnel/ventilation-calc.html:140-173,188-194,287-321`（`:192` CO 公式说明、`:305` 校验、`:306` Q、`:313` 明细、`:316-320` 结果卡）；FAQ `:234` 已自述该口径不可直接用于工程。node 复算：L=1000、N=800、q=0.02、δ=100、A=60 → Q=160 m³/h、v=0.000741 m/s；δ=-100 → Q=-160 m³/h、v=-0.000741 m/s；标准口径 0.02×800×1.0/1e-4=160000 m³/h。
- 影响：主结果与"需风量"命名极具误导性，按 160 m³/h 选风机会严重欠风量；负参数亦被接受。
- 方案：按标准单位换算后再计算（L 用 km、δ 用体积比），或把该模式明确改为无量纲对比指数并撤掉"需风量"字样；所有输入要求正数；无效时清空结果卡；把 FAQ 的免责说明前移到结果区。

### 12-G8 余震频度与衰减：无范围校验，Infinity/负频次与 b≈8.69 直接展示（中，确认）
- 描述：`calc` 仅校验震级个数≥2，不校验震级范围、K/c/p/t 的符号与 `t+c>0`；`Infinity` 用 `isNaN` 判不到，直接 `toFixed` 显示 "Infinity"；K<0 显示负频次；等震级序列使 b 分母只剩 ΔM/2，产出 b≈8.69。
- 证据：`tools/seismology/stats-attenuation.html:124-130,206-230`（`:209` 仅判长度、`:214-215` b/a、`:220` 频次、`:227` `isNaN(nt)?'—':nt.toFixed(2)`）。node 复算：K=100、c=-10、p=1、t=10 → n(t)=Infinity，页面显示 "Infinity"；K=-100 → "-9.09"；震级 [4.0,4.0] → b=8.6859（显示 8.69）、a=35.04。
- 影响：非物理参数与等值序列被当作有效分析结果，b 值与余震频次解释会失真。
- 方案：震级要求有限且 ≥0，K>0、c≥0、p>0、t≥0 且 t+c>0，并设上限；`mean==Mmin` 时提示样本无跨度、不给 b/a；用 `isFinite` 取代 `isNaN`；补极端用例。

### 12-G9 粘接故障诊断：固化 0 分钟不预警，简介/深度解析宣称的评分统计未实现（中，确认）
- 描述：风险等级只由表面处理、固化 <10 min（要求 `cure>0`）、温度 >120℃、塑料/橡胶基材计条数；`cure=0` 或负值不触发任何预警，表面已打磨时可判"低"。同时简介与深度解析以"10 个严重度评分的均值/中位数/标准差"为算例、FAQ 讨论"样本量"，但页面只有现象/基材/温度/固化/表面处理五个输入，calc 从不做统计。
- 证据：`tools/bonding/analysis-resolution.html:127-146,225-257`（`:246` `cure>0&&cure<10`、`:249` 风险分级）、`:179` 深度解析算例、`:182-183` FAQ、`:306` 简介使用场景。按源码复算：现象"开胶脱落"、基材"金属"、温度 25、固化 0、表面"打磨" → warns=[]、风险"低"。
- 影响：零固化时间被当作低风险；简介/深度解析与真实功能错位，用户按评分统计预期使用会找不到入口，也不利于搜索词匹配。
- 方案：固化时间要求 >0 且低于工艺下限（如 <10 min）一律告警，负值拦截；温度设合理区间；要么补"批量评分统计"输入并实现均值/标准差，要么把深度解析与 FAQ 改写为与故障矩阵一致的案例。
