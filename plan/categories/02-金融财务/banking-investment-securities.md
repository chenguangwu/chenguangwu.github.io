### B-F2 债务收入比页无债务时「收入债务倍数」等于月收入数值（中，确认）

- 影响：无负债用户会看到「1 万倍」的荒谬指标，误以为是杠杆倍数；负数债务或负数收入同样可写入并产出负 DTI。

- 方案：`trough<=0` 时恢复涨幅显示「—/无法恢复」，去掉 `||1`；校验 `peak>0` 且 `0<trough<peak`，顺序错误时给出提示。

### B-F9 保证金比例页权益为 0 时杠杆倍数溢出、权益超持仓时借入资金为负（中，确认）
- 描述：`杠杆倍数 = pos/Math.max(eq,1e-9)`（`tools/securities/margin-requirement.html:283`），权益为 0 时用 1e-9 兜底；`借入资金 = pos−eq`（`:282`）未区分「无借入」。守卫只拦 pos=0（`:246-256`），不拦 `eq<=0` 或 `eq>pos`。
- 证据：`tools/securities/margin-requirement.html:276-286`；复现 eq=0、pos=100000 → 保证金 0.0%、借入资金 100000.00、杠杆倍数 100000000000000.000；eq=120000、pos=100000 → 保证金 120.0%、借入资金 −20000.00。
- 影响：零权益账户显示 1e14 倍杠杆这类溢出数字；权益超过持仓时「借入资金」为负却被当作正常结果。
- 方案：eq<=0 时报错或显示「—」；eq>pos 时借入资金显示 0 并提示「无借入资金」；加 eq、pos 非负校验。

### B-F10 索提诺页每次计算额外写入一条「对比结果」历史（低，待验证）
- 描述：`sortino-ratio.html:426-445` 在 `calcTool` 末尾调用 `__sr()`，从最近 8 秒内的历史记录取最后一个字段值，再 `TBKit.history.record({对比结果: acc})` 写回历史。按代码顺序，每次点击「计算」会先由 `:325` 写入正常记录，再由 `:442` 追加一条重复「对比结果」记录。
- 证据：`tools/investment/sortino-ratio.html:325,426-445`；仅静态阅读推演，`TBKit.history.list()` / `last()` 的实际排序与去重未在浏览器复核，故标待验证。
- 影响：若成立，历史面板会按点击次数翻倍增长，且「对比结果」随时间漂移，干扰复核。
- 方案：删除该自记录块，或改为仅在用户显式「记录对比」时写入；先确认历史列表排序与去重口径。
