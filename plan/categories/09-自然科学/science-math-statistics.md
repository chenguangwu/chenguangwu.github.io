### SMS-1 单样本 t 检验允许 n=0/1 并输出误导性 p 值（高，确认源码缺陷）
- 描述：主计算只校验四项非空、`sd≠0`、`n` 不为负，未要求样本量为整数且 ≥2。n=1 时 `df=0` 仍走 `betai` 得 p=0；n=0 时除以 `√0` 使 t=0、df=−1，p 反而为 1。结果区分别显示 `p=0.0000`（看似极显著）与 `p=1.0000`（看似完全不显著）。
- 证据：`tools/statistics/one-sample-t-test.html:270,282-291`（仅拦 sd=0、n<0）；`:333-341`（`df=n-1`、`betai(df/2,0.5,…)`）。node 内存复算：`xbar=52,mu0=50,sd=10,n=1` → t=0.2, df=0, p=0；`n=0` → t=0, df=−1, p=1。页面 `:127` 的公式说明也自述「增强另要求 s>0 且 n≥2」，与主算不一致。
- 影响：`tools/statistics/one-sample-t-test.html`；非法样本量可得到「显著/不显著」结论，用户无从察觉。
- 方案：主算统一要求 n 为整数且 ≥2、df≥1，否则给出明确错误并清空结果；补充 n=0、1、小数、负数的用例。

### SMS-2 F 方差检验允许 n=1 并输出 p=0（高，确认源码缺陷）
- 描述：守卫只拦 `n<0`，n=1 通过后 `df1=0`，双侧 p 被算成 0，主结果显示 `双侧 p 值 0.0000`；页面自称后面板「另要求样本量 ≥2」，但主结果先给出了显著性结论。
- 证据：`tools/statistics/f-test-variance.html:283-293`（`__N` 仅判 `_nv<0`）；`:334-343`（`df1=n1-1`、`p=2*Math.min(pr,pl)`）。node 复算：`s1=25,s2=16,n1=1,n2=18` → F=1.5625, df=(0,17), p=0。
- 影响：`tools/statistics/f-test-variance.html`；单侧无样本量时被误报「方差不齐」。
- 方案：主算前要求 n₁、n₂ 为整数且 ≥2，df≥1；错误时同时禁用明细表与临界值矩阵。

### SMS-3 SI 单位换算把小于 1e-12 的结果强制显示为 0（高，确认源码缺陷）
- 描述：`fmt()` 先判断 `Math.abs(x)<1e-12` 直接返回 `'0'`，导致飞米/阿米等极小单位换算结果被归零；显示为 `1 fm = 0 cm`，与「换算系数」行同时出现 0，用户会误判为精确等价。
- 证据：`tools/science/si-unit-converter.html:482-487`（`if(Math.abs(x)<1e-12) return '0';`）；长度单位 `:301-304`（fm=1e-15、am=1e-18、zm=1e-21、ym=1e-24）；默认目标单位索引 12 为厘米 `:296,519`；换算与拼接 `:556-568`。node 复算：1 fm→cm = 1e-15/1e-2 = 1e-13，小于 1e-12 → `'0'`；而 `|x|<1e-6` 本应走 `toExponential(6)`。
- 影响：`tools/science/si-unit-converter.html`；长度（及质量/时间等含极小词头的量）换算出现结构性零值。
- 方案：删除「<1e-12 归零」分支，负指数区间继续用科学计数法；为 fm/am/zm/ym 与 cm/mm 组合补数值用例。

### SMS-4 卡方页自由度与 2×2 预设自相矛盾且明细表与主算口径不同（中，确认源码缺陷）
- 描述：主算固定 `df=n-1`；预设「性别 × 偏好（2×2 简化）」用 4 个格值，得到 df=3，而同页引据表明确写独立性检验 `df=(r-1)(c-1)`（2×2 应为 1）。此外页面名为「卡方检验」却不输出 p 值。明细面板又用 `Math.min` 截断并过滤非法项，长度不一致或含 `bad` 时主算报错/显示破折号，表格却照常给出另一套 χ² 与占比。
- 证据：`tools/statistics/chi-square-test.html:291-301`（主算 `df=n-1`、`parseFloat` 不过滤）；`:314-327`（`Math.min(oa.length,ea.length)`、`filter(isFinite)`）；`:342-343`（2×2 预设 `o:'50,30,20,40', e:'35,35,35,35'`）；`:373`（引据表 df 公式）。复算：该预设 χ²=500/35=14.2857，主结果显示 df=3；作为 2×2 列联应为 df=1。`o='50,30,bad'`、`e='40,40,20'` 时主算 χ² 为 NaN→「—」，明细按 2 行算得 χ²=2.5。
- 影响：`tools/statistics/chi-square-test.html`；自由度与显著性判读错误，主结果与明细互斥。
- 方案：显式区分「拟合优度（df=k−1）」与「2×2 列联（df=1）」，按模式计算 df 与 p；主算与明细共用同一份校验后的数组；非法项直接报错而非过滤。

### SMS-5 比值比页拒绝零格，与页内 Haldane 校正说明冲突（中，确认源码缺陷）
- 描述：守卫把 a/b/c/d 全部登记为「分母」，任一格为 0 即中止，报错文案还称该格是「本计算的分母」；但同页引据表写明「任一格为 0 时各格加 0.5（Haldane-Anscombe 校正）」，实现没有校正路径，增强面板也以 `a<=0||…` 直接返回。
- 证据：`tools/statistics/odds-ratio.html:269`（`__D` 含 a,b,c,d）；`:275-278`（任一格 0 即返回报错）；`:321`（`if(a<=0||b<=0||c<=0||d<=0) return;`）；`:410`（零格校正说明）。复现输入 `a=0,b=10,c=5,d=5` → 直接显示「⚠「a（暴露&结局）」是本计算的分母，不能为 0。」；按页内校正应为 (0.5×5.5)/(10.5×5.5)=0.0476。
- 影响：`tools/statistics/odds-ratio.html`；真实零格 2×2 表无法计算，且错误原因描述不准确。
- 方案：允许零格并统一应用 +0.5 校正（结果明确标注「Haldane 校正」）；或删除该引据说明；报错文案改为「任一格为 0 时 OR 无定义，可启用 0.5 校正」。

### SMS-6 有效数字修约在半值处向下错位并少给位数（中，确认源码缺陷）
- 描述：`roundToSig` 用 `Math.round(num*Math.pow(10,…))`，二进制表示使恰好半值被向下取整：1.015 保留 3 位得 1.01（十进制半入/银行家法均应为 1.02），1.005 保留 3 位得 1（页面仍宣称「保留 3 位有效数字」）；另 `sig` 超过 20 被内部截断为 20，但提示文案仍显示用户输入值。
- 证据：`tools/science/significant-figures.html:218-226`（`Math.round(num*factor)/factor`）；`:238-252`（文案直接拼 `保留 ' + sig + ' 位`）。node 复算：`1.015,3 → 1.01`、`1.005,3 → 1`、`1234.5678,25 → 1234.5678`（提示仍为 25 位）。
- 影响：`tools/science/significant-figures.html`；实验数据报出的末位与有效位数不符。
- 方案：改用十进制安全的修约（按指数拆分尾数与幂次，或按量级加微小偏移后取整），明确半值规则；`sig` 超出范围时直接报错或在文案中使用生效值；补 1.005/1.015/2.675 等用例。

### SMS-7 单因素方差分析接受 n=0/1/小数并可能显示看似正常的 F、p（中，确认源码缺陷）
- 描述：守卫既无分母表也无负值/整数校验，样本量 0、1、非整数全部放行。n₁=n₂=n₃=1 时 `dfw=0`、F/p 为 NaN；n₃=0 时组内平方和仍按 `(n−1)s²` 得负值，但因其他两组撑起 df，最终仍输出 F=2.5、p=0.1117，看起来像一次正常分析；小数 n 还能得到小数自由度并按 `toFixed(0)` 四舍五入展示。
- 证据：`tools/statistics/one-way-anova.html:292`（`__D={}`，且无 `__N`）；`:343-357`（`ssw+=(ns[i]-1)*ss[i]*ss[i]`、`dfw=N-k`、`toFixed(0)`）。node 复算：`n=1,1,1` → dfw=0, F/p 为 NaN；`n=10,10,0（m3=14,s=2）` → ssw=68, dfw=17, F=2.5, p=0.1117；`n=2.5,2.5,2.5` → dfw=4.5。
- 影响：`tools/statistics/one-way-anova.html`；无观测的组仍参与组间均值，结论不可信。
- 方案：要求每组 n 为整数且 ≥2、dfw≥1；拒绝非整数与负值；对 dfw<1 直接报错并清空结果。

### SMS-8 正态 CDF 对 σ≤0 静默按 1 计算且无任何提示（低，确认源码行为）
- 描述：σ 为空、0 或负数时被直接替换为 1，继续输出 Φ 与「对应原始值 x=μ+zσ」；例如 μ=500、σ=0、z=1 会显示 x=501，清空输入则得 Φ=0.50000，页面没有任何「已按 σ=1 计算」的提示。
- 证据：`tools/statistics/normal-cdf.html:247-252`（`if(!isFinite(sg)||sg<=0) sg=1;`、`xv=mu+z*sg`）；`:253-258`（直接展示结果）；`:126` 公式说明虽写明「σ 非有限或 ≤0 按 1 兜底」，但结果区无警示。
- 影响：`tools/statistics/normal-cdf.html`；无效标准差被当作有效输入，原始值换算失真。
- 方案：σ≤0 或空值时明确报错；若保留兜底语义，至少在结果区标注「σ 无效，已按 1 计算」并禁用历史记录与导出。

### SMS-11 pH 页清空 pH 输入后按 0 计算，直接给出「pH=0、强酸、[H⁺]=1 mol/L」（中，确认缺陷）

- 证据：`tools/science/ph-calculator.html:334-346`（空串→0 且通过校验）、`:304-306`（另一分支有 `H<=0` 拦截）。

- 影响：`tools/science/ph-calculator.html`；漏填被当成极端强酸，得到完全错误的浓度换算。

### SMS-12 pH 页酸碱分级把 pH 6–8 全部判为「中性」，6.5 与 7.5 得到同一标签（中，确认口径错误）
- 问题：分级阈值写成「<3 强酸、<6 弱酸、>11 强碱、>8 弱碱、其余中性」，即 `[6,8]` 整段都标「中性」。pH 6.5 实为弱酸、pH 7.5/8.0 实为弱碱，却被标中性；页内公式说明（`:168`）把这套阈值写成「代码口径」，等于把错误口径固化为说明。
- 证据：`tools/science/ph-calculator.html:310-314`（由 [H⁺] 分支）、`:340-344`（由 pH 分支，重复同一套阈值）、`:168`（公式说明）。

- 影响：`tools/science/ph-calculator.html`；结果区的水质类型标签错误，教学场景会误导（弱酸/弱碱分界应落在 7 附近，且中性只应是 25 ℃ 下 pH≈7）。
- 方案：按 7 为分界改为「pH<3 强酸、3≤pH<6 弱酸、6≤pH<7 微酸、pH=7 中性、7<pH≤8 微碱、8<pH≤11 弱碱、>11 强碱」，两分支共用同一分级函数，并同步改公式说明。

### SMS-13 pH 页缓冲体系 pKa 与标签错配：选「磷酸二氢」实际用 6.35（应为 7.20）（中，确认缺陷）

### SMS-14 p 值页把自由度 `parseInt` 截断，χ²=9.49、df=4.9 被按 df=4 算，p 从 0.086 变成 0.050（中，确认缺陷）
- 问题：t/卡方两个模式的 df 都用 `parseInt(value)`，小数被静默向下取整且无提示；输入框 `step="any"` 允许小数，于是 df=4.9 被当成 4，p 值恰好跨过 0.05 判定线（0.0862 → 0.04995），结论从「不显著」翻成「显著」。
- 证据：`tools/science/p-value-calculator.html:396`（t 模式 `parseInt(df1)`）、`:407`（卡方模式 `parseInt(df2)`）、`:400`/`:359`（直接代入 CDF）。
- 复现（node 复刻页面 `tCDF`/`chiSquareCDF`）：`χ²=9.49, df=4.9` → 实际 p=0.049953（显示 0.0500，判「拒绝 H₀」）；正确 df=4.9 → p=0.086232（不拒绝）。`t=2.5, df=2.5` → 实际按 df=2 得双侧 p=0.129612；按 df=2.5 应为 0.104570（且页面 df 卡片仍显示 2）。
- 影响：`tools/science/p-value-calculator.html`；小数自由度（Welch 校正、Satterthwaite 近似 df 常见为小数）被静默改值，p 与结论可能反转。
- 方案：用 `parseFloat` 并保留小数自由度（t/χ² 的 CDF 实现本身支持非整数 df）；若坚持整数 df，则输入框改 `step="1"` 并在检测到小数时报错，而不是截断。

### SMS-15 效应量页 n₁=n₂=1 时 d=NaN，仍判「极大效应」并给 r²=0（中，确认缺陷）
- 问题：两独立组守卫只要求 `n≥1`，未要求 `n₁+n₂−2>0`。n₁=n₂=1 时池化分母为 0 → `sdPooled=NaN` → `d=NaN`；结果卡把 `NaN` 渲染成占位符，但 `interp(NaN)` 里所有 `<` 比较均为 false，直落到 `return '极大效应'`，同时 `r2FromD` 的 `den>0` 为 false 返回 0，于是同屏出现「d 未定义 / 效应量等级 极大效应 / r²=0」。
- 证据：`tools/science/effect-size-calculator.html:343`（守卫 `n1<1||n2<1`）、`:345-347`（`(n1+n2-2)` 作分母、`interp(d)`）、`:287-293`（`interp` 兜底返回「极大效应」）、`:306-308`（r² 兜底 0）。
- 复现：m₁=85, SD₁=10, n₁=1；m₂=78, SD₂=12, n₂=1 → 实际 `SD_pooled=NaN`、`d=未定义`、等级「极大效应」、`r²=0`；期望明确报错「每组至少 2 个观测/df>0」。
- 影响：`tools/science/effect-size-calculator.html`；最小样本输入得到最极端的效应量标签，结论方向完全相反。
- 方案：守卫改为 `n1+n2-2>=1`（并校验整数、`n≥2`）；`interp` 前先判 `Number.isFinite(d)`，非有限值不参与分级；同时同步禁用 r² 与 U₃ 卡片。

### SMS-16 样本量页 p=0/1 直接给出「推荐样本量 0」，E>100% 给出 1，N 小数被截断（中，确认缺陷）
- 问题：p 只校验 `0≤p≤1`，端值放行：p=0 或 1 时 `p(1−p)=0` → n₀=0 → 结论「需至少调查 0 个样本」。误差范围 E 只校验 `>0`，无上限，E=150（即 ±150%）仍计算得 n=1。总体规模 N 用 `parseInt`，50.5→50；N=0 被跳过并按无限总体处理且无提示。
- 证据：`tools/science/sample-size-calculator.html:283`（`p<0||p>1` 放行端值）、`:279`/`:282`（E 仅判 >0）、`:286-288`（n₀ 公式）、`:289-295`（N 为 `parseInt` 且 `N>0` 才生效）、`:296-298`（直接输出 nFinal）、`:318`（「需至少调查 n 个样本」文案）。
- 复现：conf=0.95, E=5, p=0 → 实际「推荐样本量 n = 0」；期望报错「p 需在 (0,1) 开区间」。E=150, p=0.5 → 实际 n=1；期望拒绝 E>100 或提示不合理。N=50.5 → 实际按 N=50 修正得 n=45；期望提示 N 须为正整数（或保留小数）。
- 影响：`tools/science/sample-size-calculator.html`；调查/试验规模被算成 0 或 1，且无任何警示。
- 方案：p 改开区间校验（0<p<1）、E 加上限（如 ≤50%）并提示、N 校验正整数且要求 N≥n（否则提示「总体小于所需样本，建议全查」）；端值一律 toast 中止。

### SMS-17 卡方页静默过滤 0 频数/负数/非数字项，类别数、df 与 χ² 随之改变（中，确认缺陷）
- 问题：观察频数与期望频数都走 `filter(n=>!isNaN(n)&&n>0)`：合法的 0 频数被丢弃（0 是拟合优度检验的有效观测），负数被静默丢弃，`bad` 之类非数字项也被静默丢弃。过滤后按剩余项重算类别数、df=k−1 和全部期望（默认 E=total/k），用户看不到「有一项被丢掉」，结果与输入不符。
- 证据：`tools/science/chi-square-calculator.html:325`（obs 过滤）、`:331`（exp 过滤）、`:334`（缺失期望按 total/obs.length 重算）、`:336`（`df=obs.length-1`）、`:327`/`:332`（只在剩余项 <2 或个数不等时报错）。
- 复现：`obs="10,0"`、期望留空 → 实际「至少需要 2 个观察频数」中止（0 被丢弃后只剩 1 项）；期望按 2 类目、E=5 得 χ²=10、df=1、p=0.001565。`obs="30,25,bad,20,15,10"`、期望留空 → 实际按 5 类目（`bad` 被吞）得 χ²=12.5、df=4、p=0.013996；期望提示第 3 项非法并中止，或按用户本意的 6 类目计算（类别数不变）。
- 影响：`tools/science/chi-square-calculator.html`；零频数表无法计算，含错项时静默得到另一套自由度与 p 值。
- 方案：解析后逐项校验，非有限值/负数直接报错并指明第几项；允许 0 频数（仅当期望也为 0 时该项跳过并提示）；不再过滤后重算，保持用户输入的类别数。

### SMS-18 卡方页自由度恒为 k−1，「独立性检验 df=(r−1)(c−1)」的承诺未实现（2×2 预设也按 df=3 输出）（中，确认缺陷）
- 问题：主算固定 `df=obs.length−1`，没有任何模式区分；页内公式说明与 FAQ 都写「独立性检验 df=(r−1)(c−1)」，预设里还内置了「2×2 独立性检验」。选该预设（4 个格值）时按 k−1 得 df=3，而 2×2 列联应为 df=1，χ²=10 的 p 从 0.00157 变成 0.01857。
- 证据：`tools/science/chi-square-calculator.html:336`（`df=obs.length-1`）、`:169`（公式说明「独立性检验 df=(r−1)(c−1)」）、`:219`（FAQ 同述）、`:492`（预设「2×2 独立性检验」obs=`30,20,15,35`、exp=`25,25,25,25`）、`:351`（步骤文案直接写 df=k−1）。
- 复现（node 复刻）：该预设 χ²=(5²+5²+10²+10²)/25=10 → 实际 df=3、p=0.018566；作为 2×2 独立性检验期望 df=1、p=0.001565。另 `obs=50,30,20,40`、`exp=35...` → 实际 df=3、p=0.002541；2×2 应为 df=1。
- 影响：`tools/science/chi-square-calculator.html`；凡按列联表输入的 2×2/2×3 表，自由度与 p 值都错（同类问题见 SMS-4，但那是另一页 `tools/statistics/chi-square-test.html`）。
- 方案：增加「拟合优度 / 独立性（输入行×列）」模式：前者 df=k−1，后者按用户填写的行、列数算 df=(r−1)(c−1)；2×2 预设改为明确按 df=1 计算，或在预设名中标注「拟合优度」。

### SMS-19 ANOVA 页静默丢弃非数值项，N、dfW 与 F/p 全部随之改变（中，确认缺陷）
- 问题：每组按 `parseFloat` + `filter(!isNaN)` 解析，非法记号被静默删除，不报错；该组样本量因此变小，N、dfW=N−k、MSW 与 F 全部按缩小后的数据计算，用户无从发现少了一个观测。
- 证据：`tools/science/anova-calculator.html:321`（`filter(n=>!isNaN(n))`）、`:320`/`:322`（只校验组数 ≥2 与组非空）、`:334-337`（dfW、MSW、F、p）。
- 复现：三组 `5,7,9 / 6,bad,8 / 7,9,11` → 实际第二组变 `[6,8]`，N=8、dfW=5、SSB=7.5、SSW=18、F=1.0417、p=0.4186；若 `bad` 本意是 7（三组各 3 个观测），期望 N=9、dfW=6、F=1.3333、p=0.3318。
- 影响：`tools/science/anova-calculator.html`；一个拼写/全角逗号错误就会改变样本量、自由度与显著性结论，且无提示。
- 方案：解析后校验每行 token 数与数值有效性，出现非数字项即报错并指出组号与位置；不要静默过滤。

### SMS-20 ANOVA 页未拦 dfW=0（每组仅 1 个观测）：F 显示「未定义」却给出 p=1.0000 与「无显著差异」结论（中，确认缺陷）
- 问题：守卫只要求「至少 2 组」「每组非空」，不要求每组 ≥2 个观测。每组 1 个观测时 dfW=N−k=0，`msw=ssw/0` 为 0/0=NaN，F=NaN；`fUpperP(NaN,…)` 因 `!(f>0)` 直接返回 1，于是表格出现「组内自由度 0 / MSW 未定义 / F 未定义」，末尾仍输出「p = 1.0000，不拒绝 H₀，组间均值无显著差异」。
- 证据：`tools/science/anova-calculator.html:319-322`（组数与空组守卫）、`:334-337`（dfW、msw、F、p）、`:265-271`（`fUpperP` 对非正 F 返回 1）、`:360`（p≥0.05 文案）。

- 影响：`tools/science/anova-calculator.html`；退化输入被评为「不显著」，与「无法检验」混淆。

### SMS-21 配平页把输入前导系数当成元素倍数保留，输出出现「22H2」「22H2O」这类无意义系数串（中，确认缺陷）
- 问题：`parseFormula` 把每个物种开头的数字当作整段组成倍数（`mult`），但物种字符串本身仍带该数字；后续把求解系数与「含前导数字的物种串」直接拼接，系数就被重复计入显示。输入已配平的方程式（带系数）时尤其明显。
- 证据：`tools/science/equation-balancer.html:371-376`（前导数字进 `mult` 且不清洗 `seg`）、`:589-598`（纯文本 `(c===1?'':c)+species[k]`）、`:601-610`（HTML 同样拼接）、`:594`/`:606`（拼接点）。
- 复现（node 复刻）：`2H2 + 2O2 = 2H2O` → 实际输出 `22H2 + 2O2 = 22H2O`（把 2×"2H2" 印成 22H2）；`2H2 + O2 = H2O` → 实际 `2H2 + O2 = 2H2O`（碰巧正确）。期望先剥离前导系数只保留组成，输出系数从 1 重新编号，或直接拒绝带系数的输入并提示「请只输入化学式」。
- 影响：`tools/science/equation-balancer.html`；用户粘贴已配平方程式时得到语法上不存在的物种，复制/导出结果不可用。
- 方案：解析时把前导数字从显示用 species 中剥离（另存原始串仅用于回显），配平结果只按求解系数渲染；若检测到输入带系数，提示「已忽略输入系数」。

### SMS-22 配平页对欠定（多解）方程静默返回其中一个解，与页内「否则报错」的自述矛盾（中，确认口径问题）
- 问题：当零空间维数 >1（元素守恒方程不足以定解）时，`searchCombination` 在有限权重网格内挑「最大系数最小」的一组返回；`!coeffs` 的「存在多种配平方式（欠定）」报错分支只在搜索不到任何全正/全负组合时才触发，实际几乎不可达。页内公式说明却写「系数比唯一（或成整数倍）时方程式可配平，否则报错」。
- 证据：`tools/science/equation-balancer.html:468-496`（网格搜索取最小最大系数）、`:537-556`（多解报错分支）、`:177`（公式说明承诺唯一性）。
- 复现：`C + O2 = CO + CO2` → 实际 `3C + 2O2 = 2CO + CO2`（同为守恒解；`2C + 1.5O2 = CO + CO2`、`C + O2 = CO2` 等无穷多组均成立），无「多解」提示；`KClO3 = KClO4 + KCl` → 实际 `4KClO3 = 3KClO4 + KCl`，同样是一族解中的一组。
- 影响：`tools/science/equation-balancer.html`；用户会把任选的某一组当成唯一正确答案，尤其在多产物燃烧/歧化反应中。
- 方案：`basis.length>1` 时明确提示「该方程存在无穷多组配平系数，以下为其中一组」并列出至少两组；或要求用户指定某产物的系数后再求解；同步修正公式说明。
