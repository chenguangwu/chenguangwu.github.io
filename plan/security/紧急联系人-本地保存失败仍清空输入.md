# 紧急联系人：本地保存失败仍清空输入

## 问题描述
添加联系人时，本地存储写入异常被 `saveCustom` 捕获，但调用方无论是否写入成功都会清空姓名、号码和备注、重新读取列表并执行成功提示。存储受限或空间不足时，联系人没有保存，刚填写的内容也丢失；删除失败同样可能表现为已操作。此结论来自源码，需模拟浏览器存储失败复核。

## 解决方案
让保存函数返回明确状态；仅在成功写入后清空表单及提示成功，失败时保留输入并显示可重试的中英文提示。删除操作也应反馈真实结果，并验证存储禁用及容量不足。
