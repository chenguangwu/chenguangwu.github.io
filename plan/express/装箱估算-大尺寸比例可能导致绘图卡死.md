# 装箱估算：极端尺寸比例导致绘图次数失控

- 受影响工具：`tools/express/box-fit.html`
- 问题：输入尺寸没有上限或最小正数限制，`drawChart()` 按单层长宽件数逐件双重循环绘制。例如物品 0.01×0.01×1 cm、箱体 1000×1000×1 cm、间隙与余量为 0 时，单层需循环约 100 亿次，可能长时间冻结页面。该结论来自源码循环次数，未在浏览器执行极端用例。
- 方案：限制绘图复杂度，超出阈值时改用聚合图或抽样示意并标明非逐件绘制；对超出安全数值范围的计算提供明确提示，不静默截断。
- 验证：覆盖普通与大比例输入，确认计算结果、界面响应和示意说明一致。
