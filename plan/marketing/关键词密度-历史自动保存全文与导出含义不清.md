# 关键词密度：历史自动保存全文且导出含义不清

受影响工具：`tools/marketing/marketing-keyword-density.html`

## 问题描述
输入处理快照会采集带 id 的 textarea 和 input，自动将正文及关键词写入工具历史；粘贴未公开文章可能在本机留下完整文本。CSV 导出读取的是历史表，而非明确构建当前分析明细，用户可能误认为只导出当前结果。

## 解决方案
提供明确的本地保存说明和可关闭选项，默认避免持久化全文或仅保存用户主动选择的记录；区分“导出当前统计”和“导出历史”，并展示包含字段、提供清除入口。浏览器中核验实际存储与导出内容。
