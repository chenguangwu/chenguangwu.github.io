# 关键词密度：扩展汉字统计与字符长度口径错误

- 受影响工具：`tools/marketing/marketing-keyword-density.html`
- 问题：中文字数只匹配 `\u4e00-\u9fa5`，遗漏基本区尾部及扩展区汉字；总字符数和关键词字符数则使用 JavaScript 字符串的 UTF-16 长度，扩展区汉字通常按两个代码单元计数。例如单个 `𠀀` 的中文字数为 0，而总字符数为 2。静态分析与语言运行时计数规则可确认，界面仍待实测。
- 解决方案：明确统计单位，使用适当的 Unicode 汉字属性统计中文字，并以 Unicode 码点或用户可感知字符统一计算分子分母；覆盖扩展汉字、组合字符和混合文本，注明统计规则及浏览器兼容性。
