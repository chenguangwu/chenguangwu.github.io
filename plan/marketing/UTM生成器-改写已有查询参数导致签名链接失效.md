# UTM 生成器：已有查询串会被整体重编码

受影响工具：`tools/marketing/utm-builder.html`

## 问题描述
`__utmAppend()` 用 `URLSearchParams` 解析并重新序列化所有非 UTM 参数；例如 `?q=a%20b&x=~` 会被改写为 `?q=a+b&x=%7E`。对于按原始查询字符串签名的链接，即使参数语义不变也可能使签名失效；函数还删除所有 `utm_*` 参数，包括表单不支持的扩展字段，可能丢失原有追踪信息。

## 解决方案
保留无关参数的原始编码与顺序，仅替换明确受支持的 UTM 键；对签名 URL 显示重新签名或避免修改的提示，并让用户确认是否清除其他 UTM 字段。验证重复键、空值、编码、fragment 及签名 URL。
