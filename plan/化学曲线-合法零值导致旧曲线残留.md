# 化学曲线：合法零值导致旧曲线残留

## 问题

气体分压允许摩尔分数输入 0 并计算零分压，当量浓度允许物质的量输入 0 并计算零浓度；但各自曲线采样要求对应数值大于 0，遇到 0 时直接返回而不清除旧图。用户从正值改为 0 后，主结果与图表可能对应不同条件。分压曲线扫描的是一系列摩尔分数，本身并不需要当前摩尔分数为正。

## 解决方案

统一主结果与图表的合法范围：当量浓度的零物质的量应绘制零值曲线；分压曲线按有效总压绘制并正确表示当前零分数。确实无法绘图时清除旧图并解释原因，分别验证正值→零值→正值的切换。
