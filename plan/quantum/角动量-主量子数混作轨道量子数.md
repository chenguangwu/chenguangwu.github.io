# 角动量：主量子数混作轨道量子数

- 受影响工具：`tools/quantum/angular-momentum-quant.html`
- 问题：输入标为主量子数 n，程序却把 n 直接代入轨道角动量 √l(l+1)ħ；同时把 `(n−1)ħ` 标成相邻能级角动量差，而并非 nħ 与 (n−1)ħ 的差。没有对空值、整数和取值范围作校验。
- 解决方案：区分玻尔模型的 nħ 与量子力学的轨道量子数 l，提供合法的量子数选择和适用模型说明；重新定义或移除错误的差值指标，统一附表和中英文描述。
- 验证建议：以 n=1、l=0 和 n=3、l=0/1/2 对照公式，并测试空值、负数及小数。
