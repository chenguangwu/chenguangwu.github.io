# 盲文转译：点位图排列与盲文编号不一致

## 问题

页面说明六点盲文左列从上到下是 1、2、3，右列是 4、5、6；但结果点位图和字母对照图均按 1、2、3、4、5、6 顺序插入两列 CSS 网格，浏览器按行排列，导致第一行显示 1、2，第二行 3、4，第三行 5、6。例如字母 b 的点位 1、2 应在左列上、中两格，当前图却点亮第一行左右两格。Unicode 盲文输出本身通过点位位掩码生成，与这个图形排列问题不同。以上为静态分析。

## 解决方案

按 1、4、2、5、3、6 的行优先顺序绘制，或为每个点明确指定网格行列；同时修正结果图和字母对照图。用 b、c、数字符及全部六个单点核对图形位置与输出字符，并提供可由读屏识别的点位说明。
