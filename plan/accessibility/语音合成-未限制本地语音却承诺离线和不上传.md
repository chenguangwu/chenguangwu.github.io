# 语音合成：未限制本地语音却承诺离线和不上传

## 问题

页面 FAQ 断言语音合成无需联网且文字不上传服务器，但 `loadVoices()` 将浏览器返回的声音全部列出，播放时直接将所选声音交给 `speechSynthesis`，未检查语音的 `localService` 属性，也未处理没有本地声音时的情况。浏览器可能提供远程语音，因此仅凭调用 Web Speech API 不能证明所有所选声音都离线处理。静态代码可确认缺少限制；具体浏览器及声音的实际网络行为待验证。

## 解决方案

优先只允许可确认由本地服务提供的声音，明确标识不可确认或远程声音并禁止发送文本；没有满足条件的声音时显示可理解的提示，不静默使用浏览器默认声音。核实不同浏览器的实际出站行为及断网效果，再让 FAQ、中英文说明与实现一致，确保符合项目本地处理约束。
