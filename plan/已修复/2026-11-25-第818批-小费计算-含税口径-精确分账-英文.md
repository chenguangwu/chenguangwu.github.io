# 第818批：小费计算含税口径、精确分账、英文结果与人数校验

日期：2026-11-25

受影响工具：`tools/hotel/tip-calculator.html`

## 修复内容

### 1. 含税/未含税两种口径

- 新增「消费金额口径」：未含税（税额另加）、已含税（税额从账单中拆出）。
- 未含税：税额 = 账单 × 税率，总额 = 账单 + 税额 + 小费。
- 已含税：税额 = 账单 × 税率 ÷（100 + 税率），税前 = 账单 − 税额，总额 = 账单 + 小费；不再重复加税。
- 新增「小费基数」：按账单金额或按税前金额，已含税时可避免用含税金额重复放大。
- 公式说明同步改写，明确两种口径。

### 2. 精确分账

- 新增「货币最小单位」：CNY/USD/EUR 2 位、JPY 0 位、KWD 3 位。
- 按所选精度换算最小单位后取整分账：先均分，余数从第 1 人起依次多 1 个最小单位，各人金额之和严格等于总额。
- 覆盖 10 元 ÷ 3 人（3.34 + 3.33 + 3.33）与日元 0 位精度（4 + 3 + 3）；页面展示分账明细与余数说明。
- 「导出明细 CSV」改为导出当前口径、税额、税前、小费、总额、人数、精度、余数及逐人金额，和页面/复制结果同源。

### 3. 人数与数值校验

- `calc()` / `copyResult()` 共用 `tipRead()`：人数用完整 `Number` 转换后校验有限正整数，`2.5` 直接报错，`1e2` 正确按 100 人计算，不再 `parseInt` 截断。
- 金额、小费比例、税率分别做有限非负校验；低值 0 仍为合法输入。

### 4. 英文结果、复制与简介

- 新增 `tipIsEn()`：优先读 `I18n.lang`、`html lang` 与 `?lang=`，避免仅依赖 `TBKit` 时英文态回退中文。
- 结果、错误提示、复制文本、CSV 表头全部按当前语言生成；英文复制链路实测无中文。
- 英文标题改为 `Tip Calculator`，简介说明小费、税额、总额和精确分摊；同步 `_en_override`、`hotel-body`、`slug-en`、`hotel.json`、`hotel-phrases` 与英文第三层字典。
- 移除固定「偏低/适中/慷慨」评价，改为中性比例提示，要求先核对账单服务费与当地习惯，不做通用高低判断。
