# 第291批 · 小节 h2 中文态残留英文（承接289/290批「其他区域缺中文」）

## 问题
第289批扩展 `restoreAllDataZh()` 到 p/h3/th/td/span/label/summary/strong，但**未含 h2**；主 h2 由 `applyToolBody()` 的 `ORIG.title` 还原，而**小节 h2**（不在主卡内、非 `card.querySelector('h2')`）无人管辖 ⇒ 永久钉死英文。真实例：`tools/baking/fermentation-time.html` 的 `<h2 data-zh="🍞 酵母鲜干换算">Yeast Conversion</h2>` 在中文态仍显示英文。

## 扫描
- 静态扫 4705 页：4422 个 h2 带中文 data-zh 且静态英文，但 JSDOM 实测绝大多数是**主 h2**（`applyToolBody` 已还原），真正漏还原的是小节 h2：全站仅 **1 页（fermentation-time）+ 1 处（Yeast Conversion）** 属此类（有 ≥2 个小节 h2 的页仅此一页）。97 个含公式符号的 h2 另有 `isFormula` 口径，不可整体替换。

## 修复
`js/tool-i18n.js::restoreAllDataZh()`：
- 选择器加 `h2[data-zh]`。
- 增加 h2 专属公式守卫：`if (el.tagName === 'H2' && isFormula(cur)) continue;`——`PR = …`、`F = …` 等公式标题即使带中文 data-zh 也保留公式原样（主 h2 因 cur 含汉字天然跳过，不受影响）。
- 守卫口径不变：data-zh 含汉字 + 当前文本无汉字 + 无子元素 + 非 data-i18n。

## 验证
- 新增 `scripts/_verify_h2_data_zh.mjs`：4 页（fermentation-time / agriculture-calc-38 / it-barcode-itf / statistics-percentile-rank）× 还原 + 往返 + 公式保留专项 = **9/9**。
- **旧源码差分**：HEAD 版本 **7/9**（两条目标用例正确变红：`Yeast Conversion` 未还原），修复后 9/9。
- 新增门禁 `h2 data-zh chinese restore`，同步 `scripts/gates_manifest.txt`。

## 坑
- 只加 h2 到选择器**不够**：全站有公式型 h2（如 `PR = (Below + 0.5·Equal) / N × 100`）带中文说明型 data-zh，若不加 `isFormula` 守卫会把公式本体替换成中文说明，破坏公式显示。
- 主 h2 不会被二次覆盖：`applyToolBody()` 先把它还原成中文（cur 含汉字），还原守卫天然跳过。
- 只本地 commit，不 push。
