## 2. 残留真 bug：债券定价（price）分支无视 `p-type`

### 失败点
把方法切到「💰 债券定价」、选**零息债**，面值 100、票面利率输入框填 5%（应被忽略）、市场利率 6%、剩余 3 年、年付一次：

- 页面理论价格 `¥83.96` 是对的（100 / 1.06³），但
- 显示 `年利息：¥5.00`、`当期收益率：5.96%`，
- 底部归因写成 `折价发行：票面利率 < 市场利率` —— 零息债的折价来自「面值按市场利率折现」，与票面利率无关。

### 根因
`calc()` 的 `else if(currentMethod === 'price')` 分支里：

```js
var annualCoupon = face * couponRate / 100;
var currentYield = annualCoupon / price * 100;
```

`calcBondPrice()` 已按 `type === 'zero'` 走 `face / (1+r)^n`，但结果对象仍按票面利率算票息；`renderStats` / `renderResult` / `drawChart` 都直接消费 `r.annualCoupon`，于是三处一起错。YTM 分支早已处理零息，price 分支是漏网的一支。

### 修复位点（只改工具页 + 门禁用例，不改构建真源）
`tools/finance/bond-yield-calculator.html`：

1. 新增 `__bondEn()` 动态英文态判定（`(typeof TBKit!=='undefined'&&TBKit.util&&TBKit.util.isEn())`，附 `location.search` fallback），遵循 i18n 双语 helper 纪律。
2. price 分支：

```js
var isZeroPrice = (type === 'zero');
// 零息债券不付息：票面利率输入不参与定价，也不应产出年利息 / 当期收益率（F-N4 残留）
var annualCoupon = isZeroPrice ? 0 : face * couponRate / 100;
var currentYield = isZeroPrice ? 0 : annualCoupon / price * 100;
```

3. `renderResult` price 分支：零息时在年利息行追加 `（零息债券：无票息）` / `(zero-coupon bond: no coupon)`；底部说明改为
   - 中文：`零息债券不付息，价格由面值按市场利率折现得到，票面利率输入不参与计算`
   - 英文：`Zero-coupon bonds pay no coupon; the price is the face value discounted at the market rate, and the coupon-rate input is ignored.`
   - 附息归因补英文 `Premium bond: coupon rate above market rate` / `Discount bond: coupon rate below market rate`。

`statGrid` 与现金流图无需另改：两者直接消费 `r.currentYield` / `r.annualCoupon`，清零后自动同步（图中零息债前 n−1 期票息柱为 ¥0，末期仅剩面值）。

**数值计算逻辑（定价公式）未改**，附息债结果不变。新增文案全部走 `__bondEn()` 运行时双语，不进静态英文 map（不是静态 HTML 串，`translateGenericUI` 不覆盖运行时 innerHTML）。
