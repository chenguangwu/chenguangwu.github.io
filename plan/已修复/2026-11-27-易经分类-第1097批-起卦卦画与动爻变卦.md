# 第1097批：起卦演示修正卦画阴阳、动爻标记与变卦展示

- 受影响工具：`tools/yi/yi-divination.html`

- 状态：修复方已自测，待独立复核

## 问题

1. 生成逻辑以 `type: 1` 表示阳爻，但绘图用 `isChanged ? !l.type : l.type` 判断，静卦阶段把 `type: 1` 当成阴爻，卦画与 `mainKey` 查表结果相反。
2. 页面只绘制本卦，不标注动爻，也不展示变卦，用户无法核对变卦由哪些爻变化而来。
3. 变卦绘图把“所有爻”都反转，而变卦规则只应反转 `change: true` 的动爻；单动爻场景会把另外五爻也画错。
4. 动爻、爻位与阴阳属性没有文本说明，屏幕阅读器也读不到每爻状态。

## 修复

- 统一绘图取值：`effectiveType(line, isChanged)` 仅在 `isChanged && line.change` 时反转，其他爻保持原值；`isYin = type === 0`，`type: 1` 固定画阳爻。阴爻用两段式 `linear-gradient`，不再用空框表示。
- 新增 `guaBlock()` 双栏结果：本卦“现状（未变）”、变卦“动爻变化后的趋势”，中间箭头连接；无动爻时只显示本卦，并提示“无动爻（静卦），无变卦”。
- 每行显示自下而上的爻位：中文“初/二/三/四/五/上”，英文 `1–6`；动爻在主卦标“动/mov”、在变卦标“变/chg”，并加橙色外框；每行 `aria-label` 说明第几爻、阴/阳、是否动爻。
- 结果下方列出动爻：中文“第 N 爻（初九/六二/上九等）”，英文 `line N (yang/yin)`，并说明“老阳变阴、老阴变阳，得变卦”；静卦显示“无动爻（静卦），无变卦”。
- 结果标题、所问、本卦/变卦、动爻说明、解卦指引、演示时间均双语；英文等级用 `LEVEL_EN` 映射，英文不显示中文卦象释义，仅保留卦名与英文等级。
- 修复空问题提示：原引用未定义的 `i18nText()`，改为 `isEnUi()` 分支提示“请先输入所问之事 / Please enter a question first.”。
- 简介统一为“以随机模拟传统起卦流程生成本卦与变卦，逐爻展示自下而上的卦画、动爻和变卦，属传统文化娱乐演示，非算命。”，同步 `i18n/tools/yi.json`、英文第三层词典与相关工具推荐卡描述。
