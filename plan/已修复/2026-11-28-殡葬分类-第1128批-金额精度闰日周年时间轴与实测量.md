# 殡葬分类 第1128批：金额精度、闰日周年、跨日时间轴与实测量

## 背景

本轮清理 `plan/funeral/` 下 7 个任务，涉及 6 个工具页。修复方只移交待复核，不自行判定复核通过。

## 逐条修复

1. **丧葬预算小数金额显示被取整**（`tools/funeral/funeral-budget-planner.html`）
   - 新增按分整数存储与 `money()` 两位小数显示；输入仍接受元，内部换算为分。
   - 分项、分类小计、总计、10% 机动费、含机动总计均按分四舍五入显示。
   - 金额输入严格校验：必须为有限数值且 ≥0，空串与负数拒绝。
   - 新增“复制明细”，复用 `lastBudget`，复制内容含分项与两位小数总计。
   - 默认空表；载入预设后 14 项基础合计 48,900.00、机动 4,890.00、总计 53,790.00。
   - 注入 0.01+0.02+0.03：分项分别 0.01，总计 0.06，机动 0.01，含机动 0.07。

2. **骨灰盒格位按内径计算低估空间**（`tools/funeral/urn-size.html`）
   - 改为先算外径再叠加方向余量：`格位 = 外径 + 两侧余量`；外径 = 内径 + 两侧壁厚。
   - 默认 65 kg / 170 cm / 木质 / 骨灰架：骨灰 2.3 kg、内径 20×14×14、外径 23×17×17、格位 29×23×23。
   - 新增可选实测骨灰体积（L）与盒内长/宽/高（cm），三项内尺寸必须同时填写且 >0。
   - 实测 2.5 L + 内 20×15×15：外径 23×18×18、格位 29×24×24。
   - 身高必填且 >1；体积倍数统一为 1.8（约 80% 填充余量），删除无依据的“30% 余量”表述。
   - 复制复用 `lastUrn`，无有效结果时拒绝复制。

3. **公历忌日保存提醒未计算下一次周年**（`tools/funeral/memorial-date.html`）
   - 保存提醒新增 `repeat`（solar/lunar）与 `leap`（feb28/mar1/leapOnly）。
   - `nextAnniversary` 计算下次公历/农历周年；列表显示原忌日、农历日期、下次日期与剩余天数。
   - 新增 `.ics` 导出 `exportReminderICS`，可导入本地日历。
   - 主计算未来 3 个周年改为从今天起继续计算，不再固定在原忌日后 3 年。
   - 真机 2024-02-29 重复：2/28 ⇒ 2027-02-28；3/1 ⇒ 2027-03-01；仅闰年 ⇒ 2028-02-29。
   - 农历周年 2025-01-29 ⇒ 下次 2027-02-06。

4. **追悼会时间轴乱序录入被误判跨日**（`tools/funeral/ceremony-timeline.html`）
   - 新增“第几天”（1–7 整数），步骤显式保存 `day`；按 `(day-1)*1440 + 时间` 排序。
   - 彻底删除“后录时间早于上一条就判次日”的猜测逻辑。
   - 支持 `editStep(id)` 回填与“保存修改”，编辑后按钮复位。
   - 汇总分开“环节合计”和“实际跨度（含空档）”；逐相邻环节提示重叠或空档。
   - 列表与复制显示“第N天 HH:MM”。
   - 真机第1天 10:00 A、09:00 B：排序 B→A，无“次日”，空档 30 分钟、跨度 90 分钟；第2天 09:00 C 结束第2天 09:30。

5. **祭扫提醒闰日周年自动变为三月**（`tools/funeral/reminder-3.html`）
   - 公历每年重复新增 `sLeapRule`（feb28/mar1/leapOnly）。
   - `safeSolarNext` 专门处理 2/29 在非闰年的落点，不再静默溢成 3 月。
   - 列表显示下次公历日期与所选闰日规则。
   - 真机 2024-02-29：feb28 ⇒ 2027-02-28、mar1 ⇒ 2027-03-01、leapOnly ⇒ 2028-02-29。

6. **碑文设计空姓名仍计算吉凶和字数**（`tools/funeral/grave-design.html`）
   - 空姓名显示“（姓名待填写）”占位，但不参与计算，不输出字数与生老病死苦。
   - `charLen()` 改用 `Intl.Segmenter` 按可见字符计数（`𠮷` 计 1），避免代理对误算。
   - 新增“显示字数吉凶（民俗参考，可关闭）”复选；关闭后仍显示字数，但不输出生老病死苦结论。
   - 新增可编辑落款 `signer`；复制结果在空姓名时拒绝。
   - 真机空姓名、含 `𠮷` 姓名、关闭民俗开关、修改落款均通过。

7. **公历忌日清明节气硬编码日期错误**（`tools/funeral/memorial-date.html`）
   - `qingmingDate` 改为太阳视黄经 = 15° 的 Meeus 求解，中国标准时间 UTC+8，支持 1900–2100。
   - 超范围或求解失败返回 `null`，页面给出提示而不硬编码日期。
   - 真机 2025 ⇒ 4/4、2024 ⇒ 4/4、2105 ⇒ null。
