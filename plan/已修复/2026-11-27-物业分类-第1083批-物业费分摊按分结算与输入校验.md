# 第 1083 批：物业费分摊改为按分结算并补齐金额/面积校验

- 修复时间：2026-11-27
- 类型：金额精度 / 输入校验 / 结果可核对性
- 涉及页面：`tools/property/fee-allocation.html`

## 问题
1. 各户金额按两位小数展示，但合计用未取整的浮点值。总额 0.01 元、3 户均分时每户显示 0.00，合计却 0.01，不能直接用于收款。
2. 总额与面积空值被 `||0` 当 0，负数可进入计算；面积模式总面积 0 仍生成结果。
3. 公式框将差额解释为“浮点误差”，未说明分币余数规则。

## 修改
- 总额改为显式校验：空值提示“0 为合法零金额”，非数/负数拦截；0 正常计算。
- 面积模式逐户校验：面积不得为空、非数或负数；总面积 ≤0 时拒绝计算并清空旧结果，提示检查面积。
- 金额以分为单位分配：先按权重折算分并向下取整，剩余分按“小数余数从大到小”逐户补 1 分，同余按明细顺序。
- 表格直接展示分币金额，合计与差额均用同一组分币值计算；差额固定为 0.00。
- 结果区明确余数分配规则、剩余分数，并声明表内金额可直接用于收款核对。
- 公式框同步改为“按分结算 + 最大余数法”，删除“浮点误差”说法。
- 英文词典补齐新公式说明。

## 真机验证
- 总额 0.01、3 户均分：显示 0.01 / 0.00 / 0.00，合计 0.01，差额 0.00，剩余 1 分补给第一户。
- 总额 0.01、4 户均分：显示 0.01 / 0.00 / 0.00 / 0.00，合计 0.01。
- 总额 100、默认 4 户面积 89/89/120/120：21.29 / 21.29 / 28.71 / 28.71，合计 100.00，差额 0.00。
- 第 2 户面积留空：提示“第 2 户面积未填写”，不出旧结果。
- 总额留空：提示填写且明确 0 合法；总额 −1：提示不能为负数。
- 英文探针 0 页残留；`verify_property_calc.js` 26/26；`_test_static.py` 4654 通过 / 0 失败 / 0 告警。

## 复核要点
1. 所有展示金额之和必须与总额分币值严格相等，差额恒为 0.00。
2. 余数只能按最大余数法分配，同余按行序，且仅补 1 分/户。
3. 空值不得按 0 处理，0 金额本身合法；面积模式总面积必须 >0。
