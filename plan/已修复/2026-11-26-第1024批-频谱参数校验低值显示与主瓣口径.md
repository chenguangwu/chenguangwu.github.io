# 第 1024 批：频谱参数校验、低值显示与主瓣口径

- 影响页面：`tools/audio/analysis-1.html`
- 对应任务（6 个）：
  1. 中文公式参考表错字
  2. 英文 FAQ 误述主瓣变化
  3. 低频结果被显示为零
  4. 输入错误时复制了错误提示
  5. FFT 长度接受小数
  6. 汉宁窗主瓣宽度定义不清

## 修复

- 术语：公式表“频诊分析”改为“频谱分析”，英文列改为 `Spectrum analysis`；表头“出处标准”改为“相关原理”，来源由泛化名称改为可核对的 `DFT definition`、`Parseval theorem`、`Nyquist–Shannon sampling theorem`。
- 数值格式：新增 `__analysis_1Fmt()`，当 |值| < 0.001 或 ≥ 1e6 时用 4 位有效数字的科学计数，真正 0 仍显示 `0`；分辨率、bin 频率、主瓣宽度统一使用。
- 输入校验：FFT 长度必须是正整数，输入 1024.5、0、负数均提示“请输入大于 0 的采样率、正整数 FFT 长度……”并清除旧结果；页面注明接受任意正整数，不强制 2 的幂。
- 复制状态：新增 `__analysis_1Valid` 与 `copyBtn` 禁用态；无有效结果时按钮禁用，`copyResult()` 也会拦截并提示，避免把错误提示当作计算结果；有效计算后恢复。
- 主瓣口径：公式、结果同时给出“单侧至首个零点 ≈ 2Δf”和“零点间全宽 ≈ 4Δf”；算例补 31.25 Hz 全宽，深度解析、指南与英文词典同步。
- FAQ：中英文统一为“增加实际观测长度或降低采样率会减小 Δf；以 Hz 计主瓣全宽约 4Δf，随观测长度增加而变窄；仅补零只提高插值密度，不提高真实分辨率”，修正英文“主瓣随 N 变宽”的错误表述；FAQPage JSON-LD 同步手改并校验 `json.loads`。

## 验证

- `fs=1、N=131072、bin=1`：分辨率与目标频率均显示 `7.6294e-6 Hz`，主瓣单侧 `1.5259e-5 Hz`、全宽 `3.0518e-5 Hz`，不再显示 0.0000。
- `N=1024.5`：结果区提示正整数 FFT 长度，复制按钮 `disabled=true`；恢复 `N=1024, fs=8000, bin=10` 后显示 `78.125 Hz`、单侧 `15.6250 Hz`、全宽 `31.2500 Hz`，复制按钮恢复。
- 页面正文无“频诊”，包含“零点间全宽”；`?lang=en-US` 下公式、输入标签、FAQ 均为修正后的英文。
- `node scripts/verify_audio_calc.js` 12/12（新增低频、非整数 N、复制禁用 3 例）；`_test_static.py` exit 0；`_audit_assets.py --check` 0 死链/0 lang 缺失/0 重复 id；`_audit_links.py --check` exit 0；页面全部 JSON-LD `json.loads` 通过。
