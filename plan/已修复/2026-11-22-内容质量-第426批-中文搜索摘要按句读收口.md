# 第 426 批：中文搜索摘要按句读收口

日期：2026-11-22
类型：内容质量 / 中文搜索与卡片摘要
状态：已修复并本地提交（未 push）

## 一、原问题

第 425 批解决了英文摘要断词；同一套 `clip()` 对中文仍是纯字符硬截。中文没有空格，`json/tools.json` 的 `d` 字段（80 字上限，供首页卡片、搜索下拉、分类页、导航消费）有 218 条以省略号结尾，大量停在半个词或半句话上，例如：

- `…或粘贴 Base64 还原为文件下载。纯本地处理，文…`
- `…用户名+密码 → Base64 令牌，支持中文用户名，供接口调试与…`
- `…internationalization → i18n、accessibility → a11y，批量转换…`

## 二、修复内容

继续修改 `scripts/tool_desc_source.py::clip()`，增加中文句读回退：

1. 截断后若末尾是汉字，优先回退到最近的句末标点 `。！？；`，且位置不早于截断长度的 40%；
2. 没有可用句末标点时，回退到最近的逗号/顿号/冒号，且位置不早于 55%，并去掉尾随标点；
3. 两者都找不到时保留硬截，保证无标点长串仍可获得摘要；
4. 英文单词边界逻辑不变。
