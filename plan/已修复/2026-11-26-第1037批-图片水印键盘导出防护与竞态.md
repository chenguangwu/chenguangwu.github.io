## 修复内容

1. **长图平铺绘制量**：`drawTiledPattern()` 改为按旋转后的实际可见局部边界计算行列，只遍历覆盖画布的单元；`MAX_CELLS=60000`，超限时逐步增大 `stepX/stepY` 直到落回上限。4000×200 长图、`gap=0` 实测 `cells=171 / 0.7ms`。
2. **英文简介与导出反馈**：补 `__wmIsEn()` / `__wmT()`，结果摘要、导出成功/失败、SVG 拒绝、类型切换、加载中禁用导出、尺寸超限、格式回退均输出英文；页面首段与简介改为具体能力，页面/`image.json`/`image-body.json`/第三层字典同步，`desc-en` 不再是占位短句。
3. **类型与位置键盘操作**：类型标签改为原生 `<button>` 并保留 `role=tablist` / `role=tab` / `aria-selected` / `tabindex`；扩展 `__wmBindA11y()` 的左右方向键、Enter、Space，并 `stopPropagation()` 避免与 `js/tool-ux.js` 的通用 tablist 键盘处理重复触发；位置 `.pos-cell` 保持 `role=radio`，支持方向键、Home/End、Enter/Space。实测可见后方向键可从文字切到图片，位置 `br→tl` 循环。
4. **历史与预设不触发下载**：预设和历史恢复只调用 `render()`，不调用 `downloadImg()`；快照新增 `wmTypeState` / `wmPosState`，恢复类型与位置后再同步 `onTileToggle()` / `onPosModeChange()`。预设点击实测下载数为 0。
5. **未选择图片水印禁止导出**：新增 `__wmReady()` / `__wmStatusText()` / `__wmSetStatus()`；图片类型但未选水印图、文字为空、底图/水印加载中、超大图阻断时，三个下载按钮统一 `disabled`，`downloadImg()` 本身也二次阻断，避免导出无水印原图。
6. **防抖期间下载旧画布**：新增 `__wmFlushRender()`；`downloadImg()` 先清 `renderTimer` 并同步 `render()`，再检查 ready / renderBlocked，保证快速改文字后立即导出的是最新画布。
7. **水印超出画面提示**：`drawTextWatermark()` / `drawImageWatermark()` 记录 `lastWatermarkRect`，`__wmUpdateBoundsNote()` 显示“水印超出画面，超出部分会被裁掉；可减小字号/水印图、调整边距或改用平铺”。100×900 窄图 + 长文字实测提示可见。
8. **描边颜色独立**：新增 `wmStrokeColor` / `wmStrokeColorHex` 与双向同步；单点和平铺绘制都使用独立 `strokeStyle`；FAQ/说明删除“任意背景可读”承诺。白底红字 + 蓝描边像素统计 `blue=1404 / red=1056`，证明描边生效。
9. **文字保持原始输入**：删除英文态把 `ToolBox 水印` 自动替换成 `ToolBox Watermark` 的逻辑；`wmText` 通过 `wmTextEdited` 区分默认示例与用户输入，编辑后始终使用原文；空串进入“无文字水印/禁用导出”状态。英文页手动输入 `ToolBox 水印` 后值保持。
10. **换图与重置期间加载竞态**：底图新增 `imgLoadSeq/imgLoading`，水印新增 `wmLoadSeq/wmLoading`；成功、失败、FileReader 错误、换图、重置均校验序号，过期回调丢弃；加载中禁止导出；水印加载失败会清空旧 `wmImg` 与缩略图。底图 5×5→600×900、水印 5×5→400×300 竞态最终均为后图。
11. **画布分配前检查上限**：`render()` 在写入 `canvas.width/height` 前调用 `__wmLimitMessage()` / `canvasExportError` 检查；超限只显示警告、隐藏画布、禁用导出；JPEG 的 flatten 画布创建前再次检查。fake 17000×100 实测被阻断，原 canvas 仍为默认 300×150 且隐藏。
12. **WebP 回退扩展名**：`downloadImg()` 的 `toBlob` 回调检查 `blob.type`，按实际 MIME 决定 `.png/.jpg/.webp`；请求 WebP 却得到 PNG 时扩展名改为 `.png` 并提示“当前浏览器未返回所选格式，已按实际格式保存”；无法确认 MIME 则报错不下载。模拟回退实测文件名为 `.png`。
