# 第283批 · Emoji 明细编码显示及复制错误（IT 清单 1 条）

## 来源
`plan/categories/01-IT开发/it.md`「Emoji 明细编码显示及复制错误（中，代码确认）」，已销账删除。

## 根因
`tools/it/emoji-meaning.html` 的 `showDetail()` 把 `htmlEntity()`（`&#x1f600;`）、`cssEscape()`（`\1f600`）、`jsEscape()`（`\u{1f600}`）等转义串直接拼进 `innerHTML` 的文本位置与 `onclick="copyText('...')"`：
- 文本位置：`&#x1f600;` 被 HTML 解析成 😀，显示不出字面编码。
- 属性位置：`\u{1f600}` 被 JS 解析成 😀、`\1f600` 被解析成控制字符 U+0001 + `f600`，复制值全错。

## 修复
1. 新增 `escHtmlText()`：把 `& < > " '` 实体化，转义串作为字面文本写入 innerHTML，`&#x1f600;` 显示为字面串。
2. 复制按钮改为 `data-ntcopy` + `data-ntindex`，新增 `emojiCopyValue(kind,index)` 在点击时现算原始字面串；详情面板用事件委托，彻底不把转义串拼进 `onclick`。
3. 关键词 span 同样过 `escHtmlText()`（防止关键字含 HTML 特殊字符）。

## 验证与证据
- 独立脚本 `scripts/_verify_emoji_encoding.mjs`：新源码 **9/9**，旧源码 **3/9**（6 个判别点正确变红）。覆盖 HTML/CSS/JS/URL 四种编码的字面显示与复制值。
- JSDOM 新旧差分（😀）：OLD 复制 `html=😀 / css=\u0001f600 / js=😀`（全错）；NEW 复制 `html=&#x1f600; / css=\1f600 / js=\u{1f600} / url=%F0%9F%98%80`（全对）。
- verify 主库 +1 强锁（锁显示字面 `&amp;#x1f600;`，旧源码渲染成 😀 不命中）：`it/emoji-meaning` 2/2，全站 1690/1690。
- build 幂等 shasum 两次一致；真机无残留。

## 坑
- verify 的 stub DOM 里 `EMOJIS` 顶层 const 不在 window 上，clicks 里 `EMOJIS.findIndex` 会 undefined；改用硬编码 `showDetail(0)`（😀 是字典第 0 项）显式触发详情。
- 详情面板默认不渲染，必须 clicks 显式调用，否则用例不稳定（时有时无 detailInfo 内容）。
