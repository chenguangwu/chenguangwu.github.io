# 第692批：输入无效结果容器引用错误与冷敷护理记录不可达

## 修复项

### 1. 四个工具校验分支向不存在的 `#result` 写入提示

受影响页面：

- `tools/automotive/cycle-belt.html`：实际结果容器 `#resultArea`
- `tools/fitness/calc-heart-rate.html`：实际结果容器 `#res`
- `tools/meteorology/risk-14.html`：实际结果容器 `#res`
- `tools/tcm-chemistry/capsule-filling.html`：实际结果容器 `#fillResult`

原校验分支调用 `document.getElementById('result').innerHTML`，容器不存在时抛出 `TypeError`，错误提示无法显示，旧计算结果继续留在页面上。

修复：

- 改为各页真实结果容器。
- 校验失败时同步清空该页的结果附表、差异、图表与历史展示区，避免旧结论残留。
- 心率页同时清空 `lastResult`，防止导出的仍是上一次有效结果。
- 保留数字 `0` 的合法语义，只拦截空串、负值、零密度等真正无效输入。

### 2. 冷敷计时护理记录生成分支不可达

`tools/clinical-nursing/cold-compress-timer.html` 的 `__emrData()` 查找 `#result`，页面结果区没有该 id，函数直接返回，护理记录与复制按钮永远不生成。

修复：给页面实际结果容器补 `id="result"`，护理记录在结果区下方生成；参数切换后由 `calc()` 包装器刷新记录。

## 验证

本地 Chromium 逐页触发无效输入：

- 汽车皮带：清空当前/上次里程 → 显示“请填写当前里程与上次更换里程”，无页面异常。
- 心率：年龄 100、静息心率 120 → 显示储备心率无效提示，无页面异常，旧复制结果清空。
- 气象风险：气压 0 → 显示完整填写提示，无页面异常。
- 胶囊填充：目标装量/密度 0 → 显示“请填写大于 0 的目标装量/密度”，无页面异常。
- 冷敷计时：加载后即生成“门诊记录（可直接复制进病历）”，含部位、皮肤条件、单次时长、间隔、每日上限与皮肤观察频率。

五页均无 `pageerror`；结果区在无效输入后只显示当前提示，不再保留旧结论。

## 规则

- 空态守卫按空串判断，不把数字 `0` 当作未填写。
- 构建后改动仍存活，`_build.py` 无额外产物变化。
