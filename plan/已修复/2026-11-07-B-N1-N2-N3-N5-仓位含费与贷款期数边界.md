## 一、B-N1 固定风险仓位未纳入手续费且允许零止损距离（高）
- **文件**：`tools/securities/position-sizing.html`（`calcFixed()`）
- **缺陷**：先 `风险金额 ÷ 价差` 求股数，再把双向手续费**另加**到亏损侧 ⇒ 实际最大亏损超风险预算（10 万/2%/10 买/9 止损/0.1% ⇒ 2000 股、最大亏损 2040 > 2000）；`stop === entry` 时 `风险 ÷ 0 = 0 股` 仍走完整计算，输出伪结果。
- **修复**：
  1. 每股手续费 = `feeRate × (entry + stop)`（买入 + 止损卖出），**每股净风险 = 价差 + 每股手续费**；
  2. 股数 = `floor(风险预算 ÷ 每股净风险)`（整股向下取整）；
  3. `stop ≤ 0` 或 `stop === entry` ⇒ 明确拒绝并说明原因；股数 < 1 ⇒ 提示调整参数；
  4. 明细新增「每股手续费 / 每股净风险」，最大亏损行附「风险预算 ¥X，占用 Y%」，并给出含费净盈亏比。
- **根因**：风险预算的求解口径（不含费）与亏损展示口径（含费）不一致。

## 二、B-N3 贷款已还期数超范围产生负余额（高）
- **文件**：`tools/banking/loan-remaining-balance.html`
- **缺陷**：正文要求 `k ≤ N`，`calcTool()` 未校验；1200/12%/1 年/已还 13 期 ⇒ 余额 **-106.62**、已还本金 1306.62。
- **修复**：前置校验 `P>0`、`N=round(y×12)>0`、`k` 为 **0~N 整数**（越界/小数输出「已还期数必须是 0 ~ N 之间的整数（当前输入 x 期）」并中止）；结果新增「每月还款额」。

## 三、B-N2 零利率被当非法分母（高）— 两页
- **文件**：`tools/banking/loan-remaining-balance.html`、`tools/banking/loan-tenure.html`
- **缺陷**：两页的 `__tbInputGuard` 分母表 `__D` 把利率 `r` 列为「不能为 0」，合法零利率贷款被直接拒绝（`loan-tenure` 的 10000/200 零利率应 50 期）。
- **修复**：两页 `__D` 移除 `r`（保留 `y` / `PMT`）；主计算补零利率极限：
  - `loan-remaining-balance`：`emi = P/N`、`B = P − emi×k`（`r → 0`）。
  - `loan-tenure`：`n = P/PMT`；并新增「每期还款 ≤ 当期利息（PMT ≤ P×r）」时明确提示贷款永远还不完（原先输出「—」/NaN 无法区分）。

## 四、B-N5 理论期数×期供 ≠ 实际结清总额（中）
- **文件**：`tools/banking/loan-tenure.html`
- **缺陷**：只输出 `PMT×n`（n 为连续期数），与 FAQ「末期按剩余本金及利息结清」不一致；15000/0.5%/200 ⇒ 18847.11（连续）vs 实际 18847.20。
- **修复**：区分**理论期数** `n`（保留原「还款期数 n (期)」标签与 `94.2` 契约）与**实际还款期数** `kPay = ceil(n)`；新增「末期结清额」= 前 `kPay−1` 期还款后余额 ×(1+r)、「合计还款额」= `PMT×(kPay−1)+末期结清额`；「还款年限」改 `kPay/12`；数据表 `#loan_tenureTable` 同步这四行。
- **余项**：敏感性扫描曲线（`__ltSweep`）仍按连续期数绘制（趋势示意），如要严格对齐可后续改成整数期口径。
