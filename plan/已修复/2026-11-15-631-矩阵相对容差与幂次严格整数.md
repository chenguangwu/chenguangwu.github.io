## 缺陷与根因

| 位置 | 根因 | 表现 |
|---|---|---|
| `rank()` | 主元判定 `Math.abs(m[pivot][col])<1e-12` 用绝对阈值 | `[[1e-13,0],[0,1e-13]]` 两列线性无关（rank 应为 2），主元 1e-13 被当 0 ⇒ 显示 `rank(A) = 0` |
| `inverse()` | 行列式判定 `Math.abs(d)<1e-12`、主元同用 1e-12 | `2e-7·I` 的 det = 4e-14 < 1e-12 ⇒ 误报「矩阵不可逆（奇异矩阵）」（SMS-108） |
| `det` 分支 | 奇异提示用 `d===0` | 与 `inverse` 的容差判定不同源，可能出现「显示奇异但求逆仍走另一套」的口径分裂 |
| `power` 分支 | `parseInt(__rawP, 10)` | 幂次输入 1.5 被静默截断成 1，直接给出 A¹ |

## 修复内容

1. 新增相对容差 helper：
   ```js
   function __matScale(m){ /* max|a_ij| */ }
   function __matEps(m){const s=__matScale(m);return s>0?s*1e-12:1e-12;}
   ```
2. `inverse()`：`d` 判定与高斯消元主元判定统一使用 `__matEps(a)`。
3. `rank()`：新增 `const __eps=__matEps(a)`，主元判定改用 `__eps`。
4. `det` 分支：奇异提示改 `Math.abs(d)<=__matEps(A)`，文案明确「行列式在相对容差内为 0（|A| = …）」，与 `inverse` 同源。
5. `power` 分支：`Number()` + `Number.isInteger()` 校验，小数/非数字停算提示「幂次必须是整数（不接受小数或非数字）」；空值仍按 1 处理（保持原有行为）。

## 复核要点

- 尺寸 2×2、运算「秩」，A 填 `1e-13,0,0,1e-13`：应显示 `rank(A) = 2` 与「满秩矩阵」。
- 运算「A⁻¹」，A 填 `2e-7,0,0,2e-7`：应输出含 `5.000000e+6` 的逆矩阵，不再报不可逆。
- 运算「Aⁿ」，幂次填 `1.5`：应提示「幂次必须是整数」，不给结果。
- 运算「|A|」，A 填 `1,2,2,4`：应提示「行列式在相对容差内为 0…矩阵不可逆」。
