# 第699批：房间面积对角线公式与负数校验

## 修复项

`tools/home/room-calculator.html`

### 1. 梯形对角线公式错误

原代码用 `√(max(a,b)² + h²)`，把梯形按直角梯形的一条边处理。工具实际按等腰梯形计算周长，对角线应为 `√(((a+b)/2)² + h²)`。

实测 上底 2、下底 6、高 3：面积 12.00、周长 15.21、对角线 5.00（原为 6.71）。

### 2. 平行四边形只显示一条错误对角线

平行四边形的两条对角线长度不同，原公式 `√(底² + 高²)` 既不是短对角线也不是长对角线。

现按斜边投影计算：

- 水平偏移 `dx = √(side² - height²)`
- 短对角线 `√(max(base-dx,0)² + height²)`
- 长对角线 `√((base+dx)² + height²)`

实测 底 4、高 3、斜边 5：显示 `3.00 / 8.54`（短 / 长），导出表标签改为“对角线（短 / 长）”。斜边小于高时提示“斜边不能小于高”并停止输出。

### 3. 负尺寸仍输出结果

矩形、圆形、梯形、平行四边形原先允许负数进入公式，例如宽 -2 会得到负面积。现在所有形状在计算前统一校验：所有尺寸必须为有限正数，否则清空面积/周长/对角线并隐藏表格，提示“所有尺寸均须为正数”。

## 验证

本地 Chromium：

- 梯形 `2 / 6 / 3` → `12.00 / 15.21 / 5.00`
- 平行四边形 `4 / 3 / 5` → `12.00 / 18.00 / 3.00 / 8.54`
- 平行四边形斜边 3、高 5 → 三个结果均为 `—`
- 矩形宽 -2、圆形半径 -3 → 三个结果均为 `—`
- 无 `pageerror`

## 规则

凡以尺寸为输入的几何计算，先校验正数再进公式；一条对角线放不下两种长度时显式给出两条，不用单值冒充。
