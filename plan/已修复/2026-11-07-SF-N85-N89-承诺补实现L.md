## 一、SF-N85：Kirkpatrick 四级评估由「文案声称」改为「真实现」

- **失败点**：`assessor-csat.html` 功能特点第 4 条列「Kirkpatrick四级评估」、结果页尾注也称「CSAT + NPS + Kirkpatrick 四级评估模型」，实际只有 CSAT / NPS / 四维评分三项计算，无任何四级维度、分值或结论。
- **修复位点**：`tools/sports/assessor-csat.html`
  - 新增输入：`learn`（L2 学习层：知识/技能测评均分 0–100，默认 75）、`behavior`（L3 行为层：赛后行为改变率 0–100，默认 70）。
  - 四级口径：L1 反应 = CSAT 满意度；L2 学习 = 测评均分；L3 行为 = 行为改变率；L4 结果 = 赛事效果四维评分 × 10。
  - 结果区新增四级表（层级 / 口径 / 得分 / 判定，单级 ≥85 优秀、≥70 达标、其余未达标、空值缺测）与结论「四级贯通：n/4 级达标（缺测不计入达标数）」+ 待改进层级清单。
  - 公式框新增四级口径说明与达标判据；`formula-desc` 同步。
- **判别力实测**：
  - `learn=90, behavior=40` ⇒ L1 90.5 / L2 90 / L3 40 / L4 80 ⇒ **3/4 级达标**（默认 75/70 为 4/4，不命中）。
  - `learn='', behavior=''` ⇒ L2/L3 记「—/缺测」⇒ **2/4 级达标**，待改进列出「L2 学习（缺测）、L3 行为（缺测）」（默认无「缺测」字样）。

## 二、SF-N89：换项 T1/T2 与各段占比

- **失败点**：`convert-time.html` 标题/描述承诺「换项时间」与「各段占比」，实际只有游泳/骑车/跑步三个秒数求和 + 平均/极差，无 T1/T2 输入、无占比输出。
- **修复位点**：`tools/sports/convert-time.html`
  - 新增输入 `t1`（游泳→骑车换项，秒，默认 0）、`t2`（骑车→跑步换项，秒，默认 0）。
  - 总时长改为 `游泳 + T1 + 骑车 + T2 + 跑步`；「三项平均」与「极差」仍只统计游泳/骑车/跑步三段（避免把换项算进段平均）。
  - 新增输出：「换项合计 T1+T2 = X（占全程 Y%）」与「各段占比：游泳 … ｜ T1 换项 … ｜ 骑车 … ｜ T2 换项 … ｜ 跑步 …」。
  - 负值校验由三段扩到五段并回显五段原值；公式框改写为新口径（含「先整体四舍五入再分解」的秒数进位说明）。
- **判别力实测**：注入 `1200/3600/2400/90/60` ⇒ 总 7350 秒；换项合计 **2分30秒（占全程 2.0%）**；各段占比 **16.3% / 1.2% / 49.0% / 0.8% / 32.7%**。默认 T1=T2=0 时无占比行 ⇒ 两条锚均不命中。
- **兼容性**：既有 6 条 convert-time 用例（7200/3600/5100/1800/9000/175/15924 等）逐条复跑仍通过 —— T1/T2 默认 0 不进总时长，「第 3 项 42 秒 ｜ 合计 126 秒」等原有锚点保持不变。
