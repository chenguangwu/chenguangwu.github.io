# 535 批：G01-A7 hp-dob 呼气试验阈值按 ¹³C / ¹⁴C 分列

- 日期：2026-11-15
- 来源：`plan/G01-公式与计算正确性裁量项.md` A7
- 受影响页面：`tools/gastroenterology/hp-dob.html`

## 缺陷

页面虽提供「¹³C / ¹⁴C 呼气试验类型」下拉，但 `calc()` 无条件使用 `var threshold=4.0`：

- ¹⁴C 结果按 4.0 DPM 判读，远低于临床惯用的 ≥100 DPM 阳性判断值，低值被误判为阳性；
- 灰区分支硬编码 `dob>=2.0`，对 ¹⁴C 同样错误；
- 输入标签固定「DOB值 (‰)」，¹⁴C 实际报告 DPM；
- 深览「算法」句写「¹³C/¹⁴C 都按 DOB ≥4.0」，与同页表格 ¹⁴C ≥100 DPM 自相矛盾；
- 预设「PPI 服用中 14C 弱阳性」取 dob=3，按 DPM 口径实为阴性。

## 修复

1. `calc()` 按类型取阈值与单位：
   - ¹³C-UBT：DOB ≥4.0‰ 阳性；<2.0‰ 阴性；2.0–3.9‰ 灰区/临界。
   - ¹⁴C-UBT：DPM ≥100 为阳性判断值；<100 阴性；100–199 弱阳性（+）；200–499 阳性（++）；≥500 强阳性（+++）。
2. 输入标签动态切换（DOB值 (‰) / DPM（衰变数/分钟））；结果卡、检测信息、建议文案同步。
3. 判读标准表格改为「阴性 / 弱阳性·灰区 / 阳性」三列并按方法分列，补注试剂盒差异。
4. 深览（权威源 `i18n/tools/content_deepdive.json` 的 `gastroenterology/hp-dob`）、FAQ、公式框、引据表、场景条目同步。
5. 预设改为：默认、¹³C 阴性/阳性、¹⁴C 弱阳性/强阳性、PPI 服用中 ¹³C 阴性（显式复位三个复选框）。
6. 动态结果中英双语，并监听 `toolbox:langchange` / `toolbox:dictready` 重绘（内联脚本早于 defer i18n）。
7. `i18n/tools/en/gastroenterology/hp-dob.json` 同步新增/替换译键。

## 验收

- 真机（puppeteer + 本机 Chrome）：13C 8.5→阳性、3.0→灰区、1.5→阴性；14C 120→弱阳性（+）、350→阳性（++）、600→强阳性（+++）、40→阴性；PPI 勾选 + 13C 1.5→结果不可靠。
- 英文态：默认 `DOB value (‰)` / `Positive ...`；切 14C 120 后 `DPM (disintegrations/min)` / `Weakly positive (+)`，无汉字残留。
