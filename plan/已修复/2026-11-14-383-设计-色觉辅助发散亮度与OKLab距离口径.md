## 一、D-N106：发散模式亮度曲线做反

### 问题

`rampDiverging()` 里 `L = 0.32 + 0.58 × |2t − 1|`，t=0/0.5/1 得 0.90 / 0.32 / 0.90 —— **两端最亮、中点最暗**；而紧邻的注释与 formula-eq 都写「中心最亮、两极最暗」。同页顺序模式 `0.90 − 0.58t` 才是浅到深，两种模式口径自相矛盾。

### 修复

```js
var L = 0.90 - 0.58 * Math.abs(2 * t - 1); // 中心最亮（0.90），两极最暗（0.32）
```

`formula-eq` 同步改写为「亮度 = 0.90 − 0.58 × |2t − 1|（中心最亮 0.90、两极最暗 0.32）」，EN 字典整条 key + value 同步。

### 复算证据（n=5）

| t | 0.00 | 0.25 | 0.50 | 0.75 | 1.00 |
|---|---|---|---|---|---|
| 旧 L | 0.90 | 0.61 | **0.32** | 0.61 | 0.90 |
| 新 L | **0.32** | 0.61 | **0.90** | 0.61 | 0.32 |

旧版序列是「亮 → 暗 → 亮」，中点为整条色带最暗处，与发散配色「中点锚定浅色、两端深色」的常规相反。

> 该页主逻辑在 IIFE 内（`render`/`rampDiverging` 均为闭包私有，`change` 监听读 `this.value` 而 harness 的 `fire` 不绑定 this、桩 `click()` 又是空操作），verify 无法构造用例，故沿用 D-N10 / D-N107 先例，以独立公式复算取证。

## 二、D-N112：「OKLCH 距离」把 Lab 当 RGB，且极坐标近似失真

### 问题（两层）

1. **入参口径错**：`distFor('oklch', a, b)` 直接 `rgbToOklch(a)`，但全部调用方传的都是 **Lab**（`activeLabs()` = `list.map(rgbToLab)`、`rgbToLab(simulate(...))`、图表/CSV/叠加对照同理）。`rgbToOklch` 按 0–255 sRGB 解释，负的 a/b 被当成负通道值。
2. **距离公式本身错**：即使传入真 RGB，`oklchDist` 用「ΔL×100、ΔC 直接、色相差 × 平均彩度 ÷ 180」加权，色相差被彩度量级（0.1–0.2）压成 0.x —— 两色真实 ΔE00=49.0，它只报 ≈1.0。

### 修复

```js
function rgbToOklab(rgb) { /* 线性化 → LMS → cbrt → 返回 [L, A, B] */ }
function oklabDist(rgba, rgbb) {
  // OKLab 直角坐标欧氏距离 ×100（与 CIELAB 的 ΔE 同量级，阈值 5/10/20 可直接沿用）
  var a = rgbToOklab(rgba), b = rgbToOklab(rgbb);
  var dL = a[0]-b[0], dA = a[1]-b[1], dB = a[2]-b[2];
  return Math.sqrt(dL*dL + dA*dA + dB*dB) * 100;
}
function distFor(metric, a, b) {
  if (metric === 'e76') return deltaE76(a, b);
  if (metric === 'oklch') return oklabDist(labToRgb(a), labToRgb(b));  // Lab → sRGB → OKLab
  return deltaE2000(a, b);
}
```

删除已无调用者的 `rgbToOklch` / `oklchDist`。UI 指标名 `OKLCH 距离` → `OKLab 感知距离`，formula-desc 补「（OKLCH 同空间的直角坐标欧氏距离 ×100）」，EN 字典同步。

### 复算证据（`/tmp/pcv_probe.js` 旧、`/tmp/pcv_probe2.js` 新，按页面同款函数切片抽取）

| 色对 | ΔE00 | 旧「oklch」 | 新「oklab」 |
|---|---|---|---|
| #FFFF33 vs #FFFFFF | 29.8 | **1.1** | 20.3 |
| #E41A1C vs #377EB8 | 49.0 | **18.7** | 32.6 |
| #00FF00 vs #FF0000 | 86.6 | **16.0** | 52.0 |
| #000000 vs #FFFFFF | 100.0 | — | 100.0 |
| #808080 vs #7F8080 | 0.6 | — | 0.1 |

旧值完全失去单调性（黄/白 29.8 记 1.1「易混」、绿/红 86.6 记 16.0「可区分」）；新值与 ΔE00 同量级且单调一致，端点（黑白 100、近似色 0.1）正确。
