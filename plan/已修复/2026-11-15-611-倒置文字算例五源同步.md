## 踩坑
- 首版脚本用普通 Python 字符串写 `"hello"`，Python 把 `\"` 吞成 `"`，导致 JSON 文件里带反斜杠的 value 匹配不上 ⇒ 安全中止、只落盘前两文件。改用 **raw string** 精确匹配后续跑成功。教训：**改 JSON 里的转义串必须用 raw string 或先读原文比对**。
