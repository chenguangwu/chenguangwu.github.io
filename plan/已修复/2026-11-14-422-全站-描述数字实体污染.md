# 422 批：数字 HTML 实体污染工具描述（39 页）

日期：2026-11-14
范围：`scripts/tool_desc_source.py`

## 一、问题

`json/tools.json` 有 39 个工具的 `d` 含 `&#128274;`、`&#127912;`、`&#x1F4DD;` 这类
数字 HTML 实体。卡片、搜索结果按纯文本渲染，用户会直接看到实体源码，而不是图标。
根因是历史 i18n `zh-CN.desc` 用数字实体写图标，`clean_zh_candidate()` 未解码。

其中多数页面的 `zh-CN.intro` 本身是完整描述（如 JS 混淆器、代码高亮、摘要生成器），
只是 `desc` 以「图标 + 名称」形式通过弱描述判定，压过了 intro。

## 二、修复

在 `clean_zh_candidate()` 开头只解**数字实体**：

```python
s = re.sub(r'&#(?:x[0-9a-fA-F]+|\d+);',
           lambda m: html.unescape(m.group(0)), s or '').strip()
```

保留 `&amp;`、`&lt;` 等具名实体不动，避免破坏 HTML 转义页（`encode/html`）中
「如 &amp;」这类需要原样展示的示例。

## 三、验证

- `d` 含数字实体：**39 → 0**。
- 解码后图标不再等价于名称前缀的页面自动回落 intro：
  `it/js-obfuscator`、`it/code-highlighter`、`it/summary-generator` 等
  由「图标 + 名称」变为真实功能描述。
- `encode/html` 仍保留「如 &amp;」示例，未被误改。
- `_build.py` 连续两次幂等；`_test_static.py` **4714/4714 通过**。
