## 3. 通用两态锁加固 `scripts/_verify_fn189_rollout.mjs`

1. **canvas 桩**：`bond-yield-calculator` / `break-even-calculator` 的 `calc()` 会画 canvas，JSDOM 未装 canvas 包 ⇒ `getContext()` 返回 null、`ctx.scale` 抛错中断整条链。在 `beforeParse` 注入 `HTMLCanvasElement.prototype.getContext` 的 Proxy 桩（含 `measureText` / `createLinearGradient` / `getImageData`）+ `canvasColorWithAlpha` / `resolveCanvasColor`。
2. **改为直接驱动 `Extras()` 链**：不再调页面 `calc()`，而是写输入值 + 往结果容器注入「✅ 通过」/「⚠️ 校验错误，号码无效」两段文本，再调 `__<pre>Extras()`。这样绕开所有页面专属真机依赖，且判别力更精准（明确构造成功/失败两种结论）。
3. `new VirtualConsole()` 静默页面初始化时 canvas 等已知盲区噪音。

**回归验证**：改动后第 42 批 8 页仍 **209 PASS / 0 FAIL**，第 40/41 批抽 4 页（含 `text-reverse-words`、`sort-code-validator-validator`）**105 PASS / 0 FAIL** ⇒ 加固未破坏既有证据。
