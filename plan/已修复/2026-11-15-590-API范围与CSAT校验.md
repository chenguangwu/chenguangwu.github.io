# 590 批：API 范围警示与 CSAT 输入校验

## petrochem/api-gravity：极端 API 无警示
- 根因：只拦 `api<=-131.5`，API=-130 仍输出 94.24 g/cm³ 并标「超重质」；比重反算同样无范围提示。
- 改法：API 超出 -10~100 时在结果区追加黄色范围警示，保留原计算值；比重模式按换算后的 API 同步提示。
- 验证：新增 API=-130 用例命中「超出原油常见范围」；原 53 API / 0.85 SG（766.1707 kg/m³）保持。

## service/csat-score：空值与清零仍出结论
- 根因：`parseInt(v)||0` 把空值当 0，五项清零仍输出 0% CSAT「需改善」，星级分布 `count/total` 为 NaN；负人数可直接参与合计；NPS 实为星级代理。
- 改法：五项须为 0 或正整数（空/负/小数拒绝）；合计为 0 时提示补录并清空分布与结论；复制报告同样要求合计 >0；NPS 标签改为「NPS（星级代理）」。
- 验证：新增全 0 与 s1=-3 两例；原 216 人（83.3%/4.29/216）用例保持。
