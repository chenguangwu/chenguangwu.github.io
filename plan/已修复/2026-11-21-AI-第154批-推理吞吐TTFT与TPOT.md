# 第 154 批：推理吞吐拆分 TTFT / TPOT（AI）

- 日期：2026-11-21
- 页面：`tools/ai/inference-throughput.html`、`guides/inference-throughput-guide.html`
- 数据源：`i18n/tools/ai.json`、`i18n/tools/en/ai/inference-throughput.json`、`i18n/guides/inference-throughput-guide.json`

## 原问题

页面只有一个「单请求耗时」输入，把预填充与逐 token 解码混在一起，FAQ 却在讲 TTFT，用户无法按「首 token 延迟 + 每 token 间隔」做真实容量规划；指南里的单请求吞吐公式也把并发乘进了分母。

## 修复

- 输入拆为「首 token 延迟 TTFT 秒」与「每 token 间隔 TPOT 秒」，保留生成 tokens 与并发批量。
- 单请求时延 = `TTFT + (tokens-1) × TPOT`；总吞吐 = `tokens × 批量 ÷ 时延`；单请求吞吐 = `tokens ÷ 时延`。
- 结果新增单请求时延行并展示 TTFT/TPOT 组成；表格新增 TTFT、TPOT、时延三行；历史存 `ttft/tpot` 并可回填。
- 预设改为对话/标准/批处理三档，均带 TTFT+TPOT；图表按新时延计算。
- 简介、公式、深度解析算例、使用指南同口径改写；修正指南「单请求吞吐 = tokens /(秒×批量)」的错误公式。

## 验证

- `node scripts/verify_ai_calc.js`：134/134 + DOM 11/11。
- 900 tokens / TTFT 1.2s / TPOT 0.01s / 批量 2 ⇒ 时延 10.19s，单请求 88.3 tokens/s，总吞吐 176.6 tokens/s。
