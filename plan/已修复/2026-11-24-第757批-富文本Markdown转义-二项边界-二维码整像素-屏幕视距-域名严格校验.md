# 第757批修复记录（2026-11-24）

## 1. 富文本编辑器：普通文本被当成 Markdown 语法
- **问题**：纯文本里写 `# 标题`、`**粗体**`、`[链接]` 导出 Markdown 后变成真标题/粗体/链接，原意丢失；`<code>` 内含反引号会截断围栏。
- **修复**（`tools/it/rich-text-editor.html`）：新增 `escapeMdText(text, atLineStart)`，普通文本逐行转义 `\`、反引号、`*`、`_`、`[`、`]`、`~`、`<`；行首额外转义 `# + > -` 和 `数字.`。行内 `<code>` 按内容最长反引号自动加长围栏。链接 href 转义 `)` 与空白。使用说明补充「近似转换、复杂表格与样式无法无损」。
- **口径**：只转义「文本节点」；真正的 strong/em 仍输出 `**`/`*`，代码块/表格结构不变。

## 2. 二项分布：p=0 时右尾概率错误
- **问题**：`cdf` 先判 `p<=0 → 1`，导致 `cdf(n,-1,0)`（P(X≤-1)）错为 1，右尾也连带错。
- **修复**：`cdf` 先按 `k<0→0`、`k>=n→1` 判边界，再判退化分布 `p<=0→1`、`p>=1→0`，保证 p=0/1 时左右尾与端点一致。
- **验证值**：`cdf(5,-1,0)=0`、`cdf(5,0,0)=1`、`sf(5,0,0)=1`、`cdf(5,4,1)=0`、`cdf(5,5,1)=1`、`sf(5,5,1)=1`。

## 3. 二维码：分数像素绘制导致模块重叠
- **问题**：`cellSize` 为小数时用 `Math.ceil` 定模块宽高，相邻模块边界互相覆盖，可能改变可扫性。
- **修复**（`tools/it/qrcode.html`）：每个模块按 `round((c+margin)*cellSize)` 到 `round((c+margin+1)*cellSize)` 的整数边界绘制；保证每模块至少 1px；请求尺寸小于「模块数（含 4 格静区）」时自动提升到最小尺寸，并在生成区显示 `#qrSizeNote`（请求尺寸 / 实际尺寸 / 每模块像素 / 提升原因）。`__qrBuild` 返回 `requestedSize/minPixel/pixelSize/upscaled`。
- **口径**：默认 256px 不受影响；极小尺寸由「静默画重叠」改为「明确提升并提示」。

## 4. 屏幕尺寸计算：固定 PPI 阈值误判清晰度
- **问题**：用 300/200 固定阈值输出「视网膜/清晰/一般」，与观看距离、视力、内容无关，属伪结论。
- **修复**（`tools/it/screen-size.html`）：新增可选「观看距离（cm）」；按 `ppd = ppi × (cm/2.54) × π/180` 输出角像素密度（像素/度）；删除 300/200 评级；未填距离时只报告 PPI、点距、物理尺寸，并明确「不做清晰度结论」。公式、提示、meta 与中英文说明同步改为「阈值不能断言清晰度」。说明 60 像素/度只是常见视力粗略参考，不构成结论。
- **英文**：补充 `i18n/tools/en/it/screen-size.json` 公式/提示映射，`i18n/tools/it.json` intro 同步；英文探针 0 残留。

## 5. 字符编码工具：Punycode 输入被静默截断
- **问题**：`new URL('https://'+raw).hostname` 会静默丢掉路径、查询、`@` 前用户信息，输出只剩域名，用户误以为整个输入被转换。
- **修复**（`tools/it/char-encoder.html`）：Punycode 行只接受裸域名；检测协议、`@`、`/?#`、端口、空白、首尾点号并返回明确原因（「仅接受裸域名；含路径/查询/片段」「含用户信息」等）；合法国际化域名继续转 `xn--`。
- **验证**：`example.com/path` → 含路径拒绝；`user@example.com` → 含用户信息拒绝；`中文.中国` → `xn--` 正常。
