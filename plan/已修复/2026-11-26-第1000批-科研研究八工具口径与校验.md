# 第 1000 批：科研研究 8 个工具口径、校验与输出修正

## 1. 市场集中度（`analysis-50.html`）

- 新增可选「目标市场总规模（与营收同单位）」输入；`strictNum()` 只接受完整正数/小数，`12abc` 不再被截成 12。
- 逐行校验企业名、营收与列数：列数不足、企业名为空、营收非正/带文字，均按原行号报错并阻止计算。
- 未填市场总规模：分母取已录企业合计，全部标签标「样本内」，固定「不做完整市场集中度判定」；即使只录 1 家、样本内 HHI=10000，也不给集中度结论。
- 填市场总规模：校验「已录合计 > 市场总规模」的口径矛盾；覆盖率 <100% 只算已知企业份额/CR/HHI，不套 2500/1500 阈值；仅覆盖率 100% 才给高度集中/中度集中/竞争分散。
- 企业数 <3 时额外提示 CR3 只是已录企业合计。

## 2. 舆情声量与情感（`analysis-51.html`）

- 新增数据覆盖说明、关注阈值（默认 15%）、处置阈值（默认 25%）、绝对负面量提示阈值（默认 100）。
- 每行三类声量强制非负整数；小数、负数、尾随文字按原行号报错并阻止计算；处置阈值不得低于关注阈值。
- 结果新增负面总量、首末负面量变化（含百分比，首段 0 时说明无法算百分比）、每行负面量与环比变化、负面率最高/峰值。
- 判定改为「达到/低于当前示例阈值，但不等于安全」，删除「负面可控」；绝对负面量 ≥ 提示阈值且负面率低时，显示「低比例不代表影响小」。
- 始终显示覆盖限制：只汇总手工录入的 N 个时段，未录入时段/平台/关键词外未纳入，非自动监测。

## 3. 广告效果评估（`assessor-50.html`）

- 删除整页通用输入守卫，改为 `readNum` 逐字段严格校验；所有字段空值提示「0 合法但不能留空」。
- 触达 0、无辅助回忆 0、成本 0 不再阻断：CPM/每回忆用户成本无定义时分别显示「未定义（分母为 0）」；成本 0 时二者均显示 `¥0` 并提示确认免费资源。
- 触达 > 目标、负值、越界值按字段报错；`12abc` 不再被静默解析。

## 4. 量表分析（`analysis-49.html`）

- 删除 `filter(!isNaN)` 静默跳过逻辑；所有非空行保留原行号，列数与首行不一致即报「第 X 行有 Y 列，与首行 K 列不一致」并阻止计算。
- 空字段定位到「第 X 行第 Y 列为空或不是数值」，不按 0 处理；空数据、<2 行、首行 <2 列均明确报错。
- 总分方差为 0 时 α 无定义，不再输出信度等级。

## 5. 样本配额（`calc-97.html`）

- `readNum` 严格解析 N/n/p/e；未勾选无限总体时负数 N 报错，N 留空才视为无限总体；n 必须为 ≥1 整数，有限总体下 n 不得大于 N。
- `parseStrata()` 返回 `{rows, errors}`，每个非空行按原行号校验层名/规模；缺逗号、空名、规模非正整数均报错并阻止计算。
- 配额改用最大余数法：先 floor，再按余数降序、层规模降序、输入顺序前→后分配剩余名额，保证每层非负且合计严格等于 n。
- 分层合计不等于 N 时提示未覆盖部分；大于 N 时按口径矛盾阻止计算。

## 6. 焦点小组（`analysis-52.html`）

- 提及次数改为严格非负整数；`12abc`、`1.5`、负数、字段不足、空名均按原行号报错并阻止计算。
- 评分非数字/越界只记录、不计入均值。
- CR3 只在 ≥3 个编码时计算；不足 3 个显示「CR3 不适用，按前三项合计恒为 100%」；≥60% 表述为「提及集中，不代表意见一致」。
- 增加人工计数跨场次、未录入内容、高 CR3 不等同共识的提示。

## 7. 定性编码（`analysis-54.html`）

- 新增支持双引号字段（内部 `""` 转义）、反斜杠转义 `\,`/`\，`/`\、`/`\;`/`\|`/`\"`、行内未转义 `|` 优先分隔；正文逗号/顿号/分号可保留。
- 所有非空行按原行号解析；空正文（如 `,主题`）提示「第 1、2 行缺少资料文本」并整表不统计；未闭合引号/引号后多余字符报错。
- 正文有内容但无主题仍计入并提示「只有正文、未填写任何主题」，不算空资料。

## 8. 产品定价（`tester-17.html`）

- 新增逐位受访者 `#psmData`（4 个价格或 5 字段编号+4 价格，支持逗号/制表符/空白、CSV 表头跳过）、本地 CSV 导入与 20 人示例。
- 新增标准四条累计曲线（太便宜/便宜/贵/太贵）与 500 点扫描 + 线性插值，求 PMC/OPP/PME/IDP；修正交点算法（`贵/太贵` 用 `阈值<=x`，`psmCross` 忽略零差段，避免多交点误报）。
- 逐位模式至少 5 人；交点缺失/顺序异常/多交点时拒绝给区间结论；样本量不一致时提示。
- 仅四个汇总价时明确标为「简化参考，不是标准 PSM」：中点参考价非 OPP、下限/上限非 PMC/PME、区间宽度非弹性；不称最优价格、不建议直接上市。
- 20 人示例：PMC 40.10、OPP 66.22、PME 73.75、IDP 47.63、区间宽 50.8%；5 人示例验证交点；3 人拒绝计算。
