# 768 批：约束松解排程不再把松解时长累加进间隔（D-N39）

## 问题
`tools/clinical-nursing/restraint-duration.html` 的排程循环：

```
loosenTime = current + interval
current = loosenTime + duration
```

把上次松解占用的 15 分钟并入下一次间隔，实际连续约束 2h15m 且每轮漂移 15 分钟，
与同页公式「松解时间点 = 开始 + 间隔 × n」不符。另外：

- `totalHours` 用 `parseInt` 截断小数；
- 空值/非法值以 `||1` 回退为 1 小时并照常排程、写记录；
- 循环上限 `count<24` 静默截断且无提示。

## 修复
- 排程改为 `loosenTime = 开始 + n×间隔`，松解时长只用于显示「约 HH:MM 重新约束」，不推进间隔；
- `totalHours` 改 `parseFloat`，要求 1–24，空/越界拒绝并在排程区显示提示（含「超过 24 小时应复评并分日排程」），EMR 标「未填写」；
- 输入加 `step=0.5`、placeholder 说明可含小数；
- 复制文本沿用原始输入值；深解 JSON 的示例与场景同步为「松解时长不叠加进间隔」。

## 验证
`node scripts/verify_clinical-nursing_calc.js restraint-duration` ⇒ 4/4，新增：

- 08:00 / 8 小时 ⇒「约 12:15 重新约束」「约 16:15 重新约束」（旧实现排 10:00/12:15/14:30/16:00）；
- 2.5 小时 ⇒「约束总时长：2.5 小时」（旧实现截断为 2）；
- 空值 ⇒「约束总时长：未填写」+「请输入 1–24 小时的约束总时长」。
