任务来源：`plan/agriculture/` 前 7 项

## 修复内容

1. **灌溉均匀度：空测点不再按 0 参与**
   - 逐个读取测点原始值：空串计入 `blankCount` 并跳过；负数/非有限数直接报“测点 N 数据无效”。
   - 有效测点少于 2 个时报“当前有效 X 个，未填 Y 个”；计算成功时注明“已忽略 N 个未填测点”，柱状图标签保留原测点编号。
   - 平均灌水量为 0 时明确“CU/DU/CV 分母为零，无法计算”，不再输出 0% 与均匀性差结论。
   - `copyResult()` 采用同一空值/无效值/均值为 0 守卫。

2. **土壤有机质：前后重量为空或等重的口径**
   - 灼烧前/后重量均要求显式填写；空串提示“不能用空值代替 0”，非有限、前重≤0、后重<0 均拦截。
   - 允许后重等于前重，烧失量为 0 时提示“有机质低于该方法可检出水平”，不伪判“灼烧后不应大于前重”。
   - 增加灼烧法方法限制说明；复制采用同一校验。

3. **日光积分：高于参考上限不再称“光照充足”**
   - 区分低于、区间内、高于上限三种状态；高于 `crop.max` 判“高于参考上限”，提示光过强/热负荷/光抑制风险，必要时遮阳。
   - 说明参考区间为品种/生育期经验范围，需结合温度、CO₂ 与光周期；复制同步提示。

4. **秸秆还田：土壤有机质缺失不生成土壤建议**
   - 有机质留空保持 `null`，不按 0 进入“偏低增施”分支；负值/非有限拦截。
   - 缺失时仍计算碳氮比与补氮，但明确“未填写土壤有机质，本次不生成还田量建议”；有值时说明建议为经验值。

5. **肥料利用率：三项输入必须显式完整**
   - 施肥区吸收量、施入量、对照区吸收量任一留空即提示“对照区为零也须明确填 0，不能留空代替”。
   - 吸收量要求有限非负，施入量有限正数；复制沿用同一口径，不再 `+value || 0`。

6. **种子发芽率：缺测与无效值区分**
   - 逐日记录空串视为“未观测”，不按 0 计算；负数/非整数报“第 N 天须为非负整数”。
   - 至少 1 天有记录；缺测时标记“记录不完整”，发芽率按已记录天数计算但不给优质种/合格定级；发芽势观察未覆盖时显示“—”；活力指数在缺测或缺苗长时不计算。
   - 复制文本同步“记录不完整/未计算”说明。

7. **农药安全间隔：小数不再截断**
   - `parseInt` 改为原始字符串整数正则校验；`3.9` 明确提示“不会被截断成 3 天”。
   - 结果与复制统一表述为“按标签间隔推算的最早采收日”，并注明不构成农药残留检测结论，须核对当地登记标签与残留限量。
