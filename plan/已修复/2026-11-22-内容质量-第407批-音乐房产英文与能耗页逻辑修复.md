# 第407批：音乐 / 房产英文清零 + 能耗分摊页核心逻辑错配修复

## 依据
`scripts/_en_i18n_probe.mjs --check`：`music` 5 页、`property` 7 页英文态残留。
复核 `tools/property/energy.html` 时发现页面标题、元描述、指南与深度解析均为「能耗（水电/燃气）分摊」，但表单、公式与 `calc()` 实际是「采购运费 = 重量 × 运费率」，属整段复制粘贴错配，且配套 verify 用例也按运费写。

## 处理
- 音乐 3 页播放/增加按钮补 `data-i18n-aria`（新增 `tool.aria.play`），播放器与简谱页长说明补英文键。
- 房产 6 页元描述补英文；`energy` 页全部英文键重写。
- **`property/energy.html` 按页面主题重写核心逻辑**：
  - 输入改为公共能耗总额（元）、总建筑面积（㎡）、本户/本区域面积（㎡），默认 9600 / 10000 / 100。
  - `calc()` 输出分摊金额、面积占比、单位面积成本；增加正数校验与本户面积不得大于总面积的校验，空态/非法态不输出 0 假结果。
  - 公式框、公式说明、表头引据、提示条、重置逻辑、预设场景同步改为能耗分摊口径。
  - `i18n/tools/property-body.json` 的 `energy` 条目改为真实简介与英文简介。
  - `scripts/verify_property_calc.js` 用例由运费口径改为 9600/10000/100 → 96.00 / 1.00% / 0.96，property 用例 26/26 通过。
- 重跑 `_build.py` 刷新 SW 版本戳。
