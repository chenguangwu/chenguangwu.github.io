## 1. 广告 ROI 保本反推重复计入货品成本（545）

- **复核失败点原文**：`tools/marketing/ad-roi.html:392–395` 的 `requiredConversions` 用 `totalCost`（预算＋货品成本＋固定成本）作分子。货品成本随收入同比增长，保本条件是「转化数×客单价×毛利率 = 预算＋固定成本」，把当前货品成本并入分子会重复计算；深览示例还把成本率 40% 写成「毛利率 40%」。
- **根因**：反推公式沿用了「总成本」口径，而总成本里的货品成本本身是「收入×成本率」，依赖待求的转化数，不能作为常数分子；示例术语把「成本率」误写为「毛利率」。
- **修复位点**：
  - 新增 `fixedTotal = budget + fixed`，`requiredConversions = fixedTotal/(aov*grossMargin)`、`aovNeeded = fixedTotal/(clicks*cvr*grossMargin)`，提示改为「按广告预算与固定成本 X 元计」；
  - 深览示例改为「成本率 40%（毛利率 60%）→ 货成本 12000 元」，盈亏平衡写「ROAS=1÷毛利率=1/0.6≈1.67」；
  - 挽回阈值公式改为「（预算+固定成本）/(客单价×点击量×(1−成本率))」；
  - FAQ 改为「成本率 40%、毛利率 60% 时为 1.67」，并同步 `i18n/tools/content_deepdive.json` 与 `i18n/tools/en/marketing/ad-roi.json` 的键值。
- **验证证据**：
  - 既有亏损档用例的补亏提示期望由「5.00%」改为「13.00%」——预算 5000＋固定 200、客单 100、成本率 60%（毛利率 40%）⇒ 130 单 / 1000 点击 = 13.00%；
  - 新增 `AR545`：预算 10000、CPC 2、CVR 1%、客单 200、成本率 50% ⇒ 点击 5000、收入 10000、货品 5000、总成本 15000、利润 −5000；探针断言提示含「转化率需提升至 2.00%」「客单价提升至 400 元」且不含「总成本 15,000」。`node scripts/verify_marketing_calc.js ad-roi` 通过。
- **判别力实测**：把 `fixedTotal` 改回 `totalCost` 后 `AR545` 转红（提示变为 3.00% / 600 元，且出现「按总成本 15,000」），恢复即绿。

## 2. 「其他」份额下集中度被当作确定值（546）

- **复核失败点原文**：`tools/marketing/market-share.html` 只按具名企业求和 HHI/CR4 并直接分类，同时提示「其他视为分散，未计入」。但「其他」是合并口径，其内部平方和 > 0，且其中企业可能进入前四，真实 HHI/CR4 只会更高；把已知部分当确定值会低估集中度并给出错误的「竞争型」结论。
- **根因**：把「未拆分的其他」当成原子份额，平方和按 0 计，且分类阈值直接套用在被低估的数值上。
- **修复位点**：
  - `hasOther = otherPct > 1e-9`；有「其他」时 HHI 显示 `≥ X`、CR4 显示 `≥ Y%`，市场类型改为「无法判定（需拆分「其他」）」并注明「已知部分仅为下界」；
  - 建议区在有「其他」时改为「请拆分其他后评估」，不再输出竞争/寡占结论；「第一名占 X%」改用 `named[0]`（避免把「其他」当第一名）；
  - 深览新增 FAQ 说明下界原因；同步英文映射。
- **验证证据**：新增 `MS546`——甲 10%、乙 10%、其他 80% ⇒ 探针断言 `#hhiBox` 同时出现「≥ 200」「无法判定」「下界」且不出现「竞争型」。`node scripts/verify_marketing_calc.js market-share` 通过。
- **判别力实测**：把 `hasOther` 固定为 `false`（等价旧逻辑）后 `MS546` 转红（输出「竞争型」「视为分散」）；恢复即绿。默认输入不含「其他」条目，不命中。

## 3. 品牌资产：空值被当 0、净利润口径自相矛盾（547）

- **复核失败点原文**：`tools/marketing/assessor-51.html` 用一元 `+value` 读入参，`contribution`/`discount` 清空后会变成 0 并通过 `0–100` 校验，继续算出估值；同时输入标签写「品牌年净利润 (万元)」，公式再乘一次品牌贡献率得到「品牌净利润」，标签与口径自相矛盾。
- **根因**：数值读取未区分「空串」与「合法的 0」；标签沿用了「品牌净利润」而计算按「企业净利润 × 贡献率」。
- **修复位点**：
  - 四项输入先取 `String(...).trim()`，空串单独报「请填写…」，再判数值区间；贡献率/折现率取 0 仍合法；
  - 标签、公式、示例、错误文案、结果文案统一为「企业年净利润 × 品牌贡献率 = 品牌净利润」：输入框改为「企业年净利润 (万元)」，输出改为「企业年净利润：8000万元 × 贡献率 72% → 品牌净利润 5760万元」；同步 `content_deepdive.json` 与 `en/marketing/assessor-51.json`。
- **验证证据**：
  - 既有专项期望改为「→ 品牌净利润 5760万元」，其余三条（强度分、折现率、品牌资产价值 30249 万元）不变；
  - 新增 `AC547`（清空贡献率 ⇒ 提示「请填写品牌贡献率」且不出现「品牌资产价值」）与 `AC547Z`（贡献率=0 合法 ⇒ 正常出估值、无空值提示）互为对照。
  - `node scripts/verify_marketing_calc.js assessor-51` 通过。
- **判别力实测**：把贡献率校验改回只判区间（空串→0 放行）后 `AC547` 转红、`AC547Z` 仍绿；恢复即绿。
