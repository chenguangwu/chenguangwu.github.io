# 第683批：暗色模式页面级硬编码文本修复

## 背景

第682批已把全局组件（结果强调、深读标题/链接、提示条）改成随主题切换的文本变量。但第683批抽样扫描发现，部分工具页仍把强调色硬编码在 JS 动态生成的 HTML 中，浅色/暗色总有一侧不达标。

本批只修三页可安全替换的“纯文字色”，不改图表、色带、固定底色的页面。

## 修复内容

### 1. 新增青色文本变量（`css/common.css`）

- 浅色：`--tb-text-cyan:#0E7490`
- 暗色：`--tb-text-cyan:#22D3EE`

### 2. 古瓷断代（`tools/antiques/porcelain-date.html`）

`feature-tag` 由 JS 动态拼接：

- 青瓷标签：`#0891B2` → `var(--tb-text-cyan,#0E7490)`
- 其他标签：`#FF6B35` → `var(--tb-text-accent,#B23A08)`

实测（标签底色为 10% 半透明，已按实际合成色计算）：

| 场景 | 文字色 | 合成背景 | 对比度 |
|---|---|---|---|
| 浅色 | `#0E7490` | `#E6F4F7` | **4.76:1** |
| 暗色 | `#22D3EE` | `#22304B` | **7.30:1** |

### 3. 经络循行图（`tools/acupuncture/meridian-pathway.html`）

经脉数据中的文字色改为主题变量：

- `#065F46` → `var(--tb-text-success)`
- `#FF6B35` → `var(--tb-text-accent)`
- `#92400E` → `var(--tb-text-warning)`
- `#B91C1C` → `var(--tb-text-danger)`
- `#1D4ED8` → `var(--tb-text-info)`

这些色仅用于圆点、标题、统计数字和表格文字，不进入 Canvas。

实测：

| 场景 | 文字色 | 背景 | 对比度 |
|---|---|---|---|
| 浅色 | `#065F46` | `#FFFFFF` | **7.68:1** |
| 暗色 | `#34D399` | `#252540` | **7.71:1** |

### 4. 咬合接触分析（`tools/dentistry/bite-contact.html`）

左右/前后/力中心分级色改为 `var(--success)` / `var(--warning)` / `var(--danger)`，仅用于统计卡和表格文字。

实测（“轻度失衡”）：

| 场景 | 文字色 | 背景 | 对比度 |
|---|---|---|---|
| 浅色 | `#92400E` | `#FFF8F5` | **6.75:1** |
| 暗色 | `#FBBF24` | `#252540` | **8.88:1** |

## 验证

- `python3 _build.py`：通过；三页改动在构建后仍存活。
- `python3 _test_static.py`：4654 通过 / 0 失败。
- `_audit_links.py --check`：16795 文件 / 167644 内链 / 0 死链。
- `_audit_assets.py --check`：0 资产死链 / 0 lang 缺失 / 0 重复 id。
- 真机 Chrome 浅色/暗色各测三页，均达到 WCAG AA 正文阈值（≥4.5:1）。

## 边界

未对下列情况做整页替换，避免把固定浅色底上的文字改坏：

- 固定浅底徽章（`#fef3c7`、`#fef2f2`）。
- Canvas 绘图色。
- 动态进度条上的白字（需按条底色分别判定）。
