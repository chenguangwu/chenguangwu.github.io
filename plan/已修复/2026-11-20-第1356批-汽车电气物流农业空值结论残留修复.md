# 第 1356 批 · 空输入仍给结论（汽车 8 + 电气/物流/农业 4）

## 根因

这批页面统一形态：`calc()` 里 `val()` 走 `parseFloat`，空输入得 `NaN`；结果模板只把**数字**渲染成 `--`，但**结论句 / 建议 / 分级照常输出**，于是出现「效率 0% 疑似失效」「剩余 0 km 状态正常」「花深 -- 但状态良好」「安全系数 ∞ 屈服风险」「照度 0 明显不足」「推荐 2.3 bar 偏差 --」「建议间隔 …」等荒谬结论。另 `ohms-law`/`fuel-calculator` 只在校验失败时 `ToolBox.showToast()`，**结果区保留上一次的旧数值**。

修法统一：在 `calc()` 读完核心输入后、首次使用前插守卫，往结果容器写 `⚠ …` 提示并 `return`；有分布图 / 公式框 / 建议框的一并清空。每处留锚点注释便于构建后复查。
