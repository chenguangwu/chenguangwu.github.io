# 第 538 批：家具布局页 320px 窄屏溢出修复

## 问题
`tools/home/furniture-layout.html` 在 320px 宽度下 `scrollWidth=331`，右侧内容被裁切。

## 原因
1. 移动端网格列 `1fr` 仍以内容最小宽度撑开，`.sidebar` 与画布容器被拉到 300px。
2. 画布尺寸按固定 `SCALE=60` 像素写入，5m 房间即 300px，超过 258px 可用宽度。

## 修复
- 移动端网格改为 `minmax(0,1fr)`，侧栏与画布补 `min-width:0`，家具按钮允许换行。
- 新增 `roomScale()`：桌面保持原 60px/m 比例；窄屏按容器可用宽度等比缩放，拖拽换算同步使用当前比例。
- 监听窗口尺寸变化，旋转/缩放后自动重算。

## 验证
- 320px：`scrollWidth=320`，预设卧室布局 4 件家具 0 越界。
- `verify_home_calc.js` 39/39；`_test_static.py` 0 失败 0 告警；全量 272 门禁通过。
