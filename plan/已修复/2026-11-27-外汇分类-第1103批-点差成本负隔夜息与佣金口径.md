## 问题与修复

1. **负隔夜息被反向抵减**
   - 原公式 `总成本 = 点差成本 + 佣金 + 隔夜利息` 直接加上带符号的 swap；当 swap=−3.5 时，实际是付息，却把总成本减掉 3.5。原示例点差 20、佣金 7、隔夜 −3.5、持有 1 天显示 23.5，与 FAQ“负号=付息”矛盾。
   - 现明确 swap 为**有符号现金流**：负=付出、正=收取。
   - 新增 `隔夜现金流 = 手数 × 每手隔夜息 × 天数`、`隔夜成本 = −隔夜现金流`；付出时转为正成本，收取时转为负成本（抵减）。
   - 总成本统一为 `点差成本 + 佣金 + 隔夜成本`。
   - 同例修正为 20 + 7 + 3.5 = **30.5**；若 swap=+3.5，则 20 + 7 − 3.5 = **23.5**。

2. **佣金单边/往返口径不一致**
   - 输入标签已写“每手佣金（USD，往返）”，但深度解析原文写“总佣金 = 手数 × 单边佣金”，示例又称“佣金 7/手”。
   - 现统一为**每手往返佣金**：输入标签、公式、结果明细“佣金（每手往返）”、深度解析方法/算例全部一致；不再出现“单边佣金”。

3. **零天、收息与净收益展示**
   - 持有 0 天时明确显示“隔夜利息 = $0.00（持有 0 天，未产生过夜利息）”，不再因 `days=0` 省略该行。
   - swap=0 且持有天数>0 时显示“隔夜利息 = $0.00（每手隔夜息为 0）”。
   - 负隔夜息显示“隔夜利息支出 $3.50（计入成本）”；正隔夜息显示“隔夜利息收入 $3.50（抵减成本）”。
   - 当隔夜收入大于点差与佣金时，总成本为负，改为显示“净收益（隔夜收入大于点差与佣金）”，统计卡同步显示“净收益”、占比显示“净收益占持仓”，不再出现负的“成本占持仓”。

4. **同步数据源与验证**
   - 页面公式框、说明卡、深度解析、FAQ、FAQ JSON-LD、使用指南、`i18n/tools/content_deepdive.json`、英文词典同步。
   - `scripts/verify_forex_calc.js` 的 GBPUSD 3 手、2 天用例由旧错误值 60 改为：点差 60 + 佣金 21 + 隔夜成本 21 = **102**。
