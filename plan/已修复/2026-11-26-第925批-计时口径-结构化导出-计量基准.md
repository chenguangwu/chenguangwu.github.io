范围：`plan/life/` 8 个任务；工具页 7 个，测试与 i18n 同步。

## 处理清单

1. **多功能倒计时：循环训练与番茄休息功能缺失**
   - 不扩展为多组循环；按任务给出的备选方案，准确说明页面只有单次计时。
   - 使用说明改为“25 分钟单次专注预设；不含自动休息或多组循环，需要休息请另设一次计时”，预设按钮由“🍅 番茄钟”改为“🍅 25 分钟专注”。
   - FAQ 与 JSON-LD 原有“一次性计时、不提供多组循环”口径保留，不再让说明暗示自动休息/多轮。

2. **音乐练习计时：历史记录混合多次累计与暂停快照**
   - `recordPractice(final)` 明确起止口径：完成时写入本次单段累计，然后 `practiceSec/restSec/segStartTs/segBudgetSec` 全部归零；暂停只写入 `__tbn_practice_draft`，不新增完整历史。
   - `__tbn(doRecord)` 拆分“记录”与“只重绘成绩区”：初次加载、模板刷新只重绘，不再写入 0 秒历史；完成时才把当前值写入历史与 `TBKit.history`。
   - 真机连续两次完成（约 4.0 s、1.5 s）得到 `[4.008,1.502]`，不再第二次记成累计值；暂停后历史仍为 0 条，草稿保存当前秒数。

3. **清洁用品：购物清单取消勾选后复制仍包含该项**
   - `copyShopList()` 改为读取 `#shopList input[type=checkbox][data-id]` 的实际勾选状态，只复制已勾选项；全部取消时提示“请至少勾选一项需要购买的用品后再复制”，不产生空清单。
   - 英文态复制标题、数量与提示同步英文。
   - 真机：两项中取消第二项，复制内容只含第一项；全取消得到提示。

4. **世界时钟：导出明细读取静态说明**
   - 新增 `__world_clockViewRecord(en)`，按当前视图记录：时差视图 `view/cityA/cityB/date/time/result`，会议视图 `view/cities/workHours/result`，时钟视图 `view/cities/result`。结果取自实际计算结果节点，`--` 或偏移不可靠时返回空，不记录。
   - `__world_clockExtras()` 改为按上述结构写入历史；`__world_clockExport()` 先取当前视图结果，无可导出结果时提示而不是导出静态说明。
   - 导出/历史表头增加可读列名映射，内部字段 `cityA/workHours` 不再直接显示；时区名仍保留在值中。
   - `TBKit.history` 与导出表真机核对：时差记录含北京/伦敦、日期时间与“慢 8 小时 0 分钟”，结论为通过；无共同工作时间判 0。

5. **竞争分析：缺字段行被静默跳过**
   - 924 已实现严格整字段与缺列停止；925 补缺第四列用例 `甲,10,20`，输出“第 1 行字段数为 3，应为 4 列……已停止汇总”，不再带着缺列行继续出均价与份额。

6. **生肖星座：农历回退结果未单独警示**
   - 改为只在 `Intl.DateTimeFormat('en-u-ca-chinese')` 取到农历年时给出确定生肖；取不到时不回退公历、不显示确定生肖，红色警示“中国生肖：暂无法可靠计算”，说明当前浏览器未提供可用中国农历年。
   - 西方星座继续正常显示；FAQ、公式说明与 `content_deepdive.json` 同步“不回退公历年份”的口径。
   - 真机 monkeypatch `Intl.DateTimeFormat` 抛错：生肖区显示警示，星座仍为摩羯座。

7. **辐射剂量：跨剂量类型默认权重 1**
   - 新增“跨类换算条件”下拉：默认仅同类换算；X/γ `w_R=1`、α `w_R=20`、自定义 `w_R`。只有显式选择条件才进行 Gy↔Sv，输出标注“当量剂量，不是有效剂量（有效剂量还需组织权重因子）”。
   - 未选择时明确提示不跨类；同类结果照常输出。英文态动态单位名、量类、同类/跨类提示同步英文。
   - 旧测试按新语义更新：`2 mSv` 默认只给 0.002 Sv 同类结果，不再给 2 Sv；新增 X/γ、α、自定义与默认不跨类用例。

8. **浓度换算：质量比例与质量浓度混同**
   - 新增 `basis`：默认稀水溶液近似（密度≈1 kg/L，ppm≈mg/L，%按质量分数）；`mass` 质量比/质量浓度（ppm/%为质量分数，mg/L、g/L、mol/L 按密度折算）；`volume` 体积比（ppm/ppb/ppt/%按体积比）。
   - 新增密度输入，仅质量口径显示；体积口径拒绝从 mg/L/gL/molL 直接换算，提示改选口径或改用体积比单位。
   - 结果明确基准（`mg/L（质量浓度）` 或 `ppm（体积比）`）与近似假设；mol/L 仍要求摩尔质量。英文态基准与单位名同步。
   - 修复初版 `if(!isFinite(molarMassValue()){` 缺右括号导致的页面语法错误。
