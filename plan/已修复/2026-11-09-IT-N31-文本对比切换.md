# IT-N31：文本对比视图切换依赖全局 event

- 原问题：`switchView()` 使用隐式 `event.target`；缺少全局 event 的浏览器或程序化调用会报错，且可能在切换中途隐藏两个视图。
- 修复：`tools/it/text-diff.html` 的两个按钮显式将 `this` 传给 `switchView(view, tab)`，通过传入的元素更新选中状态。
- 验证：`node scripts/verify_text_diff_tabs.cjs` 在无全局 event 条件下断言合并与并排两态互切、选中状态与可见区域一致；旧版源码运行该检查会因读取未定义的 `event.target` 报错。`node scripts/verify_it_calc.js text-diff` 2/2 通过。
- 完整门禁按用户本轮要求暂未运行；未推送、未线上验证。
