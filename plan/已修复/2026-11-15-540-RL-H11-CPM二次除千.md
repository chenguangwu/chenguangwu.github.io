# 540 批：RL-H11 广告评估 CPM 二次除千

- 日期：2026-11-15
- 来源：`plan/categories/07-教育学习/research-library.md` RL-H11
- 受影响页面：`tools/research/assessor-50.html`

## 缺陷

`cpm` 计算已按「元/千次」口径：

```js
var cpm = cost*10000/(reach/1000);
```

结果卡 `CPM(元/千次)` 直接显示 `cpm`（正确），但底部成本效益行仍写
`(cpm/1000).toFixed(2)`，把「元/千次」又除 1000，显示值仅为真实值的 1/1000。
默认 50 万元 / 5 万人应在 10000 元/千次附近，页面却显示 10.00（再除千后为 0.01）。

## 修复

```js
html+='...CPM='+cpm.toFixed(2)+'元/千次曝光，每回忆用户成本='+(isFinite(cpr)&&cpr>0?'¥'+cpr.toFixed(1):'—')+'</p>';
```

同时把 `cpr` 在 `unaidedRecall=0` 时置为 `NaN`，避免极端情况下显示 `Infinity`
（页面已有分母守卫，此为防御性处理）。

- `node scripts/_en_i18n_probe.mjs --check research/assessor-50`：残留 0。
- `python3 _build.py` 通过；`python3 _test_static.py`：4685/4685 通过。
