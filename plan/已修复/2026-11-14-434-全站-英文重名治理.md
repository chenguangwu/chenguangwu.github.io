# 434 批：英文重名治理（15 组泛化英文名）

日期：2026-11-14
范围：`i18n/tools/_en_override.json`（33 个条目）

## 一、问题

英文重名 28 组，其中 15 组是「不同功能却共用泛化英文名」：
`Security`（4 页）、`Competition`（3 页）、`Insurance` / `Care` / `Vaccine Schedule` /
`Aspect Ratio` / `Capacitance` / `Power Calculator` / `KPI` / `Statistics` /
`Data Analysis` / `Welding` / `Sleep Quality Score` / `Countdown Timer` / `Time Zone Convert`
（各 2 页）。这些名字既互相重复，也不说明页面实际做什么。

## 二、修复

按页面真实功能逐条改写 `_en_override.json` 的 `en`（共 33 条），例如：

| 原英文名 | 页面 | 新英文名 |
| --- | --- | --- |
| Security ×4 | exhibition/assessor-evacuation | Evacuation & Fire Safety Assessment |
| | project/checker-training-hr-1 | HSE Training & Inspection Implementation |
| | mining/checker-training-hr | Mine Safety Code & Training System |
| | beauty/assessor-risk-12 | Safety Certification & Compliance Assessment |
| Competition ×3 | life / logistics / research | Competition Analysis & Response / Competitive Strategy Analysis / Competitive Intelligence Framework |
| Insurance ×2 | life / realestate | Liability & Employer Insurance Recommender / Insurance Value & Replacement Cost Assessment |
| Countdown Timer ×2 | life/countdown | Date Countdown Timer |
| | life/countdown-timer | Multi-Event Countdown & Pomodoro Timer |
| Capacitance ×2 | electronics/convert-capacitance | Capacitor Code & Voltage Converter |
| | electronics/capacitance | Crystal Load Capacitance Calculator |

其余 `Care / Vaccine Schedule / Aspect Ratio / Power Calculator / KPI / Statistics /
Data Analysis / Welding / Sleep Quality Score / Time Zone Convert` 同样按功能拆分命名；
`dynamics/power-force` 避开与 `science/mechanical-power` 的新撞名，定名
`Force-Velocity Power Calculator`。
