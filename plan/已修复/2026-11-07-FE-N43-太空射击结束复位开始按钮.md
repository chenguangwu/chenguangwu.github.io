# 2026-11-07 FE-N43 太空射击结束态复位「开始游戏」按钮

- 分类：11-文娱爱好 / fun
- 页面：`tools/fun/space-shooter.html`
- 缺陷：游戏结束态 `#btnStart` 不复位，主操作按钮永久失效
- 严重度：中（确认源码缺陷，非陈旧快照误报）

## 失败点
`startGame()` 将 `#btnStart` 置 `disabled=true` 且文案改为「游戏中...」；`gameOver()` 只切 `STATE.GAMEOVER` 与刷新 HUD，**不恢复按钮**；仅 `restartGame()` 才把文案改回「开始游戏」并 `disabled=false`。漏敌/撞机至 0 命 → 结束覆盖层出现后点「开始游戏」无任何反应，必须先点「重新开始」，用户误判页面卡死。

## 根因
结束态与按钮状态解耦：`gameOver()` 漏写按钮复位。

## 修复位点
文件 `tools/fun/space-shooter.html`：
- `gameOver()`（约 1061 行）`updateHUD()` 之后新增：
  `var b = document.getElementById('btnStart'); if (b) { b.disabled = false; b.textContent = '开始游戏'; }`
- 同步更新 GAMEOVER 覆盖层提示文案为「点击「开始游戏」再战一次」，指向现已可用的主按钮。

   - HEAD（修复前）：同流程 → 结束态仍 `true/游戏中...` → **FAIL (exit 1)**，确认 bug 真实且已修。
