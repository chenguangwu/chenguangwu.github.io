## 修复位点

### B-F6 盈利指数页不校验 CF₀ 正负与贴现率下界（中）
- **文件**：`tools/investment/profitability-index.html`、`i18n/tools/en/investment/profitability-index.json`、`scripts/verify_investment_calc.js`
- **缺陷**：`PI = pv/(−cfs[0])`，守卫只拦 `cf0 = 0`。把初始投入填成**正数**（很常见的符号混淆）时，分母 `−1000` 变负，PV 978.96 得到 **PI −0.979**，页面仍以「盈利指数」正名输出；贴现率 −100% 时 `Math.pow(1+r,i)=0`，PV 与 PI 都变 `Infinity`，最后显示「—」。此外结果区只给 PI 与 PV，不含 `NPV = PV + CF₀`，PI 容易被单独误读。
- **修复**：
  1. 校验 `cfs[0] < 0`，否则提示「期初现金流 CF₀ 应按投入记为负数（当前 X）：PI = 未来现金流现值 ÷ 期初投入，正数会让分母变负、PI 符号翻转」并中止；
  2. 校验贴现率 `> −100%`，否则提示「折现因子无意义」；
  3. 结果区新增第三张卡「净现值 NPV = PV + CF₀」（`−2500/900/1000/1100 @7%` → PV 2612.49、NPV 112.49）；
  4. `formula-eq` 与英文 map 同步新校验与 NPV 口径。
- **根因**：公式把 CF₀ 的符号当作「约定」而非「校验项」，符号约定只写在说明里，代码不设防。

### B-F9 保证金比例页权益为 0 时杠杆倍数溢出、权益超持仓时借入资金为负（中）
- **文件**：`tools/securities/margin-requirement.html`、`i18n/tools/en/securities/margin-requirement.json`、`scripts/verify_securities_calc.js`
- **缺陷**：`杠杆倍数 = pos/Math.max(eq,1e-9)`、`借入资金 = pos−eq`。权益 0 时杠杆显示 **100000000000000.000**（1e14 级溢出）；权益 120000 > 持仓 100000 时「借入资金 −20000.00」被当作正常结果。守卫只拦 `pos = 0`，不拦 `eq ≤ 0` 或 `eq > pos`。
- **修复**：
  1. 校验 `eq > 0`，否则提示「账户权益须大于 0（当前输入 X）：权益为 0 或为负时保证金比例、杠杆倍数均无定义」；
  2. 校验 `eq ≤ pos`，否则提示「账户权益不能高于持仓市值…属于无杠杆或超额保证金，请把持仓市值填成不低于权益的金额」；
  3. 删除 `Math.max(eq,1e-9)` / `Math.max(pos,1e-9)` 兜底，杠杆改 `pos/eq`、小数比例改 `eq/pos`；
  4. `eq === pos`（无借入）时借入资金显示 `0.00` 且标签加注「权益等于持仓，无借入」；
  5. 明细表同口径（无效输入清空旧表并写占位提示）；`formula-eq` 与英文 map 同步。
- **根因**：用极小值/直接相减掩盖「无定义」与「无借入」两种截然不同的业务语义。
