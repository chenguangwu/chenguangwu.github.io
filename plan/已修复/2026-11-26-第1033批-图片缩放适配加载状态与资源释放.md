# 第 1033 批：图片缩放适配、加载状态与资源释放

页面：`tools/image/image-resize.html`

本批处理 `plan/image/图片缩放-*.md` 共 12 项：

1. **换图加载期间操作可重新生成旧图**：换图开始即清空旧 `originalImg` / `originalFile` / 结果，隐藏参数区并进入 loading；新图成功后才恢复渲染，失败保持空态。载入中 `render` / 下载 / 复制均被阻断。
2. **英文动态提示**：加载信息、尺寸/像素/宽高比标签、尺寸错误、适配方式、导出/复制/下载/锁定提示、GIF/WebP 提示、适配下拉选项均接入 `tr()` / `__imgEn()` 双语；英文态动态结果不再混入中文。
3. **重新生成期间可下载旧图**：新一轮 `render` 开始即 `clearResult()`、`resultReady=false` 并递增 `blobToken`；下载/复制检查 `resultReady`，生成期间提示等待；过期 `toBlob` 回调被 token 丢弃。
4. **平台尺寸预设可能拉伸**：新增固定尺寸适配方式 `contain`（等比留白，默认）/ `cover`（等比裁切）/ `stretch`（直接拉伸）；平台预设默认 contain，预览、输出、信息栏使用同一 `drawFit`，裁切从源图中心取景。
5. **预览重复分配完整画布**：预览改为按实际展示尺寸创建小画布，仅导出创建一张完整画布；画布容量检查前置到分配前；连续滑块/尺寸修改增加 120 ms 合并与旧结果即时作废，避免重复完整编码。
6. **说明中的模式与取整不符**：公式说明改为实际界面支持的百分比与指定尺寸；明确百分比四舍五入、锁定比例以最后编辑边为基准、固定尺寸三种适配；平滑描述改为浏览器高质量平滑而不承诺双线性。
7. **预设与历史恢复意外下载旧结果**：复核 `__image_resizePresets` 与历史回调只恢复参数并调用 `render()`，均不调用下载；下载仍只由用户明确触发，无图时提示重新选择。
8. **上传入口与锁定状态缺少键盘语义**：上传区保留 `role=button` / `tabindex=0`，移除内联点击递归，改为作用域内 click + Enter/Space；锁定按钮动态更新 `aria-pressed`、`aria-label`、`title`，中英文同步。
9. **重新锁定宽高比不纠正尺寸**：重新锁定时以当前有效的宽或高为基准边同步另一边并立即重绘；无法确定时回到原图尺寸，toast 明示采用哪条基准边。
10. **平台尺寸按钮无法调用内部函数**：`setPlatformSize` 暴露到 `window`，四个内联按钮可实际调用；同时处理等比适配默认值。
11. **过期/失败对象 URL 未释放**：每次加载持有自己的 URL；成功转移所有权，失败/过期/重置/换图均 revoke；加载期间取消也会释放本次 URL。
12. **动态 WebP 导出静态图缺少提示**：识别 WebP（MIME 或扩展名），明确提示动态 WebP 仅读取第一帧，静态 WebP 不会误报为已确认动图；GIF 仍保留首帧提示。
