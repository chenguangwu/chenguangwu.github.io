## 修复内容

1. **按内容匹配数组时左右路径混淆**
   - `deepDiff` 增加 `pathRight` / `pointerRight` 参数，递归对象、普通数组和按内容匹配数组时分别传递右侧路径与 RFC 6901 指针。
   - 跨下标配对（如左侧 `[1,2]`、右侧 `[0,1,3]` 中 `2 ↔ 0`）记录为 `arr[1] → arr[0]`，左指针 `/arr/1`、右指针 `/arr/0`；路径视图、复制文本与 JSON 导出均保留两侧位置。
   - 剩余项类型不同（数字 vs 对象）时拆成删除 + 新增，不再强行报成同路径 mod。
   - 删除项不伪造右侧路径（`pathRight` / `pointerRight` 为 `null`）；新增项记录实际右侧位置。
   - 验证插入、删除、换序、重复值、类型混合与嵌套数组。

2. **根节点指针显示为斜杠**
   - 新增 `jdPointerLabel()`：空字符串显示为「（根节点，空指针）」/`(root, empty pointer)`，不再退化成 `/`；`/` 仍保留给空字符串键。
   - 新增 `jdPathLabel()`：空字符串键的 `pointer` 为 `/` 而 `path` 被写作 `(root)` 时显示「（空键）」/`(empty key)`，与根节点明确区分。
   - 路径视图显示 `JSON Pointer: 左 … / 右 …`（英文 L/R）；复制文本包含 `[空指针说明]` 与跨下标 `→`；JSON 导出保留 `pointer: ""`。
   - 验证根节点替换、空字符串键、含 `/` 与 `~` 的键（仍转义为 `/a~1b`、`/x~0y`）以及 JSON 导出。
