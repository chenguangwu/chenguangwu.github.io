# 第306批：广告/公关/租赁/物业英文占位收口

## 背景

全行业 `audit_industry.py` 汇总发现 104 个行业存在英文 `body title` 代号（如 `Analysis 30`、`Assessor 57`、`Rent 2`），直接进入英文 `<title>`/meta 与页面 H2，属可检索可见的占位。

本批先收口四个高密度行业：

| 行业 | 修复页面 |
|---|---|
| advertising | 7 |
| pr | 4 |
| rental | 4 |
| property | 3 + 1 |
| 合计 | **25**（含 19 主批 + 6 补漏） |

## 做法

对每个占位页：

1. 以页面 `data-zh` 中文标题为源，取已有 `i18n/tools/en/<ind>/<slug>.json` 的标题译文（104/107 可直接匹配），人工补齐 3 条；
2. 页面 H2 改为「原图标 + 英文标题」，首个 `<p>` 改为英文简介，`data-zh` 保留中文；
3. 同步 `i18n/tools/<ind>-body.json` 的 `title` / `h1` / `intro` 与 `en` 镜像；
4. 同步 `i18n/tools/en/<ind>/<slug>.json` 的 `name`；
5. 同步 `i18n/tools/<ind>.json` 的 `en-US.title/h1/intro`。

示例：

- `advertising/assessor-53`：`Assessor 53` → `Performance (Evaluation / Attribution / Reporting) Model`
- `pr/assessor-59`：`Assessor 59` → `PR (Effect/Evaluation/Reporting) System`
- `rental/rent-2`：`Rent 2` → `Rent (Market Comparison / Dynamic) Pricing`
- `property/cycle-10`：`Cycle 10` → `Inspection Routes and Cycle Planning`

## 孤儿键清理

删除四个 body JSON 中已无页面的 13 个键（`recognize-5`、`manager-drill-1`、`tool-012-76`、`simulator-22`、`classify-17` 等），避免审计把死配置继续算作占位。

## 验收

- `audit_industry.py --ind advertising/pr/rental/property`：`body title 真·代号/全英文=0`、孤儿键=0
- `_en_i18n_probe --check`：`advertising/tester-15`、`rental/rent-2`、`property/cycle-10`、`pr/analysis-density-1` 均 **0 残留**（pr 页另补 1 条已有正文译文）
- `_build.py`：4,426 页
- `run_gates.py --skip-build`：**268/268 全过**
