## 修复条目

### 1. `tools/rubber/tensile-strength.html` — 标距和载荷缺少边界校验

- 新增统一 `__tensileValidate()`，计算与复制共用同一校验：
  - 五项必须为非空有效数值；
  - 最大拉伸力不得为负，0 保留为空载；
  - 宽度、厚度、原始标距必须大于 0；
  - 断裂标距不得为负，也不得小于原始标距。
- 无效输入清空结果、历史表和图表；复制被 `showToast` 阻止，不再输出 0 或伪造结果。
- 移除“高强度高伸长/良好/一般/偏低”的合格式判级，改为“高强高伸长常见区间”的描述，并注明须结合胶种、配方、试验条件与产品标准。
- 公式框、深解析、FAQ 同步。

真机验证：
- 默认 500 N / 6 mm / 2 mm / 25→125 mm → 41.67 MPa、400.0%、5.00。
- 校验用例 750 N → 62.50 MPa。
- 负拉力、断裂标距 20 mm、原始标距 0 均给出对应错误。
- 最大力 0 合法，输出 0.00 MPa。

### 2. `tools/rubber/hardness-calc.html` — 越界与复制不完整

- Shore D 由 A→D 二次式反解为严格逆函数 `A=50+[−0.5+√(0.25+0.04D)]/0.02`，修正 A80→D24→A98 的往返偏差；D24 现在回到 A80。
- Shore D>50 时反解超出 A 0–100，明确显示“不可换算”，不再截断成 100。
- IRHD 仅在 20–90 HA 用 A+1 近似；A=100 显示“不可换算”，不再出现 IRHD 101；IRHD>90 同样提示超出范围。
- 换算结果附带限制说明和“工程近似、验收须实测”；等级改为“硬度区间”，只作描述。
- 复制使用 `__hardLastConvertText`，包含实际换算值与单位；无有效结果时阻止复制。模量复制共用 0–99 HA 校验。
- 公式框、深解析、FAQ、元描述同步。

真机验证：
- A100 → A100 HA、D50 HD、IRHD 不可换算。
- D45 → A97 HA、D45 HD、IRHD 不可换算（A97 超出近似范围）。
- D60 → A 不可换算、D60 HD。
- D24 → A80 HA、D24 HD、IRHD81。
- IRHD71 → A70 HA、D14 HD、IRHD71。
- IRHD95 → A/D/IRHD 均不可换算或仅保留原值。

### 3. `tools/rubber/abrasion-test.html` — 不同方法固定换算不一致

- 撤下阿克隆×130、×1.2、格拉西尔×100 等跨方法固定换算，改为每种方法只记录并显示自身读数与单位。
- 明确不同方法的试样、磨料、负荷、行程不同，不能可靠互算；需要对比时按对应标准分别实测。
- 移除按阿克隆值统一判“极好/良好/一般/较差”的评级，改为材料典型范围参考，标注“非合格判定”。
- 复制只复制当前方法读数，无有效结果时阻止；负值、空值给出错误。
- 公式框、深解析、FAQ、元描述同步；`guides/abrasion-test-guide.html` 及其英文映射同步改为“不提供跨方法换算”。

真机验证：
- 阿克隆 0.15 → 只显示 0.15 cm³/1.61km，页面不再出现 19.50 mm³。
- DIN 20 → 只显示 DIN 20 mm³，不反算阿克隆。
- 负值 -1 → “磨耗值须为非负数值”，复制为空。

### 4. `tools/rubber/mixing-ratio.html` — 负数和缺失被用于重量计算

- 新增 `__mixValidate()`，计算与复制共用：
  - 总重量为空或负数阻止计算；0 是合法空批，输出各组分 0.000 kg；
  - 每个组分 phr 为空、非数值或负数即停止，并指出具体组分；
  - 总 phr 必须大于 0。
- 无效状态把各行重量清为“—”，不保留旧值；复制同步阻断。
- 更新 `updatePhr` 区分空值与 0，`renderList` 正确显示空值。
- 公式框、深解析、FAQ、元描述同步。

真机验证：
- 默认 100 kg / 157.2 phr → 每份 0.6361 kg/phr。
- 150 kg → 每份 0.9542 kg/phr，NR 95.420 kg。
- 总重量空 → 提示填写；-5 → 提示非负；0 → 各组分 0 kg，保留 phr 配比。
- 氧化锌 phr 改 -5 → 指出“氧化锌”份数不能为负，各行重量清空；恢复 5 后正常。

### 5. `tools/rubber/cure-time.html` — 固定时间评级与错误态旧表

- 移除“<3 min 欠硫风险、>60 min 效率低、其间合理”的固定判级，改为只输出等效时间、范德霍夫近似、速率倍数与温差。
- 明确结果仅为等效时间预估，不判定欠硫/过硫，须用硫化曲线、制品厚度、配方与实测验证。
- 四项输入必须为非空且大于 0；无效时清空历史温度表。
- 复制使用 `__cureLastText`，无有效结果时阻止。
- 公式框、深解析、FAQ、元描述同步。

真机验证：
- 默认 150→160°C、20 min、90 kJ/mol → 11.1 min、范德霍夫 10.0 min、1.81×。
- 校验用例 225°C/20 min → 160°C → 1810.2 min。
- 清空基准时间 → 提示填写，温度对照表清空，复制为空。
