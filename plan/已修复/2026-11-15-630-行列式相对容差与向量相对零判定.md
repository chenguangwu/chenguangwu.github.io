## 缺陷与根因

| 编号 | 根因 | 表现 |
|---|---|---|
| SMS-163 | 展示用 `det.toFixed(2)`、判定用 `det===0` | `[[0.1,0.3],[0.3,0.9]]`（ad=bc，数学奇异）双精度残差 1.39e-17 → 卡片显示「0.00」却判「非奇异（可逆）」，展示与结论自相矛盾 |
| SMS-166 | 零向量判定用绝对阈值 `mA<1e-12` | A=(1e-13,0,0) 这类非零小向量被误判为零向量，夹角/单位向量直接拒绝计算；`fmt` 又把 1e-13 打印成 `0`，进一步造成「(0,0,0) 却有夹角」的假象 |

## 修复内容

### 二阶行列式
1. 新增 `__det2x2Judge(a,b,c,d,en)`：
   - 判据 `|det| ≤ 1e-12 · max(|ad|,|bc|)`（scale=0 时退化绝对 1e-12）；
   - 残差非零且在阈值内 → 文案标注「ad 与 bc 在双精度下仅差 1.39e-17」；
   - 展示：`|det| < 1e-9 且 ≠0` 用 `toExponential(2)`，其余 `toFixed(2)`。
2. 结果卡片、`__determinant_2x2Extras` 明细表、CSV 导出三处统一走同一 helper。
3. 标签（行列式 / 迹 / 可逆性）与判定文案按 `isEn()` 分流，EN 态零 CJK。
4. 公式框判据同步诚实化：说明容差、纯 0 直接判奇异、残差同样判奇异并标注量级；英文 map 同步。

### 向量页
1. 新增 `__isZeroVec(v)`：最大分量恰为 0，或 `|v| ≤ max|分量| · 1e-12` 才算零向量（相对尺度）。
2. 夹角、投影、单位向量、绘图复算共 5 处判定全部替换。
3. `fmt` 对非零极小值改用 `toExponential(2)`，不再把 1e-13 打印成 `0`。

## 新增判别用例

1. `math/determinant-2x2`：`a=0.1,b=0.3,c=0.3,d=0.9` → 期望 `1.39e-17` + 「奇异矩阵（不可逆；ad 与 bc 在双精度下仅差」
2. `science/vector-calculator`：`dim=3, op=angle, A=(1e-13,0,0), B=(1,0,0)` → 期望 `θ = 0°`

## 复核要点

- 行列式填 0.1 / 0.3 / 0.3 / 0.9：应显示 `1.39e-17` 与「奇异矩阵（不可逆；ad 与 bc 在双精度下仅差 1.39e-17」。
- 填 1 / 2 / 2 / 4：应显示 `0.00` 与「奇异矩阵（不可逆）」，不带残差标注。
- 向量 A=(1e-13,0,0)、B=(1,0,0)，选夹角：应给 `θ = 0°`，A 显示为 `(1.00e-13, 0, 0)`。
- 切 `?lang=en-US`：行列式结果卡片与明细表标签均为英文。
