# 第690批：暗色固定浅底卡片与按键文字

## 原问题

三页在暗色模式下文字与底色撞色：

- `tools/design/photo-print-size.html` 的 `.size-card.recommended` / `.low` 固定浅绿/浅橙底，文字继承暗色主题的浅灰 `#F3F4F6`，对比度仅 1.02:1。
- `tools/it/css-properties.html` 的分类页签、属性卡、值块固定 `#fff` 底，暗色下文字为浅灰，对比度 1.1:1。
- `tools/fun/shape-memory.html` 的 `.key.ok` / `.key.bad` 背景使用 `var(--success)` / `var(--danger)`，暗色变量翻成亮绿/亮红，文字仍是浅灰，对比度 1.4–1.9:1。

## 修复

- 照片卡：`.size-card.recommended,.size-card.low{color:#1F2937;}`，浅底固定用深字，明暗都稳定。
- CSS 属性速查：`.category-tab`、`.prop-item`、`.prop-values` 改 `var(--card-bg)` + `color:var(--text)`；`prop-header:hover` / `prop-detail` 改 `var(--bg-hover)`；暗色激活页签文字改 `#111827`。
- 形状记忆：`body.dark .key.ok,body.dark .key.bad{color:#111827;}`。

只改文字色/主题底，不改变浅色模式视觉。
