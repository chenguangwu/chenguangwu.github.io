# 416 批：`it/` 十个页面清理未调用的 `getIndent()` 死代码

日期：2026-11-14
范围：`tools/it/`

## 一、问题

模板批量生成时给多个格式化/解析页插入了 `getIndent()`：

```js
function getIndent(){const v=document.getElementById('indent').value;return v==='tab'?'\t':' '.repeat(parseInt(v));}
```

但实际缩进逻辑要么走各自的 `IND()`，要么根本不输出缩进。函数从未被调用，属于死代码；
其中 6 个解析页**连 `#indent` 控件都不存在**，一旦被误调用就会对 `null` 取 `.value` 抛错。

按当前源码统计（`function getIndent` 定义数、调用数、`id="indent"` 存在性）：

| 页面 | 调用数 | `#indent` | 处理 |
|---|---|---|---|
| ini-parser / json-to-xml / plist-parser / properties-parser / protobuf-parser / xml-to-json | 0 | 无 | 删除 |
| css-formatter / python-formatter / js-formatter / shell-script-formatter | 0 | 有 | 删除（缩进走 `IND()`） |
| json-formatter / json-schema-generator / json-to-toml | >0 | 有 | 保留（实际在用） |

## 二、修复

只删除上述 10 个页面中未被调用的 `getIndent()` 单行定义，不改动任何格式化/解析逻辑。
删除后 10 页 `getIndent` 残留均为 0。
