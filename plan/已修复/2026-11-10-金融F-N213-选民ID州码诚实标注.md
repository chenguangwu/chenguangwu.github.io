# F-N213 选民 ID（EPIC）页：州代码只展示、任意 3 字母被误当合法州码

## 来源
- `plan/categories/02-金融财务/finance.md` F-N213（中，确认缺陷）。
- 修复方本批真修（分类清单线）。

## 根因与裁量
- `tools/finance/voter-id-validator.html` 只做 `^[A-Z]{3}\d{7}$` 格式校验，州码行 `州代码：${stateCode}` 原样回显任意 3 字母并判「✅ 格式有效」，如 `AAA`/`ZZZ` 被误当合法州码。
- 裁量：印度 EPIC 前 3 位字母各邦编号规则不一（并非严格州码白名单），硬造州码表会误伤合法号，且页面自述「校验算法：无（格式校验）」。按清单方案二做**诚实标注**——明确「仅格式校验，未核对是否为有效州码」，不引入自制权威表。

## 修复位点
- `validate()` 州码行追加标注：`${stateCode}${isEn?' (format check only, state code not verified)':'（仅格式校验，未核对是否为有效州码）'}`，过 i18n helper。
