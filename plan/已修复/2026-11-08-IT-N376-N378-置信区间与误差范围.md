## IT-N376（中）`+value || 1` 使 n=0/空值静默变成 1，校验形同虚设

**失败点**：

```js
const mean = +document.getElementById('mean').value || 0;
const std  = +document.getElementById('std').value  || 0;
const n    = +document.getElementById('n').value    || 1;
```

`n=0` 或留空 → `|| 1` 兜成 1，`if(n<1||std<=0)` 永远拦不住。选 z 分布时还会输出一份看起来完全正常的区间（并标注「z 分布 · 临界值=1.960」）；选 auto 则临界值 NaN、区间显示 `[ — , — ]`。空 mean 也被静默当 0。

**修复位点**：新增 `numVal(id)` —— 先判空串再 `Number()`，非有限值返回 NaN；三个输入任一 NaN / `n<1` / `std<=0` 即整块失效：

```js
if([mean,std,n].some(isNaN) || n < 1 || std <= 0){
  document.getElementById('ci').textContent = '[ 输入无效 ]';
  document.getElementById('ci-label').textContent = '请填写均值、标准差与样本量（n ≥ 1、s > 0）';
  const detailEl = document.getElementById('calc-detail');
  if(detailEl) detailEl.innerHTML = '';   // 同时清空明细，不留上一次区间
  return;
}
```

`mean=0` 是合法值（区分靠「空串判定」而不是 `||`），行为不变。

**证据**：`mean=50, std=8, n=0, conf=0.95, dist=z`
- 修复前：`[ 34.320 , 65.680 ]` + 「z 分布 · 临界值=1.960」（把 0 样本当 n=1）
- 修复后：`[ 输入无效 ]` + 说明语 + 明细区清空

## IT-N377（中）t 临界值在 df 6–9 等区间跨档线性内插，误差最大约 +2.9%

**失败点**：`T_TABLE` 只有 df 1/2/3/4/5/10/15/20/25/30/40/60/120，`getTCritical` 在相邻两档之间对 t 值线性内插。df=6–9（n=7–10，小样本最常用区间）跨 5→10 档，插值系统性偏大 1.5–2.9%。

**修复位点**：补全 df 6/7/8/9（必需）与 11/12/13/14/16/17/18/19（减少 10–20 段插值误差），数值按标准单尾 t 表：

| df | 0.10 | 0.05 | 0.025 | 0.01 | 0.005 |
|---|---|---|---|---|---|
| 6 | 1.440 | 1.943 | 2.447 | 3.143 | 3.707 |
| 7 | 1.415 | 1.895 | 2.365 | 2.998 | 3.499 |
| 8 | 1.397 | 1.860 | 2.306 | 2.896 | 3.355 |
| 9 | 1.383 | 1.833 | 2.262 | 2.821 | 3.250 |

**为什么不改成 1/df 插值**：实测会把 df=24 的 2.065 → 2.064、df=39 的 2.709 → 2.708，与三条既有用例（它们把这两个值当契约）同时冲突；补档后 df≤20 全部走表值，误差问题已消除，故保守只补档。

**证据**：`mean=50, std=8, n=7, conf=0.95, dist=t`（df=6）
- 修复前：临界值 2.5024（跨 5→10 线性内插），ME = 7.5666，CI `[ 42.433 , 57.567 ]`
- 修复后：临界值 2.447（精确 t(0.025,6)），SE = 8/√7 = 3.0237，ME = 7.3990，CI `[ 42.601 , 57.399 ]`
- 另复核：n=8 → 2.365、n=10 → 2.262、n=7/99% → 3.707，均为表值，无插值

## IT-N378（中）N=n 时跳过有限修正仍报 ±3.10%，N<n 被静默当作无限总体

**失败点**：修正只在 `N > n` 时套用。

- `N === n`（全查）时校正因子应为 `√(0/(N−1)) = 0`（无抽样误差），但代码跳过修正、直接返回无限总体结果 ⇒ 仍报 ±3.10%。
- `N < n`（抽样数大于总体，逻辑不可能）被静默忽略，同样按无限总体输出伪结果。
- `parseInt(NStr)` 把 `1e6` 读成 1。

**修复位点**：

```js
const N=Number(NStr);
if(!isFinite(N)||!Number.isInteger(N)||N<1){ … 'N 必须是正整数（可写 1e6 这类科学计数法）' … }
if(N<n){ … 'N 必须 ≥ n（抽样数不能超过总体）' … }
Efin=E*Math.sqrt(Math.max(0,(N-n)/(N-1)));
finiteApplied=true;
```

**证据**（`n=1000, p=0.5, conf=0.95`）：

| N | 修复前 | 修复后 |
|---|---|---|
| 1000（=n） | ±0.031（3.10%），无步骤 4 | ±0（0.00%），步骤 4 给出 `0.031 × √[(1000−1000)/(1000−1)] = ±0`，CI `[0.5, 0.5]` |
| 800（<n） | ±0.031 伪结果 | 「N 必须 ≥ n（抽样数不能超过总体）」 |
| 1e6 | parseInt→1，修正被跳过 | Number→1000000，正常套修正 |
| abc | 静默跳过 | 「N 必须是正整数…」 |
