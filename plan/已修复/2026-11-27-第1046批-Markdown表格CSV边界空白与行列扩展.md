## 修复内容

1. **纯空格单元格数量翻倍**
   - 重写 `escapeMarkdown()` 的边缘空白处理：先取行首空白，再从剩余文本取行尾空白，两段不再重叠。
   - 纯空格单元格按字符逐个编码，1/2/3 个空格分别得到 1/2/3 个 `&nbsp;`，不再把 2 个空格输出成 4 个。
   - 内容两端空格同样保留：`" a  "` 输出为 `&nbsp;a&nbsp;&nbsp;`；CSV 导出始终使用未编码的 raw 值。
   - 新增回归用例 `MDSP1046`，同时断言 Markdown 只有 2 个 `&nbsp;`、CSV 保留两个原始空格。

2. **超出行列的数据静默截断**
   - 正文不再直接 `slice(0, cols)`、表头不再直接截取；生成前用表头与全部正文记录计算实际需要的行、列数。
   - 输入超过当前控件设置但在支持范围内时，自动把 `#cols` / `#rows` 扩展到实际尺寸，并在提示区说明“输入有 N 列/行，已自动扩展，不再截断”。
   - 超过支持上限（20 列 / 50 行）时明确报错、清空输出并停止生成，要求用户拆分或删减；不再静默截断。
   - 新增回归用例 `MDEXP1046`（3 列输入 / 1 列设置自动扩为 3）与 `MDLIMIT1046`（21 列明确报错）。

3. **非普通空格边界被删除**
   - 支持的边缘空白明确为：普通空格、制表符 `\t`、不换行空格 `\u00a0`、全角空格 `\u3000`。
   - `markdownEdgeWhitespace()` 按字符编码：空格/NBSP → `&nbsp;`，制表符 → `&#9;`，全角空格 → `&#12288;`；Markdown 不再因 `trim()` 丢失边界内容。
   - 提示区说明这些字符在 Markdown 中以 HTML 实体保留、CSV 导出保留原字符。
   - 新增回归用例 `MDWS1046`，校验 `\t` + NBSP 的 Markdown 实体与 CSV 原字符。

4. **CSV 引号字段内换行无法导入**
   - 新增 `splitCsvRecords()`，按引号状态扫描完整 CSV 文本：引号外换行才是记录分隔，引号内换行归入单元格；支持 `""` 转义。
   - 保留原有 `parseCsvLine()` 的字段级解析、转义引号、逗号与错误行列检查。
   - Markdown 单元格内换行用 `<br>` 呈现；`lastTableModel` 仍保存 raw 单元格，CSV 导出保留真实换行。
   - 提示区说明 `<br>` 与 CSV 真实换行的对应关系。
   - 新增回归用例 `MDNL1046`，校验跨行字段生成 `hello<br>world`，CSV 仍含真实换行。

5. **CSV 非法引号被静默接受**
   - 复核现有 `parseCsvLine()` 已具备“闭合引号后只能接逗号或行尾”“未引号字段内不能出现引号”检查（第783批引入），本轮确认 `"a"b,c` 会返回「第 2 行第 4 列：引号闭合后只能接逗号或行尾」，输出被清空。
   - 新增回归用例 `MDQUOTE1046` 锁定该行为；合法转义引号、引号内逗号、引号内空值等既有用例继续通过。
