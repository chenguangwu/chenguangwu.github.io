# 第 561 批：新增「电动车充电费用与每公里成本计算器」

## 原问题 / 需求
- 汽车交通分类缺少「充电费用 + 每公里用车成本 + 燃油车对比」的纯前端工具，现有油费/油耗工具无法覆盖电动车场景。
- 新增工具需满足纯前端、无上传，并同步中文页、英文 i18n、指南、分类索引与站点地图。

## 交付内容
- 新工具 `tools/automotive/ev-charging-cost.html`：10 项输入，计算电池侧电量、电网取电、本次电费、充电时间、增加续航、每公里电费、电动车/燃油车百公里成本、每百公里节省、年度节省。
- 增加折线/柱状成本对比图、参考速查表（按电耗/按电价双标签）、结果复制与 TXT 导出（复用 `tool-kit` 标准结果操作栏）、最近输入本地保存。
- 新增指南 `guides/ev-charging-cost-guide.html`，含公式、6 步操作、60 kWh 算例、4 条 FAQ 与相关工具。
- 补 `i18n/tools/automotive.json`、`i18n/tools/en/automotive/ev-charging-cost.json` 与 `_index.json`、`i18n/tools/slug-en.json`、`i18n/tools/_en_override.json`、`i18n/guides/ev-charging-cost-guide.json`。
- 登记 `json/guides.json` 与 `guides/index.html`。

## 验证
- 默认示例：60 kWh、20→80%、效率 90%、电价 0.60、7 kW、15 kWh/100km、油价 8、油耗 8、年 15,000 km。
  - 电池侧 36.00 kWh；电网 40.00 kWh；电费 ¥24.00；充电 5.71 h；续航 240 km；每公里 ¥0.100；EV 百公里 ¥10.00；燃油车百公里 ¥64.00；每百公里省 ¥54.00；年省 ¥8,100。
- 边界：空必填、电池 ≤0、SOC 越界或目标不高于起始、效率 0/101、电价为负均给出提示；年里程留空或 0 时年度节省显示「—」，不再显示 0。
- 中英文：中文/英文 320px 与 1280px 均无横向溢出；英文态可见中文 0；指南英文态中文 0。
- 构建：`python3 _build.py` 通过；门禁：`env -u NODE_OPTIONS python3 scripts/run_gates.py --skip-build` 272/272 通过。
