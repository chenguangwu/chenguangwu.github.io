## 修复内容

### 1. ISO 字符串默认保持字符串
- 工具栏新增复选框 `#inferDates`「将 ISO 字符串推断为 TOML 日期」，默认未勾选。
- `tomlVal()` 改为 `const dl = tomlInferDates() ? tomlDateLiteral(v) : null`：默认所有字符串走 `tomlQuote()`，日期/时间字符串保持 JSON 字符串类型。
- 勾选后才启用原严格 ISO 8601 日期、日期时间、时间推断；月日/闰年/时分秒/时区范围校验保留，不合法仍带引号。
- 页面工作原理说明同步：明确默认保留字符串类型，选项开启后才输出 TOML 原生日期；英文词典键与文案同步更新。

### 2. DEL 控制字符转义
- 新增 `tomlQuote(v)`：`JSON.stringify(String(v))` 后把 U+007F 替换为字面 `\u007F`。JSON.stringify 已覆盖 U+0000–U+001F，DEL 需单独补。
- `tomlVal()` 的字符串分支与 `tomlKey()` 的 quoted key 分支统一改用 `tomlQuote()`，值与键名都覆盖。
- 转换后仍为合法 TOML，Python `tomllib` 可解析，值往返保留原始 DEL。
