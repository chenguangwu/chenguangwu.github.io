# 879 批 · 复核失败重做 · 641 历史未来记录仍推迟提醒

## 复核退回原因
`tools/pet/reminder-vaccine-deworming.html` 的 `latestRecord()` 与 `computeItems()` 的 `coreRecs` 未过滤未来日期；本地历史若残留未来日期记录，驱虫/加强针的「下一次到期日」会据此未来记录推算，导致提醒被推后。新建与补录虽已拒绝未来日期，但旧历史不受限。

## 改动
- `latestRecord()`：过滤条件加 `d && d <= t`（`t=today()`），与 `vaccineDone()` 的「仅计 date<=today」口径统一，同时排除无效日期。
- `coreRecs`（加强针基础针完成分支）：同样加 `d && d <= t`。
- 安全性：`allCoreDone=true` 蕴含每针都有 `date<=today` 记录 ⇒ coreRecs 必非空，`reduce` 不会拿到空数组。

## 验证
- 静态断言：两处过滤均含 `d && d <= t`，三处（latestRecord/coreRecs/vaccineDone）口径一致 ✓。
- 旧版差分：`git show HEAD` 的 latestRecord 与 coreRecs 均无 `d <= t` ⇒ 旧红新绿 ✓。
- `node scripts/verify_pet_calc.js`：18/18；`node scripts/check_inline_js_syntax.js`：12100 段全正确；`python3 _build.py`：BUILD=0。
