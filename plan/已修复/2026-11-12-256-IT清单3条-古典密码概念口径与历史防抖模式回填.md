### IT-N149 Atbash「ROT13 特例」概念错误（中）— 真改
- 原理区原写"本质上是凯撒密码在位移为 13 时的特例"，与页面自身 `f(x)=25-x` 镜像映射矛盾（ROT13 是 `f(x)=x+13`，A→N 而非 A→Z）。
- 改为准确表述：两者同为对合置换（加密两次还原），但映射不同；Atbash 镜像 `f(x)=25−x`（A→Z、B→Y），ROT13 `f(x)=x+13`（A→N），不可混为一谈。英文映射同步。

### IT-N150 三页历史前缀刷屏（中）— 真改
- atbash / playfair / vigenere 三页 `oninput` 每次按键都直接 `saveHistory`，20 条上限被输入前缀刷满（vigenere 甚至完全无去重）。
- 三页统一：新增 `<prefix>ScheduleHistory()` 做 500ms 防抖（停止输入后只落一条完整结果）；`saveHistory()` 改为对全部历史 `findIndex`（按完整 input + key + mode 去重），重复项原位删除后前插。

### IT-N151 三页 TBKit 回填模式错乱（低）— 真改
- atbash / vigenere 回填回调 `setMode()` 无参 → `currentMode=undefined`、标签反转、按错误方向重算；playfair 用 `setMode(currentMode)` 但记录未带 mode。
- 三页统一：① `setMode(mode)` 加兜底 `mode = mode || currentMode || 'encrypt'`；② extras 记录写 `rec.__mode = currentMode`；③ 回填回调用 `setMode(rec.__mode || …)` 恢复记录模式；④ 回填遍历跳过 `__mode` 字段。
