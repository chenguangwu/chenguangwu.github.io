# 第696批：两页多套历史记录的统一清空

## 修复项

受影响页面：

- `tools/agriculture/estimate-soil.html`
- `tools/paper/strength-10.html`

两页都同时保留页面自有 `tb_history_` 历史面板和 `TBKit.history` 的 `tbk_hist_` 面板；两个“清空”按钮各自只删自己的键，用户点任意一个都无法清除该工具全部历史。

修复：

- 页面自有 `clearHistory()` 改为同时删除 `tb_history_` 与 `tbk_hist_`，并清空共享历史面板 DOM。
- 共享历史面板挂载时传入 `clearHistory` 作为 `onClear` 回调，点击共享面板“清空”同样清除两套键。
- 共享历史面板在空表单加载时主动渲染一次，旧记录不会因为未触发计算而不可见。
- 恢复共享记录前先清空本页对应输入，再写入记录中存在的字段，避免旧记录缺失的空字段被当前残留值覆盖：
  - 估算土壤：`years / init / rate / threshold`
  - 纸张强度：`v0 / v1`

## 验证

本地 Chromium：

- 估算土壤：预置两套键后刷新，两个面板均可见；恢复一条缺 `threshold` 的记录时，`threshold` 从当前值恢复为空；调用页面自有清空后两套键均消失；共享面板“清空”同样清除两套键。
- 纸张强度：恢复缺 `b` 的记录后 `v1` 为空；自有清空和共享清空均删除两套键。
- 两页均无 `pageerror`；共享历史面板在空表单刷新后可见。
