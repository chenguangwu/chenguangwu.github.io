# 541 批：MS-F1 / MS-F2 叠加折扣标度与等效折数

- 日期：2026-11-15
- 来源：`plan/categories/06-商业运营/marketing-sales.md` MS-F1、MS-F2
- 受影响页面：`tools/sales/stacked-discount.html`

## 缺陷

1. **MS-F1**：输入标签写「折扣（如 8 = 8折）」，但计算与预设按百分数口径
   （`cur * d.value/100`，预设 80/85）。用户按标签输入 8 得到原价 8%（0.8 折）。
   同时 `min/max` 仅约束 UI，手输 -50 / 120 可产出负价或加价，CSV 也随之污染。
2. **MS-F2**：结果区 `effRate = totalSave/price*100`，却拼成「相当于 30.0 折」；
   CSV 用 `totalSave/price*10` 拼「3.00 折」。语义应为「成交价相当于几折」。
   500 元 8 折再满 300 减 50 → 页面「30 折」、导出「3 折」，同页深览却写「7 折」。

## 修复

- 标签改为「折扣率（%，80 = 8折）」，类型下拉「折扣率(%)」，placeholder「如 80（0–100）」，
  公式框与提示文案同步为「折扣率」。
- `calc()` 与导出入口增加 `0 ≤ 折扣率 ≤ 100` 守卫；越界时结果区显示「—」并提示，
  导出只弹提示不生成文件。
- 明细行折数改为 `d.value/10`（80 → 8.0 折）。
- 结果区改为「成交价 ≈ 7.0 折（省 30.0%）」，`effRate = cur/price*10`；
  CSV 末列同口径（`cur/price*10` + 省百分比）。
- 英文词典补公式与提示整句译文。
