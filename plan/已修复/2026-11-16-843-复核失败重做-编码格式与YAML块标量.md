## 1. ITF 终止符不符合 ISO/IEC 16390（228 / 第324批）

- **复核失败点原文**：实现与公式说明写「终止 11010（宽条·窄空·窄条·窄空·宽条）」，模块展开为 `111010111`；标准终止符只有宽条·窄空·窄条三个元素，模块表示 `11101`。
- **修复位点**：`tools/it/barcode-itf.html`：`bits+='11101'`；公式说明、代码注释、`i18n/tools/en/it/barcode-itf.json` 同步。
- **验证证据**：`ITFGUARD` 断言结尾恰为 `11101` 且不再出现旧串；`ITF=135|99` 长度断言更新（原 139/103）。
- **判别力实测**：恢复旧终止符后 `slice(-5)!=='11101'` ⇒ 转红。

## 2. Slugify 拼音表 15 字键不可达（233 / 第298批）

- **复核失败点原文**：`PINYIN_MAP` 含整句键「如何学习前端开发从入门到精通」，但 `toPinyin` 贪心上限写死 `Math.min(8, …)`，该键永远匹配不到，属死数据。
- **修复位点**：`tools/it/slugify.html` 新增 `PINYIN_MAX_KEY = max(Object.keys(PINYIN_MAP).length)`，贪心从该长度开始尝试。
- **验证证据**：`SLUGKEY` 断言整句输出 `ruhe-xuexi-qianduan-kaifa-cong-rumen-dao-jingtong`。
- **判别力实测**：恢复上限 8 后按 8 字分块，输出不同 ⇒ 转红。

## 3. Python 格式化三引号被重排缩进 + 缩进栈缺失（222 / 第240批）

- **复核失败点原文**：
  - 三引号字符串体内的物理行按新层级重排缩进（4 空格 → 2 空格），代码可编译但字符串值改变；
  - 校验器只检查冒号下一行是否缩进，`if True:` / `    x=1` / `  y=2` 这种退格到 2 空格（不匹配 0 或 4）仍报「结构检查通过」，而 Python 抛 `IndentationError`。
- **修复位点**：`tools/it/python-formatter.html`
  - `formatPython` 进入三引号后逐行原样输出（含空行与行首缩进），删除旧的 rest 切片与重排逻辑；
  - `doValidate` 维护缩进栈：退格必须回到已有层级，加深只能出现在冒号块之后；括号内续行跳过；保留原有「冒号后未缩进」提示。
- **验证证据**：`PYTRIPLE` 断言缩进设 2 时三引号内仍保留 `\n    keep\n`；`VAL302B` 断言非法退格报「不匹配任何外层缩进层级」；`VAL302C` 正对照（0/4/8 合法嵌套）仍报「结构检查通过」。
- **判别力实测**：恢复旧实现后 `PYTRIPLE` 变 2 空格、`VAL302B` 报通过 ⇒ 双红。

## 4. XML→YAML 数组项对象缩进错位 + 非法 Tab 档（214 / 第242批）

- **复核失败点原文**：
  - 数组项为对象时，首键用 `pad+'- '`、子层却用 `pad+unit`（2 空格），子键与键同列：`- c:` 后 `d` 成同级兄弟、`c` 为空对象；4 空格模式后续键缩到 4 列、与首键 2 列错位；
  - 缩进下拉提供「Tab」，输出真正的 `\t`，而 YAML 规范禁止 Tab。
- **修复位点**：`tools/it/xml-to-yaml.html`
  - `dumpYaml` 数组项对象分支显式按「短横占 2 列」：首键 `pad+'- '`、后续键 `pad+'  '`、子层 `pad+'    '`；
  - 移除 Tab 选项，`pad` 统一 `parseInt(value)||2` 个空格（历史 tab 值回退 2 空格）。
- **验证证据**：`XMLNEST` 用两个 item 强制序列，断言输出含 `- c:` 与子层 `d: "1"`；`XMLTAB` 断言下拉只剩 2 个 option。
- **判别力实测**：恢复 `pad+unit` 子层后 `d` 与 `c` 同列 ⇒ `XMLNEST` 转红；加回 Tab 档 ⇒ `XMLTAB` 转红。

## 5. YAML 块标量丢注释内容与标记行尾注释（229 / 第277批）

- **复核失败点原文**：
  - `script: |` 后首行是 `  # comment` 时，建 items 阶段把 `#` 行当注释跳过，块收集从「下一个 item 的物理行」起 ⇒ 正文丢 `# comment`；
  - `script: | # header` 时块标记正则 `^([|>])([-+]?)$` 匹配失败 ⇒ 整块当普通标量，后续同级键一并丢失。
- **修复位点**：`tools/it/yaml-to-json.html`
  - `yCollectBlock` 改为按物理行收集：起点 = 标记行下一行，块缩进取首个非空物理行，结束于首个非空且缩进更小的行；末尾空行按 chomping 处理；同步推进 `p.i`；
  - 识别块标记前先 `yStripComment`，支持 `| # header` 形式。
- **验证证据**：`YBLK1` 断言结果区同时含 `# comment`、`echo hi`、`name`；`YBLK2` 断言含 `echo hi`/`name` 且不再出现 `| # header`。
- **判别力实测**：恢复旧收集起点后 `YBLK1` 丢 `# comment`；恢复旧标记识别后 `YBLK2` 出现 `| # header` 且丢 `name` ⇒ 双红。
