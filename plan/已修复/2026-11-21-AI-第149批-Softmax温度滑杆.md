# 第 149 批：Softmax 温度滑杆与数值稳定（AI）

- 日期：2026-11-21
- 页面：`tools/ai/softmax.html`
- 词典：`i18n/tools/en/ai/softmax.json`

## 原问题

- A2：Softmax 页只有 4 个数字输入，缺少可拖动的交互参数，演示性弱。
- 公式说明写「实现上通常先减 max(z) 再取指数以避免上溢」，实际代码直接 `Math.exp(z)`：输入 1000/999/998/997 时 `exp(1000)=Infinity`，结果为 NaN/—，与说明相反。

## 修复

- 新增「温度 T」数字输入 + 0.1–5 滑杆，拖动即时重算；T 越小分布越尖锐、越大越平缓。
- 计算改为 `exp((z−max(z))/T)` 再归一化，天然防上溢；T 下限 0.01。
- 结果附温度与「已先减 max(z)」提示；公式框同步新口径。

## 验证

- 新增温度用例：2/1/0.5/0.2、T=2 ⇒ P1 `40.23%`、提示 `温度 T=2.00`。
- 新增大数稳定用例：1000/999/998/997 ⇒ `64.39%` / `23.69%`，旧版为 NaN。
- 默认 T=1 的原有用例保持通过；`node scripts/verify_ai_calc.js ai/softmax`：5/5。
- 构建 4,426 页成功；内联脚本 0 错误；静态检查 4,705 通过 / 0 失败 / 0 警告。
