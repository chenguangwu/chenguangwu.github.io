# 第 128 批：视力筛查问卷未作答拦截（眼科）

- 日期：2026-11-21
- 页面：`tools/ophthalmology/vision-screening-21.html`

## 原问题

左右眼频率下拉由 `freqOptions()` 直接填入「从不 / 很少 / 有时 / 经常 / 总是」，首项默认选中且 `showQuestion()` 对未作答回填 `{l:0,r:0}`。用户不需要做任何选择，连续点 21 次「下一题」就能生成一份全阴性结论，问卷的「从未出现症状」与「根本没答」无法区分。

## 修复

- 两个频率下拉首项改为空值占位「请选择频率」，`showQuestion()` 对未作答不再回填 0。
- `recordCurrent()` 在左眼或右眼为空时提示「请先为左右眼各选择一个频率，再继续」并返回 `false`；`next()` 拦截，不推进、不出结果。
- 返回上一题时，当前题若未完整作答则删除其记录，避免半截答案被带入历史。
- 已作答的 0 分（真实「从不」）仍以显式选择保存，语义不受影响。
