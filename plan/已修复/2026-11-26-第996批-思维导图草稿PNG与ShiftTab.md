# 第 996 批：思维导图草稿覆盖、PNG 图片与 Shift+Tab 缩进

日期：2026-11-26
范围：`tools/office/mindmap.html`、`guides/mindmap-guide.html` 及相关 i18n / 校验脚本

## 修复内容

1. **清空或加载示例覆盖草稿**
   - 工具栏新增 `#btnUndo`（`↩ 恢复上一版`，默认隐藏）。
   - 清空/加载示例前统一 `mmConfirmOverwrite()` 确认；只有已有内容时才提示覆盖，空草稿清空直接提示“草稿已经是空的”。
   - 覆盖前用 `mmTakeSnapshot()` 保存代码与预览快照，`mmRestoreSnapshot()` 恢复并清空快照；清空后刷新仍保持空白，不会被示例重新填充。
   - 主分支与 Renderer 缺失的降级分支共用公共 `mmMsg()` / `mmSnap` / `mmRepaint()`，两条路径行为一致。

2. **PNG 导出丢失 Markdown 图片**
   - 新增 `collectPngImages()`，从 `#mindmap foreignObject img` 收集 alt/title/src 文件名；导出前 `confirmPngImages()` 明确列出无法嵌入的图片数量与前三个标签，并提示改用「下载 SVG」。
   - `buildPngClone()` 不再静默删除图片节点，改为追加 `[图片: alt]` 占位文本；成功提示按 `skippedImages` 说明“N 张图片以占位文本显示；保留图片请用 SVG”。
   - SVG 导出保持原样，Markdown 图片仍可保留。

3. **单光标 Shift+Tab 反向缩进**
   - 新增 `mmLineRange()` / `mmReplaceRange()`；无选区时按当前行行首 `^ {1,2}` 删除缩进，光标回到删除后的行内位置，不再插入两个空格。
   - 多行选区 Shift+Tab 按行反缩进并保留选区；单光标 Tab 仍插入 2 空格；行首无可退缩空格时不改动。
