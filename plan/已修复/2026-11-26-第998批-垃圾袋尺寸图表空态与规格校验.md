# 第 998 批：垃圾袋尺寸计算器图表空态与推荐规格校验

## 修复内容

1. **无效输入不再保留旧图表**：新增 `#chartEmpty` 与 `clearChart()`；空值/非法数时清空 canvas、写「等待有效参数后绘制容积对比」并设 `data-empty=1`，重新计算成功后隐藏空态并重绘。
2. **推荐袋型同时校验折径与袋长**：新增 `BAG_SPECS` 与 `bagCode(flat, needLen)`，按「折径 ≥ 需求且袋长 ≥ 需求」选最小现成规格；无匹配返回「定制（≥折径×袋长 cm）」并标「需定制」。
3. **数值严格校验**：`num()` 改用完整数字正则，`40abc` 之类不再被 `parseFloat` 截断。
4. **规格表与算例统一**：大号 60×80、加大 70×80、特大 80×100、超大 100×120；默认 40×30×50（外翻 10）推荐「加大 70×80 cm」，与指南/深度解析算例一致，并明确「有现成规格 / 需定制」。
