# 第 1155 批复核失败：GPA 百分制空成绩按零分添加

`tools/edu/exam-gpa-calculator.html` 的 `addCourse()` 对百分制输入取 `raw` 后直接 `Number(raw)`，空字符串变为 0，因 0 属于允许范围而被添加为零分课程。须区分未填写和明确填写 0；学分、超范围、控件切换及转义等原记录其他内容已核对。

建议先检测 `raw === ''` 并提示，再做数值范围校验；真实交互分别测试空白拒绝、0 分可添加及历史保存。

2026-11-18 修复百分制空串守卫；真实浏览器验证空成绩不添加、明确输入 0 后添加并保存到 localStorage，定向回归 7/7。
