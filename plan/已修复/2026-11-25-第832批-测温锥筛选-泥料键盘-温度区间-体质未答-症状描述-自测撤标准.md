# 第832批：测温锥筛选、泥料键盘与温度区间、体质未答停算、症状描述、自测撤标准声明

日期：2026-11-25
范围：`ceramics` 3 项、`tcm-diagnosis` 3 项，共 5 页。

## 1. ceramics/glaze-temp.html（测温锥筛选混入未匹配项）

- 原实现先按左右两栏切片，再以「整行任一匹配」决定是否显示；左栏命中时右栏无关锥号会一起出现。
- 改为先对完整 `CONES` 数据集按锥号/温度/分类过滤，再用过滤结果分两栏；无匹配显示明确空态「未找到匹配的测温锥…」。
- 验证：搜索 `022` 只返回 022（600°C/低温）；搜索 `zzz` 显示空态。
- 顺带修 `__coneTargetInit` 在缺少 options 的桩环境读 length 抛错，增加 `!sel.options` 守卫。

## 2. ceramics/ceramic-firing.html（泥料选择缺少键盘操作 + 温度条取起点）

- 泥料卡片由 `<div onclick>` 改为原生 `<button type="button">`，带 `aria-pressed` 表达当前选择；补 `:focus-visible` 焦点样式，保留 5 个泥料。
- 温度条原用 `s.temp.match(/\d+/)[0]` 取第一个数字：`常温→150` 取 150、`150→300` 取 150、`800→峰值` 取 800，不能表达区间。
- 改为解析阶段起止数值：`常温/室温/起始` 无数字时起点按 0；单数字阶段（保温）取该温度；双数字取首末。图条按 `[min,max]` 的起点偏移与区间宽度绘制，并新增文字「图示区间：start→end°C（按阶段起止温度绘制，终点 end°C）」。
- 验证：`0→150`、`150→300`、`300→600` 正确；5 个 button 可聚焦，当前项 `aria-pressed=true` 唯一。
- 顺带加 `selectClay`/`renderCurve` 空值守卫，避免无效 id 或缺失泥料时抛错。

## 3. tcm-diagnosis/constitution-test.html（未答题按中间值仍输出主体质）

- 原 `calcScore(force)` 在未答完时给「仍然计算」，按 3 分中间值计入并输出主体质；且各类均未达「是」时仍取最高分当主体质。
- 改为未答完直接停算，提示「未答完不能生成体质判定」；删除 force 按钮与参数。
- 增加确定判定门槛：只有 `verdict==='是'` 的类别才作为主体质；若无，输出「未形成确定体质判定」，最高分项仅作相对参考，不输出体质特征/调养建议的确定结论。
- 加「不作诊断」提示：结果仅供健康教育参考，判定规则与问卷需专业复核。
- 顺带修 `selectScore`/`__constRow` 在缺少参数时抛错，增加空值守卫。

## 4. tcm-diagnosis/disease-tracking.html（症状总分变化被当作病情结论）

- 原首次/末次总分差直接写「病情好转 / 病情加重 / 病情平稳」。
- 改为只描述「记录的症状总分变化」：下降 X 分、上升 X 分、无变化，并注明仅反映所录症状评分，不等于病情好转/加重/平稳。
- 新增「各症状评分变化（首次→最近）」逐项列表（如 头痛 3→1 下降 2、失眠 2→3 上升 1），提示不同症状可能此消彼长，总分不能单独代表病情，需结合舌象、脉象、其他检查与医师判断。
- 同步更新深度解析算例、FAQ 与 FAQPage JSON-LD，删除「提示好转」的旧表述。

## 5. tcm-diagnosis/self-test-constitution.html（平和质判定与标准声明需复核）

- 原实现八类偏颇均「否」即宣称平和质，且统一阈值给出「主体质」，页面多处宣称依据 ZYYXH/T 157-2009。
- 改为「体质参考得分（非判定、非诊断）」：
  - 去掉表格中的主体质星标，不再用 `mainType` 作确定结论；
  - 最高分项只写「相对最高分项（分数，判定）」，附「不作体质判定」说明；
  - 八类偏颇均未达阈值时明确「不能据此认定为平和体质，平和质自身判定条件尚未逐项核验」；
  - 删除「体质良好/属平和体质」结论与 ZYYXH 直接引据，改为「显示阈值仅供得分展示，不作标准符合性声明」。
- 同步改 meta/首段/功能特点/公式引据表/深度解析/FAQ 的「依据标准」表述为「参考九类体质框架，非标准量表，不作判定」；更新 `i18n/tools/tcm-diagnosis.json` 等相关描述源，防止构建还原。
- 验证：默认计算不再输出「主要体质：」，显示「相对最高分项」与「不作体质判定」。
