# 第854批：菜单毛利空值、调料人数、半份成本卡、零上座率、饮品取整、配送空值

## 菜单毛利：空值、负值与售价 0 的毛利率

`tools/restaurant/menu-margin.html`

- 成本/售价改原始空值读取：空值、非数字、负数逐行列出并停止计算，不再 `||0` 兜底。
- 售价为 0 时毛利率记为 `null`，表格显示「不适用（售价 0）」，不参与低/高毛利统计、排序与可视化；综合毛利率在总售价为 0 时显示「不适用」。
- 排序器对 `null` 毛利率稳定置后，避免 NaN 传播。

## 调料缩放：人数空值静默变一

`tools/restaurant/seasoning-scaler.html`

- 原人数/目标人数改原始空值读取并要求 >0；空值、0、负数、非数字逐项提示并停止。
- 每行原用量要求有限 ≥0；空值/负数报行号，复制文本同步清空，不再输出负调料量。

## 菜品成本卡：提示半份但不允许输入

`tools/restaurant/dish-cost-card.html`

- 份数校验由 `qty<1` 改为 `qty<=0`，接受 0.5 等正小数；输入 `min=0.1`、`step=0.5`，提示改为「份数须大于 0（支持 0.5 份等半份）」。
- 0.5 份可正常输出成本卡与每份成本。

## 翻台率：0% 上座率被替换为满座

`tools/restaurant/table-turnover.html`

- 六项输入逐项读取并校验：时长/桌数/用餐时间/每桌人数 >0，上座率 0–100（0 合法），人均消费 ≥0；异常列出字段并停止。
- 0% 上座率直接得实际翻台率 0.00、日接待 0 桌、营业额 ¥0，不再回退 100%。

## 烧烤饮料：四舍五入低于自身基准

`tools/restaurant/bbq-portion.html`

- 饮品由 `Math.round` 改 `Math.ceil`，按每人 700 ml 基准、330 ml/瓶向上取整。
- 结果卡同时显示瓶数、总容量与基准容量（如 2 人 → 5 瓶 1650 ml，基准 1400 ml），并注明「宁多勿少」；明细表同步。

## 配送时间：空值与零距离被替换

`tools/restaurant/delivery-time.html`

- 距离允许 0 km，速度必须 >0，备餐/到店/交付等待 ≥0，交通/天气/时段系数 >0；空值和非数字逐项提示并停止。
- 0 km 时基础骑行 0 分钟、时间窗口下限取 0，不再静默按 1 km/20 km·h⁻¹ 计算。
