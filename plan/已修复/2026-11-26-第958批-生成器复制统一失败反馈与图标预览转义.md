# 第 958 批：生成器复制统一失败反馈与图标预览转义

日期：2026-11-26
状态：已修复并验证

## 复制失败反馈

- 13 个 CSS 生成页改为统一走 `ToolBox.copyText()`：`grid-pattern`、`pattern-generator`、`loading-dots`、`spinner-generator`、`skeleton-loader`、`dot-pattern`、`checkerboard-generator`、`isometric-grid`、`blueprint-grid`、`stripe-pattern`、`card-generator`、`button-generator`、`badge-generator`。
- `favicon-from-emoji`、`favicon-from-text` 的 Data URL 复制同样改为 `ToolBox.copyText(lastURL, …)`。
- 原实现只挂 `.then` 成功回调，Clipboard API 不存在或权限被拒时没有任何提示；统一能力会先走 Clipboard API，失败自动回退 `execCommand`，仍失败则弹出中英文「复制失败」提示并给出可手动复制的文本。
- 顺带修复 `js/common.js::fallbackCopy` 的假成功：此前不判断 `execCommand('copy')` 返回值，即使返回 false 也提示「已复制」；现已按返回值分支，失败才提示并提供 prompt 回退。

## 图标预览转义

- `favicon-from-emoji`、`favicon-from-text` 新增 `__favEsc()`，三档预览中的表情/文字统一转义后再拼入 `innerHTML`。
- 输入 `<b>Hi</b>` 时画布按字符绘制，预览也按字符显示，不再生成真实的 `<b>` 标签，预览与下载 PNG 一致。

## 验证

- 新增 3 条静态守卫：13 页无直接 `navigator.clipboard.writeText(text)` 且均含 `ToolBox.copyText`；图标页 Data URL 走统一能力；图标页预览对输入转义。
- 真机：文本图标输入 `<b>Hi</b>` 后 `preview.querySelector('b') === null`，三档预览文本均为 `<b>Hi</b>`；将 `navigator.clipboard.writeText` 改为 reject 且 `execCommand` 返回 false，`copyResult()` 触发「请手动复制」prompt，页面无 JS 错误。
- `node scripts/verify_design_calc.js` 407/407。
- 七项轻量门禁全过；全量 `run_gates.py` 278/278 通过。
