# 第237批 · IT 清单 3 条（clamp-calculator）

## 销账条目
- IT-N291 clamp 表达式算错：最小视口得到首选字号、大范围提前封顶。
- IT-N292 滑块预览忽略首选字号，与表达式不一致。
- IT-N293 不校验 min/max 与空输入，倒置时生成无效 clamp()。

## 根因
- 旧实现把直线锚在 `(vwMin, pref)`，只连到 `(vwMax, max)`，`min` 仅当下限；因此最小视口输出 `pref`，且 `pref≈min` 时提前封顶。
- 预览虽然也按同一条错线算，但没有把 `pref` 作为有意义的中点目标；用户改 `pref` 时预览与表达式都不按「中点偏好」工作。
- 数值解析用 `parseFloat(...)||默认值`，空串/0 被静默替换；仅校验 `vwMin<vwMax` 与旧式 `pref∈[min,max]`，`min>max` 时照常生成 `clamp(48px, …, 16px)`。

## 修复
- 统一算法：`min` 锁定最小视口，`pref` 锁定视口中点 `(vwMin+vwMax)/2`，`max` 锁定最大视口；中间用两段线性折线。
  - `pref=(min+max)/2` 时退化为单条直线。
  - 斜率/截距保留 3 位小数参与表达式与预览求值，展示边界仍按 2 位小数显示。
  - `slope1>=slope2` 用 `min(line1,line2)`，否则用 `max(...)`，再外套 `clamp(min, ..., max)`。
- 预览与表达式共用 `clampConfig().evaluate()`，滑块命中中点时显示首选字号。
- `clampConfig()` 显式校验五个数：非空、有限、正数；`vwMin<vwMax`；`min<=pref<=max`。非法时清空 `window._clamp`、展示错误、清掉预览字号。
- 文案三源同步：页面公式说明/新增列表项/深挖示例、`i18n/tools/content_deepdive.json`、`i18n/tools/en/it/clamp-calculator.json`；动态结果串全部走 `clampText()`，英文态无 CJK。

## 关键结果
- 默认 `16/24/48 @375–1440` → `clamp(16px, max(1.502vw + 10.368px, 4.507vw - 16.901px), 48px)`；375px=16、907.5px=24、1440px=48。
- `pref=40` → `clamp(16px, min(4.507vw - 0.901px, 1.502vw + 26.369px), 48px)`；800px 预览 35.15px。
- `min=48/pref=40/max=16` → `必须满足：最小字号 ≤ 首选字号 ≤ 最大字号`；空 `min` → `字号与视口必须是有效正数`。
