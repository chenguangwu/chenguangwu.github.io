# 428 批：描述为名称复述（emoji/分隔符变体）时回退真实说明

日期：2026-11-14
范围：`scripts/tool_desc_source.py`，重建 `json/tools.json`、行业 JSON 与工具页 meta/JSON-LD

## 一、问题

- 104 个工具的 `d` 本质只是工具名再加装饰：
  - `⏰ Cron 表达式生成器`、`◈ GraphQL 格式化`、`⌨️ 按键码 Keycode 查询`、`#️⃣ MD5 哈希计算器`
  - `Base64 编码 / 解码`、`RSA 加密解密 / 签名验证`、`CSS单位换算（px / em / rem / pt / %）`
- `is_weak_desc` 只做字面比较（`d == t` 或前缀），emoji / 斜杠 / 全半角括号一变就绕过判定，
  于是卡片、搜索、顶部导航全部显示「名称复述」，而对应的 `zh-CN.intro` 有完整说明。

## 二、修复

- 新增 `_desc_skeleton()`：去掉空格、标点、emoji、箭头等装饰，只保留字母数字与汉字。
- `is_weak_desc()` 改用骨架比较，覆盖三类名称复述：完全相等、名称 + 少量后缀、描述是名称前缀。
  公式串与模板腔判定保持在前，避免误回退。

## 三、效果

- `d` 为名称复述：104 → **0**
- 105 个工具的 `d` 换成真实功能说明（1 个为派生变化），例如：
  - `Cron 表达式生成器` → 「可视化生成 Cron 表达式，支持 5 位 Unix 格式，小白也能轻松上手」
  - `GraphQL 格式化` → 「GraphQL 查询语言格式化：美化/压缩，支持 Query/Mutation/Subscription/Fragment/Schema。」
  - `按键码 Keycode 查询` → 「按下任意键，实时显示 event.key / code / keyCode / 修饰键等全部按键信息…」
- 无新的空描述或短描述（`d` < 12 字：0），全站 meta 重复描述组：**0**，描述 < 70 字：**0**。
