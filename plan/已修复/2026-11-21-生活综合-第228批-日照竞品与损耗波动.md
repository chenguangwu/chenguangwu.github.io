# 第228批：日照间距、竞品份额与损耗波动（2026-11-21）

## 修复清单

1. **日照间距预设语义错位（LF-N88）**
   - 三个预设实际写入的是判定阈值 `std`，却命名「低波动/中波动/高波动」，0.5 让全部达标、3.0 让全部不达标。
   - 改为「严格 1.5 / 常规 1.2 / 宽松 1.0」，英文 `Strict/Standard/Relaxed`，并保留默认 1.2。

2. **日照间距接受零/负间距（LF-N89）**
   - 原来只过滤 `h<=0`，`d=-22` 会算出 -1.2222 并拉低均值/极差。
   - 现 `d<=0` 同样剔除；列数不足、楼高/间距非法按行号记录，结果区显示「已跳过 N 行」及具体行号原因，不再静默吞行。

3. **竞品份额无范围校验（LF-N90）**
   - 份额 150% 仍判「覆盖主要竞争面」。现单行份额限 0–100%、价格 ≥0、增速 -100%–1000%，越界直接报行号；份额合计 >105% 拒绝出结论并提示核对；`>=95%` 才称「基本覆盖」，50–95% 称「覆盖过半」，低于 50% 明确「仅覆盖部分竞品」。

4. **损耗分析缺波动指标（LF-N93）**
   - 页面承诺「均值与波动」但只给加权平均。现补环节损耗率的总体标准差（分母 n）与变异系数 CV，并给出每个环节「与环节均值偏差」列；明细表同步扩展。

5. **成本结构负金额与零合计（LF-N97）**
   - 负金额原来照收，出现「退货 -100% 占比」；合计为 0 时出现「—% / -—%」。现逐行拒绝负金额并报行号，合计 ≤0 直接提示，不再渲染占比表。
