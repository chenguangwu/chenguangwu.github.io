# 第782批：Emoji 英文搜索与动态详情

**任务来源** `plan/it/Emoji含义查询-英文搜索与动态详情.md`
**工具** `tools/it/emoji-meaning.html`

## 问题
中文名称/关键词为主要检索字段，英文用户输入 `smile`、`thumbs up`、`China` 等常用英文名查不到；分类标签、数量、详情字段与复制按钮由脚本直接写中文，英文界面中英混杂。

## 改动

### 1. 英文数据
- 444 条 Emoji 全部补 `en`（英文名）与 `ek`（英文关键词数组）。
- 数据来源：Unicode CLDR 英文 annotations（`cldr-annotations-full`），391 条直接命中；53 条旗帜按 ISO 码＋国名映射（如 `CN`→`China`、`HK`→`Hong Kong, China`、`TW`→`Taiwan, China`）；`💹` 手工补 `Chart increasing`。
- 搜索同时匹配中文名/中文关键词、英文名、英文关键词、英文分类，中文搜索保持原有效果。

### 2. 动态界面英文化
- 新增 `CAT_EN`、`isEnE()`、`catLabel()`、`emojiName()`。
- 分类标签：`All / Smileys / Gestures / Animals / Food / Travel / Objects / Symbols / Flags`。
- 统计行：英文 `N emojis`，中文 `共 N 个 Emoji`。
- 卡片名称、详情名称/分类/关键词、复制按钮与 toast（`Copied:` / `已复制：`）随语言切换。

### 3. 误报守卫
- 英文名 `Infinity sign` 会命中页面通用 `Infinity` 守卫，导致分类/网格/详情整块被替换成「计算结果含无效值」。该页并无数值计算，移除三处 `Infinity` 文本检测，保留 `NaN` 与数值 `isFinite` 守卫。
