## 1. D-N218 farnsworth-d15：色帽文字色阈值 0.32 偏高，15 个色帽全部白字仅 4.23:1

**根因**：15 个色帽等亮度 `CAP_Y=0.198`，`textOn()` 用 `L > 0.32 ? '#111827' : '#FFFFFF'`，L=0.198 恒落白字；WCAG 黑白等优点在 L≈0.179，此处白字 4.23:1、纯黑 4.96:1。

**改动**
```js
// 旧：return L > 0.32 ? '#111827' : '#FFFFFF';
var crW = 1.05 / (L + 0.05), crB = (L + 0.05) / 0.05;
return crB >= crW ? '#000000' : '#FFFFFF';
```
深色改用纯黑而非 `#111827`（后者在 L≈0.198 只有 4.19:1，不达 AA）。
另在 IIFE 末尾加 `window.__fdTextOn = textOn;`（纯读取，供导出/自检复用），使用例可断言。

## 2. D-N172 css-border-radius：简单模式取消「四角联动」后滑杆变死控件

**根因**：`updateAll()` 仅在 `linkCorners.checked` 时把 `allRadius` 写入 8 个角；简单模式除该滑杆外无其它控件，取消勾选后拖动无任何变化。

**改动**：`updateAll()` 内简单模式强制 `linkEl.checked = true`（简单模式只有统一滑杆，语义上就是联动），进阶模式行为不变。

## 3. D-N212 generator-34：幻灯片比例下拉是死输入

**根因**：`ratio` 解析出 `W/H` 后只用于无人引用的 `ratioRows`（从未插入结果 HTML），等效像素恒按 1280 宽算。

**改动**
1. `var px=fs*96/72*(W/1280);` —— 等效像素按所选画布宽度换算（字号表与标题行同步）。
2. `ratioRows` 改为四行各自按自己的宽度算 px，并高亮当前比例行（`✓` + 加粗）。
3. 结果区 data-grid 新增「画布尺寸（px）」卡片（`W×H`）。
4. 新增「四、比例像素对照」表真正渲染 `ratioRows`（原模板要素参考顺延为「五、」）。
