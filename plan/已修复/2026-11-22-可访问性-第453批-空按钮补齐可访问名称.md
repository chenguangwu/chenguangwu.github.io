# 第 453 批：空文本按钮补齐可访问名称

- 日期：2026-11-22
- 类别：可访问性 / 屏幕阅读器
- 状态：已修复并提交

## 一、问题

全站工具页有 **146 个按钮既无文本也无 aria-label/title**，读屏只能读出“按钮”：

- 140 个是图表/表格切换 `<button class="tab-btn" data-v="chart"></button>`，按钮内部完全为空；
- 2 个是输出/指南切换按钮；
- 4 个特殊按钮：八度降低 `−`、颜色复制色块、删除门窗 `×`、导出速查表。

`×`、`−` 这类符号不算可访问名称，无法说明动作。

## 二、修复

- `_build.py` 新增 `_label_empty_tab_buttons(src)`：对内部为空、带已知 `data-v` 的 `tab-btn` 补 `aria-label` 与 `data-i18n-aria`（chart 图表 / table 表格 / out 输出 / guide 指南）；
- `js/i18n.js` 增加 7 个 `tool.aria.*` 英文键；
- 手工补齐 4 个特殊按钮：
  - 八度降低：`aria-label="降低"` + `tool.aria.decrease`；
  - 颜色复制：`aria-label="复制当前颜色"`；
  - 删除门窗：`aria-label="删除该门窗"`（含 JS 动态生成行）；
  - 导出速查表：`aria-label="导出速查表 (CSV)"`。
