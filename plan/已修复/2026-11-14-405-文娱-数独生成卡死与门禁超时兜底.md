# 2026-11-14-405 文娱 · 数独生成偶发卡死与门禁超时兜底

## 发现
- 全量门禁在第 29 关 `fun calc correctness: node scripts/verify_fun_calc.js` 卡死 **15 分钟以上**，
  CPU 100%、无任何输出；逐用例单跑却全部通过。
- 定位为 `tools/fun/generator-2.html` 的数独生成：
  1. 旧实现随机填满第一行后调 `solve()` 回溯求解，某些首行排列会让回溯搜索爆炸（浏览器同样会冻住）；
  2. 挖空用 `while (holes > 0) { 随机取格; 非空则挖 }`，当校验桩把 `Math.random` 钉为常量且未恢复时，
     永远挖同一格 → 死循环。门禁前序用例 `coin-toss-streak` / `coin-flip` 会改写 `Math.random`。
- 附带问题：`scripts/run_gates.py` 的 `subprocess.run` 没有超时，任何死循环都会让整轮门禁永久挂起。

## 修复
- `tools/fun/generator-2.html`
  - `genSudoku()` 改为「标准基座 + 行/列/数字三重置换」直接构造合法终盘，恒定 O(81)，不再回溯；
  - 挖空改为 `shuffle(0..80).slice(0, holes)` 一次性挖，随机数被外部固定也能完成。
- `scripts/run_gates.py`
  - 新增 `GATE_TIMEOUT_SEC = 30 * 60`，`subprocess.run(..., timeout=...)`；
  - `TimeoutExpired` 按 `exit=124` 失败处理，并输出超时命令，避免 CI 永久挂起。
