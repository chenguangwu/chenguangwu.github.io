# 第 449 批：表单标签与控件可访问关联

- 日期：2026-11-22
- 类别：可访问性 / HTML 语义
- 状态：已修复并提交

## 一、问题

全站工具页共 18,886 个可见表单控件，其中 **12,784 个没有可访问名称**：

- `placeholder` 兜底 8,791 个；
- 完全无标签/无名称 3,993 个。

典型结构为 `<label>性别</label><select id="gender">`：标签与控件紧邻，但没有 `for`，屏幕阅读器无法把标签读给控件。

另有 13 处 `<label for="top">` 指向不存在的 id（多选组标题误用 `for`），点击无目标。

## 二、修复

在 `_build.py` 新增两个幂等函数：

- `_associate_labels(src)`：标签结束后仅隔空白、紧跟带 `id` 的 `input/select/textarea` 时，补 `for="<id>"`；已有 `for`、控件无 id、控件自带 `aria-label/aria-labelledby` 时跳过；
- `_fix_invalid_label_for(src)`：整页找不到目标 id 时移除 `for`，保留标签文本。

调用点位于应用结构化数据清理之后，简体页与繁体产物同源生成。

- 指向不存在 id 的 `for`：**13 → 0**；
- 同一标签重复 `for` 属性：**0**；
- 繁体工具页无效 `for`：**0**；
- 连续两次构建 diff 统计完全一致（幂等）；
- `_test_static.py`：**4,626 passed / 0 failed / 0 warnings**；
