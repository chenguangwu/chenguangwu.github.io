# 复核失败重做批次 · 申请再次复核 — IT-N474

> 来源：`plan/复核失败/2026-11-09-第一批.md` 的「IT-N474 百分号与带符号取模右操作数、小数百分比遗漏」条目，重做后重新移交。

## 复核失败点原文
`7%-3` 实际 −2.93、`7%+3` 实际 3.07；按交接「% 后有操作数为取模」的约定，分别应为 1。另 `.5%` 报语法错误，预期 0.005；交接已承诺小数百分比。

## 根因
原正则 `(\d+(?:\.\d+)?)\s*%(?!\s*[0-9A-Za-z_(])/g` 把「% 后紧跟一元正负号」判为「无操作数」→ 转百分比；且 `\d+` 要求整数前缀，`.5%` 不匹配 → 保留裸 `%` 致语法错误。

## 修复位点
- `tools/it/math-evaluator.html:327-334`：改为函数式 replacer，按 `%` 后首字符是否为数字 / 左括号 / 正负号判定「保留取模」或「转百分比」；正则加 `|\.\d+` 分支支持省略整数部分的小数百分比。
- `tools/it/math-evaluator.html:115`：公式说明同步更新「% 后紧跟操作数保留取模、其余为百分比、支持小数百分比」。

## 验证证据
- node 独立复算：`7%-3`=1、`7%+3`=1、`.5%`=0.005、`15%`=0.15、`15.5%`=0.155、`50%*120`=60、`7%3`=1、`10 % 3`=1、`17%5`=2 全部 OK。
- `scripts/verify_it_calc.js` 新增 3 条用例（N474 signed1 / signed2 / .5%），整 slug 回归 40/40 通过。
