# 第 900 批复核失败重做：有正文指南仍带通用尾句（1 项）

销账：`409`。

## 409 有专属正文的指南仍保留通用隐私尾句

- 根因：`_build.py::normalize_guide_descriptions()` 的 `meta_re` 写成 `(name="description"... ) content="`，要求 `description` 属性后紧跟 `content`。而现行指南页在两者之间还有 `data-i18n-head`、`data-i18n-head-fb`、`data-attr` 三个属性，正则从未命中，导致 `_rewrite_guide_desc()` 虽有实现却始终报「收口 0 页」。
- 修复：正则改为 `(name="description"...)[^>]*?\scontent="`，允许中间属性；对 meta/og/twitter 三处同口径替换。重建后实际收口 98 页。
- 唯一仍含尾句的 `guides/text-compare-guide.html` 是 `noindex, follow` 的重定向桩，按构建口径本就跳过，不属于「有专属正文的空壳误判」。
- 防回归：`_test_static.py::check_guide_desc_boiler()` 扫描所有非 noindex/非重定向指南，逐一校验 meta/og/twitter description 不再含通用尾句。

## 英文态边界

指南描述的英文态由稳定的 `data-i18n-head` 键（如 `guide.fd-quarterly.desc`）驱动，中文摘要改写不改变键名，因此本批不会把中文重新带回英文态；示例页 `fd-quarterly-guide` 探针残留 0。全站仍有 128 页存量描述键未登记英文映射，属既有英文态遗留，不在本批范围。
