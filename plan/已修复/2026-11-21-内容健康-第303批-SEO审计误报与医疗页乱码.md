# 第303批：SEO 审计误报修正与医疗页乱码

## 一、SEO 审计解析误报（脚本）

`scripts/audit_seo.py` 原实现用窄正则取 `<title>` 与 `meta description`，导致三类假问题：

- `<title data-i18n-head=...>` 因带属性未被识别 → 128 页误报 `title_missing`；
- `<meta name="description" ... data-attr="content">` 属性顺序不同 → 128 页误报 `desc_missing`；
- 属性值含 `<10 mm` 这类比较符的 64 页，正则遇到 `>` 截断标签 → 再误报 `desc_missing`；
- `Cramér's V` 描述含英文撇号，旧 `content=["']([^"']*)` 在撇号处截断，描述只剩 `Cramér`。

改为按引号边界匹配整条 meta，并单独按起始引号配对取 content：

```python
re.finditer(r'<meta\b(?:[^>"\']|"[^"]*"|\'[^\']*\')*>', html, re.I)
re.search(r'content=(["\'])(.*?)\1', tag, re.I | re.S)
```

修正后 `title_missing` / `desc_missing` / `lang` 均归零，剩余 `desc_short 30` 为指南摘要确实偏短（12–29 字），属内容优化项、非脚本误报。
