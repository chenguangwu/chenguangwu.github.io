# 第934批（2026-11-26）

本批处理 8 个金融工具任务，全部源码、测试、真机复核通过后收口。

## 修复清单

1. **信用卡利息**（`credit-card-interest.html`）：日利率原始串为空时明确提示“如确为 0，请明确输入 0”，不再把空值当 0；非有限、负数同样拒绝；分期手续费率空值与负数同口径校验，显式 0 保留。等额对比新增 `equalCost`（差额 < 0.01）判断，两种方案总支出相同时输出“两种方案总支出相同”，不再固定推荐最低还款。
2. **期权盈亏**（`option-profit-calculator.html`）：横轴锚点改为行权价、盈亏平衡点、当前到期价三者联动，按跨度加 padding，当前到期价始终落在曲线范围内；图下新增横轴范围、当前到期价、盈亏平衡点说明。
3. **投资回报率**（`investment-roi.html`）：删除 `成本 / (利润 / 年数)` 虚构回收期，新增可选“年均现金回流”，仅在其近似相等时按“初始投资 / 年均现金回流”计算静态回收期；留空则明确输出“未提供年均现金回流”，不编造确定年数。中英文标签与说明同步。
4. **新西兰税号验证**（`ird-validator.html`）：成功结论改为“长度与校验和检查通过，但本地无法确认是否已登记、仍有效或归属某人，请以 IRD 官方渠道为准”；失败结论改为“校验和不通过，不代表其他号码未登记”。历史列与趋势改名，结论中英双语输出。
5. **货币换算预设**（`currency-converter.html`）：预设同时设置金额、汇率模式、手动汇率和源/目标币种；修正原先“人民币换美元却按 7.25 方向”的矛盾。例：5000 美元换人民币（手动 7.25）、80 美元境外账单换人民币；静态批量预设改为人民币 100 基准并补 CNY/USD。
6. **黄金换算**（`gold-price-calculator.html`）：新增基准纯度 0.9999，所有折算先按基准价折成纯金再乘目标纯度；重量、总价反算、纯度对照表统一口径。10g / 650 元 / 999.9 得 6500.00，18K 得 4875.49。
7. **利润率批量**（`profit-margin-calculator.html`）：新增集中读取与 500 行上限；成本起始/结束/步长严格判空、非有限、负数、步长 ≤0、结束小于起始均拒绝，0 成本合法；四档毛利率严格判空（0% 合法）、非有限、越界拒绝；按整数行数循环，避免浮点多行。
8. **货币符号**（`currency-symbol.html`）：新增 146 个国家/地区英文名与常见别名，每条货币生成 `countryEn` / `countrySearch`；搜索同时匹配中英文国家名，英文态卡片与导出国家列使用英文名。
