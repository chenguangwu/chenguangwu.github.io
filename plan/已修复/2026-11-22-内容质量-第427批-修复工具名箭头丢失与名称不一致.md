# 第 427 批：修复工具名中的箭头丢失与名称不一致

日期：2026-11-22
类型：内容质量 / 工具名称与结构化数据一致性
状态：已修复并本地提交（未 push）

## 一、原问题

全站扫描 `<h1>` 与 JSON-LD `WebApplication/SoftwareApplication.name`，发现 4 个页面的名称不一致，且共同特征是“↔”被替换成两个空格或直接丢失：

| 页面 | H1 / 结构化数据旧值 | 面包屑 / 标题旧值 |
|---|---|---|
| `tools/transport/convert-fuel-oil.html` | `燃油效率单位转换（MPG  L/100km）` | `…（MPG ↔ L/100km）` |
| `tools/it/convert-11.html` | `IP地址转换（十进制  二进制）` | `…（十进制 ↔ 二进制）` |
| `tools/medical/convert-glucose.html` | `血糖单位换算（mmol/L  mg/dL）` | `…（mmol/L ↔ mg/dL）` |
| `tools/data/csv-to-markdown.html` | `CSV  Markdown 表格` | `CSV ↔ Markdown 表格` |

影响：

- `WebApplication.name` 与浏览器标题/面包屑出现双空格或箭头缺失，搜索结果与屏幕阅读器读到的名称不一致；
- `tools.json` 的 `name` 同步取到带双空格的值，首页卡片、搜索下拉也显示异常；
- `csv-to-markdown` 还出现 `SoftwareApplication` 与 `WebApplication` 两个 name 不一致（`CSV ↔ Markdown 表格` vs `CSV  Markdown 表格`）。

## 二、修复内容

1. `i18n/tools/medical.json`、`transport.json`：把 `h1` 的双空格恢复为 `↔`，与 `title`/`desc` 对齐。
2. `i18n/tools/life.json`：把 `csv-to-markdown` 的 `h1` 从弱名称 `Markdown 表格` 改为 `CSV ↔ Markdown 表格`。
3. 页面磁盘同步修改（H1 为“只写一次”字段，构建不会刷新）：
   - `tools/medical/convert-glucose.html`：H1 与 meta/og/twitter 描述中的 `mmol/L  mg/dL` 全部改为 `mmol/L ↔ mg/dL`；
   - `tools/transport/convert-fuel-oil.html`：H1 改为 `MPG ↔ L/100km`；
   - `tools/data/csv-to-markdown.html`：`<title>` 与 H1 改为 `CSV ↔ Markdown 表格`；
   - `tools/it/convert-11.html`：`<title>`、H1 及页面内两处名称改为 `十进制 ↔ 二进制`。
