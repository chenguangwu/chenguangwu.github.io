# 金融 F-N46：投资回报页负「追加投入」把亏损翻成盈利（已修 · 申请复核）

## 来源
- `plan/categories/02-金融财务/finance.md` 的 F-N46「投资回报页负『追加投入』把亏损翻成盈利（中，确认）」。

## 根因
- `tools/finance/investment-calculator.html` `calc()` 原 L280 读 `additional` 用 `|| 0` 兜底，L281 守卫只校验 `init / fin / yrs`，不含 `add`。
- 负值直接进入 `totalInv = init + add`，减少总投入并放大回报率；极端负值使 `totalInv ≤ 0` 时，回报率与 CAGR 又被 `totalInv > 0 ? … : 0` 静默置 0，同屏「累计盈亏 +15,000」与「回报率 0.00%」自相矛盾。

## 修复位点
- `tools/finance/investment-calculator.html` `calc()` 守卫后新增：
  ```javascript
  // F-N46：追加投入为负等价于「取出本金」，不能简单并入总投入把亏损包装成盈利
  if(add < 0){
    document.getElementById('resultBox').innerHTML='<p style="color:var(--danger);">追加投入须 ≥ 0；如需从本金中取出，请按真实现金流另行计算。</p>';
    return;
  }
  ```
- 守卫位于 `totalInv` 计算之前，负追加不再产生任何结果卡片；`init > 0` 且 `add ≥ 0` 使 `totalInv` 恒为正，原 `:0` 兜底分支不可达，消除自相矛盾输出。
- 有效输入下计算链完全不变。

## 修复范围说明
- 清单方案含「负值走取出独立分支并按真实现金流求 IRR」。本页定位为简单回报近似测算（结果区已有「追加投入未做时点修正，结果为近似值」声明），并无 IRR 能力；为其新增取值分支会引入与页面定位不符的伪精确计算。
- 本次采取「字段级拒绝 + 明确引导另行计算」，**核心缺陷（亏损被包装成盈利、自相矛盾卡片）已闭环**；「取出独立分支」属增强需求，不在本页实现。请复核方据此判定。
