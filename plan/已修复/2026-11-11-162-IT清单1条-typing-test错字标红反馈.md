# 第162批 · IT 清单 1 条 · typing-test 错字仍标绿反馈失效

- 来源：`plan/categories/01-IT开发/it.md` → IT-N482（已整条删除）
- 修复日期：2026-11-11
- 类型：中风险交互反馈缺陷（练习反馈失效、CSS 死代码），纯前端逻辑，无文案/口径变更

## 失败点
`tools/it/typing-test.html` 的 `renderText()` 只按位置 `i < pos ? 'correct'` 给字符标绿，从不比较实际输入 `input[i]` 与目标 `text[i]`；全站无代码添加 `.wrong` 类。用户把 `abc` 打成 `axc`，前两位仍全绿、无红底提示，而错误计数/准确率已按实际比对算出 66.7% —— 视觉反馈与统计口径自相矛盾，`.char.wrong` CSS 成死代码。

## 根因
渲染层与主逻辑层脱节：`onInput()` 里已正确按 `input[i] !== text[i]` 统计 errors，`renderText()` 却另起炉灶只按输入位置分类，未复用同一判据。

## 修复位点
`renderText()` 内部读取 `#typingInput.value`，分类改 `i < pos ? (input[i] === c ? 'correct' : 'wrong') : i === pos ? 'current' : ''`。保持无参签名，三处调用点（重置/输入/退格）无需改动，避免漏改。未新增文案（复用既有 CSS class），i18n 0 残留。
