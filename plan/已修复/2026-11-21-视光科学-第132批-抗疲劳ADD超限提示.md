# 第 132 批：抗疲劳镜片 ADD 超限提示分支可达（视光）

- 日期：2026-11-21
- 页面：`tools/optical/anti-fatigue-design.html`

## 原问题

基础与进阶两个分支都先 `add = Math.min(add, 1.00)`，随后评价分支才判 `add > 1.00`。因此「计算ADD超过1.00D，建议改用渐进多焦点镜片」这段永远不可达；原始需求 2.5D 的用户只会看到「接近抗疲劳镜片上限」，误以为仍适合抗疲劳片。

## 修复

- 在封顶前保留量化值：基础分支 `uncappedAdd`、进阶分支 `uncappedAdd2`；`add` 仍按页面既有规则封顶 1.00D 展示。
- 评价顺序改为先判原始需求是否 `> 1.00D`：是则提示「原始ADD需求超过1.00D（页面按抗疲劳片上限显示为 1.00D），建议改用渐进多焦点镜片」；否则再按 0 / 0.50 / 0.75 / 1.00 分档。
- 原有「接近上限」分档保留给原始需求不超过 1.00D 的情形。

## 验证

- 新增用例：50 岁、工作距离 20cm、远用 0D ⇒ 原始 ADD 2.5D，断言出现「原始ADD需求超过1.00D」与「1.00D」；旧版只出「接近上限」。
