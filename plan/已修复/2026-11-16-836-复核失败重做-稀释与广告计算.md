# 836 批：复核失败重做（稀释口径 / 呼气试验分级 / 移动平均 / 弹性建议 / 零预算 ROAS / CPC 空值）· 申请再次复核

来源：`plan/复核失败/` 中 6 条（532、535、542、543、562、564）。

## 1. 稀释比例标签口径（532）

- **复核失败点**：FAQ 只笼统要求按标签，未对照「1:N 原液兑水」与「1:X 原液占总量」两种标签口径；算例 10 mL/990 mL 与实现 `原液 = 总量/(N+1)` 不符。
- **修复**：算例改为 1:100 ⇒ 原液 9.9 mL + 水 990.1 mL（占总量 1/101≈0.99%），并注明若标签指「原液占最终混合液 1/100」则为 10 mL + 990 mL；FAQ 新增口径对照问答，明确以标签/MSDS 定义为准。
- **验证**：`scripts/verify_static_text_claims.js` 断言新问答与 9.9 mL/1/101 存在、旧算例已清除。

## 2. 呼气试验用药分支（535）

- **复核失败点**：13C 灰区（3.0‰）在勾选 PPI 时被改判「结果不可靠/阴性」；14C 120 DPM 用药时被吞掉「弱阳性（+）」并断言「感染较重」；空值提前 return 导致单位标签不切换。
- **修复**：`calc()` 改为「先按检测值分级 → 用药只追加提示」；13C 灰区保留「灰区/临界（用药期间）」；14C 保留弱/阳/强分级并追加「（用药期间，结果可能受抑制）」，删除「感染较重」推断；单位标签切换移到空值 return 之前。
- **验证**：门禁 3 例（13C 3.0+PPI、14C 120+PPI、空值切 14C 的 `#dobLabel`），`verify_gastroenterology_calc.js` 56/56。

## 3. 移动平均守卫（542）

- **复核失败点**：<2 期直接 return 不清旧结果；split 后空串 `+''=0` 被当作第 N 期；CSV 导出不执行窗口校验。
- **修复**：`parseData()` 先 `filter(s!=='')`；`calc()` 在 <2 期时把标签改为「至少需要 2 期历史数据（当前 X 期）」并清空 `#resultTable`；`maExportCsv()` 增加同样的 <2 期与 `n>data.length` 守卫。
- **验证**：门禁 2 例（先算后只留 1 期 ⇒ 标签更新且表格为空；末尾换行 ⇒ `parseData().length===3`），`verify_sales_calc.js` 18/18。

## 4. 价格弹性建议（543）

- **复核失败点**：仅按 |Ed| 和 ΔP 给建议，正弹性（P100→110、Q100→120，收入反增）仍输出「建议降价促销」。
- **修复**：建议主判据改为实际 ΔR，并按 ΔP、ΔR 组合细分；`ed>0` 时前置「需求与价格同向变化（正弹性，非常规需求）…请先核验销量数据口径」。
- **验证**：门禁断言结果含「核验销量口径或竞品影响」且不含「建议降价促销」，`verify_marketing_calc.js` 22/22。

## 5. 零预算整体 ROAS（562）

- **复核失败点**：总预算 0 时 `totalRev/total = 0/0`，只显示破折号无无定义说明。
- **核查**：当前 `calc()` 已有 `totalRoas = total>0 ? … : null` 与「整体 ROAS 的分母为 0，不可计算」提示，属复核快照滞后。
- **新增证据**：门禁注入 `totalBudget=0` 断言该提示。

## 6. CPC 渠道空值（564）

- **复核失败点**：`onchange` 用 `parseFloat(this.value)||0`，清空占比/CVR 变成合法 0 继续计算。
- **修复**：去掉 `||0`；`updateChannel` 对非 name 字段空值存 `null`；`calcBudget` 显式判 `c.ratio===null / c.cvr===null` 并报错；输入框回显空串而非 NaN。
- **验证**：门禁 2 例（清空占比、清空 CVR 均在 `#budgetError` 报「渠道1 … 须在 0–100% 之间」）。
