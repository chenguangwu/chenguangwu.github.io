# 2026-11-26 第 931 批：金融计算口径、找词游戏与通信标识隐私

## 本批修复

1. **信用评估：资不抵债无法录入**
   - 移除资产负债率 >100% 的拦截，允许录入 101% 等资不抵债场景；评分仍按 >80% 档计 0 分。
   - 结果区新增红字说明：负债超过资产，评分模型只按 >80% 档计分，并提示补充资产明细。

2. **自动换行：字符模式拆断表情**
   - 新增 `charUnits()`，优先用 `Intl.Segmenter` 按字素簇切分，退化时用 `Array.from` 按码点。
   - `visualLen` 与 `takeByLen` 的非字节模式改用字素/码点单位，不再用 `substr` 拆开代理对，😀 等表情保持完整。

3. **雇主识别号：前缀推断与结论过强**
   - 未知前缀统一显示“未知（IRS 现行前缀分配未公开）”，删除“其他/现代分配”推断。
   - 前缀通过时只说明“9 位格式有效；前缀不在已知保留段”，明确页面不能据此确认前缀已分配或企业真实存在；保留段命中时只按格式判无效。
   - FAQ 同步改为“页面校验长度、数字格式，并排除已知保留前缀，不能离线验证注册状态”。

4. **设备租赁：净收益漏扣维护成本**
   - 新增租期内维护支出合计 `monthlyMaint × 租期`，净收益改为“总租金 + 残值 − 原值 − 租期内维护支出”。
   - 结果新增“维护费用合计”，净收益标签标明“已扣维护”；公式、算例、FAQ 与深挖数据源同步。
   - 原值 100、12 月、折旧 1 年、维护 12%、零利润、残值 0 → 租金 112、维护 12、净收益 0。

5. **设备租赁：无效计算仍可保存历史**
   - 计算开始置 `__lastCalcOk=false`，成功结束才置 true；保存历史前重新读取并校验原值、租期、折旧年限及计算状态，失败不写记录。

6. **词频统计：最小词长与占比口径**
   - 最小词长标签改为“中/英”，英文分支同样应用 `minLen`。
   - 词条百分比统一以过滤后全部词次为分母；Top N 仅控制展示条数，条形长度仍表示相对最高频词。

7. **找词游戏：词库、难度、键盘与 SEO**
   - 新增难度（10×10/6 词、12×12/8 词、14×14/10 词）、动物/水果/颜色主题及每行一个单词的自定义词表；自定义词表过滤非英文和少于 3 字母的项，全无效时明确提示且不生成矩阵。
   - 保留鼠标拖动和触摸；新增方向键移动光标、回车开始/确认、Esc 取消，以及提示（起点与方向）、开局计时和状态提示。
   - 修正中英文标题、meta/OG/Twitter 描述与页内说明，移除“金融财务工具”“固定 12×12、不支持自定义”的旧表述。

8. **通信标识验证：默认历史泄露完整号码**
   - `msisdn / imsi / iccid / imei` 四页默认不再自动写历史；新增显式“在本机保存脱敏历史（默认关闭）”选项与“清除本机历史”。
   - 写入时对输入与结果中的长数字脱敏（保留前 2 位、后 4 位），归一化号码也不会以明文进入历史；页面说明同步隐私口径。
