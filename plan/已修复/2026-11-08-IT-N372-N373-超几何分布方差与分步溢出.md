## IT-N372（中）N=1 时方差 0/0 得 NaN，卡片显示「未定义」

**失败点**：`variance = n*(K/N)*((N-K)/N)*((N-n)/(N-1))`，校验只要求 `N ≥ 1`。N=1 时校正因子 `(N−n)/(N−1)` = `0/0` = NaN，`0 * NaN` 仍是 NaN，`fmt` 把非有限值渲染成「未定义」。数学上 N=1、n=1 时 X 恒等于 K，方差应为 0。

**修复位点**：

```js
// IT-N372：有限总体校正因子 (N−n)/(N−1) 在 N=1 时是 0/0；N=1 时总体唯一、无抽样波动，方差恒为 0
const fpc = (N>1) ? (N-n)/(N-1) : 0;
const variance=n*(K/N)*((N-K)/N)*fpc;
```

**证据**：`N=1, K=1, n=1, k=1` → 修复前方差/标准差卡片双双「未定义」；修复后 `0 方差 0 标准差`（均值仍为 1）。

## IT-N373（中）分步计算用 `Math.exp(logComb())` 还原组合数，大样本溢出成「未定义」

**失败点**：主概率走 log 空间（正确），但步骤 1–4 用 `Math.round(Math.exp(logComb(...)))` 把组合数还原成数值。C(2000,1000) ≈ e^1382 已超双精度上限 1.8e308 ⇒ `exp` 得 Infinity ⇒ `fmt` 显示「未定义」，步骤 4 写成「未定义 × 未定义 / 未定义 = 0.036」，与主结果自相矛盾。

**修复位点**：新增两个辅助函数，步骤按是否溢出分流。

```js
function combInfo(n,k){
  const lg=logComb(n,k);
  if(!isFinite(lg)) return {ln:0, over:true, txt:'0'};
  const over = lg > 700;                 // e^700 ≈ 1.01e304，已逼近 MAX_VALUE
  return {ln:lg, over:over, txt: over ? ('≈ e^'+lg.toFixed(2)) : fmt(Math.round(Math.exp(lg)))};
}

```

- 未溢出：步骤 4 保持既有 `P = A × B / C = P` 形态（既有 6 条用例的 `3 × 35 / 210 = 0.5`、`P = 10 × 105 / 4,845 = 0.217` 等断言全部不变）。
- 溢出：组合数写 `≈ e^1382.27`，步骤 4 改走对数式 `P = exp(lnC₁ + lnC₂ − lnC₃) = exp(689.4673 + 689.4673 − 1382.2680) = 0.036`。

**证据**：`N=2000, K=1000, n=1000, k=500`
- 修复前：步骤 1/2/3 全「未定义」，步骤 4「未定义 × 未定义 / 未定义 = 0.036」
- 修复后：`C(2000, 1000) = ≈ e^1382.27`，`exp(689.4673 + 689.4673 − 1382.2680) = 0.036`
- 独立复算：P = 0.0356691（与页面 0.036 一致），lnC(1000,500) = 689.4673、lnC(2000,1000) = 1382.2680 —— 均由 `Σ(ln(n−i) − ln(i+1))` 累加可复算，用例已把这三个对数写进 ref 以接受复核。
