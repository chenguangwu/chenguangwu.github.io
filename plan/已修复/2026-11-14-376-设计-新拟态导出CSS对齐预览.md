# 376 设计 · 新拟态生成器导出 CSS 与预览不一致修复（D-N68）

- **日期**：2026-11-14
- **缺陷编号**：D-N68（中，确认源码缺陷）

## 缺陷与根因

预览按 `currentShape` 渲染三种形状，并同时展示凸起 / 凹陷 / 浮雕三种变体：

- `.neu-box` → `border-radius: <radius>px`
- `.neu-circle` → `border-radius: 50%`
- `.neu-btn` → `border-radius: 50px`
- 三变体分别用 `flatShadow` / `pressedShadow`（inset）/ `punchShadow`（半距外阴影＋半距内阴影）

但导出模板固定为 `border-radius: ${radius}px` + `flatShadow` 单块：

```js
const css = `background-color: ${bg};\nborder-radius: ${radius}px;\nbox-shadow: ${flatShadow};`;
```

后果：选「圆形」复制到项目得到**方形**（`20px` 而非 `50%`）；凹陷 / 浮雕两个预览变体**没有任何导出入口**，实际拿不到对应 CSS。

## 修复

1. **圆角随形状导出**：`const radiusCss = currentShape === 'circle' ? '50%' : (currentShape === 'btn' ? '50px' : radius + 'px');`
2. **三变体全部导出**：在 `.neomorphism`（凸起）之后追加 `.neomorphism-pressed`（inset）与 `.neomorphism-punch`（浮雕）两块，各自使用对应阴影变量，圆角与背景保持一致。
3. `.neomorphism` 主块模板保持原格式（`css` 变量 + 多行缩进），确保既有 verify 整行锚点用例不受影响。
