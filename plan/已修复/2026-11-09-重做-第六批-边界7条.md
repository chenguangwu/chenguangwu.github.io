## 1. D-N1 非法颜色保留旧 WCAG 评级，内部 # 通过校验
- 失败点：白/黑算出 21.00、AA 通过后把前景改成 `GGGGGG`，比率已清空但 AA 状态仍「通过」、评分条仍 100%；前景 `F#FF` + 背景 `000000` 被算成白黑 21.00。
- 根因：入口 `updateAll()` 与 `isValidHex()` 各执行一次 `replace('#','')`，内部 `#` 被抹掉后变合法 3 位 HEX；无效分支只清 `ratioNum`/`contrastGrade`，未清 WCAG 与评分条。
- 修复位点：`tools/design/contrast-checker.html` — 新增 `normalizeHex()`（只去**单个前导 #**），`hexToRgb`/`isValidHex`/`updateAll` 统一复用；新增 `clearWCAG()` 把 4 组 WCAG icon/status 置「待判定」、评分条宽 0% 且清背景色，在无效分支调用。
- 证据：新增两例 — `F#FF` 命中「颜色需为有效的 3 或 6 位 HEX 值」；先算白/黑再改 `GGGGGG` 命中「待判定」（验证旧结论被清空）。design 273/273。

## 2. M-N19 Berg 完整高分病历附加说明仍错误
- 失败点：14 项均 4 分、总分 56 时病历仍写「低于安全界值 45 分约 0 分」。
- 根因：`fallGap=total<45?(45-total):0` 与固定文案「低于…」组合，未区分高于/等于界值。
- 修复位点：`tools/rehabilitation/berg-balance-scale.html` — 按 `total<45` / `=45` / `>45` 三分支生成中英附加说明，并明确「临床阈值、分级与每分约 7% 线性估算的适用性须专业复核」（**不代替医学裁断**）。
- 证据：新增 `checks:["4"]` 用例 expect「高于安全界值 45 分约 11 分」；原有 28 分（低于 17 分）与 42 分用例保持通过。

## 3. 涂料计算的空门窗字段被当作零
- 失败点：清空门数时默认毛面积 52 m² 仍输出净面积 48.4 m²，因 `+''` 为 0，与错误文案「不能为空」矛盾。
- 根因：`+document.getElementById(...).value` 不区分空串与显式 0。
- 修复位点：`tools/home/paint-calculator.html` — `getDeduct()` 逐字段取原始字符串，空串返回「门窗字段不能为空，请逐项填写数值（无门窗请显式填 0）。」；非有限/负数返回原「门窗数量与面积均须为非负数值」提示；显式 0 仍合法。
- 证据：新增 `door-count:""` 用例 expect「门窗字段不能为空」；原有负数扣减用例与正常用例保持通过（home 10/10）。

## 4. 06-N50 负发货时效仍被选为最快标杆
- 失败点：A 发货 −1 天、B 发货 2 天，A 被选为最快标杆并显示差 3 天。
- 根因：解析时只校验 `isNaN`，未校验数值业务合法性。
- 修复位点：`tools/ecommerce/analysis-71.html` — 解析阶段收集负发货行（含行名），发现即停止计算并给出中英错误提示（本行不参与时效比较）；提示文案做字符过滤避免注入。正常正数与 0 天分组不变。
- 证据：新增用例注入 `A,...,-1` 与 `B,...,2`，expect「发货时效天数不能为负数」「请核对以下行：A」；原有 4 条 N50 正数/0 天/小数用例保持通过（ecommerce 46/46）。

## 5. CE-N10 微小参数下溢仍输出 Infinity 明细
- 失败点：年限 `1e-30`、折现率 `1e-300` 均通过有效性校验，但 `-n*log1p(r)` 下溢使主结果为 `—`、增强表含 `Infinity` 且可导出。
- 根因：`__lcoeCRF()` 未检查中间量 `n*Math.log1p(r)`；`x=0` 时 `-Math.expm1(-x)` 为 `-0`，`r/(-0)` 得 ±Infinity；Extras/Export 只看输入有效性不看结果可表示性。
- 修复位点：`tools/energy/lcoe.html` — `__lcoeCRF()` 对 `x` 非有限或为 0 返回 NaN；新增 `__lcoeComputable()`（校验 CRF 有限且 >0、LCOE 有限）；`calcTool()` 失败时清空明细并提示「资本回收因子不可表示（中间量下溢/溢出）」，`__lcoeExtras()` 与 `__lcoeExport()` 同步以 `__lcoeComputable()` 阻断并清空。
- 证据：新增极端参数用例 expect「资本回收因子不可表示」；原有零折现 `1e-18` 等常规用例保持通过（energy 98/98）。

## 6. SMS-31 负差值的效应量大小分类错误
- 失败点：差值均值 −2.5、标准差 3、配对数 15 时 `d_z=−0.8333` 被标「小效应」。
- 根因：附表用 `dz>=0.8` / `dz>=0.5` 带符号比较，负方向被误判。
- 修复位点：`tools/statistics/paired-t-test.html` — 抽出顶层 `__ptEffectSize()` / `__ptEffectSizeEn()`，按 `Math.abs(dz)` 分级（0.8 / 0.5），中英附表共用；负号保留在 `dz.toFixed(4)` 数值列表示方向。
- 证据：新增用例 clicks 由注入的 dbar/sd 算出 `d_z=−1.0000` 并断言「DZ=-1.0000|大效应|large」；默认 2.5/3 得 0.8333 不命中 ⇒ 强判别（statistics 115/115）。
