# 第990批：PDF 合并/拆分保留书签与内部跳转，表单检测与展平

## 原始问题

`tools/office/pdf-merge.html`、`tools/office/pdf-split.html` 通过新建文档并 `copyPages` 生成结果：

1. 源 PDF 的 `Outlines` 书签不会进入输出，长文档章节导航丢失。
2. 源页 `Annots` 里的内部 `GoTo` 链接在复制后 `/D` 指向输出文档中的错误对象，页内跳转目标可能失效。
3. 页面只有通用「交互表单可能不保留」提示；实际复制流程会丢字段，用户上传后得不到针对该文件的提醒，也无法选择保留外观。

## 实现

### 新增共享库 `js/tools/pdf-structure.js`

`window.PDFStructure` 提供：

- `detect(doc)`：统计 `AcroForm/Fields` 顶层字段数、递归统计书签数量、统计 Link 注释与内部跳转数量（`/Dest` 或 `/A /GoTo`）。
- `relinkPages(srcDoc, outDoc, pairs)`：以**源页注释**为基准解析目标页序号，再写入输出页正确的 `/Dest` 或 `/A /GoTo /D`。只依赖 copyPages 后的注释对象会保留错误引用，因此必须回源解析。
  - 目标页不在输出中：删除 `/Dest` 或 `/A`，计入 `dropped`，不留下指向源文件的旧对象。
  - 外部 `/URI`、`/Launch` 不动；命名目标等无法可靠映射的动作删除，计入 `unsupported`。
- `appendOutlines(srcDoc, outDoc, pageMap)`：按源书签树复制 `Title/C/F` 与 `Parent/Prev/Next/First/Last/Count`，重建目标页引用。
  - 目标页不在输出中的书签删除，其子书签提升到父级，避免整棵子树消失。
  - 支持同一输出文档多次追加（多文件合并时逐文件接入根书签链）。

类型判断统一用 `instanceof PDFLib.PDFDict/PDFArray/PDFRef`。pdf-lib 压缩后 `constructor.name` 全是 `e`，按其判断会让检测结果恒为 0。

### `pdf-merge.html`

- 文件解析时保存 `features`，列表显示「N 表单 / N 书签」badge；汇总提示框说明检测结果与重建/展平能力。
- 检测到表单时显示「合并前展平字段（保留外观，输出不再可编辑）」复选框，默认勾选。
- 合并流程：逐文件检测 → 按需 `getForm().flatten()` → `copyPages/addPage` 记录 `pairs` → `relinkPages` → `appendOutlines`。
- 结果区显示书签保留/丢弃、内部跳转修正/移除、已展平表单文件数；展平失败或用户取消展平均明确提示「字段可能丢失」。
- 成功摘要、下载提示与结构统计均支持中英双语。

### `pdf-split.html`

- 上传后用 pdf-lib 独立副本检测结构，显示针对当前文件的表单/书签/内部跳转提示。
- 检测到表单时显示展平选项，默认勾选；提取前按需展平。
- 提取页复制后按 `pairs` 调用 `relinkPages`、`appendOutlines`；所选范围外的书签删除并提升子书签，范围外链接目标移除。
- 结果摘要追加书签保留/丢弃、内部跳转修正/移除、表单展平或未展平提示；中英双语。

## 回归用例

新增 `scripts/verify_pdf_structure.js`（无浏览器依赖，直接加载 vendor/pdf-lib 与共享库），并注册到 `scripts/run_gates.py` 的 `pdf structure correctness` 门禁。5/5 通过：

1. 检测：3 个文本字段、4 个书签（含嵌套）、3 条 Link（2 条内部 GoTo + 1 条外部 URI）。
2. 合并：保留嵌套书签树 `Chapter 1 > Sub 1.1/Sub 1.2`、`Chapter 2`；2 条内部链接改写为输出页引用；外部 URI 保留；表单展平后字段 0。
3. 拆分 `[1,3]`：目标页 2 不在结果中，相关书签与链接删除；子书签 `Sub 1.2` 提升保留；外部 URI 保留。
4. 合并重排（B 文件在前、A 文件在后）：书签顺序为 `Part B`、`Chapter 1...`，A 文件内部链接仍指向重排后的正确输出页。
5. 重复源页 `[1,1,3]`：输出 3 页，书签/链接重建不产生悬空引用。
