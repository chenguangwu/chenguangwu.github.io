# 第979批：单位换算工具英文空值提示

## 问题

14 个 `tools/life/*-converter.html` 的非法输入分支 `__h0` 硬编码中文「请输入有效数值」。英文态 `?lang=en-US` 下清空输入、输入非数字时仍显示中文；`pressure-converter` 的 `clearAll()` 末尾还会再调用 `convert()`，把刚写入的英文空态立即覆盖成中文错误提示。`magnet-converter` 的 `copyRes()` 只识别中文错误串，英文错误态会被当作可复制结果。

## 修改

- 14 页统一把 `__h0` 改为按 `TBKit.util.isEn()` 切换：
  - 中文：`请输入有效数值`
  - 英文：`Enter a valid number.`
- `pressure-converter`：删除 `clearAll()` 末尾的 `convert()` 调用，清空后保留空态「请输入数值进行换算 / Enter a value to convert」，不再被非法输入提示覆盖。
- `magnet-converter`：`copyRes()` 的无可复制判断补上 `Enter a valid number.`。
- 回归用例（`scripts/verify_life_calc.js`）：
  - 重写原 `PRESSCLEAR` 用例：按 `clearAll()` 函数体切片，断言函数体内不再调用 `convert()`，避免把函数外第 314 行的 `convert();` 误判为函数体（旧用例因此假绿）。
  - 新增 `MAGCOPY`：断言 `magnet` 的 `copyRes()` 识别英文非法提示。
  - 新增 `ENHINT`：一次性扫描 14 页，要求均含 `Enter a valid number.` 且不再残留硬编码中文 `__h0`。

## 真机验证

Chrome headless（`?lang=en-US`）逐页验证 14 页：

- `pressure`：清空输入 `Enter a valid number.`；点清空按钮 `Enter a value to convert`；输入 `abc` `Enter a valid number.`
- 其余 13 页：空输入 / 非法输入均为 `Enter a valid number.`，清空按钮为 `Enter a value to convert`。
- 中文态抽查 `pressure / area / magnet / length / weight`：清空输入仍为「请输入有效数值」，点清空为「请输入数值进行换算」，无英文串入。
- 14 页均无 `pageerror`。
