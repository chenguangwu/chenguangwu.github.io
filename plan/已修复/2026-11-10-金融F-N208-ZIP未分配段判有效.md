# F-N208 ZIP 校验页：00000 / 99999 未分配段判有效

## 来源
- `plan/categories/02-金融财务/finance.md` F-N208（中，确认缺陷）。
- 修复方本批真修（分类清单线）。

## 根因
- `tools/finance/zip-code-validator.html` 只做形状匹配（`^\d{5}$`/`^\d{5}-\d{4}$`/`^\d{9}$`），不校验 USPS 分配范围（有效 5 位 ZIP 为 00501–99950）。
- `00000`、`99999` 形状合法 ⇒ 判「✅ ZIP Code 格式有效」；任意 5 位数字串零区分度。

## 修复位点
- `validate()` 在 valid 判定后、格式输出前加范围守卫：`Number(zip5) < 501 || Number(zip5) > 99950` → 输出「❌ ZIP 00000–00500、99951–99999 为 USPS 未分配段，不是有效 ZIP」并 return（过既有 NaN 守卫）。
- 默认 10001、既有用例 95014 均在范围内，不受影响。

- 既有 `95014`（SCF 950，范围内）不漂移；默认预填 10001 ⇒ 新用例不命中。
