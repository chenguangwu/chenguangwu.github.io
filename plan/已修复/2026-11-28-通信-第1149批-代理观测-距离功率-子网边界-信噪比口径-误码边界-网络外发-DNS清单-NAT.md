# 第1149批 通信（telecom）修复记录 · 待复核

## 本批范围

`plan/telecom/` 9 项任务：代理路由推断、无线距离接收功率、子网 /0 与 /31 /32、BER/SNR 口径、BER 反算边界、网络诊断外部请求、站点/服务搜索摘要、DNS 出口描述、NAT 类型推断。

## 修复内容

1. **代理分流观测**：`proxy-routing-test` 改为固定 favicon 图片加载观测，只报告成功/失败、计数与耗时；删除“规则分流 / 全局代理 / 网络故障”推断；补充浏览器无法读取系统/路由器代理配置的说明。共享 `runT10` 同步。
2. **无线距离与接收功率**：`distance-power-frequency` 对全部输入做数值/有限性/非空校验，保留 0 dBm、0 dBi；新增“最大距离处接收功率（=灵敏度，dBm）”，按 `Pt + Gt + Gr − FSPL` 计算；修正 dBm 与 dBi 在对数链路预算中可相加的说明。公式框、深度解析、指南同步。
3. **子网边界**：`subnet-planner` 对 /0 掩码显式处理（`newMask===0 ? 0 : ...`）；数量=1 保持原前缀；/31 明细改为“对端地址 + 点对点无广播”，/32 改为“单主机无广播”。覆盖 /0、/30、/31、/32 样例。
4. **BER/SNR 口径**：`convert-24` 新增“Eb/N0 / 带宽内 SNR”输入口径；SNR 口径按 `Eb/N0 = SNR − 10log10(R/B)`，容量按带宽内 SNR 计算；Eb/N0 口径不输出容量，显示“归一化信道容量：不可用”。公式、FAQ、深度解析、指南同步。
5. **BER 反算边界**：`ber-snr` 为 BPSK/QPSK、16-QAM、64-QAM 设可解上限（28/32/36 dB），先算可分辨最小 BER；低于下限、反算结果非正或相对误差 >2% 时明确报“低于可分辨下限 / 无法稳定复现”，不返回边界假值。
6. **网络诊断外发收敛**：`js/network-toolbox.js` 的 `runT1`（公网 IP）、`runT2`（IP 归属）、`runT7`（NAT/STUN）、`runT11`（测速）、`runT13`（服务状态）均不再请求第三方接口，改为本地格式校验、路由器/运营商/官方状态页自查步骤；`runT4/T10` 保留固定 favicon 观测但只报告图片加载，不代表整站/代理/网络正常。对应页面标题、首段、公式、字段、FAQ、结构化数据同步。
7. **站点与服务摘要**：`site-reachability` 明确为固定 4 个站点 favicon 图片观测；`service-status` 明确只链接官方状态页、不读取状态接口；失败不等于宕机。
8. **DNS 出口页**：`dns-egress-lookup` 标题/描述改为“DNS 出口排查指南”，去掉“通过公共 DoH 查询”的错误承诺；新增四项本地诊断清单和“粘贴 DNS 日志分析”（仅浏览器内统计行数、IP 命中、唯一解析器 IP Top，不上传/不保存原始日志）。FAQ 结构化数据同步。
9. **NAT 类型**：`nat-type-test` 不再访问 STUN、不发送 WebRTC 候选；明确浏览器页面无法可靠区分 NAT 类型，改为路由器 NAT/UPnP 与双网络 P2P 本地排查步骤。
