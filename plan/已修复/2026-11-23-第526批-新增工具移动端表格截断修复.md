# 第 526 批：两个新增工具移动端表格截断修复

- 日期：2026-11-23
- 范围：类别 2「UI 布局异常」
- 提交：`e7307bfce7`

## 问题

390 px 移动端实测发现：
- `tools/home/water-filter-lifespan.html` 的「常见滤芯类型与更换信号」3 列表格实际宽度约 470 px；
- `tools/home/ac-energy-cost.html` 的「常见匹数与额定功率参考」4 列表格实际宽度约 428 px。

页面整体 `scrollWidth` 仍为 390，表格虽在 `overflow-x:auto` 容器内可横向滚动，但首屏只看到右列被截断，移动端阅读体验差。

## 修复

两个页面各加一段 `@media (max-width:600px)` 规则，并给表格加 `compact-table table-3col / table-4col`：
- `table-layout:fixed;width:100%;font-size:12px`；
- 单元格 `white-space:normal; word-break:break-word; overflow-wrap:anywhere`，长文案自动换行；
- 3 列按 24% / 24% / 52%，4 列各 25%。

## 验证

- 390×844 真机视口复测：两页 `scrollWidth=390`，越界元素 **0**（此前分别报 8 个表格元素越界）。
- 桌面端样式不受影响（规则只在 ≤600 px 生效）。
- `verify_home_calc.js` 两个工具 8/8 通过；两页英文态残留 0；`audit_seo.py --check` 通过。
- 构建后复查 `compact-table` 标记仍在（`grep -c` 各 3 处）。
