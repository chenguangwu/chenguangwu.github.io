# 第 1085 批：公共能耗支持零费用账期并加入多户分摊核对

- 修复时间：2026-11-27
- 类型：零值口径 / 多户分摊 / 覆盖核对
- 涉及页面：`tools/property/energy.html`

## 问题
1. 公共能耗总额为 0 被判定为“非正数”，无法计算无费用账期。
2. 仅支持单户面积比例试算，不能录入多户、核对取整合计，也未说明与合同/用量法的差异。
3. 未提示录入面积是否覆盖总建筑面积。

## 修改
- 单户试算允许总额 0：分摊 0，仍输出面积占比与单位面积成本，并说明“本账期总额为 0”。
- 空值改为显式提示，负总额/负面积拦截；总面积必须 >0，本户面积不得大于总面积。
- 新增“多户分摊核对”：支持按面积比例、按户数均摊、自定义比例（合计须 100%）三种模式。
- 金额统一以分为单位分配，最大余数法补齐；表格展示逐户金额，合计与总额差额恒为 0.00。
- 面积模式与总建筑面积核对：各户面积合计超过总面积时拦截；少于总面积时提示“未覆盖 X ㎡（Y%），需确认由未列户或公共预留承担”；刚好覆盖则提示已覆盖。
- 结果区固定说明：面积法仅适用于合同按面积且无分表的情形；按用量/户数/合同比例须切换口径，避免把试算当合同规则。
- 公式框与英文词典同步更新。

## 真机验证
- 总额 0 / 总面积 10000 / 本户 100：分摊 0.00，占比 1.00%，单位成本 0.00，并显示零账期说明。
- 总额 9600、3 户面积 100/100/120：3000 / 3000 / 3600，合计 9600，差额 0；提示覆盖 3.20%、未覆盖 96.80%。
- 按户数：3200 / 3200 / 3200，合计 9600。
- 自定义比例 50/30/20：4800 / 2880 / 1920；第三户改 0（合计 80%）被拦截并提示合计应为 100%。
- 总额留空：提示填写，明确 0 为合法无费用账期。
- 英文探针 0 页残留；`verify_property_calc.js` 26/26；`_test_static.py` 4654 通过 / 0 失败 / 0 告警。

## 复核要点
1. 总额 0 必须能出结果，不能要求正数。
2. 多户金额之和必须等于总额（分币），差额恒为 0.00。
3. 自定义比例合计不等于 100% 时必须拒绝分配。
4. 面积合计超过总建筑面积必须拦截；少于时必须提示未覆盖比例。
