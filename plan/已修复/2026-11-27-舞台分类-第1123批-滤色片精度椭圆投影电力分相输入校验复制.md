## 页面修复

### stage-color-filter 色温与滤色片
- 不再先把源/目标 Mired 各自取整再比较；`calcConv()` 全程保留浮点精度，仅显示取整。`|Δ|≤1` 才表述为“近似一致”，并显示实际差值与阈值。
- 标称档改为“不超过差值的最大档”（全 131 / 半 65 / 1/4 33 / 1/8 16 Mired）；小于 16 仍用 1/8 并提示可能过度校正。结果同时给源/目标 Mired、完整差值、方向、标称位移、换算后色温、剩余偏差。
- 超过全片 131 Mired 时提示剩余量“超出单片范围，可能需组合或改用可调光源”，不再把单片当完整解。
- 删除“保证多灯色彩一致”承诺，改为颜色近似匹配，光谱、色偏与透光损失须用光谱仪/色度计实测。
- 复制改为复用 `lastConv` 有效结果，输出差值、推荐、标称位移、剩余偏差和局限；空/0/非数字/混合文本时 `copyConvBtn.disabled=true`、`lastConv=null`，拒绝复制。
- 真机：5200K→5600K 差 -13.7 Mired，1/8 CTB -16 → 约 5672K、剩余 -2.3；5600/5601 近似一致但显示实际 -0.0；3200→10000 差 -212.5，全 CTB -131 → 约 5510K、剩余 81.5 并提示超单片；空值复制按钮置灰。

### power-load 灯光总功率与负载
- 功率因数、安全裕度分别校验空值与合法 0：留空逐项提示“不会被当作 0 或 1”；功率因数须 0（不含）–1（含），裕度 0–100%。不再 `pf||1`、`margin||0`。
- 三相口径拆开：总电流是“三相均衡等效值”，另列三相线电流、单相 220V 电流、均衡分配每相电流、单相全集中一相的最不利相电流、最不利相安全裕度后电流。
- 单相占比改为 `单相功率÷总功率×100%`，只有单相负载时也有效，不再显示 0%。
- 默认供电改 380V 三相；清单含三相负载却选 220V/110V 时停止并提示“不能直接承载三相灯具”。
- 断路器不再按 16A 整数倍给建议：按标准额定档（16/20/25/32/40/50/63/80/100/125/160/200/250/315/400A）取不小于最不利相安全裕度后电流的档，并另列“负载≤额定值 80%”对应档；明确须校核线缆载流量、保护曲线、启动冲击，不能直接选型。
- 复制复用 `lastPower`，含总功率、等效总电流、最不利相电流、单相占比、双档断路器与局限；无有效结果时拒绝复制。
- 真机默认：30.40kW（三相22.40/单相8.00）、48 台、380V、pf0.9、裕度20% → 总电流 51.3A、最不利相 78.2A、裕度后 93.9A、初步断路器 100A（80%上限 125A）、单相占比 26.3%；切 220V → 三相负载提示。

### beam-angle 灯具光束角
- lux→fc 改为 ÷10.7639（1 fc = 10.7639 lux），不再 ÷10；500 lux 由旧 50.0 fc 修为 46.5 fc。
- 删除“覆盖比例 = 角度÷360”：该角度比例与照射面积/立体角占比无关，页面改为明确说明。
- 光束角/距离留空不按 0；完整数值校验；发光强度可留空（不显示照度），负值拒绝。
- 复制只允许 `lastBeam` 有效结果，输出垂直光轴圆截面直径/面积（及照度）并注明斜射舞台实际为椭圆投影；无效时按钮置灰。
- 真机：25°、10m、50000cd → 直径 4.43m、面积 15.44m²、500.0 lux / 46.5 fc；光束角 0 → 报错且复制置灰。

### dimmer-curve 调光曲线
- 输入改用完整格式匹配 `数字[%]`；`50abc` 不再被 `parseFloat` 当 50。空值、超 0–255/0–100%、混合文本均停止并清空图表。
- 复制复用 `lastDimmer`（DMX、输出、曲线名），无效输入不复制；按钮同步置灰。
- 真机：`50abc` → 完整数值提示、复制置灰；`50%` → DMX 128、平方律输出 31.8。

### light-position 灯具角度与位置
- 角度页/位置页均改严格数值解析，空值不按 0；高度/距离/角度/光束角逐项范围校验，报错时 `lastAngle/lastPos=null`。
- 区分“垂直光轴圆截面”和“舞台水平投影椭圆”：圆截面半径 = 斜距×tan(半角)；椭圆短轴 = 2×该半径，长轴 = 短轴÷sin(投射角)，面积 = π×半长轴×半短轴；新增示意 SVG 标注长短轴。
- 投射角 ≤ 半光束角时，下缘光线平行或高于舞台面，明确提示“不能形成封闭光斑”，不再输出圆面积冒充照射面积。
- 复制只读当前有效 tab 结果；角度页复制角度/斜距，位置页复制圆截面与椭圆（或不能形成封闭光斑说明）；无效时 toast 拒绝。
- 修 `switchTab` 空 `btn` 容错，避免脚本调用时 `classList` 报错。
- 真机：45°、6m、25° → 水平距 6.00m、斜距 8.49m、圆截面半径 1.88m/面积 11.12m²、椭圆短轴 3.76m/长轴 5.32m/面积 15.72m²；10° → 不能形成封闭光斑；空值提示缺项。
