## 1. D-N187 detector-29：颜色预览报错后永久显示错误文案

**根因**：`calc()` 非法分支把 `#colorPreview` 的 `textContent` 覆盖成「颜色格式错误…」，合法分支只回填 `style.color/background`、从不恢复示例文字；且无 `#` 的 `1F2937` 直接写 `style.color` 是非法 CSS，预览前景不生效。

**改动**
```js
var __previewText=null;   // 顶层缓存示例文案
...
var preview=document.getElementById('colorPreview');
if(__previewText===null&&preview) __previewText=preview.textContent;
if(fgRgb&&bgRgb){
  preview.textContent=__previewText;
  preview.style.color='rgb('+fgRgb.r+','+fgRgb.g+','+fgRgb.b+')';
  preview.style.background='rgb('+bgRgb.r+','+bgRgb.g+','+bgRgb.b+')';
}
```
**未补强锁用例（结构性盲区）**：页面 `calc()` 在非法路径之前就会因 harness 环境抛 `hexToRgb: Cannot read properties of undefined`，非法分支在桩里根本走不到 ⇒ 无法构造「先报错再恢复」的判别序列；改用无 `#` 色值（`1F2937`→`rgb(31,41,55)`）做差分时，旧码在桩下 `style.color` 同样被规范化，判别力为零。故不造伪用例，以源码 diff + 真机复核交付。
