# 第661批：修复带子标记公式表格的中文态英文残留

## 问题

中文态 `restoreAllDataZh()` 对所有含子元素的节点直接跳过。公式引据表常用 `<sub>/<sup>` 表示上下标，`data-zh` 保存完整中文说明，但中文默认态仍显示英文公式：

- 47 页共 68 个 `td`：如 `Mass per unit area ... g/m<sup>2</sup>`；
- 11 页共 11 个 `p`：如公式说明段内的 `<code>name,count,score</code>`；
- 另有带单个外链的数值修约来源单元格。

## 修复

- `td[data-zh]` / `p[data-zh]` 含子元素时改为 HTML 级还原：
  - `data-zh` 自带标记（`<sub>/<sup>` 等）→ 直接写回 `innerHTML`；
  - 纯中文说明但含 `<code>` 等内联标记 → 写回中文文本，保留可读内容；
  - 仅含单个 `<a>` 子元素 → 只替换链接文字，保留 `href`。
- 还原前缓存完整英文 HTML 到 `__tbEnHtml`；英文态由 `applyEnDict` 回填，`restoreEn` 增加 `html` 分支，中英往返不丢失 `<sub>/<sup>` 与外链。
