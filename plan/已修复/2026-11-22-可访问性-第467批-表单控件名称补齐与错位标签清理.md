# 第467批：表单控件可访问名称补齐与错位标签清理

日期：2026-11-22
分类：可访问性 / 表单控件

## 原问题

1. 静态审计发现 256 个工具页共 553 个 `input/select/textarea` 没有 label、`aria-label`、`aria-labelledby` 或 `title`；其中 range、color、file、time、date、search 六类目标控件 124 个，集中在滑块、取色器、上传框、日期时间与搜索框。
2. 另有 276 个 checkbox/radio 的 `aria-label` 与包裹它的 `<label>` 文案错位，例如 `SHA-1` 复选框写成 `aria-label="MD5"`。`aria-label` 会覆盖包裹 label，导致屏幕阅读器读错选项；其中 21 处位于运行时 JS 模板字符串，构建期静态扫描抓不到。

## 修复

`_build.py` 新增两个幂等函数，并在 `ensure_table_header_scope()` 之后调用：

- `ensure_form_control_names()`：只处理 range/color/file/time/date/search。优先取控件前最近的 `<label>`、`*-label`、`*-title`、`*-hint` 文案；推断不到时按 type 与 accept 给保守名称（「选择图片文件」「选择日期」「BPM 滑块」等）。已有 `aria-label`/`aria-labelledby`/`title` 或 `id` 已被 `label[for]` 关联的不动；少数前文是说明而非名称的控件用显式键兜底。
- `strip_redundant_wrapped_control_aria()`：被 `<label>` 包裹且 label 有可见文字的控件，直接删除冗余 `aria-label`，让包裹 label 成为唯一名称来源。纯图标 label 保留原属性。
- 运行时模板中 21 处错位属性手工清理：`rental/cycle-11`、`neurology/dn4`、`neurology/rls-severity`、`neurology/dhi`、`neurology/phq9-stroke`、`rehabilitation/mmse-scoring`、`elderly/eldercare-level`、`finance/discount-calculator`、`tcm-pharmacy/herb-properties`。
