# 第 390 批补充 + 第 391 批 · 相关工具卡锚文本清洗（全站）

## 一、缺陷

工具页底部「🔗 相关工具」卡片的显示名不是纯工具名，而是整条页面标题：

```
<span class="rt-name">二维码生成器（已有，可加强定制） - 免费在线工具，纯前端处理 | ToolBox免费在线工具箱</span>
```

两个层次：

| 形态 | 卡片数 | 示例 |
| --- | --- | --- |
| 工具名 + `- 修饰` + `\| ToolBox免费在线工具箱` | 6501 | `呼吸计时器 - 免费开发工具，在线呼吸计时器 \| ToolBox免费在线工具箱` |
| 工具名 + `- 修饰` | 6468 | `光照累积量（每日光积分DLI）计算 - 每日光积分（Daily Light Integral, ...` |
| 合计 | **12969 / 28268（45.9%）** | 涉及 3016 个页面 |

## 二、根因

1. `_build.py` 早期直接把整条 `<title>` 赋给 `t['name']`，卡片 `rt-name` 用 `t['name']` 渲染 ⇒ 标题样板整串落进锚文本。
2. 既有「相关工具」块在构建里是**修剪模式**（`_build.py:4033` 起，只删指向已删工具的死链，不刷新名称）⇒ 后来的 `t['name']` 修好了，存量产物也永远不会自愈。
3. `_strip_seo_extra()` 有个**子串误伤 bug**：它先执行 `.replace('免费在线工具', '')`，而 `免费在线工具箱` 正好包含 `免费在线工具` 这个子串，尾串被啃成残片 `箱`，之后再怎么正则都认不出来。

## 三、修法

### 1. `_build.py::_strip_seo_extra()`（防复发）

- **品牌尾串最先剥**（放在 `免费在线工具` 全局替换之前）：
  `| ToolBox免费在线工具箱`、`| ToolBox`、行首 `ToolBox免费在线工具箱|`。
- **命中品牌尾串即按首个 ` - ` / `—` / `–` 截断**：该串必为 `<title>` 全量文本，分隔符之后一律是 SEO 修饰（`- 免费开发工具，在线呼吸计时器`、`- 标准二维码生成与 PNG/SVG 导出`）。
- **无品牌尾串则完全不动**，避免误伤本身含分隔符的真实名称。

单测 9 条（含 3 条真实污染串、3 条合法名、2 条带分隔符的合法名）全部符合预期。

### 2. 一次性清洗存量产物

以**目标页 `<h1>`**（剥前导 emoji）为权威名，逐卡片重写：

- 带品牌尾串的 6501 张 → 直接重写为 `<h1>`，**0 条回退**。
- `name.startswith(<h1> + ' - ')` 的 6468 张 → 截断到 `<h1>`。
- 剩余 972 张显示名与目标 `<h1>` **不构成前缀关系**（属别名或不同页面），**保持原样**——无证据不乱改。

## 四、旁路核对（确认无需连带修改）
