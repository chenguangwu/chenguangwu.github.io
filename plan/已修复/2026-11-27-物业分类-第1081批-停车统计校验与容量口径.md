# 第 1081 批：停车统计补齐字段校验、容量封顶与估算假设

- 修复时间：2026-11-27
- 类型：输入校验 / 统计口径 / 估算说明
- 涉及页面：`tools/property/stats-manager.html`

## 问题
1. 除总车位与包月上限外，其余字段用 `||0` 把空值当 0，负数、小数车位和超 24 小时时长可进入计算。
2. 平均在场量叠加包月数可超过总容量，占用率仍输出 >100%。
3. 临停可用位为 0 时周转率显示 0，即使仍录入临停车次。
4. 30 天、包月全时占用、线性计费等假设未明示，峰值占用被误读为可由日均推断。

## 修改
- 新增“统计天数（天）”输入，默认 30，可调；临停周期收入按天数外推，同期租金按 `天数/30` 折算，单车位产出统一折算为 30 天口径。
- 所有字段改为显式校验：空值提示“0 为有效值”，负数拦截；总车位/包月/车次/天数为整数；总车位 >0；平均时长 0–24 小时；包月不得超总车位。
- 临停可用位 =0 时周转率显示“不适用（临停可用车位为 0）”，不再显示 0。
- 平均在场超过临停可用位或占用率原值 >100% 时：占用率按容量封顶 100%，展示原值并提示核对车次、时长或临停能力；可用位为 0 但有车次时单独提示。
- 结果区固定展示估算口径：包月全时占用、按统计天数线性外推、不含免费时段/封顶/优惠、峰值无法由日均推断。
- 同步更新公式框的校验与口径说明，并补齐英文词典。

## 真机验证
- 默认 260/180/320/2.5/5/350/30：周转 4.00；在场 33.33；占用 82.05%；30 天临停 120,000；租金 63,000；总收入 183,000；单车位月产出 703.85。
- 车次留空：提示填写且明确 0 有效；总车位 260.5：提示必须整数；时长 25：提示不得超过 24。
- 包月 260、车次 320：周转“不适用”，占用封顶 100%（原值 112.82%），并提示核对。
- 总车位 100/包月 50/车次 400/时长 10：在场 166.67 超过可用 50，占用封顶 100%（原值 216.67%），提示核对。
- 统计天数 7：临停 28,000、租金 14,700、总收入 42,700，单车位月产出仍按 30 天折算。
- 英文探针 0 页残留；`verify_property_calc.js` 26/26；`_test_static.py` 4654 通过 / 0 失败 / 0 告警。

## 复核要点
1. 空值不得被当作 0；0 本身仍是有效输入。
2. 占用率任何情况下不得超过 100%，超容量须显示原值并提示。
3. 可用临停位为 0 时周转率为“不适用”，不是 0。
4. 改统计天数后，临停收入、租金和总收入的周期必须一致。
