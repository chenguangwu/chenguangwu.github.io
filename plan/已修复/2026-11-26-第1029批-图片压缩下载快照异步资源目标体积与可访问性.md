# 第 1029 批：图片压缩（image-compress）18 项

页面：`tools/image/image-compress.html`

## 修复内容

1. **批量下载快照**：`downloadAll()` 确认时快照 `blob / 文件名 / 实际 MIME`，定时器只下载快照；下载期间改参数、删除或清空不再错配。单张下载使用独立 blob URL。
2. **参数防抖旧结果**：`onSettingsChange()` 立即递增 `settingsVersion`、把所有条目标为 `stale` 并重渲染，下载/复制按钮同步禁用；300ms 防抖只负责延迟重算，旧压缩任务按 gen+version 丢弃。
3. **加载中删除资源**：`loadImage(file,item)` 把 object URL 记录到 `item.pendingUrl`；删除/清空会 revoke；迟到加载回调发现条目已移除也会 revoke 并退出。
4. **英文复制结果**：`copyResult()` 按 `__imgEn()` 输出英文标题/字段，成功提示同步英文。
5. **批量单项取消**：批量列表的“加载中 / 压缩中”行补 `✕` 移除按钮，删除时 `gen++` 使迟到压缩回调失效。
6. **目标体积校验**：新增 `getTargetInfo()`，仅接受 1–20000 的十进制整数；0、负数、小数、超范围、非数字均显示错误并暂停目标压缩，不再静默关闭/截断。
7. **特殊文件名**：移除结果区对整段 HTML 的 `Infinity/NaN` 数值守卫，`Infinity.png`、`NaN.png` 正常显示与压缩；数值兜底改由真实数值路径处理。
8. **对比滑块键盘**：`.cmp-slider` 增加 `role=slider`、`tabindex=0`、`aria-valuemin/max/now`，支持 ←/→/↑/↓（Shift 加速）、Home/End，并补 focus-visible 轮廓。
9. **解码失败释放 URL**：`img.onerror` 中 `URL.revokeObjectURL(url)` 后再 reject，失败图片不再占住对象地址。
10. **中文公式来源**：公式表“来源/标准”三格补 `data-zh` 中文（压缩率定义 / 输出体积上限 / JPEG 质量因子），中文态不再显示英文。
11. **目标搜索上限**：`compressToTarget()` 的搜索上界改为用户当前质量值（1–100），不再固定 95；记录实际命中质量，未达目标时结果区明确提示。
12. **单图失败入口**：错误态补“重试 / 移除 / 重新选择图片”；解码失败不提供无意义重试，但仍可移除或重选。
13. **全部下载跳过提示**：`downloadAll()` 统计可下载、处理中/设置已变更、失败三类，提示中明确跳过数量，不再静默略过。
14. **预设重新压缩**：预设回调由仅刷新说明改为 `onSettingsChange()`；已有结果时 `__compressPresetView()` 不再覆盖结果容器，预设点击后会按新参数重压。
15. **英文错误提示**：加载/解码、压缩编码、目标体积、WebP 回落、下载/复制禁用等动态错误均走中英双语；英文态真机复核通过。
16. **BMP 一致性**：文件选择器 `accept` 增加 `image/bmp,.bmp`，过滤逻辑允许 `.bmp` 扩展名（即使 MIME 为空），页面说明与支持格式一致。
17. **GIF 静态输出说明**：上传区与说明补“GIF 动画仅取首帧输出为静态图片；BMP 同样输出所选静态格式”，页面描述同步。
18. **WebP 回落 PNG**：编码结果检查 `blob.type` 与请求 MIME；发现回落立即停止质量二分搜索，记录 `fallbackFrom` 并在结果区提示，避免对 PNG 做无效质量搜索。
