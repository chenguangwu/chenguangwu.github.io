## 处理项

### D-N72 网格图案生成器「虚线网格」与「方形网格」输出相同实线（中，已修）

- 文件：`tools/design/grid-pattern.html`
- 根因：`dashed` 分支与 `square` 分支的 `background-image` / `background-size` 逐字符相同，仅多一条 `background-position: -lw/2 0, 0 -lw/2`，结果是整体左/上移半像素的**实线**网格，不存在虚线段；五种类型里两种实质重复。
- 改动：`dashed` 改用两层 `repeating-linear-gradient`（实线段 `lw px` + 间隔 `2·lw px`），横竖各一层，真正产出断续线；删掉无意义的背景位移。
- 公式框同步：「方格用两层 linear-gradient…；虚线改用两层 repeating-linear-gradient（实线段 lw px + 间隔 2·lw px）真正产出断续线，不再靠背景位移」。
- 验证：`G72 rep=2 solid=N`（`gridType=dashed, cellSize=30, lineWidth=2` → 输出含 2 处 `repeating-linear-gradient`，且不再出现 `background-image: linear-gradient(` 实线写法）。旧码 rep=0 solid=Y ⇒ 红。

### D-N194 四层渐变实为 3 方向（30° 重复）+ 公式与规格不符（低，已修）

- 文件：`tools/design/isometric-grid.html`
- 根因：`background-image` 写 4 层，第 1、4 层都是 `linear-gradient(30deg …)` 完全重复，实际只有 30°/150°/270° 三个方向 ⇒ **一组斜线因重复层明显更粗**；公式把「四层」当特性、`background-size = 边长 × (边长 × 0.5774)` 写成面积式（实际是宽 s × 高 0.5774s）；引据表又推荐 2:1 菱形（0.5），与实现的 0.5774 互相矛盾；`size` 只在 HTML 上写 `max=200`，JS 未夹取（输入 999 直接生成巨型 tile）。
- 改动：
  - 删除与第 1 层完全重复的第 4 层，保留 30°/150°/270° 三层，并去掉无意义的 `background-position: 0 0 ×4`。
  - `size` 夹取到 10–200、`lineWidth` 夹取到 1–5（**不回写输入框**，保留用户原值，避免打断历史快照的输入回显语义）。
  - 公式框改为「三层…（三个方向互不重复，第四层与第一层完全相同已删除）；background-size 为宽 = 边长 s、高 = s·tan30° ≈ 0.5774s」。
  - 引据表「2:1 菱形」行改为「本页 tile 高取 s·tan30° ≈ 0.5774s（非 2:1 的 0.5）；2:1 菱形是另一种近似，二者不可混用」，出处改 `Isometric geometry`。
- 验证：`G194 n=3 clamp=200`（默认输入 → `linear-gradient(` 计 3 次；再把 size 填 999 → `background-size` 宽为 200px）。旧码 n=4 clamp=999 ⇒ 红。
