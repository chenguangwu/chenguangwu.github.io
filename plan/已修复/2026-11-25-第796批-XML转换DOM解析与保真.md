## 改动

### 三个工具统一改用浏览器 DOM 解析

`tools/it/xml-to-json.html`、`xml-to-toml.html`、`xml-to-yaml.html`：

- 删除 TOML/YAML 的手写正则 XML 解析器，统一使用 `DOMParser('application/xml')`。
- 新增 `xmlWellFormed()`：按标签栈校验开闭名称、未闭合标签与游离 `<`；`<a></b>`、`<root>` 等直接报「XML 解析错误」，不再静默输出空节点。
- 新增 `xmlParseFailed()`：仅把浏览器解析错误文档判失败——Chrome xhtml 命名空间、Firefox mozilla parsererror 命名空间、无父节点的错误节点；合法嵌套 `<parsererror>` 正常转换。
- 属性由 DOM 读取，单/双引号、实体、数字字符引用统一解码；CDATA（nodeType 4）纳入文本。
- 根与子元素键改用 `Object.create(null)` + `Object.defineProperty`：`__proto__` / `constructor` / `toString` 均成为自有键，不再被原型链吞掉。
- 纯文本叶子仍返回字符串（`name = "Tom & Jerry"`、`name: Tom`），不额外包 `#text`；带属性或子元素才返回对象。
- 混合内容文本与子元素交错时保留 `#text` 并新增 `#content` 保序数组；YAML/TOML 检测到 `#content` 或命名空间键时显示「⚠️ 检测到命名空间或混合内容，已按约定归一化，可能无法无损还原。」。
