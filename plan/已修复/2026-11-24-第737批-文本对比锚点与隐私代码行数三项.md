## 修复内容

1. **文本对比：大文本降级后仍能识别插入/删除锚点**
   - `anchoredLineDiff` 改为在 500 行滑动窗口内同时寻找 B 侧新增与 A 侧删除锚点，先输出多出来的一侧，再继续逐行对齐。
   - 修正插入/删除方向：开头插入一行时输出 `add` + 后续 `same`，不再把后续全部按行号判为 `modify`。
   - 超出 `MAX_DIFF_CELLS=4000000` 的页面提示明确为“滑动窗口锚点对齐”，并说明超出窗口仍会降级。

2. **文本对比：完整文本默认不落盘，改为用户主动选择**
   - 历史工具栏新增 `saveHistory` 复选框，默认不勾选。

3. **代码行数：按扩展名识别语言不再错位**
   - 文件选择去掉 `selectedIndex=map[l]||0`，改为按 option 的 `value` 设置；新增 `__applyDetectedLanguage(name)` 统一处理。
   - `.py` 文件得到 `py`，未知扩展名回到 `auto`；不再把 Python 错设成 C 系语言。

4. **代码行数：空输入不再偷偷统计示例**
   - 移除空输入时自动填入 demo 字符串的逻辑。
   - 空白输入只显示“空输入不会自动加载示例”空态，不产生总行数/代码行等统计。

5. **代码行数：同一行多个块注释与跨行块注释正确计数**
   - 新增 `__scanBlockComments(text,inBlock,rules)`，循环剥离一行内任意多个 `/* ... */`，并跟踪跨行块注释状态。
   - `calcTool` 使用扫描结果：纯注释行计注释，注释夹代码行计代码；空行处于块注释内时计注释。
   - 修正 `__maskLiterals` 把块注释结束符 `/` 误判为正则起始的问题（`lastSig==='*'` 时不再进入正则分支），避免 `/* a */ const x=1; /* b */` 中的代码被吞掉。
