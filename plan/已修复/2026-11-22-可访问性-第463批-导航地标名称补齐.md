# 第 463 批：导航地标补 `aria-label`

## 问题

全站 8,106 个 `<nav>` 中，4,832 个已有 `aria-label`，3,274 个完全没有名称，其中 3,244 个是 `guides/*` 的面包屑 `<nav class="breadcrumb">`。读屏用户在指南页会遇到两个无名称的导航区域，无法通过 landmark 快速跳转。

## 修复

`_build.py` 新增 `ensure_nav_aria_labels()`：

- 扫描所有源 HTML 的 `<nav>`，跳过 `<script>`/`<style>` 内示例字符串；
- 已有 `aria-label` / `aria-labelledby` 一律不动；
- 按 class 映射补名称：`breadcrumb` → 面包屑导航、`navbar` → 主导航、`mobile-tabbar` → 移动端底部导航、`guide-nav` → 指南导航，其余 → 页面导航；
- 繁体站生成后再跑一次 `include_tw=True`，保证 `zh-tw/` 同步；
- 与第 462 批的面包屑 `aria-current` 串行执行。

## 结果

- 构建输出 `Nav aria-label: 3271 tags in 3258 pages`；二次构建 `0 tags in 0 pages`，幂等；
- 复核源站 8,106 个 `<nav>`：8,103 个有名称，剩余 3 个是 `tools/it/code-highlighter.html`、`tools/it/html-tags.html` 脚本示例字符串里的 `<nav>`，不是真实地标；
- 名称分布：面包屑导航 8,072、主导航 9、页面导航 5、移动端底部导航 5、指南导航 3、原有「面包屑」5；
- 繁体站 8,100 个 `<nav>`：8,097 个有名称，剩余 3 个同样是脚本示例；
- 静态测试：4,626 passed / 0 failed / 0 warnings（4,606 个工具）；
- 死链门禁：16,743 文件 / 160,344 内链，0 死链；
- 资产完整性：0 资产死链 / 0 `lang` 缺失 / 0 重复 id；
- 内联标记位置审计：0 处加固片段违规；
- 全量门禁：268/268 passed（`/tmp/gates463.log`）。

## 变更规模

- `_build.py`：新增 `ensure_nav_aria_labels()`；
- 3,258 个源页面新增 3,271 个 `<nav>` 名称；繁体同步继承；`sitemap.html` / `sw.js` 等构建产物随构建更新。
