# 第669批：站外引用链接全面体检与 NIST 失效链接修复

## 背景

站内死链由 `_audit_links.py` 门禁覆盖，但正文中的**站外**参考链接长期没有体检。外部标准/指南页面改版后容易变成 404，用户点到“NIST 修约规则”却打不开，会直接伤害工具可信度。

## 扫描范围

- 全站（排除 `zh-tw/` 生成产物）所有 `href="http(s)://…"`。
- 排除本站域名、`example.com` 代码示例、淘宝客推广链。
- 实际站外引用：**29 个唯一 URL**，覆盖标准、医学文献、平台帮助、品牌尺码表等。
- 用 `curl -L` + 浏览器 UA，15 秒超时，跟随重定向检测最终状态码。

## 结果

- **200**：21 个。
- **403**：6 个（NIST 旧地址、ISO、CDC、AAP、X/Twitter、知乎），多为站点反爬，浏览器实际可访问；不属于死链。
- **418**：1 个（IEEE OUI 标准站，反爬响应）。
- **000**：1 个（`help.weibo.com` 连接被重置，未确认失效）。
- **404**：**1 个真实死链** —— `tools/science/significant-figures.html` 引用的旧 NIST 地址：

```
https://www.nist.gov/pml/owm/metric-si/appendix-b#b-7
```

## 修复

NIST 已把 Appendix B 迁到 Special Publication 811 子站，页面仍包含 B.7.1 数值修约规则：

```
https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors
```

已替换该页外链；新地址实测返回 **200**，标题为 “NIST Guide to the SI, Appendix B: Conversion Factors”，正文含 “Rounding numbers”。

## 核验

- `python3 _build.py` 后修复存活。
- 全量门禁 **274/274 通过**。
- 新链接 `curl -L` 返回 200。

## 结论

全站 29 个站外引用中仅 1 个真实 404，已修复。403/418 属于反爬而非失效；`help.weibo.com` 的 000 无法从当前网络确认，保留待后续人工复核，不做猜测性替换。
