## D-N21 SVG 清空后旧异步转换仍可恢复可下载旧图

**失败点（原复核记录）**
- 页面：`tools/design/svg-to-png.html` 的 `generate()`、图片 `onload` 回调和 `downloadPNG()`。
- 复现：启动一次有效 SVG 转换，在图片加载完成前清空输入并再次点击转换（显示「请输入 SVG 代码」）；随后旧图片加载完成，其 `onload` 仍会写回 `lastDataURL` 和预览，点击下载实际下载旧图。使用 JSDOM 延迟触发 `Image.onload` 与 canvas 桩实测重现。

**根因**
- `generate()` 每次启动一个新 `Image` 并注册 `onload`/`onerror`，但旧任务的回调没有失效标记；清空输入或二次转换只重置 `lastDataURL`，不阻止此前已派发、尚未完成的异步回调在晚到时写回旧结果。

**修复位点**
- `tools/design/svg-to-png.html`：模块级新增 `var __genToken = 0;`；`generate()` 开头 `__genToken++; const myToken = __genToken;`（在任何 `return`/`lastDataURL=''` 之前先自增）；`img.onload` 与 `img.onerror` 开头均加 `if(myToken !== __genToken) return;`，被新转换/清空取代的旧任务回调直接丢弃，不再写回 `lastDataURL` 与预览。

**验证证据**
- `env -u NODE_OPTIONS node scripts/verify_it_calc.js svg-to-png` 全绿（含新增用例）。
- 新增回归用例（harness 无 `Image`/canvas，用例内联注入全局 `Image` 桩捕获 `onload`、覆盖 `createElement('canvas')` 为带 `toDataURL` 的桩）：先生成合法 SVG（注册 onload，token=1）→ 清空输入再 `generate()`（token=2，`lastDataURL` 清空）→ 手动触发旧 onload（模拟异步晚到），断言 `D21_LAST=EMPTY` 且 `PREV=NONE`（旧图未写回）。修复前旧 onload 仍写回 `lastDataURL` 与 `<img>`，标记变 `STALE`/`IMG`。默认快照（B）无 clicks ⇒ 不命中，判别力真实。

**判别力实测**
- 单文件判别器 `node scripts/discriminate_check.js verify_it_calc.js`：1336 用例已检、正确变红 1336、逃生项 0。本用例锚「旧异步回调是否写回」，回退源码后转红，确认门禁可捕获回归。
