# 2026-11-07 · 金融-保险（R-H9 + R-H10）：赔付准备金负输入、IBNR 负准备金与非法预设

## 条目（`plan/categories/02-金融财务/insurance.md:144 / :152`）
- **R-H9**（中）：`tools/insurance/claim-reserve.html` 的输入框只写了 `min="0"`，`calc()` 用 `+el.value || 0` 直接取值，不检查合法性。已付赔款 −3500 时损失率法 IBNR 8800（超过预期终极赔款 6500）、链梯最终赔款 −5000、调整后准备金 −975，且写入历史与导出。
- **R-H10**（高）：`tools/insurance/ibnr-reserve.html` 用 `IBNR = 已报案赔款 ×(发展因子 − 1)`，不校验方向。发展因子 <1 得负 IBNR；「示例 0.5×」预设给 `reported=2000000, factor=0.625`，**主动演示** −750,000 元准备金；因子 0 时得 −4,000,000。

## 根因
1. `min="0"` 是浏览器 UI 约束，脚本不调 `checkValidity()` 就完全无效；`+el.value || 0` 把留空 / 非数 / 0 全折叠成 0，负数是合法有限值。
2. 两页 `__*Extras()` 的早退只看 `isFinite(...)`，负数照样写明细表与历史；导出固定 `exportTable('#…Table')` 读历史摘要表。
3. IBNR 页把「因子 <1 表示高估已报告」当作可展示结果，但负准备金在会计与监管口径上不成立；预设表没有下界约束。
