# F-N54 马丁格尔「平均价」数学上恒等于当期价（真修）

- 分类：金融财务 / `tools/finance/position-size-calculator.html`
- 优先级：中（确认源码缺陷）
- 批次：2026-11-10 分类线第 75 批（本地提交，未 push）

## 失败点（原清单）
- `avg = cumCost / (cumPos / price)`，其中 `cumPos` 与 `cumCost` 每层都同样 `+= pos`，故二者相等，化简后 `avg === price`，每层平均价都等于该层价格。
- 真实平均持仓成本应为「累计投入 / 累计股数」，各层股数按各自价格折算（不是按当期价一次性折算）。
- 复现：初始 1000、2 倍、5 次、每次跌 10% → 旧页面第 5 层平均价 65.61（真实 71.23），页脚「相对初始价下跌 34.39%」（按真实应为 28.77%）。

## 根因
把「累计金额 `cumPos`」当成股数参与折算，且折算用的是**当期价**而非各层成交价；`cumPos === cumCost` 使消去后只剩 `price`。

## 修复位点
`tools/finance/position-size-calculator.html` martingale 分支：
- 新增 `var cumShares = 0;`，每层 `cumShares += shares;`（`shares = pos / price` 按各层成交价折算）；
- `avg = cumShares > 0 ? cumCost / cumShares : 0;`
- `positions` 各层 `avgPrice`、`result.avgPrice`（统计卡/明细表/页脚跌幅）统一取该值。

## 证据
- 手算样例：初始 2000、2 倍、3 次、跌 10%：
  - 层1 2000/100=20 股，层2 4000/90=44.4444 股，层3 8000/81=98.7654 股；
  - 累计 14000 / 163.2099 = **¥85.78**，相对初始价 100 跌 **14.22%**；
  - 旧实现恒等于当期价 ¥81.00（跌 19.00%）。
- `scripts/verify_finance_calc.js` 补 1 例：注入 `m-initial=2000/m-multiplier=2/m-times=3/m-droppct=10` + `switchMethod('martingale')`，expect 锁 `85.78（相对初始价下跌14.22%）`。
