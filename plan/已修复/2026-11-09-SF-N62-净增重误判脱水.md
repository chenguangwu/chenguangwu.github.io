## 失败点（复核不通过原记录）
- 运动前 70 kg、运动后 72 kg、饮水 3000 mL、排尿 0、运动 60 分钟；修正出汗量为正而未被守卫拦截，页面显示「净增加 2.00 kg / 净脱水率 −2.86%」，却同时判断「轻微脱水，注意补水」并建议每小时 1000 mL。

## 根因
页面已有 `sweatKgRaw<=0` 守卫（出汗量非正时停算），但复核场景因饮水 3000 mL 使 `sweatKgRaw = 70−72+3−0 = +1 kg > 0` 绕过守卫，继续计算。随后 `netLoss = 70−72 = −2 kg`（净增重），`dehyPct = −2.86%`，被 `else if(dehyPct<3)` 误判为「注意/轻微脱水」并给出每小时补液建议——把增重误判成脱水。

## 修复位点
文件：`tools/sports/estimate-35.html`（calc 段，约 line 276-296）
- zone 分类前新增：`if(netLoss<=0){zone='净增重';zoneColor='#60A5FA';zoneDesc='体重净增加（后−前 ≤ 0），无法判定脱水；出汗率估算仅供参考，请核对称重与补液记录。';}`（netLoss≤0 即运动后体重不低于运动前）。
- 补液建议守卫：`if(netLoss>0){ 建议补液 tip } else { ℹ️ 体重净增加，无需额外补液建议 }`，净增重时不再给「每小时约 X ml」误导建议。
