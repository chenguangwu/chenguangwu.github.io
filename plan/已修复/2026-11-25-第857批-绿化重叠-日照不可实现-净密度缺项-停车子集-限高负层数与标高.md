## 修复内容

1. **绿化覆盖率 树冠与绿地重复计数**（`green-ratio.html`）
   - 新增“绿地与树冠重叠面积”输入（默认 0，留空按 0 并提示可能高估）。
   - 覆盖率改用并集 `green + canopy − overlap`；校验总面积 >0、绿地/树冠 ≥0、绿地≤总用地、树冠≤总用地、重叠≤min(绿地,树冠)、并集≤总用地，失败清空结果并提示。
   - 结果明细显示 `(green + canopy − overlap) ÷ total`，不再直接把两者相加。

2. **日照间距 超出当日日长的目标仍计算**（`calc-spacing.html`）
   - 先算当日理论日长：极夜（日长≈0）提示“当日无日照”；目标时长 > 日长时提示“超过当日理论日长，目标不可实现”，不再用周期三角函数给出有限间距。
   - 结果附注模型范围：正午对称、单一建筑高度、无其他遮挡，需专业复核；公式说明补“T 必须 ≤ 当日理论日长，极夜无解”。

3. **人口密度 居住面积缺失仍判定符合**（`population-density.html`）
   - 居住用地面积留空/≤0 视为缺失：净密度显示 `--`、校核显示“未完成校核”、结果明确“不输出符合/超标”，`ok=false`。
   - 校验总用地 >0、常住人口 >0；居住用地 >0 时不得大于总用地。

4. **停车配建 无障碍与访客车位子集矛盾**（`parking-ratio.html`）
   - 校验建筑面积/配建指标 >0、访客比例 0–100%、无障碍比例 0–10%、单车位面积 20–50 m²。
   - 明确总车位 = 常规 + 访客；无障碍车位计入总车位、不另加总数，优先从常规车位划出，常规不足时从访客车位划出；访客 100% 时常规为 0，无障碍从访客划出，不再出现“常规车位 0 却含 2 个无障碍”。
   - 明细改为“计入总车位，从常规/访客车位划出”，删除“含在常规车位内”的错误表述。

5. **建筑限高 航空标高与建筑高度混淆**（`building-height.html`）
   - 航空模式新增“建筑地面标高”（默认 0）：限制面标高 `H0 + L×slope − safety` 为绝对高程，地面以上可用高度 = 限制面标高 − 地面标高；分别显示两者，层数按可用高度计算。
   - 可用高度 ≤0 时显示禁建/无可用高度，不画楼、不输出正层数。

6. **建筑限高 无空间时出现负层数及满足结论**（`building-height.html`）
   - 楼层模式校验限高 >0、层高 2.4–6 m、室内外高差/女儿墙 0–3 m；可用高度 ≤0（含浮点边界）或层数 ≤0 时清空卡片、显示“无可建楼层”，不再输出负层数或“满足限高”。
