# 第668批：工具页输出区脏值专项扫描

## 目标

第667批扫的是“首个卡片”默认文本，能覆盖大多数工具输出，但部分页面的结果区在 `.result-box`、`#result`、`#output` 等独立容器中。本批只提取这些**结果/输出区域**，再扫 `NaN` / `undefined` / `Infinity` / `[object Object]`，避免被说明文案里的正常关键词干扰。

## 扫描范围

- 全部 **4,634** 个工具页。
- Chrome 无头真机，4 worker 复用页面，默认空态加载。
- 选择器：`.result-box`、`#result`、`[id*="result" i]`、`#output`、`[id*="output" i]`、`.output`、`.result`。
- 排除 `.formula-box`、`.tool-intro`、卡片标题等说明性容器。
- 结果：**1 条命中**，经复核为**假阳性**。

## 命中复核

`tools/finance/compound-interest.html` 的 `.result-box` 内嵌了一段利率口径导航脚本，外层 `#viewFormula` 默认 `display:none`。隐藏容器取 `innerText` 时脚本源码被并入文本，命中脚本里的 `typeof TBKit!=='undefined'`，不是用户可见输出。

真机确认该页默认可见结果正常，无 `[object Object]` / `NaN` / `undefined`。

## 结论

- 4,634 个工具页的**结果/输出区域默认空态无真实脏值**。
- 结合第667批：默认卡片区与结果区两类容器均已覆盖。
- 本批无代码改动，仅记录审计结论；后续若新增结果容器，可复用 `/tmp/b668_outputs.js` 的选择器口径复扫。

## 附带核验

- 静态可访问性扫描（剔除 `<script>/<style>/<textarea>` 代码示例后）：4,931 个工具页仅 0 个真实缺标签输入、0 个无名称按钮、0 个缺 `alt` 图片（唯一命中是 `<textarea>` 内的 HTML 示例）。
- 全站 `target="_blank"` 外链 28 个，全部已有 `rel` 含 `noopener`。
