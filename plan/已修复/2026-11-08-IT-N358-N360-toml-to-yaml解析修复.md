## IT-N358（高）多行 TOML 数组被解析成空数组，依赖列表静默丢失

**失败点**：`parseToml()` 逐行处理，`tVal()` 用 `s.slice(1, s.lastIndexOf(']'))` 取内层；行内没有 `]` 时 `lastIndexOf` 返回 `-1` ⇒ `inner` 为空 ⇒ 直接 `return []`。后续元素行（`"serde",`）又没有 `=`，被 `parseToml` 跳过。

**根因**：没有「跨行续读」概念，TOML 规范允许的换行数组完全没处理。

**修复位点**：`parseToml()` 取值前先判括号平衡（新增 `tDepth()`，识别引号内的 `[`/`]`）：

```js
if(/^\s*[\[\{]/.test(rawVal) && tDepth(rawVal)>0){
  var buf=stripComment(rawVal), guard=0;
  while(tDepth(buf)>0 && i+1<lines.length && guard++<2000){
    i++;
    buf+='\n'+stripComment(lines[i].trim());
  }
  rawVal=buf;
}
```

`tVal()` 的数组分支同时改为 `tSplitTop()` 按**顶层**逗号切分（原 `inner.split(',')` 会把 `["a,b"]`、`[{x=1,y=2}]` 切碎）。

**证据**：`dependencies = [\n  "serde",\n  "tokio",\n]` → 修复前 `dependencies:`（空，YAML 侧等于 null）；修复后 `dependencies:` + `- serde` + `- tokio`。

## IT-N359（中）`C:\temp` 被改成 `C:\` + 制表符

**失败点（输入侧）**：`tVal()` 依次 `replace(/\\n/→换行)`、`/\\t/→制表符`、`/\\"/→引号`，未先处理 `\\`。`C:\\temp` 的第 2 个反斜杠紧跟 `t`，被当成 `\t` 吃掉。

**失败点（输出侧，同一家族的第二个坑）**：`yVal()` 只转义 `"`，不转义 `\`、换行、制表符 ⇒ 即使值对了，YAML 侧写成 `path: "C:\temp"`，任何 YAML 解析器回读仍是「C: + TAB + emp」，数据照样坏。

**修复位点**：
- 新增 `tUnescape(x)`：单次 `/\\(.)/g` 映射（`n t r b f " \`），`\\` 与 `\t` 不会互相污染。
- `yVal()`：先转义 `\`，再转义 `"`、`\n`、`\r`、`\t`。
- `yNeedQ()`：补 `/[\\\n\r\t]/`，含反斜杠/控制字符的字符串必须加引号。

**证据**：
| 输入 | 修复前 | 修复后 |
|---|---|---|
| `path = "C:\\temp"` | `path: "C:<TAB>emp"` | `path: "C:\\temp"` |
| `msg = "line1\nline2"` | 值里真换行，YAML 结构被打断 | `msg: "line1\nline2"` |
| `tab = "a\tb"` | `tab: "a<TAB>b"` | `tab: "a\tb"` |

## IT-N360（中）`[[数组表]]` 下的子表、内联表数据静默丢失

**失败点**：
1. `[pkg.meta]` 分支从 root 逐级 `obj2=obj2[seg]=obj2[seg]||{}` 下钻，走到 `pkg` 时拿到的是**数组**，于是把 `meta` 挂成数组的命名属性 —— 不进 `Object.keys`，`dumpYaml` 看不见，整段丢弃。
2. `dumpYaml()` 的数组分支只用 `yVal()` 输出元素内的值，子表/子数组会变成 `"[object Object]"`。
3. `tVal()` 不认 `{a=1}` 内联表，整串被当普通字符串。

**修复位点**：
- 新增 `tChild(o,k)`：下钻时若当前节点是数组（数组表），自动取**最后一个元素**再挂子键；`[[x]]`、`[x.y]`、点号键三条下钻路径统一走它。
- `dumpYaml()` 数组分支重写：元素是映射时逐键输出，值本身是数组/映射则递归缩进（`pad+'    '`），空映射输出 `-`。
- `tVal()` 新增 `{...}` 分支：`tSplitTop` 切出 `k=v` 片段后递归 `tVal`。
- 新增 `tKeyName()` 统一处理带引号的键（顺带让点号键也走 `tUnescape`）。

**证据**：`[[pkg]]\nname="a"\n[pkg.meta]\nx=1` → 修复前 `pkg:\n    - name: a`（`meta` 消失）；修复后
```
pkg:
    - name: a
      meta:
        x: 1
```
`arr = [{a=1, b="z"}]` → 修复前 `arr: - "{a=1, b=\"z\"}"`；修复后
```
arr:
    - a: 1
      b: z
```
