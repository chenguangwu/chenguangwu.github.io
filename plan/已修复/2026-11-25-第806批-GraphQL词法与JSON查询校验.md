# 第806批：GraphQL 词法与 JSON 查询/校验

关闭 `plan/it/` 5 项：

- GraphQL格式化-负数与小数被插入空格破坏
- GraphQL格式化-展开运算符被拆开
- JSONPath查询-继承属性被当作JSON字段
- JSONSchema生成-对象数组特殊键在合并时丢失
- JSONSchema生成-推断下限可能排除示例
- JSONSchema校验-忽略承诺支持的约束导致错误通过

（含同族 6 个问题点，涉及 4 个工具页面。）

## GraphQL 格式化（`tools/it/graphql-formatter.html`）

- `tokenize()` 重写为完整词法：
  - 整数、负数、小数、指数作为一个数字 token，不再拆成 `- 1`、`1 . 5`；
  - `...` 作为单独 `spread` token，格式化不再输出 `. . .`；
  - 支持 `"""…"""` 块字符串与转义，未闭合时报位置；
  - `$变量`、名称、注释、标点分别识别；非法字符报位置。
- `validateGraphQLTokens()`：括号类型栈、字符串/块字符串闭合、`...` 后必须跟片段名或 `on`、首 token 必须是 `{` 或 query/mutation/subscription/fragment。
- `formatGraphQL()` / `minifyGraphQL()` 输出前重新切词，token 序列必须与原文完全一致，否则拒绝输出，避免格式化改语义。
- 保留原有缩进形态（`query{`、`a{`、闭合行内缩进），既有格式化用例继续通过。

## JSONPath（`tools/it/json-path.html`）

- 子字段查询从 `property in current` 改为 `Object.prototype.hasOwnProperty.call()`：`$.constructor` 对 `{}` 不再误命中继承属性，显式 `{"constructor":1}` 仍可查询。
- 通配符与递归下降改为 `Object.keys()`，只遍历自身可枚举字段。

## JSON Schema 生成（`tools/it/json-schema-generator.html`）

- 负数不再生成臆造的 `minimum: -999999`；仅非负样本保留 `minimum: 0`，确保原始样本自身可通过。
- `properties` 合并映射、`examples` 映射改为 `Object.create(null)`，`__proto__`、`constructor` 等键完整写入，不再触发原型 setter。
- 页面说明同步改为「负数不添加下限」。

## JSON Schema 校验（`tools/it/json-schema-validator.html`）

- 补齐 Draft-07 常用关键字：
  - `enum`、`const`、布尔 Schema；
  - `minimum` / `maximum` / `exclusiveMinimum` / `exclusiveMaximum` / `multipleOf`；
  - `minLength` / `maxLength` / `pattern` / 常用 `format`；
  - `minItems` / `maxItems` / `uniqueItems`、`minProperties` / `maxProperties`；
  - `allOf` / `anyOf` / `oneOf` / `not`、`additionalProperties` Schema、元组 `items`。
- 未支持关键字与 `$ref` 明确提示「未作校验」，不再给出完整通过结论；非法正则也明确报错。
