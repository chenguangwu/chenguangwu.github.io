## 修复清单

1. **正多边形边数允许小数** → `tools/geometry/regular-polygon-area.html`
   - `calcTool()` 增加 `Number.isInteger(n) && n >= 3` 与 `s > 0 && isFinite` 校验。
   - 3.5、2、非有限数均提示“正多边形边数 n 至少为 3（须为整数）……”；结果表与 extras 同步守卫。
2. **抛物线参数缺项视为零** → `tools/geometry/parabola-vertex.html`
   - `calcTool()` 逐项读取 a、b、c 原始值；任一为空提示“请完整填写 a、b、c 三项系数；空白不等于 0”。
   - 显式 `b=0` / `c=0` 保留为合法输入；a=0 仍按一次函数拒绝。
   - 新增 `#parabola_vertexSteps`、`<canvas id="parabola_vertexPlot">`、`__pvFmt`、`__pvClear`、`__pvDraw`：绘制网格、坐标轴、抛物线、顶点标注，按输入自适应视野，大数用科学计数法，非法输入清空步骤与画布。
3. **多边形边数允许非整数及小于三** → `tools/geometry/polygon-interior-angle.html`
   - `calcTool()` 在 `__tbInputGuard` 后增加 `!Number.isInteger(n) || n < 3` 分支，提示“边数 n 须为不小于 3 的整数”，并清空结果表。
   - extras 同步守卫，避免附加表残留。
4. **球体面积体积比边界错误** → `tools/geometry/sphere-surface-area.html`
   - 删除 `Math.max(volume, 1e-9)` 钳制；`r0 > 0` 用真实体积计算比值。
   - `r=0` 时比值显示“不适用（r=0，体积为 0）”；结果表与 extras 表同步。
5. **二维点积缺项及投影标注** → `tools/geometry/dot-product-2d.html`
   - 四个坐标空白时提示“请完整填写向量 a 与 b 的四个坐标；空白不等于 0”，不再把缺项当 0。
   - `b=0` 不再整页提前返回：保留点积结果，投影显示“有符号标量投影（b 为零向量，|b|=0，无定义）”。
   - 非零 b 标签改为“a 在 b 上的有符号标量投影”，允许负值。
6. **柱体及圆台缺项被视为零** → `tools/geometry/cylinder-volume.html`、`tools/geometry/cone-frustum-volume.html`
   - 圆柱：读取 r、h 原始值；空白提示“请填写底面半径 r 与高 h；空白不等于 0”；负数/非有限提示“半径 r 与高 h 须为非负有限数”；extras 用 raw 守卫。
   - 圆台：空白提示“请完整填写上底半径 R、下底半径 r 与高 h；空白不等于 0”；h≤0、负半径、两半径同时 0 提示“高 h 必须大于 0，且两底半径不能同时为 0。半径须为非负有限数”；extras 同步。
7. **坐标工具增加动态示意** → `tools/geometry/midpoint-2d.html`、`tools/geometry/parabola-vertex.html`
   - 中点页新增 `#midpoint_2dSteps` 与 `<canvas id="midpoint_2dPlot">`，`__mpDraw` 绘制 P1/P2/M、虚线线段、蓝色半段、红色中点与坐标标签；重合点显示“线段退化，M=P1=P2”；大数用科学计数法，输入非法清空画布与步骤。
   - 抛物线页同上，代入步骤含 x_v、y_v、对称轴与开口方向；两页动态标签按 `document.documentElement.lang` 输出中/英，避免英文态新增中文。
8. **圆弧扇形允许负尺寸** → `tools/geometry/arc-length.html`、`chord-length.html`、`sector-area.html`
   - 有限检查后增加 `r < 0 || deg < 0 || deg > 360` 分支，提示“半径 r 须为非负有限数，圆心角须在 0–360° 之间；本页按给定圆心角计算，不做大弧选择”，并清空对应结果表。
   - extras 同步守卫。
9. **椭圆等面积圆指标公式错误** → `tools/geometry/ellipse-area.html`
   - 等面积圆面积由 `π√(ab)` 改为 `πab`，标签“等面积圆面积 πab（半径=√(ab)）”；结果表与 extras 同步。
   - 增加 `a>0 && b>0` 有限校验，负半轴拒绝。
10. **向量与点线距离缺项被当成零** → `tools/geometry/angle-between-vectors.html`、`tools/geometry/point-line-distance.html`
    - 夹角页四坐标空白提示“请完整填写两个向量的四个坐标；空白不等于 0”；extras 用 raw 守卫。
    - 点线距页 A/B/C/x₀/y₀ 空白提示“请完整填写 A、B、C、x₀、y₀；空白不等于 0”；extras 同步，并补 A=B=0 直接返回。
