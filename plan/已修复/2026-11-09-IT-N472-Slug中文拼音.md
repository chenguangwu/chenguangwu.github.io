# IT-N472：高级 Slug 生成器中文被静默丢弃

- 原问题：仅 59 个汉字有拼音，其他汉字被丢弃，且已知字音节粘连；自带示例与结果不符。
- 修复：`tools/it/slug-generator-advanced.html` 使用本地 `pinyin-pro` 3.29.5 按连续汉字上下文转写，音节及中英文边界按所选分隔符分隔；未知汉字转为 Unicode 码点并明确提示，依赖加载失败时显示错误。拼音库及 MIT 许可随站发布，npm 版本锁定；同步中英文说明及 README。
- 验证：`node scripts/verify_slug_pinyin.cjs` 覆盖世界、博客标题、人工智能技术、产品发布、混合中英、重庆银行、多字符分隔符、未知字符和库加载失败；`node scripts/verify_it_calc.js slug-generator-advanced` 6/6 通过。本地 Chrome 中英文态实测 `Hello 世界!` → `hello-shi-jie`、`重庆银行` → `chong-qing-yin-hang`、`𠀀龘` → `u20000-da` 并显示提示，无页面异常。
- 完整门禁按用户本轮要求暂未运行；未推送、未线上验证。多音字结果依赖词库及上下文，页面提示使用前核对。
