# 第887批：会计零分母、负盈利与周转口径

日期：2026-11-26
范围：4 个扫描任务 / 16 个工具页

## 修复清单

1. **利润与现金流零分母/负数**（`accounting/ebit`、`ebitda`、`free-cash-flow`、`gross-margin`、`gross-profit`、`operating-cash-flow`）
   - 删除 `Math.max(分母,1)` 与 `(分母||1)` 兜底：分母非零时保留原值与符号，为零时比率显示 `—`。
   - 收入为 0 的毛利率、收入/成本倍数等明确不适用；收入、成本、费用负值拒绝。
   - 真机：OCF=-50、capex=20 ⇒ FCF=-70、资本支出占比 -40%、覆盖倍数 -2.500；收入 100、成本 150 ⇒ 毛利率 -50%（成本率 150%）。

2. **会计比率零分母**（`debt-to-asset`、`working-capital`、`asset-turnover`、`current-ratio`）
   - 权益乘数在权益为 0 时显示 `—`；流动比率在流动负债为 0 时显示 `—`；资产收入倒数与周转天数在收入为 0 时显示 `—`。
   - 移除守卫中把这些零分母一律拒绝的 `__D` 配置，允许「无定义」展示；资产/负债范围仍校验。
   - 真机：资产=负债=800 万 ⇒ 权益乘数 `—`；流动负债 0 ⇒ 流动比率 `—`；收入 0 ⇒ 两个倒数指标 `—`。

3. **收益比率负盈利**（`interest-coverage`、`roa-calc`）
   - 利息费用必须大于 0，零利息时保障倍数无定义；EBIT 为负时保障倍数保持负号。
   - ROA 直接使用有符号净利润与期末资产，负数不再被 `Math.max(np,1e-9)` 夹成正极小值。
   - 真机：净利 -35 万、资产 500 万 ⇒ ROA=-7.00%、资产/净利=-14.2857。

4. **周转天数小额分母与年度口径**（`days-payable-outstanding`、`days-sales-outstanding`、`inventory-days`、`inventory-turnover`）
   - 删除 `Math.max(余额,1)`：0.5 万元应付也能得到真实 DPO 与周转率，零余额时周转率显示 `—`。
   - 结果表新增「365 天/年；输入须为年度发生额，余额宜用期间平均余额」口径说明；月均周转明确按 12 个月/年。
   - 真机：应付 0.5 万、成本 100 万 ⇒ DPO=1.8 天、周转率 200 次/年（旧实现会按 1 万得到 1.0 天）。
