## 处理项

### D-N168 承诺「拖动控件调整偏移、模糊、扩散、颜色」，实际只有 1 个「生成数量」输入（高，已修·按实现兑现）

- 文件：`tools/design/generator-6.html`
- 根因：meta / 简介 / 公式框均写「可视化调整」阴影参数，实际 `input` 只有 `#cnt`，x/y/blur/spread/color/inset/层数全部由 `Math.random` 决定，用户无法得到目标阴影，只能反复随机。
- 改动：
  - 新增 9 个控件：`#sx` 水平偏移、`#sy` 垂直偏移、`#sb` 模糊、`#ss` 扩散（均「留空随机，填写即固定」，带 min/max 夹取）、`#sc` 颜色 + `#scc` 配色方式（随机 10 色板 / 使用所选颜色）、`#si` inset（混合 20% / 全部内 / 全部外）、`#sl` 每层数（1–4）、`#mode` 生成模式。
  - `gen()` 改为「填了就固定、留空才随机」，并保持随机调用顺序与旧实现完全一致（inset → x → y → blur → spread → color → alpha），避免打乱既有种子序列导致历史用例假红。
  - 预览色块 `background:#fff` → `var(--card-bg,#fff)`（同 D-N203 的深色主题白块问题）。
  - 公式框「工作原理」段同步改写（含「填 0 表示 0，与留空随机不同」的口径）。
  - 事件改 `addEventListener`（`__bindG6()` 统一绑 `input`/`change`），移除 `#cnt` 的内联 `onchange`。
- 验证：`G6FIX n=4 inset=N`（`cnt=1, sx=10, sy=-6, sb=18, ss=2, sl=2, si=no, scc=fix, sc=#ff6b35` → `10px -6px 18px 2px rgba(255, 107, 53,` 出现 4 次 = 2 层 × 2 处载体（CSS 代码块 + 预览内联样式），且全页无 inset）。旧码 n=0 ⇒ 红。

### D-N169 「层级体系」预设只是随机条数，不构成有序 elevation（中，已修）

- 文件：`tools/design/generator-6.html`
- 根因：预设仅设 `cnt`，`gen()` 每条独立随机 1–3 层、偏移/模糊/扩散/透明度全随机 ⇒「8 组（层级体系）」产出互不相关、可能倒序的样式，连点两次整批重掷，无法沉淀为设计系统 elevation scale。
- 改动：
  - 新增 `#mode` 生成模式：`rand` 随机混合 / `scale` 层级递增。
  - `scale` 模式第 i 条（1-based）固定：offset-x 0、offset-y i、blur 2i+2、spread 0、透明度 `0.15 − 0.006i`（下限 0.05）⇒ 严格单调递增的 elevation 阶梯。
  - 预设改为「随机混合 / 3 组阴影（轻量卡片）/ 8 级层级体系 / 15 级完整规范 / 内阴影强调（3 组）」，层级类预设带 `mode:scale, sl:1, si:no`，点击结果可复现且递增。
- 验证：`G6SCALE a=Y c=Y`（`cnt=3, mode=scale, sl=1, si=no` → 第 1 条 `0px 1px 4px 0px rgba(0, 0, 0, 0.14)`、第 3 条 `0px 3px 8px 0px rgba(0, 0, 0, 0.13)`，同时锚定偏移/模糊递增与透明度递减）。旧码无 `mode` 控件 ⇒ 两条均不命中 ⇒ 红。
