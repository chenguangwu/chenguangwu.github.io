# 第744批：时间戳秒精度、动态英文、日期加减校验与 DST 口径、透明背景导出

- 日期：2026-11-24
- 范围：IT 工具 2 个页面（5 项任务）
- 验证：`node scripts/verify_it_calc.js` **1960/1960**；Puppeteer 真机（America/New_York 时区，端口 8167）通过。

## 修复项

1. **毫秒转秒丢失小数**
   - 新增 `formatSecMs(ms)`：毫秒→秒最多保留 3 位小数并去除尾零；秒→毫秒使用 `Math.round`。
   - `fromTimestamp`、`fromDate`、`smartConvert`、`quickTs`、`renderResults` 的 Unix 秒字段统一走该函数，正负毫秒均不再被 floor。
2. **动态结果英文态仍为中文**
   - 新增 `tsEn()/tsT()/tsLocale()`，按 `TBKit.util.isEn()` 或 `I18n.get()` 判定语言。
   - 转换结果标签、本地日期/时间 locale、星期、复制按钮、快捷时间、日期加减/差值、历史空态与加载按钮均动态双语；监听 `toolbox:langchange` 重绘转换结果、历史、日期计算与快捷结果。
3. **日期加减数量被静默截断**
   - 数量改为完整 `Number` 校验：空值不输出结论；仅允许 0–100000；天/周/月/年必须整数；小时/分钟允许小数；负数拒绝并提示改用“减”。
   - 输入 `0` 合法；不再使用 `parseInt(value) || 0`。
4. **跨夏令时时分加减口径不清**
   - 小时/分钟改为 `new Date(start.getTime() + deltaMs)`，按真实经过时长计算。
   - 天/周/月/年继续按当地日历 `setDate/setMonth/setFullYear`，结果区说明跨 DST 可能经过 23/25 小时；目标时刻不存在时按浏览器规则顺延到下一有效时刻。
5. **透明背景对比度页面拒算但导出仍给结论**
   - `__ccExport` 在 `bg.a < 1` 时不再计算/输出 WCAG 项，只写“不导出：背景含透明度，请先指定不透明底色再计算”（英文同义）。
   - 不透明背景仍保持原有前景 alpha 合成与 WCAG 输出。

## 测试与真机

- 自动化新增 3 条：毫秒/秒双向精度、英文动态标签、导出透明度守卫；通过 1960/1960。
- 数量校验与 DST 因测试桩 Date 构造限制改用 Puppeteer 覆盖，未强行加入桩用例。
- 真机结果：1234ms→1.234s、-1234ms→-1.234s；英文结果 `Unix seconds/Copy`；空数量报错、1.5 天报整数错误、1.5 小时得 01:30；纽约时区 2024-03-10 01:30 +2 小时 = 04:30（真实 2 小时）；+2 天按日历到 03-12 01:30 并提示 DST 规则；透明背景导出无 WCAG 结论。
