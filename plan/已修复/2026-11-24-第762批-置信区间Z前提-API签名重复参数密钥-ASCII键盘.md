# 第762批修复记录（2026-11-24）

## 1. 置信区间：大样本自动选 z 缺少「σ 已知」前提
- **问题**：自动模式只按 `n≥30` 切 z，但输入框实际收的是样本标准差 s；σ 未知时 z 区间把 s 当 σ 用，区间系统性偏窄且没有任何提示；明细只在 95% 时露出自由度。
- **修复**（`tools/it/confidence-interval.html`）：
  - 新增「标准差来源」下拉 `#stdType`，默认「样本 s（σ 未知）」，可选「已知总体 σ」。
  - 自动模式改为 `useT = dist==='t' || (dist==='auto' && stdType!=='population')`；只有总体 σ 已知才用 z，大样本不再仅凭 n≥30 自动切 z。
  - 标签与明细明确展示前提：t 显示「自由度 df=n−1」，z 显示「总体 σ 已知」或「近似：总体 σ 未知，以样本 s 代替」。
  - 明细新增独立一行「自由度 df = n−1 = … / 前提：…」，不再依赖 95% 临界值括号。
  - 公式区、info-box 同步说明「σ 已知→z；σ 未知→t；手选 z 属近似」。
- **回归**：旧 n=30 默认态期望从 z `[94.632,105.368]` 改为 t `[94.398,105.602]`（df=29，t≈2.0456）。

## 2. API 签名：重复参数和特殊字符被静默改变
- **问题**：参数解析把行内值 `trim`，重复 key 后写覆盖前值，缺 `key=` 的段直接跳过；用户看到的参数与实际参与签名的内容不一致。
- **修复**（`tools/it/api-sign-generator.html`）：
  - 新增 `parseParamEntries()`：按行或 `&` 分段；空段、缺 `=`、key 首尾空白、重复 key、无参数均抛明确错误；值不 trim、不做 URL 编解码；重复 key 提示「合并、改名或删除」。
  - 值里的 `&` 明确提示写成 `%26`，或改为每行一个参数。
  - `runSign()` 使用 entries 按 key 排序生成规范化串；失败时输出错误、`#paramNote` 标红「签名未生成」，不再产出看似正常的签名。
  - 参数区新增常驻提示，说明「值原样参与签名、不做 URL 编码、重复 key 直接报错」。

## 3. API 签名：复制签名与历史摘要可能泄露密钥
- **问题**：结果区显示含 `secret` 的待签名串，「复制签名」复制整块文本；历史快照也会带上密钥相关字段。
- **修复**：
  - 密钥输入改为 `type=password`，新增「显示/隐藏密钥」按钮，默认隐藏。
  - 输出只展示「规范化串（参与签名）」+ 算法说明 + `#signValue` 签名值；HMAC 明确「消息=规范化串，密钥单独作为 HMAC key」，MD5 说明实际输入含密钥但界面不显示含密钥的串。
  - `copyResult()` 只复制 `#signValue` 的签名值，绝不带规范化串或密钥。
  - 一次性清理旧历史（`apiSignHistPurgedV2`），避免旧快照继续保留密钥摘要。

## 4. API 签名：HMAC 展示的待签名串与计算不符
- **问题**：HMAC 实际以规范化串为消息、密钥为 HMAC key，界面却展示 `规范化串&secret=密钥`，展示值与真实输入不一致。
- **修复**：按算法分别展示；HMAC 不再出现 `&secret=` 拼接串，只显示规范化串和「密钥单独作为 HMAC key」说明；MD5 单独说明实际输入含密钥但密钥不显示。同步修正公式区、深潜算例与页面描述。

## 5. ASCII 码表：字符卡片缺少键盘访问
- **问题**：字符卡片是带 `onclick` 的 `div`，无法 Tab 聚焦、Enter/Space 触发；点击卡片还会自动复制，想只看详情也会写剪贴板。
- **修复**（`tools/it/ascii-table.html`）：
  - 卡片改为原生 `<button type="button" class="ascii-card" onclick="showDetail(i)" aria-label="…">`，内部改用 `span`；CSS 补 `appearance:none`、`width:100%`、`:focus-visible` 3px outline。
  - 查看与复制拆分：点击/回车只渲染详情；详情内新增独立「复制十进制编码」按钮，`copyAsciiCode(code)` 才写 `data-copied` 并 toast 成功/失败/不支持。
  - aria-label 按语言生成英文/中文；元描述与分类页简介改为「支持键盘查看字符详情并单独复制十进制编码」。
