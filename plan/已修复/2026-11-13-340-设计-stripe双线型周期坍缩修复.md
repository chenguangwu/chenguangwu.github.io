# 第340批·stripe-pattern 双线型周期坍缩修复（D-N164）

## 根因（确证）
`stripe-pattern.html::generate()` 的 `double` 分支内部停点写死 `w+3` / `w+6`：
```js
css = `...${c1} ${w}px, ${c2} ${w}px, ${c2} ${w+3}px, ${c1} ${w+3}px, ${c1} ${w+6}px, ${c2} ${w+6}px, ${c2} ${w*2}px`;
```
当 `w<6` 时 `w+6 > w*2`，`repeating-linear-gradient` 按规范把逆序停点抬到前一值（钳制），末段 `c2` 变零宽、重复周期坍缩为 `w+6` 而非公式框承诺的 `2w`。
- 复现：w=2 → 实际周期 8（期望 4）；w=5 → 实际周期 11（期望 10）。与 formula-eq「色二 宽度+6→2×宽度」自相矛盾。

## 改动
1. `tools/design/stripe-pattern.html` 双线分支改为细线宽随 `w` 等比缩放、周期恒 `2w`：
```js
} else if(type === 'double'){
  const dt = Math.max(1, Math.round(w*0.4));
  css = `background: repeating-linear-gradient(${angle}deg, ${c1}, ${c1} ${w}px, ${c2} ${w}px, ${c2} ${w+dt}px, ${c1} ${w+dt}px, ${c1} ${w+2*dt}px, ${c2} ${w+2*dt}px, ${c2} ${w*2}px);`;
}
```
（`2*dt ≤ 0.8w < 2w`，停点严格单调，任何 w≥2 周期均恒为 2w）
2. 同步 `formula-eq` 双线说明为「周期恒为 2×宽度，内部两条细线宽随宽度等比缩放（约 0.4×宽度、下限 1px），窄宽度下周期不再坍缩」，消除误导。
