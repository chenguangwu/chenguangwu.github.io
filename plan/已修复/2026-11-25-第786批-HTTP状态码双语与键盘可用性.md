## 改动

### `tools/it/http-status.html`

- 55 条状态码全部补齐 `descEn` / `detailEn`，英文态列表、详情与 CSV 导出均按语言取值；搜索同时匹配中英文摘要与详情。
- 状态卡由 `div` 改为原生 `button`，带 `data-code`、`aria-expanded`，点击/Enter/空格均可展开，并提供 `:focus-visible` 焦点环。
- 403 按 RFC 9110 15.5.4 改为「服务器理解请求但拒绝履行」，明确「已认证但权限不足」只是常见情形；401 详情同步改为「缺少有效认证凭据」，不再把 403 绝对等同权限不足；FAQ 同步。
- 新增 499 `Client Closed Request` 条目，明确标注「Nginx 自定义、非标准 HTTP 状态码」，可按 499 搜索，并归入 4xx 分类。
- 顺带修复 `.s1xx` / `.s3xx` 的无效 CSS 属性名 `border-left-`。

### `tools/it/http-headers.html`、`tools/it/http-methods.html`

- `renderCategories()` 由 `div` 改为 `button type="button"`，带 `aria-pressed` 选中态；点击后重建分类并把焦点还给当前选中按钮，键盘 Tab/Enter/Space 可用。
- 增加 `.category-tab:focus-visible` 焦点环与 `font-family:inherit` 重置。

### 数据与测试

- `i18n/tools/en/it/http-status.json` 增补 401/403 新文案、499 摘要与详情英文映射。
- `scripts/verify_it_calc.js` 新增 4 条用例：499 数据、403 语义、HTTP 头分类按钮、HTTP 方法分类按钮。
