# 第965批：声学波长双页正数守卫、量级精度与固定介质预设

## 问题

- `tools/acoustics/wavelength-frequency.html`、`tools/acoustics/wavelength-from-freq.html` 只检查输入是否填写：波速/频率或声速/频率为 0、负数时仍输出 `Infinity`、负波长或零；扩展表、图表与历史记录继续生成。
- 主结果、扩展表固定四位 / 两位 / 三位小数；高频合法正波长小于显示精度时显示 `0.0000`，与角波数、空间频率不一致。
- 主结果与扩展表行名固定中文，英文态仍显示中文。
- 两页预设同时按比例改波速和频率，波长不变，无法直观看到频率变化的影响。

## 修复

- 两页新增统一 `__wfValidate` / `__wlfValidate`：空值、非有限、0、负数一律拒绝，提示“必须为大于 0 的有限数值（不能为 0 或负数）”；输入框标 `input-error`。
- 主结果与扩展表共用校验；无效时清空明细表、倍频程表、图表和对比区，不再写入历史记录。
- 新增 `__wfFmt` / `__wlfFmt`：正常量级保持原小数位；按当前小数位四舍五入为 0 的合法非零值改用科学计数法（4 位有效小数），主结果、扩展表、图表数据一致。
- 主结果与扩展表的行名按 `TBKit.util.isEn()` 输出中英文；英文态导出 CSV 同步为英文表头/行名。
- 预设改为固定介质下的频率对照：空气 440 Hz / 20 Hz / 40 kHz；空气 1 kHz / 水中 100 kHz / 钢中 1 MHz，避免波速与频率同比例变化造成波长不变的误导。
