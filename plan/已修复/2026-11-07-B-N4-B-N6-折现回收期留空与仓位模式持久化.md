# 2026-11-07 · 金融-投资/证券（B-N4 + B-N6）：折现回收期留空/非法参数与逐期明细、仓位历史先恢复计算模式

## 条目
- **B-N4**（高，原：`plan/categories/02-金融财务/banking-investment-securities.md:71`）
  `discounted-payback.html` 的 `num()` 把空输入转成 0：清空 CF₀、其余 500/500/500、r=10% 时显示「0.00 年」；CF₀=−1000、r=−100% 时折现分母为 0，却给出「未回收」。没有任何逐期折现明细，导出的是历史摘要表而非当前计算。
- **B-N6**（中，原：同文件 `:84`）
  `position-sizing.html` 的历史记录不保存 `currentTab`：切到凯利模式后恢复一条固定风险记录，会**按当前模式**重算，方案无法复现；导出同样是截断的历史摘要。

## 根因
1. B-N4：`num()` 是 `parseFloat(...)` 的 NaN→0 兜底，**无法区分「用户留空」与「用户显式填 0」**；`cf0=0` 时 `cum=0>=0` 立即命中 `i===0 → yr=0`，于是「未填完」被包装成「0 年回本」这一投资结论。`r=−100%` 使 `(1+r)^i = 0`（i≥1），`cum` 变 `Infinity`/`NaN`，`yr` 分支不成立 → 落到「未回收」，把数学无定义伪装成「收不回」。
2. B-N6：`__position_sizingSnap()` 只扫 DOM 里的 `input/select/textarea`，**单选式 tab 不是表单控件**，所以 `currentTab` 天然进不了快照；恢复回调又只按 id 回填元素值后直接 `calc()`，`calc()` 按**当时**的 `currentTab` 分派 → 凯利记录被固定风险公式重算。
