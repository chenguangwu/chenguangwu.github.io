# 第981批：CSV 非法引号不再静默接受

## 问题

`tools/it/csv-to-json.html` 的 `parseCSV()` 与 `tools/it/markdown-table-generator.html` 的 `parseCsvLine()` 都只跟踪是否处于引号内，没有记录「引号已闭合」状态：

- `"a"b,c` 被静默拼成 `ab`；
- `a"b,c` 把未引用字段内的引号当普通字符保留；
- 引号闭合后跟空格或其他字符也不报错。

两页都只处理未闭合引号，非法位置没有行列信息。

## 修改

### `csv-to-json`

- 新增 `fieldClosed`、`column`、`quoteStartColumn` 状态。
- 闭合引号后只允许「分隔符 / LF / CR / 输入结束」，否则抛出：
  - 中文：`第 X 行第 Y 列：引号闭合后只能接分隔符或换行，不能有其他字符`
  - 英文：`Line X, column Y: a closing quote must be followed by the delimiter or a line break`
- 未引用字段内出现引号，抛出「未加引号的字段中不能出现引号」并给出行列；合法写法提示为整体加引号 + 字面引号写两个。
- 未闭合引号提示补上起始列：`第 X 行第 Y 列有未闭合的引号`。
- 分隔符、LF、CR 分支同步重置 `fieldClosed` 与列号。

### `markdown-table-generator`

- `parseCsvLine(line, lineNo, isEn)` 新增 `closed`、`quoteStart` 状态与行列定位。
- 闭合引号后非逗号字符报错；未引用字段内引号报错；未闭合引号给出行列。
- 错误对象同时提供 `error` / `errorEn`，英文态不再输出中文「行 / 列」。
- 调用处表头传第 1 行、正文按 `idx + 2` 传行号；错误尾注从「请先补全引号再生成」改为「请修正引号后重试」。

## 真机验证

Chrome headless，两页中英文态：

| 输入 | csv-to-json | markdown-table-generator |
|---|---|---|
| `"a,b",1` / `"x""y",2` | 正常，字段 `a,b`、`x"y` | 正常，单元格 `x,y` |
| `"a"b,1` | 拒绝：第 2 行第 4 列 | 拒绝：第 2 行 4 列 |
| `a"b,1` | 拒绝：第 2 行第 2 列 | 拒绝：第 2 行 2 列 |
| `"a" ,1` | 拒绝：闭合引号后有多余字符 | 同规则拒绝 |
| `"a,1` | 拒绝：第 2 行第 1 列未闭合 | 拒绝：第 2 行 1 列 |
| `"a\nb",1` | 正常，保留字段内换行 | 逐行输入不支持跨行，维持原行为 |
| `"",1` | 正常，空字符串字段 | — |

英文态实测：

- `Conversion failed: Line 2, column 4: a closing quote must be followed by the delimiter or a line break`
- `CSV input error: line 2, column 2: a quote appeared inside an unquoted field. Fix the quotes before generating.`

两页无 `pageerror`。
