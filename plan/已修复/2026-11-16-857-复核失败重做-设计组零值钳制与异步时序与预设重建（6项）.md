## 1. 第 412 批 · 图片解码校验与记忆训练语言残留（两项）
- base64-to-image.html：引据表宣称「应校验魔数字节与声明 MIME 一致」，但实现只对无前缀输入 sniffMime、不比较声明 MIME 与魔数。按复核给的诚实路径，把引据表改为明确注意事项「本页仅对无前缀输入按魔数推测格式，不校验 data URI 声明 MIME 与魔数一致性」（中英 data-zh 双语同步），不再作未实现承诺。
- number-memory.html：训练记录日期固定 `toLocaleString('zh-CN')`，英文态仍是中文地区格式。改为按 `TBKit.util.isEn()` 选 `en-US`/`zh-CN`。

## 2. 第 317 批 · 色觉工具参数恢复与控件同步（D-N110 / D-N102）
- D-N110：cvd-safe-palette.html 的 `cvRestore()`（页面 IIFE 外）直接调 IIFE 内的 `generate()/renderResult()` 抛 ReferenceError 被 catch 吞掉，恢复参数后画面不重算。改为调用已有的可访问入口 `cvAfter()`（点击生成按钮触发 IIFE 内重算）。
- D-N102：colorblind-simulator.js 的 HEX 输入事件调 `setColorFromRgb(c, true)`，true 表示跳过取色器回写，导致手输 HEX 后取色器仍留旧色。改为 `false`（同步取色器）；取色器自身 input 仍传 true 避免双向死循环。

## 3. 第 318 批 · 频谱与波形零值钳制
- waveform-visualizer.html：`parseFloat(amp) || 0.8` 把数值 0 当假值回落到默认 0.8，未按范围钳到下限 0.1。改为先 `parseFloat`、用 `Number.isFinite` 区分空/非法与 0，0 走 clamp → 0.1。
- spectrum-visualizer.html：`parseInt(bars) || 48` 同理 0→48 而非下限 8。改为 Number.isFinite 分支，0 → 8。

## 4. 第 320 批 · 网格渐变三色预设补齐色块
- 根因：`__mesh_gradientPresets` 回调逐个读现存 color0..color2 控件，两色状态（removeColor 后）第三色块不存在，三色预设退化为两色；从五色状态则缩为三色。
- 修复：每个预设携带完整色数组 `_cols`，由闭包直接 `colors = active._cols.slice(); renderColors();` 重建全量色块；`preset.bar` 的 after 无参数且早于 active 类设置，故用 color0 控件值匹配当前预设。验证两色状态应用预设回到三色。

## 5. 第 321 批 · 进度条预览动画覆盖与终点固定
- 根因：静态 `.progress-animated{animation:progressAnim}` 覆盖 `.progress-striped` 的 animation，静态 @keyframes 终点固定 100%；动态关键帧只写进 cssOutput 文本未应用到预览。
- 修复：generate() 在预览 DOM 内联注入按 pct 的动态关键帧 `pbFill`（终点=pct、中点=pct×0.8）与 `pbStripes`，bar 用 inline `animation` 覆盖静态类，条纹与宽度动画共存。导出 CSS 逻辑不变。
