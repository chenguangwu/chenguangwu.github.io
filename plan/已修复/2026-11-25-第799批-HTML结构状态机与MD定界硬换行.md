## 改动

### HTML 嵌套检查器

`tools/it/html-nesting-checker.html`：

- 删除「正则扫一遍 → 重置 → 再扫一遍」的旧实现，改为 `htmlTagAt()` + `scanHtml()` 单遍状态机：
  - 跳过 `<!-- -->` 注释、`<!DOCTYPE>` / `<?...>` 声明；
  - 标签扫描尊重单/双引号，属性值里的 `<span>` 不当作标签；
  - `script/style/textarea/title` 作为原始文本元素成对处理：开始标签后直接跳到对应 `</name>`，脚本体与样式体不参与标签扫描；
  - 自闭合 `/ >` 与 void 元素不入栈；闭合标签按栈匹配并报告隐式闭合，保留行号。
- `htmlTagAt()`、`scanHtml()` 加空参守卫，兼容 verify 的 fallback 无参调用。

### HTML 转 Markdown

`tools/it/html-to-markdown.html`：

- 新增 `longestBacktickRun()`：统计内容中最长连续反引号。
- 行内 `CODE` 改为 `inlineCode()`：定界符长度 = 最长连续反引号 + 1；内容以反引号/空格开头或结尾时两侧补一个空格（CommonMark 规则）。
- `PRE` / `PRE>CODE` 改为 `fencedCode()`：围栏长度 = max(3, 最长连续反引号 + 1)，内容含独立 ``` 行时自动用 ```` 包围。
- 保留末尾换行清理与块级空行。

### Markdown Lint

`tools/it/markdown-lint.html`：

- 新增 `#allowHardBreak` 复选框（默认勾选）：「将行尾恰好两个空格视为合法硬换行（MD009 豁免；取消勾选则按普通尾随空格报错）」。
- 行尾检查改为先捕获 `([ \t]+)$`：仅当勾选、恰好两个空格、且行非空时视为 CommonMark 硬换行；1 个、3 个以上、制表符、空行尾随空格仍报 MD009。
- `mlEn()` 增加 `location.search` / `documentElement.lang` 兜底，英文态下动态检查消息真正走英文分支。
- 更新工作原理、检查项说明与英文词典，明确硬换行可配置。

`i18n/tools/en/it/markdown-lint.json`：补复选框、检查项、硬换行公式与动态消息英文键。
