## 1. 改模板真源 `scripts/_ux_wire.py`

F-N189 的三个失败点只存在于 **custom 模式**（`gen_custom_render` 与 `apply_custom` 里的 ResText / Extras / Export），classic 模式记录的是数值字段、无 `rk` 文本图表、不受影响 ⇒ **只改 custom，classic 一行未动**。

| 位点 | 改动 |
| --- | --- |
| `gen_custom_render` head | 加动态双语结论列 `en?'Verdict':'结论'` |
| `gen_custom_render` rows | 由 `__tbScore` 推「通过 / 未通过」（EN `Pass / Fail`），缺值 `-` |
| `gen_custom_render` mount | `if(k===rk\|\|k==='__tbScore') continue;` 跳过内部字段回填 |
| `gen_custom_render` 图表 | 数值源改 `parseFloat(arr[j].d.__tbScore)`，更名「有效性趋势 / Validity trend」 |
| `apply_custom` ResText | 旧正则 `/请输入\|无效\|不正确\|错误\|Error\|NaN/` → 只过滤空态前缀 `/^(等待输入\|请输入文本\|Waiting for input\|Please enter text)/` |
| `apply_custom` 新增 | `__<pre>Score(t)` 数值结论单一真源（失败 0 / 通过 1） |
| `apply_custom` Extras | 写 `rec.__tbScore=__<pre>Score(res)` |
| `apply_custom` Export | 无 `<tr>` 时先按当前快照调 `Render()` 补渲染，再 `exportTable` |

用 Python 脚本做**位置感知的精确替换**：`gen_custom_render` 的 5 处全文唯一；`apply_custom` 的 4 处先按 `def apply_custom` 切分、只在后半段替换（避免误伤 classic 区同形的 `window.__%sExport`）。每处 `assert count==1`，9 处全部通过。

**源与产物同源验证**：`importlib` 载入改后的 `_ux_wire.py`，调 `gen_custom_render('cnpj_validator','validate')` 生成 1757 字符，与已修 `tools/finance/cnpj-validator.html` 的 Render 段**逐字一致**；`python3 -m py_compile` 语法 OK；断言 classic 区不含 `Score` / 补渲染等新代码。`_build.py` 不调用 `_ux_wire.py`（第 41 批已核）⇒ 改源不影响线上任何字节，只防止未来手动重 wire 时把旧缺陷注回去。
