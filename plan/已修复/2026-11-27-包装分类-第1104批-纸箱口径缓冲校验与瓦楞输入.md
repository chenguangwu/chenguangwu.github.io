## 一、纸箱尺寸：空间利用率口径与校验说明

对应任务：`纸箱尺寸-空间利用率口径与校验说明.md`

原“空间利用率”实际是“产品外接尺寸乘积 ÷ 外箱外体积”，分母含纸板与缓冲，容易被误读为箱内装载率。本批改为：

1. 指标更名为“包络体积占比”，并明确分母含纸板与缓冲；公式、结果、FAQ、深度解析、SEO 描述同步说明“非长方体按外接盒计，不等于实际产品体积”。
2. 新增两个可选输入：
   - 产品实际体积（L）；
   - 箱内可用体积（L）。
3. 新增“装载体积利用率 = 产品实际体积 ÷ 箱内可用体积”；箱内可用体积留空时按 `(内长+2×缓冲)×(内宽+2×缓冲)×(内高+2×缓冲)` 估算，不含纸板。
4. 装载利用率超过 100% 时给出警告。
5. 校验口径与实现统一：产品内长/宽/高须 > 0；缓冲厚度、纸板厚度须 ≥ 0；可选体积填写时须 > 0。
6. `save/load`、CSV、预设同步新增两个可选体积；预设时清空这两项。
7. 复制/导出增加有效状态守卫：无效输入时复制被拦截、导出表清空且不下载。

真机结果（`?lang=zh-CN`）：

- 默认 300×200×150、缓冲 10、纸板 5 → 外箱 330×230×180、外体积 0.0137 m³、包络体积 0.0090 m³、包络占比 65.9%。
- 产品实际体积 5 L → 箱内可用体积 11.968 L、装载利用率 41.8%。
- 箱内可用体积 10 L → 装载利用率 50%。
- 产品实际 20 L、可用 10 L → 200% 并显示超限警告。
- 内长改 0 → 显示“请输入有效数值”，复制不增加、导出表 0 行；改回 300 后导出表 12 行。
- CSV 表含新增的产品实际体积、箱内可用体积、装载利用率行。

## 二、缓冲厚度：公式与标准引用冲突

对应任务：`缓冲厚度-公式与标准引用冲突.md`

1. 统一公式为 `t = C × H ÷ G`；标准表原“t = 脆值 × 高度 ÷ 效率”改为 `t = C × H ÷ G`。
2. 明确 C 是缓冲系数，应取自材料动态缓冲曲线或实测，不是固定常数；`ASTM D1596 / D4168` 只是动态缓冲试验方法，不直接给出设计公式。
3. 深度解析、算例、提示、FAQ 全部改为 `t = C × H ÷ G`，并新增“最终须用材料动态缓冲曲线、静压强度与实际包装件跌落试验验证”的限制说明。
4. C 范围 FAQ 改为经验值，以供应商实测曲线为准；新增 FAQ“这个公式能直接用于定型吗？”，回答明确“不能直接定型”。

真机结果：

- H=60、G=50、C=2.5 → 30.0 mm（3.00 cm）。
- H=90、G=40、C=2.5 → 56.25 mm。
- 英文态结果、公式说明、FAQ 均为英文，无中文残留。
