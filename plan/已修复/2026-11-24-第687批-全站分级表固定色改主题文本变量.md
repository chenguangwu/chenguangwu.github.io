# 第687批：全站分级表固定色改主题文本变量

## 原问题

复核指出 `tools/neurology/psqi.html` 等页面的分级表仍用固定 `#92400E`，暗色卡片背景 `#252540` 上对比度约 2.09:1。进一步全站扫描发现，同类写法共 39 个页面、41 处，并非神经科独有。

## 修复

把“分级表里只作为文字色的固定深色”统一改为随主题切换的变量：

- `style="color:#92400E;font-weight:600;"` → `style="color:var(--tb-text-warning);font-weight:600;"`
- `style="color:#B91C1C;font-weight:600;"` → `style="color:var(--tb-text-danger);font-weight:600;"`
- `style="color:#B91C1C;font-weight:700;"` → `style="color:var(--tb-text-danger);font-weight:700;"`

覆盖 39 页：

- 神经科 13 页：`adas-cog`、`dhi`、`edss`、`house-brackmann`、`moca`、`nihss`、`phq9-stroke`、`psqi`、`qmg`、`rls-severity`、`sara`、`trigeminal-bni`、`updrs`
- 耳鼻喉 15 页（含 `tonsil-grading`、`tdi-score`、`tympanometry` 等）
- 皮肤科 4 页
- 内分泌 3 页
- 儿科 4 页

只替换表格单元格/分级大字中的文字色，不动背景、色带、Canvas 与固定浅底徽章。

## 验证

真机 Chrome 抽样四页，浅色/暗色均读取实际合成背景：

| 页面 | 浅色 | 暗色 |
|---|---|---|
| `ent/tonsil-grading`（III 度） | `#92400E` / 白底 **6.75:1** | `#FBBF24` / `#252540` **8.88:1** |
| `dermatology/leprosy-grading`（1 级） | 6.75:1 | 8.88:1 |
| `pediatrics/pediatric-pneumonia`（极重症） | `#B91C1C` / 白底 **6.14:1** | `#FCA5A5` / `#252540` **8.0:1** |
| `neurology/psqi`（6-10） | 6.75:1 | 8.88:1 |

- 全站已无 `style="color:#92400E;font-weight…"` 与 `style="color:#B91C1C;font-weight…"` 残留。
- `_test_static.py`：4654 通过 / 0 失败；死链 0、资产 0。
- `python3 _build.py` 后 39 页改动全部存活。
