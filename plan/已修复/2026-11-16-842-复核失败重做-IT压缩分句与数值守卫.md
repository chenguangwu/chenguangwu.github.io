## 1. JS 压缩删除含换行块注释致 ASI 语义变化（221 / 第239批）

- **复核失败点原文**：`minifyJs` 直接跳过 comment token，`function f(){return/*\n*/1}` 输出 `return 1`——可编译但返回值从 `undefined` 变成 `1`。
- **修复位点**：`tools/it/js-formatter.html`：注释 token 含换行时在原位保留一个换行（先削掉行尾空格再补 `\n`），无换行的块注释和行注释照旧丢弃。
- **验证证据**：门禁新增 `MINASI`：输入含跨行块注释的 `return` 语句，断言压缩输出含 `return\n1`，并用 `new Function` 分别执行原文与压缩结果，两者都返回 `undefined`。
- **判别力实测**：去掉换行保留后输出 `return 1`，`b=1` ⇒ 转红。

## 2. 分句把句末 `etc.` 当句中缩写（223 / 第243批）

- **复核失败点原文**：`splitSentences` 无条件保护 `etc.` 后的句点，`Apples, pears, etc. Next item.` 被并成 1 句。
- **根因**：`etc` 与 `Dr/e.g` 等「几乎不在句末」的缩写混在同一张无条件保护表里。
- **修复位点**：`tools/it/text-statistics.html`：`etc.` 单独处理——仅当后接小写字母/数字/逗号/分号/右括号（同句延续）时保护；后接大写新句或文本结尾则按句点切分。注意不能带 `i` 标志（否则 `[a-z0-9]` 会匹配大写，等于没改）。
- **验证证据**：门禁 `SENT`：`Apples, pears, etc. Next item.` ⇒ 2 句且首句保留 `etc`；`Dr. Smith went home. He slept.` ⇒ 2 句。
- **判别力实测**：改回无条件保护后 `a=1` ⇒ 转红；带 `i` 标志的中间版本同样 `a=1`，已在本批内修正。

## 3. 列表转换静默删除空项与缩进（226 / 第260批）

- **复核失败点原文**：`convert()` 无条件 `map(trim).filter(Boolean)`：空行、行首尾空格全部消失，用户无法保留原始排版。
- **修复位点**：`tools/it/list-converter.html` 新增「保留空项与行首尾空白」复选框（`#keepBlank`，`onchange` 即时重算）；勾选时按原样逐行转换（仅把末尾换行当输入结束符，不额外计一项），未勾选保持旧行为。
- **验证证据**：门禁 `LISTKEEP`：输入 `  apple\n\nbanana  `，勾选输出 `__apple,_,_banana__`（空格换 `_`），取消后回到 `apple, banana`。
- **判别力实测**：去掉 `keep` 分支后勾选态与取消态输出相同 ⇒ 转红。

## 4. URL 构造器接受非法端口（234 / 第303批）

- **复核失败点原文**：`buildUrl()` 把 `b-port` 非空值直接拼接，`65536` / `12.5` / `abc` 都能生成并可复制非法 URL。
- **修复位点**：`tools/it/url-parser.html`：端口必须匹配 `^\d+$` 且落在 1–65535，否则显示双语提示（「端口须为 1–65535 之间的整数」）并返回空串；`copyBuiltUrl` 因此不会复制。
- **验证证据**：门禁断言 `buildUrl()` 返回 `""` 且提示文案匹配；另一条对照断言合法端口 `8080` 仍输出 `https://example.com:8080/`。
- **判别力实测**：去掉范围校验后返回 `https://example.com:65536/` ⇒ 转红。

## 5. 二项分布 CDF 出现负概率（196）

- **复核失败点原文**：`cdf()` 走补集分支时 `1−ΣP(k+1..n)`，浮点累计可能略大于 1（`n=10000,k=5001,p=0.6` 得 1+2.9e−12），返回 −2.9e−12。
- **修复位点**：`tools/it/binomial-distribution.html`：左尾与补集两条分支的结果都钳制到 `[0,1]`；该极端尾部返回 0（真实值 ~1e−40）。
- **验证证据**：门禁 `BCDF`：断言 `cdf(10000,5001,0.6)=0`、`cdf(20,4,0.3)=0.2375077789`、`cdf(10,3,0.5)=0.171875`（11/64，独立复算）。
- **判别力实测**：去掉钳制后返回负值 ⇒ 转红。
