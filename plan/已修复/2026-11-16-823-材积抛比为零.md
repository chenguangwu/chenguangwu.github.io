# 823 批：材积计算器抛比为 0 拒绝出数

- 对应条目：抛比为零被替换成 1（高）
- 页面：`tools/logistics/package-volume-calc.html`

## 问题
`||1` 兜底已在此前批次移除，但 `factor = 0` 时 `volumeCm3 / factor` 得 `Infinity`，仅靠全局 `Infinity/NaN` 替换显示「— kg」，页面仍给出体积并呈现残缺结果，容易误读为有效计算。

## 改动
`calcTool()` 在读取四项输入后前置校验：

```js
if(!(l>0)||!(w>0)||!(h>0)||!(factor>0)){
  result = '请输入大于 0 的长、宽、高与抛比系数；抛比为 0 时无法计算材积重。';
  return;
}
```
