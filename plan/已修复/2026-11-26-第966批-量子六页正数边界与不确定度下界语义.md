# 第966批：量子六页正数边界与不确定度下界语义

## 问题

- 黑体两页：`stefan-boltzmann-power` 只检查填写，负面积产生负功率；面积 0 时用 `P/(A||1)` 把出射度错误算成 0；温度 0 K 时峰值波长除零。`wien-displacement` 负温度/0 K 仍输出负/无穷峰值波长。
- 量子波长两页：`thermal-de-broglie`、`band-gap-photon` 只检查填写；0 或负数会除零，两个负数相乘反而得到看似有效的波长。固定小数会把极小非零波长显示为 0。
- 不确定关系两页：`energy-time-uncertainty`、`heisenberg-uncertainty` 对 0 / 负数不设防；把 ℏ/(2Δ) 当确定值展示，且位置页按电子质量换算速度但未在结果中说明粒子和非相对论假设。

## 修复

- 六页全部改为显式有限性/正负校验，主结果与明细表共用同一校验函数；无效输入时清空明细表、对比区和图表，并跳过历史记录。
- `stefan-boltzmann-power`：
  - 面积允许 0（P=0 合法），温度允许 0（极限），负值拒绝。
  - 出射度改为直接 `M=σT⁴`，不再用 `P/(A||1)`；温度 0 K 时峰值显示“—（0 K 无有限峰值）”。
  - 结果补充说明：M 只由温度决定、P=M·A 是理想黑体总辐射而非环境净辐射。
- `wien-displacement`：0 K / 负温度明确拒绝为“0 K 无热辐射峰值”，并补充维恩定律适用于理想黑体谱峰。
- `thermal-de-broglie` / `band-gap-photon`：质量、温度、带隙逐项要求有限正数；极小值按量级改用科学计数法；补充热波长是理想气体特征长度、截止波长受跃迁类型/温度/带尾影响的前提。
- 不确定关系两页：
  - 主结果与明细标签改为“下界 ΔE ≥ ℏ/(2Δt)”“Δp ≥ ℏ/(2Δx)”，并说明能量—时间关系依赖能级寿命与相互作用，不能直接类比位置—动量关系。
  - 位置页明确标注“按电子质量 mₑ 换算的等效速度下界”，说明 Δp 接近 mₑc 时非相对论近似失效。
- 六页结果行名按英文态输出英文，英文说明同步；导出沿用页面表格。
