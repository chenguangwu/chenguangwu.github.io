# 第 462 批：面包屑补 `aria-current` + 关键控件可访问名称

## 问题

### 1. 面包屑当前项没有 `aria-current="page"`

全站 4,823 个 `class="bc-current"` 面包屑末项，`aria-current="page"` 为 0。视觉上末项是当前层级，但读屏用户只听到一串链接，无法判断当前所在页。繁体中转站另有 4,845 个同类标签。

### 2. 关键页面控件缺可访问名称

- 首页移动搜索返回按钮只有 SVG，没有 `aria-label`；
- 首页移动搜索框、命令面板搜索框、404 搜索框、搜索页输入框、工具链名称/工具搜索框均无 `aria-label`；
- `embed.html` 的示例 iframe 没有 `title`。

## 修复

### 面包屑

`_build.py` 新增 `ensure_breadcrumb_aria_current()`：

- 扫描 `bc-current` 标签，跳过 `<script>` 内字符串；
- 无 `aria-current` 时补 `aria-current="page"`，已有值不动；
- 分类页与工具页生成模板直接写入 `aria-current="page"`，避免每轮重建后再次补写；
- 繁体站生成后再跑一次 `include_tw=True`，覆盖本地残留的 22 个无源文件繁体页。

同时把 `fix_tool_pages_seo_parallel` 内 `bc-current` 解析正则从精确匹配改为允许额外属性，避免新增 `aria-current` 后取不到面包屑名称。

### 键盘/读屏名称

- 首页返回按钮补 `aria-label="关闭搜索"`；
- 搜索输入补 `aria-label`，并挂已有 `data-i18n-aria` 键（`search.mobile` / `search.cmdk` / `err.search_ph` / `search.input_ph` / `chains.name_ph` / `chains.search_ph`），英文态读屏跟随字典；
- `embed.html` iframe 补 `title="复利计算器嵌入示例"`。

## 结果

- 构建输出：源站 `Breadcrumb aria-current: 4823 tags in 4813 pages`；模板修复后二次构建 `0 tags in 0 pages`，幂等；
- 覆盖复核：源站 4,823/4,823、繁体 4,845/4,845 个 `bc-current` 全部带 `aria-current="page"`，缺失 0；
- 分类页模板与工具页模板均已内置该属性，不再每轮补写；
- 6 个关键搜索/工具链输入、1 个关闭按钮、1 个 iframe 均已有可访问名称；
- 静态测试：4,626 passed / 0 failed / 0 warnings（4,606 个工具）；
- 死链门禁：16,743 文件 / 160,330 内链，0 死链；
- 资产完整性：0 资产死链 / 0 `lang` 缺失 / 0 重复 id；
- 内联标记位置审计：0 处加固片段违规；
- 全量门禁：268/268 passed（`/tmp/gates462.log`）。
