# 第705批：积分兑换空值与方案 B、分期空费率、三项门禁修复

## 修复项

### 1. `tools/finance/points-redemption-value.html`

- 新增 `__prRaw()` / `__prVal()`，积分、商品价值、加钱三项均先取原始字符串：空值不再按 0 计算。
- 积分、商品价值必填；商品价值允许显式 0；加钱空时提示“请填写加钱金额；无加钱请显式填 0”，显式 0 合法。
- 加钱大于商品价值仍报错；主结果、表格、图表共用同一组校验，空值/越界时清空图表。
- 新增方案 B（`pts2/val2/fee2`）：三项全填才与方案 A 比较，显示 B 每万分价值及 A/B 差额；只填部分显示“不参与比较”，不报错。

实测：空加钱 → 提示且图表/表格清空；商品价值 0 → 正常显示；加钱 > 价值 → 错误；方案 B 部分填写 → 未参与；完整 B：A 20.00、B 12.50、差 -7.50；无 `pageerror`。

### 2. `tools/finance/installment-real-rate.html`

- 每期手续费率先取原始字符串：空值不再被 `num()` 当 0%，提示“请填写每期手续费率；无手续费请显式填 0，不能留空按 0% 计算”。
- 非数字费率单独报错；显式 0 正常按 0 手续费计算。

实测：12000 元 / 12 期 / 费率空 → 只出提示且图表、表格为空；费率 0 → 正常显示 0.00 元总手续费；无 `pageerror`。
