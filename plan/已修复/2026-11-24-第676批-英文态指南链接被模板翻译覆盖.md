# 第676批：英文态指南链接被模板翻译覆盖成纯文本

## 背景

第671批新增 `patternPhraseTr()` 后，线上抽样发现 `tools/geometry/pyramid-volume.html?lang=en-US` 的指南入口变成了一行纯文本：

```
<div class="tool-guide-link">📖 View the Pyramid Volume guide</div>
```

原 `<a href="../../guides/...">` 已被删除，链接不可点击。原因是正文翻译对容器直接执行 `el.textContent = tr`，命中 `📖 查看「…」` 模板时连带清空内部 `<a>`。

这不是单页问题：全站含 `.tool-guide-link` 的页面共 **3,302** 个，属于第671批引入的批量回归。

## 修复内容

修改 `js/tool-i18n.js` 的 `translateBodyPhrases()`：

1. 含 `<a>` 后代的容器一律不做整节点替换，交给叶子 `<a>` 自己翻译，保留 `href` 和可点击性；
2. 模板译文命中带子元素的标题（如 `📖关于「…」`）时，只在文本节点层面替换核心短语，保留 `.h4-icon` 图标 `<span>`；
3. 保留 `BODY_CHANGED` 的节点级原文记录，切回中文时逐节点恢复，不破坏 DOM。

同时给探针增加 `--links` 模式，作为第275道门禁：

- 在英文态断言 `.tool-guide-link` 内 `<a>` 数量、`href` 与静态源一致；
- 断言链接文本不含中文残留；
- 切回中文后再次断言 `<a>` 数量不丢失；
- 覆盖 5 个代表页：`geometry/pyramid-volume`、`finance/compound-interest`、`accounting/cash-conversion-cycle`、`dyeing/color-diff`、`it/text-diff`。

## 核验

- 第671批线上回归页 `pyramid-volume`：英文态恢复为 `<a href="../../guides/pyramid-volume-guide.html">📖 View the Pyramid Volume guide</a>`。
- 16 个命中全局整句字典、原先 `<a>` 被删除的页面全部恢复链接；`compound-interest`、`text-diff`、`calc-weld` 等逐页确认 `href` 未变。
- 全站 3,302 个含指南块页面真机复验：**0 个英文态 `<a>` 数量异常、0 个 `href` 改变、0 个脚本异常**；18 个页面在 450ms 采样点仍显示中文链接文案，延长等待后均为英文，属异步字典未完成的采样假阳性，结构始终完整。
- 中英往返：`dyeing/color-diff` 切回中文恢复 `📖 查看「轧染色差控制 使用指南」`，`href` 不变。
- `node scripts/_en_i18n_probe.mjs --links ...`：5 页 0 异常。
- `python3 _build.py` 后修复存活。
- 全量门禁 **275/275 通过**。
