## 处理结果

### IT-N326 YAML 块标量内容全丢（高）— 真改

- 旧实现把 `|` / `>` 当普通标量写入值，`p.i` 指向下一行；外层 `while` 只接受同缩进行，遇更深缩进的块内容立即退出 ⇒ 块内容与后续同级键全丢。
- 修复：
  - `parseYaml` 预处理为每行记录 `line` 号并保存在闭包 `__yamlLines` / `__yamlItems`。
  - 新增 `yBlockMark()` 识别 `|` / `>`（含 `|-` / `>-` / `|+` / `>+`）与 chomping 标记；`yCollectBlock()` 按首个内容行缩进收集连续行，回查原始行重建（保留块内空行）。
  - `|` 用 `\n` 连接、`>` 折叠相邻非空行为空格（空行产生换行）；`-` 去末尾换行、默认恰好保留一个、`+` 保留全部。
  - `yBlock()` 映射分支与 `yMapFrom()` 两处（列表内 map 首项与后续项）都接入块标量分支。
- 效果：`desc: |` + `hello`/`world` + `name: test` → `{"desc":"hello\nworld\n","name":"test"}`。

### IT-N327 行尾注释未剥离（高）— 真改

- 旧 `yScalar` 只跳过整行 `#`，行尾 `#` 原样留值里，类型推断随之中断。
- 修复：新增 `yStripComment()`，逐字符扫描并跟踪单/双引号状态，只在引号外、且 `#` 前有空白时截断并 trim；引号内 `#`（`"a # b"`、`"#tag"`）与紧贴值的 `#`（`5#notcomment`、`http://x/a#frag`）保留。
- 效果：`port: 8080 # web port` → `"port": 8080`（数值），不再退化成字符串。
