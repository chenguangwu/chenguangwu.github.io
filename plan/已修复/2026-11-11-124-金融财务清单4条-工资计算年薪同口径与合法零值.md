## 一、逐条结论

### F-N98 年薪模式沿用月薪基数 → 负到手（高）

- **失败点**：清单复现「默认薪资 20000 切年薪 → 税后年收入 −34,000」；另 harness 固化用例注入 `salaryMode=annual, salary=240000` 输出「年五险一金 ¥64.80万 / 税后年收入 ¥-408,000.00」。前批 F-N15 已在 `switchMode()` 加「未改过基数则同步为新月薪」，但**直接注入隐藏 input / localStorage 恢复 / 用户手填过高基数**这三条路径仍会输出不可能的负工资，且无任何提示。
- **根因**：`calculate()` 只做算术、不做业务状态判定；`getNum('baseSalary') || monthlySalary` 使基数无法为 0，也与年薪口径脱节。
- **修复位点**：`calculate()` 在算出 `annualNet` 后判 `annualNet < 0 || netMonthly < 0` ⇒ 调 `__salaryClearResults()` 清空全部数值容器与柱状图，向新增 `#salaryBaseNote` 写**带当前取值**的双语提示（含「年薪÷N = ¥X/月」修正示例与「不缴社保请填 0」），然后 return。基数高于月薪但未致负收入时，写一条轻提示，避免静默沿用旧值。EN 态走 `__salaryModeIsEn()`，零 CJK。
- **顺带**：`switchMode()` 里 `getNum('monthsPerYear') || 12` 一并换成 `__salaryNum(...,12)`，避免 0 月数下除零。

### F-N99 年薪模式明细卡 / 比例 / 柱状图仍按月口径（中）

- **失败点**：hero 用年度值，明细卡 `grossSalary / taxAmount / netSalary` 与 `effectiveRate / takeHomeRate`、柱状图恒用月度值，同屏混用两套口径，年终奖税负被比例卡忽略。
- **修复位点**：新增 `__annual` / `__k = __annual ? monthsPerYear : 1`，明细卡与柱状图一律改用 `displaySalary / displayInsurance / displayTax / displayNet`（五险逐项乘 `__k`）；比例卡改为 `displayTax / displaySalary` 与 `displayNet / displaySalary`；`marginalRate` 年薪模式取新增的 `annualMarginalRate`（年度税率表档位）。`#salaryScopeNote` 动态写明「以下明细为全年合计 / 每月金额」。
- **月薪模式零漂移**：`display*` 即月值、`__k=1`，既有 `¥9,000.00` / `¥4,800.00` 用例保持 PASS。

### F-N100 计薪月数 ≠12 时扣除口径不一致（低）

- **失败点**：`annualInsurance = totalInsuranceMonthly * monthsPerYear`，但 `annualTaxable` 里 `threshold * 12`、`totalSpecialMonthly * 12` 固定 12 月。
- **修复位点**：两者同改 `* monthsPerYear`；`#salaryScopeNote` 写明按 N 个计薪月折算并标注「估算口径，正式申报以税务机关年度汇算为准」，不写无权威依据的绝对表述。
- **独立复算（清单条件）**：月薪 20000、社保 22.5%、起征点 5000、专项 3500/月、无年终奖 —— 12 月：240000−54000−60000−42000=84000 → 5880；13 月：260000−58500−65000−45500=91000 → **6580**（旧版固定 12 月为 7430）。真机与探针锁均实测 5880 / 6580。

### F-N101 `||` 兜底吞掉合法 0（低）

- **失败点**：`getNum('monthsPerYear') || 12`、`threshold || 5000`、`baseSalary || monthlySalary` 把 0 当空值，无法表达「基数为 0 / 起征点为 0 / 不缴社保」。
- **修复位点**：新增 `__salaryNum(id, fallback)` —— 仅在真空值 / 非数字时回退，0 按 0 参与计算。三个字段与 `salary / bonus` 统一改走该 helper。计薪月数 `<= 0` 会导致年薪折算除零，单独判为无效输入：`#salaryBaseNote` 写明确拒绝提示并清空数值区，不产生 `Infinity` / `NaN`。
- **空值仍回退默认**（如 `threshold=''` → 5000），真机有防回退断言。
