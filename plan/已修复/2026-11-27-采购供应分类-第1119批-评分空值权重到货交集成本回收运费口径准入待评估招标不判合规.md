## 修复内容

### 1. rater-price.html 供应商综合评分
- 权重逐项限 0–100、不得全 0，合计不等于 100 时按比例归一化。
- 合格率/准时率限 0–100；报价须大于 0。任一项留空或非法即清空排名表/差异/图表并暂停推荐，不再把空值当 0。
- 报价 0 明确不参与比价（避免最低价为 0 使所有价格分为 0）。
- 从 DOM 读原始值，区分“未填写”与明确的 0。
- 修正深解析旧算例：A/B/C 权重 40/35/25、最低价 92 时，正确综合分为 A 95.60、B 97.50、C 91.87，B 最高且与 A 差 2.50 分（<3 分提示综合考虑），旧文“A 97.20 最高”与页面不符。

### 2. stats-on-time-1.html 到货准时率统计
- 总批次、准时、合格、准时且合格四项均须非负整数且单项 ≤ 总数；小数/负数/超标拒绝。
- 交集须满足 `max(0, 准时+合格−总数) ≤ 联合 ≤ min(准时, 合格)`，否则停止计算并提示可行区间，修正原“负的准时但不良率”。
- 未同时达标率按 `(总数−联合)÷总数` 计算。

### 3. stats-on-time-qualified.html 到货准时率与合格率
- 新增可选“实测准时且合格批次”；三项计数必填整数且 ≤ 总数。
- 实测交集校验可行区间；未填交集按“准时率×合格率”独立假设估算并明确标注为估算，非实测。
- 删除旧“描述统计计算器”FAQ 与标题，改为本工具口径。

### 4. analysis-cost.html 采购成本节约
- 数量、原单价、新单价、年采购次数、投入全部必填，留空不按 0。
- 原单价 >0；新价/投入/次数 ≥0，次数整数。
- 无正节约且有投入显示“无法回收”，零投入显示“无需回收”；次数 0 且有节约显示“无法按年计算”，不再输出 0 次/0 年。

### 5. wuliu-yunshufangshi-yunfei-bidui.html 运费对比
- 改为“公路/铁路参考运费估算”，删除快递/零担/整车/时效承诺。
- 公路、铁路单价可配置；总运费 = 距离(km)×重量(t)×单价(元/吨·km)，同时展示单位费率。
- 默认费率标注为示例，非实时报价。

### 6. assessor-26.html 供应商准入评估
- 全部数值字段必填；任一留空显示“待评估：请补全全部字段后再评分”并列出缺失 id，不评分。
- 负数拒绝；负债率/合格率/客诉率/准时率限 0–100%。
- 新增可配置战略/优选/合格阈值（默认 85/70/60），校验降序且 0–100。
- 输出改为“参考分级/复核建议/示例模型”，明确不替代准入审查。

### 7. zhaobiao-gongkai-yaoqing-jingzheng-fangshi.html 招标方式
- 删除“金额 ≥400 万法定公开、低于则内部审批即可”的判定；金额仅记录。
- 新增适用制度/地区、制度核对日期（可空）。
- 输出改为三种方式的常见适用情形、典型流程与待核对清单，明确不判定合规。
- 修正英文标题与引据表，去掉与页面口径冲突的评标公式/法条暗示。
