# 第1291批 · TIMI趋势图按分值画线（03-87）

## 缺陷
`cardiology/calc-3.html` 历史记录「结果」字段存整段文本（首段「TIMI 评分： N 分」），趋势图对其 `parseFloat` 得 NaN，记录全被 isFinite 过滤，折线图永不渲染。核查发现曾被"伪修"：加了 `__tbScore` 数值字段，但该字段是 0/1 有效性标记（通用模板函数），趋势图实际画的是 0/1 线而非 TIMI 分值，与期望不符。

## 修复
- 新增 `__calc_3Timi(t)`：从结果文本首段正则提取 TIMI 分值（兼容中文「TIMI 评分： N 分」与英文「TIMI Score: N」）。
- record 时增存 `rec.__tbTimi = __calc_3Timi(res)`；mount 回填跳过该字段（与 __tbScore 并列）。
- 趋势图改读 `parseFloat(arr[j].d.__tbTimi)`，series 名由「有效性趋势」改「TIMI 评分趋势」。
- 历史表「结论」列仍用 0/1 的 `__tbScore`，语义不变。
