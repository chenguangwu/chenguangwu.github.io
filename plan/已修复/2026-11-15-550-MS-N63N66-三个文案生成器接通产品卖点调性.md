# 550 批：标语 / 话题标签 / 口号生成器接通产品、卖点与调性（MS-N63 ~ N66）

日期：2026-11-15　页面：`tools/marketing/tagline-generator.html`、`hashtag-generator.html`、`slogan-generator.html`

## 问题

- **MS-N63**：标语生成器只有主题 + 品牌名，产品、卖点、情感调性均无输入，深解里的「运动手表 / 记录心跳」算例无法复现。
- **MS-N64**：话题标签生成器对中文关键词直接加英文复数/词缀（`#健身减脂s`、`#关键词Life`），且 `suffixes[randInt()]` 取三次，可能拼出 `Vife` 这类非词。
- **MS-N65**：深解宣称「主题词 → 长尾/人群/场景扩展」，实际只是 `关键词 + s / life` 机械拼接。
- **MS-N66**：口号生成器无品牌、产品、调性输入，只是 50 条固定句随机抽选，深解算例同样不可复现。

## 修复

### 标语生成器

- 新增「产品 / 品类」「核心卖点」「情感调性（热血/温暖/极简/专业）」输入；品牌名留空时回落产品名。
- 候选池 = 8 条主题模板 + 12 条调性模板（[B]/[P]/[F] 占位替换、去重），候选池恒为 20 条，count 上限 20；未填产品/卖点时使用主题默认词并明确告知「候选池」条数。
- 深解改写为「Keep / 运动手表 / 记录心率 / 热血」与「笔记 App / 只记重点 / 极简」两组可复现输出。

### 话题标签生成器

- 中英文分流：中文关键词走内置词库（健身减脂、穿搭、旅行、美食、护肤、宠物、学习…），未收录词回落中文后缀（分享/推荐/攻略/日常/打卡），不再出现 `#关键词s`。
- 英文复数规则：辅音+y → ies、s/x/z/ch/sh → es、已以 s 结尾（shoes）保持不变；后缀只随机取一次并统一首字母，杜绝 `Vife`。
- 年份标签、多词组合、camel/lower、emoji 开关保留；深解改为中文词库扩展（#健身减脂 #减脂餐 #居家健身 #新手健身 #运动打卡）与英文复数（shoes/beach/city）两个可复现算例。

### 口号生成器

- 新增「产品 / 服务」「核心卖点」「调性（年轻活力/专业可信/温暖治愈/幽默）」输入；候选池 = 10 条场景句 + 10 条调性模板，count 上限 20。
- 深解改写为「咖啡 / 提神 / 年轻活力」与「财税软件 / 每笔账可查 / 专业可信」两组实际可生成的口径；FAQ 补「不填产品与卖点会怎样」。
