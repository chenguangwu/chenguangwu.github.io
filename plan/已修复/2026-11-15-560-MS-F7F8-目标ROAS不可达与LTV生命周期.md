# 560 批：目标 ROAS 不可达说明与 LTV 生命周期输入（MS-F7 / MS-F8）

## MS-F7 目标利润率 ≥ 毛利率时目标 ROAS 静默消失、错误提示指错字段

### 问题
- `targetRoas` 只在 `0 < targetProfit < margin` 时计算，目标利润率等于或高于毛利率时整卡不渲染，
  页面没有任何说明，用户会以为「填了目标利润率没生效」。
- 校验只判断 `price` / `margin` 的 `isNaN`，售价为空或 ≤0 时也提示「毛利率0-100之间」，指向错误字段。

### 修复
- 校验拆分为逐字段收集：售价非有限或 `≤0` →「请输入产品客单价（须大于 0）」；
  毛利率不在 `(0,100)` →「毛利率须在 0–100 之间（不含 0 与 100）」；多条错误以「；」拼接显示。
- `targetProfit ≥ margin` 时渲染占位卡：「目标ROAS 无法计算」，副标题说明目标利润率不低于毛利率、
  扣除广告费后不可能达到，并提示调到低于当前毛利率。
- 目标利润率输入提示改为「可选，须低于毛利率，用于计算目标ROAS」，提前暴露约束；EN 字典同步改键。
- `saveHistory()` 校验同步补 `price > 0`，避免非法售价进入历史。

### 验收
- 默认 299 / 40 / 当前 3 / 目标 10 → 平衡 ROAS 2.50、目标 ROAS 3.33。
- 售价清空 → 仅提示客单价字段；毛利率 120 → 仅提示毛利率区间。
- 目标利润率 50 或 40（毛利率 40）→ 出现「目标ROAS 无法计算」说明；改回 10 恢复 3.33。

## MS-F8 LTV 零值校验与回本周期硬编码 36 个月

### 现状核验
- 当前源码已含 `ltv <= 0` 拦截（`:423`），LTV 为 0 不再输出 0:1 / -100% ROI，原条目的零值部分已不适用。
- 剩余真实缺陷：回本周期固定按 36 个月分摊 LTV（`paybackMonths = cac/(ltv/36)`），
  页面无寿命输入；寿命不是 36 个月时结果系统性偏离（如 12 个月寿命应翻 3 倍）。

### 修复
- 新增「客户生命周期（月）」输入（`#lifeMonths`，默认 36，提示「LTV 的分摊周期，默认 36 个月」）。
- `paybackMonths = cac / (ltv / lifeMonths)`；生命周期非有限或 `≤0` → 提示
  「请输入客户生命周期（月，须大于 0）」并停止计算。
- 明细行与联动卡动态标注寿命口径：「回本周期（按 X 个月分摊 LTV 估算）」「回本周期（X个月寿命）」。
- 回本周期超过生命周期时追加「（超过生命周期，难以回本）」，避免把超出寿命的回收期当普通数值。
- `resetForm()` 重置寿命为 36；EN 字典补新增标签与提示的映射。

### 验收
- 默认 3000 / 500 / 36 → 6.00 : 1、回本 6.0 个月。
- 生命周期改 12 → 回本 2.0 个月，标签显示 12 个月口径。
- LTV 0 → 拒绝计算；生命周期 0 → 提示须大于 0。
- LTV 300 / CAC 500 / 36 个月 → 回本 60.0 个月并标注「超过生命周期，难以回本」。
