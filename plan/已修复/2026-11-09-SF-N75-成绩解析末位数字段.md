## 失败点（复核不通过原记录）
- 输入 `张 三,88,备注`（姓名含空格、末尾附注「备注」为非数字字段）。
- 交接声称「按最后一个可转数字字段解析」，但当前实现只取最后一列 → 末列为「备注」→ NaN → 整行被丢弃，88 分不计入统计。
- 影响：末尾附注、姓名含空格等真实 CSV 行的成绩被静默丢弃，统计结果失真。

## 根因
`var sc=parseFloat(p[p.length-1]);` 直接取最后一列作成绩。当姓名含空格（如「张 三」被逗号分隔为「张」「三」多段）或末尾带附注时，最后一列不是成绩，导致 `parseFloat` 返回 NaN，触发 `badRows++` 并整行丢弃。

## 修复位点
文件：`tools/sports/stats-11.html`（calc 解析段）
- 改为从末尾向前扫描「最后一个可转数字字段」作成绩：
  ```javascript
  var scIdx=-1;
  for(var i=p.length-1;i>=0;i--){ if(!isNaN(parseFloat(p[i]))){ scIdx=i; break; } }
  if(scIdx<0){ badRows++; if(!badName) badName=ln; return; }
  var sc=parseFloat(p[scIdx]);
  var name=p.slice(0,scIdx).join(' ');  // 其余拼回姓名（含空格、附注等）
  if(sc<0||sc>full){ overRows.push(name+'='+sc); return; }
  ```
- 姓名取成绩字段之前的所有片段，空格合并，附注等非数字字段自然并入姓名。
