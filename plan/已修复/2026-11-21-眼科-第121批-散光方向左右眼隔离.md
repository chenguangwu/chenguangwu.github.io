# 第 121 批：21 题视力筛查左右眼散光方向隔离（眼科）

- 日期：2026-11-21
- 页面：`tools/ophthalmology/vision-screening-21.html`

## 原问题

`astigVerdict(eye)` 虽然按传入眼别计算散光负荷，但判断轴位方向时取了双眼最大值：

```js
var trans = Math.max(a.q11.l, a.q11.r);
var ghost = Math.max(a.q14.l, a.q14.r);
var swim  = Math.max(a.q17.l, a.q17.r);
var night = Math.max(a.q3.l,  a.q3.r);
```

后果：左眼报告「看远转近模糊」很重、右眼没有该症状时，右眼的散光提示仍会被判成「顺规散光」；页面文案承诺「左右眼独立」，实际方向词被另一只眼污染。

## 修复

改为按传入 `eye` 取本眼回答：

```js
var trans = a.q11 ? a.q11[eye] : 0;
var ghost = a.q14 ? a.q14[eye] : 0;
var swim  = a.q17 ? a.q17[eye] : 0;
var night = a.q3  ? a.q3[eye]  : 0;
```

散光负荷 `eyeAstig(eye)` 本来就是单眼计算，此次只修方向判定这一处串眼。
