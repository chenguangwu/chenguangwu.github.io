# FE-N29 找词游戏「重置」按钮不清空 cur/found/score，界面复位后仍可继续作答

**分类**：11-文娱爱好 / 游戏 (fun/anagram-game.html)
**类型**：功能缺陷（重置语义失效）→ 已修复
**处理日期**：2026-11-07
**复核方**：待复核

## 失败点（原缺陷）
`reset()`（「重置」按钮，`onclick="reset()"`）只清空 DOM 显示（`baseWord`/`answer`/`output`/`foundList`），
不清空 `cur`、`found`、`score`。`check()` 以 `if(!v||!cur)return;` 作为「未开局」守卫，而 `cur` 在重置后仍指向上局题目，
导致「重置」后输入上局单词仍可判分/计入已找，重置语义形同虚设。

## 根因
`reset()` 与 `start()` 职责不对等：仅 `start()` → `newRound()` 会重设 `cur/found/score`，而独立的「重置」按钮调用路径只做显示复位。

## 修复位点
`tools/fun/anagram-game.html`：`reset()` 头部增加
```js
cur=null;
found=new Set();
score=0;
```
使「重置」按钮与「开始」按钮语义对称——重置后 `cur` 为空，`check()` 因 `!cur` 守卫直接 return，任何提交均不生效，直到再次点「开始」。
`start()` 仍先 `reset()` 再 `newRound()`，新局状态由 `newRound()` 重设，不受本改动影响。
