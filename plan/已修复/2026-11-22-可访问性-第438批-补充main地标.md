# 第 438 批：为全站 4,768 页补 `role="main"` 主内容地标

日期：2026-11-22
类型：可访问性 / 语义结构
状态：已修复并本地提交（未 push）

## 一、原问题

全站 4,809 个非重定向工具/分类页中，**4,809 页没有任何 `<main>` 或 `role="main"`**。屏幕阅读器用户只能逐段跳过顶部导航、分类导航和工具条，无法一键直达正文；自动化可访问性检查也会把“缺少主内容地标”列为结构缺陷。

## 二、修复内容

1. 工具页：在 `_build.py` 的页面处理流程中，若页面同时满足：
   - 不含 `<main>`；
   - 不含 `role="main"`；
   - 恰好只有一个 `<div class="container">`；
   
   则给该容器补 `role="main"`，不改变任何标签层级、样式与布局。
2. 分类页：在分类页生成模板中直接把容器改为 `<div class="container" role="main">`。
3. 幂等：已是 `role="main"` 的页面不会重复添加；复核 `multiple main roles` 为 **0**。

## 三、验证证据

- 构建：`env -u NODE_OPTIONS python3 _build.py` 成功。
- 全站非重定向工具页：
  - 已有主内容地标：**4,768 页**；
  - 仍无主内容地标：**41 页**（均为无 `.container` 的特殊布局：认知测试、色觉检查、听力测试等，需单独设计包裹层，本批不强行改动）。
- `role="main"` 重复页面：**0**。
- 静态门禁：**4,626 passed / 0 failed / 0 warnings**。
- 第 437 批后全量门禁：`/tmp/gates437.log` 显示 **All 268 quality gates passed**。
