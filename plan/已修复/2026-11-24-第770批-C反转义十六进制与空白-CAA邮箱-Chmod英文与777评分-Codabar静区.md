日期：2026-11-24

## 已修复任务（5）

1. **C 字符串反转义：十六进制边界及空白丢失**
   - `\x` 按 C 词法贪婪读取全部连续十六进制数字（`\x041` → 0x41='A'）；值 >0xFF 保留原样并提示 C 编译器会拒绝。
   - 改为按字节值 `String.fromCharCode` 输出；八进制同按单字节校验（`\377`=255 合法，`\777` 保留并提示）。
   - 不再无条件 `trim()`：裸文本保留首尾空格；仅整体带外层引号的字面量去掉引号与字面量外空白。
   - 未知转义（如 `\q`）、`\u`/`\U` 位数不足均保留原样并在 `#cEscapeNotice` 提示，不再静默吞反斜杠。

2. **CAA 记录生成器：空报告邮箱被替换为示例**
   - 勾选 iodef 后邮箱为空或格式非法（简单 `local@domain.tld`）即清空输出并报错，绝不把 `security@example.com` 当真实邮箱写入。
   - iodef 输入框显隐移到域名校验之前，域名无效时勾选状态也立即反映。
   - 公式/说明同步：示例地址只作占位；iodef 邮箱必须真实可达。

3. **Chmod：英文态常用权限说明仍为中文**
   - 新增 `tipsEn` 覆盖 755/644/777/700/600/444/555/000/4755/2755/1777；`__chmodIsEn()` 同时按 TBKit、URL `lang` 与 `html[lang]` 判定，首屏即英文。
   - 复制反馈走 `copyText` 自带双语成功提示（`Copied chmod … command` / `已复制 …`），移除重复 toast。

4. **Chmod：高风险权限被历史记录误判失败**
   - 评分不再把 `⚠/⚠️` 安全提醒判为失败；777 作为有效权限判通过，风险文案仍保留。无效/未通过/失败等仍判 0。

5. **Codabar：导出图像缺少静区**
   - 画布左右各加 10 个窄模块静区（narrow=2 ⇒ 20px），总宽 = 条码宽 + 40；预览与 PNG 下载共用同一画布。
   - 暴露 `window.__codabarGeometry`；说明补充 AIM USS-Codabar 最低静区、窄/宽模块像素与打印等比缩放保留白边。
