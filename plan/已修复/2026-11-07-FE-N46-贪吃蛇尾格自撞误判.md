# 2026-11-07 FE-N46 贪吃蛇「即将腾空的尾格」误判自撞

- 分类：11-文娱爱好 / fun
- 页面：`tools/fun/snake-game.html`
- 缺陷：自撞判定包含尾段，未吃食物时进入尾格被误判 gameOver
- 严重度：中（确认源码缺陷，非陈旧快照误报）

## 失败点
`gameStep()` 在 `unshift` 之前对**整条蛇（含尾段）**做 `some` 自撞判定（约 456 行），随后才 `pop()` 去尾。未吃食物时尾格本帧会腾空，新头进入尾格应合法，却被误判死亡。

## 根因
自撞判定与「是否吃食物」解耦：尾段是否参与判定应取决于本步是否增长（吃食物则尾不腾空，须全段判定；否则尾腾空，应忽略尾段）。

## 修复位点
文件 `tools/fun/snake-game.html`（`gameStep()` 内）：
- 先算 `const willEat = (head.x === food.x && head.y === food.y);`
- 自撞判定改为 `const bodyToCheck = willEat ? snake : snake.slice(0, -1); if(bodyToCheck.some(s => s.x === head.x && s.y === head.y)){ gameOver(); return; }`
- 未吃时 `snake.pop()`（原逻辑保留），吃到时增长不 pop。
