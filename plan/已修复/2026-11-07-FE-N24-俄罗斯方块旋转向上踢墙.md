# FE-N24 俄罗斯方块旋转补「向上踢墙」（贴底/贴顶旋转不再静默失败）

**分类**：11-文娱爱好 / 游戏 (fun/tetris.html)
**类型**：功能缺陷（旋转仅水平踢墙，无向上踢墙）→ 已修复
**处理日期**：2026-11-07
**复核方**：待复核

## 失败点（原缺陷）
`rotate()` 的踢墙表为纯横向标量 `kicks = [0, -1, 1, -2, 2]`，仅在 `currentPiece.x` 上做 0/±1/±2 偏移，
完全没有 y 方向修正。当方块贴底（如 I 块横放在最底行，旋转后需 4 行高度 19~22 越界）或贴顶时，
所有横向候选 `isValid` 均返回 false → 旋转直接 `return`，按键**无任何反应**，与参考表
「现代实现采用超级旋转系统，允许贴墙与踢墙旋转」不符。

## 根因
踢墙偏移只改 x 不改 y，无法把被地面/天花板挡住的旋转「顶上去」。最常见的地面旋转场景（方块落底后
想转个方向）因此完全失效，属旋转系统能力缺口，非偶发边界。

## 修复位点
`tools/fun/tetris.html`：
- `rotate()` 踢墙表由 `var kicks = [0, -1, 1, -2, 2];`（标量，只改 `currentPiece.x`）改为偏移对表：
  `[[0,0],[-1,0],[1,0],[-2,0],[2,0],[0,-1],[0,-2],[-1,-1],[1,-1],[-1,-2],[1,-2]]`，
  先试原位/横向（保持原手感），横向均越界后再试向上踢墙 `[0,-1]/[0,-2]`（I 块贴底横转竖必需），
  以及左上/右上组合踢墙。
- 循环内由 `currentPiece.x += kicks[i];` 改为
  `currentPiece.x += kicks[i][0]; currentPiece.y += kicks[i][1];`，使 y 方向偏移生效。
- 为支持自动化回归观测（tetris 的 `currentPiece` 位于 IIFE 闭包内，harness 与 `w.eval` 均不可见），
  在 IIFE 内新增只读/置位测试钩子 `window.__tbTetris = { piece, setPiece, rotate, isRunning }`
  （仅供 verify 脚本使用，不影响正常游戏逻辑）。
