# 第465批：指南 description 原始尖括号转义

日期：2026-11-22
分类：元数据 / HTML 属性健壮性

## 原问题

构建期 `normalize_guide_descriptions()` 只在描述文案需要收口时才重写 `<meta>` 的
`content`；文案不变时原样保留。审计发现 91 个指南页共 273 个
`description` / `og:description` / `twitter:description` 字段含原始 `<`、`>`
（如「最大液宽：<10 mm 少量、10–20 mm 中量、>20 mm…」）。

这类尖括号虽在双引号属性值里多数浏览器仍按字面解析，但社交抓取与结构化校验
容易把 `<10 mm` 误判为标签边界，属于真实的元数据健壮性缺口。

## 修复

`_build.py` 的 `normalize_guide_descriptions()` 内 `_sub_meta()` 改为：

- 先 `html.unescape` 取回真实文本，再做原有的残句收口；
- 无论文案是否变化，一律用 `esc_html_py()` 输出属性值，把 `<`/`>`/`&`/`"` 落成实体；
- 仅当转义结果与页内现值不同才写盘，保持幂等。

复跑构建后 `guides desc 收口: 91 页`；源站与繁体站描述字段原始尖括号均归 0。

## 验证

- 构建：`env -u NODE_OPTIONS python3 _build.py`，退出 0；
- 全站复核：`description` / `og:description` / `twitter:description` 含原始 `<`/`>` 的页面 182→0、字段 546→0（含源站与 zh-tw）；
- 抽查 `guides/pericardial-effusion-guide.html` 与 `zh-tw/guides/pericardial-effusion-guide.html`：`&lt;10 mm`、`&gt;20 mm` 解码后仍为 `<10 mm`、`>20 mm`，无双重转义；
- 静态：4,626 passed / 0 failed / 0 warnings；
- 死链：16,743 文件 / 160,344 内链，0 死链。
