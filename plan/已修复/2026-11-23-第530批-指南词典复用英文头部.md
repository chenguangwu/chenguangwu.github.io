# 第 530 批：3,400+ 指南页英文标题/描述词典复用

- 日期：2026-11-23
- 范围：类别 3「中英文不全」
- 提交：`e54abfe0cc`

## 背景

第 528–529 批修好了 119 个加载 `guide-en-pack.js` 的指南页头部。其余约 3,300 页没有 pack，但每页都有 `i18n/guides/<slug>.json` 正文词典，其中通常含：
- 首键：`<工具名> 使用指南` → 英文标题；
- 首句：meta description 的第一句 → 英文描述。

此前 `guide-i18n.js` 只用词典替换正文，不处理 head。

## 修复

`js/guide-i18n.js` 新增 `translateHeadFromDict()`：
- 先从 `meta description` 取首个 `。` 前完整句，查词典；
- 只有描述能完整英文化时才继续，避免「英文标题 + 中文描述」混排；
- 标题去掉 ` - ToolBox` 后缀后查词典（允许空白差异归一），命中则写 `英文 - ToolBox`；
- 同步 `og:title` / `twitter:title` / `og:description` / `twitter:description`；
- pack 页面 `HEAD_APPLIED` 为 true 时不重复处理。
