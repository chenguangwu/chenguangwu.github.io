## 销账条目
- IT-N297 格式化插入换行/注释改变 ASI 或产生语法错误。
- IT-N298 压缩删除换行与语句边界，多数多语句脚本不可运行。
- IT-N299 校验只数括号，非法语法也报通过。

## 复核与修复
- N297/N298 主体已由其他 Agent 改为保留必要换行；本批进一步收敛为「不改写换行」的安全策略：
  - `formatJs()` 只重排行首缩进与 token 间空格，原换行（含 `return` 后换行、块注释内联位置）一律保留，不再因 `{` / `;` / 注释强制插入换行。
  - `minifyJs()` 删除注释与多余空格但保留原换行作为 ASI 边界；压缩结果用 `new Function(out)` **只编译不执行**自检，失败则清空输出并报错，不让坏代码被复制。
- N299 `doValidate()` 保留括号统计输出，但结论改为 JS 引擎编译校验（`new Function(src)`，不执行代码）：非法语法报「❌ 语法错误」；括号不平衡仍单独报错；`import/export` 明确提示需 module 环境。
- 公式说明、deep-dive FAQ、中英映射三源同步：不再宣称"只数括号"或"格式化一定不动语义"，改为说明保留换行 + 编译自检的边界。

## 关键结果
- `const x = 1/*c*/+2\nconsole.log(x)` 格式化后仍算出 3；`function f(){ return\n{a:1} }` 返回 `undefined`（ASI 未被合并）。
- `let i=0\ni++\nj=1`、`const a=1 // hi\nconst b=2`、`let x=5\nconst y=[1,2].map(...)` 压缩后均可编译运行；`let a = ;` 压缩报错且输出为空。
- `const 1 = 2;` 校验报语法错误；`const x=1;` 报语法检查通过；`function f(){` 报括号不平衡。
