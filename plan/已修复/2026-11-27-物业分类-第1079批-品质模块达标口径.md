# 第 1079 批：品质检查综合优秀不再误称全部模块达标

- 修复时间：2026-11-27
- 类型：隐藏逻辑 / 结论口径
- 涉及页面：`tools/property/checker-7.html`

## 问题
结论只按加权综合分判断：综合分 ≥85% 即输出“各模块均达标”。单一低分模块可被其他高分模块抵消，与模块等级、整改项自相矛盾。

## 修改
- 明确模块达标阈值：适用模块得分率须 ≥70%；全维度 N/A 的模块不参与达标判断。
- 结论固定展示“当前未达标模块”清单（模块名 + 得分率）；无未达标模块时显示“无”。
- 只有 `综合分 ≥85` 且未达标模块为空时，才输出“所有适用模块均达到 70% 及以上”。
- 综合分优秀但仍有模块 <70% 时，改为“综合得分达到优秀，但仍有模块未达到 70%：<模块清单>；不能表述为全部模块达标，须先整改薄弱模块（整改项见上方对应模块明细）。”
- 总评良好/基本合格/不合格分支保留，但不再暗示各模块均达标。

## 真机验证
- 全维度均评“优”：综合 100.0%，未达标模块“无”，结论为“所有适用模块均达到 70% 及以上”。
- 保洁前 3 项评“差”、其余全“优”：综合 90.0% / 优秀，未达标模块“保洁服务（60.0%）”，结论明确否定“全部模块达标”，并指向模块整改明细。
- 原示例（全“良”）：综合 75.0%，未达标“无”，结论正常输出优秀。
- 英文探针 `property/checker-7` 残留 0；`scripts/verify_property_calc.js` 26/26；`_test_static.py` 4654 通过 / 0 失败 / 0 告警。

## 复核要点
1. 综合 ≥85% 但任一适用模块 <70% 时，不得出现“各模块均达标”。
2. 全 N/A 的模块不进入分母，也不进入未达标清单。
3. 结论中的未达标模块名与百分比须与上方模块明细一致。
