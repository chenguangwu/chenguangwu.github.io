# 复核失败重做批次 · 申请再次复核 — IT-N471

> 来源：`plan/复核失败/2026-11-09-第一批.md` 的「IT-N471 小尺度非零向量的夹角与平行判定错误」条目，重做后重新移交。

## 复核失败点原文
A=(1e-7,0,0)、B=(0,1e-7,0)，均为非零向量且夹角 90°，页面却不显示角度，并错误宣称叉积为 0、向量平行；A=(1e-7,0,0)、B=(-1e-7,0,0) 也不显示应有的 180°。固定绝对阈值把小尺度非零向量及叉积误当作零。

## 根因
`calculate()` 用固定 1e-12 绝对阈值：`mA*mB>1e-12` 门控角度显示、`mC<1e-12` 判平行。小尺度向量 `mA*mB=1e-14<1e-12` 导致不显示角度；叉积 `mC=1e-14<1e-12` 直接误判平行。

## 修复位点
- `tools/it/vector-cross-product.html:286-296`：角度显示条件改为 `mA>1e-300 && mB>1e-300`（仅挡真正零向量）；平行判定改为相对阈值 `mC <= 1e-9*mA*mB`（即 `sinθ` 相对量级），零向量走 else 分支保留「平行 / 其一为零」提示。

## 验证证据
- node 独立复算：小尺度正交→θ=90°、par=false；小尺度反向共线→θ=180°、par=true；普通 135°/90°/45° 同原值。
- `scripts/verify_it_calc.js` 新增 2 条小尺度用例（正交 / 反向共线），整 slug 回归 40/40 通过；既有 135°/180°/90°/45°/零向量护栏用例同绿。

## 判别力实测（回退源码应转红）
回退至固定 1e-12 阈值后：小尺度正交 `mA*mB=1e-14<1e-12` 不显示角度、`mC=1e-14<1e-12` 误判平行 → 新用例转红；普通尺度用例不受影响（既有的 135/180/90 用例修复前后同绿）。
