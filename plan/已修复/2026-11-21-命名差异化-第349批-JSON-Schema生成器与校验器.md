# 第349批：JSON Schema 生成器 / 校验器名称差异化

## 问题
`audit_seo_d.py` 最后一对高置信重复为 `it/json-schema-generator` 与 `it/json-schema-validator`。两者功能正交（前者由样例推断 schema，后者按 Draft-07 校验数据），不应合并；但标题只差后缀，名称相似度 0.828，易被搜索与用户混淆。

## 处理
- 生成器改为 `JSON Schema 生成器（由样例推断）`，英文 `JSON Schema Generator (Inferred)`。
- 校验器改为 `JSON Schema 校验器（Draft-07）`，英文 `JSON Schema Validator (Draft-07)`。
- 同步两页 `<title>` 源、可见 H2、sr-only H1、面包屑、WebApplication 与 BreadcrumbList JSON-LD、`i18n/tools/it.json`、`it-body.json` 与第三层英文映射。

## 验证
- `audit_seo_d.py`：高置信重复 1→0；工具总数 4,676 不变。
- 两页英文探针 0 残留；inline JS 0 错误。
- 静态 4,696 / 0 / 0；全量门禁 268/268。
