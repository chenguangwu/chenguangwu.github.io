## 第 305 批 · PCR 阴性对照无扩增合法输入无法通过质控
- 根因：`tools/clinical-lab/pcr-ct-interpretation.html` 阴性对照输入框明示「无扩增填0」且默认 `value="0"`，但 `interpretQual()` 用 `negFilled = isFinite(neg) && neg>0` 判已填 ⇒ 填 0 时质控永远「未完成」；同时原污染检查 `negFilled && neg<cutoff` 会把合法的 neg=0 也判「阴性对照扩增=污染」。
- 修复：
  - 阴性对照按**原始串**判空：`negRaw.trim()!=='' && isFinite(neg) && neg>=0`，明确 0（无扩增）视为已填；阳性对照仍须 >0。
  - 污染检查加 `neg>0` 前置：阴性 0 不再误报扩增污染；仅 0<neg<cutoff 才提示污染。
  - 中英文「质控未完成」提示同步新口径：阴性 Ct ≥0（0 表示无扩增）、阳性 Ct >0。
- 边界 5/5：阴性 0 + 阳性 22 → 质控正常；阴性 5 → 污染；阴性留空 → 未完成；阳性留空 → 未完成；阳性 0 → 未扩增。
- verify 用例：清空阴性对照（默认 0）要求「质控未完成」并绑定新提示中的「≥0，0 表示无扩增」；默认态质控正常不含该串 ⇒ 强判别。原「阴性 0 → 正常」态因默认即命中不构成判别，仅由 JSDOM 探针覆盖。
