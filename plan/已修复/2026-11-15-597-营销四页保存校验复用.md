# 597 批：营销四页保存路径与计算路径共用校验

## 共同根因
- `saveHistory()` 只保留最早的第一段 `isNaN` 守卫，`calc()` 后来追加的口径校验（负数、口径倒挂、区间越界）没有同步 ⇒ 非法输入产生的结果仍写入历史并参与分级/趋势，用户拿到错误沉淀。

## 改法
- 每页新增 `__xxxErr(v)` 返回错误文案；`calc()` 的多段 `if` 收敛为一次调用，`saveHistory()` 的第一段守卫换成同一函数。文案逐字保留，变量读取与结果渲染完全不动，old_string 只覆盖校验段。
- `marketing-churn-rate` → `__churnErr`（有效数值 / 负客户数 / 期初+新增<期末）；`marketing-conversion-rate-calculator` → `__convErr`（有效数值 / 负转化 / 转化>访问）；`marketing-cpa-calculator` → `__cpaErr`（有效数值 / 客户>点击 / 毛利率 0–100）；`marketing-cpm-calculator` → `__cpmErr`（有效花费与展示 / 点击 0–展示）。
