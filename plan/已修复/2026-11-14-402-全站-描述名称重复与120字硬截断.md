# 2026-11-14-402 全站 · meta description 名称重复、隐私套话与 120 字硬截断

## 发现（全站扫描）
- **55 页名称重复**：`meta/og/twitter/JSON-LD` 形如「债券定价计算器是一款免费的在线投资理财工具，**债券定价计算器。**输入面值…」——
  外层模板已带工具名，`i18n/tools/<ind>.json` 的 `zh-CN.intro` 又以工具名开头，同一主语出现两次。
- **名称退化为标题**：部分生成页唯一可取的 `data-zh` 是 h2（如「🧮 火锅食材分量计算器」），描述变成
  「XX是一款免费的在线YY工具，🧮 XX。免费在线工具，纯前端处理，数据不上传，保护隐私安全……」——名称 + 三连套话。
- **隐私套话当描述**：正文 `<p>数字谜题生成（24点游戏）。免费在线工具，纯前端处理，数据不上传，保护隐私安全。</p>`
  被当作描述来源，实际零功能信息。
- **179 页 120 字硬截断**：`seo_desc = ...[:120]` 直接切片，摘要停在「…打开浏览器即可」「…纯」等半个词上。

## 修复
- `scripts/tool_desc_source.py`
  - 新增 `strip_name_prefix()` / `clean_zh_candidate()`：剥掉描述开头的工具名（允许 `🧮` 等装饰前缀）与残留模板前缀；
    剥完只剩隐私套话尾句时按「无描述」处理，继续回退。
  - `ZH_BOILERPLATE` 增加「免费在线工具，纯前端处理 / 专业计算，数据本地处理」等整段套话特征。
  - `zh_desc()` 的 desc / intro / 人工精翻 / 页面 meta 四条候选统一走清洗，分类页、搜索、导航、`tools.json` 的 `d` 同源收敛。
- `_build.py`
  - `extract_zh_desc()`：i18n intro 先剥名称前缀；`<p>` 与 `data-zh` 候选统一清洗；新增
    `_DESC_BOILER_PAT` `_DESC_NAV_PAT` `_desc_low_value()`，过滤标题复述、导航文案、FAQ 问句与隐私套话。
  - 新增 `_clip_zh_desc()`：meta（120）与 JSON-LD（150）按句末标点 → 逗号/顿号/冒号收口，找不到才补省略号。
