# 第 112 批：文本统计总词数与停用词口径分离（IT 开发）

- 日期：2026-11-21
- 页面：`tools/it/text-statistics.html`
- 原问题：`总词数` 与词频共用同一份「过滤停用词后」的词数组。输入英文停用词 `the` 时，页面同时显示「英文词 1」和「总词数 0」，自相矛盾；用户无法区分「总词数」和「参与词频统计的词数」。

## 修复

- 新增 `contentWords` 作为去停用词后的词数组，只用于词频、Top20 与「不同词」。
- `allWords` 不再过滤停用词，`总词数` 改为真实 token 总数（中文单字 + 英文词）。
- 结果卡新增 `去停用词` 指标，避免用户把「总词数」误解为词频样本量。
- 公式框同步改为：`总词数 = 中文单字 + 英文词（不去停用词）`、`去停用词 = 过滤停用词后的词数；不同词 = 去停用词后去重计数`。

## 验证

- 新增用例：输入 `the`，断言 `1 总词数` 与 `0 去停用词`；旧实现会得到 `0 总词数`，可直接判别。
- 同步一条旧自动补强用例的完整输出串（新增指标后输出多出 `0 去停用词`）。
- `node scripts/verify_it_calc.js it/text-statistics`：7/7 通过。
- 构建 4,426 页成功；内联脚本 12,102 段 0 错误；静态检查 4,705 通过 / 0 失败 / 0 警告。

## 口径说明

`不同词` 仍表示「去停用词后的不同词数量」，因为它服务于词频 Top20。若后续需要「全部不同词」，应另加指标，不与当前口径混用。
