## 清单项
- **IT-N49**（高）：chmod 计算器只支持三位数权限，缺少 setuid/setgid/sticky 特殊位与四位数模式（如 4755/1777），符号模式无 s/S、t/T 标记 —— 本批真修并销账

## 改动
1. **特殊位控件**：新增三个复选框 `#suid`(4) / `#sgid`(2) / `#sticky`(1)，`onchange="calc()"`，中文标签 `setuid（4）/setgid（2）/sticky（1）` 同步进 `i18n/tools/en/it/chmod-calculator.json`。
2. **四位数快捷预设**：新增按钮 `4755`、`1777`；`quick(d)` 识别四位数——最高位 `sp=parseInt(s.charAt(0),10)`，低三位 `base=s.slice(1)`，并按位回填三个复选框（`sp&4 / &2 / &1`），三位数调用清空全部特殊位。
3. **`calc()` 计算特殊位**：`sp = suid*4 + sgid*2 + sticky*1`，`digits = sp ? String(sp) : ''`，输出四位数权限码。
4. **符号模式 s/S/t/T**：执行位被特殊位标记时，setuid/setgid 位用 `s/S`、sticky（其他用户位 i===2）用 `t/T`——
   ```javascript
   var xch = marked ? ((i===2) ? (x?'t':'T') : (x?'s':'S')) : (x?'x':'-');
   ```
   修正了初版把所有特殊位执行位都标成 `s/S` 的 bug（sticky 应为 `t/T`）。
5. **提示与复制**：tips 增加 4755/2755/1777 说明与英文 fallback；复制命令包含四位模式（如 `chmod 4755 <file>`）。
