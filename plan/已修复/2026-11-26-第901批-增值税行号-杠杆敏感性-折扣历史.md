# 第901批：增值税批量行号、财务杠杆敏感性、折扣历史与零值语义

日期：2026-11-26
范围：`plan/finance` 10 项任务

## 修复清单

1. **增值税批量 — 错误行缺少原始位置**
   - 新增 `__vatBatchScan()`：保留原始行号；空行忽略，非数字/负数进入 `errors`，有效行保留 `{lineNo, amt}`。
   - 新增 `__vatBatchErrorHtml()`：逐行展示原行号、原始输入、原因；合计注明“有效行 N 行；已忽略 M 行，合计不含这些行”。
   - 表头与 CSV 均改为“原行号”，有效行首列显示原始行号；CSV/复制结果末尾附错误清单。
   - 真机输入 `1000 / abc / 空行 / -5 / 5000`：有效行 1、5，错误行 2、4；合计不含错误行。

2. **财务杠杆 — 敏感性分析错误固定变动成本**
   - 敏感性表改为“变动成本率保持不变”：营收变化时按 `cm2=s2*(1-vRatio)` 重算边际贡献，不再固定变动成本总额。
   - 表前补明假设：变动成本率不变、固定成本/利息/税率/股数不变。
   - 深挖算例同步改为营收 ±10% 对应 EBIT ±20%；净利润/EPS 示例同步更新。
   - 同步 `i18n/tools/content_deepdive.json` 与英文 `analysis-risk.json`。

3. **投资回报率 — 空终值被当作全部亏损**
   - `calcSimple()` / `calcRegular()` 先读取原始字符串，任一必填项为空即提示“留空不计算，数字 0 才表示真实零值”，不再按 0 计算 −100%。
   - 终值显式填 0 仍正常输出 −100%。

4. **仓位计算 — 加仓次数为 0 导致页面异常**
   - 马丁格尔入口校验初始仓位、倍数、次数、跌幅；次数须 1–20 整数，倍数 1–100，跌幅 0–100%（仅单层允许 100%）。
   - 非法输入清空结果/统计/图表并给出具体错误，不再访问空仓位数组。
   - 真机 `m-times=0` 显示明确错误，`m-times=1` 正常出加仓计划。

5. **盈亏平衡 — 亏损销量安全边际被截为零**
   - 安全边际改为带符号的 `实际销量 − 保本销量`；低于保本显示负值并注明“距保本还差 X 件”。
   - 零销量时安全边际率显示“不可定义”（分母为 0），不再显示 0%。

6. **盈亏平衡 — 保本点经营杠杆误显示 0**
   - 利润为 0 时经营杠杆显示“未定义（边际贡献 ÷ 0 无定义；保本点两侧杠杆趋于无穷）”。
   - 非零利润仍按边际贡献/利润计算。

7. **分期实际利率 — 空手续费率默认按 0**
   - 核验现有源码已具备原始空值守卫：空费率提示“请填写每期手续费率；无手续费请显式填 0”，并清空结果/图表。
   - 本批未重复改动，真机复核留空提示、填 0 正常计算。

8. **折扣计算器 — 叠加折扣说明精度与输入不一致**
   - 标签改为“折扣（0–10 折，最多两位小数，支持叠加）”，输入步长 0.01。
   - 校验改为容差比较 `Math.abs(Math.round(x*100)-x*100) < 1e-9`，修复 8.55 折因浮点误差被判非法。
   - 折扣链输入显示按两位小数取整，避免 `8.550000000000001`；公式展示去尾零，结果注明按输入值计算并保留两位小数。

9. **折扣计算器 — 历史恢复遗漏折扣链和税务方向**
   - 历史快照新增 `__tbMode`、`__tbDiscounts`、`__tbTaxDir`。
   - 恢复时先解析折扣链/税务方向，再 `setMode`，随后重新回填输入并 `calc`；旧记录缺字段给兼容提示。
   - 真机验证模式 0 恢复两个 8.55 折并复算 73.10；模式 2 恢复“税后拆税”和金额/税率。

10. **货币代码查询 — 未命中与数据过时**
    - 标注数据版本 `2026-11`，明确当前仅维护 51 个常用 ISO 4217 代码，不是完整列表；未收录不代表代码无效。
    - EUR 地区改为“欧元区（成员国名单随数据版本维护，不固定展示数量）”，不再固定 19 国。
    - 页面描述、`i18n/tools/finance.json` intro 与英文 `currency-lookup.json` 同步“常用/非全量”口径。
