# 375 设计 · 图片取色器忽略 alpha 修复（D-N46）

- **分类**：04-设计创意
- **工具页**：`tools/design/image-color-picker.html`
- **日期**：2026-11-14
- **缺陷编号**：D-N46（中，确认源码缺陷）

## 缺陷与根因

预览区固定白底（`.preview-area{background:#fff}`，行 29），但取样用的是**透明 canvas**（行 269-272 直接 `drawImage`，未铺底），`pickColor` 只读 `data[0..2]`（行 292-294）丢弃 alpha：

- 半透明像素：画面呈现的是与白底混合后的颜色，报告值却是未混合的原始通道；
- 全透明像素：画面显示白色，报告 `#000000`。

复现：上传 50% 透明度纯红 PNG → 画面接近 `#FF8080`，HEX 输出 `#FF0000`；全透明区域点选 → 画面白、输出 `#000000`。

## 修复

按 design.md 方案一（"取样前先填白，使取样与预览一致"）落实，但采用**在 `pickColor` 内合成**而非改写 canvas 内容——效果等价且可被验证覆盖：

```js
const data = ctx.getImageData(x, y, 1, 1).data;
const a = data[3] / 255;
const r = Math.round(data[0] * a + 255 * (1 - a));
const g = Math.round(data[1] * a + 255 * (1 - a));
const b = Math.round(data[2] * a + 255 * (1 - a));
```

合成底色取 `#FFFFFF`，与预览区白底严格一致。canvas 内容保持原始（未污染），`getImageData` 的 alpha 仍可用，后续若需展示透明度无需再改取样链路。

## 验证（含旧源码差分）

新增 verify 强锁 `design/image-color-picker`：注入 `data=[255,0,0,128]` + 桩元素，调用 `pickColor`，断言 `#hex` 与 `#rgb`。
