# 第 977 批 · 单摆/弹簧曲线无效态与采样精度

日期：2026-11-26
状态：已修复并本地提交（未推送）

## 修复范围

- `tools/science/pendulum-period.html`
- `tools/science/spring-oscillation-period.html`

## 问题

1. 曲线生成 `__pdprSweep()` / `__sospSweep()` 在参数无效（空、0、负数）时返回 `null`，`__pdprChart()` / `__sospChart()` 直接 `return`，已有旧曲线继续显示，与主结果区的「请填写/不能为 0」提示矛盾。
2. 横轴标签固定舍入：单摆 `Math.round(lk*1000)/1000`、弹簧 `Math.round(kk*100)/100`。小尺度输入（L=0.0001 m、k=0.0001 N/m）时全部标签变成 0，曲线无法读。
3. 曲线数据固定四位小数（`Math.round(T*10000)/10000`），微小非零周期/角频率可能被画成 0。

## 修复

- 新增 `__pdprAxis(v)` / `__sospAxis(v)`：常规量级 `0.01~1000` 仍保留 3 位小数；小于 0.01 或大于等于 1000 时按 4 位有效数字输出 `Number(v.toPrecision(4)).toString()`，避免全 0 标签。
- 采样数据不再固定四舍五入，直接写入完整 `T`、`1/T`、`ω`，保留计算精度。
- 曲线函数先取容器并判断采样：无效时清空 `#pdprChart` / `#sospChart`，写入中英文空态「请输入有效参数后再绘制曲线。」/「Enter positive values before plotting the curve.」；有效时才调用 TBKit 绘图。
- 主计算仍由 `__tbInputGuard` 拦截并清空明细表，本次未改其判定口径。

## 真机复核

- 单摆 L=0.0001 m、g=9.80665：标签 `0.00002 / 0.000036 / 0.000052 / 0.000068`，周期数据 `0.0089729…` 非 0，图表渲染 4787 字符。
- 单摆先 L=1 出图、再改 L=0：图表容器只剩「请输入有效参数后再绘制曲线。」，旧图消失，无 JS 报错。
- 弹簧 m=k=0.0001：标签 `0.00002 / 0.000036 / …`，周期 `14.0496…` 非 0，图表渲染 4767 字符。
- 弹簧先 m=1 出图、再改 m=0：容器只剩空态提示，旧图消失，无 JS 报错。
