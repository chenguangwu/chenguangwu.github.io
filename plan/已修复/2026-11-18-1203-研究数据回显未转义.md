# 第 1203 批复核失败：研究数据回显未转义

`tools/research/analysis-50.html` 和 `analysis-51.html` 把用户输入的企业名/时段名，以及新增的 `badLines` 原文直接拼入 HTML 后赋给 `innerHTML`，没有转义。例如有效行 `<img src=x onerror=alert(1)>,1` 会把名称当作 HTML；添加一行无效数据也可通过错误提示原文触发。应对所有用户输入采用文本节点或 HTML 转义，包括表格、领先名称和无效行。负值、全零和越界评分的原判定守卫已核对。

## 修复验证（2026-11-18）

对两页表格名称、领先/峰值名称及无效行逐项转义。浏览器输入含 img/onerror 的有效名称和无效行，两页结果均作为文本展示且结果区 img 元素数为 0；各专项测试均 4/4。
