## 1. 保留注释选项真正可见、可导出

- 新增 `#commentPanel` 与 `#commentList`，解析后由 `renderComments()` 以独立列表展示每条注释的「行注释 / 块注释」类型、内容与位置（有 `loc` 显示 `Lx:y`，否则显示 `[start..end]`），位置只显示一次。
- JSON 视图与复制改用 `astExportValue()`：勾选 `optComments` 且存在注释时导出 `{ast, comments}`，不修改 ESTree 节点形状、不把注释塞进 `body`；未勾选或没有注释时仍导出纯 AST。
- 注释面板与 JSON wrapper 均随 `optComments` 开关实时切换；新增的中英文案已写入 `i18n/tools/en/it/ast-viewer.json`。

## 2. 错误指示符按显示宽度对齐

- `showError()` 改用 `__astDisplayWidth()` 计算列宽，`__astExpandTabs()` 处理缩进：Tab 按 4 列展开，CJK / 全角 / emoji 按 2 列，组合符按 0 列。
- caret 用 `' '.repeat(width)` 生成，替换旧 `new Array(col).join(' ')`（少一列）的实现；Chrome 实测行首 0、中间 10、Tab 14、CJK 11，均落在错误列。

## 3. 源码持久化改为显式 opt-in

- `<body data-no-persist>` 退出全站 `js/tool-ux.js` 的自动保存，源码不再默认写入 localStorage。
- 新增 `optPersist` 复选框（默认未勾选）与 `btnClearSaved` 按钮，并新增说明文案；本页使用独立键前缀 `tb_ast_persist_`，opt-in 键为 `tb_ast_persist_optin`。
- 未勾选时保存函数直接返回；加载时清理旧版本 `tb_ux_/tb_uxp_` 遗留键；勾选后才保存代码与设置，刷新可恢复；清除按钮删除本页键并取消勾选。
- Chrome 验证：默认无本页键且载入示例；伪造 legacy 键被清理；主动勾选后刷新恢复代码与注释选项；清除后本页键为空、选项复位。

## 4. 输入或选项变化后旧 AST 立即失效

- 新增 `invalidateAst()`，清空 `currentAst` / `currentComments`、树、JSON、统计、选中源码、错误与注释面板。
- `codeInput` 的 `input`、`ecmaVersion` / `sourceType` / `optLocations` / `optComments` 的 `change` 均触发失效；Tab 缩进后主动派发 `input`。
- 恢复自定义事件 `tb:ast-restored` 后按恢复值重新解析；复制、展开、折叠均因 `currentAst=null` 被锁，不再把旧树当作当前输入。
