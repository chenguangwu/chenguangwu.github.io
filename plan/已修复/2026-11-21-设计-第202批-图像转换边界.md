# 第 202 批：SVG 画布上限、极端比例、换图竞态与打印预设

日期：2026-11-21
范围：`04-设计创意/design.md` AB 批 D-N219–D-N227（图像/格式转换族）

## 修复项

1. `tools/design/svg-to-png.html`
   - 宽高只校验正数，6000×6000@3x=3.24 亿像素超画布上限，`toDataURL` 返回 `data:,`，下载 0 字节且无提示。新增 `w×scale×h×scale > 1 亿` 前置拦截，清空旧图并明确提示「输出超过 1 亿像素，请降低宽高或倍率」。
   - 预设「高清 2 倍图 800×800」补 `"scale":"1"`，避免沿用上一次 3x 实际输出 2400×2400。
   - 「复制 Base64」的 `clipboard.writeText` 补 `.catch` 降级提示，权限拒绝时不再静默。

2. `tools/design/px-to-rem.html`
   - 62.5% 根字号说明方向写反：改为「上表 rem 值直接乘以 1.6」，与示例 16px→1.6rem、24px→2.4rem 一致。

3. `tools/image/image-compress.html`
   - `calcDims` 极端纵横比可算出 0 边（1×4000 配 1920 长边 → 宽 0），导致 canvas 0 宽、压缩失败。两边均改为 `Math.max(1, Math.round(...))`，最小保留 1px。

4. `tools/image/image-resize.html`
   - `MAX_SIDE=10000` 只限单边，10000×10000=1 亿像素会双份画布约 800MB、Safari 直接空白。新增 `MAX_PIXELS=1600 万` 面积上限，两处尺寸校验均拦截并提示降低尺寸/比例。
   - 输出格式改为读取 `blob.type`，浏览器不支持 WebP 回落 PNG 时，结果行与下载扩展名显示实际格式并注明回落。

5. `tools/image/image-converter.html`
   - 换图无竞态令牌：旧图 3 个 `toBlob` 回调晚到会向新网格追加旧图卡片。新增 `__convertToken`，`onload`、`convertAll`、每个 `toBlob` 回调都校验令牌，过期回调直接丢弃。
   - PNG/WebP 卡片原写「已保留透明」，源为 JPG 时误导；改为「未铺白底（源图透明通道原样保留）」，JPEG 写「已铺白底（JPEG 无透明）」。

6. `tools/design/photo-print-size.html`
   - 一寸预设 295×413 与表格按 `ceil` 算出的 296×414 差 1px，点预设时「一寸」行仅「基本可用」。预设与按钮统一为 296×414（300DPI 上取整口径）。
