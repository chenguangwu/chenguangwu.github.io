# 第 673 批：全站可访问性治理（axe-core）

## 背景

用 axe-core 4.10.2 + Puppeteer 对 100 个工具页做 WCAG 2 A/AA 真机抽测，首轮 **100/100 页存在 serious/critical 违规**，集中在共享组件与全局配色，而不是单页零散问题。

## 修复内容

### 1. 共享搜索框 ARIA

`js/tool-search.js` 的搜索输入框此前被设置 `aria-autocomplete` / `aria-expanded`，但没有 combobox 语义，触发 `aria-allowed-attr`。

- 输入框补 `role="combobox"`、`aria-haspopup="listbox"`；
- 新增 `setExpanded()`，打开面板置 `aria-expanded=true`、关闭置 `false`；
- 面板补 `id`，输入框补 `aria-controls`；
- `js/common.js` 桌面搜索框补 `aria-label` 与 `data-i18n-aria`。

### 2. 共享标签栏语义

大量页面使用 `.tbk-tabbar role="tablist"`，但直接子按钮没有 `role="tab"`，触发 `aria-required-children`。

`js/tool-ux.js` 新增 `enhanceTabs()`：

- 仅对“纯标签容器”补 `role=tablist`，混合容器（含预设 div、导出按钮）跳过或移除错误 role；
- 标签补 `role=tab`、`aria-selected`、roving `tabindex`；
- 支持 ArrowLeft/Right/Home/End 键切换，div 标签支持 Enter/Space；
- 点击后延迟同步状态，并在 `load` 时兜底，兼容页面后建标签栏。

### 3. 全局语义色对比度

`css/common.css` 调整主题色与语义色，浅色态全部达到 4.5:1 以上：

- `--primary` `#FF6B35` → `#C2410C`，`--primary-dark:#9A3412`，`--primary-hover:#A4370B`；
- `--success:#047857`、`--danger:#B91C1C`、`--warning:#B45309`、`--info:#1D4ED8`、`--muted:#5B6472`；
- 暗色主题单独覆盖：`--primary:#FF9A66`、`--success:#34D399`、`--danger:#F87171`、`--warning:#FBBF24`、`--info:#60A5FA`、`--muted:#9CA3AF`；
- 激活标签 `.tbk-tab.active` 改为 `color-mix` 浅底 + 正文色，替换白字配浅 accent；
- `.btn.danger`、`.err.ok`、`.breadcrumb a`、`.tip-warn` 同步修正；
- `showToast` 四态颜色改为达标的深色值；
- TbSelect 弹层补 `aria-label="选项列表"`。

工具页内 1,468 处硬编码语义色统一替换为 `var(--danger/success/warning/info/text-muted/primary)`（376 + 239 文件两轮）。批量替换曾漏写 `color` 字面量，已完整修复 1,373 处，全站非法 `:var(` 声明残留 0。

### 4. 页面级修复

- `ast-viewer`：`.ast-decl`、`.ast-stmt` 改深色变量；`#astTree` 补 `tabindex/role/aria-label`；
- `json-diff`：暗底差异色改为固定浅色系，标题改正文色；
- `json-schema-generator`：`.jh-null` 改 `#a6adc8`；
- `json-formatter`：树节点颜色改语义变量，`.tree-null` 改 `var(--text-muted)`；
- `jwt-parser` / `jwt-debugger`：`#999`、`#2196f3` 改语义变量；
- `nat-type-test` / `webrtc-leak-test`：警告色改 `var(--warning)`；
- `robots-txt-generator`：两个动态输入补 `aria-label`；
- `svg-placeholder-generator`：生成 SVG 补 `role="img"` 可访问名称（文件字节数由 310 变 333，同步更新对应用例断言）；
- `protobuf-parser`：输出区补 `aria-live` 与 `tabindex`。
