# 第885批：声学物理边界、化学纵轴、矩阵空值、单位参照与检测范围

日期：2026-11-26
范围：10 个扫描任务 / 37 个工具页

## 修复清单

1. **声学输入范围与未定义结果**（`critical-distance`、`pipe-open`、`pipe-closed`、`freq-to-note`、`beat-frequency`、`acoustic-impedance`）
   - 依次补正数校验：体积/混响时间/指向性因子、声速/管长、频率、两频率、密度/声速；零分母不再输出 Infinity。
   - 拍频为 0 时，拍周期显示「—」并说明无有限值；声阻抗页删除 `c||1` 伪造值。
   - 真机：rt=0、L=0、c=0 均给出明确拒绝；f1=f2=42 显示「拍频为 0，拍周期无有限值」。

2. **声学功率/电压比等效分贝**（`decibel-power-ratio`、`decibel-voltage-ratio`）
   - 等阻抗下，功率比 4 的功率级与等效电压级都为 6.02 dB；电压比 2 的电压级与等效功率级都为 6.02 dB。
   - 把「倍频数 (oct)」改为「2 倍功率/电压档数（非倍频程）」，并同步公式说明。
   - 真机：功率 1→4 输出 6.02/6.02；电压 1→2 输出 6.02/6.02。

3. **化学负自由能/电势曲线超出纵轴**（`gibbs-free-energy`、`nernst-equation`）
   - 折线图按全部系列最小值补 `min`，覆盖负值与零线，负 ΔG、负电势不再落到绘图区外。
   - 真机：1000 K、ΔH=-100、ΔS=0.05 时 ΔG=-150，纵轴刻度出现 -24.8/-50.5/-76.3/-102。

4. **化学负对数曲线超出图表纵轴**（`ph-to-h`、`ph-from-ka`、`solubility-product`、`kp-kc`）
   - 为 lg[H⁺]、lg Ksp、lg Kp 等系列补负值纵轴下限，pH 7 的 lg[H⁺]=-7 可正常显示。
   - 真机：pH 0–14 图纵轴刻度出现 -2.9 至 -14.5。

5. **化学主结果失败后仍生成明细**（`gibbs-free-energy`、`kp-kc`）
   - 主计算校验失败时置 `__*_invalid` 标志，Extras 直接返回；同时清空表格与图表，不再写历史或导出。
   - 真机：T=0、Kc=0 时结果区为错误提示，明细表为空。

6. **向量/矩阵空分量按 0、标量空按 1**（`vector-calculator`、`matrix-calculator`）
   - 读取函数区分空串、非法数与合法 0；任一所需分量/单元缺失即拒绝计算，不写历史。
   - 数乘标量空值不再按 1，明确提示填写有效 k。
   - 真机：清空向量 z 分量、矩阵单元、向量/矩阵结果区均提示「空值不等于 0」。

7. **单位换算清空后尺度参照残留**（`angle/area/data-rate/energy/frequency/length/power/pressure/speed/time/volume/weight-converter`）
   - 暴露 `window.__charRefRender`，`clearAll()` 清空输入后同步重绘尺度参照区。
   - 真机：长度换算清空后 `__charRefBox` 由「尺度感知…」变为空。

8. **检测工具非法实测值仍可通过**（`general/detector-200/207/126`）
   - 在空值守卫后增加物理范围校验：所有项目非负、百分率 ≤100%，非法值停止综合判定。
   - 真机：水分 -1 时提示「所有项目不得为负，百分率不得超过 100%」。

9. **化工检测缺项仍参与标准判定**（`chemical/detector-211/213`）
   - 新增缺项守卫，未填写项目不再按 0 参与判定；同时校验非负与百分率上限。
   - 真机：纯度留空时提示「请填写全部检测项目后再判定；空值不等于 0」。

10. **食品工具英文简介与选择提示**（`food/cooking-converter`、`beer-gravity-estimator`、`dough-fermentation-time`、`vitamin-c-compare`）
    - 四条简介改为说明输入与用途的完整英文，同步 `food-body.json`、`_en_override.json`。
    - 烹饪换算的空态提示由工具标题改为「Select an ingredient」，页面源与 JS 空态同步。
