# 第 528 批：119 个指南页英文 title/description 修复

- 日期：2026-11-23
- 范围：类别 3「中英文不全」
- 提交：`6f50594dc1`

## 问题

`guides/*.html` 中有 119 页加载 `js/guide-en-pack.js`，并在 `<title>`、`meta description`、`og:title`、`og:description`、`twitter:*` 上写了 `data-i18n-head` / `data-i18n-head-fb` 键。但运行时：

- `js/i18n.js` 的 `apply()` 只处理 `data-i18n` / `-ph` / `-title` / `-aria` / `-alt` / `-html`，**不处理 `data-i18n-head`**；
- `js/guide-i18n.js` 只替换正文文本节点，不处理 head；
- `GUIDE_EN_PACK` 虽被 119 页加载，但没有任何脚本消费它。

结果 `?lang=en-US` 下正文已英文化，标题和描述仍是中文，英文 SEO/分享卡片失效。

## 修复

`js/guide-i18n.js` 新增 `translateHead()`：
- 扫描 `[data-i18n-head]`，按 `GUIDE_EN_PACK[key]` 取英文；
- 有 `data-attr` 的 meta 写对应属性（content），`<title>` 写 `textContent`；
- 因 `guide-en-pack.js` 可能晚于动态注入的 `guide-i18n.js`，增加 `load` 事件与 0/300/1000ms 重试，`HEAD_APPLIED` 成功即停。

## 覆盖审计

- 静态比对：119 个加载 pack 的指南页共 3,102 个 head 键，`GUIDE_EN_PACK` 缺失 **0**。
- 抽样真机英文态：`uuid-generator`、`csv-to-json`、`parking-fee` 三页 title 分别为 `UUID Generator`、`CSV to JSON`、`Parking Fee Calculator`，description 均为英文。
- 冷缓存连续两次测 `uuid-generator`，title/description 均稳定英文，不再有时序回退。

- 全量 271 项门禁通过。
