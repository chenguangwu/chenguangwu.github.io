# 第808批：YAML 缩进/锚点/转义与 Plist 严格结构

关闭 `plan/it/` 4 项：

- YAML转JSON-Tab缩进生成非法JSON
- YAML转TOML-锚点别名未解析且静默改变数据
- YAML转XML-引号转义未解析导致文本改变
- Plist转换-特殊键和非法结构丢失

## YAML 转 JSON（`tools/it/yaml-to-json.html`）

- Tab 缩进改为真正的 `0x09`：新增 `yamlJsonIndent()`，`'tab'` 返回单字符制表符，2/4 返回数字。
- 旧实现传字面反斜杠 + t，输出在 JSON 空白位置出现 `\t` 文本，独立解析器无法接受。
- 结果同时挂到 `__yamlToJsonLast` 供回归探针读取原始 JSON。

## YAML 转 TOML（`tools/it/yaml-to-toml.html`）

- 新增锚点表与 `yParseVal()`：
  - `a: &n hello` 注册锚点 n，`b: *n` 解析为同一值（深拷贝）；
  - `base: &b` 后的缩进块整体作为锚点值，映射别名可展开为独立表；
  - `*alias` 未定义时抛出 `未定义的 YAML 别名：*xxx`，页面捕获并显示「解析失败：…」，不再静默变字符串。
- 映射/数组内的空值统一为无原型对象。

## YAML 转 XML（`tools/it/yaml-to-xml.html`）

- 新增 `yUnescapeDouble()`：
  - 解析 `\n \t \r \0 \a \b \f \v \e \N \_ \L \P \\ \" \/ \空格`；
  - 支持 `\xXX`、`\uXXXX`、`\UXXXXXXXX` 码点；
  - 非法/未知转义按 YAML 习惯保留字符。
- 单引号标量按 YAML 规范把成对 `''` 还原为一个 `'`。
- 新增 `yCollectBlock()`：支持 `|`、`|-`、`|+`、`>`、`>-`、`>+` 块标量，字面保留换行/折叠为空格，并按 chomping 处理末尾换行。
- 原始 XML 挂到 `__yamlToXmlLast` 供回归探针读取。

## Plist 解析（`tools/it/plist-parser.html`）

- dict 改用 `Object.create(null)`，`__proto__` 等任意合法 key 作为自有属性完整进入 JSON。
- 严格结构校验：
  - key 后缺 value：`dict 中的 key「x」缺少对应 value`；
  - value 前缺 key：`<tag> 缺少前置 key`；
  - 重复 key：`dict 中重复的 key：x`；
  - array 内出现 `<key>`：明确报错；
  - 未知标签：`不支持的 plist 标签：<tag>`，不再静默转文本；
  - 缺少 `<plist>` 或根值：明确报错。
