# 675 批：价格行情页千分位解析与拒绝项提示

来源：`plan/categories/12-长尾行业/_others.md`（V 批 12-N199）。

## 问题与修复

`tools/metallurgy/analysis-price-1.html`：

- 旧实现 `split(/[,\n\s]+/) + parseFloat` 会把 `45,000` 拆成 45 与 000，`45O00` 截成 45，负价也照收，页面只显示样本数 n。
- 新增 `parsePrices()`：
  - 先按换行/分号/制表/空格切 token；
  - 命中 `^\d{1,3}(,\d{3})+(\.\d+)?$` 的 token 视为千分位，先剥离逗号；
  - 其余含逗号 token 按逗号拆分为多价格；
  - 仅接受 `^\+?\d+(\.\d+)?$` 且 `>0` 的价格，其余进入拒绝列表并保留原文。
- 结果表新增「已拒绝样本」行（数量 + 前 8 条原文，HTML 转义）；有效样本不足 2 条时在提示中列出被拒项。
- 基准价非法或 ≤0 时回退为均价。
- 标签与英文映射同步说明千分位支持与拒绝规则。
