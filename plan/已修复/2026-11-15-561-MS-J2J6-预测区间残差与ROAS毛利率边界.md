# 561 批：销售预测置信区间改用残差 σ、ROAS 毛利率边界（MS-J6 / MS-J2）

日期：2026-11-15
范围：`tools/sales/sales-forecast.html`、`tools/marketing/marketing-roas-calculator.html`

## MS-J6 置信区间用历史标准差而非残差，文档口径自相矛盾

### 问题
- `forecast()` 的 95% 区间固定用 `std(hist)`，`linreg()` 已算出的残差 `sigma` 从未使用；
  完美线性序列被展示成很宽的区间（[100,110,120] → 预测 130，区间 [110.4,149.6]）。
- 同一页「说明」写「基于历史残差标准差」，深度解析 FAQ 写「以历史标准差 σ」，两套口径并存。
- 公式框写 `± t×σ×√(1+1/n)`，与代码的 `±1.96σ` 也不一致。

### 修复
- `forecast()` 计算并返回 `sigmaKind`：
  - 线性回归：使用 `linreg()` 的残差标准差 `lr.sigma`；
  - 移动平均 / 加权移动平均：用滚动一步预测残差（至少 2 个残差才生效）；
  - 季节性：样本不足，退回历史标准差。
- 结果区新增「95% 区间口径」一行：残差口径显示 `模型残差 σ=¥X`；回落时显示
  `历史 σ=¥X（样本不足，以历史波动近似）`，不再让用户猜区间依据。
- 公式框改为 `预测值 ± 1.96×σ（σ 取模型残差标准差，样本不足时退回历史标准差）`。
- 「说明」信息框与深度解析 FAQ 同步为残差口径，并说明不足时回落；EN 字典同步新增/替换键。

### 验收
- LR、历史 [100,110,120] → 残差 σ=0.00，95% CI 为 130.00 ~ 130.00（修复前为 ±10 的宽区间）。
- MA、5 期线性数据 → 残差 σ=0.00，区间收敛到单点。
- MA、3 期 N=3（无一步残差）→ 标注「历史 σ=¥10.00（样本不足，以历史波动近似）」。
- 季节性、4 期 → 标注历史 σ 口径。

## MS-J2 ROAS 页毛利率边界（负数已处理，补 100% 与空值口径）

### 问题
- 原条目「亏损时输出负平衡 ROAS」已由前序批次改为「毛利率 ≤0 时不输出平衡点」。
- 仍存在两处边界：毛利率恰为 100% 时被 `gm < 100` 判为无平衡点（实际应为 1x）；
  毛利率为空时被当作 0，标签统一写「毛利率≤0，无平衡点」，与「未填」混淆；>100% 也无拦截。

### 修复
- 区分「未填」与「有效值」：空值 → 显示 `—` 与「盈亏平衡ROAS（未填毛利率）」。
- 平衡 ROAS 条件改为 `gm > 0`（100% 时输出 1.00x）；`gm < 0` 或 `gm > 100` 直接提示
  「商品毛利率须在 0–100% 之间，请修正后再计算」。
- 毛利率为 0 时保留「毛利率≤0，无平衡点」说明。

### 验收
- 花费 1000 / 收入 2000 / 毛利率 100% → 平衡 ROAS 1.00x。
- 毛利率 120% → 结果区提示范围错误，不再计算。
- 毛利率为空 → `—` 且标签为「未填毛利率」。
- 毛利率 0 → `—` 且标签为「毛利率≤0，无平衡点」。
