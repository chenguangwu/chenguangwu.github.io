# 598 批：营销零费用与零收入口径显式化（0/0 假合规 + 静默兜底）

## 共同根因
- 分子分母同时为 0（或分母为 0）时，页面把 `Infinity` / `NaN` 统一替换成破折号，却继续给出「健康」「回本」「优秀」等结论；反过来又把「花费为 0」这种合法输入当成无效直接拒绝。两类都让用户拿到不可复现的口径。
- 「客单价没填」与「客单价确实是 0」被 `parseFloat(...) || 0` 合并成同一条路径，零收入亏损因此无法显示。

## 改动
- `marketing-cac-calculator`：费用合计为 0 时保留合法的 CAC=¥0.00，新增「零费用口径提示」明确 LTV:CAC、投资回报率、回本周期、费用占比的分母为 0 均不可计算，不再渲染健康度分析；CAC 等级标注不与有投入的情形可比；费用占比显示 `—`。
- `marketing-cpm-calculator`：`spend<0` 才判无效，零花费 + 展示量>0 合法输出 CPM ¥0.00；两处以 CPM 为分母的「每百元可获展示」显式显示不可计算，不再出现被替换的 `Infinity`。
- `marketing-cpa-calculator`：零花费时 ROI 卡改为「分母为 0，不可计算」，不再显示 `+0.0%`「回本」。
- `marketing-conversion-rate-calculator`：区分客单价留空（不评估 ROI）与明确填 0（显示 −100.0% 亏损）；零转化历史记录写明「CPA 不可计算（零转化）」而非把 `Infinity` 静默替换。
- 同步销账 4 条已修/过时结论：`engagement-rate` 互动数清空、`google-ads-budget` 目标日点击 0 的 ROAS（现有 `clicksDay<=0` 校验已拦住）、零转化历史 CPA、零花费边界；`ad-budget-allocator` 的零预算 ROAS 仍待办，已在清单中单独保留。
