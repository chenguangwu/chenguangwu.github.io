# 第300批 · 老板报告：brinell-hardness 图表区域显示异常（宽屏偏右留白）

## 现象
老板截图反馈 `tools/materials/brinell-hardness.html` 图表区域异常：tabs 在左、图表曲线只占页面中右侧约 580px，左侧大片空白。

## 根因
共享 `js/tool-kit.js::canvas()` 把 SVG `viewBox` 固定为 `0 0 640 220`，同时 SVG `width:100%` + `height:220`。宽屏（截图 1198px）下容器被拉到 1198px，但 viewBox 仍 640，`preserveAspectRatio='xMidYMid meet'` 让 640×220 内容在 1198×220 视口内等比缩放居中 ⇒ 图表只占中间部分，左右留白。本地复现（1198px 视口）：`#bhChart` 与 svg 均 1198px 宽，viewBox 仍 `0 0 640 220`。

## 修复（向后兼容，零影响其他页）
- `js/tool-kit.js::canvas()`：新增可选 `opts.width === 'container'`，传时用宿主容器 `getBoundingClientRect().width`（下限 320）作为 viewBox 宽度；**不传时仍固定 640**（4112 个既有图表页行为逐字节不变）。
- `chart.line()`：把 `cfg.width` 透传给 `canvas()`。
- 本页 `__bhChart()` 调用加 `width:'container'`。

## 验证
- 真机（Playwright，1198px 视口）：修复后 `viewBox='0 0 1198 220'`，曲线从 1.05（最左）到 8.40（最右）撑满整宽，截图对比确认左侧空白消失。
- 回归：默认不传 width 调用 `TBKit.chart.line` ⇒ viewBox 仍 `0 0 640 220`（零变化）；零 pageerror。
- 图表数据/公式未动（仅显示几何）。
