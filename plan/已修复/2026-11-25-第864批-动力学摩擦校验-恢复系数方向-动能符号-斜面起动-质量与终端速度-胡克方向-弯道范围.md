## 修复内容

### 摩擦力两页（1 项）

- 动摩擦、最大静摩擦均要求 μ 与 N 为必填非负有限数；空值不再按 0 计算，负值拦截并清空结果、表格与图表。
- μ=0 时“正压力/摩擦系数”显示“无定义（μ=0）”/“undefined (μ=0)”，不再用 `Math.max(μ,1e-9)` 伪造巨大有限值；表格内同步。
- 最大静摩擦页原先完全没有输入守卫，本批补上必填与范围校验。

### 恢复系数（1 项）

- 速度按同一坐标轴带符号处理，允许负速度表示方向（移除原先“速度一律不得为负”的错误限制）。
- 碰前相对接近速度 `v₁−v₂` 必须大于 0，碰后分离速度 `v₂′−v₁′` 不得为负；零接近速度、碰后仍接近分别提示方向/模型不成立，并清空表格与图表。
- 结果新增“碰撞类型”：完全弹性、非弹性、完全非弹性；e>1 明确标注“超出无源碰撞范围，可能获得外部能量”，不再当普通结果。

### 动能定理（1 项）

- 质量必须为正有限数；初末速度允许正负号，仅表示方向。
- 结果新增“功的正负”，按动能变化判断：+100 J 正功、−96 J 负功。公式与指南删除“v₂>v₁ 则 W 为正”的错误判据，改为比较 ½mv₂² 与 ½mv₁²，并给出 v₁=−10、v₂=2 的 −96 J 反例。

### 斜面加速度（1 项）

- 新增“静摩擦系数 μ_s”和“初始状态（由静止释放 / 已沿斜面下滑）”。
- 由静止释放：tanθ ≤ μ_s 判静止、a=0；tanθ > μ_s 才起动。已下滑：用 μ_k 计算，a>0 加速、a=0 匀速、a<0 减速，负加速度不再误判为静止。
- θ 限制 0–90°（不含 90°）、μ_s/μ_k 非负、g 为正；非法输入清空结果、表格与图表。结果同时显示 tanθ/μ_s 临界比较。

### 动量守恒与弹性碰撞（2 项）

- 两页均要求两个质量为正有限数，负质量与 0 质量拦截；速度可正、可负、可为 0。
- 动量守恒结果新增碰前总动量与总质量；弹性碰撞新增动量、动能守恒校验，直接显示“守恒/不守恒”。

### 终端速度（1 项）

- 质量、重力加速度、介质密度、阻力系数、迎风面积五项均须为正有限数；五项全负不再因相互抵消而得到伪正速度。
- 结果新增 km/h 与“重力=阻力”平衡状态说明。

### 胡克定律（1 项）

- 恢复力改为矢量形式 `F=−k·x`，x 拉伸为正、压缩为负，负号表示指向平衡位置；同时输出弹力大小 `|F|=k|x|`。
- k 必须为正，x 可为负、可为 0；空值不再按 0 兜底。k=200、x=−0.1 输出恢复力 +20 N、大小 20 N，消除“负位移仍得负弹力”的符号矛盾。
- 公式、首段、指南与英文词典同步。

### 倾斜弯道（1 项）

- 半径 r 与重力加速度 g 必须为正，负半径/负重力不能相互抵消；θ 限制 0–90°（不含 90°）。
- θ=0 为合法边界：设计速度 0、载荷系数 1，并说明仅靠轮胎侧向力转弯。非法输入清空结果、表格与图表。
