# 第878批修复记录（2026-11-25）

本批共处理 10 个扫描任务，涉及 9 个生活类工具页。

## 修复内容

1. **角度换算：度分秒进位后分钟未归一**
   - 先把输入总角度统一换算为 0.1 角秒整数 `totalTenths`，再按 60 进位拆成度/分/秒，避免出现 `1°60′0.0″`。
   - 真机：`1.999999° → 2°0′0.0″`、`-1.999999° → -2°0′0.0″`、`359.999999° → 360°0′0.0″`。

2. **数据单位：换算基准与二进制展示错误**
   - 1024 模式结果标签改为 `KiB/MiB/GiB/TiB/PiB/EiB` 与全称，1000 模式保留 `KB/MB/...`。
   - 二进制区固定声明 `1 B = 8 bit`，与 1000/1024 前缀无关；删除按字节数伪造逐字节文件内容的展开，改为「字节数量本身的二进制，仅表示数量」。
   - 基准行按输入单位显示 `8 bit = 1 B`、`1 B = 8 bit`、`1 KB/KiB = ...`；公式静态说明同步。

3. **重量换算：尺度参照对极端数值误用约等号**
   - 仅参照比值在 0.8–1.25 时使用「≈」，其余显示「最近参照…约为其 X 倍 / 1/X」。
   - 真机：`0.001 g → 约为其 1/1000`、`500 g → ≈1 市斤`、`1e8 g → 约为其 100 倍`。

4. **生日悖论：小数截断、单日阈值、大数同步冻结**
   - `Number()` + `Number.isInteger` 严格校验，人数/总天数上限 10000，超限直接提示，不再进入同步循环。
   - 50% 阈值搜索范围改为 `1..d+1`，总天数 1 时提示「至少 2 人」。
   - 真机：23/365 → 50.7297%；N=2,D=1 → 100%；2.5 拒绝；10001 提示上限。

5. **利润现金流：零收入无法核算亏损**
   - 允许营业收入为 0、拒绝负收入；收入为 0 时毛利率/净利率显示「不适用（收入为 0）」，费用、营业利润、现金流、期末现金继续计算。
   - 真机：0 收入 + 650 费用 → 营业利润 -650、现金流 -650、期末现金 350。

6. **单位换算：历史删除缺少键盘语义**
   - 历史删除元素由 `<span>` 改为 `<button type="button" aria-label="删除这条换算历史">`，补 `:focus-visible` 轮廓，删除后 toast 提示「已删除该条历史记录」。

7. **戒指尺码：英码错误采用美码数字**
   - 新增英国字母码表：`A=37.5 mm`，每整号 +1 mm、半号 +0.5 mm，`Z=62.5`、`Z½=63.0`；支持 `M`、`M½`、`M1/2`、`M.5`。
   - 英码输入自动切文本框；反算取最近字母/半号；超出范围不阻断其他尺码结果，英码行显示「无对应英码（超出 A–Z½ 范围）」；非法字母单独报错。
   - 真机：`50 mm → M½`、`M → 内周长 49.5 mm`、`82 mm → 港码 42 / 英码无对应`、`AA → 格式提示`。

8. **损耗分析：平均值与明细偏差基准不同**
   - 顶部明确「整体加权损耗率」，新增「环节算术平均损耗率」并说明用途；表头改为「与环节算术均值偏差」，标准差/变异系数注明相对环节算术平均。
   - 真机 `A,1,10 / B,0,90`：整体加权 1.00%、环节算术平均 5.00%、偏差 +5/-5 个百分点。

9. **草坪养护：提交记录后草坪选择被重置**
   - `renderLogList()` 重建前保存当前草坪选择，重建后若选项仍存在则恢复，否则回退占位项。
