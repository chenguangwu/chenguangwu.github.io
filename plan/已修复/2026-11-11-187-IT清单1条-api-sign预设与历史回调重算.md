# 2026-11-11 第187批 · IT-N462 api-sign 预设/历史回调重算

## 清单项
- **IT-N462**：预设/历史回调调 `copyResult` 不重算，预设参数用 `&` 分隔被解析成单个值（中，结果错误）

## 根因
- `parseParams()` 只按 `\n` 切分，预设里的 `a=1&b=2&c=3` 被解析成 1 个 key `a` 值 `1&b=2&c=3`；
- 预设 bar 回调和历史恢复回调都调 `copyResult()`（只复制不计算），点击后结果区仍停在上一轮签名。

## 改动
`tools/it/api-sign-generator.html`：
1. `parseParams()` 改为 `raw.split(/[\n&]/)`，同时支持每行一条与 URL 查询串风格，逐段 trim；
2. 预设回调 `function(){ copyResult(); }` → `function(){ runSign(); }`；
3. 历史恢复回调内 `copyResult()` → `runSign()`（在 `__api_sign_generator_skip=true` 保护内，不会误写历史）。
