## 修复内容

### 1. 渲染版本与清空竞态

- 新增 `renderVersion`、`renderInFlight`、`previewStale`。
- `renderChart()` 每次调用递增 `renderVersion`；`mermaid.render()` 完成后先比对 token，过期成功/失败回调直接丢弃，不写预览、不清错误、不复位加载态。
- 清空、换类型、编辑输入、主题切换都会产生新 token；清空后旧慢渲染完成也不会把旧图重新显示。
- 实时验证：将 `mermaid.render` 延迟 350ms，启动慢渲染后 50ms 清空，500ms 后预览为空态、无旧 SVG、无错误。

### 2. 编辑后立即导出

- 输入/Tab 编辑调用 `scheduleRender()`，立即置 `previewStale=true`；500ms 防抖期间及渲染在途时，`downloadSVG()`/`downloadPNG()` 通过 `exportReady()` 提示“预览正在更新，请等待渲染完成后再导出”，不导出旧图。
- 实时验证：输入新代码后立刻调用 `downloadSVG()`，提示“预览正在更新，请等待渲染完成后再导出”；等待完成后再导出正常。

### 3. 移除 Infinity/NaN 文本误判

- 删除 `renderChart` 中 3 处对整段 HTML/字符串的 `Infinity`、`NaN` 检查；这些检查会把合法节点标签误判为无效数值。
- 保留 Mermaid 语法错误 catch 提示。
- 实时验证：`A[Infinity] --> B[NaN]` 正常生成 SVG，预览包含两个标签，`errorBox` 为空。

### 4. 清空后刷新恢复空白

- `loadSaved()` 明确返回 `localStorage.getItem()` 的原始值：`null` = 从未保存；空字符串 = 用户明确保存的空白。
- 初始化按 `saved.code !== null` 判断，保存空字符串时恢复空白并显示空编辑器引导，不再回退到示例。
- 实时验证：`clearEditor()` 后刷新，编辑器仍为空、预览空态；再输入可正常保存。

### 5. 分类草稿与覆盖提示

- 新增 `STORAGE_DRAFTS_KEY='toolbox_flowchart_drafts'`，按 `flowchart/sequence/gantt/class/state/er/pie` 分别保存草稿。
- `selectType()` 先保存当前类型草稿，再载入目标类型草稿；目标类型从未保存过才载入示例；切回时恢复该类型上次代码。
- `loadExample()`/`clearEditor()`/`importSource()` 覆盖前先确认，并记录 `lastSnapshot`，工具栏显示“↩ 恢复上一版”；`restoreSnapshot()` 恢复类型与代码。
- 新增 `exportSource()` 下载当前类型 `.mmd` 源码；新增隐藏 `#sourceInput` + `importSource()` 读取 `.mmd/.txt` 并确认覆盖。
- 实时验证：流程图改 `FlowDraft` → 切时序图改 `SeqDraft` → 切回流程图，仍为 `FlowDraft`；`localStorage` 中两种类型草稿独立。加载示例确认取消不改变内容，确认后出现“恢复上一版”，恢复后回到 `FlowDraft`。

### 6. 空内容操作反馈

- 复制空代码：`没有可复制的代码，请先输入 Mermaid 代码 / No code to copy; enter Mermaid code first.`
- 无 SVG 导出：`暂无可导出的图表，请先输入代码并等待渲染完成 / No diagram to export; enter code and wait for rendering to finish.`
- 空源码导出、清空、加载示例、导入失败、无撤销版本均有明确中英提示。
- 删除本页全部无参 `i18nText()` 调用。

### 7. PNG 导出反馈中英双语

- 成功：`已导出 PNG / PNG exported.`
- 编码失败：`导出失败：画布可能超出浏览器上限... / Export failed: the canvas may exceed...`
- 画布尺寸/上限：本地 `canvasLimitMessage()` 返回中英双语，含实际尺寸与单边 16384 / 总像素 2.68 亿限制。
- 渲染出错：`导出失败：画布渲染出错，请重试 / Export failed: canvas rendering error; please retry.`
- 真机英文：`PNG exported.`；20000×20000 SVG：`Current 40000×40000 exceeds the browser canvas limit (16384 px per side / 268 million pixels); reduce the size.`

### 8. Tab 不再默认困住焦点

- 新增可见的 `Tab 缩进` 复选框 `#indentMode`，默认**关闭**；未勾选时 Tab/Shift+Tab 使用浏览器正常焦点导航，编辑器不 `preventDefault`。
- 勾选后才拦截 Tab 并按缩进处理；编辑器内按 Esc 关闭缩进模式并提示“已退出 Tab 缩进模式，Tab 可正常切换焦点”。
- 实时验证：默认态聚焦编辑器按 Tab，焦点离开 textarea；Esc 后由开启回到关闭，Tab 再次离开。

### 9. 多行选区缩进

- 选中多行按 Tab：按行首增加 2 个空格，保留选区，不再删除选中内容。
- 选中多行按 Shift+Tab：按行减少最多 2 个空格，保留选区与有效范围。
- 单光标 Tab 插入 2 空格；单光标 Shift+Tab 删除光标前最多 2 个行首空格。
- 使用 `document.execCommand('insertText'/'delete')` 优先保留浏览器撤销栈，失败时 `setRangeText` 兜底；每次编辑后立即调度渲染并保存。
- 实时验证：`A\nB\nC` 全选按 Tab → `  A\n  B\n  C`，选区 `[2,11]`；Shift+Tab → 恢复 `A\nB\nC`，选区 `[0,5]`。
