# 538 批：G01-C1 CMC(l:c) S_H 项按 ISO 105-J03 修正

- 日期：2026-11-15
- 来源：`plan/G01-公式与计算正确性裁量项.md` C1
- 受影响页面：`tools/dyeing/assessor-color-diff.html`

## 缺陷

原实现：

```js
var Cab=(C1+C2)/2;                                  // 标样与批次平均彩度
var G=(Cab⁴)/(Cab⁴+1900);                           // 未开方
var SC=0.0638*Cab/(1+0.0131*Cab)+0.638;             // 用平均彩度
var SH=SC*(G*T+1);                                  // 缺 +1−F
```

与 ISO 105-J03 / CMC(l:c) 原式不符：

- `S_H = S_C(F·T + 1 − F)`，原式漏掉 `1−F`；
- `F = √(C₁⁴/(C₁⁴+1900))`，原式未开方；
- `S_C`、`F`、`T` 应全部使用**标样（参考样）**的 `C₁`、`h₁`，原式用了两样平均彩度。

## 修复

```js
var F=Math.sqrt(Math.pow(C1,4)/(Math.pow(C1,4)+1900));   // 标样彩度 C1
var SC=0.0638*C1/(1+0.0131*C1)+0.638;
var SH=SC*(F*T+1-F);
```

同步：

- 公式框补全 `S_L / S_C / S_H / F / T` 定义与适用色相区间；
- 引据表公式由误写的 `(ΔH ÷ (c·S_H))²` 改为 `(ΔH ÷ S_H)²`（`c` 已在 `S_C` 内，
  `S_H` 已含 `S_C`，不应重复除 `c`）；
- 深览算例 `(25.1,0.3,-0.2)` vs `(26.4,0.1,-0.5)`：实跑 `ΔE_CMC=1.06`（原写 1.4），
  仍小于容差 2.0 判可接受；
- 英文词典补公式整段译文。

## 验收

- 真机（puppeteer + 本机 Chrome）：
  - 默认 `(50,20,10)` vs `(51,21.5,9)`、CMC(2:1) → `ΔE=1.75`；
  - 深览算例 → `ΔE=1.06`，判定「可接受」；
  - 公式框含 `S_H = S_C·(F·T+1−F)`。
- `node scripts/_en_i18n_probe.mjs --check dyeing/assessor-color-diff`：残留 0。
