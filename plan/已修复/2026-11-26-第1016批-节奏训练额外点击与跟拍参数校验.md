## 1. 节奏训练多余点击不计分

- 贪心匹配完目标音符后，收集所有未被 `usedTapIndices` 占用的敲击为 `extraTapIndices`，即休止处误击或同一拍重复敲击。
- 评分分母改为 `scoredUnits = 目标音符数 + extraCount`，每个额外敲击按 0 分计入：`accuracy = totalScore / scoredUnits`。密集乱点不再因夹带准确点击而保持高分。
- 统计卡新增「额外点击 / Extra taps」红色计数；命中列表末尾追加一行 `+N 额外点击（休止处误击或重复敲击）— 不计分`。
- 使用指南补充评分口径：「准确率 = 音符得分总和 ÷（总音符数 + 额外敲击数）」。

## 2. 跟拍训练静默替换输入

- `tapStart()` 新增 `readInt(id, min, max)`：要求非空、整数、在范围内；BPM 40–200、细分 1–4、小节 1–16。
- 任一非法（空、0、负、越界、小数）即停止启动流程，状态改为「参数有误 / Invalid settings」，结果区给出完整范围提示；不再 `||100` / `Math.max` 静默回退或钳制。
- 合法输入按原值运行，输入框显示与实际节拍一致。
