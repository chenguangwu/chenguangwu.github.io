## 根因

二手车检查、外套评估、建材与涂层检测这类页面把「核心实测值」和「逐项勾选清单」混在一张评分表里。用户清空实测数值后：
- 清单未勾选 = 无问题 → 「底盘综合评分 100 分 · 优秀 · 0 问题项」
- `parseFloat('')=0` 直接当实测值 → 「抗压强度 0 MPa ✗ 超标 · 质量等级不符」「VOC 0 ✓ 甲醛 0 ✓ 合格」

即「没有输入」被读成「一切正常」。
