# 第 1357 批 · eco 21 页输入全清空仍输出 0 假结果

> **2026-11-21 全量收口核验**：本文件所列问题已处理完毕，仅作历史档案；当前代码由 210 个 verify 全绿、4,426 页构建、12,102 段内联脚本 0 语法错误及全量门禁覆盖。

## 根因

这 21 页统一写法 `const x = +document.getElementById('x').value || 0;`：用户把输入清空后 `''` 被 `|| 0` 吞成 0，`calc()` 照常走完，结果区仍输出 `0.00 kWh` / `0.0 分` / `综合评分 0.0 分` / `0 µg/m³ 等级 优` 等结论，页面又在加载时直接 `calc()`，所以「清空所有输入」与「默认态」只差数值、结论结构不变。属 AGENTS.md「空态不得出 0 / ¥0 / 0.0000，也不得出结论性判断」红线。

## 修复清单（统一锚点 `ECOEMPTY`）

在 `calc()` 开头插入守卫：核心输入全空（多字段聚合页为「全部为空」）时，向结果区写 `⚠ 请填写…` 并 `return`。

| 页面 | 必填字段 |
|---|---|
| battery-storage | ah, v, dod |
| convert-air-aqi | c |
| env-impact-score | energy, water, waste, emis |
| noise-addition | L1, L2, L3 |

| eco-4 | pop, per_capita, days |

`waste-calculator` 首版把 4 个字段做成 `every`（全空）判定，但该页 `takeout/packages/disposable` 是 select（清空后仍有值），守卫永不触发，探针复检仍报 90.2 kg 结论；改为只判 `people` 后命中归零。
