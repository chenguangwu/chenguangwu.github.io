# 750 批：IBW 低身高守卫与 BSA 0 岁分支（D-N28、D-N30）

## D-N28 理想体重 IBW
- 问题：身高允许 100–250 cm，但 Devine 公式在低身高下会给出负值（女 100 cm ⇒ −2.2 kg），并继续渲染负的 IBW/上下限。
- 修复（`tools/healthcare/ibw.html`）：
  - 计算前判断 `base + 0.91 × (身高 − 152.4) ≤ 0` ⇒ 拒绝计算，提示「公式不适用于此身高范围」并建议核对单位或改用 BMI/BSA；
  - 身高 <150 cm 时追加提示「Devine 以成人身高推导，结果可能偏低，仅供粗略参考」。
- 门禁：女 100 cm ⇒ 拒绝文案；男 148 cm ⇒ 低身高提示；原 175 cm/男 70.6 与 ABW 用例不受影响。

## D-N30 体表面积 BSA
- 问题：儿童分支条件 `age > 0 && age < 18` 把出生当天（0 岁）排除，8 kg/70 cm/0 岁走 DuBois 并标「成人，≥18 岁」。
- 修复（`tools/healthcare/bsa-calculator.html`）：改为 `age >= 0 && age < 18`，0 岁走 Haycock，并沿用「1 岁以下误差较大」提示。
- 门禁：8 kg/70 cm/0 岁 ⇒「BSA： 0.400」「所用公式： Haycock」；2 岁 0.476 用例保持通过。
