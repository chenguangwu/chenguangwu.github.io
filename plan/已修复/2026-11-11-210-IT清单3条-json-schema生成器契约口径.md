## 改动
`tools/it/json-schema-generator.html`：
1. **N267 required**：对象分支对 `propSchema.type === 'null'` 的字段跳过 `required.push`，避免生成「必填且只能为 null」的不可满足契约；`mergeSchemas` 的对象分支保留所有元素共有的 `required`（原来只重建 `{type,properties}` 整段丢弃）；说明文案由"在所有样本中都出现的键才会被判定为必填"改为"单样本推断、非 null 键均列入、数组对象取共有键、多样本需人工合并"。
2. **N268 描述注释**：`options.descriptions` 此前只在 `generateSchema()` 读入、全程零消费；现在每个属性写入 `description = 'The <key> field.'`（英文，Schema 产物无需 i18n）。保留预设「描述+极值+标题」的承诺，不再勾了没反应。
3. **N269 混合类型**：`mergeSchemas` 类型不一致时由 `return {}` 改为按 `JSON.stringify` 去重后输出 `{anyOf:[...]}`（同类仅一个时不包 anyOf）；`buildTreeView` 同步展示 `anyOf`，避免 JSON 有、结构树空一块。`anyOf` 在 draft-04/06/07/2020-12 均受支持。
4. **顺带 isIPv4**：由纯形状正则改为逐段捕获，校验 0–255 且拒绝 `01.2.3.4` 前导零写法；`999.999.999.999`/`256.0.0.1` 不再误标 `format:"ipv4"`。

`i18n/tools/en/it/json-schema-generator.json`：required 说明中文键与英译同步更新。
