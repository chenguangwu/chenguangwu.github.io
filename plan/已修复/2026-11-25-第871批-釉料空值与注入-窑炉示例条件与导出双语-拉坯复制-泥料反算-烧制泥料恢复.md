## 修复内容

1. **釉料配比 · 空白比例**：`MATS` 中比例为空串时按“必填”报错，不再 `Number('')` 当 0 继续；负数、超过 100、非有限数同样进入错误列表，全部称量输入置 `—`，暂停合格结论与加水/釉浆估算。
2. **釉料配比 · 无效总重**：干釉总重为空、0 或负数时，先把所有 `w_<idx>` 称量字段清为 `—` 再显示“请输入有效干釉料总重”，不再保留上一批克数。
3. **釉料配比 · 原料名注入**：新增 `escMat()`；称量表、合计不为 100 的表格和错误列表统一转义，`renderMats()` 改为 `createElement` + `value`/`textContent` 组装行，名称不再拼进 HTML 字符串或 `value` 属性。
4. **釉料配比 · 历史完整恢复**：快照写入 `__mats`（原料名称与比例的 JSON）；历史恢复先解析、校验并重建 `MATS`/`renderMats()`，再回填总重与方法计算；历史表、导出、去重比较均排除 `__mats` 内部字段。
5. **窑炉曲线 · 瓷器还原适用条件**：瓷器 950→1100°C 阶段改为“强还原（示例）”“还原焰（视窑型/泥釉）”；总说明补“曲线为常见示例，须按窑炉能力、泥釉配方与烧成气氛调整”；选中瓷器时额外提示该还原段不是所有瓷器必选。
6. **窑炉曲线 · 导出中英文完整**：新增 `__kfName()` / `__kfTr()`，中文态表头为“类型/阶段/温度区间/升温速率/保温”，英文态为“Type/Stage/Temp Range/Rate/Hold”，行内类型、阶段、温度、速率、保温全部按当前语言输出；补齐 `#kfHidden` 表头 `data-zh`；修正 `自然冷却` 先于 `冷却` 替换、`保温` 输出带空格，避免 `自然Cooling`/`Hold1h`。
7. **拉坯转速 · 无效复制**：`copyResult()` 找不到 `#result .big-result` 时提示“当前没有有效计算结果，请先填写有效坯体直径与设备转速范围”并返回，不再复制“拉坯转速结果”占位文本或提示复制成功。
8. **泥料收缩 · 历史反算**：历史恢复同时调用 `calc()` 与 `calcReverse()`；反算非法参数时置 `clayReverseOk=false`，反算复制守卫读取该状态；预设回调和历史回调都走正算+反算。
9. **泥料收缩 · 相关工具**：6 个陶瓷页的相关工具统一替换为泥料收缩、釉料配比、拉坯转速、窑炉烧成曲线、陶艺烧制温度曲线、釉料温度对照等同类工具，排除自身，去掉演讲计时/Markdown/Zalgo 等无关推荐。
10. **陶艺烧制 · 历史泥料**：快照写入 `__clay`；历史恢复识别 `CLAYS` 合法 id 后先还原 `selectedClay` 并 `renderClays()`，再恢复其余字段和 `renderCurve()`；旧记录无 `__clay` 或 id 无法识别时分别提示“未保存泥料选择/泥料无法识别，已按当前泥料重绘”。
