## 失败点
`tools/it/cpp-cheatsheet.html` 的重载示例同时给出 `int add(int a, int b = 0)` 与 `int add(int a)` 并调用 `add(1)`：两个候选的实参转换序列完全相同 ⇒ clang++ 报 `error: call to 'add' is ambiguous`。示例还用 `--` 作注解（C++ 无此注释符）。

## 根因
把「默认参数」与「单参重载」同时写进示例，两者对 1 个实参构成歧义；注解沿用了速查表通用的 `--` 分隔符而非目标语言注释符。

## 修复位点
该条 `example`：`int add(int a, int b = 0)` → `int add(int a, int b)`，`-- 重载` → `// 重载`；调用 `add(1, 2); add(1);` 不变。其余条目未动（其 `--` 注解属 IT-N486，另批处理）。
