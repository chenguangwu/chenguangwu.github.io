# 591 批：催化剂模式切换与响应统计口径

## petrochem/catalyst-calc：切模式不出结果、堆密度不校验
- 根因：`switchMode` 只切面板，停留时间面板在改动输入前一直空白；两模式只校验流量/空速(或停留时间)/进料密度，堆密度清空按 0 得装量 0 kg，负值得负质量。
- 改法：`switchMode` 切换后立即调用对应 `calcLsv()` / `calcTime()`；两项校验都加入 `bulk <= 0`，提示「请输入正的流量、空速(停留时间)、进料密度与催化剂堆积密度」。
- 验证：新增 bulkDensity=0 拒绝用例与 `switchMode('time')` 后 `resultTime` 含「催化剂体积」探针；原 7500 kg/h 用例保持。

## service/response-time：空值按 0、解决率漏算、SLA 静默兜底
- 根因：`updateTicket` 把空响应/解决时间写 0 并计入均值；解决率分子只数 `solve>0`，已解决但解决时间为 0 的被排除；`slaTarget` 空或 0 时 `||30` 静默改按 30 分钟。
- 改法：响应/解决时间允许为空（存 `null`），空值与负数不入均值、分位数与分布；解决率按 `status==='resolved'` 计数；SLA 目标非正时判定无效，卡片显示「--」并标注「SLA目标需为正数」，明细达标列显示「-」。
- 验证：新增 SLA=0、已解决 solve=0（解决率 50.0%）、空响应不入样（均值 20.0 分）三例；原 slaTarget=45 的 100.0% 用例保持。

## paper/paper-grade：搜索误筛明细表、本色纸显示 0 白度
- 根因：`filterTable` 遍历全局 `tbody tr`，把白度明细表一起隐藏；`__pgWhite` 对「本色」无数字返回 0，明细表也显示 0。
- 改法：搜索只遍历 `#table1~#table4` 的等级表 tbody；`__pgWhite` 无数字返回 `null`，明细表显示「—（本色无白度）」/英文提示，图表对应项留空。
- 验证：新增 `querySelectorAll` 选择器捕获用例（须含 `#table1 tbody tr` 与 `#table4 tbody tr`）；默认态无探针串。

## funeral/ceremony-timeline：手输时间被覆盖、跨午夜排序倒置
- 根因：`render()` 每次先 `autoTime()` 按 09:00 覆盖手输时间；再按 `HH:mm` 字符串排序，次日 00 点排到前一日 23 点前，摘要结束时间无日偏移。
- 改法：`render()` 不再自动重排，改由开始时间输入框 `onchange` 调用新增 `applyStart()`；按录入顺序折算绝对分钟（回退即 +1440）排序，次日环节与结束时间标「（次日）」。
- 验证：新增 23:30/00:15 跨午夜用例，断言顺序、次日标记与结束 00:45（次日）；原 startTime=09:00 用例保持。
