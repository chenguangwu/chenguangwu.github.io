# 第865批：补饲微量单位、水洗零量、白平衡范围、书法年代、品相切换、舞伴余量、BPM 节拍器

本批处理 5 个目录 7 项扫描任务，涉及 7 个工具页。

## 修复内容

1. **beekeeping/winter-feed-syrup：小量配料不再四舍五入为零**
   - 新增 `fmtKg` / `fmtL` / `fmtMoney` 自适应单位：<0.01 kg 用 mg、<1 kg 用 g、<0.01 L 用 mL；成本 <1 元保留 3 位小数。
   - 主结果卡、扣减表、CSV、图表标签、历史记录统一走同一格式化函数，避免结果/导出两套口径。
   - 1 群 × 0.001 L/群（2:1）=> 1.00 mL、1.34 kg 总重、894 mg 糖、447 mg 水、0.004 元；常规 5×4 L 结果不变。

2. **dyeing/shuixixiaolvjisuan：零水量或零布重不再给效率**
   - `calc()` 要求水量、布重均为有限正数；零或负值直接提示“水量与布重必须为正数：无水或无布时该水洗模型不适用”，并清空 `lastResult`。
   - 空值分支同步清空 `lastResult`，复制入口不会再复制上一次成功结果；有效输入仍正常给效率、评级与总用水量。

3. **photo2/white-balance：统一 1000–40000 K 并修正 Mired 命名**
   - `calc()` 上限由 20000 K 改为 40000 K；空值/越界提示、复制校验、CSV 导出校验统一为 1000–40000 K。
   - 渐变刻度末档由 `20000K+` 改为 `40000K`，位置比例分母由 19000 改为 39000。
   - 字段与结果由“白平衡偏移”改为“Mired 绝对值（1e6/K）”，复制文本同步；说明明确滤镜偏移需用两个色温的 Mired 相减，单色温只是绝对值。
   - `copyResult()` 不再被空的 Mired 必填拦截，改为复用色温范围校验；30000 K 可正常复制。

4. **antiques/calligraphy-style：补南北朝、隋、元三期**
   - `ERAS` 新增南北朝（420–589）、隋（581–618）、元（1271–1368）三条，含书体、笔法、结体、风格、代表书家与备注；筛选下拉同步新增三项。
   - 南北朝列魏碑与南朝帖双线（《郑文公碑》《张猛龙碑》《瘗鹤铭》等）；隋列智永《真草千字文》《龙藏寺碑》；元列赵孟頫、鲜于枢、康里巎巎等。
   - 鉴定要点明确“风格概括只用于学习与初步比对，不能单独作为真伪、年代或作者鉴定依据”，并补《中国书法史》（江苏教育出版社）及碑帖著录来源。

5. **antiques/rater-1：切换收藏类型保留各自瑕疵选择**
   - 新增 `ITEM_STATE` 按 coin/stamp 分别保存六项瑕疵等级；`renderItems()` 重建前先捕获旧类别状态，重建时按保存值设置 `selected`。
   - 瑕疵下拉改为 `onItemChange()`，先保存再 `calc()`；往返切换后评分按保留的选择重算，不再静默回到“无/满分”。
   - 增加“切换收藏类型会保留各自已选的瑕疵等级”提示。

6. **dance/partner-distance：偏紧建议与余量方向一致**
   - 标签改为“手臂弯曲余量（cm，从理论间距中扣除）”，说明明确余量越大计算间距越小。
   - 舒适指数 <50% 时改为“适当减小余量”或“选择开式、侧行位等更宽松持握”；余量已为 0 时不再提示减小，改为直接换持握方式。

7. **dance/bpm-rhythm：节拍器共用 BPM 校验**
   - 新增 `parseBpm()`（40–240，空值/非有限/越界均为 null）与 `stopMetronome()`。
   - `calc()` 与 `toggleMetronome()` 共用校验；非法 BPM 不启动定时器并明确提示；运行中把 BPM 改为非法值时 `metroTick` 立即停止，不再用 `||120` 静默回退。
   - 同时校验每动作拍数为正、练习时长为正、每小节拍数 2–12。
