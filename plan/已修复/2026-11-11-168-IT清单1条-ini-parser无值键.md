# 第168批 · IT 清单 1 条 · ini-parser 无值键被整行丢弃

- 来源：`plan/categories/01-IT开发/it.md` → IT-D40（问题表格行 + 族矩阵 + 逐页结论摘要已同步更新）
- 修复日期：2026-11-11
- 类型：解析正确性缺陷（INI 裸布尔标志键丢失），纯前端逻辑，无文案/口径变更

## 失败点
`tools/it/ini-parser.html` 的 `parseIni()` 逐行 `indexOf('=')`，无 `=` 的行直接 `continue`：`[s]\nflag\nx=1` → `{"s":{"x":"1"}}`，期望 `{"s":{"flag":"","x":"1"}}`。页面自身用 `=` 或 `:` 分隔的说法另属 IT-D39，本批只处理无值键。

## 根因
INI 常见布尔标志写法（无值裸键）被当作无效行跳过，而期望口径应保留该键、值为空串。

## 修复位点
`parseIni()` 的 `eq < 0` 分支：不再 `continue` 丢弃整行，改为按当前节（或根级）写入 `t` 为键、值为 `''` 后 `continue`；保持 trim 后的键名。输出、历史、i18n 均复用既有路径，无新增中文文案，i18n 0 残留。

2. **旧源码差分**：换回 `HEAD` 旧源码 → ini-parser 6/7 红（新锁失败）；恢复修好版 → 7/7 绿。判别力成立。
