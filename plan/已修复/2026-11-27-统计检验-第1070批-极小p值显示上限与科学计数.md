# 第1070批：统计检验极小 p 值不再显示为 0

> 来源：`plan/统计检验极小p值显示为零.md`。状态：待独立复核。

## 问题

四个 t/Z 检验页主结果用 `toFixed(4)`，明细用 `toFixed(6)`。非零 p 小于显示精度时被写成 `0.0000 / 0.000000`；极端参数下双精度下溢为 0 后也显示为 0，容易被理解为概率严格为零。显著性判断本身使用未格式化数值，问题只在展示/明细。

## 修复

- 四页统一新增 `fmtP(v)`：
  - 非有限或负值 → `—`；
  - `v===0`（数值下溢）→ `&lt;1e-300`，明确是上限而非零；
  - `0<v<0.0001` → `v.toExponential(2)`（如 `9.62e-5`）；
  - 其余保持 `v.toFixed(4)`。
- 主结果 dataGrid、配对页英文/中文明细、Z 页明细与报告文本全部改用 `fmtP(p)`。
- 显著性判断仍用原始 `p` 与 `0.05` 比较，不受展示格式影响。

## 验证

- `node scripts/verify_statistics_calc.js`：208/208。
- 新增 5 条极限用例：
  - 单样本 t `t=31622.78, df=999` → `<1e-300`；
  - 配对 t 同量级 → `<1e-300`；
  - 独立 t `t=22360.68, df=1998` → `<1e-300`；
  - Z `z=10000` → `<1e-300`；
  - Z `z=3.9` → `9.62e-5`（阈值附近走科学计数）。
- 四页 `fmtP` 在 `_build.py` 后仍存在；英文探针 0 残留；`_test_static.py` 4654 通过 / 0 失败 / 0 告警。
