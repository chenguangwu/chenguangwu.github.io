## 2. 八进制编解码：非法 UTF-8 静默替换
- **问题**：`new TextDecoder().decode(bytes)` 宽松解码，`377`（字节 FF）输出替换字符，复制后无法还原；失败后旧结果仍可能留存。
- **修复**（`tools/it/octal-encode.html`）：改用 `TextDecoder('utf-8',{fatal:true})`；失败时清空 `#output`，在新增 `#decodeNote` 显示「字节不是合法 UTF-8，已清空结果。原始字节（十六进制）：ff」；英文态显示对应英文。成功时清空提示。

## 3. 十进制编解码：非法 UTF-8 与中文英文提示
- **问题**：`255`（FF）宽松解码成替换字符；非法字节 alert 固定中文；失败后旧输出未清。
- **修复**（`tools/it/decimal-encode.html`）：同样 `fatal:true` + 失败清空 + `#decodeNote` 原始 hex；非法十进制字节 alert 接入中英（`Invalid decimal byte:` / `非法十进制数:`）。合法 UTF-8 正常解码并清空提示。

## 4. 栅栏密码：UTF-16 单元拆分导致字符损坏
- **问题**：加密/解密/网格按 `text.length` 与 `text[c]`（UTF-16 单元）排列，emoji 代理项被拆开，密文出现破损字符。
- **修复**（`tools/it/rail-fence-cipher.html`）：`enc`/`dec`/`renderGrid` 统一 `Array.from(text)` 按 Unicode 码点处理；矩阵列数、深度校验、网格单元格均用码点数组；提示改为「按码点计」。`😀ab中` 加解密往返无损。

## 5. 二维码文本解析：WiFi 百分号内容被改写
- **问题**：`wifiValue()` 对 SSID/密码做 `decodeURIComponent`，`Cafe%20WiFi` → `Cafe WiFi`、`abc%21` → `abc!`；WiFi 字段不是 URL 查询参数，百分号可以是真实字符，自动解码会改变配网凭据。
- **修复**（`tools/it/qr-decoder.html`）：`wifiValue` 只返回原值，仅保留 `parseWifiFields` 的协议反斜杠转义（`\;`、`\,`、`\:`、`\\`）；公式说明改为「百分号原样保留，不做 URL 解码」。
- **顺带**：识别结果卡片的中文标签在 `?lang=en-US` 下从未本地化，补 `Q(zh,en)` 映射（类型、字段名、「识别到 N 种类型」、「(空)」），英文态动态输出不再残留中文。
- **口径调整**：旧 verify `IT-D04` 要求 `%E4%B8%AD%E6%96%87` 解码为「中文」，与协议语义冲突，已改为断言原样保留。
