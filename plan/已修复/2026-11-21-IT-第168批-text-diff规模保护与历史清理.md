# 第168批：text-diff 规模保护、Myers 口径与陈旧审计清理

## text-diff（IT-D19）
原实现 `backtrack` 为纯递归、`lcsLength` 直接按 m×n 建二维数组，4000 行全不同文本或单行 5000 字符会抛 `RangeError`；4000×4000 的内存压力也很大。
- `backtrack` 改为 while 迭代回溯，消除递归深度上限。
- 新增 `MAX_DIFF_CELLS = 4000000`：行级矩阵超 400 万单元改走 `alignedLineDiff`（逐行位置对齐，明确提示不检测行移动）。
- 字符级 diff 新增 `MAX_CHAR_CELLS = 250000`：单行过长时退回整行删除/新增高亮，避免字符 DP 再次爆内存。
- 新增 `#diffNotice` 提示条；公式表出处从误导性的「Myers (1986)」改为「本页为 LCS 动态规划；Myers (1986) 为经典 diff 参考」。

验证：`node scripts/verify_it_calc.js it/text-diff` 5/5（新增规模保护源码守卫：常量 400 万、回溯无自调用、对齐函数返回 modify）；内联语法 0 错误；构建 4,426 页成功。
