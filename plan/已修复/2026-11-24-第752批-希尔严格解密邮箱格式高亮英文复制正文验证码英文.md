## 修复项

### 1. 希尔密码解密奇数密文静默补位

`tools/it/hill-cipher.html`

- `process()` 不再自行大写、删除字符或补位，只负责偶数分组的矩阵运算；输入归一与校验上移到 `enc()` / `dec()`。
- 新增 `hillMsg(zh,en)`、`setHillNote()`、`hillFail()`。`hillFail()` 先清空 `#output` 与说明，再 `alert`，失败时不再残留旧结果。
- 加密：
  - 非 ASCII 字符直接拒绝并报出首个坏字符及位置，不做 Unicode 大写转换。
  - ASCII 非字母字符忽略并计数，说明块写明「有效字母 N、忽略 M、补 X K」。
  - 明文为空或没有有效字母时拒绝。
  - 奇数长度补 1 个 X，并明确说明「解密得到补齐文本，原文末尾 X 与补位 X 无法区分」。
- 解密：
  - 只允许 A–Z/a–z 与空白，其他字符报出位置并拒绝。
  - 允许空白分组，不改变字母。
  - 奇数长度直接拒绝，明确「不会自动补位」。
  - 成功时说明密文字母数与末尾 X 歧义。
- 输出框下新增 `#hillNote` 承载规则说明。

### 2. 邮箱归一接受明显无效地址

`tools/it/email-normalizer.html`

- 新增 `__email_localValid(v)`：非空、≤64、首尾非点、无连续点、字符集合法。
- 新增 `__email_domainValid(v)`：非空、≤253、至少两个标签、每个标签 1–63、标签首尾为字母数字、内部允许连字符、TLD 至少 2 个字母。
- `normalize()` 改为调用上述校验，坏地址统一输出「邮箱格式无效（本地名点号位置/字符不合法，或域名标签以连字符开头/结尾）」；英文态为 `Invalid email: ...`。
- Gmail 归一后再次校验派生本地名；`+tag@gmail.com` 报「按 Gmail 规则归一后本地名为空或无效（+tag 前没有邮箱名）」，不再生成 `@gmail.com`。
- 仍保留原说明：只校验支持子集，不能据此判断地址真实存在或可投递。

### 3. 代码高亮动态结果缺少英文

`tools/it/code-highlighter.html`

- 新增 `__hlT(zh,en)`，按 `TBKit.util.isEn()` 返回当前语言。
- 高亮统计改为 `Lines / Non-empty / Characters / Language`，中文态仍为「行数 / 非空行 / 字符数 / 语言」。
- 主题标签改为 `Dark theme / Light theme`。
- 空输入占位改为 `Paste or enter code, then click Highlight`；清空后的占位改为 `Click Highlight, or load an example to get started`。
- 加载示例的 toast 也按语言输出。

### 4. 字符集检测复制诊断报告而非修复内容

`tools/it/charset-detector.html`

- 新增 `window.__charsetCandidates`（每项 `{label,text}`）与 `window.__charsetCopyText`。
- 字节模式在候选表后增加 `#byteCandidate` 下拉与 `#charsetCopyState`：显示完整候选、字符数，默认选可读性最高的候选；`__charsetSelectCandidate(idx)` 切换完整文本。
- 文本模式 `__charsetCopyText` 为修复后的正文；空输入为空。
- `copyResult()` 只复制 `__charsetCopyText`，不再调用 `out.innerText`，避免把「修复输出/字符构成/候选表」带入剪贴板。
- 空文本走警告提示且不写入剪贴板。

### 5. 验证码动态验证结果缺少英文

`tools/it/captcha-generator.html`

- 新增 `capT(zh,en)`，按当前语言返回文案。
- 验证成功、失败、数学题「正确答案是」均接入 `capT`，数学失败仍显示正确答案。
- Web Crypto 不可用的提示接入 `capT`，英文态为 `Web Crypto is unavailable, so an unpredictable CAPTCHA cannot be generated. Please upgrade your browser and retry.`
- `generateCode()` 的安全随机不可用提示同样按语言输出。

## 边界与说明

- 希尔密码仅支持 A–Z/a–z 与 ASCII 标点；非 ASCII 文本需先转写或翻译，不做隐式 Unicode 大写。
- 邮箱校验只覆盖本工具支持的地址子集，不验证域名 DNS、邮箱是否存在或可投递。
- 二维码模式默认单条属上一批已记录的行为口径，本批未再改动。
