# 第759批修复记录（2026-11-24）

## 1–3. A1Z26：数字/标点混淆、双空格拆词、Unicode 变换（同页合并修复）
- **问题**：`A1` 编码为 `11`（错误解码成 K）；原文数字被当编码；标点被丢弃；`toUpperCase()+NFD` 把 `é→E`、`ß→SS`；解码时 `wordSep` 被替换为 `\s+`，双空格词分隔被单空格拆散。
- **修复**（`tools/it/a1z26-cipher.html`）：
  - 编码改为**可逆 token 格式**：ASCII A–Z/a–z → 1–26；其余所有字符（数字、标点、重音字母、emoji、分隔符本身）→ `~十六进制码点`（如 `1`→`~31`、`é`→`~E9`、`ß`→`~DF`、`😀`→`~1F600`）。
  - 移除 `toUpperCase()` 与 NFD，不再静默改字；非 ASCII 原码点保留。
  - 解码精确使用所选 `sep` 切 token、`wordSep` 切词；双空格用 `/\s{2,}/`，单空格不再被当词边界；`~hex` 还原字符，越界/非法 token 标 `?` 并列出。
  - 说明更新：可逆格式、旧纯数字密文兼容。
- **口径变更**：`42!` 由原样 `42!` 改为 `~34-~32-~21`；旧 verify `N282`、自动补强用例同步更新。

## 4. ADFGVX：方阵未校验唯一性
- **问题**：长度 36 的重复字符方阵被接受，其他字符找不到时静默跳过；长度不足静默回退默认方阵。
- **修复**（`tools/it/adfgvx-cipher.html`）：新增 `checkGrid()` 校验 A–Z+0–9 各一次；非法时列出长度、缺失、重复（如 `A×36`），显示在 `#keyStatus`，`enc/dec` 都阻止执行并清空输出；空输入仍明确使用默认方阵（状态栏标注「默认方阵（未填写自定义密钥）」），不再对非空非法串静默回退。

## 5. ADFGVX：非法密文与补位标记被静默丢弃
- **问题**：解密只校验列数，非法字符被跳过、奇数尾字符被忽略、过大 `~P` 把密文截空仍显示结果。
- **修复**：解密前依次校验字符集（只允许 ADFGVX，指出列/字符）、各列等长、`~P` 须 `< 列数` 且 `≤ 总字符数`、扣除补位后长度必须偶数（无标记旧密文总长也必须偶数）；任一项失败清空 `#output`、在 `#decNote` 写明原因并 alert；成功时清除错误提示。无 `~P` 的旧密文会提示「未剥离补位字符」，不再静默。
- 说明区补充「校验」条目，中英文同步。
