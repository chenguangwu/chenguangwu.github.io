# 第 363 批 · 设计 D-N25 · SVG 转 PNG 适配模式（contain / stretch）

## 缺陷（D-N25，已确认源码缺陷）
- 页面声明「保持长宽比」（公式引据表 `输出像素宽 = viewBox 宽 x 缩放倍率，保持长宽比` + formula-eq `按 drawImage(图,0,0,画布宽,画布高) 缩放绘制`），但 `drawImage(img, 0, 0, canvas.width, canvas.height)` 把图直接拉伸铺满画布，宽高各自独立生效。
- 复现：64×64 正方形 SVG 配 400×200 输出 → 图形被横向拉成 2:1 变形，与说明矛盾。

## 修复（改源，未用 git checkout，备份 `/tmp/svg-to-png.html.bak`）
1. **控制面板**新增「适配模式」`select#fitMode`：默认 `contain`（保持比例·留白），选项 `stretch`（拉伸铺满）。
2. **监听**：`['svgInput','width','height','scale','bgMode','fitMode']` 加入数组，`fitMode` 用 `change` 事件。
3. **generate 读取** `fitMode = document.getElementById('fitMode').value`。
4. **绘制逻辑**（原单句 `drawImage(img,0,0,canvas.width,canvas.height)` 改写）：
   - `contain`：当 `img.width>0&&img.height>0` 时按 `ratio=min(canvas.w/img.w, canvas.h/img.h)` 计算 `drawW/drawH` 并居中 `drawX/drawY`，多余处保留背景/留白；
   - `stretch` 或 SVG 无固有尺寸（`img.width` 为 0）时回退铺满（与原行为一致，避免无尺寸 SVG 异常）。
5. **同步元信息**：`exportMetaVal` 由 `… · ${bgMode}` 扩为 `… · ${bgMode} · ${fitMode}`，并异步追加 ` · 绘制${drawW}×${drawH}`（仅 UX，说明实际绘制尺寸；harness 不采集异步，不影响强锁）。
6. **文案修正**：formula-eq 由「按 drawImage 缩放绘制」改为「适配模式默认『保持比例』居中绘制并保留多余画布、可选『拉伸铺满』拉伸至画布尺寸」；引据表「保持长宽比」改为「画布像素 = 设定宽高 × 倍率；默认 contain 保持长宽比居中，可选 stretch 拉伸铺满」（`data-zh` + 英文 textContent 双写，该 td 不在字典）。
7. **EN 字典同步**：`i18n/tools/en/design/svg-to-png.json` formula-eq 中英文 key 同步（JSON 合法校验通过，ensure_ascii=False/indent=2 保持）。

## 强锁（verify_design_calc.js）
- 现有用例 expect `42 × 42 · 1x · transparent` → `42 × 42 · 1x · transparent · contain`（默认模式串，依赖未设 fitMode 时 HTML 默认 contain）。
- 新增「拉伸锁」：`width=200,height=100` + 64×64 SVG，`clicks: fitMode='stretch';generate()` → expect `200 × 100 · 1x · transparent · stretch`。64×64 在 200×100 画布下 contain 会是 100×100 居中、stretch 才是 200×100 铺满，模式串可判别（harness 同步采集 exportMetaVal，不依赖 Image.onload 异步，与原 ref「不依赖 Image 实现」一致）。
- **净增 1 用例**：design 全量 376 → **378/378 全绿**（含既有 3 例 + 新 stretch）。
