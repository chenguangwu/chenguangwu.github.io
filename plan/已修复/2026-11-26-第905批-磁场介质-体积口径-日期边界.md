# 第905批：磁场介质、体积口径、日期边界

日期：2026-11-26

本批关闭 11 个任务，涉及磁场换算、体积换算、数字转中文、精确年龄、卡路里/理想体重、单位换算（马赫/音速）、生日天数、压力换算、罗马数字、颜色名称查询、倒计时日期解读。

## 修复内容

- 磁场换算：新增可选相对磁导率 μᵣ（默认 1，可留空），跨 H/B 按线性均匀介质 B = μ₀μᵣH 输出，同时保留原真空参考行；明确提示铁磁材料非线性/磁滞不适用，非法 μᵣ 给出范围提示。
- 体积换算：杯/汤匙/茶匙标注为美制口径，新增公制量杯 250 mL、公制汤匙 15 mL、公制茶匙 5 mL；主结果保留原有美制行，另附美制/公制对照换算说明。
- 数字转中文：进制输出改为按原始字符串判断小数位，`9999999999999999.1` 不再被 `parseFloat` 舍入成整数；只要小数位含非零字符即明确显示“仅整数支持”，整数值仍用原始整数字符串交给 BigInt。
- 精确年龄：时/分/秒允许留空按 0，但填写后必须是范围内整数；小时 24、分钟/秒 60 等不再交给 Date 自动滚到次日，错误时清空旧结果并提示具体范围。
- 卡路里计算：BMI 理想体重卡片改为按区间显示“低于下限 / 处于区间内 / 高于上限”，仅区间外显示到最近边界的差值，并注明这是 BMI 人群参考区间而非个人目标。
- 单位换算：马赫与“音速”统一按 15°C 标准大气压干空气 343 m/s，选项名称标明条件，速度分类新增条件说明；“1 马赫 ≈ 1234.8 km/h（15°C）”。
- 生日天数：周岁/月日分解与下次生日统一按周年日期规则，2/29 出生在平年按 2/28 计；2025-02-28 对 2024-02-29 出生者同时显示 1 岁 0 月 0 天、距下次生日 0 天。
- 压力换算：新增绝压/表压/压差基准选择；实物参照标注基准并只在同基准下比较；零值/负值不使用正压参照，超出约 10 倍范围时提示相差倍数而非直接“≈”。
- 罗马数字：历史、明细、图表与导出移到两种方向共用的结果区；历史快照只采集当前方向输入，`convertNum` 与 `convertRoman` 都触发记录，恢复历史时按记录方向切回对应面板。
- 颜色名称查询：名称匹配先保留完整数组再分页显示，标题显示“找到 N 个匹配，当前显示前 20 个”，超过 20 条提供“显示更多（剩余 N 个）”，不再把截断数当总数。
- 倒计时：日期解读移除无关生肖、星座及不准确的农历偏差说明，只保留北半球季节口径，并在脚注说明本页不推算生肖或星座。
