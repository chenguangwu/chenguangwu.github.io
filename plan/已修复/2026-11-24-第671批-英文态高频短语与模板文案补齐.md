# 第671批：英文态高频短语与模板文案补齐

## 背景

第670批修复了 emoji 标题的精确匹配缺陷。继续对 4,634 个工具页做英文态扫描后，确认残留中文主要有两类：

1. 高频短标签：`正常`、`溶解`、`难溶`、`性状：`、`主治功效：`、`步骤1`、`4分` 等；
2. 模板化文案：`📖 查看「… 使用指南」`、`📖关于「…」` 等，数量大但结构固定。

本批补的是这两类可直接复用的文案，不涉及需要逐页翻译的正文。

## 修复内容

### 1. 高频短标签补入 `BODY_PHRASE_MAP`

新增 **111** 条高频残留短语，覆盖：

- 中药/药材属性：`溶解`、`难溶`、`微溶`、`易溶`、`性状：`、`炮制目的：`、`对应部位：`、`主治功效：`、`主治：`、`禁忌原因：`；
- 量表/问卷：`非常同意`、`同意`、`中立`、`不同意`、`喜欢`、`不喜欢`、`从不(0)`、`偶尔(1)`、`有时(2)`、`常如此(2)`；
- 结果/状态：`正常`、`符合`、`合规`、`合格`、`不合格（0分）`、`未落实（0分）`、`未建立（0分）`、`未执行（0分）`；
- 常见 UI：`⬇️ 导出 TXT`、`计算明细`、`备注：`、`点击选择`、`请选择…`、`复制示例`。

这些键在全球短语层生效，单页字典已有译文时仍优先使用单页译文。

### 2. 模板文案模式翻译

`js/tool-i18n.js` 新增 `patternPhraseTr()`：

- `关于「…」` → `About <current tool name>`，标题为中文时退化为 `About this tool`；
- `📖 查看「…」` → `📖 View the <current tool name> guide`，标题为中文时退化为 `📖 View the user guide`；
- `步骤N` → `Step N`；
- `N分` → `N points`。

工具名从英文态 `document.title` 取，避免在 3,000+ 个页面上重复维护同一句指南链接文案；标题尚未英文化时使用通用兜底。

### 3. 保留 emoji 结构

沿用第670批的文本节点替换方式：`📖关于「…」` 只替换“关于…”文本节点，保留 `.h4-icon` 等图标 `<span>`，切回中文可恢复原节点值。

## 核验

- `tools/cardiology/timi-score.html` 英文态：`4 points` 出现、指南链接为 `User Guide`，0 脚本异常；切回中文恢复 `使用指南`。
- `tools/fitness/convert.html`：`📖 About Running Pace Converter`，图标结构保留。
- `tools/robotics/linear-accel-force.html`：指南链接英文化，页面 0 脚本异常。
- `tools/tcm-pharmacy/tcm-dosage.html` 英文态可见中文由 213 字降到 118 字。
- `python3 _build.py` 后修改存活。
- 全量门禁 **274/274 通过**。

## 范围说明

全站英文态仍有大量中医、医学、工程正文没有译文。本批处理的是**高频标签与固定模板**，可显著减少通用区域的中文残留，但不能替代逐页内容翻译。
