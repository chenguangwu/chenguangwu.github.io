# 第 123 批：泪膜破裂时间平均 TBUT 可单独使用（眼科）

- 日期：2026-11-21
- 页面：`tools/ophthalmology/tear-breakup-time.html`

## 原问题

页面把「平均破裂 TBUT（秒，选填）」标为选填，但 `calc()` 只要首次 BUT 为空就直接拒绝：

```js
var val = isNaN(tbut) ? but : tbut;
if (isNaN(but)) { 请输入 BUT; return; }
```

用户如果只记录 3 次测量的平均值、不填首次值，就无法得到任何分级，和「选填」矛盾。

## 修复

- 首次 BUT 与平均 TBUT 分别判空、分别校验 `≥0`；
- 两项至少一项有效即可计算；
- 平均值有效时优先使用平均值，标签显示「平均TBUT」；
- 两项都无效时提示「请输入有效的首次 BUT 或平均 TBUT（≥0 秒）」，并清空结果与两条标尺；
- 描述文案同步为「输入首次或平均 BUT，两项至少填一项」。
