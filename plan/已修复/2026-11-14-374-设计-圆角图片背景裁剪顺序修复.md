# 374 设计 · 圆角图片圆角外残留背景色修复（D-N24）

- **分类**：04-设计创意
- **工具页**：`tools/design/image-rounded-corners.html`
- **日期**：2026-11-14
- **缺陷编号**：D-N24（中，确认源码缺陷）

## 缺陷与根因

`render()` 中**先**绘制背景、**后**建立裁剪路径，导致 `clip()` 只作用于图片，背景层已经铺满整个画布：

- 纯色 / 渐变背景模式下，圆角之外的四个角仍保留背景色 → 导出的 PNG 视觉上是**方角**，与"圆角图片"承诺不符；
- 透明模式因 `bgFill` 为 `null` 不铺背景，故只有纯色/渐变模式暴露该问题。

根因是绘制顺序：`fillRect` 在 `ctx.clip()` 之前执行。

## 修复

把裁剪路径生成与 `ctx.clip()` 提到最前，背景绘制移入裁剪作用域内（同一 `save()/restore()` 块）：

```js
// 修复前：绘制背景 → 裁剪路径 → clip → drawImage
// 修复后：
var radius = getRadius();
ctx.save();
/* circlePath / ellipsePath / roundRectPath */
ctx.clip();
var bgFill = getBackgroundFill(ctx, w, h);
if (bgFill) { ctx.fillStyle = bgFill; ctx.fillRect(0, 0, w, h); }
ctx.drawImage(uploadedImage, 0, 0, w, h);
ctx.restore();
```

修复后背景随圆角形状被裁剪，圆角外保持透明；透明模式行为不变（`bgFill` 为 `null` 时不铺）。
