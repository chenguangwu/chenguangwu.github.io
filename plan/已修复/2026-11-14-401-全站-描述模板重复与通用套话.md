# 2026-11-14-401 全站 · meta description 模板重复与通用套话

## 复核失败原文（交接单第四节）
- `tools/it/phone-parser.html` / `tools/it/charset-detector.html`：归属地表/编码探测是否真实查表，先核验再决定。

## 核验与发现
- 51 个工具页 `meta description` / `og:description` / `twitter:description` / WebApplication JSON-LD 出现同一模板句两遍：
  「XX是一款免费的在线YY工具，XX是一款免费的在线YY工具，……纯前端运行、数据不上传、无需注册，打开浏览器即可使用。纯前端运行、数据不上传、无需注册，打开浏览器即可使用。」
  超过 120 字被截断，属 SEO 套话堆叠。
- 同批页面还有第二层问题：正文无中文段落时，描述直接回落成「输入参数即可实时得出结果」通用句，与工具实际用途无关。

## 根因（`_build.py`）
1. 生成页正文被英文预渲染后，中文原文移入 `data-zh` 属性，而 `extract_zh_desc()` 只扫 `<p>` 文本，取不到中文 → 回落到模板兜底串。
2. 兜底串本身已含「是一款免费的在线…工具」，随后 <70 字符补写分支又套一次模板 → 同一句出现两遍。
3. 历史构建把重复结果写回页面 meta，下一轮再读取，形成固化。

## 修复
- `extract_zh_desc()`：正文无中文 `<p>` 时，按 DOM 顺序读取 `data-zh` 属性，取首个中文 ≥8 字、非公式、非套话的描述作为来源。
- 新增 `_dedupe_desc_boiler()`：对已固化的历史描述去掉重复的固定尾句与重复模板前缀，并清理连续标点。
- <70 字符补写分支：若 core 已是模板串则不再二次套模板。
