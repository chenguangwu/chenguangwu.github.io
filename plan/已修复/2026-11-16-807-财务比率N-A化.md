# 807 批：财务比率页空值/零分母 N/A 化与复制报告同源

- 对应条目：T-N12
- 页面：`tools/audit/ratio-analysis.html`

## 问题
`val(id)` 用 `parseFloat(...)||0`，空值与 0 无法区分；所有比率分母缺失或为 0 时按 0 参与评级（如流动比率 0.00「偏低」、存货周转天数 0 天「良好」）；综合得分固定按 10 分制；复制报告用 `||1` 兜底，与结果卡不一致。

## 改动
- `val()` 空值/非数字返回 `NaN`；新增 `div(a,b)`（分母 >0 且分子有效才计算）与 `fmtR/pctV` 显示助手。
- 12 个比率在无效分母时显示「—」并标 N/A；`grade()` 对非有限值返回 `{cls:'na',label:'N/A'}`，`ratioCard()` 对 na 使用中性标签色。
- 综合得分改为 `score / (有效指标数×2)`，注明「N/A 表示分母缺失或为 0，不参与评分」；有效指标 <3 时输出「有效指标不足，无法综合评价」。
- 复制报告抽出 `reportText()`，复用 `__raLast` 同一结果对象，逐项输出 N/A 原因；无有效数据时提示先计算。
