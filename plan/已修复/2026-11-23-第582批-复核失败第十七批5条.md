## 本轮处理

### 1. 模流冷却公式说明与实际计算不一致
- 文件：`tools/metalwork/analysis-simulator.html`、`i18n/tools/en/metalwork/analysis-simulator.json`
- 公式框与 Ballman 说明统一使用 `Tref = max(模温, 水温)`，与代码 `Math.max(Tmo, Tw)` 一致。
- 真机：模温 80、水温 20、熔体 250、顶出 90、壁厚 3、α=1 → 冷却基准 80°C、冷却时间 2.80s；页面手算口径可复现。

### 2. 衍射极限光圈算例错误
- 文件：`tools/photo/photo-9.html`、`i18n/tools/content_deepdive.json`、`i18n/tools/en/photo/photo-9.json`
- 按 `N = 像素间距 / (2.44λ)` 重算：4 µm、550 nm → N ≈ 4/(2.44×0.55) ≈ f/3.0，不再写 f/29 与“像素×2.44×λ”的错误反推。
- 同步说明 f/8–f/11 是景深/像差/衍射的实际折中，不代表仍发挥 4µm 像素的全部极限。

### 3. OCT RNFL ISNT 顺序与 5µm 边界
- 文件：`tools/ophthalmology/oct-rnfl.html`
- 公式区由“上 > 鼻 > 下 > 颞”改为与实现一致的 `S ≥ I−5 且 I > N > T`；容差改为含等号的 5µm。
- 真机：S=100/I=105（低 5µm）→ 符合；S=99/I=105（低 6µm）→ 违反。

### 4. 质量流量无法作为输入
- 文件：`tools/life/flow-rate-converter.html`
- 源单位新增 `kg/s`：按密度反算体积流量，需密度 >0；输出体积各单位与质量流量，双向口径与中英文简介、公式说明一致。
- 真机：2 kg/s、密度 0.8 → 2.5 L/s、150 L/min、9 m³/h、质量 2 kg/s；密度 0 → 明确提示需有效密度。
