# 第290批 · 无 data-zh 硬编码英文表头补中文锚点（中文态残留英文逐批修复第1批）

## 背景
第289批修复了「有 data-zh 但未还原」的全站根因；老板要求继续逐批修复「无 data-zh 的硬编码英文」。静态扫描此类残留约 **4972 处 / 1678 页**，其中大量为标准名、文献引用、机构缩写、英文专名（按老板口径保留英文），不能一律翻译。本批只处理**高置信通用表头/单元格**（Item / Value / Score / Category / Description / Type / Unit / Note / Field / Name / Status / Grade / Parameter / Option / Date / Result / Symbol / Level / Time / Metric 等）。

## 做法
- 新增高置信词典 `scripts/_zh_datazh_dict.py::TERMS`（只收通用表头/描述词与少量安全复合词，如 `Body Part→身体部位`、`Frequency (Hz)→频率（Hz）`、`Weighted scoring→加权评分`；不收标准名/文献/缩写/专名）+ `KEEP_PATTERNS`（单位/符号跳过）。
- 新增 `scripts/_add_datazh.py`：给无 data-zh 的 `<td>/<th>` 补 `data-zh="中文"`，**保留英文可见文本**；中文态由第289批扩展后的 `restoreAllDataZh()` 还原，英文态不变。默认 dry-run，`--apply` 才写盘。
- 落地：`APPLY target=all: 修改 150 页 / 新增 318 个 data-zh`。Top：Value 32、Score 21、Item 19、Category 18、Description 14、Note 13、Type 13、Field 12、Unit 10、Name 10、Status 9、Option 8、Grade 8…

## 关键坑（已修）
初版脚本把 `data-zh="项目"` 插进了 **JS 字符串内的 innerHTML 模板**：
```js
"<tr><th data-zh="项目">Item</th><th data-zh="数值">Value</th></tr>"
```
双引号提前闭合 JS 字符串 ⇒ 完整门禁 `inline js syntax` + finance/health/surveying/electronics 四个 calc 门禁同时失败（`Unexpected identifier '项目'`）。
- 已撤销全部 tools 改动，修脚本：替换前用占位符保护 `<script>/<style>` 块，替换后还原。这类模板本身有 `isEn()? 英文 : 中文` 双语分支，不属 data-zh 作用域。
- 静态自检：全站 **4921 页**，替换前后 `<script>/<style>` 块逐字比对，**污染 0**。
