# 第719批：JSON 格式化状态与特殊键防护

日期：2026-11-24
页面：`tools/it/json-formatter.html`

## 修复内容

1. **顶层假值可正常展示与导出**
   - 新增 `hasValidJSON` 独立成功状态，不再用 `lastValidJSON` 真值判断。
   - `0`、`false`、`""`、`null` 均可渲染树、统计、复制与下载。

2. **无效输入不再残留旧结果**
   - 解析失败时清空 `treeCopyValues`、结果树和统计，显示「当前输入无效，未生成结果」。
   - 复制/下载在无有效状态时只提示，不再取旧数据。

3. **排序保留 `__proto__` 等特殊键**
   - `sortKeys()` 改用 `Object.create(null)` + `Object.defineProperty` 定义自有属性，避免特殊键写入原型导致静默丢失。
   - 顶层与嵌套 `__proto__`、`constructor` 均保留。

4. **重复键显式提示**
   - 新增轻量 JSON 扫描器 `__jsonDuplicateKeys()`，逐层检测对象重复键，支持转义键（如 `"\u0061"` 与 `"a"` 视为同名）。
   - 实时输入时输入标签显示「⚠ 检测到 N 个重复键；格式化将保留最后一个值」。
   - 格式化、压缩、排序、校验、提取前弹确认并列出前 5 个路径；取消则不改写输入。
