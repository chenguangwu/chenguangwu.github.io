# 第286批 · Robots 生成器 XSS + 数值守卫误判（清单 1 条，高危）

## 问题（清单两子项，同一处根因）
`tools/it/robots-txt-generator.html`：
1. **`rowTemplate()` 用户输入未转义**：ua 拼进 `value="${r.ua}"` 属性，allow/disallow 拼进 `<textarea>` 文本节点，delay 拼进 value 与 placeholder。ua 含 `"` 会闭合属性，路径含 `</textarea>` 会闭合文本框并注入任意 HTML。高危害，代码确认。
2. **`buildDom()` 误用全局数值守卫**：对 `rules.map(rowTemplate).join('')` 的整段 HTML 串做 `Infinity`/独立 `NaN` 匹配，命中即把整个规则区替换成「⚠ 计算结果含无效值」提示。robots.txt 路径含 `/NaN/`、`/InfinityPage` 等合法字样即误判，且输入已存进 `rules`，后续 addRule 重建仍命中 ⇒ 不可恢复。

## 修复
- 新增 `escRobotsHtml(v)`：`& < > " '` 全部实体化；`rowTemplate()` 中 ua / allow / disallow / delay / placeholder 全部经此转义。
- `buildDom()` 去掉数值守卫，恒为 `container.innerHTML = rules.map(r => rowTemplate(r)).join('')`。此页纯文本拼接，无数值结果需要校验。
