## SF-N95（Sinclair 工具承诺「跨体重对比」却无该功能，中 · 承诺未实现）

**失败点**
`juzhongzongchengji-sinclair-xishu.html` 的简介与深度解析反复以「跨体重对比」「不同体重级别谁更强」作为本页卖点，但页面只有「体重 + 总成绩」两个输入，输出只有 Sinclair 系数、归一化总成绩、级别判定与名次参考，**完全没有「换个体重会怎样」的换算入口**。用户读完文案找不到对应控件。

**根因**
Sinclair 系数 `C(bw)` 是体重的单变量函数，`归一化成绩 = 总成绩 ÷ C(bw)` 本身已具备双向换算能力；页面只实现了「正向」（给定体重与成绩 → 归一化值），未实现「反向」（固定归一化水平 → 目标体重下的等效成绩）。属实现裁剪过头，不是公式错误。

**修复位点**
- `tools/sports/juzhongzongchengji-sinclair-xishu.html`
  - 新增输入 `<input type="number" id="targetBw" value="81" min="30" max="250" step="0.01" oninput="calc()">`（标签「目标体重 (kg)（跨体重等效，可留空）」），`setInvalid` 对 targetBw 单独加红框。
  - `calc()` 末尾新增输出：
    ```js
    var tbw = parseFloat(document.getElementById('targetBw').value);
    var baseVal = isMasters ? mastersTotal : sinclairTotal;
    if (!isNaN(tbw) && tbw > 0) {
      var tCoef = sinclairCoef(gender, tbw);
      var equiv = baseVal / tCoef;
      // 「跨体重等效成绩：目标体重 X kg 的 Sinclair 系数 = …，
      //   若保持同等 Sinclair 水平（…），等效总成绩 ≈ … kg」
    } else {
      // 「* 跨体重预测已关闭：目标体重需为大于 0 的数值（当前「…」）。」
    }
    ```
  - 免责说明（同段输出）：「跨体重等效 = Sinclair 归一化的逆运算（同等相对实力的换算），**不是增重/减重的真实预测**：真实跨级还要考虑体重变化带来的力量-体重比改变、试举成功率与减重损耗。」
  - 公式引据框 `eq` 补一行：「跨体重等效总成绩 = Sinclair 总成绩 ÷ 目标体重的 Sinclair 系数（逆运算、同等相对实力换算，非增重/减重预测；目标体重留空则跳过）」。
- `i18n/tools/en/sports/juzhongzongchengji-sinclair-xishu.json`：新增目标体重标签键、免责说明键，改写公式键（共 32 键，`json.load` 校验通过）。

## SF-N98（马术评分三种比赛类型共用同一模型却无任何说明，中 · 口径不明）

**失败点**
`rater-36.html` 提供「盛装舞步 / 场地障碍 / 三项赛」三种类型切换，但三种类型下最终得分公式、四维权重（步态质量 / 跳跃技术 / 骑手姿态 / 路线准确性）、罚分折算系数（×0.5）完全相同，**类型只切换判读文案**。页面对此零说明，用户会误以为三种类型各有独立评分标准；障碍赛用户还会误把「一次碰杆 = 4 罚分」直接填进 `罚分` 列，导致扣减翻倍（页面按 FEI 罚分 × 0.5 折算到 10 分制）。

**根因**
功能上类型切换只驱动 `render()` 里的判读分支，未在 UI 文案层披露「共用等权模型」这一建模选择；障碍赛的罚分口径（FEI 罚分制 vs 10 分制）也没交代。属说明缺失，算法无误。

**修复位点**
- `tools/sports/rater-36.html`
  - 评分说明段补：「三种比赛类型（盛装舞步 / 场地障碍 / 三项赛）**共用同一套四维等权模型**，类型只切换下方判读说明与罚分口径提示，不改变权重。」
  - 障碍赛说明段补：「本页「罚分」列请填 **FEI 罚分总数**，换算到 10 分制时按 ×0.5 折算，故一次碰杆在此扣 2 分。」
  - 功能特点条改：「3 种比赛类型（共用同一四维等权模型，类型切换判读说明）」。
- `i18n/tools/en/sports/rater-36.json`：公式键改写 + 新增评分说明/障碍赛说明键（共 40 键，`json.load` 校验通过）。
