## 修复内容

1. **文件加载原子化（fileVersion）**
   - `handleFile()` 不再边读边写全局：先在局部完成 `arrayBuffer`、pdf.js 文档、结构检测，确认仍是最新 `fileVersion` 后才一次性提交 `pdfFile / pdfArrayBuffer / pdfjsDoc / totalPages / pdfFeatures`。
   - 换文件、重置都会递增 `fileVersion`，旧加载任务在任一 await 后检查失效并销毁旧文档，不再覆盖新文件的页数、buffer 或文件名。
   - 加载期间 `isLoadingFile=true`，提取按钮禁用并显示“加载中... / Loading…”。

2. **可视化模式换文件自动恢复缩略图**
   - 新文件提交后若 `currentMode === 'visual'`，立即调用 `renderThumbnails()`，不再要求用户手动再点一次标签。
   - 切换文件/重置会递增 `thumbRenderToken`，旧渲染任务在每个 await 后失效，不会把旧页缩略图追加到新网格。

3. **缩略图并发与键盘操作**
   - 新增 `thumbRendering / thumbRenderFor`，同一文件只允许一个渲染任务；重复点标签/调用直接返回。
   - 缩略图项由 `div` 改为原生 `button`，带 `aria-pressed`、逐页 `aria-label`（中英双语），支持 Tab / Enter / Space；选中状态通过 `applyThumbSelection()` 同步 class 与读屏语义。
   - 增加 `:focus-visible` 焦点描边；全选/反选/取消全选统一刷新所有按钮的 `aria-pressed`。
   - 提取期间锁定范围输入、标签页、快捷按钮、缩略图与展平选项，避免提取过程中修改页码/选页造成结果与当前选择错配。

4. **提取任务固定源文件（extractToken）**
   - `doExtract()` 开始时固定 `sourceBuffer / sourceName / sourceFeatures / pages / flattenForms`，后续不再读可变的 `pdfFile`、`pdfArrayBuffer`。
   - 每个 await 后校验 `runToken === extractToken && runVersion === fileVersion`；换文件或重置后旧任务直接丢弃结果，不写入 `extractedBytes`、不显示结果、不改按钮。
   - 提取中重置/换文件会立即让旧任务失效；新文件可正常加载，旧任务完成时不会抢回按钮或结果。

5. **大文件与无效输入提示**
   - 明确区分 50 MB 建议阈值与 100 MB 硬限制：50–100 MB 弹出中英文 `confirm` 警告（可取消/继续），100 MB 以上直接拒绝并说明拆分或压缩。
   - 移除两处 `i18nText('toast.saved', ...)` 误用，改为明确的 `__pdfMsg` 加载成功/缩略图失败文案；非 PDF、空页码、未选页均有具体中英文提示。
   - 密码异常按 `PasswordException` 或 `password/encrypt` 识别，提示“本页面不解密，请先用本地工具解除密码”。

6. **英文动态反馈**
   - 文件页数/大小、缩略图页码与进度、选中页数、范围预览、解析错误、提取进度、完成结果、下载 toast、按钮加载/处理/恢复文字全部中英双语。
   - 范围解析错误（空段、格式错误、非正整数、越界、起止倒置）在英文态输出英文。

7. **密码保护说明按真实能力修正**
   - 工具页正文说明、FAQ 可见内容、FAQ JSON-LD、使用指南及 `i18n/tools/office.json`、`office-phrases.json`、`content_deepdive.json`、`en/office/pdf-split.json`、`i18n/guides/pdf-split-guide.json` 同步改为：需要打开密码的 PDF 当前页面无法解密；仅限制复制/编辑权限的文件可能能预览，但提取仍可能受限。
