# 第292批 · IT 清单：Less 编译器异步竞态（旧结果覆盖新状态）

## 清单来源
`plan/categories/01-IT开发/it.md` →「Less 异步编译结果可能覆盖新状态（中，代码确认）」。`tools/it/less-compiler.html` 三个子问题：
1. `less.render()` 回调无版本/输入一致性检查——多个编译先后完成顺序反转时，旧结果覆盖新结果；
2. 清空后仍在途的成功回调可重新填充输出与复制缓存；
3. 输入刚编辑、防抖（400ms）未触发期间，复制/下载仍读上次 `lastCompiledCSS`。

## 修复
- 新增单调递增 `compileSeq` + `invalidateOutput()`（`compileSeq++`、清 timer、清 `lastCompiledCSS`）+ `outputIsStale(seq, code)`（比对序号与输入代码）。
- `compile()`：开头 `seq = ++compileSeq`、清 timer、清 `lastCompiledCSS`；then/catch 回调开头 `if (outputIsStale(seq, lessCode)) return;` 整段丢弃过期回调。
- `debouncedCompile()`：输入变化立即 `compileSeq++` + 清 `lastCompiledCSS`（防抖窗口内复制/下载不再取旧值）。
- `clearAll()`：先 `invalidateOutput()`，在途回调失效。
- 选项 change：先清 `lastCompiledCSS` 再 `compile()`（口径已过期）。

## 验证
- `verify_it_calc.js` +2 强锁（LESSSEQ / LESSSTALE）：新源码 2/2；旧源码差分 **0/2**（`compileSeq is not defined`），恢复后 2/2。全站 **1698/1698**。
- **真机（Playwright + 可控 less deferred 桩）**：新任务先解析 → 输出 `NEW-CSS`；旧任务后解析 → 仍 `NEW-CSS`（不被覆盖）；清空后旧回调再解析 → 保持空态；`lastCompiledCSS` 在途即空；零 pageerror。
- build 成功；完整门禁（262 项，未新增门禁项）通过。

## 坑
- verify harness 是 stub DOM、Promise 回调不同步跑 ⇒ 强锁断言**同步可观测**的防护点（`compileSeq`/`invalidateOutput`/`outputIsStale` 行为），真实异步乱序必须真机用 deferred 桩验证，两者互补。
- clicks 模板字符串内避免 `\"`（stub 坑）；探针写 `__tbProbe` 用 `.textContent`。
