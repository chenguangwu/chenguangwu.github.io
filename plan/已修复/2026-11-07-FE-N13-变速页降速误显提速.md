# FE-N13 变速页降速时仍显示「提速 -25%」

- 页面：`tools/music/convert-speed.html`
- 严重度：中
- 修复日期：2026-11-07
- 状态：已修复（待复核）

## 失败点（原缺陷）
`calc()` 把调速百分比文案写死为「提速 + (nb/ob-1)×100%」：`nb < ob`（降速）时算出负值，显示「提速 -25%」；`nb == ob`（等速）显示「提速 0%」。方向与符号自相矛盾，用户易误读为加速。

## 根因
文案常量拼接，未对 `nb/ob-1` 的符号分支；百分比数值带负号的「提速 -X%」违反语义。

## 修复位点（行号基于修复前源码）
- `tools/music/convert-speed.html:166` `calc()`：
  ```js
  var __p=(nb/ob-1)*100;
  var __pw=__p>0?('提速 '+__p.toFixed(0)+'%'):(__p<0?('降速 '+(-__p).toFixed(0)+'%'):'不变');
  out='...'+__pw+'</p>';
  ```
  换算链明细行（`__g2`）同步改为按符号分支「提速 X % / 降速 X % / 不变」（保留两位小数），与主显示口径一致。

## 证据 / 判别力实测
1. harness 锁定（方向依赖输入）：
   - `{slug:"music/convert-speed", inputs:{dur:"120",ob:"120",nb:"90"}, expect:["降速 25%"]}`
   - `{slug:"music/convert-speed", inputs:{dur:"120",ob:"120",nb:"150"}, expect:["提速 25%"]}`
   - 实测：`env -u NODE_OPTIONS node scripts/verify_fun_calc.js` → **fun calc 35/35**；`discriminate_check.js`（绝对路径）→ 已检 35 | 正确变红 35 | 仍 PASS(逃生项) 0。
   - 锚「降速」仅降速输入下出现，默认态（空/等速）输出「请输入有效正数」或「不变」，非逃生。
2. Node 复算对照：120→90 → 新时长 160.0s、降速 25%；120→150 → 新时长 96.0s、提速 25%；等速 → 不变。

## 复核要点
- 降速输入（nb<ob）显示「降速 X%」（不带负号）；提速显示「提速 X%」；等速显示「不变」。
- 换算链明细行的百分比方向与主显示一致，且为两位小数。
- 未做真实浏览器/英文态/移动端验证；门禁用例已覆盖降速/提速两种形态。
