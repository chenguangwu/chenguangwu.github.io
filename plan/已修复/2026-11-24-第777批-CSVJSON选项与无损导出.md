## 修复内容（`tools/it/csv-to-json.html`）

### CSV → JSON

- 新增“保留全空记录”“重复/空表头按数组输出”两个选项。
- 自定义分隔符支持 1–3 个字符，按整串匹配（如 `||`），不再只比较单个字符；空值、超长、含引号或换行时报错。
- 重复表头与空表头默认报错并给列号，不再让后列静默覆盖前列；勾选数组模式后按数据行数组输出，保留原始字段。
- 全空记录默认过滤，勾选后保留，字段为空串。
- 失败后 `renderPreview()` 对 `currentData=null` 走空态，不再解构空数据抛异常。

### JSON → CSV

- 新增“嵌套对象/数组转 JSON 字符串”，默认开启；关闭时回退 `String`（会得到 `[object Object]`）。
- 引号“无”时，含分隔符或换行的字段拒绝导出并清空输出；`全加引号` 同样拒绝，避免生成不可回读的 CSV。
- 修正引号字符在正则中的转义。

### 文案与英文

- 公式说明的“选项 / 异常”条目改为与实现一致：空记录策略、表头策略、1–3 字符分隔符、无引号拒绝无损导出、嵌套 JSON。
- `i18n/tools/en/it/csv-to-json.json` 补齐新增标签与公式说明英文；`?lang=en-US` 真机检查标签与公式区中文残留为 0。
