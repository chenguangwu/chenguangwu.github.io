## 修复项

### 1. 基准测试跨负载统一评分误导

`tools/it/benchmark-builder.html`

- 删除 `rate > 100万 极快 / 10万 很快 / 1万 正常 / 1000 偏慢 / 其余较慢` 的统一阈值评级；结果区不再给速度等级。
- `run()` 拆分 `workload()`，每个 `ops` 明确对应一轮具体工作量：
  - int：500 次整数平方累加
  - float：500 次三角函数与开方
  - str：100 次字符串拼接
  - array：推入 200 项并降序排序
  - object：写入 200 个键并读取键数
- 新增 `#warmup`（不预热 / 200ms / 500ms）；预热阶段不计 ops，也不计入实测耗时。
- 实测起点改为预热结束后的 `measureStart`，排除 30ms 启动等待；分片调度等待仍计入，并在结果中说明。
- 结果区新增环境信息（逻辑核心数、页面可见性）与口径说明：不同负载工作量不同，不能跨负载比较。
- 同一页面保留最近 5 次同负载结果，显示中位数与范围；仍属同一设备、同一负载的粗略重复观测，不做显著性检验。
- 移除公式说明中的旧评级阈值。

### 2. 密码强度破解时间呈现过度确定

`tools/it/password-strength.html`

- `formatTime()` 删除「宇宙级（无法破解）」和「Cosmic scale (uncrackable)」，改为「远超可枚举范围（按该速率）」；非有限值显示「超出可枚举范围」。
- 破解时间改为区间：
  - 在线猜测：限速 1–100 次/秒；
  - 离线 GPU：1e9–1e11 次/秒；
  - 不把 10 亿次/秒当作在线场景，也不再给单一绝对时间。
- 结果区固定追加假设说明：每位字符独立且均匀随机；在线/离线速率只是区间假设；字典、模式、复用风险可能更快；不给出绝对不可破解结论。
- 公式说明同步改为「2^熵 ÷ 猜测速率」并标注假设边界。

### 3. 贝叶斯证据强度由后验变化判定

`tools/it/bayes-theorem.html`

- 删除 `change > 0.1 证据强力支持 / >0 轻微支持 / <-0.1 强力反对` 的固定百分点结论。
- 解读区保留先验到后验的百分点变化，并新增「证据强度说明」：
  - 后验百分点变化同时取决于先验 P(H₁) 和似然比 BF；
  - 相同 BF 在不同先验下可产生不同百分点变化；
  - BF 表示证据对先验优势的倍率，应结合先验与误报率解读。
- 公式下方补充「BF 是优势倍率，后验百分点变化还取决于先验」。
- 先验为 0/1、误报率为 0 的边界说明保留。

### 4. 蓝牙版本直接断言音频能力

`tools/it/bluetooth-version.html`

- 音频场景不再按 `v >= 5.2` 输出「支持 LE Audio（LC3）」/「仅经典音频（SBC/AAC）」：
  - ≥5.2：说明版本引入 LE Audio 规范，设备是否支持 LE Audio/LC3 须查规格；
  - <5.2：说明低于规范引入版本，仍可能走经典音频 SBC/AAC，具体编码查规格。
- `BT_INFO` 的 5.2 核心特性改为「LE Audio 规范引入（设备支持需确认）」，历史表同步。
- 删除「选购设备看 BLE 版本即可」，改为音频兼容检查清单：
  - 两端是否都支持 LE Audio 与 LC3；
  - 是否都支持经典音频 SBC/AAC；
  - 需要的配置文件（A2DP/HFP/AVCTP 等）；
  - 实测配对、双向通话与延迟。
- 明确版本号只代表规范代际，不代表设备能力，也不能证明两端互通。

## 边界与说明

- 基准仍是浏览器内联 JS 微基准，不能代表整机硬件性能；同负载重复 2–5 次只做中位数/范围观察，未实现置信区间或自动多次采样。
- 密码破解区间仍是基于熵模型的固定速率假设，未提供用户自定义速率输入；真实字典/模式攻击可能远快于该区间。
- 蓝牙仅改文案与检查清单，不读取设备规格、不检测实际 LE Audio/LC3 支持。
