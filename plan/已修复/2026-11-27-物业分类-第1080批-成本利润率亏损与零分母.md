# 第 1080 批：成本利润率保留亏损负号，零分母改为不适用

- 修复时间：2026-11-27
- 类型：计算逻辑 / 输入守卫 / 结果口径
- 涉及页面：`tools/property/cost-profit.html`

## 问题
1. 亏损时利润率被强制归零：成本 100、收入 80 时利润 −20 元，利润率却显示 0%。
2. 通用输入守卫把成本、收入都识别为“分母”，任一为 0 即拦截，无法得到“不适用”说明。
3. 成本占收入比、收入/成本倍数在分母为 0 时无原因提示。

## 修改
- 移除会误杀 0 值的通用分母守卫，改为页面自校验：空值提示“请填写成本与收入（0 为有效值）”，负数提示“成本与收入不能为负数”，非法数字提示无效。
- 成本、收入输入加 `min="0"`。
- 利润率：收入 >0 时按 `(收入−成本)/收入×100%` 输出并保留负号；收入 =0 显示“不适用”。
- 成本占收入比：收入 =0 显示“不适用”；收入/成本倍数：成本 =0 显示“不适用”。
- 结果区追加原因说明：收入为 0、成本为 0、亏损（含负利润率）、收支持平。
- 利润始终输出 `收入−成本`，亏损为负值，不再被归零。

## 真机验证
- 成本 100 / 收入 80：利润 −20.00；利润率 −25.00%；成本占比 125.00%；倍数 0.80；提示“当前为亏损”。
- 成本 100 / 收入 0：利润 −100.00；利润率、成本占比“不适用”；倍数 0.00；提示收入为 0。
- 成本 0 / 收入 100：利润率 100.00%；成本占比 0.00%；倍数“不适用”；提示成本为 0。
- 成本 0 / 收入 0：利润 0.00；利润率、成本占比、倍数均“不适用”，两条原因提示齐全。
- 成本 −1 / 收入 100：拦截并提示不能为负数；成本留空：提示填写，且明确 0 为有效值。
- 英文探针残留 0；`verify_property_calc.js` 26/26；`_test_static.py` 4654 通过 / 0 失败 / 0 告警。

## 复核要点
1. 任何亏损场景利润率必须为负，不得显示 0%。
2. 0 必须被当作有效输入，不得被通用守卫拦截。
3. 分母为 0 的指标显示“不适用”，并给出对应原因。
