## 缺陷

`findInGrid()` 返回 -1 时 `enc()` 直接 `continue`，数字、标点、非拉丁字符全部消失且无提示：`AB1` 编码得 `11 12`，再解码回 `AB`，往返信息丢失、用户毫不知情。

## 修复

`tools/it/polybius-cipher.html` `enc()`：

1. 循环内改为 `if (idx === -1) { skipped.push(ch); continue; }`
2. 编码结果写完后，把跳过情况回显到 `#gridBox`（同页已有的结果盒）：
   - 空格按 Polybius 传统规则允许略过，不计入提示（避免全是噪音）；
   - 提示用固定 id `__polyLost` 并「先删旧提示再追加」，重复点「编码」不会累积；
   - 跳过字符先做 HTML 转义（`& < > " '`）再拼进 innerHTML，避免自己引入注入点。

```html
<p id="__polyLost" …>⚠ 已跳过 N 个无法编码的字符（5×5 网格外）：…</p>
```
