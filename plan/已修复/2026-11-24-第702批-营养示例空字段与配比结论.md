# 第702批：营养示例覆盖、空营养字段与配比结论

## 修复项

`tools/food/nutrition-calculator.html`

### 1. 示例餐食覆盖当前清单

- 已有食物时，替换前确认“当前已有 N 项，示例会替换当前清单”；取消不写入。
- 新增“追加而不覆盖”复选框；勾选后保留现有食物并追加示例。
- 新增“↩ 撤销示例”按钮，保存应用前的食物数组，撤销恢复原清单。
- 空清单首次载入示例不弹确认。

### 2. 空营养数据被当作 0

自定义食物改为五项必填：克数、热量、蛋白质、脂肪、碳水。

- 任一为空：提示“请填写 克数/蛋白质…；未知值不能按 0 计算”，不加入清单，焦点落到第一个缺失字段。
- 克数不再默认 100g；不再把空串通过一元 `+` 变成 0。
- 数值须为有限非负数；显式 0 合法（0 克、0 热量、0 蛋白均可加入）。
- 全部显式 0 时汇总显示 0，并提示“暂无可计算的宏量营养素”，不生成比例结论。

实测：只填部分字段 → 0 项并提示；五项全 0 → 1 项、总热量 0、显示无宏量提示。

### 3. 宏量比例被表述为整体营养合理

- 通过阈值时不再显示“✅ 营养配比合理”，改为“所录食物的蛋白/脂肪/碳水供能比例落在本工具阈值内；不代表整餐或全天膳食均衡，也不评价微量营养素与食材完整性”。
- 三条偏低/过高提示均加“仅指本餐已录入数据”，不再给“增加某类食物”的泛化健康建议。
- 公式说明同步改为“均不满足 → 仅表示所录食物宏量供能比例落在阈值内”。
- 中文/英文分别输出对应文案。

实测：示例减脂餐显示限定后的比例说明；英文态显示对应英文。

### 4. 预设验证

- 已有 1 项自定义食物 → 取消替换仍为 1 项；确认替换为 4 项示例；撤销恢复 1 项。
- 勾选追加 → 1+4=5 项；撤销恢复 1 项。
- 无 `pageerror`。

## 规则

未知营养值不得按 0 进入汇总；示例类破坏性操作必须有替换确认、追加选项和撤销入口；健康结论只描述已录入数据能支持的范围。
