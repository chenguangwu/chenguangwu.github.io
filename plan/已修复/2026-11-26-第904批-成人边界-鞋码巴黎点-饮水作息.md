# 第904批：成人边界、鞋码巴黎点、饮水作息

日期：2026-11-26

本批关闭 10 个任务，涉及蜡烛燃烧、温度换算、鞋码换算、饮水计划、音乐练习计时、清洁用品记录、文胸尺码、卡路里计算、草坪养护、日期差/节日倒计时。

## 修复内容

- 蜡烛燃烧：直径改为原始串校验，非正值/非法值提示“直径须为大于 0 的数值，或留空”；直径仍不参与时长计算。50–100mm 不再直接断言“燃烧均匀”，改为“仅为提示”，公式与输入说明同步标注“直径仅用于提示，不参与燃烧时长估算”。
- 温度换算：CSV 温标名按语言输出（摄氏度/华氏度/开尔文/兰金度/列氏度），参考标签改为 `REF:` / `参考：`，参考值单位改 `°C/°F/K`，中文导出不再残留英文温标名。
- 鞋码换算：欧码由 `2×脚长cm−10` 改为巴黎点制加约 15mm 鞋楦余量 `1.5×(脚长cm+1.5)`，结果取最近半码；美男 `EU−32.5`、英码 `EU−33.5`、美女 `EU−31`。公式区、说明、注意事项、预设标签、深度解析示例同步；`i18n/tools/content_deepdive.json` 的示例改为“EU 42 ≈ US 男 9.5 ≈ 脚长约255mm”。
- 饮水计划：新增起床/就寝时间、可选运动开始/时长输入；新增 `__dwpClock/__dwpTimeMin/__dwpSlots`，在清醒时段内按 90 分钟一段动态分段，默认 07:00–22:00 仍为 10 段；运动增量计入运动开始所在段，跨午夜显示“次日”；结果/导出统一使用动态 slots，重置会恢复 07:00/22:00，输入校验纳入时间与运动参数。
- 音乐练习计时：预设按钮增加 `data-preset` / `aria-pressed`；`loadTemplate(name, btn)` 统一同步高亮；`setTemplate(name, btn)` 不再依赖全局 `event`；`reset()` 恢复热身预设并同步阶段、剩余时间、按钮态；添加自定义阶段时清除预设高亮。
- 清洁用品：消耗记录新增分页状态 `logPage`、每页 30 条、`logPager` 容器与 `goLogPage(delta)`；显示“第 a–b 条，共 N 条”，提供上一页/下一页，删除/新增后自动夹取页码。
- 文胸尺码：快捷示例改为 `70B=70/82`、`80C=80/95`、`75A=75/85`，与当前阈值一致；公式说明新增“示例按本页区间；不同品牌/地区/测量方式可能差半码到一码”。
- 卡路里计算：年龄范围收窄为 18–120（BMR/BMI/TDEE 及保存历史统一）；BMI 面板必须年龄有效才出成人分类；结果区新增适用人群/个体差异说明；TDEE 目标低于 BMR 时提示“不建议长期执行”；“每周体重变化”改为“理论周变化（估算）”并注明 7700 千卡固定换算局限。
- 草坪养护：维护日期为空时明确提示“请选择维护日期 / Please select a maintenance date”，设置 `aria-invalid` 并聚焦日期框；删除草坪/删除记录改为具体提示，不再调用无参 `i18nText()`。
- 日期差：新增 `localDayNumber()`，节日倒计时改用本地日历日序号差，不再用绝对毫秒差 `Math.ceil`，避免跨夏令时偏一天。
