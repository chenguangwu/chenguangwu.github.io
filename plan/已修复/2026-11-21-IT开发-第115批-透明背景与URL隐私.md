# 第 115 批：颜色对比度透明背景、URL 与 nginx 历史隐私（IT 开发）

- 日期：2026-11-21
- 页面：`tools/it/color-converter.html`、`tools/it/url-encode.html`、`tools/it/nginx-config-generator.html`

## 1. 颜色对比度：背景必须不透明

原 `calcContrast()` 只把前景 alpha 合成到背景，完全忽略背景 alpha。`rgba(255,255,255,0.5)` 被当作不透明白色计算，得到的对比度取决于一个页面并不知道的底层颜色。

裁断：不猜测底层（不默认白/黑），直接拒绝计算。

- 背景 `alpha < 1` 时对比度显示 `—`，等级提示「背景色须为不透明（alpha = 1），否则对比度取决于未知底层」；
- 四个 WCAG 勾选全部置为 ✗；
- 前景 alpha 仍按「合成到已确认不透明背景」处理；
- 公式说明同步该口径。

## 2. URL 编码：待编码文本与含账号 URL 不再入历史

`__url_encodeSnap()` 原样保存所有 textarea/input，包括：

- `input`：用户粘贴的任意待编码文本；
- `parseInput`：可能含 `user:pass@host` 的 URL；
- `builtUrl`：生成结果，可能带敏感 query。

改为 `__tbPrivate` 映射，只记录「输入长度 / 解析URL长度 / 生成URL长度」，复选框等非敏感状态仍保留。

## 3. nginx 配置生成：私钥路径只记长度

`certKey` 是私钥文件路径，可能暴露主机目录结构。改为只记录「私钥路径长度」；域名、端口、静态根目录等非敏感项仍正常入历史。
