# FE-N18 五子棋 AI 悔棋整回合回退

**分类**：11-文娱爱好 / 娱乐游戏 (fun/gomoku-ai.html)
**类型**：源码缺陷（回合制）→ 已修复
**处理日期**：2026-11-07
**复核方**：待复核

## 失败点（原缺陷）
悔棋函数 `undo()` 固定只 `history.pop()` 一条并把 `turn = BLACK`：若最后一步是 AI 的白子，撤掉白子后
玩家上一手黑子仍留在盘上、`turn` 回到黑方，玩家可立刻再落一枚黑子 —— 出现「连续两手黑棋、中间无白棋应手」，
回合格被破坏；可无限「撤掉 AI 应手再补一手」，胜负与步数不可信。

## 根因
`place()` 每手都 `history.push([r,c,color])` 且 `turn = -color` 交替；但 `undo()` 不区分末手颜色、只弹一条，
导致撤 AI 应手后盘面停在「玩家刚落子且轮到玩家」的状态。

## 修复位点
`tools/fun/gomoku-ai.html` `undo()`（行 371）：
```js
function undo() {
  if (!history.length) return;
  const last = history.pop();
  board[last[0]][last[1]] = EMPTY;
  // 若撤掉的是 AI(WHITE) 的应手，则把玩家(BLACK)那一手也一并撤掉，回到「玩家重新落子」的回合，
  // 避免玩家在 AI 应手被撤后立刻再落一枚黑子、出现连续两手黑棋破坏回合制。
  if (last[2] === WHITE && history.length && history[history.length - 1][2] === BLACK) {
    const prev = history.pop();
    board[prev[0]][prev[1]] = EMPTY;
  }
  turn = BLACK;
  renderBoard();
  setStatus('已悔1回合，当前轮到你');
}
```

- `scripts/_verify_fun_batch_fe_n18.mjs` JSDOM 真机：玩家点击中心格落黑 → 等 AI 应手（setTimeout 100ms）落白
