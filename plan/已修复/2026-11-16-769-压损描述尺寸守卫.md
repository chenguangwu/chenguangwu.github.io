# 769 批：压力性损伤描述尺寸守卫（D-N123）

## 问题
`tools/clinical-nursing/pressure-injury-description.html` 用 `parseFloat(...) || 0` 读取长/宽/深：

- 清空或填 0 仍生成完整护理记录，创面大小显示「0cm × 2cm」；
- `min=0.1` 仅是浏览器约束，脚本/粘贴/输入法绕过时照样生成；
- 复制文本与门诊记录同样带 0 或负尺寸。

## 修复
- `generate()` 前置校验：长、宽须 >0，深度可留空或 ≥0，否则清空 `__EMR_S`、移除既有 EMR 框并只显示红字提示；
- `copyDesc()` 复用同一校验，无效时 toast 提示且不复制；
- 新增 `__clearEmr()` 统一清理残留门诊记录。

## 验证
`node scripts/verify_clinical-nursing_calc.js pressure-injury-description` ⇒ 3/3，新增：

- 长 0 / 宽 2 ⇒「尺寸无效时不生成护理记录，也不可复制」；
- 长 3 / 宽 2 / 深 −1 ⇒ 同一守卫。

`python3 _build.py` + `python3 _test_static.py` ⇒ 4685/4685/0。

## 说明
尺寸口径沿用页面「最长 × 最宽 × 最深」，分期标准需创面专科复核。
