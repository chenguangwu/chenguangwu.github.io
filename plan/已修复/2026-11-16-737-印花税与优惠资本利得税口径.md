# 737 批：印花税与优惠资本利得税口径

日期：2026-11-16

## 1. T-N17 印花税删除「含税金额 / 税率倒数 / 反算税额」
- 问题：印花税就凭证金额计征、不并入凭证金额，页面却给出 `a×(1+r)` 的「含税金额」与 `a×r/(1+r)` 的「按含税价反算税额」；`1/max(r,1e-12)` 在 0 税率时输出 1e12；金额/税率无校验。
- 修复：
  - 结果卡与导出表改为「印花税额 / 税率(%) / 每万元凭证税额」；
  - 新增 `amount>0`、`r>=0` 校验；
  - 公式框说明印花税不并入凭证金额、联动量定义与校验规则。
- 门禁：amount=0 ⇒「凭证金额须大于 0，税率不能为负」；42/42 自动用例改为新标签串。

## 2. T-N18 优惠资本利得税：税率限制 0–100%
- 问题：无校验，`r=-0.1` 产出负税额（等于退税）、`r=2` 税后利得为负、`r=0` 税率倒数为 1e12。
- 修复：
  - 新增 `g>0`、`0≤r≤1` 校验（提示「税率须在 0–100%（小数 0–1）之间」）；
  - 移除「税率倒数」，改为「每万元利得税额 = r×10000」；
  - extras 同步守卫与表头，公式框同步。
- 门禁：42/0.42 四项联动串；r=1.5 ⇒ 命中提示（原 r=42 用例改为 0.42）。
