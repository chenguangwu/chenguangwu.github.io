## 1. MS-N56 市场份额：合并行「其他」不再当作单一企业

- 原实现把「其他 / Other」与具名企业一起平方求和、参与 CR4，默认数据因此得到 HHI 2755（中度寡占）。
- 改为：HHI / CR4 仅统计具名企业，页面标注「『其他』占 X%（视为分散，未计入）」。
- 仅填写「其他」而无具名企业时，清空结果并提示至少填写一家具名企业。
- 默认数据（5000/3000/2000/其他 4000）现输出 HHI 1,939、CR4 71.4%、其他 28.6%。
- MS-N55 复核：负值与合计 ≤ 0 已清空结果并给出错误提示，无需再改。

## 2. MS-N57 样本量深解数值

- 深解「90% → 267、99% → 663」与页面 Cochran 公式不符，改为 **271 / 664**
  （1.645²×0.25/0.0025=270.6、2.576²×0.25/0.0025=663.58）。
- 中文 JSON 与英文词典同步更新。

## 3. MS-N58 预期比例端点

- `p` 校验由 `p<0||p>1` 收紧为 `p<=0||p>=1`，提示「不能为 0% 或 100%，建议取 50% 最保守」，
  避免输出 0 份样本。
