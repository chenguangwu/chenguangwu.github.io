# 702 批：浮游生物浓缩/稀释方向与碳/鲜重判级分档（10-H50、H51）

日期：2026-11-16　门禁：`_build.py` + `_test_static.py`（4685/4685）+ `verify_fishery_calc.js`（2/2）

## 修复

### `tools/fishery/plankton-biomass.html`
- 新增「样品处理方式」下拉：未处理 / 稀释后计数 / 浓缩后计数。
  - 稀释后计数：原水浓度 = 计数 ÷ 框体积 × 倍数（原实现）。
  - 浓缩后计数：原水浓度 = 计数 ÷ 框体积 ÷ 倍数（新增，修正 1 L 浓缩至 30 mL 被乘 33 倍的高估）。
  - `倍数 <1`、计数/体积/系数非法时清空 `lastResult` 并提示。
- 判级阈值按换算类型分档（原碳/鲜重共用 5/20/40）：
  - 碳：<0.2 偏低、<2 适宜、<5 较丰富、≥5 过密。
  - 鲜重：<2 / <20 / <50（约 10 倍口径）。
- 结果卡与复制文本写出「处理：稀释 N 倍 / 浓缩 N 倍 / 未处理」，避免倍数方向歧义。
- 预设补充 `dilMode`（「鲜重 300 细胞 稀释2倍」标记为 dilute）。

## 测试
