## 修复内容

### 1. 公式引据 `data-zh`

- 生活工具 7 页：`length-converter`、`weight-converter` 的 ISO 80000-3/4 与 GB 3100 改为「量与单位」「法定计量单位」；`date-difference-calculator` 的 Calendar arithmetic 改为「日历算术」；`percentage-calculator` 的 Arithmetic/Statistical practice 改为「算术惯例」「统计惯例」；`world-clock` 的 IANA time zone database 改为「IANA 时区数据库」；`age-calculator` 的 Civil age convention / Gregorian calendar rule 改为「民事年龄惯例」「格里高利历规则」；`countdown` 的 Arithmetic/Interaction practice 改为「算术惯例」「交互惯例」。
- 标准编号 ISO 8601、ISO 80000、GB 3100 与 HTML Living Standard 保留原样；英文态仍由 `data-zh` 的英文文本提供。

### 2. 游戏键盘隔离

- `snake-game`：canvas 增加 `tabindex="0"` 与中文 `aria-label`；keydown 先排除 `input,textarea,select,button,a,[contenteditable=true]`，仅当焦点在游戏 canvas 或事件目标为 canvas 时处理；`startGame()` 主动聚焦 canvas。
- `tetris`：canvas 增加 `tabindex="0"` 与 `aria-label`；keydown 同样排除交互控件并判断 canvas 焦点，保留已有 `canvas.focus()`。
- 目的：页面搜索框、输入框获得焦点时，方向键、空格、W/A/S/D/P 不再被游戏拦截。

### 3. 倒计时改为绝对截止时刻

- `word-scramble`：新增 `gameDeadline`，开局设为 `Date.now()+60000`；250ms interval 按 `ceil((deadline-now)/1000)` 重算剩余秒数；提交答案时若已超截止先结算；`endGame()` 强制时间和进度归零。
- `blink-counter`：新增 `deadline`，开始设为 `startTime+total*1000`；250ms interval 按剩余时间重算；结束时 `elapsed` 取 `min(total, Date.now()-startTime)`。
- 后台节流或设备休眠造成回调变慢时，不再出现实际时长超过设定时长。

### 4. 清洁选项键盘操作

- `area-hours`：`.type-item` 由 div 改为原生 `button`，带 `aria-pressed`；CSS 补 `font-family:inherit;text-align:left;width:100%`，保留可见焦点。
- `dilution-ratio`：两个 `.mode-tab` 与 `.preset-item` 改为原生 `button`，带 `aria-pressed`；`setMode()` 同步两个按钮状态并聚焦当前按钮。
- Tab、Enter、空格均可切换类型和配方。

### 5. 光学物理范围校验

- `rayleigh-criterion`：波长、孔径须为大于 0 的有限数；无效时清空结果和 `rayleigh_criterionTable`，给出中英文错误；extras 在无效时不再写表格与历史。
- `thin-film-max`：折射率、膜厚须大于 0，级次 m 须为不小于 1 的整数；无效时清空 `thin_film_maxTable`，不写历史。
- `thin-film-min`：补齐空白输入检查；折射率、膜厚须大于 0，级次 m 须为不小于 0 的整数；无效时清空 `thin_film_minTable`，不写历史。
- 有效输入恢复后重新绘制数据表；负值、零、小数级次均不再输出波长。

### 6. 英文动态结果

- 农业：`calc-15` 播种日期与安全提示、`calc-38` 均匀性评级与指标、`calc-12` 用水量指标及说明，均按当前语言生成；错误提示同步英文。
- 骑行：`calculator-calc-9` 齿比、每圈距离、齿轮英寸、踏频速度标签、速度-踏频表及齿轮直径说明英文化。
- 蜂场：`cycle-honey` 增加 `FLOW_EN` 月度蜜源英文数据；蜂箱卡片、到期状态、流蜜徽标、上次/下次摇蜜、摇蜜记录表、月度日历、统计卡与导出提示按语言输出；新增蜂箱和摇蜜记录英文可见。
- 训练负荷：`training-load` 结果指标、阶段、建议、复制文本、历史摘要与错误提示英文化；历史阶段随当前语言保存。
- 运动时间：`convert-time` 时间单位（h/m/s）、总时长、分段明细、换项说明、各段占比与负值错误英文化。
- 攀岩布点：`analysis-spacing` 错误提示、载荷、角度因子、安全系数、模型比值说明、锚点数量、间距/夹角评价与假设说明英文化；数字格式按语言选择 `en-US` / `zh-CN`。

### 7. GIF 静帧提示

- `image-flipper`、`image-rotator`：检测 `image/gif` 或 `.gif` 文件名，成功解码后显示「GIF 动图仅能导出当前静帧，动画不会保留。」并提供英文对应提示；提示放在预览图之后，避免被预览替换覆盖。
