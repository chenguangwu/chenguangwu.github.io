# 747 批：药物速查搜索字段与预设分类（D-N12）

## 问题
`tools/medical/drug-info.html`：
- 搜索 blob 只拼接 `name/en/goods/use/cat`，剂量、不良反应、禁忌、注意事项均搜不到；
- placeholder 用「降压」举例，但库内记录写的是「高血压」，页面自带示例 0 条；
- `applyDrugPreset()` 只写关键词，不重置当前分类；在「解热镇痛」等分类下点「降压药」预设会被分类过滤成 0 条。

## 修复
- `render()` 与 `__drugExtras()` 的搜索 blob 同步纳入 `dose + adverse + contraind + note`。
- label 改为「通用名/商品名/适应症/剂量/禁忌」，placeholder 示例改为「阿莫西林 / 高血压 / 头痛」。
- `applyDrugPreset()` 先把 `currentCat` 重置为 `all` 并 `initCats()` 重绘 tab 高亮，再写入关键词并 `render()`。

## 验证
`node scripts/verify_medical_calc.js medical/drug-info` ⇒ 3/3：
- 搜「zzzqx」⇒「未找到匹配药物」（既有）
- 搜「肝毒性」（仅在对乙酰氨基酚 adverse 中出现）⇒「共 1 种药物」；修复前为 0 种
- 切到「解热镇痛」分类后点降压预设 ⇒「共 4 种药物」（氨氯地平/美托洛尔/依那普利/缬沙坦）；修复前为 0 种

`python3 _build.py` + `python3 _test_static.py` ⇒ 4685/4685/0。

## 说明
仅修检索与分类状态，未改动药物数据本身；剂量/禁忌内容仍需以说明书为准。
