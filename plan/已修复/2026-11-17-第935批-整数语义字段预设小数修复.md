# 第935批：整数语义字段预设小数修复（待复核）

## 根因
通用预设模板按「默认参数 / 小规模 / 大规模 / 极端工况」生成 `×0.5 / ×1.5 / ×2` 四档。若字段实际语义为整数（天数、次数、数量、周期、齿数、胜率百分数整数档等），默认值是奇数时就会生成 `2.5 / 7.5 / 10.5` 等非法中间档：
- 多数页面用 `parseInt` 或 `step="1"`，小数会被静默截断；
- 个别页面用 `+value` 参与循环，如 `for (i<=2.5)` 会实跑 3 次，造成预设档与实际语义不一致。

本批延续第929批 `cnt` 字段修复，扩大到 11 个同类整数字段。
