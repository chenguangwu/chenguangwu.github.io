## 一、问题

7 个页面的「工具简介 / 功能特点 / 使用场景」共用同一组模板套话：「设计创意工具，可视化操作，一键生成 CSS 代码」「支持实时预览与调试」「一键复制 CSS 代码」「前端开发中的样式设计」「快速生成 CSS 效果代码」「UI 设计师配色与布局参考」「设计灵感探索与原型制作」，但这些页面没有任何 CSS 生成或复制能力。其中 waveform / spectrum 两页的工具简介此前已改成真实双语描述、pixel-art 简介已属实，但功能/场景仍是套话。

## 二、修复

- 逐页按**真实能力**重写（先看输入 id / 按钮 / 输出容器，再落笔），7 页各 1 段简介 + 4 条功能特点 + 4 条使用场景：
  - `waveform-visualizer`：公式化时域波形，类型/频率/振幅/相位/颜色可调，复制 Base64、导出明细 CSV；简介保留既有 `data-zh` 双语真实描述。
  - `spectrum-visualizer`：合成频谱柱形动画，柱数/柱形/双色可调，不接麦克风、不执行真实 FFT；简介保留既有双语描述。
  - `base64-to-image`：Base64 / Data URL → 图片预览，复制 Data URL 或下载图片；简介删掉「一键生成 CSS 代码」。
  - `data-matrix`：按文本与配色生成矩阵式方格图案，可调尺寸、复制或下载；**只描述演示图案能力，不宣称编码/纠错/可扫码**，避免与尚未修复的公式框（D-N138）产生新的直接矛盾。
  - `tailwind-colors`：22 色系 × 11 阶、按色名搜索、建议文字色、复制 HEX/RGB/CSS 变量（v4）、导出 CSV。
  - `pixel-art`：画笔/橡皮/填充/吸管、撤销重做、导出原始与放大版 PNG；简介已属实、保留。
  - `signature-pad`：鼠标/触屏手写、笔宽颜色、撤销清空、透明底/白底 PNG、比例预设。
- 保留属实的通用条目「可视化操作，所见即所得」「纯前端运行，无需安装」，删除全部 6 条 CSS 套话。

## 三、i18n 处理

- 套话原本集中在 `js/tool-i18n-en.js` 的 `GEN_UI_MAP`（全局通用中英表），新文案沿用同一通道：在该表「🎨 设计创意」段后补 **50 条**新中文短语 → 英文，避免往 7 个页级 en map 各写一遍。
- `data-zh` 双语结构**不采用**：中文站首抓应看到中文，若写成「英文可见 + data-zh 中文」，爬虫和 JS 未执行时看到的是英文，损伤中文 SEO；故一律纯中文可见文本 + 运行时 map 替换。
