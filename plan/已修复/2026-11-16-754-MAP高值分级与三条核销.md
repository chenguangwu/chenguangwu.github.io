# 754 批：MAP 高值分级修正与 CVC/理想体重核销（D-N27、D-N34、D-N35）

## D-N34 MAP 高值分级（已修）
- 问题：`tools/healthcare/map.html` 仅按 `MAP ≥70 ⇒ 正常` 分级，180/120 得 MAP 140 仍显示「正常」；心率字段读入后未展示也未参与计算。
- 修复：
  - 分级改为 ≥100「偏高（需排查）」、70–99 正常、65–69 临界、<65 偏低；
  - 结果区展示心率并注明「仅记录，不参与 MAP 计算」；
  - 公式框同步分级口径。
- 门禁：180/120 ⇒ 140.0 + 偏高；90/40 ⇒ 56.7 + 偏低 + 心率 110；80/120 ⇒ 拒绝「舒张压不得高于收缩压」。

## D-N27 CVC 冲封管（已核销）
封管液下拉已补 1000/5000 U/mL；`selectType()` 同步写入各类型默认封管液；`calc()` 用 `LOCK_CONC` 计算肝素，透析导管强制 1000 U/mL 并在 EMR 标注自动切换。既有门禁：透析导管 + 生理盐水注入 ⇒ 4,800 U，通过。

## D-N35 理想体重（已核销）
`ideal-weight.html` 已并列 Devine/Hamwi/Miller/Robinson 四式；性别 select 仅 1 为男；身高 <152.4 cm 拒绝；年龄字段已移除。新增门禁：180 cm/女 ⇒ 70.5；150 cm ⇒ 拒绝文案。
