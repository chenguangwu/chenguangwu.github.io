- 依据：`plan/G01-公式与计算正确性裁量项.md` C3「期初年金应除以 ä=a×(1+i)，页面按期末 a，年保费偏高约一个利率」。

## 代码

`tools/insurance/endowment-premium.html::calcTool()`

```js
const a=i===0?n:-Math.expm1(-n*Math.log1p(i))/i;   // 期末年金 a
const aDue=a*(1+i);                               // 期初年金 ä = a×(1+i)
const P=(death+survival)/aDue;
```

`__epLast.a` 存 `aDue`，导出与「期初年金系数 a」标签一致。
