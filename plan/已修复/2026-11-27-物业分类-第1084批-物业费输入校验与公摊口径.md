# 第 1084 批：物业费计算补齐输入校验并显式选择公摊口径

- 修复时间：2026-11-27
- 类型：输入校验 / 计费口径 / 防重复计费
- 涉及页面：`tools/property/calc-shared-property-fee.html`

## 问题
1. 空费率、空公摊比例被 `||0` 当 0，负费率可进入计算。
2. 自定义周期为空/0/小数时被强制改成至少 1 或四舍五入，账单与用户输入不一致。
3. 物业费按建筑面积计，公摊费又按公摊面积叠加，未让用户确认合同是否已含公摊，存在重复计费误导。

## 修改
- 所有必填字段显式校验并指出字段：建筑面积 >0；公摊系数 0–100%；物业费/公摊费单价不得为空或负数（0 合法）；自定义周期必须为 >0 整数；任一无效立即停止计算并清空旧结果。
- 删除 `Math.max(1, Math.round(...))` 的强制修正，保留用户原始选择。
- 新增“公摊费用口径”选择：公摊费单列（另收）/ 已含在物业费内（不另收）。选择已含时公摊费小计为 0，只收物业费。
- 结果与明细逐行注明：物业费按建筑面积、公摊费按公摊面积单列或已含；合计明确为“物业费 + 单列公摊费”。
- 新增长期计费假设说明：未考虑滞纳金、优惠、空置减免、税费；不自动判断合同口径；若合同按套内面积或公摊已并入物业费，应调整以避免重复计费。
- 公式框同步更新校验、口径和假设，英文词典补齐新增文案。

## 真机验证
- 默认 100㎡ / 20% / 2.5 / 0.5 / 12 月：物业费 3,000、公摊 120、总额 3,120、月均 260。
- 切换“已含在物业费内”：公摊 0、总额 3,000、月均 250，明细标注“不另收”。
- 物业费单价留空：提示具体字段且明确 0 合法；填 0：正常输出 0 账单。
- 公摊系数 0：正常输出，公摊 0，物业费 3,000。
- 自定义周期 0：提示不能小于 1；1.5：提示必须为整数；负数费率：提示不能小于 0。
- 英文探针 0 页残留；`verify_property_calc.js` 26/26；`_test_static.py` 4654 通过 / 0 失败 / 0 告警。

## 复核要点
1. 空值与合法 0 必须区分；错误提示须点名具体字段。
2. 自定义周期不得被静默改写为 1 或取整。
3. “已含”口径下公摊费必须为 0，且不得再出现在合计中。
4. 计费假设与合同核对提示必须常驻结果区。
