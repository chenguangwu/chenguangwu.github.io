## 修复内容

1. **位运算：BigInt 精确解析超安全整数**
   - 新增 `parseBig`，十进制/0x/0b/0o 及正负号全部用 `BigInt` 解析，不再先转 Number 丢失低位。
   - `calc` 以 `BigInt.asIntN(32)`/`asUintN(32)` 做 32 位补码运算；`2^53+1 OR 0` 的低 32 位正确得到 `1`。

2. **位运算：补齐无符号右移 `>>>`**
   - 运算下拉新增 `USHR`，结果按 32 位无符号输出；位移量统一取低 5 位（0–31）。
   - 位对齐说明区分“左移 / 算术右移 / 无符号右移”，并标注“移位数取低 5 位”；`-8 >>> 1 = 2147483644`。

3. **代码运行器：CSP 默认禁止外网，说明与实现一致**
   - 预览 `srcdoc` 注入 `Content-Security-Policy: default-src 'none'; script-src/style-src 'unsafe-inline'; img-src data: blob:; font-src data:; connect-src 'none'`，外部 fetch/图片/字体默认出站失败。
   - 说明改为：sandbox 不含 `allow-same-origin`，不能读父页/文件；sandbox 本身不阻断网络，由 CSP 禁网；未提供“允许网络”开关；同时保留死循环会冻结标签页的提示。

4. **代码运行器：控制台消息校验来源、结构与长度**
   - 只接受 `e.source === activePreviewFrame.contentWindow` 的消息；每次运行重建 iframe 后旧窗口延迟消息被丢弃。
   - 方法白名单 `log/warn/error`，`data` 必须为数组；单次最多 50 项、单项最多 2000 字符，超出截断并加省略号。
   - `addConsoleLog` 对非数组/非法方法兜底，避免 `data.map` 抛错和 class 注入。

5. **高级单位转换：数据单位区分 SI 十进制与 IEC 二进制**
   - 数据表改为 `kB/MB/GB/TB`（1000 进位）+ `KiB/MiB/GiB/TiB`（1024 进位），`B` 与 `bit` 分开。
   - 说明与常用换算表同步：1 KiB = 1024 B = 1.024 kB = 0.001024 MB，1 B = 8 bit；并注明旧版 KB=1024 的口径已按标准名称拆分。
