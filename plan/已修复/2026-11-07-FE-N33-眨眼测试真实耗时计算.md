# 2026-11-07 FE-N33 眨眼测试真实耗时计算

- 分类：11-文娱爱好 / fun
- 页面：`tools/fun/blink-counter.html`
- 缺陷：提前停止时 `elapsed` 回退为整段时长，速率被低估一个数量级
- 严重度：中（确认源码缺陷，非陈旧快照误报）

## 失败点
`finishTest()` 用 `total-remain` 推时长；若在第一个 1 秒 tick 之前手动停止（`remain` 仍等于 `total`），`elapsed<=0` 被兜底成 `total`，把不足 1 秒的测试按整段时长计算，导致短测速率被严重低估（如 3 次/0.5s 显示成 3 次/分）。

## 根因
时长统计依赖「整秒 tick 递减」的 `remain`，而非真实起止时间戳，且对 `elapsed<=0` 用整段时长兜底。

## 修复位点
文件 `tools/fun/blink-counter.html`：
- 状态声明新增 `startTime`：`var blinks=0,timer=null,remain=60,total=60,running=false,startTime=null;`
- `startTest()` 内 `running=true;` 之后加 `startTime=Date.now();`
- `finishTest()` 起点改为：
  ```js
  var elapsed=(Date.now()-startTime)/1000;
  if(!(elapsed>0))elapsed=0.001;
  var perMin=(blinks/elapsed*60);
  ```
