# 复核失败重做批次 · 申请再次复核

- 原复核条目：涂料计算：负门窗扣减反而增加涂刷面积
- 页面：`tools/home/paint-calculator.html` 的 `getDeduct()` 与 `calc()`
- 失败点：门数 −1、单门面积 2、窗数 0 时，页面显示毛面积 82 m²、门洞扣减 −2 m²、净面积 84 m²，负扣减反而增加用漆量与成本。

- 修复位点：`getDeduct()` 改为 `if(![dc,da,wc,wa].every(function(x){return isFinite(x)&&x>=0;})) return {ok:false,msg:'门窗数量与面积均须为非负数值（不能为空或负数）。'}`；`calc()` 在 `!deductRaw.ok` 分支显示 `⚠ ` 提示，并将 `total-area/net-area/total-paint/total-buckets/total-cost` 置「—」后 return。
- 证据：`scripts/verify_home_calc.js` 新增用例（inputs door-count=-1、door-area=2），expect `["门窗数量与面积均须为非负数值"]`；跑得 `==== home calc 3/3 ====`。
