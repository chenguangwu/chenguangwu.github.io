# 588 批：不确定度、RTY 全零与供应商权重

## measurement-uncertainty：空值/负值/全零
- 根因：`num()` 把空值转 0，三项清零仍输出 0 不确定度；负分量得负线性叠加；清空单项时明细因非有限值提前返回，旧表残留。
- 改法：三项须填写（可填 0 但不可为空）、不得为负、平方和不得为 0；明细路径同规则并清空旧表。
- 验证：新增 u1=-1 与 0/0/0 两例，分别命中「不能为负值」「至少一个…大于 0」；原 3.5185 用例保持。

## rolled-throughput-yield：全零误拒
- 根因：通用全零守卫把三道 0% 良率判为无意义，但 RTY=0、总不良率 100% 是合法工况。
- 改法：本页守护删除全零拦截；负良率仍拒绝，明细路径补 `<0` 清表分支。
- 验证：新增 y=0/0/0 → RTY 0.00%、总不良率 100.00%。

## supplier-score：权重与评分越界
- 根因：权重空值转 0，四权重为 0 时兜底分母 100 仍输出排名；负权重/超 100 评分无校验。
- 改法：权重须为 0–100 且合计 >0，否则红字提示并清空排名与条形图；供应商评分输入改为 0–100 校验，越界标红并保留原值。
- 验证：新增全 0 权重与 -5 权重两例；原 120% 权重提示用例保持。
