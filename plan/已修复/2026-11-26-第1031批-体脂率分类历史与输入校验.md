# 第 1031 批：体脂率计算器分类、历史与输入校验

- 页面：`tools/health/body-fat-calculator.html`
- 处理任务：17 项（`plan/health/体脂率-*.md`、`plan/health/体脂计算分类卡片方法介绍不全.md`）
- 验证脚本：`scripts/verify_health_calc.js`

## 主要修改

1. **分类与标尺统一**：新增 `BF_BANDS`，男女各 5 段（必需 / 运动员 / 健身 / 平均 / 肥胖），`getBfCategory()` 与标尺共用同一组阈值和颜色；标尺按 0–50% 比例绘制，marker 按 `bf/50` 定位，解决分类阈值与标尺阈值不一致。
2. **历史颜色按记录性别**：历史记录保存 `gender`，`renderHistory` 不再按当前性别给旧记录上色；缺性别的旧记录用中性色并标“性别未记录”，条目显示日期、时间、性别、方法。
3. **历史趋势横轴口径**：明确标注“记录次序（横轴按保存顺序，非时间等距）”，同时保留日期，避免误读为等时间间隔；过滤无效记录并显示“已忽略 N 条无效记录”。
4. **无效输入清空分析**：新增 `calcHint`；计算失败时 `lastValid=false`，清空体脂值、分类、身体成分、建议，相关字段标 `aria-invalid`，显示具体原因，不再残留上一次分析。
5. **公式结果不再静默截断**：海军法、BMI、皮褶、BIA 只做有限值与有效区间校验，删除 `Math.max(3/5, Math.min(60/55,...))` 截断；腰围≤颈围、女性腰+臀≤颈围、负身高/体重、非整数年龄等明确报错。
6. **女性皮褶字段**：男性显示胸/腹，女性隐藏；女性专用三头肌/髂脊字段仅女性显示，大腿共用，避免女性填写男性专用测点。
7. **皮褶法可见参数**：新增 `height3`、`weight4`、`age3`，不再读取隐藏 BMI 表单 `age2` 或海军法体重/身高；`getWeight()/getHeight()` 按当前方法读取可见字段。
8. **身体成分口径**：BMI 使用当前方法可见身高；BIA 无身高时 BMI 显示 `—` 并标注“BMI（需身高）”，不再回退隐藏海军法身高。
9. **减脂建议**：移除所有结果固定展示的“300–500 kcal 缺口、高蛋白 1.6–2.2 g/kg、每周 3–5 次”等统一目标；按现行分类给出非诊断性建议，并统一附孕期/哺乳期、未成年人、运动员、患病或服药人群限制；低体脂明确提示不要继续减脂。
10. **预设**：改为 4 个自定义预设（默认、海军法·男、皮褶法·女、BIA 法），点击时同时切换方法、性别和对应可见字段；旧 `data-tb=preset` 宿主替换为 `#body_fat_calculatorPresets`。
11. **自动记录控制**：历史卡新增“自动记录”复选框，写 `bodyfat_auto_record`；关闭时 `__body_fat_calculatorExtras` 不写 TBKit 历史；清空历史同时删除 `bodyfat_history` 与 `TBKit.history.clear()`，并清空自动历史表格 DOM。
12. **SEO/标题**：页面 title、h1、面包屑、og/twitter、WebApplication、meta description 统一为“体脂率计算器（围度/BMI/皮褶/体脂秤）”；英文标题/简介描述四种方法，`desc-en` 缩短以避免构建 160 字截断。
13. **英文态重算**：在 defer 的 i18n/TBKit 初始化后补一次 `calc()`，首次进入英文态即按英文分类、标尺与建议重算，不再保留中文结果。
14. **示例与指南**：`content_deepdive.json` 女性海军法示例改为 25.6%、脂肪 16.6 kg、LBM 48.4 kg、BMI 22.5；`guides/body-fat-calculator-guide.html` 与 FAQ JSON-LD 同步。
15. **i18n 同步**：`health.json`、`health-body.json`、`_en_override.json`、`slug-en.json` 的标题、简介、描述同步；分类卡片覆盖四种方法。
16. **旧校验期望更新**：`scripts/verify_health_calc.js` 删除对“健康减脂是长期过程”固定建议的断言，改为断言新定义域错误文案“海军法要求腰围大于颈围”，避免用旧固定建议倒逼页面保留错误行为。

## 真机验证

- 初始男 170/65/80/38：13.7%、运动员水平、脂肪 8.9 kg、LBM 56.1 kg、BMI 22.5；标尺 5 段正确，marker 27.4%。
- 女性同输入：25.6%、平均水平、脂肪 16.6 kg、LBM 48.4 kg、BMI 22.5；marker 51.2%，臀围显示、胸/腹隐藏、女皮褶字段显示。
- 腰围 30 / 颈围 40：显示“围度组合超出公式有效范围，请核对测量数据”，体脂/分类/身体成分/建议清空，`waist aria-invalid=true`。
- BMI 负身高/负体重/小数年龄：显示“BMI 法需要大于 0 的身高、体重和整数年龄”，`age2 aria-invalid=true`。
- 皮褶男：胸/腹显示、女性字段隐藏；填 15/20/25/30/175/70 得 17.9%、健身、BMI 22.9。
- 皮褶法·女预设：切到 skinfold/female，tricep=18、thigh=25，胸隐藏，结果 23.8%。
- 历史：男 13.7% 绿色、女 25.6% 粉色；无效 `bodyFat:null` 被忽略并显示“已忽略 1 条无效记录”；两条记录时图表显示。
- 清空：`bodyfat_history=null`、`TBKit.history.list().length=0`，历史相关 localStorage 键为空。
- 自动记录：关闭后改身高等待 1.2s，TBKit 历史 0；重新开启后改身高，历史 1。
- 低体脂 2.5%：提示“体脂率偏低…不要继续减脂”，不再出现固定热量缺口。
- 英文 `?lang=en-US`：intro 覆盖四方法且明确 sex-specific bands、not age；分类 Athletic；标尺 Essential/Athlete/Fitness/Average/Higher；建议英文；历史开关英文。
