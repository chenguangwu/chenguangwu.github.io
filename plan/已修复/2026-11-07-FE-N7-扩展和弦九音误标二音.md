# FE-N7 · 扩展和弦九音被误标为「二音」（已修复 · 待复核）

- 分类：11-文娱爱好 / fun-entertainment
- 工具页：`tools/music/chord-notes.html`
- 移交日期：2026-11-07
- 来源条目：`plan/categories/11-文娱爱好/fun-entertainment.md` → FE-N7

## 失败点（用户可见缺陷）
`C9`/`Cm9`/`Cadd9` 等扩展和弦，其最高扩展音按音乐理论应是「九音」，但页面把音程标签写成 `DEGREE_NAMES[semitone % 12]`：`add9` 的 +2 半音与 `9`/`m9` 的 +14 半音经 `%12` 都落到索引 2，显示为「二音」。这与页面自身规则表「加九和弦 = 大三+九音」矛盾，学习者被误导。

## 根因
- `chord-notes.html` 音程标签渲染（音符标签行 668、音程标签行 680）使用 `DEGREE_NAMES[note.semitone % 12]`，对 `oct>=1` 的扩展音（如 +14=九音、+17=十一音、+21=十三音）未做扩展命名，直接按 `%12` 当成基础音程（二音/四音/六音）显示。
- `add9` 的 +2 半音（oct=0）按 `+12` 约定本应称「九音」，但 `DEGREE_NAMES[2]` 是「二音」。

## 修复位点
- `tools/music/chord-notes.html`：
  - 新增 `degreeName(s, type)` 助手（行 477 后）：`base=((s%12)+12)%12`，`oct=Math.floor(s/12)`；`oct>=1` 时 `base∈{1,2,5,9}` 映射为「九/九/十一/十三音」；`s===2 && type∈{add9,'9','m9'}` 也返回「九音」；其余回退 `DEGREE_NAMES[base]`。
  - 音符标签（行 668）与音程标签（行 680）由 `DEGREE_NAMES[s%12]` 改为 `degreeName(s, chord.type)`，显式传入和弦类型以区分 `add9` 与 `sus2`。

## 复核要点（供复核方）
- `C9` / `Cm9` 结果的扩展音标注为「九音 (14半音)」；`Cadd9` 标注「九音 (2半音)」。
- `Csus2` / `C2` 仍标注「二音 (2半音)」，与挂二和弦语义一致。
- 基础三和弦/七和弦（C、Cmaj7、Cm7 等）标签不变（无回归）。
