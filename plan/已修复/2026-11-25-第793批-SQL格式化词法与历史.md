## 改动

`tools/it/sql-formatter.html`

- 新增词法器 `sqlTokenize(sql,dialect)`：区分空白、行注释（`--`、MySQL `#`）、块注释、单/双引号、反引号、SQL Server `[...]`、PostgreSQL `$tag$` 美元引用、多字符运算符；格式化与压缩均按词法 token 重建，不再用全局正则删注释/折叠空白。
- 子句识别改为 `sqlClauseInfo()`：允许关键字之间夹空白，正确识别 `GROUP BY`、`ORDER BY`、`UNION ALL`、`LEFT [OUTER] JOIN`；仅对完整 word token 命中关键字，不拆分 `information` / `on_time`，不改写字符串与带引号标识符。
- 多字符运算符 `>=`、`<=`、`<>`、`!=`、`::`、`||`、`->`、`->>` 整体输出，避免拆成 `> =`。
- 新增 `sqlLexError()`：未闭合字符串、块注释、反引号/方括号/双引号标识符、美元引用时拒绝格式化并提示，不吞掉剩余全文。
- 历史默认不落盘；新增 `#saveSqlHistory`「保存完整 SQL 到本地历史（默认关闭）」。开启后保存完整原文与摘要，点击历史完整恢复；旧摘要记录清理为「旧记录仅摘要，已清理（无法完整恢复）」，恢复时明确提示。
- 历史渲染改为 DOM `textContent` 构建，动态摘要/时间/动作不再拼入 `innerHTML`。

`i18n/tools/en/it/sql-formatter.json` 同步新增历史相关英文键。
