# 第 723 批：JSON 差异八项（重复键、大整数、假值、草稿与无障碍）

- 任务来源：`plan/it/JSON差异-*.md` 共 8 条
- 完成日期：2026-11-24

## 修复内容

### 1. 重复键被覆盖导致漏报
- 用自写 `jdParse()` 替代 `JSON.parse()`；解析时按对象层级记录重复键的侧别、路径与原始字符偏移。
- 页面顶部警告条列出前 5 处（例：左侧「a」@7），明确「后写覆盖前值」。
- 即使覆盖后解析值相同，路径视图也显示「不能视为原始文本完全相同」，不再显示 ✅ 完全相同。
- 不同对象内同名键、数组内不同元素同名键按路径区分，不误报；转义后同名的键按解码后的键名判定。

### 2. 输入变化后仍可导出旧报告
- 两侧 textarea 监听 `input`，立即清空 `lastDiff/lastLeft/lastRight`、计数、三栏行视图、路径列表、JSON 输出与图表。
- `jdCopyBtn` / `jdDownloadBtn` 在无有效结果时 `disabled`，重新对比成功后恢复。
- 复制/下载只以 `lastDiff !== null` 判断完成状态，不再用输入值真值。

### 3. 清空和交换未同步本地草稿
- 统一草稿读写：`jdSaveField/jdSaveBoth/jdStoreEmptyDrafts/jdRemoveDrafts`。
- `clearAll()` 在开启草稿时写入左右空字符串（刷新后保持空态），关闭草稿时删除键。
- `swapInputs()` 与示例按钮显式同步草稿；刷新恢复后自动按恢复内容重算。
- 新增「清除本地草稿」按钮，只清存储、不清当前输入。

### 4. 顶层假值导致复制失败
- 普通视图复制改用独立完成状态；顶层 `false/true` 可复制出 `false → true`。
- 零差异时复制「无差异：两个 JSON 文档完全相同。」；JSON 视图复制 `[]`；下载零差异为 `[]`。
- `copyDiff()` 返回生成的文本，便于回归断言；按钮调用不受影响。

### 5. 结果视图标签无法键盘操作
- 四个 `div.tab` 改为原生 `button`，补齐 `role="tab"`、`aria-selected`、`aria-controls`、`tabindex`。
- 由 `js/tool-ux.js` 统一处理方向键/Home/End 与点击；移除页面内重复 keydown 逻辑，避免一次按键跳两格。
- 增加 `.tab:focus-visible` 可见焦点；面板补 `role="tabpanel"` 与 `aria-labelledby`。

### 6. 自动保存缺少隐私选择
- 工具栏新增「本机保存草稿」开关，默认开启；关闭即删除已存草稿，后续输入不再写入。
- 新增可见说明：输入只在本机处理，开启时两侧原文存到当前浏览器 `localStorage`，可关闭并清除。
- 监听 `storage` 事件，多标签页关闭草稿时同步取消勾选并清草稿。
- 清除范围为左右两侧 JSON 草稿，不含当前输入、不含其他工具键。

### 7. 大整数精度丢失
- 新增 `JDNumber` 保精度数字：超出安全整数或有效位数 >15 的十进制值保留原始字面量。
- 新增 `jdStringify()` 全链路替代 `JSON.stringify()`：路径视图、并排/合并行视图、JSON 输出、复制、下载均保留原文。
- 数字按数值语义比较：`1.0 / 1e0 / 1` 视为相同；`0.001` 与 `1e-3` 相同；对象键不参与数字比较。
- 极端指数（|exp|>400）不展开，避免 `1e999999` 拖垮页面。
- 同步更新公式说明、页面 FAQ、FAQPage JSON-LD、`i18n/tools/content_deepdive.json` 与英文词典。

### 8. 清空后统计图残留
- `invalidateDiff()` 重置四个计数、隐藏汇总、清空 `#jdChart`、清空导出状态。
- `__jdChart()` 在 `lastDiff === null` 时直接返回；语言切换监听同样先判有效结果，清空后不再重绘旧饼图。
