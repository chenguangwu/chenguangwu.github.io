# 736 批：摊销年限整数守卫与 SYD 年份核销

日期：2026-11-16

## 1. T-N13 直线摊销：年限必须为正整数
- 问题：小数年限 0.4 时主结果年摊销 = (c−s)/0.4 = 250000，而计划表按 round(0.4)=1 年只摊 100000，两口径无法对账；负年限/残值倒挂已由既有校验拦截。
- 修复：
  - `calcTool()` 的年限校验改为 `n>0 && Number.isInteger` 语义（`Math.floor(n)!==n`），提示「摊销年限须为正整数（年）」；
  - `__amortization_intangibleExtras()` 增加同一组守卫（`c>0`、`0≤s≤c`、`n` 为正整数），非法输入不再渲染明细表与逐年计划。
- 门禁：n=0.4 / n=−5 / s>c 各一条；默认 600000/0/10 不受影响。

## 2. T-N14 SYD 越界年份核销
- 复核 `tools/accounting/depreciation-syd.html`：`calcTool()` 已校验 `c>0`、`0≤s≤c`、`n`/`yr` 为整数且 `1≤yr≤n`，提示「计算年份须为 1–N 之间的整数」。
- 补门禁：n=10、yr=12 ⇒ 命中该提示（旧实现输出 −1636.36）。
