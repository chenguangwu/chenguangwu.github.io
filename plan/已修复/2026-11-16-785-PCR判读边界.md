# 785 批：PCR Ct 判读边界与示例统一（D-N90）

## 问题
- 信息框写「Ct<30 强阳性、30–37 模板中等浓度、Ct>cutoff 阴性」，与公式框/代码的「高拷贝 / 低拷贝 / 灰区 / 阴性」不一致；
- 深解示例「Ct 28 ⇒ 载量中等」，而代码 `Ct<30` 判「阳性(高拷贝)」；
- 信息框的「Ct>cutoff」遗漏了等于 cutoff 的情况。

## 修复
信息框改为：

- Ct<30：阳性，高拷贝（强阳性）
- Ct 30–37：阳性，低拷贝（中等浓度）
- Ct 38–cutoff：弱阳性/灰区，需重复确认
- Ct≥cutoff 或无 Ct：阴性

深解示例改为「Ct 28 ⇒ 阳性高拷贝；Ct 39 近 cutoff 为灰区，建议复测」。

## 验证
`node scripts/verify_clinical-lab_calc.js pcr-ct-interpretation` ⇒ 3/3（既有 32 分低拷贝、39 分灰区用例保持通过）。
`python3 _build.py` + `python3 _test_static.py` ⇒ 4685/4685/0。

## 说明
本批只改文案与示例，判读阈值未动；Cutoff 与平台差异仍需实验室口径复核。
