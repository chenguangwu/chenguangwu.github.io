# 第332批 · 设计创意 · PNG 转 SVG 三处函数缺陷修复（销 D-N19）

## 背景
- D-N19 确认 png-to-svg 三处函数缺陷：① 阈值 0 被 `||` 兜底吞成 128；② 负值块宽直接透传生成非法 SVG（`width="-5"`）；③ `lastSVG` 换图/改参不失效，复制拿到旧图。

## 改动（tools/design/png-to-svg.html）
1. **解析钳制（修复①②③的解析与越界）**：
   - 旧 `const block = parseInt(...).value) || 8; const alphaTh = parseInt(...).value) || 128;`
   - 新 `Number.isNaN` 显式判空 + 钳制：`block ∈ [1,40]`、`alphaTh ∈ [0,255]`（**阈值 0 保留为 0**，不再被吞）；越界/负值钳为合法值并**回写输入框**。
2. **防旧图复制（修复③）**：
   - `generate()` 过文件校验后先 `lastSVG = ''`，确保重新生成必刷新。
   - 新增 `__pngReset()`：清空 `lastSVG` 与代码框；通过 `addEventListener('change', __pngReset)` 绑定到 fileInput/blockSize/alphaTh（**不用 HTML `onchange` 属性**，避免干扰 verify harness 的 stub DOM 采集）。

## 验证
- **Node 逻辑单测 16/16 全过**：阈值0→0（旧128）、块0→1（旧8）、块-5→1（旧-5非法）、块50→40（旧50）、越界/NaN 兜底正确；4 个缺陷用例旧错→新对。
- **design calc 门禁 335/335**（修复中一度因 `onchange` 属性干扰 harness 采集致 334，移除 HTML onchange 改 addEventListener 后恢复 335/335）。
- **inline JS 语法 12141/12141** 全过。
- `_build.py` EXIT=0，源无 `|| 8`/`|| 128` 残留，reset 经 addEventListener 接线就位。
- canvas/图像真实生成路径 harness 无法加载图片，按铁律走源码审查 + 逻辑单测 + 门禁，未强锁 verify 用例（既有 B 类零用例已覆盖解析/钳制输入）。

## 销账
- design.md 删 `### D-N19`（125–130 行）。

## 经验（防回归）
- **严禁在 verify 用例覆盖的工具上用 HTML `onchange`/`onclick` 内联属性做副作用**：harness 的 DOM stub 在采集输出时会因内联事件属性改变元素遍历/取值顺序，导致用例错位失败。副作用一律用 `addEventListener`（程序化设值不触发 change，不干扰 harness）。
