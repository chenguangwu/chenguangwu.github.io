# 第 424 批：Markdown 导出模板清理

日期：2026-11-22
类型：内容质量 / 导出文件正确性
状态：已修复并本地提交（未 push）

## 一、原问题

`tools/biz/markdown.html` 的“导出 HTML”功能把页面预览内容拼进一个完整的 HTML 文件时，额外注入了：

1. 本站的 `SoftwareApplication` JSON-LD，包含 `chenguangwu.github.io` URL、站点名“Markdown 预览”和本站描述；
2. 一段只服务于本站工具页的 `tool-intro` 折叠交互脚本。

导出文件本应是用户自己的 Markdown 文档，却携带本站结构化数据和无关脚本，存在两个问题：

- 用户把导出文件上传到其他站点时，JSON-LD 会把内容错误标注为本站工具，误导搜索引擎；
- 导出文件标题固定为 `Exported`，缺少语言、视口和基础排版，移动端阅读体验差。

## 二、修复内容

修改 `tools/biz/markdown.html` 的 `exportHTML()`：

- 删除导出模板中的本站 JSON-LD 与 `tool-intro` 脚本；
- 设置 `<html lang="zh-CN">`、`<meta name="viewport" ...>`、`<title>Markdown 文档</title>`；
- 保留并补全基础阅读样式：正文宽度、行高、图片自适应、代码块横向滚动、等宽字体；
- 导出内容仍为 `preview.innerHTML`，不改变 Markdown 渲染与用户正文。
