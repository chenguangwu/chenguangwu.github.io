## 修复内容

1. **长文字重叠/溢出画布**
   - 新增 `wcBreakLines` / `wcFitBlock`：标题、副标题各自限定区域高度和行数，超长时逐级缩小字号；到下限仍放不下则截断最后一行并加省略号。
   - 中文按字符换行，英文按单词换行；单个英文单词宽于可用宽度时按字符拆分，避免整词溢出。
   - 画布下方 `#wcNotice` 明确提示“标题/副标题超长，已自动缩小并在限定行数内截断”。
   - 标题区、副标题区、署名区使用独立的 top/height 预算，标题再长也不会压到副标题或页脚。
   - 实测 300 字标题 + 400 字副标题在 900×383 与 200×200 均正常结束并提示；默认短文不提示。

2. **方形导出裁字与预览不一致**
   - 取消“固定 900×383 预览 + 导出放大居中裁切”，改为 `wcTargetSize()` 读取所选尺寸后直接把画布设为目标宽高并重排。
   - 预览与下载使用同一张目标尺寸画布；`download()` 不再创建第二张裁切画布，导出像素即所选尺寸。
   - 实测 900×383、200×200、1080×1080、360×200 四种尺寸：`cover.width/height` 与 `toDataURL` 解码尺寸完全一致；方形/缩略图不再裁掉标题。
   - 尺寸表与实际选项保持 900×383 / 200×200 / 1080×1080 / 360×200。

3. **固定署名无法关闭/自定义**
   - 新增“显示署名”复选框与“署名文字”输入框；取消勾选或清空文字后画布不再绘制署名。
   - 署名过长时 `wcFitSingle` 自动缩小字号，缩到下限仍超宽则截断并加省略号，保证不超出左右边距。
   - 实测：默认署名与关闭署名画布 dataURL 不同；清空署名与关闭署名一致；超长英文署名无 pageerror。
   - 新增 FAQ“署名可以去掉吗？”与对应 FAQPage 结构化数据。

4. **英文态默认输入与画布不一致**
   - 移除“画布内暗中替换中文默认值”的逻辑；画布始终读取输入框实际内容。
   - 新增 `wcSyncDefaults`：按语言把尚未修改的示例值同步为 `Tool name` / `A practical online tool picked today` / `ToolBox · Online Tools`；用户改过的文字保留。
   - `wcBoot` 在 `DOMContentLoaded` 后补一次同步，修复 localStorage 恢复中文示例后英文页仍显示中文的问题；语言切换事件同样同步并重绘。
   - 预设改为按当前语言生成示例标题/副标题，英文态预设不再写入中文默认。
   - 实测英文首次进入：输入框、画布、占位符均为英文；编辑为 “My headline” 后再次同步仍保留；中文页预设后切英文页输入恢复英文示例。

5. **FAQ 与换行/导出尺寸不符**
   - 以 `i18n/tools/content_deepdive.json` 为权威源重写 FAQ：英文按单词换行、超长单词按字符拆分；标题过长自动缩字号/截断；导出尺寸会随所选尺寸变化且不裁切；署名可关闭。
   - 页面可见 FAQ、FAQPage JSON-LD 与数据源一致；补充署名 FAQ。
   - 更新 `image-body.json`、`image.json`、`_en_desc.json` 与英文第三层字典；英文态首段、控件标签、选项、预设、FAQ 均同步。
