## 1. 单利：不足一年复利对比措辞错误

`tools/finance/simple-interest.html` 原固定输出「按每年复利 1 次，比单利多」，即使 0.5 年时复利本利和 1,048.81 低于单利 1,050，仍配负差额。

- 复利本利和改为 `compoundFV = P·(1+r/100)^t`，差额取绝对值后按正负显示「多 / 少 / 相同」，不再出现「多 -1.19」。
- `t < 1` 时说明「不足一年按 (1+年利率)^年数 比例折算，并非真实付息日复利」，避免把按年复利公式当成真实付息频率。
- 0.5 年 / 10% / 本金 1,000：单利 1,050、复利 1,048.81、比单利少 1.19；整数年仍显示「按每年复利 1 次」。

## 2. 复利：清空利率仍按零利率计算

`tools/finance/compound-interest.html` 原 `parseFloat(rate)||0` 把空串当 0%，输出「本利和等于本金」并照常显示年表。

- 新增 `__rRaw` 判空：空串清结果并提示「请输入年化利率（如确为 0%，请明确输入 0）」；非有限值提示有效数字；显式 0 仍正常走零利率。
- 本金为负 / 利率为负 / 年限 ≤ 0 原先静默 `resetDisplay()`，现分别给「本金不能为负 / 年化利率不能为负 / 年限须大于 0」的具体提示，不再留下无结论的空结果区。

## 3. 货币换算：标签与历史操作缺少键盘入口

`tools/finance/currency-converter.html` 五个页签原为 `div onclick`，历史项与删除 `span onclick` 无键盘入口。

- 五个页签改为原生 `button type=button`，补齐 `role=tab` / `aria-selected` / `aria-controls` / `tabindex`（当前页 0，其余 -1），`switchTab()` 同步 `aria-selected` 与 roving tabindex；面板补 `role=tabpanel` + `aria-labelledby`。
- 页签容器补 `role=tablist` 与中文 `aria-label`；按钮边框/背景重置，视觉不变。
- 历史项改为可聚焦 `role=button tabindex=0`，Enter/Space 恢复；删除改为独立 `button` 并带「删除第 N 条历史记录」名称，避免嵌套按钮与无名称图标。

## 5. 信用评估：财务信用输入自动写入历史

- 勾选时立即补记当前结果；新增「清除本机历史」按钮调用 `TBKit.history.clear()` 并清空列表。

## 7. 基金定投：费用合计遗漏管理费和托管费

`tools/finance/mutual-fund-calculator.html` 的「费用合计」只累计申购费与赎回费；管理费/托管费仅通过 `netMonthlyRate` 降低净值，金额上完全不可见。

- 逐月把 `balance × (monthlyManageFee + monthlyCustodyFee)` 并入 `totalFees`，与申购/赎回费同口径展示；净值增长仍用扣除费率后的月收益率，不重复扣减。
- 复核：初始 10,000 / 月投 1,000 / 10 年 / 8% / 申购 0.5% / 赎回 0.5% / 管理 1% / 托管 0.2% ⇒ 费用合计 12,291.97（原 1,599.70）；42 年、42% 费率极端组 ⇒ 32,413.35（原 9,200.52），期末资产与累计收益不变。

## 8. 新西兰税号：完整税号进入历史

`tools/finance/ird-validator.html` 的快照把完整 8–9 位税号写入 localStorage，结果文本也带全号。

- 新增 `__ird_validatorMask()`（保留前 2 后 2，如 `49*****07`）与 `__ird_validatorMaskText()`；input 快照直接掩码，结果及所有快照字段中的 8–9 位数字统一掩码。
