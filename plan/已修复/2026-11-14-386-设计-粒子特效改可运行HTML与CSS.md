## 一、问题

输出只有一段声明了 `--count/--color/--size/--shape/--speed/--spread/--opacity` 的 CSS 加一个 `@keyframes float-N`：

- 没有任何选择器写 `animation`，keyframes 从未被引用
- 没有粒子 DOM 节点，`--count` / `--shape` / `--speed` 全文无人读取
- 页面也只有一个「生成数量」输入，与标题「可配置参数」不符
- `formula-desc` 写「基于 Canvas 的粒子系统…可导出代码或图片」，实际既不是 Canvas 也不能导出图片

结论：复制这段 CSS 到空白页，不会有任何粒子或动画。

## 二、修复

### 1. 输出改为「HTML 粒子节点 + CSS」两段可运行代码

```
<div class="particles-1">
<span class="p" style="left:42%;animation-delay:-1.3s;--dx:-18px;clip-path:circle(50% at 50% 50%)"></span>
…
</div>
```

```css
.particles-1 { position: relative; overflow: hidden; width: 100%; height: 320px;
  --size: 6px; --color: #FF6B35; --speed: 1.4s; --spread: 180px; --opacity: 0.6; }
.particles-1 .p { position: absolute; bottom: 0; width: var(--size); height: var(--size);
  background: var(--color); opacity: 0; animation: float-1 var(--speed) linear infinite; }
@keyframes float-1 { … }
```

- `animation` 真正绑定到 `.particles-N .p`，keyframes 名与选择器同源
- 全部自定义属性都被引用：`--size` ×2、`--color`、`--speed`、`--spread` ×2、`--opacity`
- 删掉了无人引用的 `--count`（粒子数由节点个数表达，避免再次被判「声明未引用」）
- 形状用 `clip-path`（circle / inset / diamond polygon / 五角星 polygon）实现，不与 transform 动画冲突
- 每个粒子带 `left`、负 `animation-delay`（错峰）、`--dx`（横向漂移）
- 页面内把生成的 CSS 注入 `<style id="gen12PreviewCss">`，并渲染最多 60 个粒子的实时预览

### 2. 补参数控件，让「可配置」名副其实

新增「每套粒子数（20–200）」「动画周期（0.3–3.0 s）」「粒子颜色（#rrggbb）」，留空则随机；`clampInt` / `clampFloat` 做区间夹取，颜色用正则校验后才采用。

### 3. 文案与引据表对齐实现

- 副标题 `data-zh` 由残缺的「可配置参数」补全为完整说明
- `formula-eq` / `formula-desc` 由「Canvas 粒子系统」改写为「CSS 关键帧粒子系统」，并写明输出形态与变量引用
- 介绍块原文是模板套话（「可视化操作」「一键复制 CSS 代码」）→ 重写为真实能力
- 引据表三行原为 Canvas 内容（每帧积分 / DPR 缩放画布 / globalCompositeOperation）→ 改为 CSS Animations Level 1 的关键帧插值、clip-path 的设备无关像素、负 delay 错峰
- `i18n/tools/design.json` intro 去掉「调参数实时预览…导出 canvas 代码或图片」的虚假承诺；EN 字典补 16 条

### 两条踩坑记录

1. **首版 expect 写了两条，旧码照样 2/2 通过** —— `50. square 粒子方案` 这种「序号 + 形状」标题新旧实现都有，零判别力；`expect` 是「或」关系，一条命中即算过。已删除，只保留有判别力的那条。
