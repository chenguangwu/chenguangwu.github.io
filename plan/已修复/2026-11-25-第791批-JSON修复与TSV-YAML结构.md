## 修复内容

### 1. JSON 修复不再改写合法字符串
- `escH()` 去掉 `String(...).replace(/Infinity|NaN/g,'—')`，只做 HTML 文本转义（`div.textContent` → `innerHTML`）。
- `calcTool()` 结果渲染不再对整段 HTML 做 `Infinity|NaN` 全局替换，直接 `innerHTML=html`。
- 是否合法完全由 `JSON.parse(fixed)` 决定：合法 `"Infinity and NaN"` / 键名 `NaN` 原样显示；裸 `NaN` 仍报 `仍无法解析`。

### 2. JSON 转 TSV 表头安全
- 表头改为 `keys.map(k => escapeTsvValue(k, {nullValue:'', newline:'space'})).join('\t')`，与默认值规则一致：制表符/换行替换为空格，键名不会把表头拆成多列或多行。
- 数据行仍按用户选择的换行模式处理。

### 3. JSON 转 YAML 空容器
- `toYaml()` 数组元素分支重写：
  - 元素为空数组/空对象时直接输出 `pad + '- ' + '[]'/'{}'`，不再换行后调用递归。
  - 非空对象/数组元素输出 `pad + '-' + '\n' + toYaml(item, indent+1)`，去掉行尾多余空格。
  - 标量仍输出 `pad + '- ' + yamlScalar(item)`。
- 根级与多级嵌套空容器均保持正确层级；Ruby Psych 解析 `[[],{}]`、`{"a":[[]],"b":{"c":{}},"d":[1,[2],{"e":[]}]}` 往返得到原结构。

### 4. 英文态
- `i18n/tools/en/it/json-to-yaml.json` 补 `✅ 转换成功`、`✅ 压缩转换`、`等待转换...`、`等待输入...`。
