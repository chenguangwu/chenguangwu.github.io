# 第803批：密码校验与随机令牌复制一致性

关闭 `plan/it/` 7 项：

- Playfair密码-解密前静默删除非法密文
- Polybius密码-越界坐标被当作有效字母
- Polybius密码-密钥J与I合并规则不一致
- ROT密码-自定义移位空值与小数静默改写
- Token生成器-无字符集时旧结果仍可复制
- NanoID生成器-自定义字符被解释为HTML
- ULID生成器-批量复制结果缺少分隔

## Playfair（`tools/it/playfair-cipher.html`）

- 解密不再 `toUpperCase().replace(/[^A-Z]/g,'')` 静默清洗：
  - 只接受 ASCII `A-Z/a-z` 字母，空格、制表符、换行作为分组符；
  - 数字、标点、非 ASCII 字符报出**首个非法字符及位置**，清空输出、步骤数与旧分组；
  - `J` 按 `I` 处理，与方阵规则一致；
  - 清洗后为空或奇数长度继续走偶数分组错误。
- 新增 `#playfairNote` 说明区：
  - 加密时明示「J 合并为 I、非字母忽略、重复字母与末尾奇数字母补 X（X 后改补 Q），不可逆」；
  - 本次输入若含非字母或发生填充，附上具体忽略/补入数量；
  - 解密时说明只接受 A-Z、空白为分组符、J 读作 I。
- 合法密文 `DB NV MI` 仍能解出 `HELXLO`，空白分组不破坏结果。

## Polybius（`tools/it/polybius-cipher.html`）

- `getGrid()` 重写密钥规范化：
  - 仅接受 ASCII 字母，`J` 合并为 `I` 后再去重填阵；
  - 非字母字符不进入方阵，并在网格下方提示忽略字符与 I/J 规则（中英双语）；
  - `JABC` 与 `IABC` 生成完全相同的方阵。
- `dec()` 逐位/逐字符校验：
  - 数字坐标每位必须 `1–5`，`16` 这类越界坐标报「第 N 位无效」并清空输出；
  - 字母坐标只接受 `A–E`，`F A` 报首位非法；字母数量奇数时报偶数要求；
  - 容忍空格、逗号、连字符、分号作分隔符。
- 错误统一写入网格下方 `#__polyNote`，不再使用阻塞式 `alert`，避免浏览器弹窗卡住页面。
- 合法 `21` 仍解为 `F`。

## ROT（`tools/it/rot-cipher.html`）

- 自定义移位改为严格 `1–25` 整数：
  - 空值、小数、负数、`0`、`26`、超大数均提示并清空输出；
  - 新增 `#shiftError`（`role=alert`），不再 `parseInt(...) || 0` 静默按 0 位或截断；
  - 合法移位仍按原公式 `(code - base + shift) % 26` 计算。
- 同步删除旧的「负数归一」测试口径，改为断言越界提示。

## Token 生成器（`tools/it/token-generator.html`）

- 新增 `tokenClearResult()` / `invalidateTokens()`：
  - 未选择任何字符集时清空 `toks`、列表与旧结果，再显示错误；
  - 长度、数量、字符集任一配置变化时立即清空旧 Token 并提示「配置已更改，请重新生成」；
  - `copyOne()` / `copyAll()` 增加空结果守卫，不再复制不存在或已失效的值；
  - 复制提示改为中英动态文案，移除未定义的 `i18nText()` 调用。

## NanoID（`tools/it/nanoid-generator.html`）

- 新增 `nanoEscape()`，每个 ID 经 HTML 转义后写入 `<code>`；
- 复制与批量复制仍读取 `<code>` 的 `textContent`，显示值与实际生成值一致；
- 尖括号、`&`、引号不再被当作标签或实体解析，也不会插入页面元素。

## ULID（`tools/it/ulid-generator.html`）

- 新增 `lastUlids` 保存本次生成数组：
  - 「复制全部」按数组 `join('\n')`，不再读块级容器的 `textContent` 导致多条粘连；
  - 每行新增单条「复制」按钮，按索引复制；
  - 新增「下载 TXT」，每行一个 ULID；
  - 空结果复制/下载提示先生成。
