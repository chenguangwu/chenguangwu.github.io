# F-N58 期权页最大盈亏未扣手续费、合约数 0 被替换为 1（真修）

- 分类：金融财务 / `tools/finance/option-profit-calculator.html`
- 优先级：低（确认缺陷）
- 批次：2026-11-10 分类线第 78 批（本地提交，未 push）

## 失败点（原清单）
- `maxProfit`/`maxLoss` 只按权利金×乘数×张数展示，未扣除 `totalFee`；总盈亏已扣开平手续费，同屏最大亏损与总盈亏口径不一致。
- `contracts`/`mult` 用 `Math.max(1, …)` 兜底，清空或填 0 仍按 1 张/乘数 1 计算。

## 修复位点与核实
- 核实：张数/乘数 0 已在 `calc()` err 守卫处理（`:463` `!(getVal('contracts') > 0)` ⇒ 「合约数量需为正整数。」、`:464` 乘数 ⇒ 「合约乘数需大于 0。」），`Math.max(1,…)` 仅在 err 通过后的渲染路径，不构成缺陷，未改。
- 真修最大盈亏渲染（`:554-562`）：
  - 最大盈利：`maxProfit * mult * contracts - totalFee`
  - 最大亏损：`maxLoss * mult * contracts + totalFee`
  - 与 `totalProfit = perShare * mult * contracts - totalFee` 同口径（手续费开仓+平仓双向计入）。
  - 新增说明行：「最大盈亏已计入开仓+平仓手续费（¥X），与总盈亏同口径。」

## 证据
- 同步 1 条旧例 expect：`最大亏损： ¥300.00` → `¥302.00`（fee=1 × 1张 × 开平 2 次 = 2，权利金 300 + 2）。
- 新增专用锁：注入 `fee=3/contracts=2` ⇒ totalFee = 3×2×2 = ¥12.00，断言新增说明行 `最大盈亏已计入开仓+平仓手续费（¥12.00）`。绑定输入算得的手续费金额（非静态文案，默认 fee=2/1张 ⇒ ¥4.00 ⇒ 不命中）。
