# 第720批：JSON Diff 过期结果、路径、计数与 FAQ

日期：2026-11-24
页面：`tools/it/json-diff.html`

## 修复内容

1. **输入无效或为空时清除旧比较**
   - 新增 `invalidateDiff()`：清空 `lastDiff`、`lastLeft`、`lastRight`、四个计数、三栏行视图、路径列表、JSON 结果和图表。
   - 空输入、解析失败都先失效再提示，复制/下载不再能取到旧报告。

2. **路径歧义用 JSON Pointer 消歧**
   - `deepDiff` / `simpleDiff` 增加 RFC 6901 `pointer` 字段；键名中的 `~`、`/` 按规范转义。
   - 路径列表在原有点路径之后展示 `JSON Pointer`，复制文本同时带 `[pointer]`。
   - 实测 `{"a.b":1,"a":{"b":1}}` 两处修改分别显示 `/a.b` 与 `/a/b`。

3. **数组按内容匹配时统一相同计数**
   - `countSame` 接收 `arrayMatch`，数组分支改按规范内容多重集匹配；`["a","b"]` 对 `["b","a"]` 现在 0 新增、0 删除、0 修改、2 相同。

4. **行视图按 LCS 对齐**
   - `generateLineDiff` 改为行级最长公共子序列；插入一行只在该位置显示 `add`，后续相同行保持 `eq`。
   - 超过 25 万行组合时降级为同位置比较，避免 DP 内存失控。

5. **FAQ 去掉不存在的「忽略类型」**
   - 同步修正页面可见 FAQ、FAQPage JSON-LD、`i18n/tools/content_deepdive.json` 和 `i18n/tools/en/it/json-diff.json`。
   - 新文案明确本工具始终严格比较、不提供类型宽松开关，并给出「先统一转字符串」的替代做法。
   - 英文链接碎片补空格，输出 `a naive text diff will ...`。
