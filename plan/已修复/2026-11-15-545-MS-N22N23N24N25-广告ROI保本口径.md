# 545 批：广告 ROI 保本 ROAS 计入固定成本

- 日期：2026-11-15
- 来源：`plan/categories/06-商业运营/marketing-sales.md` MS-N22、MS-N23、MS-N24、MS-N25
- 受影响页面：`tools/marketing/ad-roi.html`

## 改动

- **保本 ROAS 计入固定成本**：由 `1/毛利率` 改为 `（预算+固定成本）÷（预算×毛利率）`；
  固定成本为 0 时退化为原值（1.67 @ 40% 毛利率）。公式框、参考表、盈亏平衡卡、FAQ、CSV 导出口径同步。
- **预算为 0 的崩溃修复**：`breakEvenRoas` 在 `budget=0` 时为 `null`，原代码直接 `.toFixed(2)`
  抛 TypeError；改为判空显示「—（无法计算平衡点）」，CSV 同步。
- **CPC 模式 CTR 文案**：说明改为「调整出价 / 转化率 / 客单价比较方案；CPC 模式 CTR 只影响展示量，
  不改变 ROI」，与代码行为一致。
- 复核确认：公式框/引据表/代码已统一为「利润 ÷ 总成本」；亏损挽回阈值已按
  `总成本 ÷ (客单价 × 毛利率)` 反推，不再低估。

## 验收

- 真机（puppeteer + 本机 Chrome）：
  - 默认 10000/2/3%/5%/200/50%/0 → ROI 42.9%、保本 ROAS 2.00、利润 15,000、✓ 盈利；
  - 固定成本 20000 → 保本 ROAS 6.00、利润 −5,000、✗ 亏损；
  - 预算 0 → 无 JS 异常，保本显示「—（无法计算平衡点）」。

- `python3 _build.py` 通过；`python3 _test_static.py`：4685/4685 通过。
