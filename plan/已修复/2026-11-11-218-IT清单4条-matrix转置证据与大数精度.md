## 改动（仅 `fmt` 一行逻辑，其余为证据销账）
```javascript
function fmt(x){
  if(x===0) return '0';
  // IT-N175：整数（含 15 位大整数）原样输出；超安全整数走指数，避免伪精度
  if(Number.isInteger(x)) return Number.isSafeInteger(x) ? String(x) : x.toExponential(6);
  // 非整数才用 12 位有效数字消浮点噪声（如 0.1+0.2），不插千分位、不截断到 3 位小数
  return String(Number(x.toPrecision(12)));
}
```
整数路径原样输出；超出 `Number.MAX_SAFE_INTEGER` 的值本身不可精确表示，用指数记法；非整数保留原 `toPrecision(12)` 消运算噪声。页面无 fmt 精度相关的中文/英文文案承诺，无需三源同步。
