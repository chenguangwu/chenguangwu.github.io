# 第 1021 批：录音编辑器生命周期、导出与设置一致性

- 影响页面：`tools/audio/audio-recorder.html`
- 对应任务（14 个录音编辑器问题）：
  1. 录音初始化失败未释放麦克风
  2. 意外中断后录音状态未清理
  3. 快速重录时录音数据可能串次
  4. 等待授权时可重复启动
  5. 删除后新录音可能重名
  6. 录音列表播放无法停止且可叠音
  7. 播放失败仍显示播放中
  8. 导出参数与音频快照时机不同
  9. 增益导出可能静默削波
  10. 速度显示精度低于实际设置
  11. 当前与上次设置对比失效
  12. 变速试听与导出音调不一致
  13. MP3 原文件导出扩展名错误
  14. 上传对象地址未释放

## 修复

### 录音生命周期

- 新增 `isStarting`、`micReqSeq`：点击开始后立即禁用按钮并显示“正在请求麦克风”，等待授权期间再次点击不会并发申请；迟到授权（请求号过期）立即停止轨道。
- 每次录音使用闭包保存 `recorder/chunks/stream/source`，不再共享 `audioChunks/mediaRecorder`；`finishRecording()` 按 recorder 实例一次性收尾，快速停止再开始不会串数据。
- `cleanupRecording()` 统一停止轨道、断开节点、清计时器与动画、恢复按钮；`stopRecording()`、`recorder.onstop`、`onerror`、音轨 `ended` 都走同一收尾。
- 初始化失败（创建 MediaRecorder、启动等）在 catch 中停止已获取流、断开节点、恢复按钮，并显示“录音初始化失败”。
- 录音名改用单调递增 `recSeq`，删除中间录音后再录不会重名。

### 播放

- 列表播放统一为 `listAudio` 单实例，`listPlayingIndex` 记录索引；再次点同一条为暂停/继续，切换播放先暂停上一条；删除、清空、加载到编辑器时停止列表播放。
- 列表与编辑器播放都处理 `play()` Promise 拒绝：失败恢复“▶”、停止波形并提示，不再显示播放中。
- 试听设置 `preservesPitch=false`（含 webkit 前缀），与离线导出（`AudioBufferSourceNode.playbackRate` 不保调）一致；界面提示“试听与导出都随速度改变音调”。

### 导出

- `exportAudio()` 点击时快照 `loadedBlob`、gain、rate，等待解码期间切换文件或拖动滑块不会混用参数。
- 离线渲染后统计峰值与超 0dBFS 采样数；勾选“削波保护”（默认）时按峰值归一化，未勾选则提示可能失真并继续导出。
- 速度显示统一两位小数：`1.04x`；导出提示同样使用两位小数。
- `audioExtForBlob()` 优先使用原始文件安全扩展名；`audio/mpeg`/`mpga` 映射为 `mp3`，避免下载成 `.bin`。
- 上传文件的对象地址记录在 `loadedObjectUrl`，切换文件/加载录音/页面卸载时释放；录音列表 URL 仍在删除或清空时释放。

### 设置对比

- 当前设置与“上次基线”分离：`AR_SKEY` 保存当前，`AR_LASTKEY` 保存基线；滑块变化只更新当前，不再把基线同步覆盖。
- 预设选择、WAV 导出成功、点击“保存当前为上次基线”时更新基线；首用无基线显示“—”，修改后显示“已调整”。

## 验证

- Chrome 模拟麦克风（真实 `MediaStreamAudioDestinationNode` 音轨 + Fake MediaRecorder）：
  - 连点两次开始：`getUserMedia` 仅 1 次，按钮禁用，标签“正在请求麦克风”；授权后进入“录音中”。
  - 停止后新增“录音 1”；删除后再录为“录音 2”，不重复。
  - 授权拒绝：`isRecording=false`、开始按钮恢复、标签“录音初始化失败”、无残留 `activeStream`。
  - 音轨派发 `ended`：自动停止并保存 1 条、恢复按钮、标签“录音已停止”。
- 播放拒绝：`togglePlay()` 后 `isPlaying=false`、按钮恢复“▶”，无 `pageerror`。
- 上传 0.8 峰值 WAV，速度 104 → 界面 `1.04x`；增益 200%，削波保护勾选导出后 WAV 峰值 32767（归一化生效）；`currentAudio.preservesPitch=false`。
- 基线：初始当前=上次“持平”；修改速度 105 后显示“105 / 104 / 已调整”。
- `node scripts/verify_audio_calc.js` 7/7；新增静态守卫覆盖上述关键路径。
- `python3 _test_static.py` exit 0；`python3 _audit_assets.py --check` 0 死链 / 0 lang 缺失 / 0 重复 id。
