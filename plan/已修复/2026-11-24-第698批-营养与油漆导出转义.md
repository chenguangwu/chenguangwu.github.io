# 第698批：营养与油漆自定义名称的导出转义

## 修复项

### 1. 营养计算器：自定义食物名称直接插入列表与导出表

`tools/food/nutrition-calculator.html`

- `render()` 原先把 `it.name` 直接插入 `dishList.innerHTML`；自定义名称包含 `<b>` 等标签时会生成真实元素。
- 导出隐藏表 `#nutriHidden` 同样直接拼接名称。

修复：

- 列表名称改用 `ToolBox.escHtml(it.name)`。
- 导出表所有单元格先转成字符串再 `ToolBox.escHtml` 写入，隐藏表只保存文本。
- CSV 导出仍从隐藏表读取 `textContent`，不会把转义字符写进文件。

### 2. 油漆用量：导出隐藏表直接插入涂刷面名称

`tools/home/paint-calculator.html`

“导出用量 CSV”构造 `#paintHidden` 时用 `r[0]` 直接拼进 `tbody.innerHTML`；正常列表已转义，但导出路径没有。恶意名称会在点击导出时进入页面上下文。

修复：导出表名称改用 `ToolBox.escHtml(String(r[0]))`，面积同样转字符串后转义。

## 验证

本地 Chromium，以 `<b>营养</b>` / `<b>墙面</b>` 作为名称：

- 营养列表与 `#nutriHidden` 均为 0 个真实 `<b>` 元素；隐藏表 HTML 为 `&lt;b&gt;营养&lt;/b&gt;`，`textContent` 为 `<b>营养</b>`。
- 油漆设置门窗为显式 0 后导出，`#paintHidden` 为 0 个真实 `<b>`，名称为 `&lt;b&gt;墙面&lt;/b&gt;`。
- 普通名称、面积与 CSV 文本保持原值。
- 两页无 `pageerror`。

## 规则

不关闭公共转义；导出准备区只放文本，不用 `innerHTML` 拼接用户输入。
