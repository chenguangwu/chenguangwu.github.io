# 751 批：血糖单位换算默认方向与系数统一（D-N32）

## 问题
`tools/medical/convert-glucose.html`：
- `from` / `to` 两个下拉默认都是 mmol/L，首屏即输出「1 mmol/L = 1 mmol/L」并判低血糖；
- 计算用整数 18，公式框/引据写 18.0182，深度解析又写 18.0159，5.6 mmol/L 得 100.8 而非 100.9；
- 清空数值时 `+value||0` 变 0，仍输出 0 并判低血糖。

## 修复
- 默认值 5.6，`to` 默认 mg/dL ⇒ 首屏直接显示 5.6 mmol/L = 100.90192 mg/dL（正常空腹）。
- `from/to` 选项系数统一为 18.0182，分级换算同步用 `÷18.0182`。
- 新增守卫：
  - 数值为空或 ≤0 ⇒ 提示「请输入有效的血糖数值（须大于 0）」，不再输出 0 与低血糖分级；
  - `from === to` ⇒ 提示「源单位与目标单位相同，无需换算」。
- 深度解析源 `i18n/tools/content_deepdive.json` 统一为 18.0182，改写算例与 FAQ（删去「本站另一工具用 18.0159」的旧说法）。

## 验证
`node scripts/verify_medical_calc.js medical/convert-glucose` ⇒ 4/4：
- 1 mg/dL → mmol/L = 0.0554994394557（18.0182）
- 默认 5.6 mmol/L → 100.90192 mg/dL + 「正常（空腹）」
- 同单位 ⇒ 「源单位与目标单位相同」
- 空值 ⇒ 「请输入有效的血糖数值」

`python3 _build.py` + `python3 _test_static.py` ⇒ 4685/4685/0。

## 说明
18.0182 为葡萄糖分子量 180.182 的换算近似；血糖分级仅作教育参考，诊断需结合临床与检验报告。
