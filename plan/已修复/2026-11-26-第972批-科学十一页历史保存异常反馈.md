# 第 972 批：科学十一页历史保存异常反馈

时间：2026-11-26

## 问题

电池寿命、传热、LED 限流、欧姆定律、PCB 走线、压力换算、流量、分压、AWG 线规、波长转 RGB、扭矩换算十一页的 `saveHistory` 直接调用 `localStorage.setItem`，随后才回读判断。浏览器禁用存储或配额不足时抛异常，函数中断，“未保存”提示和后续逻辑都无法执行。

## 改动

十一页统一改为：

```js
let saved=false;
try{localStorage.setItem(HISTORY_KEY,payload);saved=localStorage.getItem(HISTORY_KEY)===payload;}catch(e){saved=false;}
if(saved)ToolBox.toast('已保存到历史记录');
else ToolBox.toast('历史未保存（存储不可用或空间不足），本次计算结果不受影响','error');
```

写入与回读都包在 `try` 内，失败按“未保存”处理且不中断当前结果。

## 验证

- 真机 Chrome 逐页覆写 `Storage.prototype.setItem` 为抛异常：十一页均弹出“历史未保存（存储不可用或空间不足），本次计算结果不受影响”，无页面报错、保存函数不抛异常。
- 恢复原生实现后复测分压页：提示“已保存到历史记录”，`HISTORY_KEY` 有值。
- `_test_static.py`、`_audit_links.py --check`、`_audit_assets.py --check` 均通过。
