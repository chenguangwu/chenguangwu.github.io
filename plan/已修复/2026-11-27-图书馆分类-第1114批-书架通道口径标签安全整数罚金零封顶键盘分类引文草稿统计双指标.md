## 一、书架排数与通道长度口径

- 「所需书架总长」改为实际架体总长：所需书架数 × 单架层长。
- 新增「满排布局总长」：排数 × 每排架数 × 单架层长，与实际长度分开显示，避免把未排满容量当成实际占用。
- 新增「主通道累计长度」：（排数 + 1）× 实际占用排长；排间距仅作为宽度方向参数，不再被误当成长度重复累加。
- 面积估算改为：实际占用排长 ×（排数 × 0.5m 架深 + 排间通道 ×（排数 − 1）+ 两端外通道 1.2m）。
- 结果区补「末排实际书架数」「通道数量」，并说明末排未满会多算长度还是只按实际架体计算。
- 真机：2 架、每排 1 架、层长 1m、排距 1.4m → 实际 2m、满排 8m、主通道 4m、2 条、面积 3.4㎡，末排 2 架。
- verify：`scripts/verify_library_calc.js` 书架旧用例已改为新口径断言。

## 二、标签批量超大编号卡死

- 盒号范围解析改为正则提取 + `Number`，用 `Number.isSafeInteger` 拒绝超安全整数与倒序区间。
- 有界次数循环保留前导零，避免 `parseInt` 抹零。
- 新增 `labelBoxesErr` 提示：编号超出安全整数、区间倒序、列表项非法时直接说明并停止生成。
- 500 项边界仍可生成；20 位编号不再长时间卡死。
- 真机：超大编号给出提示；`9-1` 提示倒序；`0001-0003` 生成 3 张并保留前导零。

## 三、逾期罚金零封顶

- 封顶条件改为 `useCap && finePerBook > cap`，上限填 0 时即零元封顶，不再被空值判断当作未启用。
- 输入标签、公式说明与 FAQ 明确「0 = 零元封顶」。
- 真机：启用封顶且填 0 → 每本 0 元、合计 0 元；填正上限 3 → 单本 2 元、合计 2 元；不启用 → 原价。

## 四、分类号条目键盘不可选

- 二级条目由 `div` 改为原生 `button type="button"`，支持 Tab 聚焦、Enter/Space 激活。
- `aria-pressed` 与选中态同步；搜索过滤、切换大类后同步刷新。
- CSS 重置按钮默认外观，保持原视觉。
- 真机：首项为 BUTTON、可聚焦，Enter 选中 A1，`aria-pressed=true`。

## 五、参考文献切换类型丢数据

- 新增文献语言（中文/英文）与姓名规则选择：中文超过 3 位作者用「等」，英文用 `et al`，英文姓名转 `Last, F. M.`。
- 按文献类型保存/恢复动态字段草稿：切换类型前保存旧类型字段，切回时恢复。
- 初始标题与动态字段留空，不再自动塞示例；新增「载入当前类型示例」按钮显式载入。
- 输出区补充人工核对提示；移除会误判空态的旧 NUMCLR2 守卫。
- 修复空字段仍输出多余标点的问题：期刊、专著、学位论文、会议、报告、标准、专利、报纸、电子资源按非空字段拼接。
- 真机：初始标题空、无自动示例；book → journal → book 后 place=上海、year=2024 恢复；英文 4 作者输出 `Smith, J., Doe, J., Lee, B., et al.`（省略标记不带句点，无双句点）；期刊仅填刊名时输出 `[1] 佚名. 题名[J]. 刊名.`，不再出现 `, : .`。

## 六、馆藏利用报表指标混淆与零分母

- 原「馆藏利用率」改名「借阅册次/馆藏比」，允许超过 100%，明确重复借阅会重复计数。
- 新增可选「年度至少借出一次的不同馆藏册数」与「馆藏口径（期末/年度平均）」。
- 真正「馆藏利用率」= 不同馆藏册数 ÷ 馆藏册数；未填不同馆藏时显示不可计算。
- 到馆人次为 0 时，「单次到馆借阅」显示不可计算，不做除零。
- 公式、FAQ、深解析、示例同步；`data-zh` 简介补回正文，英文词典同步。
- 真机：150000 借阅 / 100000 馆藏 → 150% 比；30000 不同馆藏 → 30% 利用率；到馆 0 → 单次到馆不可计算；未填不同馆藏 → 利用率不可计算。
