## 失败点（原缺陷）
`__tbF_place` 包装器内层 IIFE 直接引用 `r/c/color`，但这两个名字只存在于原 `place(r,c,color)` 的局部作用域，
包装器执行时抛 `ReferenceError`，被外层 `catch(e){}` 静默吞掉，导致 `__tbHistSave` 永不写入 →
深度解析承诺的「对战战绩与历史记录」完全失效（页面历史表恒显示「暂无记录」）。

## 根因
自动生成的 toolbox 历史钩子（`__tbF_place` / `__tbHistSave`）未正确捕获 `place` 的实参：原代码在内层匿名函数里
裸用 `r,c,color` 而非从 `arguments` 取，作用域错位。

## 修复位点
`tools/fun/gomoku-ai.html` `__tbF_place` 包装器（行 521-528）：
```js
place = function () {
  var a = arguments;
  var __r = __tbF_place.apply(null, a);
  try {
    var r = a[0], c = a[1], color = a[2];
    var win = (typeof checkWin === 'function') && checkWin(r, c, color);
    var full = history.length === SIZE * SIZE;
    if (!win && !full) return __r;
    __tbHistSave({ 时间: __tbTime(), 结果: __tbL(win ? (color === BLACK ? 'Win' : 'Lose') : 'Draw', win ? (color === BLACK ? '胜' : '负') : '和棋'), 步数: history.length, __v: history.length });
  } catch (e) {}
  return __r;
};
```
