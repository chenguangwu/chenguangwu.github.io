# 第 119 批：中英文混排阅读时间口径（IT 开发）

- 日期：2026-11-21
- 页面：`tools/it/text-statistics.html`

## 原问题

`readMin = Math.max(ceil(中文字数/300), ceil(英文词数/200))`。

对中英文混排文本，阅读时间应把两种阅读量相加：300 汉字（1 分钟）+ 200 英文词（1 分钟）实际需要 2 分钟，旧公式取 max 只得 1 分钟。逐项先 `ceil` 还会把小样本放大成 1 分钟，再取 max 掩盖另一部分。

## 修复

```js
const readMinutesRaw = chineseChars / 300 + englishWords.length / 200;
const readMin = readMinutesRaw > 0 ? Math.max(1, Math.ceil(readMinutesRaw)) : 0;
```

- 先按各自速率算小数分钟并相加，再统一向上取整；
- 非空文本至少显示 1 分钟；
- 空文本保持 0 分钟；
- 公式说明同步为「0（空文本）或 max(1, ⌈中文字数÷300 + 英文词数÷200⌉) 分钟」。
