# 427 批：同一工具的双份指南合并

日期：2026-11-14
范围：55 个旧命名指南页 + `_build.py` sitemap 过滤

## 一、问题

- 全站有 **55 个工具被两份指南页同时指向**：工具改名后旧指南未清理，
  例如 `dentistry/bridge-span.html` 同时有 `bridge-span-guide.html` 与
  `analysis-11-guide.html`；`fun/number-guess.html` 有
  `number-guess-guide.html` 与 `caishuzi-1-100fanwei-guide.html`。
- 两份指南 canonical 都指向自己，内容高度重叠，属于站内重复内容，
  会互相稀释排名；sitemap 也把两份都提交给搜索引擎。

## 二、修复

1. 以「与工具文件名同名」的指南为保留页（55 组全部唯一可判定）。
2. 旧命名页：
   - `<meta name="robots" content="noindex, follow">`（页面仍可访问、链接权重可传递，只退出索引）；
   - canonical 改为指向保留页。
3. `_build.py` 的 `generate_sitemap()` 跳过含 `noindex` 的指南页；
   构建一致性校验的 `guides_count` 同步改为相同口径，避免 sitemap 数量校验失败。
4. `json/guides.json` 检查：55 条旧指南均未被引用，无需改指（0 条）。

## 三、验证

- noindex 指南页：**56**（55 个本次合并 + 1 个历史 `vaccine-reminder-guide.html`）。
- `sitemap.xml` 中仍包含的 noindex 指南：**0**。
- 工具页「使用指南」链接指向缺失文件：**0**（保持 425 批修复后的自引用 canonical）。
- `python3 _build.py` 连跑两次内容哈希一致；构建一致性校验通过。
- `python3 _test_static.py`：**4714/4714** 通过。
