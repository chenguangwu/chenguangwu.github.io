# 第1255批 · IT-N453 code-runner 删除虚假超时承诺

## 问题
`tools/it/code-runner.html` 的 iframe `srcdoc` 与用户 JS 同线程执行，没有超时或终止机制；`while(true){}` 会冻结整个标签页。页面深度解析示例与公式表却写「受超时与内存限制」「需设置超时，避免死循环卡死页面」，属于承诺未实现。

## 裁断
不把 iframe 预览改成 Worker：该工具的即时预览依赖 DOM/CSS/JS 三合一渲染，Worker 化会破坏核心能力。因此采用 plan 方案二——保留 iframe 架构，删除所有超时承诺，并明确告知用户死循环会冻结当前标签页、不要运行不可信代码。
