# 第 1154 批复核失败：清空课程分数被当成零分

`tools/edu/grade-calculator.html` 的 `updateCourse()` 对分数直接调用 `Number(val)`，空串转成 0；清空分数输入后会把课程分数写为 0 并重算，而不是提示未填写。项目空态规则要求区分空串与合法 0。该批其他目标、权重和标准差校验、公式框及归一计算已核对。

建议先检测输入是否为空再解析，空态清除结果并提示，保留明确输入 0 的有效行为；用真实输入事件分别验证清空和填 0。

修复：分数和权重输入先识别空串再解析；无效时清除旧统计与等级并禁止保存，合法 0 分仍参与计算。Chrome 实测清空第一门分数后显示提示、最高分与等级为横线且不写历史；输入 0 后恢复结果并保存 67.37。`node scripts/verify_edu_calc.js grade-calculator` 11/11。
