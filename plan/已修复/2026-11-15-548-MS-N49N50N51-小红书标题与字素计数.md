# 548 批：小红书文案计数器标题、字素与全角话题（MS-N49 / N50 / N51）

日期：2026-11-15　页面：`tools/marketing/xiaohongshu-counter.html`

## 问题

- **MS-N49（高）**：深解与示例讲「录入 30 篇笔记的赞/藏/评/粉，算篇均互动、爆款占比、赞粉比」，页面只有一个正文 textarea，没有任何互动数据输入或汇总，功能承诺与实现完全错位。
- **MS-N50（中）**：meta 宣称统计「标题与正文」，实际无标题字段、标题 20 字规则未体现；字数用 `text.length`（UTF-16），`👨‍👩‍👧‍👦` 被算成 11 个字。
- **MS-N51（低）**：话题正则 `/#[^#\s]+/g` 不认全角 `＃`；`Number(value)||1000` 把上限 0/负数/NaN 静默改成 1000。

## 修复

1. **新增标题字段与 20 字上限**：`#title` 独立输入，与正文分别计数、分别提示剩余/超出；`#limit` 更名「正文字数上限」。
2. **字素簇计数**：`graphemes()` 优先 `Intl.Segmenter('zh',{granularity:'grapheme'})`，回落 `Array.from(s).length`；结果区同时保留「UTF-16 技术计数」供对照。
3. **全角话题**：正则改为 `/[#＃][^#＃\s]+/g`，结果标注「# 与 ＃ 均计入」。
4. **上限校验**：空值/0/负数/非数字 → 「请输入大于 0 的正文字数上限。」，不再兜底 1000；正文或标题超出时状态合并展示「标题超出 N 字；正文超出 M 字」。
5. **清空**：`clearAll()` 同时清空标题与正文。
6. **深解重写**（`i18n/tools/content_deepdive.json` → `marketing/xiaohongshu-counter`）：删除多笔记赞藏评粉/赞粉比场景与算例，改为标题 20 字、正文上限、全角话题、emoji 字素计数；FAQ 改为平台口径差异、话题计数、emoji 计数。
7. **英文态**：`i18n/tools/en/marketing/xiaohongshu-counter.json` 同步改标签、公式、深解与 FAQ，补 term-link 碎片键与 `输入笔记标题...` placeholder；结果卡按 `isEn()` 三元化，并在 `toolbox:langchange` / `DOMContentLoaded` 重算。
8. **验证脚本**：`scripts/verify_marketing_calc.js` 两条用例改为新输出，并新增「23 字标题 + 全角 ＃ + 家庭 emoji」用例覆盖 N50/N51。
