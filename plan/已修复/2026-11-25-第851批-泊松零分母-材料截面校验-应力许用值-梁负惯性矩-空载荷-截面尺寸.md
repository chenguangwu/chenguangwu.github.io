# 第851批：泊松零分母、材料截面校验、应力许用值、梁负惯性矩、空载荷、截面尺寸

## 泊松应变空值和零分母处理错误

`tools/engineering/poisson-strain.html`

- 轴向应变与泊松比改按原始空值读取；轴向应变允许合法 0，但空值、非数值停止计算并提示。
- 泊松比限定在 −1–0.5，超范围停止并提示。
- 轴向应变为 0 时，横向/轴向应变比显示「未定义（轴向应变为 0，不能作分母）」，不再输出 0/0=0；历史表同步「未定义（ε_x=0）」。

## 材料截面参数未校验导致负质量

`tools/engineering/material-calculator.html`

- 长度 L 改原始空值读取：空值报错，0 合法并显示「不适用（长度 0）」，重量为 0；移除 `||1` 静默长度。
- 按截面类型校验所需尺寸均为正数；圆管 `2t<D`、方管 `2t<a`、工字钢 `2t<h`、腹板 `d<=b`、角钢 `t<b/c`。
- 任一参数异常停止计算、清空截面图并逐条列出字段错误，避免出现负面积、负质量。

## 应力计算安全判定未使用许用应力

`tools/engineering/stress-calculator.html`

- 安全判定统一改用许用应力：拉压/弯曲按 `[σ]=σs/1.5`；剪切/扭转按 `[τ]=0.577σs/1.5`（剪切屈服约 0.577σs）。
- 应力按幅值 `|σ|` 比较，受压负号不再使结果恒判安全；安全系数改为 `n=许用应力/|σ|`，应力为 0 显示 ∞。
- 四类输入改原始空值读取并校验 A/W/D 为正、扭转 `0≤d<D`；异常停止并清空旧 SVG/结果卡。
- 结果区按类型显示强度依据与许用值标签，避免「显示许用应力、实际按屈服强度判定」。

## 梁挠度校核接受负惯性矩误判安全

`tools/engineering/beam-calculator.html`

- 梁长、弹性模量、惯性矩、许用挠度分母全部改原始空值读取并要求有限正数；载荷允许 0 或负值（向上）。
- 挠度按绝对值与许用值比较（`ratio<=1`），负挠度不再恒判安全；结果区标注「与设定方向相反」。
- 挠度为 0 时挠度比显示「0（无挠度）」，不再出现 1/Infinity。

## 空载荷被误当作零载荷

`tools/engineering/cantilever-deflection.html`、`tools/engineering/axial-stress.html`

- 端部集中力 P、轴向力 F 单独做原始空值校验：空值或非数值停止计算并提示，保留合法 0 与负值。
- L/E/I/A 同步改为有限正数校验，异常时不再输出 0 mm / 0 MPa。

## 圆截面惯性矩强制填写无关宽度

`tools/engineering/section-inertia.html`

- 形状只接受 1（矩形）或 2（圆）；切换时 `syncShape()` 禁用并清空矩形宽 b，圆截面仅用直径 D。
- 矩形才校验 b>0，圆截面不再被无关宽度阻断；非法形状与非法尺寸分别提示。
- 结果说明标注「仅用直径 D，b 不参与」。
