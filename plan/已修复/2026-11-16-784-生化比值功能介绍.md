# 784 批：生化比值简介与深解改为实际五项（D-N81）

## 问题
简介、使用场景与深度解析宣称支持 A/G、钠钾比、钙磷乘积、阴离子间隙（AG），
但输入面板只有 ALT/AST/ALP/GGT/BUN/Cr/UA/ALB，代码只计算五项比值：

- AST/ALT（De Ritis）
- BUN/Cr
- GGT/ALT
- R 因子
- 尿酸/白蛋白

用户按深解 AG 示例（Na 140/Cl 104/HCO3 22）无法录入，结果也不会出现 AG。

## 修复
- 简介改为「AST/ALT、BUN/Cr、GGT/ALT、R 因子、尿酸/白蛋白」；
- 使用场景改为「肝病随访 AST/ALT / 肾功能 BUN/Cr / 药物性肝损 R 因子分型」；
- 深解 JSON 重写：场景、De Ritis + R 因子示例、三条 FAQ（AST/ALT 范围、BUN/Cr 换算、R 因子前提）与 summary 全部对齐实际功能；
- 构建后页内不再出现 A/G、钠钾比、钙磷乘积、阴离子间隙字样。

## 验证
`node scripts/verify_clinical-lab_calc.js biochemistry-ratio` ⇒ 11/11（既有用例未受影响）。
`python3 _build.py` + `python3 _test_static.py` ⇒ 4685/4685/0。

## 说明
若后续要真正支持 A/G、AG、钙磷乘积，需新增 Na/Cl/HCO3/Ca/P/K/球蛋白输入，另开任务。
