# IT 工具标签切换不依赖全局 event

- 原问题：颜色转换、IP 计算和 cron 页使用 `event.target` 确定标签；缺少全局事件时切换失败。cron 历史回填还会程序化调用 `switchTab`；IP 历史回填此前固定选中首个标签，与实际内容不一致。
- 修复：`tools/it/color-converter.html`、`tools/it/ip-calculator.html`、`tools/it/cron.html` 的标签增加目标标识，切换函数按目标选中标签；IP 程序化回填复用同一函数。历史记录中 timestamp-converter 同类问题已由现有显式参数处理。
- 验证：`node scripts/verify_it_tab_switch.cjs` 在没有全局 event 的条件下覆盖三页两个方向切换、IP 程序化切换；旧源码运行检查会因 event 未定义而失败。`node scripts/verify_it_calc.js color-converter ip-calculator cron` 24/24 通过。
- 完整门禁按用户本轮要求暂未运行；未推送、未线上验证。
