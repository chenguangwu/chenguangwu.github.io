# 第802批：JWT 解析、验签与生成的状态一致性

关闭 `plan/it/` 10 项：

- JWT解析-时间状态不会随时间自动更新
- JWT解析-声明时间语言与未来签发状态
- JWT解析-动态验签结果中英文不完整
- JWT解析-输入无效后仍显示旧声明检查
- JWT生成-错误文本可复制且异步结果过期
- JWT解析-派生时间字段覆盖原始声明
- JWT解析-搜索摘要混入控件标签且截断
- JWT验签-输入改变后旧结果保留
- JWT生成-永不过期选项保留原有exp
- JWT生成-非对象JSON未校验

## 页面改造（`tools/it/jwt-parser.html`）

### 解析与声明检查

- 新增 `jwtIsEn()`，按 `TBKit.util.isEn()` → `<html lang>` → URL `lang` 判定语言，不再使用静态 `JWT_EN`。
- `parseJwt()` 重写：空输入、段数错误、Header/Payload 解析失败、签名段异常时，统一调用 `clearJwtDerived()` 清空旧声明表、隐藏并清空旧验签结果、递增验签请求序号。
- Payload 区**原样展示解码对象**，不再把 `exp_human` / `iat_human` 派生字段写回对象，避免覆盖用户自带的同名声明。
- `checkClaims()` 按声明逐项渲染：
  - `iat` 为未来时间时显示「未来签发（约 N 后），请检查本机时钟」，不再用 `Math.max` 截成 0。
  - 日期格式随 `jwtIsEn()` 切 `en-US` / `zh-CN`。
  - 表格底部标注「检查时间 …（本机时间，时钟偏差可能影响判断）」。
- 新增 `refreshJwtClock()`，`setInterval` 每秒重算；`document.hidden` 时跳过，仅在存在 token 时执行。页面语言切换后重跑解析与检查。

### 验签

- 新增 `invalidateVerify()`：密钥、算法、token 变化时立即隐藏旧结果并递增 `__verifyRequest`。
- `verifySignature()` 使用请求序号；HMAC Promise 返回后序号不匹配即丢弃，避免慢响应覆盖新输入。
- 成功文案明确「只验证签名；是否过期、生效、签发者/受众见声明检查」。
- 动态提示按 `jwtIsEn()` 输出中英，返回 Promise 便于自动化等待。

### 生成

- 新增 `__genRequest` / `genValid` 与 `invalidateGen()`：算法、有效期、Payload、密钥变化时清空旧输出并让飞行中的异步结果失效。
- `generateJwt()` 校验 Payload 必须是非空 JSON 对象（`{}` 允许；数组、`null`、原始值全部拒绝）。
- 时间策略：`iat` 始终写当前时间；`ttl > 0` 覆盖 `exp`；`ttl = 0`（永不过期）**删除**已有 `exp`，并在界面注明策略。
- JSON 错误、空密钥等提示写入输出区但 `genValid=false`；`copyGen()` / `useGen()` 均要求 `genValid`，错误文本不可复制或回填。
- 异步签名返回前校验请求序号，过期结果不落盘。

### 搜索摘要

- `i18n/tools/it.json` 的 `jwt-parser` 中文 `intro` 改为自然描述，去掉控件标签与截断；英文 `intro` 同步改写并控制在构建截断长度内。
- 构建后 `meta description`、`og:description`、`twitter:description`、WebApplication JSON-LD 描述均为完整句子，不再出现「Payload Signature」控件名或尾部省略号。

## 测试

`scripts/verify_it_calc.js`：

- 更新 2 条旧用例：`exp=0` 断言改读声明表「已过期」；非法 JWT 自动补强改为 `❌ Payload 不是合法 JSON` + `❌ 格式错误` 双锚点。
- 新增 7 条：
  1. Payload 自带 `exp_human` 原样保留，不生成派生字段。
  2. 未来 `iat` 显示「未来签发」与「本机时钟」。
  3. 合法 token 后改非法输入，声明表清空。
  4. HS256 验签后调用 `invalidateVerify()`，旧结果隐藏。
  5. 顶层数组 Payload 生成报「Payload 必须是非空 JSON 对象」。
  6. `exp` 已存在时选永不过期，生成结果无 `exp`，`iat` 为数字。
  7. 源码守卫：时钟刷新含 `checkClaims` / `hidden`，验签与生成含请求序号判断。
