## 逐条结果

### IT-N282 编码丢弃非字母（中，真修）
- 修复：`enc()` 改为字符级处理——先 `normalize('NFD')` 分解，字母取序号、组合符（U+0300–036F）跳过、其余非字母（数字/标点/中文）原样保留，用 sep 连接；不再 `return ''` + filter 丢字符，也不再产生空词分隔符。
- 证据：JSDOM `enc('hello 42!')` → `8-5-12-12-15/4-2-!`（旧 `8-5-12-12-15/`，`42!` 全丢）；`enc('café')` → `3-1-6-5`（é 经 NFD→E=5，不静默丢）；verify N282 强锁。

### IT-N283 解码越界数字静默跳过（中，真修）
- 修复：`dec()` 每个 token 先 `/^\d+$/` 校验且值在 1–26，否则就地输出 `?` 并累加非法项，末尾追加双语 `[非法项: …]` / `[invalid: …]`；不再用宽松 parseInt 截断（`12a`/`1e2`）。
- 证据：JSDOM `dec('1-99-2')` → `A?B  [非法项: 99]`（旧 `AB`）；`dec('12a-3')` → `?C  [非法项: 12a]`（旧 `LC`）；verify N283 强锁。

### IT-N284 ResText 读 textContent 恒空（中，其他 agent 已修好，本批复核补证据）
- 进批探测：清单描述的"读 r.textContent"与当前源码不符——当前 `ResText` 用 `isField = tagName in INPUT/TEXTAREA/SELECT`，`#output` 是 textarea ⇒ 读 `.value`（正确）。
