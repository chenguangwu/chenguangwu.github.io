# 第991批：PDF 合并/拆分状态一致性与页码校验

## 原始问题

第990批补上 PDF 结构保留后，合并/拆分页仍有一组独立的状态缺陷：

1. 合并页对整段文件列表 HTML 搜索 `Infinity` / `NaN`，合法文件名 `Infinity.pdf`、`NaN.pdf` 会把列表替换成「计算结果含无效值」。
2. 混合导入时非 PDF 文件被静默过滤；全部无效时提示调用空参数 `i18nText()`，没有有效反馈。
3. 只要已有 2 个文件解析成功，仍有文件 `loading` 时合并按钮就可用，早点击会漏掉未解析文件；存在无法解析文件时也可直接合并。
4. 合并中途某文件失败时，结果仍按初始 `okItems.length` 报告成功并自动下载。
5. 合并成功后增删/排序文件不清除旧结果和 Blob，清空列表只隐藏结果不释放 Blob。
6. 拆分页 `parseRanges` 用 `parseInt`，`1.5`、`2abc`、`1-3x` 会被静默截断；空段 `1,,3` 被跳过；全角逗号不支持。
7. 拆分成功后修改页码范围、切换模式或勾选缩略图，旧结果和下载按钮仍可用。
8. 拆分页提取完成只生成结果与下载按钮，并不会自动下载，但 toast 写「文件已开始下载」。
9. 拆分的历史/CSV 快照读取隐藏的 `rangeInput`，缩略图模式选页没有进入记录。
10. 合并清空确认在英文态混用中文。

## 实现

### `tools/office/pdf-merge.html`

- 移除 7 处误加的「整段 HTML 含 NaN/Infinity」守卫。文件列表、统计、结果都是字符串，不应按数值有效性判断；合法文件名不再触发错误。
- `addFiles()` 区分已接受与跳过：全部跳过时提示「仅支持 PDF，已跳过 N 个文件：…」；混合导入时在添加后提示跳过数量与名称（最多列 3 个）。
- 新增 `invalidateResult()`：清空 `#result`、`window.__lastBlob/__lastName` 并隐藏进度。添加文件、上移下移、删除、清空及清空确认都会调用；清空同时释放 Blob 引用。
- 列表底部新增 `#mergeGateHint`：有文件读取中时提示等待；有无法解析文件时提示先移除。合并按钮仅在 `okItems ≥ 2 && loading=0 && error=0 && !isMerging` 时可用。
- 合并循环新增 `mergedFiles`、`failedNames`，结果按实际成功文件数与页数报告：
  - 全部成功：正常显示并自动下载。
  - 有失败：显示「合并不完整：M / N 个文件成功」、失败文件名；不自动下载，保留「下载不完整结果」按钮供用户确认。
- 清空确认改用 `__pdfMsg()`，英文态不再混用中文。

### `tools/office/pdf-split.html`

- 移除 9 处同类字符串 NaN/Infinity 守卫。
- `parseRanges()` 改为严格解析：
  - 支持全角逗号 `，`、顿号 `、`，全角连字符 `－/—/–`，全角数字 `０-９` 归一化。
  - 每段必须是完整十进制正整数或 `正整数-正整数`；小数、字母、`1-3x`、多连字符、空段 `1,,3` 均报错并返回原文段。
- 新增 `invalidateExtraction()`：选页变化、模式切换、缩略图勾选、重新选择文件时，隐藏结果区、清空 `resultMsg`、`extractedBytes`、`extractedFileName`、`extractedPages`、`extractedSourceName`。
  - `updateRangePreview()`、`updateThumbStatus()`、tab 切换均触发；提取进行中不触发。
- `doExtract()` 成功后记录实际 `extractedPages` 与源文件名；下载提示改为「提取完成，请点击下载 PDF」，不再声称已自动下载。
- `__pdf_splitSnap()` 优先使用成功提取时的 `提取页码/源文件`；可视化模式下跳过隐藏的 `rangeInput`，没有提取结果时用当前缩略图选中页。
- `__pdf_splitResText()` 优先读取 `#resultMsg`，历史/CSV 记录实际提取结论，不再取隐藏范围预览。
- `__pdf_splitExport()` 导出前先调用 `__pdf_splitExtras()`，确保当前提取快照进入历史表。
