# 第291批：全量门禁 8 项回归收口

## 背景

第290批删除 `plan/categories/` 与 G01–G10 后，全量 `run_gates.py --skip-build` 从 268 项中暴露 8 个失败门禁：general / life / express / pulmonology / automotive / home / wedding calc correctness，以及 `anti-regression: no fake gates`。逐项定位后分为两类：页面真实运行时缺陷、验证脚本锚点过期/结构损坏。

## 真实页面缺陷（已修）

1. `tools/automotive/cycle-belt.html`
   - `calc()` 中 `interval` 自引用导致 TDZ；对比表 `__cbRenderCompare()` 在 `forEach(m)` 内裸引外层 `interval`，车型表 `renderDB()` 同样裸引。统一改为按车型取 `m.interval`，自定义车型取 `customInt`。
2. `tools/automotive/oil-change.html`
   - 剩余里程口径错误：原 `left=km-done`、`next=cur+left`，把“上次换油里程”当成已行驶量。改为 `elapsed=cur-done`、`left=km-elapsed`、`next=done+km`，到期判定按 `elapsed>=km`，提示显示真实已行驶里程。
3. `tools/automotive/fuel-anomaly.html`
   - `updateRec(idx)` 对不存在的记录写入会抛 `Cannot set properties of undefined`；补 `if(!records[idx]) return;`。
4. `tools/wedding/wedding-banquet.html`
   - `fmtMoney()` / `dataGrid()` 缺少非法入参守卫，兜底调用会抛 `toLocaleString` / `rows is not iterable`；补有限数与数组长度守卫。
5. `tools/general/detector-16.html`
   - 空值守卫读取 `dist/hgt/temp`，实际输入 id 为 `v1/v2/v3`，导致页面恒提示“请填写检测距离…”且永不计算；改为读取真实 id。
6. `tools/general/power-focal.html`
   - 推荐速度 `speed/0.8` 裸引未定义变量；改用已解析的 `V/0.8`。
7. `tools/fun/generator-24.html`
   - `solve24(nums)` 未防 `nums` 非数组，兜底调用抛 `reading 'map'`；补 `Array.isArray` 与空数组守卫。
8. `tools/express/insurance-fee.html`
   - `computeInsurance()` 在费率对象缺失时抛 `reading 'rate'`；补参数与配置守卫，返回零值结构。
9. `tools/life/date-difference-calculator.html`
   - `fmtLocalDate` / `addMonthsClamped` / `getDaysDiff` 对非法日期直接调用 `getFullYear/getDate` 抛异常；三处补 `Date` 实例与 `isNaN(getTime())` 守卫。
10. `scripts/verify_pulmonology_calc.js`
    - 脚本结构损坏：`async function main()` 被误插入 `CASES` 数组中间，后半段用例（肺癌 TNM、COPD CAT、抗结核剂量等）落在 `const fails = [...]` 内。已把 9 条用例移回 `CASES`，`fails` 恢复空数组。此前“61/61 全过却 exit 1”即由此造成。
