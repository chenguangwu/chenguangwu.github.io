# 第710批：健康类表格状态去除 HTML 标签

## 背景

`plan/表格单元格显示HTML标签-健康类.md` 列出 8 个页面把 `<span style="color:...">状态</span>` 直接传给 `ToolBox.createTable()`。公共函数按设计转义文本，结果标签以源码形式显示，颜色状态失效，且状态只靠颜色区分。

## 修复

- 状态改为纯文本 + 符号前缀，保留语义且不依赖颜色：`⚠ 需整改`、`✓ 合格`、`⚠ 重点介入`、`△ 关注`、`✓ 一般`、`⚠ 需改进`、`✓ 达标`、`⚠ 异常`、`✓ 正常`、`⚠ 待改进`、`⚠ 耐药`、`✓ 敏感`、`✗ 未达标`、`△ 部分`。
- 不关闭 `createTable()` 的转义，用户输入仍按公共逻辑转义。
- 每页在 `calc()` 前加 `__tbEn()` / `__tbSt()`，按当前 `I18n.isEnglish()` 直接输出中文或英文状态，避免英文态重算后回中文。
- `js/tool-i18n-en.js` 的 `BODY_PHRASE_MAP` 同步补充上述整串映射（含符号），供首次英文渲染使用。

## 验证

- 8 页中文态默认分支：表格 `td` 数量正常（9–28 个），无 `<span>` 标签泄漏，状态单元格显示纯文本。
- 8 页警告分支：逐页注入异常值，分别出现 `⚠ 需整改` / `⚠ 重点介入` / `⚠ 需改进` / `⚠ 异常` / `⚠ 待改进` / `⚠ 耐药`，无标签。
- 8 页英文态重算：输出 `⚠ Needs correction`、`⚠ Priority intervention`、`⚠ Needs improvement`、`⚠ Abnormal`、`⚠ Resistant`、`✗ Not met`、`⚠ Not met` 等，无中文残留。
- 静态测试：0 失败 0 告警；`verify_elderly_calc` 14/14、`verify_fitness_calc` 105/105、`verify_gastroenterology_calc` 69/69、`verify_nutrition_calc` 26/26。

## 备注

批量居中的“颜色状态”改为符号 + 文本，读屏可直接读出状态；如后续要恢复颜色，需用受控 class 或安全 DOM，不能重新把 HTML 传入 `createTable()`。
