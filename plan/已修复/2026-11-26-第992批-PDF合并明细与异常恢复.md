- 日期：2026-11-26
- 工具：`tools/office/pdf-merge.html`
- 对应任务：导出明细不包含实际文件 / 文件列表和处理状态缺少英文 / 初始化失败锁定合并按钮 / 清空期间旧任务自动下载

## 修复内容

1. **导出明细改为真实合并结果**
   - 新增 `lastMergeSnapshot`，在合并成功后记录实际参与文件的顺序、名称、页数、状态、失败原因、成功文件数、输出总页数、是否不完整。
   - `__pdf_mergeExport()` 改为从快照生成 CSV（`pdf-merge-details.csv`），列包含序号/文件名/页数/状态/失败原因/本次合并总页数；成功与失败文件分别标注，保留用户排序后的顺序。
   - 未完成合并不再导出通用历史表，提示“请先完成一次合并再导出明细”。
   - CSV 对以 `= + - @` 开头的文件名加前缀 `'`，避免表格软件公式注入；含引号/逗号/换行的字段按 CSV 规则转义。
   - `invalidateResult()` 同步清空 `lastMergeSnapshot`，改列表后旧明细不可再导出。

2. **动态文件列表与状态英文态**
   - `renderList()` 内统一计算 `en`，读取中/无法解析/页数 badge、表单/书签 badge、统计标签、拖拽排序提示、上移/下移/删除按钮 `title` 与 `aria-label` 全部中英双语。
   - 页数 badge 处理单复数（`1 page` / `3 pages`）。
   - 合并进度（处理/读取/生成/完成/不完整/失败）与成功摘要、失败结果、toast 全部走 `__pdfMsg()`。
   - 英文态实测：列表为 `Files / Total pages / Total size`，按钮 aria 为 `Move up / Move down / Remove`，页数 badge 为 `1 page`、`3 pages`。

3. **初始化失败不锁按钮**
   - `PDFDocument.create()` 移入 `try` 块，`merged` 初始为 `null`；失败进入 `catch/finally`，`isMerging` 复位、按钮恢复、错误中英双语展示。
   - 故障注入 `PDFDocument.create` 抛错：显示 `Merge failed: init boom`，`isMerging=false`、按钮未禁用；恢复后重试成功。

4. **合并期间禁止改动列表，避免旧任务误解**
   - `addFiles / moveItem / removeItem / clearAll` 在 `isMerging` 时提示并直接返回；合并中不能添加、删除、排序、清空。
   - 实测合并中调用 `clearAll()`：提示 `Merge in progress; wait before clearing.`，文件数保持 2。
   - 合并开始即抓取 `okItems` 快照，列表被锁定，不再存在“清空后旧任务仍自动下载”的路径。
