# 第305批：全站主题按钮英文无障碍标签与语言组语义

## 问题

`_en_i18n_probe --check` 对任意工具页都报 1 条英文残留：

```
· aria-label="切换主题 Toggle theme"
```

主题按钮的中英混合 `aria-label` / `title` 在英文态不会被运行时替换，屏幕阅读器会中英混读；同时 `_b5_a11y_check` 报语言切换外层 `🌐…▾` 缺 `aria-label`。

## 修复

### 1. 主题按钮（全站）

原标签（含三种历史变体：`🌙`、`&#127769;`、单引号属性）：

```html
<button class="theme-btn" ... aria-label="切换主题 Toggle theme" title="切换主题 / Toggle theme">
```

统一为：

```html
<button class="theme-btn" onclick="ToolBox.toggleToolTheme()"
  aria-label="切换主题" title="切换主题"
  data-i18n-aria="nav.theme" data-i18n-title="nav.theme">🌙</button>
```

中文态保持「切换主题」，英文态由 `js/i18n.js` 的 `nav.theme = Toggle theme` 覆盖；`title` 同步。批量覆盖 **4,892 个工具页**（含 29 个重定向存根，保持模板一致），并修改 `_build.py` 的导航生成模板，防止新页回退。

### 2. 语言切换容器

`js/i18n.js::mountSwitcher` 外层 `div.nav-icon-btn` 补：

```js
wrap.setAttribute('role', 'group');
wrap.setAttribute('aria-label', 'Language / 语言');
```

外层是包含 `select` 的语言选择组，不用 `button` 角色，避免嵌套交互控件语义错误。

### 3. 剂量页新增深潜译文

第304批给 `medical/dosage-calculator` 补的 3 条场景、1 条示例、1 条 FAQ 缺英文映射，英文态残留 1 页；在 `i18n/tools/en/medical/dosage-calculator.json` 补 6 条译文后归零。
