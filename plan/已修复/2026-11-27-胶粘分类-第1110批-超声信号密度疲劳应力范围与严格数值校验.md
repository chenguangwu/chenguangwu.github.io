## 修复条目

### 1. `tools/bonding/detector-27.html` — 信号数量误称面积比

- 删除“可疑信号面积比 = 信号数 ÷ (面积/10)”的错误换算；改为两个独立指标：
  - 可疑信号密度（个/100cm²）= 信号数 ÷ 检测面积 × 100；
  - 缺陷面积比（仅在填写有效缺陷面积时）= 缺陷面积 ÷ 检测面积 × 100，并明确重叠缺陷会重复计数。
- 新增“有效缺陷面积（cm²，可选）”输入；缺陷面积 > 检测面积时直接拒绝并清空旧结论。
- 删除不参与计算的“粘接材料/胶粘剂类型”下拉，避免“改了没反应”。
- 删除“粘接良好/基本合格/需复检/不合格”强判定，改为“读数提示（示意）”：只给复检/加密扫查建议，明确不计算粘接强度、不判定合格；阈值须由专业人员按检测规程核定。
- 更新页面 intro、meta/og/JSON-LD、相关工具卡片、深解析与 FAQ，不再宣称“给出合格判定”。

真机验证：
- 默认 −6 dB / 3 dB / 100 cm² / 2 个信号 → 信号密度 2.0，提示“少量可疑信号，建议加密扫查并复检”，无合格结论。
- 填缺陷面积 20 cm² → 面积比 20.0%；信号 6 个 / 回波 −2 / 衰减 5 → 密度 6.0，只提示可疑信号较多，不再出现“不合格”。
- 缺陷面积 200 > 100 → 报错“有效缺陷面积须在 0 与检测面积之间”，表格清空，无页面异常。

### 2. `tools/bonding/detector-26.html` — 非法测点被跳过且旧结论保留

- 测点解析改为逐 token 严格校验：只接受纯数字（可带符号/小数），不再 `map(Number).filter` 静默丢弃。
- 非法 token 逐条指出位置与原始内容，例如“第 1 个测点‘0.2mm’不是有效数字”“第 2 个测点‘abc’不是有效数字”；同时支持中文逗号/空格分隔。
- 任何非法测点、非正数/零值、或有效测点不足 3 个时：结果区只显示错误，清空 `detector_26Table / Diff / Chart`，设置 `__detector26Invalid`，导出被拦截；历史重绘在无效态跳过。
- 合法输入恢复计算并允许导出。

真机验证：
- `0.2mm,abc,0.3` → 两条定位错误，表格/图表清空。
- `0.18,0.22,0.19` → 平均 0.197、最大偏差 10.0%、均匀性 20.3%，表格恢复，无异常。
