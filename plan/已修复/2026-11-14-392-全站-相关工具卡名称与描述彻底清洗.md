## 二、描述：三个叠加缺陷

| 缺陷 | 影响面 | 表现 |
| --- | --- | --- |
| 描述 == 工具名 | 9004 张（31.8%） | 卡片上下两行是同一个词，描述槽位零信息量 |
| `[:50]` 硬截断不看句读 | 7671 张 | 停在半个词上，末字多为「器 / 算 / 化」 |
| 收口在逗号/顿号/冒号 | 7160 张 | 卡片以「，」「、」「：」结尾，像话没说完 |

### 关键判断：不是「缺描述」，是「历史产物退化」

处理 9004 张重复描述时，第一反应是「留空更干净」。**这个判断是错的。**

用唯一描述权威源 `scripts/tool_desc_source.zh_desc()` 实测：这些工具在 i18n `zh-CN.intro` 和页面 `<meta name="description">` 里**都有真实描述**（例：
`tools/agriculture/calc-38.html` → 「基于各测点灌水深度，按克里斯琴森系数计算喷滴灌均匀度…」）。
重复描述是**旧版 `_build.py` 留下的历史产物**——相关工具块在构建里是「修剪模式」（只删死链、不刷新名称与描述），存量永远不自愈。

所以正确做法是**回填真实描述**，不是留空：

| 处置 | 数量 |
| --- | --- |
| 从权威源回填真实描述 | 8724 |
| 确实无任何来源、保持空描述（不编造文案） | 280（1.0%） |

### 修法

`_build.py` 新增 `_rt_desc_html(rt, max_len=50)`，四处卡片模板里裸的 `esc_html_py(_zh_desc_of(rt))[:50]` 全部改为调用它：

1. 描述与 `name` 相同 → 输出空串（不再重复显示）。
2. 超长时**只认句末标点**（`。！？；`）收口；找不到就硬切，去掉尾部悬空标点后补 `…`。
3. 末尾若是 `，、：` 一律换成 `…`。

### 存量清洗顺序

1. 9004 张「描述 == 名称」先置空；
2. 按目标页跑 `TDS.zh_desc()` 回填 → 8724 张取回真实描述；
3. 剩余 280 张保持空（无来源，不编造）；
4. 结尾悬空标点 7160 张统一改 `…`。

## 四、复核要点

1. 任意工具页底部相关工具卡：名称应等于被链页面的 h1，描述应是真实功能描述、不为名称、不以「，、：」结尾。
2. 少数卡片只有名称没有描述（1.0%）属预期——这些工具全站无任何描述来源。
3. `_build.py` 改动只影响**新建**的相关工具块（既有块是修剪模式不刷新），故产物已用一次性脚本对齐，后续新块自动符合新规则。
