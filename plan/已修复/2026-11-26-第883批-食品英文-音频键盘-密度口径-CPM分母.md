1. **食品英文简介（syrup-brix / wine-alcohol / convert-ratio）**：英文首段不再是「convert values in-browser instantly with local processing」占位句，分别改为 Brix/SG/波美度/折射率互转、Balling 公式估算酒精度、按比例缩放配料的具体说明；同步 `i18n/tools/food-body.json`。
2. **音频进度条（audio-speed / audio-volume / audio-waveform）**：进度条补 `role="slider"`、`tabindex="0"`、`aria-label`、`aria-valuenow`；方向键 ±5 秒、Shift ±1 秒、Home/End 到首尾。音量与波形复用各自 seek 逻辑，播放中跳转仍会重启音频源。
3. **颜色互补（color-convert / color-picker）**：255−RGB 明确改称「RGB 反相色（非色轮互补）」；说明色轮互补按 HSL 色相 +180° 计算，设计工具数据卡同步更名，避免两个概念混用。
4. **关键词密度（analysis-density / marketing-keyword-density）**：删除「1%–5% 健康区间 / 可能被判定堆砌、降权」等确定性结论；改为描述性统计与常见经验参考，高密度提示「人工检查是否影响可读性」。FAQ/JSON-LD/可见文案同步。
5. **文本历史隐私（text-extract-phones / sensitive-word-filter）**：历史快照跳过 textarea、正文与敏感词表，结果只记录「已计算（不保存原文）」；历史区注明不保存原文、号码/词表与结果。真机写入电话后 localStorage 无号码、无原文，仅见脱敏标记。
6. **清洁工具合法名称（cycle-20 / staff-schedule）**：名称/备注含「NaN」等合法文字时，不再被渲染后的文本指纹守卫误判；列表按已转义 HTML 直接渲染。草坪工具同步补「开始日期无效」单独提示，避免 Invalid Date 抛错。
7. **长度/重量公式方向（length-converter / weight-converter）**：公式说明由「输入值 × 目标系数 ÷ 源系数」改为「输入值 × 源系数 ÷ 目标系数」，并注明系数表示该单位对应多少米/克。
8. **汽车摘要（cheshenkongqizulixishu / drive）**：meta 简介不再重复「输入…计算…」；深挖首场景分别改为造型/改装对比与选型对比，摘要只保留一次输入输出描述。
9. **广告 CPM 示例（reach-frequency / assessor-55 / assessor-54）**：Reach 算例改用 200 万总曝光作分母，CPM 100 元/千人并补 CPR 0.5 元/人；电视算例改为 GRP 150、OTS 750 万、CPM 106.7 元/千人，明确 CPM 分母是总曝光人次而非不重复到达人数；户外算例分母已正确（675000 人次），保留并核对。
