# 第468批：占位式 aria-label 清理

日期：2026-11-22
分类：可访问性 / 运行时表单控件

## 原问题

审计发现 19 个工具页的 38 个运行时控件把 placeholder 原样当成 `aria-label`，
如 `aria-label="如 60"`、`aria-label="e.g. '+item.qty+'"`。这些值只是输入示例
（甚至带数字范围或拼接表达式），不是字段名称；屏幕阅读器会读出「如 60」而
不是「重量」「次数」等真实语义。

## 修复

按页面与字段顺序逐项替换为稳定名称，覆盖 19 个文件、38 个控件：

- 投料/配方/物料：投入物料数量、产出物料数量、原料单价、原料数量、物料数量、物料单价；
- 健身/健康：重量（kg）、次数、RPE 自觉强度、饮品数量（杯）；
- 工程/测量：原料百分比、目标成分、原料占比、回收率、面积、厚度、密度、品位、X/Y 坐标、后视/前视读数、测段距离；
- 交通/装饰：流量比 y、黄灯时长、全红时长、阶段时长；
- 社保/营销/采购/评分：单位缴费比例、个人缴费比例、企业销售额、质量分、价格分、交期分、服务分、档位上限、通道距离、其他干扰原因、轮次名称。

同时在 `ensure_form_control_names()` 增加「已被 `<label>` 包裹则跳过」判断，
避免同一控件在构建中被「补 aria-label → 删冗余」反复改写，保证幂等。

- 构建：`env -u NODE_OPTIONS python3 _build.py`，退出 0；`Form control names: 0 controls in 0 pages`、`Wrapped control aria cleanup: 0 attrs in 0 pages`，连续两次构建无变化；
- 占位式 `aria-label="如/e.g./例如…"`：38 → 0；
