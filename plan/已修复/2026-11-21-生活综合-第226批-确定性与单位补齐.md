# 第226批：合同草案确定性、eV 与字节速率（2026-11-21）

## 修复清单

1. **合同草案每次生成都变（LF-N93）**
   - 服务列表用 `sort(()=>Math.random()-0.5)` 打乱、工期用 `randInt`，同一组单价/数量/税率每次刷新得到不同编号、服务名与工期，无法校对也无法复现。
   - 服务改为固定顺序；合同工期改为 `7 + (i*13+floor(total)) % 84`，总额决定时可复现；生成数量由 `parseInt` 改 `Number` + `Number.isInteger`，`2.5` 不再静默变 2。
   - 金额大写由小写「十二元…」改为真正的财务大写（`moneyUpper()` 映射壹/贰/叁/肆/伍/陆/柒/捌/玖/拾/佰/仟），合同条款内两处「大写」同步。

2. **常见用品预设清空自建清单（LF-N89，`cycle-4`）**
   - `applySupplyPreset` 直接 `supplies = 预设.map(...)`，用户自建用品与记录全部消失。现改为按名称合并：同名项更新参数，缺少项追加，其他自建用品保留；已有清单时先确认再覆盖同名项。

3. **保险推荐每次刷新结论都变（LF-N99，`recommender-8`）**
   - `randItem`/`randInt` 让险种、保额、保费、要点每条随机，同一场景两次生成建议不同。现按序号固定轮换险种与要点，保额用 `(i*37+n*11) % 区间跨度` 确定性取值，年保费按固定倍率；输出可复现。

4. **能量换算缺电子伏特（LF-N72）**
   - 页面简介写「支持 eV」，下拉与因子表都没有。补 `eV=1.602176634×10⁻¹⁹ J`、`keV`、`MeV`，下拉三项与公式说明同步。

5. **数据速率缺字节/秒单位、MB/s 口径混用（LF-N73/N74）**
   - 补 `B/s=8 bit`、`KB/s=8000`、`MB/s=8×10⁶`、`GB/s=8×10⁹` 四个单位与中文名；下载速度由 MiB（÷1024²）改为网络十进制 MB/s（÷10⁶），并标注「十进制，网络速率口径」。

6. **复核已修复**：`generator-random-1` 已支持小数模式且数量 `Number` 整数校验；`cycle-4` 预设按钮已存在。
