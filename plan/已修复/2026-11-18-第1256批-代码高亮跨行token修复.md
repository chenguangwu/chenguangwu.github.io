# 第1256批 · IT-N448 代码高亮跨行 token 修复

## 问题
`renderHighlighted()` 先把代码按行切开，再对每行单独调用 `tokenize()`。JS `/* */`、Python 三引号字符串、HTML `<!-- -->` 的结束符在后续行，逐行调用必然失配：JS 三行块注释的第 2 行被渲染成普通代码、第 3 行 `*/` 被渲染成运算符；Python docstring 与 HTML 多行注释同症状。错误颜色还会被「复制高亮 HTML」原样带出。

## 修复
`renderHighlighted()` 改为先对整段代码调用一次 `tokenize(code, lang)`，再按每个 token 值内部的 `\n` 把高亮 span 拆到对应行；行数仍以 `code.split('\n').length` 为准，空行保留占位。tokenize 本身无需改动——它原本就能跨行找结束符，只是此前被逐行喂入而失效。

## verify 强锚
`scripts/verify_it_calc.js` 新增三条用例，分别注入三行 JS 块注释、三行 Python 三引号字符串、三行 HTML 注释，断言三行都落在正确的 token 颜色类且无普通/运算符色混入：
- `HLBLOCK OK` / `HLDOC OK` / `HLHTML OK`

旧版差分：旧页面 1788/1791 通过，三条新用例精确变红；修复版 1791/1791 通过。默认示例均不含跨行 token ⇒ 零逃生。
