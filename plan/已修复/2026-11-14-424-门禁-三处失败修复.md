# 424 批：修复 422–423 变更引出的 3 个门禁失败

`i18n/tools/_en_override.json`

## 一、失败项与根因

### 1. `it calc correctness`（graphql-formatter 自动补强用例）

417 批让 `formatGraphQL()` 真正读取 `#indent` 缩进后，自动补强用例原来锚定的
「默认样例格式化尾部 + 跨元素拼接的 indent 值 4」不再成立。该用例注入
`input=1\n2\n3`、`indent=4`，但没有 `clicks`，走兜底函数循环，最终输出为 `1 2 3`。
原 expect `" } } } }\n4\n"` 依赖多元素拼接顺序，属于脆弱锚点。

修复：expect 改为单元素可复算结果 `"1 2 3"`；默认示例是 `query GetUser…`，
不含该串，判别力不变。显式 graphql 压缩用例（line 2686）不受影响。

### 2. `legal calc correctness`（rent-deposit 自动补强用例）

421 批为 `#utility`、`#noReceipt` 增加 `getElementById` 读取后，harness 惰性登记元素
把 `"utility"` 值插入 blob，原 expect 的跨元素拼接串
`"42\n2\n42\n押金总额： 84 元（2"` 不再连续。

修复：expect 改为结果区单元素文本 `"押金总额： 84 元（2个月租金）"`；
默认态 3,000×3=9,000 元，不命中。显式 4,500/500 用例仍通过。

### 3. `english meta degenerate`

418 批新增的 3 个英文名以括号结尾，被 P3 `paren_template` 判红：

| 页面 | 旧值 | 新值 |
|---|---|---|
| obstetrics/placenta-grading | Placental Maturity (Grannum Grading) | Placental Maturity Grannum Grading |
| obstetrics/taipanchengshudu-grannumfenji | Placental Maturity Grading (Ultrasound) | Ultrasound Placental Maturity Grading |
| pediatrics/assessor-13 | Dehydration Assessment (WHO/IMCI) | WHO IMCI Dehydration Assessment |

只改 `_en_override.json` 的 `en`/`ed`，文件原有「旧条目 5 行、418 新增条目单行」的
混合格式保持不变，避免整文件重排。
