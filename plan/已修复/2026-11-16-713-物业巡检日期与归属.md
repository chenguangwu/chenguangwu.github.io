# 713 批：物业巡检本地日期、到期标签、巡检归属与导出转义

日期：2026-11-16　门禁：`_build.py` + `_test_static.py`（4685/4685）+ `verify_property_calc.js`（4/4）

## 修复（`tools/property/cycle-10.html`）

### 日期与到期标签
- 新增 `parseDateLocal()`，`addDays()` 不再用 `new Date('YYYY-MM-DD')` 的 UTC 午夜解析，UTC-8 等西半球时区不会把 11-06 显示成 11-05。
- `dueState()` 仅 0 天标「今日到期」，1–2 天改为「剩余 N 天」；详情提示同步为「将在今日 / N 天后到期」。

### 巡检归属
- `startInspection()` 记录 `routeId`；`finishInspection()` 按 id 查找路线后回写，巡检中删除前面的路线不再写错路线或访问 `undefined`；路线已删除时丢弃本次结果并提示。

### 导出转义
- `__inspExport()` 对检查点拼接串与上次日期做 `ToolBox.escHtml`，编辑过的检查点不能再向 `tr.innerHTML` 注入标签；路线名此前已转义。

## 门禁用例

- `property/cycle-10`：`parseDateLocal('2026-11-06')` 返回本地 2026-11-06；明日到期显示「剩余 1 天」；删前序路线后巡检结果按 id 落到 RB 而非旧下标。

## 备注

- 导出注入仅做源码修复，未在浏览器执行攻击载荷。
- 巡检执行中的检查点若被同时编辑，结果仍按开始巡检时的名称快照保存。
