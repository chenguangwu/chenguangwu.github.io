# 第732批：IT 五页解析与统计边界修复

修复日期：2026-11-24
范围：`tools/it/`（Markdown 转 HTML、CSV 校验、Basic Auth、二项分布、假设检验）
验证：`node scripts/verify_it_calc.js` 1902/1902；Puppeteer 五页边界用例全绿、无 pageerror。

## 1. Markdown 转 HTML：链接地址含括号时截断

- 现象：链接/图片正则匹配到第一个右括号即停止，`https://example.com/a_(b)` 被截成 `.../a_`，剩余 `(b))` 落到正文。
- 修复：改为字符扫描解析，alt 与目标地址都支持反斜杠转义，目标地址按括号深度配对；图片与链接共用同一解析器。原有危险协议过滤保留（`javascript:` 仍退回 `#`）。
- 验证：链接与图片地址中的成对括号完整保留；危险协议仍被拦截。

## 2. CSV 校验：多字符分隔符被静默忽略

- 现象：解析器逐字符与完整分隔符字符串比较，`||` 永远匹配不到，两行都被当成 1 列，漏报第二行多一列；空分隔符被静默替换成逗号。
- 修复：非引用段按完整分隔符字符串匹配并推进 `sep.length`；空分隔符前置拒绝；分隔符含换行或双引号也拒绝并提示。引号、换行规则保持 RFC 4180 口径。
- 验证：`a||b / 1||2||3` 以 `||` 分隔 ⇒ 检出「第 2 行：列数 3（应为 2）」；空分隔符明确报错。

## 3. Basic Auth：无法生成空密码凭据

- 现象：`!user || !pass` 把空密码直接判为未填写，无法生成 `admin:` 的合法 Base64 凭据。
- 修复：新增「使用空密码」复选框，勾选后允许 `pass=''` 并生成 `YWRtaW46`；结果区提示服务端仍可能拒绝该凭据。未勾选时保持原「请填写用户名和密码」提示，区分未填写与有意空密码。

## 4. 二项分布：极小右尾概率相消为零

- 现象：`P(X≥k)=1−CDF(k−1)`，n=100、p=0.5、k=100 时 CDF 已舍入为 1，右尾被算成 0。
- 修复：新增 `sf(n,k,p)` 从 k 到 n 直接累加 PMF（对数域递推），`P(X≥k)` 与 `P(X>k)` 均改用生存函数；公式说明同步改为直接求和。
- 验证：n=100/p=0.5/k=100 ⇒ `7.88860905e-31`，不再显示 0。

## 5. 假设检验：单尾方向相反仍称设计足以分辨

- 现象：「最小效应」只比较 `|diff|` 与 MDE，左尾检验遇到正向观测仍称「观测差值高于该值，设计足以分辨」，与同页接近 0 的效能矛盾。
- 修复：单尾时保留方向，观测效应与备择方向相反即明确提示「当前检验不能据此支持该方向」，不再用绝对值给出可分辨结论；方向一致时才按 MDE 比较。双尾逻辑不变。
