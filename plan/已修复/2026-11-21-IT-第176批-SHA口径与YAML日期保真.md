# 第 176 批（IT）SHA 口径 / Base64 标签 / RC4 严格解码 / YAML 日期保真

## 修复项

1. `tools/it/sha.html`
   - WebCrypto 不提供 SHA-224，选择器也只有 SHA-1/256/384/512。删除 meta、JSON-LD、正文、FAQ 与英文词典中的 SHA-224 承诺，统一改为「SHA-224 暂未提供」。
   - 文件区「支持大文件，分块计算」改为「文件整份读入内存计算，超大文件受浏览器内存限制」，与 `file.arrayBuffer()` 实现一致。
2. `tools/it/base64-converter.html`
   - 勾选框「自动检测输入类型」实际只在解码时剥离 `data:` 前缀，改名为「解码时剥离 data: 前缀」。
3. `tools/it/rc4.html`
   - 解密 `TextDecoder` 由 `fatal:false` 改为 `fatal:true`：非 UTF-8 字节（错误密钥或二进制密文）不再输出 U+FFFD 乱码，而是落到既有 Hex 回退。
   - 同步删除一条依赖「乱码拼接值」的脆弱自动补强用例（该用例断言的是 harness 桩下的异常输出，不是页面语义）。
4. `tools/it/yaml-validator.html`
   - 两处 `jsyaml.loadAll` 统一传 `{schema: jsyaml.JSON_SCHEMA}`：`2024-01-01` 保持字符串，不再被解析为 Date 后按本地时区漂移；`!!binary` 不再变成索引对象。
