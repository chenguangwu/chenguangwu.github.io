## 改动 `tools/it/url-parser.html`

- 新增 `setParseState()`：空输入或解析失败时 `parsed = {}`，禁用「复制 JSON」「保存」；成功时恢复。
- `copyJson()` 在无有效 `parsed.href` 时拒绝复制并提示；`saveToHistory()` 要求当前输入规范化后与 `parsed.href` 一致。
- 历史默认脱敏：`redactUrl()` 移除 username/password，将 token、access_token、secret、signature、session 等敏感查询参数值替换为 `***`。
- 新增「保存完整地址（含凭据/令牌，仅存本机）」复选框，默认不勾选；勾选后才保存原文，并记录 `full` 标记。
- `getHistory()` 对旧版无 `full` 标记的记录自动脱敏迁移，避免历史遗留完整凭据。
- `buildUrl()` 改为用 URL API 校验和构造：拒绝空白/斜杠/问号/未加方括号的端口等非法 hostname，路径中的 `?`/片段空格按 URL 规则编码（`%3F`、`%20`）；失败显示错误并返回空串，复制按钮不复制。
- 增加默认脱敏说明文案。

## 数据与测试
