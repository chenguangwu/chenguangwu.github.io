## IT-N354（高）`#text` 键被「# 开头即注释」规则整行吞掉，元素文本永远输出不了

**失败点**：`parseYaml()` 里 `if(!s||s[0]==='#') continue;`，而 `jsonToXml()` 的 `k==='#text'` 分支要求该键能进 items —— 两者直接冲突，`#text` 永远读不到。页面说明第 1 条却写着「#text 键转为元素文本」。

**根因**：注释判定与业务约定共用同一个 `#` 前缀，没有豁免。

**修复位点**：`parseYaml()` 判断改为
```js
if(s[0]==='#' && !/^#text\s*:/.test(s)) continue;
```
并在 `yIsMapEntry()` 里为 `#text` 单独放行（否则会被「URL 不是映射」那条新规则误杀）。

**顺带修**：`inner+=val[k]` 原本对 `#text` 不做转义，`&`、`<` 会破坏 XML 结构；改为 `escXml(...)`。

**证据**：`note:\n  @id: 1\n  #text: hi` → 修复前 `<note id="1"></note>`（文本丢失）；修复后 `<note id="1">hi</note>`。

## IT-N355（中）顶层是序列/标量时输出非法标签或空 root

**失败点**：`jsonToXml()` 用 `Object.keys(obj)` 生成元素名。顶层数组的键是 `"0"`/`"1"`（数字开头，XML 名非法）；顶层标量在 `yBlock` 里因该行无冒号被 `continue` 丢弃，得到 `{}` ⇒ 空 `<root></root>`。

**修复位点**：
- `jsonToXml()` 增加顶层分支：数组 ⇒ `<root><item>…</item></root>`；标量 ⇒ `<root>文本</root>`。
- `parseYaml()` 在首行既不是 `- ` 也不满足 `yIsMapEntry` 时，直接返回 `yScalar(该行)`。
- 新增 `xName(k)`：非 `[A-Za-z0-9_.-]` 字符换成 `_`，数字开头补前导 `_`（`1a` → `_1a`、`foo bar` → `foo_bar`）。`__proto__` 以下划线开头，行为不变。

**证据**：`- a\n- b` → 修复前 `<root><0>a</0><1>b</1></root>`（XML 解析器直接报错）；修复后 `<root>\n  <item>a</item>\n  <item>b</item>\n</root>`。`just a string` → 修复前 `<root></root>`；修复后 `<root>just a string</root>`。

## IT-N356（中）行内注释被并入值、裸 URL 被误判为映射

**失败点**：
1. 只过滤整行注释，`name: Bob # 注释` 的值里带着 `# 注释`。
2. `yIsMapEntry()` 只要「含冒号且首字符是字母」就判映射，`- http://x` 被拆成键 `http`。

**修复位点**：
- 新增 `yStripInlineComment()`：引号外、`#` 前是空白或行首才截断；`yScalar()` 第一句先调它。
- `yIsMapEntry()` 改为要求 `^([^:]+):(\s|$)`（YAML 规定 `:` 后必须空白或行尾），键里含 `/ \ ? #` 一律判标量。

**证据**：`name: Bob # 注释` → 修复前 `<name>Bob # 注释</name>`；修复后 `<name>Bob</name>`。`items:\n  - http://x` → 修复前 `<items><http>//x</http></items>`；修复后 `<items>http://x</items>`。

## IT-N357（中）「缩进」「按键名排序输出」两个控件是死输入

**失败点**：`calcTool()` 全文从未读取 `#indent` 或 `#top_1`（只在 `resetForm`/预设里赋值），输出恒为无缩进紧凑 XML、键序恒定；而预设里就有一条叫「按键名排序输出」。

**修复位点**：
- 新增 `__yaml_to_xmlUnit()`（读 `#indent`：`2` / `4` / `tab` → 缩进串）与 `__yaml_to_xmlSort()`（读 `#top_1.checked`）。
- `jsonToXml(obj, unit, sortKeys)` 全量改写为递归缩进输出，`keysOf()` 在 `sortKeys` 时对每层键 `sort()`。

**行为变化（有意为之）**：默认「2 空格」生效 ⇒ 默认输出由单行紧凑改为逐子元素换行缩进。既有用例 `it/yaml-to-xml`（`srv/host/port`）的 expect 由 `&lt;srv&gt;&lt;host&gt;…` 改为 `&lt;srv&gt; &lt;host&gt;…`（门禁 blob 把 `\s+` 压成单空格）。

**证据**：`zeta: 1 / alpha: 2 / mid: 3` + 勾选排序 → 修复前 zeta→alpha→mid（与未勾选完全相同）；修复后 alpha→mid→zeta。缩进：同一输入在 2 空格 / 4 空格 / tab 下输出缩进分别为 2 / 4 / 1 个制表符（离线 node 复核，见下）。
