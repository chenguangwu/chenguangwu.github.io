# 第 110 批：第二批敏感工具历史隐私（IT 开发）

- 日期：2026-11-21
- 范围：`tools/it/` 8 个会接触密钥、令牌、私钥、口令或明文的工具
- 目标：`__*Snap()` 不再把敏感原文写入 localStorage 历史；需要可读性时只记录长度或非敏感参数

## 修复内容

| 工具 | 不再入历史的字段 | 处理方式 |
| --- | --- | --- |
| `otp-generator` | `secret` | 仅记录密钥长度 |
| `jwt-parser` | `jwtInput`、`secret`、`genSecret`、`genPayload`、`genOut` | 前四者只记长度，生成结果直接跳过 |
| `jwt-debugger` | `token-input`、`secret`、`gen-payload`、`gen-output` | 前三者只记长度，生成结果直接跳过 |
| `api-sign-generator` | `secret`、`params` | 只记录密钥长度与参数长度 |
| `ecdsa` | `privKey`、`pubKey`、`message`、`signature` | 只记录各自长度，私钥/签名原文不入历史 |
| `env-generator` | `importText`、`valInput` | 只记录导入内容与变量值长度 |
| `md5` | `hmacKey`、`hmacInput`、`textInput` | 只记录密钥与输入文本长度 |
| `hash` | `hmacKey`、`hmacInput`、`textInput`、`batchInput`、`verifyInput` | 只记录各自长度 |

实现统一使用函数内 `__tbPrivate` 映射：命中敏感 id 时写入「N 字符（未存原文）」后 `continue`；生成结果类只读域直接跳过。`rsa` 已有 `__rsaKeyFields` 跳过密钥字段，本批未重复改动。
