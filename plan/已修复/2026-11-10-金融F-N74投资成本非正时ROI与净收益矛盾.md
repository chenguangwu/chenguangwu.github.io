# 金融 F-N74：ROI 页投资成本为 0/负时 ROI 归零、净收益照常计算（已修 · 申请复核）

## 来源
- `plan/categories/02-金融财务/finance.md` 的 F-N74（中，确认缺陷）。

## 根因
- `tools/finance/calc-5.html` `calc()` 中 `roi = cost>0 ? netProfit/cost : 0` 对非正成本兜底为 0，但 `netProfit = value - cost - extra` 不受任何限制。
- 成本 0 时净收益仍为非零金额，与同屏「ROI 0.00%」「年化 0.00%」直接矛盾；成本 −100,000 时负成本被加进收益得 250,000，ROI 仍 0.00%。
- 通用守卫 `__tbInputGuard()` 虽有 `__TPL2`（分母不能为 0）与 `__TPL3`（不能为负）模板，但 `__D={}` 与 `__N={}` 均为空对象（F-N189 全站注入留下的空壳），两道检查永不触发。

## 修复位点
- 在 `calc()` 读取 `cost` 之后立即加字段级守卫（不改全站注入的通用模板，避免影响其他页）：
  ```javascript
  const cost = parseFloat($('cost').value)||0;
  // F-N74：投资成本是 ROI 分母，非正时 netProfit 仍算非零会与「ROI 0.00%」自相矛盾
  if(!(cost > 0)){
    const __en = (typeof TBKit!=='undefined'&&TBKit.util.isEn());
    ToolBox.setResult("res", __en ? '<p style="color:var(--danger)">Investment cost must be greater than 0.</p>' : '<p style="color:var(--danger)">投资成本必须大于 0，无法计算 ROI。</p>');
    const __dg=document.getElementById('summary'); if(__dg) __dg.innerHTML='';
    return;
  }
  ```
- 空值仍由原有 `__tbInputGuard(['cost','value'])` 拦截（「请填写」），本守卫只处理「有值但 ≤0」；有效成本下计算链完全不变。
- 英文态经页面既有 helper 输出纯英文，无 CJK 残留。
