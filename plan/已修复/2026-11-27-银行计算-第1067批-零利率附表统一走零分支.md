# 第1067批：年金、月供、储蓄目标附表零利率不再除零

> 来源：`plan/银行年金与储蓄工具-零利率附表仍按一般公式除零.md`。状态：待独立复核。

## 问题

`present-value-annuity-due`、`future-value-annuity-due`、`emi-loan` 主计算有零利率分支，但附表/对比项仍用含 `r` 或 `(1+r)^n-1` 分母的公式；`savings-goal-monthly` 主结果有零分支，附表则完全没有。零利率时主结果 12000，附表却为 NaN，并可能写入历史、被导出。

## 修复

- 三页年金的期末对比、附表 `Extras()`、图表扫描统一调用 `annuityPV/annuityFV`；函数内部 `r===0` 直接返回 `PMT*n`，正利率走 `expm1(n*log1p(r))`。
- `emi-loan` 附表统一调用 `emiValue`，`r=0` 返回 `P/N`。
- `savings-goal-monthly` 新增 `savingsPMT(fv,i,N)`：`i=0` 返回 `fv/N`，否则 `fv*i/expm1(N*log1p(i))`；主结果、附表、图表扫描全部替换。
- 储蓄附表补充利率非负、年限为正且整月校验；主结果增加 `isFinite` 检查，溢出时报错而不是写入无效数。
- 历史记录只使用已通过校验的 `pmt`，导出只导出成功生成的表。

## 验证

- `node scripts/verify_banking_calc.js`：62/62。
- 新增 4 条零利率/极限用例：
  - 年金现值 `r=0, PMT=1000, n=12`：主结果与期末对比均 `12000.00`。
  - 年金终值同参数：主结果与期末对比均 `12000.00`。
  - 储蓄目标 `r=0, FV=200000, y=10`：月存 `1666.67`、累计 `200000.00`。
  - 储蓄目标 `r=1e-14%`：月存仍 `1666.67`，与零利率连续。
- 储蓄页英文探针 0 残留；`_test_static.py` 4654 通过 / 0 失败 / 0 告警；`_build.py` 后 `savingsPMT` 与三页 `Math.log1p` 仍在。
