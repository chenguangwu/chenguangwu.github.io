# 2026-11-24 第730批：数值校验、投影与密码精度五项

## 修复清单

1. **假设检验：样本数与参数严格校验** (`tools/it/hypothesis-test.html`)
   - 样本量 n 从 `parseInt`（10.9→10）改为原始字符串十进制整数校验，要求安全整数且 ≥ 1，明确拒绝小数、负数、科学计数法。
   - 均值、μ₀、σ、α 统一 `readFinite`：空值、夹带字符、`1e309` 溢出到 Infinity 一律逐字段定位报错；σ>0、α∈(0,0.5] 保持。
   - 新增输入行约束说明；错误提示支持中英文；错误渲染不再依赖外部 `out` 变量。

2. **超几何分布：四项计数严格整数** (`tools/it/hypergeometric-distribution.html`)
   - N/K/n/k 从 `parseInt`（52.9→52、1e3→1）改为 `^\d+$` + `Number.isSafeInteger` 校验，拒绝小数、负号、科学计数法。
   - 保留 K/n/k 合法零值；范围仍为 K,n∈[0,N]、k∈[0,min(n,K)]。
   - N 上限 10000，避免超大组合数让浏览器实时计算卡死；输入区补充约束说明。

3. **比例误差范围：边界样本改用 Wilson 区间** (`tools/it/margin-of-error.html`)
   - p̂=0 或 1 时 Wald 标准误恒为 0、旧页面输出 ±0，误导为“总体比例已确定”。
   - 边界自动切换 Wilson score 区间：中心=(p+z²/2n)/(1+z²/n)，半宽=z√(p(1−p)/n+z²/4n²)/(1+z²/n)；有限总体时中心与半宽按 p̂ 缩放。
   - 普通 p̂ 仍保留原 Wald 结果；新增方法、有限总体适用前提、n<30 小样本提示；边界区间用独立精度显示（n=1000：0 次成功 [0,0.00382676]，全成功 [0.99617324,1]）。

4. **向量点积：区分带符号投影、长度与投影向量** (`tools/it/vector-dot-product.html`)
   - 旧页面把 (A·B)/|B| 标为投影长度，反向时显示 -1。现分列：带符号标量投影、非负投影长度、投影向量 ((A·B)/|B|²)×B。
   - 零向量时夹角与投影均标记未定义；空坐标不再填 0，逐分量定位提示，数值 0 仍合法。

5. **仿射密码：BigInt 精确归一化** (`tools/it/affine-cipher.html`)
   - a/b 输入从 number 改为文本数字框，避免浏览器对超长整数提前舍入。
   - 用 BigInt 对整数字符串直接 mod 26，超出 `Number.MAX_SAFE_INTEGER` 的密钥不再先变 Double：`9007199254740993 ≡ 7`。
   - 新增“实际使用 a ≡ … / b ≡ …”提示，明确归一化结果；负数同样精确取模。
