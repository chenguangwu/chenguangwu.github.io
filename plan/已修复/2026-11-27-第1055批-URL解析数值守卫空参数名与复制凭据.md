## URL 解析器

### 1. 移除 URL 文本的数值关键字守卫

- `parseUrl()` 的空输入、成功结果、失败提示三处不再对 HTML 文本扫描 `Infinity` / `NaN`；URL 路径、查询参数、片段中的这些词是合法文本，结果照常渲染。
- `renderParams()` 与历史渲染同一口径清理守卫；非法 URL 仍走 `URL` 构造异常分支，显示正确错误提示。

### 2. 参数名为空但值非空的构建行保留

- `buildUrl()` 仅跳过 `key === '' && value === ''` 的完全空白占位行；参数名留空、值非空时通过 `URLSearchParams.append('', value)` 生成 `?=值`，不再静默丢值。

### 3. 解析字段与复制口径一致、凭据默认排除

- 解析结果新增并显示 `用户名`、`密码`、`源(Origin)`；结果字段标签按当前语言输出英文/中文，空值统一显示 `—`。
- 新增 `optIncludeCreds` 复选框（默认未勾选）：复制 JSON 默认删除 `username` / `password`，保留 `origin` 及查询参数，并提示“已省略用户名/密码”；勾选后才包含凭据。
- 复制内容与页面展示字段对齐，不再出现“页面有、复制没有”的静默缺字段。
