# FE-N8 降号/升号根音无效 + 未知后缀静默降级大三和弦

- 页面：`tools/music/chord-notes.html`
- 严重度：中
- 修复日期：2026-11-07
- 状态：已修复（待复核）

## 失败点（原缺陷）
1. **合法降号/升号根音被判无效**：`NOTE_ALIASES` 仅含 `Db/Eb/Gb/Ab/Bb`，缺 `Cb/Fb/E#/B#`；`parseChord` 用 `NOTE_NAMES.indexOf(root)` 判定根音索引，缺失别名导致其返回 `-1` → `parseChord` 直接 `return null`，`Cb`、`Fb`、`E#`、`B#` 等合法根音无结果。
2. **未知后缀静默降级为大三和弦**：`parseChord` 在未匹配任何和弦类型时，不报错直接回退 `[0,4,7]` 大三和弦；拼错或未支持的和弦（如 `Cfoo`、`Cxyz9`）被当作大三和弦安静输出。

## 根因
- 别名表覆盖不全（音乐理论里 `Cb=B`、`Fb=E`、`E#=F`、`B#=C` 是标准等音）。
- 降级分支缺少"未知后缀"与"无后缀默认大三"的区分，把两者混为一谈。

## 修复位点（行号基于修复前源码）
- `tools/music/chord-notes.html:474`：`NOTE_ALIASES` 补 `Cb:'B', Fb:'E', E#:'F', B#:'C'`。
- `tools/music/chord-notes.html:633-641`：降级逻辑改为
  ```js
  if (!matched) {
    if (suffix === '') {
      /* 仅空前缀（如 "C"）默认大三和弦 */
      matched = { type: '', intervals: [0, 4, 7], name: '大三和弦' };
    } else {
      /* 未知后缀不再静默降级为大三和弦，直接返回无结果（FE-N8 修复） */
      return null;
    }
  }
  ```
