## 根因与修复

### 371 font-pairing：导出 CSS 与预览均为裸拉丁栈
- 原 CSS 输出两张模板（selectPair / applyFav）为 `font-family: '字体', sans-serif;`，无中文回退；卡片预览同样裸栈，输入中文时各自回退系统默认，中英观感不一致。
- 修复：新增 `CJK_FALLBACKS`（Noto Sans SC / PingFang SC / Microsoft YaHei / sans-serif）与 `cjkStack(family)`；两处 CSS 输出与卡片标题/正文预览统一改用双栈；FAQ 文案改为说明已内置双栈，并同步 EN 映射（键与值一致）。页面已有「中文标题 + 正文对比」预设，用户可一键查看中文效果。

### 370 font-preview：仅 FAQ 提示平台差异，无实际对比能力
- 原只有一句风险提示，未标明当前平台、未展示回退链、无缺失时预览、无平台可用性表。
- 修复：新增平台信息区 `fpPlatformBox`（UA 检测 Windows/macOS/Android/iOS/Unknown，双语）；内置主流系统常见预装字体可用性表（`FP_PLATFORM_TABLE` + `renderPlatform()`）；每张卡片新增 `fp-font-fallback` 行展示完整回退链；语言切换 `__fpOnLangChange` 同步重绘平台区。可用性表标注为「常见预装」参考口径，未预装时按回退链落 sans-serif/system-ui。
