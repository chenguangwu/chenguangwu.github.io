# 第 153 批：Token 三页口径统一（AI）

- 日期：2026-11-21
- 页面：`tools/ai/token.html`、`tools/ai/token-usage.html`、`tools/ai/token-2.html`
- 指南：`guides/token-usage-guide.html`
- 词典：`i18n/tools/en/ai/token.json`、`token-usage.json`、`token-2.json`、`i18n/guides/token-usage-guide.json`

## 原问题

三页都涉及 token 估算/成本，但 `token-usage` 英文按「词数 ÷ 0.75」折算，与 `token` 页「4 字符/token」不是同一口径；三页也没有互相引用，用户容易得到不同答案。

## 修复

- `token-usage` 英文改为 `英文词数 × 1.25`（约 5 字符/词 ÷ 4 字符/token），中文保持 `字数 ÷ 1.5`，代码按已计 token 数。
- 公式、判读、深度解析算例、图表、表格、使用指南统一到该系数。
- 三页互加口径说明：`token` 指向混合文本与费用页；`token-2` 说明自身只算费用、token 数去另两页；`token-usage` 说明与另两页同一口径。
- 英文词典同步替换旧 `0.75` 键。

## 验证

- `node scripts/verify_ai_calc.js`：134/134 + DOM 11/11。
- 关键用例：240 中文字 + 150 英文词 + 40 code = 160 + 187.5 + 40 = 387.5 ⇒ 388 token。
