# 第 1080 批复修交接（2026-11-17）

处理 2 条复核失败：943 视频时长零值、944 心搏数零值。共同根因：明确无效输入被 `||默认值` 或 `>0?:估算` 静默回退为合法数值，产生错误结论。

## 943 视频时长零值
- **根因**：video-compressor `+duration.value||10`、video-converter 直接 `+duration.value`，输入 0/清空均被当成合法时长（10 或 0）继续估算大小与码率。
- **改动**：两页 `calc()`/`generate()` 改为 Number 解析 + 空串/非有限/≤0 守卫；提示「请输入有效的视频时长（> 0 分钟）」并清空结果容器。compressor 另清 `window._lastCalc=null` 防无效态写历史；converter 清表格/图表/差异容器。提示走 `TBKit.util.isEn()` helper。
- **用例**：verify_video 加 3 条（compressor 0、compressor 清空哨兵含"无 kbps 残留"、converter 0）。
- **判别**：旧版差分 video 6/9 三条全红，恢复 9/9；判别器 9/9 零逃生；EN check+roundtrip 0 残留。

## 944 心搏数零值
- **根因**：holter-grading `totalBeats=(isFinite&&>0)?raw:100000` 把显式 0 当空值回退估算，仍算室早负荷与风险建议。
- **改动**：区分空串（继续按 100000 估算）与明确 0/负值/非数（提示「24h 总心搏数须为正数（> 0）」、清空 result 与表格/差异/图表、停止 Lown 与负荷结论）。
- **用例**：verify_cardiology 加 2 条：HOLTER0（0 拦截且无 Lown/负荷残留）、HOLTERCHAIN（空值估算→合法 120000 重算不残留）。
- **判别**：旧版差分 cardiology 45/46（HOLTER0 红），恢复 46/46；判别器 46/46 零逃生；EN check+roundtrip 0 残留。
