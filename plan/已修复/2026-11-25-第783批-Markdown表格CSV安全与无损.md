**任务来源**
- `plan/it/Markdown表格生成-CSV中文兼容性缺少处理.md`
- `plan/it/Markdown表格生成-CSV导出误删横线开头的数据.md`
- `plan/it/Markdown表格生成-CSV单元格缺少公式注入防护.md`
- `plan/it/Markdown表格生成-带引号单元格首尾空格丢失.md`

**工具** `tools/it/markdown-table-generator.html`

## 改动

### 1. CSV 解析与引号校验
- 新增 `parseCsvLine()`，返回单元格值与 `quoted` 标记及错误；未加引号字段仍去首尾空白，引号内空格原样保留。
- 未闭合双引号在表头或首行模板出现时，页面显示错误并清空输出，不再静默生成误导表格。
- `splitCsvRow()` / `parseRow()` 保留兼容入口。

### 2. 无损数据模型与空格
- `renderPreview()` 同时保存原始单元格模型 `lastTableModel` 与 Markdown 文本；CSV 导出优先使用模型，避免从 Markdown 反解析造成数据丢失。
- 引号内首尾空格在 Markdown 中以 `&nbsp;` 明示，并在页面提示；CSV 导出保留原始普通空格。
- `---item` 等以三个横线开头的数据不再被误当分隔行删除；仅删除表头后第二行的完整 `:?-{3,}:?` 分隔行。

### 3. CSV 安全与兼容
- 默认开启「中和表格公式（CSV）」：对 `=`、`+`、`-`、`@` 开头的非数值内容前置单引号，负数/正数/科学计数法保持数值；关闭开关则原样导出。
- 默认开启「Excel 兼容 BOM」：导出内容前置 UTF-8 BOM（U+FEFF），中文和逗号字段均加双引号，改善 Excel 双击打开中文乱码。
- 新增 `__mdTableCsvPayload()` 供导出与自检共用。

### 4. 文案
- 更新公式说明、增加 CSV 导出说明；同步英文第三层字典，覆盖新增复选框与说明。
