# 第983批：相关系数小样本解释限制

## 问题

`tools/science/correlation-calculator.html` 与 `tools/fun/stats-3.html` 在 n=2 时直接给出 r = ±1 和「强正/负相关」，没有提示小样本下 r 接近 ±1 是数学必然，不能推断总体相关或统计显著性。n=3 时同样可能给出 0.99 的强度结论。

## 修改

### `science/correlation-calculator.html`

- 保留原有 r、R²、强度、分步计算和数据明细。
- 当 `n < 4` 时在强度条后追加提示：

> ⚠ 样本量过小：n = N
> 只有 N 个数据点时，Pearson r 很容易接近 ±1（数据很少时，n=2 且两变量都有差异就必然为 ±1），不能据此推断总体相关强度或统计显著性。该结果仅用于演示计算过程；判断总体关系前请增加样本，并结合散点图与专业方法。

- n≥4 时不显示，保持原输出。

### `fun/stats-3.html`

- 在相关强度判定后追加同类提示：

> ⚠ 样本量仅 N 组：样本很少时（n=2 且掌长和身高都有差异，r 必然为 ±1）r 可能接近 ±1，不能代表总体相关或显著性，也不能说明因果；请增加样本后再判断。

## 真机验证

Chrome headless：

| 数据 | 科学相关系数 | 掌长-身高 |
|---|---|---|
| n=2（`1,2` / `3,4`） | r=1，显示「样本量过小：n = 2」 | r=1.0000，显示「样本量仅 2 组」 |
| n=3（`1,2,3` / `2,4,7`） | r=0.993，显示 n=3 提示 | r=0.9934，显示 n=3 提示 |
| n=5 完全线性 | r=1，不显示提示 | r=1.0000，不显示提示 |
| X 全部相同 | 「X 的方差为 0…无定义」 | 「数据无变异，无法计算相关系数」 |

两页无 `pageerror`。
