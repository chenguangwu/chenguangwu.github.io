## 一、逐条修复

### 1. 停车配比：无障碍分配说明与实际数量不符（`tools/urban/parking-ratio.html`）
- 无障碍车位明确为总车位内子集，不另加总数。
- 新增实际拆分：`accFromRegular = min(accessible, regular)`、`accFromVisitor = max(0, accessible - accFromRegular)`；文案输出“全部从常规 / 全部从访客 / 常规 X + 访客 Y”。
- 0% 输入仍按 `max(1, ceil(total × 0%)) = 1`，公式说明同步标注“输入 0% 仍至少 1 个”。
- 结果表增加“无障碍归属”来源，复制结果同步。

### 2. 停车配比：公园指标单位缺失导致千倍误差（同页）
- 单位下拉改为按类型动态生成：住宅/酒店/学校/文体=`unit`；办公/商业/医院=`100m2`；公园=`1000m2`。
- 新增 `UNITS_BY_TYPE`、`unitInfo`、`unitLabelFor`、`populateUnits()`；公园默认指标与分母统一为每 1000 m²。
- 实测公园 1000 m²、指标 0.025 → 25 个车位；不再出现 2.5 或千倍误差。

### 3. 停车配比：城市变化不更新指标及单位文案（同页）
- 新增 `onCityChange()`：未手动修改指标时随城市更新默认值，已手动修改则保留。
- `markRatioDirty()` 保护自定义值；`onTypeChange()` 重置 `ratioDirty`、单位、默认指标与面积标签。
- 初始化改为 `onTypeChange()`，住宅默认面积 500。

### 4. 用地平衡：负数与空值导致错误结论（`tools/urban/land-use.html`）
- 重写 `calc()`：人口空/非正/非有限 → `fail()` 清空统计、表格、结果、复制状态，提示“未完成校核”；面积空 → 提示“未填写”；负数/非数 → 拒绝；显式 0 合法。
- 新增 `clearOutputs()`；`total <= 0` 时比例显示 `—`，不输出 100%，不输出达标，`_lastResult=null`。
- 人均用地分“偏低/达标/偏高”三态，不再把低于下限统一写成“超标”；`allOk=okPerCap && issues.length===0`。
- 复制增加 `perStatus`，去掉重复“人均用地”行；英文结果与复制分支同步。

### 5. 人口密度：未完成校核复制成超标（`tools/urban/population-density.html`）
- 密度模式：居住用地留空/0 视为 `resAreaMissing`，净密度显示“未填写”，`resCheck=未完成校核`，bars 跳过 `NaN`；复制按 `r.complete` 输出“未完成校核（缺少居住用地面积）”，不再复制成“超标”。
- 居住用地负值/非数、面积大于总用地 → `fail` 清空。
- 容量模式重写 `calcCapacity()`：新增 `failCap()`；空值、负值、非有限、人均 >1000、占比 >100%、净密度 >10000 全部拒绝并清空；`capFinal <= 0` 拒绝；bars 跳过非法；英文分支同步。

### 6. 绿地率：缺人口时仍输出达标判断（`tools/urban/green-ratio.html`）
- 新增自定义下限输入 `inMinGreen`、`inMinPerCap`；留空用类型默认，非法拒绝。
- 重写 `calc()`：类型要求人均指标且人口空 → `incomplete=true`，`resCheck=部分未完成`，结果“人均指标未完成校核”；不输出人均达标/不达标。
- 人口非正/非数 → `fail`；`resPerCap` 缺失显示 `--`；结果/复制按 `statusText` 输出“绿地率达标；人均指标未完成校核”，复制不再写“不达标”。
- 标准说明改为“默认参照 GB50180-2018 等，存在自定义下限，指标按当地标准调整，本工具为估算不作审批依据”。
- `_lastResult` 含 `statusText/incomplete/popMissing/minGreen/minPerCap/stdName`；重置清空自定义下限。

### 7. 建筑限高：无效输入保留旧计算（`tools/urban/building-height.html`）
- `calcSun()` 新增 `failSun()`：`D<=0`、`floorH<=0`、纬度/系数非法时清空 `resH/resFloor/resExtra`、示意与结果，`_lastResult=null`；负层高不再通过 `!floorH`。
- 航空模式 `fail` 消息与结果改为简化模型：`可用高度 = 限制面标高 − 地面标高`；“可行/禁建”改为“简化模型：有可用高度 / 无可用高度”，并明确须核实净空面、坐标、跑道基准与地方规定，不构成审批结论。
- 楼层模式负层高/非法参数继续拒绝并清空。

### 8. 日照间距：边界与模型适用性（`tools/urban/calc-spacing.html`）
- 目标时长 0：单独返回 0 m 与“零日照要求、无需留间距”，并声明非合规结论。
- 目标等于当日理论日长：边缘高度角接近 0 时显示“不可形成有限间距”，并提示调整目标或采用专业分析；极昼按午夜太阳高度算有限间距，极夜正目标不可实现。
- 模型说明补全：正午对称、正南朝向、地面目标点、单一建筑高度、无其他遮挡；北向投影只适用于南向立面，窗台高度/朝向/地形/相邻建筑需另行修正，不构成法定日照合规结论。
