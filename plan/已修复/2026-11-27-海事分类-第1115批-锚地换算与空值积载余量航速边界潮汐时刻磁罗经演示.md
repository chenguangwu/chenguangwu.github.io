## 一、锚地单船面积平方公里换算

- 单船面积换算由 `/10000` 改为 `/1000000`，并保留 6 位小数。
- 1,000,000 m² 现在显示 1 km²，不再错误放大为 100 km²。
- 真机：200 m 船长、20 m 水深、5 倍出链、50 m 余量 → 单船面积 384,845 m²（0.384845 km²），不再是 38.4845 km²。

## 二、锚地缺失输入仍给安全结论

- 逐项区分空值、负数/非有限值与合法零值；空值或负值只给「请补全有效参数，当前不出容量或安全建议」，不输出任何容量。
- 船长、水深、出链系数必须大于 0；安全余量允许 0；锚地面积允许 0（容量 0）。
- 圆形模式容量明确标为「理论可容船舶数（理想上限）」，说明未计锚地边界、形状与锚位间距，实际锚位须现场核验。
- 元描述、页面简介、公式、深解析、指南同步去除「可安全容纳」表述。
- 真机：清空船长 → 只提示；水深 -1 → 提示负值且不再重复「须大于0」；1 km² 正常输出 2 艘理论值。

## 三、积载计算把载重吨全部当作货物余量

- 新增「本航次其他载荷（吨）」，货物载重余量 = 总载重吨 − 其他载荷；其他载荷为负或超过 DWT 时报错。
- 载重利用率、载重限制最大装载均改用货物载重余量；结果同时显示 DWT、其他载荷与货物载重余量。
- SF 分类改为「经验分类（偏沉/偏泡）」，限制类型由实际舱容上限与货物载重余量取小值判断，不再仅凭 SF 阈值下结论。
- 结果补充未计平舱损耗、亏舱、稳性、强度、吃水与吃水差限制，实际配载须专业核算。
- 真机：DWT 10000、其他载荷 2000、6000 t 货、SF 1.5、舱容 9000 m³ → 货物载重余量 8000 t、载重利用率 75%、舱容限制 6000 t、舱容受限、最大 6000 t。

## 四、航速航程零值与时间格式边界

- 分离空值、负值、分母为零三类校验：求航程允许 0 航速/0 时间；求时间要求航速 >0、航程 ≥0；求航速要求时间 >0、航程 ≥0。
- 空值不再按 0 计算；负值直接提示。
- 易读时间先四舍五入总分钟，再拆天/小时/分，59.6 分钟进位为 1 小时，不再出现「0小时 60分」。
- 真机：0 节 × 2 小时 → 0 海里合法；10 节 × 0.9933 小时 → 9.93 海里、易读「1小时」；10 节 + 0 航程 → 0 小时合法。

## 五、潮汐窗口推荐时刻与完整通航不一致

- 明确四个时刻：最早开始 = 窗口起点；最晚开始 = 窗口终点 − 通航时间；推荐开始 = 起点 +（窗口时长 − 通航时间）÷2；推荐完成 = 推荐开始 + 通航时间。
- 表格列改为「最早开始 / 推荐开始 / 推荐完成 / 最晚开始」，跨日时刻加「（+1天）」标识。
- 窗口等于通航时长时，推荐开始=最早开始、完成=窗口终点，间隔正好等于通航时间。
- 公式、FAQ 示例、深解析、指南同步。
- 真机：窗口 09:53–18:48（535 分钟）、通航 300 分钟 → 推荐 11:51 开始、16:51 完成，最早 09:53、最晚开始 13:48；跨午夜窗口 02:00–08:01 全部标（+1天）。

## 六、磁罗经示例系数生成自差表易误用

- 新增 A/B/C/D/E 五系数输入（默认 0.5/3/-1.2/1.8/-0.6），自差表按用户输入系数生成，不再把单个自差直接当 B 系数。
- 页面标题、按钮、元描述、简介、表格提示统一改为「教学演示/示例」，明确默认系数不可用于航行校正。
- 系数为空或非数值时提示并不生成；复制结果仍只含当前换算。
- 真机：B 清空 → 提示；A=0、B=2、C/D/E=0 → 000° 自差 0.0、015° 约 +0.5°E，表按系数变化。
