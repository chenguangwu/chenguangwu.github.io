## 修复内容

1. **斜杠转义可往返**：`unesc()` 的反转义默认分支除 `META` 外同时识别 `/`。开启“转义 /”并选 verbose 风味时，`a/b\c (v1)` → `a\/b\\c \(v1\)` → 原始文本，`\/` 不再残留。
2. **默认场景改为数字正则**：初始 `pattern` 从 HTML 中写死的两个反斜杠 `\\d+` 改为单反斜杠 `\d+`；“默认参数”预设同步改为 `\\d+`（JS 字符串求值后为 `\d+`），默认测试文本 `abc 123 ddd 456` 匹配 `123`、`456`，不会把字母 d 当数字。
3. **异步请求按通道失效**：`runRegexGuarded(payload, done, key)` 为 `test` / `replace` / `copy` 各维护递增版本号；旧 Worker 返回或超时时，版本已过期则直接丢弃，不再写入新输入的结果。清空正则、清空测试文本、`clearAll()` 均使在途请求失效。
4. **替换状态与错误分离**：新增 `replaceState`（`idle` / `pending` / `success` / `error`）与 `replaceResultText`；只有成功结果才允许复制/下载，处理中、语法错误、超时和空输入均禁用按钮。复制/下载直接使用保存的成功结果，不再读取可能含错误提示的输出区。
5. **历史记录默认不保存测试文本**：历史快照改为显式字段 `pattern`、`flags`、`replaceWith`、`testText`、`replaceText`；`testText` / `replaceText` 仅在用户勾选“历史记录保存测试文本（默认关闭）”后才写入。新增“清除历史记录”按钮，并说明历史仅存本机、CSV 导出范围。
6. **初始化健壮性**：`restoreSharedRegex()` 对缺失 `location.hash` 的环境做兜底，避免测试桩/嵌入环境在初始化时因 `hash.slice` 抛错。
