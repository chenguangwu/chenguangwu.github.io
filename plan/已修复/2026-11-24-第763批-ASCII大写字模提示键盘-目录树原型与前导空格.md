# 第763批修复记录（2026-11-24）

## 1. ASCII 大字：强制大写开关始终生效
- **问题**：`generate()` 先无条件 `toUpperCase()`，再读「强制大写」开关；取消勾选也完全无效，属于欺骗性控件。
- **修复**（`tools/it/ascii-art.html`）：确认内置三套字模仅有大写形态，移除无效的「强制大写」复选框；输入统一自动转大写并在标签、公式说明中写明「内置字模只有大写」。不再保留无法改变行为的开关。

## 2. ASCII 大字：不支持字符被静默渲染为空白
- **问题**：字模未收录的字符（中文、部分标点、emoji）回退到问号字形；字体连问号都没有时补等宽空白，用户看到/复制的图形与输入不对应且无任何提示。
- **修复**：
  - 生成时逐字符检测 `font[ch]`，收集不支持字符及 1-based 位置（去重、最多列 8 个）。
  - 新增 `#unsupportedNote`（`aria-live="polite"`），结果上方明确提示「不支持的字符：X（第 N 个字符）…；已用 ? 字形替代，复制前请确认」。
  - 字体无 `?` 字形时不再补空白，改用 `?` 组成的占位字形，保证可见、可察觉。
  - 覆盖中文、标点、emoji 与自动大写后的多字符输入。

## 3. ASCII 大字：样式选项不刷新、字体卡片不可键盘操作
- **问题**：彩色复选框没有绑定刷新事件，勾选后现有预览不变；字体卡片是仅支持点击的 `div`，键盘无法聚焦/选择，也没有选中态语义。
- **修复**：
  - 彩色复选框加 `onchange="generate()"`，切换立即重绘。
  - 字体卡片改为原生 `<button type="button" class="font-card" aria-pressed="…">`；CSS 重置按钮外观、固定宽度，并补 `:focus-visible` 3px outline。
  - `setFont(f)` 先校验字体名存在，再同步 `active` 与 `aria-pressed`；对测试桩缺失的 `dataset` 做回退读取 `data-font`。

## 4. ASCII 目录树：原型同名路径导致生成异常
- **问题**：节点用普通对象保存并以 `if(!node[p])` 判断，`constructor`、`toString`、`__proto__` 等合法目录名会命中 `Object.prototype` 继承属性：节点被误判为已存在，或访问继承值的 `_children` 时报错，子树丢失。
- **修复**（`tools/it/ascii-tree-generator.html`）：
  - 根树与所有 `_children` 改用 `Object.create(null)`。
  - 判存在改为 `Object.prototype.hasOwnProperty.call(parent, name)`，仅认自有节点。
  - `constructor/file.js`、`__proto__/x.txt` 等路径可正常建树、合并且不污染原型。

## 5. ASCII 目录树：路径行前导空格触发错误解析
- **问题**：旧实现只要任意一行以空白或树形字符开头就整份按缩进树解析；路径列表里某行偶然带前导空格（如 `  src/b.js`），斜杠路径会被当成单个节点名，父子关系全错但仍显示生成成功。
- **修复**：
  - 新增「输入格式」下拉：自动识别 / 路径列表 / 缩进树，用户可显式指定。
  - 自动识别收紧：仅当出现真正树形前缀（`│/|/├/└/``）或「存在缩进且整份输入不含 `/`」才按缩进树；否则按路径列表。
  - 路径模式按行 `trim()`，单行前导空格不再改变整份解析；缩进模式保留行首空白与连接符，按最小非零缩进推断层级。
  - 结果摘要区分「行缩进树输入 / 个路径」，说明区同步两种模式与自动识别规则。
