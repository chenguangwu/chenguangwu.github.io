# 2026-11-24 第731A批：图片尺寸校验、BMP 过滤、下载命名与拼图网格五项

## 修复清单

1. **图片缩放：小数尺寸不再被静默取整** (`tools/image/image-resize.html`)
   - `validateTargetSize` 增加整数校验：宽高为小数时判无效，提示实际取整结果（100.4×200 → 建议 100×200），不再 `Math.round` 后照常导出；合法整数尺寸返回值不再二次取整。
   - `onSizeInput` 去掉 `parseInt` 预截断：小数原样交给校验函数；锁定宽高比时只有整数基准才联动对边，避免把 100.9 静默写成 100 再算出对边。
   - 尺寸标签补充「仅支持 1–10000 的整数」。

2. **图片缩放：BMP 提示与文件选择器一致** (`tools/image/image-resize.html`)
   - 上传区文案已写「支持 PNG / JPEG / WebP / GIF / BMP」，但 `accept` 只列 4 种格式。现补 `image/bmp,.bmp`，选择器不再默认隐藏 BMP；拖放校验本就按 `image/*` 放行，两条入口口径一致。

3. **图片转换：最长边不再 parseInt 静默截断** (`tools/image/image-converter.html`)
   - 新增 `resolveMaxSide`：留空或 0 = 保持原尺寸（与标签一致）；负数、小数、>10000、非数字逐类返回明确错误，不再 `Math.min(10000)` 静默夹取。
   - 非法时清空预览并停止转换，输入框置 `aria-invalid`，新增 `#convMaxSideError` 行内提示。
   - `#result` 新增 `#convOutSize`，每次转换展示实际输出尺寸与原始尺寸，便于核对最长边是否真的生效。

4. **图片转换：下载文件名保留来源与参数** (`tools/image/image-converter.html`)
   - 新增 `makeDownloadName`：沿用清洗后的原文件名（去路径、去已知图片扩展名、去非法字符、长度 40 上限、空名回落 `image`），附加实际输出尺寸；有损格式再附 `-q质量`。
   - 例：`照片 a.png` → `照片_a-800x600-q85.webp`；`a/b:c*?.jpg` → `bc-100x100.png`；空名 → `image-10x10.jpg`。三类格式与回落扩展名继续跟随 blob 实际 MIME。

5. **图片拼图：自定义行列必须是 1–20 整数** (`tools/image/image-collage.html`)
   - 新增 `resolveGridSize` / `resolveGridAxis`：空值、非数字、小数、越界分别提示并判无效，替代 `clamp(+value||1,1,20)` 的静默修正（2.5 列会让 `Math.floor(idx/cols)` 排不出完整网格）。
   - 非法时不绘制、隐藏上一份预览并在结果区显示错误，行列输入置 `aria-invalid`；`download()` 同样拦截，避免导出陈旧画布。
   - `CollageTool.gridSize` 暴露纯函数供验证。
