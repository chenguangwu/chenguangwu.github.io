## 一、缺陷：`asin` 无法区分 θ 与 180°−θ

```js
const sinT=mC/(mA*mB);
const ang=Math.asin(Math.max(-1,Math.min(1,sinT)))*180/Math.PI;
```

`sinθ` 在 90°–180° 单调下降，`asin` 值域只有 0–90°，所有点积为负的钝角都被镜像成锐角；反向共线（θ=180°）更被算成 0°，与 FAQ `:213` 自述「夹角为 0° 或 180°」直接矛盾。

| A | B | A·B | \|A×B\| | 修复前 | 修复后 |
|---|---|---|---|---|---|
| (1,0,0) | (−1,1,0) | −1 | 1 | **45°** | **135°** |
| (1,0,0) | (−1,0,0) | −1 | 0 | **0°** | **180°** |
| (1,0,0) | (0,1,0) | 0 | 1 | 90° | 90°（护栏） |
| (1,1,0) | (1,0,0) | 1 | 1 | 45° | 45°（护栏） |
| (1,2,3) | (4,5,6) | 32 | √54 | 12.933° | 12.933°（默认态） |

**修复**（清单给定方案）：

```js
const sinT=mC/(mA*mB);
const dot=A[0]*B[0]+A[1]*B[1]+A[2]*B[2];
/* IT-N471：asin 只返回 0–90°，钝角会被镜像成 180°−θ；atan2(|A×B|, A·B) 给 0–180°，
   mC=0 时按 A·B 符号自然得 0°（同向）或 180°（反向）。 */
const ang=Math.atan2(mC,dot)*180/Math.PI;
```

`atan2(0, dot<0)` 自然给 π，无需为共线单列分支；`mA*mB≈0` 时原本就不输出角度行，零向量不会得到假的 0°。

### 关键设计选择：输出文本形态逐字不变

既有 `scripts/verify_it_calc.js:9390` 的自动补强用例锚定整段

```
"||B|) = 0 → θ = 0° A × B = 0，说明 A 与 B 平行（或其中之一为零向量）"
```
