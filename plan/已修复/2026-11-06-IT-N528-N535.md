## 一、本批真实修复（8 条，全部改源）

### IT-N528 · kubernetes-yaml-generator 端口 / 名称 / 镜像不校验（中）
- 根因：`Math.floor(num('port'))||80` 只兜底 0/NaN，70000 与 -1 原样写入 `containerPort` / Service `port`；`name` 仅 `trim()`，大写 / 空格 / `: ` 拼进 YAML 后 `kubectl apply` 必拒；`image` 同样原样拼接。
- 修复（`tools/it/kubernetes-yaml-generator.html:calcTool()`）：生成 YAML 前统一校验，任一不合法即在 `#result` 显示双语错误提示并 **return，不再输出清单**：
  - `name`：`/^[a-z0-9]([-a-z0-9]*[a-z0-9])?$/` 且 ≤63 字符（DNS-1123 label）；
  - `port`：`isFinite` 且 1–65535；
  - `image`：不含空白、引号、`: `（会破坏 YAML 标量的形态）。
- 中文态合法路径输出与改前逐字一致（既有 `api/redis:7-alpine/6379/3` 补强用例未改写即通过）。
- 证据：新增 3 条 verify 用例（`Bad_Name` / `70000` / `my image:1`），回退后 3/3 转红。

### IT-N529 · NATO 反查 `X-ray` 返回 `?`（中）
- 根因：反查先把词 `replace(/[^a-z]/g,'')` 成 `xray`，而 `REV` 只注册了 `x-ray` 键 ⇒ 唯一带连字符的码词永远反解失败。
- 修复：构造 `REV` 时同时注册 `w` 与 `w.replace(/[^a-z]/g,'')` 两个键；`X-ray` → `X`。
- 证据：新增用例 `checks:["from"]` + `input:"X-ray"` 断言结果区明细 `X-ray → X`（明细为本次新增输出，回退后不存在）。

### IT-N530 · NATO 字母数与音标词数算错（中）
- 根因：正向用 `raw.replace(/\s/g,'').length` 把标点 / 数字 / 汉字都算「字母」；反向用 `letters.length` 把未解析的 `?` 也计入。
- 修复：正向只数 `/[A-Z]/` 字母；反向只数 `!=='?'` 的成功项。`Hi! 123` 由 6 改 2、`Alpha Zzz` 由 2 改 1。
- 证据：新增 2 条 verify 用例，回退后 2/2 转红。

### IT-N531 · NATO 公式承诺的明细 / 数字读法未实现（中）
- 根因：`parts` / `all` 构造后从未渲染，结果区只有计数；数字原样保留，与「3 读作 Tree、9 读作 Niner」的承诺（含同页 FAQ）不符。
- 修复：
  - 新增 `NATO_DIGITS`（`0=Zero, 1=One, 2=Two, 3=Tree, 4=Fower, 5=Fife, 6=Six, 7=Seven, 8=Eight, 9=Niner`），正向复制框与明细都按专用读法转换；
  - 结果区渲染「字母=音标词 / 数字=读法」明细（正向）与「原词 → 字母」明细（反向）；
  - 标点 / CJK 仍原样透传到复制框（保留既有 `😀` 代理对回归用例），但 `formula-eq` 改为**如实说明**「不计入字母数、不参与音标转换」，不再含糊承诺；「数字」条目改为明确列出工具已实现的读法；两处文案 EN map 键同步。
- 证据：新增 2 条用例（`S3` → `S=Sierra 3=Tree` 明细、`Sierra Tree` 复制框）+ **同批改写 1 条漂移的自动补强用例**（原锚 `1 2 3 / 已转换 3 个字母` → `One Two Tree`，铁律①）。
- 兼容性：主用例 `AB → Alpha Bravo`、代理对 `😀 → LEN=2` 均未改写即通过。

### IT-N532 · emoji-cheatsheet 重复条目重复计数（中）
- 根因：`EMOJIS` 表有 8 组完全 / 近似重复条目，`ec_groups()` 按条目累加、搜索结果「共 N 个 emoji」也按条目，柱状图与总数重复计数。
- 修复：删除第二次出现的 8 行（🤩 / 😎 / 🥳 / 🤓 / 🍺 / ❌ / ☔ / ❇️ 各 1 行），保留首现条目；`EMOJIS` 由 551 条降为 543 条，分类统计与搜索计数自动一致。
- 证据：新增用例 `search:"🍺"` 断言「共 1 个 emoji」（修复前 2 个、默认空搜索 543 个，均不命中）。

### IT-N533 · java-cheatsheet 4 处 `--` 非法注释（中）
- 根因：Java 无 `--` 行注释，`--` 被解析为递减运算符；示例 `:341 / :405 / :445(两处) / :509` 复制后编译失败。
- 修复：4 处 `  -- ` → `  // `；同时**补 4 条 EN map 键**（这 4 个 example 原页面英文态漏中文，属顺带修复）。
- 校验：改后 `java-cheatsheet.html` 中 `  -- ` 残留 0 处。

### IT-N534 · nginx-cheatsheet 3 处 `--` 非法注释（中）
- 根因：nginx 注释符是 `#`，`:445 / :469 / :541` 的 `-- 注解` 会被当作未知指令 / 非法参数，`nginx -t` 失败。
- 修复：3 处 `  -- ` → `  # `；同步 EN map 的 3 个 example 整句键与英文值。

### IT-N535 · nginx `if ($https = off)` 永不成立（中）
- 根因：nginx 的 `$https` 只有 `on` 或空值，`= off` 恒假，HTTP→HTTPS 跳转永不触发，与同页 `ssl_redirect` 条目的 server 块写法自相矛盾。
- 修复：改为 `if ($scheme = http) { return 301 https://$host$request_uri; }`，与同页 `ssl_redirect` 的 listen 80 无条件跳转语义一致。
