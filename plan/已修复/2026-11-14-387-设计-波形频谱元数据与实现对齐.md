`_build.py` 用 `i18n/tools/design.json` 的 `zh-CN.intro` 覆写 `name="description"` / `og:description` / `twitter:description` / JSON-LD 的 `description`（`seo_desc = _zh_desc_raw[:120]`）。因此直接改 JSON 源，再 `_build.py` 重建，四处自动同步：

| 页面 | 旧 intro（虚假） | 新 intro（82 / 83 字符） |
|---|---|---|
| waveform | 在线波形可视化工具，将音频或信号数据绘制为时域波形图，支持上传文件与实时渲染、缩放查看… | 参数化波形可视化工具：按正弦/方波/三角波/锯齿波/混合波公式逐点计算并绘制时域波形，可调频率、振幅与相位，适合波形外观演示与教学示意，纯前端处理，不读取音频文件。 |
| spectrum | 在线频谱可视化工具，基于 Web Audio API 将音频实时绘制为频域频谱图，支持 FFT 分析与峰值查看… | 模拟频谱柱形动画生成器：按正弦叠加公式合成幅值并绘制频域柱形动画，可调条数、柱状样式与配色，适合视觉演示与版式参考，不接入麦克风、不读取音频文件、不执行真实 FFT。 |

### 2. waveform 引据表两行改写

| 行 | 旧 | 新 |
|---|---|---|
| 幅度归一化 | 采样值映射到 −1..1 后乘画布半高 / 出处 Web Audio API specification | `y = 中线 − 振幅 × 画布半高 × f(x)`，f(x) 为所选波形归一化函数 / 出处「函数图像绘制通则」 |
