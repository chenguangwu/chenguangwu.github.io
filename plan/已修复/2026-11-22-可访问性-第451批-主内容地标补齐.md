# 第 451 批：主内容地标补齐

- 日期：2026-11-22
- 类别：可访问性 / 语义结构
- 状态：已修复并提交

## 一、问题

全站仍有 42 个工具页和 2 个核心页缺少 `main` 地标：

- 32 个自绘测试/工具页以 `.container` 作主内容容器，但没有 `role="main"`；
- `search.html`、`chains.html` 同样缺少主地标；
- 其余 10 个工具页使用无 `.container` 的自定义布局，暂不适用同一规则。

屏幕阅读器无法通过“跳到主内容”绕过导航。

## 二、修复

在 `_build.py` 新增 `_ensure_main_role(src)`：

- 整页既无 `<main>` 也无 `role="main"` 时，给首个 `class` 含 `container` 的 `<div>` 补 `role="main"`；
- 已有 `<main>`/`role="main"`/其他 `role` 的标签不动；
- 不改变 DOM 层级与 CSS 选择器，只增加 ARIA 地标。

`search.html`、`chains.html` 直接给主容器补 `role="main"`。

## 三、验证

- 工具页缺 `main` 地标：**42 → 10**（剩余 10 个为无 `.container` 的自定义布局）；
- `search.html` / `chains.html`：已补；
- 单页多个 `role="main"`：**0**；
- 连续两次构建 diff 统计一致（幂等）；
- `_test_static.py`：**4,626 passed / 0 failed / 0 warnings**；
- 构建 exit 0。
