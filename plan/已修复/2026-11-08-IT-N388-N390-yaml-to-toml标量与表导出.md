## 一、缺陷与修复

### IT-N388 YAML 流式序列 `[a, b, c]` 未解析，整串变成字符串（高）
- 失败点：`yScalar` 只认引号串/布尔/null/整数/小数，没有 `[` / `{` 分支 ⇒ `arr: [a, b, c]` 输出 `arr = "[a, b, c]"`。参考表里给的示例（`[a, b, c]` → `arr = ["a", "b", "c"]`）与实际行为相反。
- 根因：值解析是「一串正则 if」，缺容器类型；也没有「顶层分隔」概念。
- 修复位点：新增 `ySplitTop(s, sep)`（:231，引号/转义/`[]{}` 深度感知的顶层逗号切分），`yScalar`（:257）新增 `[...]` → 数组、`{a: 1}` → 对象（递归）。
- 证据：`arr: [a, b, c]` → `arr = ["a", "b", "c"]`；`p: {x: 1, y: 2}` → `[p]` 表。

### IT-N389 行内注释未剥离，注释被写进值（中）
- 失败点：`yScalar` 对整段值求值，`port: 8080 # 端口` 的注释被当成值内容 ⇒ 值不再是纯数字 ⇒ 输出 `port = "8080 # 端口"`（字符串），数值语义丢失。
- 根因：解析器只跳过「整行以 # 开头」的注释，没有行内注释剥离。
- 修复位点：新增 `yStripComment(s)`（:215），按 YAML 规范「`#` 只在行首或空白之后才算注释」截断，且引号内不截断；`yScalar` 第一句即调用。
- 证据：`port: 9911 # 端口` → `port = 9911`（数值）；`note: "a # b"` 保留 `a # b`；`tag: a#b` 保留 `a#b`（`#` 前无空白，不是注释）。

### IT-N390 表数组元素内的子表缺父前缀，输出 `[meta]` 而非 `[items.meta]`（中）
- 失败点：`dumpTable` 处理 `[[k]]` 时递归调用没传 `prefix` ⇒ 元素内的嵌套对象被当成根级表，回读后 `meta` 与 `items` 彻底脱钩。
- 根因：prefix 只沿着「普通表」分支往下传，数组表分支漏传。
- 修复位点：prefix 改为**路径段数组**（`dumpTable(t, sort, prefix[])`），数组表分支 `prefix.concat([k])` 并把同一路径传给递归；新增 `tPathKeys(parts)`（:402）逐段 `tKey` 再拼 `.` —— 旧写法把整条前缀直接拼进 `[...]`，键里含点号/空格时会拼出非法表头。
- 证据：`items:\n  - name: a\n    meta:\n      x: 1` → `[[items]]` + `[items.meta]`；嵌套数组表 `cfg:\n  list:\n    - k: 1\n      sub:\n        deep: 2` → `[[cfg.list]]` + `[cfg.list.sub]`。

### IT-N391（yaml 侧）：无效的「缩进」下拉
- 失败点：页面提供「缩进：2 空格 / 4 空格 / Tab」，但 JS 里写的是 `'indent'==='tab'`（字面量比较，恒 false），算出的 `pad` 又从未被 `dumpToml` 使用 ⇒ 控件完全无效。
- 处置：TOML 本身没有缩进语义（缩进只为可读性，且本页输出是「表头 + 键值」平铺），故**移除该下拉**，同步删掉 `pad` 计算、`resetForm` 里的 `selectedIndex` 复位、以及 4 个预设里的 `indent` 键（含「Tab 缩进的嵌套表」改名为「嵌套表配置」）。
- 验证：jsdom 里 `document.getElementById('indent') === null`；`audit_verify_input_ids.js` 僵尸 id 0 条。

## 二、同批顺带修（审计中新发现，已补用例）

**根级「标量数组」被排到表头之后 ⇒ TOML 语义错位**：`dumpTable` 原本把「标量数组」放在第二个循环输出，若该数组键排在某个表之后（默认样例正是 `server` 在 `features` 之前），生成的
```
[server]
host = "0.0.0.0"
...
features = ["logging", "metrics"]
```
按 TOML 规范 `features` 会被解析成 `server.features`。与页面 `formula-desc` 里「TOML 要求表必须写在所有普通键之后」的说明直接矛盾。
- 修复：新增 `tIsTableArray(v)`（:395），第一个循环改为「输出所有非表数组的键值」，第二个循环只处理表数组与普通表；数组分支里原本会重复输出标量数组的 `else` 一并删除（否则同一键输出两次）。
- 证据：默认样例现在 `features = ["logging", "metrics"]` 出现在 `[server]` 之前；用例 `server…features…`（表在前、数组在后）锁定该顺序。

## 五、已知限制（未修，留待后续）

- **块状嵌套序列不支持**：`m:\n  - - 1\n    - 2` 这类「列表里再嵌列表」（块风格）会被解析成 `m = ["- 1"]` 并丢掉 `- 2`。流式写法 `m: [[1],[2]]` 正确。属 yaml 解析器的独立缺陷，本批未纳入（不在 N388~N391 范围），建议后续单独立项。
- **锚点/别名（`&`/`*`）、多文档（`---`）** 仍不支持，页面 `formula-desc` 已明示需先展开。
