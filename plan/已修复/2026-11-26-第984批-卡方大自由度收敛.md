# 第984批：卡方大自由度不再失败

## 问题

`tools/science/p-value-calculator.html` 与 `tools/science/chi-square-calculator.html` 的 `gammp()` 级数在 `x ≈ a` 且 `a` 很大时收敛极慢，固定 499 次迭代未收敛仍返回半成品结果：

- `χ² = 1,000,000, df = 1,000,000` 实测 `p = 0.739745`，正确值约 **0.4998**；
- 旧实现没有任何不收敛标记，仍照常输出显著性结论。

## 修改

### 两页共通

- `gammp()` 的级数分支与连分数分支、`gammq()` 的连分数分支都增加 `ok` 收敛标记；499 次内未收敛返回 `NaN`，不再返回半成品。
- 新增 `chiSquareNormalCDF(x,df)`：Wilson–Hilferty 变换

  \[
  z=\frac{(x/df)^{1/3}-(1-\frac{2}{9df})}{\sqrt{2/(9df)}},\qquad P(\chi^2\le x)\approx \Phi(z)
  \]

- `chiSquareCDF()` 在 `df ≥ 200` 时走该渐近展开；`df < 200` 仍用 `gammp(df/2,x/2)` 精确级数。该近似误差随 df 增大迅速减小。
- 计算结果若 `NaN` 或越界，输出「数值计算未收敛或结果无效，请降低自由度后重试，或改用统计软件复核」，不再给「拒绝/不拒绝 H₀」结论。

### 页面输出

- `p-value-calculator` 的 χ² 分支：`df ≥ 200` 直接使用 `1 - chiSquareNormalCDF`，并追加「大自由度说明」。
- `chi-square-calculator` 两种模式都在 `df ≥ 200` 时标注大自由度近似；CDF/p 值统一钳制在 `[0,1]`，避免浮点越界。
- 英文态同步（`Large-df note` / `did not converge...`）。
