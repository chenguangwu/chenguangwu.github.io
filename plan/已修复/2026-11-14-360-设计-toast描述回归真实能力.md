## 一、D-N129 toast-generator 描述承诺「位置/动画」配置，实际无控件也无输出（文案修复）

**问题**：toast-generator 的描述在多处承诺「配置文案、位置、图标与动画」「生成 HTML/CSS/JS 代码片段」，但页面只有类型/消息/圆角/背景色 4 个输入，实际只输出 CSS 样式（padding/radius/background/color/flex/shadow/icon）与实时预览，没有 `position`、没有 `transform/opacity`/`@keyframes`，也不生成 JS/HTML 片段。属「承诺 vs 实际」不一致，与第357批 D-N138/D-N139 同族。

**方案（按 D-N129 条目②）**：让描述回归真实能力（样式生成），不补伪功能。

**真源改动（4 处）**：
1. `i18n/tools/design.json`：`toast-generator.zh-CN.intro` 与 `en-US.intro` —— 去掉「位置、动画」与「HTML/CSS/JS 代码片段」，改为「类型、文案、圆角与背景色，生成对应的 CSS 样式代码与实时预览」。intro 不含后缀「纯前端运行…」（该后缀由构建模板统一追加到 meta，与既有模式一致）。
2. `i18n/tools/content_deepdive.json`：`design/toast-generator` 的 FAQ「位置怎么定？」答案 —— 由「用 fixed 定位到顶/底/角，配合 transform 做入出场动画」改为「本工具只生成 Toast 的样式（配色、圆角、图标），不输出定位或动画代码；把下方 CSS 套进你页面里已用 fixed 定位好的容器即可自定位置。」
3. `tools/design/toast-generator.html` 页内 `formula-desc`（行 146）—— 由「定位容器 + 图标 + 文案 + 进出场动画（translate / opacity）；按位置、图标与动画拼装 HTML / CSS / JS 片段」改为「图标 + 文案 + 配色 + 圆角；按类型拼装 CSS 样式片段，用于消息提示外观。」
4. `tools/design/toast-generator.html` 正文可见 intro 段落（行 148，`<p data-zh="…">en</p>`）—— 构建只注入 meta 标签、**不注入正文段落**，故该静态模板元素需手改；`data-zh` 与可见英文同步为新 intro。

**EN 字典同步**：`i18n/tools/en/design/toast-generator.json` 的 `map` 删除 3 个旧 key（intro/formula-desc/FAQ 答），新增 3 个新中文串 → 英文串映射，保证 EN 态不回退中文。格式 `ensure_ascii=False, indent=2`（与项目既有字典一致，差异最小）。
