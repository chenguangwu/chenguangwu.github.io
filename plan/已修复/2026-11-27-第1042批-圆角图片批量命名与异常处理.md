## 修复内容

1. **异步任务互相覆盖结果**
   - `rcRender` 每次递增 `rcRunSeq`，本轮 `outcomes/results` 只存在局部变量；旧任务在文件循环、图片 `onload`、最终提交处均校验 `runId`，过期结果直接丢弃。
   - `rcGenerating` 统一控制下载按钮；换图连续触发时只提交最后一次选择。
   - 实测先传 3000×2000、20ms 后换 400×300，最终结果只保留 1 张 400×300，不混入旧批次。

2. **同名输出冲突**
   - 新增 `rcOutputNames`：输出名使用 `原文件名-扩展名-rounded.png`（如 `photo-png-rounded.png` / `photo-jpg-rounded.png`），同名副本再追加 `-2`、`-3`。
   - 实测 `photo.png` 两份输出 `photo-png-rounded.png`、`photo-png-rounded-2.png`；`photo.png` + `photo.jpg` 输出名可区分原格式。

3. **英文简介缺少功能信息**
   - `i18n/tools/image-body.json` 英文 `intro` 改为完整说明：1–12 张 PNG/JPEG/WebP、百分比/固定像素、透明四角、批量下载、本地处理；`i18n/tools/image.json` 的 `en-US.intro/title/h1` 同步。
   - 英文第三层补充新预设、首段与按钮映射；英文态首段、预设、全部下载按钮均显示英文。
   - 页面 `description` / `og:description` / WebApplication 描述随构建更新为批量、透明 PNG 说明。

4. **批量处理静默跳过不支持文件**
   - `rcSupported` 同时看扩展名和 MIME，空 MIME 时按扩展名放行；不支持的文件进入 `outcomes` 的 `skip` 列表，明确显示“跳过：文件名 — 不支持 image/gif，仅支持 PNG/JPEG/WebP”。
   - 超过 12 张的部分同样逐项标为跳过，不再无声丢弃。
   - 实测 PNG + JPG + GIF：成功 2、跳过 1，状态栏与明细一致。

5. **文件名直接拼 HTML 属性**
   - `rcRenderResults` 全部改用 `document.createElement` / `textContent` 构建结果卡片；文件名只作为文本节点，输出名只写 `a.download`，不再拼 `innerHTML`。
   - 实测文件名 `evil"quote<img>.png`：原文件名按纯文本显示，结果区没有注入的 `<img>` 子节点；输出名安全替换为 `evil_quote_img_-png-rounded.png`。

6. **画布处理异常导致批次停住**
   - 每张图独立 `try/catch`：`rcMakeCanvas` 检查尺寸/上下文，`roundRect` 失败回退 `arcTo` 路径；`toDataURL` 异常被捕获并标记该张失败。
   - `finish` 保证每张只 resolve 一次，失败也继续下一张；最终显示“成功 0 / 跳过 0 / 失败 1”，下载按钮禁用，不再整批卡住。
   - 实测注入 `toDataURL` 抛错：批次正常结束，失败明细为“失败：test400x300.png — Error”。

7. **场景预设未作用于实际控件**
   - 新增原生 `#rcPresets`：头像正圆 50%、卡片 12px、柔和 20%、直角 0px；`rcApplyPreset` 直接设置真实 `#rcMode` / `#rcRadius` 后触发 `rcRender`。
   - 删除旧 `#generator_15Presets` 的 `cnt` 预设与未定义 `gen()` 调用；补 `gen()` 兼容别名，旧历史恢复/导出逻辑不再报错。
   - 移除无效的“预设”tab，避免通用 tab 脚本把新预设栏隐藏；预设栏默认可见。
   - 实测点击“头像正圆 50%”：mode=pct、radius=50，结果按 50% 重新生成；点击“柔和 20%”得到 pct/20。

8. **圆角值静默截断**
   - `rcValidateRadius` 对空值/非数字返回明确错误；百分比负数归 0、超过 50 归 50；像素负数归 0、超过 10000 归 10000；被夹取时回写输入框并在状态栏提示。
   - 逐图像素半径按该图短边一半限制，结果卡片显示实际 `r=…px`，状态栏提示“第 N 张图像短边限制，实际半径 …px（输入 …px）”，不再静默使用不同半径。
   - 实测百分比 80 → 输入回写 50、状态提示；-5 → 回写 0；像素 999 在 400×300 图上显示实际 150px 并提示。

9. **清空圆角后仍可下载旧结果**
   - `rcRender` 一开始即清空 `rcItems` 并禁用全部下载；空文件、空/非法圆角都清空结果区，状态明确“请填写有效的圆角值”，旧结果不可下载。
   - 实测生成后清空圆角：结果区 0 张、下载按钮 disabled。
