## 修复

`tools/it/regex-visualizer.html` 的 `buildStates()` 中，状态数 = token 数 + 2（start / accept），循环按 `states.length - 1` 生成边，最后一条边取 `tokens[i]` 越界，得到 `undefined`。

修复为：最后一条边（最后一个 token 状态 → accept）没有对应 token，标签用 `ε` 表示空转移。

```
const lab = (i < tokens.length ? escapeHtml(tokens[i]) : '') || 'ε';
```

复验：转移图末条边为 `10 --ε--> 11`，页面 `undefined` 0。
