# 第165批：calc-4 增加独立 html 根字号，收口 rem 口径

## 问题
`tools/it/calc-4.html` 的「基准字号」既当 em 的父字号，又当 rem 的根字号；rem 换算恒写死 `px / 16`。当用户把基准设为 18（预设标注「18px根」）时，18px 被算成 1.125rem，而真实根字号 18 时应为 1rem。页面公式也固化 `rem = px ÷ 16`，与「基准字号」语义冲突。

## 修改
- 新增 `#rootSize`（html 根字号，默认 16），em 用 `#baseSize`、rem 用 `#rootSize`，两者独立校验，任一非法即提示。
- 结果区同时展示「父级/基准字号」与「html 根字号」；两者不等时补一行说明各自分母。
- 复制结果附「基准 X px，根字号 Y px」；预设按钮与 `TBKit.preset` 同步写入 `rootSize`；`setBase()` 同步两个输入。
- 公式框更新为 `rem = px ÷ html 根字号（默认 16）`，并注明基准字号与根字号都必须大于 0。

## 验证
- 新增 `IT-CALC4-ROOT` 用例：`baseSize=16, rootSize=18, pxInput=18` ⇒ `1.125em / 1rem / html 根字号 18px`；默认根字号 16 时 rem 为 1.125，不命中。
- `node scripts/verify_it_calc.js it/calc-4`：5/5 通过（含原 C4GUARD 形态强锚）。
- `node scripts/check_inline_js_syntax.js`：12,102 段 0 错误。
