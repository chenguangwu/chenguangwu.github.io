# 第704批：提前还款空值、月数解析与负摊还/建议文案

## 修复项

`tools/finance/mortgage-prepayment.html`

### 1. 空提前还款额与月数截断

- 提前还款额改为先取原始字符串：空串不再 `|| 0`，主结果提示“请填写完整有效参数……本次不提前还款请显式填写 0”，不输出节省结论；显式 0 仍正常计算。
- 剩余月数从 `parseInt` 改为 `Number` 完整解析，要求 1–1200 的整数；`12.5`、`240.5` 被拒绝，`1e2` 按 100 处理，不再截成 1 或 12。
- 输入错误状态同步标记。

实测：清空提前还款 → 仅提示，无结果；填 0 → 正常出结果；12.5 → 提示整数；1e2 → 合同参考按 100 期计算。

### 2. 负摊还误判

原逻辑只要月供低于合同应还月供就提示“原方案将出现负摊还”。现分别判断：

- 月供 < 合同应还但 > 首期利息：提示“还款期延长，但仍偿还部分本金，不是负摊还”。
- 月供 ≤ 首期利息：提示负摊还，无法按此月供还清。

实测 10 万、6%、120 期、月供 1000：合同应还 1110.21，首期利息 500，提示“不是负摊还”；月供 400 或 500：进入负摊还/无法还清分支。

### 3. 建议文案固定结论与 1/3 最优时点

- 删除“前期还款大多在还利息”的固定说法，改为按当前输入显示下一期利息、本金及其占月供比例。
- 删除未经计算的“前 1/3 期限最划算”，改为“不能仅凭剩余期数判断；需结合已还期数、合同总期限、违约金、手续费与机会成本”。
- 补上建议区文字赋值（原先 `valTxt` 计算后未写入 DOM，建议区正文为空）。
- 策略行加“利率/期限不变且无违约金”的简化条件，并要求核对合同；提前还款额行改为“实际节省以结果表与合同为准”。
- 中英文同步；英文态提示无中文泄漏。

## 验证

- 月供 1000：建议区显示“下一期利息 500.00、本金 500.00、利息占月供 50.0%”，无“大多”“1/3”。
- 月供 400：本金 -1500，“负摊还”标记正确。
- 零利率：无负摊还误报；建议区正常显示。
- 无 `pageerror`。

## 规则

空值与合法 0 分开；负摊还只按“月供是否覆盖当期利息”判断，不用合同月供代替；建议文案只描述当前输入能算出的下一期，不替代合同与机会成本判断。
