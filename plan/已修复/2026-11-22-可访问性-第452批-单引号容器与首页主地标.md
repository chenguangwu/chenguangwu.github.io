# 第 452 批：单引号容器识别与首页主地标

- 日期：2026-11-22
- 类别：可访问性 / 语义结构
- 状态：已修复并提交

## 一、问题

第 451 批后仍有 10 个工具页缺 `main` 地标。原因不是没有容器，而是容器写成单引号：

`<div class='container'>`

`_CONTAINER_TAG_RE` 只匹配双引号 `class="..."`，漏识别。

同时首页 `index.html` 的 hero、分类、工具区等主要 section 没有 `main` 包裹，屏幕阅读器无法直达主内容（命令面板对话框应留在 main 外）。

## 二、修复

- `_CONTAINER_TAG_RE` 同时匹配单/双引号 `class`，10 个页面自动补 `role="main"`；
- 游戏页 `tools/fun/jimao-3a-game.html` 主容器为 `.jm-wrap`，直接补 `role="main"`；
- `index.html`：在 hero 前插入 `<main id="main-content">`，在最后一个内容 section 后、广告与命令面板前闭合，对话框保持在 main 外。

## 三、验证

- 工具页缺 `main` 地标：**10 → 0**；
- 4,606 个工具页均已有 `<main>` 或 `role="main"`；
- 首页 `<main>` / `</main>` 各 1，标签平衡；
- 剩余无 main 页面为 177 个 `noindex` 迁移存根、`sitemap.html`、`embed.html` 与 1 个独立游戏页，均非普通索引页；
- 连续两次构建 diff 统计一致（幂等）；
- `_test_static.py`：**4,626 passed / 0 failed / 0 warnings**；
- 构建 exit 0。

- 9 个单引号容器工具页 + `tools/fun/jimao-3a-game.html` 补主地标；
- `index.html` 增加 `<main id="main-content">` 包裹主内容；
