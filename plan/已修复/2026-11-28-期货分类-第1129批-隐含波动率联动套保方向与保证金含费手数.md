## 一、逐任务修复

### 1. 期权希腊字母：隐含波动率未随参数更新

- `calc()` 末尾在市价存在时调用 `calcIV()`；现价、行权价、利率、期限、股息或市价任一变化都会同步重算。
- 首次加载在 `DOMContentLoaded` 后显式执行一次 IV 计算，不再因结果容器尚未生成而静默失败。
- `calcIV()` 先校验容器与市价，再严格校验现价、行权价、利率、期限和股息；市价不合法或超出 `(0,500%]` 时清空旧 IV 并提示“参数无效，隐含波动率暂不计算”。
- 真机默认值 IV 15.06%，现价由 100 改为 90 后 IV 32.41%，无 JS 报错。

### 2. 期权希腊字母：相关推荐与用途不符

- 删除单词反转、字数统计、自动换行、词频、镜像文字五个无关推荐。
- 改为同目录的期权损益、期货保证金、对冲比例、期货定价四个工具，链接与中英文名称校验通过。

### 3. 期权损益：非法输入后旧曲线仍可见

- 行权价非正、权利金为负等非法输入时，除清空数值卡片外同时 `clearRect` 画布，并置 `__option_payoffOk=false` 阻止复制/导出。
- 真机验证：先有效出曲线，再改 `p=-1`，结果区与 canvas 均清空；恢复有效值后正常重绘。

### 4. 期权损益：权利金高于行权价仍显示负最大盈利

- 新增纯函数 `payoffSummary(type, side, K, p)`，统一生成 BEP、最大盈利/亏损与边界说明。
- `bep>0` 显示数值；`bep==0` 显示“0（仅 S=0 边界）”；`bep<0` 显示“不可达（需负价格）”。
- 看跌买方 `p>K`：显示“无正收益”，最大亏损 `¥p`，并提示 S=0 时最高损益为 `K-p`，任何 `S≥0` 都无法盈利。
- 看跌卖方 `p>K`：最大盈利 `p`，最大亏损“无”，提示 S=0 最低损益 `p-K`。
- 图表 BEP 仅在 `bep>0` 时绘制，绘制判断显式检查非 `null`。
- 真机 `put buy K100/p120`：显示“无正收益 / 不可达（需负价格）/ 最高损益 ¥-20.00”。

### 5. 期货套保：相关系数及合约输入缺少校验

- 全量校验 `rho∈[-1,1]`、`sigmaS>0`、`sigmaF>0`、`spotValue>0`、`futurePrice>0`、合约乘数为正整数；失败时清空统计卡、结果、图表与明细表并提示。
- 负相关 `h*<0`：所选方向可执行 0 手，单独给出反向手数，并提示“所选方向与最小方差方向相反，应反向持有期货”；不再把负手数当可执行空单。
- 统计卡拆为“最优对冲比例 h* / 理论风险降低 R² / 所选方向整数手数 / 整数手数实际覆盖”。
- 明细分开“理论覆盖率 h*”和“整数手数实际覆盖”，避免把正相关正例的 145.7% 理论覆盖与 114.0% 实际覆盖混为一谈。
- 真机 `rho=-0.85`：`h*=-0.7286`，所选方向 0 手；`rho=0.85`：`h*=1.4571`、理论 145.7%、1 手实际 114.0%。

### 6. 期货保证金：最大开仓未计手续费及手数校验

- 拆分核心参数与费率校验：保证金比例 `0–100%`、手续费 `≥0`、手数必须为非负整数。
- `cashPerLot = perLotMargin + fee`；`maxLots = floor(capital / cashPerLot)`。
- 空值或 0 手不再替换为最大手数，按未开仓处理；手数超过最大可开时拒绝并提示“最多可开 N 手；请减少手数或增加资金”。
- 明细新增“每手占用现金”“满仓后剩余资金”；公式箱同步改为含手续费口径，并注明估算不含交易所临时提高保证金、维持保证金、涨跌停与强平规则。
- 预设手数由 2 改为 1（20 万资金、每手占用 136,810 时最多 1 手）。
- 真机：1000 资金 / 每手保证金 1000 / 费 10 ⇒ 0 手；3800×300×12%、20 万、0 手、费 10 ⇒ 最多 1 手、每手占用 136,810、未开仓；1.5 手被拒绝。

### 7. 期货定价：套利方向判断与差额标签颠倒

- 实际期货价非有限或 `<0` 时拒绝，留空不做比较。
- `diff = actualFuture - futurePrice`，标签统一为“实际价 - 理论价”；
- `diff>0`：实际价高于理论价，可考虑卖期货买现货；`diff<0`：实际价低于理论价，可考虑买期货卖现货；`abs(diff)<0.005` 视为相等。
- 增加免责声明：未计手续费、冲击成本、资金占用、交割限制与基差风险，不构成套利可行性结论。
- 真机：理论价 5043.94；实际 5100 ⇒ 差额 +56.06、高于理论、卖期货买现货；实际 5000 ⇒ 差额 -43.94、方向相反。
