# 2026-11-14-404 指南 · 300 页 description 硬切残句收口

## 发现
- `guides/*.html` 中 **300 页** 的 `meta description / og:description / twitter:description / Article JSON-LD`
  停在半个词上，均无句末标点：
  - 「…用于产房新生儿初」
  - 「…适用于大样本或已知总体」
  - 「…用于抛物线轨迹、最值问题与函」
  - 「…用于水库调」
- 根因：各 `gen_*_guides.py` 按固定字数硬切摘要后直接写入 meta，之后没有构建期收口逻辑
  （`_build.py` 只处理工具页与 zh-tw 派生的短线描述）。

## 修复
- `_build.py` 新增 `_close_guide_desc()` + `normalize_guide_descriptions()`：
  - 缺句末标点时，截到最后一个 `，` / `；` / `：`（位置 ≥40 才截），并补「。」；
  - 同步 meta / og / twitter 与 JSON-LD `description`（JSON 走 `json.loads`/`json.dumps`，避免 HTML 实体污染）；
  - 跳过 `TOOLBOX-REDIRECT` 与 `noindex` 跳转页；已收口的页不再改写，幂等。
- 调用点放在 `generate_opencc_static_locales()` 之前，保证 zh-tw 派生页继承干净文案。
