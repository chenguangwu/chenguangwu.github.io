# 复核失败重做批次 · 申请再次复核

## IT-N549 名称生成器短长度时后缀选项失效

**失败点（原复核记录）**
- 页面：`tools/it/team-name-generator.html`
- 复现：领域「创意」、风格「古风」、最大长度 6、种子 x、数量 5，分别选择数字和符号后缀，结果均为 `Bamboo`, `Jade V`, `Bamboo`, `Crysta`, `Ink Ma`，没有任何所选后缀。多次重试仍超长后直接截断字符串，尾部后缀随之丢失。

**根因**
- `generate()` 把 base 与 suffix 拼接后再整体判 `name.length<=maxLen`，重试 16 次若始终超长，循环结束后 `name=name.slice(0,maxLen)` 是**整串截断**，后缀位于末尾被一起切掉 ⇒ 短 maxLen 时后缀消失。

**修复位点**
- `tools/it/team-name-generator.html` `generate()`：先独立生成 base（重试收敛到 ≤maxLen，超限则截断 base），再单独追加 suffix；若 `base+suffix` 仍超长，**仅截断 base 为 `maxLen-suffix.length`** 再拼接，保证 suffix 始终可见。

**验证证据**
- `env -u NODE_OPTIONS node scripts/verify_it_calc.js team-name-generator` 全绿（含新增探针）；既有 N549 种子/风格/后缀复现、最大长度截断用例均无回归。
- 新增回归探针：种子 `x`、古风、创意、maxLen 6、数字后缀、5 条 → 探针统计所有候选是否以「 两位数字」结尾，写 `TN549_SUFFIX=1`；按页面真实 mulberry32+词库复现得 `Jad 25 / Neo 19 / Moo 72 / Neo 28 / Cry 42`，全部带后缀。回退整串截断 ⇒ 候选为 `Jade W` 等无数字后缀 ⇒ 探针为 0。

**判别力实测**
- 探针 `TN549_SUFFIX=1` 由注入的短 maxLen+数字后缀触发，修复前整串截断丢失后缀 ⇒ 为 0；默认态（无种子、maxLen=24、随机）不命中该串 ⇒ 强判别、零逃生。回退源码后转红。
