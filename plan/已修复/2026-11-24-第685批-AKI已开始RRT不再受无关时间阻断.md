# 第685批：AKI 已开始 RRT 不再受无关时间输入阻断

## 原问题

`tools/nephrology/jixingshensunshang-kdigo-fenqi.html` 中，基线采血时间的非法校验位于 RRT 分支之外。选择“已开始 RRT”后，只要时间输入残留负数，就会提前返回“请输入有效的基线采血距当前时间”，无法输出本应独立成立的 AKI 3 期。

## 修复

把时间校验改为仅在非 RRT 路径执行：

```js
if(!rrt && hours!==null && (isNaN(hours)||hours<0)){ ... return; }
```

RRT 已开始时，基线/当前肌酐、体重、时间均不再阻断 3 期判定；这些无关字段也不会被标红。

## 验证

`scripts/verify_nephrology_calc.js` 新增用例：

- `rrt=yes`、肌酐/体重为空、`hours=-1` → `AKI 3 期` + `已开始肾脏替代治疗`。

真机 Chrome 四条路径：

| 场景 | 结果 |
|---|---|
| RRT=yes，时间 -1 | AKI 3 期，依据“已开始肾脏替代治疗（RRT），直接判为 3 期” |
| RRT=yes，时间空 | AKI 3 期 |
| RRT=no，时间 -1 | 正确提示时间非法 |
| RRT=no，400→400 μmol/L、24h | 无 AKI，稳定高值不误判 |

- `node scripts/verify_nephrology_calc.js`：**40/40**。
- `python3 _build.py`：通过，改动存活。
- 临床适用范围仍由专业人员确认。
