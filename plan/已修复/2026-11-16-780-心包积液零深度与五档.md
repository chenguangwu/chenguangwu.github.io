# 780 批：心包积液零/负深度守卫与五档深解（D-N100 / D-N101）

## D-N100（修复）
`calc()` 把深度读成 `parseFloat(...)||0`，0 mm 或负数都会按「微量（<10mm）」输出 50–100mL，
与「未见积液」的临床含义相反。改为：

- 空值：保留「请填写最大积液深度」提示；
- 0 mm：输出「未见心包积液（未检出液性暗区）」；
- 负数/非数值：输出「最大深度须为不小于 0 的数值（mm）」。

## D-N101（修复）
深解 JSON 原为三档（<10 / 10–20 / >20），示例称 14mm 为「中量」，与代码/表格的五档冲突。
统一为五档：<10 微量、10–20 少量、20–30 中量、30–40 大量、>40 极大量；
示例改为「14mm ⇒ 少量（100–500mL）、门诊随访」，FAQ 与 summary 同步。

## 验证
`node scripts/verify_cardiology_calc.js pericardial-effusion` ⇒ 5/5，新增：

- 0 mm ⇒「未见心包积液」；
- −5 mm ⇒「最大深度须为不小于 0 的数值」。

`python3 _build.py` + `python3 _test_static.py` ⇒ 4685/4685/0。
