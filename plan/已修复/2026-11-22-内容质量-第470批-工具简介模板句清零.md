# 第470批：工具简介模板句清零

日期：2026-11-22
分类：内容质量 / 工具简介

## 原问题

大量工具页「工具简介」首段由建站模板拼接而成，例如：

- 「XX计算器是一款农业种植领域的在线工具。农业种植工具，帮助计算种植参数与产量。」
- 「XX。专为开发者打造的在线工具，纯前端运行，代码不离开浏览器。」
- 「XX。科学研究工具，采用标准科学公式，计算精准。」

这类句子不含工具真实输入、计算口径与输出，只是行业套话；另有 34 页简介只有
工具名四个字（如「学习计划制定。」「阅读速度计算器。」）。指南页
`certificate-check-guide` 与 `guides/index.html` 摘要也复用了同一模板句。

## 修复

1. 以每页自身 `meta description` 为素材，剥掉「XX是一款免费的在线……工具，」
   / 「……领域的在线工具。」/「专为开发者打造」/「采用标准科学公式」等模板前缀，
   取真实功能说明作为简介；
2. 共改写 842 个工具页「工具简介」首段，并同步写入 `data-zh` 中文回退；
   34 个只有工具名的过短简介也按 meta 补成完整说明；
3. 指南 `certificate-check-guide` 的 meta / OG / Twitter / Article / 正文，
   以及 `guides/index.html` 对应条目均改为具体说明；
4. 构建刷新 `json/tools.json` 等索引后，132 个页面的「相关工具」卡片描述同步更新。

说明：构建的 SEO 描述策略会在 `description < 70` 时自动补「XX是一款免费的在线……
工具，」前缀，这是既有生成规则；本批只治理正文简介，未改该 SEO 策略。
