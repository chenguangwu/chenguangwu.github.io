# 第 432 批：修复 JSON-LD 描述被 HTML 实体二次转义

日期：2026-11-22
类型：SEO / 结构化数据
状态：已修复并本地提交（未 push）

## 一、原问题

全站 `WebApplication` JSON-LD 的 `description` 由页面 meta 描述经 `esc_html_py()` 生成，导致 HTML 实体被写进 JSON-LD 字符串。全站实测 **48 个页面**出现：

- `&quot;`：如 `作物轮作周期规划表…基于&quot;豆科 → 禾本科…&quot;循环原理`
- `&lt;` / `&gt;`：如 `Z&lt;0 表示低于均值`
- `&amp;`：如 `由变量名与 &amp;&amp;、||…组成的布尔表达式`

搜索引擎读取 JSON-LD 时看到的是字面实体，富结果/知识面板可能直接显示 `&quot;`、`&lt;` 等乱码；`it/meta-tags-generator.html` 的 `&amp;lt;head&amp;gt;` 更是二次转义。

## 二、修复内容

修改 `_build.py` 的 `WebApplication` JSON-LD 生成：

1. `description` 先 `html.unescape()` 还原实体，再用 `json.dumps(ensure_ascii=False)` 统一负责引号、反斜杠与控制字符转义；
2. `name` 同样改为 `json.dumps`，避免工具名中的 `&` 被写成 `&amp;`；
3. 不再对 JSON-LD 文本使用 HTML 转义函数。

页面 `<meta name="description">` / `og:description` 仍保持 HTML 实体转义，不受影响。
