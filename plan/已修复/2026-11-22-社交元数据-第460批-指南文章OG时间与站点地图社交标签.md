# 第 460 批：指南 Article 时间补进 OpenGraph + 站点地图社交标签

## 问题

### 1. 指南页缺 `article:published_time` / `article:modified_time`

3,247 个可索引指南的 Article JSON-LD 已有 `datePublished` / `dateModified`，但页面 `<head>` 里没有任何 OpenGraph article 时间字段。社交卡片、聚合器和部分内容平台会用这两项判断内容新鲜度。

### 2. `sitemap.html` 社交标签不完整

`sitemap.html` 是 `index,follow` 的公开页面，已有 `og:title` / `og:description`，但缺：

- `og:type`、`og:url`、`og:site_name`；
- `og:image` 及 width/height/alt；
- `twitter:card` / `twitter:title` / `twitter:description` / `twitter:image` / `twitter:image:alt`。

另外该页每次由模板重建，模板内没有 hreflang marker，导致每轮 `inject_core_hreflang()` 都要重新注入一次。

## 修复

### 指南文章时间

`_build.py` 新增 `ensure_guide_article_og()`，在 `sync_guide_article_ld()` 之后运行：

- 遍历 `guides/*.html`，跳过重定向/`noindex`；
- 从 Article JSON-LD 读取 `datePublished` / `dateModified`；
- 缺 `article:published_time` / `article:modified_time` 时，紧跟 `<meta property="og:type" content="article">` 插入；
- 纯日期补 `T00:00:00+08:00`，已是完整时间则原样保留；
- 已有字段不重复插入。

### 站点地图

- `generate_html_sitemap()` 模板补齐 `og:type` / `og:url` / `og:site_name` / `og:image` 三件套 / twitter 五件套；
- 模板生成后直接调用 `inject_hreflang()`，让 sitemap.html 自带 marker 和完整 alternate；
- 后续 `inject_core_hreflang()` 命中 marker 只做整块替换，不再每轮重建。

## 结果

- 构建输出：首次 `Guide article OG times: 3244 pages`，补齐带 `data-page-node-id` 的 3 页后共 3,247 页；二次构建 `0 pages`，幂等；
- 覆盖复核：3,247 个指南页 × 2 字段 = 6,494 个时间 meta，格式全部 `YYYY-MM-DDT00:00:00+08:00`，缺失 0，重复 0；
- `guides/index.html` 为列表页，无 Article，正常跳过；
- 其中 3 个指南的 `og:type` 带 `data-page-node-id` 额外属性，首轮精确字符串匹配漏掉，改为匹配 `<meta ... content="article"[^>]*>` 后补齐；
- `sitemap.html`：`og:type`、`og:url`、`og:site_name`、`og:image` 三件套、twitter 五件套、4 条 hreflang、`theme-color` 全部存在；
- 构建日志：`core hreflang 补齐: 0 页`、`guides hreflang 补齐: 0 页`，不再每轮重写；
- 静态测试：4,626 passed / 0 failed / 0 warnings（4,606 个工具）；
- 死链门禁：16,743 文件 / 160,344 内链，0 死链；
- 资产完整性：0 资产死链 / 0 `lang` 缺失 / 0 重复 id；
- 内联标记位置审计：4,921 页，0 处加固片段违规。

## 变更规模

- `_build.py`：新增 `ensure_guide_article_og()`、sitemap 模板社交标签和 hreflang 注入；
- 3,247 个指南页各新增 2 行 meta；`sitemap.html` 新增 12 行社交/hreflang 标签。
