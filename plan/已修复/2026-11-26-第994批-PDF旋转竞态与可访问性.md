## 修复内容

### 1. 导出快照与导出令牌

- `downloadPdf()` 点击瞬间快照 `buffer / name / rotations / version`，后续异步渲染只使用该快照，不再读取可能已被替换的全局 `state`。
- 新增 `exportToken`：换文件、重置、加载新文件时递增；旧导出完成后若 token 不一致，丢弃输出并恢复按钮状态，不显示旧文件结果。
- `exporting` 防重复点击；未选中页面时不进入导出。
- 输出角度统一取 `snapshot.rotations[i] || 0`。

真机验证：延迟 `PDFDocument.load`，点击下载后 200ms执行 `rotateAll(90)`；页面 `state.rotations=[90,90,90]`，实际导出 PDF 解析为 `[0,0,0]`，证明导出只用点击时快照。

### 2. 加载与重置竞态

- `loadPdf()` 改为局部读取/解析：先在局部完成 `arrayBuffer`、pdf.js 文档和结构检测，确认 `loadToken` 仍是最新后，才一次性提交 `state.buffer / state.fileName / state.pdfjsDoc / state.numPages / state.features / state.rotations / state.selected / state.renderedPages`。
- 新增 `loadToken`：换文件、重置、旧加载完成时校验；旧文档若已不再使用会 `destroy()`。
- `resetFile()` 递增 `loadToken/exportToken/stateVersion`，断开缩略图 observer、清空页面渲染 token、销毁旧 pdf.js 文档、隐藏面板；不再允许旧加载任务把结果写回。
- 加载期间 `setLoadingState(true)`：`#loadStatus` 可见、`#loadingOverlay` 显示，`#dropZone/#fileInput/#pdfPanel` 内相关控件禁用，`#downloadBtn` 禁用。
- `loadPdf` 失败只对当前 token 提示并销毁 pending 文档，旧文件状态保留。
- 文件加载成功后若当前是可视化模式，自动调用 `renderAllThumbs()`。

真机验证：延迟 `File.arrayBuffer` 后调用 `loadPdf(oldFile)`，150ms 时 `loadStatus=正在加载 PDF…` 可见、`downloadBtn.disabled=true`、`dropZone.disabled=true`；随后 `resetFile()` 再上传 1 页 `pdf990b.pdf`，旧任务完成后文件名/页数仍为 `pdf990b.pdf / 1`，加载态隐藏、下载恢复、无 `pageerror`。

### 3. 缩略图渲染隔离与离屏回收

- 新增 `state.version / state.renderedPages / pageRenderToken / thumbObserver / thumbPaused`。
- `renderAllThumbs()` 只创建缩略图 DOM，不一次性渲染所有 canvas；`IntersectionObserver`（`rootMargin:'300px 0px'`）进入视口才渲染。
- `renderThumbCanvas(i)` 捕获当前 `doc / state.version / angle / pageRenderToken`，每个 `await` 后校验 token、文件版本、角度快照、缩略图 DOM 仍是同一个节点；任一不符即丢弃结果。
- 同一页重复渲染由 `pageRenderToken` 作废旧任务，后完成的任务不会覆盖新角度。
- 新增离屏回收：缩略图离开视口且不是 `dirty` 状态时，移除 canvas、恢复“滚动到此处加载”占位，`state.renderedPages.delete(i)` 并刷新进度，避免百页文件永久保留大量 canvas。
- `markThumbDirty(i)` 只对可见页立即重绘，其他页保持 `dirty=1` 等滚动进入时重绘。
- `jumpToPage()` 改为 `scrollIntoView({behavior:'auto'})`，避免从第 1 页平滑滚到第 100 页时沿途触发大量中间页渲染。
- 新增 `#thumbRenderStatus`：显示“已渲染 X / N（滚动加载）”；新增 `#thumbToggle` 暂停/继续渲染。
- 新增 `#jumpPage` 页码跳转、`#selectRangeInput` 范围选择；范围支持全角逗号/连字符，支持范围与单选；空段/越界有中英提示。

真机验证（3 页）：上传后 3 个 `.thumb-item`、初始 0 canvas；滚动到网格后 `已渲染 3/3（滚动加载）`。快速连续 `rotateOne(0,90)` 三次，最终角度 270、badge `270°`、`#wrap-0` 仅 1 个 canvas。暂停后按钮“继续渲染”，继续后恢复。

真机验证（100 页，21KB 生成文件）：加载约 1.2s 后 100 个条目、0 canvas、`已渲染 0/100（滚动加载）`；滚动到网格后 9 canvas；跳转第 100 页后 7 canvas 且目标页有 canvas；全量右转后 7 canvas、`state.rotations` 前 5 页均为 90；无 `pageerror`。

### 4. 选页/保存提示

- 未选中页面旋转：`请先勾选要旋转的页面 / Select pages before rotating.`
- 未选择页面旋转选中项、无文件下载、空 PDF、加载失败、重置完成、下载完成、复制结果等均改为 `M()`/`setToast` 明确中英提示，不再调用无参 `i18nText('toast.saved')`。
- 下载成功提示包含文件名或“已开始下载”，英文态对应 `Download started.`。

### 5. 英文简介与英文态动态控件

- `i18n/tools/office.json` 的 `pdf-rotate` `en-US.intro` 从占位句改为完整功能描述：浏览器内旋转、单页/批量/全部、实时预览、不上传。
- `tools/office/pdf-rotate.html` 的 `meta name="desc-en"` 改为功能描述；`_build.py` 归一化后静态 `desc-en` 仍会截断到约 120 字符（保留“Rotate PDF pages in your browser…preview…reset”），运行时英文 intro 为完整句，未受截断影响。
- `applyUiLanguage()` 设置静态文案：拖拽标题/提示、跳转/范围标签、按钮、选中栏 `Selected / pages`、缩略图暂停文字；`renderInfo()`、`createThumbItem()`、旋转/重置/空选/下载/错误提示全部中英双语。

真机验证（`?lang=en-US`）：intro `Rotate PDF page orientation entirely in the browser, supporting single-page, batch and rotate-all modes with live preview, and files are never uploaded to the server.`；信息区 `File name / Pages / File size`；按钮 `Rotate all left 90° / Rotate selected right / Select all / Clear selection / Reset rotation / Choose another PDF / Download rotated PDF`；缩略图 `Page 1`、`Select page 1`、`Left 90° / Right 90°`、`Scroll to load`；状态 `Rendered 0 / 3 (lazy)`；空选提示 `Select pages before rotating.`；空范围 `Empty page segment; check commas.`；越界 `Enter a page from 1 to 3.`。

### 6. 大文件逐页缩略图性能

- 采用可视区域懒加载 + 离屏回收，仅渲染进入视口（含 300px 预取）的页面；100 页测试同时存在的 canvas 控制在 7–9 个，而不是 100 个。
- 加载阶段不阻塞按钮状态；缩略图异步渲染，暂停/继续可用；页码跳转直接定位，不经过中间页。
- 大文件提示保留：页数多时状态栏显示加载/渲染进度，不静默卡死。

### 7. 数字签名提示

- 工具页使用说明新增：
  - “旋转操作仅改变页面方向，不会修改文字、图片等内容；保存会重新写出 PDF”
  - “含数字签名的 PDF 旋转后签名可能失效，请保留原件并检查输出文件的签名状态”
- 页面可见 FAQ 与 FAQPage JSON-LD 新增“旋转带数字签名的 PDF 会影响签名吗？”及说明：保存会重新写出 PDF，原签名可能不再有效或无法通过验证；保留原件并在阅读器检查输出签名；表现取决于签名方式与阅读器。
- 指南 `guides/pdf-rotate-guide.html` 正文注意事项与 FAQ 同步；`i18n/guides/pdf-rotate-guide.json`、`i18n/tools/content_deepdive.json`、`i18n/tools/en/office/pdf-rotate.json`、`i18n/tools/office-phrases.json`、`i18n/tools/office.json` 同步英文映射。
- 局限：本机没有真实数字签名 PDF 样本，也未安装 Acrobat/qpdf/poppler/pdftk，未做签名状态第三方阅读器验证；本批只保证文案与结构提示准确。

### 8. 上传入口键盘可访问

- 上传区由 `div onclick` 改为原生 `<button type="button" id="dropZone">`，内部含拖拽标题/提示；独立隐藏 `#fileInput` 由按钮触发，避免嵌套交互元素。
- 支持 Tab 聚焦、Enter/Space 触发文件选择；新增 `:focus-visible` 描边。
- `#dropZone` 加载期间 `disabled`，避免重复打开文件选择器；重新上传按钮同样可用键盘操作。

真机验证：聚焦 `#dropZone` 按 Enter 打开文件选择器并上传 `pdf990b.pdf` 成功；新文件 `1 items`、总页数 1、状态 `0/1`（视口外符合懒加载）。
