## IT-N374（中）先验为 100% 时优势比本应为 ∞，页面显示「未定义」

**失败点**：`priorOdds = prior/(1−prior)`，`prior=1` 时分母 0 得 `Infinity`；`posteriorOdds = priorOdds*BF` 同样 `Infinity`。`fmt()` 的统一口径是 `if(!isFinite(x)) return '未定义'` —— 「发散到 ∞」与「未定义」被写成同一个词。同理 `fp=0` 时 BF 也发散。

**修复位点**：`tools/it/bayes-theorem.html`

```js
// IT-N374：优势比的发散（分母 0）与「未定义」是两种语义，必须分开显示
function fmtOdds(x){
  if(x===Infinity) return '∞';
  if(x===-Infinity) return '−∞';
  if(!isFinite(x)) return '未定义';
  return fmt(x);
}
```

- 统计卡片「优势比变化」、步骤 5 全部改用 `fmtOdds`。
- 新增两条「边界说明」：`prior===0||prior===1` 说明先验优势发散、后验恒为 `prior`；`fp===0` 说明 BF 发散。

**证据**：`prior=1, likelihood=0.9, falsePositive=0.05`
- 修复前：卡片 `未定义 → 未定义`，步骤 5 `先验优势 = 未定义；BF … = 18；后验优势 = 未定义×18 = 未定义`
- 修复后：`先验优势 = ∞；BF = P(E|H₁)/P(E|¬H₁) = 0.9/0.05 = 18；后验优势 = ∞×18 = ∞`，并附「先验 P(H₁) = 1 时 P(¬H₁) = 0，先验优势 1/0 发散为 ∞；此时证据无法再改变信念，后验恒为 1」。
- 后验本身仍为 1（100.00%），与「先验绝对确定时证据无法改变信念」的解释一致。

## IT-N375（中）承诺「知三求一 / 计算所需样本量」，实际只有功效一个输出

**失败点**：`formula-desc` 写「计算统计检验的功效或所需样本量」、要点写「四要素……知三可求其一」、英文简介写 "required sample size"，但输入只有 d/n/α/检验方向，`calculate()` 只算 power，**没有任何反解入口**。

**修复位点**（`tools/it/statistical-power.html`）：

1. 新增两个控件：`#solveFor`（求功效 / 求样本量）、`#targetPower`（默认 0.8）。
2. `calculate()` 在 `solveFor==='size'` 时先反解：

```js
zA = (tail==='two') ? normalInv(1-alpha/2) : normalInv(1-alpha);
zB = normalInv(targetPower);
solvedN = Math.ceil(2*Math.pow((zA+zB)/d,2));
n = solvedN;                 // 再用该 n 走原有效率路径复核实际功效
```

3. 主结果首行在反解模式下改为 `所需样本量 = N（每组），实际功效 X%`，并在分步区首行给出反解算式。
4. 公式区补一行 `反解样本量：n = ⌈2 × ((z₁₋α′ + z₁₋β) / d)²⌉（每组，α′ 双侧取 α/2）`。
5. 求功效模式的校验与输出完全不变（默认 `solveFor='power'`）。

**证据**：`d=0.5, α=0.05, 双侧, 目标功效=0.8`
- 修复前：无该控件，只能反复试 n（n=64 时功效 80.7%）
- 修复后：`所需样本量 = 63（每组），实际功效 80.13%`，分步区 `n = ⌈2×((1.96 + 0.842)/0.5)²⌉ = 63（每组）`
- 独立复算：z₁₋α/₂=1.95996、z₁₋β=0.84162 ⇒ 2×((1.95996+0.84162)/0.5)² = 62.79 ⇒ ⌈·⌉=63；δ=0.5×√(63/2)=2.8062 ⇒ Φ(2.8062−1.95996)=0.8013 ⇒ 80.13%。
