# 596 批：公关赞助评估与营销标签的输入安全与计数口径

## pr/analysis-assessor：权益名 DOM 注入、零投入假结论、坏行静默
- 根因：`r.n` 未转义即拼入 `<td>` 与「价值最高权益」（DOM 注入路径）；`roi=tc>0?...:0` 在投入合计为 0 时记 0 并给「基本回本」；格式错误行被 `continue` 静默丢弃，用户不知道数据被丢。
- 改法：新增 `__esc`（`& < > " '` 五字符）覆盖两处拼接；`tc<=0` 直接拒绝计算；收集 `bad` 行号并在结果区列出；非数/负值行同样显式跳过并计数。
- 验证：新增用例「冠名权益,800000,0」→「投入合计需大于 0」；「冠名权益,800000,300000 + 坏行」→「第 2 行数据无效」。转义用源码形态判定（`__esc` 覆盖两处拼接），原 4 行 ROI 用例保持 161.90% 不变。

## pr/analysis-density-1：关键词大小写漏计
- 根因：先按大小写敏感 `text.indexOf(k,pos)` 计数，仅 `cnt===0` 时才回退小写 `split` → 正文「Apple apple」、关键词「Apple」只算 1 次。
- 改法：统一在 `lower` 文本上按 `lk` 做非重叠计数，删除回退分支。
- 验证：新增用例 text=「Apple apple」、kw=「Apple」→ 2 次 / 密度 100.00%（旧实现 1 次 / 50.00%）。原中文用例 5.56% / 2 次不变。

## marketing/marketing-chinese-hashtag-generator：用户输入进 innerHTML 与内联脚本
- 根因：标签文本直接拼进 `innerHTML`、内联 `onclick="navigator.clipboard.writeText('${t}')"` 与模板字面量按钮 `ToolBox.copyText(\`${tagArr.join(' ')}\`)`；含单引号、反引号或 HTML 标记的输入可破坏结构并造成注入。
- 改法：新增 `__he`（`& < > " ' \`` 六字符）；单个标签改 `data-tag` + `onclick="copyTag(this)"`，复制全部改 `data-tags` + `onclick="copyAllTags(this)"`，两处复制函数从 DOM 属性取值；所有用户输入渲染前转义。
- 验证：源码形态判定（内联串中无 `${t}` / 模板字面量、两处 `__he`）+ 既有用例 `#手机`/`#抖音爆款`/`#短视频` 回归通过。
