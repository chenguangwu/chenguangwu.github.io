# 第333批 · 设计 · pixel-art 历史恢复保留用户绘制网格（D-N97 收口）

## 根因
`tools/design/pixel-art-generator.html` 的历史快照函数 `__pixel_art_generatorSnap()` 只采集 `input/select/textarea` 的 UI 值（gs/color/mode），**不含绘制网格 `window.__pxGrid`**。历史恢复回调遍历 rec 设 UI 值后调 `calcTool()`，`calcTool()` 因无网格数据而重建空网格（或 gs===8 时的默认笑脸），**用户绘制内容丢失**，历史回看无法还原当时像素画。

## 改动
文件：`tools/design/pixel-art-generator.html`

1. 新增 `__pixel_art_generatorData()`：序列化 `window.__pxGrid` 为 JSON（`__pxGrid` 键），仅在网格存在时收集（不进表格列头）。
2. `__pixel_art_generatorExtras()`：`var data=__pixel_art_generatorData();`；构建 record 时把 `data` 的键并入 `rec`（表格列头 `keys` 仍只取 `snap` 的 UI 输入，网格不污染表格列）。
3. 历史恢复回调 `TBKit.history.mount(...)`：遍历 rec 跳过 `__pxGrid`；在设完 UI 值后解析 `rec.__pxGrid` 写回 `window.__pxGrid / window.__pxSize / window.__pxInited=true`，再调 `calcTool()`。因 `window.__pxInited && window.__pxSize===gs && window.__pxGrid` 条件成立，`calcTool()` 复用写回网格（不再重建空/笑脸），绘制内容完整还原、画布与字符画同步刷新。

## 预防
- 历史快照/恢复机制凡涉及“用户交互产生的非 UI 态数据”（如网格、画布、序列），须一并序列化进 record 并在恢复时写回，再触发重渲染；仅存的 UI 输入不足以还原交互结果。
- 沿用硬约束：verify 覆盖工具禁 HTML 内联事件属性做副作用，本批仅改脚本内逻辑 + addEventListener 风格绑定，未新增内联 on* 属性。
