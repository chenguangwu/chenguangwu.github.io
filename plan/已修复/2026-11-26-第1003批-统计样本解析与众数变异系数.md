# 第 1003 批：统计样本解析、众数与变异系数边界

日期：2026-11-26
范围：`tools/statistics/` 七个页面，对应 4 个工具问题任务。

## 修复内容

1. 几何/调和/总体方差（3 页）
- `geometric-mean`：删除旧输入守卫；新增 `__gmParse()` 逐项完整数字校验，非法项和 ≤0 项按第 N 项报错，`1,-2,4` 不再被过滤成 `1,4`。
- `harmonic-mean`：新增 `__hmParse()`，0 和负数按位置阻止，避免 `1/0` 得到无限大。
- `population-variance`：新增 `__qvParse()`，`2abc` 不再被 `parseFloat` 读成 2；非有限值按位置报错。
- 三页的增强明细改用同一解析函数，非法输入时清空表格。

2. 样本方差与标准差（2 页）
- `sample-variance`：`__svList` 改为 `__svParse()` 返回 `{vals|error}`；非法项按位置报错，不再静默过滤后按剩余数据计算；空值/单值提示至少 2 个。
- `stddev-list`：新增 `__sdParse()`，逐项校验；少于 2 个有效值停算，避免分母 n−1 为 0。
- 所有数字正则允许负号，负样本值不再被误判为“不是有效数值”。

3. 基础统计（`statistics-12`）
- 支持只填 2–7 个输入，空白项自动忽略，不再强制 7 项全部填写。
- 中位数按实际 n 计算：奇数取中间值，偶数取中间两数平均；极差、均值、总和同步按实际 n。
- 新增众数：出现次数最多的值；支持多个众数与“无众数（各值出现次数相同）”。
- 页面公式说明、输入提示、指南正文与英文指南映射同步改为可变样本口径。
- 图表/明细表标签按实际 n 生成，不再固定 7 根柱。

4. 变异系数（`statistics-10`）
- 均值/标准差严格解析，拒绝文字与负数标准差。
- 任一均值为 0 时明确提示 CV 无定义，不能比较。
- 两组 CV 相等时显示“两组相同”，不再固定判 B 组更离散；明细/图表判定同步。
