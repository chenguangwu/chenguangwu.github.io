# 第733批：文本相似度、截断复制、中文二元分词、自定义分隔符、短链复制五项

日期：2026-11-24
基线：`99b1561f94`（第732批）

## 修复内容

1. **文本相似度：特殊词命中原型链导致余弦错误**
   - `tokensToFreqVec` 改用 `Object.create(null)` 建词频表，计数用 `hasOwnProperty` 判定；`cosineSimilarity` 读取同样只认自有属性。
   - 修复 `constructor`、`toString`、`__proto__` 等词命中原型函数、计数变 `NaN`、余弦被算成 0 的问题；相同文本含这些词时余弦恢复为 1。

2. **文本截断：无效数量提示被当作结果复制**
   - 新增全局 `__lastTruncated` 保存最近一次**有效**截断结果；空输入、数量非正整数、字节模式非法等所有错误分支都清空它。
   - `copyResult()` 只读取 `__lastTruncated`，为空时提示“请先完成一次有效截断”；剪贴板不可用或写入失败也有明确提示，不再把错误提示复制进剪贴板。

3. **关键词密度：中文二元分词始终没有词项**
   - 二元模式改为先把连续汉字合成为片段，再在片段内生成相邻二元组；单汉字片段按 `minLen` 保留。
   - 中英文、数字、标点边界处 flush 片段，避免跨语言/跨标点组词；`北京天气` 现在可正常得到“北京”“天气”。

4. **文本去重排序：修改自定义分隔符未重新拆分**
   - `customSep` 的输入事件由 `renderOutput()` 改为新增的 `onCustomSepChange()`。
   - 该函数重建 `snapshotOriginal`、`currentLines`、`dedupeCount` 并重绘统计，使 `a|b|a` 按 `|` 拆成 3 项、去重后剩 2 项；只重绘不重拆的旧行为已消除。

5. **短链接生成：批量复制粘连且混入原始地址**
   - 新增全局 `__lastShortLinks` 保存本次生成的候选短链接；`generate()` 开始时清空，批量与自定义 slug 分支只 push 纯候选链接。
   - `copyResult()` 改为 `join('\n')` 逐行复制；候选为空、剪贴板不可用、写入失败均给出提示，不再复制“原始 URL”等说明文字。
