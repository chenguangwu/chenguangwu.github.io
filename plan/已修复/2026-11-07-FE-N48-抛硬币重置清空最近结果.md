# 2026-11-07 FE-N48 抛硬币重置清空最近结果

- 分类：11-文娱爱好 / fun
- 页面：`tools/fun/coin-flip.html`
- 缺陷：重置统计后「最近结果」残留旧序列
- 严重度：中（确认源码缺陷，非陈旧快照误报）

## 失败点
`updateStats()` 仅在 `recent.length>0` 时重绘 `#recentResults`；`reset()` 清空 `recent=[]` 后再调用 `updateStats()`，因 `recent.length===0` 跳过绘制，容器仍显示旧的正/反标记，与已归零的统计自相矛盾。

## 根因
绘制逻辑缺少「空态」分支，重置后不主动清空 DOM 容器。

## 修复位点
文件 `tools/fun/coin-flip.html` `updateStats()`（约 372 行）：
- 在原 `if (recent.length > 0) { ... }` 之后新增 `else` 分支：
  ```js
  } else {
    const __h1='<span style="color:var(--text-muted)">暂无记录</span>'; /* 同套校验后 */ document.getElementById('recentResults').innerHTML=__h1;
  }
  ```
