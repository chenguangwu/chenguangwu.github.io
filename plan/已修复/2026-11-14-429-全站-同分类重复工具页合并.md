# 429 批：同分类同功能重复工具页合并

日期：2026-11-14
范围：5 组重复工具页（4 组含重复指南）

## 一、问题

同分类内存在成对的「同一功能、不同文件名」工具页，h1、输入项与计算逻辑完全一致，
只是历史生成器各生成了一份，属于典型站内重复内容：

| 保留页 | 合并页 | 功能 |
| --- | --- | --- |
| acoustics/sound-intensity-level | acoustics/intensity-level | 由声强求声强级（L_I=10·log₁₀(I/I₀)） |
| statistics/sample-variance | statistics/variance-list | 由数值序列求样本方差（n−1） |
| dynamics/momentum-conservation | dynamics/inelastic-collision | 完全非弹性碰撞末速 |
| nuclear/specific-activity | nuclear/specific-activity-from-halflife | 由半衰期与摩尔质量求比活度 |
| agriculture/calculator-calc-density | agriculture/calc-2 | 种植密度（株距×行距） |

核验方式：逐对比较 `id` 输入项与归一化后的页面主体；5 组输入项、按钮、结果字段一一对应。
`life/countdown` 与 `life/countdown-timer` 虽然名称相近，但一个是单日期倒计时、
一个是多事件 + 番茄钟，功能集合不同，**不合并**。

## 二、修复

1. 合并页原地改写为 `TOOLBOX-REDIRECT` 重定向桩（meta refresh + canonical + noindex，
   与 `scripts/merge_dupes_p2b.py` 历史口径一致），旧 URL 不丢、无死链；
   `_build.py` 扫描时自动跳过，`tools.json` / `industry-*.json` / sitemap 均不再收录。
2. 保留页按「标题更干净、描述更完整」选取：
   - `sound-intensity-level` 的 zh `title` 原为公式串，改为「声强级计算器」，
     `desc` 改为完整功能说明；
   - `momentum-conservation` 的英文名由 `Momentum Conservation` 改为
     `Perfectly Inelastic Collision Calculator`（与实际算法一致）；
   - `calculator-calc-density`、`sample-variance`、`specific-activity` 的
     `slug-en` 英文名分别修正为 `Planting Density Calculator` /
     `Sample Variance Calculator` / `Specific Activity Calculator`。
3. 4 组对应的重复指南（`intensity-level / variance-list / inelastic-collision /
   specific-activity-from-halflife`）加 `noindex, follow` + canonical 指向保留指南；
   `json/guides.json` 删除这 4 条旧指引入口。
   `calc-2-guide.html` 实为 `hydraulic/calc-2` 的指南（basename 撞名），**未改动**。
4. 其余 24 个指南页里指向旧工具页的链接批量改写到保留页；
   工具页正文里的 term-link / 相关工具由 `_build.py` 自动重指向或降级为纯文本。
