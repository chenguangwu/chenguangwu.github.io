# 595 批：公关 CPM 量纲与营销零值兜底

## pr/assessor-58：CPM 高 10 倍、单粉成本分母错、guard 残留复制值
- 根因：费用与曝光单位同为「万」时 CPM 应为万元÷万次×1000，代码乘 10000；单粉成本用 expo>0 判断却除以 fans；清空必填项只替换结果区，旧 dataset.copyValue 仍可被复制。
- 改法：×10000→×1000；CPE 条件改 fans>0；曝光或粉丝为 0 时两值显示「—」并跳过性价比判读；guard 分支同步清空 copyValue。中文深解源、英文 map 键与值、算例三源同步（20÷3000×1000=6.67 元、低质账号 50 元，7.5 倍关系不变）。
- 验证：新增用例 k1=15/k6=7/k7=250 → CPM 28.00 元/千次、CPE 0.47 元/粉；旧实现得 280.00，不含 28.00 串，注入失败即不命中。

## pr/assessor-59：核心报道越界、空值按 0、占比无定义仍显示 0%
- 根因：+value||0 把空值按 0；core>reports 无校验可输出 200% 占比；reports=0 时占比强行显示 0%。
- 改法：显式校验空值/非数/负数，core>reports 拦截；占比无分母时显示「—」；无效态清空 copyValue，提示按中英双态输出。
- 验证：新增用例 p1=10/p2=20 → 拦截提示；p1 清空 → 补录提示。

## marketing/marketing-discount-rate：清空被当 0、保存绕过计算校验
- 根因：calc 与 saveHistory 共 6 处 parseFloat(...)||0，空串按 0 得「无折扣」结果；保存路径只校验原价 >0，越界输入仍写入历史。
- 改法：抽 __drNum（空串/非数返回 NaN）与 __drError（三模式统一校验），calc 与 saveHistory 共用；清空时结果区提示补录、不写历史。原有越界提示文案保留以维持用例判别力。
- 验证：新增折扣率清空用例 → 「请填写原价与折扣率」；原 3 条用例全绿。

## marketing/marketing-keyword-density：零分母仍给密度建议
- 根因：正文仅标点时 totalChars=0，density 记 0 却继续输出「密度偏低」。
- 改法：totalChars===0 直接给「正文不含可统计字符」提示（中英双态）并 return。
- 验证：新增 keyword=a/content=!!! 用例 → 新提示；原 2 条密度用例全绿。
