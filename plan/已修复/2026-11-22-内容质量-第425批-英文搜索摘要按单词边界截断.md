# 第 425 批：英文搜索摘要按单词边界截断

日期：2026-11-22
类型：内容质量 / 英文搜索与卡片摘要
状态：已修复并本地提交（未 push）

## 一、原问题

`scripts/tool_desc_source.py::clip()` 对英文描述做硬截断：取前 `n-1` 个字符后直接补省略号，只清理末尾标点，不判断单词边界。

`json/tools.json` 的 `ed` 字段由 `TDS.en_desc(t, max_len=60)` 生成，供英文态搜索下拉、首页卡片、分类页和顶部导航消费。修复前 4,606 个工具中 **3,986 条**以省略号结尾，其中大量在单词中间断开，例如：

- `Pick stacks (Python/Node/Go/Rust/Java/.NET/IDE) and merge a…`
- `Parse Java .properties files into key-value pairs with corr…`
- `Build a signed API request string: combine your parameters…`
- `Parse JavaScript source into an abstract syntax tree with a…`

搜索结果和卡片出现 `a…`、`corr…`、`parameters…` 这类残词，影响英文可读性与专业感。

## 二、修复内容

修改 `scripts/tool_desc_source.py::clip()`：

1. 截断后若末尾仍是英文字母/数字，先回退到最近的空格、制表符、连字符、斜杠或左括号；
2. 仅当该边界位于截断长度 55% 之后时才回退，避免摘要被切得过短；
3. 找不到可靠边界（长 URL、无空格串）时保留原硬截，避免输出空串；
4. 中文无空格，行为不变，仍按字符数硬截。
