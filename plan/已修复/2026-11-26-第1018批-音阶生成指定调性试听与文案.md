# 第 1018 批：音阶生成指定调性、试听键盘与 SEO 文案

- 影响页面：`tools/music/generator-1.html`
- 对应任务：`plan/music/音阶生成缺少指定调性与试听.md`、`plan/music/音阶生成器试听SEO文案不符.md`

## 问题

1. 页面只允许输入数量，根音与调式全部随机，无法按练习或创作指定调性；结果只有音名，没有试听、键盘位置，音名固定升号、部分调性拼写错误。
2. 英文标题、描述与正文声称可试听、有频率，但页面实际没有对应功能。

## 修复

- 新增模式选择：指定调性 / 随机练习；指定模式可选择 12 个根音、6 种调式（自然大调、自然小调、和声小调、旋律小调、大调五声、小调五声）与起始八度 2–6。
- 新增 `ROOTS` / `SCALES` / `spellPitch()` / `buildScale()`：按音级字母加升降号拼写，支持 `B♭`、`E♯`、`B♯` 等理论拼写；频率按 `f = 440 × 2^((midi − 69)/12)` 计算。
- 结果每行给出标题、音名序列与频率；新增 `renderKeyboard()` 单八度键盘，高亮调内音。
- 新增 `playScale()` / `stopScaleAudio()`，本地 Web Audio 顺序试听第一组音阶；切换模式或重新生成时停止旧音频。
- 随机模式数量为空、非整数或不在 1–50 时提示“随机数量需为 1–50 的整数”；固定模式隐藏数量、启用根音与调式选择。
- 同步 `i18n/tools/music.json`、`music-body.json`、`_en_override.json`、`en/music/generator-1.json` 与 `guides/generator-1-guide.html`，英文标题改为 `Scale Generator & Player`，描述与正文统一为正确拼写、频率、试听、键盘高亮与随机练习。

## 验证

- `node scripts/verify_music_calc.js`：82/82 通过；新增静态守卫覆盖 `spellPitch` / `ROOTS` / `buildScale` / `renderKeyboard` / `playScale` 与随机练习，动态探针校验 F 大调。
- Chrome 真机：C 大调 `C4…B4`、F 大调 `F4 G4 A4 B♭4 C5 D5 E5`（466.16 Hz）、C♯ 大调 `C♯4 D♯4 E♯4 F♯4 G♯4 A♯4 B♯4`、A 小调五声 `A4 C5 D5 E5 G5`，键盘分别高亮 7 / 7 / 7 / 5 个；随机空数量报错；`?lang=en-US` 标题、调式名、按钮均为英文。
- `python3 _test_static.py` exit 0；`python3 _audit_assets.py --check` 0 死链 / 0 lang 缺失 / 0 重复 id。
