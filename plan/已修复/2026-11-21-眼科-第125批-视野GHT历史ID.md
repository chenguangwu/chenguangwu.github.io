# 第 125 批：视野分析 GHT 单选补 id，历史可恢复（眼科）

- 日期：2026-11-21
- 页面：`tools/ophthalmology/visual-field-analysis.html`

## 原问题

GHT 三个单选按钮都只有 `name="ght"`，没有 `id`：

```html
<input type="radio" name="ght" value="normal" checked ...>
<input type="radio" name="ght" value="borderline" ...>
<input type="radio" name="ght" value="outside" ...>
```

通用历史快照只收 `input[id]`，因此 GHT 永远不进入 localStorage 记录；从历史恢复时页面保留当前 GHT，再用旧 MD/PSD/VFI 重算，可能得到与当时不同的结论。另外三条 `aria-label` 被复制成「正常 / 正常 / 临界」，屏幕阅读器读到的选项名与实际不符。

## 修复

- 补 id：`ghtNormal` / `ghtBorderline` / `ghtOutside`；
- `aria-label` 改为「GHT 正常 / GHT 临界 / GHT 异常」；
- 现有通用快照与恢复逻辑无需改动：radio 会按 `1/0` 记录，恢复时先清未记录勾选，再按 id 恢复。
