# 559 批：目标分解尾差与权重校验、零毛利保本判定（MS-F5 / MS-F6）

日期：2026-11-15
范围：`tools/sales/target-breakdown.html`、`tools/sales/price-calculator.html`

## MS-F5 目标分解合计与逐行不一致、负权重无拦截

### 问题
- 逐行目标用 `fmt()`（`Math.round`）取整，合计用未取整的 `sumTarget` 再取整；1000 ÷ 3 时逐行显示
  333/333/333（合计 999），合计行却显示 1,000。
- 权重模式允许负数，权重合计 ≤0 时按 1 兜底，产出 0 或负目标且无任何提示。

### 修复
- 新增 `computeShares()`：目标统一按两位小数取整，除不尽时把尾差归入目标最大项，保证逐行之和 = 总目标；
  `calc`、CSV 导出、图表共用同一组数值。
- 占比按取整后的目标计算并保留 1 位小数，尾差同样归入最大项，合计固定 100.0%。
- 权重模式校验：任一权重 <0 或非有限值 → 提示「权重不能为负数」；合计 ≤0 → 提示「权重合计须大于 0，
  请调整权重或改用均分模式」，不再静默兜底。
- 总目标 ≤0 时提示「请输入大于 0 的团队总目标」；导出与图表复用同一校验。
- 公式说明与深度解析同步新口径（两位小数、尾差归最大项、负权重拦截）。

### 验收
- 均分 1000 / 3 人 → 333.34 + 333.33 + 333.33 = 1,000.00，占比 33.4/33.3/33.3 = 100.0%。
- 权重 30/25/20（总 1000）→ 400.00 / 333.33 / 266.67，合计 1,000.00。
- 权重 -10 → 结果区提示「权重不能为负数」；权重全 0 → 提示改用均分。

## MS-F6 零毛利仍断言 1 件保本、竞品偏差可算负售价

### 问题
- `fixedCost=0` 分支无条件输出「盈亏平衡销量：1 件（无固定成本时，售价 > 成本即盈利）」，
  售价等于或低于成本时结论与事实相反。
- 竞品参照模式对偏差不设下限，偏差 -150% 时可得出负售价。

### 修复
- `fixedCost=0` 改按单位毛利判定：
  - `>0`：「1 件即可盈利（无固定成本，售价 > 成本）」；
  - `=0`：「不盈不亏（售价 = 成本，且无固定成本）」；
  - `<0`：「每卖一件亏损 ¥X（售价 < 成本），无法保本」。
- 竞品偏差补 `> -100%` 下限校验，避免售价 ≤0。
- `calc()` 出错时清空旧结果并置空 `_lastResult`，防止把上一次的有效售价误当本次结果复制。

### 验收
- 成本 100、加成 0%、固定成本 0 → 「不盈不亏」；加成 10% → 「1 件即可盈利」。
- 竞品价 100、偏差 -150% → 提示「偏差应大于 -100%（否则售价 ≤ 0）」，结果区清空，`_lastResult` 为 null。
