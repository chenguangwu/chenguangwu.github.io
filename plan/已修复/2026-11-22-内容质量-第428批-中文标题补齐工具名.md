# 第 428 批：中文标题补齐工具名（“由……”型标题）

日期：2026-11-22
类型：内容质量 / SEO 标题
状态：已修复并本地提交（未 push）

## 一、原问题

全站工具页扫描发现 1,078 个页面的 `<h1>` 未出现在 `<title>` 中。其中 330 个标题以“由……”开头，只描述计算过程、不含工具名，例如：

- `由试验数、成功概率与上限求累积概率 - 免费在线统计学工具`（H1：二项累积分布计算器）
- `由数值序列求极差 - 快速衡量数据离散跨度`（H1：极差计算器）
- `由二阶矩阵四元素求行列式 - 免费在线数学计算工具`（H1：二阶行列式计算器）

搜索结果只显示“由……求……”，用户无法一眼看出这是什么工具，也不利于工具名关键词收录。

## 二、修复内容

对满足以下条件的 253 个页面，在 i18n 中文 `title` 前补上工具名：

1. 标题以“由”开头；
2. 标题不含当前 H1 工具名；
3. 工具名含“计算器”，且不含 `=` 等公式符号；
4. 新标题长度不超过 70 字（实测最长 58 字）。

修改方式：

- 在 `i18n/tools/<industry>.json` 的 `zh-CN.title` 中写入 `工具名 - 原标题`；
- 不直接改页面磁盘 `<title>`（构建会从 i18n 还原）；
- 构建后由 `_build.py` 同步刷新 `<title>`、`og:title`、`twitter:title`。

示例：

- `二阶行列式计算器 - 由二阶矩阵四元素求行列式 - 免费在线数学计算工具`
- `余弦定理求边计算器 - 由两边及夹角求第三边 - 免费在线数学计算工具`
- `卡诺效率计算器 - 由冷热源温度求理论最高热效率 - 免费在线能源电力工具`
- `PEG 估值指标计算器 - 由市盈率与盈利增长率求 PEG - 高成长股是否被高估`

## 三、验证证据

- 构建：`env -u NODE_OPTIONS python3 _build.py` 成功。
- 修复后“由……”且缺工具名的计算器标题从 330 降至 14；剩余 14 条均为标题过长、名称含公式符号或名称不含“计算器”的边界项，按规则跳过。
- 全站 H1 未出现在标题的页面从 1,078 降至 825。
- 标题长度：无 `>70` 字页面。
- 重复标题：排除重定向存根后 **0 组**。
- 静态门禁：**4,626 passed / 0 failed / 0 warnings**。
- 上一批全量门禁：**268 项全部通过**。
