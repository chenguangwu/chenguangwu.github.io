# 金融 F-N45：定投页初始申购费漏计 + 月初扣款 IRR 时点错位（已修 · 申请复核）

## 来源
- `plan/categories/02-金融财务/finance.md` 的 F-N45「定投页初始申购费未计入费用合计、期初扣款 IRR 时点错位（中，确认）」。

## 根因
- **子项一**：`tools/finance/mutual-fund-calculator.html` `calc()` 中 `shares = initial * (1 - buyFee)` 已从份额中扣除初始申购费，但 `totalFees` 初值 0 且循环只加 `monthly * buyFee`，赎回费才在末尾累加 ⇒ 费用合计系统性漏掉 `initial * buyFee`。
- **子项二**：`calcIRR(monthly, initial, months, finalValue, monthStart)` 形参含 `monthStart` 却完全未使用；现金流固定 `[-initial, -monthly × months]`（t=1..N），月初扣款首期应在 t=0 却仍按月末落位，与自身余额模型不一致。

## 修复位点
- 初始申购费入账（`calc()`）：
  ```javascript
  var shares = initial > 0 ? initial * (1 - buyFee) : 0;
  // F-N45：初始投入的申购费已从份额中扣除，必须同步计入费用合计，否则费用展示系统性偏低
  if(initial > 0) totalFees += initial * buyFee;
  ```
- IRR 现金流按时点落位（`calcIRR()`）：
  ```javascript
  // F-N45：按真实现金流发生时点落位——月初扣款首期在 t=0（与初始投入同时点），月末扣款首期在 t=1；期末回收统一在 t=months
  var cashFlows = [];
  for(var t = 0; t <= months; t++) cashFlows.push(0);
  cashFlows[0] = -initial;
  for(var t = 0; t < months; t++){
    var slot = monthStart ? t : t + 1;
    cashFlows[slot] -= monthly;
  }
  cashFlows[months] += finalValue;
  ```
- 非月初分支与旧实现完全等价（t=0 初始、t=1..months 月投、t=months 回收）；月初分支改为 t=0 首期、t=1..months−1 后续、t=months 回收。原端点异号校验、二分、残差复核与年化复利换算均保留。
