## N210 公式框 m² 分级与代码 ft² 分级冲突

- 问题：公式框按 m²（≤1.0 小张 / 1.0–2.0 中张 / >2.0 大张）描述，代码与 info-box 按 ft²（≥25 大皮 / 15–25 中皮 / 8–15 小皮 / <8 碎皮）；22 ft² 在公式框口径下判「大张」、代码判「中皮」。
- 修复 `tools/leather/area-20.html`：公式框统一为 ft² 阈值，并把「综合定级取较低等级」改为实际逻辑「层位（≥0.8mm 头层，否则二层）+ 面积等级」；补校验说明。英文映射同步替换。
- 结果：22 ft² → 中皮（2.5mm 头层 → 头层中皮），与结果卡、info-box、深解一致。

## N211 空值/负值仍出等级

- 问题：`num()` 把空值/非数字返回 0，`calc()` 仅加红框仍按 0 分级并写历史，清空表单会得到「二层薄皮 / 碎皮 / 二层碎皮」。
- 修复：`calc()` 改为读取原始字符串，分别校验 `trim()!=='' && isFinite && >0`；任一非法即标红对应字段、清空结果与 `lastResult`、提示「请填写有效的厚度与面积（均需大于 0）」并 return，不再写历史。
