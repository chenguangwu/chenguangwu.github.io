# CE-N10：LCOE 零折现与明细口径

- 原问题：零折现时主计算被分母守卫拦截。经复核，主结果与公式说明此前已由 `5c4ba68bad` 修复，但零折现时明细仍用 0/0 得到 NaN，趋势图直接拒绝 r=0；很小的非零 r 会因浮点消减让主结果也失效。
- 修复：`tools/energy/lcoe.html` 统一主结果、明细与趋势曲线的资本回收因子；r=0 使用 1/n，正折现率使用 `expm1` / `log1p` 避免接近 0 时消减。主结果和增强层统一有效输入判断；无效时清除旧表、差异、图表并禁止导出；零投资、零运维和零折现保留为合法输入。英文结果标签同步。
- 验证：`node scripts/verify_lcoe_zero_discount.cjs` 覆盖 r=0、1e-18、零成本、零年限、表格、曲线和恢复；旧源码执行专项测试会失败。`node scripts/verify_energy_calc.js lcoe` 4/4 通过。本地 Chrome 中英文交互验证：500 万元、20 年、零折现、10 万元/年、120 万 kWh/年 → CRF=0.0500、LCOE=0.292；6% → CRF=0.0872、LCOE=0.447；零年限清空明细和曲线，无页面异常。
