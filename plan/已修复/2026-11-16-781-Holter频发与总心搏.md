# 781 批：Holter 频发判定、总心搏输入与持续室速边界（D-N96 / D-N97 / D-N99）

## 修复
- **D-N96**：频发判定改为 `effHr = pvcHr>0 ? pvcHr : pvcTotal/24`，
  未填每小时时按 24h 总量折算，8,500 次/24h 不再被判「偶发」。
- **D-N97**：新增「24h 总心搏数」输入（默认 100000），负荷按录入值计算，
  12,000/98,000 = 12.2%，与深解示例一致；公式框与明细同步说明。
- **D-N99**：持续室速判定 `vtSec>30` → `vtSec>=30`，提示语与信息框统一为「≥30 秒」，
  与同页引据「非持续(<30s)/持续(≥30s)」一致。
