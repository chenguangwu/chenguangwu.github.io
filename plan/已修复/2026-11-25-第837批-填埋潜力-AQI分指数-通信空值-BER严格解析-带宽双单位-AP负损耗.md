## 1. eco/landfill-methane.html — 算例与模型口径不一致

- **问题**：深度解析示例「1 万 t × 40% × 0.05 = 200 m³」却写成「约 200 万 m³」；把简单乘积称为 IPCC 一阶模型年排放；meta/SEO 承诺回收发电减排。
- **修复**：示例改为与页面公式同源的完整算例（1×10⁷ kg、DOC 0.4、MCF 0.8、体积比 0.5 ⇒ 2.13×10⁶ kg ≈ 2.97×10⁶ m³），明确「产生潜力、非当年实际排放」；页面追加黄色提示，说明不含 FOD 时间衰减、氧化因子、收集率与发电效率；meta/og/JSON-LD、简介、功能特点、公式说明统一撤掉「年排放/回收发电减排」；新增 kg→m³（0.717 kg/m³）输出；DOC/MCF/体积比限定 0–1，有机物量 ≥ 0。
- **真机**：默认输出含「CH₄ 产生潜力 / 累计产生潜力」；DOC=1.2 显示「比例超出范围不计算」。

## 2. eco/aqi-converter.html — 单污染物分指数误称整体 AQI

- **问题**：只按一种污染物插值，却把结果称为整体 AQI；FAQ 自己说整体取最大；反向模式仅凭整体 AQI + 所选污染物反推浓度，数学上不唯一。
- **修复**：结果标题改为「污染物分指数 IAQI（非整体 AQI）」，卡片改「IAQI 分指数」；反向输入标签改「目标 IAQI（指定污染物）」；反向结果增加提示「整体 AQI 由各污染物 IAQI 最大值决定，不能仅凭整体 AQI 与该污染物唯一反推浓度」；表头改「若整体 AQI=…，各污染物分别达到该 IAQI 时的浓度（仅作反查参考）」；简介/meta/JSON-LD 同步；空输入不再按 0 计算。
- **真机**：PM2.5=349 输出 IAQI 379/严重污染且不再出现「空气质量指数 (AQI)」；a2c 模式出现唯一性提示。

## 3. telecom/distance-power-frequency.html — 空参数按 0、dBm/dBi 混淆

- **问题**：`getV()` 把空值返回 0，漏填增益/功率会得到看似合理的距离；结果卡把 `Pt(dBm)+Gt+Gr` 标成「收发总增益（dB）」，把 dBm 与 dBi 直接相加。
- **修复**：五个输入逐项判空（0 dBm/0 dBi 合法，需显式填写），空值直接阻断并提示；无效数字标红；结果卡改为「到达接收点功率（dBm）」并追加说明：dBm 与 dBi 不能直接相加，该值是同一 dBm 参考下的合计，不是天线总增益。
- **真机**：清空发射功率出现「留空不按 0 处理」；默认结果含「到达接收点功率」及相加口径说明。

## 4. telecom/ber-snr.html — 科学计数尾随字符被部分解析

- **问题**：`parseFloat('1e-5abc')` 静默取 `1e-5`，把非法输入当作合法 BER 计算。
- **修复**：反向 BER 输入改用完整数字/科学计数正则 `^[+]?(\d+(\.\d*)?|\.\d+)([eE][+-]?\d+)?$`，尾随单位或字符直接报「BER 格式无效」；再校验有限且在 (0,1)。
- **真机**：`1e-5abc` 报格式无效；合法 `1e-5` + 64-QAM 仍输出 17.79 dB。

## 5. telecom/bandwidth-calculator.html — 时间进位与容量单位口径

- **问题**：`fmtTime()` 分别对分/秒取整，119.6 秒会显示「1 分 60 秒」；文件大小用 `fSize*sUnit`（1/1024/…）却标 MB/GB，实际是 MiB/GiB，十进制与二进制混用。
- **修复**：`fmtTime()` 先把总秒四舍五入再拆分，杜绝 60 秒；大小单位改为「每单位字节数」：B、KB/MB/GB（10³/10⁶/10⁹）、KiB/MiB/GiB/TiB（2¹⁰/2²⁰/2³⁰/2⁴⁰）；下载时间按字节数 ×8 ÷(Mbps×10⁶×效率)；步骤 3 同时给出字节数、十进制 MB 与二进制 MiB；输出卡与提示文案、算例、FAQ、公式全部改成双口径并说明 Windows 的「GB」多为 GiB。
- **真机**：`fmtTime(119.6)` = 「2 分 0 秒」；1 GB 十进制显示 1000.00 MB = 953.67 MiB。

## 6. telecom/ap-coverage.html — 负损耗/负衰落裕量抬高半径

- **问题**：`extra`、`fade` 未校验非负，填负值等于假设信号被放大，MAPL 与覆盖半径虚高；卡片「总损耗余量」措辞易误解。
- **修复**：附加损耗与衰落余量必须 ≥ 0，负值直接阻断并说明后果；频率/参数改有限值校验；卡片改名「扣除的总损耗」；FAQ 明确两者均须 ≥ 0。
- **真机**：附加损耗 -10 显示「必须 ≥ 0 dB」；恢复 10 后正常输出 MAPL 89.00 dB。
