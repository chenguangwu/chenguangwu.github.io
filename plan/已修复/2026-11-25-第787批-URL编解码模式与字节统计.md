## 改动 `tools/it/url-encode.html`

- `decodeUrl()` 按当前模式选择 `decodeURI` / `decodeURIComponent`：URI 模式保留 `%2F`、`%3F` 等结构编码，组件模式正常还原。
- 解码不再 `trim()` 输入；空态判断改为严格空串，首尾空格与换行原样保留。
- 新增 `__urlResultValid`：输入变化立即清空旧输出；编码/解码/规范化失败清空结果并重置统计；`copyOutput()` 在无有效结果时拒绝复制。
- URL 解析失败隐藏旧结果；解析输入变化即隐藏结果；`copyParseResult()` 失败时不再静默。
- 统计改为同时显示输入/输出字符数与 UTF-8 字节数，变化率统一按字节计算；公式说明同步。
- `encodeURI` 文案改为“保留 : / ? # @ ! $ & ' ( ) * + , ; =，但 [ 与 ] 实际编码为 %5B/%5D”，并提示 IPv6 用 URL API 解析。
