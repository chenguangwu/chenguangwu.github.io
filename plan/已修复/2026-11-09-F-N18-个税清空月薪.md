# 复核失败重做批次 · 申请再次复核

- 原复核条目：F-N18 个税工具清空月薪仍生成零税和奖金结论
- 页面：`tools/finance/tax-calculator.html`
- 失败点：清空「税前月薪」后调用计算，页面仍显示税额 ¥0.00、税后 ¥0.00 和年终奖计税对比结论。
- 根因：`calculate()` 用 `parseFloat(el.value) || 0` 把空值兜底成 0，且 `__taxCheck()` 只拒绝负值，空值被当 0 参与计算，输出零税结论。
- 修复位点：`calculate()` 在读取 salary 前检测空值——`__salaryRaw===''` 时调用 `__taxBlock('请填写税前月薪（元）')` 并 return；显式填 0 仍按 0 计算（合法）。
- 证据：`verify_finance_calc.js` 新增用例（salary 空 → expect「请填写税前月薪（元）」）；finance 分类 382/382 通过。
- 判别力实测：`discriminate_check.js verify_finance_calc.js` 382/382 变红、逃生 0；`audit_verify_input_ids.js` 僵尸 id 0。
