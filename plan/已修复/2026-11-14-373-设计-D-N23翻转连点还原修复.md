# D-N23 翻转快速连点两次不能还原 — 修复（中，源码缺陷已确认并修复）

## 缺陷
`tools/design/image-flipper.html` 的 `flip(mode)` 同步读 `currentImg || origImg` 作为绘制源（行 291），但 `currentImg` 仅在翻转完成后异步 `newImg.onload` 回调里更新（原行 326-328：
```js
const newImg = new Image();
newImg.onload = () => { currentImg = newImg; };
newImg.src = lastURL;
```
）。快速连点「水平翻转」两次时，第二次点击发生在第一次的 `onload` 之前，`currentImg` 仍为旧值（null 或上一张），两次都基于 `origImg` 生成同一张单次翻转图，无法还原；页面「翻过去再翻回来」说明不成立。

## 修复（最小、彻底、零功能退化）
将「下次翻转源」改为**同步**更新：翻转绘制成功后直接把本次画布赋给 `currentImg`，canvas 可直接作为后续 `drawImage` 源（水平→水平即还原）。
```js
// 同步更新当前图，供下一次翻转累积变换：原 newImg.onload 异步更新会在快速连点时仍读旧图，
// 导致「翻过去再翻回来」两次翻转无法还原；canvas 可直接作为后续 drawImage 源，水平→水平即还原。
currentImg = canvas;
```
- `currentImg` 仅在 `__flipperState()` 调试接口（行 347）用作 `.src`，且已有 `origImg.src` fallback，改为 canvas 后无副作用；下载/复制路径用 `lastURL`/`lastBlob`，不依赖 `currentImg`。
- 换图时 `fileInput` change 已 `currentImg = null`，下次翻转回到 `origImg`，正确。
