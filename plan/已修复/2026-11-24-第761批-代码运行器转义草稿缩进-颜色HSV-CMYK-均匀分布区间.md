# 第761批修复记录（2026-11-24）

## 1. 代码运行器：JS 含 `</script>` / CSS 含 `</style>` 被截断
- **问题**：源码直接拼进 iframe `srcdoc` 的内联 `<script>`/`<style>`，HTML 解析器把字符串或注释里的结束标签当成元素结束，代码被截断、语法错误。
- **修复**（`tools/it/code-runner.html`）：注入前 `safeJs = js.replace(/<\/script/gi, '<\\/script')`、`safeCss = css.replace(/<\/style/gi, '<\\/style')`。JS/CSS 中 `\/` 均为转义斜杠，运行时值不变，但解析器不再识别为结束标签；控制台捕获与 CSP 不变。

## 2. 代码运行器：示例覆盖草稿、刷新丢失、Python 算例错误
- **问题**：点示例直接覆盖三栏且无恢复；刷新总回默认示例；正文用 `print(2**10)` 但实际只运行 JavaScript。
- **修复**：新增 `getDraft/saveDraft/restoreDraft`，三栏输入 300ms 防抖写入 `localStorage(codeRunnerDraftV1)`，初始化优先恢复草稿；示例切换前保存 `__crUndoDraft` 并启用「撤销示例」按钮，可完整恢复三栏；「清空并清除草稿」同时删除本地草稿；正文算例改为 `console.log(2**10)` → `1024`，并明确不提供 Python 解释器。

## 3. 代码运行器：选区按 Tab 删除内容
- **问题**：Tab 处理始终把选区替换为两个空格，选中多行即删除；无 Shift+Tab。
- **修复**：新增 `applyTabIndent(el, outdent)`：单光标插入/回退两个空格；多行选区按行首加/减最多两个空格，按行累计位移并保留选区；末尾仅在有 `dispatchEvent` 时触发自动预览。兼容原生 `setRangeText` 与测试桩的切片回退。

## 4. 颜色转换：文案声称 HSV/CMYK 互转但无输入
- **问题**：描述称支持 HEX/RGB/HSL/CMYK/HSV 互转，实际只解析 HEX/RGB/HSL，结果区也无 HSV。
- **修复**：新增 `rgbToHsv/hsvToRgb/cmykToRgb`，`parseColor` 接受 `hsv()/hsb()`（H 0–360、S/V 0–100%）与 `cmyk()`（四分量 0–100%），超范围拒绝；结果区新增 HSV 卡片；占位与错误提示同步列出 hsv/cmyk；公式说明改为「接受 HEX、RGB(A)、HSL(A)、HSV/HSB、CMYK 输入」。中英文映射与占位 key 同步。

## 5. 均匀分布：区间外密度仍为 1/(b−a)
- **问题**：`f(x)` 恒为 `1/(b−a)`，U(0,1) 取 x=2 显示 1；x 为空时把 NaN 带进结果。
- **修复**（`tools/it/uniform-distribution.html`）：新增 `inside=(x>=a&&x<=b)` 与 `pdfX=inside?pdf:0`；大结果与分步计算按区间内外分别显示；单独保留「区间内常数密度 1/(b−a)」卡片；x 空或非有限值时明确报「请输入有效的有限数值 x」；FAQ 注明端点按闭区间计。
