## 206 单利清空后延迟任务回填（simple-interest.html）
- 退回：`clearAll()` 未取消 `__simple_interest_timer`，1s 后节流任务把占位文案「请输入数据」重新记入历史。
- 修复：`clearAll()` 开头 `clearTimeout(__simple_interest_timer); __simple_interest_timer=null;`（不设 skip，避免阻塞后续 calc）。
- 验证：JSDOM `calc();calc();clearAll()` 等 1.3s，历史不含「请输入数据」。

## 207 增值税删除历史数值格式失配（vat-calculator.html）
- 退回：自定义历史金额存数字 2500、自动历史快照存字符串「2500.00」，`deleteHistory()` 用 `String()` 比较导致匹配失败、自动历史残留。
- 修复：金额与税率比较改用 `Number()` 数值等价（`Number(d.amount)===Number(removed.amount)`）。
- 验证：JSDOM 输入 2500.00 保存后删自定义第 0 条，自动历史不再含 2500。

## 208 工资计算空字段静默用默认值（salary-calculator.html）
- 退回：threshold/monthsPerYear/baseSalary 空串时 `__salaryNum` 回退默认值，空态仍给结论。
- 修复：`calculate()` 开头对这三个字段空串统一守卫，提示「请填写…留空不计算（数字 0 合法）」并清空结果；区分空串与 0。
- 验证：JSDOM 清空 threshold 提示填写、无金额结果、恢复填写后重新出结果。

## 209 工资条空缴费基数仍计算（payroll-calculator.html）
- 退回：空 base（rawNum 返回 NaN）被 `var base = isFinite(baseRaw)?baseRaw:salary` 回退成 salary，仍算出五险一金；数字 0 应合法。
- 修复：baseRaw 非有限数（空串）时即 `fail()` 提示填写并停算；`baseRaw<0` 单独判负；0 保持合法。
- 验证：JSDOM 清空 base 提示填写、base=0 不再报「请填写」。
