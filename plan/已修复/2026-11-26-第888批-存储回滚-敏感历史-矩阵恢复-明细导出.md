# 第888批：存储失败回滚、敏感历史、矩阵恢复与明细导出

日期：2026-11-26　范围：10 个扫描任务 / 31 个工具页

## 1. 生活记录工具存储失败无提示且内存与记录不一致

`tools/life/reminder-cycle.html`、`tools/life/cycle-pruning-lawn.html`

- `save()` / `saveLawns()` / `saveLogs()` 改为 `try/catch` 返回布尔值；新增 `__saveFail()` 中英提示。
- 添加、删除、标记清洁、快速记录、手工记录、删除记录均先保存内存快照，写入失败立即回滚并提示，不再出现“界面已改、刷新即丢”。
- 真机注入 `localStorage.setItem` 抛异常：`save()`、`saveLawns()` 均返回 `false`，页面出现“保存失败…本次修改已撤销”。

## 2. 敏感输入通用历史快照可能保存密码

`tools/it/bcrypt.html`、`tools/life/detector-checker-strength.html`

- bcrypt 页面加载即清除本页历史键，`__bcryptExtras()` 直接返回，不再记录密码原文/哈希。
- 密码强度页加载时清洗历史记录中的 `pwdInput/password/pass/token/secret`，记录快照前删除同类键。
- 真机：bcrypt 输入虚构密码后历史键为空；强度页预置含 `pwdInput` 的旧记录，刷新后仅剩 `foo`，明文键被移除。

## 3. 电话和短信二维码联系方式被自动保存历史

`tools/it/phone-qr.html`、`tools/it/sms-qr.html`

- 新增 `qrSaveHistory` 复选框，默认不勾选，文案说明“会保存号码/短信内容”。
- 未勾选时扩展逻辑直接返回；页面加载清空旧历史，避免默认收集残留。
- 真机：两页复选框默认 `checked=false`；电话页未勾选历史为空，勾选后才生成记录。

## 4. 矩阵工具历史恢复不完整

`tools/it/matrix-inverter.html`、`tools/it/matrix-determinant.html`、`tools/it/matrix-transpose.html`、`tools/it/matrix-multiplier.html`

- 快照显式包含全部矩阵单元格（含空单元格），移除记录时 `keys.length>12` 截断。
- 新增 `__mxRestore(rec)`：先校验历史维度与全部单元格键，再设回行列数、`build()` 重建、逐格回填，最后 `calculate()`；不再把旧维度记录拼到当前矩阵上。
- 旧版缺单元格记录提示“无法完整恢复，未改动当前矩阵”并拒绝恢复。
- 真机 4×4 逆矩阵：历史记录 20 键，切到 2×2 后恢复成功，16 格合计 136；缺格伪造记录被拒绝且当前矩阵不变。

## 5. 统计工具非法样本被静默截断或丢弃

`tools/science/mean-calculator.html`、`tools/science/median-calculator.html`

- `parseData` 返回 `{data,bad}`；遇到非法 token 停止计算，列出非法样本并说明“非数字项不会被静默丢弃”。
- 真机输入 `1, abc, 3`：输出“非法样本：abc。请修正或删除后再计算…”，不再按 `1,3` 出均值。

## 6. 农业计算失败仍记录历史与附表

`tools/agriculture/calc-36.html`、`calculator-calc-density.html`、`estimate-area-density.html`、`nongjijuzuoyexiaolv-mu-xiaoshi-duibi.html`

- 扩展逻辑先计算 `__tbScore`，失败直接返回，不写历史、不渲染附表/趋势。
- 同时清理本页历史中 `__tbScore<1` 的旧无效记录。
- 真机 `ET₀=-1`：主计算提示 Kc/效率范围错误，历史条数为 0。
