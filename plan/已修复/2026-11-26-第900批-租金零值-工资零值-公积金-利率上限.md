## 修复内容

### 租金回报率与对比

- 贷款年限按整月换算后至少 1 个月；0.01 年不再产生 0 期、Infinity 月供，提示“按整月换算后不足 1 个月”。
- `addCompare()` 与单套计算共用原始输入口径：逐项读取总价、租金、物业/取暖/装修/维修/中介/税费；空值提示且不加入对比，合法 0 原样保留，不再用 300/2400/5000 等默认费用替换。
- 对比数据记录 `rentMode`，年租金输入按 `/12` 折算月租金，与单套计算一致；卡片显示六项费用明细，便于核对参与计算的参数。

### 工资

- 空值字段列表加入 `salary`：清空工资提示“请填写工资，留空不计算（数字 0 为合法输入）”，并清空月/年/累计结果。
- 明确输入 0 时不再被空值拦截；工资为 0 时社保/公积金基数按 0 计算，输出税额 0、税后 0，避免默认 20,000 基数造成“负收入停止计算”。

### 公积金

- 工资基数、个人/单位比例、缴存月数、余额倍数分别检查原始空串；空值明确提示，0 比例/0 余额合法。
- 缴存月数要求非负整数，比例限制 0–100%，余额倍数必须大于 0。
- 新增可选“已有账户余额”，账户余额估算改为“当前月缴存额 × 月数 + 已有余额”；结果注明未计历史工资变化、利息和提取，不代表真实账户余额。
- 当地最高额度留空或 ≤0 时明确显示“未设上限”，不再静默套默认。

### 房贷

- 年利率限制为 0–100%，100000% 直接拒绝并给出带当前输入的提示。
- 月供计算使用 `payRate`：月利率低于 `1e-9` 时按零利率处理，避免 `(1+r)^n` 浮点精度归零导致 factor−1=0、月供 Infinity；极低利率输出有限的本金均摊值。
- 导出 CSV 使用同一稳定利率口径。

### 贷款摊销

- 年限入口统一限制为 1–1000 的整数年（最多 12000 期）；1001 年明确报错，不再静默截断为 12000 期。
- 等额本息、等额本金、先息后本、气球贷共用入口校验；保留 `generateSchedule` 12000 期防御上限。

### 股票盈亏

- 佣金费率、印花税率、过户费率、最低佣金四项先检查原始空串；任一为空提示补全并停止计算，明确输入 0 仍合法。
- 不再用 `parseFloat(...) || 0` 把未填写费率当成零费率。

### 增值税

- 单笔结果标签改为“增值税额（按输入税率拆分）”，批量表头改为“增值税额（按输入税率）”。
- 结果区增加说明：仅按输入税率做价税拆分，未考虑进项抵扣、征收方式、优惠和申报口径，不等于实际应纳（应缴）税额。
- 页面描述与 `i18n/tools/finance.json` 简介同步改为“价税拆分参考，不替代进项抵扣和实际申报”；英文层补对应译文。
- 英文态动态结果使用 `__vatIsEn()` 输出英文标签与说明。

### 闰年查询

- `check()` 先读取年份、范围原始字符串；任一为空只提示“请填写…，留空不会按 0 计算”，不改写输入框。
- 删除无效分支把 `Number('') = 0` 写回范围字段的逻辑；非法非空值仍按整数范围校验。

### 工作日

- 排除周六/周日复选框增加 `onchange="calc()"`。
- 法定节假日、调休上班日文本框增加 `oninput="calc()"`；修改条件立即重算，不再显示旧结果。
