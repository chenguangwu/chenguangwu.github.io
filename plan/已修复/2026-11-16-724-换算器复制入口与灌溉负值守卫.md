# 724 批：换算器复制入口与灌溉负值守卫

日期：2026-11-16

## 1. 密度/磁场/辐射换算器补「复制结果」（LF-V3）
- 问题：三页 FAQ 与 opt-guide 承诺「支持复制与导出」，工具栏只有换算/导出/清空，无任何复制入口。
- 修复：三页工具栏新增「📋 复制结果」按钮 + `copyRes()`：
  - 读取 `#resultBox` 的 `innerText`（回退 `textContent`）并压缩空白；
  - 空态（「请输入数值进行换算」/「请输入有效数值」）只提示「暂无可复制的结果」，不复制提示语；
  - 正常结果交 `ToolBox.copyText`，无 ToolBox 时回退 `navigator.clipboard.writeText`；
  - 中英文案由 `TBKit.util.isEn()` 决定。
- 门禁（`life/density-converter`）：
  - 替换 `ToolBox.copyText` 采集入参，断言以「基准：」开头 ⇒ `CP OK`；
  - 清空结果区后调用 `copyRes()`，采集调用次数为 0 ⇒ `CPE 0`。

## 2. 灌溉均匀度负值/零均值守卫核销（10-28）
- 源码已有守卫：`vals.some(v => v < 0)` ⇒「收集水量不能为负值」；`!(avg > 0)` ⇒「收集水量均值必须大于 0，才能计算均匀度」。
- 本批补门禁：
  - `values = "-10 -12"` ⇒ 负值提示；
  - `values = "0 0"` ⇒ 零均值提示。
- 口径说明：单个测点 0 允许（滴头完全堵塞是真实观测），只拦截负值与零均值。
