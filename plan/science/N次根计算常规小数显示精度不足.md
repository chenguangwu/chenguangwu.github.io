# N 次根计算常规小数显示精度不足

## 问题
格式化函数对绝对值大于 0.001 的数仍使用默认 `toLocaleString()`，默认最多三位小数。例如 1.0004 显示为 1、0.0011 显示为 0.001；输入、根及验证步骤都复用该函数，用户无法看出计算值差异。静态分析并用 Node 核对格式化，浏览器表现待核验。

## 解决方案
以有效数字或用户可选精度输出，明确近似标记，对很大或很小的值使用科学计数法；确保输入回显、结果和验证步骤的精度一致，覆盖 1.0004、0.0011 和大数值。
