# 摩尔质量大下标超出安全整数范围

## 问题

`tools/science/molar-mass-calculator.html` 用 JavaScript Number 解析并累计原子个数，只检查有限且大于零，未检查安全整数范围或嵌套乘积。例如 `H9007199254740993` 的下标会被舍入为 `9007199254740992` 后继续计算，显示的原子数与输入不同。非常大的嵌套乘积还可能溢出。静态检查所得，页面表现待核验。

## 解决方案

为化学式长度、下标和累计原子数设置合理上限，逐次检查安全整数及乘法溢出；超限时明确提示，避免输出看似精确的结果。若有大分子支持需求，使用精确整数计算计数并说明质量精度。覆盖安全边界、嵌套倍数及普通化学式。
