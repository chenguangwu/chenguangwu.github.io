# 波长转 RGB 历史记录缺少英文和存储失败反馈

- 受影响工具路径：`tools/science/wavelength-to-rgb.html`。
- 问题：历史记录空态、色名、保存反馈和时间格式使用中文或固定中文区域设置，英文用户查看已保存数据时可能出现混合语言。写入 `localStorage` 未捕获配额或浏览器限制异常，异常时无法显示预期的保存失败提示。
- 解决方案：按当前语言渲染色名、空态和反馈，并使用对应区域的日期格式；对存储读写及内容结构做容错，失败时保留当前结果并给出可理解提示。覆盖语言切换、已有历史和存储不可用场景。
- 证据：静态检查 `saveHistory()` 与 `renderHistory()`；运行时翻译和存储异常表现待验证。
