# 概率分布：指数分位端点与小概率精度

## 问题
指数分布的反函数拒绝概率 0，但其 0 分位数为 0。累计概率使用 `1 - exp(-λx)`，小概率会因浮点相消归零；例如 λ=1、x=1e-17，计算结果为 0，实际概率接近 1e-17。区间概率通过相减 CDF，在尾部也可能丢失有效数字。静态分析并在 Node 中核对表达式，页面运行待核验。

## 解决方案
允许 p=0 并返回 0，明确 p=1 的无穷分位数；使用 `expm1`、`log1p` 和稳定的尾概率差计算，验证零端点、极小概率、远尾和一般参数。
