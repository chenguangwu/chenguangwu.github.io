# 平均数工具极小正数调和平均发生下溢

## 问题

调和平均直接累加每个样本的倒数。输入合法的极小正数如 `1e-309` 时，倒数超过 JavaScript 浮点范围而成为 Infinity，随后 `n / Infinity` 得到 0；实际单个正样本的调和平均应等于该样本。页面仍展示调和平均并输出不等式勾选，无法区分有效零值与中间运算溢出。静态分析，页面表现待核验。

## 解决方案

用缩放或其他稳定算法计算调和平均，并对中间及最终结果做有限性检查；确实超出可表示范围时明确提示，不输出无依据的勾选结论。用单个及混合极小正数、普通正数和范围边界验证，结果采用可辨别小数的科学计数格式。
