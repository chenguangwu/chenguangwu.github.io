# 分压器零输入电压时比例显示异常

## 问题

正向计算允许 Vin 为 0，但分压比使用 `Vout / Vin` 计算，得到 `0 / 0`，界面将 NaN 替换为破折号。对于已知且均为正数的 R1、R2，电阻决定的理想分压比例仍可表示为 `R2 / (R1 + R2)`，当前展示会让用户以为比例不可计算。静态分析结论，页面表现待验证。

## 解决方案

依据电阻比例计算理想分压比，说明它与零输入时实际输出电压的区别；覆盖 Vin 为零、正值和负值时的显示、历史及导出一致性。
