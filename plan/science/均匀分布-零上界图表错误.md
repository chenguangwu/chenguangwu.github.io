# 均匀分布：上界为零时图表绘制错误

受影响工具：`tools/science/probability-calculator.html`

均匀分布图表用 `parseFloat(b) || 1` 读取上界。上界 0 可以与负下界组成合法区间，例如 `a=-1, b=0`，但图表按 `[-1,1]` 绘制，与用户输入和主计算的区间不一致。该结论从绘图源码确认，需在浏览器复核结果、横轴与图形。

解决方案：图表复用主计算已校验的上下界，严格检查有限数与 `a < b`，不要把 0 替换为默认值；输入无效时清除或禁用旧图。验证 `[-1,0]`、`[0,1]`、普通区间、相等和反向边界，并检查中英文图表说明。
