# 离散概率：大输入可能使页面失去响应

受影响工具：`tools/science/probability-calculator.html`

`binomialCDF(k,n,p)` 从 0 累加到 `floor(k)`，即使 `k` 已远大于 `n` 仍继续循环；`poissonCDF(k,lambda)` 也循环到 `k`，且每次调用的概率质量函数又从 2 循环至当前项。输入框未见与运算量相配套的上限，较大的 k 或 n 可使主线程运行很久，阻塞页面。此结论基于源码复杂度分析；实际阈值需在有超时和可终止的隔离环境测试，不应在普通用户页面直接试极大值。

解决方案：利用分布支持域缩小边界，采用稳定的累积算法并为大输入提供明确限制或后台可取消计算；不以错误的截断值冒充精确结果。验证 `k > n`、大 n/k、极端概率、普通值与参考结果，同时测试超时、取消和页面响应。
