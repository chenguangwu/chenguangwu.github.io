# 指数计算溢出下溢与步骤不一致

## 问题

指数计算将浮点溢出显示为无穷，无法与数学上的有限结果区分；极小正结果下溢时显示为精确 0。步骤中的 e⁻ˣ 通过 `1 / exp(x)` 计算，而结果卡片直接用 `exp(-x)`，如 x=710 时前者因 exp(x) 溢出得到 0，后者仍为非零值，步骤与结果不一致。静态分析所得，浏览器展示待核验。

## 解决方案

区分溢出、下溢与数学意义上的无穷和零，并提供数量级或明确精度范围提示；结果和步骤共用稳定计算值，检查双曲函数在极小及极大输入下的精度。覆盖 ±710、接近 0 和普通输入。
