# SI 换算中间值溢出导致有限结果丢失

## 问题

普通单位换算先计算 `value * fromFactor` 再除以 `toFactor`。当中间值超出 JavaScript 数值范围时，即使最终数学结果可表示，也会显示“未定义”。例如长度从 Ym 到 Ym、输入 `1e300`，中间乘以 `1e24` 溢出，而正确结果仍为 `1e300`。静态分析确认计算顺序，页面交互仍需复现。

## 解决方案

使用适合极端数量级的换算策略，避免不必要的中间溢出或下溢；对最终结果确实超出可表示范围的情况单独提示。验证同单位的极大值和极小值、跨数量级及普通输入，检查结果与说明一致。
