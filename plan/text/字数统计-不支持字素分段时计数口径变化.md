# 字数统计：字素分段不可用时统计口径改变

受影响工具：`tools/text/stats-1.html`

问题：页面说明字符按 Unicode 字素簇统计，但 `Intl.Segmenter` 不可用时直接以 `Array.from` 统计码点。组合重音或多个码点组成的 emoji 在降级环境可能被计为多个字符，与页面承诺以及支持分段的浏览器结果不一致。

解决方案：采用兼容的字素分段实现，或明确显示降级口径并说明计数差异；在目标浏览器范围内覆盖组合重音、肤色修饰、旗帜和 ZWJ 表情，同时核对含空白和不含空白计数。

证据范围：静态代码分析，需在不提供 Segmenter 的环境实际验证。
