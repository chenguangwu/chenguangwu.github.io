# 种子发芽率：负数和缺失记录仍生成质量结论

## 问题描述
逐日发芽数直接转换数字并将空值当作 0，没有检查负数、整数或每天数据是否填写；只校验总和不得超过供试数。输入负数可以得到负发芽率或抵消其他天的过大值；缺测天数则被误认为没有发芽，仍给出种子质量等级。苗长空值也按 0 计算活力指数。源码静态分析，需复核页面交互。

## 解决方案
区分未观测、明确记录为零和无效值；逐日数量和供试数要求非负整数并检查累计范围。缺测时停止相关指标或提示结果不完整，未填写苗长时不计算活力指数。发芽势天数应与已覆盖的观察天数匹配。
