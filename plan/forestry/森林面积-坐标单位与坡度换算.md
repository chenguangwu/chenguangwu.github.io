# 森林面积坐标单位与坡度换算

## 问题

多边形输入提示可使用 GPS 坐标，但计算直接将坐标作为米制平面坐标套用鞋带公式；经纬度不能直接得到平方米。结果又统一乘坡度余弦，未区分坐标面积已是水平投影还是坡面面积，可能重复换算。空坐标按 0 处理，坡度缺少有效范围检查，也可能产生错误甚至负面积。以上为静态分析。

## 解决方案

明确仅接受米制平面坐标，或提供明确坐标系的经纬度面积算法；区分坡面与水平面积及换算方向。逐项校验顶点、坐标和坡度，提示无效或不足的输入，并用已知面积与水平投影案例验证。
