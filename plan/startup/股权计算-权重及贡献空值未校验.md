# 股权计算：权重及贡献空值未校验

## 问题描述

权重和创始人贡献使用 `parseFloat(...) || 0`，空值被当作 0 参与分配；期权池清空也按 0 计算。贡献值仅检查非负，未限制页面标注为 0–10 的创意及资源评分；权重没有非负校验，负权重可能产生负个人得分和负股权比例，只要总分仍为正就会继续输出。静态分析，交互待复核。

## 解决方案

按当前模式校验必需字段，区分未填写与明确的 0；约束权重非负、评分符合标注范围，并阻止负股权结果。期权池为空应提示填写，覆盖权重为负、评分越界、空字段和正常零贡献。
