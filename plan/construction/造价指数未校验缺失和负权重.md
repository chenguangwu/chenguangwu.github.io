# 造价指数未校验缺失和负权重

受影响工具：`tools/construction/gongchengzaojiazhishujisuan.html`

## 问题

`readInputs()` 标记空项并返回 `valid=false`，但 `calc()` 未检查该标记；报告期价格或权重为空会按 0 参与计算，页面仍输出涨跌结论。负报告期价格和负权重也未阻止；权重结果固定显示 100%，无法反映原始合计。

## 解决方案

先检查所有必填项，区分空值和明确的零值；按价格与权重语义校验负数和权重总和，失败时清除结果、图表和导出状态。分别展示原始权重合计及归一化权重，补充缺失、零值、负权重和正常算例。
