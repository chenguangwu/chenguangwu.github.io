# 工程造价调差输入与合同口径

受影响工具：`tools/construction/calc-94.html`

## 问题

空值被当作 0；基期指数为 0 时 `idx` 直接返回 1，所有权重为 0 时综合系数为 0，页面仍输出报告期造价和调差额。例如基价 100 万、三项权重全为 0 会显示调差 -100 万，属于缺失参数产生的误导结果。权重被自动归一化，也无法表示合同中不参与调差的固定部分。

## 解决方案

区分空值与有效 0，校验指数、权重和基期分母，不能计算时清除结果与复制内容；显示权重归一化方式，支持固定部分和按合同约定的权重与调差公式，展示逐项贡献及计算示例。具体合同和计价口径由造价专业人员核验。
