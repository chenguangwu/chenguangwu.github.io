# 焊接缺陷帕累托：输入和主要类别判断

- 受影响工具：`tools/welding/analysis-37.html`
- 问题：解析会静默跳过无效行，接受负数及带尾随字符的数量；缺陷名称直接插入 HTML，输入标记可影响页面。A 类仅计累计占比不超过 80% 的行，例如 90、10 两类会给出 A 类 0 项，无法用于识别占主要比例的首要缺陷。
- 解决方案：逐行严格校验有限非负整数并报告错误行，名称按文本安全渲染，明确重复类别合并规则。明确 80% 边界策略，提供包含首次跨过阈值类别的常见帕累托口径并标注，增加图形和数据复制以便复核。
- 验证建议：覆盖 90/10、恰好 80%、重复名称、负数、无效行及含 HTML 字符的名称。
