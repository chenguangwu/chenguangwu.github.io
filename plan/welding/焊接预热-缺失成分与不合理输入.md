# 焊接预热：缺失成分及输入边界

- 受影响工具：`tools/welding/temp-time-6.html`
- 问题：板厚和碳当量只检查是否为数字，负数仍可得到“焊接性优”或“无需预热”。元素输入留空被按 0 计入简化碳当量，可能把未知成分误读为零；经验式输出推荐温度和保温时间，未充分体现材料、接头约束和工艺条件。
- 解决方案：校验板厚、碳当量和元素含量的有效范围；缺失元素不参与完整计算并明确标为未知。区分用户输入和成分估算，提供方法适用范围及依据，缺少条件时避免给出确定的无需预热结论，由合格工艺规程和专业人员确认。
- 验证建议：覆盖负值、空成分、真实零值及厚板低碳当量的判断，并核查适用依据。
