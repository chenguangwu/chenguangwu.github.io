# 焊烟通风：需求风量误当现有通风能力

- 受影响工具：`tools/welding/ventilation-protection.html`
- 问题：页面没有输入现有风量，却用估算的需求风量除以车间体积得到换气次数，再据此评为“通风不足”“良好”或“优秀”，甚至建议保持现有系统；需求越大反而可能得到越好评价。固定焊烟系数及单一浓度未充分考虑烟尘成分、局部捕集和实际暴露。
- 解决方案：分开显示估算需求与实测或设计有效风量，仅在提供可比数据和适用条件时比较；不要推断现场达标。列明计算假设与限值依据，职业卫生防护及监测由专业人员按实际污染物和场所确定。
- 验证建议：固定场所提高焊材消耗量，以及输入不同实际风量时，检查需求与结论方向；专业复核适用标准。
