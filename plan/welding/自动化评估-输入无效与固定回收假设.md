# 焊接自动化评估：输入边界与回收假设

- 受影响工具：`tools/welding/hanjiezidonghuapinggu.html`
- 问题：工作日为 0 会造成日工时除零；负产量、时间或成本也可进入回收期与推荐等级。机器人节拍、人工费和维护费使用固定比例，未纳入投资构成、停机、能耗及实际产能限制，仍按单一回收期给出“强烈推荐”。
- 解决方案：校验非负值、正工作日及合理产量；允许输入机器人节拍、人工与维护成本等，并展示简化回收期的条件和未覆盖项目。提示产能超出可用工时，提供敏感性比较而非直接决策结论。
- 验证建议：覆盖零工作日、负数、无节省、零投资及产能不足，并核对单位与年化成本。
