# 激光焊接光斑：离焦缺失及模型依据

- 受影响工具：`tools/welding/jiguanghanjieguangbanjisuan.html`
- 问题：离焦量为空时被标记无效并代入 0，仍输出焦点光斑和焊接模式；非理想光束的瑞利长度与 M² 模型关系需专业复核。仅按功率密度固定阈值判定焊接模式，未考虑材料吸收、速度和工艺条件。
- 解决方案：检查全部必需输入有效性，空离焦与实际零离焦分开；核验 M² 光束传播公式、光束直径定义和假设。说明功率密度口径及模式阈值来源，条件不足时不作确定的焊接模式判断。
- 验证建议：覆盖离焦留空、零和正负值，以及 M² 变化；用有依据的光学算例核对。
