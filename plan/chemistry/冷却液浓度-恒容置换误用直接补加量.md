# 冷却液浓度：恒容置换误用直接补加量

## 问题

页面把直接补加所需体积用于先排出同量旧液、再补入的恒容置换，但两种公式不同。例如 100 L、当前 5%、目标 10%、原液 20%，直接补加需 50 L，恒容置换需约 33.33 L；按页面建议置换 50 L 会得到 12.5%。降浓度分支同样存在偏差，目标为 0 时直接补水公式还会除零。

## 解决方案

分别推导和展示直接补加与恒容置换所需体积，校验目标可达范围及容量约束；明确 0% 等边界是否可达，结果、复制和历史保持一致，并用正反算例核验。
