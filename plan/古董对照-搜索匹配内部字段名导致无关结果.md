# 古董对照：搜索匹配内部字段名导致无关结果

- 受影响工具：`tools/antiques/porcelain-date.html`、`tools/antiques/calligraphy-style.html`、`tools/antiques/seal-identification.html`、`tools/antiques/bronze-identification.html`、`tools/antiques/furniture-style.html`
- 问题：筛选将整个数据对象 `JSON.stringify` 后进行子串搜索，包含 `key`、`name`、`period` 等内部属性名。输入 `period` 等字段名会匹配每条记录，即使展示内容没有该关键词；复制也采用同一条件，造成无关条目被复制。
- 解决方案：仅索引供用户搜索的中英文内容字段及明确维护的别名，排除属性名和内部标识；统一页面筛选和复制范围，覆盖中英文、字段名及空结果。
