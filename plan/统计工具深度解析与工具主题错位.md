# 统计工具深度解析与工具主题错位

- 问题：多页深度解析的示例沿用其他工具主题：置信区间页讲标准分；样本量估算页主要讲置信区间临界值；加权平均页讲无权重样本汇总；均值中位数页讲四分位与 P90；标准差方差页讲偏度峰度正态诊断；线性回归页讲功效估算。读者无法从示例学会当前工具的输入和结果，部分文字还会造成错误预期。
- 解决方案：分别围绕页面真实输入、公式与输出重写中英文示例和 FAQ，以可直接复现的数值展示步骤及适用限制；同步内容来源和结构化数据，并用实际计算结果校验。避免仅替换标题保留错位正文。
