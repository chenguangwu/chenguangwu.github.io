# G08 · 注入器幂等判据清单（2026-11-04）

> **递归事故背景**：包装器 `calc = function(){ __<p>_f0.apply(null, arguments) }` 中的 `__<p>_f0` 是**全局变量**。首次注入时它指向原函数；若同一页再注入一次，第二段 `var __<p>_f0 = calc` 会把该变量改成第一层包装器，第一层包装器体内引用的正是这个变量 → 包装器调用自身 → 点击即 `Maximum call stack size exceeded`。
>
> 新增任何“包装已有函数”的注入脚本，必须满足：**二次运行不新增第二层包装**。

补充核验（2026-11-04）：
- classic 包装缺 `TBKit.matrix.table` 守卫：**0 页**；
- `__orig` 包装缺 hooked 标志：**0 页**；

## 新增脚本照抄模板

```python
# 方案 1：标记变量守卫（适合 __<p>_f0 / __tb_fn0 这类全局捕获变量）
if ("var __%s_f0" % p) in s0 or ('id="%sTable"' % p) in s0:
    return "skip:already-wired(custom)"
```

```python
# 方案 2：START/END 标记整块替换（适合整段注入的图表/参考块）
if START in s0 and END in s0:
    s0 = re.sub(re.escape(START) + r'[\s\S]*?' + re.escape(END), '', s0)
```

```python
# 方案 3：函数打标（适合包装单个函数）
if getattr(fn, "__tb_hooked__", False):
    return
fn.__tb_hooked__ = True
```
