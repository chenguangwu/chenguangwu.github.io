# 金融工具：空费用被当成零费用

## 问题描述

以下页面的 `num()` 将空值转成 0，但相应费用字段会改变计算结论：

- `tools/finance/installment-real-rate.html`：清空每期手续费率后，主计算按 0% 计算并显示真实利率，可能让用户误以为输入的是免手续费。
- `tools/finance/points-redemption-value.html`：清空“需加钱换购”后，主计算按 0 元扣减并输出兑换价值与划算程度；附加表格对空值却会提前返回，可能保留旧数据。

以上依据主计算与附加模块源码确认，需浏览器逐页验证提示、旧图表和导出行为。明确输入 0 仍是合法情况。

## 解决方案及验收

按页面语义区分未填写、格式错误和数值 0；为空时提示补充或由用户明确选择“无费用”，依赖该字段的结果不作结论，同时清理过期表格、图表和导出。测试有效值→清空→0→恢复，以及非法值、中英文、历史与复制下载。
