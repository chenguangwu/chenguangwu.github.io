# 银行年金计算：处理零利率和期数边界

- 受影响工具：`tools/banking/present-value-annuity-due.html`、`tools/banking/future-value-annuity-due.html`、`tools/banking/growing-annuity-pv.html`
- 问题：期初年金现值和终值公式直接除以利率，利率为 0 时得到非有限值，虽然这时正确结果是每期金额乘期数。增长年金现值直接除以 r−g，贴现率等于增长率时同样无法得到有限期的正确结果。各页也未明确限制期数为非负整数，输入小数可能产生没有对应付款期次的结果。
- 解决方案：按公式极限分别处理零利率和 r=g 的有效场景，校验付款期数并说明首期现金流时点；用零利率、等增长率和非法期数做回归验证。
- 依据：静态阅读各页面 `calcTool()`；交互和现有空值守卫行为待浏览器复核。
