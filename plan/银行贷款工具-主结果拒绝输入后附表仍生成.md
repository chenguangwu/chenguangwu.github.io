# 银行贷款工具：主结果拒绝输入后附表仍生成

- 受影响工具：`tools/banking/loan-to-value.html`、`tools/banking/loan-total-interest.html`、`tools/banking/loan-remaining-balance.html`。
- 问题：附表包装函数在主计算返回后仍独立运行，校验条件与主计算不同。贷款价值比的抵押物价值为 0 时，主结果拒绝，附表却仍按零分母计算；贷款总利息对负利率或无效期限亦可能生成附表。剩余本金主结果要求年限换算为整数个月，附表却直接四舍五入，可在主结果提示错误时写入另一结果和历史。空字段场景部分附表仅返回而不清除旧结果。上述为源码分析，展示和导出行为待浏览器复核。
- 解决方案：主结果和附表共用输入解析、校验与计算结果；输入失效时清空当前附表并禁止导出、写历史，避免图表保留旧结论；覆盖零分母、负利率、非整月和清空输入。
