# PDF 合并与拆分：关键操作缺少提示

- 受影响工具：`tools/office/pdf-merge.html`、`tools/office/pdf-split.html`；公共提示行为见 `js/common.js`。
- 问题：两页多个错误、警告和状态分支调用 `i18nText()` 而不传文案。公共函数对空键返回空串，`showToast()` 会跳过空消息。例如合并添加非 PDF 文件、拆分未选页时都缺少解释；拆分选择超过 100 MB 文件时仅调用空提示且仍继续加载。结论来自源码，具体交互及不同语言待浏览器验证。
- 解决方案：逐分支补充明确的中英文提示和可执行处理建议；大文件明确采用硬限制还是性能警告，并使提示与实际行为一致。验收非 PDF、无选页、过大文件以及成功和失败状态，中英文均能得到对应反馈。
