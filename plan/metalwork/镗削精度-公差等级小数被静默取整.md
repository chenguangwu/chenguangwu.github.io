# 镗削精度：公差等级小数被静默取整

- 受影响工具路径：`tools/metalwork/tangxue-tangdao-tanggan-jingdu-kongzhi.html`
- 问题：提示要求 IT 等级为 5–10 的整数，实际只检查范围并以 `Math.round` 取整，输入 7.5 会按 IT8 计算而不提示。界面将计算出的半公差直接称作圆度／同轴度建议，未说明其只是启发式值，且孔径和等级输入的无障碍标签分别写成镗刀和镗杆。
- 解决方案：显式校验整数或使用等级下拉；按适用标准的尺寸分段和范围计算公差并标明估算或查表依据。形位公差应根据图纸及具体基准选择，避免通用半值冒充标准要求；修正控件标签，专业口径需核验。
