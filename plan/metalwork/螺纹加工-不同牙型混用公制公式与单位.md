# 螺纹加工：不同牙型混用公制公式与单位

- 受影响工具路径：`tools/metalwork/thread.html`
- 问题：类型提供公制、UNC/UNF、G/NPT 和梯形螺纹，但中径、小径、底孔始终使用同一组公式；页面输入直径和螺距均为毫米，UNC 规格却把两项直接显示成英寸和每英寸牙数，管螺纹也拼成 `G直径/螺距`，未区分 G 与 NPT。历史摘要无论类型都写 `M`，梯形预设同样套用这组公式。
- 解决方案：按具体标准、牙型、内外螺纹和规格建立独立的参数及换算逻辑；英制尺寸和每英寸牙数需明确单位并正确转换，管螺纹采用标准规格表；暂未支持的类型应明确说明并停止输出假定结果。历史与复制内容同步规格。各标准公式、尺寸及适用范围需专业核验。
