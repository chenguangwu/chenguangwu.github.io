# 金相晶粒度：视场名称未转义且参数静默替换

- 受影响工具：`tools/metalwork/analysis-39.html`
- 问题：视场名称直接拼接进 `innerHTML`，包含 HTML 的输入会被当作标记解析，存在脚本注入风险；放大倍数或图上线长为空、非正数时静默替换成 100 和 20，结果看似成功但可能不是用户的试验条件。解析不完整或非正截点行也被跳过，容易漏统计。
- 解决方案：使用文本节点或对用户输入转义，明确校验并提示缺失、非法和被拒绝行，不以默认参数替代错误输入。标准公式、取样方法及级别平均口径需依据适用标准版本核验。
- 验证建议：输入含 HTML 的视场名、空白和负数参数、混合有效及错误行，确认只显示文本且不能静默得到结果；浏览器复核。
