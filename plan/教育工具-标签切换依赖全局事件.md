# 教育工具：标签切换依赖全局事件

- 受影响工具：`tools/edu/ebbinghaus-curve.html`、`tools/edu/word-count-pages.html`、`tools/edu/chinese-zodiac.html`、`tools/edu/edu-unit-converter.html`、`tools/edu/quiz-score-percentage.html`、`tools/edu/chinese-stroke-counter.html`
- 问题：标签切换函数直接读取未显式传入的全局 `event.target`。浏览器不提供兼容性全局事件时会抛错；函数已先移除原标签和面板的激活状态，可能留下空白区域。
- 解决方案：显式传入按钮或事件并使用当前按钮更新状态，验证鼠标、键盘和不同浏览器中的各标签切换。
