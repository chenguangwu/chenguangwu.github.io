# PDF 页面复制后文档级功能保留情况待核验

- 受影响工具：`tools/office/pdf-merge.html`、`tools/office/pdf-split.html`
- 问题：合并和拆分都创建新 PDF，再使用 `pdf-lib` 的 `copyPages()` 复制页面；源码未见针对文档级书签、表单、附件、元数据或数字签名的专项迁移和提示。不能仅据此断言所有内容均会丢失，但用户可能误以为页面之外的功能也完整保留；实际保留情况需样本验证。
- 解决方案：准备分别含书签、交互表单、注释、附件和数字签名的测试 PDF，在多种查看器比较处理前后的页面和文档级功能；按结果补充保留或限制说明，并评估纯前端可行的迁移方案，让用户在处理前了解风险。
