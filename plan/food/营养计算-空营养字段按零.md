# 营养计算：空的营养数据被当作零

受影响工具：`tools/food/nutrition-calculator.html`

自定义食物的热量、蛋白质、脂肪和碳水输入被一元 `+` 直接转换，空串成为 0；只验证名称后即加入计算。例如只填写热量而把三种营养素留空，会被当成这三项均为 0；部分字段填入后，其余空字段也会影响汇总与“营养配比”判断。空克数还被默认当作 100g。源码确认，需实机核对提示与最终显示。显式输入 0 是合法数值，应与未知值区分。

解决方案：明确哪些字段必填、哪些可未知；未填的营养数据不得作为 0 参与结论，未知数据可单独标识并暂停依赖它的比例判断。克数缺失时要求填写或明确展示并确认默认值；校验有限非负数。测试全空、部分已知、显式 0、普通值、负值和恢复输入，核对汇总、比例、图表和导出。
