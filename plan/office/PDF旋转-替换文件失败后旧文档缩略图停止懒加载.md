# PDF 旋转：替换文件失败后旧文档缩略图停止懒加载

## 问题描述

加载新文件一开始就断开当前缩略图的 `IntersectionObserver` 并使旧渲染失效；如果新文件读取或解析失败，错误处理只解除禁用并提示失败，旧文档和界面仍在，但没有重新建立观察器。使用支持该 API 的浏览器时，旧文档尚未加载或已回收的页面滚入视野后可能一直显示“滚动到此处加载”，影响逐页查看和旋转。源码静态分析，需用多页文件和损坏 PDF 实际复核。

## 解决方案

新文件加载成功后再切换和释放旧文档的观察状态；失败时恢复旧文档的观察器、渲染状态和控制项，并明确提示仍显示原文件。验证旧文档未渲染页面、正在渲染、暂停缩略图以及多次替换失败后的交互和导出。

## 受影响工具路径

- `tools/office/pdf-rotate.html`
