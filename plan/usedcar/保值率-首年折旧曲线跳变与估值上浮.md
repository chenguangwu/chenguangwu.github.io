# 保值率：首年折旧曲线跳变与估值上浮

## 问题描述

`retained(age)` 在车龄为 0 时返回 1，任何大于 0 的极小车龄则按 `0.85×0.91^(age−1)` 计算，靠近零时约为 0.934，造成首次使用时的突降；再乘品牌、车况和低里程系数后，部分组合可使估值超过购置价，却被统一表述为“累计贬值”。静态分析，模型意图及业务适用性待复核。

## 解决方案

明确首年折旧和不足一年的插值方式，保证计算与说明一致；对溢价和负贬值采用准确标签并解释模型是假设，或允许用户调整系数并展示限制。验证 0、接近 0、1 年和高系数组合。
