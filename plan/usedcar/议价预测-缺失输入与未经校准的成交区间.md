# 议价预测：缺失输入与未经校准的成交区间

- 受影响工具：`tools/usedcar/ershouchetanpanyijiakongjianyuce.html`
- 问题：除报价和车龄外，里程、年基准、预算缺失会按 0 处理；负里程和非正年基准也可参与结果，年基准为 0 时里程修正被跳过。模型仅按卖家报价和固定系数推算，却将结果称为“合理成交区间”及“成交把握大”，没有市场成交数据支撑；SEO 文案也未体现限制。
- 解决方案：区分必填与可选预算，校验有限值、非负里程及正年基准；将结果标为可调整假设的议价试算，说明不能代表市场价或成交概率，允许用户输入同款市场参考价、整备费用并对比多种方案；同步修正中英文介绍和搜索描述。
- 验证建议：测试空里程、空或零年基准、负值、零车龄和预算为空；检查结果与文案是否准确表达假设。
