# 统计检验无效输入后旧明细仍可导出

- 受影响工具路径：`tools/statistics/one-sample-t-test.html`、`tools/statistics/one-sample-z-test.html`
- 问题：两页附加计算遇到空值或非正标准差等无效输入时直接返回，没有清除上一轮的图表和明细；导出仍读取已有明细表。单样本 t 检验还只在主计算检查样本量整数，附加计算可能继续为小数样本量生成明细。静态分析，页面及下载表现待核验。
- 解决方案：统一主计算和附加模块的校验，失败时清除结果相关图表、明细和导出目标并提示；保留独立的历史记录。验证有效计算后清空输入、输入小数样本量、非正标准差和恢复有效输入。
