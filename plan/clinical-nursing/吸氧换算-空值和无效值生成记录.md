# 吸氧换算：空值和无效值仍生成结果或病历

- 受影响工具路径：`tools/clinical-nursing/convert-flow-concentration.html`
- 问题描述：静态代码显示，流量输入被 `+value || 0` 转换，清空时按 0 L/min 算出 FiO₂ 21%。超出范围时虽然显示错误，却仍保存输入，包装函数继续生成病历文本，例如流量 -1 可被写成 FiO₂ 17%。无效值不应产生可复制的计算结论。
- 解决方案：先区分空串、合法的 0 和无效输入；校验失败时清空计算摘要、病历及相关导出内容，禁止复制旧结果。覆盖空值、0、负数、超范围和恢复有效输入的双语测试；实际页面表现待运行验证。
