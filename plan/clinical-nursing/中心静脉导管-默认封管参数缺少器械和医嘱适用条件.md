# 中心静脉导管：默认封管参数缺少适用条件

- 受影响工具路径：`tools/clinical-nursing/cvc-maintenance.html`
- 问题描述：静态配置按导管大类给出默认容积、固定每日维护次数，并统一采用导管容积的 1.2 倍作为封管量；页面结果和病历直接输出方案。不同导管型号、腔内容积、使用状态及机构规程可能不同，现有界面未要求确认具体器械参数，公式与频次的适用范围需专业核验。
- 解决方案：由临床人员依据产品说明及相关规范核实算法、频次与适用范围；要求明确确认每腔标称容积，解释默认值只是示例并提供医嘱或机构规程优先提示。同步修改复制和记录，增加不同型号及多腔场景测试。
