# 摄影工具：相关推荐未关联拍摄任务

受影响工具：`tools/photo2/focal-length.html`、`tools/photo2/white-balance.html`、`tools/photo2/video-storage.html`、`tools/photo2/exposure-triangle.html`

问题：四个页面的相关工具均展示 CSS 动画、节拍器、二维码和条形码等，与焦距、曝光、色温或视频容量的主要任务缺少关联；完成计算后缺少自然的下一步入口。

解决方案：按具体拍摄场景配置相关推荐，例如曝光、焦距、色温与存储工具之间互链，结合已有摄影工具和使用指南，核验链接、中英文名称及移动端呈现。
