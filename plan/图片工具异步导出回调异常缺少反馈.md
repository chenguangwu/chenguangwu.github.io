# 图片工具异步导出回调异常缺少反馈

## 问题

多个图片工具用外层 `try/catch` 包裹 `canvas.toBlob` 调用，但下载 URL 创建和点击发生在异步回调内。若这些步骤抛错，外层捕获不到，用户可能没有收到文件也看不到失败提示；部分情况下已分配的 URL 或下载节点也可能未清理。此为静态分析，需模拟回调内部异常复验。

## 解决方案

在异步回调内部单独捕获下载准备与触发异常，明确显示失败，并在所有分支释放对象 URL、移除临时节点；只在下载触发完成后显示相应反馈。分别验证 URL 创建和点击阶段失败以及后续重试。

## 受影响的工具路径

- `tools/image/image-crop.html`
- `tools/image/image-filter.html`
- `tools/image/image-mosaic.html`
- `tools/image/image-rotate.html`
- `tools/image/image-watermark.html`
- `tools/image/image-collage.html`
