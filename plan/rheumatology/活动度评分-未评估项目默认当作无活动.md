# 风湿病活动度评分：未评估即显示无活动

## 问题描述

SLEDAI 和 BVAS 初始复选框均未勾选，ESSDAI 各域默认“无活动”；页面加载后直接显示 0 分、无活动或缓解及管理建议。复选框未选不能区分未检查与确认无表现，尤其检验、肾脏或神经项目可能尚未评估，结果因此容易被当成完整评估。源码静态核查，实际交互待复验。

## 解决方案

让各项目明确表示未评估、有和无，必要项目完整后再显示结论；支持明确的全无表现输入，示例和复制导出标注完整性，临床含义及建议由专业人员审核。
