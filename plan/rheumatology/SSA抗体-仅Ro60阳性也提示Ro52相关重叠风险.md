# SSA 抗体：仅 Ro60 阳性也提示 Ro52 相关重叠风险

## 问题

工具把 `ssa !== 'neg'` 统一视为 SSA 阳性。只选 Ro60 阳性并勾选雷诺现象时，也会进入系统性硬化症重叠提示，说明却直接称“抗 Ro52 与 SSc-ILD 相关”，即使输入没有 Ro52 阳性。这混淆了亚型结果，可能使用户以为自己的 Ro52 已阳性。

## 解决方案

分别保存和判读 Ro52、Ro60 的阳性、阴性与未检测状态，只有对应亚型存在时才展示特异性关联；没有足够信息时说明不能作出该亚型判断。由专业人员复核提示依据，并覆盖仅 Ro60、仅 Ro52、双阳和未检测的组合。
