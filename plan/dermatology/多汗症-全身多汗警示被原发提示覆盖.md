# 多汗症：全身多汗警示被原发提示覆盖

## 问题描述

同时勾选“全身广泛”、症状持续、25 岁前发病和睡眠时停止出汗时，`primary` 与 `warn` 均为真；展示条件 `warn && !primary` 抑制了全身多汗警示，却显示“符合原发性局灶性多汗症特征”。所选部位与提示相互矛盾。源码静态核查，实际操作待复验。

## 解决方案

分别展示输入中存在的局灶和全身特征，不用一个条件静默屏蔽另一警示；对矛盾或信息不足的组合提示进一步评估，判定规则及临床表述交专业人员复核。
