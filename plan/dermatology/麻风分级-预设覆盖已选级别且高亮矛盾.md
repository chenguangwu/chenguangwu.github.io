# 麻风分级：预设覆盖已选级别且保留旧高亮

## 问题描述

`__presetFillGrades()` 在手足或眼任一项未选择时，将两项都设为 0，同时给两组首项增加高亮，却没有移除原有高亮。例如先选择手足 2 级、眼未选择，再选择分型预设，手足 2 级仍显示选中，实际计算却使用 0 级，且 0 级也被高亮。源码静态核查，浏览器交互待复验。

## 解决方案

预设明确包含两项完整级别或不改变用户已有选择，状态更新前清理旧高亮，并确保显示、计算、复制和导出使用同一状态。覆盖只选择一组后应用预设的场景。
