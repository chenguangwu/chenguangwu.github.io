# 保洁排班：载入示例覆盖已有排班

受影响工具：`tools/cleaning/staff-schedule.html`

## 问题

“载入示例”调用 `loadPreset()`，直接用四条示例覆盖 `staff` 并写入本地存储，没有判断是否已有人员或提醒用户。已录入的人员、负责面积和手工调整的班次会被替换；而同页“清空”已有确认。源码已确认，需隔离浏览器验证刷新后是否仍能恢复旧数据。

## 解决方案及验收

已有记录时提供“替换 / 追加 / 取消”或明确的覆盖确认，并提供撤销或备份；避免示例 ID 与已有记录冲突。验证新增人员、调整班次、载入示例、取消及撤销，并在刷新后核对数据；检查中英文提示和移动端操作。
