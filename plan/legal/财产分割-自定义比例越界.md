# 财产分割：自定义比例未做范围校验

受影响工具：`tools/legal/divorce-property.html`

自定义比例的输入框标有 0–100%，但 `calculate()` 未校验该范围。使用页面原函数在隔离 JavaScript 环境输入净资产 100000、我方比例 120%，会输出我方 120000、对方约 -20000，而不是拒绝非法比例。单独的 0% 被替换成 50% 问题见 `plan/合法零值被默认值替换.md`。

解决方案：自定义模式下检查输入非空、有限且位于 0–100%，越界时清除旧结论并在字段附近提示；保留 0 和 100 两端。验证手动输入及预设、切换比例模式、非法值恢复、历史/导出同步，并由相关专业人员核对页面说明和适用限制。
