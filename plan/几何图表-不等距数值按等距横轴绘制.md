# 几何图表：不等距数值按等距横轴绘制

- 受影响工具：`tools/geometry/circle-area.html`、`tools/geometry/circle-circumference.html`、`tools/geometry/cone-volume.html`、`tools/geometry/cylinder-volume.html`、`tools/geometry/distance-3d.html`、`tools/geometry/regular-polygon-area.html`、`tools/geometry/rectangle-diagonal.html`、`tools/geometry/angle-between-vectors.html`；共用绘图组件 `js/tool-kit.js`。
- 问题：这些曲线传入间隔不均的数值标签，例如半径 0.5、1、2、3、5、8，而 `TBKit.chart.line` 依数组下标等距放置横坐标。图表视觉上的斜率及曲线形状因此不能表达数值坐标上的线性或平方关系；三维距离图虽称线性，采样偏移也不等距。此为源码确认，渲染效果待浏览器复核。
- 解决方案：数值曲线使用按真实数值比例定位横坐标的绘图方式，或改用等间距采样；明确横轴单位及采样前提，检查其他使用同一组件的不等距数值曲线。
- 验证建议：在 1、2、3、5、8 等横坐标下检查点间距；用已知线性关系验证直线，并在移动端复核刻度可读性。
