# 巡检计划默认正常与统计展示

受影响工具：`tools/property/cycle-10.html`

问题：开始巡检时所有检查点默认为“正常”，无需逐项确认即可完成并提示全部正常；这会把未检查的项目记成通过。统计卡片的 `stat(v,l)` 接收数值在前、标签在后，调用却传入标签在前，导致卡片数值和标签位置颠倒。

方案：检查点初始设为未检查，要求逐项确认或单独标注未检查及原因，再生成对应完成情况；按正确顺序传递卡片数值和标签，覆盖有异常、未检查和全部确认场景。

问题：介绍承诺统计完成率，但现有统计仅有路线数、逾期数、累计完成次数和问题数；每月、每季度、每年使用固定 30、90、365 天，与自然月计划可能偏离。

方案：定义计划次数、完成次数和逾期口径并展示完成率；提供自然月周期和固定天数选择，说明提前巡检如何影响下次日期。

依据源码静态分析，需复核运行及跨月日期。
