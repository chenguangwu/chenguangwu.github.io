# 消防检查不适用项目计入合格

受影响工具：`tools/property/checker-recorder-drill.html`

问题：设施检查的“不适用”与“合格”使用相同数值，统计时进入合格项和加权分母；全部选不适用也会得出“全部合格”“消防系统运行正常”，将未检查内容误当作通过。

方案：为合格、不合格、不适用及未检查设置独立状态；不适用从合格率分子和分母排除并单独列示，无有效检查项时不输出合格结论。对不合格项目保留整改与复查记录。

问题：演练疏散用时为空时按 0 秒计算并评为优秀；固定时限和评分被写成合格结论，缺少建筑条件、演练方案及评估依据。

方案：校验人数和用时并明确未填写状态；按项目演练方案配置参考阈值，标明评估假设，避免以固定时间代替安全验收。

依据源码静态分析，实际交互和专业规则需复核。
