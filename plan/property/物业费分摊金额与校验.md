# 物业费分摊金额与校验

受影响工具：`tools/property/fee-allocation.html`

- 问题：各户金额分别保留两位小数展示，但合计使用未经取整的数值。总额 0.01 元、3 户均分时，每户显示 0.00 元，合计却显示 0.01 元、差额为零，不能用于实际收款核对。
  方案：以分为单位分配，明确余数分配规则，展示各户实际金额并用展示金额计算合计与差额；覆盖均分及按面积分摊。
- 问题：空总额和空面积被当作 0，负数也未在计算中拦截；按面积分摊时总面积为 0 仍生成结果，容易误认为已完成分摊。
  方案：区分未填写与合法的零金额，校验金额和面积的有效范围；面积模式总面积必须大于零，无效时给出具体提示并清除旧结果。
