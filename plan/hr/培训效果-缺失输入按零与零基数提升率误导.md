# 培训效果：缺失输入按零与零基数提升率

## 问题描述
仅在所有数值字段同时为空时才提示，任一项有值后，其他空字段会被 `||0` 当作实际 0 分或 0 人参与综合评价。例如清空培训前评分会改变提升率和综合等级；培训前分数为 0 时，页面将分差除以 10 后标为“提升率”，但相对基期的提升率不可计算。培训主题也直接插入 `innerHTML`，含标签会被解析。

## 解决方案
区分缺失与真实 0，核心字段缺失时不输出结论；零基期单独显示分数变化和“相对提升率不可计算”，说明综合评分只是一种自定义规则。主题按文本渲染，验证空值、零基期、负变化和特殊字符。
