# 多方过程端点误差被近等温公式放大

- **受影响工具路径**：`tools/thermodynamics/polytropic-work.html`
- **问题描述**：页面容许输入末压与多方关系推算值相差 1%，但计算功时仍使用输入末压；当指数接近 1，公式分母 `1−n` 很小，端点舍入误差会被大量放大。例如 P₁=100 kPa、V₁=1 m³、V₂=2 m³、n=1.0001、P₂=50 kPa 可通过一致性检查，却得到约 0 kJ，而按同一多方过程约为 69.3 kJ。
- **解决方案**：明确由哪些输入确定过程，使用一致的推算末压计算功，并在接近 n=1 时采用稳定表达式或极限公式；展示输入偏差及功的正负号约定。验证近等温、膨胀与压缩样例。
