# 比热比输入和零质量潜热复算

- **受影响工具路径**：`tools/thermodynamics/cp-cv-ratio.html`、`tools/thermodynamics/latent-heat.html`
- **问题描述**：比热比工具直接以 `cv=cp−R` 计算，未阻止 cv≤0，可能输出无物理意义的负比热比或除零。潜热工具中质量为合法的 0 时，相变热量为 0，但 `Q/(m||1)` 将无法从零质量复算的比潜热显示为 0。
- **解决方案**：限定理想气体模型参数为有限正值且 cp>R，说明其适用前提；零质量时保留 Q=0，将比潜热复算标为未定义。校验错误态与辅助表一致，覆盖相等、负值及零质量。
