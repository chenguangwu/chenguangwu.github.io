# 化学浓度工具：零溶质时图表保留旧曲线

## 问题

摩尔浓度和质量摩尔浓度工具允许溶质物质的量为 0，主结果会计算出零浓度；但图表扫描函数将 `n <= 0` 当作无效输入并直接返回，未清除上一次的曲线。用户从非零输入改为 0 后，结果与图表不一致，容易误读。

## 解决方案

将 0 作为有效的溶质物质的量，分母保持严格大于 0，绘制对应的零浓度曲线；输入无效或清空时清除旧图并显示提示。验证非零切换至 0、清空输入和恢复输入的情况。
