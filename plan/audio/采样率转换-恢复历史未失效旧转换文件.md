# 采样率转换：恢复历史未失效旧转换文件

- 受影响工具路径：`tools/audio/audio-sample-rate.html`
- 问题：手动更改目标采样率会触发 `__asrInvalidateConverted`，清除旧试听和导出；历史恢复直接赋值后仅调用 `calc()`，不会触发该监听器。转换 48 kHz 文件后恢复目标 16 kHz 的历史，界面估算变为 16 kHz，但仍可下载此前的 48 kHz WAV。
- 解决方案：统一参数更新入口，在历史恢复时比较目标采样率并失效旧转换，提示重新转换；也可在导出前校验结果与目标参数一致。覆盖恢复相同和不同目标采样率、转换进行中恢复历史等场景。静态分析发现，交互及下载待复核。
