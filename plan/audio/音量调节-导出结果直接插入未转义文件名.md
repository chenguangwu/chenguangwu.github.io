# 音量调节：导出结果直接插入未转义文件名

- 受影响工具路径：`tools/audio/audio-volume.html`
- 问题：导出成功时将源文件名去扩展名后的 `baseName` 直接拼进 `result.innerHTML`。包含 HTML 标记或特殊字符的本地文件名会被浏览器当作标记解析，可能破坏结果展示并引入脚本注入风险；文件信息区本身使用 `textContent`。
- 解决方案：文件名使用文本节点或 `textContent` 输出，其他动态内容也按上下文安全编码；用含尖括号、引号和 HTML 属性的文件名验证结果和下载名称。静态分析发现，实际可利用性需受控环境验证。
