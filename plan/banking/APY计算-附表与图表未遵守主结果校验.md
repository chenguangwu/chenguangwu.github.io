# APY 计算：附表与图表未遵守主结果校验

## 问题描述

主结果要求复利次数为正整数、名义利率大于 −100%，附表只检查输入是否为有限数字，因此输入复利次数 0 或 1.5 时仍生成明细和历史。图表只接受正利率：合法的零利率及负利率会保留先前的曲线；清空利率也会保留旧曲线。用户看到的图表、明细和主结果可能属于不同状态。以上为源码分析，待浏览器复核。

## 解决方案

统一主结果、明细及历史的输入校验，错误输入清除或禁用相关输出；图表对合法零利率画零线，对支持的负利率按各复利次数的定义域展示，对不支持的点说明原因；清空时清除旧图表。验证零利率、负利率、非法复利次数及恢复输入。
