# 增长年金：示例数值与有限期适用说明错误

- 受影响工具：`tools/banking/growing-annuity-pv.html`。
- 问题：首期 1000、贴现率 8%、增长率 3%、10 期示例把幂值写为 0.6188、现值写为 7624；按页面公式计算约为 0.622493、7550.13。FAQ 还称增长率必须小于贴现率，否则有限期现值发散，与有限期模型及主计算允许 `r = g` 的分支不符；同一错误出现在 FAQ 结构化数据。
- 解决方案：用同一计算口径重算示例；区分有限期与永续增长年金的适用条件，同步可见 FAQ、结构化数据和英文说明，并核对 `r = g`、`r < g` 场景。
