# 主计算失败后附加明细仍继续计算

## 问题描述
多个页面把原计算函数包装为“执行主计算后无条件执行 Extras”，而 Extras 仅检查输入是否为有限数字，不共享业务校验。以 GDP 增长率为例，基期设为 0 时主结果提示分母不能为零，但 Extras 随后重新生成包含 Infinity 的明细并尝试记录历史；支出乘数、税收乘数输入 MPC=1 时主结果拒绝，但明细仍按 1 计算；名义实际转换的负通胀被主守卫拒绝，却仍生成相应明细。导出由明细表生成，可能把无效结果带走。

## 解决方案
将输入校验和计算收敛为同一份明确的成功或失败结果，失败时同步清除或禁用明细、图表、历史及导出；检查同形包装器，不把有限数等同于业务有效。用上述示例分别验证提示、明细、历史和导出，并覆盖有效输入恢复。
