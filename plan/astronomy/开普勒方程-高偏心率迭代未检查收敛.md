# 开普勒方程：迭代未检查收敛或偏心率范围

- 受影响工具：`tools/astronomy/kepler-equation.html`
- 问题：牛顿迭代以平近点角为初值固定执行 50 次，未检查残差或求导分母，也未校验椭圆方程的偏心率范围。按页面算法离线计算 e=0.9999、M=1° 时得到约 3144.78 rad，残差远大于合理误差，却仍作为结果展示；该输入的浏览器交互需进一步复核。
- 解决方案：校验椭圆模型适用范围，对角度归一化、高偏心率选用稳健初值与有界求根回退；依据残差和最大迭代次数判断收敛，失败时明确提示而非输出数值。说明不同轨道类型需要不同方程。
- 验证建议：比较普通及接近 1 的偏心率、近零平近点角以及非法输入，以独立求根法和方程残差核对。
