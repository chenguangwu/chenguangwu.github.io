# 撞击坑估算：水体目标直接套用固体地表坑模型

- 受影响工具：`tools/astronomy/crater-estimator.html`
- 问题：目标类型包含“水 / 海洋”，但只改变目标密度，仍使用同一坑径、简单或复杂坑和固定坑深比例，未输入水深、海底地质等参数。结果仍称“最终坑径”和“坑深”，可能把水体中的暂态空腔误认为海底撞击坑。
- 解决方案：区分固体地表和水体撞击模型，缺少足够参数与可靠模型时不输出海底坑径结论；明确教学估算的假设与适用范围，经验性破坏半径和等效震级也需提供来源与单位口径。
- 验证建议：分别对岩石、冰和海洋场景核对结果标签及模型输入，并请行星科学专业人员核实缩放公式。
