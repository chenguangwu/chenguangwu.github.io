# 太阳赤纬：缺少观测纬度却显示正午高度相关结果

- 受影响工具：`tools/astronomy/solar-declination.html`
- 问题：页面只输入年内日序，仍将 `90−|赤纬|` 标为“当日正午太阳高度余量”。该数值相当于特定纬度条件下的几何量，不能代表任意地点正午太阳高度；正文还建议据此估计建筑或光伏场景，而未提供观测纬度。清空日序则被当作 0 参与计算。
- 解决方案：明确该量的定义与适用纬度，或增加纬度并计算当地真太阳正午高度；处理极昼极夜和模型精度等边界。将空值与有效日序分开，并根据年份校验日期范围。
- 验证建议：比较赤道与中高纬同一天的正午太阳高度，核对空输入和年末日期；由天文专业人员复核模型。
