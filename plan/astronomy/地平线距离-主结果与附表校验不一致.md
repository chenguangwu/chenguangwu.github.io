# 地平线距离：主结果与附表校验不一致

## 问题

主计算的守卫拒绝负高度，但附表只检查数值是否有限，负高度仍可能进入附表与历史；单一输入为零时，全零守卫又错误地拦截合法的 0 米高度。已有任务 `plan/astronomy/地平线高度基准与负值校验.md` 中“负高度未被阻止”的描述需要按此口径理解：主结果已阻止，附表未同步。

## 解决方案

主结果、附表和历史统一采用非负高度校验，允许零值；无效或清空时清除过期附表并阻止记录和导出。验证负值、零值和正值，并保留已有任务关于高度基准的处理。
