# 柔韧测试百分位边界与年龄输入误导

## 问题

成绩等于表中 P10 或 P90 阈值时，代码分别返回 P5 或 P95；低于 P10 和高于 P90 的所有成绩也固定显示 P5 或 P95，却宣称优于对应比例的人群。年龄空值自动替换为 25，超范围值被截到 6 或 69，用户可能误以为使用了原始年龄；成绩为空时复制仍按 0 计算。以上为静态分析。

## 解决方案

对等于分位阈值的输入返回对应分位，范围之外展示低于 P10 或高于 P90，避免虚构精确百分位；注明参考人群、来源和适用范围。年龄缺失或越界时提示并清除结果，复制复用通过校验的当前结果；覆盖阈值、边界外及空值。
