# 学期 GPA：切换绩点制后沿用旧绩点

- 受影响工具：`tools/edu/exam-gpa-calculator.html`
- 问题：添加课程时保存的是当时所选制度算出的绩点；切换制度只更改当前制度，不重新计算或隔离已有课程。比如 5.0 制添加优秀课程后切到 4.0 制，结果仍可能为 5.00；不同制度下添加的课程也会混合计算。源码中 `setScale()` 与课程 `points` 的保存、汇总逻辑可确认此问题，交付前需浏览器复核。
- 解决方案：保存可重新换算的原始成绩及其类型，切换时按新制度重新计算；无法可靠换算的等级成绩须明确提示用户补填或保留在原制度，禁止混算。覆盖 5.0 转 4.0、百分制与等级制互切及已有记录恢复。
