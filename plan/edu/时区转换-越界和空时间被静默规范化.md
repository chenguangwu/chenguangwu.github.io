# 时区转换：越界或空的时间字段仍参与计算

- 受影响工具路径：`tools/edu/timezone-converter.html`
- 问题：时间字段虽设置了 HTML 的最小最大值，转换函数却不校验，空值以 0 处理、越界值会被日期构造规范化。例如输入 25 时可能被当成次日 1 时，用户看不到明确的输入错误。
- 解决方案：转换前校验日期及各时间字段的非空、整数和范围，显示字段级提示并清除旧结果；保留合法的 0 时、0 分、0 秒。
- 依据：`doConvert()` 对字段使用 `parseInt(...) || 0`，随后 `wallToInstant()` 直接调用 `Date.UTC`；实际交互与日期边界待复核。
