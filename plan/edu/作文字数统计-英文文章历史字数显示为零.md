# 作文字数统计：英文文章历史字数显示为零

- 受影响工具路径：`tools/edu/essay-word-counter.html`
- 问题：统计结果显示中英混合的纯文字字数，但保存历史时只记录汉字数量。纯英文文章即使有内容，历史列表也显示 0 字，中英混合文章的历史数值也与统计结果不一致。
- 解决方案：统一保存及展示的统计口径，或分别标注汉字数、英文词数；旧记录恢复时可依据保存的正文重新计算，并验证纯英文及中英混合文本。
- 依据：`count()` 以汉字数加英文词数计算 `pureChars`；`saveToHistory()` 的 `charCount` 仅为汉字数，`renderHistory()` 直接显示为「字」。
