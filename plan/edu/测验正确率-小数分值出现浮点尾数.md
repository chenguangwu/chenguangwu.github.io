# 测验正确率：小数分值计算出现浮点尾数

## 问题描述

页面允许输入小数每题分值，但得分和满分直接使用 JavaScript 浮点乘法结果展示、保存。例如答对 3 题、每题 0.1 分，得分可能显示为 `0.30000000000000004`，历史也保存该值，影响成绩阅读和复用。

以上来自源码及 JavaScript 数值运算分析，实施时应在浏览器中复现并核验结果与历史。

## 解决方案

按输入分值的小数精度采用可靠的十进制计算或明确的展示舍入规则，计算与历史使用一致口径；避免只截掉显示尾数而保留错误的持久化值。验证 0.1、0.25、多个小数位和大题量。
