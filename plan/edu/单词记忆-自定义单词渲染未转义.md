# 单词记忆：自定义内容插入列表时未转义

受影响工具：`tools/edu/word-memory.html`

## 问题描述
自定义单词、释义和音标来自输入，`filterWords()` 将其直接拼接进 `innerHTML`。若输入包含 HTML 标记或带事件的内容，列表会按页面内容解析，而不是作为文字显示，可能改变页面或执行脚本。数据只在本机，但从外部复制不可信词条仍可能触发。源码分析所得，需安全地在隔离环境复核。

## 解决方案
用 `textContent` 创建词条节点，或在所有 HTML 插值位置统一转义；复核已有自定义词库和导入数据。测试尖括号、引号及带事件的文本按原文显示且不执行。
