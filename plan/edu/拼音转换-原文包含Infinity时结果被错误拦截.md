# 拼音转换：原文包含 Infinity 时结果被错误拦截

## 问题描述

转换结果 HTML 被无效数值守卫整体检查，只要字符串包含 `Infinity` 或独立的 `NaN`，就显示“计算结果含无效值”。这两个词可以是用户输入的正常英文内容，例如 `Infinity`，与拼音转换的数值错误无关，因此正常文本会被错误拦截。

此结论来自源码分析，实施时应在浏览器中输入英文 `Infinity` 和 `NaN` 验证。

## 解决方案

仅对需要数值运算的结果检查有限性，文本转换结果直接按安全转义后的文本呈现，不以内容关键词判断错误。验证普通英文、包含这两个词的混合文本及 HTML 特殊字符。
