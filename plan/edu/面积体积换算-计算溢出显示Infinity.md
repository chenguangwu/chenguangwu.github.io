# 面积体积换算：极大数值换算显示 Infinity

## 问题描述

换算函数没有检查输入和换算结果是否为有限数。例如输入 `1e308` 千米并换算为毫米时，乘法溢出，结果区显示 `Infinity`，没有说明计算超出数值范围。用户无法区分有效结果与计算溢出。

该结论来自源码及 JavaScript 浮点运算分析，实施时应在浏览器中验证极大输入和正常科学计数法输入。

## 解决方案

检查输入与中间和最终结果的有限性，溢出时清除旧结果并提示缩小输入范围；如果支持大数，则采用适当的十进制或科学计数法表示。验证极大值、极小值、零值和正常范围。
