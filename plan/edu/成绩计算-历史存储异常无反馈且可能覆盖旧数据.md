# 成绩计算：历史存储异常无反馈且可能覆盖旧数据

## 问题描述

保存成绩时，历史 JSON 解析异常被忽略并回退为空数组，随后直接写回，可能覆盖原有异常数据；本地存储写入异常则没有捕获，用户看不到明确的保存失败提示。删除单条历史也采用相同模式。存储损坏或受限时，成绩历史可能丢失或操作失败而不明确。

以上为静态分析，实施时需分别模拟历史 JSON 损坏与写入失败确认行为。

## 解决方案

读取失败时停止覆盖并提示用户备份或恢复；捕获写入失败并保留当前计算内容，成功后才确认保存或删除。验证存储禁用、空间不足、格式损坏和正常记录操作。
