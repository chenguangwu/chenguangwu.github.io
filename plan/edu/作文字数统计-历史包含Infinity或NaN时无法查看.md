# 作文字数统计：历史内容触发无效数值守卫

- 受影响工具：`tools/edu/essay-word-counter.html`
- 问题：历史列表把作文标题和前 50 个字符组成 HTML 后，对整段文本检查 `Infinity` 和独立的 `NaN`。当正常的作文标题或预览包含这些词（如 “Infinity”）时，列表被替换成“计算结果含无效值”，已保存的其他作文也无法从列表打开。这是静态源码分析，需在浏览器实际验证。
- 解决方案：仅在数值运算结果处检查非有限数，不对用户文本或整段 HTML 扫描数值标记；以安全的 DOM 文本节点渲染历史，并保留已有转义保护。
- 验证建议：保存标题或前 50 字含 `Infinity`、`NaN` 的作文，切换历史并加载；同时验证真实的非有限数值仍得到正确提示。
