# 学习计划：任务列表中的科目名未转义

- 受影响工具：`tools/edu/study-planner.html`
- 问题：新增或编辑科目时名称保存到本地；任务列表的 `renderTasks()` 将对应 `subj.name` 直接拼入 `innerHTML`，而同一页面的科目列表和下拉选项会转义名称。科目名称含 HTML 时可改变任务列表 DOM，带事件处理的内容可能在当前页面执行；这是静态代码分析，需要在隔离环境复现。
- 解决方案：以 `textContent` 渲染科目名称，或在所有 HTML 输出点统一进行上下文适配的转义；检查历史、周计划和其他科目名称展示点，避免只修复一个入口。
- 验证建议：用包含尖括号及安全测试标记的科目名创建任务、切换标签与刷新，确认展示原文且不产生额外 DOM 或事件执行。
