# 艾宾浩斯复习计划：默认日期可能与本地日期不同

- 受影响工具路径：`tools/edu/ebbinghaus-curve.html`
- 问题：默认日期通过 `valueAsDate = new Date()` 设置，日期控件按 UTC 日期取值，在本地日期与 UTC 日期不同时可能默认为前一天或后一天，生成的整套复习日期随之偏移。
- 解决方案：按本地年月日构造日期输入值，明确学习日期口径；在正、负时区接近午夜时验证默认值与生成计划。
- 依据：页面初始化直接设置 `startDate.valueAsDate`，`generate()` 则按本地日期构造复习日期；不同时区的浏览器表现待复核。
