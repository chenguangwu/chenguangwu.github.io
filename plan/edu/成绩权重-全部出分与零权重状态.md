# 成绩权重：完整成绩和零权重项目的结果状态

## 问题

- 全部成绩已出时，剩余权重为 0，但页面仍显示“要达到目标分，剩余需考 --”，没有说明最终成绩是否达标。例如权重 20%、30%、50%，成绩 85、78、90，目标 80 分时，总分为 85.40，剩余需考却显示 `--`。
- 零权重项目即使不填写成绩，也不会影响总分；页面却把它当作未出分，隐藏最终成绩并显示“部分成绩未出”。

## 解决方案

- 剩余权重为 0 时，根据最终加权分与目标分展示已达标或未达标，避免继续展示剩余所需成绩。
- 判断成绩是否完整时忽略权重为 0 的项目；覆盖已达标、未达标、零权重未填写及权重调整后重新计算等场景。
