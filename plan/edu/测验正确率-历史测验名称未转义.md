# 测验正确率：历史名称直接作为 HTML 解析

- 受影响工具：`tools/edu/quiz-score-percentage.html`
- 问题：保存时将用户输入的测验名称写入本地历史，`renderHistory()` 再将名称直接插入 HTML 字符串并赋给 `innerHTML`，没有转义。粘贴含标签或事件属性的名称后查看历史，可能改变页面结构或执行脚本，而且记录会在本地持续存在。
- 解决方案：用 DOM 元素与 `textContent` 展示名称等用户内容，或在所有 HTML 插入点正确转义；对已有历史数据也采用安全渲染，避免仅限制新输入。
- 验证建议：保存含尖括号和事件属性的名称，重新打开历史并刷新页面，确认只显示文字且没有额外元素或事件；普通名称仍可恢复。
