# 艾宾浩斯复习计划：历史列表未转义用户内容

- 受影响工具：`tools/edu/ebbinghaus-curve.html`
- 问题：生成计划时学习内容经过 HTML 转义，但保存后历史列表将同一内容直接拼进 `innerHTML`。用户输入包含 HTML 标签或事件属性时，打开历史记录可能插入意外 DOM 或触发脚本；影响本地页面安全及历史展示。
- 解决方案：历史渲染使用 `textContent` 创建文本节点，或对所有持久化字段进行适当的 HTML 转义；历史数据读取仍需处理非法格式，不依赖输入框限制。
- 验证建议：保存包含尖括号、引号及无害 HTML 标签的学习内容，再打开历史、刷新和恢复计划，确认均按原文显示且不会创建标签或执行事件。
