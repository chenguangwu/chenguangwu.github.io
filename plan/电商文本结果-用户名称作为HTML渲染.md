# 电商文本结果：用户名称作为 HTML 渲染

## 问题

竞品比价的商品名称及 BI 看板的指标名称直接拼入结果表格和摘要的 `innerHTML`，没有转义。例如输入 `<b>商品</b>,10,12` 会将名称渲染为粗体，而非原样文本；粘贴不可信清单还可能触发页面脚本或事件处理。BI 图表同一名称已做转义，但表格和摘要仍未转义。静态代码分析，浏览器表现待复核。

## 解决方案

所有用户提供的名称使用文本节点或统一 HTML 转义，不拼接为可执行标记；保留中英文及特殊字符，验证尖括号、引号和事件属性均以文本展示。检查复制及导出是否保留原始名称。

## 受影响的工具路径

- `tools/ecommerce/analysis-25.html`
- `tools/ecommerce/report.html`
