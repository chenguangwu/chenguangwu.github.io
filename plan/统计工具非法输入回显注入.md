# 统计工具非法输入回显注入

## 问题

多个工具解析数据失败时，将未经转义的原始输入拼接进错误提示的 `innerHTML`。包含 HTML 标签的无效输入会被浏览器解析为节点，可能触发脚本或改变页面内容。静态检查发现百分位工具的数据及百分位参数、方差分析的组数据、相关系数的 X/Y 数据、卡方工具的观察及期望频数均存在这条路径；浏览器行为待复核。

## 解决方案

用 `textContent` 显示用户输入，或在插入 HTML 前统一转义，并检查其他工具的同类错误回显。覆盖尖括号、引号和事件属性，验证只展示纯文本。

## 受影响的工具路径

- `tools/science/percentile-calculator.html`
- `tools/science/anova-calculator.html`
- `tools/science/correlation-calculator.html`
- `tools/science/chi-square-calculator.html`
