# 银行年金与储蓄工具：零利率附表仍按一般公式除零

- 受影响工具：`tools/banking/emi-loan.html`、`tools/banking/savings-goal-monthly.html`、`tools/banking/present-value-annuity-due.html`、`tools/banking/future-value-annuity-due.html`。
- 问题：主计算对零利率有特殊分支，附表却仍使用含利率或幂差分母的一般公式，产生 NaN，且相关附表可用于导出、部分结果还写入历史。例如每期 1000、12 期的年金主结果为 12000，而附表现值或终值不为有效数字。贷款总利息页面的同类问题已另立任务。
- 解决方案：主结果、附表、历史和导出复用同一计算结果和零利率分支；验证零利率、正利率切换和无效输入后无残留结果。
