# 黑体计算：面积与绝对温度边界

- 受影响工具：`tools/quantum/stefan-boltzmann-power.html`、`tools/quantum/wien-displacement.html`
- 问题：两页只检查是否填写，负绝对温度仍产生黑体结果；0 K 时峰值波长除零。辐射功率页面积为零时用 `P/(A||1)` 得到零出射度，实际出射度应由温度单独计算；负面积也会产生负功率。
- 解决方案：分别校验温度和面积，处理 0 K 的极限和无有限峰值；出射度按 σT⁴ 直接计算，说明总辐射与环境净辐射的区别。主结果和附表使用一致校验。
- 验证建议：测试温度为负、零、300 K，面积为负和零，核对功率、出射度及峰值显示。
