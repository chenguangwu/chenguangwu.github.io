# 统计平均数工具主结果与明细解析规则不同

- 受影响工具路径：`tools/statistics/geometric-mean.html`、`tools/statistics/harmonic-mean.html`
- 问题：主计算只按英文逗号分割并用 `parseFloat` 读取，明细则使用公共列表解析器，额外支持空格、分号及中文标点。输入 `1 2,3` 时，主计算按 1、3 处理，明细按 1、2、3 处理，样本数和平均值可能互相矛盾。静态分析，页面表现待核验。
- 解决方案：统一主计算、图表、明细及历史的数列解析和校验，并在输入说明中列明支持的分隔符；非法项应明确提示。验证空格、英文和中文标点、混合分隔符及非法数值。
