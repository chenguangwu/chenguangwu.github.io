# 护理工具：通用护理摘要误称自评筛查量表

- 受影响工具路径：`tools/clinical-nursing/iv-drip-rate.html`、`tools/clinical-nursing/cvc-maintenance.html`、`tools/clinical-nursing/restraint-duration.html`、`tools/clinical-nursing/oxygen-concentration.html`、`tools/clinical-nursing/suction-pressure.html` 等使用同一摘要模板的页面。
- 问题描述：通用护理摘要统一附加“自评/筛查量表”，但输液滴速、导管维护、约束排程、氧浓度和吸痰压力属于计算或操作辅助，不是自评量表。模板文案会随摘要复制，误导接收者理解信息来源与用途。
- 解决方案：根据工具类型提供准确用途和局限说明，避免将测量、计算或排程归类为自评；检查中英文复制内容并排查使用同一模板的其他页面，临床表述须经专业人员审核。
