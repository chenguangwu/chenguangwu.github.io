# 调光曲线：标准默认及零输入增益表述

## 问题

页面声称平方律是“DMX512 标准默认”，但没有提供支撑该曲线默认值的具体条款；公式表仅列出协议名称，不能据此证明灯具输出曲线由协议统一规定。此外，输入 0 时代码用 `Math.max(dmx, 1)` 作分母，显示增益 0×，实际输出与输入均为 0，二者之比无法定义。源码静态分析，标准表述需核对权威原文。

## 解决方案

核对标准及设备资料，移除或修正缺乏依据的默认曲线断言，说明各灯具曲线依产品设定；零输入时将输出与输入之比显示为不适用，并用 0、最小非零值和满量程验证。
