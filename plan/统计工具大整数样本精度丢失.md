# 统计工具大整数样本精度丢失

- 受影响工具路径：`tools/science/mode-calculator.html`、`tools/science/median-calculator.html`、`tools/science/mean-calculator.html`、`tools/science/percentile-calculator.html`
- 问题：这些工具将输入直接转换为 JavaScript Number，只验证有限性，未识别超出安全整数范围的样本。以众数为例，两个不同的输入 `9007199254740992, 9007199254740993` 均被转换成同一个数，因而可能错误地显示该数出现两次并得出众数；排序、分位数和平均数也可能受到舍入影响。根据源码和 Number 转换规则推导，页面表现待核验。
- 解决方案：解析时检测精度无法保持的整数字面量并明确提示，或使用适当的高精度数值方案进行排序与统计；说明小数和科学计数法的精度边界，避免静默改变样本。验证相邻大整数、重复大整数、普通小数及科学计数法。
