# 图片工具读取异常后加载状态无法恢复

## 问题

图片裁剪、缩放和马赛克在创建文件对象 URL 之前已将加载状态设为进行中，但没有捕获 `URL.createObjectURL` 的同步异常。若创建失败，正常的图片加载失败回调不会执行：裁剪和马赛克可能持续阻止导出，缩放则停留在加载提示且已清空旧结果。此为异常分支静态分析，需模拟失败确认实际界面。

## 解决方案

捕获对象 URL 创建异常，并统一走对应工具的加载失败收尾：恢复加载标记，清理资源和临时状态，给出明确提示；旧图保留或清空应保持一致。覆盖首次加载、已有图片后换图、失败后重新选择文件三个场景。

## 受影响的工具路径

- `tools/image/image-crop.html`
- `tools/image/image-resize.html`
- `tools/image/image-mosaic.html`
