# 单位换算工具：英文空值提示可能残留中文

- 受影响工具：`tools/life/pressure-converter.html`、`tools/life/energy-converter.html`、`tools/life/concentration-converter.html`、`tools/life/area-converter.html`、`tools/life/data-rate-converter.html`、`tools/life/angle-converter.html`、`tools/life/length-converter.html`、`tools/life/power-converter.html`、`tools/life/speed-converter.html`、`tools/life/frequency-converter.html`、`tools/life/time-converter.html`、`tools/life/weight-converter.html`、`tools/life/magnet-converter.html`、`tools/life/volume-converter.html`
- 问题：空值分支动态写入硬编码中文“请输入有效数值”，压力换算清空后还会立即重算并覆盖英文空态。需实测运行时翻译机制后确认各页英文态是否残留中文；流量换算已有单项任务。
- 解决方案：按当前语言生成错误及空态文案，验证清空、语言切换和恢复输入，并复用一致的提示规则。
