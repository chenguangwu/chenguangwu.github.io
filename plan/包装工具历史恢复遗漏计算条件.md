# 包装工具历史恢复遗漏计算条件

## 问题描述

以下两页各有一个独立的旧版历史区，记录及恢复函数只保存前两个数值。剥离强度页会保留当前的参考基准、角度、速度、标准和材料；热收缩页会保留当前方向、工艺余量、搭接及热封记录。恢复历史后出现的结果和条件因此可能属于不同批次，甚至改变膜宽或基准偏差。两页还存在另一套历史组件，本问题特指页面内 `historyBox` 对应的旧历史。以上为静态分析，需浏览器复现。

## 解决方案

旧历史完整保存和恢复所有参与计算与结果解释的字段，明确处理旧格式记录；或整合两套历史并提供无歧义迁移。验证修改条件后恢复、可选项由有值变为空和刷新后的结果一致性。
