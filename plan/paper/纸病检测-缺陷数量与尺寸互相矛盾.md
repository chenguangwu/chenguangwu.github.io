# 纸病检测可接受相互矛盾的缺陷输入

**受影响工具路径：** `tools/paper/detector-17.html`

## 问题描述

工具允许最大缺陷尺寸和每平方米缺陷数分别为 0 或正数，未检查两者关系。例如面积 10 m²、密度 0、最大尺寸 2.5 mm 时仍给出总缺陷数 0 和参考分级；密度大于 0 而尺寸为 0 也照常判级。对于同一检测范围和缺陷类型，这些输入可能互相矛盾；目前用户无法区分未检出与未测量。

## 解决方案

先明确两个字段是否对应同一检测样本、密度是否为估计值；为未检出、未知尺寸和已测缺陷提供明确表达。发现矛盾时提示核对，必要信息不全时不生成等级；验证零缺陷、正缺陷及估计密度的合理边界。
