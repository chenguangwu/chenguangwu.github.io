# 纸卷不足一整圈时两种模式结论冲突

- 受影响工具：`tools/paper/roll-length.html`
- 问题：反算外径模式按连续面积公式得到非零长度对应的外径，层数四舍五入后可以显示“约 0 层”；把该外径带入长度模式时，如果计算层数小于 0.5，页面却拒绝计算并称无法形成有效层数。短纸段可能不足一整圈，且报错所称“外径与纸芯差值不足一个纸厚”也不等同于一整圈的径向厚度。静态分析，需实测与核对模型适用性。
- 解决方案：统一两种模式对不足一整圈的定义；区分连续近似模型与实际绕卷模型，显示小数圈数或适当提示，而非把正长度直接判无效。双向核验短长度、半圈附近及常规多圈的数值，并同步复制校验。
