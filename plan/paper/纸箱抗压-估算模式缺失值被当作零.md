# 纸箱抗压估算模式将空环压值当作零

**受影响工具路径：** `tools/paper/strength-1.html`

## 问题描述

未填写直接 ECT 时，工具以面纸、里纸、芯纸环压值估算 ECT；`num()` 将空值转成 0，而有效性只要求各环压值非负且最终 ECT 为正。清空其中一个环压值、保留其他正值后仍产生 ECT、BCT 和最大堆码层数，未告知数据缺失。空白与明确测得 0 的语义不同，结果可能被用于选箱决策。

## 解决方案

按模式校验输入：估算模式要求相关环压数据明确填写且有限，并对 0 的物理意义作提示；直接 ECT 模式不要依赖不参与计算的环压字段。缺项时清除估算、堆码及图表结论，并覆盖空值、明确 0、直接 ECT 和完整估算样例。
