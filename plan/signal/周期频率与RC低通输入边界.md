# 周期频率与 RC 截止频率：输入边界

## 问题

- 基频工具允许负周期，得到负频率；长周期时 `1/ω` 的分母被强行提高到 10⁻⁹，结果不再等于实际倒数。将 `1/ω` 称为“时间常数”也可能与系统阶跃响应时间常数混淆。
- RC 低通工具允许负电阻、负电容和零值参与公式，产生负时间或无穷结果占位；两个负值还可能生成貌似有效的正截止频率。上升时间公式未突出 10%～90% 阶跃响应及理想一阶低通前提。

## 解决方案

周期、电阻和电容要求有限正数；不以固定阈值钳制有效分母，对极端数值使用科学计数法或明确溢出。将 `1/ω` 描述为倒角频率，并解释 RC 模型、上升时间定义及负载假设，验证零、负数和极端数值。静态分析，运行待核验。
