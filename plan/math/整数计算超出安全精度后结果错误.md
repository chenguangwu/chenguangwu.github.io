# 整数计算超过安全精度后仍显示精确结果

## 问题

斐波那契、阶乘及最大公约数工具均用 JavaScript Number 处理大整数，超出安全范围时可能静默舍入，却以完整整数展示。例如 F(79)、23! 和输入 9007199254740993 的最小公倍数均无法保证准确。斐波那契 n=0 时后继比值和 ln F(0) 也被兜底成数值，实际上未定义；阶乘公式对小数及负数的处理说明与当前校验不一致。

## 解决方案

整数运算采用 BigInt 或严格限制安全输入并明确提示；近似值与精确整数分开展示，对未定义结果单独标识，并同步公式。验证 F(79)、n=0、23!、超安全整数与非法输入。
