# 可重复组合：不重复组合对比值丢失大整数精度

- 受影响工具：`tools/math/combination-repetition.html`
- 问题：主结果使用 BigInt，而“不重复组合数”对比值仍用 Number 逐项计算。n=60、r=30 时，该对比值按页面算法显示 118,264,581,564,861,420，精确值为 118,264,581,564,861,424；主结果标明精确整数，但对比值未提示精度损失。已用 Node 和 Python 组合数核对计算逻辑。
- 解决方案：对比值复用精确整数算法，并明确大整数的展示及复制口径；覆盖安全整数边界、大数组合和 r>n 的对比结果。
