# PDF 合并与拆分：文档级信息保留范围需验证并说明

- 受影响工具：`tools/office/pdf-merge.html`、`tools/office/pdf-split.html`。
- 问题：两页通过创建新 PDF 并复制页面输出，页面没有明确说明书签、交互表单、批注、内部链接、附件和数字签名等文档特性的保留范围。页面外观正常不能证明这些能力仍然有效；签名文档重写后的签名有效性尤其需要明确。具体兼容性尚未用样本验证，不能直接认定所有特性均丢失。
- 解决方案：使用包含上述特性的样本，分别核对合并、抽取后的行为及签名状态；对无法保留的功能在处理前用中英文明确提示，并评估纯前端可实现的保留方案。提供可复现样本与支持矩阵，让用户在下载前判断结果是否适用。
