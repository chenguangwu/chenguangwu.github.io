# 前列腺体积：分类矛盾与活检建议过度确定

- 受影响工具：`tools/urology/calc-volume.html`
- 问题：体积小于 20 mL 显示“偏小”、30–40 mL 显示“轻度增大”，但只要不超过 40 mL，提示均写“体积在正常范围”，与同屏分类矛盾。可选 PSA 为负数时被静默忽略；PSAD 达 0.2 后直接建议穿刺活检，且不限制 PSA 灰区或结合 MRI 等临床信息；高体积也直接标注 BPH。
- 解决方案：校验可选 PSA 的有限非负值，统一数值与参考区间展示，避免单凭体积给出疾病诊断或单凭密度推荐活检；由专业人员审核适用人群、阈值及说明，提示结合影像和其他因素综合判断。参考 [EAU 前列腺癌诊断评估](https://uroweb.org/guidelines/prostate-cancer/chapter/diagnostic-evaluation)。
- 验证建议：覆盖体积 19、35、41 mL，PSA 负数、0 及高密度等情形，核对同屏文案与导出。
