# 膀胱容量：单次排尿量被当成容量异常

- 受影响工具：`tools/urology/bladder-capacity.html`
- 问题：结果说明“排尿量＋残余尿”为单次估算、不能等同最大容量，但随后以其占年龄参考值的比例直接提示“容量缩小/增大”，列出疾病并建议尿动力学评估；未充分充盈也可能产生低值，两部分解释冲突。年龄用 `parseInt` 截断小数，且 0 岁无法输入。
- 解决方案：以单次排尿前估算量表述结果，不由单次值推断最大膀胱容量或病因；明确充盈条件、年龄输入方式和适用人群，相关参考及提示由临床人员核对。对婴幼儿年龄提供明确输入精度及适用范围。
- 验证建议：相同人群分别录入不同充盈量，检查结果是否仅解释本次测量；测试 0 岁和小数年龄边界。
