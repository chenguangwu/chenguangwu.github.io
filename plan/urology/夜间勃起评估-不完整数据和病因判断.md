# 夜间勃起评估：不完整数据和病因判断

- 受影响工具：`tools/urology/penile-rigidity.html`
- 问题：只有三个夜间监测值全部为空时才阻止计算，缺一两项仍显示硬度及建议，缺失监测没有说明；勃起次数为 0 时直接跳过监测判读。数据满足固定阈值就显示“正常 → 提示心理性 ED”，否则提示器质性 ED，未体现监测条件及其他影响因素。
- 解决方案：逐项区分未填、零和无效值，完整后再给监测结果；将结果定位为待专业评估的信息，不据此单独判定病因。监测口径、阈值和硬度解释由临床人员核对。
- 验证建议：分别测试缺一项、次数为 0、硬度超范围和完整输入，确认提示不遗漏且不作确定病因判断。
