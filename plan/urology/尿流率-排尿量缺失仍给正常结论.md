# 尿流率：排尿量缺失仍给正常结论

- 受影响工具：`tools/urology/urine-flow-rate.html`
- 问题：排尿量留空、0 或负数均绕过低排尿量提醒，仍按 Qmax 显示“正常、排尿功能良好”；即使填写低于 150 mL，同屏仍先给确定性正常或梗阻等级。页面接受任意正年龄，却只按性别使用固定阈值，未界定适用人群。
- 解决方案：区分未知、零和非法排尿量，测量条件不足时不输出确定性功能或梗阻结论；说明 Qmax 的局限并结合测量量、曲线、症状及专业评估，适用年龄和性别口径由临床人员核实。参考 [EAU 男性下尿路症状评估](https://uroweb.org/guidelines/management-of-non-neurogenic-male-luts/chapter/diagnostic-evaluation) 对排尿量和复测的说明。
- 验证建议：测试空值、0、负值、100 mL 与 150 mL，确保测量可靠性提示与结论一致。
