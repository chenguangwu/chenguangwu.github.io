# 尿道狭窄：缺项和未验证评分产生诊断暗示

- 受影响工具：`tools/urology/urethral-stricture.html`
- 问题：仅校验最大及平均尿流率，排尿量和时间为空、零或负数均可继续评分并显示“参数基本正常”；平均流率可大于最大流率，排尿量除时间虽计算却未用于核对。页面以固定加分规则称“高度可疑尿道狭窄”，未给出模型验证来源；低尿量仅在已填正数时提示。
- 解决方案：校验流率关系、排尿量及时间，缺失和不可靠测量避免输出正常或疾病等级；展示客观输入及可复核的测量质量提示，评分和阈值由临床人员审核，不以流率独立诊断狭窄。参考 [EAU 尿道狭窄诊断评估](https://uroweb.org/guidelines/urethral-strictures/chapter/diagnostic-evaluation)。
- 验证建议：测试平均大于最大、空及负排尿量、少量排尿和不同曲线，核对提示和结果。
