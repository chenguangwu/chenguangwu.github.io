# 尿动力学：由指数直接推断手术效果

- 受影响工具：`tools/urology/urodynamics.html`
- 问题：页面按 BOOI、BCI 两项直接称“手术无益”或解除梗阻“效果通常较好”，并依据勾选项给出药物建议；结果未体现个体病史、检查质量、适用人群等限制。可选压力、容量负数被静默忽略，部分输入也未参与结果解释。
- 解决方案：将输出限定为指数计算及其适用人群内的参考分层，不由两项数值决定手术或药物；核验测量条件和可选输入，缺项、未知、异常分别展示，并经临床人员审核说明。参考 [EAU 男性下尿路症状诊断评估](https://uroweb.org/guidelines/management-of-non-neurogenic-male-luts/chapter/diagnostic-evaluation)。
- 验证建议：覆盖各 BOOI/BCI 边界、缺失和负数可选参数，核对结果不输出确定性治疗效果。
