# 尿培养解读：菌落数与症状的判断过于确定

- 受影响工具：`tools/urology/uti-diagnosis.html`
- 问题：低菌落数直接判为污染，中等菌落数在未同时勾选尿路症状和白细胞时也判污染，即使录入发热；高菌落数加发热则直接判急性肾盂肾炎并给固定抗菌疗程。页面无法区分未检查与阴性，且未收集采样方式等影响解释的信息。
- 解决方案：将信息不足列为待评估，补充采样方式、症状及检查结果的未知状态；以适用人群和临床指南为依据重审判断，避免输出确定诊断及脱离具体情境的治疗处方。相关文案由临床人员审核。
- 验证建议：覆盖低菌落数伴发热、中等菌落数但尿检未知、高菌落数伴发热及无症状等组合，检查不确定性是否得到保留。
