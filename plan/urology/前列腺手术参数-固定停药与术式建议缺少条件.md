# 前列腺手术参数：固定停药与术式建议缺少条件

- 受影响工具：`tools/urology/turp-parameters.html`
- 问题：仅收集手术方法、前列腺体积和宽泛抗凝类别，便给出氯吡格雷、华法林或 DOAC 固定停药建议、激光功率及按体积线性估算的手术时间和组织重量；未收集具体药物、肾功能、血栓风险、设备和术者等关键条件。单极冲洗液描述为“5%甘露醇/葡萄糖（低渗）”，浓度与渗透性表述亦需核实。
- 解决方案：将手术参数和围术期用药交由专业人员结合个体和设备确定，避免生成可直接执行的固定处置方案；标明信息不足和估算局限，逐项核对冲洗液、数值及引用来源。
- 验证建议：由泌尿外科及麻醉/药学人员审阅不同抗凝用药、设备和风险情形，核对文案与来源。
