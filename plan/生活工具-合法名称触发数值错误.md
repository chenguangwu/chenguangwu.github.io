# 生活工具：合法名称触发数值错误

## 问题描述
草坪养护和多功能倒计时将用户输入的名称拼入列表 HTML 后，检查整段内容是否含 `Infinity` 或独立的 `NaN`。添加这些合法名称会使整个列表被数值错误提示替换，记录已保存，刷新后仍难以通过列表删除。此结论来自源码，待浏览器复核。

## 解决方案
仅校验实际数值，用户文本安全转义后按原文显示；检查列表、草坪日历、维护记录选择和删除，覆盖特殊名称与普通名称。

## 受影响工具路径
- `tools/life/cycle-pruning-lawn.html`
- `tools/life/countdown-timer.html`
