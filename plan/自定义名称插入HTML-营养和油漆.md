# 自定义名称被作为 HTML 插入页面

## 问题描述

- `tools/food/nutrition-calculator.html`：自定义食物名称在 `render()` 中直接插入 `dishList.innerHTML`；CSV 导出隐藏表格也直接拼接名称。隔离 DOM 中以无害加粗标签作为名称，调用页面原 `render()` 后出现真实元素。
- `tools/home/paint-calculator.html`：正常列表会转义名称，但 CSV 导出构造隐藏表格时直接拼接用户涂刷面名称；隔离 DOM 已验证会生成真实元素。该工具的具体任务另见 `plan/home/油漆用量-导出表插入用户HTML.md`。

恶意内容可能在页面上下文执行，影响本地数据与隐私；无害 DOM 标记测试只证明输入被解析成 HTML，并未执行恶意代码。

## 解决方案及验收

自定义名称以 `textContent` 或经过上下文正确转义的文本写入所有列表、表格和导出准备区，不要关闭公共转义；CSV 输出保留公式注入防护。使用普通名称、尖括号、引号和无害事件探针，分别验证添加、重新渲染、预设恢复和导出时输入按文本展示、不会执行，中英文及移动端结果一致。
