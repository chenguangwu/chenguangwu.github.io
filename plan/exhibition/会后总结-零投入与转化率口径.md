# 会后总结零投入与转化率口径

## 问题

总投入为 0 且其他输入有效时，代码直接计算签约额除以总投入，再用该结果评级；无穷大可能被替换成破折号但仍得出“效果优异”。线索、意向与签约数无层级一致性检查，可能显示超过 100% 的转化率。此外该值实际是签约额与成本之比，标为 ROI，容易与净收益除成本的定义混淆。以上为静态分析。

## 解决方案

零投入时显示比率不可计算且不生成评级，区分签约额投入比与净收益 ROI；校验人数和漏斗层级，若允许跨期或非同口径数据则由用户明确说明。提供金额、签约与实际回款的口径提示。
