# 展会预算输入名称被当作 HTML 且零预算误判

## 问题

费用项名称直接拼接到结果表格及最大超支项的 `innerHTML`，若用户粘贴含 HTML 标签的名称会被浏览器解析，可能执行注入内容。预算合计为 0、实际费用大于 0 时执行率被显示为 0%，同时结论为“预算可控”；单项零预算也显示 0% 而非无法计算。无效行静默跳过，费用负数亦可参与。以上为静态分析。

## 解决方案

通过文本节点输出用户输入，避免解析 HTML；零预算时将执行率标为不可计算并单独展示未预算支出。逐行提示错误、校验费用范围并保留行号，核对复制结果与有效数据。
