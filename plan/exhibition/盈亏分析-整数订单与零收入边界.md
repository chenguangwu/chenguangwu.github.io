# 盈亏分析整数订单与零收入边界

## 问题

盈亏平衡订单数显示一位小数，例如需 2.1 单即提示该数，实际需要整数订单才能达到目标。单笔贡献为 0 时无论赞助及票务是否已覆盖固定成本，均显示无法通过增加订单扭亏。转化率、成本率、金额的负数或超范围缺少完整校验，空值静默作为 0。以上为静态分析。

## 解决方案

同时显示理论临界值和向上取整的实际订单数，并据整数目标判断可达性；先处理直接收入已覆盖成本，再处理贡献为零等情况。对必填项、非负金额与百分比范围分别校验，保留合法零值并清除无效结论。
