# 食品工具：英文简介和选择提示未传达实际用途

## 问题

烹饪换算的食材选择空态中文提示“请选择食材”，英文源文案却是工具标题；啤酒比重、面团发酵、维生素 C 对比的英文简介仅重复标题，未传达中文介绍中的输入和用途。静态源码核查，运行时字典是否覆盖需浏览器验证。

## 解决方案

补齐语义一致且自然的英文操作提示和简介，并核对相关字典与构建产物；验证英文态可见文本及语言切换。

- `tools/food/cooking-converter.html`
- `tools/food/beer-gravity-estimator.html`
- `tools/food/dough-fermentation-time.html`
