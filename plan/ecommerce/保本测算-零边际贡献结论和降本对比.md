# 保本测算：零边际贡献结论和降本对比

## 问题描述

单价等于单位变动成本时，页面一律称“任何销量均亏损”，但固定成本也为 0 时利润恒为 0；在销量为 0 且固定成本为 0 的情况下也不能称亏损。此外，优化后成本允许高于原成本，仍显示“降本后利润提升”，实际数值可能为负；两种成本相等时，校核文案称每降低 1 元增加 0 元，与销量为正时的边际变化不符。静态分析，交互待复核。

## 解决方案

区分固定成本及边际贡献的零值边界，准确说明无唯一保本点、恒为零利润或正销量亏损等情况；根据成本差显示利润增加、减少或不变，单位成本每变动 1 元的影响按销量单独计算。覆盖固定成本为零、边际贡献为零及成本上升、相等、下降场景。
