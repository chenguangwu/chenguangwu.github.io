# 流量统计：空转化数当作零且口径不明

## 问题

清空转化数后，计算将空值替换为 0 并显示 0% 转化率，无法区分没有转化与没有输入数据。页面按转化数不超过 UV 来校验，又直接以转化数乘客单价推算销售额；如果转化数指去重购买人数而客单价按订单计算，同一客户多单时结果不成立。静态分析，交互待复核。

## 解决方案

区分空值与明确的零转化；定义转化数是去重人数、订单数还是事件数，并仅对相同统计范围的指标计算比例。销售额估算分别使用订单数和每单金额，或使用购买人数和每人消费额，清楚标明估算假设并验证重复下单场景。
