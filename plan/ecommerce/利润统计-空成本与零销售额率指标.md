# 利润统计：空成本与零销售额的指标口径

## 问题

成本、费用和税费为空时被直接当作 0，页面仍输出毛利和净利；未填写成本可能被误认为完全无成本。销售额为 0 时，毛利率与净利率也被直接显示为 0%，即使存在成本和亏损，掩盖了分母为零而无法计算的事实。静态分析，交互待复核。

## 解决方案

区分未填写与明确输入的 0，要求填写必要项目或明确提示空项按 0 处理；销售额为 0 时保留利润金额，将利润率标为不适用并解释原因。验证空成本、零成本、零销售额及亏损场景，复核结果导出和中英文提示。
