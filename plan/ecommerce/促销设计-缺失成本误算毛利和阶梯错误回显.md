# 促销设计：缺失成本误算毛利和阶梯错误回显

## 问题描述

清空货品成本时，代码把空值当作 0，仍计算并展示折后毛利率，容易将未提供成本误读为零成本。二级折扣、满减及券数值也以相同方式回退，启用对应规则时无法区分未填写和明确输入 0。另满减阶梯格式错误时，原始片段直接拼入 `innerHTML` 错误信息，输入中的 HTML 可能被解释。静态分析，交互待复核。

## 解决方案

按启用状态区分可选项、空值和数值 0；未提供成本时显示毛利率不可计算，启用规则时校验必要字段。严格解析阶梯并以文本方式展示错误输入，测试清空成本、启用规则缺值和含 HTML 的错误片段。
