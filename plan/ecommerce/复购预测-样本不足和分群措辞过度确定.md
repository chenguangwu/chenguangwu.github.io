# 复购预测：样本不足和分群措辞过度确定

## 问题描述

只有一笔购买记录时，平均复购周期显示为 0 天，容易误认为已观测到零天复购。五次购买即归为 VIP 并描述为“高价值、购买频次高且稳定”，但代码没有按消费金额或间隔稳定性判断；超过阈值即称“已流失”，也只是按未购买天数推断。静态分析，交互和业务口径待复核。

## 解决方案

无复购间隔时显示“数据不足”；将分群改为可解释的次数和未购买天数规则，避免未经验证的价值、稳定性和确定流失结论。允许用户调整阈值并说明预测仅为历史间隔外推，验证单笔、同日多笔及不规则间隔。
