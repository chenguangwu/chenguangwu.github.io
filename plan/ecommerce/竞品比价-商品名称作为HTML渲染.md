# 竞品比价：商品名称作为 HTML 渲染

## 问题

商品名称直接拼入结果表格和最低价差摘要的 `innerHTML`，没有转义。名称中包含 HTML 标记时会改变页面结构；例如录入 `<b>商品</b>,10,12` 会把名称渲染为粗体，而非原样文本。粘贴不可信商品清单还可能触发页面脚本或事件处理。静态代码分析，浏览器表现待复核。

## 解决方案

所有用户提供的商品名使用文本节点或统一 HTML 转义，不拼接为可执行标记；保留中英文及特殊字符，验证尖括号、引号和恶意事件属性均以文本展示。检查复制及导出是否保留原始名称。
