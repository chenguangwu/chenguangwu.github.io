# 增长率：负基期的方向与说明不一致

## 问题描述

工具允许负基期，仍按 `(本期−基期)÷基期` 输出增长率，但公式说明又称增长额大于 0 为正增长。例如基期 −100、本期 −50，增长额为 +50、显示增长率却为 −50%，容易让用户误判亏损改善的方向。跨零和负基期的百分比解释也并不等同于正基期增长。静态分析，交互待复核。

## 解决方案

明确负基期、跨零场景的统计口径和局限，避免用单一正负标签直接解读；可展示绝对变化并解释现有计算公式，若提供其他口径则标明分母及用途。测试负到负、负到正、正到负以及零基期。
