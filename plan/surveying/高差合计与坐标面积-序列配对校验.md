# 高差合计与坐标面积序列配对校验

## 问题

高差页分别解析前后视列表，但循环只按后视数量计算，缺少的前视读数按 0 处理，多余前视读数被忽略；空逗号项也会被 `Number` 当成 0。坐标面积页未校验 X、Y 列表长度一致及各项完整，空项可能变 0，缺项则可能产生无效结果。输入守卫的分隔和计算解析规则也不同。以上为静态分析。

## 解决方案

统一分隔规则并逐项严格解析，拒绝空项和非数字；高差要求前后视逐站一一配对，坐标面积要求两个列表等长且至少三个有效顶点。显示具体错误位置，补充缺项、多余项、合法 0 与正常样例。
