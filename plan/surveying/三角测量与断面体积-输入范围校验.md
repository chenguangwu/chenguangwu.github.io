# 三角测量与断面体积输入范围校验

## 问题

三角边长页仅校验输入非空，边长可为负，两个角可为 0、负值或相加不小于 180°，从而产生负边长、退化三角形或除零结果。棱台体积页也仅检查数值是否存在，负断面积或负间距会得到无实际意义的体积。以上为静态分析。

## 解决方案

分别校验边长为正、两角均大于 0 且和小于 180°；断面积允许合理零值但不得为负，间距须为正。校验失败时清除旧结果及附属图表，覆盖退化、零值和正常算例。
