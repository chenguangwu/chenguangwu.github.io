# 变形监测的周期名称直接插入 HTML

## 问题

逐行数据中的周期名称未经 HTML 转义，直接拼接到结果表和最大变化期名称后写入 `innerHTML`。粘贴含 HTML 标记的周期名称会被浏览器当作页面结构解析，可能破坏表格；恶意构造的输入还可能触发页面脚本。该风险来自用户粘贴或导入的数据，不依赖数据上传。

## 解决方案

将周期名称作为文本节点写入，或在所有 HTML 插值处统一转义；同步检查辅助表、复制和导出对特殊字符的处理。用包含尖括号、引号、逗号及事件属性的文本验证其仅作为文本显示。
