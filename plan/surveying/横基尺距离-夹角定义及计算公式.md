# 横基尺距离夹角定义及计算公式

## 问题

输入标为横基尺长和夹角，计算使用 `D=c/tan(θ)`；若 c 是横基尺全长且 θ 是两端视线夹角，对称垂直布设常见几何关系为 `D=c/(2tan(θ/2))`，两种口径不能混用。页面未在输入标签明确全长、半长或半角的约定，也未限制角度与长度范围；零角可导致除零。以上为静态分析，具体仪器测法须核实。

## 解决方案

用示意图明确测站、基尺、全长与夹角的定义，并据此核对公式和示例；支持不同测法时显式区分输入。校验基尺长度和有效角度，提供独立几何算例验证。
