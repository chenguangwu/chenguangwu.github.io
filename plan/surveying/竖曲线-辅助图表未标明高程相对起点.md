# 竖曲线辅助图表未标明高程相对起点

## 问题

`grade-intersection-elev.html` 未输入起点高程，公式 `y = g₁x + (g₂−g₁)x²/(2L)` 计算的是相对于曲线起点的高程变化，主结果也标为「相对高程」。辅助图表标题及数据系列却称「竖曲线高程剖面」「曲线高程」，未说明起点基准，可能被误读为实际高程。此问题基于静态文案和公式检查。

## 解决方案

图表和英文文案明确标为相对起点高程变化，并标注单位和零基准；可增加可选起点高程，提供绝对高程时区分显示及导出。用非零起点示例核验。
