# 坡度角：双向能力与水平坡

## 问题

`grade-angle` 的标题和 SEO 描述称角度与百分比可双向换算，但页面只有角度输入，只能求百分比。当前还拒绝 0°，无法计算常见水平坡；公式说明声称角度接近 90° 时坡比 1:n 的 n 急剧增大，实际 n = 1/tan(θ) 趋近于零。负坡度也无法表达下降方向。

## 解决方案

增加百分比反算角度的输入或切换，并支持 0° 与有符号坡度，说明坡比的方向和水平坡分母表达；保留接近垂直的边界提示。修正公式说明及 SEO 中英文文案，以水平、上下坡、45° 和接近 90° 验证。以上为静态分析，运行待核验。
