# 坡度及竖曲线除零与有效区间

## 问题

坡度页仅检查输入非空，水平距离为 0 时除零、为负时仍产生坡度；负高差时不显示坡度倒数。竖曲线相对高程页同样仅检查非空，曲线长 0 或负数、桩距在曲线范围外时仍计算，可能产生无效结果或未注明的外推。以上为静态分析。

## 解决方案

校验水平距离和曲线长度为正；明确负高差的下坡含义与坡比表示。竖曲线桩距限定在曲线范围或显式标记外推，并用水平坡、下坡、零长度和端点案例验证。
