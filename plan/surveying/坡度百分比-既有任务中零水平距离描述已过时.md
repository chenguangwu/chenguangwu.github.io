# 坡度百分比既有任务中的零距离描述需复核

## 问题

已有任务 `坡度及竖曲线-除零与有效区间.md` 称坡度工具只检查非空、水平距离为 0 时直接除零。当前 `slope-percent.html` 的输入守卫已将 `d` 列为分母并在 `d=0` 时返回提示，因此该句与当前代码不符；负水平距离仍未被同一守卫拒绝，负高差时坡度倒数也仍显示为 `—`。如果不核对现状就执行旧任务，可能重复修复已处理的分母边界，遗漏仍存在的范围问题。

## 解决方案

处理旧任务前重新核对当前主分支及真实页面，修正任务描述；保留负水平距离和下降坡度表达等仍需解决的项目，并验证零距离的提示及辅助输出。此记录基于静态代码，运行时行为待复核。

- `tools/surveying/slope-percent.html`
