# 角度测量：单次观测误判零误差与合格

- 受影响工具：`tools/surveying/calc-angle-2.html`
- 问题：方向法只输入一组有效盘左、盘右读数，或复测法只输入一个有效读数时，页面仍计算并显示标准差、标准误差为 0，同时将观测间的 2C 互差或读数较差显示为 0 并判定合格。单次观测不足以估计样本标准差或比较不同观测的差异，容易让用户误以为精度已经得到验证。
- 证据：`stdDev` 在样本数小于 2 时直接返回 0；两种模式均允许仅一条有效记录进入统计和限差判断。
- 解决方案：样本不足时保留可计算的单次结果，将样本标准差、标准误差和观测间互差标为“数据不足”，不输出合格结论；增加两种模式的单次与多次观测校验，并同步中英文说明。
