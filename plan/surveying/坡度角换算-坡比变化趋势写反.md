# 坡度角换算坡比变化趋势写反

## 问题

公式框定义坡比 `1:n` 中 `n=1/tanα`，却称角度趋近 90° 时“坡度与坡比急剧增大”。按页面定义，坡度百分比增大，而 n 趋近 0；例如 45° 时 n=1，80° 时 n≈0.176。原文未区分坡度值和比例右项，可能误导边坡参数理解。静态核对发现。

## 解决方案

说明 1:n 的竖向与水平分量及 n 随角度增大而减小，同时说明坡度百分比增大；使用 45° 和 80° 算例核对公式、结果和中英文文案，并明确接近垂直或水平时的边界表示。
