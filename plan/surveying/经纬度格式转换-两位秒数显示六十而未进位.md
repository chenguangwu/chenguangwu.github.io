# 经纬度格式转换的两位秒数未正确进位

## 问题

`toDMS` 按三位小数的阈值 59.9995 秒进位，但页面顶部结果使用两位小数显示。十进制度 `10.349998888888889` 对应约 10°20′59.996″，顶部四舍五入显示为 10°20′60.00″，同页表格显示 10°20′59.996″，导致两种展示格式不一致且顶部出现 60 秒。算例已用 JavaScript 运算核对。

## 解决方案

按每个显示精度先四舍五入，再统一处理秒到分、分到度的进位；或统一所有结果的精度。验证临近 60 秒、60 分、负角和度数边界，并确保复制、表格及导出一致。
