# 坐标面积：大坐标小宗地鞋带求和精度丢失

- 受影响工具：`tools/surveying/area-coordinates.html`
- 问题：主结果与辅助表直接对绝对坐标做乘积相减，面对大坐标和小面积时浮点消减可能严重失真。本地 Node 验证：以 (1000000000,1000000000)、(1000000001,1000000000)、(1000000001,1000000001)、(1000000000,1000000001) 为顶点，理论面积为 1 m²，现有求和得到 0 m²。
- 解决方案：先将所有顶点平移到共同局部原点再计算鞋带和，必要时使用补偿求和；主结果、辅助表和导出统一算法。验证大坐标小地块、平移不变性和顺逆时针结果，并明确坐标单位及精度限制。
