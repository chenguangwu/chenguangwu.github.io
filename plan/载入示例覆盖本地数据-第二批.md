# 载入示例覆盖已保存数据：第二批

## 问题描述

以下页面的示例入口直接替换用户正在维护的数据并写入本地存储，未见覆盖确认或撤销路径；误触可能丢失草稿。以下为源码确认，需在隔离浏览器中进一步验证刷新和恢复行为。

- `tools/edu2/study-progress.html`：`loadSample()` 用 `SAMPLE` 覆盖科目输入后立即调用 `saveInput()`；原本保存的科目内容被替换。
- `tools/funeral/ceremony-timeline.html`：“载入标准流程”的 `loadPreset()` 用模板替换 `steps`，随后 `saveStorage()`；预设栏也会调用该函数。
- `tools/funeral/funeral-budget-planner.html`：“载入参考预算”的 `loadPreset()` 用示例条目替换 `items`，随后 `saveStorage()`。

相关的 `tools/cleaning/staff-schedule.html` 和 `tools/home/renovation-budget.html` 已分别记录在分类任务中。

## 解决方案及验收

当用户已有数据时明确告知示例将替换什么，提供取消、替换或合适的追加操作，并保留可撤销的旧数据；首次空白使用可直接载入。分别验证手动修改、点击每个示例入口、取消、确认、撤销与刷新；检查本地存储失败时的提示及中英文界面。避免把示例作为真实用户数据静默保存。
