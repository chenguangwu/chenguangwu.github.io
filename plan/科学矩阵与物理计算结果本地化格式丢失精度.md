# 科学矩阵与物理计算结果本地化格式丢失精度

- 受影响工具路径：`tools/science/matrix-calculator.html`、`tools/science/physics-calculator.html`。
- 问题：两页对部分普通量级数值先保留较多小数，再调用未配置精度的 `toLocaleString()`；默认通常只展示最多三位小数。例如 0.001234567 在常见中英文环境下显示为 0.001，矩阵结果或物理计算因此损失有效数字。
- 解决方案：设置明确的有效数字和小数位策略，必要时使用科学计数法；计算、历史和导出保留原始值，并说明展示精度。验证接近 0.001 的数值、矩阵逆及多个语言环境。格式化示例已用 Node 验证，浏览器表现待核验。
