# 视频倍速：时间码解析和边界校验

- 受影响工具：`tools/video/video-speed.html`
- 问题：时间码按冒号或分号直接分割并用 `parseInt`，不校验分钟、秒和帧号范围，也将分号当作普通非丢帧时间码；输入三段时间码时保留上一次毫秒值，导致转换依赖旧状态。分钟、秒及毫秒的 HTML 范围没有在计算逻辑中校验，反向目标为负数时也会生成负速度后才报错。
- 解决方案：明确支持的时间码格式与帧率，严格校验分量并清除缺省帧；未实现 DF 转换时拒绝或明确提示分号格式，避免标为 SMPTE 精确值。校验时长分量、帧率及目标时长，非法输入清除结果并给出针对性提示。
- 验证建议：依次输入带帧和不带帧的时间码、越界帧号、分号时间码及负目标时长，核对结果和错误提示。
