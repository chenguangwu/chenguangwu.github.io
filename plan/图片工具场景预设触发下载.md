# 图片工具：应用预设或恢复历史可能触发下载

受影响工具：`tools/image/image-resize.html`、`tools/image/image-watermark.html`、`tools/image/image-collage.html`。

问题：三个工具向 `TBKit.preset.bar()` 注册的应用后回调分别调用下载函数，历史恢复回调也调用下载函数。公共预设按钮点击后会先写入参数再调用该回调，用户只是选择场景或恢复历史，却可能得到一次未经预期的下载；图片缩放的异步编码还可能让下载内容和新参数不同。图片水印历史恢复另见[单工具任务](image/图片水印-历史与预设触发意外下载.md)。

解决方案：预设和历史恢复只更新参数并触发预览或重新生成，无法恢复本地文件时明确提示；明确标识处理状态，只允许用户主动下载已完成且与当前参数一致的结果。验证有图、无图、历史恢复、快速切换预设、异步编码及 PNG/JPEG/WebP，确认没有意外下载。

证据范围：本机无头 Chrome 通过本地 HTTP 加载图片缩放，使用受控 100×50 图片；点击 25% 预设时，预览尺寸更新为 25×13，但截获的下载文件名仍为 `test_50x25.png`。通过拦截下载链接点击验证，未保存文件；水印、拼图及历史恢复仍为静态分析，待浏览器复核。
