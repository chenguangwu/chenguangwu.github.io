# CSS 动画自定义贝塞尔坐标难以编辑

- 受影响工具：`tools/design/css-animation-generator.html`
- 问题：自定义 cubic-bezier 数字框每次 `input` 都调用参数读取函数，空值经 `Number('')` 变成 0 并立即写回。清空旧值后输入新值、或逐字输入负数及小数时，中间状态会被改写，妨碍编辑；Y 坐标还被限制在 -1 至 2，无法表达该范围外的合法 CSS 曲线。
- 解决方案：允许空值、负号和小数点等编辑中间态，失焦或确认时再校验并反馈；仅对 X 坐标实施 CSS 要求的 0～1 范围校验，Y 坐标允许有限实数，同时保持预览与导出一致。
