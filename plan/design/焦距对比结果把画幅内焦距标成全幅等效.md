# 焦距对比结果把画幅内焦距标成全幅等效

## 问题
“各画幅等效焦距对比”的输入标为“全画幅焦距”，计算使用 `focal / crop`，得到的是与该全幅视角相近的目标画幅实际焦距；结果却标为“全幅等效”。例如输入全幅 50mm，佳能 APS-C 显示 31mm 全幅等效，实际 31.25mm 是该画幅上的近似镜头焦距，其全幅等效仍约 50mm。

## 解决方案
明确标记输入为全画幅等效焦距，输出为各画幅对应的实际镜头焦距；若同时展示反向换算，则分别标注方向和单位。结合画幅长宽比、裁切系数近似值说明视角匹配的局限，验证全幅 50mm 与 APS-C、M4/3 的换算。
