# 颜色选择器：透明色对比度未考虑合成

受影响工具：`tools/design/color-picker.html`

## 问题描述
透明度滑块会改变预览，但 `renderContrast` 和白底、黑底对比度计算只使用 RGB，不考虑 alpha。比如黑色透明度为 0、对比背景为白色时，实际合成后是白色，对比度为 1:1；页面却按不透明黑色计算为 21:1 并判定通过。对比演示也使用不透明 HEX，不能体现当前选择。

## 解决方案
先将前景 RGBA 按所选不透明背景合成，再按 WCAG 相对亮度计算对比度和通过状态；白底、黑底分析分别合成。演示展示合成效果并说明所用背景，增加 0%、50%、100% 透明度及不同背景的验证。推荐文字色也应基于实际背景合成结果，或明确限定为不透明颜色。
