# 字号阶梯：CSS 缺少正文规则且展示级选择器不适用

## 问题

工具称生成从标题到正文的字号表和 CSS，但基础字号被分配给 `h6`，生成的规则没有 `body` 或正文选择器；展示级被输出为 `display { ... }`，它是元素选择器，通常不会作用于常见的 `.display` 类。用户直接复制后可能看不到预期的正文和展示字号。静态分析发现，需在浏览器复核。

## 解决方案

明确基础字号对应正文，生成可直接使用的正文规则和可配置的展示级类选择器，同时说明标题层级和变量；预览及 CSS 使用同一比例映射。验证复制到普通 HTML 后正文、标题和展示级的实际字号。

## 受影响工具路径

- `tools/design/typography-scale.html`
