# 等距网格生成结果缺少连续斜线

## 问题
默认 CSS 使用三层线性渐变，色标只在每个渐变的起点保留 1px 颜色，其余均透明。使用源码默认参数在 Chrome 中渲染得到周期性竖线和零散点，未形成介绍所述的连续 30°／150° 菱形网格；复制的 CSS 与预览使用相同表达式，也会产生相同问题。

## 解决方案
重算各方向的渐变色标、平铺尺寸与位置，使相邻 tile 的斜线连续衔接，形成规则的等距网格；明确「格子大小」的度量方式，并核对线宽、不同尺寸和背景颜色下的预览与复制结果。使用多种尺寸和主流浏览器检查接缝及线条连续性。

- `tools/design/isometric-grid.html`
