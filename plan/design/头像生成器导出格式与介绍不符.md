# 头像生成器导出格式与介绍不符

## 问题
中英文介绍宣称支持 PNG 和 SVG，实际通过 Canvas 的 `toDataURL('image/png')` 生成图片，下载按钮仅保存 PNG，没有 SVG 导出入口；页面底部中文介绍还错误称“一键生成 CSS 代码”。这些文案使用户对结果格式产生错误预期。

## 解决方案
提供可独立使用的 SVG 导出并验证各样式、圆角与预览一致；若暂不实现，明确只支持 PNG 和 Base64，修正中英文简介、SEO 和正文，删除无关 CSS 描述。

- `tools/design/avatar-generator.html`
