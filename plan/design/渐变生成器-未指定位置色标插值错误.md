# CSS 渐变生成器：未指定位置的色标按错误区间插值

受影响工具：`tools/design/gradient.html`

## 问题描述
`parseGradient()` 对每个缺省位置的色标按它在全部色标中的序号均匀分配百分比，而不是根据相邻已指定位置插值。例如 `linear-gradient(#000 60%, #fff, #f00 80%)` 中白色色标应位于 70%，当前解析为 50%，随后排序会改变色标顺序，导致相邻色标对比度检测结果失真。此结论来自静态代码，需在浏览器复核。

## 解决方案
按 CSS 色标位置规则处理显式与省略位置，包括首尾缺省、连续缺省及位置回退；对于无法可靠解析的语法给出提示而非输出确定结果。覆盖上述示例和混合位置的回归用例。
