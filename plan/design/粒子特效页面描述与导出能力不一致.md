# 粒子特效页面描述与导出能力不一致

## 问题
SEO 描述末尾出现“教学 canvas。”片段，中英文说明缺少清晰的用途和能力边界；正文算例声称输出“预览与导出代码”，实际操作按钮导出的是参数 JSON，没有可直接运行的粒子代码，用户无法仅凭 JSON 复现效果。

## 解决方案
重写中英文 SEO 与正文，准确说明本地 Canvas 预览、发射模式、交互和配置导出；提供可导入配置及可独立运行的示例代码，或在实现前明确说明 JSON 仅为参数记录。校验页面、社交描述和结构化数据一致。
