# 护理风险评分：历史“通过”结论与实际风险无关

- 受影响工具路径：
  - `tools/clinical-nursing/assessor-rater-risk.html`
  - `tools/clinical-nursing/calc-rater-risk.html`
- 问题描述：Morse 和 Braden 历史表均根据结果文字是否包含“错误”“无效”等关键词生成“通过/未通过”，并绘制二值有效性趋势，而不是根据量表分数与风险等级判定。高风险结果也可能标成“通过”，容易被误解为患者安全；Braden 的单页细节另见对应任务。
- 解决方案：去除含糊的通过判定，保存并展示经确认的总分、风险等级和评估时间；趋势使用真实评分，并标明量表方向、时间及同一患者的适用范围。排查其他引用同类历史模块的临床工具。
