# 图片工具英文描述截断及元数据同步

## 问题

以下五个图片工具的 `desc-en` 以省略号结束在未完成的句子中，例如证件照页在 “Background replacement and compliance are not…” 处截断，遗漏了不能自动换背景和需自行核验合规的重要限制。英文态的 `js/i18n.js` 会用该字段同步 description 和分享元数据，影响英文摘要表达；搜索引擎最终展示仍需实际核验。

## 解决方案

检查构建使用的英文描述源，分别改成长度合适、语义完整的句子，保留关键能力与限制；避免仅手改会被构建覆盖的页面。构建后核对英文态 description、OG 和 Twitter 描述，并抽查其他工具是否存在相同截断。

## 受影响的工具路径

- `tools/image/generator-15.html`
- `tools/image/image-mosaic.html`
- `tools/image/image-crop.html`
- `tools/image/id-photo-crop.html`
- `tools/image/image-watermark.html`
