# 染色时间：缺项和降温处理

受影响工具：`tools/textile/dyeing-time.html`。

## 问题

- `getVal` 和 `getStages` 将空值转为 0；多段目标温度为 0 或空值的行被静默跳过，保温时间可为负数并参与合计，容易输出不完整或负的工期。
- 单段或多段目标温度低于上一温度时，升温时间直接按 0 计；单段明细仍把负温差除以正速率写成 0。反算页则会给出负的“升温速率”，都未说明降温耗时不在模型内。

上述为源码推导，需在浏览器复核；多段是否应支持降温需结合工艺确认。

## 解决方案

区分未填和合法的 0，逐行校验温度及非负保温时间，缺项时标出对应行并暂停结果。只支持升温时拒绝降温并解释；若支持降温则单独输入降温速率并计时，展示与计算一致的过程。验证相等温度、降温、缺项和零保温。
