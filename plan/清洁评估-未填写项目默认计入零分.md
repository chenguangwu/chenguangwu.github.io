# 清洁评估：未填写项目默认计入零分

## 问题描述

保洁流程标准化和保洁质量考核的各检查项初始值均为 0，页面初始化即计算结果。用户尚未检查的项目会分别被视为“未制定”或“未做”，计入低分和整改清单；质量考核甚至给出不合格及扣罚建议。系统无法区分未评估与明确选择零分，部分填写时结论可能误导。源码静态分析，需在页面交互中复核。

## 解决方案

增加独立的“请选择／未评估”状态，保留用户明确选择的零分；展示已评估数量，全部完成前不输出完整评级或奖惩建议，或明确标示部分评估及其分母。导出与重置保持相同口径，覆盖未填写、部分填写和明确全部零分的情况。
