# 碳化深度：零年限与风险功能

## 问题

- 页面拒绝使用年限为 0 的输入，无法表示模型起点；平方根公式在年限为零时有明确的零深度结果。
- 标题和描述提及钢筋锈蚀风险及何时逼近保护层，但页面仅输出两个单位的碳化深度，没有保护层厚度、当前实测深度和时间比较输入，不能完成所述评估。

## 解决方案

- 将 0 年与空值区分，覆盖零年限及系数的有效范围。
- 提供保护层厚度和基于实测数据的参考比较，说明平方根模型、系数来源及适用限制；未实现前同步修正 SEO 文案，耐久性判断交专业人员核验。
