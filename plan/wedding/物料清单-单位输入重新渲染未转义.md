# 婚礼物料清单：单位输入重新渲染未转义

## 问题

物料单位由用户输入并直接拼入 HTML 的 `value` 属性；添加或删除物料时整表重新渲染，该值未做属性转义。输入含引号及 HTML 片段时，可能破坏行布局或注入标记；物料名称则使用了转义函数。源码静态分析，具体表现需在隔离环境复核。

## 解决方案

使用 DOM 属性赋值创建控件，或对单位等所有动态属性值进行适当的属性转义；同时检查其他可编辑字段在重新渲染及导出时的处理，使用引号和尖括号样例验证原样保留且不产生额外元素。
