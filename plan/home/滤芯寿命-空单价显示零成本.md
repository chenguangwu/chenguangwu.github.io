# 滤芯寿命：空单价被当成零成本

受影响工具：`tools/home/water-filter-lifespan.html`

`hasBlankCore()` 不检查滤芯单价，`num('price')` 把空值转换为 0，因此 `isFinite(d.price)` 仍通过，结果会把未填写价格当作免费滤芯，显示零年成本和零每升成本；代码中“请填写滤芯单价”的提示无法覆盖该空值场景。显式输入 0 是合法的免费滤芯价格。源码确认，需浏览器核对结果与导出。

解决方案：分别解析原始空串和数值；单价未填时提示补充或只展示与价格无关的寿命结果，不给成本结论；显式 0 正常计算。验证有效价格→清空→0→恢复，以及成本、日期、图表和 CSV 的一致性。
