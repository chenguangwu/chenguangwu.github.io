# 房间面积：部分形状未拒绝负尺寸

受影响工具：`tools/home/room-calculator.html`

字段设置 `min=0`，但矩形、圆形、梯形和平行四边形分支未完整检查输入的有限性和非负性，直接计算。隔离执行页面原 `calc()` 时，矩形宽 -2、高 3 返回面积 -6、周长 2 和对角线约 3.61；HTML 的 `min` 本身不会阻止脚本计算。平行四边形还需检查边长与高能否构成实际形状。

解决方案：根据各形状的几何约束明确校验输入，负值、非有限值或无法构成形状时只提示错误并清除旧结果和导出；按页面需求明确零尺寸是合法退化情况还是应提示，不能将 0 当作空值。验证手动输入、科学计数法、边界、不同形状切换、图表和历史。
