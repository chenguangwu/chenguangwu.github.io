# 照明计算：无效输入后图表仍显示估算

受影响工具：`tools/home/lighting-calculator.html`

主 `calc()` 在必填项缺失或 CU/MF 越界时清空灯具结果并显示提示，但包装函数随后无条件调用 `__lightExtras()`。该函数对空 CU/MF 使用 0.6/0.8 默认值，只要面积有效就会重新绘制功率图；无效但非空的系数也可能进入图表。用户会同时看到输入错误和看似有效的图表。源码确认，需实机验证图表状态及无效值边界。

解决方案：由主计算返回统一的有效结果对象，图表和导出仅消费该对象；验证失败或清空时清除旧图及缓存，不用额外默认值生成结论。测试有效输入→清空 CU/MF→输入越界→恢复，核对提示、图表、导出和语言切换。
