# 油漆用量：CSV 导出时将用户名称作为 HTML 插入

受影响工具：`tools/home/paint-calculator.html`

“涂刷面”名称可由用户输入并保存；列表展示时使用了转义，但 `__paintExport()` 在构造隐藏表格时将名称直接拼入 `tbody.innerHTML`。隔离 DOM 中以无害的加粗标签作为名称，调用页面原导出函数后出现了真实元素。恶意内容可能在点击导出时进入本站页面上下文，影响本地数据与隐私；该风险不因表格隐藏而消失。

解决方案：通过 DOM 创建单元格并用 `textContent` 写入名称，或采用上下文正确的可靠转义；保持 CSV 公式注入防护，不能为了渲染关闭公共转义。验证尖括号、引号、换行和无害事件探针按文本导出且不执行，并核对普通名称、复制和下载。
