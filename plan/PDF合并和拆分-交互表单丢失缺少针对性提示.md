# PDF 合并和拆分：交互表单丢失缺少针对性提示

- 受影响工具路径：`tools/office/pdf-merge.html`、`tools/office/pdf-split.html`

## 问题描述

页面已有通用提示称交互表单可能不保留，但实际页面复制流程会使表单字段丢失。使用项目自带 PDF 库在内存复现：源 PDF 含文本字段，按页面的 `copyPages` 流程生成后字段列表为空。用户选择文件后不会得到针对该文件的提醒，可能在下载后才发现无法编辑。

## 解决方案

检测输入文档是否含表单，操作前明确说明实际支持情况，并研究可靠保留字段或由用户选择展平的纯前端方案；验证字段值、多个字段及常用阅读器显示。
