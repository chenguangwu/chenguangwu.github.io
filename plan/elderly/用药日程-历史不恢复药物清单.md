# 用药日程：历史记录不包含完整药物清单

受影响工具：`tools/elderly/medication-schedule.html`

药物行由 `list` 动态生成，输入只有 `data-i` / `data-k`，没有 id；通用 `__medication_scheduleSnap()` 只收集带 id 的控件，因此不会保存每种药的名称、剂量、间隔和首剂时间。点击历史记录的回填函数也只恢复带 id 的字段，再调用 `render()`，保留当前药物清单而非当时的清单。历史摘要仅截取结果文本前 80 个字符，不能作为完整方案恢复。源码确认，需在隔离浏览器中用两组不同药物验证交互和刷新行为。

解决方案：若提供历史恢复，明确本地保存完整、版本化的药物条目与日期参数，并在恢复前清除当前表单的遗漏字段、展示完整清单供确认；对旧的不完整记录标明无法恢复，不能默默混用当前药物。提供清空、存储失败提示及隐私说明；验证不同药物数量、空字段、刷新、恢复、清除和复制。用户应始终核对处方，工具不推断用药方案。
