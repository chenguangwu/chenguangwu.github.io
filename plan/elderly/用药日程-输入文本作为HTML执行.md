# 用药日程：药名和剂量未转义地插入 HTML

受影响工具：`tools/elderly/medication-schedule.html`

用户可编辑的药名和剂量直接拼入日程的 `result.innerHTML`，重新生成输入行时又被拼进 `value` 属性。隔离 DOM 中用无害加粗标签作为药名调用页面原 `render()`，结果区生成了真实元素。恶意内容可能在本站上下文执行，影响用药数据和用户隐私；本次验证仅使用无害标记，没有执行恶意代码。

解决方案：日程文字通过 `textContent` 或可靠的文本转义写入，输入行使用 DOM 属性设置，避免属性逃逸；检查复制与导出路径。以尖括号、单/双引号和无害事件探针测试编辑、添加/删除药物、日程重绘与复制，不得关闭公共转义。
