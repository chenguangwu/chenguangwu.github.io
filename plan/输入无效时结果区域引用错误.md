# 输入无效时结果区域引用错误

## 问题描述

以下工具的校验分支均向不存在的 `#result` 写入错误提示，实际结果区域使用其他 ID。触发时会抛出 `TypeError`，提示不能显示，先前结果也可能保留。已在本地隔离 Chromium 分别触发下面四种情况，均实测抛出 `TypeError: Cannot set properties of null (setting innerHTML)`；附加表格、导出和历史是否残留旧结果仍需进一步检查。

- `tools/automotive/cycle-belt.html`：清空当前里程或上次更换里程后计算，校验写入 `#result`，实际容器是 `#resultArea`。
- `tools/fitness/calc-heart-rate.html`：年龄 100、静息心率 120 时储备心率为 0，校验写入 `#result`，实际容器是 `#res`。
- `tools/meteorology/risk-14.html`：清空气压或将其设为 0 后计算，校验写入 `#result`，实际容器是 `#res`。
- `tools/tcm-chemistry/capsule-filling.html`：目标装量或填充密度设为 0 后计算装量，校验写入 `#result`，实际容器是 `#fillResult`。

## 解决方案及验收

使用各页面实际的结果容器，校验失败时先清空该计算的结果、辅助图表、可复制/导出状态和缓存，再显示与当前语言一致的提示；不要影响合法的零值。逐页测试有效输入→无效输入→恢复有效输入，确认无异常、无旧结论、提示正确，并测试中英文及移动端。
