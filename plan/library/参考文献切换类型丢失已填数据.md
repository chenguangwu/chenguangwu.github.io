# 参考文献切换类型丢失已填数据

## 问题

更换文献类型时，`onTypeChange` 直接重建类型相关输入并填入示例值；切换回来后之前填写的出版地、期刊或网址等内容丢失。生成器也把所有超过三名的作者统一标为“等”，与页面承诺英文作者使用 `et al.` 不一致，且原样输出作者姓名，没有完成所称的外文姓名格式化。

## 解决方案

按文献类型保存草稿并在切换回来时恢复，示例需用户主动载入；提供语言及作者姓名字段，按所选著录规则处理省略标识和姓名，同时提示人工核对。验证不同类型往返切换及中英文四作者示例。

- `tools/library/citation-format.html`
