# 跑道长度：顺风未纳入修正

- 受影响工具：`tools/aerospace/runway-length.html`
- 问题：顶风字段接受负数，FAQ 也说明顺风会增加所需距离，但计算中 `Math.max(0, headwind)` 将所有顺风归零，正负风速不会按实际方向对称处理。页面还给修正结果统一增加 15% 并称“建议长度”，使用粗略固定修正系数而未提供机型、跑道状态等真实性能依据，容易让人误认为可用于实际运行。
- 建议：明确风向和符号，增加顺风输入及其计算口径；修正方法、适用前提和数据来源应由专业人员核定。将当前结果标明为教学估算，说明不能替代适航手册及运行性能计算，不以固定余量直接给出运行建议。
- 验证建议：比较零风与不同顺风输入，确保顺风不会被当成零风；核查中英文说明和输入范围一致。
