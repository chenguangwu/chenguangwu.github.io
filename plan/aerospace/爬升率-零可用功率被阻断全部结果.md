# 爬升率：可用功率为零时主计算被阻断

- 受影响工具：`tools/aerospace/climb-rate.html`
- 问题：爬升率公式为 `(可用功率−所需功率)/重量`，可用功率 0 是可表达发动机不提供功率的情况；但统一输入守卫因“剩余功率占比”以可用功率为分母，将 0 视为整个计算的错误，使仍可定义的剩余功率和估算垂直速度无法查看。
- 解决方案：主公式按其自身条件校验，允许可用功率为零；仅将以零为分母的占比标为未定义并解释。明确公式的稳态模型和负爬升率含义，不作为实际飞行性能结论。
- 验证建议：测试可用功率为零、所需功率为零、重量为零以及正功率情况，核对主结果、图表和导出；请专业人员复核适用条件。
