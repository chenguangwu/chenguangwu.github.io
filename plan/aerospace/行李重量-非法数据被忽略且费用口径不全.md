# 行李重量：非法输入被丢弃，费用口径不完整

- 受影响工具：`tools/aerospace/stats-weight-luggage.html`
- 问题：重量列表使用 `parseFloat` 并过滤非正数，像 `18kg` 会被接受为 18，非法项或负数会被无提示丢弃，导致件数和总重偏差。页面只按超重公斤计费，额外件数虽有显示但不计额外件费用；未说明该估算只覆盖这一项，容易与实际航司收费混淆。
- 解决方案：逐项严格校验并提示具体错误位置；明确预估费用仅按输入的单件超重公斤数计算，不包含超件、超尺寸等费用，可支持用户配置各项费用规则与免费额度分配。
- 验证建议：测试非法字符、负数、额外件、空参数及不同收费规则，核对件数、总重和明细。
