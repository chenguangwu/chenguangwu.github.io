# 燃油消耗：时间模式使用隐藏的巡航速度

- 受影响工具：`tools/aerospace/fuel-consumption.html`
- 问题：切换“按飞行时间”后隐藏了巡航速度输入，但结果仍用该隐藏值乘飞行时间，显示估算距离；该值可能来自默认值或用户此前输入，当前模式无法查看和修改，造成结果依据不透明。部分空值使用 `||` 回退为 0 或 1，速度为零时也被当成 1 km/h，仍给出结果。
- 建议：时间模式若需要估算距离，应显示可编辑的速度并说明取值假设；否则不显示距离。按所选模式校验必填参数和有效范围，明确缺失或无效输入，不静默替换为数值。将固定耗油率估算的适用限制写清，不作为实际放行燃油依据。
- 验证建议：切换模式后修改速度、清空速度及输入零，检查界面与输出一致；核对零油耗、零滑行油等合法零值的语义。
