# 飞行时间：城市时区固定导致夏令时计算偏差

- 受影响工具：`tools/aerospace/flight-time.html`
- 问题：出发和到达城市的选项采用固定 UTC 偏移，未根据航班日期处理夏令时。例如纽约始终使用 UTC−5，伦敦始终使用 UTC+0；夏令时日期的实际偏移可能不同，从而使飞行时长或到达时间偏差一小时。页面按城市直接展示固定值，缺少显著提示，也缺少任意偏移选项。
- 建议：按日期和 IANA 时区计算当地时间，处理跨夏令时转换的歧义；支持自定义时区或明确自定义偏移，注明历史时区规则及数据来源。机场日期时间转换应与访问者设备所在时区无关。
- 验证建议：分别用纽约冬夏日期、夏令时切换边界和不同时区的访问设备核对转换及往返结果。
