# 雷诺数：圆管流态阈值被用于通用航空场景

- 受影响工具：`tools/aerospace/reynolds-number.html`
- 问题：工具默认输入与算例针对机翼特征长度，但结果始终按照圆管流动的 2300、4000 阈值给出“流态判别”。虽然结果卡带有圆管参考字样，标题、搜索描述和部分说明仍泛称可判断流态；机翼外流的边界层转捩取决于几何、表面及来流等因素，不能套用该阈值作为通用结论。
- 解决方案：通用模式只计算雷诺数并说明局限；若提供圆管流态参考，要求显式选择场景、说明适用条件和判据的经验性。同步修正搜索描述和正文的绝对表述。
- 验证建议：分别检查圆管与机翼场景的结果、说明和 SEO；由流体力学专业人员核实适用边界。
