# 跑道温度修正：空海拔和温度被默认为零

- 受影响工具：`tools/aerospace/length-temp-runway.html`
- 问题：海拔、温度使用 `parseFloat(...) || 0`，清空字段后仍显示“修正后所需长度”，等同于明确输入 0 m 或 0°C。现有公式为固定系数的简化估算，结果名称容易被误用为实际运行所需距离。
- 解决方案：区分空值与合法的零，缺项时提示并清除旧结果；明确计算仅作教学估算，列出修正系数及其局限，实际运行采用机型性能资料和适用规则。
- 验证建议：分别清空海拔、温度，输入 0 和负温度，核对主结果及历史数据；专业人员复核公式和文案。
