# 失速速度与翼载荷负输入参与计算

受影响工具：`tools/aerospace/stall-speed.html`、`tools/aerospace/wing-loading.html`

问题：主计算只由通用守卫检查空值和零分母，未统一校验重量、面积、密度和最大升力系数的物理范围。负数可能得到无意义的失速速度，多个负值相消时甚至可产生有限结果；翼载荷的单位载荷面积使用 `max(W,1)`，小于 1 N 的正重量被静默替换。

方案：对参与公式的参数进行有限正数校验，移除静默截断；主结果、图表、明细与历史共用同一有效状态，无效时清除旧值。标明翼载荷页面失速估算所用密度和升力系数仅为固定假设，支持调整。

依据源码静态分析，需复核实际输入交互和模型。
