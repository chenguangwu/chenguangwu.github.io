## 问题

`tools/jewelry/convert-31.html`、`tools/astronomy/convert-15.html`、`tools/general/convert-22.html`
三页的「全部数值输入为空」守卫写在**顶层**：

```js
if (__ni.length && __ni.every(...)) { ...; return; }
```

classic script 不允许顶层 `return`，整段内联脚本在解析阶段即 `SyntaxError: Illegal return statement`，
该页 `calc()` / 复制 / 预设 / 历史等全部逻辑静默失效（页面能打开、按钮无反应）。

## 根因：既有门禁为什么没抓到

`scripts/check_inline_js_syntax.js` 用 `new Function(code)` 做语法检查，而 `new Function`
会把代码包进函数体 —— 函数体内的 `return`（即使在 `if` 块里）完全合法，因此这类缺陷被误判为通过。
只有 `vm.Script`（Program 语义，等同浏览器 classic script）才会报 `Illegal return statement`。

## 修复

1. 三页守卫改为 IIFE：`(function(){ ... })();`
2. `scripts/check_inline_js_syntax.js` 改用 `new vm.Script(code)`，并在注释中写明为什么不能用
   `new Function`；升级后全站立即又抓出上述两页（convert-15 / convert-22），说明门禁有效。
3. 复查全站 12,102 个内联脚本，0 语法错误。
