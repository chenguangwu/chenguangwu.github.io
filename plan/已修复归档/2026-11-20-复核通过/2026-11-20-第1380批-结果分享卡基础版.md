# 第 1380 批：结果分享卡基础版（G06-S4）

> **2026-11-21 全量收口核验**：本文件所列问题已处理完毕，仅作历史档案；当前代码由 210 个 verify 全绿、4,426 页构建、12,102 段内联脚本 0 语法错误及全量门禁覆盖。

## 目标
G06 诊断「结果不可带走」：数字看完即止，没有体面的分享物。S4 要求「一键生成结果分享卡（工具名+关键输入+结果+站点 URL），
纯前端 canvas，不上传」。

## 实现（全部在 `js/common.js` 既有的「分享与嵌入」组件内，不改工具页）
- `tbSeResultLines(max)`：按 `.result-box → .results → .result → .output → #result → #results` 顺序找结果区，
  用 **innerText**（跳过 `display:none` 的分步面板）压缩空白后按 `｜`/`；`/句读切成最多 3 行、每行 34 字截断。
- `tbSeMakeCard()`：本地 canvas 1200×630，深蓝渐变背景 + 工具名（22 字截断）+ 首行高亮（黄）结果 + 站点标识/底栏；
  `toDataURL('image/png')` 生成下载链接，文件名 `toolbox-<slug>-card.png`；埋点 `share_card_download`（走既有 Analytics，不含任何页面数据）。
- 分享面板新增按钮「生成结果分享卡 / Create a result card」，状态位 `.tb-se-card-tip` 三态（空结果 / 成功 / 失败），
  空态提示「先在页面上算出结果，再来生成分享卡」，不会凭空导出一张空卡。
- `css/common.css`：`.tb-se-card` 一行布局 + 提示配色。

## 边界
- 只在标准工具页出现（沿用既有 `isStandardToolUrl` 判定），首页/分类页/嵌入态不出现。
- 纯本地，无网络请求、无上传；不读用户历史记录。
- 已知局限：部分页面把多种模式的说明都放在 `.result-box`，卡片取的是「当前可见文本」的前几行，文案可能偏说明性；
  后续可在高频页给结果区加 `data-share-summary` 精确指定分享文案（不影响本批）。
