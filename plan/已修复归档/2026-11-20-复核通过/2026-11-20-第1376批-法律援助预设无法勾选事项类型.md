## 缺陷
`tools/legal/legal-aid-eligibility.html` 四组预设只写 `applicantType/monthlyIncome/localLowIncome`，
而「申请事项类型」是一组无 id 的 `class="matter-type"` 复选框，`TBKit.preset.bar` 按 id 写值 ⇒ 永远勾不上，
点任一预设都只会得到「⚠️ 请选择申请事项类型」，等于预设全部失效。

## 修复
- 给 7 个事项复选框补稳定 id：`matter_labor / marriage / traffic / state / social / support / hero`（`checkEligibility` 仍按 class 读取，逻辑不变）。
- 预设补 `matter_*` 键：低收入/收入超标 → 劳动争议；农民工讨薪 → 劳动争议；重度残疾 → 社会保险待遇。
