# CKD 分期：UACR 边界分期与参考区间不一致

## 受影响工具路径

- `tools/nephrology/ckd-staging.html`

## 问题描述

静态检查发现，UACR 为 300 mg/g 时，主分期代码 `uacr <= 300` 给出 A2；参考区间 `__uBands` 使用左闭右开区间，300 落入 A3。同一输入可在页面同时出现 A2 分期和 A3 参考区间，导致结果自相矛盾。具体边界应以所选指南及单位口径核实，尚未进行浏览器复现或医学文献核验。

## 解决方案

由专业人员确认所采用的指南版本和边界后，统一主分期、参考区间、风险分层与中英文文案的端点规则；增加 300 及其两侧输入的验证，并检查表格和导出使用同一结果。
