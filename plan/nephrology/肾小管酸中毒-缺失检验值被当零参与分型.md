# 肾小管酸中毒：缺失检验值被当零参与分型

## 问题

页面仅要求血液 pH 和碳酸氢盐为正；清空血钾、尿 pH、尿阴离子间隙或 FE-HCO₃ 时，这些值会被替换为 0 并参与分型和文字解释。例如血钾缺失显示“血钾=0 → 低钾”，尿阴离子间隙 0 被称为负值。缺失或零值可能导致错误类型及治疗文字。

## 解决方案

按分型依赖逐项校验和展示未检测，缺乏必要证据时保留不确定状态；尿阴离子间隙正、零、负分开处理。由专业人员核查算法及治疗表述，并验证每项空值、零值和异常值。
