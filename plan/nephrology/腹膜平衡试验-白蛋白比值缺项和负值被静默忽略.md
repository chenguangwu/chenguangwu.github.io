# 腹膜平衡试验：白蛋白比值缺项和负值被静默忽略

## 受影响工具路径

- `tools/nephrology/peritoneal-equilibrium.html`

## 问题描述

静态检查发现，白蛋白比值读取时用 `parseFloat(...) || 0`，仅在值大于 0 时输出解读。因此清空、输入 0 或负数都不会显示该指标，页面仍给出其余结果，没有说明白蛋白比值未评估或输入无效。特别是负数可被静默接受，用户不易发现录入错误。该结论尚未做浏览器实测或医学标准核验。

## 解决方案

区分未填写、合法零值和非法数值；对负数及非有限数给出明确提示，缺项标记为未评估，不影响其他可独立计算的指标。明确白蛋白比值的适用范围和临床解释，并由专业人员核对参考依据；补充空值、零值、负值和正常值的交互验证。
