# CKD 管理：ACR 空值在特定单位被误判为 A3

## 问题

选择 ACR 单位 mg/mmol 后留空，`parseFloat` 得到 NaN，转换时直接乘以 8.84，结果仍为 NaN 而非表示缺失的 null。后续分期判断 `NaN < 30` 和 `NaN <= 300` 均为假，因而进入 A3，继续计算风险。相同空值在 mg/g 模式被正确标为未检测，两个单位行为不一致。

## 解决方案

先独立判断 ACR 是否缺失及是否为有限非负数，再进行单位换算；缺失时显示未检测并暂停依赖 ACR 的风险分级。覆盖两种单位的空值、零值、负值和有效等价数值，核对计算、保存和恢复一致。
