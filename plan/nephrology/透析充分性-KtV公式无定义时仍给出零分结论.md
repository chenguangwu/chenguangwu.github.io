# 透析充分性：Kt/V 公式无定义时仍给出零分结论

## 问题

公式中的对数参数为 `R - 0.008 × 透析小时数`，页面只检查透析前后 BUN 的大小，并未检查该参数是否大于 0。参数为负时产生 NaN 后被强行改成 0，继续输出“透析不充分”；为 0 时可能产生 Infinity，仍进入后续分级。持续时间和体重减少量等负数也未被有效排除。错误输入因此可能被呈现为有意义的临床结论。

## 解决方案

明确校验输入的有限性、合理范围、正的分母和对数定义域；公式无定义或结果非有限时停止判读并解释需检查的字段，不用 0 替代。增加参数为正、零、负及极端输入的回归验证，医学阈值与建议由专业人员复核。
