# 同一工具的多套历史记录清除范围不一致

## 问题描述

部分页面同时使用页面自有的 `tb_history_...` 和共享 `TBKit.history` 的 `tbk_hist_...`；各自历史面板的清空按钮只清除各自的键。用户看到“清空历史”或“清空”，可能以为该工具的全部历史已删除，但另一份仍保留在本地。

已从源码确认的代表路径：

- `tools/agriculture/estimate-soil.html`：自有历史的 `clearHistory()` 只删除 `historyKey()`，同时使用 `TBKit.history`。
- `tools/paper/strength-10.html`：同样存在自有历史面板和 `TBKit.history` 面板，需实机验证各清空入口及交互。
- `tools/nephrology/jixingshensunshang-kdigo-fenqi.html`：另一份自有历史面板不可见；点击可见面板的清空后，自有键仍留存，已实机复现。详见 `plan/nephrology/KDIGO历史重复存储.md`。

静态筛选同时包含 `tb_history_`、`TBKit.history` 和 `localStorage.setItem` 的页面共 496 个，仅为待复核候选，可能包含兼容或清理逻辑；不得把总数视为已确认缺陷。

## 解决方案及验收

统一历史记录和清空入口，或在界面明确标出每个入口的范围并提供清除该工具全部记录的操作；处理旧版遗留键时避免误删其他工具数据。临床及其他敏感输入优先核查。测试两种记录均有数据时分别清空、刷新、重新访问，并检查所有该工具相关 localStorage 键；在保存和删除失败时给出清晰提示。

候选路径可由以下只读筛选复现；需要逐页确认保存键、按钮语义和清理行为：

```sh
python3 - <<'PY'
from pathlib import Path
for p in sorted(Path('tools').glob('*/*.html')):
    s = p.read_text(encoding='utf-8')
    if 'tb_history_' in s and 'TBKit.history' in s and 'localStorage.setItem' in s:
        print(p)
PY
```
