# 混合配比：超出百分百的浓度仍被接受

## 问题描述
混合模式只检查浓度非负，稀释和酒精模式只检查浓度大于 0 及目标低于原浓度，没有限制百分比或酒精体积分数不超过 100。例如混合输入 150% 与 150% 会得到 150% 的混合浓度，酒精原浓度 150%、目标 120% 也会给出加水量，输入错误可能被当作可执行方案。

## 解决方案
根据各模式明确浓度单位及允许区间，对百分比和体积分数校验 0–100，分别处理零浓度与零用量；越界时清空旧结果并给出具体字段提示。验证 0、100、超过 100 和目标高于原浓度等场景。
