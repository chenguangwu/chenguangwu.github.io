# 配料排序：用户文本作为 HTML 插入结果

受影响工具：`tools/food-testing/ingredient-sorter.html`

`foodName` 和配料名称直接拼进 HTML 字符串后赋给 `result.innerHTML`，未进行文本转义。在隔离 DOM 中，输入包含普通加粗标签的食品名称后，结果区产生了真实的加粗元素，而不是按文本显示标签。含事件处理的恶意内容可能在本站页面上下文执行，影响本地数据和用户隐私；配料名称亦有同样的拼接路径。

解决方案：用户提供的名称仅使用 `textContent` 或经可靠的上下文转义后再插入；检查表格、图表、复制和导出路径，不要把用户输入作为 HTML 或属性拼接。用普通文字、尖括号、引号和无害事件探针验证输入被原样展示且不执行；复核其他同模式页面，但不要扩大到尚未确认的路径。
