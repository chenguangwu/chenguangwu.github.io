# 摩尔质量工具明细导出缺少元素组成

- 受影响工具路径：`tools/science/molar-mass-calculator.html`、`tools/science/calc-cycle.html`
- 问题：两个页面的“导出明细 CSV”均导出历史记录表，历史结果只保留结果区文本的前 80 个字符，而非当前逐元素组成、原子量、质量和占比等完整明细。多元素化学式尤其容易丢失后续数据，导出名称与用户预期不符。依据源码分析，实际 CSV 待核验。
- 解决方案：以当前有效计算的结构化元素明细生成 CSV，包含化学式、总摩尔质量、元素计数、原子量、分项质量和占比；历史导出单独标明。验证多元素、水合物、清空和计算错误后的导出，以及中英文列名。
