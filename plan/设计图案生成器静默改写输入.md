# 设计图案生成器静默改写输入

## 问题描述

多页将空值静默替换为默认值或对低于下限的输入截断，输入框数值与实际 CSS 不一致；例如蓝图网格主间距输入 10，生成结果却使用 20px。

## 解决方案

统一检查空值、有限数及适用上下限，提示无效输入，保留合法零值并确保显示与生成结果一致。

## 受影响的工具路径

- `tools/design/dot-pattern.html`
- `tools/design/stripe-pattern.html`
- `tools/design/blueprint-grid.html`
- `tools/design/isometric-grid.html`
- `tools/design/checkerboard-generator.html`
