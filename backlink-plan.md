# ToolBox 外链建设作战清单

> 生成于脚本 `scripts/gen_backlink_plan.py`（可复跑）。全站 **5023** 个工具，A 级 **5023** 个。

> 外链（backlinks）= 别的网站链向 ToolBox。质量 > 数量、相关性 > 泛链接。**只做白帽**，买链/PBN/群发一律不碰（降权除名风险）。

## 二、AlternativeTo 竞品关联（把 ToolBox 挂到这些竞品产品下）

- **it-tools.tech** — 直接竞品（同纯前端工具站），ToolBox 工具更全、中文友好
- **Toolfk.com** — 中文在线工具聚合站
- **Smallpdf / iLovePDF** — PDF 类工具竞品（若做了 PDF 工具）
- **JSON Formatter / Base64 Decode 等单工具站** — 对应分类下作为 alternative 出现

> 在 AlternativeTo 建「ToolBox」条目后，于每类工具的 *Alternatives to* 栏填入上述竞品，用户搜索竞品时会看到 ToolBox，自然带 DoFollow 外链。

## 四、提交文案模板

### 4.1 Product Hunt Launch
```
Tagline: 6000+ free online tools, 100% in-browser, no data upload.
Topics: Productivity, Developer Tools, Web App
First Comment: 为什么做 / 与 it-tools 的差异（更全、中文友好）
```

### 4.2 Hacker News (Show HN)
```
Title: Show HN: ToolBox – 6000+ free, fully client-side web tools
Text: 纯静态、零后端、数据不上传；覆盖 IT/金融/设计/生活。求反馈。
```

### 4.3 资源页邮件 Outreach
```
邮件: Hi, 我发现你的 {行业} 工具清单很棒，可否把 ToolBox（6000+ 工具含 {行业} 分类）加进去？
```

## 五、铁律（决定外链有没有用）

1. **质量 > 数量**：1 条 DR 80 外链 > 100 条 DR 5。
2. **相关性**：同行业/同主题外链权重更高。
3. **自然锚文本**：混用品牌词 + 泛词（「在线 Base64 工具」），别全用「ToolBox」。
4. **渐进式增长**：别一天暴涨上千条，会被判作弊。
5. **UGC/广告平台链接加 `rel="ugc"/"sponsored"`**，避免被连坐。
6. **站内已埋回链入口**：工具页「分享与嵌入」组件生成带品牌回链的 iframe 代码，鼓励用户自发外链（见 `embed.html`）。


## 六、配套动作（已上线）

- 工具页底部「分享与嵌入」组件（`js/common.js` `injectShareEmbed`）：嵌入码自带可抓取品牌回链，不用 `nofollow`。
- `embed.html` 文档页新增「带署名回链」推荐写法，引导用户正确嵌入以传递权重。
