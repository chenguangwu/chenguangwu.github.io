🧩 工具嵌入 API

ToolBox 的所有工具均为纯前端实现，可直接通过 <iframe> 嵌入到你的网站、博客或文档中，数据全部在访客浏览器本地处理。

免费 · 无后端 · 数据不出浏览器

1. 推荐写法：带署名回链

iframe 本身不传递 SEO 权重——搜索引擎看到的是 iframe 的 src，不会给嵌入方或本站加分。 真正有价值的是 iframe 下方那条可点击、可抓取的署名链接。因此推荐用下面这段完整代码：

<div class="toolbox-embed">
  <iframe
    src="https://chenguangwu.github.io/tools/it/json-formatter.html?embed=1"
    width="100%" height="520"
    style="border:0;border-radius:12px" loading="lazy"
    title="JSON Formatter"></iframe>
  <p style="margin:6px 0 0;font:12px/1.5 system-ui,-apple-system,sans-serif;text-align:right">
    <a href="https://chenguangwu.github.io/tools/it/json-formatter.html" target="_blank" rel="noopener">JSON Formatter · ToolBox</a>
  </p>
</div>

不必手抄：打开任意工具页，页面底部都有「分享与嵌入」区块，展开即可一键复制适配当前工具的代码（可选高度与深浅主题）。

2. 基础嵌入（最简写法）

将任意工具页 URL 放入 iframe 即可（注意：这种裸 iframe 不含回链，不会传递权重）：

<iframe
  src="https://chenguangwu.github.io/tools/it/json-formatter.html?embed=1"
  width="100%" height="520" style="border:0;border-radius:12px"
  loading="lazy"></iframe>

3. 嵌入参数

参数说明示例
embed开启嵌入模式，自动隐藏导航栏、面包屑、隐私标识与主题按钮?embed=1
theme强制主题：dark 或 light?theme=dark
accent自定义主题色（十六进制，含 #）?accent=%23FF6B35

4. 组合示例

<iframe
  src="https://chenguangwu.github.io/tools/finance/compound-interest.html?embed=1&theme=dark&accent=%237C3AED"
  width="100%" height="560" style="border:0;border-radius:12px"
  loading="lazy"></iframe>

6. 注意事项与 SEO 说明

  • 嵌入页与官网完全一致，所有计算在访客本地完成，无需你的服务器承担算力。
  • 建议为 iframe 设置合适的固定高度（工具页内容高度随输入变化）。
  • 如被浏览器拦截（X-Frame-Options），本站点已允许同源/跨域 iframe 嵌入。
  • 关于权重：iframe 不传递链接权重，只有页面里真实存在的 <a href> 才会传递。若希望这次嵌入也算作对 ToolBox 的一次推荐，请保留第 1 节中的署名回链（不要给它加 rel="nofollow"）；若不方便展示，去掉也完全没问题，工具照样可用。
