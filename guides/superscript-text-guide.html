上标文字 使用指南

将选中文字转为上标格式并生成可复制的 Unicode 或 HTML 上标代码，适合化学式、数学指数与脚注标注，便于在文档中插入上标。

功能说明

将选中文字转为上标格式并生成可复制的 Unicode 或 HTML 上标代码，适合化学式、数学指数与脚注标注，便于在文档中插入上标。

使用步骤

  1. 填写「转换模式」。
  2. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 化学式与数学公式展示：把指数、阶码转为上标形态（如 x²、CO₂ 的 2 用上标）。
  • 脚注与修订标记：在正文标注上标序号，对应文末注。
  • 单位与版本号：如 m²、v2 的轻量展示。

算例参考

  • 生成 x 的平方：输入「x2」，上标模式输出「x²」；也可用上标数字区块直接展示，适合化学式 H₂O、面积 m² 等无需公式环境的场景。

注意事项

本工具在浏览器本地运行，输入内容不会上传服务器；结果为模型估算，工程决策请结合实测数据复核。

上标和普通小字区别？
上标用专用 Unicode 上标码位（² ¹ ⁿ），排版位置更高且不被当作普通数字参与计算；普通缩小的字只是视觉变小。
