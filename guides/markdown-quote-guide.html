Markdown 引用转换器 使用指南

将粘贴的多行文本批量转换为 Markdown 引用块（每行前加 >），便于在文档中引用他人内容或做批注说明。

功能说明

将粘贴的多行文本批量转换为 Markdown 引用块（每行前加 >），便于在文档中引用他人内容或做批注说明。

典型使用场景

  • 引用他人内容：把选中段落批量加上 > 前缀，生成规范 blockquote。
  • 多级引用与嵌套：演示如何在引用内再引用，保持缩进正确。
  • 写文档「提示/警告」框：用引用块承载 tip/note 内容。

算例参考

  • 多行加引用：粘贴 3 行文字，工具在每行前加「> 」，得到「> 第一行 > 第二行 > 第三行」，渲染为连续引用块；空行分隔可断开为多个独立引用。

注意事项

本工具在浏览器本地运行，输入内容不会上传服务器；结果为模型估算，工程决策请结合实测数据复核。

怎么嵌套引用？
在子行前缀用「> > 」即可形成二级引用；层级越多前缀 > 越多，注意层级间用空行分隔更易读。
引用块能包含代码吗？
可以，引用块内再用代码围栏即可；但缩进与围栏要正确闭合，否则会破坏引用结构。
