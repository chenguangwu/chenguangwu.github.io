广告效果指数 AEI 使用指南

触达 0、无辅助回忆 0、投入 0 都是合法输入；只让对应比率显示「未定义」或「¥0」，其他指标继续计算。

功能说明

从曝光（触达率、频次、CTR）、记忆（辅助/无辅助回忆、品牌识别）、态度（好感提升、购买意向、NPS）三维计算 AEI，并按 ≥80/65/50 分档评级。另算 CPM（元/千次曝光）与每回忆用户成本，用于跨渠道性价比比较。

输入与范围

  • 触达人数为非负整数，目标人群为大于 0 的整数；触达不能大于目标。
  • 平均频次、CTR、回忆率、识别率、好感/意向提升按页面范围填写；NPS 允许 −100–100。
  • 广告投入以万元计，必须是非负数；0 表示免费投放，不会被替换成 1 万元。
  • 零触达或零频次时 CPM 显示「未定义（触达人数或平均频次为 0）」；零回忆时每回忆用户成本显示未定义。

操作步骤

  1. 先填目标人群与去重触达人数，确认触达率口径。
  2. 填平均频次、CTR 与三项记忆指标；没有做回忆调研时不要用 0 冒充「未测量」，应留空或先补数据。
  3. 填好感、意向、NPS 与投入，查看 AEI、三维得分和成本指标。
  4. 按短板建议调整创意/媒介，不要只因为 AEI 低就加预算。

算例

触达 400000/目标 800000（50%→15 分）、频次 4（40 分）、CTR 2.0%（12 分）→曝光 67；辅助 60/无辅助 35/识别 70→记忆 53；好感+20/意向+15/NPS30→态度 48；AEI≈55「效果一般」。投入 50 万元时，每回忆用户成本=500000÷140000≈3.57 元，CPM=500000÷1600=312.5 元。

注意事项

AEI 是加权评估，不是销量预测；触达、回忆和态度指标必须同源同口径。零值代表真实的「没有」或「免费」，但若实际是漏填，结果会严重失真。工具不上传数据。

触达填 0 为什么还能算？
0 是合法的「没有触达」；其余分项仍计算，但触达率、CPM 会明确显示 0 或未定义，并提示不能代表真实投放。
投入 0 时 CPM 是多少？
CPM 与每回忆用户成本均为 ¥0；页面会提醒确认是免费资源，而不是漏填预算。
为什么每回忆用户成本显示未定义？
分母需要触达人数与无辅助回忆率都大于 0；任一为 0 时没有可计算的回忆人数。
