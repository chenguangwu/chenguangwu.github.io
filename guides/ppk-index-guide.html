Ppk 过程性能计算器 使用指南

Ppk 过程性能计算器求考虑中心偏移的长期过程性能指数，适合实际生产数据的能力评估与供货质量承诺。

计算公式与原理

Ppk = min((USL−μ),(μ−LSL)) / (3σ_lt)

Ppk 过程性能计算器求考虑中心偏移的长期过程性能指数，适合实际生产数据的能力评估与供货质量承诺。

使用步骤

  1. 填写「上规格限 USL」。
  2. 填写「下规格限 LSL」。
  3. 填写「过程均值 μ」。
  4. 填写「长期标准差 σ_lt」。
  5. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 用整体标准差（长期）评估过程实际性能 Ppk，同时纳入均值偏移，给出长期可达的合格品能力。
  • 与 Cpk 对照：Ppk 用整体σ、Cpk 用组内σ，两者差大表示长期存在偏移或特殊原因。
  • 客户年度审核、PPAP 等用 Ppk 作为长期质量承诺指标。

算例参考

  • 公式与判定：Ppk = min[(USL − μ)/(3σ_long), (μ − LSL)/(3σ_long)]，σ_long 为整体标准差。判定：≥1.33 长期充足、<1.00 不足。Ppk 通常 ≤ Cpk。
  • 算例：规格 USL=10.05、LSL=9.95，长期均值 μ=10.0、整体σ_long=0.015：Ppk = min[(10.05−10.0)/(3×0.015), (10.0−9.95)/(3×0.015)] = min[0.05/0.045, 0.05/0.045] = min[1.111, 1.111] = 1.111。若短期 Cpk=1.667，则 Ppk<Cpk，提示长期需进一步稳定化。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

Ppk 与 Cpk 的核心区别？
唯一差别在σ 的来源：Cpk 用组内（短期）标准差，Ppk 用整体（长期）标准差；两者都计均值偏移。因而 Ppk 更贴近客户长期收到货的实际表现。
客户要 Ppk 还是 Cpk？
PPAP/年度审核多要求 Ppk（长期承诺），过程开发阶段内部用 Cpk（短期能力）驱动改进；稳妥做法是两者都达标且差距小，说明过程既能力强又稳定。
