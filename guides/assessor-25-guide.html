阅读（打开率/完读）评估 使用指南

内容阅读效果在线评估工具，输入打开率、完读率与互动率等指标评估文章表现，辅助运营优化，纯前端运行。

功能说明

内容阅读效果在线评估工具，输入打开率、完读率与互动率等指标评估文章表现，辅助运营优化，纯前端运行。

典型使用场景

  • 推送效果复盘：录入发送/打开/完读/互动与阅读时长，用打开率看标题封面、完读率看内容质量、互动率看共鸣。
  • 阅读完成度诊断：用 实际阅读时长 ÷ 预期时长（字数÷5）看用户是否真的读完，定位「点开就走」的低质流量。
  • 综合评分：三率各按阈值给 0–3 分（满分 9），≥75% 优秀、50–75% 良好、25–50% 一般、<25% 差，快速分级。

算例参考

  • 算例（发送8000/打开2400/完读1440/互动300/阅读120秒/总字数800）：打开率 = 2400÷8000×100% = 30.0%；完读率 = 1440÷2400×100% = 60.0%；互动率 = 300÷2400×100% = 12.5%；预期时长 = 800÷5 = 160 秒；阅读完成度 = 120÷160×100% = 75.0%。三率均达标 → 综合 9/9 = 100%『阅读效果优秀』。工具按四维输出并给综合评分与优化建议。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

打开率/完读率多少算正常？
打开率通常 5–30%（看粉丝质量与标题），完读率 20–60%；三者都高说明内容匹配度高。本例打开 30% / 完读 60% / 互动 12.5% 均处中上。
阅读完成度怎么理解？
预期时长 = 字数 ÷ 5（按约 5 字/秒阅读速度），阅读完成度 = 实际时长 ÷ 预期时长。偏低（如 <60%）说明用户没读完，可能是开头不抓人、篇幅过长或预期不符。
