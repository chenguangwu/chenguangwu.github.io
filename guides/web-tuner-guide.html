Web Audio 调音器 使用指南

调用浏览器麦克风实时采集声音并用Web Audio分析音高，显示当前音名与偏差，辅助吉他、贝斯、尤克里里等弦乐器快速调音，纯前端无需联网。

功能说明

调用浏览器麦克风实时采集声音并用Web Audio分析音高，显示当前音名与偏差，辅助吉他、贝斯、尤克里里等弦乐器快速调音，纯前端无需联网。

典型使用场景

  • 吉他/尤克里里对着麦克风调音，看指针与音分偏差
  • 乐器走音时测偏差方向（偏高/偏低）微调弦钮
  • 教学里演示音分概念，±5 音分内即准

算例参考

  • 频率算音名与音分：C0 = 16.3516 Hz，n = 12·log2(f/C0)；440 Hz → n=69 → A4，音分 = (69−69)×100 = 0（准）。446 Hz → n≈69.246 → +24.6 cents（偏高）。
  • 判定准与否：指针居中且 |音分|≤5 显示「准确」；+24.6 cents 提示「偏高」，需放松弦降低频率至 440 Hz 附近。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。
