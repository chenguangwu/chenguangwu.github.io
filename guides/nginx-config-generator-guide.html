Nginx 配置生成器 使用指南

Nginx 配置块多易错。本工具按常见场景（反向代理、静态目录、重定向、HTTPS）产出可用的 server 块。本地生成不上传。

核心功能

  • 反向代理片段
  • 静态站点配置
  • 301 重定向
  • HTTPS/证书占位
  • 本地处理

适用场景

  • 部署前端静态站
  • 给后端加反向代理
  • 配置域名重定向

使用步骤

  1. 选场景填域名/端口
  2. 点击生成
  3. 复制 server 块

实用技巧

  • proxy_pass 末尾斜杠注意
  • 静态站用 root+try_files
  • 改完 nginx -t 校验

常见问题

怎么生效配置？
保存后 nginx -s reload。
