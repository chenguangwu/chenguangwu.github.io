纸箱抗压强度（马基公式） 使用指南

由三项环压估算 ECT，或用实测 ECT 直接计算 BCT；估算模式必须完整填写三项环压，空值不再按 0 处理。

功能说明

估算模式：ECT≈(面纸环压 + 里纸环压 + 芯纸环压×瓦楞率)×换算系数；直接模式：使用输入的实测 ECT，完全忽略三项环压。再由 McKee 近似式 BCT=5.87×ECT×√(周长×厚度) 计算，并结合安全系数、单箱重量与箱高给出堆码层数。

典型使用场景

  • 已有 ECT 实测值：选直接模式，快速估算 BCT 与堆码能力。
  • 只有原纸环压：选估算模式，完整填写三项环压后估算 ECT。
  • 方案对比：调整楞型或环压，观察 BCT 与堆码高度变化。

算例参考

  • C 楞、面纸 6000、里纸 4000、芯纸 2500 N/m、系数 0.5：ECT≈(6000+4000+2500×1.45)×0.5=6812.5 N/m；400×300×300mm、厚 3.6mm 时 BCT≈3994 N。
  • 直接 ECT=7000 N/m：不再读取环压；即使环压留空或为负，也不影响直接模式计算。

注意事项

环压 0 表示确实测得为 0，不等同于未测；三项全为 0 时无法估算，页面会拒绝。McKee 公式为经验近似，实际 BCT 受箱型、开孔、印刷、湿度与堆码时间影响，应以整箱实测为准。

BCT 公式 BCT=5.87·ECT·√(Pm·d) 适用条件？
这是 McKee 经验公式的常用形式，适用于规则开槽箱(RSC)、瓦楞方向正确的 ECT 输入。ECT 可由面/中纸环压与楞型伸张系数估算（ECT≈(面+面+中×takeup)×效率），也可直接实测输入。
安全系数取多少合适？
一般运输仓储取 3–5，潮湿/长周期/自动堆码取高值。它综合温湿度、堆码时间、振动与人工因素；安全系数过小易压塌，过大则过度用材增成本。
