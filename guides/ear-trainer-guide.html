耳训练器 使用指南

耳训练器基于 Web Audio API 播放音程与和弦并训练听音辨识，反复练习可提升视唱练耳与即兴演奏的听力基础，适合音乐学习者。

功能说明

耳训练器基于 Web Audio API 播放音程与和弦并训练听音辨识，反复练习可提升视唱练耳与即兴演奏的听力基础，适合音乐学习者。

典型使用场景

  • 听两个音判音程（小二度到大七度），练相对音感
  • 听和弦判类型（大/小/属七等），提升和声辨识
  • 反复随机出题并即时反馈，建立音程与听感的映射

算例参考

  • 音程半音数：相邻音名半音差：小二度 1、大二度 2、小三度 3、大三度 4、纯四度 5、三全音 6、纯五度 7、小六度 8、大六度 9、小七度 10、大七度 11、八度 12。
  • 和弦辨识：同时响 C-E-G 为大三（明亮）、C-E♭-G 为小三（柔和）、C-E-G-B♭ 为属七（带张力）；听色彩与完成度区分。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

怎么练相对音感？
从纯五度、大三度等色彩鲜明的音程入手，记住参照曲（如《星球大战》开头纯五度），再扩展到全部半音级数。
和弦辨识从哪开始？
先分大/小三和弦（明/暗），再加属七（解决感）、大七（爵士柔光）；每次听后看答案建立听觉记忆。
