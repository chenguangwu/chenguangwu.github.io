YAML 转 JSON 使用指南

YAML 是 JSON 超集、用缩进表达层级。本工具把 YAML 解析为等效 JSON，方便程序读取与转换。本地解析不上传。

核心功能

  • YAML→JSON 转换
  • 缩进层级解析
  • 支持锚点/引用
  • 类型推断
  • 本地处理

适用场景

  • K8s/Docker Compose 配置转数据
  • 写文档示例
  • 格式校验

使用步骤

  1. 粘贴 YAML
  2. 点击转换
  3. 查看 JSON

实用技巧

  • 缩进务必用空格不用 Tab
  • 锚点 & 与 * 会被展开
  • 多文档 --- 取首个
