Basic Auth 生成器 使用指南

Basic Auth 把"用户名:密码"Base64 后放入请求头。本工具生成标准头值与可复制的 curl 命令，便于联调。本地生成不上传凭据。

核心功能

  • 生成 Authorization 头
  • Base64 编码凭据
  • 输出 curl 示例
  • 本地运算

适用场景

  • 调试受保护接口
  • 快速联调后台
  • 生成测试请求

使用步骤

  1. 输入用户名与密码
  2. 点生成得头值
  3. 复制 curl 或请求头

实用技巧

  • Basic Auth 明文传输，务必配 HTTPS
  • 头格式 "Basic <base64>"
  • 凭据勿硬编码进前端

常见问题

为什么要 Base64？
仅编码非加密，配合 HTTPS 才安全。
能给个例子吗？
"user:pass" → "Authorization: Basic dXNlcjpwYXNz"。
