提示词 Token 成本 使用指南

LLM Token 成本估算器，输入输入输出 token 数与单价估算 API 费用，按 1 USD≈7.2 CNY 折算人民币，辅助调用预算。

计算公式与原理

输入费用 = 输入 tokens / 10⁶ × 输入单价；输出费用 = 输出 tokens / 10⁶ × 输出单价；人民币 ≈ 美元 × 汇率

大模型 API 普遍按输入与输出分别计价，且输出单价通常高于输入，因此压缩提示词与控制生成长度都能直接省钱。换算人民币时汇率按当期取值，另需考虑批量/缓存折扣与最低计费粒度。

使用步骤

  1. 填写「输入 Token 数」。
  2. 填写「输出 Token 数」。
  3. 填写「输入单价 $/1M」。
  4. 填写「输出单价 $/1M」。
  5. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 费用=输入 token×输入单价+输出 token×输出单价，按模型计费口径估算。
  • 支持按 1 USD≈7.2 CNY 折算人民币，辅助调用预算与成本对比。
  • 不同模型分词器差异大，token 数需以对应模型为准，本估算为量级参考。

算例参考

  • 成本估算：输入 10k token($0.01/1k)、输出 2k token($0.03/1k) → 费用=10×0.01+2×0.03=0.16 USD≈1.15 元。批量调用前用此预判账单。

注意事项

结果为按上述公式得到的理论估算值，实际表现受数据分布、实现细节与运行环境影响，落地决策请以实测为准；本工具纯前端运行，输入不上传服务器。
