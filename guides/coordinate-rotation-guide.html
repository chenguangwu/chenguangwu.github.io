平面点绕原点旋转 使用指南

平面坐标旋转在线计算器，输入点坐标与旋转角求得绕原点旋转后的新坐标，用于测量与图形变换，纯前端运行。

计算公式与原理

x'=x·cosθ−y·sinθ, y'=x·sinθ+y·cosθ

x&#x27; = x·cosθ − y·sinθ，y&#x27; = x·sinθ + y·cosθ。

使用步骤

  1. 填写「点 X (m)」。
  2. 填写「点 Y (m)」。
  3. 填写「旋转角 θ (°)」。
  4. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 把点绕原点旋转 θ 得新坐标。
  • 轴线对齐/局部系建立。
  • 图形定向。

算例参考

  • 旋转 90°：(1,0) 绕原点转 90° → x'=1·cos90−0·sin90=0，y'=1·sin90+0=1 → (0,1)。
  • 通用：θ=30°、点(2,0) → x'=2×0.866=1.732，y'=2×0.5=1.0 → (1.732,1.0)，用于把建筑轴转到正北。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。
