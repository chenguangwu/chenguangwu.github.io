任意进制转换器 使用指南

支持 2-36 进制任意互转，底层使用 BigInt，可处理远超 Number 精度上限的超大整数；输入数字与源进制，实时得到目标进制结果及常用进制一览。

核心功能

  • 2-36 进制任意互转
  • BigInt 支持超大整数（任意位数）
  • 自动生成二进制/八进制/十进制/十六进制/32/36 一览
  • 进制内非法字符检测与定位
  • 一键复制结果

适用场景

  • 颜色值、MAC 地址的进制换算
  • 数据编码与压缩调试
  • 密码学/哈希场景的大数进制转换

使用步骤

  1. 输入数字（如 ff、1010、255）
  2. 设置源进制与目标进制（2-36）
  3. 实时查看结果与多进制一览
  4. 点击「复制结果」

实用技巧

  • 十六进制字母不区分大小写（ff 与 FF 均可）
  • 进制必须为 2-36 之间
  • 输入含源进制不支持的字符会提示错误位置

常见问题

能转换多大的数？
基于 BigInt 实现，理论上不限位数，可处理百位十进制大数。
为什么 10 进制显示为字符串？
大数超出 Number 精度后会丢精度，工具统一用字符串保真处理。
