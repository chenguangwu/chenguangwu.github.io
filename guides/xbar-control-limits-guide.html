X̄ 控制图界限计算器 使用指南

X̄ 控制图界限计算器求子组均值控制图的 3σ 上下控制限，适合统计过程控制（SPC）中均值稳定性的监控与判异。

计算公式与原理

σ=2、n=5 → 界限 ±2.683。 σ/√n 为均值标准误。

子组均值控制图的 3σ 控制界限。

使用步骤

  1. 填写「总均值 x̄̄」。
  2. 填写「标准差 σ」。
  3. 填写「子组大小 n」。
  4. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 为均值控制图（X̄图）计算中心线 CL 与控制限 UCL/LCL，监控过程均值是否受控、有无特殊原因波动。
  • 过程能力研究前先确认过程稳定（受控），否则能力指数无意义。
  • 子组容量变化时（n 不同），按 √n 更新标准误与界限。

算例参考

  • 公式：标准误 SE = σ/√n（σ 为过程标准差，n 为子组容量）；中心线 CL = μ（过程目标/均值）；控制限 UCL = μ + 3·SE、LCL = μ − 3·SE（3σ 原则，对应约 0.27% 误发警报率）。σ 未知时多用子组极差均值 R̄/d₂ 估计。
  • 算例：过程目标 μ=50、σ=2、子组容量 n=5：SE = 2/√5 ≈ 0.8944；UCL = 50 + 3×0.8944 ≈ 52.683，LCL = 50 − 3×0.8944 ≈ 47.317，CL = 50.000。若某子组均值超出 [47.317, 52.683] 即触发判异，应查特殊原因而非立即调机。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

公式里的 σ 用哪个？
控制图限用『过程固有标准差』估计（如 R̄/d₂ 或 S̄/c₄），反映受控下的普通原因波动；不要用全样本整体标准差（含特殊原因会夸大 σ、放宽控制限、漏检异常）。
子组容量 n 越大控制限越窄吗？
是的。SE = σ/√n，n 越大 SE 越小、控制限越窄，对均值漂移越敏感；但 n 过大会增加检测滞后与成本，常规取 4~5，关键过程可取更大子组。
