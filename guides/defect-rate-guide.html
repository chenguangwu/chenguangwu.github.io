不良率与西格玛计算 使用指南

输入缺陷数与机会数，计算直通率、DPMO、PPM、CPK及对应西格玛水平，用于质量水平评估与六西格玛过程管理。

功能说明

输入缺陷数与机会数，计算直通率、DPMO、PPM、CPK及对应西格玛水平，用于质量水平评估与六西格玛过程管理。

典型使用场景

  • 质量月报统计缺陷水平时，用不良率、直通率与 DPMO/西格玛换算，横向对比不同产线或月份的过程能力。
  • 多工序产品评估整体良率，用滚动直通率 RTY 揭示各工序累积损失，定位主要失效工序。
  • 客户审核或六西格玛项目汇报时，将 PPM/DPMO 换算成西格玛水平与 CPK，直观呈现质量等级。

算例参考

  • 装配线质量分析示例：某装配线投入 50000 件、检出不良 250 件、共 2 道工序。不良率 = 250÷50000 = 0.5%；单工序直通率 = 1−0.5% = 99.5%；滚动直通率 RTY = 0.995² ≈ 99.00%；PPM = 0.5%×10⁶ = 5000；DPMO = 5000÷2 = 2500；查表得西格玛水平 3.5σ，按本工具近似换算 CPK ≈ 0.33（偏低，提示过程稳定性待提升，应优先治理变异来源）。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

直通率 RTY 和一次合格率有什么差别？
单工序直通率 FTY 只反映该工序一次通过比例；滚动直通率 RTY 是各工序 FTY 连乘，揭示多工序累积损失。RTY 往往远低于单工序合格率，是暴露隐性损耗的关键指标。
DPMO 和西格玛水平怎么理解？
DPMO 指每百万次机会中的缺陷数，西格玛水平由 DPMO 查表换算：约 66807→3σ、6210→3.5σ、233→4σ、3.4→5σ、0.002→6σ。数值越高过程越稳定，行业通常目标 ≥4σ（约 DPMO≤6210）。
