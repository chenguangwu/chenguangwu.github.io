功能说明

凝血酶生成（TG）曲线分析工具。输入凝血参数，前端生成凝血酶生成曲线并给出分析结果，用于凝血功能研究与教学演示，数据本地生成。

典型使用场景

  • 输入 TGA 参数（Lag time、Peak、ttPeak、ETP、Start Tail），评估整体止血表型
  • 高凝/血栓倾向看 Peak 与 ETP 是否升高；出血倾向看是否降低
  • 血友病可据 TGA 个体化调整因子替代，评估凝血酶生成是否达标

算例参考

  • 方法：凝血酶生成试验（TGA）关键参数：Lag time（凝血酶启动延迟，正常约 1–5 min）、Peak（凝血酶爆发峰值，正常约 100–400 nM）、ttPeak（达峰时间，约 4–10 min）、ETP（内生凝血酶潜力，正常约 800–1800 nM·min）、Start Tail（尾部起始，反映抗凝灭活）。整体以四项联合判读，单看一项易误判。
  • 算例：例（Lag=3 min、Peak=180 nM、ttPeak=6.5 min、ETP=1200 nM·min）：四项均落正常范围 → 凝血功能平衡。对照一例 Peak=450 nM、ETP=2000 nM·min → Peak 与 ETP 升高 → 高凝/血栓倾向，需结合 D-二聚体与抗凝蛋白评估。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

TGA 和常规凝血试验有何不同？
常规 PT/APTT 只看启动相，TGA 反映从启动到峰再到灭活的全程凝血酶生成量（ETP），对高凝态与因子替代后的「是否够」更敏感，但标准化与参考区间因试剂/仪器差异大。
Peak 与 ETP 哪个更关键？
Peak 反映瞬时爆发强度（与血栓更相关），ETP 反映总生成量（与止血充分性更相关）；血友病替代治疗常追求 ETP/Peak 达正常下限以上，但目标值依中心与方案而异。
