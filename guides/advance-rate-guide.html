隧道掘进速度估算 使用指南

输入孔深、利用率、工序耗时、计划循环数、有效日工时、施工天数与目标长度；同时给出整循环与跨日平均日进尺、月进尺与工期，并提示理想假设。

功能说明

输入孔深、利用率、工序耗时、计划循环数、有效日工时、施工天数与目标长度；同时给出整循环与跨日平均日进尺、月进尺与工期，并提示理想假设。

典型使用场景

  • 单循环进尺：循环进尺=炮孔深度×炮孔利用率 η（一般 0.85~0.95，由岩性与钻孔精度决定）；孔深加大能提高进尺，但 η 通常随之下降。
  • 整循环模型：时间允许的完整循环=floor(有效日工时÷单循环时间)，实际完整循环=min(计划循环数, 时间允许循环数)，日进尺=单循环进尺×完整循环数。该模型不允许循环跨日，单循环超过日工时即日进尺为 0。
  • 跨日平均模型：按连续施工折算每日循环=min(计划循环数, 有效日工时÷单循环时间)，允许单循环跨日；日进尺=单循环进尺×折算循环数，用于连续掘进与工期估算。
  • 月进尺与工期：月进尺=跨日平均日进尺×30；工期=目标掘进长度÷跨日平均日进尺。工具另按计划施工天数给出该时段进尺，便于比较不同工序组合的边际收益。

算例参考

  • 算例：孔深 3 m、利用率 0.9、循环 9.5 h：输入孔深 3 m、利用率 0.9、钻孔 3 h、爆破 1 h、通风 0.5 h、出渣 3 h、支护 2 h、计划 3 次/日、有效日工时 24 h。单循环进尺=2.70 m；单循环时间=9.50 h；整循环模型 floor(24÷9.5)=2 次/日，日进尺 5.40 m；跨日平均模型 24÷9.5=2.526 次/日，日进尺 6.82 m；月进尺约 204.6 m；1000 m 工期约 146.6 天（4.9 个月）。若有效日工时改为 8 h：整循环为 0 次/日，跨日平均为 0.842 次/日、日进尺 2.27 m、月进尺 68.2 m、1000 m 工期约 439.8 天，说明单循环跨日时必须看平均模型。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

为什么整循环日进尺和跨日平均日进尺会不同？
整循环模型要求每个循环都在当日工时内完成，余下不足一个循环的时间不计入进尺；跨日平均模型按连续施工把剩余工时折算成循环份额，因此单循环时间不能整除日工时时两者不同。前者适合按班制排程、不允许跨日的场景；后者适合连续掘进与工期估算。页面同时展示两者，避免把任意一个当作唯一真值。
单循环总耗时填 0 为什么不能估算？
单循环时间是计算每日循环数与工期的分母。总耗时为 0 不是“无限快”，而是缺少有效工序数据；页面会明确提示必须填写大于 0 的总耗时，并清除旧结果，避免用 0 分母得出无意义的天数。
