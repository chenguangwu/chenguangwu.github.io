Docker Run 转 Compose 使用指南

docker run 参数一长串难维护。本工具解析镜像、端口、挂载、环境变量等，生成结构化的 compose 文件。本地解析不上传。

核心功能

  • 解析镜像与命令
  • 提取端口/挂载/环境变量
  • 生成 compose 结构
  • 保留常用参数
  • 本地处理

适用场景

  • 把临时容器固化为配置
  • 多服务统一管理
  • 迁移单机命令到 compose

使用步骤

  1. 粘贴 docker run 命令
  2. 点击转换
  3. 复制 docker-compose.yml

实用技巧

  • 卷挂载注意宿主机路径
  • 端口格式 主机:容器
  • 环境变量用 environment 段

常见问题

compose 和 run 等价吗？
语义一致，compose 更易维护。
