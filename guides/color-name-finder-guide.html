颜色名称查询 使用指南

输入色值查询颜色名称，或输入颜色名查询对应的色值，包含中文传统颜色大全

功能说明

输入色值查询颜色名称，或输入颜色名查询对应的色值，包含中文传统颜色大全

典型使用场景

  • 由 HEX 查近似颜色名。
  • 界面选色时由 Hex 反查色名，方便与设计或开发沟通「这是什么颜色」。

算例参考

  • 查：#FF0000 → Red（红）；#00FF00 → Lime；#0000FF → Blue。

注意事项

本工具在浏览器本地运行，输入内容不会上传服务器；结果为模型估算，工程决策请结合实测数据复核。

名字唯一？
同色可有多个近似名，取最接近。
为什么同一个 Hex 有多个名字？
色名库来自不同标准（如 CSS 命名色与中文习惯色名），同一色值可能对应多个名称，页面给出最接近的一个。
