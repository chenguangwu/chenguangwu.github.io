MAP 平均动脉压 使用指南

MAP 平均动脉压计算器。输入收缩压与舒张压，按 MAP ≈ 舒张压 + (收缩压−舒张压)/3 估算平均动脉压，反映器官灌注压力，用于循环监测参考。

计算公式与原理

MAP ≈ 舒张压 + (收缩压 − 舒张压) / 3

MAP 平均动脉压计算器。输入收缩压与舒张压，按 MAP ≈ 舒张压 + (收缩压−舒张压)/3 估算平均动脉压，反映器官灌注压力，用于循环监测参考。

典型使用场景

  • 器官灌注：MAP 反映心脑肾等平均灌注压
  • 休克监测：MAP<65 常需升压维持灌注
  • 血压管理：结合收缩压/舒张压看整体

算例参考

  • 方法：算法：MAP ≈ 舒张压 + (收缩压−舒张压)/3；脉压 = 收缩压−舒张压；分级：MAP≥70 正常、65–69 临界、<65 偏低。要求血压>0。
  • 算例：例1（120/80）：MAP=80+(120−80)/3=93.3mmHg，脉压 40mmHg，正常。例2（100/60）：MAP=73.3mmHg，正常。例3（90/55）：MAP=66.7mmHg，临界。

注意事项

医疗健康类结果为按公式得到的估算值，不能替代医生诊断与处方。给药剂量、补液速度、抗凝与溶栓决策必须以药品说明书、临床指南和主治医师判断为准；出现胸痛、呼吸困难、意识改变等急症请立即就医。

MAP 比收缩压重要吗？
MAP 更代表器官平均灌注，尤其麻醉/ICU 关注 MAP 是否≥65；但收缩压过低也影响冠脉灌注，需综合判断。
为什么除以 3 不是 2？
舒张期占整个心动周期约 2/3，故权重 2/3 给舒张压、1/3 给脉压，即 DBP+PP/3，是经验近似。
