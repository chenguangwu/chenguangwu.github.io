输精管造影（通畅）评估 使用指南

输精管造影通畅度评估工具，逐段评估输精管/精囊/射精管通畅情况，辅助梗阻性无精子症诊断

功能说明

输精管造影通畅度评估工具，逐段评估输精管/精囊/射精管通畅情况，辅助梗阻性无精子症诊断

典型使用场景

  • 无精子症病因定位。
  • 梗阻性 vs 非梗阻性鉴别。
  • 显微外科重建术前评估。

算例参考

  • 双侧各段均 2 分：评分 0=梗阻、1=部分、2=通畅；双侧全部 2 → 双侧通畅，不支持梗阻性无精子症。
  • 左段一处 0 分：左某段评 0 → 左侧梗阻；若仅单侧且对侧通畅，仍有自然受孕可能，可先观察。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

评分怎么用？
逐段（腹股沟/盆段/壶腹等）评 0–2，任一段 0 即该侧梗阻，双侧 0 为梗阻性无精子症。
下一步？
双侧梗阻常选 PESA+ICSI；单侧可据精液参数决定是否手术探查。
