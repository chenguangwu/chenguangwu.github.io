预产期计算器（医疗） 使用指南

根据末次月经（LMP）、受孕日或 IVF 胚胎移植日，按 Naegele 法则计算预产期、当前孕周及关键产检里程碑。

功能说明

根据末次月经（LMP）、受孕日或 IVF 胚胎移植日，按 Naegele 法则计算预产期、当前孕周及关键产检里程碑。

典型使用场景

  • 按末次月经（LMP）用 Naegele 法则推算预产期（EDD），并按实际月经周期长度校正。
  • 推算当前孕周与所处孕期阶段，判断是否进入足月区间（37-42 周）。
  • 反推预计受孕日（排卵日），用于核对孕周与超声检查结果是否一致。

算例参考

  • 公式：EDD = LMP + 280 天（Naegele 法则，默认周期 28 天且排卵在 LMP 后 14 天）；周期校正：EDD = LMP + (280 + (实际周期 − 28)) 天；预计受孕日 = LMP + 14 天。孕期阶段：<14 周孕早期、<28 周孕中期、≤42 周孕晚期、>42 周过期妊娠；37-42 周为足月。
  • 算例：LMP 2026-01-01、周期 28 天：EDD = 2026-01-01 + 280 天 = 2026-10-08，预计受孕日 = 2026-01-15。若周期 35 天（排卵偏晚），EDD = 2026-01-01 + 287 天 = 2026-10-15，比标准算法晚 7 天。再如 LMP 2026-03-01、周期 28 天：EDD = 2026-12-06。孕期进度按「距 LMP 天数 ÷ 280」计算，超过 280 天后进度条封顶 100%。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

预产期与实际分娩日为什么经常不一致？
Naegele 法则假设周期 28 天、第 14 天排卵，且孕期恰好 280 天。真实人群中只有约 5% 的胎儿在预产期当天出生，约 80% 落在预产期前后两周内。周期不规律、排卵推迟、哺乳期月经未恢复者误差更大，此时应以早孕期超声（CRL）核对孕周为准。
周期不是 28 天时怎么校正？
按「EDD = LMP + 280 + (实际周期 − 28)」校正：周期短于 28 天则提前、长于 28 天则推后，差值等于排卵日相对第 14 天的偏移。注意这只校正排卵时间，不校正黄体期异常或记错 LMP 的情况；若超声孕周与校正后孕周相差 ≥7 天（早孕期 ≥5 天），通常以超声为准。
