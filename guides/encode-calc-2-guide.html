URL 编码 / 解码 使用指南

支持 URL 组件编码（encodeURIComponent）与完整 URL 解析。

功能说明

支持 URL 组件编码（encodeURIComponent）与完整 URL 解析。

使用步骤

  1. 填写「输入」。
  2. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 参数构造：把用户输入拼进查询参数前转义，避免 &/= 截断。
  • 日志还原：把服务端记录的编码 URL 解码回可读地址便于排查。
  • 接口联调：核对前端实际发送的请求行是否符合预期。

算例参考

  • 示例：编码 "a b&c=1"：encodeURIComponent → "a%20b%26c%3D1"，解码还原为原串，空格变 %20、& = 变 %26 %3D。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

encodeURI 与 encodeURIComponent 区别？
后者转义更彻底（含 ?#/等），适合编码单个参数值；前者保留 URL 结构字符。
哪些字符不用编码？
RFC 3986 中 A-Za-z0-9 及 -_.~ 为安全字符，可原样保留。
解码后还是乱码？
多为服务端未按 UTF-8 解码，属服务端问题，本工具解码本身正确。
