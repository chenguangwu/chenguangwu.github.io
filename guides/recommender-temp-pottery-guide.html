陶艺烧制温度曲线推荐 使用指南

陶艺烧制温度曲线推荐工具依据泥料与器型推荐升温、保温与冷却曲线，辅助电窑或气窑的烧成方案制定，适合陶艺创作。

功能说明

陶艺烧制温度曲线推荐工具依据泥料与器型推荐升温、保温与冷却曲线，辅助电窑或气窑的烧成方案制定，适合陶艺创作。

典型使用场景

  • 按泥料查询素烧与釉烧的推荐温度区间及保温时长，作为装窑烧制的参数依据。
  • 对比不同泥料的烧成窗口，判断某釉料是否与坯体烧成温度匹配。
  • 按保温时长安排高温段的恒温控制，确保坯体或釉面充分反应。

算例参考

  • 推荐参数表：素烧/釉烧温度与保温：陶土（低温陶）800–950℃ / 980–1050℃ / 20–30 min；炻器泥（中温）900–1000℃ / 1180–1240℃ / 30–45 min；高岭土（高温瓷）900–980℃ / 1260–1320℃ / 40–60 min；紫砂泥 1000–1100℃ / 1120–1180℃ / 20–30 min；骨质瓷 900–1000℃ / 1220–1280℃ / 30–40 min。釉烧温度应略低于坯体极限，保温使釉料充分熔融。
  • 算例：烧制高岭土瓷器：素烧取 950℃（区间 900–980 中值）保温 20–30 min，使坯体定型并具备一定强度便于施釉；釉烧升至 1300℃（区间 1260–1320）保温 50 min，使釉面完全玻化。若釉料成熟温度为 1200℃，则不适用于该坯体，应改选炻器泥。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

素烧温度为什么要低于釉烧？
素烧目的是定型、脱水并产生一定孔隙以便吸釉，温度过高坯体过于致密反而不易挂釉；釉烧则需高温使釉料熔融玻化。
保温时间怎么影响成品？
保温不足釉面未完全流平会有针孔、橘釉；过长则可能流釉粘底或坯体过烧变形，一般高温瓷需 40–60 min，低温陶 20–30 min 即可。
