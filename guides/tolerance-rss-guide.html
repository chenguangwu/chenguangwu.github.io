公差叠加计算器（RSS） 使用指南

输入线性尺寸链中各环节的公差，工具用均方根（RSS）法估计装配后的统计总公差，相比极值法更贴近大批量生产的实际波动，辅助公差分配与可装配性评估。

计算公式与原理

√0.0725≈0.269。 RSS 比最差情况宽松。

用均方根法估计线性尺寸链的统计总公差。

使用步骤

  1. 填写「公差1 t₁」。
  2. 填写「公差2 t₂」。
  3. 填写「公差3 t₃」。
  4. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 尺寸链/装配间隙分析中，用方和根（Root Sum Square）估算多个零件公差叠加后的总变异，比最坏情况更贴近统计实际。
  • 大批量生产下各零件误差近似独立随机分布，RSS 给出『典型』总公差而非极端值。
  • 在保证装配功能前提下，用 RSS 放宽容差以降本，而非一味按最坏情况加严。

算例参考

  • 公式：总公差 T = √(t₁² + t₂² + … + tₙ²)，各 tᵢ 为各组成环公差（同向叠加时取绝对值）。RSS 假设各误差相互独立且近似正态，给出约 99.73%（±3σ）置信下的典型总变异。
  • 算例：某装配尺寸链由三段组成，各段公差分别为 0.1、0.15、0.2 mm：T = √(0.1² + 0.15² + 0.2²) = √(0.01 + 0.0225 + 0.04) = √0.0725 ≈ 0.269 mm（RSS）。相比最坏情况叠加的 0.45 mm，RSS 显著更小，说明大批量下可适度放宽单件公差而不超差。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

RSS 和最坏情况（WC）怎么选？
WC 假设所有误差同时取极值同向叠加，给出绝对安全但过严的总公差；RSS 假设独立随机、给出典型值。单件/小批/安全关键件用 WC，大批量统计过程控制下用 RSS 更经济。
RSS 的前提是什么？
要求各组成误差相互独立、且分布近似正态（或至少对称）；若存在系统性偏差（如刀具统一偏大），应先当作偏移而非随机公差处理，否则 RSS 会低估真实总误差。
