社保缴纳基数查询 使用指南

查询全国主要城市2024年社保缴纳基数上下限及缴费比例，输入工资计算实际缴纳金额

功能说明

查询全国主要城市2024年社保缴纳基数上下限及缴费比例，输入工资计算实际缴纳金额

使用步骤

  1. 填写「选择城市」。
  2. 填写「险种」。
  3. 填写「月工资（元）」。
  4. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 按当地上下限把工资「 clamp 」到缴费基数，估算单位与个人各险种缴费额。
  • 工资低于下限按下限、高于上限按上限缴纳。
  • 对比不同城市费率与基数，辅助参保与薪酬规划。

算例参考

  • 基数 1 万、常见费率：养老单位 16% = 1600、个人 8% = 800；医疗单位约 8% = 800、个人 2% = 200；失业单位 0.5% = 50、个人 0.5% = 50；月缴单位合计约 2470、个人约 1050 元（费率以当地为准）。
  • 工资越限处理：工资 3000 低于下限 4250 则按下限缴；工资 3 万高于上限 21258 则按上限缴，超出部分不计入基数。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值，涉及具体争议请以证据与司法机关认定为准，必要时咨询执业律师。

缴费基数怎么确定？
一般以上年度本人月平均工资为准，在当地公布的上下限之间；新参保按起薪当月工资，后续年度调整。
单位和个人比例固定吗？
全国框架统一但各省费率略有差异（如工伤按行业风险浮动、医保单位比例不同），以参保地规定为准。
