JSON 修复器 使用指南

手写或接口返回的 JSON 常因漏括号、多逗号、用了单引号而报错。本工具尝试定位并修复常见格式问题，方便复制进代码或配置。纯前端，数据不上传。

核心功能

  • 补全缺失的括号与引号
  • 去除尾随逗号
  • 单引号转双引号
  • 错误位置提示
  • 本地处理

适用场景

  • 接口返回的 JSON 被截断
  • 从网页复制的 JSON 漏了符号
  • 调试 JSON.parse 报错

使用步骤

  1. 粘贴疑似出错的 JSON
  2. 点击修复
  3. 复制修正后的结果

实用技巧

  • 修复后仍建议再校验一次
  • 嵌套深时优先检查最内层
  • 单引号是最常见的一个坑
