IPv6 Converter

The IPv6 Converter normalizes addresses to full and compressed forms and converts between IPv4-mapped and other representations.

Key Features

  • Validation
  • Local only

Use Cases

  • Normalize a config

  • Debug a binding

How to Use

  1. Enter the address
  2. Choose the form
  3. Copy the result

Practical Tips

  • Leading zeros are dropped in compression
  • :: stands for the longest zero run
  • Double-check the scope
