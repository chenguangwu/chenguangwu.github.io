Wi-Fi QR Generator

The Wi-Fi QR Generator creates a QR code that lets phones join a network by scanning, without typing the password.

Contents
  • Key Features
  • Use Cases
  • How to Use
  • Practical Tips
  • FAQ

Key Features

  • WPA, WEP, open
  • Hidden network option
  • Encodes SSID and key
  • Local only

Use Cases

  • Share a guest network
  • Set up a venue
  • Teach QR uses
  • Avoid typing a long key

How to Use

  1. Enter SSID and password
  2. Pick the auth type
  3. Generate and scan

Practical Tips

  • Use WPA2 or better
  • Keep the code private
  • Test with a real phone
