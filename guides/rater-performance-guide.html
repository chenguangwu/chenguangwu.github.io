物业绩效考核评分体系 使用指南

六大维度加权评分，可自定义权重并展示归一化权重、配置 A/B/C/D 评级阈值；权重为 0 的维度不参与得分与排序，优先改进按分差×权重列出。

计算公式与原理

综合得分 = Σ(维度得分 × 归一化权重)；归一化权重 = 该维权重 ÷ 非零权重合计

得分必须在 0–100、权重必须在 0–100 且不得为负；超出范围或留空会点名报错并停止计算，不会静默截断。权重为 0 的维度不参与综合得分、等级判断和改进排序。改进优先级按「(100−得分)×归一化权重」排序，同时体现分差与权重，取前 3 项。

使用步骤

  1. 逐维填写得分（0–100）与权重（0–100）；保留观察项可将权重设为 0，但至少一个维度权重大于 0。
  2. 按公司制度配置 A/B/C/D 四个等级下限，默认 90/80/70/60，要求严格递减；低于 D 下限为 E 级。
  3. 生成后核对归一化权重表：每个维度的原始权重、归一化百分比和对综合分的贡献应能对上。
  4. 查看「优先改进」的加权提升空间，并结合合同条款与公司考核制度决定整改或复核；工具建议仅供参考。

典型使用场景

  • 物业项目经理按月对各岗位评分，各维度权重按岗位职责差异化配置
  • 公司自定义 A/B/C/D 等级阈值，按合同或制度复核绩效等级
  • 设置零权重维度以保留观察数据，但不让其影响综合得分与优先改进排序

算例参考

  • 加权评分与归一化：客户满意度 90（权重20）、设施维护 85（20）、响应时效 90（15）、收费率 88（15）、安全合规 92（15）、环境品质 85（15）→ 权重合计 100，归一化后分别为 20%/20%/15%/15%/15%/15%；综合 = 0.20×90 + 0.20×85 + 0.15×90 + 0.15×88 + 0.15×92 + 0.15×85 = 88.25 分。
  • 零权重维度：环境品质得分 10、权重改为 0，其余权重合计 85；该维度不参与得分与排序，归一化权重变为 23.5%/23.5%/17.6%/17.6%/17.6%，综合 = (85×20 + 80×20 + 90×15 + 88×15 + 92×15) ÷ 85 = 86.5 分。
  • 可配置评级阈值：默认 A≥90、B≥80、C≥70、D≥60、E<60；若改为 A≥85、B≥75、C≥65、D≥55，则 86.3 分由 B 级变为 A 级。

注意事项

得分超 100、低于 0、为空或非数字，以及权重为负或超过 100，都会点名报错并保留输入框原值。评级阈值须严格递减；合同复核提示随当前等级给出，但是否复核仍以合同条款和公司制度为准。本工具纯前端运行，输入不上传服务器；结果为管理参考，不替代正式考核文件。

超出 0–100 的分数会被截断吗？
不会。超范围、为空或非数字都会点名报错并停止计算，输入框保留原值，便于核对后改正。
权重为 0 的维度参与考核吗？
不参与。权重为 0 的维度不进入综合得分、等级判断和优先改进排序，页面会单独标注「不计入」，并展示其余维度的实际归一化权重。
改进优先级为什么不是直接看最低分？
低分但权重很小的维度，即使拉满对总分影响也有限。工具按「(100−得分)×归一化权重」计算加权提升空间，同时体现分差和权重。
评级阈值可以按公司制度调整吗？
可以。A/B/C/D 四个下限均可配置，要求严格递减；低于 D 下限为 E 级。评级和合同复核提示仅供参考。
