磁罗经校正 使用指南

基于五系数自差模型，在真航向、磁航向、罗航向间相互换算，并生成各罗经航向的自差值表，用于船舶磁罗经校正与航行误差修正。

功能说明

基于五系数自差模型，在真航向、磁航向、罗航向间相互换算，并生成各罗经航向的自差值表，用于船舶磁罗经校正与航行误差修正。

典型使用场景

  • 航行推算时，在罗航向(CH)、磁航向(MH)、真航向(TH)之间按磁差(Var)与自差(Dev)互转，满足航行计划与避碰需求。
  • 罗经自检或新装罗经后，用五系数法（A/B/C/D/E）绘制自差表，量化各罗经向位的自差修正量。
  • 海图作业或 GPS 偏置比对时，将罗经读数修正为真北基准，消除罗经差（Dev+Var）带来的航向偏差。

算例参考

  • 罗航向求真航向示例：某海区磁差 Var = 5°E、自差 Dev = 3°E，罗航向 CH = 090° 求真航向。罗经差 = Dev + Var = 3 + 5 = 8°E；磁航向 MH = 090 + 3 = 093°；真航向 TH = 093 + 5 = 098°。反向（真→罗）则逐次减去修正量：CH = TH − Var − Dev。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

磁差和自差有什么区别？
磁差 Var 是地磁北与真北的夹角（随海区与年变），自差 Dev 是船体磁材对罗经的干扰（随船首向变化）；罗经差 = Dev + Var，是罗经读数与真北的总偏差。航行中按船首向查自差表修正即可抵消。
自差表（五系数）怎么用？
自差 Dev = A + B·sin(CH) + C·cos(CH) + D·sin(2CH) + E·cos(2CH)，系数由实测罗经向位拟合。表中每个罗航向 CH 对应一个修正量，航行时按当前船首向查表加减即可得磁航向，再加磁差得真航向。
