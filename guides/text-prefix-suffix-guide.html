批量添加前缀后缀 使用指南

为每行文本批量添加固定的前缀或后缀（如编号、符号），支持正则与分隔符，适合清单批量处理与格式整理。

功能说明

为每行文本批量添加固定的前缀或后缀（如编号、符号），支持正则与分隔符，适合清单批量处理与格式整理。

使用步骤

  1. 填写「前缀（可留空）」。
  2. 填写「后缀（可留空）」。
  3. 填写「序号起始值」。
  4. 填写「序号格式」。
  5. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 批量加引号/括号：给每行内容包上单引号或圆括号，快速拼 SQL IN 列表或数组。
  • 生成 SQL/代码列表：把名字列表加『'』与逗号，直接贴进查询。
  • 标注与包装：给每项加统一前缀（如「TODO:」）或后缀（如「.com」）。

算例参考

  • 拼 SQL IN 列表：粘贴「a/b/c」每行一个，加前缀「'」后缀「',」得「'a',『b',『c',」，最后一项去掉尾逗号即得 ('a','b','c')，省去手敲。

注意事项

本工具在浏览器本地运行，输入内容不会上传服务器；结果为模型估算，工程决策请结合实测数据复核。

尾逗号怎么处理？
可在选项去掉末行后缀，或用「末行不加」模式，避免 SQL 语法错误；也可生成后手动删最后一个逗号。
内容含引号会冲突吗？
会。若原文本已有单引号，再包单引号会破坏字符串；此时改用双引号或转义，或选无冲突的分隔。
