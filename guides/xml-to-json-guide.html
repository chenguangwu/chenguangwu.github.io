XML 转 JSON 使用指南

将 XML 映射为 JSON：标签为键、属性前缀化、重复标签转数组。便于前端用 JS 直接消费。本地转换不上传。

核心功能

  • XML→JSON 映射
  • 属性转 @ 前缀键
  • 重复兄弟标签转数组
  • 文本节点抽取
  • 本地处理

适用场景

  • 旧接口 XML 接入前端
  • 配置 XML 转可读对象
  • 数据格式迁移

使用步骤

  1. 粘贴 XML
  2. 点击转换
  3. 查看 JSON 并复制

实用技巧

  • 属性默认加 @ 前缀避免与子节点冲突
  • 无子节点无属性的标签直接变字符串
  • 同名多子节点自动成数组

常见问题

属性怎么表示？
通常加 "@" 前缀，如 <a id="1"> → {"a":{"@id":"1"}}。
能给个例子吗？
"<a><b>1</b><b>2</b></a>" → {"a":{"b":["1","2"]}}。
