refractive-index-speed 使用指南

refractive-index-speed：在线输入参数即可即时得到结果，无需安装与注册。

计算公式与原理

n = c / v

由光在介质中的速度求折射率。

使用步骤

  1. 填写「介质光速 v (m/s)」。
  2. 填写「真空中光速 c (m/s)」。
  3. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 已知光在介质中的传播速度，反推该介质的折射率。
  • 比较不同光学材料对光的减速能力，用于材料选型。
  • 校核实验测得的光速数据是否落在合理折射率区间。

算例参考

  • 水中光速 v=2.25e8 m/s：n=c/v=3e8/2.25e8=1.3333，与水在可见光波段的折射率约 1.33 一致。
  • 玻璃中光速 v=1.5e8 m/s：n=c/v=3e8/1.5e8=2.0000。该值对应高折射率光学玻璃（普通冕牌玻璃约 1.5，对应 v≈2.0e8 m/s）。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

折射率可以小于 1 吗？
按 n=c/v，若算得 n<1 说明介质中光速大于真空光速，这违背狭义相对论，通常意味着输入有误（如单位写错或把群速度/相速度混用）。常规透明介质 n≥1。
折射率与波长有关吗？
有关，这就是色散。同一材料对短波（蓝紫光）的折射率通常更大，因此棱镜能把白光分解成光谱。计算时应注明所用波长，常见参考值是钠黄光 589 nm 下的 n_D。
