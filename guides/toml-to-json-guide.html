TOML 转 JSON 使用指南

将 TOML 片段解析为 JSON 对象，支持嵌套表、数组与标准类型。适合把配置文件喂给 JS/接口。本地解析。

核心功能

  • TOML→JSON 解析
  • 嵌套表展开
  • 数组与类型还原
  • 错误定位
  • 本地处理

适用场景

  • 读 Cargo.toml 配置
  • 配置文件校验
  • TOML→接口数据

使用步骤

  1. 粘贴 TOML
  2. 点击解析
  3. 查看 JSON

实用技巧

  • 表顺序在 JSON 中会被打乱(对象无序)
  • 点号键如 a.b 会成嵌套
  • 日期时间转字符串
