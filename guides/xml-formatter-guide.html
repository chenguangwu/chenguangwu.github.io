XML 格式化 使用指南

XML 常用于配置与数据交换。本工具对缩进混乱的 XML 重新排版、高亮层级，并可检测标签是否闭合。纯前端，数据不上传。

核心功能

  • 缩进美化 XML
  • 标签闭合校验
  • 折叠展开节点
  • 支持大文件分段
  • 本地处理

适用场景

  • 查看接口返回的 XML
  • 整理配置文件
  • 排查标签缺失

使用步骤

  1. 粘贴 XML
  2. 点击格式化
  3. 查看缩进结果或错误提示

实用技巧

  • 属性与子元素混排时注意层级
  • CDATA 内文本不被解析
  • 错误会标出大致行号
