阀门选型计算（Cv/Kv 流量系数） 使用指南

算法：相对密度 SG = 介质密度/1000；Kv = 流量×√(SG/压差)；Cv = 1.167×Kv；设计 Cv = Cv×1.3；在标准通径 Cv 系列中取首个 ≥ 设计 Cv 者作为推荐通径；估算流速 = 流量…

核心功能

  • 按流量、压差与介质密度计算 Cv/Kv
  • 按估算流速校核所选通径
  • 反算既有阀门 Cv 判断开度与调节性能
  • 输出 Cv/Kv 换算与选型建议

适用场景

  • 调节阀选型：由流量、压差与介质密度算 Cv/Kv 并选通径
  • 口径校核：用估算流速判断所选通径是否合适
  • 既有阀门评估：反算 Cv 判断开度与调节性能

使用步骤

  1. 输入流量与阀前后压差
  2. 输入介质密度（或相对密度）
  3. 点击计算，读取所需 Cv/Kv
  4. 按 1.3 倍余量选择阀门通径
  5. 用流速校核所选通径是否合适

实用技巧

  • Kv 为公制（m³/h、1bar 水）、Cv 为英制（US gal/min、1psi），Cv = 1.167×Kv，须确认厂家口径
  • 设计 Cv 常乘 1.3~2.0 留开度余量，避免长期大开度导致调节性能变差
  • 选型须结合阀权度与可调比校核
  • 高黏度、闪蒸/汽蚀工况须特殊修正，必要时选防汽蚀阀内件

常见问题

Kv 和 Cv 有什么区别？
Kv 是国际单位制流量系数（m³/h，压差 1bar、介质为水）；Cv 是英制（US gal/min，压差 1psi）。换算关系为 Cv = 1.167×Kv，选型时务必确认厂家样本使用的是哪一种。
为什么设计 Cv 要乘 1.3？
为阀门开度与工况波动留余量，避免阀门长期在过大开度工作导致调节性能变差。调节型阀门通常按计算 Cv 的 1.3~2.0 倍选取，并结合阀权度与可调比校核。
