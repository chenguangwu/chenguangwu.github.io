和弦音符转换器 使用指南

输入和弦名称（如 Cmaj7、Am），解析其组成音、各音频率并在钢琴键盘上高亮显示。用于学习和弦构成、伴奏编配与视唱练耳。

功能说明

输入和弦名称（如 Cmaj7、Am），解析其组成音、各音频率并在钢琴键盘上高亮显示。用于学习和弦构成、伴奏编配与视唱练耳。

典型使用场景

  • 输入 C、Am、G7、F#m7 等和弦名，查实际组成音与频率
  • 编配时确认和弦拼写，避免漏/多加音
  • 配合钢琴/吉他指法，看各音在键盘/指板的位置

算例参考

  • 三和弦构成：从根音起三度叠置：大三和弦间隔 [0,4,7]→C = C E G；小三和弦 [0,3,7]→Am = A C E；减三 [0,3,6]、增三 [0,4,8]。
  • 七和弦：属七 dom7 [0,4,7,10]→G7 = G B D F；小七 m7 [0,3,7,10]→Am7 = A C E G；大七 maj7 [0,4,7,11]→Cmaj7 = C E G B。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

和弦名里的数字什么意思？
数字指叠加的音程（以根音为 1）：7=属七（小七度）、maj7=大七度、9/11/13 为延伸音；m 为小三和弦、dim 减、aug 增。
怎么快速写任意根音和弦？
记住间隔模板，把根音音名按半音数往后数：如根=A，大三 [0,4,7] → A、A+4(半音)=C、A+7=E → A C E。
