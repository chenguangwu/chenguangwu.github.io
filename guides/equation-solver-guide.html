方程求解器 使用指南

方程求解器支持一元一次/二次、二元及三元线性方程组求解，输入系数实时输出根或解，适合数学作业、工程计算与方程组验证。

计算公式与原理

一次方程：x = −b / a；二次方程：x = (−b ± √Δ) / 2a，Δ = b² − 4ac；三次方程：牛顿迭代 + 二分法求全部实根

一次方程直接求解；二次方程先算判别式 Δ = b² − 4ac，Δ > 0 得两个实根、Δ = 0 得重根、Δ < 0 输出一对共轭复根；三次方程以牛顿法配合区间扫描求全部实根。

典型使用场景

  • 一元一次/二次方程求解用于物理公式变形、盈亏平衡点与运动学求时间。
  • 判别式 Δ 决定二次方程实根个数，是解题第一判据。
  • 验证根时把解代回原方程，看是否约等于 0，可快速发现输入错误。

算例参考

  • 算例：一次方程 2x − 6 = 0：x = −b/a = −(−6)/2 = 3.000000；验证 2×3 − 6 = 0.000000。
  • 算例：二次方程 x² − 5x + 6 = 0：Δ = b²−4ac = 25 − 24 = 1；x₁ = (−b+√Δ)/(2a) = 3.000000，x₂ = (−b−√Δ)/(2a) = 2.000000。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

判别式 Δ 代表什么？
Δ = b²−4ac：Δ>0 两不等实根，Δ=0 两相等实根（重根），Δ<0 无实根但有一对共轭复根。它是判断根的性质的第一道关口。
二次方程无实根怎么办？
实数范围内无解，但复根 x = (−b ± i√|Δ|)/(2a) 仍有意义（如电路、振动分析）。若业务只认实数，应提示『无实数解』而非报错中断。
