思维导图编辑器 使用指南

在左侧用 Markdown 缩进书写层级，右侧实时生成思维导图，支持缩放、拖拽与导出。

功能说明

在左侧用 Markdown 缩进书写层级，右侧实时生成思维导图，支持缩放、拖拽与导出。

使用步骤

  1. 填写「Markdown 编辑区Tab 增加层级 / Shift+Tab 减少」。
  2. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 做读书笔记或头脑风暴时，用 # 标题与 - 列表的缩进直接表达层级，右侧自动生成思维导图，比手动画节点更快。
  • 整理会议议题时，把中心主题放在一级、讨论点放在子级，缩进越深层级越深，结构一目了然。
  • 准备汇报大纲时，先把要点写成 Markdown 大纲再导出图片，配合缩放、拖拽、节点折叠展开做演示。

算例参考

  • 示例：用缩进语法写一张思维导图：# 产品规划 ## 用户增长 - 渠道投放 - 活动裂变 ## 体验优化 - 性能 - 交互 左侧按缩进书写，右侧实时生成导图；滚轮缩放、拖拽平移、单击圆点可折叠/展开子节点。导出 PNG 前先点「适应屏幕」让内容完整显示。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

如何调整节点层级？
用 # 表示标题层级、用 - 列表表示子节点，缩进越多层级越深；Tab 键可快速缩进调整从属关系。
怎么导出完整思维导图？
支持导出 SVG 与 PNG；导出 PNG 前建议先点「适应屏幕」，确保所有内容落在画布内不被裁切，草稿保存在 localStorage。
