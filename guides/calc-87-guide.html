化探异常衬度计算 使用指南

输入背景值、异常值（及可选标准差），计算衬度系数、富集系数、异常下限与异常强度

计算公式与原理

衬度系数 Ac = 异常值 / 背景值；异常下限 T = 背景值 + 2 × 标准差；异常强度 = 异常值 / T

Ac > 1 判为正异常、< 1 为负异常；强度 ≥ 2 为强异常，≥ 1.5 中异常，≥ 1 弱异常，否则落于背景范围。

典型使用场景

  • 异常筛选：由背景值与异常值算衬度系数，快速识别正/负异常
  • 异常分级：用异常下限与强度判定弱/中/强异常，指导验证排序
  • 剖面解释：沿测线逐点算衬度，圈定异常中心与浓集中心

算例参考

  • 方法：算法：衬度系数 Ac = 异常值 C / 背景值 B；异常下限 T = B + 2σ（σ 为标准差，未填则按 0）；异常强度 = C / T；富集系数 = C / B。判定：Ac>1 正异常、<1 负异常；强度 ≥2 强异常、≥1.5 中异常、≥1 弱异常、否则背景范围。
  • 算例：例：背景 B=40μg/g、异常 C=120μg/g、σ=10 → Ac=120/40=3.000、异常下限 T=40+2×10=60、强度=120/60=2.000，判为「强异常」（浓集中心明显）。若 B=30、C=90、σ=10 → Ac=3.000、T=30+20=50、强度=90/50=1.800，判为「中异常」。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

异常下限为什么用 B+2σ？
在背景近似正态分布时，约 95% 的背景点落在均值±2σ 内，超出即视为统计异常。若背景明显偏态，宜改用中位数+倍数或迭代剔除高值后重算，避免矿致高值被纳入背景抬高下限。
衬度和强度有什么区别？
衬度 Ac=C/B 反映相对背景的倍比；强度=C/T 以异常下限为基准，更能指示异常相对于“阈值以上”的富集程度。二者结合可区分“整体偏高但弱”与“局部极强”两类异常。
