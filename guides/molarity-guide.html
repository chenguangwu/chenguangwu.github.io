摩尔浓度（c = n / V） 使用指南

摩尔浓度计算器，由物质的量与溶液体积按 c=n/V 求物质的量浓度，用于溶液浓度配制。

计算公式与原理

c = n / V

由物质的量与溶液体积计算物质的量浓度。

使用步骤

  1. 填写「物质的量 (mol)」。
  2. 填写「溶液体积 (L)」。
  3. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 标准液配制：称固体定容到 V 得 c，作滴定基准。
  • 滴定计算：由 c 与 V 算参加反应摩尔，联算待测浓度。
  • 稀释复核：稀释后 c 按 C1V1=C2V2 变。

算例参考

  • 0.5 mol 溶质定容 250 mL 演练：输入 n=0.5 mol、V=250 mL，工具输出 c=2.0 mol/L，并提示须定容至刻度而非加溶剂到体积。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。
