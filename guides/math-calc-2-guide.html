比例计算 使用指南

依据比例式 A:B=C:D，输入任意三项求解第四项未知数，适用于配方缩放、地图比例与相似图形计算等比例换算场景。

计算公式与原理

比例 a:b = a/b

根据比例式 A : B = C : D，输入任意三项求解第四项。

使用步骤

  1. 填写「A」。
  2. 填写「B」。
  3. 填写「C」。
  4. 填写「D」。
  5. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 比例式 a:b = c:d（即 a/b = c/d）广泛用于地图缩放、配方、相似图形与单位换算。
  • 已知三项求第四项（交叉相乘 a×d = b×c）是比例计算的核心操作。
  • 校验两条比例是否相等时，比较两边交叉乘积即可，避免逐项约分出错。

算例参考

  • 算例：缺项求解（2:3 = 4:d）：由 a×d = b×c → d = b×c÷a = 3×4÷2 = 6.000000；校验：2×6 = 12.000000，3×4 = 12.000000，等式成立。
  • 算例：求首个比值（a:5 = 3:4）：a = b×c÷d = 5×3÷4 = 3.750000。通用公式：缺谁就用其余三项交叉相乘除以它的对角项。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

比例和百分比有什么联系？
百分比是『分母为 100 的比例』。比例重对应关系（a:b），百分比重相对大小（a/100）。两者可互化：3:4 等价于 75:100，即 75%。
交叉相乘为什么成立？
由 a/b = c/d 两边同乘 b×d 得 a×d = b×c。它是比例等式等价变形，用于解未知项与校验等式，是最可靠的比例运算依据。
