公式 使用指南

由流量、管长、粗糙系数 C 与管径，按 h_f = 10.67·L·Q^1.852/(C^1.852·D^4.87) 计算水头损失（SI）。

功能说明

由流量、管长、粗糙系数 C 与管径，按 h_f = 10.67·L·Q^1.852/(C^1.852·D^4.87) 计算水头损失（SI）。

使用步骤

  1. 填写「流量 Q (m³/s)」。
  2. 填写「管长 L (m)」。
  3. 填写「粗糙系数 C」。
  4. 填写「管径 D (m)」。
  5. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 给水管网按经验式估沿程损失。
  • 不同 C 值（管材）对比能耗。
  • 长距离配水校核末端压力。

算例参考

  • 标准算例：Q=0.01 m³/s、L=100 m、C=120、d=0.1 → h_f=10.67×100×0.01^1.852/(120^1.85×0.1^4.87)≈0.25 m。
  • C 值影响：C 从 120 降到 100（旧管），同条件损失增约 40%，结垢显著抬升能耗。

注意事项

本工具在浏览器本地运行，输入内容不会上传服务器；结果为模型估算，工程决策请结合实测数据复核。
