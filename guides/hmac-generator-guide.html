HMAC 生成器 使用指南

HMAC 是带密钥的哈希消息认证码，服务端用同一密钥验证请求未被篡改。本工具选算法、输入消息与密钥即得签名。本地运算不上传密钥。

核心功能

  • 支持 SHA1/256/512 等
  • 文本或十六进制输出
  • 密钥与消息分离
  • Base64/Hex 切换
  • 本地运算

适用场景

  • Webhook 签名校验
  • API 请求鉴权
  • 验证数据完整性

使用步骤

  1. 选哈希算法(常用 SHA256)
  2. 输入消息与密钥
  3. 点生成得签名
  4. 复制给对方校验

实用技巧

  • 密钥务必保密、两端一致
  • 签名用于防篡改非加密
  • 十六进制与 Base64 需约定一致

常见问题

HMAC 和哈希区别？
HMAC 多了密钥，单方无法伪造。
能给个例子吗？
消息"hello"、密钥"key"、HMAC-SHA256 得一段 64 位十六进制串。
