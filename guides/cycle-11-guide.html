水电（读数/周期）结算 使用指南

按读数结算水电燃气费用：末档不设上限，空读数和读数倒退会被拦截，换表可勾选后从 0 起算。

功能说明

记录水电燃气读数并按阶梯或单一费率结算；末档不设上限、支持换表与计费周期累计，空读数和读数倒退会阻止结算。

使用步骤

  1. 选择电费/水费/燃气费，配置单一单价或阶梯档位；阶梯上限须严格递增、单价非负。
  2. 填写每次抄表日期与读数；换表行勾选「换表」。
  3. 选择阶梯累计周期：每次区间独立套档或整个结算周期累计。
  4. 点「计算结算」，查看各段用量、费用与阶梯明细；空读数或倒退会列出具体行。

典型使用场景

  • 退租或换租时按上次/本次读数结算。
  • 阶梯电量超过原末档上限时，核对超出部分是否仍计费。
  • 电表更换后按新表从 0 起算，避免把倒退读数记成 0。

算例参考

330 kWh 与超过末档上限

12 450 → 12 780，用电 330 kWh。单一价 0.60：330×0.60 = 198.00 元。阶梯 0–200 按 0.55、200–600 按 0.63：200×0.55 + 130×0.63 = 191.90 元。若 700 kWh 且末档从 600 起不限：200×0.55 + 400×0.63 + 100×0.83 = 445.00 元，超出 100 kWh 不漏计。

注意事项

读数倒退默认阻止结算，勾选「换表」才按新表从 0 起算；空读数不再保存为 0；整个周期累计时费用按各段用量比例分摊并在报告注明。

读数倒退怎么办？
先更正读数；确为换表则勾选该行「换表」，按新表从 0 起算。
阶梯按区间还是整周期？
可在「阶梯累计周期」选择；整周期累计会先对总用量套档再按比例分摊。
空读数会记 0 吗？
不会，空读数会阻止结算并提示补填或删除该行。
