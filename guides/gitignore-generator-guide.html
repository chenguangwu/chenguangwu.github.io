.gitignore 生成器 使用指南

不同技术栈要忽略的文件不同（node_modules、__pycache__、.env 等）。本工具勾选后生成合并的 .gitignore。本地生成不上传。

核心功能

  • 按语言/框架勾选
  • 合并常用规则
  • 包含密钥文件忽略
  • 标准模板
  • 本地处理

适用场景

  • 新仓库初始化
  • 多语言项目合一
  • 防止误提交密钥

使用步骤

  1. 勾选所用技术栈
  2. 点击生成
  3. 复制 .gitignore

实用技巧

  • 务必忽略 .env
  • 已跟踪文件需 git rm --cached
  • 全局忽略用 git config

常见问题

已提交的文件还能忽略吗？
需先 git rm --cached 取消跟踪。
