年息 / 现价 使用指南

输入债券年利息与当前市价，按当前收益率 = 年利息 / 债券现价 计算，用于比较不同债券的固定收益水平与到期前票息回报。

计算公式与原理

CY = 年息/现价

当前收益率 = 年利息 / 债券现价。

使用步骤

  1. 填写「年利息 (元)」。
  2. 填写「债券现价 (元)」。
  3. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 债券年息除以当前市价，快速看票息回报率。
  • 与 YTM 区分：当期收益率忽略资本利得/折价。
  • 货基/债基票息率的横向比较。

算例参考

  • 年息 50、市价 1000：当期收益率 = 年息/市价 = 50/1000 = 5%。若市价跌到 950：50/950 ≈ 5.26%。
  • 折价债：面值 1000、票息 4%（年息 40）、市价 960：当期收益率=40/960≈4.17%，低于面值交易的 YTM（还含折价摊销）。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。
