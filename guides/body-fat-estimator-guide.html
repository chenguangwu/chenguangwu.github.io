体脂率估算 使用指南

输入身高、体重、年龄与性别，使用 Deurenberg 公式估算体脂率，提供身体成分的大致参考，用于健身减脂过程中的体脂变化追踪（仅供粗略估算）。

计算公式与原理

BF% = 1.2·BMI + 0.23·年龄 − 10.8·性别(男1) − 5.4

输入身高、体重、年龄与性别，使用 Deurenberg 公式估算体脂率，提供身体成分的大致参考，用于健身减脂过程中的体脂变化追踪（仅供粗略估算）。

典型使用场景

  • 体成分跟踪：由 BMI、年龄、性别估体脂率，辅助减脂
  • 健身参考：看脂肪而非仅体重，避免"轻但胖"
  • 科普：理解年龄性别对体脂的影响

算例参考

  • 方法：算法（Deurenberg）：体脂% = 1.2×BMI + 0.23×年龄 − 10.8×(男 1 / 女 0) − 5.4；BMI = 体重 ÷ 身高²。要求各值>0。属粗略估算，误差约 ±3.5%。
  • 算例：例1（65kg / 170cm / 30 岁 / 男）：BMI = 22.5，体脂 = 1.2×22.5 + 0.23×30 − 10.8 − 5.4 = 17.7%。例2（55kg / 160cm / 40 岁 / 女）：BMI = 21.5，体脂 = 1.2×21.5 + 0.23×40 − 0 − 5.4 = 29.6%。

注意事项

医疗健康类结果为按公式得到的估算值，不能替代医生诊断与处方。给药剂量、补液速度、抗凝与溶栓决策必须以药品说明书、临床指南和主治医师判断为准；出现胸痛、呼吸困难、意识改变等急症请立即就医。

估算准吗？
公式法误差较大，仅作趋势参考；较准方法为皮褶厚度、生物电阻抗(BIA)、DXA（双能 X 线）。健身者肌肉多会被高估体脂。
男女公式为何不同？
同 BMI 下男性基础脂肪低于女性，公式用 −10.8（男）/0（女）修正性别差异；女性健康体脂通常高于男性。
