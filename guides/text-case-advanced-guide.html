高级大小写转换 使用指南

在基础大小写转换之上支持按句、按标题规则智能转换英文大小写，并保留专有名词，适用于长文档英文排版规范化，本地处理不联网。

功能说明

在基础大小写转换之上支持按句、按标题规则智能转换英文大小写，并保留专有名词，适用于长文档英文排版规范化，本地处理不联网。

典型使用场景

  • 编程命名互转：在 camelCase、PascalCase、snake_case、kebab-case 之间转换，统一多语言代码风格。
  • 数据库字段与 API 字段映射：把下划线字段转前端驼峰，或反向。
  • 配置文件键规范化：批量把 YAML/JSON 键统一为某风格。

算例参考

  • my_var_name 转 camelCase：输入「my_var_name」，camelCase 输出「myVarName」，PascalCase 输出「MyVarName」，kebab-case 输出「my-var-name」；用于把 Python 变量名改成 JS 属性名。

注意事项

本工具在浏览器本地运行，输入内容不会上传服务器；结果为模型估算，工程决策请结合实测数据复核。

数字边界怎么处理？
如「user2name」转 camel 通常得「user2Name」，下划线分隔更明确；含数字的命名建议显式加分隔符，避免歧义。
中文变量名能转吗？
中文非字母命名不在大小写体系内，工具会原样保留；本功能面向拉丁字母标识符。
