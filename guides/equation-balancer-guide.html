化学方程式配平器 使用指南

根据质量守恒，调整反应物与生成物系数使两边每种原子数相等。输入如 "H2 + O2 = H2O"，工具给出配平后的 "2H2 + O2 = 2H2O"。

核心功能

  • 支持多物种反应式输入
  • 矩阵法/代数法配平
  • 校验左右原子数守恒
  • 输出最简整数系数

适用场景

  • 中学化学作业
  • 实验投料比估算
  • 理解质量守恒

使用步骤

  1. 输入未配平方程式(用 + 连反应物，= 分隔生成物)
  2. 点击配平
  3. 查看配平系数与原子守恒表

实用技巧

  • 用 + 分隔物质、= 或 → 分隔两边
  • 系数默认最简整数
  • 无法配平(如信息不足)会提示

常见问题

配平失败常见原因？
物质写错、电荷未平衡或反应本身不成立。
能给个例子吗？
