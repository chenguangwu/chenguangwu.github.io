Hash Identifier

The Hash Identifier inspects a hash's length and character set to suggest which algorithm produced it, speeding up forensic and debugging work.

Contents
  • Key Features
  • Use Cases
  • How to Use
  • Practical Tips
  • FAQ

Key Features

  • Detects MD5, SHA families, bcrypt, etc.
  • Length and charset analysis
  • Confidence hints
  • Local only

Use Cases

  • Identify a stored password hash
  • Classify unknown data
  • Teach hash formats
  • Triage a breach dump

How to Use

  1. Paste the hash
  2. Read the candidates
  3. Confirm by context

Practical Tips

  • Length is a strong clue but not proof
  • bcrypt starts with $2
  • Never trust identification alone
