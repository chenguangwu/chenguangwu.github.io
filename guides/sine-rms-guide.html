有效值（V_rms = V_pk / √2） 使用指南

输入正弦波峰值电压，按 V_rms = V_pk / √2 计算有效值，用于交流测量、电源设计与功率计算的 RMS 换算。

计算公式与原理

V_rms = V_pk / √2

正弦波的 RMS（有效值）为峰值的 1/√2。

使用步骤

  1. 填写「峰值电压 (V)」。
  2. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 正弦峰值 Vpk 转有效值 Vrms = Vpk/√2。
  • 交流电压/电流测量换算。
  • 功率计算须用有效值。

算例参考

  • Vpk=10V：有效值 Vrms = 10 / √2 ≈ 7.071 V；施加 50Ω 负载功率 = 7.071²/50 ≈ 1.0 W。
  • 市电峰值：若有效值 220V，则峰值 ≈ 220×√2 ≈ 311V。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

为什么用有效值算功率？
有效值使交流与直流在电阻上产生同功率，是功率等效的直流当量。

不，√2 仅对正弦成立；其他波形有各自波形因数。
