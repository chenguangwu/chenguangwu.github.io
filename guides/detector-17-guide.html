纸病（孔洞/刮痕）检测 使用指南

按纸种与缺陷类型对照内置参考阈值做筛查；先区分未检出、尺寸未知与已测缺陷，信息不全时不生成等级。

功能说明

记录状态分三种：未检出（尺寸与密度均为 0）、尺寸未知（尺寸 0、估计密度大于 0）、已测缺陷（尺寸大于 0 且密度大于 0）。尺寸大于 0 而密度为 0、密度大于 0 而尺寸为 0 等矛盾组合会被拒绝，并清空旧结果。总缺陷数按“估计密度×检测面积”外推。

典型使用场景

  • 印刷纸孔洞/斑点初筛：记录最大尺寸与每 m² 估计密度，对照参考阈值。
  • 包装纸刮痕/气泡检查：按纸种选择对应参考阈值。
  • 批次记录：未检出时明确记 0/0；只统计了密度但没量尺寸时选“尺寸未知”，不硬凑一个 0 尺寸。

算例参考

  • 印刷纸孔洞，尺寸 2.5mm、密度 8 个/m²、面积 10m²：两项均超参考阈值，10m² 估计约 80 个缺陷；仅提示筛查风险，不是标准不合格判定。
  • 尺寸 0、密度 12、面积 10m² 且选“尺寸未知”：只输出估计 120 个缺陷，不生成等级；须补测最大尺寸后再判定。

注意事项

内置阈值未逐项标注标准编号、版本与试验方法，只用于初步筛查。密度是面积外推估计，不是逐张计数；尺寸与密度应来自同一检测样本。放行、索赔或判定不合格须按合同、产品标准与第三方检测报告。

不同纸种的缺陷限值一样吗？
不一样。本工具内置印刷/包装/生活/工业四类参考阈值：如孔洞，印刷纸尺寸≤2mm、密度≤5；工业纸放宽到尺寸≤10mm、密度≤10。选错纸种会得到偏移的参考结论；这些阈值不是国家标准限值。
尺寸和密度哪个更关键？
都关键，但大尺寸缺陷（孔洞、气泡）对印刷断纸/外观影响更致命，通常优先卡尺寸；密度反映整体洁净度。两项同时超出时提示“两项均超出参考阈值”，是否不合格仍须按合同或产品标准判定。
