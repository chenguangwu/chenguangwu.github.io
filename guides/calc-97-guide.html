样本量/配额/误差计算 使用指南

计算所需样本量与实际抽样误差，并用最大余数法分配分层配额；负数 N、非整数 n 与非法分层行都会按字段或原行号拦截。

功能说明

按置信水平、预期比例 p、允许误差 e 与总体规模 N 计算所需样本量和实际误差；勾选无限总体时忽略 N。分层抽样按各层规模比例分配 n，先取整数下限，剩余名额按余数从大到小分配，余数相同按层规模大→小、输入顺序前→后，保证每层非负且合计严格等于 n。

输入与校验

  • N 为有限总体时必须大于 0 的整数；未勾选无限总体时负数、0 或小数不能当作无限总体。
  • 实际样本量 n 必须是 ≥1 的整数；有限总体下 n 不能超过 N。
  • p 与 e 必须在 0–100% 之间且不含端点；分层每行「层名,规模」必须完整，规模为正整数。
  • 分层合计不等于 N 时提示未覆盖部分；大于 N 时按口径矛盾阻止计算。

使用步骤

  1. 先确定置信水平、p 与允许误差，计算无限总体 n₀ 与有限总体校正后的 n。
  2. 有实际样本量时反算误差，检查是否达到目标；n>N 会直接拦截。
  3. 需要分层时录入各层规模，核对分配表合计是否严格等于 n。

算例

N=10000、p=50%、e=3%、95% 置信水平：所需样本量 965；若实际 n=400，误差约 4.8%，超过目标。四层各 100、N=400、n=2 时，四层下限均为 0，剩余 2 个名额按输入顺序分配为 1、1、0、0。

注意事项

  • p=50% 时 p(1−p) 最大，样本量最保守；确信比例接近 0 或 1 时可按实际比例估算。
  • 抽样比 n/N 超过约 5% 时有限总体校正影响明显；n=N 是普查，抽样误差为零但不代表没有非抽样误差。
  • 分层配额按分层合计计算，不强制等于 N；合计小于 N 时请确认分层是否覆盖全部总体。
N 填负数会怎样？
未勾选无限总体时直接报「有限总体规模 N 必须是 >0 的整数」，不会把负数当无限总体。
n 可以填小数吗？
不可以。实际样本量必须是 ≥1 的整数，小数会被拦截。
分层配额合计会不等于 n 吗？
不会。最大余数法保证每层为非负整数且合计严格等于 n。
