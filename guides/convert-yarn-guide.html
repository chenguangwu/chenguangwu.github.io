纱线英支/公支/旦尼尔换算 使用指南

纱线细度换算器：在英支、公支与旦尼尔之间换算纱线细度，用于纺纱与面料工艺参数转换。

功能说明

纱线细度换算器：在英支、公支与旦尼尔之间换算纱线细度，用于纺纱与面料工艺参数转换。

典型使用场景

  • 按 tex 与长度互算纱线重量，核算单件用纱量
  • 不同回潮率下把净重折算为公定重量，公平结算
  • tex 与旦尼尔互转（denier = tex × 9）

算例参考

  • tex 转旦尼尔：20 tex → denier = 20 × 9 = 180 D；即 20tex 合 180 旦，常用于长丝标注。
  • 公定重量折算：净重 1000 g、实际回潮率 6%、棉公定回潮率 8.5% → 公定重量 = 1000 × (1 + 8.5%) / (1 + 6%) ≈ 1023.6 g。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

为什么要用公定重量？
纱线含水率随环境变化，公定重量按标准回潮率折算，买卖计量才公平可比。
tex 和旦尼尔差在哪？
tex = g/km，denier = g/9km，旦尼尔多用于长丝、tex 多用于短纤与通用。
