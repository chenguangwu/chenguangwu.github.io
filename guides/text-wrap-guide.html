文本换行与填充 使用指南

在线文本换行与填充工具，按指定宽度对段落自动折行，或向每行填充前缀/后缀至固定长度，适合代码注释与排版对齐，纯前端处理。

计算公式与原理

字符模式：行数 = ⌈文本长度 / 宽度⌉，第 i 行 = 文本[i×宽度 : (i+1)×宽度]；词模式：按空白切词，累计长度超过宽度即换行；超长词（单词长度 > 宽度）按宽度强制切分

字符模式严格按定长切分，会切断英文单词与中文词语，适合固定宽度设备（如小票、终端）。词模式保持单词完整，行数略多但可读性好，是正文排版的默认选择。两种模式都按 UTF-16 code unit 计数，含 emoji 或代理对字符（如 𝕏、部分表情）时计数会偏大，视觉宽度以实际渲染为准。换行符可选 \n、\r\n 或 <br>，写 HTML 片段用 <br>，生成 Windows 文本用 \r\n。

使用步骤

  1. 填写「每行字符数」。
  2. 填写「换行符」。
  3. 填写「每行填充到长度」。
  4. 填写「填充字符」。
  5. 填写「起始数字」。
  6. 填写「步长」。
  7. 填写「分隔符」。
  8. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 固定宽度排版：把长段落按每行 N 字符断行，适合终端/邮件正文。
  • 代码注释换行：长说明按 80 列折行，符合规范。
  • 移动端预览：窄屏按短行重排提升可读。

算例参考

  • 按 40 字宽换行：一段 120 字说明设宽度 40，拆成 3 行各约 40 字，在等宽字体下整齐；注意不在单词中间断（除非开启强制断）。

注意事项

结果为按上述公式得到的理论估算值，实际表现受数据分布、实现细节与运行环境影响，落地决策请以实测为准；本工具纯前端运行，输入不上传服务器。
