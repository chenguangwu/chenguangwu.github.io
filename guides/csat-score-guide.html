CSAT客户满意度评分 使用指南

录入各星级评价人数，自动计算 CSAT 得分、满意度分布与 NPS 趋势参考，评估客户体验。

功能说明

录入各星级评价人数，自动计算 CSAT 得分、满意度分布与 NPS 趋势参考，评估客户体验。

典型使用场景

  • 满意度核算：录入各星级评价人数（1-5 星），工具算出 CSAT（4-5 星占比）、NPS（推荐者−贬损者）、平均星级与等级评定。
  • 服务评级：按 CSAT 阈值（≥90 优秀 / ≥75 良好 / ≥50 合格 / 否则需改善）给出等级，结合贬损者占比判断是否触发整改。
  • 趋势对比：将不同周期（本月 vs 上月）的星级分布分别核算，量化服务改善幅度，支撑 KPI 考核与团队激励。

算例参考

  • 算例：100 条评价（5星50 / 4星30 / 3星12 / 2星5 / 1星3）：总评价 100；满意(4+5星)=80 → CSAT = 80.0%（良好）；推荐者(5星)=50% → NPS = 50% − 贬损者(1+2星=8%) = 42；平均星级 = (3×1+5×2+12×3+30×4+50×5)/100 = 4.19；贬损者占比 8.0%。结论：满意度良好，但仍有 8% 贬损者，建议针对差评工单做根因分析。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

CSAT 和 NPS 有什么区别？
CSAT 衡量「满意」（4-5 星占比），关注整体体验；NPS 衡量「忠诚」（推荐者% − 贬损者%），关注复购与口碑。本工具二者同屏给出：上例 CSAT=80%、NPS=42。
等级评定依据什么阈值？
CSAT ≥90 为优秀、≥75 为良好、≥50 为合格、低于 50 为需改善。上例 80% 处于「良好」档；若贬损者占比 >20% 会额外提示负面口碑风险。
