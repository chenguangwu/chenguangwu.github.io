向量点积 使用指南

(1,2,3)·(4,5,6)=1·4+2·5+3·6=32。…

核心功能

  • 计算两个向量的点积（内积）
  • 支持 2D 到 5D 维度切换
  • 点积为 0 说明两向量正交
  • 可用于相似度、投影与夹角计算

适用场景

  • 判断向量夹角、投影、相似度计算。
  • 做推荐或检索时衡量相似度：把两个特征向量做点积（或归一化后的余弦），判断它们方向上是否接近。

使用步骤

  1. 选择向量维度（2D 到 5D）
  2. 分别填入两个向量的各分量
  3. 点计算得到点积
  4. 点积为 0 即两向量垂直，可用来验证正交性
  5. 结合模长可反推夹角：cosθ = 点积 /（|a||b|）

实用技巧

  • 因此比较「方向是否接近」时应用余弦（如文本相似度），而点积同时含长度与方向，适合需要兼顾强度的场景（如注意力权重）

常见问题

点积为 0 含义？
两向量正交（垂直）。
点积和余弦相似度是一回事吗？
不完全。点积 = |a||b|cosθ，会受向量长度影响；余弦相似度再除以两个模长，只保留方向信息。因此比较「方向是否接近」时应用余弦（如文本相似度），而点积同时含长度与方向，适合需要兼顾强度的场景（如注意力权重）。
