应税所得 = 固定扣除 / 边际税率 使用指南

盈亏平衡应税额计算器：结合固定扣除与边际税率，估算达到税后目标所需的应税所得，用于税务筹划。

计算公式与原理

税前沿 = 税后/(1−r)。

估算达到税后目标所需的应税所得。

使用步骤

  1. 填写「目标税后所得」。
  2. 填写「免税/扣除额」。
  3. 填写「税率 (%)」。
  4. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 股东或经营者想拿到手 target 元，反推需要申报多少应税所得。
  • 已知固定扣除 deduct 与比例税率 r，求实现目标净所得的税前门槛。
  • 测算分红、薪酬设计的税前平衡点。

算例参考

  • 目标到手 75 万、税率 25%、无扣除：所需应税所得 = (750000 + 0) / (1 − 0.25) = 1,000,000 元；应纳税额 = 1,000,000 × 0.25 = 250,000 元，税后正好 75 万。
  • 含扣除的情形：若还可扣除 10 万（deduct=100000），则应税所得 = (750000 + 100000) / 0.75 = 1,133,333 元，比无扣除时少申报 13.3 万。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

公式为什么是 (target+deduct)/(1−r)？
税后所得 = 应税所得×(1−r) − deduct，移项得应税所得 = (税后所得 + deduct)/(1−r)。
税率 r 用小数还是百分数？
本工具 r 输入百分数（如 25 代表 25%），内部换算为 0.25 参与 (1−r) 计算。
