哈希碰撞概率 使用指南

输入哈希空间位数与已存入的条目数量，工具用生日攻击模型估算发生碰撞的概率，提醒在 n 接近 √2^bits 时风险显著上升。

计算公式与原理

P ≈ 1 − e^(−n(n−1)/(2·2ᵇⁱᵗˢ))

输入哈希空间位数与已存入的条目数量，工具用生日攻击模型估算发生碰撞的概率，提醒在 n 接近 √2^bits 时风险显著上升。

典型使用场景

  • 去重/分桶设计：评估哈希桶规模接近平方根时冲突陡增的风险。
  • 唯一 ID 规划：为短 ID 选择足够位宽以控制业务内碰撞率。
  • 安全边界：说明短哈希用于标识而非防碰撞的极限。

算例参考

  • 示例：32 位哈希、7.7 万条：约 5 万条时碰撞概率已近 1%，接近 √(2^32)≈6.5 万后快速上升，需升到 64 位。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。
