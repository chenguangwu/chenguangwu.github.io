User-Agent 解析器 使用指南

UA 串包含浏览器、系统、设备等信息。本工具把一段 UA 解析为结构化字段，便于日志分析、兼容判断。本地解析。

核心功能

  • 解析浏览器/版本
  • 识别 OS 与设备
  • 判别爬虫/移动端
  • 结构化展示
  • 本地处理

适用场景

  • 分析访问日志来源
  • 做浏览器兼容分支
  • 识别爬虫流量

使用步骤

  1. 粘贴 UA 字符串
  2. 点击解析
  3. 查看结构化字段

实用技巧

  • UA 可被伪造，判断需谨慎
  • 移动端含 "Mobile" 关键字
  • 新版 Chrome 带 "Edg"/"Chrome" 双标识
