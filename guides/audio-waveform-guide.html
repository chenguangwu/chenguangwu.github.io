音频波形显示工具 使用指南

在线音频波形显示工具，基于 Web Audio API 实时绘制时域波形与频域频谱（FFT），支持本地文件分析，适合音频调试，纯前端。

功能说明

在线音频波形显示工具，基于 Web Audio API 实时绘制时域波形与频域频谱（FFT），支持本地文件分析，适合音频调试，纯前端。

典型使用场景

  • 调试录音或混音时观察时域波形，判断音量是否过载、有无静音段与爆音。
  • 分析一段音频的频域能量分布，定位某频率的嗡嗡声或共振峰。
  • 教学或演示时把声音可视化，直观展示振幅与频谱的关系。

算例参考

  • FFT 频谱参数示例：在 Web Audio 中用 AnalyserNode 取数据：设 fftSize=2048，则频域 bin 数为 1024，频率分辨率 = 采样率÷fftSize = 44100÷2048 ≈ 21.5Hz/bin。叠加汉宁窗（Hann）可减少频谱泄漏。时域波形则直接反映每个采样点的振幅（−1~+1），纵轴常按 dB 或线性幅度显示。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

为什么频谱图会糊成一片？
分辨率不够或没加窗函数会导致泄漏。增大 fftSize 可提高频率分辨率（但时间分辨率下降），并对信号加汉宁/汉明窗抑制边缘不连续，频谱会更清晰锐利。
波形上看不见声音但能听到？
可能是极小幅度的超声波段或相位抵消在单声道显示时被平均，也可能是波形纵轴缩放在满量程而信号很小。可放大纵轴或切换频谱视图交叉验证。
