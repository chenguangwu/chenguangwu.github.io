BPM 速度转换器 使用指南

BPM 与音符时长、延迟时间、LFO 频率、采样长度互转，音乐制作与 DJ 必备

功能说明

BPM 与音符时长、延迟时间、LFO 频率、采样长度互转，音乐制作与 DJ 必备

使用步骤

  1. 填写「BPM 数值 (40-300)」。
  2. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 编曲时把 BPM 转成四分音符毫秒，对齐音符网格与延迟时间
  • 给 LFO/颤音设与 BPM 同步的频率（如每拍一次的滤波扫频）
  • 按采样率算某音符占多少采样点，做精准切片

算例参考

  • BPM 转音符时长：120 BPM → 四分音符 = 60000/120 = 500 ms；八分 = 250 ms、十六分 = 125 ms、附点四分 = 500×1.5 = 750 ms。
  • LFO 与采样数：120 BPM 下每拍 500 ms；要 LFO 每拍一个周期，频率 = 1000/500 = 2 Hz。44100 Hz 采样率下四分音符 = round(500/1000×44100) = 22050 个采样点。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

BPM 和毫秒怎么互转？
四分音符毫秒 = 60000 / BPM；已知某音符毫秒 ms，对应 BPM = 60000 × 该音符的拍数 / ms（如八分音符拍数 0.5）。
LFO 同步频率怎么算？
周期毫秒 = 四分音符毫秒 × 倍数（每拍=1、每两拍=2），频率(Hz) = 1000 / 周期毫秒；如每小节(4 拍)一次 = 1000/(500×4)=0.5 Hz。
