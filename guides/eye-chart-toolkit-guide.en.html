Eye Chart Toolkit

A toolkit of standard eye charts (Snellen and logMAR) with distance helpers, so you can do a quick, repeatable visual-acuity check at home or in a clinic.

Contents
  • Key Features
  • Use Cases
  • How to Use

Key Features

  • Snellen and logMAR charts
  • Distance guidance
  • Per-eye testing
  • Printable-friendly
  • 100% client-side

Use Cases

  • Rough acuity check
  • Classroom or workplace screen
  • Monitoring over time

How to Use

  1. Set the recommended distance
  2. Cover one eye
  3. Read the smallest line you can
  4. Record the line
  5. Switch eyes

Practical Tips

  • Consistent lighting and distance
  • Don’t lean forward
  • Glasses as you normally wear them
  • Confirm with an optometrist

FAQ

Is this accurate?
It is a rough screen, not a refraction; real acuity needs professional measurement.
Snellen vs logMAR?
Both express acuity; logMAR is the modern, linearly scalable standard.
