IPv6 ULA Generator 使用指南

随机 ULA 前缀如 「fd12:3456:789a::/48」（48 位全局 ID 随机，后接子网）。

核心功能

  • 按 RFC 4193 生成唯一的本地 IPv6 地址（ULA，fc00::/7）
  • 可一次生成多个地址
  • 含 /48 前缀与 /64 子网的结构，便于内网规划
  • 地址在本地生成，不上传

适用场景

  • 生成 fd00::/8 的唯一本地地址用于内网。
  • 搭建内网或实验环境：生成 fd00::/8 段内的 /48 前缀，再自行划分子网，避免与公网路由冲突。

使用步骤

  1. 填要生成的数量
  2. 点生成得到 ULA 前缀与地址
  3. 把 /48 前缀按子网再划分为多个 /64 分配给不同网段
  4. 在路由器或主机上配置该地址（ULA 不能在公网路由）
  5. 记录所生成前缀，重建时若需保持不变应显式指定而非随机生成

实用技巧

  • 不能，fd00::/8 仅本地通信，类似 IPv4 私网
  • 搭建内网或实验环境：生成 fd00::/8 段内的 /48 前缀，再自行划分子网，避免与公网路由冲突。

常见问题

ULA 能上公网吗？
不能，fd00::/8 仅本地通信，类似 IPv4 私网。
为什么要随机生成 Global ID？
RFC 4193 要求 ULA 的 40 位 Global ID 用随机算法生成，而不是手写 fd00:0000:0000::/48 之类。目的是保证两家组织的地址空间几乎不可能重合，将来做 VPN 互联或公司合并时不会出现地址冲突。
