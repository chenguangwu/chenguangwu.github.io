提取 IP 地址 使用指南

从日志或文档中一键提取所有 IPv4/IPv6 地址并去重列出，方便网络排查、访问统计与数据清洗整理。

功能说明

从日志或文档中一键提取所有 IPv4/IPv6 地址并去重列出，方便网络排查、访问统计与数据清洗整理。

典型使用场景

  • 安全审计与日志分析：从访问日志抽出来源/目标 IPv4，定位异常流量。
  • 网络排查：汇总设备 IP 做资产与连通性核对。
  • 数据脱敏预检：先抽全部 IP 再决定是否打码。

算例参考

  • 从 Nginx 日志抽 IP：日志含「192.168.1.10 - - [..]」「203.0.113.5 - - [...]」，工具抽得两个 IPv4 并统计频次，便于发现高频访问源。

注意事项

本工具在浏览器本地运行，输入内容不会上传服务器；结果为模型估算，工程决策请结合实测数据复核。
