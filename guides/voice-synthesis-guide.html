语音合成 使用指南

基于浏览器 Web Speech API，将文字朗读为语音，支持中英文、语速音调调节

功能说明

基于浏览器 Web Speech API，将文字朗读为语音，支持中英文、语速音调调节

典型使用场景

  • 视障辅助阅读：粘贴长文，选中文语音（zh），点击朗读，浏览器本地合成语音逐字播报，配合读屏软件实现无障碍阅读，文本不上传服务器。
  • 中英文切换：语言筛选切到英文，选择 en 语音，朗读 “Hello, how are you today?”，语速/音调可调（0.5~2.0），适配不同听力偏好。
  • 公共语音提示：用预制“请注意安全，慢行通过。”等提示语，调音量/语速生成候车厅、走廊广播稿，循环播放或导出。

算例参考

  • 算例：默认文本朗读：默认文本“欢迎使用语音合成工具，在这里输入文字即可朗读。”（含标点共 23 字），选中文语音、语速 1.0、音调 1.0、音量 1.0，点击朗读后状态显示“朗读中… 第 N 字”并按 onboundary 实时更新字符进度；朗读完显示“朗读完成”。语音由浏览器内置引擎本地合成，无需联网。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

语音合成需要联网吗？
不需要。本工具调用浏览器内置的 Web Speech API（speechSynthesis）在本地合成语音，文字不上传服务器；不同浏览器/系统可用的声音列表不同，以本机安装的语言包为准。
为什么听不到声音？
部分浏览器需在用户手动点击“朗读”后才会发声（如 iOS Safari 的安全策略）；若页面提示“当前浏览器不支持 Web Speech API”，请改用 Chrome / Edge / Safari 最新版。
