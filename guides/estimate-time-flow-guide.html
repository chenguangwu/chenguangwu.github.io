人员安全疏散时间估算（流量法） 使用指南

人员安全疏散时间估算器（流量法）。输入人员密度、出口宽度与流量系数，按流量法估算疏散所需总时间，用于建筑消防疏散设计与安全评估。

计算公式与原理

T = L/v + P/(W×F) + Tpre

将行走时间、出口排队时间和预动作时间相加，估算人员完成疏散所需时间。

典型使用场景

  • 疏散设计中，由人数、出口宽度、人流速度与行走距离估算总疏散时间。
  • 预案编制时，把行走时间、出口排队时间与预动作时间叠加得到总耗时。
  • 出口能力不足会形成排队瓶颈，是疏散时间的主要来源。

算例参考

  • 算例：100 人、出口宽 2m、流量 1.5 人/(s·m)、距离 30m、速度 1.2m/s、预动作 30s：行走 = 30/1.2 = 25.0 s；排队 = 100/(2×1.5) = 33.3 s；总疏散 = 25.0 + 33.3 + 30 = 88.3 s（≈1.47 min）；出口能力 = 2×1.5 = 3.00 人/s。
  • 算例：瓶颈识别：总时间 = 行走 + 排队 + 预动作，其中『排队 = 人数/(出口宽×单位宽度流量)』对结果最敏感。加宽出口或分流可显著压降排队时间。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

单位宽度人流流量取多少？
常见设计取值约 1.3–1.5 人/(s·m)（水平出口），楼梯略低。实际受人员构成、熟悉度影响，本工具以输入为准，取值应参考现行疏散设计规范。
预动作时间是什么？
指人员发现火情到开始撤离的反应时间（察觉、判断、广播、起身），通常 30–60 s 量级。它不依赖出口能力，但占疏散总时长的相当比例，演练可显著缩短。
