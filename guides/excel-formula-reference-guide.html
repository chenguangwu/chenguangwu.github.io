Excel 公式速查表使用指南

按函数名或用途搜索 27 个常用 Excel 函数，每条都给出语法模板、可直接粘贴的示例公式、示例数据、预期结果和适用版本；支持中英文关键词、分类筛选和本地 CSV 导出。

功能说明

页面收录汇总、统计、逻辑、查找、文本与动态数组六类函数。搜索会匹配函数名、中英文说明、分类和常见别名（例如「条件计数」「lookup」「average」），并自动去掉首尾空格；分类按钮可叠加搜索条件。结果区显示匹配数量，无结果时列出清除与常用关键词入口。

怎么用

  1. 在顶部搜索框输入函数名或用途，例如 SUMIFS、「条件计数」或 average；需要缩小范围时点分类按钮。
  2. 在条目中先看「语法模板」了解参数顺序，再看「示例公式」和「示例数据」；示例是可直接粘贴的完整公式，预期结果用于自检。
  3. 点「复制语法模板」或「复制示例公式」，到 Excel 中把示例区域替换成自己的单元格；复制失败时页面会选中文本，按 Ctrl+C 即可。
  4. 需要离线留存时点「导出当前结果 CSV」，导出内容跟随当前搜索和分类，中文/英文表头随页面语言切换。

典型使用场景

  • 做月度销售报表时，搜索「多条件求和」找到 SUMIFS，复制示例后替换地区、月份和销售额区域。
  • 升级 Excel 前搜索 XLOOKUP、FILTER、UNIQUE，核对版本标签；旧版改用 INDEX+MATCH、VLOOKUP 或辅助列。
  • 清洗系统导出的文本时，用 TRIM 去多余空格、SUBSTITUTE 去分隔符、LEFT/RIGHT/MID 截取编号，再复制示例验证。

算例参考

示例：按地区和月份汇总销售额。假设 A2:A5 是地区（East/West/East/North）、B2:B5 是月份、C2:C5 是销售额，统计 East 且 Jan 的总额：=SUMIFS(C2:C5,A2:A5,"East",B2:B5,"Jan")，预期结果为 300。复制后把三个区域替换成实际列；若本机列表分隔符是分号，把公式中的逗号换成 ;。

注意事项

  • 示例统一用逗号作列表分隔符；Windows 区域设置使用分号时，Excel 会要求把参数分隔符改成 ;。
  • 语法模板里的中文占位（如「查找值」「区域」）不能直接执行，必须换成单元格或实际值；示例公式才是可粘贴版本。
  • XLOOKUP 需要 Microsoft 365 或 Excel 2021+；FILTER、UNIQUE、SORT 需要支持动态数组的 365/2021+，旧版会返回 #NAME?。
  • 动态数组公式下方要留空，否则可能显示 #SPILL!；复制示例前先确认目标区域没有被其他内容占用。

隐私说明

搜索、筛选和复制全部在当前浏览器中完成，不记录搜索词、不写入历史、不上传服务器；刷新页面即清空输入。导出的 CSV 只包含当前筛选结果，由浏览器本地生成。

常见问题

如何快速查找某个函数？
在顶部搜索框输入函数名或用途关键词（如 VLOOKUP、查找、条件计数），支持中英文和首尾空格；也可以点分类按钮筛选。结果会显示匹配数量，无结果时提供清除与常用关键词。
示例公式可以直接用吗？
每条都区分“语法模板”和“可直接粘贴的示例公式”，示例附有示例数据与预期结果；复制前请把示例区域替换成你的单元格，并确认本机列表分隔符是逗号还是分号。
XLOOKUP、FILTER 等新函数在旧版 Excel 能用吗？
XLOOKUP 需要 Microsoft 365 或 Excel 2021 及以上；FILTER、UNIQUE、SORT 需要支持动态数组的 365/2021 及以上。旧版请用 INDEX+MATCH、VLOOKUP 或高级筛选替代，条目内会标注适用版本。
搜索词会被保存吗？
不会。搜索和筛选只在当前浏览器内存中完成，不写入搜索历史、不上传服务器；刷新页面即清空输入。
