由中心频率与带宽求品质因数 使用指南

输入中心频率 f0 与 −3dB 带宽 Δf，按 Q=f0/Δf 求品质因数，评估谐振系统选择性。

计算公式与原理

Q = f₀ / Δf

输入中心频率 f0 与 -3dB 带宽 Δf，求品质因数 Q。

使用步骤

  1. 填写「中心频率 f₀ (Hz)」。
  2. 填写「带宽 Δf (Hz)」。
  3. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 谐振器 Q = f0 / 带宽，衡量储能与损耗比。
  • 滤波器选择性、腔体 Q 评估。
  • 对比窄带高 Q 与宽带低 Q。

算例参考

  • f0=1000Hz、BW=100Hz：Q = 1000 / 100 = 10；若 BW 收窄到 10Hz，则 Q=100（更高选择性）。
  • 低 Q：若 BW=500Hz，则 Q=2，宽带低选择性、损耗相对大。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。
