XML 校验器 使用指南

XML 常用于配置与数据交换。本工具解析并校验格式良好性（well-formed），指出未闭合标签或非法字符的位置。纯前端，数据不上传。

核心功能

  • 标签闭合校验
  • 属性引号检查
  • 嵌套层级检查
  • 错误行定位
  • 本地处理

适用场景

  • 排查配置文件报错
  • 校验接口返回的 XML
  • 检查 RSS / SVG 合法性

使用步骤

  1. 粘贴 XML
  2. 点击校验
  3. 查看通过提示或错误位置

实用技巧

  • 格式良好不等于 schema 合法
  • CDATA 内文本不被解析
  • 注意大小写敏感

常见问题

格式良好和合法有什么不同？
格式良好只检查语法；合法还需符合 DTD/XSD 约束。
能给个例子吗？
<a><b>1</a> 缺 b 闭合，会报未闭合标签。
