IBAN 校验 使用指南

IBAN = 国别码(2 字母)+ 校验位(2 数字)+ 本国账号 BBAN。如 DE89 3704 0044 0532 0130 00：DE 德国、89 校验位、后接德国账号。

核心功能

  • 按 ISO 13616 校验 IBAN 的国家代码与长度
  • 用 mod-97 算法验证两位校验位
  • 解析国家码与 BBAN 结构
  • 可点击目标国家加载标准示例账号

适用场景

  • 校验国际银行账号 IBAN 格式与校验位
  • 跨境汇款前防错
  • 识别国家码与 BBAN 结构
  • MOD-97 算法

使用步骤

  1. 选择目标国家，确认该国 IBAN 的标准长度
  2. 粘贴或输入 IBAN（可含空格）
  3. 页面把前 4 位移到末尾，再将字母转为数字（A=10…Z=35）
  4. 对转换后的整数取模 97，判断余数是否为 1
  5. 读取校验结论与结构解析，用于汇款前复核

实用技巧

  • 校验通过仅说明格式与校验位正确，不代表账户真实存在；大额汇款建议先小额试汇
  • 各国 IBAN 长度不同（15–34 位），跨币种汇款前先确认收款国标准长度
  • 手工录入时分 4 位一组更易发现漏位，空格会被自动忽略
  • IBAN 是国码+校验位+本地账号（BBAN）的标准化封装，国内转账仍用本地账号

常见问题

IBAN 和账号关系？
IBAN 是在本国账号(BBAN)前加国码与校验位的标准化形式，便于跨国自动校验路由；本国内部仍用本地账号。
校验通过就一定能汇款吗？
通过仅说明格式与校验位正确；能否到账还取决于账户真实存在、行号有效及收款行政策，大额建议先小额试汇。
