Password Strength Checker

The Password Strength Checker scores a password on length, variety and patterns, helping users pick stronger credentials. It never stores or sends input.

  • Local only

Use Cases

  • Validate a field

How to Use

  1. Type the password
  2. Read the score
  3. Apply the suggestions

  • Avoid dictionary words
