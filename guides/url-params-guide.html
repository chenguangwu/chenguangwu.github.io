URL 参数解析器 使用指南

URL 查询串（?a=1&b=2）常需解析、重组或编码。本工具把 URL / 查询串拆成结构化键值对，并支持编码解码。

目录 适用场景 · 操作步骤 · 注意事项 · 常见问题

适用场景

  • 调试接口时查看请求带了哪些参数
  • 从复杂 URL 中批量提取某个参数
  • 构造带正确编码的查询串

操作步骤

  1. 粘贴完整 URL 或仅查询串（? 之后）
  2. 点击解析，得到键值对列表，可排序/筛选
  3. 对值做 URL 解码（如 %E4%BD%A0 还原为中文）
  4. 复制结构化结果或重组后的 URL

注意事项

  • 参数值常经 URL 编码，直接看是 %XX 形式，需解码才可读
  • 同名参数（a=1&a=2）应解析为数组，注意后端取值方式
  • 构造 URL 时特殊字符务必编码，避免截断或注入

常见问题（FAQ）

%+ 和空格？

空格可编码为 %20 或 +（仅查询串），解码时注意上下文。

同名参数怎么处理？

标准允许多次出现，解析为数组；后端可能只取第一个。

hash(#) 后的参数能解析吗？

# 后是 fragment，不在查询串里，需单独处理。
