价格（行情/成本/竞争）分析 使用指南

价格（行情/成本/竞争）分析工具。输入产品价格、成本与竞品数据，按通用财务规则测算毛利率与竞争定位，用于消防产品定价与经营分析（结果仅供参考）。

计算公式与原理

毛利 = 售价 - 单位成本；毛利率 = 毛利 / 售价

用售价、单位成本和竞品价格列表评估单件利润、毛利率与市场价格位置。

典型使用场景

  • 定价与竞品分析是销售策略的基础：由售价、单位成本与竞品价格带，量化毛利、毛利率与市场定位。
  • 新品定价或调价时，需对照竞品区间判断自身处于高价、低价还是中段，避免定价脱离市场。
  • 毛利率低于行业基准时需回溯成本结构或调整售价，竞品均价是重要参照锚点。

算例参考

  • 算例：售价 100、成本 60、竞品[80,90,100,110,120]：单件毛利 = 100 − 60 = 40.00 元；毛利率 = 40/100×100 = 40.00%；竞品均价 = (80+90+100+110+120)/5 = 100.00 元；售价相对竞品均价 = (100/100−1)×100 = 0.00% → 处于竞品区间。
  • 算例：价格位置判定：若售价 < 最低竞品则『低于全部竞品』，> 最高竞品则『高于全部竞品』，否则『处于竞品区间』。结论随竞品集合与售价实时变化，输入至少 1 个有效竞品价才有意义。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

毛利率和单件毛利有什么区别？
单件毛利=售价−成本（绝对额，元），毛利率=毛利÷售价×100%（相对比例）。毛利率排除了售价量级影响，更适合跨品类、跨价位比较。
竞品价格带不完整会影响结论吗？
会。最低/最高竞品决定『高于/低于全部竞品』的判定，均价决定相对位置。样本过少或漏掉关键竞品会使定位失真，建议覆盖主流竞品后再下结论。
