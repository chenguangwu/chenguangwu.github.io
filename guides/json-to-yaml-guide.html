JSON 转 YAML 使用指南

YAML 是 JSON 的超集，用缩进表达层级、更适合人读。输入 JSON 即得等价的 YAML，本地转换不上传。

核心功能

  • JSON→YAML 转换
  • 保持层级与类型
  • 支持缩进配置
  • 可双向校验
  • 本地处理

适用场景

  • 写 Kubernetes / Docker Compose 配置
  • 把接口 JSON 转可读文档
  • 配置文件格式迁移

使用步骤

  1. 粘贴 JSON
  2. 点击转换查看 YAML
  3. 复制或下载

实用技巧

  • YAML 用缩进表示层级，别用 Tab
  • 字符串含特殊字符会加引号
  • YAML 是 JSON 超集，可转换回去
