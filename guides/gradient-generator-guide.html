CSS 渐变生成器 使用指南

渐变是常用背景装饰。本工具调节起止色、角度与色标，实时预览并复制 linear/radial-gradient 代码。纯前端，不上传。

核心功能

  • 线性/径向渐变
  • 角度与色标调节
  • 实时预览
  • CSS 代码输出
  • 本地处理

适用场景

  • 按钮/背景装饰
  • 卡片封面渐变
  • 落地页 hero 区

使用步骤

  1. 加色标调角度
  2. 实时预览
  3. 复制 CSS

实用技巧

  • 至少两个色标
  • 角度 0–360
  • 可用透明度色标
