由各级增益(dB)求总增益 使用指南

输入多级（如三级）增益 dB 值，按 G_total(dB) = Σ Gᵢ 求总增益并换算为线性倍率，用于射频级联放大器与链路预算计算。

计算公式与原理

20=27 dB → 线性≈501。

输入三级增益（dB），求总增益与线性总增益。

使用步骤

  1. 填写「第1级增益 G₁ (dB)」。
  2. 填写「第2级增益 G₂ (dB)」。
  3. 填写「第3级增益 G₃ (dB)」。
  4. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 多级放大器/衰减器总增益按 dB 直接相加。
  • 已知各级 g1/g2/g3 求总 dB 与线性倍率。
  • 含负增益（衰减）的链路测算。

算例参考

  • g1=10、g2=−3、g3=20 dB：总增益 = 10 − 3 + 20 = 27 dB；线性倍率 = 10^(27/10) ≈ 10^2.7 ≈ 501 倍。
  • 净衰减：若三级均 −3dB，则总 −9dB、线性 ≈ 0.126 倍（约衰减到 1/8）。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

为什么 dB 直接相加？
dB 是对数单位，级联相乘对应对数相加，故总增益为各级 dB 之和。
负 dB 代表什么？
负 dB 表示衰减，如 −3dB 约衰减到 0.707 倍（一半功率）。
