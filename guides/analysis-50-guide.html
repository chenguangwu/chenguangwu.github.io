竞争格局与市场份额测算 使用指南

先按已录企业算样本内份额与 HHI；只有录入市场总规模且覆盖完整市场时，才使用 2500/1500 阈值判集中度。

功能说明

逐行输入「企业名,营收」，工具计算各企业份额、CR3、CR5 与 HHI。目标市场总规模是选填项：留空时分母取已录企业合计，所有标签显示「样本内」，不判完整市场集中度；填写后先算覆盖率，只有覆盖率 100% 才给「高度集中/中度集中/竞争分散」结论。

输入与校验

  • 每行一条「企业,营收」，支持半角/全角逗号、顿号、分号或制表符；企业名不能为空。
  • 营收必须是大于 0 的数字，带文字（如 12abc）会按原行号报错并阻止计算；不再静默跳过。
  • 市场总规模必须与营收使用同一单位（如都为万元）；已录企业合计大于市场总规模时属于口径矛盾，页面会拒绝计算。
  • 企业数少于 3 时，CR3 只是已录企业合计，页面会单独提示，不能当完整市场 CR3。

操作步骤

  1. 先把同一口径、同一期间的企业营收按行录入。
  2. 需要判断完整市场时再填目标市场总规模；不确定时留空，只看样本内份额。
  3. 点击计算，先看覆盖率与「样本内/完整市场」标签，再看 CR3、HHI 与企业数提示。
  4. 若已录合计大于市场总规模，回到原始数据核对单位、期间与重复计算。

算例

A 300、B 200、C 100，未填市场总规模：已录合计 600，样本内份额 50.0%/33.3%/16.7%，HHI=3888.89，CR3=100%，但页面固定「不做完整市场集中度判定」。把市场总规模填为 600 后，覆盖率 100%，才判「高度集中」。若市场总规模填 10000，覆盖率仅 6%，HHI=14，不套 2500/1500 阈值。

注意事项

样本内 HHI 只描述已录企业，不能外推为行业集中度；HHI 阈值只在完整市场口径下使用。营收单位不影响份额比例，但同一份输入内必须统一。工具不自动校验企业间重复、关联交易或会计口径差异。

不填市场总规模还能用吗？
可以，但只能得到样本内份额与样本内 HHI，页面会明确标注，不判完整市场集中度。
覆盖率不是 100% 时能判集中度吗？
不能。页面只展示已知企业份额与 HHI，不套 2500/1500 阈值；需要补充未录入企业或完整市场总规模。
数据会保存或上传吗？
全部在浏览器本地计算；刷新后输入会恢复默认示例，不上传服务器。
