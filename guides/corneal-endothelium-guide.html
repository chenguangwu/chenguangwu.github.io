角膜内皮细胞密度形态计数器 使用指南

基于角膜内皮显微镜照片，计算内皮细胞密度(CD)、变异系数(CV)和六角形比例(6A)，评估角膜内皮功能。

计算公式与原理

细胞密度 CD = 细胞数 / 框面积（cells/mm²）；变异系数 CV = SD / 平均细胞面积；六角形比例 6A = 六角形细胞数 / 总细胞数 × 100%

CD ≥ 2500 正常、1500–2500 临界、 0.40 异常；六角形比例 ≥ 55% 正常、50%–55% 临界。

典型使用场景

  • 镜面照相计数与面积求细胞密度 CD = 计数/面积（cells/mm²）。
  • 变异系数 CV = 标准差/平均面积评估多形性。
  • 六边型细胞比例评估稳定性。

算例参考

  • 计数 2500、面积 1mm²：CD = 2500 / 1 = 2500 cells/mm²（正常成人约 2000–3000）；若 CV 低、六边形 >60% 则形态良好。
  • 密度下降：若 CD<1000 提示内皮失代偿风险，白内障手术须谨慎评估。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

CV 高说明什么？
