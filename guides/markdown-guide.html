Markdown 实时预览 使用指南

在左侧编辑区输入 Markdown，右侧实时渲染标题、列表、代码块等效果，支持即时对照，便于写作与格式校对。

功能说明

在左侧编辑区输入 Markdown，右侧实时渲染标题、列表、代码块等效果，支持即时对照，便于写作与格式校对。

典型使用场景

  • 写 README、博客与文档：实时把 Markdown 渲染为带标题、列表、表格、代码的排版，确认效果后再发布。
  • Markdown 转 HTML：把写好的 .md 导出为网页片段，嵌入 CMS 或邮件。
  • 格式校验：检查嵌套列表、代码块围栏是否闭合，避免发布后错版。

注意事项

本工具在浏览器本地运行，输入内容不会上传服务器；结果为模型估算，工程决策请结合实测数据复核。

和标准 Markdown 有差异吗？
本工具按 GitHub 风格 GFM 解析（支持表格、删除线、任务列表）；若你用严格 CommonMark，部分扩展语法（如表格）在标准里不定义，迁移时注意。
HTML 混写安全吗？
Markdown 允许内联 HTML，但发布到公网前需确认不过滤危险标签；本工具仅本地渲染，不上传内容。
