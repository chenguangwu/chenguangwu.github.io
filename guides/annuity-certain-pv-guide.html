保险年金定价基础 使用指南

输入年金期数 n 与每期利率 i，按年金现值系数 a_n| = (1 − vⁿ)/i 计算确定年金的现值因子，用于寿险保费厘定与年金产品定价的精算基础计算。

计算公式与原理

PV = C·(1−(1+i)^−n)/i

确定年金现值 a_n| = (1 − v^n) / i。

使用步骤

  1. 填写「年金额 (元)」。
  2. 填写「年利率 i」。
  3. 填写「年数 (年)」。
  4. 结果区会即时更新；可一键复制结果用于记录或汇报。

典型使用场景

  • 算一笔每年固定领、领 n 年的年金，现在值多少钱，用于定价或比较产品。
  • 把未来一系列确定给付折现到当下，看内部回报率是否合理。

算例参考

  • 年领 1.2 万、3%、15 年：PV = 12000×(1−1.03⁻¹⁵)/0.03 = 12000×11.9379 ≈ 143254 元。即 15 年每年 1.2 万、3% 折现的现值约 14.3 万。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

利率 i 用多少？
用预定利率或市场可比收益率。i 越高现值越低；3% 是常见演示利率，实际以合同预定利率为准。
定价利率和演示利率能混用吗？
不能。定价利率是计算保费的保守假设（监管设上限），演示利率用于利益展示可更高；混用会高估客户收益、低估公司负债。
