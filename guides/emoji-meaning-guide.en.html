Emoji Meaning Lookup

The Emoji Meaning tool resolves an emoji to its Unicode name and codepoint, helpful when you need the canonical label for accessibility or search.

Contents
  • Key Features
  • Use Cases
  • How to Use
  • Practical Tips

Key Features

  • Shows name and codepoint
  • Unicode version
  • Copy the escape sequence
  • Search by keyword
  • Local only

Use Cases

  • Find an emoji name for a label
  • Get the codepoint for CSS
  • Teach Unicode
  • Clarify a glyph

How to Use

  1. Paste or search the emoji
  2. Read its metadata
  3. Copy what you need

Practical Tips

  • Some emoji are sequences of codepoints
  • Skin tones add variation selectors
  • Names help screen readers
