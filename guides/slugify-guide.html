URL Slug 生成器 使用指南

Slug 是 URL 中可读的路径段，如 "how-to-use-toolbox"。本工具把标题转小写、去标点、空格换连字符，并尽量保留语义，利于 SEO 与分享。本地转换。

核心功能

  • 标题→slug 转换
  • 空格/下划线转连字符
  • 去除或保留停用词
  • 支持中文转拼音
  • 本地处理

适用场景

  • 博客/文章 URL 生成
  • 商品页友好链接
  • 批量处理标题

使用步骤

  1. 粘贴标题文本
  2. 选分隔符与语言策略
  3. 点击生成
  4. 复制 slug

实用技巧

  • slug 短而含关键词更利 SEO
  • 避免连续连字符
  • 中文建议转拼音或保留英文关键词
