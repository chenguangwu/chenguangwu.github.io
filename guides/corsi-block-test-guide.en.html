Corsi Block-Tapping Test

The Corsi Block-Tapping Test assesses visual-spatial working memory. The system highlights a sequence of blocks; you tap them back in the same (forward) or reverse (backward) order. A staircase procedure adapts difficulty, and everything runs locally in your browser.

Key Features

  • Forward and backward recall modes
  • Adaptive staircase difficulty
  • Visual-spatial span scoring
  • Product-score (sum of correct sequence lengths)
  • Age-norm reference (child ~4.8, adult ~5.5, elderly ~4.9)
  • 100% client-side

Use Cases

  • Self-check of spatial memory
  • Clinical or research screening aid
  • Cognitive training and tracking

How to Use

  1. Pick a recall mode (forward/backward)
  2. Watch the blocks light up in sequence
  3. Tap the blocks back in order
  4. Continue as length grows
  5. Read your span and product score

Practical Tips

  • Minimize distractions during the task
  • Backward span is harder and more sensitive
  • One low run is normal; trends matter
  • Use as a training tracker, not a diagnosis

FAQ

Corsi vs digit span?
Corsi measures visual-spatial memory (location sequences); digit span measures verbal/phonological memory (number sequences).
Is a low score a problem?
A single low run is usually not concerning; if it persists, consider a professional assessment.
