JSON 格式化 使用指南

JSON 是前后端通信的事实标准，但原始的压缩 JSON 难以阅读。ToolBox JSON 格式化工具在本地帮你美化缩进、校验语法错误、折叠展开节点，是调试接口返回值的得力助手。

核心功能

  • 一键美化：压缩 JSON 按层级缩进显示
  • 语法校验：定位缺失的引号、逗号、括号等错误
  • 紧凑模式：把美化后的 JSON 再压缩成单行
  • 树形折叠：大对象可逐层展开/收起
  • 复制结果：格式化后一键复制

适用场景

  • 对接接口时查看后端返回的 JSON 结构
  • 排查前端报错：定位 JSON.parse 失败的准确位置
  • 整理配置文件、日志片段
  • 对比两份 JSON 的结构差异

使用步骤

  1. 把原始 JSON 粘贴到左侧输入框
  2. 点击"格式化"，右侧出现带缩进的结果
  3. 若提示语法错误，按高亮位置修正后重试
  4. 需要折叠时点击行首三角收起子节点
  5. 点击"复制"把结果用于代码或文档

实用技巧

  • 格式化前先确认内容确实为 JSON，而非 XML 或 YAML
  • 超长单行 JSON 建议先格式化再阅读，错误位置更易定位
  • 生产环境不要把包含密钥的 JSON 粘贴到不可信的在线工具，本地工具更安全

常见问题

为什么提示 JSON 语法错误？
常见原因是尾部多了逗号、键名没加双引号、或使用了单引号；按提示位置修正即可。
格式化会修改数据吗？
不会，仅调整排版与缩进，数据内容保持不变。
