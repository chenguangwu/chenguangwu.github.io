遗址探方计算 使用指南

根据遗址范围与探方规格计算探方数量、发掘面积与各探方坐标（西南角为原点，北为 X 正向、东为 Y 正向）

功能说明

根据遗址范围与探方规格计算探方数量、发掘面积与各探方坐标（西南角为原点，北为 X 正向、东为 Y 正向）

典型使用场景

  • 布方时按遗址范围与发掘计划确定探方规格（常用 5×5m 或 10×10m），计算所需探方数量与总发掘面积，并编排探方编号。
  • 建立统一坐标网格：以遗址西南角为原点，北为 X 正向、东为 Y 正向，将每个探方西南角坐标（如 T0503 = X50 Y30）标注于探方登记表。
  • 矩形遗址用取整加边界法：行数=ceil(南北长/规格)、列数=ceil(东西宽/规格)，再扣掉完全落在遗址外的边角探方。

算例参考

  • 100m×60m 遗址布 5m 探方：列数=ceil(100/5)=20，行数=ceil(60/5)=12，探方总数=20×12=240 个，发掘面积=240×25=6000 m²。西南角首方记为 T0000（或 T0101 依惯例），向东列号递增、向北行号递增。

注意事项

本工具纯前端运行，输入内容不上传服务器；结果为按上述口径得到的理论估算值。实际应用受设备参数、测量条件与当地规范影响，请以设备铭牌、检测报告与现行标准为准，重大决策建议咨询专业人士。

探方编号 T0503 是什么意思？
常见约定中 T 后四位或两位数字分别表示 X、Y 坐标的十米/五米格。例如 5m 探方下 T0503 指西南角位于 X=50m、Y=30m 处；具体位数与原点以该遗址《发掘方案》为准。
为什么探方要统一规格？
统一规格便于层位、遗物出土单位（context）横向对比与面积统计，也方便后期用坐标回放 GIS。规格不同会导致层位划分与遗物密度不可比。
