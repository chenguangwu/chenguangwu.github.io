## 2. 统一验收环境

每个页面至少使用以下组合复测：

| 环境 | 视口 | 重点 |
|---|---|---|
| Desktop | 1280x900 | 布局、键盘、焦点、桌面信息密度 |
| Mobile | 390x844 | 触控、单栏布局、底部安全区、横向溢出 |
| Zoom | 200% | 内容重排、按钮可见性、文字裁切 |
| Theme | light/dark | 对比度、边框、结果态和禁用态 |

浏览器复测应通过本地 HTTP 服务进行，不使用 `file://`：

```bash
python3 -m http.server 8765
```

## 3. 每页固定检查项

### 3.1 结构与加载

- 页面返回状态正常，标题、description 和 canonical 存在且合理。
- 公共 CSS、公共 JS、页面专属资源和图片均能加载。
- 控制台无未处理的 JavaScript 异常。
- 页面首屏没有明显空白、错位或加载中的永久残留。
- 页面只有一个可识别的主标题，导航和面包屑可理解。

### 3.2 移动端布局

- 390px 宽度无横向滚动。
- 主要输入、主按钮和结果区在首屏可找到。
- 触控目标约不小于 44px，按钮之间不会误触。
- 固定底栏、sticky 区域和系统安全区不遮挡内容。
- 键盘弹出后输入和结果仍能滚动到可见位置。
- 长文本、长数字、错误提示和空状态不会撑破卡片。

### 3.3 键盘和无障碍

- Tab 顺序符合页面视觉顺序。
- 所有图标按钮都有可访问名称。
- 焦点环清晰可见，不被 overflow 或背景色吞掉。
- 输入框有对应 label，错误提示能关联到输入。
- 弹层可通过 Esc 关闭，关闭后焦点回到触发按钮。
- 复制、下载、重置和提交等核心操作不依赖鼠标。
- `prefers-reduced-motion` 下没有强制长动画。

### 3.4 功能状态

- 空输入或首次进入状态。
- 正常输入和正常结果。
- 边界值、非法值、超长文本或不支持的文件类型。
- 计算中、模型加载中、处理失败和下载失败状态（适用时）。
- 复制成功、复制失败、重置后状态和重复操作。
- 切换主题、刷新页面和返回首页后状态合理。

## 5. 优先级定义

- `P0`：页面无法使用、核心按钮被遮挡、键盘无法退出弹层、文件数据无法处理或存在明显数据损坏风险。
- `P1`：主要路径仍可完成，但移动端、键盘、焦点、错误反馈或结果展示明显不可靠。
- `P2`：间距、动效、视觉一致性、非核心文案和次要交互优化。

修复顺序固定为 `P0 -> 公共 P1 -> 页面 P1 -> P2`。盘点阶段只登记问题，不以“顺便修复”为验收条件。
