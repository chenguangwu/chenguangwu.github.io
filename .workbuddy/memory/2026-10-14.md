### 批次5 新增教训（判据 → 处置，下批直接套）
1. **无初始调用的页面，初始 `calculate()` 必须放进 `__xxBoot()` 的 DCL 分支，不能裸放在脚本末尾**。裸放会让 harness 在「编译+执行期」就触达输入控件，改变 `elements` 键序 ⇒ 撞碎依赖「输入回显顺序」的自动补强用例（debt/statute 的 `abc123测试` 例，expect 是值回显顺序串）。放进 Boot 后桩里 readyState≠loading 且 TBKit 未定义 ⇒ 分支不执行 ⇒ 顺序零变化。
2. **初始调用一律 `try{ fn(); }catch(e){}`**：日期页注入非法值时 `new Date('abc')` → `toISOString()` 抛 Invalid time value，裸调用会让整页「初始化失败」。
3. **`__xxD` 清空 + 空态清容器**：包装器开头 `__xxD=null`，extras 里 `if(!D){ 清空 Chart/Table; return; }` ⇒ 用户清空日期时不会残留上一次的图表。
4. **`__xxExtras()` 后必须再调 `__xxMountHist()`**：`history.mount` 只在调用那一刻快照列表，原先只在 Boot 调一次 ⇒ 历史面板永远只有 1 条、点了预设也不涨。改为每次计算后重挂即可累积（实测 1→8 条）。
5. **预设值不得与页面默认值相同**：相同则点了没任何变化 = 装饰性卡片（loan/debt/statute 第 1 个预设踩中，已改成不同日期）。
6. **替换 HTML 字符串片段时别把引号写进 new**：`'...<div class="lbl">中文</div></div>'` 只替换 `<div class="lbl">中文</div></div>` 时，new 必须写成 `<div class="lbl">' + ptL(...) + '</div></div>`；误写成 `'<div class="lbl">'+...` 会提前闭合字符串 ⇒ `Unexpected token 'class'`。**改完立刻 `node --check` 抽出的脚本**（比跑门禁快 100 倍）。
7. **per-tool 字典 i18n JSON 必须用原始缩进重写**（本项目是 `indent=1` + 末尾换行）：用 `indent=2` 会把整文件重写成 50+ 行噪音 diff。
8. **双语 helper 前缀必须与页面一致**：debt 页误写 `lsL()`（loan 的前缀）⇒ `lsL is not defined`，且被 `try/catch` 静默吞掉，表现为「EN 门禁报无图表渲染」而非明确报错。排查手段：直接在最小桩里 `sb.calculate()` 打印真实异常。
9. **日期型页面英文化要连 `fmtDate` 一起改**：返回 `2035年3月20日` 这种中文日期格式，须加 ISO 分支 `ptL(zh, en)`；verify expect 若锚中文格式（如 `2035年3月`）仍走 zh 分支，不受影响。

### 批次6 新增教训（判据 → 处置，下批直接套）
1. **extras 访问不到 `calculate()` 内的局部常量**（legal-age 的 `const milestones`）⇒ `milestones is not defined` 被 try/catch 吞掉，表现为「EN 门禁报无图表渲染」而非明确报错。修法：随 `__xxD` 携带（`ms: milestones`）或提到顶层。**排查手段：把 `catch(e){}` 临时换成 `catch(e){console.log(e.message)}` 在最小桩里跑一次**，比猜快十倍。
2. **🔴 history.record 的值必须能回填到 option value**：展示用全称（`typeNames['养老']='养老保险'`）⇒ `select.value='养老保险'` 静默失败变空 ⇒ 后续 `cfg[insType]` undefined ⇒ `calc()` 崩溃（表格不再更新，用户侧表现为「点了历史没反应」）。修法：record 存**双语短名** `xxL(短key, EN[短key])`，restore 侧写**双向反查**（英→key、中→key 都覆盖）。social-security 的 city/insType、calc-interest 的 method 同法处理。
3. **英文态历史面板会显示中文值**（city='北京'）⇒ 真浏览器取证报泄漏。上一条的双语短名同时解决展示与回填，一举两得。
4. **结果区双语化是硬门槛且范围比预期大**：EN 门禁扫 `allHtml` 前 4000 字符，包含**所有**动态渲染容器（result / baseTable / allResult / singleResult / faqList / taxResult / lawTip / compHistory …），默认态能渲染出来的都要翻。本批六页共 88 条替换（含 FAQ 8 条问答、8 条法援分支、5 条城市名、5 条险种名）。
5. **模板串/拼接串里的中文要连同全角标点一起包进 helper**：`laL('出生日期：','Date of birth: ')`。只翻文字、留下 `：` 仍会被 FW_PUNCT 命中。
